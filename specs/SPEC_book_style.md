# SPEC — สไตล์หนังสือของคู่มือ 2 เล่ม (By_Unit · By_Topic) · 2026-10-27

ผู้ใช้ขอให้ทั้งสองเล่ม "อ่านเป็นหนังสือ" ไม่ใช่โน้ตอัด ๆ: มีช่องไฟ มีบทนำก่อนเข้าเนื้อหา แบ่งหัวข้อชัด ไม่มีประโยคตัวอย่างต่อกันเป็นพรืดด้วย `·` และไม่ตัดคำผิดที่
ตัวจัดหน้า (`scripts/make_pdf.py`) ทำเรื่องฟอนต์ ระยะ หัว/ท้ายกระดาษ สารบัญ เลขข้อ และการไม่ตัดคำเกาหลีให้แล้ว —
**ไฟล์เนื้อหาต้องทำส่วนที่เหลือ** ตามกติกาข้างล่าง ไฟล์ตัวอย่างที่ถูกต้อง = `content/guide/01_units/unit23.md` และ `content/guide/02_grammar/37_b-irregular.md`

## 1. หัวข้อ = โครงสร้าง (ตัวจัดหน้าอาศัยหัวข้อ)

| ระดับ | ใช้กับ | ตัวจัดหน้าทำอะไร |
|:---|:---|:---|
| `#` | ชื่อส่วน (ส่วนที่ N) — มีในไฟล์ header เท่านั้น | หน้าใหม่ทั้งหน้า |
| `##` | **บท** (NN과) หรือ **หัวข้อไวยากรณ์** (NN.) — หนึ่งต่อไฟล์ | ขึ้นหน้าใหม่ ชื่อบทตัวใหญ่ ขีดเส้นใต้ ขึ้นสารบัญ และเป็นหัวกระดาษของทุกหน้าในบท |
| `###` | **ตอน** ภายในบท | เลขตอนอัตโนมัติ (1. 2. 3. …) ระยะเว้นเหนือหัวข้อ ไม่ทิ้งหัวข้อไว้ท้ายหน้า |
| `####` | ตอนย่อย | ตัวหนา ระยะเว้นเล็กลง |

- **ห้ามใช้บรรทัดตัวหนาแทนหัวข้อ** (`**📝 ไวยากรณ์**` ✗) — มันไม่ได้เลขตอน ไม่ได้ระยะ และสารบัญ/หัวกระดาษไม่เห็น
- **ห้ามใส่เลขตอนเอง** ใน `###` (ตัวจัดหน้าใส่ให้) — ไอคอนอีโมจินำหน้าได้ เช่น `### 📝 ไวยากรณ์: ㅂ 불규칙`
- ข้อไวยากรณ์แต่ละข้อในบท = `###` ของตัวเอง ไม่ใช่รายการเลข `1. **…**` ที่ซ้อนตารางอยู่ข้างใน
- ชื่อบท: `## 23과 · 불고기는 맵지 않은 음식이에요 (บุลโกกิเป็นอาหารที่ไม่เผ็ด)` · ชื่อหัวข้อ: `## 37. ㅂ 불규칙 (ㅂ ไม่ปกติ: 맵다 → 매워요)`

## 2. ทุกบทมีบทนำและบทสรุป

- บรรทัดแรกหลัง `##` คือกล่อง **`> [!INTRO] บทนี้ว่าด้วยอะไร`** (3–8 ประโยคภาษาไทยธรรมดา): สถานการณ์ที่ใช้ · บทนี้จะเจออะไรบ้าง (ไวยากรณ์กี่ข้อ ชื่ออะไร คืออะไรในหนึ่งประโยค) · มีไว้ทำไม/ต่างจากที่เรียนมาอย่างไร · จบบทแล้วทำอะไรได้ · จุดที่คนไทยมักงง
  หัวข้อไวยากรณ์ (เล่ม 2) ใช้กล่องเดียวกัน: คืออะไร · ใช้เมื่อไร · สอนในบทไหน · ต่อยอดจากข้อไหน / ไปใช้ต่อข้อไหน
- **ทุก `###` ขึ้นต้นด้วยประโยคนำ 1–3 ประโยค** ก่อนตาราง/รายการ ("ตอนนี้จะดู… · สังเกตว่า…") — ห้ามให้ตารางหรือรายการโผล่มาทันทีใต้หัวข้อ
- ปิดบทด้วยกล่อง **`> [!SUMMARY] สรุปท้ายบท`** 3–6 ข้อ: กฎที่ต้องจำ · รูปที่ออกสอบ · ข้อผิดที่ต้องระวัง

กล่องที่ใช้ได้: `[!INTRO]` `[!SUMMARY]` `[!TIP]` `[!WARNING]` `[!NOTE]` `[!IMPORTANT]` `[!CAUTION]` — เขียนชื่อกล่องต่อท้ายได้ (`> [!WARNING] ที่น่าจะพลาดในข้อสอบ`) ถ้าไม่ใส่จะได้ชื่อมาตรฐานภาษาไทย

## 3. ความหนาแน่น — หนึ่งตัวอย่างต่อหนึ่งบรรทัด

- ในย่อหน้า/บุลเล็ต ต่อกันด้วย `·` ได้**ไม่เกิน 3 ชิ้น** (เช่น "맵다 · 덥다 · 춥다") — ชุดที่ยาวกว่านั้นต้องเป็น **รายการ** (หนึ่งบรรทัดต่อหนึ่งชิ้น) หรือ **ตาราง**
- **ประโยคตัวอย่างทุกประโยคอยู่บรรทัดของตัวเอง พร้อมคำแปลไทยในบรรทัดเดียวกัน**: `- 김치가 매워요. *(กิมจิเผ็ด)*` หรือแถวตาราง `| 김치가 매워요. | กิมจิเผ็ด |`
  ห้ามรวมคำแปลไว้ท้ายชุด (`… · 아이가 귀여워요 *(กิมจิเผ็ด · อากาศร้อน · …)*` ✗)
- บุลเล็ตหนึ่งข้อยาวไม่เกิน ~2 บรรทัดเมื่อพิมพ์ (≈ 160 ตัวอักษร) · รายการซ้อนได้ 2 ชั้น · ห้ามวางตารางไว้ในบุลเล็ต (ย้ายออกมาใต้ `####`)
- ตาราง: ไม่เกิน 4 คอลัมน์ (ตารางผัน 5 ได้) · หัวคอลัมน์สั้น · คอลัมน์แรกสั้น (คำเดียว/วลีเดียว) · ในหนึ่งช่องไม่เกิน 3 ชิ้นต่อ `·` · ตารางตัวอย่าง = `| 한국어 | ไทย |` (+ คอลัมน์ "สังเกต" ได้)
- ย่อหน้าภาษาไทยธรรมดาเขียนเป็นประโยคเต็ม มีจุดจบความ ไม่ใช่วลีต่อกันด้วย `·` และ `—`

## 4. โครงบทรายบท (เล่ม 1 · `01_units/unitNN.md`)

```
## NN과 · 제목 (ไทย)
> [!INTRO] บทนี้ว่าด้วยอะไร
### 🗣️ คำศัพท์ที่ต้องรู้ก่อน         ประโยคนำ + ตารางคำคู่ | 한국어 | ไทย | 한국어 | ไทย | (เฉพาะคำสำคัญ ~16–24 คำ; รายการเต็มอยู่ท้ายบทจากชีตศูนย์)
### 📝 ไวยากรณ์: <ชื่อข้อ> (ไวยากรณ์ข้อ NN)   หนึ่ง ### ต่อหนึ่งข้อ:
    ย่อหน้านำ: คืออะไร ใช้เมื่อไร ต่างจากที่รู้อยู่อย่างไร (2–4 ประโยค)
    #### รูปแบบ                      ตารางเงื่อนไข (ราก | ต่อท้าย | ตัวอย่าง)
    #### ตัวอย่างจากตำรา               รายการ/ตาราง หนึ่งประโยคต่อบรรทัด ระบุหน้า/연습 ที่มา
    #### 📽️ จากสไลด์อาจารย์             (ถ้ามี — เก็บเนื้อหาเดิมทั้งหมด)
    #### ⚠️ ระวัง                       บุลเล็ตสั้น ๆ + ข้อผิดจริงของผู้เรียนที่เกี่ยว
    → เจาะลึก: ไวยากรณ์ข้อ NN (เล่ม 2)
### 💬 대화 NN-1                      ประโยคนำ (ใคร ที่ไหน คุยเรื่องอะไร) → บทสนทนาแบบ > quote → #### สังเกตจากบทสนทนา → #### ฝึกสลับ (ตาราง)
### 📖 읽기 NN-2 · 🎧 듣기             ประโยคนำ → บทอ่าน (> quote) → #### คำถามท้ายบทอ่าน (ตาราง คำถาม | คำตอบ) → #### 활동
### 🔊 발음                           ประโยคนำ → ตาราง | เขียน | อ่าน | กฎ |
### 🧪 ออกสอบอย่างไร                  ประโยคนำ → บุลเล็ต (ข้อสอบจริง/ใบฝึกที่เคยเจอ · คะแนน · ข้อผิด) → > [!WARNING] ที่น่าจะพลาด
### 🔗 เชื่อมโยง                      ← ต่อยอดจาก (รายการ) · → ใช้ต่อใน (รายการ)
> [!SUMMARY] สรุปท้ายบท
```
ส่วน `💬` `📖` `🔊` ที่บทไหนไม่มีก็ข้าม (เช่น 26과 มีแค่หน้าไวยากรณ์) — ห้ามแต่งเนื้อหาตำราเพิ่ม

## 7. สิ่งที่ห้ามเปลี่ยน (เนื้อหาเดิมต้องครบ)

- **ข้อเท็จจริงทั้งหมดต้องอยู่ครบ**: ทุกประโยคเกาหลีตัวอย่าง · เลขหน้าตำรา · เนื้อหาสไลด์อาจารย์ `📽️` · คำอธิบายภาพ `🖼️` · บันทึกข้อสอบ/คะแนน/ข้อผิดของผู้เรียน (★ ⚠️) · การอ้าง "ไวยากรณ์ข้อ NN" · หมายเหตุ "เสริม" (ไม่อยู่ในตำรา) · เครื่องหมาย ✓ ✗
  งานนี้คือ **จัดเรียงใหม่และเขียนย่อหน้านำ** ไม่ใช่เขียนเนื้อหาใหม่ — ห้ามแต่งประโยคตัวอย่างเกาหลีเพิ่ม (แต่งได้เฉพาะข้อความอธิบายภาษาไทย)
- คำแปลไทยของประโยคเกาหลีเขียนในรูป `*(…)*` ต่อท้ายประโยคเสมอ (ระบบสีอาศัยรูปแบบนี้) · แท็กสี `{n:…}` ที่มีอยู่แล้วคงไว้ทุกตัว · เสียงอ่าน `[…]` คงไว้
- บทสนทนา: บรรทัด `> 가: …` คั่นด้วยบรรทัด `>` เปล่า · ห้าม `~~` · ห้าม HTML (ยกเว้น `<details>` เดิมของแบบทดสอบ) · ห้ามใช้ `{` `}` นอกจากแท็กสี
- `01_units/00_header.md` และ `02_grammar/00_header.md` มีเพียง `#` ชื่อส่วน + ย่อหน้านำสั้น ๆ

## 8. ตรวจก่อนส่ง (ต่อไฟล์)

1. `grep -c '^\*\*' file` = 0 (ไม่มีบรรทัดตัวหนาแทนหัวข้อ) · มี `> [!INTRO]` 1 กล่อง และ `> [!SUMMARY]` 1 กล่อง
2. ไม่มีบรรทัดที่มี `·` มากกว่า 3 ตัวนอกตาราง: `grep -nv '^|' file | awk -F'·' 'NF>4'` ต้องว่าง (ยกเว้นรายการคำศัพท์สั้น ๆ ที่ตั้งใจ)
3. ทุก `###` ตามด้วยย่อหน้าข้อความก่อนตาราง/รายการ
4. จำนวนประโยคเกาหลี (`grep -o '[가-힣]\+' | wc -l`) ไม่น้อยกว่าไฟล์เดิมเกิน 5 %
5. ไฟล์เดิมถูกเขียนทับ (ไม่สร้างไฟล์ใหม่) · ไม่มี `~~` · ไม่มี `{` นอกแท็กสี
