*สอบวันพุธที่ 14 ต.ค. 2026 · เก็งจากแบบทดสอบจริง 5–17과 (13 ชุด) + หนังสือเรียน + เวิร์กบุ๊ก + ใบฝึก 18과 ที่แจกวันนี้*

> [!IMPORTANT]
> **นี่คือการเดา ไม่ใช่ข้อสอบจริง** แต่การเก็ง 17과 เมื่อวานตรงรูปแบบทุกส่วน ข้อ A 3–4 ตรงทั้งประโยค และคำบอกข้อ 8 ตรงทุกตัวอักษร

- ตรงชั่วโมงพอดีไม่มี 분: 9:00 = 아홉 시 · 30 นาที = 삼십 분 หรือ 반 (반 ไม่มี 분 ต่อท้าย)
- AM/PM วางหน้าสุด: PM 11:30 = **오후** 열한 시 반 · AM 8:40 = **오전** 여덟 시 사십 분
- 몇 시**예요**? (시 ไม่มีตัวสะกด) แต่ 십 분**이에요** / 반**이에요** (มีตัวสะกด)
- บอกเวลาที่ทำกิจกรรมต้องมี 에: 일곱 시**에** 일어나요 · 오후 네 시**에** 해요 (แต่ 지금 몇 시예요? ไม่มี 에)
- เว้นวรรคหน้า 시 และ 분 เสมอ: 두 시 이십 분 (เมื่อวานเขียน 두시 이십분 ติดกัน)

#### 2.4 ตาราง -(으)러 + คู่สถานที่/จุดประสงค์ที่หนังสือใช้

| กฎ | ตัวอย่าง |
|:---|:---|
| ไม่มีตัวสะกด → 러 | 사러 · 보러 · 배우러 · 만나러 · 마시러 · 빌리러 · 추러 · 부르러 · 자르러 |
| ตัวสะกด ㄹ → 러 (ไม่เติม 으) | 만들러 · 놀러 · 살러 |
| ตัวสะกดอื่น → 으러 | 먹으러 · 읽으러 · 씻으러 · 입으러 · 찾으러 · 찍으러 · 받으러 |
| 하다 → 하러 | 운동하러 · 공부하러 · 쇼핑하러 · 숙제하러 · 일하러 · 노래하러 · 청소하러 |

| สถานที่ | ไปทำอะไร | ประโยคเต็ม |
|:---|:---|:---|
| 서점 | 책을 사다 | 서점에 책을 사러 가요. |
| 체육관 | 운동하다 / 태권도를 배우다 | 체육관에 운동하러 가요. |
| 도서관 | 책을 빌리다 | 도서관에 책을 빌리러 가요. |
| 은행 | 돈을 찾다 | 은행에 돈을 찾으러 가요. |
| 미용실 | 머리를 자르다 | 미용실에 머리를 자르러 가요. |
| 학원 | 러시아어를 가르치다 | 학원에 러시아어를 가르치러 가요. |
| 운동장 | 농구를 하다 | 운동장에 농구를 하러 가요. |
| 노래방 | 노래를 부르다 | 노래방에 노래를 부르러 가요. |
| 백화점 / 동대문 시장 | 옷을 사다 | 옷을 사러 백화점에 가요. |
| 용산 | 컴퓨터를 사다 | 용산에 컴퓨터를 사러 가요. |
| 이태원 | 외국 음식을 먹다 | 이태원에 외국 음식을 먹으러 가요. |

| 화장실 | 손을 씻다 | 손을 씻으러 화장실에 가요. |
| 사진관 | 사진을 찍다 | 사진을 찍으러 사진관에 가요. |
| PC방 | 게임을 하다 | PC방에 게임을 하러 가요. |

- ลำดับคำสลับได้ทั้งสองแบบ: 서점에 책을 사러 가요 = 책을 사러 서점에 가요 (หนังสือใช้ทั้งคู่)
- -(으)러 **ไม่ผันตามกาล** ผันที่ 가다 ตัวเดียว: 명동에 쇼핑하러 **갔어요**? · 책을 빌리러 **가겠어요**
- หลัง -(으)러 ต้องเป็นกริยาเคลื่อนที่ 가다/오다/다니다 เท่านั้น

#### 2.5 จุดที่คุณเคยพลาดเอง (จากงานที่ตรวจไปแล้ว — รวมสอบ 17과 เมื่อวาน)

1. **ㅈ กับ ㅊ สลับกันทั้งสองทาง** — เสียคะแนนแล้ว 3 ครั้ง: 가족→가촉 (สอบ 15), 책→젝 และ 청소 ที่ ㅊ ไม่มีขีดบน (สอบ 17) · คืนนี้เขียน 책 · 체육관 · 청소 · 친구 · 집 ช้า ๆ 3 รอบ
2. **생활 → 생할** (สอบ 17 ข้อ 9) · 활 = ㅎ + ㅘ + ㄹ
3. **열심히 → 열심이** (สอบ 17 ข้อ 10) · คำวิเศษณ์ลงท้าย 히
4. **씻러 ✗ → 씻으러** (เวิร์กบุ๊ก 18과 ข้อ 2-3) · มีตัวสะกด ㅅ ต้องเติม 으 — ในตารางใบฝึกเขียนถูก แต่พอเขียนเองลืม
5. **ลืม 분**: 사십오 이에요 ✗ → 사십오 분이에요 (เวิร์กบุ๊ก 18과 ข้อ 3-3)
6. **เว้นวรรค 시/분**: 두시 이십분 → 두 시 이십 분
7. **-(으)러 ต้องมีกรรมถ้าตัวอย่างมี**: 사러 → 과일을 사러 · 찍으러 → 사진을 찍으러 (เวิร์กบุ๊ก 18과 ข้อ 2-4, 2-5)
8. เดิม: 학생였어요 ✗ → 학생이었어요 · 어떻었어요 ✗ → 어땠어요 · 받십니다 ✗ → 받으십니다 · 백화점에 샀어요 ✗ → 백화점에서 샀어요
