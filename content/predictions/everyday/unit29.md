#### 2.2 V-(으)ㄴ + N — สูตรสั้น (เต็มในไวยากรณ์ข้อ 47)

ตารางนี้สรุปการผันกริยาให้ขยายคำนามแบบอดีต ("…ที่ …แล้ว")

| รากกริยา | รูป | ตัวอย่าง |
|:---|:---|:---|
| ไม่มีตัวสะกด | ราก + **ㄴ** | 가다 → **간** · 오다 → **온** · 보다 → **본** · 배우다 → **배운** · 마시다 → **마신** · 쓰다 → **쓴** · 주다 → **준** · 쉬다 → **쉰** · 기다리다 → **기다린** |
| มีตัวสะกด | ราก + **은** | 먹다 → **먹은** · 읽다 → **읽은** · 입다 → **입은** · 받다 → **받은** · 닫다 → **닫은** |
| ราก ㄹ | ตัด ㄹ แล้ว + ㄴ | 살다 → **산** · 만들다 → **만든** · 팔다 → **판** · 놀다 → **논** · 열다 → **연** |
| ㅂ 불규칙 | ㅂ → 우 + ㄴ | 돕다 → **도운** |
| -하다 | 하 → 한 | 운동하다 → **운동한** · 전화하다 → **전화한** |
| ปฏิเสธ | -지 않은 | 아침을 먹지 않은 사람 (않 มีตัวสะกด → 은) |
| 있다 · 없다 · 좋아하다 | ใช้ **-는** (ไม่ใช้ -(으)ㄴ) | 맛있는 · 좋아하는 사람 |
| คำคุณศัพท์ | -(으)ㄴ = ปัจจุบัน (ไม่ใช่อดีต) | 친절한 사람 · 키가 큰 사람 |
| ประธาน/กรรมในอนุประโยค | ยังเป็น 이/가 · 을/를 ตามปกติ | 책**을** 읽은 사람 (✗ 책이 읽은) · 제**가** 만든 음식 |

ลำดับทำ: ① หาคำบอกเวลา (어제/지난주 = อดีต → -(으)ㄴ · 지금/자주 = -는) ② ดูตัวสะกดของราก ③ ราก ㄹ ตัด ㄹ ④ ใส่ ㄴ หรือ 은 ⑤ วางหน้าคำนามที่ขีดเส้นใต้ ⑥ คัดคำอื่นให้ครบ (좀 · 에)

| คำถามที่ต้องตอบ | ราก | ผ่านกฎ | ผล |
|:---|:---|:---|:---|
| คนที่อ่านหนังสือเมื่อวาน | 읽다 | มีตัวสะกด → 은 | 어제 책을 **읽은** 사람 |
| อาหารที่ฉันทำ | 만들다 | ราก ㄹ → ตัด ㄹ + ㄴ | 제가 **만든** 음식 |
| คนที่ช่วยเมื่อสัปดาห์ที่แล้ว | 돕다 | ㅂ → 우 + ㄴ | 지난주에 제가 **도운** 할머니 |
| เพื่อนที่เจอเมื่อวาน | 만나다 | ไม่มีตัวสะกด → ㄴ | 어제 **만난** 친구 |
| ภาษาที่เรียนอยู่ตอนนี้ | 배우다 | **지금 → -는** | 지금 **배우는** 외국어 |

#### 2.3 A/V-아/어/여서 — สูตรสั้น (เต็มในไวยากรณ์ข้อ 48)

| รากลงท้าย | ต่อท้าย | ตัวอย่าง |
|:---|:---|:---|
| สระ ㅏ / ㅗ | **-아서** | 많아서 · 좋아서 · 타서 · 가서 · 와서 · 봐서 (보 + 아 = 봐) |
| สระอื่น | **-어서** | 먹어서 · 없어서 · 맛있어서 · 재미없어서 · 쉬어서 · 길어서 |
| -하다 | **-해서** | 피곤해서 · 청소해서 · 깨끗해서 · 빨래해서 |
| ㅡ ตก (쓰다 · 아프다 · 바쁘다 · 예쁘다 · 고프다) | ตัด ㅡ แล้วดูสระก่อนหน้า | 써서 · 아파서 · 바빠서 · 예뻐서 · 배가 고파서 |
| ㅂ 불규칙 | ㅂ → 워 (돕다·곱다 → 와) | 추워서 · 더워서 · 매워서 · 가까워서 · 도와서 |
| ราก 이/ี + 어 (주다 · 마시다 · 치다 · 배우다) | รวมเสียง | 줘서 · 마셔서 · 쳐서 · 배워서 |
| นาม + 이다 (ลงท้ายพยัญชนะ) | **N이어서** | 학생이어서 · 겨울이어서 · 생일이어서 · 고등학생이어서 |

| ราก ㄹ (놀다 · 길다 · 멀다) | ㄹ ไม่ตก | 놀아서 · 길어서 · 멀어서 |

ลำดับทำ: ① ตัด -다 ② ดูสระสุดท้ายของราก: ㅏ ㅗ → 아 / อื่น → 어 / 하 → 해 ③ ปรับ ㅡ ㅂ ④ + 서 ⑤ **ห้ามใส่ -았/었- หรือ -겠- หน้า 서** ⑥ ดูประโยคหลัง: **ห้ามคำสั่ง/ชวน**

| สไลด์ครู — ประโยคหลังของ -아/어/여서 | ผล | ตัวอย่างกับ 시험이 있어서 |
|:---|:---|:---|
| -(으)세요 (สั่ง) | ✗ | 시험이 있어서 공부하세요 ✗ |
| -(으)ㄹ까요? (ชวนถาม) | ✗ | 시험이 있어서 공부할까요? ✗ |
| 같이 -아/어/여요 (ชวน) | ✗ | 시험이 있어서 같이 공부해요 ✗ |
| -았/었어요 · -아/어요 | ✓ | 시험이 있어서 공부했어요 · 공부해요 |
| -(으)ㄹ 거예요 | ✓ | 시험이 있어서 공부할 거예요 |
| -고 싶어요 · -고 있어요 · -겠어요 | ✓ | 공부하고 싶어요 · 공부하고 있어요 · 공부하겠어요 |

#### 2.4 -는 หรือ -(으)ㄴ — ดูคำบอกเวลา

สูตรเต็มของ -는 อยู่ที่ไวยากรณ์ข้อ 44 (27과) ตารางนี้ช่วยแยกสองรูปที่ใบฝึก C ผสมกัน

| คำบอกเวลา / เบาะแส | รูปที่ใช้ | ตัวอย่าง |
|:---|:---|:---|
| 지금 · 요즘 · 매일 · 자주 · 보통 · -고 있어요 | **-는** (ปัจจุบัน/ประจำ) | 지금 **배우는** 외국어 · 자주 **먹는** 음식 · 제가 자주 **만나는** 친구 · 지금 같이 **사는** 친구 |
| 어제 · 지난주 · 작년 · 아까 · -았/었어요 | **-(으)ㄴ** (อดีต) | 어제 **배운** 문법 · 지난주에 **간** 식당 · 어제 **만든** 케이크 |
| 있다 · 없다 · 계시다 · 좋아하다 (เป็นสภาพ) | **-는** เสมอ | 맛있는 · 좋아하는 사람 |
| คำคุณศัพท์ (좋다 · 예쁘다 · 친절하다) | **-(으)ㄴ** = ปัจจุบัน | 예쁜 꽃 · 친절한 사람 |
| ราก ㄹ | -는: ตัด ㄹ (사는) · -(으)ㄴ: ตัด ㄹ (산 · 만든) | 지금 사는 친구 · 어제 만든 케이크 |

### 7. ก่อนสอบ 10 นาที — เช็กลิสต์

- **อ่านโจทย์ทั้งหน้าก่อนเลือกคำตอบ:** คำตอบของบางข้ออยู่ในประโยคที่พิมพ์ไว้ข้าง ๆ (28과 ข้อ 6 · 8 เสียไป 2 คะแนน)
- **-(으)ㄴ + N:** ไม่มีตัวสะกด → ㄴ (간 · 온 · 본 · 배운 · 쓴) · มีตัวสะกด → **은** (먹은 · 읽은 · 입은 · 받은) · ราก ㄹ ตัด ㄹ (산 · 만든 · 판 · 논) · ㅂ → 도운 · -하다 → 한
- **ดูคำบอกเวลาก่อนเติม:** 지금 · 자주 · 요즘 → **-는** (배우는 · 먹는 · 사는) / 어제 · 지난주 · 작년 → **-(으)ㄴ**
- **เติมเฉพาะที่ช่องต้องการ + คัดคำอื่นให้ครบ:** 좀 · 에 · 을/를 · อย่าซ้ำ 은/는 หลังช่อง
- **-아/어/여서:** ㅏ ㅗ → 아서 · อื่น → 어서 (**ห้ามตก 어**: 맛있어서 · 재미없어서) · 하 → 해서 · ㅡ ตก (써서 · 아파서 · 바빠서 · 예뻐서) · ㅂ → 워/와 (추워서 · 도와서) · 이어서 / 여서 (겨울이어서 · 의사여서)
- **ห้ามใส่ -았/었-/-겠- หน้า 서 · ประโยคหลังห้ามสั่ง/ชวน:** ✗ 왔어서 · ✗ 공부하세요 · ✗ 공부할까요? · ✗ 같이 공부해요
- **ตอบ 왜요? ด้วยเหตุผล + 서** (시간이 없어서 · 날씨가 추워서)
- **กริยาสวมใส่:** 모자 · 안경 = **쓰다** / 운동화 · 구두 = **신다** / 치마 · 바지 · 옷 = **입다**

- **ตัวเขียน:** ㅈ/ㅊ (죄송 · 취미 · 축제 · 가르친) · ㅐ/ㅔ (택시 · 내년 · 괜찮다) · 가 ไม่ใช่ 기 · 피 ต้องมี ㅣ
