#### 1.4 จุดอ่อนส่วนตัวที่ต้องปิดก่อนวันศุกร์ (เรียงตามคะแนนที่เคยเสียจริง)

1. **ㅈ/ㅊ** — เสียคะแนนมาแล้ว 5 ครั้ง (저/처 · 책/젝 · 청소 · 몇/몆 · 차/자) → เขียนช้าลงเฉพาะ 4 คำนี้: **책 · 청소 · 몇 · 차** และ ㅈ ไม่มีขีดบน
2. **조사 จุดหมาย = 에** (학생식당하고 가요 ✗) · **에 vs 에서** (백화점에 샀어요 ✗)
3. **คำบอกตำแหน่ง** — คำที่อยู่หน้า 앞/뒤/옆 คือจุดอ้างอิง (พลาด 2 ครั้ง: 쓰기 7 · 읽기 8)
4. **으 หลัง 받침** — 받**으**십니다 · 씻**으**러 · 읽**으**세요 (พลาด 3 ครั้ง)
5. **เปลี่ยนรูปสุภาพต้องคงกาล** — 안 했어요 → 안 했**습니다** (ไม่ใช่ 하지 않습니다)
6. **ตอบให้ตรง 의문사** — 언제 → เวลา · 며칠 → วันที่ · 몇 시 → โมง · 뭐 → สิ่ง (test 19 −1)
7. **ลักษณนามต้องครบ** คำนาม + เลขแท้ + ลักษณนาม: 책 **네 권** · **열네** 명
8. **รูปแบบคำสั่งอ่าน** — (　)에 무엇이 맞아요? = เลือกคำเติมช่องว่างในเรื่อง · 다니다 = เป็นนักเรียน/พนักงาน ไม่ใช่ "ไปวันนี้" · 수업 = คาบเรียน ไม่ใช่สอบ
9. สะกดเล็ก ๆ ที่โผล่ซ้ำ: 생활 · 열심히 · 된장찌개 · 친구**예**요 · 갈 거예요 (เว้นวรรค มี 예)

ครูบอกว่า "ข้อสอบจะไม่ห่างจาก 복습시험 ①, ② และชุดทบทวน (review 01) — อาจเปลี่ยนแค่คำศัพท์" จึงทำสองชุดนี้: **제1회** = โครงเดียวกับ 쓰기 ข้อ 1–14 ของชุดทบทวน (14 ส่วน) · **제2회** = รวมรูปแบบจริงของ 복습시험 ① (คำช่วย · คำถาม · ลักษณนาม · เรียงประโยค · ดูภาพตอบ) กับ ② (反대말 · 합니다체 · ยกย่อง · 보기 ไวยากรณ์ -네요/-(으)시/-(으)러 · ตอบคำถาม · ดูภาพเขียนเรื่อง) ทุกส่วนมีป้ายบอกว่าเลียนแบบแบบฟอร์มไหน

กับดักที่วางไว้ตามข้อผิดซ้ำของเรา: ㅈ/ㅊ (책 · 찾으러 · 몇) · ㅐ/ㅔ (개/게) · 시월/유월 · 에 ไม่ใช่ 하고 · 안 + N하다 · -(으)러 + กรรม · 으 หลังตัวสะกด (읽으세요 · 받으세요) · คงกาลตอนเปลี่ยนรูป · 먹다 → 드세요 · ประโยคถามต้องลงท้าย -ㅂ니까 · ตอบให้ตรงคำถาม (언제/며칠/몇 시)

#### 1. 맞는 것을 고르세요. (각 1점×5=5점)
*คำสั่ง: เลือกคำที่ถูกต้อง (입니다 / 있습니다) · รูปแบบ = 복습문제 쓰기 1*

> 안녕하십니까? 저는 카오루①(입니다, 있습니다). 일본 사람②(입니다, 있습니다). 가족은 아버지, 어머니, 여동생이 ③(입니다, 있습니다). 저는 국민대학교 학생④(입니다, 있습니다). 기숙사는 학교 뒤에 ⑤(입니다, 있습니다).

*(สวัสดีครับ/ค่ะ ฉันชื่อคาโอรุ เป็นคนญี่ปุ่น ครอบครัวมีพ่อ แม่ น้องสาว ฉันเป็นนักศึกษามหาวิทยาลัยคุกมิน หอพักอยู่หลังมหาวิทยาลัย)*

*ตัวเลือก: 입니다 / 있습니다*

#### 2. 맞는 것을 고르세요. (각 1점×5=5점)
*คำสั่ง: เลือกคำที่ถูกต้อง (에 / 에서) · รูปแบบ = 복습문제 쓰기 2*

> 저는 알렉세이예요. 러시아①(에, 에서) 왔어요. 지금 서울②(에, 에서) 살아요. 월요일③(에, 에서) 도서관④(에, 에서) 친구를 만나요. 일요일에는 한강 공원⑤(에, 에서) 운동해요.

*(ฉันชื่ออเล็กเซย์ มาจากรัสเซีย ตอนนี้อยู่โซล วันจันทร์พบเพื่อนที่ห้องสมุด วันอาทิตย์ออกกำลังกายที่สวนฮันกัง)*

*ตัวเลือก: 에 / 에서*

#### 3. [보기]에서 알맞은 단어를 골라 쓰세요. (각 1점×8=8점)
*คำสั่ง: เลือกคำช่วยจาก [보기] เติมในวงเล็บ (ใช้ซ้ำได้) · รูปแบบ = 복습문제 쓰기 3*

> **<보기>:** 이/가 · 은/는 · 도 · 에 · 와/과 · 을/를 · 에서 · 만 · 부터

1. 교실에 칠판 (　　) 있어요. *(ในห้องเรียนมีกระดานดำ)*

2. 저는 한국 사람이 아니에요. 제프리 씨 (　　) 한국 사람이 아니에요. *(ฉันไม่ใช่คนเกาหลี คุณเจฟฟรีย์ก็ไม่ใช่คนเกาหลี)*

3. 커피는 마셔요. 녹차 (　　) 안 마셔요. *(กาแฟดื่ม ส่วนชาเขียวไม่ดื่ม)*

4. 매일 아침에 우유 (　　) 마셔요. *(ดื่มนมทุกเช้า)*

5. 저는 매일 도서관 (　　) 가요. *(ฉันไปห้องสมุดทุกวัน)*

6. 서점 (　　) 책을 사요. *(ซื้อหนังสือที่ร้านหนังสือ)*

7. 저는 오늘 숙제 (　　) 했어요. 다른 일은 안 했어요. *(วันนี้ฉันทำแต่การบ้าน ไม่ได้ทำอย่างอื่น)*

8. 책상 위에 책 (　　) 공책이 있어요. *(บนโต๊ะมีหนังสือกับสมุด)*

#### C. เช็กลิสต์ก่อนเข้าห้อง
*คำสั่ง: อ่านทวน 8 ข้อนี้ก่อนเข้าห้องสอบ ทุกข้อมาจากที่คุณเคยพลาด*

- **ตอบให้ตรงคำถาม:** 언제 → เวลา (방학에) · 며칠 → วันที่ (시월 이십이 일) · 몇 시 → นาฬิกา (세 시 십오 분) · 뭐 → สิ่งของหรือกิจกรรม (เคยเสีย 1 คะแนนเพราะตอบ 가족을 만날 거예요 กับ 언제)
- **กาลและระดับภาษาตรงคำถาม:** 했어요 → 했어요 · 할 거예요 → 할 거예요 · 하고 있어요 → 하고 있어요 · 합니까 → 합니다 · เปลี่ยนแค่ท้ายประโยค ไม่เปลี่ยนกาล
- **ใช่/ไม่ใช่:** ขึ้นต้น 네 หรือ 아니요 ก่อน · นาม → 이/가 아니에요 · กริยา → 안 + กริยา · มี → 없어요
- **ตัวเลขพูดช้า ๆ แยกชนิด:** เลขจีน = 층 호 분 원 월 일 · เลขแท้ = 시 개 명 살 권 · เคยพลาด: 시월 (✗ 십월) · 열네 명 (✗ 열넷 명) · 204호 vs 203호
- **이에요 / 예요:** คำนามลงตัวสะกด → 이에요 (빔이에요) · ลงสระ → 예요 (친구예요) · ไม่แน่ใจ ใช้ 입니다
- **시 ของ -(으)세요:** ตอบเรื่องตัวเองด้วย 해요 ไม่มี 시 · พูดถึงผู้ใหญ่ (부모님 · 선생님) คง 시 (계세요 · 다니세요)
- **좋아하다 เป็นกริยาคำเดียว:** 안 좋아해요 (✗ 좋아 안 해요) · แต่ 운동 안 해요 · 아르바이트 안 해요 (✗ 안 아르바이트 해요)
- **ลักษณนามต้องมีนามและเลขแท้:** 책 두 권 · 학생 열네 명 — ราคาต่อหน่วยใช้ 에 (한 권에 만 이천 원) · ✗ ตอบ 권 เฉย ๆ

> 여자: 언제 가요? *(จะไปเมื่อไหร่คะ)*
