## 23과 · 불고기는 맵지 않은 음식이에요 (บุลโกกิเป็นอาหารที่ไม่เผ็ด)

> [!INTRO] บทนี้ว่าด้วยอะไร
> บทที่ 23 เป็นบทแรกของเล่ม 1-2 และว่าด้วยเรื่อง **รสชาติกับอาหาร** สถานการณ์ในบทคือการนั่งดูเมนูในร้านอาหารเกาหลี ถามเพื่อนว่า "อันนี้เผ็ดไหม" "รสเป็นยังไง" แล้วเล่าว่าตัวเองชอบอาหารแบบไหน
>
> ไวยากรณ์ใหม่มี 2 เรื่อง และทั้งสองเรื่องเป็นเรื่อง **"รูป" ของคำคุณศัพท์** ไม่ใช่ความหมายใหม่:
>
> 1. **ㅂ 불규칙** — คำคุณศัพท์ที่ลงท้ายด้วย ㅂ (맵다 เผ็ด · 덥다 ร้อน · 쉽다 ง่าย) พอผันเป็น -아/어요 ตัว ㅂ จะหายแล้วกลายเป็น 우 เช่น 맵다 → 매워요 ความหมายเท่าเดิมทุกประการ ต่างกันแค่ตัวสะกด
> 2. **-(으)ㄴ + คำนาม** — วิธีเอาคำคุณศัพท์ไปวาง**หน้า**คำนามเพื่อบอกว่า "คำนามแบบไหน" เช่น 매운 음식 (อาหารที่เผ็ด) · 시원한 주스 (น้ำผลไม้เย็น ๆ) ภาษาไทยวางคำขยายไว้หลังนาม แต่ภาษาเกาหลีวางไว้หน้านาม จึงต้องมีรูปนี้
>
> จบบทแล้วจะผันคำคุณศัพท์กลุ่ม ㅂ ได้ถูก บรรยายอาหาร คน และสิ่งของด้วย "คุณศัพท์ + คำนาม" ได้ ตอบคำถาม 어떤 N? ("N แบบไหน") ได้ และอ่านบทอ่าน 23-2 ซึ่งเป็นตัวเต็งของ **낭독시험 ⑤ (28 ต.ค. 2026)** ได้คล่อง
>
> จุดที่คนไทยงงบ่อย: คิดว่าการผันไม่ปกติทำให้ความหมายเปลี่ยน (ไม่เปลี่ยน) และคิดว่าเงื่อนไขเยอะ (จริง ๆ มีคำถามเดียวคือ "สิ่งที่ต่อท้ายขึ้นต้นด้วยสระไหม")

### 🗣️ คำศัพท์ที่ต้องรู้ก่อน

คำศัพท์ของบทนี้มี 3 กลุ่มตามหน้าที่ในบท: คำบอกรสชาติและชื่ออาหาร (ใช้ในบทสนทนาและกิจกรรมเลือกร้าน) คำคุณศัพท์กลุ่ม ㅂ (ใช้ฝึกไวยากรณ์ข้อแรก) และคำคุณศัพท์ปกติที่ใช้ฝึก -(으)ㄴ ตารางนี้คัดเฉพาะคำที่ต้องรู้เพื่ออ่านบท รายการเต็มของศูนย์ (ชีตหน้า 20 + ขอบหน้าตำรา) อยู่ท้ายบท

### 📝 ไวยากรณ์: ㅂ 불규칙 — ㅂ กลายเป็น 우 ก่อนสระ (ไวยากรณ์ข้อ 37)

ตอนนี้ว่าด้วยคำคุณศัพท์ (และกริยาบางคำ) ที่รากลงท้ายด้วย ㅂ เช่น 맵다 · 덥다 · 쉽다 ตอนผันตามปกติเราเอา -아/어요 ไปต่อราก (먹다 → 먹어요) แต่คำกลุ่มนี้ตัว ㅂ จะหายไปแล้วกลายเป็น 우 ก่อนรวมกับ 어 เป็น 워 (맵다 → 매워요) เรื่องนี้เป็นเรื่องตัวสะกดล้วน ๆ 매워요 ยังแปลว่า "เผ็ด" เหมือน 맵다 ทุกประการ

ตำราหน้า 234 สรุปกฎไว้ว่า "ถ้ารากลงท้ายด้วย ㅂ พอรวมกับสระ ㅂ เปลี่ยนเป็น 오 หรือ 우" ส่วนใหญ่เป็น 우 และมี 2 คำที่เป็น 오 คือ 돕다 กับ 곱다

#### รูปแบบ

| ตามหลังรากด้วย | ㅂ เปลี่ยนอย่างไร | ตัวอย่าง |
|:---|:---|:---|
| สระ -아/어요 · -았/었어요 | ㅂ → 우 แล้ว 우 + 어 = **워** | 맵다 → 매워요 · 매웠어요 |
| สระ -(으)ㄴ · -(으)ㄹ까요? | ㅂ → 우 แล้วต่อ ㄴ / ㄹ | 맵다 → 매운 음식 · 돕다 → 도울까요? |
| พยัญชนะ -고 · -지 않아요 · -습니다 | **ไม่เปลี่ยน** | 맵고 · 맵지 않아요 · 맵습니다 |
| 돕다 · 곱다 + 아/어 (ยกเว้น) | ㅂ → 오 แล้ว 오 + 아 = **와** | 도와요 · 고와요 |
| 입다 · 잡다 · 좁다 (ผันปกติ) | ㅂ อยู่เหมือนเดิม | 입어요 · 잡아요 · 좁아요 |

ตำราให้ท่อง 입다 · 잡다 · 좁다 ว่าเป็นคำลงท้าย ㅂ ที่ผัน**ปกติ** ดูจากตัวสะกดอย่างเดียวบอกไม่ได้ ต้องจำจากรายการ

#### ตารางผันคำในบท

| ราก | -아/어요 | -(으)ㄴ + N | -습니다 · -지 않아요 |
|:---|:---|:---|:---|
| 맵다 | 매워요 | 매운 음식 | 맵습니다 · 맵지 않아요 |
| 덥다 · 춥다 | 더워요 · 추워요 | 더운 날씨 · 추운 날씨 | 덥습니다 · 춥지 않아요 |
| 어렵다 · 쉽다 | 어려워요 · 쉬워요 | 어려운 시험 · 쉬운 시험 | 어렵습니다 · 쉽지 않아요 |
| 고맙다 · 귀엽다 | 고마워요 · 귀여워요 | 고마운 친구 · 귀여운 아이 | 고맙습니다 · 귀엽지 않아요 |
| 아름답다 | 아름다워요 | 아름다운 경치 | 아름답습니다 |
| 가깝다 · 더럽다 · 가볍다 | 가까워요 · 더러워요 · 가벼워요 | 가까운 집 · 더러운 운동화 · 가벼운 가방 | 가깝습니다 · 가깝지 않아요 |
| 돕다 · 곱다 (ยกเว้น) | **도와요 · 고와요** | 도운 · 고운 | 돕습니다 · 돕지 않아요 |
| 입다 · 좁다 (ปกติ) | 입어요 · 좁아요 | 입은 옷 · 좁은 방 | 입습니다 · 좁지 않아요 |

#### 연습 2 (หน้า 235) — ดูภาพแล้วถาม-ตอบ

แบบฝึกนี้ให้ดูภาพสองภาพแล้วถามว่าอันไหนเป็นอย่างไร คำตอบทุกข้อคือ "คำนาม + 이/가 + คุณศัพท์ผัน"

| คำถาม | คำตอบ | ความหมาย · ภาพ |
|:---|:---|:---|
| 누구 운동화가 더러워요? | 지훈 씨 운동화가 더러워요. | รองเท้าผ้าใบของใครสกปรก — ของจีฮุน |
| 어디가 더워요? | 사우디아라비아가 더워요. | ที่ไหนร้อน — 🖼️ ซาอุฯ เทอร์โมมิเตอร์ 48° |
| 어디가 추워요? | 몽골이 추워요. | ที่ไหนหนาว — 🖼️ มองโกเลีย |
| 어느 음식이 매워요? | 떡볶이가 매워요. | อาหารไหนเผ็ด — 🖼️ ต๊อกบกกีเทียบกิมบับ |
| 무슨 시험이 어려워요? | 쓰기 시험이 어려워요. *(ตัวอย่างตอบ — ในภาพคนสอบ 쓰기 หน้าตากังวล ส่วนคนสอบ 듣기 ยิ้มสบาย)* | สอบอะไรยาก — 🖼️ 듣기 / 쓰기 |
| 누구 집이 학교에서 가까워요? | 카오루 씨 집이 가까워요. | บ้านใครใกล้โรงเรียน — ตามภาพ |

#### 연습 3 (หน้า 235) — ตอบรับและปฏิเสธ

การปฏิเสธใช้**รากเดิม** เพราะ -지 않다 ขึ้นต้นด้วยพยัญชนะ ㅂ จึงไม่เปลี่ยน (가깝지 ✓ · 가까워지 ✗) จะใช้ 안 ก็ได้ (ไวยากรณ์ข้อ 08 · 16)

- 가: 집이 가까워요? *(บ้านใกล้ไหม)*
- 나: 네, 가까워요. *(ใกล้)* / 아니요, 가깝지 않아요. *(ไม่ใกล้)* / 아니요, 안 가까워요.

โจทย์ของแบบฝึกมี 6 ข้อ ตำราพิมพ์เป็นรูปรากแล้วให้ถาม-ตอบตามกรอบข้างบน (ข้อ 1 คือตัวอย่างเอง) ตำราไม่ได้พิมพ์เฉลย ตารางนี้เขียนตามกรอบทุกข้อเพื่อฝึกผัน ㅂ ทั้งแบบรับและแบบปฏิเสธ

| โจทย์ในตำรา | ถาม | ตอบรับ / ปฏิเสธ (ตัวอย่างตอบ) | ความหมาย |
|:---|:---|:---|:---|
| 1. 집이 가깝다 | 집이 가까워요? | 네, 가까워요. / 아니요, 가깝지 않아요. | บ้านใกล้ไหม — ใกล้ / ไม่ใกล้ |
| 2. 날씨가 춥다 | 날씨가 추워요? | 네, 추워요. / 아니요, 춥지 않아요. | อากาศหนาวไหม — หนาว / ไม่หนาว |
| 3. 한국어가 쉽다 | 한국어가 쉬워요? | 네, 쉬워요. / 아니요, 쉽지 않아요. | ภาษาเกาหลีง่ายไหม — ง่าย / ไม่ง่าย |
| 4. 교실이 더럽다 | 교실이 더러워요? | 네, 더러워요. / 아니요, 더럽지 않아요. | ห้องเรียนสกปรกไหม — สกปรก / ไม่สกปรก |
| 5. 고향 음식이 맵다 | 고향 음식이 매워요? | 네, 매워요. / 아니요, 맵지 않아요. | อาหารบ้านเกิดเผ็ดไหม — เผ็ด / ไม่เผ็ด |
| 6. 시험이 어렵다 | 시험이 어려워요? | 네, 어려워요. / 아니요, 어렵지 않아요. | ข้อสอบยากไหม — ยาก / ไม่ยาก |

#### ⚠️ ระวัง

- ★ 맵어요 · 덥어요 ✗ → **매워요 · 더워요** — ลืมเปลี่ยน ㅂ เป็นข้อผิดอันดับหนึ่งของเรื่องนี้
- ㅂ เปลี่ยนเฉพาะ**ก่อนสระ** ส่วน 맵습니다 · 맵지만 · 맵고 ㅂ คงเดิม
- อย่าสลับ 어/아: ✗ 추와요 → 추워요 ตัว 와 ใช้เฉพาะ 돕다 · 곱다
- ประธานคำคุณศัพท์ใช้ 이/가 (날씨가 더워요 ✓ · 날씨를 더워요 ✗ — ไวยากรณ์ข้อ 18)
- 어둡다 → 어두워요 ที่เคยท่องเป็นคำในข้อ 18 คือกฎ ㅂ ข้อเดียวกันนี้
- ใบฝึก 23과 (26 ต.ค.) ผู้เรียนเขียน **메워요** แทน 매워요 — ㅐ/ㅔ สลับกันในช่องแรกสุด ที่เหลือถูกหมด

→ เจาะลึก: ไวยากรณ์ข้อ 37 (เล่ม 2)

### 📝 ไวยากรณ์: A-(으)ㄴ N — คำคุณศัพท์ขยายคำนาม (ไวยากรณ์ข้อ 36)

ตอนนี้ว่าด้วยการเอาคำคุณศัพท์ไปวาง**หน้า**คำนามเพื่อบอกว่า "คำนามแบบไหน" ภาษาไทยพูดว่า "อาหาร**เผ็ด**" คือวางคำขยายไว้หลัง แต่ภาษาเกาหลีวางไว้หน้า (매운 음식) และต้องเปลี่ยนท้ายคำคุณศัพท์เป็น -(으)ㄴ ก่อน เหมือนภาษาอังกฤษ *spicy food* ไม่ใช่ *food spicy* ตำราหน้า 236 อธิบายว่ารูปนี้ "ต่อท้ายรากคำคุณศัพท์เพื่อขยายคำนามถัดไป แสดงลักษณะหรือสภาพของคำนาม"

เงื่อนไขของ ㄴ คือกฎเดิมที่ใช้กับ -(으)세요 และ -(으)ㄹ까요? มีตัวสะกดก็ใส่ 으 ไม่มีก็ไม่ใส่ มีเพิ่มแค่กลุ่ม 있다/없다 ที่ใช้ -는

|:---|:---|:---|
| สระ | -ㄴ | 시원하다 → 시원한 주스 · 예쁘다 → 예쁜 옷 · 깨끗하다 → 깨끗한 교실 |
| ตัวสะกด ㄹ (ㄹ หลุด) | -ㄴ | 길다 → 긴 · 달다 → 단 · 멀다 → 먼 (กฎ ㄹ 탈락 ดูบท 25) |
| ตัวสะกดอื่น | -은 | 작다 → 작은 방 · 넓다 → 넓은 운동장 · 좋다 → 좋은 사람 |
| ㅂ 불규칙 | ㅂ → 우 + ㄴ = -운 | 맵다 → 매운 음식 · 뜨겁다 → 뜨거운 커피 · 가볍다 → 가벼운 가방 |
| -있다 / -없다 | -는 | 재미있다 → 재미있는 영화 · 맛있다 → 맛있는 한식집 |

#### ถามด้วย 어떤 + N (연습 2 หน้า 237)

คำถาม 어떤 N? ถาม**ลักษณะ** ("N แบบไหน") คำตอบจึงเป็น "คุณศัพท์-(으)ㄴ + N" เสมอ ต่างจาก 무슨 ที่ถาม**ชนิด** และตอบด้วยคำนามหมวด (ไวยากรณ์ข้อ 34) คำใน 보기 ของแบบฝึก: 시다 ✓ · 넓다 · 착하다 · 재미있다 · 똑똑하다 · 맵다 · 창문이 크다 · 무섭다

| คำถาม | คำตอบ | ความหมาย |
|:---|:---|:---|
| 투이 씨는 어떤 사람을 좋아해요? | 친절한 사람을 좋아해요. | ทุยชอบคนแบบไหน — คนใจดี (ตัวอย่างตำรา) |
| 어떤 과일을 좋아해요? | 신 과일을 좋아해요. | ชอบผลไม้แบบไหน — ผลไม้เปรี้ยว (ตัวอย่างตำรา) |
| 어떤 친구를 좋아해요? | 착한 친구를 좋아해요. | ชอบเพื่อนแบบไหน — เพื่อนนิสัยดี (ตำราให้เติมเอง) |
| 어떤 교실에서 공부해요? | 창문이 큰 교실에서 공부해요. | เรียนในห้องแบบไหน — ห้องที่หน้าต่างใหญ่ (เติมเอง) |
| 어떤 음식을 좋아해요? | 매운 음식을 좋아해요. | ชอบอาหารแบบไหน — อาหารเผ็ด (เติมเอง) |
| 어떤 집을 좋아해요? | 넓은 집을 좋아해요. | ชอบบ้านแบบไหน — บ้านกว้าง (เติมเอง) |
| 어떤 영화를 봤어요? | 무서운 영화를 봤어요. | ดูหนังแบบไหนมา — หนังน่ากลัว (เติมเอง) |

#### คำคุณศัพท์หลายคำ (연습 3 หน้า 237)

ถ้าบรรยายด้วยคำคุณศัพท์สองคำ คำแรกต่อ -고 คำสุดท้ายต่อ -(으)ㄴ (ไวยากรณ์ข้อ 34) แบบฝึกให้เลือกคำนามจาก 가방 · 음식 · 선생님 · 커피숍 · 사람

- 가: 어떤 가방을 좋아해요? *(ชอบกระเป๋าแบบไหน)*
- 나: 예쁘고 가벼운 가방을 좋아해요. *(ชอบกระเป๋าที่สวยและเบา)*

ตำราให้คำนามอีก 4 คำ คือ 음식, 선생님, 커피숍 และ 사람 กับคำคุณศัพท์ในขอบหน้า 5 คำ คือ 시다, 착하다, 똑똑하다, 무섭다 และ 가볍다 ให้ถาม-ตอบเองตามกรอบข้างบน ตำราไม่ได้พิมพ์เฉลย ตัวอย่างตอบมีดังนี้

| คำนาม | ถาม | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 음식 | 어떤 음식을 좋아해요? | 맛있고 매운 음식을 좋아해요. | ชอบอาหารแบบไหน — อร่อยและเผ็ด |
| 선생님 | 어떤 선생님을 좋아해요? | 똑똑하고 착한 선생님을 좋아해요. | ชอบครูแบบไหน — ฉลาดและนิสัยดี |
| 커피숍 | 어떤 커피숍을 좋아해요? | 예쁘고 시원한 커피숍을 좋아해요. | ชอบคาเฟ่แบบไหน — สวยและเย็นสบาย |
| 사람 | 어떤 사람을 좋아해요? | 친절하고 착한 사람을 좋아해요. | ชอบคนแบบไหน — ใจดีและนิสัยดี |

#### รูปปฏิเสธ A-지 않은 N

ชื่อบทเองก็ใช้รูปนี้: 불고기는 맵지 않은 음식이에요 *(บุลโกกิเป็นอาหารที่ไม่เผ็ด)* จะใช้ 안 + A ก็ได้ (안 매운 음식) ส่วนกริยาใช้ -지 않는 ซึ่งตำราไม่ได้อธิบายในบทนี้ (เสริม ดูไวยากรณ์ข้อ 44 บท 27)

#### ⚠️ ระวัง

- ★ ตัดพยางค์ 으: 작은 → 작ㄴ ✗ · 좋은 → 좋ㄴ ✗ — ตระกูลเดียวกับ 씻러 · 읽세요 · 받십니다 ที่เคยพลาด
- -있다 ใช้ **-는** ไม่ใช่ -은: 맛있은 ✗ → 맛있는
- ㄹ หลุดก่อน -ㄴ (긴 · 단 · 먼) เหมือน 만들다 → 만듭니다 ที่เคยเขียนผิดเป็น 만들습니다
- **คำนามตามหลังเสมอ** 매운 อยู่ท้ายประโยคไม่ได้ (매운요 ✗ → 매워요)
- อย่าใส่ 이에요 ต่อคำคุณศัพท์ขยายนามโดยไม่มีคำนาม: 매운 음식이에요 ถูกเพราะคำนามคือ 음식
- ใบฝึก 23과 (26 ต.ค.) ตาราง (으)ㄴ ทั้ง 16 ช่องผู้เรียนทำถูกหมด

→ เจาะลึก: ไวยากรณ์ข้อ 36 (เล่ม 2)

### 💬 대화 23-1 — ในร้านอาหารเกาหลี

장핑 พา 마키 มาร้านอาหารเกาหลีที่มาบ่อย 마키 ไม่รู้จัก 순두부찌개 จึงถามว่าเผ็ดไหม แล้วถามต่อว่าบุลโกกิรสเป็นอย่างไร บทสนทนานี้ใช้ทั้ง "매운 음식이에요" และ "맵지 않은 음식이에요" คือรูปขยายคำนามแบบบอกเล่าและแบบปฏิเสธ

> 장핑: 이 식당 음식이 맛있어요. 그래서 자주 와요. *(อาหารร้านนี้อร่อย เลยมาบ่อย)*
>
> 마키: 순두부찌개가 뭐예요? 매운 음식이에요? *(ซุปเต้าหู้อ่อนคืออะไร เป็นอาหารเผ็ดไหม)*
>
> 장핑: 네, 조금 매운 음식이에요. *(ใช่ เป็นอาหารเผ็ดนิดหน่อย)*
>
> 마키: 불고기는 맛이 어때요? 매워요? *(บุลโกกิรสเป็นยังไง เผ็ดไหม)*
>
> 장핑: 아니요, 불고기는 맵지 않은 음식이에요. 달아요. *(ไม่ บุลโกกิเป็นอาหารที่ไม่เผ็ด หวาน)*
>
> 마키: 장핑 씨는 불고기를 좋아하세요? *(คุณจางผิงชอบบุลโกกิไหมคะ)*
>
> 장핑: 네, 아주 좋아해요. *(ชอบมากครับ)*

🖼️ *ร้านอาหาร มีป้ายเมนูติดผนัง (불고기 1인분 · 냉면 · 순두부찌개 · 된장찌개) ชายหญิงนั่งดูเมนูที่โต๊ะ ตัวเลขราคาในภาพเล็กอ่านไม่ชัด*

#### สังเกตจากบทสนทนา

- 매운 음식이에요 / 맵지 않은 음식이에요 — คำคุณศัพท์ขยาย 음식 ทั้งแบบบอกเล่าและปฏิเสธ
- 맛이 어때요? — ถามรสชาติ ตอบด้วยคำคุณศัพท์ผัน (매워요 · 달아요)
- 달아요 — 달다 ลงท้าย ㄹ ผันปกติ ไม่ใช่กลุ่ม ㅂ
- 좋아하세요? — ถามความชอบด้วยกริยา 좋아하다 แบบยกย่อง (ไวยากรณ์ข้อ 20)

#### ฝึกสลับ (หน้า 238)

เปลี่ยนชื่อร้านกับอาหารตามตาราง แล้วพูดบทสนทนาเดิม

| ร้าน | อาหารเผ็ด | อาหารอีกอย่าง |
|:---|:---|:---|
| 한식집 *(ร้านอาหารเกาหลี)* | 순두부찌개 / 맵다 | 불고기 / 달다 |
| 중국집 *(ร้านอาหารจีน)* | 짬뽕 / 맵다 | 짜장면 / 달다 |
| 일식집 *(ร้านอาหารญี่ปุ่น)* | 회덮밥 / 맵다 | 튀김 / 맛있다 |
| 분식집 *(ร้านของกินเล่น)* | 떡볶이 / 맵다 | 김밥 / 맛있다 |

คำถามเช็กความเข้าใจท้ายบทสนทนา (ตอบแบบ 합니다체):

- 장핑 씨는 무슨 음식을 좋아합니까? → 불고기를 좋아합니다. *(จางผิงชอบอาหารอะไร — บุลโกกิ)*
- 불고기는 맛이 어떻습니까? → 맵지 않습니다. 답니다. *(บุลโกกิรสเป็นอย่างไร — ไม่เผ็ด หวาน)*

### 📖 읽기 23-2 · 🎧 듣기 — อาหารเกาหลีที่ฉันชอบ

บทอ่านเป็นเรื่องเล่าของผู้เขียนว่าชอบอาหารเกาหลีอะไรบ้าง คนเกาหลีกินอะไรหน้าร้อน และไปกินที่ไหนกับเพื่อน บทนี้มีรูป "คุณศัพท์ + คำนาม" ถึง 6 แห่ง (시원한 냉면 · 더운 날씨 · 뜨거운 삼계탕 · 매운 떡볶이 · 맛있는 한식집 · 예쁜 카페) จึงเหมาะกับ 낭독시험 มาก

ก่อนอ่าน ตำราหน้า 240 ให้ตอบคำถามอุ่นเครื่อง 2 ข้อ (ตอบเองตามจริง ไม่มีเฉลย)

- 여러분은 식당에 자주 가요? *(คุณไปร้านอาหารบ่อยไหม)*
- 어떤 식당에 가요? *(ไปร้านแบบไหน)*

> 저는 한국 음식을 좋아해요. 삼계탕과 갈비찜, 그리고 시원한 냉면을 좋아해요. *(ฉันชอบอาหารเกาหลี ชอบซัมเกทัง คัลบีจิม และเนงมยอนเย็น ๆ)*
>
> 한국 사람들은 아주 더운 날씨에 뜨거운 삼계탕을 먹어요. 삼계탕은 닭고기로 만들어요. 인삼을 넣어요. *(คนเกาหลีกินซัมเกทังร้อน ๆ ในอากาศร้อนมาก ซัมเกทังทำจากเนื้อไก่ ใส่โสม)*
>
> 제 친구는 불고기하고 매운 떡볶이를 좋아해요. 우리는 한국 음식을 먹으러 삼청동에 자주 가요. *(เพื่อนฉันชอบบุลโกกิกับต๊อกบกกีเผ็ด ๆ พวกเราไปซัมช็องดงบ่อยเพื่อกินอาหารเกาหลี)*
>
> 거기에는 맛있는 한식집이 많고 카페도 많아요. 오늘은 시원한 아이스커피를 마시러 예쁜 카페에 갈 거예요. *(ที่นั่นมีร้านอาหารเกาหลีอร่อย ๆ เยอะ และมีคาเฟ่เยอะด้วย วันนี้จะไปคาเฟ่สวย ๆ เพื่อดื่มกาแฟเย็นเย็น ๆ)*

สังเกต 닭고기로 만들어요 — (으)로 บอกวัตถุดิบ ตำราไม่อธิบายในบทนี้ (ดูไวยากรณ์ข้อ 49 · 51)

#### 라 — ทำบทอ่านเป็นบทสนทนา (ตัวอย่างตอบ)

ตำราเว้นช่องให้เติมเอง ช่องว่างกลางเป็นคำถามที่ต้องคิดเอง

- 가: 삼계탕은 무슨 고기로 만들어요? 나: 닭고기로 만들어요. *(ซัมเกทังทำจากเนื้ออะไร — เนื้อไก่)*
- 가: (어디에 자주 가요?) 나: 삼청동에 자주 가요. *(ไปที่ไหนบ่อย — ซัมช็องดง)*
- 가: 삼청동은 어때요? 나: 맛있는 한식집이 많고 카페도 많아요. *(ซัมช็องดงเป็นยังไง — ร้านอร่อยเยอะ คาเฟ่ก็เยอะ)*

| 메뉴 *(ร้านญี่ปุ่น)* | 회덮밥 · 초밥 · 우동 · 돈가스 |
| MENU *(ร้านตะวันตก)* | 스테이크 · 스파게티 · 피자 · 샐러드 |

- 무슨 음식을 좋아해요? → 한국 음식을 좋아해요. *(ชอบอาหารอะไร — อาหารเกาหลี)*
- 그럼 한식집에 갈까요? → 네, 좋아요. *(งั้นไปร้านอาหารเกาหลีกันไหม — ดี)*
- 무슨 음식을 먹을까요? → 냉면하고 불고기를 먹어요. *(กินอะไรดี — เนงมยอนกับบุลโกกิ)*
- 냉면은 맛이 어때요? → 조금 매워요. *(เนงมยอนรสเป็นยังไง — เผ็ดนิดหน่อย)*

🖼️ *ราคาบนเมนูทั้ง 4 แผ่น: ร้านเกาหลี 6,000–8,000 วอน · ร้านจีน 4,500–13,000 วอน · ร้านญี่ปุ่น 6,000–8,000 วอน · ร้านตะวันตก 9,000–37,000 วอน*

#### 활동 2 (หน้า 239) — เมนูของประเทศตัวเอง

ตำราให้ทำต่อจากกิจกรรมข้างบน เป็นการพูดอิสระ ไม่มีเฉลย

- 메뉴판에 여러분 나라의 음식 이름을 쓰고 친구들과 말해 봅시다. *(เขียนชื่ออาหารของประเทศตัวเองลงในเมนู แล้วคุยกับเพื่อน)*
- 메뉴판을 3~4개 모아 놓고 위와 같이 말해 봅시다. *(รวมเมนู 3–4 แผ่นไว้ด้วยกัน แล้วพูดตามบทสนทนาข้างบน)*

🖼️ *เมนูเปล่า มีคำว่า MENU ที่หัวกระดาษ ไว้เขียนชื่ออาหารเอง*

#### 활동 (หน้า 241) — อาหารตามอากาศ

กิจกรรมท้ายบทอ่านให้เล่าเรื่องอาหารที่กินตอนอากาศร้อนจัดหรือหนาวจัดในประเทศของตัวเอง ใช้โครงเดียวกับบทอ่าน 23-2 ได้ ตำราไม่มีเฉลย

- 여러분 나라에서 아주 더운 날씨, 아주 추운 날씨에 먹는 음식이 있어요? 친구와 같이 말해 봅시다. *(ในประเทศของคุณมีอาหารที่กินตอนอากาศร้อนจัดหรือหนาวจัดไหม คุยกับเพื่อน)*
- 한국 사람들은 아주 더운 날씨에 뜨거운 삼계탕을 먹어요. *(คนเกาหลีกินซัมเกทังร้อน ๆ ในอากาศร้อนจัด — โครงตัวอย่างจากบทอ่าน)*

### 🧪 ออกสอบอย่างไร

บทนี้ยังไม่มีคะแนนสอบจริง สิ่งที่มีคือใบฝึกของครูและการคาดการณ์ บทนี้อยู่ในขอบเขตของ **복습시험③ (22–29과, 6 พ.ย.)** และ **기말 (23–37과)** ส่วน **낭독시험 ⑤ (28 ต.ค.) = 23과** ซึ่งบทอ่าน 23-2 เป็นตัวเต็ง เพราะ 복습시험①/② ยก 읽기 ในตำรามาเกือบคำต่อคำ

- **ใบฝึก 23과 (แจก 26 ต.ค.)** มี 3 ส่วน: ตาราง ㅂ 불규칙 10 คำ (맵다 … 돕다 + 입다) ผันเป็น -아/어요 และ -았/었어요 · ตาราง (으)ㄴ 4 กลุ่ม (받침 O → 은 · 받침 X → ㄴ · ㅂ → 운 · 있다/없다 → 는) · ฝึกพูด 누가 친절해요? → 친절한 사람은 ○○ 씨예요
- ผู้เรียนทำใบฝึกถูกทุกช่องยกเว้น **메워요** (→ 매워요) ดูเฉลยเต็มใน KMU_Everyday_unit23.pdf
- ครูบอกว่า 매일시험 23과 จะเน้น**การผันรูป** — ข้อสอบจำลอง 3 ชุดอยู่ใน KMU_Predict_unit23.pdf (A ผันคำจากภาพ · B ตารางผัน + ใบฝึก · C เขียนตามคำบอกจาก 대화/읽기)
- จุดเสี่ยงที่คาด: เติมรูป ㅂ ในตาราง (맵다 → 매워요 / 매운) · ต่อคำคุณศัพท์เข้ากับคำนามตาม 보기 (시원한 주스) · ตอบ 어떤 + N
- รูปแบบที่ 복습시험② เคยใช้และน่าเอามาเล่นกับบทนี้: 반대말 (덥다 ↔ 춥다 · 쉽다 ↔ 어렵다) · 해요 → 합니다 (매워요 → 맵습니다 ㅂ กลับมา) · ตอบคำถามด้วยไวยากรณ์ที่กำหนด

> [!WARNING] ที่น่าจะพลาด (คาดจากข้อผิดเดิม)
> - ★ ตกพยางค์ **으** หรือเลือก 은/는/ㄴ ผิด: 좋은 · 작은 · 넓은 (มีตัวสะกด) แต่ 시원한 · 예쁜 (ไม่มี) และ 맛있는 (-있다 ใช้ -는) — ตระกูลเดียวกับ 씻러 · 읽세요 · 받십니다
> - ★ ㅂ 불규칙: ✗ 맵어요 · 덥어요 · 가깝아요 → 매워요 · 더워요 · 가까워요 และสลับ 아/어: ✗ 추와요 (와 ใช้เฉพาะ 돕다 · 곱다) — เคยสลับที่ 살어요 · 받었어요
> - ★ ㅐ/ㅔ: 메워요 (ใบฝึก 23과) · 스파게티 · 레스토랑 · 떡볶이 — เคยพลาด 네 게 · 젝 · 테국
> - ★ ㅈ/ㅊ ในคำของบท: 착하다 · 짜장면 · 짬뽕 · 가깝다 — ขีดบนของ ㅊ ให้ครบ
> - 이/가 กับคำคุณศัพท์ (날씨가 더워요 · ✗ 날씨를 더워요) · 어떤 (ลักษณะ) vs 무슨 (ชนิด) · 어때요 ≠ 어떻게 · ถามชอบใช้ 좋아해요 ไม่ใช่ 좋아요 · ✗ 좋아 안 해요 → 안 좋아해요

> [!SUMMARY] สรุปท้ายบท
> - ㅂ 불규칙 เปลี่ยนแค่ตัวสะกด ไม่เปลี่ยนความหมาย: ก่อนสระ ㅂ → 우 (매워요 · 매운 · 도울까요?) ก่อนพยัญชนะไม่เปลี่ยน (맵고 · 맵습니다 · 맵지 않아요)
> - ยกเว้น 2 แบบ: 돕다 · 곱다 → 도와요 · 고와요 (오) และ 입다 · 잡다 · 좁다 ผันปกติ
> - คุณศัพท์ขยายคำนามวางหน้านาม: ไม่มีตัวสะกด -ㄴ · มีตัวสะกด -은 · ㅂ → -운 · 있다/없다 → -는 · ㄹ หลุดก่อน ㄴ
> - 어떤 N? ถามลักษณะ ตอบ "คุณศัพท์-(으)ㄴ N" · 무슨 N? ถามชนิด ตอบคำนามหมวด
> - ข้อสอบ: ตารางผัน · 보기처럼 (시원한 주스) · 어떤 + N · ปฏิเสธ 맵지 않은 음식 · 낭독 23-2 (시원한 · 더운 · 뜨거운 · 매운 · 맛있는 · 예쁜)
