## 7과 · 제 사전이 아니에요 (ไม่ใช่พจนานุกรมของฉัน)

> [!INTRO] บทนี้ว่าด้วยอะไร
> บทที่ 7 ยังคุยเรื่องสิ่งของรอบตัวเหมือนบท 6 สถานการณ์ในบทคือการถามว่าของชิ้นนี้ "ใช่…ไหม" "คืออะไร" และ "เป็นของใคร" โดยใช้ของใช้และเครื่องเขียนเป็นตัวอย่าง ท้ายบทเป็นบทอ่านที่อเล็กเซย์เล่าเรื่องสิ่งของในกระเป๋าสตางค์ของตัวเอง
>
> ไวยากรณ์ใหม่มี 3 เรื่อง:
>
> 1. **N + 이에요 / 예요** — "เป็น/คือ…" แบบสุภาพ ใช้พูดทุกวัน
> 2. **N + 이/가 아니에요** — "ไม่ใช่…" ใช้ปฏิเสธคำนาม
> 3. **제 · 이게 · 뭐 · 그리고** — คำย่อภาษาพูดและตัวเชื่อมประโยค
>
> บท 5–6 ใช้ -입니다 ซึ่งเป็นรูปทางการ บท 7 เปลี่ยนเป็นรูปสุภาพที่ใช้พูดทุกวัน ความหมายเท่าเดิมแต่ระดับภาษาเปลี่ยน สิ่งที่ต่างคือ 입니다 ไม่ต้องดูตัวสะกด แต่ 이에요/예요 ต้องดูพยางค์สุดท้ายของคำนาม
>
> จบบทแล้วจะถามว่า "นี่ใช่…ไหม / คืออะไร" ด้วยรูปสุภาพ N이에요/예요 และตอบปฏิเสธว่า "ไม่ใช่…" ด้วย N이/가 아니에요 แล้วบอกของจริงต่อได้
>
> จุดที่คนไทยมักพลาด: ลืมใช้ 예요 หลังคำนามที่ไม่มีตัวสะกด (เวิร์กบุ๊กถูกครูแก้ 4 ข้อ) · สับสน 뭐예요 กับ 뭐이에요 · แยก 아니요 (คำตอบ "ไม่") ออกจาก 아니에요 (กริยา "ไม่ใช่") ไม่ได้ · และเขียน 이/가 กับ 아니에요 ติดกัน

### 📝 ไวยากรณ์: N + 이에요 / 예요 — "เป็น/คือ…" แบบสุภาพ (ไวยากรณ์ข้อ 02)

ตอนนี้ว่าด้วยรูปสุภาพของ "เป็น/คือ…" ที่ใช้พูดทุกวัน ใช้แทน 입니다 ในบท 5–6 ความหมายเหมือนเดิมทุกอย่าง แต่ต่างตรงที่ต้องดูพยางค์สุดท้ายของคำนาม ถ้ามีตัวสะกดใช้ 이에요 ถ้าไม่มีใช้ 예요 และเวลาถามใช้รูปเดิมแล้วทำเสียงสูงขึ้นท้ายประโยค

#### รูปแบบ

| ท้ายคำนาม | ต่อท้ายด้วย | ตัวอย่าง |
|:---|:---|:---|
| มีตัวสะกด (받침 ○) | **이에요** | 연필이에요. *(เป็นดินสอ)* |
| ไม่มีตัวสะกด (받침 ✗) | **예요** | 지우개예요. *(เป็นยางลบ)* |

#### ตัวอย่างจากตำรา

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 알렉세이 씨는 경찰이에요. | {n:คุณอเล็กเซย์}{e:เป็น}{n:ตำรวจ} | 경찰 มีตัวสะกด ㄹ → 이에요 |
| 카메라예요. | เป็นกล้อง | ไม่มีตัวสะกด → 예요 |
| 왕쯔이 씨는 의사예요. | คุณหวางจื่ออีเป็นหมอ | ไม่มีตัวสะกด → 예요 |
| 연필이에요? → 아니요, 지우개예요. | เป็นดินสอหรือ → ไม่ใช่ เป็นยางลบ | ถามด้วยรูปเดิม (เสียงสูงขึ้น) |

#### 연습 1 (หน้า 58) — บอกชื่อสิ่งของจากภาพ

ตัวอย่างในตำราคือ "책이에요." แบบฝึกให้ดูภาพของ 6 อย่างแล้วตอบด้วย N + 이에요/예요 (ข้อ 1 ซ้ำกับตัวอย่าง) ตำราไม่พิมพ์เฉลย คอลัมน์ "ตัวอย่างตอบ" จึงเป็นคำตอบตามโครงที่พิมพ์ สังเกตว่าคำที่ไม่มีตัวสะกด (지우개 · 카메라 · 휴대 전화) ต้องใช้ 예요

| ข้อ | ชื่อใต้ภาพ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 책 | 책이에요. | เป็นหนังสือ |
| 2 | 지우개 | 지우개예요. | เป็นยางลบ |
| 3 | 가방 | 가방이에요. | เป็นกระเป๋า |
| 4 | 카메라 | 카메라예요. | เป็นกล้อง |
| 5 | 지갑 | 지갑이에요. | เป็นกระเป๋าสตางค์ |
| 6 | 휴대 전화 | 휴대 전화예요. | เป็นมือถือ |

#### 연습 2 (หน้า 59) — ถามแล้วปฏิเสธ บอกของจริง

โครงในตำราคือ "책이에요? / 아니요, 공책이에요." ใต้ภาพของ 5 อย่างมีคำ 2 คำ คำบนใช้ถามและคำล่างใช้ตอบ (ข้อ 1 ซ้ำกับตัวอย่าง) ตำราไม่พิมพ์เฉลย ตัวอย่างตอบข้างล่างยังไม่ใช้ 이/가 아니에요 เพราะเป็นเพียงการตอบ 아니요 แล้วบอกของจริง

| ข้อ | คำบน → คำล่าง | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 책 → 공책 | 책이에요? → 아니요, 공책이에요. | เป็นหนังสือหรือ → ไม่ใช่ เป็นสมุด |
| 2 | 필통 → 지갑 | 필통이에요? → 아니요, 지갑이에요. | เป็นกล่องดินสอหรือ → ไม่ใช่ เป็นกระเป๋าสตางค์ |
| 3 | 공책 → 수첩 | 공책이에요? → 아니요, 수첩이에요. | เป็นสมุดหรือ → ไม่ใช่ เป็นสมุดโน้ตเล่มเล็ก |
| 4 | 볼펜 → 지우개 | 볼펜이에요? → 아니요, 지우개예요. | เป็นปากกาหรือ → ไม่ใช่ เป็นยางลบ |
| 5 | 연필 → 볼펜 | 연필이에요? → 아니요, 볼펜이에요. | เป็นดินสอหรือ → ไม่ใช่ เป็นปากกา |

#### 연습 3 (หน้า 59) — เล่นบทมากิกับบาตดูของบนโต๊ะ

ตำราให้เล่นเป็น 마키 (ผู้ถาม) กับ 바트 (ผู้ตอบ) ดูภาพโต๊ะที่มีของวางอยู่แล้วถาม-ตอบตามกรอบ "이게 뭐예요? / 지갑이에요." ตำราไม่พิมพ์รายการของและไม่พิมพ์เฉลย ตารางข้างล่างเลือกของที่เห็นบนโต๊ะและผนังในภาพ ซึ่งตรงกับคำศัพท์ขอบหน้าอย่าง 공책 · 필통 · 전자사전

| ของในภาพ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|
| 지갑 | 이게 뭐예요? → 지갑이에요. | นี่คืออะไร → กระเป๋าสตางค์ (ตัวอย่างในตำรา) |
| 공책 | 이게 뭐예요? → 공책이에요. | นี่คืออะไร → สมุด |
| 볼펜 | 이게 뭐예요? → 볼펜이에요. | นี่คืออะไร → ปากกา |
| 책 | 이게 뭐예요? → 책이에요. | นี่คืออะไร → หนังสือ |
| 전자사전 | 이게 뭐예요? → 전자사전이에요. | นี่คืออะไร → พจนานุกรมอิเล็กทรอนิกส์ |
| 안경 | 이게 뭐예요? → 안경이에요. | นี่คืออะไร → แว่นตา |
| 가방 | 이게 뭐예요? → 가방이에요. | นี่คืออะไร → กระเป๋า |
| 시계 | 저게 뭐예요? → 시계예요. | โน่นคืออะไร → นาฬิกา |
| 달력 | 저게 뭐예요? → 달력이에요. | โน่นคืออะไร → ปฏิทิน |
| 텔레비전 | 저게 뭐예요? → 텔레비전이에요. | โน่นคืออะไร → โทรทัศน์ |

#### เชื่อมกับรูปทางการ (ระดับภาษา)

ความหมายเดิม เปลี่ยนแค่ระดับภาษา: **입니다 ไม่ดูตัวสะกด แต่ 이에요/예요 ต้องดู**

| ทางการ (บท 5–6) | สุภาพ (บท 7) | ไทย |
|:---|:---|:---|
| 학생입니다. | 학생이에요. | เป็นนักเรียน |
| 의사입니다. | 의사예요. | เป็นหมอ |
| 학생입니까? | 학생이에요? | เป็นนักเรียนหรือ |
| 이것이 무엇입니까? | 이게 뭐예요? | นี่คืออะไร |

#### 📽️ จากสมุดทบทวน 14/9 (หน้าสมุดจดของคุณ)

ในสมุดจด "이에요, 예요" คู่กับ 입니다 และมีหัวข้อ "이/가 아니에요"

#### ⚠️ ระวัง

- ไม่มีตัวสะกด → **예요** — เวิร์กบุ๊กครูแก้ 4 ข้อที่เขียน 이에요 ✗:
  - 휴대 전화예요 *(เป็นมือถือ)*
  - 기자예요 *(เป็นนักข่าว)*
  - 운동선수예요 *(เป็นนักกีฬา)*
  - 여자예요 *(เป็นผู้หญิง)*
- 카드예요 *(เป็นบัตร)* — ไม่มีตัวสะกด → 예요 เหมือนกัน (매일시험 C9)
- 뭐 กับ 무엇 ต่อท้ายต่างกัน ดูตารางข้างล่าง

| คำ | ถูก | ผิด | เหตุผล |
|:---|:---|:---|:---|
| 뭐 | 뭐예요 ✓ | 뭐이에요 ✗ | 뭐 ไม่มีตัวสะกด → 예요 |
| 무엇 | 무엇이에요 ✓ | 무엇예요 ✗ | 무엇 มี ㅅ → 이에요 |

→ เจาะลึก: ไวยากรณ์ข้อ 02 (เล่ม 2)

### 📝 ไวยากรณ์: N + 이/가 아니에요 — "ไม่ใช่…" (ไวยากรณ์ข้อ 02)

ตอนนี้ว่าด้วยการปฏิเสธคำนามว่า "ไม่ใช่…" ใช้ 이/가 ต่อท้ายคำนามแล้วตามด้วย 아니에요 ถ้ามีตัวสะกดใช้ 이 ถ้าไม่มีใช้ 가 เมื่อปฏิเสธแล้วมักบอกของจริงต่อทันที เหมือนที่ในบท 5 ตอบ 아니요 แล้วบอกข้อมูลที่ถูก

#### รูปแบบ

| ท้ายคำนาม | ต่อท้ายด้วย | ตัวอย่าง |
|:---|:---|:---|
| มีตัวสะกด (받침 ○) | **이 아니에요** | 사전이 아니에요. *(ไม่ใช่พจนานุกรม)* |
| ไม่มีตัวสะกด (받침 ✗) | **가 아니에요** | 카메라가 아니에요. *(ไม่ใช่กล้อง)* |

#### ตัวอย่างจากตำรา

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 볼펜이 아니에요. | ไม่ใช่ปากกา | 볼펜 มีตัวสะกด → 이 |
| 나무가 아니에요. | ไม่ใช่ต้นไม้ | 나무 ไม่มีตัวสะกด → 가 (เว้นวรรคก่อน 아니에요) |
| 꽃이에요. | เป็นดอกไม้ | กรอบหน้า 60: ตอบต่อจาก 나무가 아니에요 |
| 중국 사람이 아니에요. 한국 사람이에요. | ไม่ใช่คนจีน เป็นคนเกาหลี | กรอบหน้า 60: ปฏิเสธแล้วบอกของจริง |
| 카메라예요? → 아니요, 카메라가 아니에요. 휴대폰이에요. | เป็นกล้องหรือ → ไม่ใช่กล้อง เป็นมือถือ | บทสนทนาเปิดข้อ 준비 2 หน้า 60 |
| 공책이에요? → 아니요, 공책이 아니에요. 책이에요. | เป็นสมุดหรือ → ไม่ใช่สมุด เป็นหนังสือ | 연습 2–3: ปฏิเสธแล้วบอกของจริงต่อ |
| 이게 볼펜이에요? → 아니요, 볼펜이 아니에요. 연필이에요. | นี่ปากกาหรือ → ไม่ใช่ปากกา เป็นดินสอ | 연습 2–3: ปฏิเสธแล้วบอกของจริงต่อ |
| 제 여자 친구는 러시아 사람이 아니에요. 미국 사람이에요. | {n:แฟนสาว}{p:ของ}{n:ฉัน}{x:ไม่ใช่}{n:คนรัสเซีย} {e:เป็น}{n:คนอเมริกัน} | ใช้ร่วมกับ 은/는 ในประโยคเดียว |

#### 연습 1 (หน้า 60) — พูดว่า "ไม่ใช่…" ตามโจทย์

ตัวอย่างในตำราคือ "카메라가 아니에요." ข้างหลังแต่ละคำมี (×) แปลว่า "ไม่ใช่" ให้ต่อด้วย 이/가 아니에요 (ข้อ 1 ซ้ำกับตัวอย่าง) ตำราไม่พิมพ์เฉลย ดูตัวสะกดของคำก่อนเลือก 이 หรือ 가

| ข้อ | โจทย์ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 카메라(×) | 카메라가 아니에요. | ไม่ใช่กล้อง |
| 2 | 볼펜(×) | 볼펜이 아니에요. | ไม่ใช่ปากกา |
| 3 | 지우개(×) | 지우개가 아니에요. | ไม่ใช่ยางลบ |
| 4 | 휴대폰(×) | 휴대폰이 아니에요. | ไม่ใช่มือถือ |
| 5 | 가방(×) | 가방이 아니에요. | ไม่ใช่กระเป๋า |
| 6 | 컴퓨터(×) | 컴퓨터가 아니에요. | ไม่ใช่คอมพิวเตอร์ |

#### 연습 2 (หน้า 61) — ปฏิเสธแล้วบอกของจริงด้วย 이/가 아니에요

โครงในตำราคือ "공책이에요? / 아니요, 공책이 아니에요. 책이에요." ใต้ภาพของ 6 อย่างมีคำ 2 คำ คำบนใช้ถามและคำล่างคือของจริง (ข้อ 1 ซ้ำกับตัวอย่าง) ตำราไม่พิมพ์เฉลย ข้างหลังคำล่างต้องเลือก 이에요 หรือ 예요 ตามตัวสะกด

| ข้อ | คำบน → คำล่าง | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 공책 → 책 | 공책이에요? → 아니요, 공책이 아니에요. 책이에요. | เป็นสมุดหรือ → ไม่ใช่สมุด เป็นหนังสือ |
| 2 | 책 → 수첩 | 책이에요? → 아니요, 책이 아니에요. 수첩이에요. | เป็นหนังสือหรือ → ไม่ใช่หนังสือ เป็นสมุดโน้ตเล่มเล็ก |
| 3 | 휴대폰 → 카메라 | 휴대폰이에요? → 아니요, 휴대폰이 아니에요. 카메라예요. | เป็นมือถือหรือ → ไม่ใช่มือถือ เป็นกล้อง |
| 4 | 학생증 → 카드 | 학생증이에요? → 아니요, 학생증이 아니에요. 카드예요. | เป็นบัตรนักศึกษาหรือ → ไม่ใช่ เป็นบัตร |
| 5 | 수첩 → 지갑 | 수첩이에요? → 아니요, 수첩이 아니에요. 지갑이에요. | เป็นสมุดโน้ตหรือ → ไม่ใช่ เป็นกระเป๋าสตางค์ |
| 6 | 볼펜 → 연필 | 볼펜이에요? → 아니요, 볼펜이 아니에요. 연필이에요. | เป็นปากกาหรือ → ไม่ใช่ปากกา เป็นดินสอ |

#### 연습 3 (หน้า 61) — เอาของของตัวเองมาถามเพื่อน

ตำราให้แต่ละคนวางของของตัวเองบนโต๊ะแล้วคุยกับเพื่อนตามกรอบ ไม่มีรายการของและไม่มีเฉลย

- 각자 자기의 물건을 놓고 다음과 같이 친구와 말해 봅시다. *(ต่างคนวางของของตัวเองแล้วคุยกับเพื่อนตามตัวอย่างข้างล่าง)*
- 가: 이게 볼펜이에요? 나: 아니요, 볼펜이 아니에요. 연필이에요. *(นี่ปากกาหรือ — ไม่ใช่ปากกา เป็นดินสอ)*

#### ⚠️ ระวัง

- 띄어쓰기 (ตามตำรา): 이/가 **ติดนาม** แล้ว **เว้นวรรค** ก่อน 아니에요 — 나무가 아니에요 ✓ · 나무가아니에요 ✗ (ไวยากรณ์ข้อ 13)
- 아니요 (คำตอบ "ไม่") ≠ 아니에요 (กริยา "ไม่ใช่") — 아니요, 지갑이 아니에요 ✓
- 아니에요 ต้องมี 이/가 นำหน้า: 저는 한국 사람**이** 아니에요

→ เจาะลึก: ไวยากรณ์ข้อ 02 (เล่ม 2)

### 📝 ไวยากรณ์: 제 · 이게 · 뭐 · 그리고 — คำย่อภาษาพูดและตัวเชื่อม

ตอนนี้ว่าด้วยคำที่ภาษาพูดย่อให้สั้นลง ได้แก่ 제 (= 저의) 이게/그게/저게 (= 이것이/그것이/저것이) และ 뭐 (= 무엇) พร้อมตัวเชื่อม 그리고 ที่เชื่อมประโยคเข้าด้วยกัน คำเหล่านี้จะเจอในบทสนทนาและบทอ่านของบทนี้ทั้งหมด

#### รูปแบบ

| รูปเต็ม | รูปย่อภาษาพูด | ความหมาย |
|:---|:---|:---|
| 저의 | **제** | ของฉัน |
| 이것이 · 그것이 · 저것이 | **이게 · 그게 · 저게** | นี่ · นั่น · โน่น (ประธาน) |
| 무엇 | **뭐** | อะไร |

#### ตัวอย่างจากตำรา

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 제 사전 | พจนานุกรมของฉัน | 제 = 저의 |
| 제 지갑 | กระเป๋าสตางค์ของฉัน | 제 = 저의 |
| 이게 뭐예요? → 지갑이에요. | นี่คืออะไร → กระเป๋าสตางค์ | 이게 = 이것이 · 뭐 = 무엇 |
| 이 사람이 누구예요? → 제 여자 친구예요. | คนนี้คือใคร → แฟนสาวของฉัน | 누구 ไม่มีตัวสะกด → 예요 |

#### 그리고 — เชื่อมประโยค

그리고 แปลว่า "และ/แล้วก็" ใช้เชื่อม**ประโยค** คือจบประโยคเดิมแล้วขึ้นประโยคใหม่ด้วย 그리고

| 한국어 | ไทย |
|:---|:---|
| 이것은 러시아 돈이에요. 그리고 이것은 여자 친구 사진이에요. | {n:นี่}{e:คือ}{n:เงินรัสเซีย} {a:และ}{n:นี่}{e:คือ}{n:รูปแฟนสาว} |

#### 📽️ จากสมุดทบทวน

สมุดจดไว้ว่า "그리고 : sentence. 그리고 sentence. ; noun 하고 noun." — 하고 เชื่อมคำนาม (บท 13 · ไวยากรณ์ข้อ 11)

### 💬 대화 7-1 — นั่นหนังสือหรือ

압둘라 (อับดุลลา) ถาม 투이 (ทุย) ว่าสิ่งนั้นเป็นหนังสือหรือไม่ ทุยตอบว่าไม่ใช่ เป็นพจนานุกรม และไม่ใช่ของตัวเองแต่เป็นของเพื่อน บทสนทนานี้ใช้ทั้ง 이에요 และ 아니에요 ในบทเดียวกัน

> 압둘라: 그게 책이에요? *(นั่นหนังสือหรือ)*
>
> 투이: 아니요, 사전이에요. *(ไม่ใช่ค่ะ เป็นพจนานุกรม)*
>
> 압둘라: 투이 씨 사전이에요? *(เป็นพจนานุกรมของคุณทุยหรือ)*
>
> 투이: 아니요, 제 사전이 아니에요. 친구 사전이에요. *(ไม่ใช่ค่ะ ไม่ใช่พจนานุกรมของฉัน เป็นของเพื่อน)*

#### สังเกตจากบทสนทนา

- 그게 책이에요? — ถามด้วย 이에요 แล้วทำเสียงสูงขึ้น
- 아니요, 사전이에요. — ปฏิเสธแล้วบอกของจริง
- 투이 씨 사전이에요? — ชื่อ + 씨 + นาม = "ของคุณทุย"
- 제 사전이 아니에요. 친구 사전이에요. — ปฏิเสธด้วย 이/가 아니에요 แล้วบอกว่าเป็นของใคร

#### 확인 — คำถามท้ายบทสนทนา

คำถามในตำรา ใช้ 입니까 ส่วนเฉลยหาได้จากบทสนทนาข้างบน

- 이게 책입니까? → 아니요, 사전입니다. *(นี่หนังสือหรือ → ไม่ใช่ พจนานุกรม)*
- 누구 사전입니까? → 친구 사전입니다. *(ของใคร → ของเพื่อน)*

#### ฝึกสลับ (หน้า 62)

ตำราให้เอาคู่คำในตารางไปแทนที่ในบทสนทนาข้างบน คำซ้ายคือสิ่งที่ถามผิด คำขวาคือของจริง แถวแรกคือบทสนทนาเดิม ตัวอย่างแถว 2 คือ "그게 휴대폰이에요? → 아니요, 카메라예요." *(นั่นมือถือหรือ → ไม่ใช่ เป็นกล้อง)*

| ถามว่า | ของจริง |
|:---|:---|
| 책 *(หนังสือ)* | 사전 *(พจนานุกรม)* |
| 휴대폰 *(มือถือ)* | 카메라 *(กล้อง)* |
| 지갑 *(กระเป๋าสตางค์)* | 수첩 *(สมุดโน้ตเล่มเล็ก)* |
| 공책 *(สมุด)* | 잡지 *(นิตยสาร)* |

#### 활동 (หน้า 63) — เกมจำชื่อสิ่งของ

กิจกรรมคู่ให้จำชื่อของจากภาพแล้วถาม-ตอบตามกรอบ "이게 책이에요?" ตำราให้ภาพของ 15 อย่างเรียงเป็นตาราง 3 แถว แถวละ 5 ช่อง โดยไม่พิมพ์ชื่อกำกับ รายการข้างล่างอ่านจากภาพโดยเรียงจากซ้ายไปขวา แถวบนลงล่าง

- 물건의 이름을 기억해서 다음과 같이 말해 봅시다. *(จำชื่อสิ่งของแล้วพูดตามตัวอย่างข้างล่าง)*
- 가: 이게 책이에요? *(นี่หนังสือหรือ)*
- 나: 네, 책이에요. / 아니요, 책이 아니에요. *(ใช่ เป็นหนังสือ / ไม่ใช่ ไม่ใช่หนังสือ)*

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|
| 책 | หนังสือ | 수첩 | สมุดโน้ตเล่มเล็ก |
| 카메라 | กล้อง | 안경 | แว่นตา |
| 시계 | นาฬิกา | 지갑 | กระเป๋าสตางค์ |
| 연필 | ดินสอ | 공책 | สมุด |
| 전자사전 | พจนานุกรมอิเล็กทรอนิกส์ | 달력 | ปฏิทิน |
| 볼펜 | ปากกา | 가방 | กระเป๋า |
| 휴대폰 | มือถือ | 휴지통 | ถังขยะ |
| 사전 | พจนานุกรม | | |

ตำราให้วิธีเล่นชื่อ 방법 1 มี 5 ข้อ ช่องว่างในตำราเขียนเป็นขีดล่าง ที่นี่ใช้ ○○ แทน

- (1) 위와 같은 사물 그림 카드 15장을 준비한다. *(เตรียมการ์ดรูปสิ่งของแบบข้างบน 15 ใบ)*
- (2) 학생 A가 사물 그림 카드를 30초 동안 보여 주고 뒤집는다. *(นักเรียน A โชว์การ์ดรูปสิ่งของให้ดู 30 วินาทีแล้วคว่ำการ์ดลง)*
- (3) 학생 B가 그 카드를 기억해 내면서 '○○이에요?' 라고 질문한다. *(นักเรียน B นึกถึงการ์ดเหล่านั้นแล้วถามว่า "…이에요?")*
- (4) 학생 A가 자신만 그 카드를 보고 학생 B의 말이 맞으면 '네, ○○이에요.' 라고 말하면서 카드를 뒤집어 놓고, 맞지 않으면 '○○이/가 아니에요.' 로 대답한다. 이때, 학생 A는 카드에 있는 사물 이름을 말하지 않는다. *(A ดูการ์ดคนเดียว ถ้า B พูดถูกก็ตอบ "네, …이에요." แล้วพลิกการ์ดหงายขึ้น ถ้าไม่ถูกก็ตอบ "…이/가 아니에요." ระหว่างนี้ A ห้ามพูดชื่อของบนการ์ด)*
- (5) 이 게임은 한 사람당 3분 정도 진행한다. *(เกมนี้ใช้เวลาคนละประมาณ 3 นาที)*

### 📖 읽기 7-2 · 🎧 듣기 — กระเป๋าสตางค์ของฉัน

บทอ่านเป็นการแนะนำของที่อยู่ในกระเป๋าสตางค์ของอเล็กเซย์ ได้แก่ บัตรนักศึกษา เงินรัสเซีย และรูปแฟนสาว ประโยคเหล่านี้เป็นแหล่งของข้อสอบเขียนตามคำบอก

> 제 지갑이에요. *(กระเป๋าสตางค์ของฉันครับ)* 이것은 국민대학교 학생증이에요. *(นี่คือบัตรนักศึกษามหาวิทยาลัยคุกมิน)*
>
> 이것은 러시아 돈이에요. *(นี่คือเงินรัสเซีย)* 그리고 이것은 여자 친구 사진이에요. *({a:และ}{n:นี่}{e:คือ}{n:รูปแฟนสาว})*
>
> 제 여자 친구는 러시아 사람이 아니에요. *(แฟนสาวของฉันไม่ใช่คนรัสเซีย)* 미국 사람이에요. *({e:เป็น}{n:คนอเมริกัน})*

#### ก่อนอ่าน (หน้า 64) — ในกระเป๋าสตางค์มีอะไร

ในตำราหัวข้อนี้อยู่ก่อนบทอ่าน ให้ถามกันว่ามีกระเป๋าสตางค์ไหมและในกระเป๋ามีอะไร ตำราไม่พิมพ์เฉลย ใช้ประโยคจากบทอ่านของอเล็กเซย์เป็นตัวอย่างตอบ

- 여러분은 지갑이 있어요? 지갑에 무엇이 있어요? *(พวกคุณมีกระเป๋าสตางค์ไหม ในกระเป๋ามีอะไรบ้าง)*
- 이것은 국민대학교 학생증이에요. 이것은 러시아 돈이에요. *(นี่คือบัตรนักศึกษามหาวิทยาลัยคุกมิน นี่คือเงินรัสเซีย)*

#### คำถามท้ายบทอ่าน

คำถามมีทั้งแบบถาม-ตอบและแบบ O/X ที่ตอบจากบทอ่านข้างบน

| คำถาม | คำตอบ |
|:---|:---|
| 이 사람 직업이 뭐예요? *(คนนี้อาชีพอะไร)* | 학생이에요. *(นักศึกษา — ในหนังสือจดไว้ 대학생이에요)* |
| 여자 친구는 어느 나라 사람이에요? *(แฟนสาวเป็นคนประเทศไหน)* | 미국 사람이에요. *(คนอเมริกัน)* |
| 이 사람은 국민대학교 학생이에요. *(คนนี้เป็นนักศึกษาคุกมิน)* | **○** ถูก |
| 이 지갑은 여자 친구 지갑이에요. *(กระเป๋านี้เป็นของแฟนสาว)* | **×** ผิด — เป็น 제 지갑 (ของฉัน) |

#### 다 — ฟังแล้วอ่านตาม (ขีดเส้นใต้เพื่อเน้น)

ตำราให้ฟังแทร็ก 7-3 แล้วอ่านตาม โดยตั้งใจที่ส่วนที่ขีดเส้นใต้ในแต่ละประโยค ตัวหนาข้างล่างคือส่วนที่ขีดเส้นใต้ในตำรา

- 제 **지갑이에요.** *(เป็นกระเป๋าสตางค์ของฉัน)*
- **사진이에요.** *(เป็นรูป)*
- **학생증**이에요. *(เป็นบัตรนักศึกษา)*
- **돈이에요.** *(เป็นเงิน)*

#### 7-3 라 — แปลงบทอ่านเป็นบทสนทนา

ตำราให้อเล็กเซย์คุยกับเพื่อนโดยเติมคำตอบจากบทอ่าน ตัวอย่างข้างล่างคือคำตอบที่เติมได้

โจทย์ในตำราคือ "알렉세이 씨가 친구와 자기 지갑에 대해 이야기합니다. 어떻게 얘기할까요? 읽은 내용을 대화로 만들어 봅시다." *(อเล็กเซย์คุยกับเพื่อนเรื่องกระเป๋าสตางค์ของตัวเอง จะคุยกันอย่างไร ลองเอาเนื้อหาที่อ่านมาทำเป็นบทสนทนา)* ข้อนี้มีภาพประกอบ 4 ช่อง ช่องที่ 1 พิมพ์คำตอบของ 알렉세이 ไว้แล้ว ส่วนช่องที่ 2–4 พิมพ์เฉพาะคำถามของ 친구 และเว้นคำตอบให้เติมเอง

🖼️ *ภาพ 4 ช่องตามลำดับ: กระเป๋าสตางค์ที่มีบัตรอยู่ข้างใน · บัตรนักศึกษา · ธนบัตรรัสเซีย · รูปผู้หญิงผมยาวหยักศก*

- 친구: 이것이 뭐예요? → 알렉세이: 제 지갑이에요. *(นี่คืออะไร → กระเป๋าสตางค์ของฉัน)*
- 이것이 카드예요? → 아니요, 카드가 아니에요. 학생증이에요. *(นี่บัตรหรือ → ไม่ใช่บัตร เป็นบัตรนักศึกษา)*
- 이것이 미국 돈이에요? → 아니요, 미국 돈이 아니에요. 러시아 돈이에요. *(นี่เงินอเมริกันหรือ → ไม่ใช่ เป็นเงินรัสเซีย)*
- 이 사람이 누구예요? → 제 여자 친구예요. *(คนนี้คือใคร → แฟนสาวของฉัน)*

#### 활동 (หน้า 65) — ถามเรื่องในกระเป๋าสตางค์ของเพื่อน

ตำราให้ถาม-ตอบกับเพื่อนเรื่องของในกระเป๋าสตางค์ของเพื่อนเหมือนบทสนทนาข้างบน ไม่มีเฉลย ตัวอย่างตอบข้างล่างยืมโครงจากบทสนทนา 라 และใช้ ○○ แทนชื่อของ

- 친구의 지갑에 무엇이 있어요? 위의 대화와 같이 묻고 대답해 봅시다. *(ในกระเป๋าสตางค์ของเพื่อนมีอะไรบ้าง ลองถาม-ตอบเหมือนบทสนทนาข้างบน)*
- 이것이 뭐예요? → 제 ○○이에요. *(นี่คืออะไร → … ของฉัน)*
- 이것이 ○○이에요? → 아니요, ○○이/가 아니에요. ○○이에요. *(นี่ … หรือ → ไม่ใช่ … เป็น …)*

#### 🎧 ชีตฟัง 본문 듣기 (ใบงานฟังของศูนย์)

ใบงานฟังของศูนย์มี 2 แบบ คือ O/X และเติมคำในช่องว่าง

| ประโยค | ผล |
|:---|:---|
| 그것이 친구 책이에요. *(นั่นคือหนังสือของเพื่อน)* | **×** ผิด — เป็น 사전 (พจนานุกรม) |
| 그것이 책이 아니에요. *(นั่นไม่ใช่หนังสือ)* | **○** ถูก |
| 그것이 투이 씨 사전이에요. *(นั่นคือพจนานุกรมของคุณทุย)* | **×** ผิด — เป็น 친구 사전 (ของเพื่อน) |

เติมคำตามลำดับ: 그게 책이에요 / 사전이에요 / 아니에요 / 친구

### 🔊 발음

บทนี้ต้องใช้การเชื่อมเสียง (연음) บ่อยมาก เพราะ 이에요 ขึ้นต้นด้วยสระ ทำให้ตัวสะกดของคำนามด้านหน้าย้ายไปเป็นพยัญชนะต้นของพยางค์ถัดไป นอกจากนี้มี 2 คำที่ออกเสียงเข้มกว่าที่เขียน

| เขียน | อ่าน | กฎ |
|:---|:---|:---|
| 연필이에요 · 책이에요 | [연피리에요] · [채기에요] | 연음: 받침 + 이에요 → ย้ายตัวสะกดไปขึ้นต้นพยางค์ถัดไป |
| 공책이에요 · 지갑이에요 | [공채기에요] · [지가비에요] | 연음 (กฎเดียวกัน) |
| 볼펜이에요 · 사전이에요 | [볼페니에요] · [사저니에요] | 연음 |
| 학생증 · 잡지 | [학쌩쯩] · [잡찌] | ㄱ + ㅅ → ㅆ · ㅂ + ㅈ → ㅉ · 증 อ่านเสียงเข้ม [쯩] ในคำประสม (ตามที่ตำราให้) |
| 사진이에요 · 돈이에요 (7-3) | [사지니에요] · [도니에요] | 연음 (อ่านตามกฎเดียวกัน) |

### 🧪 ออกสอบอย่างไร

บทนี้ออกสอบเป็นแบบทดสอบประจำวัน 7과 และเนื้อหาของบทกลับมาใน 복습시험 ① กับ 중간시험 복습문제 ด้านล่างคือสิ่งที่ครูแก้และข้อผิดที่เคยเจอ

- **매일시험 7과** — ไม่มีคะแนนตัวเลขบนสแกน · ครูแก้ 2 จุด
  - A (4 ข้อ) ดูรูปแล้วเขียน: 연필 · 지우개 · 카메라 · 컴퓨터
  - B (3 ข้อ) เลือกจาก 보기: 이게 / 뭐 / 아니에요
  - C (3 ข้อ) เขียนตามคำบอก:
        - 제 사전이에요 *(เป็นพจนานุกรมของฉัน)*
        - 그게 카드예요 *(นั่นคือบัตร)* — C9
        - 이것이 돈이에요 *(นี่คือเงิน)* — C10
- 복습시험 ① 쓰기 A5–A6: 저(**는**) 한국 사람(**이**) 아니에요. *(ฉันไม่ใช่คนเกาหลี)*
- 복습시험 ① 쓰기 B3: 누구예요
- 복습시험 ① 쓰기 E2: 선생님이에요? → 아니요, 선생님이 아니에요. 간호사예요. *(เป็นครูหรือ → ไม่ใช่ครู เป็นพยาบาล)*
- 중간시험 복습문제 ข้อ 3: 저( ) 회사원( ) 아니에요
- 중간시험 복습문제 ข้อ 15 (읽기 7과 + ข้อ 5–6)

> [!WARNING] ที่เคยพลาด (매일시험 · เวิร์กบุ๊ก · ชีตฟัง · ดูก่อนสอบ)
> - ✗ C9 카드예요 → เขียน 가트 이에요 (ไม่มีตัวสะกด → 예요 ต่อกันเลย)
> - ✗ C10 돈 → 둔 (ㅗ/ㅜ)
> - ✗ เวิร์กบุ๊ก (ครูแก้ 4 ข้อ): 전화이에요 → **전화예요**
> - ✗ เวิร์กบุ๊ก: 기자 · 운동선수 · 여자 ก็ต้อง **예요**
> - ✗ ชีตฟัง B2: 사전이에요 → 사천미에요 (ㅈ/ㅊ ★)
> - ก่อนเติม 이에요/예요 ให้มองพยางค์สุดท้ายของคำนามก่อน: มีตัวสะกด → 이에요
> - ไม่มีตัวสะกด → 예요 (뭐예요 · 누구예요 · 카드예요 · 기자예요)

### 🔗 เชื่อมโยง

← ต่อยอดจาก

- 5과 입니다/입니까 → 이에요/예요 (ความหมายเดิม เปลี่ยนเป็นรูปสุภาพ)
- 5과 은/는 + 6과 이/가 → 여자 친구는 러시아 사람이 아니에요
- 6과 이것이 · 무엇 → 이게 · 뭐

→ ใช้ต่อใน

- 8과 몇 층이에요? · 몇 호예요? · 몇 번이에요?
- 10과 얼마예요? → 천 원이에요
- 15과 N(이)세요 (선생님이세요)
- 16과 아닙니다
- 17과 N이었어요/였어요

> [!SUMMARY] สรุปท้ายบท
> - 이에요/예요 = รูปสุภาพของ 입니다: มีตัวสะกด → 이에요 ไม่มี → 예요 (입니다 ไม่ดูตัวสะกด แต่ 이에요/예요 ต้องดู)
> - ปฏิเสธคำนามด้วย 이/가 아니에요: มีตัวสะกด → 이 ไม่มี → 가 แล้วบอกของจริงต่อ และเว้นวรรคก่อน 아니에요
> - 아니요 (คำตอบ "ไม่") ไม่ใช่ 아니에요 (กริยา "ไม่ใช่") ต้องมี 이/가 นำหน้า
> - ภาษาพูด: 제 = 저의, 이게 = 이것이 และ 뭐 = 무엇 (뭐예요 ✓ · 뭐이에요 ✗ · 무엇이에요 ✓) ส่วน 그리고 ใช้เชื่อมประโยค
> - ข้อผิดที่ต้องระวัง: 전화이에요 → 전화예요 (ไม่มีตัวสะกด) · 가트 이에요 → 카드예요 · 둔 → 돈 · 사천 → 사전 (ㅈ/ㅊ)
