## 7과: 제 사전이 아니에요 (ไม่ใช่พจนานุกรมของฉัน)

> **หลังจบบทนี้ทำอะไรได้**: ถามว่า "นี่ใช่…ไหม / คืออะไร" ด้วยรูปสุภาพ N이에요/예요 และตอบปฏิเสธ "ไม่ใช่…" ด้วย N이/가 아니에요 แล้วบอกของจริงต่อ

**🗣️ คำศัพท์สำคัญ**

| หมวด | คำศัพท์ (ไทย) |
|---|---|
| เครื่องเขียน ✏️ | 연필 (ดินสอ) · 지우개 (ยางลบ) · 볼펜 (ปากกาลูกลื่น) · 공책 (สมุด) · 수첩 (สมุดพก) · 필통 (กล่องดินสอ) |
| ของใช้ | 카메라 (กล้อง) · 컴퓨터 (คอมพิวเตอร์) · 전자사전 (พจนานุกรมอิเล็กทรอนิกส์) · 학생증 (บัตรนักศึกษา) · 카드 (บัตร) · 잡지 (นิตยสาร) · 휴대 전화 (มือถือ) |
| ในบทอ่าน | 돈 (เงิน) · 사진 (รูปถ่าย) · 여자 친구 (แฟนสาว) · 대학교 (มหาวิทยาลัย) · 그리고 (และ · แล้วก็) |
| ภาษาพูด | 제 (= 저의 ของฉัน) · 이게 / 그게 / 저게 (= 이것이 / 그것이 / 저것이) · 뭐 (= 무엇 อะไร) |

*รายการเต็มของศูนย์อยู่ท้ายบท*

**📝 ไวยากรณ์**

1. **N + 이에요 / 예요** — "เป็น/คือ…" แบบสุภาพ ใช้พูดทุกวัน · (ไวยากรณ์ข้อ 02)
   - 받침 ○ → **이에요**: 연필이에요 *(เป็นดินสอ)* · 알렉세이 씨는 경찰이에요 *({n:คุณอเล็กเซย์}{e:เป็น}{n:ตำรวจ})*
   - 받침 ✗ → **예요**: 지우개예요 *(เป็นยางลบ)* · 카메라예요 *(เป็นกล้อง)* · 왕쯔이 씨는 의사예요 *(คุณหวางจื่ออีเป็นหมอ)*
   - ถามด้วยรูปเดิม (เสียงสูงขึ้น): 연필이에요? → 아니요, 지우개예요. *(เป็นดินสอหรือ → ไม่ใช่ เป็นยางลบ)*
   - ลิงก์ระดับภาษา — ความหมายเดิม เปลี่ยนแค่ระดับ: 학생입니다 → 학생이에요 · 의사입니다 → 의사예요 · 학생입니까? → 학생이에요? · 이것이 무엇입니까? → 이게 뭐예요? · **입니다 ไม่ดูตัวสะกด แต่ 이에요/예요 ต้องดู**
   - 📽️ สมุดทบทวน 14/9 (หน้าสมุดจดของคุณ): จด "이에요, 예요" คู่กับ 입니다 และหัวข้อ "이/가 아니에요"
   - ⚠️ ไม่มีตัวสะกด → **예요**: 휴대 전화예요 · 기자예요 · 운동선수예요 · 여자예요 (เวิร์กบุ๊ก ครูแก้ 4 ข้อ ที่เขียน 이에요 ✗) · 카드예요 (매일시험 C9)
   - ⚠️ 뭐예요 ✓ · 뭐이에요 ✗ · 무엇이에요 ✓ · 무엇예요 ✗ (무엇 มี ㅅ → 이에요 · 뭐 ไม่มีตัวสะกด → 예요)
2. **N + 이/가 아니에요** — "ไม่ใช่…" (ปฏิเสธคำนาม) · (ไวยากรณ์ข้อ 02)
   - 받침 ○ → **이 아니에요**: 사전이 아니에요 *(ไม่ใช่พจนานุกรม)* · 볼펜이 아니에요 *(ไม่ใช่ปากกา)* · 받침 ✗ → **가 아니에요**: 카메라가 아니에요 *(ไม่ใช่กล้อง)* · 나무가 아니에요 *(ไม่ใช่ต้นไม้)*
   - ปฏิเสธแล้วบอกของจริงต่อ (연습 2–3): 공책이에요? → 아니요, 공책이 아니에요. 책이에요. *(เป็นสมุดหรือ → ไม่ใช่สมุด เป็นหนังสือ)* · 이게 볼펜이에요? → 아니요, 볼펜이 아니에요. 연필이에요. *(นี่ปากกาหรือ → ไม่ใช่ปากกา เป็นดินสอ)*
   - ใช้ร่วมกับ 은/는 ในประโยคเดียว: 제 여자 친구는 러시아 사람이 아니에요. 미국 사람이에요. *({n:แฟนสาว}{p:ของ}{n:ฉัน}{x:ไม่ใช่}{n:คนรัสเซีย} {e:เป็น}{n:คนอเมริกัน})*
   - ⚠️ 띄어쓰기 (ตามตำรา): 이/가 **ติดนาม** แล้ว **เว้นวรรค** ก่อน 아니에요 → 나무가 아니에요 ✓ · 나무가아니에요 ✗ (ไวยากรณ์ข้อ 13)
   - ⚠️ 아니요 (คำตอบ "ไม่") ≠ 아니에요 (กริยา "ไม่ใช่") → 아니요, 지갑이 아니에요 ✓ · 아니에요 ต้องมี 이/가 นำหน้า: 저는 한국 사람**이** 아니에요
3. **제 · 이게 · 뭐 · 그리고** — คำย่อภาษาพูด และตัวเชื่อม
   - 제 = 저의 (ของฉัน): 제 사전 *(พจนานุกรมของฉัน)* · 제 지갑 *(กระเป๋าสตางค์ของฉัน)* · 이게 / 그게 / 저게 = 이것이 / 그것이 / 저것이 · 뭐 = 무엇: 이게 뭐예요? → 지갑이에요. *(นี่คืออะไร → กระเป๋าสตางค์)* · 이 사람이 누구예요? → 제 여자 친구예요. *(คนนี้คือใคร → แฟนสาวของฉัน — 누구 ไม่มีตัวสะกด → 예요)*
   - **그리고** = "และ/แล้วก็" เชื่อม**ประโยค** (ขึ้นประโยคใหม่): 이것은 러시아 돈이에요. 그리고 이것은 여자 친구 사진이에요. *({n:นี่}{e:คือ}{n:เงินรัสเซีย} {a:และ}{n:นี่}{e:คือ}{n:รูปแฟนสาว})* — 📽️ สมุดทบทวน: "그리고 : sentence. 그리고 sentence. ; noun 하고 noun." (하고 เชื่อมคำนาม — บท 13 · ไวยากรณ์ข้อ 11)

**💬 대화 (7-1)**

> 압둘라: 그게 책이에요? *(นั่นหนังสือหรือ)*
>
> 투이: 아니요, 사전이에요. *(ไม่ใช่ค่ะ เป็นพจนานุกรม)*
>
> 압둘라: 투이 씨 사전이에요? *(เป็นพจนานุกรมของคุณทุยหรือ)*
>
> 투이: 아니요, 제 사전이 아니에요. 친구 사전이에요. *(ไม่ใช่ค่ะ ไม่ใช่พจนานุกรมของฉัน เป็นของเพื่อน)*

- 확인 (คำถามในตำรา ใช้ 입니까 · เฉลยจากบทสนทนา): 이게 책입니까? → 아니요, 사전입니다. · 누구 사전입니까? → 친구 사전입니다. *(นี่หนังสือหรือ → ไม่ใช่ พจนานุกรม · ของใคร → ของเพื่อน)*

**📖 읽기 7-2 · 🎧 듣기**

กระเป๋าสตางค์ของฉัน — ประโยคเหล่านี้เป็นแหล่งคำบอกเขียน:

> 제 지갑이에요. *(กระเป๋าสตางค์ของฉันครับ)* 이것은 국민대학교 학생증이에요. *(นี่คือบัตรนักศึกษามหาวิทยาลัยคุกมิน)*
>
> 이것은 러시아 돈이에요. *(นี่คือเงินรัสเซีย)* 그리고 이것은 여자 친구 사진이에요. *({a:และ}{n:นี่}{e:คือ}{n:รูปแฟนสาว})*
>
> 제 여자 친구는 러시아 사람이 아니에요. *(แฟนสาวของฉันไม่ใช่คนรัสเซีย)* 미국 사람이에요. *({e:เป็น}{n:คนอเมริกัน})*

- ถาม-ตอบ: 이 사람 직업이 뭐예요? → 학생이에요 (ในหนังสือจดไว้ 대학생이에요) · 여자 친구는 어느 나라 사람이에요? → 미국 사람이에요 *(คนนี้อาชีพอะไร → นักศึกษา · แฟนสาวเป็นคนประเทศไหน → คนอเมริกัน)*
- O/X: 이 사람은 국민대학교 학생이에요 (O) · 이 지갑은 여자 친구 지갑이에요 (X → 제 지갑) *(คนนี้เป็นนักศึกษาคุกมิน = ถูก · กระเป๋านี้เป็นของแฟนสาว = ผิด เป็นของฉัน)*
- แปลงเป็นบทสนทนา (7-3 라 — อเล็กเซย์คุยกับเพื่อน เติมคำตอบจากบทอ่าน):
  - 친구: 이것이 뭐예요? → 알렉세이: 제 지갑이에요. *(นี่คืออะไร → กระเป๋าสตางค์ของฉัน)*
  - 이것이 카드예요? → 아니요, 카드가 아니에요. 학생증이에요. *(นี่บัตรหรือ → ไม่ใช่บัตร เป็นบัตรนักศึกษา)*
  - 이것이 미국 돈이에요? → 아니요, 미국 돈이 아니에요. 러시아 돈이에요. *(นี่เงินอเมริกันหรือ → ไม่ใช่ เป็นเงินรัสเซีย)*
  - 이 사람이 누구예요? → 제 여자 친구예요. *(คนนี้คือใคร → แฟนสาวของฉัน)*
- 🎧 ชีตฟัง 본문 듣기 (ใบงานฟังของศูนย์): 그것이 친구 책이에요 (X → 사전) · 그것이 책이 아니에요 (O) · 그것이 투이 씨 사전이에요 (X → 친구 사전) *(นั่นคือหนังสือของเพื่อน = ผิด เป็นพจนานุกรม · นั่นไม่ใช่หนังสือ = ถูก · นั่นคือพจนานุกรมของคุณทุย = ผิด เป็นของเพื่อน)* · เติมคำ: 그게 책이에요 / 사전이에요 / 아니에요 / 친구

- **매일시험 7과** — ไม่มีคะแนนตัวเลขบนสแกน · ครูแก้ 2 จุด

  - B (3) เลือกจาก 보기: 이게 / 뭐 / 아니에요
  - C (3) เขียนตามคำบอก: 제 사전이에요 · 그게 카드예요 · 이것이 돈이에요 *(เป็นพจนานุกรมของฉัน · นั่นคือบัตร · นี่คือเงิน)*
