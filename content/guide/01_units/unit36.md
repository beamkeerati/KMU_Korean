## 36과 · 저녁은 제가 살게요 (เย็นนี้ฉันเลี้ยงเอง)

> [!INTRO] บทนี้ว่าด้วยอะไร
> บทที่ 36 ว่าด้วยเรื่อง **การนัดหมายและการปฏิเสธอย่างสุภาพ** สถานการณ์ในบทคือเพื่อนชวนไปดูหนังหรือไปร้านอาหารอินเดีย อีกฝ่ายตอบว่า "ติดนัดอยู่น่ะ" แล้วบอกว่า "เดี๋ยวฉันโทรกลับนะ" หรือ "เย็นนี้ฉันเลี้ยงเอง"
>
> ไวยากรณ์ใหม่มี 2 ข้อ และทั้งสองข้อเป็น **คำลงท้ายประโยค** ที่ให้น้ำเสียงต่างกัน:
>
> 1. **A/V-(으)ㄴ/는데요** (ไวยากรณ์ข้อ 61) — บอกสถานการณ์หรือเหตุผลแล้วทิ้งท้ายให้อีกฝ่ายตอบ ใช้ปฏิเสธอ้อม ๆ ว่า "…น่ะค่ะ" เช่น 지금은 좀 바쁜데요 *(ตอนนี้ค่อนข้างยุ่งน่ะ)*
> 2. **V-(으)ㄹ게요** (ไวยากรณ์ข้อ 62) — "…นะ (ฉันจะ…)" ใช้รับปากหรือตัดสินใจต่อหน้าผู้ฟัง โดยประธานต้องเป็นผู้พูดเอง เช่น 저녁은 제가 살게요 *(เย็นนี้ฉันเลี้ยงเอง)*
>
> ภาษาไทยแต่งน้ำเสียงด้วย "น่ะ" "นะ" "ค่ะ" ได้ตามใจ แต่ภาษาเกาหลีต้องเลือกรูปให้ตรงหน้าที่ การบอกสถานการณ์ (-는데요) ต่างจากการบอกแผน (-(으)ㄹ 거예요) และต่างจากการให้สัญญา (-(으)ㄹ게요)
>
> จบบทแล้วจะปฏิเสธคำชวนอย่างนุ่มนวลได้ รับปากหรือตัดสินใจต่อหน้าอีกฝ่ายได้ ("เดี๋ยวฉันโทรกลับนะ" · "เย็นนี้ฉันเลี้ยงเอง") และพูดโทรศัพท์นัดหมายและตอบรับคำชวนได้
>
> จุดที่คนไทยงงบ่อย: ตัด 으 ใน -(으)ㄹ게요 (먹게요 ✗ → 먹을게요) รากที่ลงท้าย ㄹ (살는데요 ✗ → 사는데요) และการปฏิเสธคำชวนด้วย "아니요" ตรง ๆ แทนที่จะบอกเหตุผลด้วย -는데요

### 📝 ไวยากรณ์: A/V-(으)ㄴ/는데요 — บอกสถานการณ์แล้วรอให้อีกฝ่ายตอบ (ไวยากรณ์ข้อ 61)

ตอนนี้ว่าด้วยรูปลงท้ายประโยคที่บอกสถานการณ์หรือเหตุผลแล้วทิ้งท้ายไว้ให้อีกฝ่ายตอบต่อ จึงฟังนุ่มกว่าการตอบตรง ๆ และใช้ปฏิเสธอ้อม ๆ ได้ ("…น่ะค่ะ") รูปที่ต่อขึ้นอยู่กับชนิดของคำ คือกริยา คำคุณศัพท์ หรือนาม

#### รูปแบบ

กฎตามชนิดคำ (กล่องตำรา หน้า 352) ใส่กาลได้ด้วย เช่น -았/었는데요

| ชนิดคำ | ต่อท้าย | ตัวอย่าง |
|:---|:---|:---|
| กริยา | **-는데요** | 안 먹는데요 · 끝나는데요 · 좋아하지 않는데요 |
| กริยา ราก ㄹ | ตัด ㄹ + **-는데요** | 사는데요 (살는데요 ✗) |
| คำคุณศัพท์ รากมีตัวสะกด | **-은데요** | 많은데요 |
| คำคุณศัพท์ รากจบสระหรือ ㄹ | **-ㄴ데요** | 바쁜데요 · 고픈데요 |
| คำคุณศัพท์ ㅂ ไม่ปกติ (ข้อ 37) | ㅂ → 우 + -ㄴ데요 | 추운데요 · 무서운데요 |
| นาม + 이다 | **-인데요** (ปฏิเสธ → -이/가 아닌데요) | 자리인데요 · 마키인데요 · 2급이 아닌데요 |
| 있다 / 없다 | **있는데요 / 없는데요** | 약속이 있는데요 · 시간이 없는데요 |
| ใส่กาล | **-았/었는데요** | 먹었는데요 |
| นามอดีต 받침 O | **-이었는데요** | 학생이었는데요 |
| นามอดีต 받침 X | **-였는데요** | 의사였는데요 |
| ปฏิเสธ กริยา | **-지 않는데요** | 쇼핑을 좋아하지 않는데요 |
| ปฏิเสธ คำคุณศัพท์ | **-지 않은데요** | 배가 고프지 않은데요 |
| ปฏิเสธ อดีต | **-지 않았는데요** | 숙제가 끝나지 않았는데요 |

ครูวงกลม 않는데요 กับ 않은데요 ในห้องและเขียน "not" กำกับรูปปฏิเสธทั้งสี่ (-지 않는데요 · -지 않은데요 · -지 않았는데요 · 이/가 아닌데요)

#### แสดงวิธีทำ: -(으)ㄴ/는데요 (ย่อ · ตารางเต็มในไวยากรณ์ข้อ 61)

กฎ 1 ถ้าเป็นอดีตให้ใส่ 았/었 ที่รากแล้วต่อ 는데요 กฎ 2 ถ้าเป็นปัจจุบันให้ดูชนิดคำ กริยากับ 있다/없다 ใช้ 는데요 นามใช้ 인데요 คำคุณศัพท์ใช้ 은데요 เมื่อมีตัวสะกด และ ㄴ데요 เมื่อไม่มี ส่วนรากที่ลงท้าย ㄹ และ ㅂ ดูตารางเต็มในข้อ 61

| ราก + คำต่อ | ① กาล | ② ชนิดคำ → คำต่อ | ③ ผล |
|:---|:---|:---|:---|
| 끝나 + (으)ㄴ/는데요 | ปัจจุบัน | กริยา → 는데요 | **끝나는데요** |
| 없 + (으)ㄴ/는데요 | ปัจจุบัน | 있다/없다 → 는데요 | **없는데요** |
| 많 + (으)ㄴ/는데요 | ปัจจุบัน | คำคุณศัพท์ มีตัวสะกด → 은데요 | **많은데요** |
| 바쁘 + (으)ㄴ/는데요 | ปัจจุบัน | คำคุณศัพท์ ไม่มีตัวสะกด → ㄴ데요 | **바쁜데요** |
| 자리 + 이다 | ปัจจุบัน | นาม → 인데요 | 자리**인데요** |
| 먹 + (으)ㄴ/는데요 | อดีต: 먹 + 었 | ทุกชนิดคำ → 는데요 | **먹었는데요** |

#### ตัวอย่างจากตำรา (กล่องหน้า 352)

ตัวอย่างในกล่องเป็นคำชวนตามด้วยคำปฏิเสธที่บอกเหตุผลด้วย -는데요 สี่แถวท้ายเป็นแบบปฏิเสธด้วย -지 않- และ 아닌데요 ที่ครูเน้นในห้อง (352쪽)

| 한국어 | ไทย |
|:---|:---|
| 윤아 씨, 내일 만날까요? → 미안해요. 내일은 다른 약속이 **있는데요**. | คุณยุนา พรุ่งนี้พบกันไหม — ขอโทษนะ พรุ่งนี้มีนัดอื่นน่ะ (บทสนทนาเปิดบท 준비 1) |
| 얘기 좀 할까요? → 지금은 좀 **바쁜데요**. | คุยกันหน่อยไหม — ตอนนี้ค่อนข้างยุ่งน่ะ |
| 여기에 앉아도 돼요? → 미안합니다. 제 **자리인데요**. | นั่งตรงนี้ได้ไหม — ขอโทษนะ ที่ของฉันน่ะ |
| 그럼 내일 만날까요? → 죄송합니다. 내일도 시간이 **없는데요**. | งั้นพรุ่งนี้พบกันไหม — ขอโทษ พรุ่งนี้ก็ไม่มีเวลาน่ะ |
| 점심 먹으러 갈까요? → 벌써 **먹었는데요**. | ไปกินข้าวกลางวันไหม — กินไปแล้วน่ะ |
| 주말에 쇼핑하러 갈까요? → 저는 쇼핑을 좋아하지 **않는데요**. | สุดสัปดาห์ไปช้อปปิ้งกันไหม — ฉันไม่ชอบช้อปปิ้งน่ะ (กริยา → 않는데요) |
| 지금 밥을 먹으러 갈까요? → 저는 아직 배가 고프지 **않은데요**. | ตอนนี้ไปกินข้าวกันไหม — ฉันยังไม่หิวน่ะ (คำคุณศัพท์ → 않은데요) |
| 우리 지금 운동하러 갈까요? → 저는 아직 숙제가 끝나지 **않았는데요**. | ตอนนี้ไปออกกำลังกายกันไหม — ฉันยังทำการบ้านไม่เสร็จน่ะ (อดีต → 않았는데요) |
| 2급 학생들은 언제 시험을 봐요? → 저는 아직 2급이 **아닌데요**. 1급**인데요**. | นักเรียนระดับ 2 สอบเมื่อไร — ฉันยังไม่ใช่ระดับ 2 น่ะ ฉันระดับ 1 น่ะ (นาม → 아닌데요) |

#### 연습 1 (หน้า 352) — ฝึก

ช่องว่างที่ตำราไม่พิมพ์เฉลย เติมให้ตามกฎ ข้อแรกเป็น 보기 ของตำรา

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 내일 콘서트에 갈까요? (있다) → 미안해요. 내일 시험이 **있는데요**. | ไปคอนเสิร์ตพรุ่งนี้ไหม — ขอโทษนะ พรุ่งนี้มีสอบน่ะ | 보기 |
| 저 영화를 볼까요? (좋아하지 않다) → 미안해요. 저는 무서운 영화를 **좋아하지 않는데요**. | ดูหนังเรื่องนั้นกันไหม — ขอโทษนะ ฉันไม่ชอบหนังน่ากลัวน่ะ | เติมตามกฎ |
| 같이 식사할까요? (먹었다) → 저는 1시간 전에 **먹었는데요**. | ไปกินข้าวด้วยกันไหม — ฉันกินไปเมื่อชั่วโมงก่อนน่ะ | เติมตามกฎ |
| 지금 좀 얘기할 수 있어요? (바쁘다) → 미안해요. 지금은 좀 **바쁜데요**. | คุยกันตอนนี้หน่อยได้ไหม — ขอโทษนะ ตอนนี้ค่อนข้างยุ่งน่ะ | เติมตามกฎ |
| 같이 운동을 할까요? (많다) → 미안해요. 오늘은 숙제가 **많은데요**. | ออกกำลังกายด้วยกันไหม — ขอโทษนะ วันนี้การบ้านเยอะน่ะ | เติมตามกฎ |
| 지금 통화할 수 있어요? (운전 중이다) → 지금 **운전 중인데요**. | คุยโทรศัพท์ตอนนี้ได้ไหม — ตอนนี้กำลังขับรถอยู่น่ะ | เติมตามกฎ |

#### 연습 2 (หน้า 353) — ปฏิเสธพร้อมเหตุผล

ข้อ 1 เป็น 보기 ข้อ 2 มีคำใบ้ (고기를 안 먹다) ส่วนข้อ 3–5 ตำราไม่มีคำใบ้ให้ตอบเอง ตัวอย่างตอบของข้อ 2–5 ด้านล่างเป็นตัวอย่างที่สร้างขึ้น

- 지금 같이 청소를 할까요? → 미안해요. 지금 바쁜데요. *(ไปทำความสะอาดด้วยกันตอนนี้ไหม — ขอโทษนะ ตอนนี้ยุ่งน่ะ — 보기)*
- 불고기를 먹으러 갈까요? (고기를 안 먹다) → 저는 고기를 안 먹는데요. *(ไปกินบุลโกกิกันไหม — ฉันไม่กินเนื้อน่ะ — ตัวอย่างตอบ)*
- 버스를 타고 갈까요? → 버스는 사람이 많은데요. *(นั่งรถบัสไปกันไหม — รถบัสคนเยอะน่ะ — ตัวอย่างตอบ ตำราให้ตอบเอง)*
- 빨간색 옷을 살까요? → 저는 빨간색을 안 좋아하는데요. *(ซื้อเสื้อสีแดงกันไหม — ฉันไม่ชอบสีแดงน่ะ — ตัวอย่างตอบ ตำราให้ตอบเอง)*
- 백화점에 구두를 사러 갈까요? → 오늘은 돈이 없는데요. *(ไปซื้อรองเท้าที่ห้างกันไหม — วันนี้ไม่มีเงินน่ะ — ตัวอย่างตอบ ตำราให้ตอบเอง)*

#### 연습 3 (หน้า 353) — ปฏิเสธพร้อมเสนอเวลาใหม่

แบบฝึกนี้เป็นบทสนทนาต่อเนื่อง คนหนึ่งเสนอเวลาไปเรื่อย ๆ อีกคนปฏิเสธทุกครั้งด้วย -는데요 จนในที่สุดนัดไว้คราวหน้า

- (ชวน) 같이 식사할까요? *(ไปกินข้าวด้วยกันไหม)*
- (ปฏิเสธ) 배가 안 **고픈데요**. *(ยังไม่หิวน่ะ)*
- (ชวน) 그럼 한 시간 후에 만나서 식당에 갈까요? *(งั้นอีกชั่วโมงแล้วพบกันไปร้านไหม)*
- (ปฏิเสธ) 그때에는 친구와 약속이 **있는데요**. *(ตอนนั้นนัดเพื่อนอยู่น่ะ)*
- (ชวน) 그럼 내일은 어때요? *(งั้นพรุ่งนี้ล่ะ)*
- (ปฏิเสธ) 내일은 수업이 늦게 **끝나는데요**. *(พรุ่งนี้เลิกเรียนช้าน่ะ)*
- (ชวน) 그럼 주말에는 어때요? *(งั้นสุดสัปดาห์ล่ะ)*
- (ปฏิเสธ) 미안해요. 주말에는 숙제가 **많은데요**. *(ขอโทษนะ สุดสัปดาห์การบ้านเยอะน่ะ)*
- (ชวน) 알겠어요. 그럼 다음에 같이 식사해요. *(เข้าใจแล้ว งั้นไว้คราวหน้านะ)*

การ์ดสถานการณ์ให้เลือกชวน:

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|
| 같이 식사하다 | กินข้าวด้วยกัน | 놀이공원에 가다 | ไปสวนสนุก |
| 커피숍에 가서 커피를 마시다 | ไปร้านกาแฟแล้วดื่มกาแฟ | 주말에 저녁을 먹다 | กินมื้อเย็นวันหยุด |
| 같이 쇼핑하러 가다 | ไปช้อปปิ้งด้วยกัน | 같이 축구하다 | เล่นฟุตบอลด้วยกัน |

#### ขึ้นต้นสายโทรศัพท์ (บท 37 ใช้ต่อ)

-인데요 ใช้บอกตัวเองตอนขึ้นต้นสายได้ด้วย

- 저는 마키**인데요**. *(นี่มากิค่ะ — ขึ้นต้นสาย)*

#### N하고 있어요 = N 중이에요 (เหตุผลว่ากำลังติดธุระ)

คำนาม + -하다 บอกว่ากำลังทำอยู่ได้สองแบบ คือ N하고 있어요 กับ N 중이에요 (ครูเขียน "ing" กำกับ 하고 있어요 ตำรา 352쪽) และเพราะ 중이다 คือ N이다 จึงต่อ -인데요 ใช้บอกว่าตอนนี้ไม่สะดวก ดังใน 연습 1 ข้อ 지금 운전 중인데요

| N하고 있어요 | N 중이에요 | N 중인데요 | ไทย |
|:---|:---|:---|:---|
| 수업하고 있어요 | 수업 중이에요 | 수업 중**인데요** | กำลังเรียนอยู่ |
| 운전하고 있어요 | 운전 중이에요 | 운전 중**인데요** | กำลังขับรถอยู่ |
| 식사하고 있어요 | 식사 중이에요 | 식사 중**인데요** | กำลังรับประทานอาหารอยู่ |
| 전화하고 있어요 | 통화 중이에요 | 통화 중**인데요** | กำลังคุยโทรศัพท์อยู่ |

- ครูยกคำ 수업하다 กับ 운전하다 เป็นตัวอย่างของ N하다 (และอีกสามคำ 식사하다 · 전화하다 · 일하다)
- 전화하고 있어요 = 전화 통화하고 있어요 = 통화 중이에요 โดยครูขีดเส้นใต้ **통화** (ใช้ 통화 중 ไม่ใช้ 전화 중)
- รูป 중인데요 ในตารางเป็นตัวอย่างประกอบจากกฎ -인데요 (ตัวอย่างในตำรามีเฉพาะ 운전 중인데요)

#### ⚠️ ระวัง

- **ปฏิเสธด้วย -는데요 ไม่ตอบ 아니요 ตรง ๆ** เหมือนข้อ 33 -(으)ㄹ까요? ที่ปฏิเสธด้วย 미안해요 + เหตุผล แต่เหตุผลเปลี่ยนจาก -아/어요 เป็น -는데요 ฟังนุ่มกว่า
- 있다 / 없다 / 재미있다 ใช้ **-는데요**: 재미있은데요 ✗ → 재미있는데요
- ★ ราก ㄹ: 사는데요 ✓ · 살는데요 ✗
- ㅂ ไม่ปกติ (ข้อ 37): 춥다 → 추운데요 · 무섭다 → 무서운데요
- 안 고프다 → 안 고픈데요
- ★ **-지 않다 ตามชนิดของคำที่อยู่ก่อน:** กริยา → 좋아하지 **않는**데요 · คำคุณศัพท์ → 고프지 **않은**데요 (✗ 고프지 않는데요 · ✗ 좋아하지 않은데요)
  - 좋아하다 เป็นกริยา (쇼핑을 좋아하다 มี 을/를) ส่วน 고프다 เป็นคำคุณศัพท์ ครูวงกลมสองรูปนี้ไว้บนกระดาน
  - เป็นกฎเดียวกับข้อผิดเดิม: ใช้ -는 กับคำคุณศัพท์ไม่ได้ (작는 ✗ → 작은 · 다르는 ✗ → 다른)
  - 끝나다 เป็นกริยา แต่ตัวอย่างเป็นอดีต จึงเป็น 끝나지 않았는데요 (ปัจจุบันคือ 끝나지 않는데요)
- N이/가 아니다 → 아닌데요 (2급이 아닌데요) และ 중이다 เป็น N이다 จึงเป็น 중인데요 เสมอ
- -네요 (ข้อ 30) = ตื่นเต้น/ค้นพบ เช่น 있네요 *(มีอยู่นี่นา)* ≠ -는데요 = บอกสถานการณ์แล้วรอให้อีกฝ่ายตอบ
- ตัวอย่างกล่องของตำราใช้ **앉아도 돼요?** (-아/어도 되다 "ได้ไหม") ซึ่งไม่อยู่ในรายการไวยากรณ์ของบท

→ เจาะลึก: ไวยากรณ์ข้อ 61 (เล่ม 2)

### 📝 ไวยากรณ์: V-(으)ㄹ게요 — "…นะ (ฉันจะ…)" รับปากต่อหน้าผู้ฟัง (ไวยากรณ์ข้อ 62)

ตอนนี้ว่าด้วยรูปที่ผู้พูดใช้รับปากหรือตัดสินใจทำสิ่งหนึ่งต่อหน้าอีกฝ่าย เช่น "ฉันไปก่อนนะ" "เดี๋ยวโทรใหม่นะ" **ประธานต้องเป็นผู้พูดเอง** (กล่องตำรา หน้า 354) ใช้ขออนุญาตแบบง่าย ๆ ได้ด้วย เช่น "ขอเปิดประตูหน่อยนะ"

#### รูปแบบ

| รากลงท้ายด้วย | ต่อท้าย | ตัวอย่าง |
|:---|:---|:---|
| สระ | **-ㄹ게요** | 가다 → 갈게요 |
| ตัวสะกด | **-을게요** | 읽다 → 읽을게요 |
| ㄹ | **-게요** (ไม่เปลี่ยน) | 만들다 → **만들게요** · 열다 → 열게요 |

#### แสดงวิธีทำ: -(으)ㄹ게요 (ย่อ · ตารางเต็มในไวยากรณ์ข้อ 62)

กฎ 1 ดูตัวสะกดของราก ไม่มีตัวสะกดใช้ ㄹ게요 มีตัวสะกดใช้ 을게요 กฎ 2 รากที่ลงท้าย ㄹ ให้ตัด 으 แล้วตัด ㄹ ของรากเพื่อให้ ㄹ ของคำต่อมาแทน ส่วนราก ㅂ และ ㄷ ไม่ปกติดูตารางเต็มในข้อ 62

| ราก + คำต่อ | ① ตัวสะกด → เลือก | ② ตัด 으 / ㄹ ของราก | ③ ผล |
|:---|:---|:---|:---|
| 가 + (으)ㄹ게요 | ไม่มีตัวสะกด → ㄹ게요 | ไม่มี 으 ให้ตัด | **갈게요** |
| 사 + (으)ㄹ게요 | ไม่มีตัวสะกด → ㄹ게요 | ไม่มี 으 ให้ตัด | **살게요** |
| 읽 + (으)ㄹ게요 | มีตัวสะกด → 을게요 | ไม่ตัด 으 | **읽을게요** |
| 앉 + (으)ㄹ게요 | มีตัวสะกด → 을게요 | ไม่ตัด 으 | **앉을게요** |
| 만들 + (으)ㄹ게요 | ราก ㄹ นับเหมือนไม่มี → ㄹ게요 | ตัด 으 แล้วตัด ㄹ ของราก | **만들게요** |
| 열 + (으)ㄹ게요 | ราก ㄹ นับเหมือนไม่มี → ㄹ게요 | ตัด 으 แล้วตัด ㄹ ของราก | **열게요** |

#### ตัวอย่างจากตำรา (กล่องหน้า 354)

| 한국어 | ไทย | การใช้ |
|:---|:---|:---|
| 주말에 이 영화를 볼까요? → 좋아요. 제가 표를 **살게요**. | ดูหนังเรื่องนี้สุดสัปดาห์ไหม — ได้ ฉันซื้อตั๋วเอง | บทสนทนาเปิดบท 준비 2 |
| 먼저 갈게요. | ฉันไปก่อนนะ | รับปาก/ตัดสินใจ |
| 제가 읽을게요. | ฉันอ่านเอง | รับปาก/ตัดสินใจ |
| 이번에는 제가 만들게요. | ครั้งนี้ฉันทำเอง | รับปาก/ตัดสินใจ |
| 문 좀 열게요. | ขอเปิดประตูหน่อยนะ | ขออนุญาตแบบง่าย |
| 여기 좀 앉을게요. | ขอนั่งตรงนี้นะ | ขออนุญาตแบบง่าย |

#### 연습 1 (หน้า 354)

แบบฝึกนี้ให้ตอบสถานการณ์ด้วยการรับปาก ข้อแรกเป็น 보기 และข้อสุดท้ายตำราให้เติมตามกฎ

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 언제 전화할 거예요? → 이따가 다시 **전화할게요**. | เมื่อไหร่จะโทร — เดี๋ยวโทรใหม่นะ | 보기 |
| 어디에서 기다릴 거예요? → 여기서 **기다리고 있을게요**. | จะรอที่ไหน — รออยู่ที่นี่นะ | 연습 1 |
| 음악이 좀 시끄러워요. → 죄송합니다. 조용히 **할게요**. | เพลงดังไปหน่อย — ขอโทษ จะทำให้เงียบนะ | 연습 1 |
| 교실이 너무 더워요. → 제가 문을 **열게요**. | ห้องร้อนไป — ฉันเปิดประตูเองนะ | 연습 1 |
| 지훈 씨, 오늘도 지각했어요. → 내일은 학교에 일찍 **올게요**. | วันนี้ก็มาสายอีก — พรุ่งนี้จะมาเช้านะ | 연습 1 |
| 좀 춥지 않아요? → 그럼 창문을 **닫을게요**. | หนาวไหม — งั้นฉันปิดหน้าต่างนะ | 연습 1 |
| 피자 좀 더 드세요. → 그럼 더 **먹을게요**. | กินพิซซ่าเพิ่มสิคะ — งั้นกินเพิ่มนะ | เติมตามกฎ |

#### 연습 2 (หน้า 355)

แบบฝึกนี้ให้ตอบด้วย -(으)ㄹ게요 เช่นกัน ข้อ 1 เป็น 보기 ข้อ 2 มีคำใบ้ (제가 읽다) ส่วนข้อ 3–5 ตำราไม่มีคำใบ้ ตัวอย่างตอบของข้อ 3–5 ที่เขียนไว้เป็นของที่สร้างขึ้น

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 몇 시까지 올 수 있어요? → 4시까지 **갈게요**. | มาได้ถึงกี่โมง — ไปให้ถึงสี่โมงนะ | 보기 |
| 책을 누가 읽을까요? → 제가 **읽을게요**. | ใครจะอ่านหนังสือดี — ฉันอ่านเองนะ | 연습 2 |
| 지금 전화할 수 있어요? → 아니요. 이따가 **전화할게요**. | โทรได้ตอนนี้ไหม — ไม่ได้ เดี๋ยวโทรนะ | ตัวอย่างตอบ |
| 교실이 어두워요. → 제가 불을 켤게요. | ห้องมืด — ฉันเปิดไฟเอง | ตัวอย่างตอบ (ตอบเอง) |
| (식당에서) 오늘 지갑을 안 가지고 왔어요. → 그럼 제가 **살게요 / 낼게요**. | วันนี้ไม่ได้เอากระเป๋าตังค์มา — งั้นฉันเลี้ยง/จ่ายเอง | ตัวอย่างตอบ |

#### 연습 3 (หน้า 355) — สัญญากับครู/เพื่อน

แบบฝึกนี้ต่อ -(으)면 กับ -(으)ㄹ게요 เพื่อสัญญาว่าจะทำอะไรถ้าเกิดเหตุการณ์หนึ่ง ตำราพิมพ์ไว้แค่ต้นประโยค 4 ข้อ ตัวอย่างตอบในตารางเป็นของที่สร้างขึ้น

| โจทย์ | ตัวอย่างตอบ | ไทย |
|:---|:---|:---|
| 오늘 숙제를 안 하면…… | 숙제를 안 하면 내일 꼭 할게요. | ถ้าไม่ทำการบ้านวันนี้ พรุ่งนี้จะทำแน่นอน |
| 시험에서 1등을 하면…… | 1등을 하면 제가 저녁을 살게요. | ถ้าสอบได้ที่ 1 ฉันจะเลี้ยงมื้อเย็น |
| 선생님/친구 생일에…… | 선생님 생일에 선물을 드릴게요. | วันเกิดครู/เพื่อน ฉันจะมอบของขวัญให้ (ตัวอย่างตอบ สร้างขึ้น) |
| 고향에 돌아가면…… | 고향에 돌아가면 전화할게요. | ถ้ากลับบ้านเกิดจะโทรหานะ |

#### เทียบ -(으)ㄹ게요 กับ -(으)ㄹ 거예요 และ -겠-

สามรูปนี้ทั้งหมดพูดถึงสิ่งที่จะทำ แต่ใช้ในสถานการณ์ต่างกัน

| รูป | ใช้เมื่อ | ตัวอย่าง | ไทย |
|:---|:---|:---|:---|
| -(으)ㄹ 거예요 (ข้อ 28) | แผนหรืออนาคตทั่วไป ถามได้ | 뭐 할 거예요? | จะทำอะไร |
| -(으)ㄹ게요 (ข้อ 62) | สัญญาหรือตัดสินใจตอบสนองอีกฝ่ายตอนนั้น **ถามไม่ได้** | 제가 읽을게요. | ฉันอ่านเองนะ |
| -겠습니다 (ข้อ 22) | แบบทางการ | 제가 하겠습니다. | ผมจะทำเอง |

#### ⚠️ ระวัง

- ✗ ใช้กับบุคคลที่สามไม่ได้: 민수 씨가 올게요 ✗ *(ประธานต้องเป็นผู้พูดเอง)*
- ✗ ใช้กับคำคุณศัพท์หรือรูปอดีตไม่ได้
- ★ **ตัด 으 ไม่ได้**: 먹게요 ✗ → 먹**을**게요 — ตระกูลเดียวกับ 씻러 · 읽세요
- สะกดเป็น **-ㄹ게요** ไม่ใช่ -ㄹ께요 แต่ออกเสียงเข้ม [ㄹ께요]

→ เจาะลึก: ไวยากรณ์ข้อ 62 (เล่ม 2)

### 💬 대화 36-1 — ชวนไปดูหนังและเลี้ยงข้าว

제프리 ชวน 마키 ไปดูหนัง 마키 บอกว่าพรุ่งนี้มีนัดอื่น (ปฏิเสธนุ่ม ๆ ด้วย -는데요) แต่เย็นวันพฤหัสหรือวันศุกร์ว่าง ท้ายบทสนทนาเธอตกลงดูหนังด้วยกันแล้วบอกว่าจะเลี้ยงมื้อเย็น (-(으)ㄹ게요)

> 제프리: 마키 씨, 내일 시간 있어요? *(คุณมากิ พรุ่งนี้ว่างไหม)*
>
> 마키: 내일은 다른 약속이 있는데요. 왜요? *(พรุ่งนี้มีนัดอื่นอยู่น่ะ ทำไมเหรอคะ)*
>
> 제프리: 시간이 있으면 마키 씨하고 같이 영화를 보러 가고 싶어요. *(ถ้ามีเวลา อยากไปดูหนังด้วยกันกับคุณมากิ)*
>
> 마키: 그래요? 목요일이나 금요일 저녁에는 시간이 괜찮아요. 그런데 무슨 영화예요? *(เหรอคะ เย็นวันพฤหัสหรือวันศุกร์ว่างค่ะ แล้วเป็นหนังอะไรคะ)*
>
> 제프리: 코미디 영화예요. *(หนังตลกครับ)*
>
> 마키: 재미있겠네요. 그럼 우리 영화 보고 같이 식사해요. 저녁은 제가 살게요. *(น่าจะสนุกนะคะ งั้นดูหนังแล้วกินข้าวด้วยกันนะคะ มื้อเย็นฉันเลี้ยงเอง)*

#### สังเกตจากบทสนทนา

- 내일은 다른 약속이 있는데요 — ปฏิเสธนุ่ม ๆ ด้วย -는데요 แล้วถามต่อว่า 왜요?
- 시간이 있으면 — -(으)면 "ถ้า" (ข้อ 55)
- 목요일이나 금요일 — N(이)나 "หรือ" (ข้อ 58)
- 재미있겠네요 — -겠- เดา (ข้อ 42) ต่อ -네요
- 저녁은 제가 살게요 — -(으)ㄹ게요 รับปากต่อหน้าผู้ฟัง

#### ฝึกสลับ (หน้า 356)

แต่ละบรรทัดมี 4 ช่อง คือ สิ่งที่จะไปทำ — วันเวลา — ประเภท — สิ่งที่ทำต่อ เปลี่ยนคำแล้วพูดบทสนทนาเดิม

- 영화를 보다 — 목요일/금요일 저녁 — 코미디 영화 — 식사하다 *(ดูหนัง — พฤหัส/ศุกร์เย็น — หนังตลก — กินข้าว)*
- 콘서트에 가다 — 토요일/일요일 오후 — 케이팝(K-POP) 콘서트 — 커피를 마시다 *(ไปคอนเสิร์ต — เสาร์/อาทิตย์บ่าย — คอนเสิร์ตเคป๊อป — ดื่มกาแฟ)*
- 축제를 구경하다 — 금요일/토요일 — 벚꽃 축제 — 영화를 보다 *(เที่ยวงานเทศกาล — ศุกร์/เสาร์ — งานซากุระ — ดูหนัง)*

#### 확인 — คำถามเช็กความเข้าใจ

- 제프리 씨는 언제 마키 씨와 영화를 보러 갑니까? → 목요일이나 금요일 저녁에 갑니다. *(เจฟฟรีย์จะไปดูหนังกับมากิเมื่อไหร่ — เย็นวันพฤหัสหรือวันศุกร์)*
- 영화를 본 후에 두 사람은 무엇을 하겠습니까? → 같이 식사하겠습니다. *(หลังดูหนังสองคนจะทำอะไร — กินข้าวด้วยกัน)*

#### 활동 (หน้า 357) — แสดงบทบาทสมมุติให้สัญญาด้วย -(으)ㄹ게요

กิจกรรมนี้ให้จับคู่แสดงบทบาท ฝ่ายหนึ่งตำหนิหรือถามถึงปัญหา อีกฝ่ายขอโทษและสัญญาว่าจะแก้ไขด้วย -(으)ㄹ게요 โจทย์ตามตำรา:

- 다음과 같은 상황이라면 여러분은 무슨 약속을 하겠어요? *(ถ้าเจอสถานการณ์แบบนี้ คุณจะสัญญาว่าอะไร)*
- 친구와 함께 아래의 대화처럼 '-(으)ㄹ게요'를 사용하여 역할극을 해 봅시다. *(แสดงบทบาทสมมุติกับเพื่อนเหมือนบทสนทนาด้านล่าง โดยใช้ -(으)ㄹ게요)*

| คู่บทบาท | สถานการณ์ |
|:---|:---|
| 선생님 – 학생 | 날마다 숙제를 안 해요 · 책을 안 가지고 와요 · 연필도 없어요 |
| 엄마 – 아이 | 엄마 말을 안 들어요 · 날마다 늦게 자고 늦게 일어나요 |
| 남편 – 아내 | 날마다 늦게 집에 들어와요 |
| 남자(여자) 친구 | 내 생일을 잊어버렸어요 · 다른 여자(남자)를 만나요 |

ตัวอย่างของตำรา:

- 선생님: 장핑 씨, 숙제했어요? *(จังผิง ทำการบ้านแล้วไหม)*
- 장핑: 죄송합니다. 어제 너무 바빴어요. 내일 꼭 할게요. *(ขอโทษค่ะ เมื่อวานยุ่งมาก พรุ่งนี้จะทำแน่นอน)*
- 선생님: 책은 가지고 왔어요? *(เอาหนังสือมาไหม)*
- 장핑: 아니요, 안 가지고 왔어요. 내일은 꼭 가지고 올게요. *(ไม่ได้เอามา พรุ่งนี้จะเอามาแน่นอน)*
- 선생님: 연필은 있어요? *(มีดินสอไหม)*
- 장핑: 연필도 없어요. 내일은 꼭 준비할게요. *(ไม่มีดินสอด้วย พรุ่งนี้จะเตรียมมาแน่นอน)*

### 🎧 듣기 36-2 — โทรศัพท์ชวนไปร้านอาหารอินเดีย

บทฟัง 듣기 36-2 เป็นบทสนทนาทางโทรศัพท์ที่ 제프리 โทรชวน 마키 ไปร้านอาหารอินเดียเปิดใหม่หน้าโรงเรียน สคริปต์มาจากภาคผนวก หน้า 373 บทนี้ใช้ทั้ง -는데요 (집에서 할 일이 좀 있는데요) และ -(으)ㄹ게요 (다시 전화할게요) ในบทสนทนาเดียว

คำถามก่อนฟังในตำรา (หน้า 358):

- 여러분은 약속을 하고 싶을 때나 약속을 거절하고 싶을 때 어떻게 말합니까? *(เวลาอยากนัดหมายหรืออยากปฏิเสธนัด คุณพูดอย่างไร)*

> 제프리: 여보세요. 마키 씨, 저 제프리예요. *(ฮัลโหล คุณมากิ ผมเจฟฟรีย์นะ)*
>
> 마키: 안녕하세요, 제프리 씨. *(สวัสดีค่ะ คุณเจฟฟรีย์)*
>
> 제프리: 마키 씨, 주말에 약속이 있어요? *(คุณมากิ สุดสัปดาห์มีนัดไหม)*
>
> 마키: 약속은 없지만 집에서 할 일이 좀 있는데요. 하지만 일요일에는 괜찮아요. 왜요? *(ไม่มีนัดแต่มีงานต้องทำที่บ้านนิดหน่อยน่ะ แต่วันอาทิตย์ไม่เป็นไรค่ะ ทำไมเหรอ)*
>
> 제프리: 학교 앞에 인도 식당이 생겼어요. 마키 씨가 인도 음식 좋아하니까 같이 가 볼까요? *(หน้าโรงเรียนมีร้านอาหารอินเดียเปิดใหม่ คุณมากิชอบอาหารอินเดียก็เลยไปลองด้วยกันไหม)*
>
> 마키: 저는 어제도 동대문에서 인도 음식을 먹었어요. 하지만 너무 달고 느끼했어요. *(เมื่อวานฉันก็กินอาหารอินเดียที่ตงแดมุน แต่หวานและเลี่ยนมากไป)*
>
> 제프리: 그랬어요? 하지만 학교 앞에 있는 식당은 요리사가 인도 사람이에요. 진짜 인도 요리를 하니까 맛있을 거예요. *(อย่างนั้นเหรอ แต่ร้านหน้าโรงเรียนพ่อครัวเป็นคนอินเดีย ทำอาหารอินเดียแท้ ๆ ก็น่าจะอร่อย)*
>
> 마키: 좋아요. 그럼 한번 가 봐요. 제가 토요일 밤에 다시 전화할게요. *(ได้ค่ะ งั้นไปลองสักครั้ง คืนวันเสาร์ฉันจะโทรหาใหม่นะคะ)*
>
> 제프리: 네, 기다릴게요. 안녕히 계세요. *(ครับ ผมจะรอนะ สวัสดีครับ)*
>
> 마키: 네, 안녕히 계세요. *(ค่ะ สวัสดีค่ะ)*

#### คำถามท้ายบท (เฉลยจากภาคผนวก)

| ข้อ | คำถาม | คำตอบ |
|:---|:---|:---|
| 가 1 | 제프리 씨는 왜 마키 씨에게 전화를 했습니까? | 마키 씨와 학교 앞에 새로 생긴 인도 식당에 같이 가고 싶어서 전화했습니다. |
| 가 2 | 마키 씨가 어제 먹은 음식은 어땠습니까? | 달고 느끼했습니다. |
| 가 3 | 학교 앞에 생긴 식당은 어떤 곳입니까? | 인도 사람이 요리하는 인도 식당입니다. |
| 나 1 | 마키 씨는 토요일에 친구와 약속이 있어요. | **✗** บทฟังบอกว่าไม่มีนัด มีแค่งานที่บ้าน |
| 나 2 | 마키 씨는 인도 요리를 좋아하지 않아요. | **✗** เฉลยให้ ✗ — เธอกินอาหารอินเดียเมื่อวานด้วย และ 제프리 ก็พูดว่า 좋아하니까 จึงไม่ใช่ว่าไม่ชอบ แค่บ่นว่าหวานเลี่ยนเกินไป |
| 나 3 | 제프리 씨는 마키 씨하고 일요일에 같이 식사할 거예요. | **○** เฉลยให้ ○ |

#### 다 — ฟังแล้วเขียน (36-3, เฉลยจากภาคผนวก)

- 약속은 없지만 집에서 할 일이 좀 있는데요.
- 너무 달고 느끼했어요.
- 제가 토요일 밤에 다시 전화할게요.

#### ท้ายบท — พูดอิสระ

- 한국에서 친구와 같이 간 곳에 대해 말해 봅시다. *(เล่าถึงสถานที่ในเกาหลีที่ไปกับเพื่อน — พูดอิสระ)*

### 🔊 발음

ตำราให้ 2 คำที่ใช้ในบท กฎที่ใช้คือ ㅆ ท้ายพยางค์ออกเสียงเป็น ㄷ และเปลี่ยนเป็น ㄴ เมื่อตามด้วย ㄴ กับ ㄱ ที่ตามหลัง ㄷ ออกเสียงเข้ม

| เขียน | อ่าน | กฎ |
|:---|:---|:---|
| 있는데요 | [인는데요] | ㅆ ท้ายพยางค์ออกเสียงเป็น ㄷ แล้วเป็น ㄴ เมื่อตามด้วย ㄴ |
| 재미있겠네요 | [재미읻껜네요] | กฎเดียวกัน และ ㄱ ตามหลัง ㄷ ออกเสียงเข้ม |

กฎทั่วไปที่ตำราบทนี้ไม่ได้พิมพ์ (-(으)ㄹ게요 ออกเสียงท้ายเข้ม [ㄹ께요] แต่สะกด -ㄹ게요):

| เขียน | อ่าน | เขียน | อ่าน |
|:---|:---|:---|:---|
| 먹을게요 | [머글께요] | 전화할게요 | [전화할께요] |
| 없는데요 | [엄는데요] | 연락할게요 | [열라칼께요] (ตำรา 37과 พิมพ์ไว้) |

### 🧪 ออกสอบอย่างไร

บทนี้ยังไม่มีข้อสอบจริง และไม่มี 매일시험 หรือเวิร์กบุ๊กของ 36과 ในคลัง ที่มีคือการคาดการณ์จากรูปแบบข้อสอบที่ผ่านมา

- คาดว่าออกใน **복습시험④ (30–37과 · 11/18)** และ **기말시험 (23–37과 · ศ. 11/20 · จ. 11/23)**
- รูปแบบที่น่าจะออก (ตาม 복습시험①②) มี 4 แบบ:
  - ตอบคำชวนด้วย -는데요 (เหตุผลที่ให้มา)
  - เติม -(으)ㄹ게요 ตามคำถาม -(으)ㄹ 거예요?
  - 말하기: ชวนไปดูหนัง/นัดเวลา + ปฏิเสธ + เลี้ยงข้าว (저녁은 제가 살게요)
  - 듣기: โทรศัพท์นัดหมาย

> [!WARNING] ที่น่าจะพลาด (คาดจากข้อผิดเดิม — ยังไม่มีข้อสอบจริง)
> - ★ ลืม **으**: 먹게요 ✗ → 먹을게요 · 닫게요 ✗ → 닫을게요 · 앉게요 ✗ → 앉을게요
> - ตระกูลเดียวกับที่เคยพลาด: 씻러 · 읽세요 · 받십니다
> - ★ ราก ㄹ: 만들을게요 ✗ → 만들게요 · 열을게요 ✗ → 열게요 · 사는데요 (살는데요 ✗)
> - ★ -는데요 กับคำคุณศัพท์ รากจบสระ/มีตัวสะกด: 바쁜데요 · 많은데요 · 고픈데요 — ลืม ㄴ หรือ 은
> - ★ ㅂ ไม่ปกติ: 추운데요 · 더운데요 (เคยสับสนเรื่อง ㅂ)
> - ตอบคำถามผิดประเภท: 언제 전화할 거예요? ตอบด้วย -(으)ㄹ게요 + เวลา (이따가 · 내일)
> - ตอบชวนด้วย 아니요 ตรง ๆ ✗ → 미안해요 + -는데요 (เคยปฏิเสธด้วย 아니요 ตรง ๆ)
> - ★ ㅈ/ㅊ และ ㅐ/ㅔ ในคำของบท: 지금 · 죄송합니다 · 조용히 · 자리
> - คำอื่นที่เสี่ยง: 지각 · 진짜 · 느끼하다 (느끼 ไม่ใช่ 느끄)
> - คำอื่นที่เสี่ยง: 결혼 · 벚꽃 · 약속
> - ไม่ใช้ -(으)ㄹ게요 กับบุคคลที่สาม/ถามผู้ฟัง: 마키 씨가 살게요? ✗ → 마키 씨가 살 거예요 / 제가 살게요 ✓

> [!SUMMARY] สรุปท้ายบท
> - -(으)ㄴ/는데요: บอกสถานการณ์แล้วรอให้อีกฝ่ายตอบ ใช้ปฏิเสธนุ่ม ๆ กริยา -는데요 · คำคุณศัพท์ -(으)ㄴ데요 · นาม -인데요 · 있다/없다 -는데요 (ไม่ตอบ 아니요 ตรง ๆ)
> - -(으)ㄹ게요: รับปากหรือตัดสินใจต่อหน้าผู้ฟัง ประธานต้องเป็นผู้พูดเอง สระ -ㄹ게요 · ตัวสะกด -을게요 · ㄹ -게요 และถามไม่ได้ ต่างจาก -(으)ㄹ 거예요
> - ข้อผิดที่ต้องระวัง: ตัด 으 (먹게요 ✗ → 먹을게요) ราก ㄹ (살는데요 ✗ · 만들을게요 ✗) และใช้ -(으)ㄹ게요 กับบุคคลที่สาม
> - ข้อสอบ: ตอบคำชวนด้วย -는데요 · เติม -(으)ㄹ게요 ตามคำถาม -(으)ㄹ 거예요? · 말하기 ชวน/ปฏิเสธ/เลี้ยงข้าว (저녁은 제가 살게요) · 듣기 โทรศัพท์นัดหมาย
