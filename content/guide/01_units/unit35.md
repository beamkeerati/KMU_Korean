## 35과 · 운동하는 것을 좋아하세요? (ชอบการออกกำลังกายไหมคะ?)

> [!INTRO] บทนี้ว่าด้วยอะไร
> บทที่ 35 ว่าด้วยเรื่อง **งานอดิเรก ประสบการณ์ และความฝัน** สถานการณ์ในบทคือเพื่อนสองคนคุยกันว่าชอบออกกำลังกายหรือเปล่า คนหนึ่งชอบ "ดู" มากกว่า "ทำ" จากนั้นอ่านเรื่องของบัทที่มีงานอดิเรกและความฝันเยอะจนกังวลใจ
>
> ไวยากรณ์ใหม่มี 2 ข้อ กับเนื้อหาเสริมอีก 1 เรื่อง:
>
> 1. **V-는 것** (ไวยากรณ์ข้อ 59) — ทำกริยาให้เป็นคำนามแปลว่า "การ…" หรือ "สิ่งที่…" เช่น 운동하는 것을 좋아해요 *(ชอบการออกกำลังกาย)* ใช้พูดว่าชอบ ไม่ชอบ ยาก หรือง่ายต่อ "การทำ…"
> 2. **V-아/어/여 보다** (ไวยากรณ์ข้อ 60) — แปลว่า "ลอง…ดู" และ "เคย…" พร้อมกัน เช่น 제주도에 가 봤어요? *(เคยไปเชจูไหม)* ภาษาไทยมีคำ "ลอง" กับ "เคย" แยกกัน แต่ภาษาเกาหลีใช้รูปเดียว
> 3. **N이/가 되다** (เสริม) — "กลายเป็น/เป็น…" ที่ปรากฏในสำนวน 되고 싶다 *(อยากเป็น…)* ตอนพูดถึงความฝัน
>
> จบบทแล้วจะพูดถึงงานอดิเรกด้วย "การ + กริยา" ได้ ถามและเล่าประสบการณ์ได้ แนะนำให้เพื่อนลองทำสิ่งต่าง ๆ ได้ (한번 가 보세요) และเล่าความฝันได้ด้วย -고 싶다 กับ 되고 싶다
>
> จุดที่คนไทยงงบ่อย: รากที่ลงท้าย ㄹ ต้องตัด ㄹ ก่อน -는 것 (만들는 것 ✗ → 만드는 것) ราก ㄷ กับ 르 ต้องเปลี่ยนก่อนต่อ -어 보다 (듣어 ✗ → 들어 보다) และ 가 봤어요 (เคยไป) ไม่ใช่ 갔어요 (ไปแล้ว)

### 📝 ไวยากรณ์: V-는 것 — "การ…" ทำกริยาให้เป็นคำนาม (ไวยากรณ์ข้อ 59)

ตอนนี้ว่าด้วยการเปลี่ยนกริยาให้ทำหน้าที่เป็นคำนาม แปลว่า "การ…" หรือ "สิ่งที่…" ภาษาไทยเอา "การ" มานำหน้ากริยาได้เลย แต่ภาษาเกาหลีต้องต่อ -는 것 ที่ท้ายราก แล้ว 것 ก็ทำหน้าที่เป็นคำนามตัวหนึ่ง ตามด้วยคำช่วย 이/가 · 은/는 · 을/를 ตามหน้าที่ในประโยค

#### รูปแบบ

ใช้กับ**รากกริยา** และกับ**คำคุณศัพท์ที่ลงท้าย 있다/없다** กล่องตำราหน้า 344 พูดถึงกริยากับ 있다/없다 เท่านั้น ส่วนคำคุณศัพท์อื่นใช้ -(으)ㄴ 것 (ดูข้อ 36) รากที่ลงท้าย ㄹ ต้อง**ตัด ㄹ**

| ราก | + -는 것 | ความหมาย |
|:---|:---|:---|
| 보다 | 보는 것 | การดู |
| 걷다 | 걷는 것 | การเดิน |
| 살다 | **사는 것** | การอยู่อาศัย |
| 만들다 | **만드는 것** | การทำ การสร้าง |
| 재미있다 | 재미있는 것 | สิ่งที่สนุก |
| 없다 | 없는 것 | การไม่มี |

#### ตัวอย่างจากตำรา (กล่องหน้า 344)

| 한국어 | ไทย |
|:---|:---|
| 이리나 씨, 운동하는 것을 좋아하세요? → 아니요. 하는 것보다 보는 것을 좋아해요. | คุณอีรีนา ชอบออกกำลังกายไหม — ไม่ ชอบดูมากกว่าทำ (บทสนทนาเปิดบท 준비 1) |
| 영화 보는 것을 좋아해요. | ชอบดูหนัง |
| 걷는 것은 건강에 좋아요. | การเดินดีต่อสุขภาพ |
| 시간이 없는 것이 문제입니다. | การไม่มีเวลาเป็นปัญหา |
| 외국에서 사는 것은 쉽지 않습니다. | การอยู่ต่างประเทศไม่ง่าย |

ช่องว่างที่ตำราไม่พิมพ์เฉลย เติมให้ตามกฎ ข้อแรกเป็น 보기 ของตำรา

| 한국어 | ไทย | ที่มา |

| 영화 보는 것이 제 취미예요. | การดูหนังคืองานอดิเรกของฉัน | เติมตามกฎ |
| 노래 부르는 것을 좋아하세요? | ชอบร้องเพลงไหมคะ | เติมตามกฎ |

| 기숙사에 사는 것이 어때요? | การอยู่หอพักเป็นยังไงบ้าง | เติมตามกฎ |

#### 연습 2 (หน้า 345) — ถามงานอดิเรก

แบบฝึกนี้ให้ถามและตอบว่างานอดิเรกคืออะไรโดยดูภาพ 10 ช่อง

- 제프리 씨, 취미가 뭐예요? → 저는 운동하는 것을 좋아해요. *(คุณเจฟฟรีย์ งานอดิเรกคืออะไร — ฉันชอบออกกำลังกาย)*

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|
| 운동하다 | ออกกำลังกาย | 영화 보다 | ดูหนัง |

| 춤추다 | เต้น | 콘서트에 가다 | ไปคอนเสิร์ต |
| 여행하다 | เที่ยว | 게임하다 | เล่นเกม |

#### 연습 3 — ถามเพื่อนร่วมชั้น

แบบฝึกนี้ให้ถามเพื่อนว่าชอบทำสิ่งต่าง ๆ ไหมด้วย -는 것 แล้วตอบว่าชอบมากหรือไม่ชอบ

- 혼자 영화 보는 것을 좋아하세요? → 네, 아주 좋아해요. / 아니요, 싫어해요. *(ชอบดูหนังคนเดียวไหม — ชอบมาก / ไม่ ไม่ชอบ)*

หัวข้อในตารางของตำรา:

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|
| 혼자 영화를 보다 | ดูหนังคนเดียว | 그림을 그리다 | วาดรูป |
| 혼자 식사하다 | กินข้าวคนเดียว | 외국어 공부를 하다 | เรียนภาษาต่างประเทศ |
| 편지를 쓰다 | เขียนจดหมาย | 앞자리에 앉다 | นั่งแถวหน้า |

#### เทียบสองอย่าง (ข้อ 41 N보다 จาก 26과)

-는 것 ใช้เทียบสองการกระทำได้ด้วย N보다 ที่เรียนมาจาก 26과

- 하는 것보다 보는 것을 좋아해요. *(ชอบดูมากกว่าทำ)*

#### ⚠️ ระวัง

- **것 เป็นคำนามอาศัย เขียนเว้นวรรค** (보는 **것**을) แล้วตามด้วย 이/가 · 은/는 · 을/를 ตามหน้าที่ในประโยค
- ★ **ราก ㄹ ต้องตัด ㄹ**: 만들는 것 ✗ → **만드는 것** ตระกูลเดียวกับ 만들습니다 · 만들으세요 ที่เคยพลาด
- 좋아하는 것 = "สิ่งที่ชอบ/การชอบ" ต่างจาก 좋아하는 + N *(ชอบ…)* ที่ยังมีนามตามหลัง

→ เจาะลึก: ไวยากรณ์ข้อ 59 (เล่ม 2)

### 📝 ไวยากรณ์: V-아/어/여 보다 — "ลอง…ดู" · "เคย…" (ไวยากรณ์ข้อ 60)

ตอนนี้ว่าด้วยรูปที่แปลได้สองแบบ คือ "ลองทำดู" (ลองทำ) และ "เคยทำ" (ประสบการณ์ในอดีต) ภาษาไทยมีคำว่า "ลอง" กับ "เคย" แยกกัน แต่ภาษาเกาหลีใช้ -아/어 보다 รูปเดียว ถ้าอยู่ในอดีต (봤어요) แปลว่า "เคย" ถ้าเป็นคำสั่งชวน (보세요) แปลว่า "ลองดูนะ"

#### รูปแบบ

| รากลงท้ายด้วย | ต่อท้าย | ตัวอย่าง |
|:---|:---|:---|
| สระ ㅏ / ㅗ | **-아 보다** | 가다 → 가 보다 · 오다 → 와 보다 · 타다 → 타 보다 |
| สระอื่น | **-어 보다** | 먹다 → 먹어 보다 · 입다 → 입어 보다 · 배우다 → 배워 보다 |
| 하다 | **해 보다** | 하다 → 해 보다 |

#### ตัวอย่างจากตำรา (กล่องหน้า 346)

| 한국어 | ไทย |
|:---|:---|
| 제프리 씨, 제주도에 가 봤어요? → 아니요, 안 가 봤어요. | คุณเจฟฟรีย์ เคยไปเชจูไหม — ไม่ ไม่เคยไป (บทสนทนาเปิดบท 준비 2) |
| 우리 집에 한번 와 보세요. | ลองมาบ้านฉันสักครั้งนะ |
| 이 음악을 들어 보셨어요? | เคยลองฟังเพลงนี้ไหมคะ |
| 한국 노래를 해 봤어요? | เคยร้องเพลงเกาหลีไหม |
| 제주도에 안 가 봤어요. | ยังไม่เคยไปเชจู |

#### ถาม "เคย…ไหม" (หน้า 346)

แบบฝึกนี้ให้ถามว่าเคยทำสิ่งต่าง ๆ ไหม มีตัวอย่างถาม-ตอบก่อน แล้วฝึก 7 ข้อ

- 제주도에 가 봤어요? → 아니요, 안 가 봤어요. *(เคยไปเชจูไหม — ไม่ ไม่เคยไป)*

| โจทย์ | ตอบด้วย -아/어 봤어요 | ความหมาย |
|:---|:---|:---|
| 제주도에 가다 | 가 봤어요 | ไปเชจู |
| 고속버스를 타다 | 타 봤어요 | ขึ้นรถทัวร์ด่วน |
| 한국 노래를 부르다 | **불러** 봤어요 | ร้องเพลงเกาหลี |
| 한복을 입다 | 입어 봤어요 | ใส่ฮันบก |
| 혼자 여행을 하다 | 해 봤어요 | เที่ยวคนเดียว |
| 삼계탕을 먹다 | 먹어 봤어요 | กินซัมเกทัง |
| 이 음악을 듣다 | **들어** 봤어요 | ฟังเพลงนี้ |

#### 연습 2 (หน้า 347) — ชวนให้ลอง

แบบฝึกนี้ถามว่าเคยทำไหม ถ้าไม่เคยก็ชวนให้ลองพร้อมบอกว่าเป็นอย่างไร

- 한강에서 유람선을 타 봤어요? → 아니요, 안 타 봤어요. → 그럼 한번 타 보세요. 아주 재미있어요. *(เคยนั่งเรือล่องแม่น้ำฮันไหม — ไม่เคย — งั้นลองสักครั้งนะ สนุกมาก)*

โจทย์ 7 ข้อของตำรา:

| 한국어 | ไทย |
|:---|:---|
| 한강에서 유람선을 타다 / 아주 재미있다 | นั่งเรือล่องแม่น้ำฮัน / สนุกมาก |
| 태권도를 배우다 / 재미있다 | เรียนเทควันโด / สนุก |
| 한복을 입다 / 예쁘다 | ใส่ฮันบก / สวย |
| 한국 신문을 읽다 / 어렵지 않다 | อ่านหนังสือพิมพ์เกาหลี / ไม่ยาก |
| 찜질방에 가다 / 기분이 좋다 | ไปชิมจิลบัง / รู้สึกดี |
| 떡볶이를 만들다 / 아주 간단하다 | ทำต๊อกบกกี / ง่ายมาก |
| 시골 여행하다 / 경치가 좋다 | เที่ยวชนบท / ทิวทัศน์ดี |

#### 연습 3 (หน้า 347) — แนะนำสถานที่

แบบฝึกนี้ให้ถามเพื่อนว่าเคยไปที่ไหนไหม แล้วแนะนำว่าควรทำอะไรและกินอะไร ตัวอย่างในตำราเป็นบทสนทนาเรื่องเมียงดง

- 바트 씨, 명동에 가 봤어요? *(คุณบัท เคยไปเมียงดงไหม)*
- → 네, 가 봤어요. *(เคย)*
- 저도 명동에 가고 싶어요. 명동에서는 무엇을 하는 것이 좋아요? *(ฉันก็อยากไปเมียงดง ที่นั่นควรทำอะไรดี)*
- → 가게가 많으니까 쇼핑을 해 보세요. 아주 재미있을 거예요. *(ร้านเยอะ ลองช้อปปิ้งดูนะ สนุกแน่)*
- 음식은 뭘 먹는 것이 좋아요? *(อาหารควรกินอะไรดี)*
- → 명동은 칼국수가 유명해요. 칼국수를 먹어 보세요. *(เมียงดงขึ้นชื่อเรื่องคาลกุกซู ลองกินดูนะ)*

ตารางให้เติมข้อมูลของเพื่อน ตัวอย่างแถวแรกเป็นของตำรา

| 이름 | 장소 | 할 일 | 음식 |
|:---|:---|:---|:---|
| 바트 | 명동 | 쇼핑 | 칼국수 |

#### -아/어 보고 싶다 — "อยากลอง…ดู"

รูป -아/어 보다 ต่อกับ -고 싶다 (ข้อ 38) ได้ทันที ได้ความว่า "อยากลอง…ดู" โดยต่อ -고 싶다 ท้ายรูป -아/어 보다

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 저는 몽골에 가 보고 싶어요. | ฉันอยากลองไปมองโกเลีย | 활동 หน้า 349 |
| 몽골에서 말을 타 보고 싶어요. | อยากลองขี่ม้าที่มองโกเลีย | 활동 หน้า 349 |
| 나중에 영화를 만들어 보고 싶습니다. | ภายหลังอยากลองสร้างหนัง | 읽기 35-2 |

#### ⚠️ ระวัง

- ★ **ราก ㄷ / 르 ต้องเปลี่ยนก่อนต่อ -어 보다** (ข้อ 51 ㄷ 불규칙 · ข้อ 54 르 불규칙)
  - 듣다 → **들어** 보다 *(ลองฟัง)* ไม่ใช่ 듣어 ✗
  - 부르다 → **불러** 보다 *(ลองร้อง)* ไม่ใช่ 부르어 ✗
- **가 봤어요 ≠ 갔어요**: 가 봤어요 = เคยไป (ประสบการณ์) ส่วน 갔어요 = ไปแล้ว (เหตุการณ์)
- ปฏิเสธ = **안 + กริยา 가**: 안 가 봤어요 ✓ · 가 안 봤어요 ✗
- 한번 *(ลองสักครั้ง/สักวัน)* เขียนติดกันในตำรา

→ เจาะลึก: ไวยากรณ์ข้อ 60 (เล่ม 2)

### 📝 ไวยากรณ์: N이/가 되다 — "กลายเป็น / เป็น…" (เสริม — ไม่มีหมายเลขข้อ)

📌 หัวข้อนี้เป็นเนื้อหาเสริมที่ปรากฏในบท 되다 แปลว่า "กลายเป็น/เป็น…" ใช้ 이/가 ตามหลังนามที่เป็นผลลัพธ์ ตำราไม่ได้อธิบายเป็นหัวข้อ ให้จำเป็นสำนวน "N이/가 되고 싶다" *(อยากเป็น N)* ที่ใช้เล่าความฝันในบทอ่าน (หน้า 350)

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 사진작가도 되고 싶고 | อยากเป็นช่างภาพด้วย | 읽기 35-2 |
| 유명한 소설가나 영화감독도 되고 싶습니다. | อยากเป็นนักเขียนนิยายหรือผู้กำกับหนังที่มีชื่อเสียงด้วย | 읽기 35-2 |

→ เจาะลึก: ไม่มีหมายเลขข้อของตัวเอง เล่ม 2 รวมไว้เป็นหมายเหตุเสริมในข้อ 59 และ 60

### 💬 대화 35-1 — ชอบดูมากกว่าทำ

윤아 ถาม 간토야 ว่าชอบออกกำลังกายไหม เขาตอบว่าชอบ "ดู" มากกว่า "ทำ" 윤아 เล่าว่าช่วงนี้เรียนสปอร์ตแดนซ์และชวนให้ลองเรียน 간토야 ไม่ชอบเต้นแต่อยากไปดู บทสนทนานี้ใช้ทั้ง -는 것 และ -아/어 보다

> 윤아: 간토야 씨, 운동하는 것을 좋아하세요? *(คุณคันโตยะ ชอบออกกำลังกายไหมคะ)*
>
> 간토야: 아니요, 하는 것보다 보는 것을 좋아해요. *(ไม่ค่ะ ชอบดูมากกว่าทำ)*
>
> 윤아: 그래요? 저는 요즘 스포츠 댄스를 배우고 있어요. *(เหรอคะ ช่วงนี้ฉันกำลังเรียนสปอร์ตแดนซ์อยู่)*
>
> 간토야: 스포츠 댄스요? 그거 어려워요? *(สปอร์ตแดนซ์เหรอคะ ยากไหม)*
>
> 윤아: 전혀 어렵지 않아요. 간토야 씨도 배워 보세요. *(ไม่ยากเลยค่ะ คุณคันโตยะก็ลองเรียนดูสิคะ)*
>
> 간토야: 저는 춤추는 것을 좋아하지 않아요. 하지만 윤아 씨가 하는 것을 보러 가고 싶어요. *(ฉันไม่ชอบเต้น แต่อยากไปดูที่คุณยุนาทำ)*

#### สังเกตจากบทสนทนา

- 운동하는 것을 좋아하세요? — ใช้ -는 것 เป็นกรรมของ 좋아하다 เพื่อถามความชอบ
- 하는 것보다 보는 것을 좋아해요 — เทียบ "ทำ" กับ "ดู" ด้วย N보다 และ -는 것 สองครั้ง
- 배워 보세요 — -아/어 보다 ในความหมาย "ลอง…ดูนะ" เพื่อแนะนำให้ลอง
- 윤아 씨가 하는 것을 보러 가고 싶어요 — -는 것ซ้อนกับ -(으)러 และ -고 싶다

#### ฝึกสลับ (หน้า 348)

เปลี่ยนคู่กริยาและสิ่งที่เรียนตามตาราง แล้วพูดบทสนทนาเดิม

| 하다 | 보다 | 배우다 | ไทย |
|:---|:---|:---|:---|
| 운동하다 | 보다 | 스포츠 댄스를 배우다 | ออกกำลังกาย — ดู — เรียนสปอร์ตแดนซ์ |
| 운동하다 | 보다 | 요가를 배우다 | ออกกำลังกาย — ดู — เรียนโยคะ |
| 요리하다 | 먹다 | 한국 요리를 배우다 | ทำอาหาร — กิน — เรียนอาหารเกาหลี |
| 노래 부르다 | 듣다 | 케이팝(K-pop)을 배우다 | ร้องเพลง — ฟัง — เรียนเคป๊อป |

#### 확인 — คำถามเช็กความเข้าใจ

- 간토야 씨는 운동하는 것을 좋아합니까? → 아니요, 보는 것을 좋아합니다. *(คันโตยะชอบออกกำลังกายไหม — ไม่ ชอบดู)*
- 윤아 씨는 스포츠 댄스가 어렵습니까? → 아니요, 전혀 어렵지 않습니다. *(ยุนาคิดว่าสปอร์ตแดนซ์ยากไหม — ไม่ ไม่ยากเลย)*

#### 활동 (หน้า 349) — 가 보고 싶은 나라

โจทย์ตามตำรา:

- 여러분은 가 보고 싶은 나라가 있어요? 그 나라에서 뭘 하고 싶어요? *(มีประเทศที่อยากลองไปไหม อยากทำอะไรที่นั่น)*
- 그 나라에서 온 친구가 있으면 아래와 같이 궁금한 것을 물어 봅시다. *(ถ้ามีเพื่อนจากประเทศนั้น ลองถามสิ่งที่สงสัยตามตัวอย่างด้านล่าง)*

กิจกรรมนี้ให้เล่าว่าอยากลองไปประเทศไหนและอยากทำอะไรที่นั่น ตำรามีตัวอย่างเรื่องมองโกเลีย:

- 저는 몽골에 가 보고 싶어요. *(ฉันอยากลองไปมองโกเลีย)*
- 몽골에서 말을 타 보고 싶어요. *(อยากลองขี่ม้าที่มองโกเลีย)*
- 그리고 몽골의 전통 집 게르에서 자 보고 싶어요. *(และอยากลองนอนในเกอร์ บ้านดั้งเดิมของมองโกเลีย)*
- 밤에는 별이 많은 하늘을 보고 싶어요. *(ตอนกลางคืนอยากดูท้องฟ้าที่ดาวเยอะ)*
- 몽골에 가면 어디에서 말을 탈 수 있어요? *(ถ้าไปมองโกเลียจะขี่ม้าได้ที่ไหน)*

### 📖 읽기 35-2 — 바트 씨의 취미와 꿈 (งานอดิเรกและความฝันของบัท)

บทอ่านเล่าเรื่อง 바트 ผู้มีงานอดิเรกหลายอย่าง คือถ่ายรูป เที่ยว และเขียนหนังสือ ตอนนี้เขากำลังเรียนงานถ่ายหนัง และมีความฝันมากจนกังวลใจ บทนี้ใช้ -는 것, -아/어 보고 싶다 และ 되고 싶다 หลายแห่ง จึงเหมาะกับการอ่านออกเสียงและการแต่งบทสนทนา

คำถามก่อนอ่านในตำรา (หน้า 350):

- 여러분은 무슨 취미가 있습니까? *(คุณมีงานอดิเรกอะไรบ้าง)*

> 바트 씨는 취미가 많습니다. *(บัทมีงานอดิเรกมาก)* 사진 찍는 것을 좋아해서 주말마다 밖으로 사진을 찍으러 나갑니다. *(เพราะชอบถ่ายรูป ทุกสุดสัปดาห์จึงออกไปข้างนอกเพื่อถ่ายรูป)* 또 여행하는 것도 좋아합니다. *(และชอบเดินทางท่องเที่ยวด้วย)* 방학이 되면 항상 친구들과 여행을 떠납니다. *(พอถึงปิดเทอมก็ออกเดินทางท่องเที่ยวกับเพื่อน ๆ เสมอ)*
>
> 바트 씨는 글을 쓰는 것도 좋아합니다. *(บัทชอบเขียนหนังสือด้วย)* 날마다 일기를 쓰고 친구나 부모님께 편지도 자주 씁니다. *(เขียนไดอารี่ทุกวัน และเขียนจดหมายถึงเพื่อนหรือพ่อแม่บ่อย ๆ)* 지난번 쓰기 대회 때 바트 씨는 재미있는 이야기를 써서 상을 받았습니다. *(ในการประกวดเขียนครั้งที่แล้ว บัทเขียนเรื่องสนุกจึงได้รางวัล)*
>
> 요즘 바트 씨는 영화를 찍는 일을 배우고 있습니다. *(ช่วงนี้บัทกำลังเรียนงานถ่ายทำภาพยนตร์)* 여러 사람을 만나는 것도 즐겁고 영화 일도 아주 재미있습니다. *(การได้พบคนหลายคนก็สนุก และงานหนังก็สนุกมาก)* 나중에 영화를 만들어 보고 싶습니다. *(ภายหลังอยากลองสร้างหนัง)*
>
> 바트 씨는 꿈이 많습니다. *(บัทมีความฝันมาก)* 사진작가도 되고 싶고 세계 여행도 하고 싶습니다. *(อยากเป็นช่างภาพ และอยากเที่ยวรอบโลกด้วย)* 또 유명한 소설가나 영화감독도 되고 싶습니다. *(และอยากเป็นนักเขียนนิยายหรือผู้กำกับหนังที่มีชื่อเสียงด้วย)* 그래서 바트 씨는 요즘 고민이 많습니다. *(เพราะอย่างนั้นช่วงนี้บัทจึงกังวลใจมาก)*

- 사진 **찍는** 것을 좋아해서 주말마다 밖으로 사진을 찍으러 나갑니다.

#### 라 — ทำบทอ่านเป็นบทสนทนา (ตัวอย่างตอบ)

ตำราเว้นช่องว่างให้เติมเอง ด้านล่างเป็นตัวอย่างตอบ

#### ท้ายบท — พูดอิสระ

### 🧪 ออกสอบอย่างไร

บทนี้ยังไม่มีข้อสอบจริง และไม่มี 매일시험 หรือเวิร์กบุ๊กของ 35과 ในคลัง ที่มีคือการคาดการณ์จากรูปแบบข้อสอบที่ผ่านมา

- คาดว่าออกใน **복습시험④ (30–37과 · 11/18)** และ **기말시험 (23–37과 · ศ. 11/20 · จ. 11/23)**
- รูปแบบที่น่าจะออก (ตาม 복습시험①②) มี 4 แบบ:
  - ผันตาราง V → V-는 것 และ V → V-아/어 보다
  - เติมประโยค "취미가 뭐예요?" ด้วย -는 것
  - ตอบ "~ 가 봤어요?" ทั้งแบบเคยและไม่เคย
  - 말하기: ถามงานอดิเรกและความฝัน (활동: 가 보고 싶은 나라)

> [!WARNING] ที่น่าจะพลาด (คาดจากข้อผิดเดิม — ยังไม่มีข้อสอบจริง)
> - ★ ราก ㄹ: 만들는 것 ✗ → 만드는 것 · 사는 것 (เคยพลาด 만들습니다 / 만들으세요 แบบเดียวกัน)
> - ★ ราก ㄷ/르 ก่อน -어 보다: 듣어 봤어요 ✗ → 들어 봤어요 · 부르어 ✗ → 불러
> - ★ ㅏ/ㅗ ต้องใช้ -아: 받어 / 살어 ✗ → 받아 / 살아 (เคยพลาด 살었어요)
> - ★ ㅈ/ㅊ และ ㅐ/ㅔ ในคำของบท: 좋아하다 · 춤추다 · 찍다 · 제주도
> - คำอื่นที่เสี่ยง: 게임 · 배우다 · 취미
> - คำอื่นที่เสี่ยง: 한복 · 칼국수
> - 에 vs 에서: 제주도**에** 가 봤어요 (จุดหมาย) · 한강**에서** 유람선을 타 봤어요 (สถานที่ทำกิจกรรม)
> - 안 가 봤어요 ✓ / 가 안 봤어요 ✗
> - 좋아 안 해요 ✗ → 안 좋아해요 / 좋아하지 않아요
> - ตอบ 취미가 뭐예요? ต้องตอบเป็นกริยา + -는 것 ไม่ใช่ตอบชื่อคนหรือสถานที่
> - เรื่องเลือกตอบ O/X ให้ยึดบทอ่านทีละประโยค (ข้อ 1 ผิดเพราะ "고향" ไม่ใช่ในบท)

- 36과 -(으)ㄴ/는데요 (ข้อ 61) ต่อด้วยรูป -는 เหมือนกัน (좋아하지 않는데요)
- 37과 -아/어/여 주세요 (ข้อ 63) ← เทียบ -아/어 보세요 "ลองดูนะ" กับ "ช่วย…ให้หน่อย"
- 37과 -(으)ㄹ 것이 (살 것이 많이 있었어요 = ข้อ 56)

> [!SUMMARY] สรุปท้ายบท
> - -는 것 = "การ…": รากกริยา (และคำคุณศัพท์ลงท้าย 있다/없다) + -는 것 ราก ㄹ ตัด ㄹ (사는 것 · 만드는 것) และ 것 เว้นวรรคแล้วตามด้วย 이/가 · 은/는 · 을/를
> - -아/어/여 보다 = "ลอง…ดู" และ "เคย…": ㅏ/ㅗ → -아 보다 · สระอื่น → -어 보다 · 하다 → 해 보다 โดย 가 봤어요 (เคยไป) ≠ 갔어요 (ไปแล้ว) ปฏิเสธ 안 가 봤어요
> - ราก ㄷ/르 ต้องเปลี่ยนก่อน -어 보다: 들어 보다 · 불러 보다 (ไม่ใช่ 듣어 · 부르어)
> - ต่อกับ -고 싶다 ได้ "อยากลอง…ดู" (가 보고 싶어요) และเล่าความฝันด้วย N이/가 되고 싶다
> - ข้อสอบ: ผัน -는 것 / -아/어 보다 · ตอบ 취미가 뭐예요? ด้วย -는 것 · ตอบ 가 봤어요? ทั้งเคยและไม่เคย · 말하기 เรื่องงานอดิเรกและความฝัน
