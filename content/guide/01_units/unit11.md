## 11과 · 저는 지금 숙제를 해요 (ตอนนี้ฉันทำการบ้าน)

> [!INTRO] บทนี้ว่าด้วยอะไร
> บทที่ 11 เป็นบทที่เริ่ม**พูดถึงสิ่งที่กำลังทำ** สถานการณ์ในบทคือเพื่อนถามกันว่า "อยู่ที่ไหน" และ "ตอนนี้ทำอะไรอยู่" ส่วนบทอ่านเล่าว่าเพื่อน ๆ ในงานวันเกิดของคุณทุยแต่ละคนทำอะไรอยู่ (ร้องเพลง เต้นรำ กินเค้ก ถ่ายรูป)
>
> ไวยากรณ์ใหม่มี 2 เรื่อง และต้องใช้คู่กันในแทบทุกประโยค:
>
> 1. **V-아/어/여요** (ข้อ 06) — รูปสุภาพไม่เป็นทางการของ**กริยา** ใช้ได้ทั้งบอกเล่าและถาม บท 7 เรียนรูปสุภาพกับคำนามมาแล้ว (N이에요/예요) บทนี้ขยายมาถึงกริยา โดยตัด 다 ออกแล้วเลือกต่อ 아요 / 어요 / 해요 ตามสระท้ายของราก
> 2. **N을/를** (ข้อ 07) — ตัวชี้**กรรม** (สิ่งที่ถูกกระทำ) วางหลังคำนามที่อยู่หน้ากริยา เช่น 책을 읽어요 ภาษาไทยไม่มีตัวชี้แบบนี้ จึงต้องฝึกให้ติดมือ
>
> จบบทแล้วจะผันกริยาได้ถูกทั้ง 4 กลุ่ม (กลุ่ม ㅏ/ㅗ, กลุ่มสระอื่น, กลุ่ม 하다 และกลุ่ม ㅡ) และแต่งประโยค "ใคร + สิ่งที่ถูกกระทำ + ทำอะไร" เพื่อถามและตอบว่าตอนนี้ทำอะไรอยู่ได้
>
> จุดที่คนไทยงงบ่อย: ลืมว่ารากที่ลงท้ายด้วย ㅏ/ㅗ ต้องต่อ 아요 (✗ 받어요) สะกดกริยาที่ควบสระไม่ถูก (줘요 · 춰요 · 마셔요) และเลือกกริยาไม่เข้ากับกรรม (✗ 학생을 공부해요)

### 📝 ไวยากรณ์: V-아/어/여요 — รูปสุภาพไม่เป็นทางการ (ไวยากรณ์ข้อ 06)

ตอนนี้ว่าด้วยรูปสุภาพไม่เป็นทางการของกริยา ใช้ได้ทั้งบอกเล่าและถาม วิธีผันมี 3 ขั้น: ตัด 다 ออกจากรูปพจนานุกรม ดูสระของพยางค์สุดท้ายของราก แล้วต่อ 아요 / 어요 / 해요 ให้ถูกกลุ่ม กลุ่มที่เป็น ㅡ มีขั้นเพิ่มเล็กน้อย และเมื่อสระชนกันจะควบเป็นพยางค์เดียว เช่น 보다 → 봐요

#### รูปแบบ

| สระท้ายราก | ต่อท้าย | ตัวอย่าง |
|:---|:---|:---|
| ㅏ · ㅗ | -아요 | 가다 → 가요 |
| สระอื่นทั้งหมด | -어요 | 먹다 → 먹어요 |
| ...하다 | 해요 | 공부하다 → 공부해요 |
| ㅡ | ตัด ㅡ ก่อน แล้วดูสระพยางค์หน้า (ไม่มีพยางค์หน้า → 어요) | 쓰다 → 써요 |

#### แสดงวิธีทำ: -아/어/여요 (ย่อ · ตารางเต็มในไวยากรณ์ข้อ 06)

กฎ 1 สระท้ายราก ㅏ ㅗ ต่อ 아요 กฎ 2 สระอื่นต่อ 어요 กฎ 3 …하다 ได้ 해요 กฎ 4 รากลงท้าย ㅡ ให้ตัด ㅡ ก่อนแล้วใช้กฎ 1 หรือ 2 และสุดท้ายถ้ารากไม่มีตัวสะกดต้องควบสระ ตารางนี้แสดงทุกขั้นกับคำของตำราบท 11 คำละหนึ่งกลุ่ม

| ราก + คำต่อ | ① ตัด ㅡ? | ② ดูสระ → เลือก | ③ ผล (ควบสระ) |
|:---|:---|:---|:---|
| 받 + 아/어요 | ไม่มี ㅡ | ㅏ → 아 | **받아요** (มีตัวสะกด ไม่ควบ) |
| 가 + 아/어요 | ไม่มี ㅡ | ㅏ → 아 | **가요** (아 ยุบเข้า ㅏ) |
| 보 + 아/어요 | ไม่มี ㅡ | ㅗ → 아 | **봐요** (ㅗ + ㅏ = ㅘ) |
| 먹 + 아/어요 | ไม่มี ㅡ | ㅓ → 어 | **먹어요** (มีตัวสะกด ไม่ควบ) |
| 마시 + 아/어요 | ไม่มี ㅡ | ㅣ → 어 | **마셔요** (ㅣ + ㅓ = ㅕ) |
| 공부하 + 아/어요 | ไม่มี ㅡ | …하 → 여 | **공부해요** (하 + 여 = 해) |
| 쓰 + 아/어요 | ตัด → ㅆ | ไม่มีพยางค์หน้า → 어 | **써요** (ㅆ + ㅓ = 써) |
| 아프 + 아/어요 | ตัด → 아ㅍ | พยางค์หน้า 아 → 아 | **아파요** (ㅍ + ㅏ = 파) |

#### กลุ่ม ㅏ · ㅗ → -아요

ถ้าพยางค์สุดท้ายของรากมีสระ ㅏ หรือ ㅗ ให้ต่อ -아요 (ตัวสะกดไม่มีผล) ถ้ารากลงท้ายด้วย ㅏ อยู่แล้ว 아 จะยุบรวมกับสระเดิมจนเหลือตัวเดียว ส่วน ㅗ + ㅏ จะควบเป็น ㅘ

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 가다 → **가요** | ไป | 가 + 아 ยุบเหลือ 가 |
| 만나다 → **만나요** | พบ | 나 + 아 ยุบเหลือ 나 |
| 앉다 → **앉아요** | นั่ง | ㅏ มีตัวสะกด → ต่อ 아요 |
| 받다 → **받아요** | รับ | ㅏ มีตัวสะกด → ต่อ 아요 (✗ 받어요) |
| 팔다 → **팔아요** | ขาย | ㅏ มีตัวสะกด → ต่อ 아요 |
| 보다 → **봐요** | ดู | ㅗ + ㅏ = ㅘ |
| 오다 → **와요** | มา | ㅗ + ㅏ = ㅘ |

#### กลุ่มสระอื่น → -어요

รากที่มีสระอื่นนอกจาก ㅏ/ㅗ ทั้งหมดต่อ -어요 ถ้าสระท้ายของรากเป็น ㅣ หรือ ㅜ จะควบกับ 어 เป็นพยางค์เดียว (ㅣ+ㅓ=ㅕ · ㅜ+ㅓ=ㅝ)

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 먹다 → **먹어요** | กิน | ต่อ 어요 ตรง ๆ |
| 읽다 → **읽어요** | อ่าน | ต่อ 어요 ตรง ๆ |
| 씻다 → **씻어요** | ล้าง | ต่อ 어요 ตรง ๆ |
| 마시다 → **마셔요** | ดื่ม | ㅣ + ㅓ = ㅕ |
| 가르치다 → **가르쳐요** | สอน | ㅣ + ㅓ = ㅕ |
| 기다리다 → **기다려요** | รอ | ㅣ + ㅓ = ㅕ |
| 주다 → **줘요** | ให้ | ㅜ + ㅓ = ㅝ |
| 배우다 → **배워요** | เรียน | ㅜ + ㅓ = ㅝ |
| 춤추다 → **춤춰요** | เต้นรำ | ㅜ + ㅓ = ㅝ |

#### กลุ่ม ...하다 → 해요

คำที่ลงท้ายด้วย 하다 ผันเป็น 해요 ทุกคำ

| 한국어 | ไทย |
|:---|:---|
| 공부하다 → **공부해요** | เรียน |
| 일하다 → **일해요** | ทำงาน |
| 이야기하다 → **이야기해요** | คุย |
| 운동하다 → **운동해요** | ออกกำลังกาย |

#### กลุ่ม ㅡ → ตัด ㅡ ก่อน

รากที่ลงท้ายด้วย ㅡ ให้ตัด ㅡ ออกก่อน แล้วดูสระของพยางค์ที่อยู่หน้ามัน ถ้าเป็น ㅏ/ㅗ ต่อ 아요 นอกนั้นต่อ 어요 และถ้าไม่มีพยางค์หน้าเลยให้ใช้ 어요

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 쓰다 → **써요** | เขียน | ไม่มีพยางค์หน้า → 어요 |
| 끄다 → **꺼요** | ปิด | ไม่มีพยางค์หน้า → 어요 |
| 아프다 → **아파요** | เจ็บ | พยางค์หน้า 아 เป็น ㅏ → 아요 |

#### ตัวอย่างในกรอบตำรา (หน้า 96)

ตำราเปิดข้อ 준비 1 ด้วยบทสนทนาสั้น ๆ ที่ใช้รูปนี้ แล้วสรุปกฎไว้ในกรอบพร้อมสูตรผัน 10 สูตร สูตรที่มี ※ คือกลุ่ม ㅡ ที่ต้องตัด ㅡ ก่อนต่อ 어요

- 아이가 자요? *(เด็กนอนหลับอยู่หรือ)*
- 네, 아이가 자요. *(ใช่ เด็กนอนหลับอยู่)*

| สูตรในกรอบ | ผลที่ได้ | ความหมาย |
|:---|:---|:---|
| 가 + 아요 | 가요 | ไป |
| 마시 + 어요 | 마셔요 | ดื่ม |
| 읽 + 어요 | 읽어요 | อ่าน |
| 좋 + 아요 | 좋아요 | ดี |
| ※ 크 + 어요 | 커요 | ใหญ่ |
| 보 + 아요 | 보아요 → 봐요 | ดู |
| 먹 + 어요 | 먹어요 | กิน |
| 하 + 여요 | 하여요 → 해요 | ทำ |
| 많 + 아요 | 많아요 | มาก |
| ※ 예쁘 + 어요 | 예뻐요 | สวย |

#### 연습 1 (หน้า 96) — ดูภาพแล้วผันกริยา

ตำราให้ดูภาพ 6 ภาพ แล้วพูดตามตัวอย่าง "만나요." โดยผันกริยาที่พิมพ์กำกับภาพเป็นรูป -아/어/여요 ตำราไม่พิมพ์เฉลย คำตอบด้านล่างผันตามกฎของข้อนี้ (ตัวอย่างตอบ)

| ข้อ | กริยากำกับภาพ | ตัวอย่างตอบ | ความหมาย · ภาพ |
|:---|:---|:---|:---|
| 1 | 만나다 | 만나요. | พบกัน — 🖼️ หญิงสองคนเดินมาพบกัน (ตัวอย่างตำรา) |
| 2 | 오다 | 와요. | มา — 🖼️ ชายโบกมือเดินเข้ามาหาชายที่นั่งอยู่ |
| 3 | 먹다 | 먹어요. | กิน — 🖼️ ชายเดินพลางกินขนมปัง |
| 4 | 읽다 | 읽어요. | อ่าน — 🖼️ หญิงนั่งอ่านหนังสือ |
| 5 | 마시다 | 마셔요. | ดื่ม — 🖼️ ชายยกแก้วขึ้นดื่ม |
| 6 | 일하다 | 일해요. | ทำงาน — 🖼️ ชายผูกเน็คไทนั่งทำงานที่คอมพิวเตอร์ |

#### 연습 2 (หน้า 97) — ถาม-ตอบว่าใครทำอะไร

ตำราให้ดูภาพอาคารที่มีหน้าต่าง 6 บาน (🖼️ แต่ละบานมีคนทำกิจกรรมหนึ่งอย่าง) แล้วถาม-ตอบตามตัวอย่าง "알렉세이 씨가 무엇을 해요? → 노래해요." โดยมีคู่ชื่อกับกริยาให้ 6 คู่ คำตอบคือรูป -아/어/여요 ของกริยานั้น

| ข้อ | คำถาม (ชื่อ – กริยา) | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 알렉세이 씨가 무엇을 해요? (알렉세이 – 노래하다) | 노래해요. | คุณอเล็กเซย์ทำอะไร — ร้องเพลง (ตัวอย่างตำรา) |
| 2 | 왕쯔이 씨가 무엇을 해요? (왕쯔이 – 씻다) | 씻어요. | คุณหวางจื่ออีทำอะไร — ล้าง |
| 3 | 카오루 씨가 무엇을 해요? (카오루 – 마시다) | 마셔요. | คุณคาโอรุทำอะไร — ดื่ม |
| 4 | 마키 씨가 무엇을 해요? (마키 – 쉬다) | 쉬어요. | คุณมากิทำอะไร — พัก |
| 5 | 압둘라 씨가 무엇을 해요? (압둘라 – 먹다) | 먹어요. | คุณอับดุลลาห์ทำอะไร — กิน |
| 6 | 투이 씨가 무엇을 해요? (투이 – 공부하다) | 공부해요. | คุณทุยทำอะไร — เรียน |

#### 연습 3 (หน้า 97) — ถามด้วยประโยคใช่-ไม่ใช่แล้วแก้คำตอบ

ข้อนี้ใช้ภาพและคู่ชื่อ–กริยาเดียวกับ 연습 2 แต่ตำราตั้งคำถามใช่-ไม่ใช่ที่ใส่กริยาผิดไว้ ผู้ตอบต้องปฏิเสธด้วย 아니요 แล้วบอกกริยาที่ถูก ตำราไม่พิมพ์เฉลย คำตอบด้านล่างหาจากคู่ชื่อ–กริยาของ 연습 2 (ตัวอย่างตอบ)

| ข้อ | คำถาม | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 알렉세이 씨가 쉬어요? | 아니요, 노래해요. | คุณอเล็กเซย์พักหรือ — ไม่ ร้องเพลง (ตัวอย่างตำรา) |
| 2 | 왕쯔이 씨가 마셔요? | 아니요, 씻어요. | คุณหวางจื่ออีดื่มหรือ — ไม่ ล้าง |
| 3 | 카오루 씨가 노래해요? | 아니요, 마셔요. | คุณคาโอรุร้องเพลงหรือ — ไม่ ดื่ม |
| 4 | 마키 씨가 공부해요? | 아니요, 쉬어요. | คุณมากิเรียนหรือ — ไม่ พัก |
| 5 | 압둘라 씨가 씻어요? | 아니요, 먹어요. | คุณอับดุลลาห์ล้างหรือ — ไม่ กิน |
| 6 | 투이 씨가 먹어요? | 아니요, 공부해요. | คุณทุยกินหรือ — ไม่ เรียน |

#### 📽️ จากสไลด์อาจารย์

ครูสรุปกฎการผันไว้บนกระดานเป็น "4 Rules" แล้วเพิ่มกฎข้อที่ 5 เรื่องการควบสระ (โน้ตจากกระดาน)

- ① ㅏ/ㅗ + 아요
- ② ถ้าไม่ใช่ ㅏ/ㅗ + 어요
- ③ ...하다 → ...해요
- ④ มี ㅡ ให้ตัดก่อนแล้วใช้ข้อ ①②
- ข้อ 5 (เพิ่มจาก 4 Rules): กฎควบสระ ㅗ+ㅏ=ㅘ · ㅣ+ㅓ=ㅕ

### 📝 ไวยากรณ์: N을/를 — ชี้กรรม (ไวยากรณ์ข้อ 07)

ตอนนี้ว่าด้วยตัวชี้**กรรม** (สิ่งที่ถูกกระทำ) ภาษาไทยไม่มีตัวชี้แบบนี้ แต่ภาษาเกาหลีต้องเติม 을/를 ท้ายคำนามที่เป็นกรรมก่อนกริยา เช่น 책을 읽어요 ประโยคเต็มจึงเรียงเป็น **ประธาน 이/가 + กรรม 을/를 + กริยา** โดย 이/가 มาจากบท 6

#### รูปแบบ

| ท้ายคำนาม | ใช้ | ตัวอย่าง |
|:---|:---|:---|
| มีตัวสะกด (받침) | **을** | 책을 · 밥을 · 물을 |
| ไม่มีตัวสะกด | **를** | 영화를 · 친구를 · 커피를 |
| ตัวสะกด ㅇ (นับเป็น 받침) | **을** | 책상을 · 가방을 · 안경을 |
| N하다 (คำนาม + 하다) | 을/를 ตามกฎเดียวกัน | 숙제를 · 운동을 · 청소를 |

#### แสดงวิธีทำ: N + 을/를 (ย่อ · ตารางเต็มในไวยากรณ์ข้อ 07)

กฎ 1 ดูตัวสะกดของพยางค์สุดท้ายของคำนามที่เป็นกรรม ถ้ามี (ㄹ และ ㅇ ก็นับ) ใช้ 을 กฎ 2 ถ้าไม่มีใช้ 를 และ N + 하다 ก็ใช้กฎเดียวกันแล้วตามด้วย 해요 ตารางนี้แสดงทุกขั้นกับคำของตำราบท 11

| นาม + กริยา | ① ตัวสะกด | ② เลือก | ③ ผล |
|:---|:---|:---|:---|
| 책 + 읽어요 | มี (ㄱ) | 을 | **책을 읽어요** |
| 물 + 마셔요 | มี (ㄹ) | 을 | **물을 마셔요** |
| 영화 + 봐요 | ไม่มี | 를 | **영화를 봐요** |
| 친구 + 만나요 | ไม่มี | 를 | **친구를 만나요** |
| 숙제 + 해요 | ไม่มี | 를 | **숙제를 해요** |
| 운동 + 해요 | มี (ㅇ) | 을 | **운동을 해요** |

#### ตัวอย่างประโยค

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 책을 읽어요. | อ่านหนังสือ | 책 มีตัวสะกด → 을 |
| 밥을 먹어요. | กินข้าว | 밥 มีตัวสะกด → 을 |
| 물을 마셔요. | ดื่มน้ำ | 물 มีตัวสะกด → 을 |
| 영화를 봐요. | ดูหนัง | 영화 ไม่มีตัวสะกด → 를 |
| 친구를 만나요. | พบเพื่อน | 친구 ไม่มีตัวสะกด → 를 |
| 커피를 마셔요. | ดื่มกาแฟ | 커피 ไม่มีตัวสะกด → 를 |
| 숙제를 해요. | ทำการบ้าน | N하다 ก็ติด 을/를 |
| 운동을 해요. | ออกกำลังกาย | N하다 ก็ติด 을/를 |
| 청소를 해요. | ทำความสะอาด | N하다 ก็ติด 을/를 |

#### ประโยคเต็ม — ประธาน이/가 + กรรม을/를 + กริยา

| 한국어 | ไทย |
|:---|:---|
| 친구가 신문을 봐요. | เพื่อนอ่านหนังสือพิมพ์ |
| 동생이 사과를 먹어요. | น้องกินแอปเปิล |
| 학생이 책을 읽어요. | นักเรียนอ่านหนังสือ |

#### ถาม-ตอบ

คำถามใช่-ไม่ใช่ใช้รูปเดียวกับประโยคบอกเล่า เพียงยกเสียงขึ้นท้ายประโยค ส่วนคำตอบที่ปฏิเสธมักบอกต่อว่าจริง ๆ แล้วทำอะไร

| คำถาม | คำตอบ | ความหมาย |
|:---|:---|:---|
| 무엇을 해요? | 텔레비전을 봐요. | ทำอะไร — ดูทีวี |
| 누가 노래를 해요? | 마키 씨가 노래를 해요. | ใครร้องเพลง — คุณมากิ |
| 알렉세이 씨가 쉬어요? | 아니요, 노래해요. | คุณอเล็กเซย์พักหรือ — ไม่ ร้องเพลง |
| 마키 씨가 이메일을 써요? | 아니요, 책을 읽어요. | คุณมากิเขียนอีเมลหรือ — ไม่ อ่านหนังสือ |

#### 연습 1 (หน้า 98) — พูดตามตัวอย่าง N을/를 + กริยา

ข้อ 준비 2 เปิดด้วยบทสนทนา "무엇을 해요? → 빵을 먹어요." *(ทำอะไรอยู่ → กินขนมปัง)* แล้วให้ฝึกพูดจากคำใบ้ "คำนาม / กริยา" 6 ข้อ ตามตัวอย่าง "영화를 봐요." เติม 을/를 หลังคำนามตามตัวสะกด แล้วผันกริยาเป็น -아/어/여요 ตำราไม่พิมพ์เฉลย คำตอบด้านล่างทำตามกฎของข้อนี้ (ตัวอย่างตอบ)

| ข้อ | คำใบ้ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 영화 / 보다 | 영화를 봐요. | ดูหนัง (ตัวอย่างตำรา) |
| 2 | 청소 / 하다 | 청소를 해요. | ทำความสะอาด |
| 3 | 물 / 마시다 | 물을 마셔요. | ดื่มน้ำ |
| 4 | 옷 / 입다 | 옷을 입어요. | ใส่เสื้อผ้า |
| 5 | 손 / 씻다 | 손을 씻어요. | ล้างมือ |
| 6 | 책 / 읽다 | 책을 읽어요. | อ่านหนังสือ |

#### 연습 2 (หน้า 99) — ดูภาพแล้วถาม-ตอบ 무엇을 해요?

ตำราให้ดูภาพ 6 ภาพ แล้วถาม-ตอบตามตัวอย่าง "가: 무엇을 해요? 나: 물을 마셔요." คำใบ้พิมพ์ไว้ใต้เลขข้อแล้ว (ตัวอย่างตอบ)

| ข้อ | คำใบ้ | ตัวอย่างตอบ | ความหมาย · ภาพ |
|:---|:---|:---|:---|
| 1 | 물 / 마시다 | 물을 마셔요. | ดื่มน้ำ — 🖼️ ชายยกแก้วดื่ม (ตัวอย่างตำรา) |
| 2 | 청소 / 하다 | 청소를 해요. | ทำความสะอาด — 🖼️ ชายก้มดูดฝุ่น |
| 3 | 친구 / 만나다 | 친구를 만나요. | พบเพื่อน — 🖼️ หญิงสองคนเดินมาพบกัน |
| 4 | 신문 / 읽다 | 신문을 읽어요. | อ่านหนังสือพิมพ์ — 🖼️ ชายนั่งอ่านหนังสือพิมพ์ |
| 5 | 손 / 씻다 | 손을 씻어요. | ล้างมือ — 🖼️ หญิงล้างมือที่อ่างล้างหน้า |
| 6 | 운동 / 하다 | 운동을 해요. | ออกกำลังกาย — 🖼️ หญิงยกดัมเบล |

#### 연습 3 (หน้า 99) — ถามเพื่อนแล้วปฏิเสธกิจกรรมแรก

ตำราให้ 8 คน คนละ 2 กิจกรรม และภาพบอกว่าแต่ละคนทำกิจกรรมที่สอง ผู้ถามเดาด้วยกิจกรรมแรก ผู้ตอบปฏิเสธด้วย 아니요 แล้วบอกกิจกรรมที่อยู่ในภาพ ตามตัวอย่าง "마키 씨가 이메일을 써요? → 아니요, 책을 읽어요." ตำราไม่พิมพ์เฉลย แถว 2–8 เป็นตัวอย่างตอบที่ทำตามรูปแบบเดียวกัน

| ข้อ | คำถาม | ตัวอย่างตอบ | ความหมาย · ภาพ |
|:---|:---|:---|:---|
| 1 | 마키 씨가 이메일을 써요? | 아니요, 책을 읽어요. | ไม่ อ่านหนังสือ — 🖼️ หญิงนั่งอ่านหนังสือ (ตัวอย่างตำรา) |
| 2 | 용재 씨가 노래를 해요? | 아니요, 춤을 춰요. | ไม่ เต้นรำ — 🖼️ ชายเต้นท่ากลับหัว |
| 3 | 바트 씨가 이야기를 해요? | 아니요, 요리를 해요. | ไม่ ทำอาหาร — 🖼️ ชายทอดไข่ในกระทะ |
| 4 | 왕쯔이 씨가 샤워를 해요? | 아니요, 손을 씻어요. | ไม่ ล้างมือ — 🖼️ หญิงล้างมือที่อ่าง |
| 5 | 카오루 씨가 숙제를 해요? | 아니요, 전화를 해요. | ไม่ โทรศัพท์ — 🖼️ ชายสวมสูทคุยโทรศัพท์ |
| 6 | 제프리 씨가 운동을 해요? | 아니요, 샤워를 해요. | ไม่ อาบน้ำ — 🖼️ ชายอาบน้ำใต้ฝักบัว |
| 7 | 알렉세이 씨가 빨래를 해요? | 아니요, 청소를 해요. | ไม่ ทำความสะอาด — 🖼️ ชายดูดฝุ่น |
| 8 | 이리나 씨가 영화를 봐요? | 아니요, 친구를 기다려요. | ไม่ รอเพื่อน — 🖼️ หญิงยืนมีฟองความคิดเป็นภาพเพื่อน |

#### 📽️ จากสไลด์อาจารย์

สไลด์ 문법 1 ให้โครงประโยค "___이/가 ___을/를 ___아/어/여요" แล้วถาม-ตอบ 3 คู่

- 친구가 무엇을 해요? → 빵을 먹어요. *(เพื่อนทำอะไร → กินขนมปัง)*
- 선생님이 무엇을 해요? → 텔레비전을 봐요. *(ครูทำอะไร → ดูทีวี)*
- 왕쯔이 씨가 무엇을 해요? → 친구를 만나요. *(คุณหวางจื่ออีทำอะไร → พบเพื่อน)*

#### ใบฝึก C — เติม 을/를 หลังของใช้ 15 ชิ้น

ใบฝึก 연습지 11 ส่วน C ให้เติม 을/를 หลังคำนามของใช้ 15 ชิ้น ตัวอย่าง 8 ชิ้นจากใบฝึกอยู่ในตารางนี้ สังเกตว่าตัวสะกด ㅇ ก็นับเป็น 받침

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 책상**을** | {n:โต๊ะเรียน} | ลงท้าย ㅇ → 을 |
| 가방**을** | กระเป๋า | ลงท้าย ㅇ → 을 |
| 텔레비전**을** | ทีวี | ลงท้าย ㄴ → 을 |
| 안경**을** | แว่นตา | ลงท้าย ㅇ → 을 |
| 카메라**를** | กล้อง | ไม่มีตัวสะกด → 를 |
| 컴퓨터**를** | คอมพิวเตอร์ | ไม่มีตัวสะกด → 를 |
| 지도**를** | แผนที่ | ไม่มีตัวสะกด → 를 |
| 휴대 전화**를** | มือถือ | ไม่มีตัวสะกด → 를 |

#### คู่คำบังคับ (ไวยากรณ์ข้อ 14)

กรรมบางตัวต้องจับคู่กับกริยาตายตัว ห้ามใช้ 하다 แทนกริยาคู่ของมัน

- 춤을 추다 *(เต้นรำ — ✗ 춤을 하다)*
- 사진을 찍다 *(ถ่ายรูป)*
- 노래를 하다 *(ร้องเพลง)*

#### ⚠️ ระวัง

- 학생을 공부해요 ✗ → **숙제를 해요** (กรรมต้องเข้ากับกริยา)
- 반나요 ✗ → **만나요** (ขึ้นต้นด้วย ㅁ)
- 지금 · 매일 ไม่ใส่ 에 (กฎเต็ม → 13과, ไวยากรณ์ข้อ 10):
  - 지금 숙제를 해요. *(ตอนนี้ทำการบ้าน)*
  - 매일 한국 음식을 먹어요. *(กินอาหารเกาหลีทุกวัน)*

### 💬 대화 11-1 — ถามว่าอยู่ที่ไหนและทำอะไรอยู่

왕쯔이 ถามบาตว่าอยู่ที่ไหน บาตตอบว่าอยู่บ้านและกำลังดูทีวี แล้วถามกลับว่า 왕쯔이 ทำอะไรอยู่ ซึ่งตอบว่ากำลังทำการบ้าน บทสนทนาสั้น ๆ นี้ใช้ทั้ง N이에요 (집이에요) จากบท 7 และโครงใหม่ N을/를 + กริยา-아/어/여요

> 왕쯔이: 바트 씨, 어디예요? *({n:คุณบาต} {e:อยู่}{q:ที่ไหน})*
>
> 바트: 집이에요. *({e:อยู่}{n:บ้าน})*
>
> 왕쯔이: 무엇을 해요? *({v:ทำ}{q:อะไร}{e:อยู่})*
>
> 바트: 텔레비전을 봐요. 왕쯔이 씨는 무엇을 해요? *({v:ดู}{n:โทรทัศน์} แล้ว{n:คุณหวางจื่ออี}{v:ทำ}{q:อะไร})*
>
> 왕쯔이: 저는 지금 숙제를 해요. *(ตอนนี้ฉันทำการบ้าน)*

#### สังเกตจากบทสนทนา

- 어디예요? → 집이에요 — ถามที่อยู่ด้วย 어디 ตอบด้วย N이에요 (บท 7)
- 무엇을 해요? → 텔레비전을 봐요 — ถามว่าทำอะไร ตอบด้วย N을/를 + กริยา-아/어/여요
- 왕쯔이 씨는 무엇을 해요? — ถามกลับด้วยโครงเดิม เปลี่ยนเฉพาะประธาน
- 저는 지금 숙제를 해요 — 지금 ไม่ใส่ 에 และ 숙제 (N하다) ก็ติด 를

#### 확인해 봅시다 (หน้า 100)

ตำราถามเช็กความเข้าใจ 2 ข้อหลังบทสนทนา ตอบด้วยประโยคจากบทสนทนาได้เลย

| คำถาม | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|
| 바트 씨가 무엇을 해요? | 텔레비전을 봐요. | คุณบาตทำอะไร — ดูทีวี |
| 왕쯔이 씨가 무엇을 해요? | 숙제를 해요. | คุณหวางจื่ออีทำอะไร — ทำการบ้าน |

#### ฝึกสลับ (ตำราหน้า 100 · 어디예요? → 무엇을 해요?)

เปลี่ยนสถานที่ในประโยค 어디예요? และเปลี่ยนกิจกรรมในประโยค 무엇을 해요? ตามตาราง แล้วพูดบทสนทนาเดิม

| สถานที่ | กิจกรรมที่ 1 | กิจกรรมที่ 2 |
|:---|:---|:---|
| 집 *(บ้าน)* | 텔레비전을 보다 *(ดูทีวี)* | 밥을 먹다 *(กินข้าว)* |
| 친구 집 *(บ้านเพื่อน)* | 영화를 보다 *(ดูหนัง)* | 책을 읽다 *(อ่านหนังสือ)* |
| 교실 *(ห้องเรียน)* | 숙제를 하다 *(ทำการบ้าน)* | 빨래를 하다 *(ซักผ้า)* |
| 명동 *(เมียงดง)* | 쇼핑을 하다 *(ช้อปปิ้ง)* | 청소를 하다 *(ทำความสะอาด)* |
| 학교 *(โรงเรียน)* | 친구를 만나다 *(พบเพื่อน)* | 요리를 하다 *(ทำอาหาร)* |

#### 활동 (หน้า 101) — ถามเพื่อนว่าทุกวันทำอะไร

กิจกรรมให้ถามเพื่อนทีละคนว่า "매일 ... 해요?" แล้วใส่ ○ หรือ × ลงในตารางตามที่เพื่อนตอบ ตำรามีตัวอย่าง 2 แบบ คือตอบรับ (네, 매일 …) และปฏิเสธแล้วบอกสิ่งที่ทำจริง (아니요, 매일 …)

- 가: 마키 씨, 매일 한국 음식을 먹어요? *(คุณมากิ กินอาหารเกาหลีทุกวันไหม)*
- 나: 네, 매일 한국 음식을 먹어요. *(ใช่ กินอาหารเกาหลีทุกวัน)*
- 가: 마키 씨, 매일 숙제를 해요? *(คุณมากิ ทำการบ้านทุกวันไหม)*
- 나: 아니요, 매일 텔레비전을 봐요. *(ไม่ ดูทีวีทุกวัน)*

ตารางมีช่องให้เขียนชื่อเพื่อน 5 คน ช่องแรกตำรากรอกตัวอย่างของ 마키 ไว้แล้ว (한국 음식 ○ · 숙제 ×) ส่วนที่เหลือเว้นว่างให้เติมเอง คำใบ้ 7 ข้อและคำถามที่ทำตามแบบ (ตัวอย่างคำถาม) มีดังนี้

| คำใบ้ในตาราง | ตัวอย่างคำถาม | ความหมาย |
|:---|:---|:---|
| 한국 음식 / 먹다 | 매일 한국 음식을 먹어요? | กินอาหารเกาหลีทุกวันไหม (마키 ○) |
| 숙제 / 하다 | 매일 숙제를 해요? | ทำการบ้านทุกวันไหม (마키 ×) |
| 텔레비전 / 보다 | 매일 텔레비전을 봐요? | ดูทีวีทุกวันไหม |
| 컴퓨터 / 하다 | 매일 컴퓨터를 해요? | เล่นคอมพิวเตอร์ทุกวันไหม |
| 커피 / 마시다 | 매일 커피를 마셔요? | ดื่มกาแฟทุกวันไหม |
| 친구 / 만나다 | 매일 친구를 만나요? | พบเพื่อนทุกวันไหม |
| 한국어 / 공부하다 | 매일 한국어를 공부해요? | เรียนภาษาเกาหลีทุกวันไหม |

### 📖 읽기 11-2 — งานวันเกิดคุณทุย

บทอ่านบรรยายงานวันเกิดของคุณทุย เพื่อนแต่ละคนทำกิจกรรมต่างกัน ประโยคส่วนใหญ่ใช้โครง "ชื่อ + 씨는 + N을/를 + กริยา" ซึ่งเป็นการฝึกไวยากรณ์ทั้งสองข้อของบทโดยตรง

ก่อนอ่าน ตำราถามให้คิดถึงปาร์ตี้วันเกิดเพื่อน (หน้า 102):

- 친구 생일 파티예요. 여러분은 친구 생일 파티 때 보통 무엇을 해요? *(นี่คือปาร์ตี้วันเกิดเพื่อน ปกติเวลาไปปาร์ตี้วันเกิดเพื่อน พวกคุณทำอะไรกัน)*

> 오늘은 투이 씨 생일이에요. *(วันนี้เป็นวันเกิดคุณทุย)* 친구들이 투이 씨 생일을 축하해요. *(เพื่อน ๆ แสดงความยินดีกับวันเกิดคุณทุย)*
>
> 마키 씨는 노래를 해요. *(คุณมากิร้องเพลง)* 알렉세이 씨는 춤을 춰요. *({n:คุณอเล็กเซย์}{v:เต้นรำ})*
>
> 제프리 씨는 케이크를 먹어요. *(คุณเจฟฟรีย์กินเค้ก)* 압둘라 씨는 주스를 마셔요. *(คุณอับดุลลาห์ดื่มน้ำผลไม้)*
>
> 카오루 씨는 사진을 찍어요. *(คุณคาโอรุถ่ายรูป)* 파티가 재미있어요. *(ปาร์ตี้สนุก)*

#### 가 — ใครทำอะไร (เลือกเลขจากภาพ)

ข้อ 가 ให้อ่านบทอ่านแล้วเลือกเลข 1–6 ในภาพมาใส่วงเล็บหลังชื่อแต่ละคน เฉลยจากภาคผนวก (ภาพอธิบายในคอลัมน์ขวา)

- 누가 무엇을 해요? 윗글을 읽고 다음 그림에서 번호를 골라 쓰세요. *(ใครทำอะไร อ่านบทข้างบนแล้วเลือกเลขจากภาพต่อไปนี้มาเขียน)*

| ข้อ | ชื่อ | เลขในภาพ | ทำอะไร · ภาพ |
|:---|:---|:---|:---|
| (1) | 투이 | 4 | เจ้าของวันเกิด — 🖼️ คนใส่หมวกปาร์ตี้กลางภาพ ข้างกล่องของขวัญ |
| (2) | 마키 | 1 | 노래를 해요 — 🖼️ คนถือไมโครโฟน |
| (3) | 알렉세이 | 2 | 춤을 춰요 — 🖼️ คนยกแขนเต้นใต้ป้าย Happy Birthday |
| (4) | 제프리 | 5 | 케이크를 먹어요 — 🖼️ คนถือจานเค้ก |
| (5) | 압둘라 | 3 | 주스를 마셔요 — 🖼️ คนถือแก้วที่มีหลอด |
| (6) | 카오루 | 6 | 사진을 찍어요 — 🖼️ คนถือกล้อง |

#### 나 — คำถามท้ายบทอ่าน (O/X ในตำรา)

| ข้อความ | ความหมาย | ตอบ |
|:---|:---|:---|
| 오늘 투이 씨 생일 파티가 있어요. | วันนี้มีปาร์ตี้วันเกิดคุณทุย | **○** |
| 압둘라 씨가 케이크를 먹어요. | คุณอับดุลลาห์กินเค้ก | **×** กินเค้กคือ 제프리 |
| 카오루 씨가 사진을 찍어요. | คุณคาโอรุถ่ายรูป | **○** |

#### 다 — ฟังแล้วอ่านตาม (ขีดเส้นใต้เพื่อเน้น)

ข้อ 다 ให้ฟังแทร็ก 11-3 แล้วอ่านตามออกเสียง โดยตั้งใจกับส่วนที่ตำราขีดเส้นใต้ไว้ (ตัวหนาด้านล่าง) ทั้ง 3 ประโยคมาจากบทอ่าน

- 친구들이 투이 씨 **생일을 축하해요**. *(เพื่อน ๆ แสดงความยินดีกับวันเกิดคุณทุย)*
- 알렉세이 씨는 **춤을 춰요**. *(คุณอเล็กเซย์เต้นรำ)*
- 파티가 **재미있어요**. *(ปาร์ตี้สนุก)*

#### 라 — แปลงบทอ่านเป็นบทสนทนาโทรศัพท์ 투이 ↔ 지훈

ตำราข้อ 라 ให้แปลงบทอ่านเป็นบทสนทนาโทรศัพท์ระหว่างคุณทุยกับคุณจีฮุน รูปแบบเดียวกับข้อสอบ 읽기 แบบ 가/나

ตำราพิมพ์บทสนทนาโทรศัพท์ไว้ครบ แต่เว้นช่องว่างให้เติมเอง ตัวหนาด้านล่างคือคำที่ใส่ในช่องว่าง (ตัวอย่างตอบ) ส่วนที่ไม่ใช่ตัวหนาคือบรรทัดที่ตำราพิมพ์ไว้ให้

> 투이: 여보세요? *(ฮัลโหล)*
>
> 지훈: 여보세요? 투이 씨, 어디예요? *(ฮัลโหล คุณทุย อยู่ที่ไหน)*
>
> 투이: 집이에요. 오늘 제 생일이에요. 지금 생일 파티를 해요. *(อยู่บ้าน วันนี้วันเกิดฉัน ตอนนี้จัดปาร์ตี้วันเกิด)*
>
> 지훈: 아, 그래요? **축하해요.** *(อ๋อ เหรอ ยินดีด้วยนะ)*
>
> 투이: 고맙습니다. *(ขอบคุณ)*
>
> 지훈: 누가 있어요? *(ใครอยู่บ้าง)*
>
> 투이: **마키 씨, 알렉세이 씨, 제프리 씨, 압둘라 씨, 카오루 씨**가 **있어요.** *(คุณมากิ คุณอเล็กเซย์ คุณเจฟฟรีย์ คุณอับดุลลาห์ คุณคาโอรุอยู่)*
>
> 지훈: 제프리 씨는 무엇을 해요? *(คุณเจฟฟรีย์ทำอะไร)*
>
> 투이: **제프리 씨**가 **케이크를 먹어요.** *(คุณเจฟฟรีย์กินเค้ก)*
>
> 지훈: 누가 노래를 해요? *(ใครร้องเพลง)*
>
> 투이: **마키 씨**가 **노래해요.** *(คุณมากิร้องเพลง)*
>
> 지훈: 재미있어요? *(สนุกไหม)*
>
> 투이: **네, 재미있어요.** *(ใช่ สนุก)*

ในช่อง "이/가" ตำราให้วงกลมเลือกเอง ชื่อที่ลงท้ายด้วย 씨 ไม่มีตัวสะกด จึงต้องเลือก 가 (마키 씨가 · 제프리 씨가)

#### คำถามชวนคุย (หน้า 103)

ท้ายบทอ่านมีคำถามให้คุยกับเพื่อนเกี่ยวกับธรรมเนียมวันเกิดในประเทศของตัวเอง

- 여러분 나라에서는 생일에 무엇을 먹어요? 무엇을 선물해요? 친구와 같이 이야기해 보세요. *(ในประเทศของคุณ วันเกิดกินอะไร ให้ของขวัญอะไร ลองคุยกับเพื่อน)*
- ตัวอย่างตอบ: 태국에서는 생일에 케이크를 먹어요. 선물도 줘요. *(ที่ไทยวันเกิดกินเค้ก และให้ของขวัญด้วย)*

### 🔊 발음

บทนี้เจอกฎการเชื่อมเสียง (연음) เกือบทุกคำ คือตัวสะกดตามด้วยสระ แล้วตัวสะกดย้ายไปเป็นพยัญชนะต้นของพยางค์ถัดไป และมีกรณี ㄱ + ㅎ รวมเป็น [ㅋ] ใน 축하해요 สัญลักษณ์ 📖 ในตารางหมายถึงเสียงอ่านที่ตำราพิมพ์ไว้เอง (ระบุหน้า) ส่วนแถวที่ไม่มีเครื่องหมายคือเสียงตามกฎมาตรฐาน

| เขียน | อ่าน | กฎ |
|:---|:---|:---|
| 먹어요 | [머거요] | 📖 หน้า 97 · 연음: 받침 + สระ → ตัวสะกดย้ายไปเป็นพยัญชนะต้นของพยางค์ถัดไป |
| 씻어요 | [씨서요] | 📖 หน้า 97 · 연음 |
| 물을 | [무를] | 📖 หน้า 99 · 연음 |
| 이메일을 | [이메이를] | 📖 หน้า 99 · 연음 |
| 책을 | [채글] | 📖 หน้า 99 · 연음 |
| 집이에요 | [지비에요] | 📖 หน้า 100 · 연음 |
| 생일을 축하해요 | [생이를 추카해요] | 연음 + ㄱ+ㅎ → [ㅋ] (ตำราขีดเส้นใต้ฝึกอ่าน 11-3) |
| 춤을 춰요 | [추믈 춰요] | 연음 (ตำราขีดเส้นใต้ 11-3) |
| 재미있어요 | [재미이써요] | 연음 (ตำราขีดเส้นใต้ 11-3) |

เขียนตามรูปคำ ไม่ใช่ตามเสียง: [생이를 추카해요] ✗ → 생일을 축하해요

#### 매일시험 11 — โครงข้อสอบ

매일시험 11 ไม่มีตัวเลขคะแนนบนสแกน (ครูขีดแดงเป็นข้อ ๆ) คะแนนรวม 10 = A 15 × 0.4 + B 3 × 1 + C 2 × 0.5 ส่วน A ให้ดูภาพแล้วผัน -아/어요 รูปที่ถูกทั้ง 15 ข้อคือ

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|

| 써요 | เขียน | 춤을 춰요 | เต้นรำ |
| 입어요 | สวมใส่ | 쉬어요 | พัก |
| 일해요 | ทำงาน | 자요 | นอน |
| 봐요 | ดู | 공부해요 | เรียน |
| 줘요 | ให้ | 마셔요 | ดื่ม |
| 씻어요 | ล้าง | 기다려요 | รอ |
| 사요 | ซื้อ | | |

- ส่วน B ตอบ 무엇을 해요? ได้แก่ 숙제를 해요 *(ทำการบ้าน)* · 친구를 만나요 *(พบเพื่อน)* · 책을 읽어요 *(อ่านหนังสือ)*
- ส่วน C เขียนตามคำบอกจากบทอ่าน 11-2 มี 2 ข้อ:
  - 생일을 축하해요. *({v:แสดงความยินดี}{n:วันเกิด})*
  - 파티가 재미있어요. *(ปาร์ตี้สนุก)*

#### ข้อที่ครูมาร์กใน 매일시험 11

ครูมาร์กไว้ 7 ข้อ แต่ละข้อเป็นข้อผิดที่เจอซ้ำกับเรื่องที่เรียนในบท

- A11 줘요 *(ให้)* — เขียน 주세요 ✗
- B16 학생을 공부해요 ✗ — ที่ถูกคือ 숙제를 해요 *(ทำการบ้าน)*
- B17 반나요 ✗ — ที่ถูกคือ 만나요 *(พบ)*
- C19 생이를 추가해요 ✗ — ที่ถูกคือ 생일을 축하해요 *(แสดงความยินดีวันเกิด)*
- C20 파트가 체미있어요 ✗ — ที่ถูกคือ 파티가 재미있어요 *(ปาร์ตี้สนุก)*

- 12과 안 + V-아/어요
- 14과 คำคุณศัพท์ผันเหมือนกริยา และใช้ 도 แทน 을/를 ได้
- 17과 -았/었- และ 19과 -(으)ㄹ 거예요 — หารากด้วยการตัด 다 เหมือน 11과
- 21과 -고 있어요 — 지금 숙제를 하고 있어요 *(ตอนนี้กำลังทำการบ้าน)*

> [!SUMMARY] สรุปท้ายบท
> - V-아/어/여요: ตัด 다 แล้วดูสระท้ายราก — ㅏ/ㅗ → -아요, สระอื่น → -어요, ...하다 → 해요, ส่วน ㅡ ให้ตัดก่อนแล้วดูสระพยางค์หน้า (ไม่มีพยางค์หน้า → 어요)
> - สระชนกันจะควบเป็นพยางค์เดียว เช่น ㅗ+ㅏ=ㅘ (봐요, 와요) ㅣ+ㅓ=ㅕ (마셔요) และ ㅜ+ㅓ=ㅝ (줘요, 배워요)
> - N을/를: มีตัวสะกด (รวม ㅇ) → 을 ไม่มี → 를 N하다 ก็ติด 을/를 โครงประโยคคือ ประธาน이/가 + กรรม을/를 + กริยา
> - กรรมต้องเข้ากับกริยา: 춤을 추다 (✗ 춤을 하다) · 사진을 찍다 · 노래를 하다 และ 지금 กับ 매일 ไม่ใส่ 에
> - ข้อสอบ: ผัน 15 คำจากภาพ · ตอบ 무엇을 해요? · เขียนตามคำบอกจากบทอ่าน 11-2 (생일을 축하해요 · 파티가 재미있어요)
> - ข้อผิดที่เคยเจอ: 받어요 · 춤어요 · 주세요 แทน 줘요 · 체미 แทน 재미
