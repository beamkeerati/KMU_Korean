## 27과 · 장마가 끝나고 더워졌어요 (หลังหน้าฝนจบอากาศก็ร้อนขึ้น)

> [!INTRO] บทนี้ว่าด้วยอะไร
> บทที่ 27 ว่าด้วยฤดูกาลและอาหารตามฤดูในเกาหลี ในบทสนทนา จางผิงสังเกตว่าอากาศร้อนขึ้นหลังหน้าฝน ยุนอาเล่าว่าคนเกาหลีกินพัตบิงซูในหน้าร้อน แล้วทั้งคู่ชวนกันไปกิน ส่วนบทอ่านเป็นข้อความแชตที่ยุนอานัดเจฟฟรีย์ไปกินพาจอนที่จงโนในวันฝนตก
>
> ไวยากรณ์ใหม่มี 2 เรื่อง:
>
> 1. **A-아/어/여지다** — "กลายเป็น… / …ขึ้น" ใช้บอกว่าสภาพเปลี่ยนไปแล้ว (날씨가 더워졌어요) ผันตาม 아/어 เหมือน -아/어요 แล้วเติม 지다 ใช้กับคำคุณศัพท์
> 2. **V-는** — ใช้เอากริยาปัจจุบันไปขยายคำนามที่ตามหลัง (여름에 자주 먹는 음식) เป็นคู่กับ -(으)ㄴ ที่ใช้กับคำคุณศัพท์ในบท 23 ภาษาไทยวางส่วนขยายไว้หลังนามว่า "อาหารที่กินบ่อย" แต่ภาษาเกาหลีวางไว้หน้านามและมีรูป -는
>
> จบบทแล้วจะบอกได้ว่าสภาพเปลี่ยนไปอย่างไร ขยายนามด้วยกริยาได้ พูดถึงลักษณะของ 4 ฤดูในเกาหลีได้ และอ่านข้อความแชตนัดเจอกันได้
>
> จุดที่คนไทยงงบ่อย: ไม่แยก 더워요 (ร้อน) กับ 더워졌어요 (ร้อนขึ้น) ใช้ -는 กับคำคุณศัพท์ (ต้องเป็น -(으)ㄴ) และใส่ ㄹ ค้างไว้ในกริยาอย่าง 만들다 · 살다 จนได้ 만들는 · 살는

### 🗣️ คำศัพท์ที่ต้องรู้ก่อน

คำศัพท์ของบทนี้มี 4 กลุ่ม ได้แก่ คำเกี่ยวกับฤดูและอากาศ ชื่ออาหารและของกินตามฤดู คำเกี่ยวกับภาษาและการเรียนที่ใช้ฝึก -는 และคำอื่น ๆ จากบทสนทนากับข้อความแชต ตารางนี้คัดเฉพาะคำที่ต้องรู้เพื่ออ่านบท รายการเต็มของศูนย์อยู่ท้ายบท

### 📝 ไวยากรณ์: A-아/어/여지다 — "กลายเป็น… / …ขึ้น" (ไวยากรณ์ข้อ 43)

ตอนนี้ว่าด้วยการบอกว่าสภาพเปลี่ยนไปทีละน้อย ตำราบอกว่า "สภาพที่พูดถึงกำลังค่อย ๆ เปลี่ยนไป" รูปนี้ใช้กับ**คำคุณศัพท์** ผันตาม 아/어 เหมือน -아/어요 (ไวยากรณ์ข้อ 06) แล้วเติม **지다** ตัวที่เปลี่ยนเป็นประธาน (이/가) เช่น 날씨**가** 맑아졌어요 *(อากาศแจ่มใสขึ้น)*

#### รูปแบบ

ตารางนี้แยกตามสระท้ายราก สังเกตว่า 하다 เปลี่ยนเป็น 해 ส่วน ㅂ และ ㅡ ผันตามกฎเดิมที่เรียนมา

| ราก | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| พยางค์ท้ายมี ㅏ / ㅗ | -아지다 | 맑다 → **맑아졌어요** [말가졌써요] · 좋다 → 좋아졌어요 · 많다 → 많아졌어요 |
| สระอื่น | -어지다 | 흐리다 → 흐려졌어요 · 길다 → 길어졌어요 |
| 하다 | -**해**지다 | 따뜻하다 → 따뜻해졌어요 · 시원하다 → 시원해졌어요 · 쌀쌀하다 → 쌀쌀해졌어요 |
| ㅡ ตกก่อน 아/어 | ดูสระหน้า ㅡ | 예쁘다 → 예뻐졌어요 · 나쁘다 → 나빠졌어요 |
| ㅂ 불규칙 | ㅂ → 워 | 춥다 → 추워졌어요 · 덥다 → 더워졌어요 · 어둡다 → 어두워졌어요 |

#### แสดงวิธีทำ: -아/어/여지다 (ย่อ · ตารางเต็มในไวยากรณ์ข้อ 43)

กฎ 1 เลือก 아 เมื่อสระท้ายรากเป็น ㅏ ㅗ นอกนั้นเลือก 어 และ 하 รวมเป็น 해 กฎ 2 ราก ㅡ ตกก่อนแล้วดูสระหน้า ㅡ ส่วน ㅂ 불규칙 เปลี่ยนเป็น 워 กฎ 3 ผัน 아/어 เสร็จแล้วจึงต่อ 지다 เป็น -졌어요

| ราก + 지다 | ① เลือก 아/어/여 | ② รวมเสียง | ③ ผล |
|:---|:---|:---|:---|
| 맑 + 지다 | ㅏ → 아 | 맑 + 아 → 맑아 | **맑아졌어요** |
| 길 + 지다 | ㅣ → 어 | 길 + 어 → 길어 (ㄹ อยู่ครบ) | **길어졌어요** |
| 흐리 + 지다 | ㅣ → 어 | 리 + 어 → 려 | **흐려졌어요** |
| 따뜻하 + 지다 | 하 → 여 | 하 + 여 → 해 | **따뜻해졌어요** |
| 예쁘 + 지다 | ㅡ ตก ดู 예 → 어 | 쁘 → ㅃ + 어 → 뻐 | **예뻐졌어요** |
| 덥 + 지다 | ㅂ 불규칙 → 어 | ㅂ ตก + 우 + 어 → 워 | **더워졌어요** |

#### ตัวอย่างจากตำรา

ตัวอย่างในตำราใช้คู่กับ N보다 (ข้อ 41) บ่อย เพราะ "เย็นลงกว่าเมื่อวาน" คือการเปรียบเทียบพร้อมการเปลี่ยนแปลง

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 오늘도 더워요? → 어제보다 시원해졌어요. | วันนี้ก็ร้อนไหม → เย็นลงกว่าเมื่อวาน | ตำรา — ใช้คู่กับ N보다 (ข้อ 41) |
| 작년보다 한국어 실력이 좋아졌어요. | ทักษะเกาหลีดีขึ้นกว่าปีที่แล้ว | ตำรา |
| 하늘이 어두워졌어요. | ท้องฟ้ามืดลง | ตำรา — ตัวพิมพ์ของตัวอย่างนี้เสียหายในสแกน อ่านเป็น 어두워졌어요 |
| 청소를 해서 방이 깨끗해졌어요. | ทำความสะอาดแล้วห้องก็สะอาดขึ้น | ตำรา |

#### 연습 1 (หน้า 270) — ตอบตามแบบ

ตำรามีแต่โจทย์ ให้ตอบตามแบบ "날씨가 맑아졌어요" คำตอบในตารางเป็นรูปที่ควรได้

| คำตอบ | ความหมาย |
|:---|:---|
| 날씨가 맑아졌어요. | อากาศแจ่มใสขึ้น |
| 흐려졌어요. | ครึ้มขึ้น |
| 따뜻해졌어요. | อุ่นขึ้น |
| 추워졌어요. | หนาวขึ้น |
| 윤아 씨가 예뻐졌어요. | ยุนอาสวยขึ้น |
| 건강이 나빠졌어요. | สุขภาพแย่ลง |

#### 연습 2 (หน้า 271) — ดูภาพถาม-ตอบ

แบบฝึกนี้ให้ดูภาพแล้วบอกว่าอะไรเปลี่ยนไป ข้อแรกเป็นตัวอย่างตำรา คำตอบ 연습 2 ที่เหลือเป็นตัวอย่าง เพราะตำรามีช่องว่าง

| โจทย์ | คำตอบ | ความหมาย · ภาพ |
|:---|:---|:---|
| 가: 날씨가 어때요? | 나: 날씨가 더워졌어요. | อากาศเป็นยังไง — ร้อนขึ้น · 🖼️ เทอร์โมมิเตอร์สูงขึ้น (ตัวอย่างตำรา) |
| 지금도 맑아요? | 아니요, 흐려졌어요. | ตอนนี้ก็ยังแจ่มใสไหม — ไม่ ครึ้มขึ้นแล้ว · 🖼️ ท้องฟ้าแดด → เมืองฝนครึ้ม |
| 시험을 잘 봤어요? | 네, 시험 점수가 좋아졌어요. | สอบได้ดีไหม — ใช่ คะแนนสอบดีขึ้น · 🖼️ ข้อสอบ 2 ใบ คะแนนดีขึ้น |
| 마키 씨가 화장을 했네요. | 그래서 예뻐졌어요. | มากิแต่งหน้านะ — เลยสวยขึ้น · 🖼️ ก่อน/หลังแต่งหน้า |
| 지훈 씨가 운동을 하지 않아요. | 그래서 뚱뚱해졌어요. | จีฮุนไม่ออกกำลังกาย — เลยอ้วนขึ้น · 🖼️ 70 กก. → 80 กก. |

#### 연습 3 (หน้า 271) — เล่าสิ่งที่เปลี่ยนไปจากภาพ

ภาพในแบบฝึกนี้คือโรงเรียนตอนบ่ายเทียบกับตอนกลางคืน ให้เล่าว่าเปลี่ยนไปอย่างไร คำสั่งในตำราคือ 다음 그림은 학교의 풍경입니다. 그림을 보고 오후와 밤의 풍경이 어떻게 달라졌는지 말해 봅시다. *(ภาพนี้คือบรรยากาศในโรงเรียน ดูภาพแล้วเล่าว่าตอนบ่ายกับตอนกลางคืนต่างกันอย่างไร)* ตำราไม่มีเฉลย ประโยคด้านล่างเป็นตัวอย่างเสริม

🖼️ *ภาพโรงเรียนตอนบ่ายกับตอนกลางคืน*

- 하늘이 어두워졌어요. *(ท้องฟ้ามืดลง)*
- 날씨가 추워졌어요. *(อากาศหนาวขึ้น)*
- 학교가 조용해졌어요. *(โรงเรียนเงียบลง)*

#### -졌어요 กับ -져요

รูป -졌어요 บอกว่าเปลี่ยนไปแล้ว (อดีต) ส่วน -져요 บอกว่าเปลี่ยนอยู่หรือเปลี่ยนเรื่อยไป (ปัจจุบัน) และในภาษาเขียนแบบ 합니다체 จะเป็น -졌습니다

| รูป | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| -졌어요 | เปลี่ยนไปแล้ว (อดีต) | 날씨가 맑아졌어요 |
| -져요 | เปลี่ยนอยู่ / เรื่อยไป (ปัจจุบัน) | 맑아져요 |
| -졌습니다 | 합니다체 | 쌀쌀해졌습니다 (읽기 27-2) |

#### ⚠️ ระวัง

- ★ ㅏ/ㅗ → **아**: 맑어졌어요 ✗ → 맑**아**졌어요 · 좋어졌어요 ✗ — ตระกูลเดียวกับ 살어요 · 받었어요 ที่เคยผิด
- 하다 → **해**지다 (ไม่ใช่ 하어지다)
- 졌 (ㅈ) ≠ 쳤 (ㅊ)
- 더워요 (ร้อน — สภาพ) ≠ 더워졌어요 (ร้อน**ขึ้น** — การเปลี่ยน)
- ใช้กับคำคุณศัพท์ ไม่ใช้บอกการกระทำ

→ เจาะลึก: ไวยากรณ์ข้อ 43 (เล่ม 2)

### 📝 ไวยากรณ์: V-는 — กริยาขยายนาม (ไวยากรณ์ข้อ 44)

ตอนนี้ว่าด้วยการเอากริยามาขยายคำนามที่ตามหลัง ตำราอธิบายว่า -는 ต่อท้ายรากกริยาหรือ 있다/없다 เพื่อขยายนาม แสดงเหตุการณ์ที่**กำลังเกิดหรือทำประจำ** หรือเกิดพร้อมกริยาหลัก ส่วนคำคุณศัพท์ยังใช้ -(으)ㄴ ตามที่เรียนในบท 23 (ข้อ 36)

#### รูปแบบ

ตารางนี้แยกตามชนิดของราก สังเกตว่ากริยาต่อรากตรง ๆ ไม่ดูตัวสะกด ราก ㄹ ต้องตัด ㄹ ก่อน และ 있다/없다 รวมถึง 맛있다 ใช้ -는 ด้วย

| ราก | รูป | ตัวอย่าง |
|:---|:---|:---|
| กริยา (ไม่ดูตัวสะกด) | -는 | 먹다 → **먹는** 음식 · 듣다 → 듣는 노래 · 입다 → 입는 옷 |
| กริยา (ไม่ดูตัวสะกด) | -는 | 외우다 → 외우는 것 |
| ราก ㄹ (ตัด ㄹ) | -는 | 만들다 → **만드는** 음식 · 살다 → 사는 곳 |
| 있다 / 없다 (รวม 맛있다) | -는 | 교실에 있는 사람 · 맛있는 음식 |
| คำคุณศัพท์ | -(으)ㄴ (23과 ข้อ 36) | 매운 음식 · 시원한 냉면 |

#### แสดงวิธีทำ: -는 กริยาขยายนาม (ย่อ · ตารางเต็มในไวยากรณ์ข้อ 44)

กฎ 1 กริยาและ 있다/없다 ต่อ 는 ตรง ๆ โดยไม่ดูตัวสะกด กฎ 2 รากลงท้าย ㄹ ต้องตัด ㄹ ก่อนเพราะ 는 ขึ้นต้นด้วย ㄴ กฎ 3 ราก ㅂ 불규칙 ไม่เปลี่ยน ส่วนคำคุณศัพท์ไม่ใช้ 는

| ราก + 는 | ① ชนิดคำ | ② ราก ㄹ? | ③ ผล |
|:---|:---|:---|:---|
| 먹 + 는 | กริยา → 는 | ไม่ใช่ | **먹는** |
| 맛있 + 는 | 있다 → 는 | ไม่ใช่ | **맛있는** |
| 만들 + 는 | กริยา → 는 | ใช่ ตัด ㄹ | **만드는** |
| 살 + 는 | กริยา → 는 | ใช่ ตัด ㄹ | **사는** |
| 돕 + 는 | กริยา ㅂ 불규칙 → 는 | ไม่ใช่ (ㅂ อยู่) | **돕는** |
| 맵 (คำคุณศัพท์) | ✗ 는 ใช้ -(으)ㄴ | ไม่ใช่ | **매운** |

#### ตัวอย่างจากตำรา

ตัวอย่างต่อไปนี้เป็นประโยคที่ตำราใช้อธิบายกฎ สังเกตว่าประธานของกริยาที่ขยายใช้ 이/가

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 한국 사람들이 여름에 자주 먹는 음식이 뭐예요? → 여름에 냉면을 많이 먹어요. | อาหารที่คนเกาหลีกินบ่อยในหน้าร้อนคืออะไร → กินเนงมยอนเยอะ | ตำรา |
| 이 노래가 요즘 자주 듣는 노래예요. | เพลงนี้เป็นเพลงที่ช่วงนี้ฟังบ่อย | ตำรา |
| 단어를 외우는 것이 힘들었어요. | การท่องคำศัพท์เหนื่อยมาก | ตำรา |
| 지금 교실에 있는 사람이 누구예요? | คนที่อยู่ในห้องตอนนี้คือใคร | ตำรา |

#### 연습 1 (หน้า 272) — ลากเส้นจับคู่

แบบฝึกนี้ให้ลากเส้นจับคู่วลีกับนาม ตำราลากเส้นไว้แค่ข้อ 1 (→ 옷) ที่เหลือจับคู่ตามความหมาย คือ 과일 · 음악 · 차 · 책

| วลี | ความหมาย | หมายเหตุ |
|:---|:---|:---|
| 봄에 자주 입는 옷 | เสื้อผ้าที่ใส่บ่อยในฤดูใบไม้ผลิ | ตัวอย่างตำรา |
| 여름에 자주 먹는 과일 | ผลไม้ที่กินบ่อยในฤดูร้อน | จับคู่ตามความหมาย |
| 가을에 자주 듣는 음악 | ดนตรีที่ฟังบ่อยในฤดูใบไม้ร่วง | จับคู่ตามความหมาย |
| 겨울에 많이 마시는 차 | ชาที่ดื่มเยอะในฤดูหนาว | จับคู่ตามความหมาย |
| 요즘 읽는 책 | หนังสือที่ช่วงนี้อ่านอยู่ | จับคู่ตามความหมาย |

#### 연습 2 (หน้า 273) — ถาม-ตอบเรื่องที่ทำบ่อย

แบบฝึกนี้ให้ถามตอบด้วยโครง "-는 + นาม" ข้อ 1–2 มีคำตอบในตำรา ข้อ 3–6 ตำราเว้นให้ตอบเอง คำตอบที่ใส่ไว้ในตารางเป็นตัวอย่างตอบของผู้เขียนคู่มือ

| โจทย์ | คำตอบ | ความหมาย |
|:---|:---|:---|
| ___ 씨가 요즘 배우는 외국어가 뭐예요? | 제가 요즘 배우는 외국어는 한국어예요. | ภาษาต่างประเทศที่ช่วงนี้เรียนคืออะไร → เกาหลี |
| 자주 마시는 음료수 | 콜라 | เครื่องดื่มที่ดื่มบ่อย → โคล่า |
| 자주 만드는 음식 | 제가 자주 만드는 음식은 볶음밥이에요. *(ตัวอย่างตอบ)* | อาหารที่ทำบ่อย — ข้าวผัด |
| 자주 부르는 노래 | 제가 자주 부르는 노래는 한국 노래예요. *(ตัวอย่างตอบ)* | เพลงที่ร้องบ่อย — เพลงเกาหลี |
| 자주 만나는 친구 | 제가 자주 만나는 친구는 같은 반 친구예요. *(ตัวอย่างตอบ)* | เพื่อนที่พบบ่อย — เพื่อนร่วมห้อง |
| 요즘 좋아하는 가수 | 제가 요즘 좋아하는 가수는 아이유예요. *(ตัวอย่างตอบ)* | นักร้องที่ช่วงนี้ชอบ — ไอยู |

#### 연습 3 (หน้า 273) — ถามเพื่อนว่าชอบหรือไม่ชอบอะไร

แบบฝึกนี้ให้ถามเพื่อนว่าชอบหรือไม่ชอบอะไรโดยใช้ 무슨/어떤 จากบท 22 (ข้อ 34) คำสั่งในตำราคือ 좋아하는 것과 싫어하는 것에 대해서 친구와 이야기해 봅시다. *(คุยกับเพื่อนเรื่องสิ่งที่ชอบและไม่ชอบ)* คำถามมี 6 ข้อ ให้ใส่ชื่อเพื่อนในช่องว่าง ตำราไม่มีเฉลย ตัวอย่างตอบเป็นของผู้เขียนคู่มือ

| คำถามในตำรา | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|
| ___ 씨가 좋아하는/싫어하는 한국어 단어가 뭐예요? | 제가 좋아하는 한국어 단어는 사랑이에요. | คำเกาหลีที่ชอบ / ไม่ชอบคืออะไร — ที่ชอบคือ "ความรัก" |
| ___ 씨가 좋아하는/싫어하는 채소가 있어요? | 네, 저는 당근을 좋아해요. 양파는 싫어해요. | มีผักที่ชอบ / ไม่ชอบไหม — ชอบแครอต ไม่ชอบหัวหอม |
| ___ 씨가 좋아하는/싫어하는 동물은 뭐예요? | 제가 좋아하는 동물은 강아지예요. | สัตว์ที่ชอบ / ไม่ชอบคืออะไร — ที่ชอบคือลูกสุนัข |
| ___ 씨는 무슨 음식을 좋아해요/싫어해요? | 저는 불고기를 좋아해요. 매운 음식은 싫어해요. | ชอบ / ไม่ชอบอาหารอะไร — ชอบบุลโกกิ ไม่ชอบอาหารเผ็ด |
| ___ 씨는 무슨 색깔을 좋아해요/싫어해요? | 저는 파란색을 좋아해요. 빨간색은 싫어해요. | ชอบ / ไม่ชอบสีอะไร — ชอบสีฟ้า ไม่ชอบสีแดง |
| ___ 씨는 어떤 사람을 좋아해요/싫어해요? | 저는 친절한 사람을 좋아해요. 불친절한 사람은 싫어해요. | ชอบ / ไม่ชอบคนแบบไหน — ชอบคนใจดี ไม่ชอบคนบริการไม่ดี |

#### ⚠️ ระวัง

- ประธานของกริยาที่ขยายใช้ **이/가**: 한국 사람들**이** 자주 먹는 음식 *(ไม่ใช่ 은/는)*
- นามที่ถูกขยายคือกรรมของ 먹다 อยู่แล้ว ห้ามใส่ 을/를 ซ้ำใน clause
- 비 오는 날 *(วันที่ฝนตก)*
- **ราก ㄹ ตัดทิ้ง**: 만들는 ✗ → 만드는 · 살는 ✗ → 사는 (ตระกูลเดียวกับ 만들습니다 ✗ → 만듭니다 ที่เคยผิด)
- 있다/없다 → **있는/없는**: 맛있는 · 재미있는 · 맛없는
- 좋아하는 (กริยา: คนที่ "ชอบ") ≠ 좋은 (คำคุณศัพท์: "ดี"): 좋아하는 가수 · 좋은 사람
- คำคุณศัพท์ห้ามใช้ -는: 매운 ✓ · 맵는 ✗
- เวลา: ปัจจุบัน -는 · อดีต -(으)ㄴ (29과 ข้อ 47) · อนาคต -(으)ㄹ (33과 ข้อ 56)

→ เจาะลึก: ไวยากรณ์ข้อ 44 (เล่ม 2)

### 💬 대화 27-1 — ร้อนขึ้นแล้วไปกินพัตบิงซู

จางผิงสังเกตว่าอากาศร้อนกว่าสัปดาห์ที่แล้ว ยุนอาบอกว่าพอหมดฤดูฝนก็ร้อนขึ้น จางผิงเลยถามว่าคนเกาหลีกินอะไรในหน้าร้อน ยุนอาตอบว่าพัตบิงซู แล้วทั้งคู่ชวนกันไปกิน บทสนทนานี้มีทั้ง -아/어지다 และ V-는 อย่างละหนึ่งที่

> 장핑: 지난주보다 많이 덥네요. *(ร้อนกว่าสัปดาห์ที่แล้วมากเลยนะ)*
>
> 윤아: 장마가 끝나고 더워졌어요. *(พอฝนหมดฤดูก็ร้อนขึ้นน่ะ)*
>
> 장핑: 그런데 한국 사람들이 여름에 자주 먹는 음식이 뭐예요? *(ว่าแต่ อาหารที่คนเกาหลีกินบ่อยในหน้าร้อนคืออะไร)*
>
> 윤아: 한국 사람들은 여름에 팥빙수를 많이 먹어요. 아주 시원하고 맛있어요. *(คนเกาหลีกินพัตบิงซูเยอะในหน้าร้อน เย็นสดชื่นและอร่อยมาก)*
>
> 장핑: 그럼, 지금 팥빙수를 먹으러 갈까요? *(งั้นตอนนี้ไปกินพัตบิงซูกันไหม)*
>
> 윤아: 좋아요. 빨리 가요. *(ได้เลย รีบไปกันเถอะ)*

#### สังเกตจากบทสนทนา

- 지난주보다 많이 덥네요 — N보다 (ข้อ 41) และ -네요 (ข้อ 30)
- 장마가 끝나고 더워졌어요 — -아/어지다 (ข้อ 43)
- 여름에 자주 먹는 음식 — V-는 (ข้อ 44) โดยประธาน 한국 사람들이 ใช้ 이/가
- 팥빙수를 먹으러 갈까요? — -(으)러 + -(으)ㄹ까요? (ข้อ 33)
- 그런데 — ใช้เปลี่ยนหัวข้อว่า "ว่าแต่"

#### ฝึกสลับ (ตำรา หน้า 274)

ตำราให้ชุดคำสลับ 3 ชุด พิมพ์เป็นสายคำตัวอักษร (ไม่ใช่ภาพ) คำสั่งในตำราคือ 다음 표현을 사용해서 위와 같이 대화를 만들어 봅시다. *(ใช้สำนวนต่อไปนี้ทำบทสนทนาเหมือนข้างบน)* แต่ละช่องตรงกับคำที่แทนในบทสนทนา เช่น 덥다 ใส่ในช่อง 더워졌어요 (ผันเป็น -아/어졌어요) และ 팥빙수 ใส่ในช่องชื่อของกิน ตารางด้านล่างเรียงสายคำของตำราเป็นคอลัมน์

| ช่อง | ชุด 1 | ชุด 2 | ชุด 3 |
|:---|:---|:---|:---|
| สภาพที่เปลี่ยน | 덥다 *(ร้อน)* | 춥다 *(หนาว)* | 쌀쌀하다 *(หนาวเย็น ๆ)* |
| สาเหตุ | 장마가 끝나다 *(ฝนหมดฤดู)* | 눈이 오다 *(หิมะตก)* | 비가 오다 *(ฝนตก)* |
| ฤดู | 여름 *(ฤดูร้อน)* | 겨울 *(หน้าหนาว)* | 겨울 *(หน้าหนาว)* |
| ประเภทของกิน | 음식 *(อาหาร)* | 간식 *(ของว่าง)* | 차 *(ชา)* |
| ชื่อของกิน | 팥빙수 *(พัตบิงซู)* | 군고구마 *(มันเทศเผา)* | 유자차 *(ชายูจา)* |
| คำบรรยาย | 시원하다 / 맛있다 *(เย็น / อร่อย)* | 달다 / 맛있다 *(หวาน / อร่อย)* | 따뜻하다 / 달다 *(อุ่น / หวาน)* |

คำถามเช็กความเข้าใจท้ายบทสนทนา:

- 오늘 날씨가 어때요? → 지난주보다 많이 더워요. 장마가 끝나고 더워졌어요. *(วันนี้อากาศเป็นยังไง — ร้อนกว่าสัปดาห์ที่แล้วมาก หลังหมดฤดูฝนก็ร้อนขึ้น)*
- 장핑 씨와 윤아 씨는 무엇을 할 거예요? → 팥빙수를 먹으러 갈 거예요. *(จางผิงกับยุนอาจะทำอะไร — จะไปกินพัตบิงซู)*

### 📖 읽기 27-2 · 🎧 듣기 — ข้อความแชตนัดกินพาจอน

บทอ่านเป็นข้อความ SMS ระหว่างยุนอา (윤아) กับเจฟฟรีย์ (제프리) ช่วงหน้าฝน เจฟฟรีย์ที่ชอบฟุตบอลเบื่อเพราะฝนตกทั้งสัปดาห์ แล้วยุนอาส่งข้อความมานัดไปกินพาจอนกับมักกอลลีที่จงโน ในบทมีทั้ง -아/어지다 (쌀쌀해졌습니다) และ -는 (좋아하는 · 먹는) ให้เห็นหลายจุด

ก่อนอ่าน ตำราหน้า 276 ให้ตอบคำถามอุ่นเครื่อง 2 ข้อ (ตอบเองตามจริง ไม่มีเฉลย)

- 여러분 고향에도 사계절이 있어요? *(บ้านเกิดของคุณมีสี่ฤดูไหม)*
- 고향에서는 비가 오면 무엇을 해요? *(ที่บ้านเกิดพอฝนตกทำอะไร)*

> 요즘은 장마철입니다. 1주일 동안 계속 비가 왔습니다. 그래서 날씨가 쌀쌀해졌습니다. 축구를 좋아하는 제프리 씨는 너무 심심했습니다. 그때 윤아 씨에게서 메시지가 왔습니다. 제프리 씨는 윤아 씨의 메시지가 아주 반가웠습니다. *(ช่วงนี้เป็นหน้ามรสุมฝน ฝนตกต่อเนื่อง 1 สัปดาห์ อากาศเลยเย็นลง เจฟฟรีย์ที่ชอบฟุตบอลเบื่อมาก ตอนนั้นมีข้อความจากยุนอามา เจฟฟรีย์ดีใจกับข้อความของยุนอามาก)*
>
> 윤아: 제프리 씨, 잘 지냈어요? 오늘 저녁에 지훈 씨하고 만날 거예요. 같이 만날까요? *(เจฟฟรีย์ สบายดีไหม เย็นนี้ฉันจะพบจีฮุน ไปพบด้วยกันไหม)*
>
> 제프리: 좋아요. 좀 심심했어요. 어디에서 만날까요? *(ได้เลย เบื่ออยู่พอดี พบกันที่ไหนดี)*
>
> 윤아: 우리는 오늘 파전을 먹을 거예요. 파전은 종로가 유명해요. 7시에 종로에서 만나요. *(เราจะกินพาจอนกัน พาจอนที่จงโนมีชื่อ เจอกัน 7 โมงที่จงโน)*
>
> 제프리: 파전이 뭐예요? *(พาจอนคืออะไร)*
>
> 윤아: 파전은 한국 사람들이 비 오는 날 먹는 음식이에요. 막걸리하고 같이 먹어요. *(พาจอนเป็นอาหารที่คนเกาหลีกินวันฝนตก กินคู่กับมักกอลลี)*
>
> 제프리: 아주 맛있겠네요. 저는 막걸리도 아주 좋아해요. 그럼 종로에서 만나요. *(น่าจะอร่อยมากเลย ผมก็ชอบมักกอลลีมาก งั้นเจอกันที่จงโน)*

- **막걸리**하고 **같이** 먹어요. *(กินคู่กับมักกอลลี)*

#### 라 — เติมไดอารี่ "제프리의 일기 6월 10일"

ตำรามีแต่ช่องว่าง และให้วงกลมไอคอนอากาศ (☀ ☂ ⛄) หนึ่งอัน (ตัวอย่างตอบคือ ☂ เพราะฝนตก) คำในวงเล็บคือช่องว่างและเป็นตัวอย่างตอบของผู้เขียนคู่มือ

- 오늘도 계속 비가 왔습니다. *(วันนี้ฝนก็ตกต่อเนื่อง)*
- 저녁에 (종로)에서 (지훈 씨)하고 (윤아 씨)를 만났습니다. *(ตอนเย็นพบจีฮุนกับยุนอาที่จงโน)*
- (파전)을 먹고 (막걸리)도 마셨습니다. *(กินพาจอนและดื่มมักกอลลีด้วย)*
- 파전은 아주 맛있었습니다. *(พาจอนอร่อยมาก)*
- 파전은 한국 사람들이 (비 오는 날) 먹는 음식입니다. *(พาจอนเป็นอาหารที่คนเกาหลีกินวันฝนตก)*
- 낮에는 심심했지만 저녁에는 (재미있었습니다). *(ตอนกลางวันเบื่อแต่ตอนเย็นสนุก)*

#### 활동 (หน้า 275) — ฤดูของเกาหลี

กิจกรรมนี้ให้พูดเรื่องฤดูของเกาหลีจากภาพ แล้วพูดเรื่องฤดูที่บ้านเกิด และเลือกประเทศของเพื่อนที่อยากไปพร้อมเหตุผล (ใช้ -고 싶다 ข้อ 38 และ 중에서 ข้อ 45) คำสั่งในตำราหน้า 275 มี 4 ประโยค ไม่มีเฉลย

- 한국의 사계절에 대해 더 알아봅시다. *(มาดูเรื่องสี่ฤดูของเกาหลีให้มากขึ้น)*
- 고향의 계절에 대해서 반 친구들에게 이야기해 봅시다. *(เล่าเรื่องฤดูกาลที่บ้านเกิดให้เพื่อนร่วมห้องฟัง)*
- 우리 반 친구들의 고향 중에서 가 보고 싶은 나라를 하나 선택하세요. *(เลือกประเทศบ้านเกิดของเพื่อนร่วมห้องที่อยากไปสักหนึ่งประเทศ)*
- 그리고 언제 가고 싶은지, 왜 그 계절에 가고 싶은지에 대해서 이야기해 봅시다. *(แล้วเล่าว่าอยากไปเมื่อไร และทำไมถึงอยากไปในฤดูนั้น)*

ภาพของแต่ละฤดูมีคำใบ้ดังนี้

| ฤดู | ผลไม้ในภาพ | ลักษณะอากาศในภาพ |
|:---|:---|:---|
| 봄 | 🖼️ 딸기 *(สตรอว์เบอร์รี)* | 따뜻하다 *(อบอุ่น)* · 황사 *(ฝุ่นทราย)* |
| 여름 | 포도 *(องุ่น)* · 수박 *(แตงโม)* | 덥다 *(ร้อน)* · 장마 *(ฤดูฝน)* |
| 가을 | 감 *(ลูกพลับ)* | 시원하다 *(เย็นสบาย)* · 단풍 *(ใบไม้เปลี่ยนสี)* |
| 겨울 | 귤 *(ส้มเกาหลี)* | 춥다 *(หนาว)* · 눈 *(หิมะ)* |

#### 활동 (หน้า 277) — วันฝนตกอยากทำอะไร

คำถามปิดท้ายบทอ่านให้คุยกับเพื่อนเรื่องสิ่งที่อยากทำในวันฝนตก ตอบได้ด้วย -는 (비 오는 날) คู่กับ -고 싶다 ตำราไม่มีเฉลย

- 여러분은 비가 오는 날 무엇을 하고 싶어요? *(วันฝนตกคุณอยากทำอะไร)*
- 저는 비 오는 날 파전을 먹고 싶어요. *(ตัวอย่างตอบ — วันฝนตกฉันอยากกินพาจอน)*

### 🔊 발음

ตำราหน้า 270 และ 272 ให้ 3 คำแรกในตาราง ส่วน 4 คำที่เหลือเป็นคำที่คำนวณตามกฎจากเสียง 27-3 (เสริม) คอลัมน์กฎเป็นคำอธิบายที่ผู้เขียนคู่มือเติมให้

| เขียน | อ่าน | กฎ |
|:---|:---|:---|
| 맑아졌어요 | [말가졌써요 / 말가져써요] | ㄺ + สระ: ㄱ ย้ายไปเป็นต้นพยางค์ถัดไป |
| 먹는 | [멍는] | ㄱ + ㄴ → ㅇ + ㄴ |
| 듣는 | [든는] | ㄷ + ㄴ → ㄴ + ㄴ |
| 같이 | [가치] | เสริม: ㅌ + ㅣ → ㅊ |
| 막걸리 | [막껄리] | เสริม: ㄱ + ㄱ → ㄲ |
| 좋아하는 | [조아하는] | เสริม: ㅎ เบาเมื่อตามด้วยสระ |
| 심심했습니다 | [심심핻씀니다] | เสริม: ㅆ ท้ายพยางค์ = [ㄷ] · ㅂ + ㄴ → ㅁ |

### 🧪 ออกสอบอย่างไร

บทนี้ยังไม่มีข้อสอบจริง สิ่งที่บอกได้ตอนนี้คือขอบเขตการสอบและรูปแบบที่คาดจากข้อสอบก่อนหน้า

- คาดว่าบทนี้ออกใน **복습시험③ (22–29과, 6 พ.ย.)** และ **기말 (23–37과)**
- รูปแบบที่คาด:
  - ผันตาราง -아/어/여지다 กับคำปกติ: 맑다 · 흐리다 · 따뜻하다
  - ผันตาราง -아/어/여지다 กับคำไม่ปกติ: 춥다 · 예쁘다 · 나쁘다
  - ต่อสองประโยคด้วย -는: 한국 사람들이 자주 먹어요 + 음식 → 한국 사람들이 자주 먹는 음식
  - ตอบ 요즘 배우는 외국어가 뭐예요?
  - จับคู่ -는 + นาม
  - 읽기 27-2 (ข้อความแชต) มาเป็นบทสนทนา 가/나

> [!WARNING] ที่น่าจะพลาด (คาดจากข้อผิดเดิม — ยังไม่มีข้อสอบจริง)
> - ★ ㅏ/ㅗ → 아 ผิดเป็น 어: 맑어졌어요 · 좋어졌어요 (เหมือน 살어요 / 받었어요)
> - ★ ㅈ/ㅊ: 졌 ↔ 쳤 · ตัวสะกดคู่ ㄺ ของ 맑
> - ★ ㄹ-drop ใน -는: 만들는 ✗ → 만드는 · 살는 ✗ → 사는 (เหมือน 만들으세요 ✗ → 만드세요)
> - ★ ㅂ ผิด: 추워졌어요 · 더워졌어요 (ไม่ใช่ 춥어졌어요)
> - ㅡ ตก: 예뻐졌어요 · 나빠졌어요 · 바빠졌어요 (ไม่ใช่ 바빱니다 แบบที่เคยผิด)
> - ★ ใส่ 을/를 ซ้ำใน -는: 음식을 먹는 음식 ✗
> - ลืม 이/가 ของประธานใน clause: 한국 사람들이 자주 먹는 음식
> - ใช้ 가 กับกรรมของ 듣다/받다: 이야기가 들었어요 ✗ → 이야기를 들었어요
> - ★ ㅐ/ㅔ: 태국 (ไม่ใช่ 테국) · 점수 · 메시지 (ㅔ) ↔ 배 · 새 (ㅐ)

### 🔗 เชื่อมโยง

← ต่อยอดจาก

- 26과 N보다 (ข้อ 41): 어제보다 시원해졌어요 — เทียบ + เปลี่ยน
- 23과 ข้อ 36–37 -(으)ㄴ คำคุณศัพท์ + ㅂ 불규칙: 춥다 → 추워졌어요
- 14과 คำคุณศัพท์ (ข้อ 18)
- 22과 -(으)ㄹ까요? + -(으)러 (ข้อ 33): 팥빙수를 먹으러 갈까요?
- 20과 -네요 (ข้อ 30): 덥네요 · 맛있겠네요 ใช้คู่กับ -겠- (ข้อ 42)

→ ใช้ต่อใน

- 29과 -(으)ㄴ: กริยาอดีตขยายนาม (ข้อ 47)
- 33과 -(으)ㄹ: อนาคตขยายนาม (ข้อ 56 — สรุปตารางทั้ง 3 เวลาร่วมกับ -는)
- 35과 -는 것 (ข้อ 59): 단어를 외우는 것이 힘들었어요 ในบทนี้เป็นตัวอย่างแรก
- 28과 중에서: 활동 หน้า 275 ใช้ 고향 중에서 ก่อนเรียนจริง

> [!SUMMARY] สรุปท้ายบท
> - -아/어/여지다 ใช้กับคำคุณศัพท์บอกว่าสภาพเปลี่ยน: ㅏ/ㅗ → -아지다 · สระอื่น → -어지다 · 하다 → -해지다
> - ㅂ → 워 (추워졌어요) และ ㅡ ตกก่อน 아/어 (예뻐졌어요) ส่วน -졌어요 = เปลี่ยนไปแล้ว และ -져요 = ปัจจุบัน
> - V-는 ขยายนามด้วยกริยาปัจจุบัน ต่อรากตรง ๆ ราก ㄹ ตัด ㄹ (만드는 · 사는) และ 있다/없다 → 있는/없는
> - คำคุณศัพท์ใช้ -(으)ㄴ ห้ามใช้ -는 (매운 ✓ · 맵는 ✗) และประธานใน clause ใช้ 이/가 ห้ามใส่ 을/를 ซ้ำ
> - ข้อสอบคาด: ผันตาราง -아/어/여지다 · ต่อสองประโยคด้วย -는 · 읽기 27-2 เป็นบทสนทนา 가/나
