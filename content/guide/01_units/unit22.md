## 22과: 같이 밥 먹으러 갈까요? (ไปกินข้าวด้วยกันไหม?)

> **หลังจบบทนี้ทำอะไรได้**: ชวน/ถามความเห็นด้วย -(으)ㄹ까요? (รับ-ปฏิเสธอย่างสุภาพ) · ถามชนิดของสิ่งของด้วย 무슨 + N · เชื่อมคำคุณศัพท์/กริยาด้วย -고 (…และ…)

**🗣️ คำศัพท์สำคัญ**

| หมวด | คำศัพท์ (ไทย) |
|:---|:---|
| ชวน · นัด | 같이 (ด้วยกัน) · 미안하다 (ขอโทษ) · 약속 (นัด) · 다음 (ครั้งหน้า) · 준비하다 (เตรียม) · 괜찮다 (ไม่เป็นไร) |
| อาหาร | 불고기 (พุลโกกิ) · 냉면 (เนงมยอน) · 비빔밥 (บิบิมบับ) · 삼계탕 (ซัมเกทัง) · 삼겹살 (หมูสามชั้น) · 한식집 (ร้านอาหารเกาหลี) |
| สภาพ | 깨끗하다 (สะอาด) · 밝다 (สว่าง) · 맵다 (เผ็ด) · 넓다 (กว้าง) · 친절하다 (ใจดี) · 똑똑하다 (ฉลาด) · 착하다 (นิสัยดี) · 가깝다 (ใกล้) |
| สถานที่ · อื่น ๆ | 경복궁 (พระราชวังคยองบกกุง) · 삼청동 (ซัมช็องดง) · 정문 (ประตูหน้า) · 값 (ราคา) |

*รายการเต็มของศูนย์อยู่ท้ายบท*

**📝 ไวยากรณ์**

1. **V-(으)ㄹ까요?** — "…กันไหม" (ชวนทำด้วยกัน) · "…ดีไหม" (ถามความเห็น) · (ไวยากรณ์ข้อ 33)
   - ราก**ไม่มีตัวสะกด หรือ ㄹ** → **-ㄹ까요?**: 보다 *ดู* → 볼까요? · 마시다 *ดื่ม* → 마실까요? · 가다 → 갈까요? · 만들다 *ทำ* → **만들까요?** (ㄹ ไม่ซ้ำ) / **มีตัวสะกด** → **-을까요?**: 먹다 → 먹을까요? · 찍다 → 찍을까요? · 앉다 → 앉을까요?
   - มักมี 같이/함께: 같이 밥 먹으러 갈까요? *(ไปกินข้าวด้วยกันไหม)* · 영화를 볼까요? *(ดูหนังกันไหม)* · 우리 어디에서 사진을 찍을까요? *({n:เรา}{v:ถ่ายรูป}กัน{q:ที่ไหน}{e:ดี})* · 언제 파티를 할까요? *({v:จัด}{n:ปาร์ตี้}{q:เมื่อไหร่}{e:ดี})* · 무엇을 준비할까요? *({v:เตรียม}{q:อะไร}{e:ดี})* · 우리 몇 시에 만날까요? *({v:นัด}กัน{q:กี่โมง}{e:ดี})*
   - **รับ**: 네, 좋아요 / 네, -아/어요 (같이 가요 · 같이 먹어요 · 저기 나무 옆에서 찍어요) · **ปฏิเสธ**: ไม่พูด 아니요 ตรง ๆ → ขอโทษ + เหตุผล + นัดครั้งหน้า: 미안해요. 약속이 있어요. → 그럼 다음에 같이 봐요 *({v:ขอโทษ} {v:มี}{n:นัด} — {a:งั้น}{n:ครั้งหน้า}{v:ไปดู}{a:ด้วยกัน})* · 미안해요. 벌써 밥을 먹었어요. 다음에 같이 가요 *({v:ขอโทษ} {v:กิน}{n:ข้าว}{e:แล้ว} {n:ครั้งหน้า}{v:ไป}{a:ด้วยกัน})*
   - ฝึกปฏิเสธ (ตำรา หน้า 225 — ชวน / เหตุผลที่ปฏิเสธ): 영화를 보다 / 약속이 있다 *({v:ดู}{n:หนัง} / {v:มี}{n:นัด})* · 쇼핑을 하다 / 숙제가 많다 *({n:ช้อปปิ้ง} / {n:การบ้าน}{v:เยอะ})* · 운동하다 / 시간이 없다 *(ออกกำลังกาย / ไม่มีเวลา)* · 도서관에 가다 / 친구를 만나다 *(ไปห้องสมุด / พบเพื่อน)* · 산에 가다 / 고향에 가다 *(ไปภูเขา / กลับบ้านเกิด)* · 저녁을 먹다 / 좀 바쁘다 *({v:กิน}{n:มื้อเย็น} / {a:ค่อนข้าง}{v:ยุ่ง})*
   - เสนอเวลา: 언제 파티를 할까요? → 내일 오후 2시가 어때요? → 미안해요. 2시에는 약속이 있어요. 5시가 어때요? → 좋아요. 그럼 5시에 해요 *(เสนอเวลาด้วย …가 어때요? — ถ้าไม่ว่างก็เสนอใหม่)*
   - ⚠️ ★ ราก ㄹ: 만들**을**까요 ✗ → 만들까요 · ราก**มีตัวสะกด**ต้องมี **으**: 먹**을**까요 · 찍**을**까요 (อย่าตัด 으 — ตระกูลเดียวกับ 씻러 · 읽세요 ที่เคยพลาด) · ตอบรับห้ามใช้รูปคำถามซ้ำ: 네, 갈까요 ✗ → 네, 가요 · 갈까요? (ชวนด้วยกัน) ≠ 갈 거예요? (ถามแผนของอีกฝ่าย — ไวยากรณ์ข้อ 28)
2. **무슨 + N** — "N อะไร / N ชนิดไหน" (ถามประเภทของสิ่งของ) · (ไวยากรณ์ข้อ 34)
   - วางหน้านามเสมอ: 무슨 음식을 좋아해요? → 불고기를 좋아해요 *({v:ชอบ}{n:อาหาร}{q:อะไร} — {v:ชอบ}{n:พุลโกกิ})* · 무슨 영화를 볼까요? → 공포 영화를 봐요 *({v:ดู}{n:หนัง}{q:อะไร}{e:ดี} — {n:หนังสยองขวัญ})* · 요즘 무슨 책을 읽어요? → 소설책을 읽어요 *({a:ช่วงนี้}{v:อ่าน}{n:หนังสือ}{q:อะไร} — {n:นิยาย})* · 무슨 색깔 옷을 샀어요? → 빨간색 옷을 샀어요 *({v:ซื้อ}{n:เสื้อสี}{q:อะไร} — {n:สีแดง})* · 이 단어가 무슨 뜻인지 잘 모르겠어요 *(ไม่รู้ว่าคำนี้แปลว่าอะไร)*
   - ดูภาพตอบ (ตำรา หน้า 227 ข้อ 6 — ตารางสอบ 쓰기 9:00 · 듣기 10:00 · 읽기 11:00): 내일 10시에 무슨 시험을 봐요? → 듣기 시험을 봐요 *({a:พรุ่งนี้} {m:10 โมง}{v:สอบ}{q:อะไร} — {v:สอบ}{n:ฟัง} · ตัวอย่างตอบ)* · ศัพท์สอบ: 시험 *(การสอบ)* · 쓰기 *({n:เขียน})* · 듣기 *({n:ฟัง})* · 읽기 *({n:อ่าน})*
   - หมวดในตำรา (หน้า 226–227): 음식 *(อาหาร)* 삼계탕 · 갈비찜 *(ซี่โครงตุ๋น)* · 비빔밥 / 영화 *(หนัง)* 액션 · 공포 *(สยองขวัญ)* · 코미디 *(ตลก)* / 운동 *(กีฬา)* 축구 *(ฟุตบอล)* · 농구 *(บาสเกตบอล)* · 수영 *({n:ว่ายน้ำ})* / 음악 *(ดนตรี)* 케이팝 · 클래식 · 힙합 / 색깔 *(สี)* 하얀색 *(ขาว)* · 빨간색 *(แดง)* · 파란색 *(น้ำเงิน)*
   - 📽️ สไลด์อาจารย์ (สมุดศัพท์ภาพ 22과 หน้า 82–83): **음식** 불고기 · 냉면 · 비빔밥 · 된장찌개 *(ซุปเต้าเจี้ยว)* · 삼계탕 · 김밥 · 떡볶이 *(ต๊อกบกกี)* · 팥빙수 *(น้ำแข็งไสถั่วแดง)* · 미역국 *(ซุปสาหร่าย)* / **과일** 사과 *(แอปเปิล)* · 수박 *(แตงโม)* · 포도 *(องุ่น)* · 감 *(ลูกพลับ)* · 딸기 *(สตรอว์เบอร์รี)* · 배 *(ลูกแพร์)* · 바나나 *(กล้วย)* · 레몬 *(เลมอน)* / **색깔** 빨간색 · 분홍색 *(ชมพู)* · 노란색 *(เหลือง)* · 녹색 = 초록색 *(เขียว)* · 파란색 · 남색 *({n:น้ำเงินเข้ม})* · 보라색 *(ม่วง)* · 갈색 *(น้ำตาล)* · 하얀색 · 까만색 *(ดำ)* / **동물** 개 *(สุนัข)* · 고양이 *(แมว)* · 토끼 *(กระต่าย)* · 쥐 *(หนู)* · 원숭이 *(ลิง)* · 판다 *(แพนด้า)* · 곰 *(หมี)* · 사자 *(สิงโต)*
   - ⚠️ ถามชนิดของสิ่งของ = **무슨** · ถามลักษณะ/สภาพ = **어떤**: 어떤 사람을 좋아해요? → 똑똑하고 착한 사람을 좋아해요 *({v:ชอบ}{n:คน}{q:แบบไหน} — {n:คน}{v:ฉลาด}{e:และ}{v:นิสัยดี})* · ถามประเทศ = 어느 나라 (ไม่ใช้ 무슨)
3. **A/V-고** — "…และ…" เชื่อมสองสภาพหรือสองการกระทำ · (ไวยากรณ์ข้อ 34)
   - ตัด 다 + **-고** (ไม่ดูตัวสะกด · ㅂ ไม่เปลี่ยน): 깨끗하다 → 깨끗하고 · 맵다 → 맵고 · 많다 → 많고
   - คุณศัพท์ + คุณศัพท์: 동대문 시장은 어때요? → 물건이 많고 싸요 *({n:ตลาดตงแดมุน}{q:เป็นยังไง} — {n:ของ}{v:เยอะ}{e:และ}{v:ถูก})* · 이 교실은 깨끗하고 밝아요 *({n:ห้องนี้}{v:สะอาด}{e:และ}{v:สว่าง})* · 불고기는 맵지 않고 맛있어요 *({n:บุลโกกิ}{x:ไม่}{v:เผ็ด}{e:และ}{v:อร่อย})* · 이 가방은 예쁘고 값도 싸요 *({n:กระเป๋านี้}{v:สวย}{e:และ}{n:ราคา}{p:ก็}{v:ถูก})*
   - กริยา + กริยา: 일요일에는 집에서 청소도 하고 요리도 합니다 *({n:วันอาทิตย์}{p:ที่}{n:บ้าน}{p:ทั้ง}{v:ทำความสะอาด}{e:และ}{v:ทำ}{n:อาหาร})* · 학교에서 한국어를 공부하고 친구도 만나요 *({p:ที่}{n:โรงเรียน}{v:เรียน}{n:เกาหลี}{e:และ}{v:พบ}{n:เพื่อน}{p:ด้วย})* · 저는 숙제를 하고 동생은 피아노를 쳐요 *({n:ฉัน}{v:ทำ}{n:การบ้าน}{e:และ}{n:น้อง}{v:เล่น}{n:เปียโน})*
   - ทั้ง…ทั้ง… (N도 …고 N도 …): 불고기도 맛있고 냉면도 맛있어요 *(บุลโกกิก็อร่อย เนงมยอนก็อร่อย)* · 경복궁도 가깝고 한식집도 많아요 *({v:ใกล้}{n:คยองบกกุง}{e:และ}{v:มี}{n:ร้านอาหารเกาหลี}{v:เยอะ})*
   - เทียบสองคน (เวิร์กบุ๊ก H): 마키 씨는 일본 사람**이고** 장핑 씨는 중국 사람이에요 *(นาม + 이다 → 이고 — พบในเวิร์กบุ๊ก ตำราอธิบายเฉพาะกริยา/คำคุณศัพท์)*
   - เรื่องกาล: ตัวอย่างในตำราใส่กาลที่**กริยาท้ายประโยค** (문이 많고 예뻤어요 — 경복궁은 어땠어요? ใน 읽기 22-2) แต่ 보기 ของเวิร์กบุ๊ก H ใส่กาลที่ตัวหน้าด้วย: 마키 씨는 세 달 전에 **왔고** 장핑 씨는 한 달 전에 왔어요 → **ทำตาม 보기 ของโจทย์** อย่าถือเป็นกฎตายตัว (ยังไม่มีข้อสอบจริงชี้ขาด)
   - ⚠️ นาม + นาม ใช้ **하고/와/과**: 불고기하고 냉면 ✓ · 불고기고 냉면 ✗ · -고 (และ) ≠ -고 있다 (กำลัง — 21과)
