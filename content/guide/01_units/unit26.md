## 26과: 제주도는 서울보다 따뜻해요 (เชจูอุ่นกว่าโซล)

> **หลังจบบทนี้ทำอะไรได้**: เปรียบเทียบสองสิ่งด้วย N보다 (+ 더) · เดา/คาดคะเนจากสิ่งที่เห็นด้วย -겠- (곧 비가 오겠어요 · 재미있었겠어요) · ถามตอบเรื่องอากาศและชีวิตในเกาหลี

> [!WARNING]
> **26과 มีสแกนแค่ 3 หน้า (ตำรา หน้า 262–264)**: 준비 1 보다 + 연습 1 · 연습 2–3 · 준비 2 -겠-² (กล่องไวยากรณ์ครบทั้งสองข้อ) — **หน้า 준비 2 연습 2–3 · 대화 · 활동 · 읽기 ยังไม่มีในคลัง** ส่วน 대화 26-1 และ 읽기 26-2 ด้านล่างถอดจากไฟล์เสียงตำรา (26-1/26-2/26-3.mp3, Whisper ~95 % — ตรวจกับคำแปลอังกฤษและเฉลยในภาคผนวก; สะกดบางคำอาจต่างจากตำรา) · รายการศัพท์ขอบหน้าของหน้าที่ขาดไม่มี

**🗣️ คำศัพท์สำคัญ**

| หมวด | คำศัพท์ (ไทย) |
|:---|:---|
| อากาศ | 따뜻하다 (อุ่น) · 맑다 (ท้องฟ้าแจ่มใส) · 흐리다 (ครึ้ม เมฆมาก) · 곧 (อีกไม่นาน) · 비 (ฝน) · 기온 (อุณหภูมิอากาศ) · 영하 (ต่ำกว่าศูนย์) |
| เปรียบเทียบ · เวลา | 더 (…กว่า ยิ่ง…) · 이번 주 (สัปดาห์นี้) · 지난주 (สัปดาห์ที่แล้ว) · 올해 (ปีนี้) · 작년 (ปีที่แล้ว) |
| อื่น ๆ | 말하기 (การพูด) · 세일 (ลดราคา) · 짧다 (สั้น) · 비싸다 (แพง) · 눈 (หิมะ) · 스키 (สกี) |

*รายการเต็มของศูนย์อยู่ท้ายบท*

**📝 ไวยากรณ์**

1. **N보다** — "…กว่า…" (นามหลัง 보다 คือ**ตัวเทียบ**) · (ไวยากรณ์ข้อ 41)

    | ส่วน | หน้าที่ | ตัวอย่าง |
    |:---|:---|:---|
    | A이/가 | ตัวที่ "มากกว่า" (ประธาน) | 제주도**가** · 올해**가** |
    | B보다 | ตัวเทียบ (ติดนาม ไม่เว้นวรรค) | 서울**보다** · 작년**보다** |
    | (더) + V/A | คำคุณศัพท์/กริยา (더 = เน้น ตัดได้) | (더) 따뜻해요 · (더) 추워요 |

   - ต่อท้ายนามที่เป็นตัวเทียบ ไม่ดูตัวสะกด ไม่เว้นวรรค: 서울**보다** · 작년**보다** · 듣기**보다** · โครงสร้าง **A가/이 B보다 + คำคุณศัพท์/กริยา** (A คือตัวที่ "มากกว่า"): 제주도가 서울보다 따뜻해요 *(เชจูอุ่นกว่าโซล)*
   - **더** (…กว่า) มักมาด้วยเพื่อเน้น และตัดได้: 올해가 작년보다 더 추워요 *(ปีนี้หนาวกว่าปีที่แล้ว)* · 말하기가 듣기보다 어려워요 *(การพูดยากกว่าการฟัง)* · 형보다 내가 더 많이 먹어요 *(ฉันกินมากกว่าพี่ชาย — สลับเป็น B보다 A가 ได้)*
   - ตำรา 연습 1 (หน้า 262 — แบบ "A > B / คำคุณศัพท์" และ "A < B"): 제주도 > 서울 / 따뜻하다 → 제주도가 서울보다 따뜻해요 *(เชจูอุ่นกว่าโซล)* · 러시아 > 일본 / 춥다 → 러시아가 일본보다 추워요 *(รัสเซียหนาวกว่าญี่ปุ่น)* · 사우디아라비아 > 베트남 / 덥다 → 사우디아라비아가 베트남보다 더워요 *(ซาอุฯ ร้อนกว่าเวียดนาม)* · 부산 < 경주 / 맑다 → 경주가 부산보다 맑아요 *(คย็องจูแจ่มใสกว่าปูซาน — เครื่องหมาย < แปลว่าตัวแรกน้อยกว่า ตัวหลังต้องเป็นประธาน)* · 지난주 < 이번 주 / 시원하다 → 이번 주가 지난주보다 시원해요 *(สัปดาห์นี้เย็นกว่าสัปดาห์ที่แล้ว)* · 어제 < 오늘 / 흐리다 → 오늘이 어제보다 흐려요 *(วันนี้ครึ้มกว่าเมื่อวาน)* *(ตำรามีแต่โจทย์ — ประโยคตอบเป็นตัวอย่างตามแบบของตำรา)*
   - ถาม–ตอบดูภาพ (연습 2, หน้า 263): 누가 더 커요? → 압둘라 씨가 마키 씨보다 커요 *(ใครสูงกว่า — อับดุลลาสูงกว่ามากิ · ตัวอย่างในตำรา)* · 무엇이 더 많아요? (커피 / 주스) → 커피가 주스보다 많아요 *(🖼️ กาแฟหลายแก้ว · น้ำส้ม 3 ขวด)* · 누구 집이 더 작아요? (지훈 씨 집 / 윤아 씨 집) → 윤아 씨 집이 지훈 씨 집보다 작아요 *(🖼️ บ้านหลังใหญ่ vs หลังเล็ก)* · 무엇이 더 비싸요? (우유 700원 / 빵 1,000원) → 빵이 우유보다 비싸요 · 누구 머리가 더 짧아요? (유리 / 미나) → 미나 씨 머리가 유리 씨 머리보다 짧아요 *(🖼️ ผมยาว vs ผมสั้น — ตัวอย่างตอบ)*
   - ถามชีวิตในเกาหลี (연습 3): 언제 더 바빠요? ☑ 평일 / 주말 · 어디에 사람이 많아요? 동대문시장 / 명동 · 뭐가 더 매워요? 김치찌개 / 라면 · 뭐가 더 어려워요? 말하기 / 쓰기 · 누구하고 더 자주 전화해요? 부모님 / 남자(여자) 친구 *(ตอบเอง — ตำราติ๊ก ☑ ให้ข้อแรกเท่านั้น คือ 평일에 더 바빠요 = วันธรรมดายุ่งกว่า)*
   - ⚠️ ต้องตอบ**ให้ตรงคำถาม**: 누가 → ชื่อคน + 가 · 무엇이/뭐가 → สิ่งของ + 이/가 · 누구 집이 → "ชื่อ 씨 집이" (ไม่ใช่ 윤아 씨가) · 언제 → เวลา + 에 · คำคุณศัพท์ ㅂ ผัน: 춥다 → 추워요 · 덥다 → 더워요 · 어렵다 → 어려워요 · 맵다 → 매워요 (ไวยากรณ์ข้อ 37)
   - ⚠️ 보다 (กว่า) ≠ 보다 (ดู: 영화를 봐요) สะกดเหมือนกัน แต่ **N보다** ติดนามเสมอ · เปรียบเทียบ**สองสิ่ง** = 보다 · "ที่สุดในหลายสิ่ง" = **중에서 제일** (28과 ข้อ 45)
2. **-겠-²** — "คงจะ…" (เดา/คาดคะเนจากสิ่งที่เห็นหรือได้ยิน) · (ไวยากรณ์ข้อ 42 · ต่างจาก -겠- ตั้งใจในข้อ 22)

    | ประเภท | รูป | ตัวอย่าง |
    |:---|:---|:---|
    | เดาปัจจุบัน/อนาคตใกล้ | ราก + **-겠어요** | 맛있겠어요 · 피곤하겠어요 · 비가 오겠어요 |
    | เดาเรื่องอดีต | ราก + **-았/었/였겠어요** | 재미있었겠어요 *(ปีที่แล้วไปเที่ยว → คงสนุก)* |
    | ตั้งใจ (16과 ข้อ 22 — คนละความหมาย) | ราก + -겠습니다 | 열심히 공부하겠습니다 |

   - ต่อท้ายราก**กริยา/คำคุณศัพท์** ไม่ดูตัวสะกด ไม่ต้องใส่ 으: 맛있다 → 맛있겠어요 · 피곤하다 → 피곤하겠어요 · 오다 → 오겠어요 · ตำราบอกว่าการเดามัก "มีเบาะแส" ควบอยู่ด้วย
   - บทสนทนาตั้งต้น: 날씨가 많이 흐리네요 → 그래요. 곧 비가 오겠어요 *(อากาศครึ้มมากเลยนะ — ใช่ เดี๋ยวฝนคงตก)* · 가: 하늘이 흐려요 → 나: 곧 비가 오겠어요 *(ฟ้าครึ้ม → เดี๋ยวฝนคงตก)*
   - **เดาเรื่องในอดีต** = -았/었/였- + -겠- → **-았겠/었겠/였겠**: 가: 작년에 미국 여행을 했어요 → 나: 재미있었겠어요 *(ปีที่แล้วไปเที่ยวอเมริกา → คงสนุกแน่ ๆ)* · 가: 5시간 동안 청소를 했어요 → 나: 피곤하겠어요 *(ทำความสะอาด 5 ชั่วโมง → คงเหนื่อย)*
   - ตำรา 연습 1 (หน้า 264): 이 불고기 좀 드세요. → 맛있겠어요 *(เชิญทานพุลโกกิหน่อย → คงอร่อย)* · 남자 친구한테서 편지를 받았어요. → 기분이 좋겠어요 *(ได้จดหมายจากแฟน → คงอารมณ์ดี)* · 지난 일요일에 기숙사 청소를 했어요. → 기숙사가 깨끗하겠어요 *(ทำความสะอาดหอเมื่ออาทิตย์ที่แล้ว → หอคงสะอาด)* · 주말부터 백화점에서 세일을 해요. → 주말에 사람이 많겠어요 *(ห้างเซลตั้งแต่สุดสัปดาห์ → คนคงเยอะ)* · 아침, 점심, 저녁 모두 안 먹었어요. → 배가 고프겠어요 *(ไม่ได้กินทั้งเช้ากลางวันเย็น → คงหิว)* *(คำตอบ = ส่วนที่ตำราให้ไว้หลัง "/" แปลงเป็น -겠어요)*
   - ⚠️ **-겠- มี 2 ความหมาย**: ตั้งใจ/จะ (16과: 마시겠습니다 · 열심히 공부하겠습니다 — ผู้พูดเป็นประธาน) ↔ เดา (บทนี้: 맛있겠어요 · 춥겠어요 — พูดถึงคนอื่น/สภาพ/สิ่งที่กำลังจะเกิด) · อดีตต้องมี 았/었: 재미있겠어요 ✗ → 재미있었겠어요 (เรื่องที่จบไปแล้ว) · -겠- ≠ -(으)ㄹ 거예요 (แผนการ — ไวยากรณ์ข้อ 28)

**💬 대화 26-1** *(หน้าสแกนไม่มี — ถอดจากเสียง 26-1.mp3; บทพูดของ 압둘라 กับ 이리나 ตามภาคผนวก Lesson 26)*

> 압둘라: 오늘 정말 춥네요. *(วันนี้หนาวจริง ๆ นะ)*
>
> 이리나: 러시아는 더 추워요. *(รัสเซียหนาวกว่านะ)*
>
> 압둘라: 그래요? 러시아가 한국보다 더 추워요? *(จริงเหรอ รัสเซียหนาวกว่าเกาหลีอีกเหรอ)*
>
> 이리나: 네, 보통 겨울 기온이 영하 40도예요. *(ใช่ ปกติอุณหภูมิหน้าหนาวติดลบ 40 องศา)*
>
> 압둘라: 춥겠어요. *(คงหนาวมากเลย)*
>
> 이리나: 사우디아라비아는 어때요? *(แล้วซาอุดีอาระเบียล่ะเป็นยังไง)*
>
> 압둘라: 한국보다 따뜻해요. *(อุ่นกว่าเกาหลี — ภาคผนวกแปลว่า "หน้าหนาวที่นั่นอุ่นกว่าเกาหลี")*

**📖 읽기 26-2** *(หน้า 읽기 ไม่มีในคลัง — ถอดจากเสียง 26-2.mp3 · เป็นไดอารี่ของนักเรียนเวียดนาม วันที่ 12월 29일 월요일 อากาศ: หิมะ)*

> 오늘은 아침부터 눈이 왔어요. 제 고향 베트남에는 눈이 오지 않아요. 그래서 한국에서 눈을 처음 봤어요. *(วันนี้หิมะตกตั้งแต่เช้า บ้านเกิดฉันเวียดนามหิมะไม่ตก เลยเห็นหิมะครั้งแรกที่เกาหลี)*
>
> 수업이 끝나고 우리 반 학생들과 같이 운동장으로 나갔어요. 운동장에서 사진을 많이 찍었어요. 우리는 눈사람도 만들었어요. 좀 춥고 힘들었지만 아주 재미있었어요. *(เลิกเรียนแล้วออกไปสนามกับเพื่อนร่วมห้อง ถ่ายรูปเยอะ ปั้นตุ๊กตาหิมะด้วย หนาวและเหนื่อยหน่อยแต่สนุกมาก)*
>
> 저녁에는 오후보다 눈이 더 많이 왔어요. 학생 식당에서 저녁을 먹고 기숙사에서 고향 친구하고 채팅을 했어요. 그 친구도 눈을 보고 싶어 해요. 그래서 고향 친구에게 눈 사진을 보냈어요. *(ตอนเย็นหิมะตกหนักกว่าตอนบ่าย กินข้าวเย็นที่โรงอาหารแล้วแชตกับเพื่อนบ้านเกิดที่หอ เพื่อนก็อยากเห็นหิมะ เลยส่งรูปหิมะให้)*
>
> 이번 주말에는 스키를 타러 갈 거예요. 주말에는 스키장에 사람이 많겠지만 재미있을 거예요. 고향 친구에게 스키장 사진도 보낼 거예요. 고향 친구가 스키장에 가고 싶어 하겠네요. *(สุดสัปดาห์นี้จะไปเล่นสกี ลานสกีคงมีคนเยอะแต่คงสนุก จะส่งรูปลานสกีให้เพื่อนด้วย เพื่อนคงอยากไปลานสกีสินะ)*

- ไวยากรณ์ในบท: 오후**보다** 눈이 **더** (ข้อ 41) · 사람이 많**겠**지만 · 가고 싶어 하**겠**네요 (ข้อ 42 + -네요 ข้อ 30 + 싶어 하다 ข้อ 38) · 타러 갈 거예요 (ข้อ 26 + 28)
- เฉลยภาคผนวก **가**: 1. 아침부터 눈이 왔어요 · 2. 수업이 끝나고 반 학생들과 운동장에 나갔어요 + 눈길을 걷고 사진도 찍고 눈사람도 만들었어요 · 3. 스키를 타러 갈 거예요 *(1. หิมะตกตั้งแต่เช้า · 2. เลิกเรียนออกสนามกับเพื่อน เดินบนทางหิมะ ถ่ายรูป ปั้นตุ๊กตาหิมะ · 3. จะไปเล่นสกี)* · **나** (O/X): 1. ○ 2. ○ 3. × *(ตัวประโยคโจทย์ 나 ไม่อยู่ในคลัง)*
- ตำรา 26-3 (ฟังแล้วอ่านตาม — เสียงมี 2 ประโยค): 수업이 끝나고 우리 반 학생들과 같이 운동장으로 나갔어요 · 주말에는 스키장에 사람이 많겠지만 재미있을 거예요 *(ส่วนที่ขีดเส้นใต้ในตำราไม่ทราบ)*

> - ★ ตอบผิดคำถาม: 누구 집이 더 작아요? / 무엇이 더 비싸요? ต้องตอบ "ชื่อ + (집)이/가 + B보다 + คำคุณศัพท์" — ตระกูลเดียวกับ 언제 → 가족을 만날 거예요 ที่เคยเสียคะแนน
> - ★ สลับตัวเทียบ (A/B กลับด้าน) เหมือนคำบอกตำแหน่ง 앞/뒤 ที่เคยกลับจุดอ้างอิง: **ตัวหลัง 보다 = ตัวที่แพ้** ตัวประธาน (이/가) = ตัวที่ชนะ
> - ★ ㅈ/ㅊ และ ㅐ/ㅔ ในคำของบท: 짧아요 · 맑아요 · 따뜻해요 · 세일 (ㅔ) ↔ 새 (ㅐ) · 개 (ㅐ) · 태국 (ไม่ใช่ 테국)
> - ㅂ ผันผิด: 추워요 · 더워요 · 어려워요 · 매워요 (ไม่ใช่ 춥어요 · 덥어요) · ㅡ ตกก่อน 아/어: 바쁘다 → 바빠요 (ไม่ใช่ 바쁘어요)
> - -겠어요 กับอดีต: 재미있겠어요 ✗ → 재미있었겠어요 · อย่าใช้ -겠- เดาแทน -(으)ㄹ 거예요 (แผนของตัวเอง)
