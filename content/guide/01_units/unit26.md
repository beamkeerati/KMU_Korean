## 26과 · 제주도는 서울보다 따뜻해요 (เชจูอุ่นกว่าโซล)

> [!INTRO] บทนี้ว่าด้วยอะไร
> บทที่ 26 ว่าด้วยเรื่องอากาศและชีวิตในเกาหลี และเป็นบทแรกของหัวข้อ 날씨와 계절 (อากาศและฤดูกาล บท 26–29) ตามสารบัญตำรา หน้าที่ภาษาของบทคือ 비교하기 (เปรียบเทียบ) กับ 추측하기 (เดา) ตัวละครคุยกันว่าที่ไหนหนาวกว่ากัน (대화 26-1 อับดุลลากับอีรีนาที่ป้ายรถเมล์) และนักเรียนเวียดนามเขียนไดอารี่ถึงวันที่ได้เห็นหิมะครั้งแรก (읽기 26-2 ไดอารี่ของทุย)
>
> ไวยากรณ์ใหม่มี 2 เรื่อง:
>
> 1. **N보다** — "…กว่า…" ติดท้ายนามที่เป็นตัวเทียบ (제주도가 서울보다 따뜻해요) ภาษาไทยวางตัวเทียบไว้หลังคำคุณศัพท์ (อุ่นกว่าโซล) แต่ภาษาเกาหลีวางไว้ก่อนคำคุณศัพท์และติด 보다 (서울보다 따뜻해요)
> 2. **-겠-** ความหมายที่สอง — "คงจะ…" ใช้เดาหรือคาดคะเนจากสิ่งที่เห็นหรือได้ยิน (곧 비가 오겠어요 · 재미있었겠어요) ต่างจาก -겠- ที่แปลว่า "ตั้งใจ/จะ" ซึ่งเรียนไปแล้วในบท 16 (ข้อ 22)
>
> จบบทแล้วจะเปรียบเทียบสองสิ่งได้ เดาจากสิ่งที่เห็นได้ ถามตอบเรื่องอากาศและชีวิตในเกาหลีได้ และคุยโทรศัพท์เทียบอากาศเกาหลีกับบ้านเกิดได้ (활동 หน้า 267)
>
> จุดที่คนไทยงงบ่อย: สลับตัวเทียบจนประโยคกลับด้าน ตอบไม่ตรงคำถาม (누구 집이 → ต้องตอบเป็นชื่อบ้านของใคร) และใช้ -겠- ผิดความหมายระหว่าง "ตั้งใจ" กับ "เดา"

### 🗣️ คำศัพท์ที่ต้องรู้ก่อน

คำศัพท์ของบทนี้มี 3 กลุ่ม ได้แก่ คำเกี่ยวกับอากาศที่ใช้ในบทสนทนาและบทอ่าน คำสำหรับเปรียบเทียบ บอกเวลาและฤดูกาล และคำอื่น ๆ ที่ใช้ในแบบฝึก ตารางนี้คัดเฉพาะคำที่ต้องรู้เพื่ออ่านบท

#### อากาศ

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|
| 따뜻하다 | อุ่น | 맑다 | ท้องฟ้าแจ่มใส |
| 흐리다 | ครึ้ม เมฆมาก | 곧 | อีกไม่นาน |
| 비 | ฝน | 기온 | อุณหภูมิอากาศ |
| 영하 | ต่ำกว่าศูนย์ | 도 | องศา |
| 쌀쌀하다 | หนาวเย็นนิด ๆ (ลมเย็น) | | |

#### เปรียบเทียบ เวลา และฤดูกาล

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|
| 더 | …กว่า ยิ่ง… | 이번 주 | สัปดาห์นี้ |
| 지난주 | สัปดาห์ที่แล้ว | 올해 | ปีนี้ |
| 작년 | ปีที่แล้ว | 보통 | ปกติ โดยทั่วไป |
| 겨울 | ฤดูหนาว | 여름 | ฤดูร้อน |
| 가을 | ฤดูใบไม้ร่วง | | |

#### อื่น ๆ

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|
| 말하기 | การพูด | 세일 | ลดราคา |
| 짧다 | สั้น | 비싸다 | แพง |
| 눈 | หิมะ | 스키 | สกี |
| 기분 | อารมณ์ ความรู้สึก | 행복하다 | มีความสุข |
| 시간 | เวลา ชั่วโมง | 끝나다 | จบ เสร็จสิ้น |

*รายการเต็มของศูนย์อยู่ท้ายบท*

### 📝 ไวยากรณ์: N보다 — "…กว่า…" (ไวยากรณ์ข้อ 41)

ตอนนี้ว่าด้วยการเปรียบเทียบสองสิ่ง นามที่อยู่หน้า 보다 คือ**ตัวเทียบ** ส่วนสิ่งที่ "มากกว่า" เป็นประธานของประโยคและใช้ 이/가 ส่วน 보다 ต่อท้ายนามโดยไม่ดูตัวสะกดและไม่เว้นวรรค เช่น 서울**보다** · 작년**보다** · 듣기**보다**

#### รูปแบบ

โครงประโยคคือ **A가/이 B보다 + คำคุณศัพท์/กริยา** โดย A คือตัวที่ "มากกว่า" ตัวอย่างเช่น 제주도가 서울보다 따뜻해요 *(เชจูอุ่นกว่าโซล)*

| ส่วน | หน้าที่ | ตัวอย่าง |
|:---|:---|:---|
| A이/가 | ตัวที่ "มากกว่า" (ประธาน) | 제주도**가** · 올해**가** |
| B보다 | ตัวเทียบ (ติดนาม ไม่เว้นวรรค) | 서울**보다** · 작년**보다** |
| (더) + V/A | คำคุณศัพท์/กริยา (더 = เน้น ตัดได้) | (더) 따뜻해요 · (더) 추워요 |

#### บทสนทนาตั้งต้น (준비 1 หน้า 262)

ตำราเริ่มบทด้วยบทสนทนาสั้น ๆ ที่ถามสภาพอากาศแล้วตอบด้วยการเปรียบเทียบ ประโยคตอบนี้เป็นต้นแบบของโครง A가/이 B보다 (หัวข้อบทด้วย)

- 제주도는 날씨가 어때요? *(เชจูอากาศเป็นยังไง)*
- 제주도는 서울보다 따뜻해요. *(เชจูอุ่นกว่าโซล)*

🖼️ *หญิงผมยาวสีน้ำตาล (ซ้าย) เป็นฝ่ายถาม ชายผมสั้นที่สวมแจ็กเก็ตสีน้ำตาล (ขวา) เป็นฝ่ายตอบ*

#### ตัวอย่างประกอบ

ตำราหน้า 262 อธิบายว่า 보다 ต่อท้ายนามเพื่อเปรียบเทียบความต่าง นามที่ติด 보다 คือสิ่งที่ถูกเอามาเทียบ และมักใช้คู่กับคำว่า **더** *(…กว่า)* คำว่า 더 ใช้เพื่อเน้น และตัดออกได้โดยความหมายไม่เปลี่ยน ตัวอย่างในตารางทั้ง 4 ประโยคมาจากหน้า 262 (กรอบตัวอย่างของ 연습 1 และกรอบไวยากรณ์ท้ายหน้า)

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 제주도가 서울보다 따뜻해요. | เชจูอุ่นกว่าโซล | โครงพื้นฐาน |
| 올해가 작년보다 더 추워요. | ปีนี้หนาวกว่าปีที่แล้ว | มี 더 เพื่อเน้น |
| 말하기가 듣기보다 어려워요. | การพูดยากกว่าการฟัง | ไม่มี 더 ก็ได้ |
| 형보다 내가 더 많이 먹어요. | ฉันกินมากกว่าพี่ชาย | สลับเป็น B보다 A가 ได้ |

#### 연습 1 (หน้า 262) — เปรียบเทียบตามเครื่องหมาย

แบบฝึกนี้ให้ดูเครื่องหมาย > หรือ < แล้วแต่งประโยคเปรียบเทียบ เครื่องหมาย < แปลว่าตัวแรกน้อยกว่า ดังนั้นตัวหลังต้องเป็นประธาน ตำรามีแต่โจทย์ 6 ข้อ (ข้อ 1 ตรงกับประโยคในกรอบตัวอย่าง) ประโยคตอบในตารางจึงเป็นตัวอย่างตอบตามแบบของตำรา

| โจทย์ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|
| 제주도 > 서울 / 따뜻하다 | 제주도가 서울보다 따뜻해요. | เชจูอุ่นกว่าโซล |
| 러시아 > 일본 / 춥다 | 러시아가 일본보다 추워요. | รัสเซียหนาวกว่าญี่ปุ่น |
| 사우디아라비아 > 베트남 / 덥다 | 사우디아라비아가 베트남보다 더워요. | ซาอุฯ ร้อนกว่าเวียดนาม |
| 부산 < 경주 / 맑다 | 경주가 부산보다 맑아요. | คย็องจูแจ่มใสกว่าปูซาน |
| 지난주 < 이번 주 / 시원하다 | 이번 주가 지난주보다 시원해요. | สัปดาห์นี้เย็นกว่าสัปดาห์ที่แล้ว |
| 어제 < 오늘 / 흐리다 | 오늘이 어제보다 흐려요. | วันนี้ครึ้มกว่าเมื่อวาน |

#### 연습 2 (หน้า 263) — ถาม-ตอบดูภาพ

แบบฝึกนี้ให้ดูภาพแล้วตอบว่าใครหรืออะไร "มากกว่า" คำสั่งในตำราหน้า 263 คือ 그림을 보고 다음과 같이 묻고 대답해 봅시다. *(ดูภาพแล้วถาม-ตอบตามตัวอย่าง)* ข้อ 1 เป็นตัวอย่างที่ตำราเฉลยไว้ (ขีดเส้นใต้คำตอบ) ส่วนข้อ 2–5 ตำราเว้นบรรทัดให้เขียนเอง คำตอบในตารางจึงเป็นตัวอย่างตอบที่ผู้เขียนคู่มือเติม

| คำถาม | ตัวอย่างตอบ | ความหมาย · ภาพ |
|:---|:---|:---|
| 누가 더 커요? | 압둘라 씨가 마키 씨보다 커요. | ใครสูงกว่า — อับดุลลาสูงกว่ามากิ (ตัวอย่างในตำรา) · 🖼️ ห้องเรียน ชายตัวสูง (อับดุลลา) ยืนข้างหญิงที่เตี้ยกว่า (มากิ) |
| 무엇이 더 많아요? (커피 / 주스) | 커피가 주스보다 많아요. | อะไรมากกว่า — กาแฟมากกว่าน้ำส้ม · 🖼️ กาแฟหลายแก้ว น้ำส้ม 3 ขวด |
| 누구 집이 더 작아요? (지훈 씨 집 / 윤아 씨 집) | 윤아 씨 집이 지훈 씨 집보다 작아요. | บ้านใครเล็กกว่า — บ้านยุนอาเล็กกว่าบ้านจีฮุน · 🖼️ บ้านหลังใหญ่ vs หลังเล็ก |
| 무엇이 더 비싸요? (우유 700원 / 빵 1,000원) | 빵이 우유보다 비싸요. | อะไรแพงกว่า — ขนมปังแพงกว่านม |
| 누구 머리가 더 짧아요? (유리 / 미나) | 미나 씨 머리가 유리 씨 머리보다 짧아요. | ผมใครสั้นกว่า — ผมมินะสั้นกว่าผมยูริ · 🖼️ ผมยาว vs ผมสั้น |

#### 연습 3 (หน้า 263) — ถามเรื่องชีวิตในเกาหลี

แบบฝึกนี้ให้ถามตอบเรื่องของตัวเองโดยเลือกจากสองตัวเลือก คำสั่งในตำราหน้า 263 คือ 한국 생활에 대해서 친구와 묻고 대답해 봅시다. *(ถาม-ตอบกับเพื่อนเรื่องชีวิตในเกาหลี)* ตำราติ๊ก ☑ ให้ข้อแรกเท่านั้น คือ 평일에 더 바빠요 *(วันธรรมดายุ่งกว่า)* ที่เหลือให้ตอบเอง

| คำถาม | ตัวเลือก | ความหมาย |
|:---|:---|:---|
| 언제 더 바빠요? | ☑ 평일 / 주말 | เมื่อไรยุ่งกว่า — วันธรรมดา / สุดสัปดาห์ |
| 어디에 사람이 많아요? | 동대문시장 / 명동 | ที่ไหนคนเยอะ — ตลาดตงแดมุน / เมียงดง |
| 뭐가 더 매워요? | 김치찌개 / 라면 | อะไรเผ็ดกว่า — ซุปกิมจิ / ราเมียน |
| 뭐가 더 어려워요? | 말하기 / 쓰기 | อะไรยากกว่า — การพูด / การเขียน |
| 누구하고 더 자주 전화해요? | 부모님 / 남자(여자) 친구 | โทรหาใครบ่อยกว่า — พ่อแม่ / แฟน |

ตัวอย่างตอบข้างล่างเป็นประโยคเต็มที่ผู้เขียนคู่มือแต่ง ข้อแรกคือคำตอบที่ตำราติ๊กไว้ ส่วนข้ออื่นให้เปลี่ยนตัวเลือกให้ตรงกับความจริงของตัวเอง

- 평일에 더 바빠요. *(วันธรรมดายุ่งกว่า)*
- 명동에 사람이 더 많아요. *(ที่เมียงดงคนเยอะกว่า)*
- 김치찌개가 라면보다 더 매워요. *(ซุปกิมจิเผ็ดกว่าราเมียน)*
- 말하기가 쓰기보다 더 어려워요. *(การพูดยากกว่าการเขียน)*
- 부모님하고 더 자주 전화해요. *(โทรหาพ่อแม่บ่อยกว่า)*

#### ⚠️ ระวัง

- ต้องตอบ**ให้ตรงคำถาม**:
  - 누가 → ชื่อคน + 가
  - 무엇이 / 뭐가 → สิ่งของ + 이/가
  - 누구 집이 → "ชื่อ 씨 집이" (ไม่ใช่ 윤아 씨가)
  - 언제 → เวลา + 에
- คำคุณศัพท์ ㅂ ต้องผัน: 춥다 → 추워요 · 덥다 → 더워요 · 어렵다 → 어려워요 (ไวยากรณ์ข้อ 37)
- 맵다 → 매워요 ก็เป็นกฎ ㅂ ข้อเดียวกัน (ไวยากรณ์ข้อ 37)
- 보다 (กว่า) ≠ 보다 (ดู: 영화를 봐요) สะกดเหมือนกัน แต่ **N보다** ติดนามเสมอ
- เปรียบเทียบ**สองสิ่ง** = 보다 ส่วน "ที่สุดในหลายสิ่ง" = **중에서 제일** (28과 ข้อ 45)

→ เจาะลึก: ไวยากรณ์ข้อ 41 (เล่ม 2)

### 📝 ไวยากรณ์: -겠-² — "คงจะ…" เดาจากสิ่งที่เห็น (ไวยากรณ์ข้อ 42)

ตอนนี้ว่าด้วยความหมายที่สองของ -겠- ซึ่งต่างจาก -겠- แบบ "ตั้งใจ" ที่เรียนในบท 16 (ข้อ 22) ความหมายใหม่คือ "คงจะ…" ใช้เดาหรือคาดคะเนจากสิ่งที่เห็นหรือได้ยิน ตำราบอกว่าการเดามัก "มีเบาะแส" ควบอยู่ด้วย รูปนี้ต่อท้ายราก**กริยาหรือคำคุณศัพท์** ไม่ดูตัวสะกด ไม่ต้องใส่ 으 เช่น 맛있다 → 맛있겠어요 · 피곤하다 → 피곤하겠어요 · 오다 → 오겠어요

#### รูปแบบ

ตารางนี้แยกตามเวลาของเรื่องที่เดา สังเกตว่าเรื่องในอดีตต้องใส่ -았/었/였- ก่อน -겠-

| ประเภท | รูป | ตัวอย่าง |
|:---|:---|:---|
| เดาปัจจุบัน/อนาคตใกล้ | ราก + **-겠어요** | 맛있겠어요 · 피곤하겠어요 · 비가 오겠어요 |
| เดาเรื่องอดีต | ราก + **-았/었/였겠어요** | 재미있었겠어요 *(ปีที่แล้วไปเที่ยว → คงสนุก)* |
| ตั้งใจ (16과 ข้อ 22 — คนละความหมาย) | ราก + -겠습니다 | 열심히 공부하겠습니다 |

#### แสดงวิธีทำ: -겠- คาดเดา (ย่อ · ตารางเต็มในไวยากรณ์ข้อ 42)

กฎ 1 ถ้าเดาสภาพตอนนี้ ต่อ 겠 หลังรากได้เลยโดยไม่ดูตัวสะกด กฎ 2 ถ้าเดาเรื่องที่จบไปแล้ว ให้ใส่ 았/었/였 ก่อนแล้วจึงต่อ 겠 ตารางนี้ใช้คำจากบทนี้

| ราก + 겠어요 | ① เดาเรื่องเมื่อไร | ② ใส่ 았/었/였? | ③ ผล |
|:---|:---|:---|:---|
| 오 + 겠어요 | ยังไม่เกิด | ไม่ใส่ | **오겠어요** |
| 맛있 + 겠어요 | ตอนนี้ | ไม่ใส่ | **맛있겠어요** |
| 덥 + 겠어요 | ตอนนี้ | ไม่ใส่ (ㅂ อยู่ครบ) | **덥겠어요** |
| 피곤하 + 겠어요 | ตอนนี้ | ไม่ใส่ | **피곤하겠어요** |
| 재미있 + 겠어요 | จบแล้ว | ใส่ 었 | **재미있었겠어요** |
| 피곤하 + 겠어요 | จบแล้ว | ใส่ 였 → 했 | **피곤했겠어요** |

#### บทสนทนาตั้งต้น (준비 2 หน้า 264)

ตำราเริ่มจากสถานการณ์ฟ้าครึ้ม ซึ่งเป็นเบาะแสให้เดาว่าฝนจะตก ประโยคแรกใช้ -네요 (ข้อ 30) เพราะเพิ่งสังเกตเห็นว่าฟ้าครึ้ม ส่วนประโยคตอบใช้ -겠- เดาผลที่จะตามมา บรรทัดที่สองคือตัวอย่างในกรอบไวยากรณ์ท้ายหน้า

- 날씨가 많이 흐리네요. → 그래요. 곧 비가 오겠어요. *(อากาศครึ้มมากเลยนะ — ใช่ เดี๋ยวฝนคงตก)*
- 가: 하늘이 흐려요. → 나: 곧 비가 오겠어요. *(ฟ้าครึ้ม → เดี๋ยวฝนคงตก)*

🖼️ *ชายผมบลอนด์สวมเสื้อสีเขียวเข้ม (ซ้าย) บอกว่าอากาศครึ้ม ชายผิวเข้มสวมแจ็กเก็ตสีม่วง (ขวา) ตอบ*

#### เดาเรื่องในอดีต: -았/었/였- + -겠-

เมื่อเรื่องที่เดาจบไปแล้ว ให้ใส่ -았/었/였- แล้วตามด้วย -겠- ได้เป็น **-았겠 / 었겠 / 였겠** ตัวอย่างในกรอบไวยากรณ์ท้ายหน้า 264 มี 2 ประโยคที่ต้องแยกให้ออก 재미있었겠어요 เดาเรื่องที่ผ่านไปแล้ว (ตอนไปเที่ยวคงสนุก) จึงต้องมี -았- ส่วน 피곤하겠어요 เดาสภาพ "ตอนนี้" ของคนพูด (ทำความสะอาดมา 5 ชั่วโมง ตอนนี้คงเหนื่อย) จึงไม่ต้องใส่ -았-

- 가: 작년에 미국 여행을 했어요. → 나: 재미있었겠어요. *(ปีที่แล้วไปเที่ยวอเมริกา → คงสนุกแน่ ๆ)*
- 가: 5시간 동안 청소를 했어요. → 나: 피곤하겠어요. *(ทำความสะอาด 5 ชั่วโมง → คงเหนื่อย)*

#### 연습 1 (หน้า 264) — เดาจากสถานการณ์

แบบฝึกนี้ให้อ่านสถานการณ์แล้วเดาผลด้วย -겠어요 คำตอบคือส่วนที่ตำราให้ไว้หลังเครื่องหมาย "/" แล้วแปลงเป็น -겠어요

| สถานการณ์ | คำตอบ | ความหมาย |
|:---|:---|:---|
| 이 불고기 좀 드세요. | 맛있겠어요. | เชิญทานพุลโกกิหน่อย → คงอร่อย |
| 남자 친구한테서 편지를 받았어요. | 기분이 좋겠어요. | ได้จดหมายจากแฟน → คงอารมณ์ดี |
| 지난 일요일에 기숙사 청소를 했어요. | 기숙사가 깨끗하겠어요. | ทำความสะอาดหอเมื่ออาทิตย์ที่แล้ว → หอคงสะอาด |
| 주말부터 백화점에서 세일을 해요. | 주말에 사람이 많겠어요. | ห้างเซลตั้งแต่สุดสัปดาห์ → คนคงเยอะ |
| 아침, 점심, 저녁 모두 안 먹었어요. | 배가 고프겠어요. | ไม่ได้กินทั้งเช้ากลางวันเย็น → คงหิว |

#### 연습 2 (หน้า 265) — ฟังแล้วเลือกคำตอบด้วย -겠어요

แบบฝึกนี้ให้ฟังคำพูดของเพื่อนแล้วเลือกคำตอบที่เข้ากันจากกรอบ คำสั่งในตำราคือ 친구의 말을 듣고 어울리는 대답을 찾아서 다음과 같이 이야기해 봅시다. *(ฟังที่เพื่อนพูด เลือกคำตอบที่เข้ากัน แล้วคุยตามตัวอย่าง)* ตัวอย่างของตำราคือ 이 떡볶이 좀 드세요. → 맵겠어요. โดยติ๊ก ✓ ไว้ที่ 맵다 ในกรอบ กรอบคำตอบในตำรามี 8 คำดังนี้

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|
| 맛있다 | อร่อย | 시원하다 | เย็นสบาย |
| 춥다 | หนาว | ✓ 맵다 | เผ็ด (ตัวอย่างของตำรา) |
| 기분이 나쁘다 | อารมณ์ไม่ดี | 행복하다 | มีความสุข |
| 바쁘다 | ยุ่ง | 피곤하다 | เหนื่อย |

คำพูดของเพื่อนในตำรามี 6 บัตร (รวมตัวอย่าง) ตำราไม่เฉลยว่าจับคู่กับคำไหน ตารางข้างล่างเป็นตัวอย่างตอบที่ผู้เขียนคู่มือจับคู่เอง จึงเหลือ 춥다 กับ 바쁘다 ที่ไม่ได้ใช้ บัตรใบสุดท้ายตอบ 춥겠어요 ก็เข้าได้ ขึ้นกับฤดู

| คำพูดของเพื่อน | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|
| 이 떡볶이 좀 드세요. | 맵겠어요. | เชิญทานต๊อกบกกีหน่อย — คงเผ็ด (ตัวอย่างของตำรา) |
| 제가 김밥을 만들었어요. | 맛있겠어요. | ฉันทำกิมบับ — คงอร่อย |
| 어제 3시간 잤어요. | 피곤하겠어요. | เมื่อวานนอน 3 ชั่วโมง — คงเหนื่อย |
| 친구가 오늘도 약속 시간에 늦게 왔어요. | 기분이 나쁘겠어요. | เพื่อนมาสายตามนัดอีกแล้ว — คงอารมณ์ไม่ดี |
| 남자 친구가 한국에 왔어요. | 행복하겠어요. | แฟนมาเกาหลี — คงมีความสุข |
| 제 방에 창문이 많아요. | 시원하겠어요. | ห้องมีหน้าต่างเยอะ — คงเย็นสบาย |

รูปผันเมื่อต่อ -겠어요 ไม่ยุ่งยาก เพราะ 겠 ขึ้นต้นด้วยพยัญชนะ ㅂ จึงไม่เปลี่ยนเป็น 워 และ ㅡ ก็ไม่ตก

- 맵다 → 맵겠어요 *(ㅂ คงเดิม ไม่ใช่ ✗ 매우겠어요)*
- 춥다 → 춥겠어요 *(เหมือนกัน ไม่ใช่ ✗ 추우겠어요)*
- 바쁘다 → 바쁘겠어요 *(ㅡ ไม่ตก เทียบกับ 바빠요)*

#### 연습 3 (หน้า 265) — เป็นผู้ประกาศพยากรณ์อากาศ (기상 캐스터)

แบบฝึกนี้ให้เล่นเป็นผู้ประกาศพยากรณ์อากาศ ดูแผนภาพอากาศ 7 วันแล้วพยากรณ์ คำสั่งในตำราคือ 기상 캐스터가 되어 이번 주 날씨가 어떨지 일기예보를 해 봅시다. *(เป็นผู้ประกาศพยากรณ์อากาศ แล้วพยากรณ์ว่าสัปดาห์นี้อากาศจะเป็นอย่างไร)* ตำราพิมพ์ตัวอย่างไว้ 2 ประโยคแล้วเว้น 하지만 …… ให้ผู้เรียนพูดต่อเอง และไม่มีเฉลย

🖼️ *กล่องสีน้ำเงินมี 7 ช่อง เรียงวัน 일 월 화 수 목 금 토 มีคำว่า 오늘 (วันนี้) อยู่เหนือช่องแรก (일) ไอคอนของแต่ละวันตามตารางข้างล่าง*

| วัน | ภาพในตำรา | พูดว่า (ตัวอย่างตอบ) |
|:---|:---|:---|
| 일 (오늘) | ดวงอาทิตย์เต็มดวง | 맑다 |
| 월 | ดวงอาทิตย์กับก้อนเมฆเล็ก | 맑다 → 흐리다 |
| 화 | ร่ม | 비가 오다 |
| 수 | ร่ม | 비가 오다 |
| 목 | ก้อนเมฆกับดวงอาทิตย์ | 흐리다 |
| 금 | ดวงอาทิตย์เต็มดวง | 맑다 |
| 토 | ก้อนเมฆ | 흐리다 |

ตัวอย่างที่ตำราพิมพ์ไว้ในกรอบสีส้มอ่อน ใช้ -ㅂ니다 กับวันนี้ที่เห็นอยู่แล้ว และ -겠습니다 กับวันพรุ่งนี้ที่เดาจากแผนภาพ

> 오늘은 날씨가 맑습니다. 내일 오전까지 날씨가 맑겠습니다. 하지만 …… *(วันนี้อากาศแจ่มใส พรุ่งนี้ช่วงเช้าก็คงแจ่มใส แต่ ……)*

ตัวอย่างตอบข้างล่างผู้เขียนคู่มือแต่งต่อจากแผนภาพ

- 하지만 오후부터 흐리겠습니다. *(แต่ตั้งแต่บ่ายคงครึ้ม)*
- 화요일과 수요일에는 비가 오겠습니다. *(วันอังคารกับวันพุธฝนคงตก)*
- 목요일에는 흐리겠습니다. *(วันพฤหัสคงครึ้ม)*
- 금요일에는 맑겠습니다. *(วันศุกร์คงแจ่มใส)*
- 토요일에는 흐리겠습니다. *(วันเสาร์คงครึ้ม)*

#### ⚠️ ระวัง

- **-겠- มี 2 ความหมาย**: ตั้งใจ/จะ (16과: 마시겠습니다 · 열심히 공부하겠습니다) โดยผู้พูดเป็นประธาน
- อีกความหมายคือเดา (บทนี้: 맛있겠어요 · 춥겠어요) พูดถึงคนอื่น สภาพ หรือสิ่งที่กำลังจะเกิด
- เรื่องที่จบไปแล้วต้องมี 았/었: 재미있겠어요 ✗ → 재미있었겠어요
- -겠- ไม่ใช่ -(으)ㄹ 거예요 ซึ่งใช้บอกแผนการ (ไวยากรณ์ข้อ 28)
- ㅂ ไม่ผันก่อน -겠- เพราะ 겠 ขึ้นต้นด้วยพยัญชนะ: 춥겠어요 · 맵겠어요 ✓ ส่วน 추우겠어요 ✗ (ผัน ㅂ เป็น 워 เฉพาะก่อนสระ — ไวยากรณ์ข้อ 37)

→ เจาะลึก: ไวยากรณ์ข้อ 42 (เล่ม 2)

### 💬 대화 26-1 — วันนี้หนาวจริง ๆ

อับดุลลากับอีรีนายืนรอรถอยู่ที่ป้ายรถเมล์ (버스 정류장) อับดุลลาตัวสั่นเพราะหนาว ส่วนอีรีนาทำหน้าเฉย ๆ เพราะที่รัสเซียหนาวกว่านี้ บทสนทนานี้มีทั้ง N보다 ที่ใช้เปรียบเทียบและ -겠어요 ที่ใช้เดา ข้อความด้านล่างเป็นไปตามที่พิมพ์ในตำราหน้า 266 และตรงกับคำแปลอังกฤษในภาคผนวกหน้า 374

> 압둘라: 오늘 정말 춥네요. *(วันนี้หนาวจริง ๆ นะ)*
>
> 이리나: 러시아는 더 추워요. *(รัสเซียหนาวกว่านะ)*
>
> 압둘라: 그래요? 러시아가 한국보다 더 추워요? *(จริงเหรอ รัสเซียหนาวกว่าเกาหลีอีกเหรอ)*
>
> 이리나: 네. 보통 겨울 기온이 영하 40도예요. *(ใช่ ปกติอุณหภูมิหน้าหนาวติดลบ 40 องศา)*
>
> 압둘라: 춥겠어요. *(คงหนาวมากเลย)*
>
> 이리나: 사우디아라비아는 어때요? *(แล้วซาอุดีอาระเบียล่ะเป็นยังไง)*
>
> 압둘라: 한국보다 따뜻해요. *(อุ่นกว่าเกาหลี)*

🖼️ *ป้ายรถเมล์ (버스 정류장) ชายผิวเข้ม (압둘라) พันผ้าพันคอสีแดง ตัวสั่นจนหายใจเป็นไอ มีเส้นประรอบตัวบอกอาการหนาว ข้าง ๆ หญิงผมบลอนด์ (이리나) สวมแจ็กเก็ตสีฟ้าอ่อนคอขนสีขาว มือล้วงกระเป๋า สีหน้าเฉย ๆ*

#### สังเกตจากบทสนทนา

บทสนทนาใช้ไวยากรณ์ของบทนี้ร่วมกับ -네요 และ ㅂ 불규칙 ที่เรียนมาก่อน ข้อที่น่าสังเกตมีดังนี้

- 오늘 정말 춥네요 — -네요 (ข้อ 30) ใช้อุทานเมื่อเพิ่งรู้สึกว่าหนาว
- 러시아는 더 추워요 — ไม่พูด 한국보다 เพราะรู้กันอยู่ว่าเทียบกับเกาหลี พอถามซ้ำจึงพูดเต็มประโยค (한국보다 더 추워요)
- 러시아가 한국보다 더 추워요? — N보다 + 더 (ข้อ 41)
- 보통 겨울 기온이 영하 40도예요 — 영하 = ต่ำกว่าศูนย์ และ 도 (องศา) อ่านด้วยเลขจีน-เกาหลี คือ 영하 사십 도 (ข้อ 04)
- 춥겠어요 — -겠- แบบเดา (ข้อ 42)
- 춥네요 · 추워요 · 춥겠어요 — ㅂ คงเดิมก่อนพยัญชนะ (-네요 · -겠-) และเปลี่ยนเป็น 워 ก่อนสระ (-아/어요) (ข้อ 37)
- 한국보다 따뜻해요 — ภาคผนวกแปลว่า "หน้าหนาวที่นั่นอุ่นกว่าเกาหลี"

#### 확인해 봅시다 (หน้า 266)

ใต้บทสนทนาตำราให้คำถามตรวจความเข้าใจ 2 ข้อ ตำราไม่พิมพ์เฉลย ตัวอย่างตอบด้านล่างผู้เขียนคู่มือเรียบเรียงจากบทสนทนา

- 오늘 날씨가 어때요? → 정말 추워요. *(วันนี้อากาศเป็นยังไง — หนาวจริง ๆ)*
- 이리나 씨는 왜 춥지 않아요? → 러시아가 한국보다 더 추워요. 보통 겨울 기온이 영하 40도예요. *(ทำไมอีรีนาไม่หนาว — รัสเซียหนาวกว่าเกาหลี ปกติหน้าหนาวติดลบ 40 องศา)*

#### ฝึกสลับ (หน้า 266) — 다음 표현을 사용해서 위와 같이 대화를 만들어 봅시다

คำสั่งในตำราแปลว่า "ใช้สำนวนต่อไปนี้ สร้างบทสนทนาเหมือนข้างบน" ตำราให้ตารางคำ 3 แถว แต่ละแถวมี 5 ช่องเรียงตามลำดับที่ใช้ในบทสนทนา ได้แก่

- ช่อง ① คำคุณศัพท์ที่ใช้ในประโยคแรก (오늘 정말 ＿＿네요)
- ช่อง ② ประเทศที่หนาวหรือร้อนกว่าเกาหลี (＿＿는 더 추워요)
- ช่อง ③ ฤดูกาลกับอุณหภูมิ (보통 ＿＿이 ＿＿예요)
- ช่อง ④ ประเทศที่ถามต่อ (＿＿는 어때요?)
- ช่อง ⑤ คำตอบของประเทศนั้น (한국보다 ＿＿)

| แถว | ช่อง ① ② | ช่อง ③ | ช่อง ④ ⑤ |
|:---|:---|:---|:---|
| 1 | 춥다 · 러시아 | 겨울 기온 / 영하 40도 | 사우디아라비아 · 따뜻하다 |
| 2 | 덥다 · 베트남 | 여름 기온 / 30도 | 몽골 · 시원하다 |
| 3 | 쌀쌀하다 · 몽골 | 가을 기온 / 3도 | 베트남 · 따뜻하다 |

ความหมายของแต่ละแถวคือ

- แถว 1 พูดถึงความหนาว รัสเซียหน้าหนาวติดลบ 40 องศา แล้วถามต่อถึงซาอุดีอาระเบียที่อุ่นกว่าเกาหลี
- แถว 2 พูดถึงความร้อน เวียดนามหน้าร้อน 30 องศา แล้วถามต่อถึงมองโกเลียที่เย็นกว่าเกาหลี
- แถว 3 พูดถึงอากาศเย็นลมหนาว มองโกเลียหน้าใบไม้ร่วง 3 องศา แล้วถามต่อถึงเวียดนามที่อุ่นกว่าเกาหลี

คำคุณศัพท์ในช่อง ① ต้องผันตามตำแหน่งในบทสนทนา ตารางนี้ผู้เขียนคู่มือเติมให้ (เสริม) สังเกตว่า ㅂ ของ 춥다 และ 덥다 คงเดิมก่อน -네요 และ -겠어요 แต่เปลี่ยนเป็น 워 ก่อน -아/어요

| คำ | -네요 (บรรทัดแรก) | -아/어요 (บรรทัดที่ 2–3) | -겠어요 (บรรทัดที่ 5) |
|:---|:---|:---|:---|
| 춥다 | 춥네요 | 추워요 | 춥겠어요 |
| 덥다 | 덥네요 | 더워요 | 덥겠어요 |
| 쌀쌀하다 | 쌀쌀하네요 | 쌀쌀해요 | 쌀쌀하겠어요 |

ช่อง ⑤ ผันเป็น -아/어요 เช่นกัน คือ 따뜻하다 → 따뜻해요 และ 시원하다 → 시원해요

#### 활동 (หน้า 267) — การ์ดอากาศ 2 ชุด

กิจกรรมนี้เล่นเป็นคู่ คนหนึ่งเป็นเพื่อน A ที่อยู่เกาหลี อีกคนเป็นเพื่อน B ที่กลับประเทศไปแล้ว โทรคุยกันเรื่องอากาศ คำสั่งในตำราคือ 한국 날씨와 다른 나라 날씨를 비교해서 이야기해 봅시다. *(เปรียบเทียบอากาศเกาหลีกับประเทศอื่นแล้วคุยกัน)* ตำราให้การ์ดข้อมูล 2 ชุด (4 ใบ) ใบของ A เขียนว่า 한국에 있는 친구 *(เพื่อนที่อยู่เกาหลี)* ใบของ B เขียนว่า 중국 หรือ 베트남에 돌아간 친구 *(เพื่อนที่กลับไปจีนหรือเวียดนาม)* โดย 어제 날씨 คืออากาศเมื่อวาน และ 오늘 날씨 คืออากาศวันนี้

| ชุด | การ์ด | 어제 날씨 | 오늘 날씨 |
|:---|:---|:---|:---|
| 1 | 한국에 있는 친구 A | 맑다, 30도 | 덥다, 35도 |
| 1 | 중국에 돌아간 친구 B | 맑다, 25도 | 덥다, 30도 |
| 2 | 한국에 있는 친구 A | 눈, 영하 1도 | 춥다, 1도 |
| 2 | 베트남에 돌아간 친구 B | 비, 28도 | 덥다, 32도 |

- ชุด 1 เกาหลีกับจีน เมื่อวานแจ่มใสทั้งคู่ (30 กับ 25 องศา) วันนี้ร้อนขึ้นทั้งคู่ (35 กับ 30 องศา)
- ชุด 2 เกาหลีเมื่อวานหิมะตกติดลบ 1 องศา วันนี้หนาว 1 องศา ส่วนเวียดนามเมื่อวานฝนตก 28 องศา วันนี้ร้อน 32 องศา

องศา (도) อ่านด้วยเลขจีน-เกาหลี เช่น 35도 = 삼십오 도 และ 영하 1도 = 영하 일 도 (ไวยากรณ์ข้อ 04)

#### 활동 — กรอบบทสนทนาโทรศัพท์

ตำราให้กรอบบทสนทนาโทรศัพท์ที่เว้นช่องไว้ ให้เติมตามข้อมูลในการ์ดของตัวเอง ○○ คือชื่อของผู้เล่นแต่ละคน ช่องว่างต้องใช้คำคุณศัพท์ที่ผันแล้ว รูปเปรียบเทียบกับ 어제보다 ตัวเลของศา และ -겠어요

> A: 여보세요? *(ฮัลโหล)*
>
> B: 여보세요? 누구세요? *(ฮัลโหล ใครคะ)*
>
> A: ○○ 씨, 저 ○○이에요. *(คุณ ○○ นี่ ○○ นะ)*
>
> B: 아, ○○ 씨 반가워요. 잘 지냈어요? *(อ๋อ คุณ ○○ ดีใจจัง สบายดีไหม)*
>
> A: 네, 잘 지냈어요. 중국은 날씨가 어때요? *(สบายดี ที่จีนอากาศเป็นยังไงบ้าง)*
>
> B: 오늘 날씨가 어제보다 ＿＿＿＿. 한국은 어때요? *(วันนี้อากาศ ＿＿ กว่าเมื่อวาน ที่เกาหลีล่ะเป็นยังไง)*
>
> A: 오늘 날씨가 ＿＿＿＿. 오늘은 ＿＿도예요. *(วันนี้อากาศ ＿＿ วันนี้ ＿＿ องศา)*
>
> B: 여기는 ＿＿도예요. 정말 ＿＿겠어요. *(ที่นี่ ＿＿ องศา ที่นั่นคง ＿＿ จริง ๆ)*

#### 활동 — วิธีเล่น (방법) และตัวอย่างตอบ

ตำราสรุปวิธีเล่นไว้ 4 ข้อ

- (1) 한국에 있는 친구 A와 고향에 돌아간 친구 B로 역할을 나눈다. *(แบ่งบทบาทเป็นเพื่อน A ที่อยู่เกาหลีกับเพื่อน B ที่กลับบ้านเกิดไปแล้ว)*
- (2) A는 한국 날씨, B는 고향 날씨에 대한 내용의 카드를 가진다. *(A ถือการ์ดอากาศเกาหลี B ถือการ์ดอากาศบ้านเกิด)*
- (3) 제시된 카드의 내용을 숙지한다. *(จำข้อมูลในการ์ดที่ได้รับให้ขึ้นใจ)*
- (4) 통화하는 상황을 가정하여 카드의 내용을 바탕으로 날씨에 대해 묻고 대답한다. *(สมมติว่าคุยโทรศัพท์กัน แล้วถามตอบเรื่องอากาศตามข้อมูลในการ์ด)*

ตัวอย่างตอบข้างล่างเติมช่องว่างด้วยการ์ดชุด 1 ตำราไม่เฉลย ใช้ชื่อตัวละครในตำราแทน ○○ และตัวหนาคือส่วนที่เติม ชื่อที่ลงท้ายด้วยสระใช้ 예요 ไม่ใช่ 이에요 (ไวยากรณ์ข้อ 02)

> A: 여보세요? *(ฮัลโหล)*
>
> B: 여보세요? 누구세요? *(ฮัลโหล ใครคะ)*
>
> A: **장핑** 씨, 저 **마키**예요. *(คุณจางผิง ฉันมากิค่ะ)*
>
> B: 아, **마키** 씨 반가워요. 잘 지냈어요? *(อ๋อ คุณมากิ ดีใจจัง สบายดีไหม)*
>
> A: 네, 잘 지냈어요. 중국은 날씨가 어때요? *(สบายดีค่ะ ที่จีนอากาศเป็นยังไงบ้าง)*
>
> B: 오늘 날씨가 어제보다 **더 더워요**. 한국은 어때요? *(วันนี้อากาศร้อนกว่าเมื่อวาน ที่เกาหลีล่ะเป็นยังไง)*
>
> A: 오늘 날씨가 **어제보다 더 더워요**. 오늘은 **35**도예요. *(วันนี้อากาศร้อนกว่าเมื่อวาน วันนี้ 35 องศา)*
>
> B: 여기는 **30**도예요. 정말 **덥**겠어요. *(ที่นี่ 30 องศา ที่นั่นคงร้อนมากเลย)*

### 📖 읽기 26-2 — ไดอารี่วันหิมะตก

บทอ่านเป็น 투이의 일기 (ไดอารี่ของทุย) นักเรียนเวียดนามลงวันที่ 12월 29일 월요일 ช่องอากาศ (날씨) วาดเป็นรูปตุ๊กตาหิมะแทนคำว่าหิมะ ทุยเล่าว่าเห็นหิมะครั้งแรกที่เกาหลี ไปเล่นหิมะกับเพื่อนร่วมห้อง และวางแผนไปเล่นสกีสุดสัปดาห์นี้ ข้อความด้านล่างเป็นไปตามที่พิมพ์ในตำราหน้า 268 (เสียงประกอบคือแทร็ก 26-2)

ก่อนอ่าน ตำราหน้า 268 ให้ตอบคำถามอุ่นเครื่อง 2 ข้อ (ตอบเองตามจริง ไม่มีเฉลย)

- 오늘 날씨가 어때요? *(วันนี้อากาศเป็นยังไง)*
- 여러분은 어떤 날씨를 좋아해요? *(คุณชอบอากาศแบบไหน)*

🖼️ *หัวบทอ่านมีภาพหญิงผมยาวสีดำสวมเสื้อสีแดง (ทุย) ข้างชื่อเรื่อง 투이의 일기 ท้ายบรรทัดวันที่มีรูปตุ๊กตาหิมะแทนคำว่าหิมะ*

> 12월 29일 월요일, 날씨 : *(29 ธันวาคม วันจันทร์ อากาศ: หิมะ — วาดเป็นรูปตุ๊กตาหิมะ)*
>
> 오늘은 아침부터 눈이 왔어요. 제 고향 베트남에는 눈이 오지 않아요. 그래서 한국에서 눈을 처음 봤어요. *(วันนี้หิมะตกตั้งแต่เช้า บ้านเกิดฉันเวียดนามหิมะไม่ตก เลยเห็นหิมะครั้งแรกที่เกาหลี)*
>
> 수업이 끝나고 우리 반 학생들과 같이 운동장으로 나갔어요. 운동장에서 사진을 많이 찍었어요. 우리는 눈사람도 만들었어요. 좀 춥고 힘들었지만 아주 재미있었어요. *(เลิกเรียนแล้วออกไปสนามกับเพื่อนร่วมห้อง ถ่ายรูปเยอะ ปั้นตุ๊กตาหิมะด้วย หนาวและเหนื่อยหน่อยแต่สนุกมาก)*
>
> 저녁에는 오후보다 눈이 더 많이 왔어요. 학생 식당에서 저녁을 먹고 기숙사에서 고향 친구하고 채팅을 했어요. 그 친구도 눈을 보고 싶어 해요. 그래서 고향 친구에게 눈 사진을 보냈어요. *(ตอนเย็นหิมะตกหนักกว่าตอนบ่าย กินข้าวเย็นที่โรงอาหารแล้วแชตกับเพื่อนบ้านเกิดที่หอ เพื่อนก็อยากเห็นหิมะ เลยส่งรูปหิมะให้)*
>
> 이번 주말에는 스키를 타러 갈 거예요. 주말에는 스키장에 사람이 많겠지만 재미있을 거예요. 고향 친구에게 스키장 사진도 보낼 거예요. 고향 친구가 스키장에 가고 싶어 하겠네요. *(สุดสัปดาห์นี้จะไปเล่นสกี ลานสกีคงมีคนเยอะแต่คงสนุก จะส่งรูปลานสกีให้เพื่อนด้วย เพื่อนคงอยากไปลานสกีสินะ)*

#### ไวยากรณ์ในบทอ่าน

บทอ่านนี้เอาไวยากรณ์ของบทนี้และของบทก่อนหน้ามาใช้ซ้ำหลายจุด และมีรูปจากบท 30 ที่ใช้ล่วงหน้าอีกหนึ่งจุด

- 오후**보다** 눈이 **더** — N보다 + 더 (ข้อ 41)
- 사람이 많**겠**지만 — -겠- (ข้อ 42) + -지만
- 가고 싶어 하**겠**네요 — -겠- (ข้อ 42) + -네요 (ข้อ 30) + 싶어 하다 (ข้อ 38)
- 타러 갈 거예요 — -(으)러 (ข้อ 26) + -(으)ㄹ 거예요 (ข้อ 28)
- 아침**부터** 눈이 왔어요 — 부터 (ข้อ 27)
- 눈이 오**지 않**아요 — -지 않다 (ข้อ 16)
- 수업이 끝나**고** — -고 แบบ "แล้ว" (ลำดับเหตุการณ์ ดูหมายเหตุในข้อ 34)
- 고향 친구**에게** 눈 사진을 보냈어요 — 에게 (ข้อ 29)
- 운동장**으로** 나갔어요 — (으)로 บอกทิศทาง (ข้อ 49 ตำราสอนในบท 30 บทอ่านใช้ล่วงหน้า)

#### คำถามท้ายบทอ่าน (เฉลยจากภาคผนวก หน้า 372)

ตำรามีคำถาม 2 ชุดใต้บทอ่าน ชุด 가 คือ 읽고 이야기해 봅시다. *(อ่านแล้วคุยกัน)* เป็นคำถามปลายเปิด 3 ข้อ ชุด 나 คือ 윗글을 읽고 맞으면 ○, 틀리면 ×를 하세요. *(อ่านข้อความข้างบน ถูกใส่ ○ ผิดใส่ ×)* เป็นข้อ ○/× 3 ข้อ เฉลยของทั้งสองชุดมาจากภาคผนวกของตำรา

| 나 3 | 이번 주말에 고향 친구하고 같이 스키장에 갈 거예요. *(สุดสัปดาห์นี้จะไปลานสกีกับเพื่อนบ้านเกิด)* | **×** | ทุยจะไปสกี แต่แค่ส่งรูปลานสกีให้เพื่อน เพื่อนเพียง "อยากไป" (스키장에 가고 싶어 하겠네요) |

#### 다 — ฟังแล้วอ่านตาม (ตำรา 26-3 · ขีดเส้นใต้เพื่อเน้น)

ข้อ 다 ให้ฟังเสียงแล้วอ่านตามโดยระวังส่วนที่ตำราขีดเส้นใต้ไว้ หัวข้อในตำราพิมพ์เป็นเส้นขีดเปล่าแล้วตามด้วย 에 주의하면서 ความหมายคือ "ให้ระวังส่วนที่ขีดเส้นใต้" เสียง 26-3 มี 2 ประโยค ตัวหนาข้างล่างคือส่วนที่ตำราขีดเส้นใต้

- 수업이 **끝나고** 우리 반 **학생들과 같이** 운동장으로 나갔어요. *(เลิกเรียนแล้วออกไปสนามกับเพื่อนร่วมห้อง)*
- 주말에는 스키장에 사람이 **많겠지만** 재미있을 거예요. *(สุดสัปดาห์ลานสกีคงมีคนเยอะแต่คงสนุก)*

ผู้เขียนคู่มือสังเกตว่าส่วนที่ขีดเส้นใต้ทั้ง 3 จุดเป็นจุดที่เสียงเปลี่ยน (เสริม ตำราไม่ได้พิมพ์คำอ่านของส่วนเหล่านี้) คือ 끝나고 [끈나고] · 학생들과 같이 [학쌩들과 가치] · 많겠지만 [만켇찌만] ดูกฎในหัวข้อ 🔊 발음

#### 라 — ทำบทอ่านเป็นบทสนทนา (ตัวอย่างตอบ)

ข้อ 라 คือ 읽은 내용을 대화로 만들어 봅시다. *(เอาเรื่องที่อ่านมาทำเป็นบทสนทนา)* ให้เปลี่ยนไดอารี่เป็นบทสนทนาระหว่างทุยกับเพื่อนบ้านเกิด ตำราพิมพ์บางบรรทัดไว้ให้ (บรรทัดแรกของทุย คำถามของเพื่อน และบรรทัดปิดท้าย) ที่เหลือเว้นช่องให้เติมและไม่มีเฉลย ข้างล่างคือกรอบตามที่ตำราพิมพ์ ตัวหนาคือตัวอย่างตอบที่ผู้เขียนคู่มือเติม

> 투이: 오늘 처음 눈을 봤어요. *(วันนี้เห็นหิมะเป็นครั้งแรก)*
>
> 고향 친구: 그래요? 좋았겠어요. 그래서 뭘 했어요? *(จริงเหรอ คงดีใจแย่เลย แล้วทำอะไรบ้าง)*
>
> 투이: 수업이 끝나고 **반 학생들과 운동장에 나갔어요. 사진도 찍고 눈사람도 만들었어요.** *(เลิกเรียนแล้วออกไปสนามกับเพื่อนในห้อง ถ่ายรูปและปั้นตุ๊กตาหิมะด้วย)*
>
> 고향 친구: **재미있었**겠어요. 주말에는 뭘 할 거예요? *(คงสนุกแน่ ๆ เลย สุดสัปดาห์จะทำอะไร)*
>
> 투이: **이번 주말에는 스키를 타러 갈 거예요. 스키장에 사람이 많겠지만 재미있을 거예요.** *(สุดสัปดาห์นี้จะไปเล่นสกี ลานสกีคงมีคนเยอะแต่คงสนุก)*
>
> 고향 친구: 저도 스키장에 가고 싶어요. *(ฉันก็อยากไปลานสกีเหมือนกัน)*

ช่องหน้า 겠어요 ควรเป็นรากในรูปอดีต เช่น 재미있었 หรือ 힘들었 เพราะเพื่อนเดาเรื่องที่ผ่านไปแล้ว เหมือน 좋았겠어요 ในบรรทัดก่อนหน้า

#### 활동 (หน้า 269) — วางแผนสุดสัปดาห์จากพยากรณ์อากาศ

ท้ายบทตำราให้หาพยากรณ์อากาศของสุดสัปดาห์นี้ แล้ววางแผนสุดสัปดาห์ให้เข้ากับอากาศ คำสั่งในตำราคือ 일기예보에서 이번 주말 날씨를 찾아보고 주말 계획을 세워 보세요. *(หาพยากรณ์อากาศสุดสัปดาห์นี้จากรายงานอากาศ แล้ววางแผนสุดสัปดาห์)* ตำราไม่มีเฉลย ตัวอย่างตอบข้างล่างผู้เขียนคู่มือแต่ง โดยใช้ -겠- เดาอากาศและ -(으)ㄹ 거예요 บอกแผน

- 토요일에는 날씨가 맑겠어요. 그래서 공원에 갈 거예요. *(วันเสาร์อากาศคงแจ่มใส เลยจะไปสวนสาธารณะ)*
- 일요일에는 비가 오겠어요. 그래서 집에서 쉴 거예요. *(วันอาทิตย์ฝนคงตก เลยจะพักผ่อนที่บ้าน)*

  - คุยโทรศัพท์เทียบอากาศตามการ์ดแบบ 활동 หน้า 267 (여보세요 → 어제보다 … → 정말 …겠어요)

> [!WARNING] ที่น่าจะพลาด (จากข้อผิดเดิมและการบ้าน 26과 ที่ทำแล้ว)
> - ★ **เกิดจริงแล้วในใบฝึก 26과:** เขียน 압둘라 씨가 왕쯔이보다 시험을 잘 봤어요 ทั้งที่หวางจื่ออีได้ 90 คะแนน (สลับฝ่ายชนะ) · **เกิดจริงในเวิร์กบุ๊ก D:** 국민식당이 분위기가 학생식당이 분위기보다 (มี 이 เกินในวลีที่ต่อด้วย 보다 → 국민식당이 학생 식당보다 분위기가 더 좋아요)
> - ★ ตอบผิดคำถาม: 누구 집이 더 작아요? / 무엇이 더 비싸요? ต้องตอบ "ชื่อ + (집)이/가 + B보다 + คำคุณศัพท์" — ตระกูลเดียวกับ 언제 → 가족을 만날 거예요 ที่เคยเสียคะแนน
> - ★ สลับตัวเทียบ (A/B กลับด้าน) เหมือนคำบอกตำแหน่ง 앞/뒤 ที่เคยกลับจุดอ้างอิง: **ตัวหลัง 보다 = ตัวที่แพ้** ตัวประธาน (이/가) = ตัวที่ชนะ
> - ★ ㅈ/ㅊ ในคำของบท: 짧아요 · 맑아요 · 따뜻해요
> - ★ ㅐ/ㅔ ในคำของบท: 세일 (ㅔ) ↔ 새 (ㅐ) · 개 (ㅐ) · 태국 (ไม่ใช่ 테국)
> - ㅂ ต้องผัน: 추워요 · 더워요 · 어려워요 · 매워요
> - ไม่ใช่ 춥어요 · 덥어요 (ผัน ㅂ ผิด)
> - แต่ก่อน -겠- ㅂ ไม่ผัน: 춥겠어요 · 맵겠어요 (ไม่ใช่ 추우겠어요)
> - ㅡ ตกก่อน 아/어: 바쁘다 → 바빠요 (ไม่ใช่ 바쁘어요)
> - -겠어요 กับอดีต: 재미있겠어요 ✗ → 재미있었겠어요
> - อย่าใช้ -겠- เดาแทน -(으)ㄹ 거예요 (แผนของตัวเอง)

> [!SUMMARY] สรุปท้ายบท
> - N보다 ต่อท้ายนามตัวเทียบ ไม่ดูตัวสะกด ไม่เว้นวรรค โครงคือ **A가/이 B보다 (더) + A/V** (제주도가 서울보다 따뜻해요)
> - ตัวประธาน (이/가) = ตัวที่ "มากกว่า" ส่วนตัวหลัง 보다 = ตัวที่แพ้ และต้องตอบให้ตรงคำถาม (누가 → ชื่อ + 가 · 누구 집이 → ชื่อ 씨 집이)
> - -겠-² "คงจะ…" ใช้เดาจากเบาะแส: ราก + -겠어요 (맛있겠어요) และอดีต = -았/었겠어요 (재미있었겠어요)
> - -겠- เดา ต่างจาก -겠- ตั้งใจ (บท 16) และต่างจาก -(으)ㄹ 거예요 ที่ใช้บอกแผนการ ส่วน ㅂ ผันเป็น 워 เฉพาะก่อนสระ (추워요) แต่คงเดิมก่อน -네요 · -겠어요 (춥네요 · 춥겠어요)
> - บทอ่านและกิจกรรม: 투이의 일기 (읽기 26-2) ใช้ทั้ง N보다 และ -겠- ส่วน 활동 หน้า 267 ฝึกคุยโทรศัพท์เทียบอากาศ ด้วย 어제보다 + ตัวเลข 도 + 정말 …겠어요
> - ข้อสอบคาด: เติม A보다 B가 · 누가/무엇이 더 …? ตามภาพ · เดา -겠어요 · อดีต -았/었겠어요
