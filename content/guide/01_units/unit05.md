## 5과 · 어느 나라 사람입니까? (คุณเป็นคนชาติไหน?)

> [!INTRO] บทนี้ว่าด้วยอะไร
> บทที่ 5 เป็นบทแรกหลังจากเรียนอักษรเกาหลี (자모) และว่าด้วยเรื่อง **การแนะนำตัว** สถานการณ์ในบทคือการพบกันครั้งแรก: ทักทาย บอกชื่อ ถามว่าเป็นคนประเทศไหน และบอกอาชีพ
>
> ไวยากรณ์ใหม่มี 3 เรื่อง ซึ่งใช้ประกอบกันจนเป็นบทสนทนาแรก:
>
> 1. **N + 입니다 / 입니까?** — "เป็น…" แบบทางการ 입니다 ใช้บอกเล่า 입니까? ใช้ถาม ต่อท้ายคำนามได้เลยโดยไม่ต้องดูตัวสะกด
> 2. **N + 은 / 는** — ตัวบอกหัวเรื่อง "ส่วน…" หรือ "…น่ะ" ใช้ 은 หลังนามที่มีตัวสะกดและใช้ 는 หลังนามที่ไม่มี
> 3. **어느 나라 사람입니까?** — ประโยคถาม-ตอบสัญชาติ ใช้ชื่อประเทศ + 사람
>
> บทนี้ใช้รูปทางการ -입니다 ซึ่งเป็นรูปที่ใช้แนะนำตัวและพูดกับครู ส่วนรูปพูดทุกวัน 이에요/예요 ที่ความหมายเดียวกันจะเรียนในบท 7 ดังนั้นในบทนี้ยังไม่มี 아니에요 การปฏิเสธใช้ 아니요 แล้วบอกข้อมูลที่ถูกต่อทันที
>
> จบบทแล้วจะแนะนำตัว (ชื่อ · ชาติ · อาชีพ) และถาม-ตอบสัญชาติหรืออาชีพด้วยรูปทางการ -입니다 / -입니까? ได้
>
> จุดที่คนไทยมักพลาด: สลับท้ายประโยคระหว่าง 입니다 กับ 입니까 (เคยสลับตอนเขียนตามคำบอก) · เขียนตามเสียง [임니다] แทนรูปจริง 입니다 · และเขียน ㅈ ให้กลายเป็น ㅊ เวลาเขียนมือ (저는 → 처는)

### 📝 ไวยากรณ์: N + 입니다 / 입니까? — "เป็น…" แบบทางการ (ไวยากรณ์ข้อ 02)

ตอนนี้ว่าด้วยการบอกว่า "A เป็น B" ในรูปทางการ 입니다 ต่อท้ายคำนามได้เลยโดยไม่ต้องดูตัวสะกด (ต่างจาก 은/는 ในข้อถัดไป) ถ้าจะถามให้เปลี่ยนเป็น 입니까? แล้วตอบด้วย 네, …입니다 ส่วนการปฏิเสธใช้ 아니요 ตามด้วยข้อมูลที่ถูก เพราะ 아니에요 ยังไม่เรียนจนถึงบท 7

เรื่องระดับภาษา: 입니다 เป็นรูปทางการ ใช้แนะนำตัวและพูดกับครู ส่วน 이에요/예요 ในบท 7 มีความหมายเดียวกันแต่เป็นภาษาพูดทุกวัน (학생입니다 = 학생이에요)

#### รูปแบบ

| ชนิดประโยค | รูป | หมายเหตุ |
|:---|:---|:---|
| บอกเล่า | N + 입니다 | ต่อท้ายนามได้เลย ไม่ต้องดูตัวสะกด |
| คำถาม | N + 입니까? | ถามต้องลงท้าย 입니까 |
| ตอบรับ | 네, …입니다 | ตอบว่า "ใช่" แล้วพูดซ้ำข้อมูล |
| ตอบปฏิเสธ | 아니요, + ข้อมูลที่ถูก | ยังไม่มี 아니에요 (เรียนบท 7) |

#### ตัวอย่างจากตำรา

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 학생입니다. | เป็นนักเรียน | ต่อท้ายนามได้เลย |
| 의사입니다. | เป็นหมอ | ไม่ต้องดูตัวสะกด |
| 책입니다. | เป็นหนังสือ | ใช้กับสิ่งของได้เหมือนกัน |
| 선생님입니까? → 네, 선생님입니다. | เป็นครูหรือ → ใช่ เป็นครู | กรอบหน้า 42 |
| 책입니까? → 네, 책입니다. | เป็นหนังสือหรือ → ใช่ เป็นหนังสือ | กรอบหน้า 42 |
| 중국 사람입니까? → 네, 중국 사람입니다. | เป็นคนจีนหรือ → ใช่ เป็นคนจีน | ถามด้วย 입니까? ตอบ 네, …입니다 |
| 선생님입니까? → 아니요, 저는 학생입니다. | เป็นครูหรือ → ไม่ใช่ ฉันเป็นนักเรียน | ปฏิเสธ = 아니요 + ข้อมูลที่ถูก |
| 학생입니다. = 학생이에요. | เป็นนักเรียน (ทางการ = ภาษาพูดทุกวัน) | 이에요/예요 เรียนบท 7 |

ตำราให้ตัวอย่าง "왕쯔이입니다." แล้วให้ดูภาพคน 6 คนและพูดชื่อด้วย N + 입니다 (ข้อ 1 ซ้ำกับตัวอย่าง) ตำราไม่พิมพ์เฉลย คอลัมน์ "ตัวอย่างตอบ" จึงเป็นคำตอบตามโครงที่พิมพ์

|:---|:---|:---|:---|
| 1 | 왕쯔이 | 왕쯔이입니다. | คือหวางจื่ออี |
| 2 | 압둘라 | 압둘라입니다. | คืออับดุลลา |
| 3 | 알렉세이 | 알렉세이입니다. | คืออเล็กเซย์ |
| 4 | 제프리 | 제프리입니다. | คือเจฟฟรีย์ |
| 5 | 지훈 | 지훈입니다. | คือจีฮุน |

#### 연습 2 (หน้า 43) — ถาม-ตอบสัญชาติจากภาพ

โครงในตำราคือ "일본 사람입니까? / 네, 일본 사람입니다." แบบฝึกให้ดูภาพคนถือธง 6 ภาพแล้วถาม-ตอบด้วยโครงเดียวกัน ทุกข้อตอบรับด้วย 네 (ข้อ 1 ซ้ำกับตัวอย่าง) ตำราไม่พิมพ์เฉลย

| ข้อ | ประเทศใต้ภาพ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 일본 | 일본 사람입니까? → 네, 일본 사람입니다. | เป็นคนญี่ปุ่นหรือ → ใช่ เป็นคนญี่ปุ่น |
| 2 | 몽골 | 몽골 사람입니까? → 네, 몽골 사람입니다. | เป็นคนมองโกเลียหรือ → ใช่ เป็นคนมองโกเลีย |
| 3 | 베트남 | 베트남 사람입니까? → 네, 베트남 사람입니다. | เป็นคนเวียดนามหรือ → ใช่ เป็นคนเวียดนาม |
| 4 | 러시아 | 러시아 사람입니까? → 네, 러시아 사람입니다. | เป็นคนรัสเซียหรือ → ใช่ เป็นคนรัสเซีย |
| 5 | 중국 | 중국 사람입니까? → 네, 중국 사람입니다. | เป็นคนจีนหรือ → ใช่ เป็นคนจีน |
| 6 | 호주 | 호주 사람입니까? → 네, 호주 사람입니다. | เป็นคนออสเตรเลียหรือ → ใช่ เป็นคนออสเตรเลีย |

#### 📽️ จากสมุดทบทวน 14/9 (หน้าสมุดจดของคุณ)

หน้าสมุดหน้านี้จดคู่ซ้าย-ขวาของรูปประโยคไว้ ซ้ายเป็นรูปคำถาม ขวาเป็นรูปบอกเล่า

| คำถาม ? | บอกเล่า |
|:---|:---|
| 입니까? | 입니다 · 이에요 · 예요 |

นอกจากนี้ในสมุดมีการแก้ตัวสะกด 범 → **입** — ออกเสียง [임니다] แต่ต้องเขียน 입니다

#### ⚠️ 입니다 vs 있습니다 (ชุดทบทวนกลางภาค ข้อ 1 — ผิด 2 ใน 11)

ข้อ 1 ของชุดทบทวนกลางภาคเน้นการแยก 입니다 กับ 있습니다 ซึ่งผู้เรียนผิด 2 ใน 11 ช่อง ตารางนี้ใช้ประโยคจากข้อนั้นแยกให้เห็นว่ารูปไหนใช้ได้และรูปไหนผิด

| ประโยค | แปล | ใช้ได้ไหม |
|:---|:---|:---|
| 고향이 LA**입니다** | บ้านเกิด**คือ** LA | ✓ 입니다 ติดคำนามตรง ๆ |
| 고향이 LA**에** 있습니다 | บ้านเกิด**อยู่ที่** LA | ✓ ต้องมี 에 (โจทย์ไม่ให้ → เลือกไม่ได้) |
| 고향이 LA 있습니다 | — | ✗ LA ลอย ไม่มีคำช่วย |
| 남동생**이 있습니다** / 남동생**입니다** | **มี**น้องชาย / **เป็น**น้องชาย | ✓ ทั้งคู่ แต่คนละความหมาย |
| 남동생이 입니다 | — | ✗ 입니다 ไม่รับ 이/가 ข้างหน้า |

กฎ: เห็น **이/가** หรือ **에** นำหน้าช่องว่าง → 있습니다 · ไม่มีอะไรคั่น → 입니다 (รายละเอียด ไวยากรณ์ข้อ 02)

#### ⚠️ ระวัง

- ถามต้องลงท้าย 입니까 (입니다? ✗)
- เขียนติดนาม 사람입니까 (사람 입니까 ✗ — ไวยากรณ์ข้อ 13)
- เคยสลับ 니다/니까 ตอนฟังเขียน (ชีตฟัง ข้อ B2: เขียน 어느 나라 사람입니다 ✗)

→ เจาะลึก: ไวยากรณ์ข้อ 02 (เล่ม 2)

### 📝 ไวยากรณ์: N + 은 / 는 — ตัวบอกหัวเรื่อง (ไวยากรณ์ข้อ 01)

ตอนนี้ว่าด้วย 은/는 ซึ่งวางหลังคำนามเพื่อบอกว่า "ส่วน…" หรือ "…น่ะ" ว่าประโยคนี้จะพูดถึงใคร เลือก 은 หรือ 는 ดูที่ตัวสุดท้ายของคำนามว่ามีตัวสะกด (받침) หรือไม่ ในบทนี้ใช้กับ 저는 และชื่อคนที่ต่อด้วย 씨 เป็นหลัก เวลาถามคนฟังให้เรียกด้วยชื่อ + 씨는 แล้วตอบเรื่องตัวเองด้วย 저는

#### รูปแบบ

| ท้ายคำนาม | ต่อท้ายด้วย | ตัวอย่าง |
|:---|:---|:---|
| มีตัวสะกด (받침 ○) | **은** | 마이클은 학생입니다. *(ไมเคิลเป็นนักเรียน)* |
| ไม่มีตัวสะกด (받침 ✗) | **는** | 카오루는 일본 사람입니다. *(คาโอรุเป็นคนญี่ปุ่น)* |
| 저 (ฉัน แบบสุภาพ) | **는** | 저는 학생입니다. *(ฉันเป็นนักเรียน)* |
| 씨 (ไม่มีตัวสะกด) | **는** เสมอ | 윤아 씨는 *(คุณยุนอา…)* — 씨은 ✗ |

#### แสดงวิธีทำ: N + 은/는 (ย่อ · ตารางเต็มในไวยากรณ์ข้อ 01)

กฎ 1 ดูพยางค์สุดท้ายของคำนาม ถ้ามีตัวสะกด (ㄹ ก็นับ) ใช้ 은 กฎ 2 ถ้าไม่มีตัวสะกดใช้ 는 โดย 저 กับ 씨 ไม่มีตัวสะกดจึงเป็น 는 เสมอ ตารางนี้แสดงทุกขั้นกับคำของตำราบท 5

| คำนาม + คำชี้ | ① พยางค์สุดท้าย | ② ตัวสะกด → เลือก | ③ ผล |
|:---|:---|:---|:---|
| 학생 + 은/는 | 생 | มี (ㅇ) → 은 | **학생은** |
| 마이클 + 은/는 | 클 | มี (ㄹ) → 은 | **마이클은** |
| 선생님 + 은/는 | 님 | มี (ㅁ) → 은 | **선생님은** |
| 카오루 + 은/는 | 루 | ไม่มี → 는 | **카오루는** |
| 저 + 은/는 | 저 | ไม่มี → 는 | **저는** |
| 윤아 씨 + 은/는 | 씨 | ไม่มี → 는 | **윤아 씨는** |

#### ตัวอย่างจากตำรา

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 윤아 씨는 선생님입니까? → 아니요, 저는 학생입니다. | คุณยุนอาเป็นครูหรือ → ไม่ใช่ ฉันเป็นนักเรียน | ถามคนฟังด้วย N + 씨는 ตอบเรื่องตัวเองด้วย 저는 |
| 이지훈 씨 | คุณอีจีฮุน | 씨 ต่อท้ายชื่อเต็มหรือชื่อตัว เว้นวรรคก่อน 씨 |
| 장핑 씨 | คุณจางผิง | 씨 ต่อท้ายชื่อเต็มหรือชื่อตัว เว้นวรรคก่อน 씨 |

#### 연습 1 (หน้า 44) — บอกสัญชาติด้วย N 씨는

ตัวอย่างในตำราคือ "이지훈 씨는 한국 사람입니다." แบบฝึกให้เอาชื่อกับสัญชาติที่พิมพ์ใต้ภาพมาต่อเป็นประโยคเดียว ข้อ 5 เป็น 선생님 ซึ่งไม่ใช้ 씨 จึงใช้ 은 ตรง ๆ ตำราไม่พิมพ์เฉลย

| ข้อ | โจทย์ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 이지훈 / 한국 사람 | 이지훈 씨는 한국 사람입니다. | คุณอีจีฮุนเป็นคนเกาหลี |
| 2 | 바트 / 몽골 사람 | 바트 씨는 몽골 사람입니다. | คุณบาตเป็นคนมองโกเลีย |

#### 연습 2 (หน้า 45) — ถามอาชีพแล้วปฏิเสธ

### 📝 ไวยากรณ์: 어느 나라 사람입니까? — ถาม-บอกสัญชาติ

ตอนนี้ว่าด้วยการถามและบอกสัญชาติ ใช้ชื่อประเทศ + 사람 แปลว่า "คนชาตินั้น" และใช้ 어느 ถามว่า "ประเทศไหน" ซึ่งหมายถึงเลือกจากหลายตัวเลือก ส่วนการตอบใช้ 저는 + ประเทศ + 사람입니다 ได้ทันที

#### รูปแบบ

| ประเทศ | + 사람 | ความหมาย |
|:---|:---|:---|
| 한국 | 한국 사람 | คนเกาหลี |
| 중국 | 중국 사람 | คนจีน |
| 러시아 | 러시아 사람 | คนรัสเซีย |

#### ตัวอย่างจากตำรา

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 어느 나라 사람입니까? → 저는 중국 사람입니다. | เป็นคนประเทศไหน → ฉันเป็นคนจีน | 어느 = "ไหน" (เลือกจากหลายตัวเลือก) |
| 이리나 씨는 미국 사람입니까? → 아니요, 저는 러시아 사람입니다. | คุณอีรีนาเป็นคนอเมริกันหรือ → ไม่ใช่ ฉันเป็นคนรัสเซีย | เดาแล้วปฏิเสธ + บอกข้อมูลที่ถูก |

#### 연습 3 (หน้า 43) — ถามว่าเป็นคนประเทศไหน

โครงในตำราคือ "어느 나라 사람입니까? / 한국 사람입니다." แบบฝึกให้ดูภาพ 6 ภาพแล้วตอบด้วยชื่อประเทศ + 사람입니다 (ข้อ 1 ซ้ำกับตัวอย่าง) ตำราไม่พิมพ์เฉลย

| ข้อ | ประเทศใต้ภาพ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 한국 | 한국 사람입니다. | เป็นคนเกาหลี |
| 2 | 러시아 | 러시아 사람입니다. | เป็นคนรัสเซีย |
| 3 | 미국 | 미국 사람입니다. | เป็นคนอเมริกัน |
| 4 | 캐나다 | 캐나다 사람입니다. | เป็นคนแคนาดา |
| 5 | 사우디아라비아 | 사우디아라비아 사람입니다. | เป็นคนซาอุดีอาระเบีย |
| 6 | 태국 | 태국 사람입니다. | เป็นคนไทย |

### 💬 대화 5-1 — แนะนำตัวครั้งแรก

이리나 (อีรีนา) กับ 장핑 (จางผิง) ทักทายและแนะนำชื่อกัน แล้วถามสัญชาติของอีกฝ่าย 장핑 ตอบว่าเป็นคนจีน ส่วน 이리나 ถูกเดาว่าเป็นคนอเมริกัน จึงปฏิเสธและบอกว่าเป็นคนรัสเซีย

> 이리나: 안녕하세요? 저는 이리나입니다. *({v:สวัสดี}ค่ะ {n:ฉัน}{e:ชื่อ}{n:อีรีนา})*
>
> 장핑: 안녕하세요? 저는 장핑입니다. *({v:สวัสดี}ครับ {n:ผม}{e:ชื่อ}{n:จางผิง})*
>
> 이리나: 장핑 씨는 어느 나라 사람입니까? *({n:คุณจางผิง}{e:เป็น}{n:คนประเทศ}{q:ไหน}คะ)*
>
> 장핑: 저는 중국 사람입니다. 이리나 씨는 미국 사람입니까? *({n:ผม}{e:เป็น}{n:คนจีน} {n:คุณอีรีนา}{e:เป็น}{n:คนอเมริกัน}หรือครับ)*
>
> 이리나: 아니요, 저는 러시아 사람입니다. *(ไม่ใช่ค่ะ ฉันเป็นคนรัสเซีย)*

#### สังเกตจากบทสนทนา

- 저는 이리나입니다 / 저는 장핑입니다 — แนะนำชื่อด้วย 저는 + ชื่อ + 입니다
- 장핑 씨는 어느 나라 사람입니까? — ถามสัญชาติของอีกฝ่ายด้วยชื่อ + 씨는 + 어느 나라 사람입니까?
- 이리나 씨는 미국 사람입니까? — เดาสัญชาติแล้วถามด้วยประเทศ + 사람입니까?
- 아니요, 저는 러시아 사람입니다. — ปฏิเสธด้วย 아니요 แล้วแก้ข้อมูลให้ถูก (ยังไม่ใช้ 아니에요)

#### 확인 — คำถามท้ายบทสนทนา

คำถามในตำรา เฉลยหาได้จากบทสนทนาข้างบน

- 장핑 씨는 중국 사람입니까? → 네, 중국 사람입니다. *(คุณจางผิงเป็นคนจีนหรือ → ใช่ เป็นคนจีน)*
- 이리나 씨는 어느 나라 사람입니까? → 러시아 사람입니다. *(คุณอีรีนาเป็นคนประเทศไหน → คนรัสเซีย)*

- **장핑입니다.** *(คือจางผิง)*
- 중국 **사람입니다.** *(เป็นคนจีน)*
- **반갑습니다.** *(ยินดีที่ได้รู้จัก)*

#### 5-3 라 — แปลงบทอ่านเป็นบทสนทนา

โจทย์ในตำราคือ "장핑 씨가 이지훈 씨를 만났습니다. 어떻게 자기소개를 할까요? 읽은 내용을 대화로 만들어 봅시다." *(จางผิงพบกับอีจีฮุน จะแนะนำตัวกันอย่างไร ลองเอาเนื้อหาที่อ่านมาทำเป็นบทสนทนา)* ตำราพิมพ์กรอบบทสนทนาไว้แล้วเว้น 3 ช่องของ 장핑 ให้เติมเอง ตัวหนาข้างล่างคือตัวอย่างตอบของช่องว่าง รูปแบบนี้เหมือน 읽기 ในข้อสอบ และข้อความนี้อยู่ใน 중간시험 복습문제 ข้อ 15 ด้วย

- 이지훈: 안녕하세요? 저는 이지훈입니다. *(สวัสดีครับ ผมชื่ออีจีฮุน)*
- 장핑: 안녕하세요? **저는 장핑입니다.** *(สวัสดีครับ ผมชื่อจางผิง)*
- 이지훈: 장핑 씨는 어느 나라 사람입니까? *(คุณจางผิงเป็นคนประเทศไหน)*
- 장핑: 저는 **중국 사람입니다.** *(ผมเป็นคนจีน)*
- 이지훈: 장핑 씨는 회사원입니까? *(คุณจางผิงเป็นพนักงานบริษัทหรือ)*
- 장핑: **아니요, 저는 요리사입니다.** *(ไม่ใช่ ผมเป็นพ่อครัว)*

#### 활동 (หน้า 49) — ทำนามบัตรและเขียนแนะนำตัว

ตำราให้ทำนามบัตรแบบของจางผิงแล้วเขียนข้อความแนะนำตัวเอง บัตรเปล่ามีเส้นให้เขียน 2 เส้นกับบรรทัด 이메일 : อีก 1 เส้น และใต้บัตรมีเส้น 2 บรรทัดสำหรับข้อความ ตัวอย่างตอบข้างล่างยืมโครงจากบทอ่าน 5-2 แล้วเว้นช่องให้ใส่ข้อมูลของตัวเอง

- 장핑처럼 명함을 만들고 자신을 소개하는 글을 써 봅시다. *(ทำนามบัตรแบบจางผิงแล้วเขียนข้อความแนะนำตัวเอง)*
- 안녕하세요? 저는 ○○입니다. ○○ 사람입니다. *(สวัสดี ฉันชื่อ… เป็นคน…)*
- 저는 ○○입니다. 만나서 반갑습니다. *(ฉันเป็น… ยินดีที่ได้รู้จัก)*

#### 🎧 ชีตฟัง 본문 듣기 (ใบงานฟังของศูนย์)

ใบงานฟังของศูนย์มี 2 แบบ คือ O/X และเติมคำในช่องว่าง

| ประโยค | ผล |
|:---|:---|
| 장핑 씨는 중국 사람입니다. *(คุณจางผิงเป็นคนจีน)* | **○** ถูก |
| 이리나 씨는 미국 사람입니다. *(คุณอีรีนาเป็นคนอเมริกัน)* | **×** ผิด — เป็น 러시아 (รัสเซีย) |

เติมคำตามลำดับ: 안녕하세요 / 어느 나라 사람입니까 / 중국 / 아니요 / 러시아

### 🔊 발음

ประโยคแนะนำตัวมีเสียงที่อ่านต่างจากตัวเขียน 3 เรื่อง คือการเชื่อมเสียงตัวสะกดกับสระถัดไป (연음) การที่ ㅂ หน้า ㄴ ออกเสียงเป็น ㅁ และการที่ ㄱ หรือ ㅂ หน้า ㅅ ทำให้ ㅅ เป็น ㅆ

| เขียน | อ่าน | กฎ |
|:---|:---|:---|
| 사람입니까 · 사람입니다 | [사라밈니까] · [사라밈니다] | 연음 (람+이 → 라미) · ㅂ + ㄴ → ㅁ |
| 선생님입니까 · 학생 | [선생니밈니까] · [학쌩] | 연음 · ㄱ + ㅅ → ㅆ |
| 경찰관입니까 · 회사원입니다 | [경찰과님니까] · [회사워님니다] | 연음 + ㅂ + ㄴ → ㅁ |
| 반갑습니다 | [반갑씀니다] | ㅂ + ㅅ → ㅆ แล้ว ㅂ + ㄴ → ㅁ |

เขียนตามรูปคำ ไม่ใช่ตามเสียง: [임니다] → 입니다 และ [사라밈니다] → 사람입니다

### 🧪 ออกสอบอย่างไร

บทนี้ออกสอบเป็นแบบทดสอบประจำวัน 5과 (단어 시험) และเนื้อหาของบทกลับมาอีกใน 복습시험 ① กับ 중간시험 복습문제 ด้านล่างคือสิ่งที่ครูแก้และข้อผิดที่เคยเจอ

- **매일시험 5과 (단어 시험)** — ไม่มีคะแนนตัวเลขบนสแกน · ครูแก้ 3 จุด
  - A (6 ข้อ) เขียนอาชีพจากรูป: 선생님, 요리사, 기자, 경찰관, 간호사, 운동선수
  - B (4 ข้อ) 카오루 / 장핑 / 투이 / 마이클 → "…은/는 [ประเทศ] 사람입니다" *(เติมประโยคตอบ)*
  - C — ไม่มีข้อเขียนตามคำบอก
- 복습시험 ① (10/6) 쓰기 E1: 어느 나라 사람이에요? → 한국 사람이에요 *(เป็นคนประเทศไหน → คนเกาหลี)*
- 복습시험 ① (10/6) 읽기 1: 마키 씨는 어느 나라 사람입니까? → 일본 사람입니다 *(คุณมากิเป็นคนประเทศไหน → คนญี่ปุ่น)*
- 중간시험 복습문제 ข้อ 15 (장핑 + ข้อ 1–2)

> [!WARNING] ที่เคยพลาด (매일시험 · เวิร์กบุ๊ก · ชีตฟัง · ดูก่อนสอบ)
> - ✗ A1 선셍님 → **선생님**
> - ✗ A4 경차관 → **경찰관** (ㄹ ตก)
> - ✗ B10 세나다 → **캐나다** (ㅐ/ㅔ ★)
> - ✗ เวิร์กบุ๊ก 운동산수 → **운동선수**
> - ✗ ชีตฟัง: 어느 나라 사람입니다 → **입니까**
> - ✗ ชีตฟัง: 아니요 เขียนเป็น 이니요 (ลายมืออ่านไม่ชัด)
> - ★ เขียนมือ: ㅈ → ㅊ (저는 → 처는)
> - ★ 안녕하세요 ต้องมี ㅇ ที่ 녕 (ร่างพูดเคยเขียน 안녀하…)

### 🔗 เชื่อมโยง

← ต่อยอดจาก

- 자모: 받침 → เลือก 은/는 (학생은 · 의사는)
- 자모: 연음 → [사라밈니다]

→ ใช้ต่อใน

- 6과 이/가 (누가 의사입니까? ตอบด้วย 이/가 เทียบกับ 은/는)
- 7과 이에요/예요 = 입니다 (ความหมายเดียวกัน ต่างระดับภาษา)
- 14과 도 (저도 학생이에요)
- 16과 -ㅂ니다/습니다 (갑니다 · 먹습니다 — 입니다 คือรูปทางการของ 이다 ที่หน้าตาเหมือนกริยา)

> [!SUMMARY] สรุปท้ายบท
> - 입니다 / 입니까? ต่อท้ายนามได้เลยโดยไม่ดูตัวสะกด ถามลงท้าย 입니까 ตอบ 네, …입니다 หรือปฏิเสธด้วย 아니요 แล้วบอกข้อมูลที่ถูก (아니에요 เรียนบท 7)
> - 은/는 บอกหัวเรื่อง: มีตัวสะกด → 은 ไม่มี → 는 และ 씨 ใช้ 는 เสมอ (씨은 ✗) ห้ามใช้ 씨 กับตำแหน่งหรือญาติ (선생님 씨 ✗)
> - สัญชาติ = ประเทศ + 사람 ถามด้วย 어느 나라 사람입니까? ตอบด้วย 저는 …사람입니다
> - ที่ออกสอบ: เขียนอาชีพจากรูป · เติม …은/는 [ประเทศ] 사람입니다 · เขียนตามคำบอกจากบทอ่าน 5-2
> - ข้อผิดที่ต้องระวัง: สลับ 입니다 กับ 입니까 · เขียน ㅈ เป็น ㅊ (처는) · และเห็น 이/가 หรือ 에 นำหน้าช่องว่างต้องใช้ 있습니다 ไม่ใช่ 입니다
