## 6과: 그것이 마키 씨 지갑입니까? (นั่นเป็นกระเป๋าสตางค์ของคุณมากิหรือ?)

> **หลังจบบทนี้ทำอะไรได้**: ถาม-ตอบว่า "นี่/นั่น/โน่นคืออะไร · ของใคร" ใช้ 이/가 ชี้ประธาน (ใคร/อะไร) และถามชื่อ-อาชีพ (이름이 / 직업이 무엇입니까?)

**🗣️ คำศัพท์สำคัญ**

| หมวด | คำศัพท์ (ไทย) |
|---|---|
| ของในห้องเรียน 🏫 | 책상 (โต๊ะ) · 의자 (เก้าอี้) · 시계 (นาฬิกา) · 지도 (แผนที่) · 달력 (ปฏิทิน) · 창문 (หน้าต่าง) · 텔레비전 (โทรทัศน์) · 휴지통 (ถังขยะ) |
| ของใช้ส่วนตัว | 지갑 (กระเป๋าสตางค์) · 가방 (กระเป๋า) · 사전 (พจนานุกรม) · 휴대 전화 / 휴대폰 (มือถือ) |
| ชี้ · ถาม | 이것 · 그것 · 저것 (นี่ · นั่น · โน่น) · 무엇 (อะไร) · 누구 (ใคร / ของใคร) · 누가 (ใคร — ประธาน) · 이름 (ชื่อ) · 직업 (อาชีพ) |
| ในบทอ่าน | 여기 (ที่นี่) · 우리 (เรา) · 교실 (ห้องเรียน) · 모두 (ทั้งหมด) |

*รายการเต็มของศูนย์อยู่ท้ายบท*

**📝 ไวยากรณ์**

1. **N + 이 / 가** — ตัวบอกประธาน (ใคร/อะไร ทำ · เป็น) · (ไวยากรณ์ข้อ 01)
   - 받침 ○ → **이**: 책이 있어요 *(มีหนังสือ)* · 받침 ✗ → **가**: 아이가 자요 *(เด็กนอน)* · 카오루 씨가 일본 사람입니다 *(คุณคาโอรุเป็นคนญี่ปุ่น — 씨 ไม่มีตัวสะกด → 가)*
   - รูปหดที่ต้องจำ: 누구 + 가 = **누가** · 나 + 가 = **내가** · 너 + 가 = **네가** · 저 + 가 = **제가** (누구가 ✗ · 저가 ✗)
   - ถามว่า "ใคร" → ตอบด้วย 이/가: 누가 중국 사람입니까? → 왕쯔이 씨가 중국 사람입니다. *(ใครเป็นคนจีน → คุณหวางจื่ออีเป็นคนจีน)* · 누가 의사입니까? → 왕쯔이 씨가 의사입니다. *(ใครเป็นหมอ → คุณหวางจื่ออี)*
   - เทียบ 5과: 은/는 = เรื่องที่กำลังพูดถึง (저는 학생입니다) · 이/가 = "ใคร/อะไร" ที่เป็นคำตอบ หรือเพิ่งพูดถึงครั้งแรก
   - ⚠️ อ่านคำตอบก่อนเลือกคำถาม: ตอบเป็น "คน" → **누가** · ตอบเป็น "ชื่อ" → **이름** · ตอบเป็น "อาชีพ" → **직업** (매일시험 B5–7)
2. **이것 / 그것 / 저것** และ **이 / 그 / 저 + N** — นี่ · นั่น · โน่น · (ไวยากรณ์ข้อ 03)
   - **이** = ใกล้ผู้พูด · **그** = ใกล้ผู้ฟัง · **저** = ไกลทั้งสองฝ่าย
   - 이것이 무엇입니까? → 책상입니다. *(นี่คืออะไร → โต๊ะ)* · 저것이 무엇입니까? → 시계입니다. *(โน่นคืออะไร → นาฬิกา)* · 이것이 의자입니까? *(นี่คือเก้าอี้หรือ)*
   - บอกว่า "ส่วน…" ใช้ 은 ได้ (ตัวอย่างตำรา): 이것은 책입니다 · 그것은 책상입니다 · 저것은 의자입니다 · ขยายนามใช้ 이/그/저 + N: 이 사람이 압둘라 씨입니다 *(คนนี้คือคุณอับดุลลา)* — หน้านามไม่ใช้ 이것
   - ⚠️ เสียง ≠ ตัวเขียน: [이거시] = 이것이 · [저거시] = 저것이 · [교시림니다] = 교실입니다 (매일시험 C8 ⚠️) · ฟัง 시계 ผิดเป็น 씨 (C9 ⚠️)
3. **무엇 · 누구** — ถามสิ่งของ ชื่อ อาชีพ เจ้าของ
   - 이름이 무엇입니까? → 김윤아입니다. *(ชื่ออะไร → คิมยุนอา)* · 직업이 무엇입니까? → 학생입니다. *(อาชีพอะไร → นักเรียน)*
   - 누구 + N = "ของใคร": 누구 지갑입니까? → 마키 씨 지갑입니다. *(กระเป๋าสตางค์ของใคร → ของคุณมากิ)* · N + N = "ของ N" วางสองนามติดกัน ไม่ต้องมีคำว่า "ของ": 마키 씨 지갑 · 압둘라 씨 책
   - 누구 (เจ้าของ + นาม) ≠ 누가 (ประธาน + กริยา/입니다)
   - ระดับภาษา: บท 6 ยังเป็นทางการทั้งหมด → บท 7 เปลี่ยนเป็นภาษาพูดที่ความหมายเดิม: 그것이 무엇입니까? = 그게 뭐예요? · 지갑입니다 = 지갑이에요

**💬 대화 (6-1)**

> 알렉세이: 그것이 무엇입니까? *(นั่นคืออะไรครับ)*
>
> 카오루: 지갑입니다. *(เป็นกระเป๋าสตางค์ครับ)*
>
> 알렉세이: 누구 지갑입니까? *(เป็นกระเป๋าสตางค์ของใครครับ)*
>
> 카오루: 마키 씨 지갑입니다. *(เป็นกระเป๋าสตางค์ของคุณมากิครับ)*

- 확인 (คำถามในตำรา · เฉลยจากบทสนทนา): 이것이 무엇입니까? → 지갑입니다 · 카오루 씨 지갑입니까? → 아니요, 마키 씨 지갑입니다. *(นี่คืออะไร → กระเป๋าสตางค์ · เป็นของคุณคาโอรุหรือ → ไม่ใช่ เป็นของคุณมากิ)*
- ฝึกกลุ่ม (หน้า 55): 이것이 무엇입니까? → 책입니다. · 마키 씨 책입니까? → 아니요. · 누구 책입니까? → 알렉세이 씨 책입니다. *(นี่คืออะไร → หนังสือ · ของคุณมากิไหม → ไม่ · ของใคร → ของคุณอเล็กเซย์)*

**📖 읽기 6-2 · 🎧 듣기**

ห้องเรียนของเรา — ประโยคเหล่านี้เป็นแหล่งคำบอกเขียน:

> 여기는 우리 교실입니다. *(ที่นี่คือห้องเรียนของเรา)* 이 사람이 압둘라 씨입니다. *(คนนี้คือคุณอับดุลลา)*
>
> 압둘라 씨는 사우디아라비아 사람입니다. *(คุณอับดุลลาเป็นคนซาอุดีอาระเบีย)* 운동선수입니다. *(เป็นนักกีฬา)*
>
> 이 사람이 마키 씨입니다. *(คนนี้คือคุณมากิ)* 마키 씨는 일본 사람입니다. *(คุณมากิเป็นคนญี่ปุ่น)* 회사원입니다. *(เป็นพนักงานบริษัท)*
>
> 이 사람들은 모두 우리 반 친구입니다. *({n:คนเหล่านี้}{a:ทั้งหมด}{e:เป็น}{n:เพื่อนร่วมห้อง}{p:ของ}{n:เรา})*

- ถาม-ตอบ: 압둘라 씨 직업이 무엇입니까? → 운동선수입니다 · 누가 일본 사람입니까? → 마키 씨가 일본 사람입니다 *(อาชีพของคุณอับดุลลาคืออะไร → นักกีฬา · ใครเป็นคนญี่ปุ่น → คุณมากิ)*
- O/X: 여기는 교실입니다 (O) · 압둘라 씨와 마키 씨는 친구입니다 (O) · 마키 씨는 운동선수입니다 (X → 회사원) *(ที่นี่คือห้องเรียน = ถูก · อับดุลลากับมากิเป็นเพื่อนกัน = ถูก · มากิเป็นนักกีฬา = ผิด เป็นพนักงานบริษัท)*
- แปลงเป็นบทสนทนา (6-3 라 — เติมคำตอบจากบทอ่าน): 가: 이름이 무엇입니까? 나: 압둘라입니다. 가: 어느 나라 사람입니까? 나: 사우디아라비아 사람입니다. 가: 직업이 무엇입니까? 나: 운동선수입니다. *(ชื่ออะไร → อับดุลลา · เป็นคนประเทศไหน → ซาอุดีอาระเบีย · อาชีพอะไร → นักกีฬา)*
- รูปแบบนี้ = 읽기 ในข้อสอบ: 복습시험 ① ข้อ 1–2 ใช้ข้อความนี้ (ดัดแปลงท้ายเป็น 마키 씨는 우리 반 친구입니다)
- 🎧 ชีตฟัง 본문 듣기 (ใบงานฟังของศูนย์): 그것이 가방입니다 (X → 지갑) · 카오루 씨 지갑입니다 (X → 마키 씨) *(นั่นคือกระเป๋า = ผิด เป็นกระเป๋าสตางค์ · เป็นของคุณคาโอรุ = ผิด เป็นของคุณมากิ)* · เติมคำ: 그것이 무엇입니까 / 지갑 / 누구

**🔊 발음**

| เขียน | อ่านจริง | หลักการ |
|---|---|---|
| 이름이 · 직업이 · 사람이 | [이르미] · [지거비] · [사라미] | 연음: 받침 + 이 → ย้ายไปเป็นพยัญชนะต้น |
| 무엇입니까 · 지갑입니다 | [무어심니까] · [지가빔니다] | 연음 + ㅂ + ㄴ → ㅁ |
| 이것이 · 저것이 | [이거시] · [저거시] | 받침 ㅅ + 이 → 시 |
| 시계 | [시계/시게] | ออกเสียงได้สองแบบ |
| 교실입니다 · 회사원입니다 | [교시림니다] · [회사워님니다] | 6-3 ตำราขีดเส้นใต้ — เขียนตามรูปคำ ไม่ตามเสียง |

**🧪 매일시험 · ข้อผิดที่เคยเจอ**

- **매일시험 6과** — ไม่มีคะแนนตัวเลขบนสแกน · ครูแก้ 2 จุด
  - A (4) รูป → 지도 · 가방 · 시계 · 책상
  - B (3) เลือกจาก 보기: 누가 / 이름 / 직업
  - C (3) เขียนตามคำบอก: 교실입니다 · 그것이 시계입니다 · 우리 반 친구 *(เป็นห้องเรียน · นั่นคือนาฬิกา · เพื่อนร่วมห้อง)* — ที่มา: 우리 교실입니다 = 6-3 · 시계입니다 = 연습 2 · 우리 반 친구입니다 = 읽기
- 복습시험 ①: 읽기 1–2 (ข้อความ 6-2) · 쓰기 B3 (이 사람이 (누구)예요? → 제 동생이에요 *คนนี้คือใคร → น้องของฉัน*) · B4 (저것이 (무엇)입니까? → 휴지통입니다 *โน่นคืออะไร → ถังขยะ*) · 중간시험 복습문제 ข้อ 15 (6과 + ข้อ 3–4: 압둘라 씨 직업 · 누가 일본 사람)
