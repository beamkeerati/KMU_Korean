## 9과 · 도서관은 학생회관 옆에 있어요 (ห้องสมุดอยู่ข้างอาคารสโมสรนักศึกษา)

> [!INTRO] บทนี้ว่าด้วยอะไร
> บทที่ 9 พาออกมาในมหาวิทยาลัย สถานการณ์ในบทคือการถามว่า "จะไปไหน" และ "สถานที่นั้นอยู่ตรงไหน" โดยใช้ร้านค้าและอาคารในอาคารสโมสรนักศึกษาเป็นตัวอย่าง
>
> ไวยากรณ์ใหม่มี 2 เรื่อง:
>
> 1. **위치 명사 + 에 있어요 / 없어요** — คำบอกตำแหน่ง 7 คำ (위, 아래, 앞, 뒤, 옆, 안, 밖) ต่อด้วย 에 เพื่อบอกว่าของหรือสถานที่ "อยู่ตรงไหน"
> 2. **N + 에 가요 / 와요** — บอกจุดหมายว่า "ไป/มา ที่…"
>
> บท 8 บอกที่อยู่ได้แค่ระดับชั้นหรือสถานที่ บท 9 ขยายให้ละเอียดขึ้นว่าอยู่บน ล่าง หน้า หลัง ข้าง ใน หรือนอก คำนามที่อยู่หน้าคำบอกตำแหน่งคือจุดอ้างอิง เช่น 책 옆에 แปลว่า "ข้างหนังสือ" ส่วน 에 ในบทนี้ใช้ทั้ง "อยู่ที่" (에 있어요) และ "ไปที่" (에 가요) ซึ่งต่างจาก 에서 "ทำกิจกรรมที่…" ที่จะเรียนในบท 12
>
> จบบทแล้วจะบอกว่าของ/สถานที่อยู่ตรงไหนด้วยคำบอกตำแหน่ง + 에 있어요 และบอกจุดหมายที่ไปด้วย N에 가요 ได้ และอ่านบทอ่าน 9-2 ซึ่งเป็นข้อความ **낭독시험 ①** ได้
>
> จุดที่คนไทยมักพลาด: ลืม 에 หลังสถานที่ปลายทาง (학생식당하고 가요 ✗) · สับสน 앞 (หน้า) กับ 옆 (ข้าง) และ 위 (บน) กับ 위층 (ชั้นบน) · และตอบคำถาม 뭐가 ด้วยตำแหน่งแทนที่จะตอบเป็นสิ่งของ

### 📝 ไวยากรณ์: 위치 명사 + 에 있어요 / 없어요 — "อยู่/มี ที่ตำแหน่ง…" (ไวยากรณ์ข้อ 05)

ตอนนี้ว่าด้วยคำบอกตำแหน่ง 7 คำ ซึ่งวางหลังคำนามที่เป็นจุดอ้างอิงแล้วต่อด้วย 에 เช่น 책 옆에 (ข้างหนังสือ) ต่อยอดจาก N에 있어요/없어요 ในบท 8 ที่บอกได้แค่ชั้นหรือสถานที่ ตอนนี้บอกได้ละเอียดขึ้น โครงคือ [N] + [ตำแหน่ง] + **에** โดยเว้นวรรคระหว่างนามกับคำบอกตำแหน่ง แล้ว 에 ติดท้ายคำบอกตำแหน่ง

#### รูปแบบ

| คำบอกตำแหน่ง | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| **위** | บน | 책상 위에 *(บนโต๊ะ)* |
| **아래 = 밑** | ล่าง · ใต้ | 의자 아래에 *(ใต้เก้าอี้)* |
| **앞** | หน้า | 지도 앞에 *(หน้าแผนที่)* |
| **뒤** | หลัง | 이리나 씨 뒤에 *(หลังคุณอีรีนา)* |
| **옆** | ข้าง | 책 옆에 *(ข้างหนังสือ)* |
| **안** | ใน | 교실 안에 *(ในห้องเรียน)* |
| **밖** | นอก | 교실 밖에 *(นอกห้องเรียน)* |

#### ตัวอย่างจากตำรา

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 연필이 어디에 있어요? → 책 옆에 있어요. | ดินสออยู่ที่ไหน → อยู่ข้างหนังสือ | ถามที่อยู่ 어디에 ตอบเป็นตำแหน่ง |
| 책상 위에 뭐가 있어요? → 필통이 있어요. | บนโต๊ะมีอะไร → มีกล่องดินสอ | ถามว่ามีอะไร 뭐가 ตอบเป็นสิ่งของ |
| 1층에 빵집이 있어요. | {m:ชั้น 1} {v:มี}{n:ร้านขนมปัง} | ชั้น + 에 |

#### 연습 1 (หน้า 76) — ถามว่าของอยู่ที่ไหน

โครงในตำราคือ "연필이 어디에 있어요? / 책 옆에 있어요." ใต้ภาพ 6 ภาพมีคำ 2 บรรทัด บรรทัดบนคือสิ่งที่ถามและบรรทัดล่างคือตำแหน่งที่ตอบ (ข้อ 1 ซ้ำกับตัวอย่าง) ตำราไม่พิมพ์เฉลย ตัวอย่างตอบจึงต่อจากคำใต้ภาพตามโครงที่พิมพ์

| ข้อ | โจทย์ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 연필 / 책 옆 | 연필이 어디에 있어요? → 책 옆에 있어요. | ดินสออยู่ที่ไหน → อยู่ข้างหนังสือ |
| 2 | 시계 / 이리나 씨 뒤 | 시계가 어디에 있어요? → 이리나 씨 뒤에 있어요. | นาฬิกาอยู่ที่ไหน → อยู่หลังคุณอีรีนา |
| 3 | 가방 / 의자 아래 | 가방이 어디에 있어요? → 의자 아래에 있어요. | กระเป๋าอยู่ที่ไหน → อยู่ใต้เก้าอี้ |
| 4 | 라디오 / 지도 앞 | 라디오가 어디에 있어요? → 지도 앞에 있어요. | วิทยุอยู่ที่ไหน → อยู่หน้าแผนที่ |
| 5 | 이리나 / 교실 안 | 이리나 씨가 어디에 있어요? → 교실 안에 있어요. | คุณอีรีนาอยู่ที่ไหน → อยู่ในห้องเรียน |
| 6 | 간토야 / 교실 밖 | 간토야 씨가 어디에 있어요? → 교실 밖에 있어요. | คุณคันโตยะอยู่ที่ไหน → อยู่นอกห้องเรียน |

ใต้แบบฝึกมีกรอบ 위치 명사 *(คำบอกตำแหน่ง)* ที่วาดกล่องกับลูกบอลแดงให้ดูครบทั้ง 7 คำ ตรงกับตาราง "รูปแบบ" ข้างบนทุกคำ

#### 연습 2 (หน้า 77) — ถามว่าตรงนั้นมีอะไร

โครงในตำราคือ "책상 위에 뭐가 있어요? / 필통이 있어요." คราวนี้ถามด้วย 뭐가 แล้วตอบเป็นสิ่งของ + 이/가 ใต้ภาพ 6 ภาพมีคำ 2 บรรทัด บรรทัดบนคือตำแหน่งที่ถามและบรรทัดล่างคือของที่ตอบ (ข้อ 1 ซ้ำกับตัวอย่าง) ตำราไม่พิมพ์เฉลย

| ข้อ | โจทย์ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 책상 위 / 필통 | 책상 위에 뭐가 있어요? → 필통이 있어요. | บนโต๊ะมีอะไร → มีกล่องดินสอ |
| 2 | 선생님 뒤 / 칠판 | 선생님 뒤에 뭐가 있어요? → 칠판이 있어요. | หลังครูมีอะไร → มีกระดานดำ |
| 3 | 의자 옆 / 우산 | 의자 옆에 뭐가 있어요? → 우산이 있어요. | ข้างเก้าอี้มีอะไร → มีร่ม |
| 4 | 간토야 씨 앞 / 텔레비전 | 간토야 씨 앞에 뭐가 있어요? → 텔레비전이 있어요. | หน้าคุณคันโตยะมีอะไร → มีโทรทัศน์ |
| 5 | 필통 안 / 볼펜 | 필통 안에 뭐가 있어요? → 볼펜이 있어요. | ในกล่องดินสอมีอะไร → มีปากกา |
| 6 | 창문 밖 / 나무 | 창문 밖에 뭐가 있어요? → 나무가 있어요. | นอกหน้าต่างมีอะไร → มีต้นไม้ |

#### 연습 3 (หน้า 77) — ดูภาพโต๊ะแล้วถามว่าของอยู่ที่ไหน

ตัวอย่างในตำราคือ "책이 어디에 있어요? / 책상 위에 있어요." ซึ่งเป็นประโยคเดียวกับบทสนทนาเปิด 준비 1 ตำราให้ดูภาพโต๊ะกับเก้าอี้ที่มีของวางอยู่หลายอย่างแล้วถาม-ตอบตามกรอบ ไม่พิมพ์รายการของและไม่พิมพ์เฉลย ตารางข้างล่างเลือกของที่เห็นในภาพ ส่วนชื่อ 신발 *(รองเท้า)* ตำราไม่พิมพ์ไว้ มีแต่ที่จดเพิ่มด้วยดินสอในเล่ม

| ของในภาพ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|
| 책 | 책이 어디에 있어요? → 책상 위에 있어요. | หนังสืออยู่ที่ไหน → อยู่บนโต๊ะ (ตัวอย่างในตำรา) |
| 컴퓨터 | 컴퓨터가 어디에 있어요? → 책상 위에 있어요. | คอมพิวเตอร์อยู่ที่ไหน → อยู่บนโต๊ะ |
| 필통 | 필통이 어디에 있어요? → 책상 위에 있어요. | กล่องดินสออยู่ที่ไหน → อยู่บนโต๊ะ |
| 가방 | 가방이 어디에 있어요? → 책상 아래에 있어요. | กระเป๋าอยู่ที่ไหน → อยู่ใต้โต๊ะ |
| 휴지통 | 휴지통이 어디에 있어요? → 책상 옆에 있어요. | ถังขยะอยู่ที่ไหน → อยู่ข้างโต๊ะ |
| 신발 | 신발이 어디에 있어요? → 의자 아래에 있어요. | รองเท้าอยู่ที่ไหน → อยู่ใต้เก้าอี้ |

#### เลือก 은/는 หรือ 이/가

- ของที่พูดถึงแล้วใช้ 은/는: 도서관은 어디에 있어요? *(ห้องสมุดอยู่ที่ไหน)*
- ของใหม่หรือคำตอบใช้ 이/가: 연필이 *(ดินสอ)* · 필통이 *(กล่องดินสอ)* (ไวยากรณ์ข้อ 01)

#### 📽️ จากสไลด์อาจารย์ (문법 1 · ตำราหน้า 76)

ครูวงกลม **명사** กับ **에** สีแดง แล้วโยงสองประโยคที่ความหมายเท่ากัน

- โครงประโยค: \_\_\_이/가 \_\_\_에 있어요. = \_\_\_에 \_\_\_이/가 있어요.
- ตัวอย่าง: 볼펜이 책상 위에 있어요. = 책상 위에 볼펜이 있어요. *(ปากกาอยู่บนโต๊ะ = บนโต๊ะมีปากกา)*
- สรุป: บอกที่ตั้งได้สองลำดับ

#### ⚠️ ระวัง

- 앞 ≠ 옆 (หน้า ≠ ข้าง): 서점 **앞**에 우체국 *(หน้าร้านหนังสือมีไปรษณีย์)*
- 위 ≠ 위층 (บน ≠ ชั้นบน): 우체국 **위층**에 학생 식당 *(ชั้นบนของไปรษณีย์มีโรงอาหารนักศึกษา)*
- 아래 = 밑 ใช้แทนกันได้
- ถาม 무엇이/뭐가 ต้องตอบเป็น "สิ่งของ" ไม่ใช่ตำแหน่ง: 창문 밖에 무엇이 있어요? → 나무가 있어요. ✓ *(นอกหน้าต่างมีอะไร → มีต้นไม้)* (매일시험 B7 ⚠️)

→ เจาะลึก: ไวยากรณ์ข้อ 05 (เล่ม 2)

### 📝 ไวยากรณ์: N + 에 가요 / 와요 — "ไป/มา ที่…" (ไวยากรณ์ข้อ 09)

ตอนนี้ว่าด้วยการบอกจุดหมายของการไปและการมา วางสถานที่ปลายทางแล้วต่อด้วย 에 ก่อน 가요 (ไป) หรือ 와요 (มา) ทุกครั้ง ประธานใช้ 은/는 ได้ตามปกติ และเมื่อถามด้วย 어디에 ก็ตอบด้วยสถานที่ + 에 ได้เลย

#### รูปแบบ

| โครงประโยค | ความหมาย |
|:---|:---|
| สถานที่ + **에** + 가요 | ไปที่… |
| สถานที่ + **에** + 와요 | มาที่… |

#### ตัวอย่างจากตำรา

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 학교에 가요. | ไปโรงเรียน | สถานที่ + 에 + 가요 |
| 중국에 가요. | ไปจีน | ใช้กับประเทศได้ |
| 백화점에 가요. | ไปห้าง | สถานที่ + 에 + 가요 |
| 어디에 가요? → 우체국에 가요. | ไปไหน → ไปไปรษณีย์ | ถามจุดหมาย 어디에 |
| 바트 씨는 어디에 가요? → 은행에 가요. | คุณบาตไปไหน → ไปธนาคาร | ประธานใช้ 은/는 ได้ |
| 도서관에 가요? → 아니요, 서점에 가요. | ไปห้องสมุดหรือ → ไม่ ไปร้านหนังสือ | ถามยืนยัน |

#### 연습 1 (หน้า 78) — ถามว่าไปไหน

โครงในตำราคือ "어디에 가요? / 우체국에 가요." แบบฝึกให้ดูภาพสถานที่ 5 ภาพแล้วตอบด้วยสถานที่ + 에 가요 (ข้อ 1 ซ้ำกับตัวอย่าง) ตำราไม่พิมพ์เฉลย

| ข้อ | สถานที่ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 우체국 | 우체국에 가요. | ไปไปรษณีย์ |
| 2 | 병원 | 병원에 가요. | ไปโรงพยาบาล |
| 3 | 미용실 | 미용실에 가요. | ไปร้านเสริมสวย |
| 4 | 공항 | 공항에 가요. | ไปสนามบิน |
| 5 | 식당 | 식당에 가요. | ไปร้านอาหาร |

#### 연습 2 (หน้า 79) — ถามยืนยันแล้วแก้เป็นที่ถูก

โครงในตำราคือ "도서관에 가요? / 아니요, 서점에 가요." ใต้ภาพ 6 ภาพมีคำ 2 บรรทัด บรรทัดบนคือที่ที่ถามผิดและบรรทัดล่างคือที่ที่ไปจริง (ข้อ 1 ซ้ำกับตัวอย่าง) ตำราไม่พิมพ์เฉลย

| ข้อ | ถามผิด → ที่จริง | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 도서관 → 서점 | 도서관에 가요? → 아니요, 서점에 가요. | ไปห้องสมุดหรือ → ไม่ ไปร้านหนังสือ |
| 2 | 영화관 → PC방 | 영화관에 가요? → 아니요, PC방에 가요. | ไปโรงหนังหรือ → ไม่ ไปร้านอินเทอร์เน็ตคาเฟ่ |
| 3 | 우체국 → 은행 | 우체국에 가요? → 아니요, 은행에 가요. | ไปไปรษณีย์หรือ → ไม่ ไปธนาคาร |
| 4 | 식당 → 커피숍 | 식당에 가요? → 아니요, 커피숍에 가요. | ไปร้านอาหารหรือ → ไม่ ไปร้านกาแฟ |
| 5 | 병원 → 약국 | 병원에 가요? → 아니요, 약국에 가요. | ไปโรงพยาบาลหรือ → ไม่ ไปร้านขายยา |
| 6 | 학교 → 미용실 | 학교에 가요? → 아니요, 미용실에 가요. | ไปโรงเรียนหรือ → ไม่ ไปร้านเสริมสวย |

#### 연습 3 (หน้า 79) — ดูแผนที่แล้วถามว่าแต่ละคนไปไหน

โครงในตำราคือ "바트 씨는 어디에 가요? / 은행에 가요." แผนที่มีคน 7 คนยืนอยู่หน้าร้านต่าง ๆ ให้ถามว่าแต่ละคนไปที่ไหน ตำราไม่พิมพ์เฉลย ตัวอย่างตอบอ่านจากร้านที่อยู่ข้างตัวคนในแผนที่ (คู่ 간토야 กับ 미용실 และ 장핑 กับ PC방 ตัดสินจากตำแหน่งที่ยืน)

| คน | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|
| 바트 | 바트 씨는 어디에 가요? → 은행에 가요. | คุณบาตไปไหน → ไปธนาคาร (ตัวอย่างในตำรา) |
| 마키 | 마키 씨는 어디에 가요? → 커피숍에 가요. | คุณมากิไปไหน → ไปร้านกาแฟ |
| 투이 | 투이 씨는 어디에 가요? → 식당에 가요. | คุณทุยไปไหน → ไปร้านอาหาร |
| 알렉세이 | 알렉세이 씨는 어디에 가요? → 도서관에 가요. | คุณอเล็กเซย์ไปไหน → ไปห้องสมุด |
| 간토야 | 간토야 씨는 어디에 가요? → 미용실에 가요. | คุณคันโตยะไปไหน → ไปร้านเสริมสวย |
| 장핑 | 장핑 씨는 어디에 가요? → PC방에 가요. | คุณจางผิงไปไหน → ไปร้านอินเทอร์เน็ตคาเฟ่ |
| 제프리 | 제프리 씨는 어디에 가요? → 우체국에 가요. | คุณเจฟฟรีย์ไปไหน → ไปไปรษณีย์ |

#### 📽️ จากสไลด์อาจารย์ (문법 2 · ตำราหน้า 78)

สไลด์ให้โครง \_\_\_이/가 \_\_\_에 가요. แล้วครูเขียนสีน้ำเงินเพิ่มอีก 2 อย่าง

- สีน้ำเงิน: **\_\_\_은/는 \_\_\_에 가요 / 와요**
- สีน้ำเงิน: **장소(명사)에 가다**
- ตัวอย่างถาม-ตอบ: 가: 어디에 가요? 나: 도서관에 가요. *(ไปไหน → ไปห้องสมุด)*
- สรุป: จุดหมายต้องตามด้วย 에 แล้วจึง 가요 (ไป) / 와요 (มา)

#### ⚠️ ระวัง

- 학생식당**하고** 가요 ✗ → 학생식당**에** 가요 ✓ (복습시험 ① เสีย 4 — เห็น 하고 อยู่ใน 보기 เลยหยิบมาใช้)
- "ไป/มา" ต้องมี [สถานที่] + 에 เสมอ
- 에 ใช้ทั้ง "อยู่ที่" (에 있어요) และ "ไปที่" (에 가요) ส่วน "ทำกิจกรรมที่…" ใช้ 에서 (บท 12) — ไวยากรณ์ข้อ 09

→ เจาะลึก: ไวยากรณ์ข้อ 09 (เล่ม 2)

### 💬 대화 9-1 — ไปไหน ห้องสมุดอยู่ที่ไหน

제프리 (เจฟฟรีย์) เจอ 마키 (มากิ) แล้วถามว่าไปไหน 마키 ตอบว่าไปห้องสมุด เจฟฟรีย์จึงถามต่อว่าห้องสมุดอยู่ที่ไหน บทสนทนานี้ใช้ทั้ง N에 가요 (บอกจุดหมาย) และคำบอกตำแหน่ง + 에 있어요 (บอกที่ตั้ง)

> 제프리: 마키 씨, 어디에 가요? *(คุณมากิ ไปไหนครับ)*
>
> 마키: 도서관에 가요. *(ไปห้องสมุดค่ะ)*
>
> 제프리: 도서관은 어디에 있어요? *(ห้องสมุดอยู่ที่ไหนครับ)*
>
> 마키: 학생회관 옆에 있어요. *(อยู่ข้างอาคารสโมสรนักศึกษาค่ะ)*

#### สังเกตจากบทสนทนา

- 어디에 가요? — ถามจุดหมาย ตอบด้วย N에 가요
- 어디에 있어요? — ถามที่ตั้ง ตอบด้วยคำบอกตำแหน่ง + 에 있어요 (학생회관 옆에)
- 도서관은 — ห้องสมุดถูกพูดถึงแล้วจึงใช้ 은 ไม่ใช่ 이

#### 확인 — คำถามท้ายบทสนทนา

คำถามในตำรา เฉลยหาได้จากบทสนทนาข้างบน

- 마키 씨는 학생회관에 가요? → 아니요, 도서관에 가요. *(คุณมากิไปอาคารสโมสรนักศึกษาหรือ → ไม่ ไปห้องสมุด)*
- 도서관은 학생회관에 있어요? → 아니요, 학생회관 옆에 있어요. *(ห้องสมุดอยู่ในอาคารสโมสรนักศึกษาหรือ → ไม่ อยู่ข้างอาคาร)*

#### ฝึกสลับ

เปลี่ยนร้านกับตำแหน่งตามตารางแล้วพูดบทสนทนาเดิม เช่น 식당은 어디에 있어요? → 은행 앞에 있어요. *(ร้านอาหารอยู่ที่ไหน → อยู่หน้าธนาคาร)*

| ร้าน | ตำแหน่ง |
|:---|:---|
| 도서관 *(ห้องสมุด)* | 학생회관 옆 *(ข้างอาคารสโมสรนักศึกษา — แถวนี้คือบทสนทนาเดิม)* |
| 식당 *(ร้านอาหาร)* | 은행 앞 *(หน้าธนาคาร)* |
| 미용실 *(ร้านเสริมสวย)* | 식당 뒤 *(หลังร้านอาหาร)* |
| 빵집 *(ร้านขนมปัง)* | 커피숍 아래 *(ใต้ร้านกาแฟ)* |
| 문구점 *(ร้านเครื่องเขียน)* | 은행 위 *(เหนือธนาคาร)* |
| 안경점 *(ร้านแว่น)* | 학생회관 안 *(ในอาคารสโมสรนักศึกษา)* |

#### 활동 (หน้า 81–82) — ถามที่ตั้งของร้านจากการ์ด A/B

กิจกรรมคู่แบบช่องว่างข้อมูล ตำราสั่งว่า "다음과 같이 카드에 있는 장소에 대해 친구에게 물어봅시다." *(ถามเพื่อนเรื่องสถานที่ในการ์ดตามตัวอย่างข้างล่าง)* นักเรียน A ถือหน้า 81 และนักเรียน B ถือหน้า 82 ต่างคนมีภาพตึก 2 หลังที่บางช่องว่างอยู่ ต้องฟังอีกฝ่ายพูดแล้วเติมช่องว่างให้ถูกที่

- 학생 A 1: 친구가 어디에 가요? 친구의 말을 듣고 그림에 표시하세요. *(เพื่อนไปไหน ฟังที่เพื่อนพูดแล้วทำเครื่องหมายบนภาพ)*
- 학생 A 2: 나는 어디에 가요? 그림을 보고 친구에게 말해 주세요. *(ฉันไปไหน ดูภาพแล้วบอกเพื่อน — การ์ด 은행 · 우체국 · 커피숍 · 문구점)*
- 학생 B 1: 나는 어디에 가요? 그림을 보고 친구에게 말해 주세요. *(ฉันไปไหน ดูภาพแล้วบอกเพื่อน — การ์ด 안경점 · 서점 · 식당 · 병원)*
- 학생 B 2: 친구는 어디에 가요? 친구의 말을 듣고 그림에 표시하세요. *(เพื่อนไปไหน ฟังที่เพื่อนพูดแล้วทำเครื่องหมายบนภาพ)*

บทสนทนาตัวอย่างในตำรา (พิมพ์ซ้ำทั้งหน้า A และหน้า B) คือ

- 가: 어디에 가요? *(ไปไหน)*
- 나: 안경점에 가요. *(ไปร้านแว่น)*
- 가: 안경점은 어디에 있어요? *(ร้านแว่นอยู่ที่ไหน)*
- 나: PC방 옆에 있어요. *(อยู่ข้างร้านอินเทอร์เน็ตคาเฟ่)*

ภาพของ A และ B เมื่อรวมกันได้ผังเต็มของตึก 2 หลัง (ตึกละ 2 แถว แถวละ 3 ร้าน) ตารางข้างล่างเรียงจากซ้ายไปขวา ตำราไม่พิมพ์ผังเต็ม ผังนี้ประกอบจากช่องที่พิมพ์ไว้ทั้งสองหน้า

| ตึก | แถว | ซ้าย — กลาง — ขวา |
|:---|:---|:---|
| ตึกบน | บน | 미용실 — 안경점 — PC방 |
| ตึกบน | ล่าง | 식당 — 문구점 — 서점 |
| ตึกล่าง | บน | 병원 — 커피숍 — 은행 |
| ตึกล่าง | ล่าง | 빵집 — 우체국 — 약국 |

### 📖 읽기 9-2 · 🎧 듣기 — อาคารสโมสรนักศึกษา

บทอ่านเล่าว่าในอาคารสโมสรนักศึกษามีร้านอะไรอยู่ตรงไหนบ้าง **นี่คือข้อความ 낭독시험 ① (อ่านออกเสียง)** และเป็นแหล่งของข้อสอบเขียนตามคำบอก

> 우리는 매일 학생회관에 가요. *(พวกเราไปอาคารสโมสรนักศึกษาทุกวัน)* 학생회관에 가게가 많이 있어요. *(ที่อาคารมีร้านค้าเยอะ)*
>
> 1층에 빵집이 있어요. *({m:ชั้น 1} {v:มี}{n:ร้านขนมปัง})* 빵집 옆에 서점이 있어요. *(ข้างร้านขนมปังมีร้านหนังสือ)*
>
> 서점 안에 학생들이 많이 있어요. *(ในร้านหนังสือมีนักศึกษาเยอะ)* 서점 **앞**에 우체국이 있어요. *(หน้าร้านหนังสือมีไปรษณีย์)*
>
> 우체국 위층에 학생 식당이 있어요. *(ชั้นบนของไปรษณีย์มีโรงอาหารนักศึกษา)* 식당 음식이 맛있어요. *(อาหารของโรงอาหารอร่อย)*

#### ⚠️ ข้อสังเกตจากสไลด์และสมุดจดของคุณ

สไลด์และสมุดจดมีรายละเอียด 3 อย่างที่ต้องจำ

- สไลด์/สมุดจดไฮไลต์ 에 สีเขียว และ 이/가 สีชมพู พร้อมขีดเส้นใต้ 옆에 · 위층에 · 안에 · 많이
- ประโยคที่ 6 ในสไลด์เขียน 서점 **옆**에 แต่ตำราและ 중간시험 복습문제 ใช้ **앞** → ยึดตามตำรา
- ข้อสอบดัดแปลงข้อความได้: 복습시험 ① ข้อ 3–6 ใช้ **서점 위층에** 학생 식당이 있어요 *(ชั้นบนของร้านหนังสือมีโรงอาหารนักศึกษา)*

#### ก่อนอ่าน (หน้า 83) — อาคารสโมสรนักศึกษาของโรงเรียนเรา

ในตำราหัวข้อนี้อยู่ก่อนบทอ่าน ให้ถามกันว่าอาคารสโมสรนักศึกษาของโรงเรียนอยู่ที่ไหนและแต่ละชั้นมีอะไร ตำราไม่พิมพ์เฉลย ใช้ประโยคจากบทอ่านเป็นตัวอย่างตอบ

- 우리 학교 학생회관은 어디에 있어요? 몇 층에 무엇이 있어요? *(อาคารสโมสรนักศึกษาของโรงเรียนเราอยู่ที่ไหน ชั้นไหนมีอะไรบ้าง)*
- 1층에 빵집이 있어요. *(ชั้น 1 มีร้านขนมปัง)*

#### คำถามท้ายบทอ่าน

คำถามมีทั้งแบบถาม-ตอบและแบบ O/X ที่ตอบจากบทอ่านข้างบน

| คำถาม | คำตอบ |
|:---|:---|
| 우리는 매일 어디에 가요? *(พวกเราไปไหนทุกวัน)* | 학생회관에 가요. *(ไปอาคารสโมสรนักศึกษา)* |
| 학생회관 1층에 무엇이 있어요? *(ชั้น 1 ของอาคารมีอะไร)* | 빵집이 있어요. *(มีร้านขนมปัง)* |
| 빵집은 1층에 있어요. *(ร้านขนมปังอยู่ชั้น 1)* | **○** ถูก |
| 우체국 옆에 서점이 있어요. *(ข้างไปรษณีย์มีร้านหนังสือ)* | **×** ผิด — 빵집 옆에 서점 · 서점 앞에 우체국 |
| 식당은 1층에 있어요. *(โรงอาหารอยู่ชั้น 1)* | **×** ผิด — เป็น 2층 อยู่เหนือไปรษณีย์ |

#### 다 — ฟังแล้วอ่านตาม (ขีดเส้นใต้เพื่อเน้น)

ตำราให้ฟังแทร็ก 9-3 แล้วอ่านตาม โดยตั้งใจที่ส่วนที่ขีดเส้นใต้ในแต่ละประโยค ตัวหนาข้างล่างคือส่วนที่ขีดเส้นใต้ในตำรา (ข้อ 2 ขีดทั้ง 많이 และ 있어요 ข้อ 4 ขีดทุกคำ)

- **학생회관에** 가요. *(ไปอาคารสโมสรนักศึกษา)*
- 가게가 **많이 있어요.** *(มีร้านค้าเยอะ)*
- **빵집 옆에** 있어요. *(อยู่ข้างร้านขนมปัง)*
- **식당 음식이 맛있어요.** *(อาหารของโรงอาหารอร่อย)*

#### 9-3 라 — แปลงบทอ่านเป็นบทสนทนา

ตำราให้เติมคำตอบจากบทอ่าน ตัวอย่างข้างล่างคือคำตอบที่เติมได้ทั้ง 5 คู่

- 빵집이 어디에 있어요? → 학생회관 1층에 있어요. *(ร้านขนมปังอยู่ที่ไหน → ชั้น 1 ของอาคารสโมสรนักศึกษา)*
- 그럼, 서점은 어디에 있어요? → 빵집 옆에 있어요. *(งั้นร้านหนังสืออยู่ที่ไหน → ข้างร้านขนมปัง)*
- 서점 앞에 뭐가 있어요? → 우체국이 있어요. *(หน้าร้านหนังสือมีอะไร → มีไปรษณีย์)*
- 학생 식당은 어디에 있어요? → 우체국 위층에 있어요. *(โรงอาหารนักศึกษาอยู่ที่ไหน → ชั้นบนของไปรษณีย์)*
- 학생 식당 음식이 맛있어요? → 네, 맛있어요. *(อาหารโรงอาหารอร่อยไหม → ค่ะ อร่อย)*

#### 활동 (หน้า 84) — คุยกับเพื่อนเรื่องที่ไปทุกวัน

ตำราให้คุยกับเพื่อนว่าทุกวันไปไหนและแถวนั้นมีอะไรบ้าง ตำราไม่พิมพ์เฉลย ตัวอย่างตอบใช้ประโยคจากบทอ่าน 9-2

- 친구와 말해 봅시다. 매일 어디에 가요? 그 근처에 무엇이 있어요? *(คุยกับเพื่อน ทุกวันไปไหน แถวนั้นมีอะไรบ้าง)*
- 우리는 매일 학생회관에 가요. *(พวกเราไปอาคารสโมสรนักศึกษาทุกวัน)*
- 학생회관에 가게가 많이 있어요. *(ที่อาคารมีร้านค้าเยอะ)*

#### 📌 Culture ท้ายบท — 한국인의 이름

หน้า Culture ท้ายบทอธิบายชื่อคนเกาหลีและวิธีเรียกชื่อ ชื่อ = นามสกุล + ชื่อตัว (이지훈 = 이 + 지훈) และเรียกคนได้ 2 แบบ คือใช้ตำแหน่งหรือใช้ 씨

| วิธีเรียก | ตัวอย่าง | ความหมาย |
|:---|:---|:---|
| นามสกุล + ตำแหน่ง | 김 선생님 | ครูคิม |
| ชื่อเต็ม + ตำแหน่ง | 김민수 선생님 | ครูคิมมินซู |
| ชื่อเต็ม + 씨 | 이지훈 씨 | คุณอีจีฮุน |
| ชื่อตัว + 씨 | 지훈 씨 | คุณจีฮุน |

ห้ามต่อ 씨 ในกรณีต่อไปนี้ (✗)

- ✗ 씨 หลังนามสกุลอย่างเดียว
- ✗ 선생님 씨 *(ครู)*
- ✗ 의사 씨 *(หมอ)*
- ✗ 엄마 씨 *(แม่)*
- ✗ 오빠 씨 *(พี่ชาย)*

ภาพประกอบหน้านี้มีคำทักทายตัวอย่างที่ใช้เรียกครูและเพื่อน

- 김민수 선생님, 안녕하세요? *(ครูคิมมินซู สวัสดีครับ)*
- 윤아 씨, 안녕하세요? *(คุณยุนอา สวัสดีครับ)*
- 압둘라 씨, 안녕하세요? *(คุณอับดุลลา สวัสดีครับ)*

ท้ายหน้ามีกิจกรรม 해 봅시다 *(ลองทำดู)* 2 ข้อ

- 1급 선생님을 불러 봅시다. *(ลองเรียกครูระดับ 1 ด้วยวิธีเรียกที่ถูก)*
- 반 친구 이름을 불러 봅시다. *(ลองเรียกชื่อเพื่อนร่วมห้องด้วยวิธีเรียกที่ถูก)*

### 🔊 발음

บทนี้มีเสียงที่อ่านต่างจากตัวเขียน 4 เรื่อง คือการเชื่อมเสียงตัวสะกดกับสระ (연음) การที่ ㄱ ท้ายพยางค์ทำให้พยัญชนะถัดไปเป็นเสียงเข้ม การที่ ㅎ ไม่ออกเสียง และ ㄱ + ㅅ ที่เป็น ㅆ

| เขียน | อ่าน | กฎ |
|:---|:---|:---|
| 도서관에 · 우체국에 · 서점에 | [도서과네] · [우체구게] · [서저메] | 연음: 받침 + 에 → ย้ายตัวสะกด |
| 식당 · 약국 · 학교 | [식땅] · [약꾹/야꾹] · [학꾜/하꾜] | 받침 ㄱ ทำให้พยัญชนะถัดไปเป็นเสียงเข้ม (ㄷ → ㄸ · ㄱ → ㄲ) |
| 옆에 · 안에 · 많이 | [여페] · [아네] · [마니] | ㅍ/ㄴ ย้ายไปขึ้นพยางค์ถัดไป · ㅎ ไม่ออกเสียง |
| 식당 음식이 · 맛있어요 | [식땅 음시기] · [마시써요] | 9-3 ตำราขีดเส้นใต้ — 연음 (อ่านตามกฎ) |
| 학생회관에 | [학쌩회과네] | ㄱ + ㅅ → ㅆ + 연음 |

เขียนตามรูปคำ ไม่ใช่ตามเสียง: [만이] ✗ → 많이 และ [임시기 마시서요] ✗ → 음식이 맛있어요

### 🧪 ออกสอบอย่างไร

บทนี้ออกสอบเป็นแบบทดสอบประจำวัน 9과 และเนื้อหากลับมาใน 복습시험 ① กับ 중간시험 복습문제 หลายข้อ ด้านล่างคือสิ่งที่ครูแก้และข้อผิดที่เคยเจอ

- **매일시험 9과** — ไม่มีคะแนนตัวเลขบนสแกน · ครูแก้ 4 จุด
  - A (4 ข้อ) ดูรูปแล้วเขียน: 은행 · 공항 · 약국 · 우체국
  - B (3 ข้อ) ตอบตำแหน่ง (มาจาก 연습 ของตำรา):
        - 의자 아래에 있어요 *(อยู่ใต้เก้าอี้)*
        - 필통 안에 있어요 *(อยู่ในกล่องดินสอ)*
        - 나무가 있어요 *(มีต้นไม้)*
  - C (3 ข้อ) เขียนตามคำบอก:
        - 학생회관 뒤 *(ด้านหลังอาคารสโมสรนักศึกษา)* — ไม่พบในตำรา คาดว่ามาจากเสียงฟัง
        - 많이 있어요 *(มีเยอะ)* — มาจาก 읽기
        - 음식이 맛있어요 *(อาหารอร่อย)* — มาจาก 읽기
- 복습시험 ① 쓰기 A2: 매일 학생식당(에) 가요 *(ไปโรงอาหารทุกวัน)*
- 복습시험 ① 쓰기 D1: 책상 위에 컴퓨터가 있어요 *(บนโต๊ะมีคอมพิวเตอร์)*
- 복습시험 ① 읽기 3–6 (ข้อความ 9-2 ดัดแปลง)
- 복습시험 ① 듣기 4–7 (ชั้น O/X — ดูบท 8)
- 중간시험 복습문제 ข้อ 7 (ภาพห้อง): 고양이가 테이블 (  )에 있어요 *(แมวอยู่…โต๊ะ)* … ×10
- 중간시험 복습문제 ข้อ 12-3: 컴퓨터 / 있다 / 책상 위
- 중간시험 복습문제 ข้อ 15 ข้อ 7–8:
  - 빵집은 1층 (O) *(ร้านขนมปังอยู่ชั้น 1 = ถูก)*
  - 우체국 옆에 서점 (X — ผิดเพราะบทอ่านคือ 서점 앞에 우체국) *(ข้างไปรษณีย์มีร้านหนังสือ = ผิด)*

> [!WARNING] ที่เคยพลาด (매일시험 · 복습시험 ① · ดูก่อนสอบ)
> - ✗ B7 ตอบเป็นตำแหน่งแทนสิ่งของ (ต้อง 나무가 있어요)
> - ✗ C8 학생웍 → **학생회관**
> - ✗ C9 만이 → **많이**
> - ✗ C10 임시기 마시서요 → **음식이 맛있어요** (เขียนตามเสียง)
> - ★ ㅐ/ㅔ: เขียน 메일 แทน **매일** ในงานเขียนของคุณ (คำนี้อยู่ในประโยคแรกของ 읽기)
> - ★ 학생식당**하고** 가요 → 학생식당**에** 가요 (복습시험 ① −4)
> - ★ ตอบ 어디에 → ตำแหน่ง / 뭐가 → สิ่งของ

### 🔗 เชื่อมโยง

← ต่อยอดจาก

- 8과 N에 있어요/없어요 (몇 층에) → ขยายเป็นคำบอกตำแหน่งละเอียดขึ้น
- 6과 이/가 (뭐가? 누가?) → 필통이 있어요
- 5과 은/는 → 바트 씨는 어디에 가요?

→ ใช้ต่อใน

- 12과 N에 가요 ↔ N에서 해요 (ไปที่ ↔ ทำที่)
- 15과 있어요 → 계세요 (어머니가 고향에 계세요 *(คุณแม่อยู่ที่บ้านเกิด)*)
- 17과 N에서 왔어요 (학교에 와요 มาที่ ↔ 몽골에서 왔어요 *(มาจากมองโกเลีย)*)
- 18과 N에 V-(으)러 가요 (도서관에 책을 빌리러 가요 *(ไปห้องสมุดเพื่อยืมหนังสือ)*)

> [!SUMMARY] สรุปท้ายบท
> - คำบอกตำแหน่งมี 7 คำ (บน ล่าง หน้า หลัง ข้าง ใน นอก) ใช้โครง [N] + [ตำแหน่ง] + 에 + 있어요/없어요 โดยเว้นวรรคระหว่างนามกับตำแหน่ง และบอกที่ตั้งได้ 2 ลำดับ
> - ไป/มา ต้องมีสถานที่ + 에 เสมอ (학생식당에 가요 ✓ · 학생식당하고 가요 ✗) ส่วนทำกิจกรรมที่… ใช้ 에서 (บท 12)
> - ถาม 어디에 → ตอบตำแหน่ง · ถาม 뭐가/무엇이 → ตอบสิ่งของ · ของที่พูดถึงแล้วใช้ 은/는 ของใหม่หรือคำตอบใช้ 이/가
> - ข้อสอบ: เขียนตามคำบอกจาก 읽기 9-2 · ตอบตำแหน่ง · 낭독시험 ① · ข้อผิดที่เห็นคือ 앞 ↔ 옆 และ 위 ↔ 위층
> - ข้อผิดที่ต้องระวัง: เขียนตามเสียง ([만이] แทน 많이 · 임시기 แทน 음식이) · 메일 แทน 매일 · ㅐ/ㅔ
