**📝 ไวยากรณ์**

1. **N-(으)로** (ทิศทาง) — "ไปทาง… / ไปที่ทิศ…" · (ไวยากรณ์ข้อ 49)
   - คำนาม**ลงท้ายพยัญชนะ** → **-으로**: 오른쪽으로 · 3층으로 · 밖으로 · 안으로 · 시청으로 / **ลงท้ายสระหรือ ㄹ** → **-로**: 교실로 · 서울로 · 거기로
   - กล่องตำรา: ต่อท้ายคำนามเพื่อบอก**ทิศทางของการเคลื่อนที่** ใช้บ่อยกับ 가다 · 오다 · 내려가다 · 올라가다 · 들어가다 · 들어오다 · 나오다
   - ตัวอย่างบทสนทนา: 약국이 어디에 있어요? → 사거리에서 오른쪽으로 가세요 *(ร้านขายยาอยู่ที่ไหน → ที่สี่แยกให้ไปทางขวา)* · 저는 프랑스로 여행을 가고 싶어요 *(ฉันอยากไปเที่ยวฝรั่งเศส)* · 3층으로 올라가십시오 *(เชิญขึ้นไปชั้น 3)* · 쉬는 시간이 끝났으니까 교실로 들어오세요 *(หมดเวลาพักแล้ว เข้าห้องเรียนด้วย)*
   - 연습 1 (ดูไอคอน บอกทิศ): 왼쪽으로 가세요 *(ไปทางซ้าย)* · 밖으로 나오세요 *(ออกไปข้างนอก)* · 안으로 들어가세요 *(เข้าไปข้างใน)* · 9층으로 올라가세요 *(ขึ้นไปชั้น 9)* · 1층으로 내려가세요 *(ลงไปชั้น 1)* · 🖼️ ไอคอนคนเดิน ลูกศร ประตูเข้า-ออก บันไดขึ้น 9F ลงมา 1F
   - 연습 2 (보기 우체국이 어디에 있어요? → 오른쪽으로 가세요): 1. 우체국 / 오른쪽 / 가다 (🖼️ ป้ายไปรษณีย์ ลูกศรขวา 300m) · 2. PC방 / 2층 / 올라가다 → PC방이 어디에 있어요? 2층으로 올라가세요 · 3. 병원 / 3번 출구 / 나가다 → 3번 출구로 나가세요 · 4. 교실 / 건물 안 / 들어가다 → 건물 안으로 들어가세요 · 5. 주차장 / 지하 1층 / 내려가다 → 지하 1층으로 내려가세요 *(ตัวอย่างตอบตามกฎ)*
   - 연습 3 (🖼️ แผนที่สี่แยก: 제프리 อยู่ด้านล่าง · 마키 อยู่ด้านซ้าย · ร้านขนม · ร้านขายยา · ไปรษณีย์ · ห้าง · โรงพยาบาล · ลูกศรขึ้นเขียนว่า 시청쪽): 제프리: 우체국에 가고 싶어요. 그런데 우체국에 어떻게 가요? → 지훈: 사거리에서 오른쪽으로 가세요 *(อยากไปไปรษณีย์ ไปยังไง → ที่สี่แยกไปทางขวา)* · ตารางให้เติมทางไป: 제프리 → 우체국 · 빵집 · 약국 / 마키 → 백화점 · 병원 *(ตำราเว้นว่าง — ตอบตามภาพ ภาพเล็ก)*
   - ⚠️ **에 = จุดหมาย** (우체국에 가요) ↔ **(으)로 = ทิศทาง/ช่องทาง** (우체국으로 가요) — ตำราสอนให้ตอบ "어떻게 가요?" ด้วยทิศ + (으)로 · ★ ㄹ ท้ายใช้ **로** ไม่ใช่ 으로: 서울로 ✓ 서울으로 ✗ · (으)로 ที่ 31과 เป็นอีกความหมาย "ด้วยวิธี/พาหนะ" (ข้อ 51) รูปเหมือนกัน
2. **V/A-(으)니까** — "เพราะ… (เลย…)" เหตุผลที่ตามด้วยคำสั่ง/ชวนได้ · (ไวยากรณ์ข้อ 50)
   - ราก**มีตัวสะกด** → **-으니까**: 없다 → 없으니까 · 읽다 → 읽었으니까 / **ไม่มีตัวสะกดหรือ ㄹ** → **-니까**: 막히다 → 막히니까 · 오다 → 오니까 · 멀다 → **머니까** (ตัด ㄹ) / **ㅂ 불규칙** → 우: 덥다 → **더우니까** · 춥다 → 추우니까 · 뜨겁다 → 뜨거우니까 (ข้อ 37) / **นาม**: N**이니까** (ลงท้ายพยัญชนะ) · N**니까** (ลงท้ายสระ): 제 생일이니까 · 중요한 서류니까
   - กล่องตำรา: บอกว่าประโยคหน้าเป็น**เหตุผลหรือข้ออ้าง**ของประโยคหลัง ใส่ **กาล (-았/었-) ได้** · (เทียบ -아/어서 ข้อ 48 บท 29)
   - ตัวอย่างบทสนทนา: 택시를 탈까요? → 출근 시간에는 길이 막히니까 지하철을 타세요 *(นั่งแท็กซี่ดีไหม → ชั่วโมงเร่งด่วนรถติด ไปรถไฟใต้ดินเถอะ)* · 다음 주에 시험을 보니까 같이 공부해요 *(สัปดาห์หน้ามีสอบ เรียนด้วยกันเถอะ)* · 제 생일이니까 꼭 오세요 *(วันเกิดฉัน มาให้ได้นะ)* · 이 책은 읽었으니까 다른 책을 빌려 주세요 *(เล่มนี้อ่านแล้ว ช่วยยืมเล่มอื่นให้หน่อย)* · 커피가 뜨거우니까 조심하세요 *(กาแฟร้อน ระวังนะ)* · 중요한 서류니까 버리지 마세요 *(เอกสารสำคัญ อย่าทิ้ง)*
   - 연습 1 (보기 시간이 없으니까 택시를 타세요 *ไม่มีเวลา ไปแท็กซี่เถอะ*): 점심에 약속이 있다 / 저녁에 만나다 → 점심에 약속이 있으니까 저녁에 만나요 · 친구가 기다리다 / 빨리 가다 → 친구가 기다리니까 빨리 가세요 · 길을 모르다 / 길을 물어보다 → 길을 모르니까 길을 물어보세요 · 우리 집이 멀다 / 기숙사에서 파티를 하다 → 우리 집이 머니까 기숙사에서 파티를 해요 · 교실이 덥다 / 에어컨을 켜다 → 교실이 더우니까 에어컨을 켜세요 *(ตัวอย่างผันตามกฎ — ตำราให้แค่ราก)*
   - 연습 2 จับคู่เหตุผล → ข้อเสนอ (보기 비가 오니까 우산을 준비하세요 *ฝนตก เตรียมร่มด้วย*): 내일 손님이 올 거예요 → 방을 청소하세요 · 다리가 아파요 → 의자에 앉을까요? · 한국 노래를 알아요 → 한국 노래를 부르세요 · 감기에 걸렸어요 → 아이스크림을 먹지 마세요 · 명동에 사람이 많아요 → 동대문시장으로 가요 *(พรุ่งนี้มีแขก → ทำความสะอาดห้อง · ขาเจ็บ → นั่งเก้าอี้ไหม · รู้จักเพลงเกาหลี → ร้องเพลงเกาหลีสิ · เป็นหวัด → อย่ากินไอศกรีม · เมียงดงคนเยอะ → ไปตลาดทงแดมุน — ตัวอย่างจับคู่ตามความหมาย)*
   - 연습 3 คุยแผนวันนี้: 가: ___ 씨, 우리 등산을 할까요? 나: 비가 오니까 영화를 봐요. 어때요? 가: 좋아요 *(…ไปปีนเขากันไหม → ฝนตกเลยดูหนังกัน เป็นไง → ดีเลย)* · ตัวเลือก: 뭘 할까요? 등산 · 영화 · 도서관 · 게임 · 따뜻한 차 · 산책 / 다른 것: TV · 단어 외우기 · 놀이공원 · 쇼핑 · 노래방 / 왜요? 내일 시험이에요 · 비가 와요 · 기분이 나빠요 · 눈이 와요 · 날씨가 좋아요 · 더워요
   - ⚠️ **-(으)니까 vs -아/어서** (ตำราโยงกลับไปข้อ 48): ① ประโยคหลังเป็น**คำสั่ง/ชวน**ได้เฉพาะ -(으)니까 (우산을 준비하세요 · 같이 공부해요) ② -(으)니까 ใส่ **-았/었-** ได้ (읽었으니까) -아/어서 ไม่ได้ ③ บอก**ข้อเท็จจริงที่เป็นเหตุผลโดยตรง** ใช้ -아/어서 (비가 와서 안 갔어요) — ต้องการ "เพราะเหตุผลนี้ ขอให้…" ใช้ -(으)니까
   - ⚠️ ★ ราก ㄹ: 멀다 → **머니까** (멀으니까 ✗) · 만들다 → 만드니까 (ตระกูลเดียวกับ 만들습니다 ✗ ที่เคยพลาด) · ลืม **으** หลังตัวสะกด: 없으니까 ✓ 없니까 ✗ · 읽으니까 (ตระกูลเดียวกับ 읽세요 ✗ · 씻러 ✗) · ㅂ: 덥다 → **더우니까** (덥으니까 ✗)
