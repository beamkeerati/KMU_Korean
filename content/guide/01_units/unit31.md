## 31과: 버스로 30분쯤 걸려요 (นั่งรถบัสใช้เวลาประมาณ 30 นาที)

> **หลังจบบทนี้ทำอะไรได้**: บอกพาหนะ/วิธีด้วย N(으)로 (버스로 가요 · 걸어서 가요) · ผันกริยา ㄷ 불규칙 (듣다 → 들어요 · 걷다 → 걸어요 · 묻다 → 물어요) · ถามและตอบระยะทาง/เวลาด้วย N에서 N까지 얼마나 걸려요? / 30분쯤 걸려요 · อ่านอีเมลเชิญและบอกเส้นทาง

**🗣️ คำศัพท์สำคัญ**

| หมวด | คำศัพท์ (ไทย) |
|:---|:---|
| พาหนะ | 기차 (รถไฟ) · 배 (เรือ) · 비행기 (เครื่องบิน) · 지하철 (รถไฟใต้ดิน) · 택시 · 교통수단 (พาหนะ) · 걸어서 가다 (เดินไป) |
| เส้นทาง | 갈아타다 (เปลี่ยนสาย) · 내리다 (ลงรถ) · 건너다 (ข้าม) · 육교 (สะพานลอย) · 횡단보도 (ทางม้าลาย) · 안내 방송 (ประกาศ) · 출발 (ออกเดินทาง) · 도착 (มาถึง) |
| เวลา · ระยะ | 얼마나 (เท่าไร นานแค่ไหน) · 걸리다 (ใช้เวลา) · 쯤 (ประมาณ) |
| สถานที่ | 출입국관리사무소 (สำนักงานตรวจคนเข้าเมือง) · 대사관 (สถานทูต) · 63빌딩 · 경복궁역 · 길음역 · 안국동 · 김포공항역 · 종로3가역 · 인천 |

*รายการเต็มของตำราอยู่ท้ายบท*

**📝 ไวยากรณ์**

1. **N-(으)로** (พาหนะ/วิธี/เครื่องมือ) — "ด้วย… / โดย…" · (ไวยากรณ์ข้อ 51)
   - คำนาม**ลงท้ายพยัญชนะ** → **-으로**: 숟가락으로 · 젓가락으로 / **ลงท้ายสระหรือ ㄹ** → **-로**: 버스로 · 택시로 · 기차로 · 비행기로 · 배로 · 지하철로 · 칼로
   - กล่องตำรา: ต่อท้ายคำนามที่เป็น**เครื่องมือ วิธีการ หรือพาหนะ**ของการกระทำ (เทียบ N(으)로¹ ทิศทาง ใน 30과 ข้อ 49)
   - ตัวอย่างบทสนทนา: 지훈 씨, 집에 어떻게 가요? → 버스로 가요. 장핑 씨는요? → 저는 걸어서 가요 *(จีฮุน กลับบ้านยังไง → นั่งรถบัส · จางผิงล่ะ → เดินกลับ)* · 비행기로 제주도에 갈 거예요 *(จะไปเชจูด้วยเครื่องบิน)* · 한국 사람들은 숟가락과 젓가락으로 음식을 먹어요 *(คนเกาหลีกินข้าวด้วยช้อนและตะเกียบ)* · 사과를 칼로 잘라서 드세요 *(หั่นแอปเปิลด้วยมีดแล้วกินนะ)*
   - 연습 1 (보기 학교에 어떻게 가요? → 버스로 가요 / 버스를 타고 가요): 🖼️ วงกลม 6 จุดรอบ 지훈 — 병원 (แท็กซี่) · 학교 (รถบัส) · 부산 (รถไฟ) · 기숙사 (เท้าเดิน) · 명동 (รถไฟใต้ดิน) · 제주도 (เรือ) → 병원에 택시로 가요 · 부산에 기차로 가요 · 기숙사에 걸어서 가요 · 명동에 지하철로 가요 · 제주도에 배로 가요 *(ตัวอย่างตอบตามภาพ — ภาพเล็ก)*
   - 연습 2: 1. 국민대학교에 어떻게 가요? → **버스로** 가요 (🖼️ ไอคอนรถบัส) · 2. 북한산 → **171번 버스로** 가요 · 3. 경복궁역 → **지하철 3호선으로** 가요 · 4. 63빌딩 → **육교로** 건너세요 *(ข้ามสะพานลอย)* · 5. 영화관 → **횡단보도로** 건너세요 *(ข้ามทางม้าลาย)* *(ตัวอย่างตอบตามภาพ ตำราเว้นให้เติม)*
   - ⚠️ **N(으)로 = N을/를 타고** : 버스로 가요 = 버스를 타고 가요 · เดินใช้ **걸어서 가요** (걷으로 ✗) · ★ ㄹ ท้ายใช้ **로**: 칼로 ✓ 칼으로 ✗ · 지하철로 ✓ (철 ท้าย ㄹ) · ★ **ตอบให้ตรงคำถาม**: 어떻게 가요? → (으)로 · 어디에 가요? → 에 · 얼마나 걸려요? → 시간 (เคยตอบผิดคำถาม) · (으)로 สองความหมายรูปเดียวกัน: 오른쪽으로 가세요 (ทิศ ข้อ 49) ↔ 버스로 가세요 (พาหนะ ข้อ 51)
2. **ㄷ 불규칙 กริยา/คำคุณศัพท์** — ㄷ ท้ายเปลี่ยนเป็น ㄹ ก่อนสระ · (ไวยากรณ์ข้อ 51 ภาคต่อ)
   - ราก**ลงท้ายด้วย ㄷ** + endings ที่ขึ้นต้นด้วยสระ (-아/어요 · -(으)세요 · -(으)니까 · -았/었-) → **ㄷ → ㄹ**: 듣다 → **들**어요 · 걷다 → **걸**어요 · 묻다 → **물**어요 · (ตำราลิสต์: 듣다 · 걷다 · 묻다 · 싣다 · 깨닫다) / ก่อนพยัญชนะ (-고 · -지만 · -습니다) → ไม่เปลี่ยน: 듣고 · 걷고 · 묻습니다
   - ตัวอย่าง: 날마다 한국 뉴스를 들어요 *(ฟังข่าวเกาหลีทุกวัน)* · 모르는 것이 있으면 물어보세요 *(ถ้ามีอะไรไม่รู้ ลองถามนะ)* · ※ 사랑하는 사람과 손을 잡고 공원을 걷고 싶어요 *(อยากจูงมือคนที่รักเดินในสวน — ก่อน -고 ไม่เปลี่ยน)* · ※ 시끄러우니까 문을 닫으세요 *(เสียงดัง ปิดประตูด้วย — 닫다 เป็นกริยาปกติ)*
   - 연습 3 เปลี่ยน -ㅂ/습니다 → -아/어요 (보기 한국 노래를 듣습니다 → 한국 노래를 들어요): 친구와 같이 운동장을 걷습니다 → **걸어요** *(เดินสนามกีฬากับเพื่อน)* · 선생님께서 이름을 묻습니다 → **물어요** *(อาจารย์ถามชื่อ)* · ※ 추워서 창문을 닫습니다 → **닫아요** · ※ 용돈을 받습니다 → **받아요** *(ข้อมี ※ = เป็นกริยาปกติ ไม่เปลี่ยน)*
   - 연습 4: 지금 뭘 들어요? (음악) → **음악을 들어요** · 친구가 뭘 물었어요? (이메일 주소) → **이메일 주소를 물었어요** · 듣기 시험이 어렵네요 (한국어 CD) → 그럼 한국어 CD를 **들으**세요 · 왜 다리가 아파요? (2시간 걷다) → **2시간 걸어**서 다리가 아파요 · 생일에 무엇을 받고 싶어요? (ตอบเอง) *(ตัวอย่างตอบตามกฎ)*
   - 연습 5 ถามเพื่อน: 어디에 살아요? 학교에 어떻게 와요? — 윤아 씨는 기숙사에서 살아요. 학교에 걸어서 와요 *(ยุนอา อยู่หอพัก เดินมาโรงเรียน)*
   - ⚠️ ★ **ไม่ใช่ทุก ㄷ**: 닫다 · 받다 · 믿다 · 얻다 เป็นปกติ (닫아요 ✓ 달아요 ✗) · ★ ลืม **으** ใน 들으세요 · 걸으세요 · 물으세요 (ตระกูลเดียวกับ 읽세요 ✗) · 듣다 ต้องใช้ **을/를** (이야기를 들어요 — เคยพลาด 이야기가 들었어요 ✗) · 걸어서 (เดินแล้ว…) ต่างจาก 걸려요 (ใช้เวลา — 걸리다) ★ สองคำนี้คนละกริยา
3. **N에서 N까지 · 얼마나 걸려요? · 쯤** — "จาก…ถึง… ใช้เวลาประมาณเท่าไร" · (ไวยากรณ์ข้อ 52)
   - กล่องตำรา: **N에서 N까지** ต่อท้ายคำนามบอก**จุดเริ่มและจุดสิ้นสุด**ของการเคลื่อนที่ · ถามเวลาที่ใช้: **얼마나 걸려요?** ตอบ: **(พาหนะ)로 + เวลา + 쯤 걸려요** · **쯤** = ประมาณ ต่อท้ายตัวเลข (30분쯤 · 100m쯤 · 2시간쯤)
   - ตัวอย่างบทสนทนา: 학교에서 길음역까지 얼마나 걸려요? → 버스로 20분쯤 걸려요 *(จากโรงเรียนถึงสถานีคิลึมใช้เวลานานแค่ไหน → รถบัสประมาณ 20 นาที)* · 학교에서 집까지 멀지 않아요 *(จากโรงเรียนถึงบ้านไม่ไกล)* · 서울에서 부산까지 기차로 2시간쯤 걸려요 *(จากโซลถึงปูซานนั่งรถไฟประมาณ 2 ชั่วโมง)*
   - 연습 1 (보기 학교에서 집까지 어떻게 가요? → 학교에서 집까지 버스로 가요 — 🖼️ รถบัสสีเขียว): 1. 서울 → 부산 (รถไฟ) → 서울에서 부산까지 기차로 가요 · 2. 도쿄 → 베이징 (เครื่องบิน) → 도쿄에서 베이징까지 비행기로 가요 · 3. 인천 → 제주도 (เรือ) → 인천에서 제주도까지 배로 가요 · 4. 교실 → 기숙사 (เท้า) → 교실에서 기숙사까지 걸어서 가요 *(ตัวอย่างตอบตามภาพ)*
   - 연습 2 (보기 학교에서 명동까지 얼마나 걸려요? → 30분쯤 걸려요): 집 → 공항 1시간 · 교실 → 사무실 5분 · 한국 → 미국 13시간 30분 · 지하철역 → 약속 장소 10분 · 여기 → 거기 20분 → 집에서 공항까지 **한 시간쯤** 걸려요 · 교실에서 사무실까지 **오 분쯤** 걸려요 · 한국에서 미국까지 **열세 시간 삼십 분쯤** 걸려요 *(ตัวอย่างตอบ)*
   - 연습 3 อ่านตารางพาหนะ (보기 학교에서 시청까지 얼마나 걸려요? → 버스로 30분쯤 걸려요): 학교 → 시청 (รถบัส 09:00 → 09:30) → **버스로 30분쯤** · 서울 → 부산 (รถไฟ 04:30 → 07:00) → **기차로 2시간 30분쯤** · 한국 → 사우디 (เครื่องบิน 08:00 → 23:00) → **비행기로 15시간쯤** (ตามตาราง ไม่คิดเวลาต่างโซน) · 길음역 → 롯데월드 (รถไฟใต้ดิน 11:00 → 12:00) → **지하철로 1시간쯤** · 교실 → 학생 식당 (เดิน 08:55 → 09:00) → **걸어서 5분쯤** *(คำนวณจากตาราง ตำราไม่พิมพ์เฉลย)*
   - ⚠️ **ระยะเวลา ≠ เวลานาฬิกา**: ใช้ **한 시간 · 두 시간 · 열세 시간** (ตัวเลขเกาหลีแท้ + 시간) ส่วน **분** ใช้ตัวเลขจีน (삼십 분 · 이십 분) เหมือนเวลานาฬิกา · ข้อ 25 สอน 시/분 แบบนาฬิกา (한 시 = 1 โมง ↔ 한 시간 = 1 ชั่วโมง) · ★ 시/분 ต้องมีช่องว่าง (두 시간 삼십 분) และห้ามทิ้ง 분 (เคยพลาด 사십오 이에요 → 사십오 분이에요) · **에서~까지** (สถานที่ จุดเริ่ม-จุดจบ) ≠ **부터~까지** (เวลา — ข้อ 27 บท 19) · ★ 쯤 ติดกับตัวเลข ไม่เว้น (30분쯤) · **에서** ที่เป็นจุดเริ่มต้น ≠ 에서 สถานที่ทำกิจกรรม (ข้อ 09)
   - ⚠️ ★ 걸려요 = ใช้เวลา (걸리다 → 걸려요 ไม่ใช่ 걸어요) · คำตอบต้องมีพาหนะ+ระยะเวลา: 버스로 30분쯤 걸려요 ไม่ใช่ 버스를 타요
