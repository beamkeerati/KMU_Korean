# ส่วนที่ 2 · 은/는 vs 이/가 (เจาะลึกพิเศษ)

ส่วนนี้ลงรายละเอียดกว่าข้อ 1 ของส่วนที่ 1 ให้อ่านเมื่อยังเลือกคำชี้ไม่มั่นใจว่าจะใช้ 은/는 หรือ 이/가 เนื้อหาเรียงจากพื้นฐานไปหาการใช้จริง เริ่มจากรูปที่เปลี่ยนตามตัวสะกด ต่อด้วยความหมายที่ต่างกัน โครงสร้างประโยค 6 แบบ การเปรียบเทียบ และการเล่าเรื่อง ถ้ารีบทบทวนก่อนสอบให้เปิดบทที่ 6 ซึ่งเป็นตารางตัดสินใจหน้าเดียวก่อน แล้วค่อยย้อนมาอ่านเหตุผลของแต่ละกฎ

## 1. รูปพื้นฐาน: เลือกตามตัวสะกด (받침)

> [!INTRO] บทนี้ว่าด้วยอะไร
> 은/는 และ 이/가 แต่ละคู่มีสองรูป คือรูปที่ใช้หลังคำนามที่มีตัวสะกด (받침) กับรูปที่ใช้หลังคำนามที่ไม่มีตัวสะกด บทนี้สอนวิธีเลือกรูปจากพยางค์สุดท้ายของคำนาม และรูปพิเศษ 3 คำที่ต้องจำแยกต่างหาก
>
> ต้องใช้ทุกครั้งที่ติดคำชี้หลังคำนาม ต่อยอดจากข้อ 1 ของส่วนที่ 1 และเป็นฐานของบทที่ 2–6 ที่พูดถึงความหมายและการใช้

### เลือกคำชี้ตามตัวสะกดของคำนาม

คำชี้แต่ละตัวมีสองรูป ตารางแรกสรุปว่ารูปไหนใช้เมื่อไร ตารางที่สองเป็นตัวอย่างทีละคำให้เห็นว่าตัวสะกดของพยางค์สุดท้ายตัดสินการเลือกอย่างไร

| คำชี้ | มีตัวสะกด (받침 ✓) | ไม่มีตัวสะกด (받침 ✗) |
|---|---|---|
| **Topic marker** | **은** | **는** |
| **Subject marker** | **이** | **가** |

#### ตัวอย่างทีละคำ

| คำนาม + คำชี้ | ตัวสะกด | ความหมายของคำนาม |
|:---|:---|:---|
| 선생님**은** | มี (ㅁ) | อาจารย์ (Topic) |
| 책**은** | มี (ㄱ) | หนังสือ (Topic) |
| 저**는** | ไม่มี | ฉัน (Topic) |
| 카오루**는** | ไม่มี | คาโอรุ (Topic) |
| 책**이** | มี (ㄱ) | หนังสือ (Subject) |
| 직업**이** | มี (ㅂ) | อาชีพ (Subject) |
| 의자**가** | ไม่มี | เก้าอี้ (Subject) |
| 마키 씨**가** | ไม่มี | คุณมากิ (Subject) |

### วิธีเช็คตัวสะกด

ดูที่พยางค์สุดท้ายของคำนามเท่านั้น แล้วถามตัวเองว่ามีพยัญชนะอยู่ข้างล่างพยางค์ไหม ถ้ามีให้ใช้ 은 / 이 ถ้าไม่มีให้ใช้ 는 / 가

| คำนาม | พยางค์สุดท้าย | ใช้ |
|:---|:---|:---|
| 학생 *(นักเรียน)* | 생 มี ㅇ ข้างล่าง | **은 / 이** |
| 의사 *(หมอ)* | 사 ไม่มี | **는 / 가** |

### รูปพิเศษที่ต้องจำ

คำนามสามคำนี้ไม่ได้แค่ต่อ 가 ท้ายคำเฉย ๆ แต่ตัวคำเปลี่ยนรูปไปด้วย จึงต้องจำเป็นคู่ ๆ

| คำ | + 가 | ความหมาย |
|---|---|---|
| 저 | **제가** (ไม่ใช่ 저가) | ฉัน (สุภาพ) |
| 나 | **내가** | ฉัน (กันเอง) |
| 누구 | **누가** (ไม่ใช่ 누구가) | ใคร |

> [!SUMMARY] สรุป
> - ดูพยางค์สุดท้ายของคำนาม: มีตัวสะกด → **은 / 이** ไม่มีตัวสะกด → **는 / 가**
> - Topic marker คือ 은/는 และ Subject marker คือ 이/가 ทั้งสองคู่เลือกรูปด้วยวิธีเดียวกัน
> - รูปพิเศษที่ต้องจำ: 저 → **제가** · 나 → **내가** · 누구 → **누가**

## 2. ความหมายต่างกันยังไง

> [!INTRO] บทนี้ว่าด้วยอะไร
> เมื่อรู้รูปของคำชี้แล้ว บทนี้อธิบายว่า 은/는 กับ 이/가 ต่างกันที่ความหมายและน้ำหนักของประโยคอย่างไร ภาษาไทยไม่มีคำชี้แบบนี้ แปลออกมาจึงดูใกล้กัน ผู้เรียนเลยเลือกผิดบ่อย
>
> ต่อยอดจากบทที่ 1 (รูปและตัวสะกด) และเป็นฐานของโครงสร้างประโยคในบทที่ 3

### เทียบ 은/는 กับ 이/가

ตารางนี้เทียบคำชี้สองคู่ในสี่ด้าน ให้สังเกตว่า "ข้อมูลที่สำคัญ" ของประโยคอยู่คนละตำแหน่งกัน

| ด้านที่เทียบ | **은/는** (Topic) | **이/가** (Subject) |
|---|---|---|
| ทำหน้าที่ | บอก **"เรื่องที่กำลังพูดถึง"** | บอก **"ใครหรืออะไรที่ทำ/เป็น"** |
| แปลไทยประมาณ | "ส่วน..." / "สำหรับ...นั้น" / "...น่ะ" | "...นี่แหละ" / "ตัว...เอง" |
| ข้อมูลที่ **สำคัญ** อยู่ที่ | **ท้ายประโยค** (ส่วนที่ตามมา) | **ตัวคำนามที่มี 이/가** |
| ใช้กับข้อมูล | ที่ผู้ฟัง **รู้อยู่แล้ว** | ข้อมูล **ใหม่** |

> [!TIP] จำง่าย ๆ
> - **은/는** → ความสำคัญอยู่**ข้างหลัง** เช่น 마키 씨는 **일본 사람**이에요. *(มากิน่ะ เป็นคนญี่ปุ่น — น้ำหนักอยู่ที่ "คนญี่ปุ่น")*
> - **이/가** → ความสำคัญอยู่**ข้างหน้า** เช่น **마키 씨**가 일본 사람이에요. *(มากินี่แหละ ที่เป็นคนญี่ปุ่น — น้ำหนักอยู่ที่ "มากิ")*

> [!SUMMARY] สรุป
> - **은/는** บอกเรื่องที่พูดถึงและเป็นข้อมูลที่ผู้ฟังรู้แล้ว ความสำคัญอยู่ที่ส่วนท้ายประโยค
> - **이/가** บอกว่าใครหรืออะไรทำ/เป็น และเป็นข้อมูลใหม่ ความสำคัญอยู่ที่คำนามที่ติด 이/가
> - ประโยคเดียวกันเปลี่ยนคำชี้แล้วน้ำหนักย้ายที่: 마키 씨는 일본 사람이에요 เน้น "คนญี่ปุ่น" ส่วน 마키 씨가 일본 사람이에요 เน้น "มากิ"

## 3. โครงสร้างประโยค

> [!INTRO] บทนี้ว่าด้วยอะไร
> ประโยคที่ใช้ 은/는 และ 이/가 มีรูปแบบซ้ำกันอยู่ 6 แบบ บทนี้ไล่ทีละแบบพร้อมแม่แบบและตัวอย่าง แบบ A ใช้แนะนำหัวข้อด้วย 은/는 แบบ B ถามและตอบ 누가/뭐가 ด้วย 이/가 แบบ C บอกว่ามีหรือไม่มี แบบ D ปฏิเสธว่าไม่ใช่ แบบ E ถามชื่อและอาชีพ ส่วนแบบ F ใช้ทั้งสองตัวในประโยคเดียว
>
> ใช้เมื่อต้องแต่งประโยคเองแล้วไม่แน่ใจว่าต้องใส่ตัวไหน ต่อยอดจากความหมายที่ต่างกันในบทที่ 2

### โครงสร้าง A: แนะนำ / อธิบายสิ่งที่พูดถึง → ใช้ 은/는

นี่คือโครงสร้างพื้นฐานที่สุด ตั้งหัวข้อด้วย 은/는 แล้วบอกข้อมูลเกี่ยวกับหัวข้อนั้น ใช้แนะนำตัว แนะนำสิ่งของ และบอกที่ตั้ง

```
[คำนาม] + 은/는 + [คำนาม] + 입니다 / 이에요/예요
  (หัวข้อ)          (ข้อมูลเกี่ยวกับหัวข้อ)
```

| ประโยค | ความหมาย |
|---|---|
| 저**는** 학생입니다. | ฉัน (ว่าด้วยตัวฉัน) เป็นนักเรียน |
| 장핑 씨**는** 중국 사람이에요. | จางผิง เป็นคนจีน |
| 이것**은** 책이에요. | อันนี้ เป็นหนังสือ |
| 도서관**은** 학생회관 옆에 있어요. | ห้องสมุด อยู่ข้างตึกนักศึกษา |

### โครงสร้าง B: ถามว่า "ใคร / อะไร" → ใช้ 이/가 ทั้งคำถามและคำตอบ

เมื่อถามว่าใครหรืออะไร คำถามใช้ 이/가 (누가 · 뭐가 · 무엇이) และคำตอบก็ต้องใช้ 이/가 ตามไปด้วย เพราะคำตอบคือข้อมูลใหม่ที่ผู้ถามยังไม่รู้

```
누가 / 뭐가 / 무엇이 + [กริยา]?
→ [คำนาม] + 이/가 + [กริยา].
```

| คำถาม | คำตอบ |
|---|---|
| **누가** 의사입니까? *(ใครเป็นหมอ)* | 왕쯔이 씨**가** 의사입니다. *(คุณหวางจื่ออีเป็นหมอ)* |
| **누가** 일본 사람이에요? *(ใครเป็นคนญี่ปุ่น)* | 마키 씨**가** 일본 사람이에요. *(คุณมากิเป็นคนญี่ปุ่น)* |
| 책상 위에 **뭐가** 있어요? *(บนโต๊ะมีอะไร)* | 필통**이** 있어요. *(มีกล่องดินสอ)* |

> [!WARNING] ตอบคำถาม 누가 / 뭐가 ห้ามใช้ 은/는
> ✗ 마키 씨는 일본 사람이에요. *(ไม่ตรงคำถาม เพราะ 은/는 ไม่ได้บอกว่าใครคือคนที่ถูกถามถึง)*

### โครงสร้าง C: มี / ไม่มี → ใช้ 이/가

ประโยคบอกว่ามีหรือไม่มีของ/คนในที่แห่งหนึ่ง ใช้ 에 บอกสถานที่ แล้วติด 이/가 ที่สิ่งของหรือคนที่มีหรือไม่มี

```
[สถานที่] + 에 + [สิ่งของ/คน] + 이/가 + 있어요 / 없어요
```

| ประโยค | ความหมาย |
|---|---|
| 가방에 책**이** 있어요. | ในกระเป๋ามีหนังสือ |
| 교실에 학생**이** 없어요. | ในห้องเรียนไม่มีนักเรียน |
| 1층에 빵집**이** 있어요. | ชั้น 1 มีร้านขนมปัง |

### โครงสร้าง D: ไม่ใช่... → ใช้ 이/가 아니에요

เมื่อปฏิเสธคำนามว่า "ไม่ใช่…" ให้ติด 이/가 ที่คำนามที่ถูกปฏิเสธ แล้วต่อด้วย 아니에요

```
[คำนาม] + 이/가 + 아니에요
```

- 볼펜**이** 아니에요. *(ไม่ใช่ปากกา)*
- 카메라**가** 아니에요. *(ไม่ใช่กล้องถ่ายรูป)*
- รวมกับ 은/는 ได้: 제 여자 친구**는** 러시아 사람**이** 아니에요. *(แฟนของฉันไม่ใช่คนรัสเซีย)*

### โครงสร้าง E: ถามข้อมูล (이름, 직업) → ใช้ 이/가

การถามชื่อและอาชีพก็ใช้ 이/가 กับคำนามที่ถามถึง ส่วนคำตอบเป็นข้อมูลเฉย ๆ

```
[คำนาม] + 이/가 + 무엇입니까? / 뭐예요?
```

| คำถาม | คำตอบ |
|---|---|
| 이름**이** 무엇입니까? *(ชื่ออะไร)* | 김윤아입니다. *(ชื่อคิมยุนอา)* |
| 직업**이** 뭐예요? *(อาชีพอะไร)* | 학생이에요. *(เป็นนักเรียน)* |

### โครงสร้าง F: ทั้งสองอย่างในประโยคเดียว

ประโยคเดียวใช้คำชี้ได้ทั้งสองตัว 은/는 ตั้งหัวข้อใหญ่ แล้ว 이/가 ชี้ประธานย่อยที่ตามมา แปลไทยได้ว่า "…น่ะ … เยอะ/ไม่มี"

```
[หัวข้อ] + 은/는 + [ประธานย่อย] + 이/가 + [คุณศัพท์/กริยา]
```

| ประโยค | ความหมาย |
|---|---|
| 학생회관**은** 가게**가** 많아요. | ตึกนักศึกษาน่ะ ร้านค้าเยอะ |
| 인사동**은** 옛날 물건**이** 많아요. | อินซาดงน่ะ ของเก่าเยอะ |
| 저**는** 휴대폰**이** 없어요. | ฉันน่ะ ไม่มีมือถือ |

> [!SUMMARY] สรุป
> - แนะนำตัวหรืออธิบายหัวข้อ (แบบ A) ใช้ **은/는**
> - ถาม 누가 / 뭐가 / 무엇이 (แบบ B) ใช้ **이/가** ทั้งคำถามและคำตอบ
> - มี / ไม่มี (แบบ C) · ไม่ใช่ (แบบ D) · ถามชื่อและอาชีพ (แบบ E) ใช้ **이/가**
> - ประโยคเดียวใช้ได้ทั้งสองตัว (แบบ F): **은/는** ตั้งหัวข้อ แล้ว **이/가** ชี้ประธานย่อย

## 4. ใช้ 은/는 เพื่อ "เปรียบเทียบ"

> [!INTRO] บทนี้ว่าด้วยอะไร
> นอกจากการตั้งหัวข้อ 은/는 ยังใช้เทียบสองสิ่งให้เห็นความต่างได้ด้วย โดยใส่ 은/는 ทั้งสองฝั่ง ฝั่งละหนึ่งตัว ใช้เมื่อต้องการบอกว่า "อันนี้เป็นอย่างหนึ่ง ส่วนอันนั้นเป็นอีกอย่าง"
>
> ต่อยอดจากบทที่ 2 และบทที่ 3 แบบ A

เมื่อต้องการเทียบสองสิ่ง ให้เขียนสองประโยคต่อกัน และใส่ 은/는 ที่หัวข้อของทั้งสองประโยค ผู้ฟังจะรู้ทันทีว่ากำลังเทียบกัน

```
A + 은/는 ..., B + 은/는 ...
```

| ประโยค | ความหมาย |
|---|---|
| 장핑 씨**는** 중국 사람이에요. 이리나 씨**는** 러시아 사람이에요. | จางผิงเป็นคนจีน **ส่วน**อีรินาเป็นคนรัสเซีย |
| 커피**는** 안 마셔요. 차**는** 마셔요. | กาแฟน่ะไม่ดื่ม **แต่**ชาดื่ม |
| 고향에서**는** 요리를 해요. 한국에서**는** 안 해요. | ที่บ้านเกิดทำอาหาร **แต่**ที่เกาหลีไม่ทำ |

> [!TIP] 는 ต่อท้าย 에서 ได้
> 는 ต่อท้าย 에서 ได้ด้วย (에서 + 는 = **에서는**) เพื่อเปรียบเทียบสถานที่ ดังในประโยคที่สามของตารางข้างบน

> [!SUMMARY] สรุป
> - เปรียบเทียบสองสิ่ง ใส่ **은/는** ทั้งสองฝั่ง
> - ภาษาไทยแปลเป็น "ส่วน…" หรือ "แต่…" เพื่อให้เห็นความต่าง
> - 는 ต่อท้าย 에서 ได้ (에서는) เมื่อเทียบสถานที่

## 5. ข้อมูลใหม่ → ข้อมูลเก่า (การเล่าเรื่อง)

> [!INTRO] บทนี้ว่าด้วยอะไร
> เวลาเล่าเรื่องต่อเนื่อง ผู้พูดมักแนะนำสิ่งใหม่ด้วย 이/가 ก่อน แล้วพอสิ่งนั้นกลายเป็นเรื่องที่รู้กันแล้ว ก็เปลี่ยนมาใช้ 은/는 บทนี้ใช้บทอ่านจาก Unit 6 เป็นตัวอย่างให้เห็นการสลับคำชี้
>
> ต่อยอดจากความต่างระหว่างข้อมูลใหม่กับข้อมูลที่ผู้ฟังรู้แล้วในบทที่ 2

หลักสั้น ๆ คือ ครั้งแรกที่พูดถึง → **이/가** และพูดถึงซ้ำ → **은/는** ตัวอย่างข้างล่างมาจากบทอ่าน Unit 6 ดูว่าแต่ละประโยคเป็นการแนะนำครั้งแรกหรือการพูดถึงต่อ

| ประโยค | ความหมาย | ครั้งที่พูดถึง |
|---|---|---|
| 이 사람**이** 압둘라 씨입니다. | คนนี้คือคุณอับดุลลา | แนะนำครั้งแรก → **이/가** |
| 압둘라 씨**는** 사우디아라비아 사람입니다. | คุณอับดุลลาเป็นคนซาอุดีอาระเบีย | พูดถึงต่อ → **은/는** |
| 이 사람**이** 마키 씨입니다. | คนนี้คือคุณมากิ | แนะนำครั้งแรก → **이/가** |
| 마키 씨**는** 일본 사람입니다. | คุณมากิเป็นคนญี่ปุ่น | พูดถึงต่อ → **은/는** |

> [!SUMMARY] สรุป
> - ครั้งแรกที่พูดถึง → **이/가**
> - พูดถึงซ้ำหรือเล่าต่อ → **은/는**
> - ตัวอย่างจากบทอ่าน Unit 6: 이 사람이 압둘라 씨입니다 → 압둘라 씨는 사우디아라비아 사람입니다

## 6. สรุปตารางตัดสินใจ

> [!INTRO] บทนี้ว่าด้วยอะไร
> ตารางเดียวที่รวมทุกสถานการณ์ในส่วนที่ 2 ไว้ด้วยกัน ใช้ทบทวนก่อนสอบหรือเปิดดูตอนแต่งประโยคแล้วลังเลระหว่าง 은/는 กับ 이/가 ให้ดูคอลัมน์ซ้ายว่าสถานการณ์ตรงกับข้อไหน แล้วอ่านคอลัมน์กลางเพื่อเลือกคำชี้
>
> สรุปจากบทที่ 1–5 ทั้งหมด

ตารางด้านล่างแบ่งเป็นสองกลุ่ม 3 แถวแรกใช้ **은/는** ส่วนแถวที่เหลือใช้ **이/가** ทุกแถวมีตัวอย่างพร้อมคำแปล

| สถานการณ์ | ใช้ | ตัวอย่าง |
|---|---|---|
| แนะนำตัว / อธิบายหัวข้อ | **은/는** | 저**는** 태국 사람이에요. *(ฉันเป็นคนไทย)* |
| เปรียบเทียบ 2 อย่าง | **은/는** | 빵**은** 있어요. 우유**는** 없어요. *(ขนมปังมี ส่วนนมไม่มี)* |
| พูดถึงสิ่งที่รู้กันแล้ว | **은/는** | 마키 씨**는** 회사원이에요. *(คุณมากิเป็นพนักงานบริษัท)* |
| คำถาม 누가 / 뭐가 และคำตอบ | **이/가** | **누가** 와요? → 투이 씨**가** 와요. *(ใครมา → คุณทุยมา)* |
| 있다 / 없다 | **이/가** | 돈**이** 없어요. *(ไม่มีเงิน)* |
| 아니에요 | **이/가** | 사전**이** 아니에요. *(ไม่ใช่พจนานุกรม)* |
| 이름/직업 + 뭐예요? | **이/가** | 이름**이** 뭐예요? *(ชื่ออะไร)* |
| คุณศัพท์บรรยายสิ่งของ | **이/가** | 식당 음식**이** 맛있어요. *(อาหารร้านอาหารอร่อย)* |
| แนะนำสิ่งใหม่ครั้งแรก | **이/가** | 이 사람**이** 압둘라 씨입니다. *(คนนี้คือคุณอับดุลลา)* |

> [!SUMMARY] สรุป
> - **은/는** ใช้กับการแนะนำตัว อธิบายหัวข้อ เปรียบเทียบ และสิ่งที่รู้กันแล้ว
> - **이/가** ใช้กับคำถาม 누가 / 뭐가 และคำตอบ · 있다 / 없다 · 아니에요
> - **이/가** ยังใช้กับคำถามชื่อและอาชีพ คุณศัพท์ที่บรรยายสิ่งของ และการแนะนำสิ่งใหม่ครั้งแรก
