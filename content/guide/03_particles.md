# ส่วนที่ 2 · 은/는 vs 이/가 (เจาะลึกพิเศษ)

> ส่วนนี้ลงรายละเอียดกว่าข้อ 1 ของส่วนที่ 1 — อ่านเมื่อยังเลือกคำชี้ไม่มั่นใจ

## 1. รูปพื้นฐาน: เลือกตามตัวสะกด (받침)

| | มีตัวสะกด (받침 ✓) | ไม่มีตัวสะกด (받침 ✗) |
|---|---|---|
| **Topic marker** | **은** — 선생님**은**, 책**은** | **는** — 저**는**, 카오루**는** |
| **Subject marker** | **이** — 책**이**, 직업**이** | **가** — 의자**가**, 마키 씨**가** |

**วิธีเช็คตัวสะกด**: ดูพยางค์สุดท้ายของคำนาม มีพยัญชนะอยู่ข้างล่างไหม
- 학생 → 생 มี ㅇ ข้างล่าง → **은 / 이**
- 의사 → 사 ไม่มี → **는 / 가**

**รูปพิเศษ (ต้องจำ)**

| คำ | + 가 | ความหมาย |
|---|---|---|
| 저 | **제가** (ไม่ใช่ 저가) | ฉัน (สุภาพ) |
| 나 | **내가** | ฉัน (กันเอง) |
| 누구 | **누가** (ไม่ใช่ 누구가) | ใคร |

---

## 2. ความหมายต่างกันยังไง

| | **은/는** (Topic) | **이/가** (Subject) |
|---|---|---|
| ทำหน้าที่ | บอก **"เรื่องที่กำลังพูดถึง"** | บอก **"ใครหรืออะไรที่ทำ/เป็น"** |
| แปลไทยประมาณ | "ส่วน..." / "สำหรับ...นั้น" / "...น่ะ" | "...นี่แหละ" / "ตัว...เอง" |
| ข้อมูลที่ **สำคัญ** อยู่ที่ | **ท้ายประโยค** (ส่วนที่ตามมา) | **ตัวคำนามที่มี 이/가** |
| ใช้กับข้อมูล | ที่ผู้ฟัง **รู้อยู่แล้ว** | ข้อมูล **ใหม่** |

> **จำง่าย ๆ**
> - **은/는** → ความสำคัญอยู่ **ข้างหลัง** → "마키 씨는 **일본 사람**이에요" (มากิน่ะ เป็น **คนญี่ปุ่น**)
> - **이/가** → ความสำคัญอยู่ **ข้างหน้า** → "**마키 씨**가 일본 사람이에요" (**มากินี่แหละ** ที่เป็นคนญี่ปุ่น)

---

## 3. โครงสร้างประโยค

### โครงสร้าง A: แนะนำ / อธิบายสิ่งที่พูดถึง → ใช้ 은/는

```
[คำนาม] + 은/는 + [คำนาม] + 입니다 / 이에요/예요
  (หัวข้อ)          (ข้อมูลเกี่ยวกับหัวข้อ)
```

| ประโยค | ความหมาย |
|---|---|
| 저**는** 학생입니다. | ฉัน (ว่าด้วยตัวฉัน) เป็นนักเรียน |
| 장핑 씨**는** 중국 사람이에요. | จางผิง เป็นคนจีน |
| 이것**은** 책이에요. | อันนี้ เป็นหนังสือ |
| 도서관**은** 학생회관 옆에 있어요. | ห้องสมุด อยู่ข้างตึกนักศึกษา |

### โครงสร้าง B: ถามว่า "ใคร / อะไร" → ใช้ 이/가 ทั้งคำถามและคำตอบ

```
누가 / 뭐가 / 무엇이 + [กริยา]?
→ [คำนาม] + 이/가 + [กริยา].
```

| คำถาม | คำตอบ |
|---|---|
| **누가** 의사입니까? (ใครเป็นหมอ) | 왕쯔이 씨**가** 의사입니다. |
| **누가** 일본 사람이에요? | 마키 씨**가** 일본 사람이에요. |
| 책상 위에 **뭐가** 있어요? | 필통**이** 있어요. |

> ⚠️ ตอบคำถาม 누가 / 뭐가 **ห้ามใช้ 은/는** — 마키 씨는 일본 사람이에요 (ไม่ตรงคำถาม)

### โครงสร้าง C: มี / ไม่มี → ใช้ 이/가

```
[สถานที่] + 에 + [สิ่งของ/คน] + 이/가 + 있어요 / 없어요
```

| ประโยค | ความหมาย |
|---|---|
| 가방에 책**이** 있어요. | ในกระเป๋ามีหนังสือ |
| 교실에 학생**이** 없어요. | ในห้องเรียนไม่มีนักเรียน |
| 1층에 빵집**이** 있어요. | ชั้น 1 มีร้านขนมปัง |

### โครงสร้าง D: ไม่ใช่... → ใช้ 이/가 아니에요

```
[คำนาม] + 이/가 + 아니에요
```

- 볼펜**이** 아니에요. / 카메라**가** 아니에요.
- รวมกับ 은/는: 제 여자 친구**는** 러시아 사람**이** 아니에요.

### โครงสร้าง E: ถามข้อมูล (이름, 직업) → ใช้ 이/가

```
[คำนาม] + 이/가 + 무엇입니까? / 뭐예요?
```

- 이름**이** 무엇입니까? → 김윤아입니다.
- 직업**이** 뭐예요? → 학생이에요.

### โครงสร้าง F: ทั้งสองอย่างในประโยคเดียว

```
[หัวข้อ] + 은/는 + [ประธานย่อย] + 이/가 + [คุณศัพท์/กริยา]
```

| ประโยค | แปล |
|---|---|
| 학생회관**은** 가게**가** 많아요. | ตึกนักศึกษาน่ะ ร้านค้าเยอะ |
| 인사동**은** 옛날 물건**이** 많아요. | อินซาดงน่ะ ของเก่าเยอะ |
| 저**는** 휴대폰**이** 없어요. | ฉันน่ะ ไม่มีมือถือ |

## 4. ใช้ 은/는 เพื่อ "เปรียบเทียบ"

```
A + 은/는 ..., B + 은/는 ...
```

| ประโยค | แปล |
|---|---|
| 장핑 씨**는** 중국 사람이에요. 이리나 씨**는** 러시아 사람이에요. | จางผิงเป็นคนจีน **ส่วน**อีรินาเป็นคนรัสเซีย |
| 커피**는** 안 마셔요. 차**는** 마셔요. | กาแฟน่ะไม่ดื่ม **แต่**ชาดื่ม |
| 고향에서**는** 요리를 해요. 한국에서**는** 안 해요. | ที่บ้านเกิดทำอาหาร **แต่**ที่เกาหลีไม่ทำ |

> เห็นไหมว่า 는 ต่อท้าย 에서 ได้ด้วย (에서 + 는 = **에서는**) เพื่อเปรียบเทียบสถานที่

---

## 5. ข้อมูลใหม่ → ข้อมูลเก่า (การเล่าเรื่อง)

ครั้งแรกที่พูดถึง → **이/가** / พูดถึงซ้ำ → **은/는**

> 이 사람**이** 압둘라 씨입니다. ← แนะนำครั้งแรก
> 압둘라 씨**는** 사우디아라비아 사람입니다. ← พูดถึงต่อ
> 이 사람**이** 마키 씨입니다.
> 마키 씨**는** 일본 사람입니다.

## 6. สรุปตารางตัดสินใจ

| สถานการณ์ | ใช้ | ตัวอย่าง |
|---|---|---|
| แนะนำตัว / อธิบายหัวข้อ | **은/는** | 저**는** 태국 사람이에요. |
| เปรียบเทียบ 2 อย่าง | **은/는** | 빵**은** 있어요. 우유**는** 없어요. |
| พูดถึงสิ่งที่รู้กันแล้ว | **은/는** | 마키 씨**는** 회사원이에요. |
| คำถาม 누가 / 뭐가 และคำตอบ | **이/가** | **누가** 와요? → 투이 씨**가** 와요. |
| 있다 / 없다 | **이/가** | 돈**이** 없어요. |
| 아니에요 | **이/가** | 사전**이** 아니에요. |
| 이름/직업 + 뭐예요? | **이/가** | 이름**이** 뭐예요? |
| คุณศัพท์บรรยายสิ่งของ | **이/가** | 식당 음식**이** 맛있어요. |
| แนะนำสิ่งใหม่ครั้งแรก | **이/가** | 이 사람**이** 압둘라 씨입니다. |
