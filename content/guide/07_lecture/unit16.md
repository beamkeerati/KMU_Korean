### 📽️ สไลด์อาจารย์ 16과

#### 📽️ [topic:21] -(스)ㅂ니다 / -(스)ㅂ니까? (교과서 144쪽)
🖼️ *สไลด์ 문법 1 (ภาพหน้า 14 ของไฟล์) ตารางบนแบ่ง 3 ส่วน อาจารย์เขียนสีแดงว่า "드십니다" เหนือหัวสไลด์ และ "않습니다" ใต้สไลด์*

| 동사, 형용사 | 받침(✗) + ㅂ니다 / ㅂ니까? | 받침(○) + 습니다 / 습니까? | 명사 + 입니다 / 입니까? |
|---|---|---|---|
| ตัวอย่าง | 가다-갑니다 · 가르치다-가르칩니다 · 크다-큽니다 · 친절하다-친절합니다 | 먹다-먹습니다 · 읽다-읽습니다 · 작다-작습니다 · 많다-많습니다 | 선생님입니다 · 의사입니다 |

- 명사 + 이/가 **아닙니다 / 아닙니까?** *(ไม่ใช่)*
- 동사/형용사 + 지 **않습니다 / 않습니까?** *(ไม่...)*

**📝 ที่คุณจดไว้:** "= 드시다 + ㅂ니다 → 드십니다" · "드십니다" (ลายมือน้ำเงิน ขีดฆ่า 다 และลูกศรชี้ ㅂ니다)

**💡 สรุป:** รูปสุภาพทางการ: ก้านไม่มีตัวสะกด + ㅂ니다 (갑니다), ก้านมีตัวสะกด + 습니다 (먹습니다), คำนาม + 입니다 ; คำถามเปลี่ยนเป็น -ㅂ니까? / -습니까?

#### 📽️ [topic:20] -(으)시- + -(스)ㅂ니다 → -(으)십니다
🖼️ *สไลด์ (ภาพหน้า 14 ของไฟล์) ตารางเปรียบเทียบผู้พูด คนเล็ก กับ คนใหญ่ หัวสไลด์อาจารย์เขียน "-(으)시다 + (스)ㅂ니다 → -(으)십니다"*

| | เพื่อน/คนเสมอกัน (ภาพผู้หญิง 2 คนคุยกัน) | พิธีกร/ผู้ฟัง (ภาพชายยืนที่โพเดียม) |
|---|---|---|
| ผู้พูดอายุน้อย | -아/어/여요 (11과) | -(스)ㅂ니다 / -(스)ㅂ니까? |
| ผู้พูดอายุมาก/ยกย่อง | -(으)세요 (15과) | **-(으)십니다 / -(으)십니까?** (อาจารย์วงกลม) |

**📝 ที่คุณจดไว้:** เขียนในวงเล็บ (11과) และ (15과) ข้างรูปแบบ

**💡 สรุป:** ภาษาสุภาพแบบทางการสำหรับผู้ใหญ่ = ผสม -(으)시- กับ -(스)ㅂ니다 กลายเป็น -(으)십니다 / -(으)십니까?

#### 📽️ [topic:20] -(으)십니다 และ 높임말 (ศัพท์ยกย่อง)
🖼️ *สไลด์ (ภาพหน้า 14 ของไฟล์) ตาราง 3 ช่อง ช่องที่สามพื้นสีส้ม "높임말" ถูกวงกลม*

| 받침(✗) + 십니다 / 십니까? | 받침(○) + 으십니다 / 으십니까? | 높임말 |
|---|---|---|
| 가다-가십니다 | 씻다-씻으십니다 | 자다-**주무십니다** |
| 가르치다-가르치십니다 | 읽다-읽으십니다 | 먹다-**드십니다** |
| 크다-크십니다 | 작다-작으십니다 | 마시다-**드십니다** |
| 친절하다-친절하십니다 | 많다-많으십니다 | 있다-**계십니다** |
| | | 없다-**안 계십니다** |

**💡 สรุป:** เติม 십니다 ท้ายก้านที่ไม่มีตัวสะกด และ 으십니다 ท้ายก้านที่มีตัวสะกด ; ถ้ามีคำยกย่องเฉพาะ (주무시다 · 드시다 · 계시다) ใช้คำเหล่านั้นเลย

#### 📽️ [topic:23] 이었어요/였어요 · 이/가 아니었어요 (교과서 152쪽)
🖼️ *สไลด์ 문법 1 (ภาพหน้า 15 ของไฟล์) หัวข้อ -았/었/였- ข้อ 5. คำนาม มี 2 ตาราง*

| 명사 + **이었어요 / 였어요** | 받침(○) + 이었어요 | 받침(✗) + 였어요 |
|---|---|---|
| ตัวอย่าง | 학생-학생이었어요 · 공원-공원이었어요 | 의사-의사였어요 · 학교-학교였어요 |

| 명사 + 이/가 **아니었어요** | 받침(○) + 이 아니었어요 | 받침(✗) + 가 아니었어요 |
|---|---|---|
| ตัวอย่าง | 학생-학생이 아니었어요 · 공원-공원이 아니었어요 | 의사-의사가 아니었어요 · 학(교)... (ภาพถูกบัง) |

**💡 สรุป:** อดีตของ "เป็น" = 이었어요 หลังคำนามที่มีตัวสะกด และ 였어요 หลังคำนามที่ไม่มีตัวสะกด ; ปฏิเสธใช้ 이/가 아니었어요

#### 📽️ [topic:24] N에서 왔어요 (교과서 154쪽)
🖼️ *สไลด์ 문법 2 (ภาพหน้า 15 ของไฟล์) หัวข้อ 에서 왔어요*

- **명사 에서 왔어요** (명사 = 나라, 고향…) *(มาจาก...)*
- 가: 장핑 씨는 어느 나라에서 왔어요? *(คุณจางผิงมาจากประเทศไหน)*
- 나: 중국에서 왔어요. *(มาจากจีน)*
- 가: 중국 어디에서 왔어요? *(มาจากจีนที่ไหน)*
- 나: 중국 베이징에서 왔어요. *(มาจากปักกิ่ง ประเทศจีน)*

**💡 สรุป:** บอกว่ามาจากที่ไหน = สถานที่ + 에서 + 왔어요 (ถามด้วย 어느 나라 / 어디)

#### 📽️ [topic:23] 활동: ถามเรื่องวันเกิด (교과서 156쪽)
🖼️ *สไลด์ 활동 (ภาพหน้า 18 ของไฟล์) "친구와 같이 질문하고 대답하세요." รายการคำถาม 9 ข้อ ข้อ 사진이 있어요 ถูกขีดฆ่า*

- 생일이 며칠이에요? *(วันเกิดวันที่เท่าไร)*
- 지난 생일에 무엇을 했어요? *(วันเกิดครั้งก่อนทำอะไร)*
- 어디에서 했어요? · 누구하고 같이 했어요? *(ทำที่ไหน / ทำกับใคร — อาจารย์ใส่ "+" รวมสองข้อ)*
- 무엇을 먹었어요? *(กินอะไร)*
- 무엇을 받았어요? · 누가 줬어요? *(ได้รับอะไร / ใครให้ — มี "+" รวมสองข้อ)*
- 사진이 있어요? ✗ *(ข้อนี้ถูกขีดฆ่า)*
- 지난 생일이 어땠어요? *(วันเกิดครั้งก่อนเป็นอย่างไร)*

**💡 สรุป:** ใช้ภาคอดีต -았/었/였- ถามและตอบเรื่องวันเกิด ข้อที่ครูใส่ "+" ให้ตอบเชื่อมเป็นประโยคเดียวได้
