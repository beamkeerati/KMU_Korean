### 📽️ สไลด์อาจารย์ 12과

#### 📽️ [topic:08] 안 + 동사 / 명사 + 안 + 하다
![](img:lc12-6-slide-an) 🖼️ *สไลด์ (ภาพหน้า 6 ของไฟล์) หัวข้อ 안 มีตัวอย่าง 2 ข้อ ปลายบรรทัดล่างมีเครื่องหมาย ✗ ปากกาดำ*

- **1. 안 + 동사**
  - 마시다 → **안** 마셔요 *(ไม่ดื่ม)*
- **2. 명사 + 안 + 하다**
  - 공부(를) 하다 → 공부(를) **안** 해요 *(ไม่เรียน)* (มีเครื่องหมาย ✗ ท้ายประโยค ความหมายไม่ชัด (?))

**💡 สรุป:** 안 วางหน้ากริยา แต่ถ้าเป็นคำนาม + 하다 ให้วาง 안 ระหว่างนามกับ 해요 เช่น 공부 안 해요 (ห้ามพูด 안 공부해요)

#### 📽️ [topic:00] 12과_안_형태 연습 1 · 문장 연습 2 · 에서_확장 연습 3
![](img:lc12-6-sheet1) ![](img:lc12-6-sheet2) ![](img:lc12-7-sheet) 🖼️ *ใบงานพิมพ์ 3 ส่วน (ภาพหน้า 6 และ 7 ของไฟล์) ส่วน 1 ตารางภาพ 21 ช่อง + 12 ช่อง ให้เขียนรูป 안 + กริยา ส่วน 2 ประโยคเติมช่องว่าง ส่วน 3 ตารางจับคู่กริยา (O/X) กับสถานที่*

ส่วน 1 รูป 안 + กริยา (คุณเขียนไว้): 안 가요 · 안 자요 · 안 사요 · 안 만나요 · 안 팔아요 · 안 앉아요 · 안 받아요 / 안 와요 · 안 봐요 · 안 먹어요 · 안 읽어요 · 안 쉬어요 · 안 입어요 · 안 씻어요 / 안 마셔요 · 안 기다려요 · 안 가르쳐요 · 안 배워요 · 안 줘요 · 춤을 안 춰요 · 안 써요 ; ชุดที่สอง (นามกริยา + 안 해요): 공부 안 해요 · 운동 안 해요 · 이야기 안 해요 · 노래 안 해요 · 청소 안 해요 · 쇼핑 안 해요 / 일 안 해요 · 전화 안 해요 · 요리 안 해요 · 샤워 안 해요 · 숙제 안 해요 · 빨래 안 해요

**📝 ที่คุณจดไว้:** ภาพหน้า 7 เป็นฉบับที่ยังเขียนรูปธรรมดา (가요 · 자요 · 사요 · 만나요 · 팔아요 · 앉아요 · 받아요 ...) ยังไม่ใส่ 안 ; ครูวงกลมแดงที่ 앉아요 และ 받어요 (สะกดผิด ต้องเป็น 받아요 (?)) และติดดาวแดงที่ 춤을 춰요 (?) ; ตารางภาพ 12 ช่องล่างยังว่าง

ส่วน 2 ประโยคปฏิเสธ (ช่องว่างเติมเฉพาะบางข้อ):

- 친구가 선생님을 **안 만나요**. (만나다 ✗) *(เพื่อนไม่พบครู)*
- 아이가 과자를 **안 먹어요**. (먹다 ✗) *(เด็กไม่กินขนม)*
- 선생님이 한국어를 **안 가르쳐요**. (가르치다 ✗) *(ครูไม่สอนภาษาเกาหลี)*
- 의사가 신문을 **안 읽어요**. (읽다 ✗) *(หมอไม่อ่านหนังสือพิมพ์)*
- 학생이 영어를 **안 배워요**. (배우다 ✗) *(นักเรียนไม่เรียนภาษาอังกฤษ)*
- 가수가 노래 **안 해요**. (노래하다 ✗) *(นักร้องไม่ร้องเพลง)*
- 동생이 텔레비전을 **안 봐요**. (보다 ✗) *(น้องไม่ดูทีวี)*
- 마키 씨가 커피를 (　　). (마시다 ✗) — ช่องว่าง
- 윤아 씨가 (　　). (공부하다 ✗) — ช่องว่าง

ส่วน 3 จับคู่ (คำที่ใช้ไม่ได้ ✗ / ใช้ได้ ○ ต่อสถานที่ 12 แห่ง):

| คำที่ผิด (✗) | คำที่ถูก (○) |
|---|---|
| 돈을 찾다 | 돈을 보내다 |
| 책을 읽다 | 책을 빌리다 |
| 산책을 하다 | 자전거를 타다 |
| 선생님을 만나다 | 학생증을 만들다 |
| 옷을 사다 | 고기를 사다 |
| 영화를 보다 | 아르바이트를 하다 |
| 축구를 하다 | 농구를 하다 |
| 라면을 먹다 | 김밥을 먹다 |
| 커피를 마시다 | 녹차를 마시다 |
| 영어를 배우다 | 한국어를 배우다 |
| 공책을 사다 | 연필을 사다 |
| 운동을 하다 | 친구를 만나다 |

**💡 สรุป:** ฝึกใช้ 안 ปฏิเสธกริยา และฝึกเลือกกริยาที่เข้ากับสถานที่ (ใช้ 에서) ประโยคใช้กริยาเดิมคู่กับคำนามเดิมไม่ได้ในบางคู่ เช่น 돈을 찾다 / 돈을 보내다

#### 📽️ [topic:09] 장소 명사 + 에서 + 동사 (교과서 106쪽)
![](img:lc12-6-slide-eseo) 🖼️ *สไลด์ (ภาพหน้า 6 ของไฟล์) 문법 2 หัวข้อ 에서 อาจารย์เขียนลายมือสีน้ำเงินด้านบน และตัวอย่างสีแดง*

| 장소 명사 | 에서 | + | 동사 |
|---|---|---|---|
| 식당에서 | | | 밥을 먹어요. *(กินข้าวที่โรงอาหาร)* |
| 교실에서 | | | 공부를 해요. *(เรียนที่ห้องเรียน)* |
| 커피숍에서 | | | 친구를 만나요. *(พบเพื่อนที่ร้านกาแฟ)* |

- อาจารย์เขียนโครงสร้างด้านบน: ___이/가(은/는) + ___에서 + ___을/를 + ___아/어/여요
- ตัวอย่างที่ครูเขียนสีแดง: 저는 교실에서 한국말은 (안) 공부해요. (มีตัว "안" เขียนในวงเล็บเหนือ 을/를 (?))

**💡 สรุป:** สถานที่ที่ทำกิจกรรมต้องใส่ 에서 แล้วตามด้วยกริยา (ต่างจาก 에 ที่ใช้กับ 가다/오다/있다)
