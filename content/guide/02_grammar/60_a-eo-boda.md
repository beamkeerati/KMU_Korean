## 60. -아/어/여 보다 (ลอง… · เคย…)
ต่อท้ายรากกริยา + **보다** (ตำราเรียกว่า trial of an action or past experience) ได้สองความหมาย: ① **ลองทำ** — 먹어 **보세요** *(ลองกินดูสิ)* · 가 **보고 싶어요** *(อยากลองไป)* ② **เคยทำ (ประสบการณ์)** — 가 **봤어요?** *(เคยไปไหม)* · 안 가 **봤어요** *(ไม่เคยไป)*
สอนในบท 35 (교과서 346–347쪽 · 준비 2) · ต่อยอดจาก ข้อ 06 (-아/어요 — กฎ ㅏ/ㅗ → 아 · อื่น → 어 · 하다 → 해) · ข้อ 23 (-았/었어요) · ข้อ 08 (안) · ข้อ 20 (-(으)세요)
ใช้ต่อใน ข้อ 38 (-고 싶다: 가 보고 싶어요) · ข้อ 55 (…가 보면) · ข้อ 63 (-아/어/여 주세요 ที่ดูคล้ายกัน) และ 활동 บท 35 (몽골에 가 보고 싶어요)

### 📌 รูปแบบและเงื่อนไข
เลือก 아/어/여 จาก**สระของพยางค์สุดท้ายของราก** เหมือนการผัน -아/어요 (ข้อ 06) แล้วตามด้วย **보다** (ผันตามปกติ: 봐요 · 봤어요 · 보세요 · 보고 싶어요)

| สระพยางค์สุดท้ายของราก | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| **ㅏ · ㅗ** | **-아 보다** | 가다 → **가 봐요** · 오다 → **와 봐요** · 타다 → **타 봐요** · 앉다 → **앉아 봐요** · 살다 → **살아 봐요** *(ลองไป · ลองมา · ลองขี่ · ลองนั่ง · ลองอยู่)* |
| สระอื่น | **-어 보다** | 먹다 → **먹어 봐요** · 입다 → **입어 봐요** · 읽다 → **읽어 봐요** · 만들다 → **만들어 봐요** · 배우다 → **배워 봐요** · 마시다 → **마셔 봐요** |
| **하다** | **해 보다** (하여 → 해) | 하다 → **해 봐요** · 여행하다 → **여행해 봐요** · 공부하다 → **공부해 봐요** |
| ㅡ-ราก | ㅡ หลุด | 쓰다 → **써 봐요** · 끄다 → **꺼 봐요** |
| ㄷ · ㅂ · 르 ไม่ปกติ | ตามกฎเดิมก่อน 아/어 (ข้อ 51 · 37 · 54) | 듣다 → **들어 봐요** · 돕다 → **도와 봐요** · 부르다 → **불러 봐요** · 자르다 → **잘라 봐요** |

- **ตำรา 346쪽:** "ต่อหลังรากกริยาแสดงการทดลองทำหรือประสบการณ์ในอดีต — ㅏ/ㅗ → -아 보다 · อื่น ๆ → -어 보다 · 하다 → 하여 보다 (→ 해 보다)"
- **รูปที่พบบ่อย (เปลี่ยนเฉพาะ 보다):** 가 **봐요** (บอกเล่า/ลอง) · 가 **봤어요** (เคย) · 가 **보세요** (ลองไปสิ — ขอร้อง/แนะนำ ข้อ 20) · 가 **보셨어요?** (ถามผู้ใหญ่ว่าเคยไหม) · 가 **보고 싶어요** (อยากลองไป ข้อ 38) · 가 **볼까요?** (ลองไปกันไหม ข้อ 33) · 가 **볼 거예요** (จะลองไป ข้อ 28) · 가 **보면** (ถ้าลองไป ข้อ 55)
- **ใช้กับกริยาเท่านั้น** — ลองทำ/เคยทำต้องเป็นการกระทำ ไม่ใช้กับคำคุณศัพท์
- **ถามประสบการณ์:** …-아/어 봤어요? → ตอบ **네, -아/어 봤어요** *(เคย)* / **아니요, 안 -아/어 봤어요** *(ไม่เคย — 안 อยู่หน้ากลุ่มทั้งหมด: 안 가 봤어요)*
- **เว้นวรรค:** 가 **봤어요** · 먹어 **보세요** · 해 **봤어요** — 보다 เป็นกริยาช่วยแยกคำจากราก (ข้อ 13) · 한번 = "ลองสักครั้ง" (ตำราเขียน 한번 ติดกัน)

### 📖 ตัวอย่างและการใช้
#### จากกล่องไวยากรณ์และ 준비 (346쪽)
1. 제프리 씨, 제주도에 **가 봤어요**? — 아니요, **안 가 봤어요**. *(คุณเจฟฟรีย์ เคยไปเกาะเชจูไหม — ไม่ค่ะ ไม่เคยไป)*
2. 우리 집에 한번 **와 보세요**. *(ลองมาบ้านเราสักครั้งสิ — ㅗ + 아 → 와)*
3. 한국 노래를 **해 봤어요**? *(เคยร้องเพลงเกาหลีไหม — 노래를 하다 = ร้อง/ทำเพลง)*
4. 이 음악을 **들어 보셨어요**? *(เคยฟังเพลงนี้ไหมคะ — ㄷ → ㄹ + 시 + 었)*

#### 연습 1 (346쪽): 〜해 봤어요?
| โจทย์ | ประโยคคำถาม | แปล |
|:---|:---|:---|
| 제주도에 가다 | 제주도에 **가 봤어요**? | เคยไปเกาะเชจูไหม |
| 고속버스를 타다 | 고속버스를 **타 봤어요**? | เคยขึ้นรถบัสด่วนไหม |
| 한국 노래를 부르다 | 한국 노래를 **불러 봤어요**? | เคยร้องเพลงเกาหลีไหม — 르 ไม่ปกติ |
| 한복을 입다 | 한복을 **입어 봤어요**? | เคยใส่ชุดฮันบกไหม |
| 혼자 여행을 하다 | 혼자 여행을 **해 봤어요**? | เคยเที่ยวคนเดียวไหม |
| 삼계탕을 먹다 | 삼계탕을 **먹어 봤어요**? | เคยกินซัมกเยทังไหม |
| 이 음악을 듣다 | 이 음악을 **들어 봤어요**? | เคยฟังเพลงนี้ไหม — ㄷ ไม่ปกติ |

#### 연습 2–3 และ 활동 (347–349쪽): ถาม–แนะนำให้ลอง
- 가: 한강에서 유람선을 **타 봤어요**? — 나: 아니요, **안 타 봤어요**. — 가: 그럼 한번 **타 보세요**. 아주 재미있어요. *(เคยขึ้นเรือสำราญที่แม่น้ำฮันไหม — ไม่เคย — งั้นลองขึ้นดูสักครั้ง สนุกมาก)*
- โจทย์ต่อ (ตำราให้คู่คำ — เรียบเรียงตามรูปแบบ): 태권도를 배우다 / 재미있다 → 태권도를 **배워 보세요**. 재미있어요 · 한복을 입다 / 예쁘다 → **입어 보세요**. 예뻐요 · 한국 신문을 읽다 / 어렵지 않다 → **읽어 보세요**. 어렵지 않아요 · 찜질방에 가다 / 기분이 좋다 → **가 보세요**. 기분이 좋아요 · 떡볶이를 만들다 / 아주 간단하다 → **만들어 보세요**. 아주 간단해요 · 시골 여행하다 / 경치가 좋다 → **여행해 보세요**. 경치가 좋아요
- 가: 바트 씨, 명동에 **가 봤어요**? — 나: 네, **가 봤어요**. — 가: 그래요? 저도 명동에 가고 싶어요. 명동에서는 무엇을 하는 것이 좋아요? — 나: 가게가 많으니까 쇼핑을 **해 보세요**. 아주 재미있을 거예요. *(เคยไปเมียงดงไหม — เคย — อยากไปเหมือนกัน ที่นั่นทำอะไรดี — ร้านเยอะ ลองช็อปปิงดูสิ สนุกแน่)* … 칼국수를 **먹어 보세요**. *(ลองกินคัลกุกซูดูสิ)*
- 활동 (349쪽): 저는 몽골에 **가 보고 싶어요**. 몽골에서 말을 **타 보고 싶어요**. 그리고 몽골의 전통 집 게르에서 **자 보고 싶어요**. *(ฉันอยากลองไปมองโกเลีย · อยากลองขี่ม้า · อยากลองนอนในเกอร์ บ้านดั้งเดิมของมองโกเลีย — -고 싶다 ข้อ 38)* · 몽골에 가면 어디에서 말을 탈 수 있어요? *(ถ้าไปมองโกเลียจะขี่ม้าได้ที่ไหน — ข้อ 55 · 46)*

### ⚠️ จุดสับสน
#### -아/어 보다 vs -았/었어요 vs -아/어 주다 vs -고 있다
| | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| **-아/어 보다** | **ลอง / เคย** (ประสบการณ์) | 삼계탕을 먹어 봤어요 *(เคยกินซัมกเยทัง)* |
| -았/었어요 (ข้อ 23) | ทำแล้ว (เหตุการณ์ในอดีต ไม่เน้นประสบการณ์) | 삼계탕을 먹었어요 *(กินซัมกเยทังแล้ว)* |
| -아/어 주다 (ข้อ 63) | **ทำให้** (เพื่อผู้อื่น) | 삼계탕을 만들어 주세요 *(ช่วยทำซัมกเยทังให้หน่อย)* |
| -고 있다 (ข้อ 32) | กำลังทำ | 삼계탕을 먹고 있어요 *(กำลังกิน)* |

- **เคย (ถามประสบการณ์) ใช้ -아/어 봤어요** ในอดีต: ✓ 제주도에 가 봤어요? *(เคยไปไหม)* / 제주도에 갔어요? *(ไปเชจูแล้วหรือยัง/ไปมาหรือเปล่า — ไม่ชัดว่าถามประสบการณ์)* · ✗ 제주도에 가 봐요? (ปัจจุบัน = "ลองไป")
- **ลอง (ขอร้อง/แนะนำ) ใช้ -아/어 보세요:** ✓ 한번 가 보세요 *(ลองไปสักครั้ง)* · ใช้ 한번 บ่อย
- **ㅏ/ㅗ → 아:** ✓ 가 봐요 · 와 봐요 · 앉아 봐요 · 살아 봐요 / ✗ 살어 봐요 · 받어 봐요 · 앉어 봐요 (เคยพลาด: 살어요 · 받었어요 — ราก 살 · 받 มี ㅏ จึงใช้ 아)
- **하다 → 해:** ✓ 해 봤어요 · ✓ 여행해 봤어요 / ✗ 하 봤어요 · ✗ 하어 봤어요 (รูปเต็ม 하여 보다 เป็นภาษาเขียน/ทางการ — ตำราให้ย่อเป็น 해 보다)
- **ㅡ-ราก:** ✓ 써 봤어요 (쓰다) · ✓ 꺼 봤어요 (끄다) / ✗ 쓰어 봤어요
- **ㄷ/르:** ✓ 들어 봤어요 · 불러 봤어요 / ✗ 듣어 봤어요 · ✗ 부르어 봤어요
- **ตำแหน่ง 안:** ✓ 안 가 봤어요 *(ตำรา 346쪽)* · △ 가 안 봤어요 (ไวยากรณ์ได้แต่ความหมายเพี้ยน — ตำราใช้ 안 วางหน้ากลุ่ม) · ✓ 아직 안 가 봤어요 *(ยังไม่เคยไป — เสริม)*
- **เว้นวรรค:** ✓ 가 봤어요 / ✗ 가봤어요 (ตำราเว้นวรรค — เหมือน ✗ 갈거예요 ที่เคยเขียนติดกัน)
- **-(으)ㄴ 적이 있다** *(เคยมีประสบการณ์)* ปรากฏในคำถามอุ่นเครื่องของ 읽기 บท 37 ("약속을 바꾼 적이 있어요?") แต่**ตำรายังไม่สอนเป็นข้อไวยากรณ์** — ในบท 35 ใช้ -아/어 봤어요 แทน (เสริม)

> [!TIP]
> **-아/어 보다 = "ลอง/เคย"** — เปลี่ยนเฉพาะ 보다: **봐요 · 봤어요 (เคย) · 보세요 (ลองสิ) · 보고 싶어요 (อยากลอง)** · เลือก 아/어/해 จากสระของราก

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- ยังไม่มีข้อสอบจริงเกี่ยวกับ -아/어 보다 — 35과 อยู่ใน **복습시험④ (11/18)** และ **기말** · ประโยค "…가 봤어요? — 네, 가 봤어요 / 아니요, 안 가 봤어요" เหมาะกับ 말하기 (ถาม–ตอบประสบการณ์)
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ (CLAUDE.md §6b):** ★ **ㅏ-stem + 어요:** 살어요 · 살었어요 · 받었어요 ✗ → 살아요 · 받았어요 (ครูไฮไลต์ใน sheet 19) → ใช้กฎเดียวกัน 살아 봐요 · ✗ 살어 봐요 · **안 + N하다:** 안 아르바이트 해요 ✗ → 아르바이트 안 해요 · **ㅡ-drop** 바빴어요 (ถูกอยู่แล้ว) → 써 봤어요 · **เขียนติดกัน** 갈거예요 · 청소할거예요 → 가 봤어요 (เว้นวรรค) · ㅐ/ㅔ (네 게 ✗ → 네 개 · 젝 → 책) · **tense หลุด:** 숙제를 안 했어요 → 하지 않습니다 (แปลงรูปแล้วกาลหาย) → "เคย" ต้องคง 봤어요
- **คาดการณ์รูปแบบข้อสอบ** (เดาจากรูปแบบ 복습시험①②):
  1. **ผันตาราง:** 먹다 · 오다 · 입다 · 듣다 · 부르다 · 하다 → ___ 봤어요 / ___ 보세요 (เน้น ㅏ/ㅗ และ 하다 → 해)
  2. **ถามประสบการณ์ตอบด้วยไวยากรณ์ที่กำหนด:** 제주도에 가 봤어요? → 네, 가 봤어요 / 아니요, 안 가 봤어요 (ประโยค 쓰기 "ตอบด้วย -아/어 보다")
  3. **ให้คำแนะนำ:** 한복을 입다 / 예쁘다 → 한복을 입어 보세요. 예뻐요 (ประโยค "문장을 만드세요")
  4. **읽기/대화 35-1 หรือ 활동:** "몽골에 가 보고 싶어요 / 말을 타 보고 싶어요" ปรับเป็นบทสนทนา 가/나
