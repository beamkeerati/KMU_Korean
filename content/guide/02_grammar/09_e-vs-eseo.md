## 09. 에 vs 에서 (ไปที่/อยู่ที่ vs ทำที่)
คำชี้สถานที่ 2 ตัวที่แปลไทยว่า "ที่" เหมือนกัน แต่เลือกตาม **กริยาท้ายประโยค** ไม่ใช่ตามสถานที่ — เป็นอีกจุดที่ออกสอบบ่อยที่สุด
สอนในบท 8–9 (에 있다/없다 · 에 가다/오다 — 교과서 78쪽) และบท 12 (에서 + กริยา — 106쪽) · ต่อยอดจากข้อ 05 (에 있어요) และข้อ 07 (กรรม 을/를)
ใช้ต่อในข้อ 10 (에 บอกเวลา), ข้อ 24 (에서 "มาจาก"), ข้อ 26 (N에 V-(으)러 가요), ข้อ 27 (에서~까지), ข้อ 29 (에게/한테)

### 📌 รูปแบบและเงื่อนไข

| | **에** | **에서** |
|:---|:---|:---|
| ใช้กับกริยา | **있다/없다** (มี/อยู่) · **가다/오다** (ไป/มา) | กริยาการกระทำอื่น ๆ: 먹다 · 만나다 · 일하다 · 사다 · 공부하다 |
| ความหมาย | ที่ตั้ง / จุดหมายปลายทาง — "อยู่**ที่** / ไป**ที่**" | สถานที่ที่ **ทำกิจกรรม** — "ทำ**ที่**" |
| โครงสร้าง | สถานที่ + **에** + 있어요 / 가요 / 와요 | สถานที่ + **에서** + (กรรม + 을/를) + กริยา |
| ตัวอย่าง | 학교**에** 가요 *(ไปโรงเรียน)* · 집**에** 있어요 *(อยู่บ้าน)* | 학교**에서** 공부해요 *(เรียนที่โรงเรียน)* · 식당**에서** 밥을 먹어요 *(กินข้าวที่โรงอาหาร)* |

- **ตัดสินที่ "กริยา"** — สถานที่เดียวกัน กริยาต่างกัน คำชี้ก็ต่าง: 집**에** 가요 · 집**에** 있어요 ↔ 집**에서** 쉬어요 · 집**에서** 텔레비전을 봐요
- **에 + 가다/오다** *(교과서 78쪽)*: ติดหลังนามสถานที่ + กริยาเคลื่อนที่ บอก "ปลายทาง/ทิศทาง" → ___이/가(은/는) ___**에** 가요/와요
- **에서 + กริยา** *(교과서 106쪽)*: ติดหลังนามสถานที่ เพื่อบอกว่าที่นั่นคือสถานที่ที่การกระทำเกิดขึ้น → ___이/가(은/는) ___**에서** ___을/를 ___아/어/여요
- **ถามสถานที่**: 어디**에** 가요? *(ไปไหน)* → 도서관에 가요. · 어디**에** 있어요? *(อยู่ที่ไหน)* → 학생회관 옆에 있어요. · 어디**에서** 옷을 사요? *(ซื้อเสื้อที่ไหน)* → 백화점에서 옷을 사요.
- เสียงจริง: 도서관에 [도서과네] · 우체국에 [우체구게] · 집에 [지베] · 커피숍에서 [커피쇼베서] — ตัวสะกดไหลไปเชื่อมกับเสียง 에

### 📖 ตัวอย่างและการใช้

**에 가다/오다 (บท 9 · 교과서 78–80쪽)**

📽️ **สไลด์อาจารย์ (교과서 78쪽 문법 2)** — **___이/가 ___에 가요.** (ครูเขียนเพิ่ม **___은/는 ___에 가요 / 와요**) · **장소(명사)에 가다** *(ไป + สถานที่)* → 가: 어디에 가요? 나: 도서관에 가요. *(ไปไหน → ไปห้องสมุด)* · สรุป: สถานที่ที่เป็นจุดหมายปลายทางต้องตามด้วย **에** แล้วจึงใช้ 가요 (ไป) หรือ 와요 (มา)

- 마키 씨, 어디에 가요? → 도서관에 가요. · 도서관에 가요? → 아니요, 서점에 가요. · 바트 씨는 어디에 가요? → 은행에 가요. *(คุณมากิไปไหน → ห้องสมุด · ไปห้องสมุดไหม → ไม่ ไปร้านหนังสือ · คุณบาตไปไหน → ธนาคาร)*
- 우체국에 가요 · 병원에 가요 · 미용실에 가요 · 공항에 가요 · 식당에 가요 · 영화관에 가요 · 약국에 가요 *(ไปไปรษณีย์ · โรงพยาบาล · ร้านเสริมสวย · สนามบิน · โรงอาหาร · โรงหนัง · ร้านขายยา)*
- 친구가 우리 집에 와요. *(เพื่อนมาบ้านเรา — เวิร์กบุ๊ก 12과 F โจทย์ที่ 3)*

**에서 + กริยา (บท 12 · 교과서 106–108쪽)**

📽️ **สไลด์อาจารย์ (교과서 106쪽 문법 2 — 장소 명사 + 에서 + 동사)**

| 장소 + 에서 | + 동사 |
|:---|:---|
| 식당**에서** | 밥을 먹어요. *(กินข้าวที่โรงอาหาร)* |
| 교실**에서** | 공부를 해요. *(เรียนที่ห้องเรียน)* |
| 커피숍**에서** | 친구를 만나요. *(พบเพื่อนที่ร้านกาแฟ)* |

ครูเขียนโครงสร้าง **___이/가(은/는) + ___에서 + ___을/를 + ___아/어/여요** · สรุป: สถานที่ที่ทำกิจกรรมต้องใส่ **에서** แล้วตามด้วยกริยา (ต่างจาก 에 ที่ใช้กับ 가다/오다/있다)

- 백화점에서 옷을 사요. · 서점에서 책을 사요. · 공원에서 운동을 해요. · 은행에서 돈을 찾아요. · 공원에서 산책을 해요. · 회사에서 일을 해요. *(ซื้อเสื้อที่ห้าง · ซื้อหนังสือที่ร้านหนังสือ · ออกกำลังกายที่สวน · ถอนเงินที่ธนาคาร · เดินเล่นที่สวน · ทำงานที่บริษัท)*
- 어디에서 공부를 해요? → 학교에서 공부해요. · 집에서 무엇을 해요? → 집에서 텔레비전을 봐요. *(เรียนที่ไหน → ที่โรงเรียน · ทำอะไรที่บ้าน → ดูทีวีที่บ้าน)*
- 커피숍에서 무엇을 해요? → 커피숍에서 아르바이트를 해요. *(ทำอะไรที่ร้านกาแฟ → ทำงานพิเศษ)* · 저는 고향에서 요리를 해요. 한국에서 요리를 안 해요. *(ที่บ้านเกิดฉันทำอาหาร ที่เกาหลีไม่ทำ)*

#### 📽️ ฝึกจากสไลด์อาจารย์ — 에서 확장 연습 (ใบงาน 12과 ส่วน 3)
ทุกสถานที่ฝึกพูด "✗ ไม่ได้ทำ → ○ ทำ" ด้วย 에서 + 안 (ข้อ 08): 은행**에서** 돈을 **안** 찾아요. 돈을 보내요. *({p:ที่}{n:ธนาคาร}{x:ไม่}{v:ถอน}{n:เงิน} แต่{v:โอน}{n:เงิน})*

| สถานที่ | ✗ ไม่ได้ทำ | ○ ทำ |
|:---|:---|:---|
| 은행 *(ธนาคาร)* | 돈을 찾다 *(ถอนเงิน)* | 돈을 보내다 *(โอนเงิน)* |
| 도서관 *(ห้องสมุด)* | 책을 읽다 *(อ่านหนังสือ)* | 책을 빌리다 *(ยืมหนังสือ)* |
| 공원 *(สวนสาธารณะ)* | 산책을 하다 *(เดินเล่น)* | 자전거를 타다 *(ขี่จักรยาน)* |
| 사무실 *(สำนักงาน)* | 선생님을 만나다 *(พบครู)* | 학생증을 만들다 *(ทำบัตรนักศึกษา)* |
| 시장 *(ตลาด)* | 옷을 사다 *(ซื้อเสื้อผ้า)* | 고기를 사다 *(ซื้อเนื้อ)* |
| 극장 *(โรงหนัง)* | 영화를 보다 *(ดูหนัง)* | 아르바이트를 하다 *(ทำงานพิเศษ)* |
| 운동장 *(สนามกีฬา)* | 축구를 하다 *(เล่นฟุตบอล)* | 농구를 하다 *(เล่นบาสเกตบอล)* |
| 식당 *(ร้านอาหาร)* | 라면을 먹다 *(กินราเมียน)* | 김밥을 먹다 *(กินคิมบับ)* |
| 커피숍 *(ร้านกาแฟ)* | 커피를 마시다 *(ดื่มกาแฟ)* | 녹차를 마시다 *(ดื่มชาเขียว)* |
| 학교 *(โรงเรียน)* | 영어를 배우다 *(เรียนภาษาอังกฤษ)* | 한국어를 배우다 *(เรียนภาษาเกาหลี)* |
| 문구점 *(ร้านเครื่องเขียน)* | 공책을 사다 *(ซื้อสมุด)* | 연필을 사다 *(ซื้อดินสอ)* |
| 헬스장 *(ฟิตเนส)* | 운동을 하다 *(ออกกำลังกาย)* | 친구를 만나다 *(พบเพื่อน)* |

### ⚠️ จุดสับสน

#### 에 vs 에서 — ผิดที่เจอบ่อย
| ✗ ผิด | ✓ ถูก | เพราะ |
|:---|:---|:---|
| 학교**에서** 가요 | 학교**에** 가요 | 가다 = เคลื่อนที่ไปจุดหมาย → 에 |
| 학교**에** 한국어를 공부해요 | 학교**에서** 한국어를 공부해요 | 공부하다 = การกระทำ → 에서 |
| 백화점**에** 샀어요 ★ | 백화점**에서** 샀어요 *(หรือ 백화점**에** 갔어요)* | 사다 = การกระทำ → 에서 · ถ้าจะใช้ 에 กริยาต้องเป็น 가다 |
| 학생식당**하고** 가요 ★ *(−4)* | 학생식당**에** 가요 | จุดหมายของ 가다 ใช้ **에** · เผลอหยิบ 하고 เพราะอยู่ใน 보기 (하고 = "และ/กับ" ข้อ 11) |
| 친구가 우리 집**에서** 와요 | 친구가 우리 집**에** 와요 | 오다 → 에 *(ครูแก้ใน 워크북 12과 F โจทย์ที่ 3)* |
| 집**에서** 있어요 | 집**에** 있어요 | "อยู่" = 에 · "ทำกิจกรรมที่" = 에서 |

> [!TIP]
> **ถามตัวเอง:** กริยาท้ายประโยค "เคลื่อนที่/อยู่/มี" (가다 · 오다 · 있다 · 없다) → **에** · "กระทำอย่างอื่น" (กิน ซื้อ เรียน ทำงาน พบ อ่าน) → **에서**

#### 에 vs 에서 vs 에게/한테
ไทยใช้คำว่า "ที่ / ให้ / ไป" ปนกันหมด เกาหลีแยกเป็น 3 ตัวตาม *ประเภทของปลายทาง* และ *ชนิดของกริยา*

| | 에 | 에서 | 에게/한테 |
|:---|:---|:---|:---|
| ไทยแปล | ไป*ที่* / อยู่*ที่* | ทำ*ที่* | ให้*แก่* (คน) |
| ตามด้วย | 가다, 오다, 있다 | กริยากิจกรรม | 주다, 보내다, 전화하다 |
| ตัวอย่าง | 학교**에** 가요 | 학교**에서** 공부해요 | 친구**에게** 줘요 |

* 학교**에** 가요. ✓ *(ไปโรงเรียน — ที่หมาย)* · 학교**에서** 공부해요. ✓ *(เรียนที่โรงเรียน — ทำกิจกรรม)*
* 친구**에게** 줘요. ✓ *(ให้เพื่อน — ผู้รับเป็นคน)* · 꽃**에** 물을 줘요. ✓ *(รดน้ำให้ดอกไม้ — ผู้รับเป็นสิ่งของ → **에** ไม่ใช่ 에게 — ข้อ 29)*

#### 에 และ 에서 มีมากกว่า 1 งาน
| คำ | งาน | ตัวอย่าง | ข้อ |
|:---|:---|:---|:---:|
| **에** | ที่ตั้ง / จุดหมาย | 학교에 가요 · 집에 있어요 | 05 · 09 |
| **에** | เวลา | 일요일**에** · 7시**에** | 10 |
| **에** | "ละ/ต่อ" หน่วยนับ | 한 개**에** 천 원이에요 | 04 |
| **에** | จุดหมาย + จุดประสงค์ | 서점**에** 책을 사러 가요 | 26 |
| **에서** | ทำที่… | 학교**에서** 공부해요 | 09 |
| **에서** | จาก… | 몽골**에서** 왔어요 · 서울**에서** 부산까지 *(จากโซลถึงปูซาน)* | 24 · 27 |

> [!TIP]
> **กฎจำง่าย:** ที่หมาย/ที่ตั้ง → 에 · ทำกิจกรรม → 에서 · ผู้รับเป็นคน → 에게/한테 (เป็นสิ่งของ → 에)

#### 에 สามหน้าที่ในย่อหน้าเดียว (ชุดทบทวนกลางภาค โจทย์ที่ 2)

ย่อหน้า "저는 아사꼬예요…" ใช้ 에 ครบทั้งสามแบบ — เห็น 에 แล้วต้องรู้ว่าเป็นแบบไหน ไม่ใช่แค่ "ที่"

| หน้าที่ของ 에 | ตัวอย่างในโจทย์ | แปล | ข้อ |
|:---|:---|:---|:---:|
| **เวลา** "ตอน…" | 오전**에** 학교에서 배워요 · 주말**에** 파티가 있어요 | ตอนเช้า · สุดสัปดาห์ | 10 |
| **จุดหมาย / ที่อยู่** | 도서관**에** 가요 · 명동**에** 갔어요 · 센터**에** 다녀요 | ไป… · เรียนที่… | 09 |
| **ต่อหน่วย** "…ละ" | 치마는 한 벌**에** 55,000원 · 티셔츠는 한 벌**에** 30,000원 | ตัวละ 55,000 วอน | 04 |

- 벌 = ลักษณนามของเสื้อผ้า (ตัว/ชุด) — รูปเดียวกับ 사과 한 개**에** 천 원 (10과) · ที่นี่ 에서 ใช้ไม่ได้เลย เพราะไม่ใช่สถานที่ทำกิจกรรม
- ในย่อหน้าเดียวกัน 에서 มี 2 งาน: 일본**에서** 왔어요 (จาก) · 학교**에서** 배워요 · 옷가게**에서** 샀어요 (ทำกิจกรรมที่)
