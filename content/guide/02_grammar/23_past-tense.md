## 23. -았/었/였- · N이었어요/였어요 (อดีตกาล)
เติม **-았/었/였-** หลังรากศัพท์ + ตอนจบประโยค → อดีต ("…แล้ว / เคย…") ใช้กับกริยา คำคุณศัพท์ และ N+이다 · **สอนในบท 17** (교과서 152쪽 · ส่วน N이었어요/였어요 มาจากสไลด์ครู 17과)
ต่อยอดจาก ข้อ 06 (กฎเลือก 아/어 เหมือนกัน แค่เติม ㅆ) · ข้อ 18 (ㅡ 탈락 · 어때요) · ข้อ 02 (이에요/예요) · ใช้ต่อใน ข้อ 24 (왔어요) · ข้อ 21 (갔습니다) · ข้อ 20 (-(으)셨-) · ข้อ 28 (อดีต ↔ อนาคต) · ข้อ 30 (-았/었/였네요)

### 📌 รูปแบบและเงื่อนไข
#### 1) กฎเลือกสระ = กฎเดียวกับ -아/어/여요 (ข้อ 06) แต่เติม ㅆ
ดู **สระของพยางค์สุดท้ายของราก** (ไม่ใช่ตัวสะกด) เหมือนตอนผันปัจจุบัน

| สระท้ายราก | ปัจจุบัน | อดีต | ตัวอย่าง |
|:---|:---|:---|:---|
| **ㅏ หรือ ㅗ** | -아요 | **-았어요** | 많다 → **많았어요** · 앉다 · 살다 → **살았어요** · 받다 → **받았어요** · 놀다 · 좋다 → **좋았어요** |
| **สระอื่น** (ㅓ ㅜ ㅣ ㅐ ฯลฯ) | -어요 | **-었어요** | 먹다 → **먹었어요** · 읽다 → **읽었어요** · 있다 → **있었어요** · 재미있다 → **재미있었어요** |
| **하다** | 해요 | **했어요** | 공부하다 → **공부했어요** · 일하다 · 피곤하다 · 친절하다 |

รากไม่มีตัวสะกด → **ควบสระ** · มีตัวสะกด → **ไม่ควบ**: 가+았 → **갔어요** · 오+았 → **왔어요** · 보+았 → **봤어요** · 사다 → **샀어요** · 만나다 → **만났어요** · 마시+었 → **마셨어요** · 배우+었 → **배웠어요** · 주다 → **줬어요** · 가르치다 → **가르쳤어요** · 기다리다 → **기다렸어요** (ยกเว้น 쉬다 → 쉬었어요 ไม่ควบ) · 먹었어요 · 읽었어요 · 앉았어요

#### 2) ราก ㅡ ตัดทิ้ง (ข้อ 18) · และ 어떻다
ตัด ㅡ แล้วดูสระ**พยางค์ก่อนหน้า**เลือก 아/어 — ไม่มีพยางค์ก่อนหน้า ใช้ 어

| คำ | ปัจจุบัน | อดีต |
|:---|:---|:---|
| 쓰다 (เขียน/ใช้) · 크다 (ใหญ่) | 써요 · 커요 | **썼어요** · **컸어요** (พยางค์เดียว → 었) |
| 바쁘다 (ยุ่ง) · 아프다 (เจ็บ) · 나쁘다 · 배고프다 | 바빠요 · 아파요 · 나빠요 · 배고파요 | **바빴어요** · **아팠어요** · 나빴어요 · 배고팠어요 (ก่อนหน้า ㅏ/ㅗ → 았) |
| 예쁘다 (สวย) | 예뻐요 | **예뻤어요** (ก่อนหน้า ㅖ) |
| 어떻다 (เป็นอย่างไร) | 어때요 | **어땠어요** (ท่องเป็นคู่ — ข้อ 18) |

#### 3) N이다 ในอดีต
📽️ **สไลด์อาจารย์ (교과서 152쪽)** — ตัวสะกด ○ → 이었어요 · ✗ → 였어요 · ปฏิเสธ 이/가 아니었어요

| คำนาม | อดีต ("เคยเป็น…") | ปฏิเสธอดีต ("ไม่ได้เป็น…") |
|:---|:---|:---|
| **มี**ตัวสะกด | N**이었어요**: 학생이었어요 · 공원이었어요 | N**이 아니었어요**: 학생이 아니었어요 · 공원이 아니었어요 |
| **ไม่มี**ตัวสะกด | N**였어요**: 의사였어요 · 학교였어요 | N**가 아니었어요**: 의사가 아니었어요 · 학교가 아니었어요 |

* ที่มา: 이에요 → 이**었**어요 · 예요 → **였**어요 (예요 = 이에요 ที่ย่อ จึงเป็น 였 ที่ย่อจาก 이었) · 있다 / 없다 → 있었어요 / 없었어요
* ผสมกับรูปอื่น: 안 + อดีต 안 갔어요 (ข้อ 08) · -지 않았어요 (ข้อ 16) · ㅂ니다 → 갔습니다 (ข้อ 21) · ยกย่อง 가셨어요 (시 + 었 → 셨 ข้อ 20)
* คำบอกเวลา: **어제** ไม่มี 에 (ข้อ 10) แต่ **작년에 · 지난주에 · 지난 토요일에 · 주말에** มี 에 ได้ — ตำรา 152쪽: 작년**에** 이 책을 읽었어요
* 일찍 *(แต่เช้า/เร็ว)* · 늦게 *(สาย/ช้า)* วางหน้ากริยา: 압둘라 씨는 학교에 일찍 왔어요. *({n:คุณอับดุลลา}{v:มา}{n:โรงเรียน}{a:แต่เช้า} — 매일시험 17 A3)*

### 📖 ตัวอย่างและการใช้
**ตำรา 교과서 152–155쪽**
1. 가: 숙제를 했어요? / 나: 네, 숙제를 했어요. / 아니요, 안 했어요. *(ทำการบ้านแล้วไหม / ทำแล้ว / ยังไม่ได้ทำ)*
2. 영화를 봤어요. · 친구를 만났어요. · 영어를 배웠어요. · 빵을 먹었어요. · 책을 읽었어요. *(ดูหนัง · พบเพื่อน · เรียนภาษาอังกฤษ · กินขนมปัง · อ่านหนังสือ — ฝึกพูด 152쪽)*
3. 어제 동생이 집에 왔어요. · 주말에 청소를 했어요. · 작년에 이 책을 읽었어요. · 영화가 재미있었어요. · 어제 도서관에 사람이 많았어요. · 지난 토요일에 친구에게 이메일을 썼어요. *({n:น้อง}{v:มา}{n:บ้าน} · {v:ทำความสะอาด} · {v:อ่าน}{n:เล่มนี้ปีที่แล้ว} · {n:หนัง}{v:สนุก} · {n:คน}{v:เยอะ}{p:ที่}{n:ห้องสมุด} · {v:เขียน}{n:อีเมล}{p:ถึง}{n:เพื่อน})*
4. 가: 어제 아침에 도서관에 갔어요? / 나: 아니요, 은행에 갔어요. *({n:เช้า}{a:วาน}{v:ไป}{n:ห้องสมุด}ไหม / {x:ไม่} {v:ไป}{n:ธนาคาร})* — ฝึกต่อ 153쪽: 지난 주말에 명동에 갔어요? / 아니요, 집에서 쉬었어요. · 어제 저녁에 일찍 잤어요? / 아니요, 늦게 잤어요.
5. 가: 지난 주말에 뭐 했어요? / 나: 등산을 했어요. 가: 어땠어요? / 나: 좋았어요. *(สุดสัปดาห์ที่แล้วทำอะไร / ปีนเขา / เป็นอย่างไร / ดี)*
6. 대화 17-1: 고향에서 무엇을 했어요? / 회사에서 일했어요. · 회사 생활이 어땠어요? / 아주 바빴어요. *(ที่บ้านเกิดทำอะไร / ทำงานที่บริษัท · ชีวิตบริษัทเป็นอย่างไร / ยุ่งมาก)*
7. ทางการ (읽기 17-2, 18-2): 고향에서 영어를 공부했습니다. · 10시 20분이었습니다. · 영화가 재미있었습니다. *({v:เรียน}{n:อังกฤษ}{p:ที่}{n:บ้านเกิด} · ตอนนั้น {m:10:20} · {n:หนัง}{v:สนุก})*

#### 📽️ ฝึกจากสไลด์อาจารย์ — 활동 ถามเรื่องวันเกิด (교과서 156쪽)
ถาม-ตอบกับเพื่อนด้วยอดีต · ข้อที่ครูใส่ "+" ตอบรวมเป็นประโยคเดียวได้ (คำตอบตัวอย่างดัดแปลงจากใบฝึก 17과 F)

| คำถาม | ตัวอย่างตอบ |
|:---|:---|
| 생일이 며칠이에요? *(วันเกิดวันที่เท่าไร)* | 시월 오일이에요. |
| 지난 생일에 무엇을 했어요? *(วันเกิดครั้งก่อนทำอะไร)* | 파티를 했어요. |
| 어디에서 했어요? **+** 누구하고 같이 했어요? | 집에서 친구들하고 같이 했어요. |
| 무엇을 먹었어요? *(กินอะไร)* | 케이크를 먹었어요. |
| 무엇을 받았어요? **+** 누가 줬어요? | 친구가 선물을 줬어요. |
| 지난 생일이 어땠어요? *(เป็นอย่างไร)* | 아주 재미있었어요. |

### ⚠️ จุดสับสน
**ตารางหด และ 이다 ในอดีต** — บางคำสระหดรวม บางคำไม่หด และ 이다 ใช้รูปเฉพาะ

| | ปัจจุบัน | อดีต |
|:---|:---|:---|
| 이다 หลังตัวสะกด | 학생이에요 | 학생이**었**어요 |
| 이다 หลังสระ | 의사예요 | 의사**였**어요 |
| 있다 / 없다 | 있어요 / 없어요 | 있었어요 / 없었어요 |
| ยกย่อง (시) | 가세요 | 가**셨**어요 |

- ✗ **살었어요** → ✓ 살**았**어요 · ✗ **받었어요** → ✓ 받**았**어요 — ดู **สระ** (ㅏ) ไม่ใช่ตัวสะกด ㄹ/ㄷ · ✗ 먹았어요 → ✓ 먹었어요 (ㅓ)
- ✗ **학생였어요** · **공원였어요** → ✓ 학생**이**었어요 · 공원**이**었어요 (มีตัวสะกดต้องมี 이 · 의사였어요 ถูกเพราะ 사 ไม่มีตัวสะกด)
- ✗ **어떻었어요** → ✓ **어땠어요** (ทั้ง 어때요 และ 어땠어요 ต้องท่องเป็นคำ)
- ✗ 하었어요 → ✓ 했어요 (ตำรา 152쪽: 하였어요 ก็ถูก แต่เป็นภาษาเขียน — ทั่วไปและข้อสอบใช้ 했어요) · ✗ 갔았어요 (ใส่ 았 ซ้ำ) → ✓ 갔어요
- ✗ 학생이에요 (ปัจจุบัน) ที่โจทย์ถามอดีต → ✓ 학생이었어요 · ปฏิเสธอดีต ✓ 이/가 **아니었**어요 (ไม่ใช่ 아니에요)
- สะกด/ตัวอักษร (เสียครึ่งคะแนนใน 매일시험 17): **책** (✗ 젝) · **청소** · **생활** (✗ 생할) · **열심히** (✗ 열심이) · ออกเสียง 작년 [장년] · 늦게 [늗께] (ตำรา 153쪽) · 먹었어요 [머거써요] · 많았어요 [마나써요]

> [!TIP]
> ดู**สระ**ของราก: ㅏ/ㅗ → **았** · อื่น → **었** · 하다 → **했** · ㅡ ตัดแล้วดูพยางค์ก่อนหน้า · 이다: ตัวสะกด → **이었** / สระ → **였** · ไม่มีตัวสะกด → ควบ (갔 · 왔 · 봤 · 마셨) · มีตัวสะกด → ไม่ควบ (먹었 · 읽었)

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- **매일시험 17 (10/13) = 8/10:** B5–7 ตอบด้วยอดีต (영화를 봤어요 · 책을 읽었어요 · 기숙사를 청소했어요) · เสียครึ่งคะแนน 4 ข้อ **ล้วนเรื่องสะกด ไม่ใช่ไวยากรณ์**: B6 **젝을** (책을 — ㅊ→ㅈ และ ㅐ→ㅔ) · B7 ㅊ ของ **청소** ขีดบนหาย + เขียน "청소 했어요" เว้นวรรค · C9 **생할** · C10 **열심이**
- **ใบฝึก 17과 (10/12):** เขียนปากกาถูกทั้งหมด (A–E) — กฎในตารางแม่น แต่พลาดตอนเขียนอิสระ (เห็นได้จากข้อล่าง)
- **ตระกูล "เลือก 아/어 ผิด":** **살어요 · 살었어요** ⚠️ (ใบฝึก 19과 A ครูไฮไลต์) · **받었어요** (สมุดงาน 20과) · **어떻었어요** แทน 어땠어요 (ทั้งที่ 어땠어요 พิมพ์อยู่ใกล้ ๆ)
- **นามอดีต:** **학생였어요 · 공원였어요** ✗ — รู้ 의사였어요 แต่เผลอไม่ใส่ 이 หลังตัวสะกด
- **복습시험② (14–20과 · เก็ง):** 쓰기 ③ ตารางผัน 4 รูป (았/었/였어요 · (스)ㅂ니다 · (으)세요 · (으)ㄹ 거예요) · 쓰기 ⑤ ดูภาพตอบ "เมื่อวานทำอะไร" · 읽기 17-2 / 18-2 (อดีตแบบ -ㅂ/습니다)
