## 23. -았/었/였- · N이었어요/였어요 (อดีตกาล)

> [!INTRO] ข้อนี้คืออะไร
> -았/었/였- คือส่วนที่เติมหลังรากศัพท์ก่อนคำลงท้ายประโยค เพื่อบอก**อดีต** ("…แล้ว" หรือ "เคย…") ใช้กับกริยา คำคุณศัพท์ และ N+이다 เช่น 먹다 → 먹었어요 และ 학생이다 → 학생이었어요
>
> สอนในบท 17 (ตำราหน้า 152) ส่วน N이었어요/였어요 มาจากสไลด์ครู 17과 กฎการเลือกสระเหมือนการผัน -아/어/여요 ในข้อ 06 ทุกอย่าง เพียงแต่เติม ㅆ เข้าไป
>
> ต่อยอดจาก ข้อ 06 (กฎเลือก 아/어), ข้อ 18 (ㅡ 탈락 และ 어때요) และ ข้อ 02 (이에요/예요) แล้วไปใช้ต่อใน ข้อ 24 (왔어요), ข้อ 21 (갔습니다), ข้อ 20 (-(으)셨-), ข้อ 28 (อดีต ↔ อนาคต) และ ข้อ 30 (-았/었/였네요)

### 📌 รูปแบบและเงื่อนไข

การสร้างอดีตมี 3 เรื่องที่ต้องรู้ คือ เลือกสระ 았/었/했 ให้ถูก จัดการรากที่ลงท้าย ㅡ และ 어떻다 และรูปของ N+이다 ตอนนี้จะดูทีละเรื่อง

#### กฎเลือกสระ = กฎเดียวกับ -아/어/여요 (ข้อ 06) แต่เติม ㅆ

ดู**สระของพยางค์สุดท้ายของราก** (ไม่ใช่ตัวสะกด) เหมือนตอนผันปัจจุบัน ถ้าเป็น ㅏ หรือ ㅗ ใช้ 았 ถ้าเป็นสระอื่นใช้ 었 และ 하다 เป็น 했

| สระท้ายราก | ปัจจุบัน | อดีต |
|:---|:---|:---|
| **ㅏ หรือ ㅗ** | -아요 | **-았어요** |
| **สระอื่น** (ㅓ ㅜ ㅣ ㅐ ฯลฯ) | -어요 | **-었어요** |
| **하다** | 해요 | **했어요** |

| กลุ่ม | 기본형 | อดีต | ความหมาย |
|:---|:---|:---|:---|
| ㅏ หรือ ㅗ | 많다 | **많았어요** | เยอะ |
| ㅏ หรือ ㅗ | 살다 | **살았어요** | อาศัยอยู่ |
| ㅏ หรือ ㅗ | 받다 | **받았어요** | ได้รับ |
| ㅏ หรือ ㅗ | 좋다 | **좋았어요** | ดี |
| สระอื่น | 먹다 | **먹었어요** | กิน |
| สระอื่น | 읽다 | **읽었어요** | อ่าน |
| สระอื่น | 있다 | **있었어요** | มี/อยู่ |
| สระอื่น | 재미있다 | **재미있었어요** | สนุก |
| 하다 | 공부하다 | **공부했어요** | เรียน |

กริยาที่ผันตามกลุ่ม ㅏ หรือ ㅗ แบบเดียวกันคือ 앉다 · 놀다 ส่วนกลุ่ม 하다 ที่ผันเป็น -했어요 เหมือนกันมี 일하다 · 피곤하다 · 친절하다

#### ควบสระหรือไม่ควบ

รากที่ไม่มีตัวสะกดจะ**ควบสระ**กับ 았/었 ส่วนรากที่มีตัวสะกด**ไม่ควบ** ตารางนี้ดูตัวอย่างทั้งสองแบบ รวมทั้งข้อยกเว้น 쉬다

| ราก | อดีต | หมายเหตุ |
|:---|:---|:---|
| 가 + 았 | **갔어요** | ไม่มีตัวสะกด → ควบสระ |
| 오 + 았 | **왔어요** | ไม่มีตัวสะกด → ควบสระ |
| 보 + 았 | **봤어요** | ไม่มีตัวสะกด → ควบสระ |
| 사다 | **샀어요** | ไม่มีตัวสะกด → ควบสระ |
| 만나다 | **만났어요** | ไม่มีตัวสะกด → ควบสระ |
| 마시 + 었 | **마셨어요** | ไม่มีตัวสะกด → ควบสระ |
| 배우 + 었 | **배웠어요** | ไม่มีตัวสะกด → ควบสระ |
| 주다 | **줬어요** | ไม่มีตัวสะกด → ควบสระ |
| 가르치다 | **가르쳤어요** | ไม่มีตัวสะกด → ควบสระ |
| 기다리다 | **기다렸어요** | ไม่มีตัวสะกด → ควบสระ |
| 쉬다 | **쉬었어요** | ยกเว้น ไม่ควบ |
| 먹다 | **먹었어요** | มีตัวสะกด → ไม่ควบ |
| 읽다 | **읽었어요** | มีตัวสะกด → ไม่ควบ |
| 앉다 | **앉았어요** | มีตัวสะกด → ไม่ควบ |

#### ราก ㅡ ตัดทิ้ง (ข้อ 18) และ 어떻다

ตัด ㅡ แล้วดูสระ**พยางค์ก่อนหน้า**เพื่อเลือก 아/어 ถ้าไม่มีพยางค์ก่อนหน้า ใช้ 어

| 기본형 | ปัจจุบัน | อดีต | หมายเหตุ |
|:---|:---|:---|:---|
| 쓰다 *(เขียน/ใช้)* | 써요 | **썼어요** | พยางค์เดียว → 었 |
| 크다 *(ใหญ่)* | 커요 | **컸어요** | พยางค์เดียว → 었 |
| 바쁘다 *(ยุ่ง)* | 바빠요 | **바빴어요** | ก่อนหน้า ㅏ/ㅗ → 았 |
| 아프다 *(เจ็บ)* | 아파요 | **아팠어요** | ก่อนหน้า ㅏ/ㅗ → 았 |
| 나쁘다 | 나빠요 | 나빴어요 | ก่อนหน้า ㅏ/ㅗ → 았 |
| 배고프다 | 배고파요 | 배고팠어요 | ก่อนหน้า ㅏ/ㅗ → 았 |
| 예쁘다 *(สวย)* | 예뻐요 | **예뻤어요** | ก่อนหน้า ㅖ |
| 어떻다 *(เป็นอย่างไร)* | 어때요 | **어땠어요** | ท่องเป็นคู่ — ข้อ 18 |

#### 📽️ N이다 ในอดีต (สไลด์อาจารย์ 교과서 152쪽)

สไลด์ครูสรุปว่า ตัวสะกด ○ → 이었어요 · ✗ → 였어요 · ปฏิเสธ 이/가 아니었어요 ตารางนี้ให้ตัวอย่างทั้งสองกรณี

| คำนาม | อดีต ("เคยเป็น…") | ปฏิเสธอดีต ("ไม่ได้เป็น…") |
|:---|:---|:---|
| **มี**ตัวสะกด | N**이었어요**: 학생이었어요 · 공원이었어요 | N**이 아니었어요**: 학생이 아니었어요 · 공원이 아니었어요 |
| **ไม่มี**ตัวสะกด | N**였어요**: 의사였어요 · 학교였어요 | N**가 아니었어요**: 의사가 아니었어요 · 학교가 아니었어요 |

ที่มาของรูปนี้และ 있다/없다 เป็นดังนี้

- 이에요 → 이**었**어요 และ 예요 → **였**어요 (예요 = 이에요 ที่ย่อ จึงเป็น 였 ที่ย่อจาก 이었)
- 있다 / 없다 → 있었어요 / 없었어요

#### ใช้ร่วมกับรูปอื่น

-았/었/였- ผสมกับรูปที่เรียนมาก่อนได้ ดังตารางนี้

| รูปที่ผสม | ตัวอย่าง | ความหมาย | ข้อ |
|:---|:---|:---|:---|
| 안 + อดีต | 안 갔어요 | ไม่ได้ไป | ข้อ 08 |
| -지 않다 | -지 않았어요 | ไม่ได้… | ข้อ 16 |
| -ㅂ니다 | 갔습니다 | ไปแล้ว (ทางการ) | ข้อ 21 |
| ยกย่อง 시 + 었 → 셨 | 가셨어요 | ท่านไปแล้ว | ข้อ 20 |

#### คำบอกเวลาและคำวิเศษณ์ที่มักใช้กับอดีต

คำบอกเวลาบางคำใส่ 에 บางคำไม่ใส่ และมีคำวิเศษณ์ 일찍 กับ 늦게 ที่วางหน้ากริยา

- **어제** ไม่มี 에 (ข้อ 10)
- ส่วน 작년에 · 지난주에 · 지난 토요일에 และ 주말에 มี 에 ได้ — ตำรา 152쪽: 작년**에** 이 책을 읽었어요
- 일찍 *(แต่เช้า/เร็ว)* และ 늦게 *(สาย/ช้า)* วางหน้ากริยา
  - 압둘라 씨는 학교에 일찍 왔어요. *({n:คุณอับดุลลา}{v:มา}{n:โรงเรียน}{a:แต่เช้า} — 매일시험 17 A3)*

#### สูตรและวิธีทำ: -았/었/였- · N이었어요/였어요 (แบบกระดานครู)

อดีตคือการเติม ㅆ ให้คำลงท้าย ขั้นตอนเลือกสระเหมือนผัน -아/어/여요 ทุกอย่าง แต่ต้องตัดสินใจเพิ่มว่าควบสระหรือไม่ควบ และ N + 이다 แยกเป็นอีกกฎหนึ่ง

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | ดูสระของพยางค์สุดท้ายของราก (ไม่ใช่ตัวสะกด) | สระ ㅏ หรือ ㅗ ใช้ **았** สระอื่นใช้ **었** และ 하다 เป็น **했** | กฎเดียวกับ -아/어/여요 ✗ 살었어요 เพราะไปดู ㄹ แทนสระ ㅏ |
| **กฎ 2** | รากลงท้ายด้วย ㅡ | ตัด ㅡ แล้วดูสระของพยางค์ก่อนหน้า ถ้าไม่มีพยางค์ก่อนหน้าใช้ 었 | ㅡ หายเมื่อต่อ 아/어 เหมือน -아/어요 |
| **กฎ 3** | รากไม่มีตัวสะกด หรือมีตัวสะกด | ไม่มีตัวสะกด **ควบสระ** กับ 았/었 และมีตัวสะกด (รวม ㄹ) **ไม่ควบ** วางต่อกัน | 가 + 았 → 갔 แต่ 먹 + 었 → 먹었 และ 살 + 았 → 살았 ข้อยกเว้นคือ 쉬었 |
| **กฎ 4** | N + 이다 | คำนามมีตัวสะกด ใช้ **이었** และไม่มีตัวสะกด ใช้ **였** ปฏิเสธใช้ N이/가 **아니었**어요 | 였 คือ 이었 ที่ย่อ เหมือน 예요 ย่อจาก 이에요 ✗ 학생였어요 |

ลำดับทำคือ ① ดูสระท้ายราก เลือก 았 / 었 / 했 (ราก ㅡ ตัด ㅡ ก่อนแล้วดูสระหน้า) ② ถ้ารากไม่มีตัวสะกดให้ควบสระ ถ้ามีตัวสะกดให้วางต่อกัน ③ ต่อ 어요 หรือ 습니다 ตารางนี้แสดงทุกขั้นกับคำที่ตำราใช้

| ราก + คำต่อ | ① เลือก 았/었/했 | ② ควบสระ? | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 받 + 았어요 | ㅏ → 았 | ไม่ควบ (มีตัวสะกด) | **받았어요** | ✗ 받었어요 |
| 가 + 았어요 | ㅏ → 았 | ควบ (ไม่มีตัวสะกด) | **갔어요** | 가 + 았 หลอมเป็นพยางค์เดียว |
| 보 + 았어요 | ㅗ → 았 | ควบ | **봤어요** | ㅗ + ㅏ → ㅘ |
| 살 + 았어요 | ㅏ → 았 | ไม่ควบ (ㄹ เป็นตัวสะกด) | **살았어요** | ㄹ อยู่ครบ ✗ 살었어요 |
| 먹 + 었어요 | ㅓ → 었 | ไม่ควบ (มีตัวสะกด) | **먹었어요** | ไม่ใช่ 먹았어요 |
| 마시 + 었어요 | ㅣ → 었 | ควบ | **마셨어요** | ㅣ + ㅓ → ㅕ |
| 배우 + 었어요 | ㅜ → 었 | ควบ | **배웠어요** | ㅜ + ㅓ → ㅝ |
| 주 + 었어요 | ㅜ → 었 | ควบ | **줬어요** | ㅜ + ㅓ → ㅝ |
| 쉬 + 었어요 | ㅟ → 었 | ไม่ควบ (ข้อยกเว้น) | **쉬었어요** | ㅟ ไม่ควบกับ 었 เขียนแยก |
| 공부하 + 였어요 | 하 → 했 | ควบ | **공부했어요** | 하였어요 ถูกแต่เป็นภาษาเขียน ข้อสอบใช้ 했어요 |
| 쓰 + 었어요 | ตัด ㅡ ไม่มีพยางค์หน้า → 었 | ควบ | **썼어요** | ㅡ หาย ตัวอักษรหน้ารวมกับ 었 |
| 바쁘 + 았어요 | ตัด ㅡ ดู 바 (ㅏ) → 았 | ควบ | **바빴어요** | ดูสระพยางค์ก่อน ㅡ |
| 예쁘 + 었어요 | ตัด ㅡ ดู 예 (ㅖ) → 었 | ควบ | **예뻤어요** | ㅖ ไม่ใช่ ㅏ ㅗ จึงเป็น 었 |
| 어떻다 + 었어요 | ท่องเป็นคู่ (ไม่ผันตามกฎ) | ท่องทั้งรูป | **어땠어요** | ✗ 어떻었어요 |

ส่วน N + 이다 ไม่ผ่านกฎสระ ดูแค่ตัวสะกดของคำนาม ตารางนี้แสดงทั้งรูปอดีตและรูปปฏิเสธอดีต

| คำนาม + คำต่อ | ① ตัวสะกดของคำนาม | ② เลือก | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 학생 + 이다 | มี (ㅇ) | 이었어요 | **학생이었어요** | ✗ 학생였어요 |
| 공원 + 이다 | มี (ㄴ) | 이었어요 | **공원이었어요** | ✗ 공원였어요 |
| 의사 + 이다 | ไม่มี | 였어요 | **의사였어요** | 예요 → 였어요 |
| 학교 + 이다 | ไม่มี | 였어요 | **학교였어요** | ไม่ต้องมี 이 |
| 학생 + 아니다 | มี (ㅇ) | 이 아니었어요 | **학생이 아니었어요** | ปฏิเสธอดีต |
| 의사 + 아니다 | ไม่มี | 가 아니었어요 | **의사가 아니었어요** | ไม่ใช่ 아니에요 |

> [!TIP] วิธีจำสั้น ๆ
> ดูสระ ไม่ใช่ตัวสะกด ㅏ ㅗ → 았 สระอื่น → 었 하다 → 했 รากไม่มีตัวสะกดควบสระ รากมีตัวสะกดวางต่อกัน ส่วนคำนาม ตัวสะกดมี → 이었 ไม่มี → 였

#### ผันคำเดียวครบทุกคำต่อ (อดีต)

ตารางนี้ผันกริยาสี่คำกับคำต่อที่เรียนมาแล้ว เพื่อดูว่า -았/었- เปลี่ยนรูปแล้วต่อกับคำลงท้ายอื่นอย่างไร

| กริยา | -아/어요 | -았/었어요 | -았/었습니다 | -(으)셨어요 | 안 + อดีต |
|:---|:---|:---|:---|:---|:---|
| 가다 | 가요 | **갔어요** | 갔습니다 | 가셨어요 | 안 갔어요 |
| 읽다 | 읽어요 | **읽었어요** | 읽었습니다 | 읽으셨어요 | 안 읽었어요 |
| 하다 | 해요 | **했어요** | 했습니다 | 하셨어요 | 안 했어요 |
| 쓰다 | 써요 | **썼어요** | 썼습니다 | 쓰셨어요 | 안 썼어요 |

#### รูปผิด / รูปถูก (อดีต)

ตารางนี้รวมรูปผิดที่ผู้เรียนเคยเขียน ดูคอลัมน์ขวาว่าผิดที่ขั้นไหนของสูตร

| รูปผิด | รูปถูก | ผิดที่ขั้นไหน |
|:---|:---|:---|
| ✗ 살었어요 | **살았어요** | ขั้น ① ดู ㄹ แทนสระ ㅏ จึงเลือก 었 |
| ✗ 받었어요 | **받았어요** | ขั้น ① ดู ㄷ แทนสระ ㅏ จึงเลือก 었 |
| ✗ 학생였어요 | **학생이었어요** | กฎ 4 คำนามมีตัวสะกดต้องมี 이 |
| ✗ 공원였어요 | **공원이었어요** | กฎ 4 คำนามมีตัวสะกดต้องมี 이 |
| ✗ 어떻었어요 | **어땠어요** | 어떻다 ต้องท่องเป็นคู่ 어때요 กับ 어땠어요 |

### 📖 ตัวอย่างและการใช้

ตัวอย่างชุดแรกมาจากตำราหน้า 152–155 ชุดถัดมามาจากบทสนทนาและบทอ่านที่เจออดีต และสุดท้ายเป็นแบบฝึกถามเรื่องวันเกิดจากสไลด์อาจารย์

#### 📽️ ฝึกจากสไลด์อาจารย์ — 활동 ถามเรื่องวันเกิด (교과서 156쪽)

ถาม-ตอบกับเพื่อนด้วยอดีต ข้อที่ครูใส่ "+" ตอบรวมเป็นประโยคเดียวได้ คำตอบตัวอย่างดัดแปลงจากใบฝึก 17과 F

| คำถาม | ตัวอย่างตอบ |
|:---|:---|
| 생일이 며칠이에요? *(วันเกิดวันที่เท่าไร)* | 시월 오일이에요. |
| 지난 생일에 무엇을 했어요? *(วันเกิดครั้งก่อนทำอะไร)* | 파티를 했어요. |
| 어디에서 했어요? **+** 누구하고 같이 했어요? | 집에서 친구들하고 같이 했어요. |
| 무엇을 먹었어요? *(กินอะไร)* | 케이크를 먹었어요. |
| 무엇을 받았어요? **+** 누가 줬어요? | 친구가 선물을 줬어요. |
| 지난 생일이 어땠어요? *(เป็นอย่างไร)* | 아주 재미있었어요. |

### ⚠️ จุดสับสน

ในอดีต บางคำสระหดรวมกัน บางคำไม่หด และ 이다 ใช้รูปเฉพาะของมันเอง ตารางนี้เทียบรูปปัจจุบันกับอดีตของ 이다 และกริยาที่เจอบ่อย

| | ปัจจุบัน | อดีต |
|:---|:---|:---|
| 이다 หลังตัวสะกด | 학생이에요 | 학생이**었**어요 |
| 이다 หลังสระ | 의사예요 | 의사**였**어요 |
| 있다 / 없다 | 있어요 / 없어요 | 있었어요 / 없었어요 |
| ยกย่อง (시) | 가세요 | 가**셨**어요 |

ข้อผิดที่เจอบ่อยสรุปเป็นคู่ ✓ / ✗ ได้ตามตารางนี้

| สถานการณ์ | ✓ ถูก | ✗ ผิด | เหตุผล |
|:---|:---|:---|:---|
| เลือก 아 (ㅏ) | 살았어요 · 받았어요 | 살었어요 · 받었어요 | ดู **สระ** (ㅏ) ไม่ใช่ตัวสะกด ㄹ/ㄷ |
| เลือก 어 (ㅓ) | 먹었어요 | 먹았어요 | สระ ㅓ → 었 |
| N หลังตัวสะกด | 학생이었어요 · 공원이었어요 | 학생였어요 · 공원였어요 | มีตัวสะกดต้องมี 이 (의사였어요 ถูกเพราะ 사 ไม่มีตัวสะกด) |
| 어떻다 | 어땠어요 | 어떻었어요 | ทั้ง 어때요 และ 어땠어요 ต้องท่องเป็นคำ |
| 하다 | 했어요 | 하었어요 | 하였어요 ก็ถูกแต่เป็นภาษาเขียน ทั่วไปและข้อสอบใช้ 했어요 (ตำรา 152쪽) |
| ใส่ 았 ซ้ำ | 갔어요 | 갔았어요 | ใส่ 았 ซ้ำ |
| โจทย์ถามอดีต | 학생이었어요 | 학생이에요 | 학생이에요 เป็นปัจจุบัน |
| ปฏิเสธอดีต | 이/가 **아니었**어요 | 아니에요 | ปฏิเสธอดีตไม่ใช่ 아니에요 |
| สะกด 책 | **책** | 젝 | ㅊ→ㅈ และ ㅐ→ㅔ (เสียครึ่งคะแนน 매일시험 17) |
| สะกด 생활 | **생활** | 생할 | เสียครึ่งคะแนน 매일시험 17 |
| สะกด 열심히 | **열심히** | 열심이 | เสียครึ่งคะแนน 매일시험 17 |

#### กับดัก

- **청소** ก็เป็นคำที่เสียครึ่งคะแนนใน 매일시험 17 (ㅊ ขีดบนหาย และเขียนเว้นวรรค "청소 했어요")
- ออกเสียง 작년 [장년] และ 늦게 [늗께] (ตำรา 153쪽)
- ออกเสียง 먹었어요 [머거써요] และ 많았어요 [마나써요]

> [!TIP] กฎสั้น ๆ
> ดู**สระ**ของราก: ㅏ/ㅗ → **았** · สระอื่น → **었** · 하다 → **했**
>
> ㅡ ตัดแล้วดูพยางค์ก่อนหน้า · 이다: ตัวสะกด → **이었** / สระ → **였**
>
> ไม่มีตัวสะกด → ควบ (갔 · 왔 · 봤 · 마셨)
>
> มีตัวสะกด → ไม่ควบ (먹었 · 읽었)

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ผู้เรียนทำตารางกฎได้แม่น แต่เสียคะแนนตอนเขียนอิสระ โดยเฉพาะการสะกดและการเลือก 아/어

- **매일시험 17 (10/13) = 8/10**
  - B5–7 ตอบด้วยอดีต (영화를 봤어요 · 책을 읽었어요 · 기숙사를 청소했어요)
  - เสียครึ่งคะแนน 4 ข้อ **ล้วนเรื่องสะกด ไม่ใช่ไวยากรณ์** ได้แก่ข้อต่อไปนี้
  - B6 **젝을** (책을 — ㅊ→ㅈ และ ㅐ→ㅔ)
  - B7 ㅊ ของ **청소** ขีดบนหาย + เขียน "청소 했어요" เว้นวรรค
  - C9 **생할**
  - C10 **열심이**
- **ใบฝึก 17과 (10/12)** เขียนปากกาถูกทั้งหมด (A–E) — กฎในตารางแม่น แต่พลาดตอนเขียนอิสระ (เห็นได้จากข้อล่าง)
- **ตระกูล "เลือก 아/어 ผิด"**
  - **살어요 · 살었어요** ⚠️ (ใบฝึก 19과 A ครูไฮไลต์)
  - **받었어요** (สมุดงาน 20과)
  - **어떻었어요** แทน 어땠어요 (ทั้งที่ 어땠어요 พิมพ์อยู่ใกล้ ๆ)
- **นามอดีต** **학생였어요 · 공원였어요** ✗ — รู้ 의사였어요 แต่เผลอไม่ใส่ 이 หลังตัวสะกด
- **복습시험② (14–20과 · เก็ง)**
  - 쓰기 ③ ตารางผัน 4 รูป (았/었/였어요 · (스)ㅂ니다 · (으)세요 · (으)ㄹ 거예요)
  - 쓰기 ⑤ ดูภาพตอบ "เมื่อวานทำอะไร"
  - 읽기 17-2 / 18-2 (อดีตแบบ -ㅂ/습니다)

### 🔗 เชื่อมโยง

ข้อนี้ต่อจากการผัน -아/어요 และเป็นฐานของอดีตในรูปทางการ รูปยกย่อง และ -네요 ในข้อถัดไป

← ต่อยอดจาก

- ข้อ 06 กฎ 아/어 + ควบสระ แล้วเติม ㅆ
- ข้อ 18 ㅡ 탈락 → 바빴어요 · 컸어요 · 어때요
- ข้อ 02 N이에요/예요 → N이었어요/였어요
- ข้อ 09 N에서 + กริยา: 회사에서 일했어요

→ ใช้ต่อใน

- ข้อ 24 N에서 **왔어요** (บท 17)
- ข้อ 21 갔습니다 · 이었습니다 ในบทอ่านบท 17–18
- บทอ่าน 21 (จดหมายเล่าเรื่องวันนี้)
  - 눈을 처음 봤어요 *(เห็นหิมะครั้งแรก)*
  - 눈사람도 만들었어요 *(ปั้นตุ๊กตาหิมะด้วย)*
- ข้อ 20 가셨어요
- ข้อ 28 อดีต 한 달 전에 왔어요 ↔ อนาคต 갈 거예요
- ข้อ 30 -았/었/였네요: 왔네요
- ข้อ 32 -고 있었어요

> [!SUMMARY] สรุป
> - ดู**สระ**ของรากเหมือน -아/어요: ㅏ/ㅗ → 았 · สระอื่น → 었 · 하다 → 했
> - ไม่มีตัวสะกด → ควบสระ (갔 · 왔 · 봤) ส่วนมีตัวสะกด → ไม่ควบ (먹었 · 읽었)
> - ㅡ ตัดแล้วดูพยางค์ก่อนหน้า (바빴 · 컸) และ 어떻다 → 어땠어요
> - 이다: มีตัวสะกด → 이었어요 · ไม่มี → 였어요 · ปฏิเสธ → 이/가 아니었어요
> - ข้อผิดเรื่องรูป: 살었어요 · 받었어요 · 학생였어요 · 어떻었어요
> - ข้อผิดเรื่องสะกด: 책 (젝) · 생활 (생할) · 열심히 (열심이)
