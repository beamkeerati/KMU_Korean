## 61. -(으)ㄴ/는데요 (…น่ะ · …นะ — บอกสถานการณ์ รอให้อีกฝ่ายตอบ · ปฏิเสธอ้อม ๆ)
ลงท้ายประโยคด้วย **-(으)ㄴ/는데요** เพื่อ "วางสถานการณ์/เหตุผลไว้ แล้วให้ผู้ฟังตัดสินใจต่อเอง" — ตำรา 352쪽: ผู้พูดบอกสถานการณ์หรือความตั้งใจอ้อม ๆ เพื่อรอการตอบสนองของผู้ฟัง และใช้ **ปฏิเสธอ้อม ๆ** ได้ (ไม่พูดคำว่า "ไม่" ตรง ๆ)
สอนในบท 36 (교과서 352–353쪽 · 준비 1) · ต่อยอดจาก ข้อ 06 · ข้อ 18 (คำคุณศัพท์) · ข้อ 23 (-았/었/였-) · ข้อ 33 (-(으)ㄹ까요? = คำชวนที่ถูกปฏิเสธ) · ข้อ 44 · 36 (รูป -는 / -(으)ㄴ เดียวกับคำขยายนาม)
ใช้ต่อใน ข้อ 62 (-(으)ㄹ게요 บทเดียวกัน) · ข้อ 55 (…면 …는데요) · ข้อ 63 (저는 마키인데요. …바꿔 주세요) · ข้อ 64 · และ 말하기 (ตอบปฏิเสธคำชวน)

### 📌 รูปแบบและเงื่อนไข
เลือกรูปตาม**ชนิดของรากศัพท์**และพยางค์สุดท้าย (เหมือนชุดขยายนามข้อ 36 · 44)

| ชนิดของรากศัพท์ | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| **กริยา** | **-는데요** | 가다 → **가는데요** · 먹다 → **먹는데요** · 끝나다 → **끝나는데요** · 좋아하지 않다 → **좋아하지 않는데요** |
| **있다 / 없다** (รวม 맛있다 · 재미있다) | **-는데요** | 있다 → **있는데요** · 없다 → **없는데요** · 재미있다 → **재미있는데요** |
| **คำคุณศัพท์** มีตัวสะกด | **-은데요** | 좋다 → **좋은데요** · 많다 → **많은데요** · 괜찮다 → **괜찮은데요** · 작다 → **작은데요** |
| **คำคุณศัพท์** สระ | **-ㄴ데요** | 바쁘다 → **바쁜데요** · 고프다 → **고픈데요** · 크다 → **큰데요** · 비싸다 → **비싼데요** |
| ลงท้าย **ㄹ** | **ㄹ หลุด** | คำคุณศัพท์: 길다 → **긴데요** · 멀다 → **먼데요** · กริยา: 살다 → **사는데요** · 만들다 → **만드는데요** · 놀다 → **노는데요** |
| ㅂ ไม่ปกติ (คำคุณศัพท์) | ㅂ → 우 + ㄴ데요 | 춥다 → **추운데요** · 맵다 → **매운데요** · 무섭다 → **무서운데요** |
| **N이다** | N**인데요** | 학생**인데요** · 마키**인데요** · 제 자리**인데요** · 운전 중**인데요** |
| **N이/가 아니다** | N이/가 **아닌데요** | 학생이 **아닌데요** · 제 자리가 **아닌데요** |
| **อดีต** | **-았/었/였는데요** (ใส่กาลก่อน) | 먹다 → **먹었는데요** · 가다 → **갔는데요** · 바쁘다 → **바빴는데요** · N이다 → **이었는데요** |
| อนาคต (เสริม) | -(으)ㄹ **건데요** (거 + ㄴ데요) | 내일 갈 **건데요** *(พรุ่งนี้จะไปน่ะ)* |

- **ตำรา 352쪽:** "กริยา → -는데요 · คำคุณศัพท์ที่ลงท้ายตัวสะกด → -은데요 · ลงท้ายสระหรือ ㄹ → -ㄴ데요 · นาม → 인데요 / 이/가 아닌데요 · 있다/없다 → 있는데요 / 없는데요 · ใช้ร่วมกับ tense marker ได้"
- **ลงท้าย 요 = สุภาพ (해요체):** ตัด 요 ออกได้ในภาษาพูดกับเพื่อน (바쁜데) แต่ในบทเรียนคงไว้ · **ไม่พูดต่อ** — ท้ายประโยคค้างไว้ให้ผู้ฟังเดาผล "…น่ะ (เลยไปไม่ได้)"
- **ไม่ต้องมี 아/어 และไม่เป็นรูป 해요체:** ราก + (으)ㄴ/는 + 데요 — ไม่ใช่ -아/어요
- **ออกเสียง:** 있는데요 [인는데요] · 재미있겠네요 [재미읻껜네요] *(ตำรา 352쪽 และ 356쪽 พิมพ์ไว้)* · 없는데요 [엄는데요] · 먹는데요 [멍는데요] · 좋은데요 [조은데요] *(กฎมาตรฐาน — เสริม)*

### 📖 ตัวอย่างและการใช้
#### จากกล่องไวยากรณ์และ 준비 (352쪽)
1. 가: 얘기 좀 할까요? — 나: 지금은 좀 **바쁜데요**. *(คุยกันหน่อยได้ไหม — ตอนนี้ค่อนข้างยุ่งน่ะ — ปฏิเสธอ้อม)*
2. 가: 여기에 앉아도 돼요? — 나: 미안합니다. 제 **자리인데요**. *(นั่งตรงนี้ได้ไหม — ขอโทษค่ะ ที่นั่งของฉันน่ะ — N인데요)*
3. 가: 그럼 내일 만날까요? — 나: 죄송합니다. 내일도 시간이 **없는데요**. *(งั้นพรุ่งนี้เจอกันไหม — ขอโทษค่ะ พรุ่งนี้ก็ไม่มีเวลาน่ะ)*
4. 가: 점심 먹으러 갈까요? — 나: 벌써 **먹었는데요**. *(ไปกินข้าวเที่ยงกันไหม — กินไปแล้วน่ะ — -았/었는데요)*
5. 윤아 씨, 내일 만날까요? — 미안해요. 내일은 다른 약속이 **있는데요**. *(คุณยุนอา พรุ่งนี้เจอกันไหม — ขอโทษค่ะ พรุ่งนี้มีนัดอื่นน่ะ)*

#### 연습 1–3 (352–353쪽)
| ผู้ชวน (가) | คำปฏิเสธ (나) | แปล |
|:---|:---|:---|
| 내일 콘서트에 갈까요? | 미안해요. 내일 시험이 **있는데요**. | พรุ่งนี้ไปคอนเสิร์ตไหม — ขอโทษ พรุ่งนี้มีสอบน่ะ |
| 저 영화를 볼까요? | 미안해요. 저는 무서운 영화를 **좋아하지 않는데요**. | ดูหนังเรื่องนั้นไหม — ขอโทษ ฉันไม่ชอบหนังน่ากลัวน่ะ *(เติมตามกฎ)* |
| 같이 식사할까요? | 저는 1시간 전에 **먹었는데요**. | กินข้าวด้วยกันไหม — ฉันกินไปเมื่อชั่วโมงก่อนน่ะ *(เติมตามกฎ)* |
| 지금 좀 얘기할 수 있어요? | 미안해요. 지금은 좀 **바쁜데요**. | ตอนนี้คุยได้ไหม — ขอโทษ ตอนนี้ยุ่งนิดหน่อยน่ะ |
| 같이 운동을 할까요? | 미안해요. 오늘은 숙제가 **많은데요**. | ออกกำลังกายด้วยกันไหม — ขอโทษ วันนี้การบ้านเยอะน่ะ |
| 지금 통화할 수 있어요? | 지금 운전 **중인데요**. | ตอนนี้คุยโทรศัพท์ได้ไหม — กำลังขับรถอยู่น่ะ — N중이다 → 중인데요 |

- **연습 2:** 지금 같이 청소를 할까요? (지금 바쁘다) → 미안해요. 지금 **바쁜데요**. · 불고기를 먹으러 갈까요? (고기를 안 먹다) → 저는 고기를 안 **먹는데요**. · 버스를 타고 갈까요? · 빨간색 옷을 살까요? · 백화점에 구두를 사러 갈까요? *(ตำราเว้นคำตอบ — ตอบด้วย -(으)ㄴ/는데요 + เหตุผลเอง)*
- **연습 3 (353쪽) บทสนทนาปฏิเสธเป็นขั้น ๆ:** 가: 같이 식사할까요? — 나: 배가 안 **고픈데요**. — 가: 그럼 한 시간 후에 만나서 식당에 갈까요? — 나: 그때에는 친구와 약속이 **있는데요**. — 가: 그럼 내일은 어때요? — 나: 내일은 수업이 늦게 **끝나는데요**. — 가: 그럼 주말에는 어때요? — 나: 미안해요. 주말에는 숙제가 **많은데요**. — 가: 알겠어요. 그럼 다음에 같이 식사해요. *(…ฉันไม่หิวน่ะ → ตอนนั้นมีนัดกับเพื่อนน่ะ → พรุ่งนี้เลิกเรียนช้าน่ะ → เสาร์อาทิตย์การบ้านเยอะน่ะ → ได้ งั้นไว้กินข้าวด้วยกันคราวหน้า)* — ปฏิเสธสามครั้งโดยไม่พูดว่า "ไม่" เลย
- **36-1 (356쪽):** 제프리: 마키 씨, 내일 시간 있어요? — 마키: 내일은 다른 약속이 **있는데요**. 왜요? — 제프리: 시간이 있으면 마키 씨하고 같이 영화를 보러 가고 싶어요. — 마키: 그래요? 목요일이나 금요일 저녁에는 시간이 괜찮아요. … — 코미디 영화예요. — 재미있겠네요. *(พรุ่งนี้ว่างไหม — พรุ่งนี้มีนัดอื่นน่ะ ทำไมคะ — ถ้าว่างอยากไปดูหนังกับคุณ — คืนพฤหัสหรือศุกร์ว่างค่ะ … — หนังตลก — คงสนุกนะ — -겠-/-네요 ข้อ 42 · 30)*
- **37-1 (364쪽) โทรศัพท์:** 마키: 여보세요. 저는 **마키인데요**. 알렉세이 씨 좀 바꿔 주세요. *(ฮัลโหล ฉันมากิน่ะค่ะ ขอสายคุณอเล็กเซย์หน่อย — ใช้ -(으)ㄴ데요 "แนะนำตัวแล้วรอให้อีกฝ่ายตอบ" — ข้อ 63)*

#### สามหน้าที่ของ -(으)ㄴ/는데요
| หน้าที่ | สูตร | ตัวอย่าง |
|:---|:---|:---|
| ① **ปฏิเสธอ้อม ๆ** | เหตุผลหรือสถานะ + -(으)ㄴ/는데요 | 내일 시험이 있는데요 *(พรุ่งนี้มีสอบน่ะ — เลยไปไม่ได้)* |
| ② **วางสถานการณ์ให้ผู้ฟังตอบต่อ** | บอกข้อเท็จจริง + -(으)ㄴ/는데요 | 저는 마키인데요 *(ฉันมากิ — แล้วคุณจะ…)* · 지금 운전 중인데요 |
| ③ **ให้เหตุผลก่อนขอสิ่งใด** (เสริม ตำราไม่สอน) | -(으)ㄴ/는데요 + ขอ/ถาม | 지금 바쁜데요, 이따가 해도 돼요? *(เสริม)* |

### ⚠️ จุดสับสน
#### -(으)ㄴ/는데요 vs -아/어서 vs -지만 vs -네요
| | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| **-(으)ㄴ/는데요** | บอกสถานการณ์ **อ้อม ๆ** ให้อีกฝ่ายตัดสินใจ | 내일 시험이 있는데요 *(พรุ่งนี้มีสอบน่ะ…)* |
| -아/어서 (ข้อ 48) | **เพราะ…จึง…** บอกเหตุผลตรง ๆ | 내일 시험이 있어서 못 가요 *(เพราะพรุ่งนี้มีสอบ จึงไปไม่ได้)* |
| -지만 (ข้อ 40) | **แต่…** | 바쁘지만 괜찮아요 *(ยุ่งแต่ไม่เป็นไร)* |
| -네요 (ข้อ 30) | **อุทาน** เพิ่งรู้/เพิ่งเห็น | 바쁘네요 *(โอ้ ยุ่งนะเนี่ย)* |

- **ปฏิเสธคำชวน -(으)ㄹ까요?:** ไม่ตอบ 아니요 ตรง ๆ → "미안해요 + เหตุผล + -(으)ㄴ/는데요 + ไว้คราวหน้า" (ตำรา 353쪽) — ตรงกับกฎของ ข้อ 33 ("ไม่ตอบ 아니요 แต่ขอโทษ + บอกเหตุผล")
- **คำคุณศัพท์ ≠ กริยา:** ✓ 바쁜데요 · 좋은데요 · 많은데요 / ✗ 바쁘는데요 · 좋는데요 · 많는데요 — คำคุณศัพท์ไม่ใช้ -는데요
- **있다 / 없다 เป็น -는 เสมอ:** ✓ 있는데요 · 없는데요 · 재미있는데요 / ✗ 있은데요 · 없은데요
- **กริยา ใช้ -는데요 แม้มีตัวสะกด:** ✓ 먹는데요 / ✗ 먹은데요 (นั่นคือรูปอดีตขยายนาม ข้อ 47) · อดีตจริงต้อง **먹었는데요**
- **N → 인데요 ไม่ผันตามตัวสะกด:** ✓ 학생인데요 · 마키인데요 / ✗ 학생는데요 · 마키은데요 · ✗ 학생이에요데요
- **ㄹ-ราก:** ✓ 사는데요 · 만드는데요 / ✗ 살는데요 · 만들는데요 · ✓ 긴데요 / ✗ 길은데요 (ㄹ หลุดเหมือน -는 ข้อ 44)
- **ㅂ ไม่ปกติ (คำคุณศัพท์):** ✓ 추운데요 · 매운데요 / ✗ 춥은데요 · 맵은데요 (ข้อ 37)
- **-겠네요 / -네요:** 재미있겠네요 *(คงจะสนุกนะ — เดา ข้อ 42 + อุทาน ข้อ 30)* ≠ 재미있는데요 *(สนุกนะ/สนุกน่ะ…)*

> [!TIP]
> **กริยา/있다·없다 → -는데요 · คำคุณศัพท์ → -(으)ㄴ데요 · นาม → 인데요 · อดีต → -았/었는데요** · ใช้ปฏิเสธอ้อม ๆ: "เหตุผล + -는데요" แล้วเว้นไว้

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- ยังไม่มีข้อสอบจริงเกี่ยวกับ -(으)ㄴ/는데요 — 36과 อยู่ใน **복습시험④ (11/18)** และ **기말** · ตำรา 358쪽 (듣기 36-2) มีข้อ O/X ที่เกี่ยวกับ **การปฏิเสธคำชวน**: "마키 씨는 토요일에 친구와 약속이 있어요 · 인도 요리를 좋아하지 않아요 · 제프리 씨는 마키 씨하고 일요일에 같이 식사할 거예요" — ผู้เรียนต้องจับว่าใครปฏิเสธเพราะอะไร
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ (CLAUDE.md §6b):** **ตอบไม่ตรงคำถาม** (언제 → 가족을 만날 거예요 ✗) — กับคำชวน ต้องตอบ "รับ/ปฏิเสธ + เหตุผล" ไม่ใช่เล่าเรื่องใหม่ · **tense ของคำตอบไม่ตรงคำถาม** (어디에 가요? → 서점에 갈 거예요) → ตอบคำชวนด้วย -아/어요 หรือ -(으)ㄴ/는데요 ห้ามซ้ำรูป -(으)ㄹ까요? (✗ 네, 갈까요 — ข้อ 33) · **좋아 안 해요** → 좋아하지 않는데요 · **ใช้ 가 กับกริยาที่ต้องการ 을/를** · **tense หลุด** (숙제를 안 했어요 → 하지 않습니다) → "벌써 먹었는데요" ต้องคง -았/었 · ㅡ-ราก 바빱니다 ✗ → 바쁩니다 · ㅐ/ㅔ (네 게 ✗ → 네 개)
- **คาดการณ์รูปแบบข้อสอบ** (เดาจากรูปแบบ 복습시험①②):
  1. **เติม -(으)ㄴ/는데요:** 바쁘다 · 있다 · 많다 · 먹었다 · 학생이다 → ___ (เน้นแยกคำคุณศัพท์ ↔ กริยา ↔ 있다/없다 ↔ N)
