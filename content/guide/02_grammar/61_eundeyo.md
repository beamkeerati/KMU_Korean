## 61. -(으)ㄴ/는데요 (…น่ะ · …นะ — บอกสถานการณ์ รอให้อีกฝ่ายตอบ · ปฏิเสธอ้อม ๆ)

> [!INTRO] ข้อนี้คืออะไร
> -(으)ㄴ/는데요 ใช้ลงท้ายประโยคเพื่อ "วางสถานการณ์หรือเหตุผลไว้ แล้วให้ผู้ฟังตัดสินใจต่อเอง" ตำรา 352쪽 อธิบายว่าผู้พูดบอกสถานการณ์หรือความตั้งใจอ้อม ๆ เพื่อรอการตอบสนองของผู้ฟัง และใช้**ปฏิเสธอ้อม ๆ** ได้ คือไม่ต้องพูดคำว่า "ไม่" ตรง ๆ
>
> สอนในบท 36 (교과서 352–353쪽 · 준비 1) ต่อยอดจาก ข้อ 06 ข้อ 18 (คำคุณศัพท์) ข้อ 23 (-았/었/였-) และ ข้อ 33 (-(으)ㄹ까요? = คำชวนที่ถูกปฏิเสธ) รวมทั้ง ข้อ 44 กับ ข้อ 36 (รูป -는 / -(으)ㄴ เดียวกับคำขยายนาม)
>
> ไปใช้ต่อใน ข้อ 62 (-(으)ㄹ게요 บทเดียวกัน) · ข้อ 55 (…면 …는데요) · ข้อ 63 (저는 마키인데요. …바꿔 주세요) · ข้อ 64 และ 말하기 (ตอบปฏิเสธคำชวน)

### 📌 รูปแบบและเงื่อนไข

เลือกรูปตาม**ชนิดของรากศัพท์**และพยางค์สุดท้าย เหมือนชุดคำขยายนามในข้อ 36 · 44 ตารางแรกสรุปกฎ ตารางที่สองให้ตัวอย่างของแต่ละชนิด

| ชนิดของรากศัพท์ | ต่อ |
|:---|:---|
| **กริยา** | **-는데요** |
| **있다 / 없다** (รวม 맛있다 · 재미있다) | **-는데요** |
| **คำคุณศัพท์** มีตัวสะกด | **-은데요** |
| **คำคุณศัพท์** สระ | **-ㄴ데요** |
| ลงท้าย **ㄹ** | **ㄹ หลุด** |
| ㅂ ไม่ปกติ (คำคุณศัพท์) | ㅂ → 우 + ㄴ데요 |
| **N이다** | N**인데요** |
| **N이/가 아니다** | N이/가 **아닌데요** |
| **ปฏิเสธ** กริยา | -지 **않는데요** |
| **ปฏิเสธ** คำคุณศัพท์ | -지 **않은데요** |
| **ปฏิเสธ** อดีต (กริยา/คำคุณศัพท์) | -지 **않았는데요** |
| **อดีต** | **-았/었/였는데요** (ใส่กาลก่อน) |
| **อดีต** N ตัวสะกด **มี** (받침 O) | N**이었는데요** |
| **อดีต** N ตัวสะกด **ไม่มี** (받침 X) | N**였는데요** |
| อนาคต (เสริม) | -(으)ㄹ **건데요** (거 + ㄴ데요) |

ครูวาดตารางนี้บนกระดาน (ตำรา 352쪽) แยกกริยา คำคุณศัพท์ และนาม ทั้งแบบมีและไม่มี 받침 แล้ววงกลม 않는데요 กับ 않은데요 ในแถวปฏิเสธ พร้อมเขียนคำว่า "not" ไว้ข้างรูปปฏิเสธทั้งสี่ ส่วนนามในอดีตมีสองรูปตามตัวสะกด คือ 이었는데요 กับ 였는데요

#### ข้อความของตำราและข้อควรรู้

ตำรา 352쪽 สรุปกฎไว้ชัดเจน ส่วนข้อควรรู้คือระดับความสุภาพ การไม่ต้องมี 아/어 และเสียงอ่าน

- **ตำรา 352쪽** สรุปรูปไว้ดังนี้
  - กริยา → -는데요
  - คำคุณศัพท์ที่ลงท้ายตัวสะกด → -은데요
  - ลงท้ายสระหรือ ㄹ → -ㄴ데요
  - นาม → 인데요 / 이/가 아닌데요
  - นามอดีต → 받침 O 이었는데요 · 받침 X 였는데요
  - ปฏิเสธ → -지 않는데요 (กริยา) · -지 않은데요 (คำคุณศัพท์) · -지 않았는데요 (อดีต)
  - 있다/없다 → 있는데요 / 없는데요
  - ใช้ร่วมกับ tense marker ได้
- **ลงท้าย 요 = สุภาพ (해요체):** ตัด 요 ออกได้ในภาษาพูดกับเพื่อน (바쁜데) แต่ในบทเรียนคงไว้ · **ไม่พูดต่อ** — ท้ายประโยคค้างไว้ให้ผู้ฟังเดาผล "…น่ะ (เลยไปไม่ได้)"
- **ไม่ต้องมี 아/어 และไม่เป็นรูป 해요체:** ราก + (으)ㄴ/는 + 데요 — ไม่ใช่ -아/어요

คำเหล่านี้ออกเสียงต่างจากที่เขียน ตำราพิมพ์เสียงอ่านไว้ให้สองคำ ส่วนที่เหลือเป็นกฎมาตรฐาน

#### สูตรและวิธีทำ: -(으)ㄴ/는데요 (แบบกระดานครู)

-(으)ㄴ/는데요 ไม่ได้เลือกจากตัวสะกดอย่างเดียว ต้องดูกาลก่อน แล้วดูชนิดของคำ แล้วดูตัวสะกดของคำคุณศัพท์ และสุดท้ายดูรากที่ลงท้าย ㄹ หรือ ㅂ กฎมีสี่ข้อและใช้ตามลำดับ

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | ประโยคเป็นอดีต | ใส่ **았/었/였** ที่รากก่อน แล้วต่อ **-는데요** กับทุกชนิดคำ | หลังรูปอดีตไม่มี 은/ㄴ ให้เลือก |
| **กฎ 2** | ปัจจุบัน ดูชนิดคำ | กริยากับ 있다/없다 ใช้ **는데요** · นามใช้ **인데요** (ปฏิเสธ **아닌데요**) · คำคุณศัพท์ไปกฎ 3 | กริยาไม่ดูตัวสะกด |
| **กฎ 3** | ปัจจุบัน คำคุณศัพท์ | ราก**มี**ตัวสะกด ใช้ **은데요** · ราก**ไม่มี**ตัวสะกด ใช้ **ㄴ데요** | เหมือนคำขยายนาม -(으)ㄴ ข้อ 36 |
| **กฎ 4** | รากลงท้าย **ㄹ** หรือคำคุณศัพท์ **ㅂ** | ㄹ **หลุด**ก่อน ㄴ · ㅂ ของคำคุณศัพท์ **เป็น 우** | ㄹ ไม่อยู่หน้า ㄴ (กฎ 2 ของครู) · ㅂ เหมือนข้อ 37 |

ลำดับทำคือ ① ดูกาล ถ้าเป็นอดีตใส่ 았/었 ② ดูชนิดคำและตัวสะกด เลือก 는데요 · 은데요 · ㄴ데요 · 인데요 ③ ปรับ ㄹ และ ㅂ ④ ต่อกัน ตารางแรกเป็นประโยคปัจจุบันของทุกชนิดคำ

| ราก + คำต่อ | ① กาล | ② ชนิดคำ → คำต่อ | ③ ปรับ ㄹ · ㅂ | ④ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|:---|
| 가 + (으)ㄴ/는데요 | ปัจจุบัน | กริยา → 는데요 | ไม่ปรับ | **가는데요** | กริยาไม่ดูตัวสะกด |
| 있 + (으)ㄴ/는데요 | ปัจจุบัน | 있다 → 는데요 | ไม่ปรับ | **있는데요** | 없다 กับ 맛있다 ก็ใช้ 는데요 |
| 좋 + (으)ㄴ/는데요 | ปัจจุบัน | คำคุณศัพท์ มีตัวสะกด → 은데요 | ไม่ปรับ | **좋은데요** | ✗ 좋는데요 |
| 바쁘 + (으)ㄴ/는데요 | ปัจจุบัน | คำคุณศัพท์ ไม่มีตัวสะกด → ㄴ데요 | ไม่ปรับ (ㅡ อยู่ครบ) | **바쁜데요** | ✗ 바쁘는데요 |
| 멀 + (으)ㄴ/는데요 | ปัจจุบัน | คำคุณศัพท์ ㄹ นับเหมือนไม่มีตัวสะกด → ㄴ데요 | ตัด ㄹ ก่อน ㄴ | **먼데요** | ✗ 멀은데요 |
| 살 + (으)ㄴ/는데요 | ปัจจุบัน | กริยา → 는데요 | ตัด ㄹ ก่อน ㄴ | **사는데요** | ✗ 살는데요 |
| 춥 + (으)ㄴ/는데요 | ปัจจุบัน | คำคุณศัพท์ มีตัวสะกด → 은데요 | ㅂ เป็น 우 (으 รวมเข้า) | **추운데요** | ✗ 춥은데요 |
| 돕 + (으)ㄴ/는데요 | ปัจจุบัน | กริยา → 는데요 | ไม่ปรับ (ㅂ กริยาไม่เปลี่ยนก่อน ㄴ) | **돕는데요** | ✗ 도우는데요 |
| 듣 + (으)ㄴ/는데요 | ปัจจุบัน | กริยา → 는데요 | ไม่ปรับ (ㄷ ไม่เปลี่ยนก่อน ㄴ) | **듣는데요** | ✗ 들는데요 |
| 모르 + (으)ㄴ/는데요 | ปัจจุบัน | กริยา → 는데요 | ไม่ปรับ (르 ไม่เปลี่ยนก่อน ㄴ) | **모르는데요** | ✗ 몰르는데요 |
| 학생 + 이다 | ปัจจุบัน | นาม → 인데요 | ไม่ปรับ | 학생**인데요** | หลังสระก็ยังเป็น 인데요 |
| 학생 + 이/가 아니다 | ปัจจุบัน | นาม → 아닌데요 | ไม่ปรับ | 학생이 **아닌데요** | 아니 + ㄴ데요 |
| 좋아하 + 지 않다 | ปัจจุบัน | หน้า 않다 เป็นกริยา → 않는데요 | ไม่ปรับ | **좋아하지 않는데요** | 않다 ตามชนิดคำที่อยู่ก่อน |
| 고프 + 지 않다 | ปัจจุบัน | หน้า 않다 เป็นคำคุณศัพท์ → 않은데요 | ไม่ปรับ | **고프지 않은데요** | ✗ 고프지 않는데요 |

ตารางที่สองเป็นประโยคอดีต ใส่ 았/었/였 ที่รากก่อนแล้วต่อ 는데요 กับทุกชนิดคำ ดังนั้นไม่มี 은 หรือ ㄴ ในรูปอดีต

| ราก + คำต่อ | ① กาล | ② ชนิดคำ → คำต่อ | ③ ปรับ ㄹ · ㅂ | ④ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|:---|
| 먹 + (으)ㄴ/는데요 | อดีต: 먹 + 었 | ทุกชนิดคำ → 는데요 | ไม่ปรับ | **먹었는데요** | 벌써 먹었는데요 |
| 가 + (으)ㄴ/는데요 | อดีต: 가 + 았 เป็น 갔 | ทุกชนิดคำ → 는데요 | ไม่ปรับ | **갔는데요** | |
| 바쁘 + (으)ㄴ/는데요 | อดีต: 바빠 + ㅆ | ทุกชนิดคำ → 는데요 | ㅡ ตกก่อน 았 | **바빴는데요** | ✗ 바쁜었는데요 |
| 춥 + (으)ㄴ/는데요 | อดีต: 추우 + 었 | ทุกชนิดคำ → 는데요 | ㅂ เป็น 우 | **추웠는데요** | |
| 살 + (으)ㄴ/는데요 | อดีต: 살 + 았 | ทุกชนิดคำ → 는데요 | ไม่ตัด ㄹ (았 ไม่ใช่ ㄴ ㅂ ㅅ ㄹ) | **살았는데요** | ㄹ อยู่ครบ |
| 학생 + 이다 | อดีต: 이 + 었 | ทุกชนิดคำ → 는데요 | ไม่ปรับ | **학생이었는데요** | หลังสระ 의사였는데요 |
| 의사 + 이다 | อดีต: 이 + 었 ย่อเป็น 였 | ทุกชนิดคำ → 는데요 | 받침 X → 였 | **의사였는데요** | 받침 O → 이었 · 받침 X → 였 |
| 끝나 + 지 않다 | อดีต: 않 + 았 | ทุกชนิดคำ → 는데요 | ไม่ปรับ | **끝나지 않았는데요** | กริยาและคำคุณศัพท์ใช้ 않았는데요 เหมือนกัน |

> [!TIP] วิธีจำสั้น ๆ
> ถามตัวเองตามลำดับ อดีตไหม ถ้าใช่ใส่ 았/었 แล้วต่อ 는데요 เลย ถ้าไม่ใช่ดูชนิดคำ กริยากับ 있다/없다 ใช้ 는데요 นามใช้ 인데요 คำคุณศัพท์ดูตัวสะกด และสุดท้ายถ้าเป็นราก ㄹ ให้ ㄹ หายก่อน ㄴ ถ้าเป็นคำคุณศัพท์ ㅂ ให้เปลี่ยนเป็น 우 ส่วนรูปปฏิเสธ -지 않다 ให้ดูชนิดของคำที่อยู่หน้า 않다 แล้วเลือก 않는데요 หรือ 않은데요 ถ้าเป็นอดีตใช้ 않았는데요

#### N하고 있어요 = N 중이에요: บอกเหตุผลว่ากำลังติดธุระ

คำนามที่ต่อ -하다 ได้ เช่น 수업하다 กับ 운전하다 (ที่ครูเขียนไว้ยังมี 식사하다 · 전화하다 · 일하다) บอกว่ากำลังทำสิ่งนั้นอยู่ได้สองแบบ คือ N하고 있어요 กับ N 중이에요 ครูเขียน "ing" กำกับ 하고 있어요 เพราะเป็น -고 있다 (ข้อ 32) ส่วนหัวข้อนี้มาอยู่ในข้อ -(으)ㄴ/는데요 เพราะ "กำลังเรียนอยู่ · กำลังขับรถอยู่" เป็นเหตุผลที่คนใช้บอกว่าตอนนี้ไม่สะดวกคุยหรือไปไม่ได้ และ 중이다 คือ N이다 จึงต่อเป็น 중인데요

| N하고 있어요 | N 중이에요 | ไทย |
|:---|:---|:---|
| 수업하고 있어요. | 수업 중이에요. | กำลังเรียนอยู่ |
| 운전하고 있어요. | 운전 중이에요. | กำลังขับรถอยู่ |
| 식사하고 있어요. | 식사 중이에요. | กำลังรับประทานอาหารอยู่ |
| 전화하고 있어요. = 전화 통화하고 있어요. | 통화 중이에요. | กำลังคุยโทรศัพท์อยู่ |

- **กฎ:** N하고 있어요 = N 중이에요 *(กำลัง…อยู่)* โดย 중 แปลว่า "ระหว่าง/อยู่ในช่วง" วางต่อจากคำนามส่วนหน้าของ N하다
- **คำนามหน้า 중 คือส่วนหน้าของ -하다:** 수업하다 → 수업 중 · 운전하다 → 운전 중 · 식사하다 → 식사 중
- **전화하다 ใช้ 통화 ต่อหน้า 중:** ครูขีดเส้นใต้ **통화** ในคู่เทียบ 통화 중이에요 จึงจำรูป 통화 중 (ไม่เขียน 전화 중이에요) และ 전화하고 있어요 เท่ากับ 전화 통화하고 있어요

เมื่อทำเป็นรูปบอกเหตุผล ให้ใช้ N 중**인데요** เพราะ 중이다 เป็น N이다 แม้ 중 จะมี ㅇ เป็นตัวสะกด นามก็ยังต่อ 인데요 เสมอ ตารางนี้เรียงรูปที่ได้จากสี่คำ

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 지금 수업 **중인데요**. | ตอนนี้กำลังเรียนอยู่น่ะ | ตัวอย่างประกอบ |
| 지금 운전 **중인데요**. | ตอนนี้กำลังขับรถอยู่น่ะ | 연습 1 (352쪽) |
| 지금 식사 **중인데요**. | ตอนนี้กำลังรับประทานอาหารอยู่น่ะ | ตัวอย่างประกอบ |
| 지금 통화 **중인데요**. | ตอนนี้กำลังคุยโทรศัพท์อยู่น่ะ | ตัวอย่างประกอบ |

#### สามหน้าที่ของ -(으)ㄴ/는데요

จากตัวอย่างทั้งหมด -(으)ㄴ/는데요 ทำหน้าที่หลักสามอย่าง สองอย่างแรกตำราสอน ส่วนอย่างที่สามเป็นเรื่องเสริม

| หน้าที่ | สูตร | ตัวอย่าง |
|:---|:---|:---|
| ① **ปฏิเสธอ้อม ๆ** | เหตุผลหรือสถานะ + -(으)ㄴ/는데요 | 내일 시험이 있는데요 *(พรุ่งนี้มีสอบน่ะ — เลยไปไม่ได้)* |
| ② **วางสถานการณ์ให้ผู้ฟังตอบต่อ** | บอกข้อเท็จจริง + -(으)ㄴ/는데요 | 저는 마키인데요 *(ฉันมากิ — แล้วคุณจะ…)* · 지금 운전 중인데요 *(ตอนนี้กำลังขับรถอยู่น่ะ)* |
| ③ **ให้เหตุผลก่อนขอสิ่งใด** (เสริม ตำราไม่สอน) | -(으)ㄴ/는데요 + ขอ/ถาม | 지금 바쁜데요, 이따가 해도 돼요? *(เสริม)* |

### ⚠️ จุดสับสน

-(으)ㄴ/는데요 สับสนกับตัวลงท้ายอื่นที่บอกเหตุผลหรืออุทาน และพลาดบ่อยที่การเลือกรูปตามชนิดของคำ ตารางแรกเทียบความหมาย ตารางที่สองรวมรูปที่ถูกกับรูปที่ผิด

#### -(으)ㄴ/는데요 vs -아/어서 vs -지만 vs -네요

สี่รูปนี้ล้วนใช้ลงท้ายหรือเชื่อมประโยคเรื่องเหตุผลและความรู้สึก แต่นัยต่างกัน

| รูป | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| **-(으)ㄴ/는데요** | บอกสถานการณ์ **อ้อม ๆ** ให้อีกฝ่ายตัดสินใจ | 내일 시험이 있는데요 *(พรุ่งนี้มีสอบน่ะ…)* |
| -아/어서 (ข้อ 48) | **เพราะ…จึง…** บอกเหตุผลตรง ๆ | 내일 시험이 있어서 못 가요 *(เพราะพรุ่งนี้มีสอบ จึงไปไม่ได้)* |
| -지만 (ข้อ 40) | **แต่…** | 바쁘지만 괜찮아요 *(ยุ่งแต่ไม่เป็นไร)* |
| -네요 (ข้อ 30) | **อุทาน** เพิ่งรู้/เพิ่งเห็น | 바쁘네요 *(โอ้ ยุ่งนะเนี่ย)* |

#### กับดัก

ตารางนี้รวมรูปที่ถูกและรูปที่ผิดที่พบบ่อย พร้อมเหตุผลสั้น ๆ ส่วนข้อที่ไม่มีคู่เปรียบเทียบอยู่ในรายการด้านล่าง

| ประเด็น | ✓ ถูก | ✗ ผิด | หมายเหตุ |
|:---|:---|:---|:---|
| คำคุณศัพท์ ≠ กริยา | 바쁜데요 · 좋은데요 · 많은데요 | 바쁘는데요 · 좋는데요 · 많는데요 | คำคุณศัพท์ไม่ใช้ -는데요 |
| 있다 / 없다 | 있는데요 · 없는데요 · 재미있는데요 | 있은데요 · 없은데요 | เป็น -는 เสมอ |
| กริยามีตัวสะกด | 먹는데요 | 먹은데요 | กริยาใช้ -는데요 แม้มีตัวสะกด — 먹은데요 คือรูปอดีตขยายนาม (ข้อ 47) · อดีตจริงต้อง **먹었는데요** |
| N → 인데요 | 학생인데요 · 마키인데요 | 학생는데요 · 마키은데요 · 학생이에요데요 | ไม่ผันตามตัวสะกด |
| ㄹ-ราก | 사는데요 · 만드는데요 · 긴데요 | 살는데요 · 만들는데요 · 길은데요 | ㄹ หลุดเหมือน -는 ข้อ 44 |
| ㅂ ไม่ปกติ (คำคุณศัพท์) | 추운데요 · 매운데요 | 춥은데요 · 맵은데요 | ข้อ 37 |
| ปฏิเสธ: กริยา | 좋아하지 않는데요 | 좋아하지 않은데요 | 좋아하다 เป็นกริยา (쇼핑을 좋아하다) |
| ปฏิเสธ: คำคุณศัพท์ | 고프지 않은데요 | 고프지 않는데요 | 고프다 เป็นคำคุณศัพท์ |
| ปฏิเสธ: อดีต | 끝나지 않았는데요 | 끝나지 않는데요 | 아직 + ยังไม่เสร็จ ใช้ 않았 |

- **ปฏิเสธคำชวน -(으)ㄹ까요?:** ไม่ตอบ 아니요 ตรง ๆ → "미안해요 + เหตุผล + -(으)ㄴ/는데요 + ไว้คราวหน้า" (ตำรา 353쪽) — ตรงกับกฎของ ข้อ 33 ("ไม่ตอบ 아니요 แต่ขอโทษ + บอกเหตุผล")
- **-겠네요 / -네요:** 재미있겠네요 *(คงจะสนุกนะ — เดา ข้อ 42 + อุทาน ข้อ 30)* ≠ 재미있는데요 *(สนุกนะ/สนุกน่ะ…)*
- **않다 ทำตัวตามชนิดของคำที่อยู่ก่อน:** ครูวงกลม 않는데요 กับ 않은데요 และเขียน "not" กำกับ เพราะสองรูปนี้สลับกันบ่อย
  - กริยา → -지 **않는**데요: 좋아하다 ฟังเหมือนความรู้สึกแต่เป็นกริยา (ใช้กับ 을/를) จึงเป็น 좋아하지 않는데요
  - คำคุณศัพท์ → -지 **않은**데요: 고프다 เป็นคำคุณศัพท์ จึงเป็น 고프지 않은데요 (ไม่ใช่ ✗ 고프지 않는데요)
  - อดีต → -지 **않았**는데요 ทั้งกริยาและคำคุณศัพท์ 끝나다 เป็นกริยา แต่ในประโยค 아직 숙제가 끝나지 않았는데요 เป็นอดีต (ถ้าปัจจุบัน 끝나지 않는데요)
- **ข้อผิดเดิมของผู้เรียนที่เป็นกฎเดียวกัน:** ใช้ -는 กับคำคุณศัพท์ (작는 ✗ → 작은 · 다르는 ✗ → 다른) ใน -지 않다 ก็ผิดแบบเดียวกัน (고프지 않는데요 ✗) ให้ถามก่อนว่าคำหน้า 않다 เป็นกริยาหรือคำคุณศัพท์
- **N 중이에요:** กำลังคุยโทรศัพท์ใช้ 통화 중이에요 (ครูขีดเส้นใต้ 통화) และเมื่อต่อเป็นเหตุผลใช้ 중**인데요** เสมอ เพราะ 중이다 เป็น N이다 (ดูหัวข้อ N하고 있어요 = N 중이에요 ในส่วน 📖)

> [!TIP] กฎสั้น ๆ
> - **กริยา/있다·없다 → -는데요 · คำคุณศัพท์ → -(으)ㄴ데요**
> - **นาม → 인데요 · อดีต → -았/었는데요**
> - **ปฏิเสธ: กริยา → -지 않는데요 · คำคุณศัพท์ → -지 않은데요 · อดีต → -지 않았는데요 · นาม → 이/가 아닌데요**
> - ใช้ปฏิเสธอ้อม ๆ: "เหตุผล + -는데요" แล้วเว้นไว้ (ติดธุระ: N하고 있어요 = N 중이에요 → N 중인데요)

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

-(으)ㄴ/는데요 ออกจริงแล้วใน 매일시험 36과 ส่วน A (ตาราง 8 ช่อง) กับคำบอกในส่วน C และมีในใบฝึกกับชุดทบทวนปลายภาค รายการแยกตามแหล่งที่มา พร้อมข้อที่ผู้เรียนเคยพลาด

- **매일시험 36과 (17 พ.ย. · ส่วน A ได้ 3/4):** แต่ละแถวถามคอลัมน์เดียว
  - ช่องอดีต: 갔는데요 ✓ *(ไปแล้ว)*
  - ช่องอดีต: 먹는데요 ✗ → **먹었는데요** *(เขียนรูปปัจจุบันในช่องอดีต)*
  - ช่องอดีต: 학생인데요 ✗ → **학생이었는데요** *(พลาดแบบเดียวกัน)*
  - ช่องปัจจุบัน: 사는데요 · 좋은데요 · 추운데요 · 먼데요 · 맛있는데요 ✓ *(ราก ㄹ · ㅂ · 있다 ถูกหมด)*
  - ส่วน C คำบอก 약속이 있는데요 *(มีนัดน่ะ)* — เขียน 야속 ✗ → **약속**
- **연습지 36 (16 พ.ย.):** ถูกทุกช่อง
  - หน้า 1 กริยา -는데요 / -았/었는데요 20 ช่อง รวม 사는데요 · 돕는데요 · 도왔는데요 · 모르는데요 · 몰랐는데요 ✓
  - หน้า 2 คำคุณศัพท์ 아픈데요 · 먼데요 · 맛없는데요 และนาม 수업 중이었는데요 · 친구였는데요 ✓
- **워크북 36과:** ส่วน C D (ข้อ G ช่อง 1 และ 3) สแกนเป็นหน้าเปล่า ไม่มีบันทึกการตรวจ
- **ชุดทบทวนปลายภาค (เฉลยเป็นของ AI ไม่ใช่ของครู):** ข้อ 6-9 *(미안해요. … -는/(으)ㄴ데요)* และข้อ 2-5 พิมพ์ 저는 마키인데요 ไว้ในบทสนทนาโทรศัพท์
- **복습시험④ (18 พ.ย.):** สอบแล้ว ผลยังไม่ออก ดูชุดเก็งใน KMU_Predict_miniexam04.pdf

> [!SUMMARY] สรุป
> - -(으)ㄴ/는데요 = บอกสถานการณ์อ้อม ๆ แล้วให้ผู้ฟังตัดสินใจต่อ ใช้ปฏิเสธคำชวนโดยไม่พูดว่า "ไม่" (내일 시험이 있는데요)
> - เลือกรูปตามชนิดคำ: **กริยา/있다·없다 → -는데요** · **คำคุณศัพท์ → -(으)ㄴ데요**
> - นาม → **인데요** · อดีต → **-았/었는데요** (นามอดีต 받침 O → 이었는데요 · 받침 X → 였는데요)
> - ปฏิเสธ: กริยา → **-지 않는데요** · คำคุณศัพท์ → **-지 않은데요** · อดีต → **-지 않았는데요** · นาม → **아닌데요** (않다 ตามชนิดคำหน้า)
> - เหตุผลว่ากำลังทำอยู่: N하고 있어요 = N 중이에요 → N 중인데요 (수업 · 운전 · 식사 · 통화 중인데요)
> - ㄹ-ราก ทำ ㄹ หลุด (사는데요 · 긴데요) และ ㅂ ไม่ปกติเปลี่ยนก่อน (추운데요)
> - ที่ต้องระวัง: คำคุณศัพท์ + -는데요 ✗ (바쁘는데요) · กริยามีตัวสะกด + -은데요 ✗ (먹은데요) · ตอบคำชวนด้วยรูป -(으)ㄹ까요? ซ้ำ ✗
