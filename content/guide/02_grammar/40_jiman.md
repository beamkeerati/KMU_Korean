## 40. -지만 (…แต่… · แม้…ก็…) + ㄹ 탈락 (ราก ㄹ หลุด)

> [!INTRO] ข้อนี้คืออะไร
> -지만 เชื่อมสองประโยคที่**ขัดแย้งหรือตรงข้ามกัน** แปลว่า "A **แต่** B" ต่อท้ายรากของกริยาและคำคุณศัพท์ได้เลยโดยไม่ดูตัวสะกด ผู้พูดมักให้น้ำหนักกับประโยคหลัง
>
> บทเดียวกันนี้ตำราสอน **ㄹ 탈락** ด้วย คือรากที่ลงท้าย ㄹ จะทิ้ง ㄹ เมื่อตามด้วย ㄴ ㅂ ㅅ ㄹ เราจึงรวมเรื่องนี้ไว้ท้ายข้อเดียวกัน
>
> สอนในบท 25 (ตำรา 250–251쪽 준비 1 และ 252–253쪽 준비 2) ต่อยอดจากข้อ 16 (-지 ใช้เหมือน -지 않다) ข้อ 34 (-고 "และ") ข้อ 01 (은/는 เทียบ) และข้อ 21 (ㄹ ตกก่อน ㅂ니다 ซึ่งเสริมมาตั้งแต่ข้อ 35) แล้วไปใช้ต่อในข้อ 61 (-(으)ㄴ/는데요 "แต่" แบบนุ่ม) ข้อ 46 (하고 싶지만 할 수 없어요) ข้อ 50 (-(으)니까 ที่ต่อกับ ㄹ ตก) และข้อ 41 (เปรียบเทียบสองสิ่งในบท 26)

### 📌 รูปแบบและเงื่อนไข

ตำรา 250쪽 สอนให้ต่อรากของกริยาหรือคำคุณศัพท์เพื่อบอกความสัมพันธ์แบบ**ตรงข้าม/ขัดกัน**ระหว่างเรื่องหน้ากับเรื่องหลัง ต่อหลัง **-았/었-** และ **-겠-** ได้ และใช้ในสำนวนตายตัว เช่น **실례지만** และ **죄송하지만** ส่วนคำนาม (N이다) ตำราให้ฝึกใน 연습 2 ข้อ 6 (저는 학생이다 → 학생이지만) และสไลด์ครู 문법 1 (10/28) สรุปครบทั้งปัจจุบันและอดีตตามตารางนี้

#### ตารางสรุปตามสไลด์ครู (문법 1 · 교과서 250쪽)

ตารางนี้วางตามสไลด์ของครู แถวกริยา/คำคุณศัพท์ไม่ต้องดูตัวสะกด ส่วนคำนามต้องดู และช่องอดีตของคำนามคือรูปอดีตของ 이다 จากบท 17 (ข้อ 23) + 지만 ซึ่งครูเขียนกำกับไว้ว่า "17과 +"

| ชนิดคำ | ตัวสะกด | ปัจจุบัน | อดีต |
|:---|:---|:---|:---|
| กริยา / คำคุณศัพท์ | มีหรือไม่มี เหมือนกัน | ราก + **-지만** | ราก + **-았/었/였지만** |
| คำนาม (N이다) | มีตัวสะกด | N + **이지만** | N + **이었지만** |
| คำนาม (N이다) | ไม่มีตัวสะกด | N + **지만** (이지만 ก็ได้) | N + **였지만** |

#### ตัวอย่างรูปที่ผันแล้ว

แต่ละแถวคือหนึ่งรูป เรียงตามตารางข้างบน

| ต่อกับ | รูป | ตัวอย่าง |
|:---|:---|:---|
| กริยา | ราก + **-지만** | 오다 → **오지만** *(มาแต่)* |
| คำคุณศัพท์ | ราก + **-지만** | 맵다 → **맵지만** *(เผ็ดแต่)* |
| คำคุณศัพท์ (ราก ㅡ) | ราก + **-지만** | 크다 → **크지만** *(ใหญ่แต่)* |
| อดีต | ราก + -았/었/였- + **지만** | 비싸다 → 비쌌**지만** *(แพงแต่)* |
| อดีต + -고 싶다 | 싶- + -었- + **지만** | 먹고 싶다 → 먹고 싶었**지만** *(อยากกินแต่)* |
| คาดเดา/ความตั้งใจ | ราก + -겠- + **지만** | 불편하다 → 불편하겠**지만** *(คงไม่สะดวกแต่)* |
| ปฏิเสธ | -지 않**지만** | 춥지 않다 → 춥지 않**지만** *(ไม่หนาวแต่)* |
| คำนาม มีตัวสะกด | N + **이지만** | 학생**이지만** *(เป็นนักเรียนแต่)* |
| คำนาม มีตัวสะกด · อดีต | N + **이었지만** | 학생**이었지만** *(เคยเป็นนักเรียนแต่)* |
| คำนาม ไม่มีตัวสะกด | N + **지만** | 의사**지만** *(เป็นหมอแต่)* |
| คำนาม ไม่มีตัวสะกด · อดีต | N + **였지만** | 의사**였지만** *(เคยเป็นหมอแต่)* |
| สำนวนตายตัว | 실례**지만** | 실례지만 여기 화장실이 어디에 있어요? *(ขอโทษนะคะ ห้องน้ำอยู่ที่ไหน)* |
| สำนวนตายตัว | 죄송하**지만** | 죄송하지만 지금은 시간이 없어요. *(ขอโทษนะคะ แต่ตอนนี้ไม่มีเวลา)* |

#### ไม่ผัน ㅂ และ ㄹ ก่อน -지만

-지만 ขึ้นต้นด้วย ㅈ ซึ่งไม่ใช่ ㄴ ㅂ ㅅ ㄹ ราก ㅂ ไม่ปกติและราก ㄹ จึงอยู่ครบ และไม่แปรตามตัวสะกด

| ราก | ผล | ตัวอย่าง |
|:---|:---|:---|
| ㅂ ไม่ปกติ (ข้อ 37) | **ㅂ อยู่** | 맵지만 · 덥지만 · 가깝지만 |
| ราก ㄹ | **ㄹ อยู่** | 달지만 · 살지만 · 길지만 |

#### โครงประโยคและน้ำหนัก

โครงคือ `[A-지만] + [B]` โดย A เป็นข้อเท็จจริงแรก และ B เป็นสิ่งที่ตรงข้ามกับที่คาด

- **น้ำหนักของผู้พูดอยู่ที่ B:** 음식은 맛있지만 좀 불친절해요. *(อาหารอร่อยแต่บริการไม่ค่อยดี — เน้นว่าบริการแย่)*
- **ประธานสองข้างต่างกันได้** และมักใช้ 은/는 เทียบ (ข้อ 01): 한국 음식**은** 맵지만 일본 음식**은** 안 매워요. *(อาหารเกาหลีเผ็ดแต่อาหารญี่ปุ่นไม่เผ็ด)*

#### การออกเสียง (ตำรา 250–251쪽)

ㅈ หลังตัวสะกดออกเสียงเป็น **ㅉ** ในคำเหล่านี้

| คำ | อ่านว่า |
|:---|:---|
| 맛있지만 | [마신찌만] |
| 맵지만 | [맵찌만] |
| 젓가락 | [젇까락] |

### 📌 เสริมจากบทเดียวกัน: ㄹ 탈락 (ตำรา 252–253쪽 준비 2)

ตำรา 252쪽 บอกว่าถ้ารากของกริยาหรือคำคุณศัพท์ลงท้ายด้วย **ㄹ** แล้วตามด้วยคำลงท้ายที่ขึ้นต้นด้วย **ㄴ ㅂ ㅅ ㄹ** ตัว ㄹ จะ**หลุด** ตัวอย่างในกล่องตำรามี 4 ประโยค

- 창문을 **여**세요. *(เปิดหน้าต่างหน่อย)*
- 고향이 멀어요? 네, **멉**니다. *(บ้านเกิดไกลไหม — ไกลค่ะ)*
- 단 음식을 너무 많이 먹지 마세요. *(อย่ากินของหวานมากเกินไป)*
- 오후에 친구하고 같이 **놀** 거예요. *(ตอนบ่ายจะไปเล่นกับเพื่อน)*

#### สูตรรวมคำ 2 กฎ 3 ขั้น ตามกระดานครู (10/28)

ครูเขียนกฎของราก ㄹ บนกระดานเป็นข้อ ๆ ให้เห็นว่าตอนรวมคำมีอะไรหายไปบ้าง กฎมีสองข้อและใช้ตามลำดับเสมอ

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | ราก ㄹ + คำต่อที่มี **(으)** | **ตัด 으 ทิ้ง** เสมอ | ราก ㄹ นับเหมือนไม่มีตัวสะกดเวลาเลือก 으 |
| **กฎ 2** | ราก ㄹ + ตัวแรกของคำต่อเป็น **ㄴ ㅂ ㅅ** หรือ **받침 ㄹ** | **ตัด ㄹ ของราก** ทิ้ง | ㄹ ไม่อยู่หน้าเสียง ㄴ ㅂ ㅅ ㄹ |

ลำดับทำคือ ① ดูว่ามี (으) ไหม ถ้ามีตัดทิ้ง ② ดูตัวแรกที่เหลือของคำต่อ ถ้าเป็น ㄴ ㅂ ㅅ ㄹ ตัด ㄹ ของราก ③ ต่อกัน ตารางนี้แสดงทุกขั้นของตัวอย่างบนกระดาน (만들다) และคำอื่นที่ตำราใช้

| ราก + คำต่อ | ① ตัด 으 | ② ตัด ㄹ ของราก? | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 만들 + (으)러 | 만들 + 러 | ไม่ตัด (ㄹ ไม่ใช่ ㄴ ㅂ ㅅ ㄹ) | **만들러** | กฎ 1 อย่างเดียว |
| 만들 + 네요 | ไม่มี 으 | ตัด (ㄴ) | **만드네요** | กฎ 2 อย่างเดียว |
| 만들 + (으)세요 | 만들 + 세요 | ตัด (ㅅ) | **만드세요** | กฎ 1 แล้วกฎ 2 |
| 만들 + (으)ㄹ 거예요 | 만들 + ㄹ 거예요 | ตัด (받침 ㄹ) แล้ว ㄹ ของคำต่อเข้ามาแทน | **만들 거예요** | หน้าตาเหมือนเดิม แต่ ㄹ ตัวนี้เป็นของคำต่อ |
| 만들 + ㅂ니다 | ไม่มี 으 | ตัด (ㅂ) แล้ว ㅂ เข้ามาเป็นตัวสะกด | **만듭니다** | ✗ 만들습니다 |
| 길 + (으)ㄴ | 길 + ㄴ | ตัด (받침 ㄴ) แล้ว ㄴ เข้ามาแทน | **긴** | 긴 치마 |
| 만들 + (으)ㄹ까요? | 만들 + ㄹ까요? | ตัด แล้ว ㄹ ของคำต่อเข้ามาแทน | **만들까요?** | ✗ 만들을까요 |
| 살 + 아요 | ไม่มี 으 | ไม่ตัด (ㅇ ไม่อยู่ในกฎ) | **살아요** | ㄹ อยู่ครบ |
| 살 + 고 | ไม่มี 으 | ไม่ตัด (ㄱ) | **살고** | ㄹ อยู่ครบ |
| 만들 + 지만 | ไม่มี 으 | ไม่ตัด (ㅈ) | **만들지만** | ข้อนี้เอง |

> [!TIP] วิธีจำสั้น ๆ
> เห็น (으) หลัง ㄹ ให้ลบ 으 ก่อนเสมอ แล้วค่อยถามว่าตัวถัดไปคือ ㄴ ㅂ ㅅ ㄹ ไหม ถ้าใช่ ㄹ ของรากหาย ถ้าไม่ใช่ ㄹ อยู่ รูปที่ดูเหมือนไม่เปลี่ยนอย่าง 만들 거예요 ที่จริง ㄹ ของรากหายไปแล้วและ ㄹ ของคำต่อมาแทน

#### สไลด์ครู 문법 2 (252쪽): ㄹ + 으 ✗ และตัวอย่าง 놀다 แบบ O/X

สไลด์ 문법 2 สรุปกฎ 1 ด้วยคำต่อที่มี (으) ที่เรียนมาแล้ว 4 ตัว แล้วใช้ 놀다 แสดงรูปผิดกับรูปถูกคู่กัน ตารางนี้คัดลอกมาและเพิ่มรูปผิดแบบ 으 ที่ผู้เรียนเคยเขียน

| คำต่อ | รูปผิดบนสไลด์ | ผิดอีกแบบที่เคยเจอ | รูปถูก | เหตุผล |
|:---|:---|:---|:---|:---|
| -(으)러 가다 | — | ✗ 놀으러 | **놀러 가요** (O) | ตัด 으 แล้ว ㄹ อยู่ เพราะ ㄹ ไม่ใช่ ㄴ ㅂ ㅅ ㄹ |
| -(으)ㄹ 거예요 | ✗ 놀ㄹ 거예요 | ✗ 놀을 거예요 | **놀 거예요** | ตัด 으 แล้ว ㄹ ของรากหลุด ㄹ ของคำต่อมาแทน |
| -(으)ㄹ까요? | ✗ 놀ㄹ까요? | ✗ 놀을까요? | **놀까요?** | เหมือนแถวบน |
| -(으)세요 | ✗ 놀세요 | ✗ 놀으세요 | **노세요** | ตัด 으 แล้ว ㄹ หลุดหน้า ㅅ |

ครูเขียนเพิ่มบนสไลด์ว่า 살 + (스)ㅂ니다 → 삽니다 คู่กับ 읽습니다 และ 봅니다 ประเด็นคือราก ㄹ **เลือก ㅂ니다 เหมือนรากไม่มีตัวสะกด** ไม่ใช่ 습니다 แล้ว ㄹ ค่อยหลุดตามกฎ 2

| ราก | ตัวสะกด | เลือก | ผล |
|:---|:---|:---|:---|
| 보다 | ไม่มี | ㅂ니다 | **봅니다** |
| 읽다 | มี (ㄱ) | 습니다 | **읽습니다** |
| 살다 | ㄹ นับเหมือนไม่มี | ㅂ니다 แล้วตัด ㄹ | **삽니다** (✗ 살습니다) |

#### ผันคำเดียวครบทุกคำต่อ (ครึ่งหลังของสไลด์ 문법 2)

ครึ่งหลังของสไลด์วาง 놀다 กับคำต่อทั้ง 6 ไว้บรรทัดเดียว ห้าช่องแรก ㄹ หลุด (ㄴ ㅂ ㅅ และ 받침 ㄹ) ช่องสุดท้าย -(으)러 ㄹ อยู่ ตารางนี้ทำแบบเดียวกันกับกริยา ㄹ ที่ตำราใช้อีก 4 คำ

| 만들다 | **만드**네요 | **만듭**니다 | **만드**세요 | **만들** 거예요 | **만들**까요? | 만들러 가요 |
| 살다 | **사**네요 | **삽**니다 | **사**세요 | **살** 거예요 | **살**까요? | 살러 가요 |
| 팔다 | **파**네요 | **팝**니다 | **파**세요 | **팔** 거예요 | **팔**까요? | 팔러 가요 |
| 열다 | **여**네요 | **엽**니다 | **여**세요 | **열** 거예요 | **열**까요? | 열러 가요 |

### ⚠️ จุดสับสน

มีสองเรื่องให้ระวัง คือแยก -지만 ออกจากตัวเชื่อมอื่นที่แปลว่า "แต่" และเขียนรูป ㄹ 탈락 ให้ถูกว่า ㄹ หลุดเมื่อไรและอยู่เมื่อไร

#### -지만 vs -고 vs 그런데 · 그렇지만 · 하지만

ทั้งสี่แบบแปลเป็นไทยได้ใกล้กัน แต่เกาหลีแยกว่าอยู่ในประโยคเดียวหรือขึ้นประโยคใหม่ และขัดกันหรือไปทางเดียวกัน

| รูป | ใช้เมื่อ | ตัวอย่าง |
|:---|:---|:---|
| **-고** (ข้อ 34) | บอกสิ่งที่ **ไปทางเดียวกัน** (และ) | 음식도 맛있**고** 아주머니도 친절한 식당 *(ร้านที่อาหารอร่อยและคุณป้าก็ใจดี — 25-1)* |
| **-지만** | **ขัดกัน** ในประโยคเดียว | 음식은 맛있**지만** 좀 불친절해요. *(อร่อยแต่บริการไม่ดี)* |
| **그런데** | ขึ้นประโยคใหม่ — "แต่/ว่าแต่" เปลี่ยนเรื่องหรือเริ่มข้อขัดแย้งอย่างเบา | 맛있었어요. **그런데** 아주머니가 좀 불친절하네요. *(25-1)* |
| **그렇지만 · 하지만** | ขึ้นประโยคใหม่ — "แต่" ชัดเจน | 스케이트는 못 타요. **그렇지만** 스키는 탈 수 있어요. *(28과 280쪽)* |

- -지만 อยู่กลางประโยค ส่วน 그런데 / 그렇지만 / 하지만 ขึ้นต้นประโยคถัดไป (มี "." ก่อน)
- อย่าใช้ซ้อนสองตัวในจุดเดียว เช่น ✗ 맛있지만 그렇지만 …

#### กับดักของ -지만

ตาราง ✓/✗ สรุปข้อผิดเรื่องการผันก่อน 지만 ส่วนบุลเล็ตด้านล่างเป็นข้อควรระวังเรื่องความหมายและเสียง

| ✗ ผิด | ✓ ถูก | สาเหตุ |
|:---|:---|:---|
| ✗ 맵으지만 | ✓ **맵지만** | ㅂ อยู่ ไม่มี 으 |
| ✗ 먹으지만 | ✓ **먹지만** | ไม่ต้องดูตัวสะกด |
| ✗ 더우지만 | ✓ **덥지만** | ㅂ อยู่หน้า ㅈ |

- **ซ้ำความหมาย:** ✗ -지만 + 하지만 (แต่ซ้อน) → ใช้ตัวเดียว
- **ลืมตัดตรงข้าม:** -지만 ต้องมีสองข้อที่ตรงข้ามกันจริง ถ้าสองข้างบวกทั้งคู่ให้ใช้ -고
- **-지만 vs -지 않다:** รูป -지 เหมือนกัน แต่ -지 **않**다 = ไม่… (ข้อ 16) ส่วน -지**만** = แต่… และ 춥지 않지만 ใช้ติดกันได้
- **สำนวน 실례지만 / 죄송하지만:** ไม่ได้แปลว่า "แต่" ตรง ๆ แต่เป็นคำเริ่มขอร้อง *(ขอโทษที…)*
- **ㅈ/ㅊ และ ㅉ:** 맛있지만 [마신찌만] ต้องเขียน **ㅈ** ไม่ใช่ ㅉ ✗ 맛있찌만 และ ✗ 맛있치만 (ผู้เรียนเคยสลับ ㅈ/ㅊ)

#### กับดักของ ㄹ 탈락

ตารางนี้รวมข้อผิดของ ㄹ-ราก ที่ผู้เรียนเคยพลาดหรือน่าจะพลาด

| ✗ ผิด | ✓ ถูก | สาเหตุ |
|:---|:---|:---|
| ✗ 살습니다 | ✓ **삽니다** | ㄹ ตกก่อน ㅂ |
| ✗ 만들습니다 | ✓ **만듭니다** | ㄹ ตกก่อน ㅂ *(เคยเจอใน mock ②)* |
| ✗ 알습니다 | ✓ **압니다** | ㄹ ตกก่อน ㅂ |
| ✗ 만들으세요 | ✓ **만드세요** | ㄹ + (으)세요 *(เคยเจอ 만들으세요)* |
| ✗ 열으세요 | ✓ **여세요** | ㄹ + (으)세요 |
| ✗ 놀으세요 | ✓ **노세요** | ㄹ + (으)세요 |
| ✗ 놀세요 | ✓ **노세요** | ㄹ ต้องหลุดหน้า ㅅ *(สไลด์ครู 문법 2)* |
| ✗ 살을 거예요 | ✓ **살 거예요** | ㄹ + ㄹ ไม่ซ้ำ (ข้อ 28) |
| ✗ 만들을까요 | ✓ **만들까요** | ㄹ + ㄹ ไม่ซ้ำ (ข้อ 33) |
| ✗ 다아요 | ✓ **달아요** | ㄹ คงอยู่หน้าสระ |
| ✗ 머어요 | ✓ **멀어요** | ㄹ คงอยู่หน้าสระ |

เสียงของ 들다 · 듣다 · 먹다 ในรูป -(으)세요 พ้องกันหรือใกล้กันมาก ต้องดูคำนามหน้าประโยคจึงจะรู้ว่าเป็นคำไหน

| กริยา | รูป | ความหมาย |
|:---|:---|:---|
| 손을 들다 | **드세요** | ยกมือ |
| 듣다 | 들으세요 | ฟัง (ㄷ 불규칙 ข้อ 51) |
| 먹다 | 드세요 | ท่านทาน (ข้อ 20) |

> - ㄹ 탈락 = ราก ㄹ + (ㄴ ㅂ ㅅ ㄹ) → ตัด ㄹ
> - ท่องรายการ: 달다 멀다 불다 열다 팔다 만들다 길다 살다 들다 알다 놀다

> [!SUMMARY] สรุป
> - **-지만 = "แต่"** ต่อรากตรง ๆ ไม่ดูตัวสะกด ㅂ และ ㄹ อยู่ครบ (맵지만 · 달지만) ต่อหลัง -았/었- และ -겠- ได้
> - ใช้กับสองข้อที่ตรงข้ามกันจริง ถ้าไปทางเดียวกันใช้ -고 และ 그런데 · 그렇지만 · 하지만 ขึ้นประโยคใหม่
> - **ㄹ 탈락:** ราก ㄹ ตัด ㄹ ก่อน ㄴ ㅂ ㅅ (삽니다 · 사세요 · 사는) ไม่ซ้ำ ㄹ ก่อน -(으)ㄹ (살 거예요) และคงอยู่ก่อนสระ (살아요)
> - ข้อผิดที่เคยเจอ: 만들습니다 · 만들으세요 · 바빱니다 · ลืม 으 หลังตัวสะกด
