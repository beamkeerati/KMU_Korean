## 46. -(으)ㄹ 수 있다/없다 (ทำได้ / ทำไม่ได้)

> [!INTRO] ข้อนี้คืออะไร
> -(으)ㄹ 수 있다/없다 บอกว่า**ทำสิ่งนั้นได้หรือไม่ได้** ทั้งแบบ "มีความสามารถ" เช่น ขับรถได้ เล่นสกีได้ และแบบ "สถานการณ์เอื้อหรือไม่เอื้อ" เช่น ไปไม่ได้เพราะมีสอบ วิธีใช้คือต่อท้ายรากของ**กริยา**แล้วตามด้วย 수 있다 หรือ 수 없다
>
> สอนในบท 28 (ตำรา 280쪽 준비 2 และ 281쪽 연습) ต่อยอดจากข้อ 06 (หารากศัพท์) ข้อ 28 (กฎ ㄹ/을 เดียวกัน) ข้อ 33 (-(으)ㄹ까요? ใช้กฎเดียวกัน) และข้อ 08 (안 ปฏิเสธ ซึ่งคนละความหมาย)
>
> ข้อนี้ไปใช้ต่อในบท 29–32 ซึ่งอ่านเจอซ้ำ เช่น 수영을 할 수 없었어요 และ 버스로 갈 수 있고… รวมทั้งข้อ 48 (…아/어서 …할 수 없어요) และข้อ 51 (ㄷ 불규칙: 걸을 수 있어요)

### 📌 รูปแบบและเงื่อนไข

ตัด 다 ทิ้ง แล้วดู**พยางค์สุดท้ายของราก** จากนั้นเติม -(으)ㄹ ตามด้วย **수 있어요** (ได้) หรือ **수 없어요** (ไม่ได้) ตารางนี้แยกตามเสียงท้ายของราก ช่องว่างในสองคอลัมน์แรกหมายความว่ายังเป็นกรณีเดียวกับแถวบน

| รากศัพท์ลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| ไม่มีตัวสะกด (รวม ㅡ · 하다) | **-ㄹ 수 있어요 / 없어요** | 타다 → **탈 수 있어요** *(ขี่ได้)* |
| | | 보다 → **볼 수 있어요** *(ดูได้)* |
| | | 하다 → **할 수 있어요** *(ทำได้)* |
| | | 운전하다 → **운전할 수 있어요** *(ขับรถได้)* |
| มีตัวสะกด | **-을 수 있어요 / 없어요** | 먹다 → **먹을 수 있어요** *(กินได้)* |
| | | 읽다 → **읽을 수 있어요** *(อ่านได้)* |
| | | 찍다 → **찍을 수 있어요** *(ถ่ายได้)* |
| ลงท้าย **ㄹ** | **-ㄹ 수** (ㄹ ของรากเป็น ㄹ ของรูปนี้อยู่แล้ว ไม่ซ้ำ ไม่ใส่ 을) | 만들다 → **만들 수 있어요** *(ทำได้)* |
| | | 살다 → **살 수 있어요** *(อยู่ได้)* |
| | | 놀다 → **놀 수 있어요** *(เล่นได้)* |
| ปฏิเสธ | -(으)ㄹ **수 없어요** | 먹을 수 없어요 *(กินไม่ได้)* |
| | | 갈 수 없어요 *(ไปไม่ได้)* |
| กาลอื่น | เปลี่ยนที่ 있다/없다 | 할 수 **있었어요** *(ทำได้ (แล้ว))* |
| | | 할 수 **없었어요** *(ทำไม่ได้ (ตอนนั้น))* |

#### กฎตามตำรา 280쪽

ตำราบอกว่ารูปนี้ต่อหลังรากของ**กริยา**เพื่อบอกว่าเหตุการณ์นั้น "เป็นไปได้" หรือผู้พูด "มีความสามารถ" ข้อควรจำมีดังนี้

- รากมีตัวสะกด → -을 수 있다 และไม่มีตัวสะกด → -ㄹ 수 있다 และไม่ได้ → -(으)ㄹ 수 없다
- **수 เป็นคำนาม** ("ทาง/วิธี") จึงเขียนแยกเป็น 3 คำ: ทำ-ㄹ 수 있어요 ✗ 갈수있어요 → ✓ **갈 수 있어요**
- ใช้กับ**กริยา**เท่านั้น ไม่ใช้บอก "สวยได้" กับคำคุณศัพท์ในความหมายนี้
- ประธานเป็นใครก็ได้ รูปไม่เปลี่ยน

#### การออกเสียง (ตำรา 280쪽)

ㅅ ของ 수 กลายเป็น ㅆ หลัง ㄹ ทุกรูปในตารางนี้

| รูป | อ่านว่า |
|:---|:---|
| 탈 수 있어요 | [탈 쑤 이써요] |
| 탈 수 없어요 | [탈 쑤 업써요] |
| 먹을 수 있어요 | [머글 쑤 이써요] |

### 📖 ตัวอย่างและการใช้

ตัวอย่างเริ่มจากสูตรตอบรับและปฏิเสธใน 준비 2 แล้วไปตามแบบฝึก 연습 1–3 บทสนทนา 28-1 กิจกรรมสัมภาษณ์งานพาร์ตไทม์ และจบที่ประโยคจากบท 29–32 ที่ใช้รูปนี้อีก

#### สูตรตอบรับและปฏิเสธ

คำถาม "ทำได้ไหม" ตอบได้สองแบบ ตอบปฏิเสธมักต่อด้วย 그렇지만 เพื่อบอกสิ่งที่ทำได้แทน

| | สูตร | ตัวอย่าง |
|:---|:---|:---|
| ตอบรับ | 네, **-ㄹ/을 수 있어요**. | 가: 농구를 할 수 있어요? — 나: 네, 농구를 할 수 있어요. *(เล่นบาสได้ไหม — ได้ เล่นบาสได้)* |
| ตอบปฏิเสธ | 아니요, **-ㄹ/을 수 없어요**. (+ 그렇지만 …은/는 …할 수 있어요) | 가: 이리나 씨, 스케이트를 탈 수 있어요? — 나: 아니요, 스케이트를 탈 수 없어요. 그렇지만 스키는 탈 수 있어요. *(อิรีนา เล่นสเก็ตได้ไหม — ไม่ได้ แต่เล่นสกีได้)* |

#### จากตำรา 28과 และบทถัดไป

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|

| 이리나 씨는 한국 음식을 **만들 수 있어요**. | อิรีนาทำอาหารเกาหลีได้ (ㄹ-ราก) | ตัวอย่างตำรา |
| 저는 매운 음식을 **먹을 수 없어요**. | ฉันกินอาหารเผ็ดไม่ได้ | ตัวอย่างตำรา |
| 운전을 **할 수 있어요**. / 운전을 **할 수 없어요**. | ขับรถได้ / ขับไม่ได้ | 연습 1 |

| 네, **탈 수 있어요**. | ได้ ขี่ได้ | ใบฟัง 28-3 |

| 수영복이 없어서 수영을 **할 수 없었어요**. | ไม่มีชุดว่ายน้ำเลยว่ายน้ำไม่ได้ | 29과 읽기 |
| 맛있는 음식을 **먹을 수 있고** 서울 야경도 **볼 수 있었어요**. | กินอาหารอร่อยได้และดูวิวกลางคืนของโซลได้ด้วย | 30과 읽기 |
| 버스로 **갈 수 있고**, 지하철로도 **갈 수 있어요**. | ไปด้วยรถบัสได้ และไปด้วยรถไฟใต้ดินก็ได้ | 31과 활동 |
| 한국 영화를 **이해할 수 있어요**? — 아니요. 한국말이 빨라서 **이해할 수 없어요**. | เข้าใจหนังเกาหลีไหม — ไม่ เพราะภาษาเกาหลีพูดเร็ว เข้าใจไม่ได้ | 32과 연습 |

#### 연습 2: ถามจากรูป 9 อย่าง

แบบฝึกนี้ให้รูปกับคำนาม ส่วนกริยาผู้เรียนต้องจับคู่เอง ถามด้วย "…을/를 -(으)ㄹ 수 있어요?"

| คำนาม | กริยา | ความหมาย |
|:---|:---|:---|
| 농구 | 하다 | บาสเกตบอล |
| 수영 | 하다 | ว่ายน้ำ |
| 골프 | 치다 | กอล์ฟ |
| 테니스 | 치다 | เทนนิส |
| 탁구 | 치다 | ปิงปอง |
| 기타 | 치다 | กีตาร์ |
| 피아노 | 치다 | เปียโน |
| 자전거 | 타다 | จักรยาน |
| 말 | 타다 | ม้า |

- 농구를 **할 수 있어요**? *(เล่นบาสได้ไหม)*
- 피아노를 **칠 수 있어요**? *(เล่นเปียโนได้ไหม)*
- 말을 **탈 수 있어요**? *(ขี่ม้าได้ไหม)*

#### 연습 3: คุยกับเพื่อน

แบบฝึกนี้ให้ถามตอบกับเพื่อนเป็นคู่ ถามด้วย 무슨 + N แล้วตอบซ้ำกริยาเดิม

| 질문 | 답 | ไทย |
|:---|:---|:---|
| 무슨 외국어를 **할 수 있어요**? | 한국어를 할 수 있어요. | พูดภาษาต่างประเทศอะไรได้ — พูดภาษาเกาหลีได้ |
| 무슨 운동을 **할 수 있어요**? | 축구를 할 수 있어요. | เล่นกีฬาอะไรได้ — เล่นฟุตบอลได้ |

#### 활동: สัมภาษณ์งานพาร์ตไทม์

กิจกรรมนี้ให้สัมภาษณ์งานพาร์ตไทม์ที่ KS편의점 และ BBO 치킨 ซึ่งถามด้วย -(으)ㄹ 수 있어요 ทุกข้อ

| 한국어 | ไทย |
|:---|:---|
| 한국어를 **할 수 있어요**? | พูดเกาหลีได้ไหม |
| 몇 시부터 몇 시까지 **일할 수 있어요**? | ทำงานได้ตั้งแต่กี่โมงถึงกี่โมง |
| 언제부터 **일할 수 있어요**? | เริ่มงานได้ตั้งแต่เมื่อไหร่ |
| 운전을 **할 수 있어요**? | ขับรถได้ไหม |
| 오토바이를 **탈 수 있어요**? | ขี่มอเตอร์ไซค์ได้ไหม |
| 주말에도 **일할 수 있어요**? | ทำงานวันหยุดสุดสัปดาห์ได้ไหม |

### ⚠️ จุดสับสน

มีสองเรื่องหลักที่ต้องแยก คือ 수 없다 กับ 안 และ 못 และการเขียนรูปให้ถูกเรื่องตัวสะกด ㄹ-ราก และการเว้นวรรค

#### -(으)ㄹ 수 없다 vs 안 + V vs 못 + V

สามรูปนี้แปลเป็นไทยว่า "ไม่" ทั้งหมด แต่ความหมายต่างกัน

| รูป | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| 안 + V (ข้อ 08) | **ไม่ทำ** (เลือกเอง ไม่อยาก) | 오늘 안 가요 *(วันนี้ไม่ไป)* |
| -(으)ㄹ 수 없다 | **ทำไม่ได้** (ไม่มีความสามารถ/มีอุปสรรค) | 오늘 갈 수 없어요 *(วันนี้ไปไม่ได้)* |
| 못 + V *(เสริม)* | = -(으)ㄹ 수 없다 พูดสั้น | 못 가요 = 갈 수 없어요 |

- 못 ตำรายังไม่สอน แต่โผล่ในกล่องตัวอย่าง 29과: 시간이 없어서 **못** 가겠어요 *(ไม่มีเวลาเลยคงไปไม่ได้)*
- ตอบรับ/ปฏิเสธต้องคงรูปเต็ม: ✓ 네, 할 수 있어요 และ ✓ 아니요, 할 수 없어요
- ✗ 아니요, 할 수 있어요 และ ✗ 안 할 수 있어요 *(ปฏิเสธซ้อนผิด)*
- เทียบ **-아/어요** กับ **-(으)ㄹ 수 있어요:** 운전해요 *(ขับรถ — ทำอยู่/ทำเป็นกิจวัตร)* ไม่เท่ากับ 운전할 수 있어요 *(ขับรถ**ได้** — ถามความสามารถ)*
- ถาม "ได้ไหม" ใช้รูปนี้ ไม่ใช้ -(으)ㄹ까요? (ข้อ 33 = ชวนทำด้วยกัน)

#### กับดักที่เจอบ่อย

ตาราง ✓/✗ ด้านล่างรวมข้อผิดเรื่องรูป ส่วนบุลเล็ตเป็นข้อควรระวังเรื่องกรรม กริยาจับคู่ และกริยาไม่ปกติ

| ✗ ผิด | ✓ ถูก | สาเหตุ |
|:---|:---|:---|
| ✗ 만들을 수 있어요 | ✓ **만들 수 있어요** | ㄹ-ราก ไม่ใส่ 을 (เหมือน ✗ 만들을까요 ข้อ 33 · ✗ 만들을 거예요 ข้อ 28) |
| ✗ 먹 수 있어요 | ✓ **먹을 수 있어요** | ลืม 을 หลังตัวสะกด |
| ✗ 읽 수 있어요 | ✓ **읽을 수 있어요** | ลืม 을 หลังตัวสะกด |
| ✗ 갈수있어요 | ✓ **갈 수 있어요** | 수 เป็นคำนาม เขียนแยก 3 คำ |
| ✗ 갈 수있어요 | ✓ **갈 수 있어요** | เว้นวรรคให้ครบ |
| ✗ 스케이트가 탈 수 없어요 | ✓ **스케이트를 탈 수 없어요** | กรรมของ 타다/치다/하다 ใช้ 을/를 |

- ✓ 살 수 และ ✓ 놀 수 ก็ไม่ใส่ 을 เช่นเดียวกัน
- ข้อผิดซ้ำของผู้เรียนคือลืม 으/을 หลังตัวสะกด: 읽세요 · 받십니다 · 씻러 — ลืมทุกครั้ง
- ผู้เรียนเคยใช้ 가 กับกรรมผิด: 시계가 받았어요 · 이야기가 들었어요
- ใช้ 은/는 เน้นความต่างได้: 스케이트**를** 탈 수 없어요. 그렇지만 스키**는** 탈 수 있어요 *(เล่นสเก็ตไม่ได้ แต่เล่นสกีได้ — ข้อ 01 · ข้อ 40 -지만)*
- **ชั้นความสุภาพ:** ผู้ใหญ่ที่เป็นประธานใช้ -(으)ㄹ 수 **있으세요**? *(เสริม — ข้อ 20)*

#### กริยาจับคู่กับกีฬาและเครื่องดนตรี

กริยาที่ใช้กับกีฬาและเครื่องดนตรีเลือกตามคำนาม ✗ 피아노를 할 수 있어요 ไม่เป็นธรรมชาติ (ดูข้อ 14 collocations)

| กริยา | ใช้กับ |
|:---|:---|
| 타다 | 자전거 · 말 · 스케이트 · 스키 |
| 치다 | 골프 · 테니스 · 탁구 · 기타 · 피아노 |
| 하다 | 농구 · 수영 · 운전 |

#### กริยาไม่ปกติ

รากไม่ปกติบางกลุ่มเปลี่ยนรูปก่อนต่อ -(으)ㄹ ผู้เรียนต้องผันรากให้ถูกก่อน

| กลุ่ม | ตัวอย่าง | ความหมาย |
|:---|:---|:---|
| ㄷ → ㄹ (ข้อ 51) | 걷다 → **걸을** 수 있어요 | เดินได้ |
| ㄷ → ㄹ (ข้อ 51) | 듣다 → **들을** 수 있어요 | ฟังได้ |
| ㅂ → 우 (ข้อ 37) | 돕다 → **도울** 수 있어요 | ช่วยได้ |
| 르 ไม่เปลี่ยนก่อน 을 (ข้อ 54) | 모르다 → **모를** 수 | ไม่รู้ |

> [!TIP] กฎสั้น ๆ
> - **-(으)ㄹ 수 있다/없다 = ความสามารถ/ความเป็นไปได้** ส่วน 안 = ไม่ทำ
> - ✗ 갈수있어요 → ✓ 갈 수 있어요 (3 คำ)
> - ㄹ-ราก ไม่ใส่ 을

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ยังไม่มีข้อสอบจริงที่ครูตรวจแล้วเกี่ยวกับ -(으)ㄹ 수 있다/없다 แต่ 28과 อยู่ในขอบเขต **복습시험③ (11/6, 22–29과)** และ **기말 (11/20–23)** และตำรามีใบฟังที่ครูอาจยกมาออก

- ใบฟังในตำรา (เฉลยภาคผนวก) 28과 듣기: ข้อสอบ O/X และเขียนตามคำบอก
  - O/X: ข้อ 1 ✗ · ข้อ 2 ○ · ข้อ 3 ✗
  - เขียนตามคำบอก: 저는 계절 중에서 봄을 제일 좋아해요. *(ในบรรดาฤดูฉันชอบฤดูใบไม้ผลิที่สุด)*
  - เขียนตามคำบอก: 투이 씨, 자전거를 탈 수 있어요? *(ตุ้ย เล่นจักรยานได้ไหม)*
  - เขียนตามคำบอก: 이번 주말에 자전거를 타러 갈까요? *(สุดสัปดาห์นี้ไปปั่นจักรยานกันไหม)*
  - ประโยคนี้ครูอาจยกมาออก (복습시험②: 듣기 10 ข้อ ยกจากบทฟังในตำรา)
- คาดการณ์รูปแบบข้อสอบ (จากรูปแบบ 복습시험①②; เป็นการคาดไม่ใช่ข้อสอบจริง) มี 4 แบบ
  - **ผันตาราง** (ระวัง ㄹ-ราก และ 을):
    - 가다 → 갈 수 있어요 *(ไปได้)*
    - 읽다 → 읽을 수 있어요 *(อ่านได้)*
    - 만들다 → 만들 수 있어요 *(ทำได้)*
    - 타다 → 탈 수 있어요 *(ขี่ได้)*
    - 하다 → 할 수 있어요 *(ทำได้)*
  - **ตอบคำถามด้วยไวยากรณ์ที่กำหนด** (เหมือน 복습시험② ข้อ 5): ดูรูป 농구/피아노/운전 แล้วตอบ 네, …을/를 -(으)ㄹ 수 있어요 หรือ 아니요, … 수 없어요
  - **อ่านจับคู่บทสนทนา 가/나 เว้นคำตอบ:** 29과 읽기 ตำราให้เติม 머드 축제에서는 ______(으)ㄹ 수 있어요 *(ที่เทศกาลโคลน…ได้)*
    - เฉลยคือ 머드 마사지를 할 수 있어요 หรือ 머드 게임을 할 수 있어요
    - รูปแบบเดียวกับ 복습시험① อ่าน (บทอ่านในตำราถูกแปลงเป็นบทสนทนา 가/나 เว้นคำตอบของ 나)
  - **สัมภาษณ์ 말하기:**
    - 한국어를 할 수 있어요? *(พูดเกาหลีได้ไหม)*
    - 무슨 운동을 할 수 있어요? *(เล่นกีฬาอะไรได้)*
    - 무슨 외국어를 할 수 있어요? *(พูดภาษาต่างประเทศอะไรได้)*

> [!SUMMARY] สรุป
> - **ราก + -(으)ㄹ 수 있어요/없어요** = ทำได้/ทำไม่ได้ ไม่มีตัวสะกด → -ㄹ มีตัวสะกด → -을 และราก ㄹ → -ㄹ (ไม่ซ้ำ ไม่ใส่ 을) เช่น 탈 수 · 먹을 수 · 만들 수
> - 수 เขียนแยกเป็น 3 คำ (✗ 갈수있어요) ใช้กับกริยาเท่านั้น และกรรมยังใช้ 을/를 (스케이트를 탈 수 없어요)
> - 수 없다 = ทำไม่ได้ (มีอุปสรรค) ส่วน 안 = ไม่ทำ (เลือกเอง) และ 못 เป็นรูปสั้น (เสริม)
> - ตอบรับ 네, 할 수 있어요 และตอบปฏิเสธ 아니요, 할 수 없어요 ห้ามปฏิเสธซ้อน (✗ 안 할 수 있어요)
> - ข้อสอบน่าจะออกในรูปผันตาราง ตอบจากรูป และสัมภาษณ์ 말하기 (한국어를 할 수 있어요?)
