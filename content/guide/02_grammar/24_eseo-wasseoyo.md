## 24. N에서 왔어요 (มาจาก…)
บอก **ต้นทาง** ของคนที่มา (ประเทศ เมือง บ้านเกิด) — **สถานที่ + 에서 + 왔어요** · **สอนในบท 17** (교과서 154쪽 + 대화 17-1)
ต่อยอดจาก ข้อ 09 (에서 = "ที่" ทำกิจกรรม → ที่นี่ = "จาก") และ ข้อ 23 (왔어요 = 오다 อดีต) · ใช้ต่อใน ข้อ 29 (에게서/한테서 "จาก" + คน — สถานที่ยังใช้ 에서)

### 📌 รูปแบบและเงื่อนไข
| โครงสร้าง | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| N**에서 왔어요** | มาจาก N | 몽골**에서 왔어요**. *({v:มา}{p:จาก}{n:มองโกเลีย})* · 베트남 · 캐나다 · 태국 · 호주 · 중국 · 미국 |
| ประเทศ + เมือง + 에서 | ระบุเมืองด้วย | 일본 도쿄**에서** 왔어요 · 중국 베이징**에서** 왔어요 · 베트남 하노이**에서** 왔어요 |
| **어느 나라**에서 왔어요? | มาจากประเทศไหน | 알렉세이 씨는 어느 나라에서 왔어요? — 러시아에서 왔어요. |
| **어디**에서 왔어요? | มาจากที่ไหน | 마키 씨는 어디에서 왔어요? — 일본 도쿄에서 왔어요. |
| 고향이 어디예요? | บ้านเกิดอยู่ที่ไหน (ไม่ใช้กริยา) | 고향이 어디예요? — 몽골이에요. *(ข้อ 02)* |

* ใช้ **왔어요** (อดีต) เสมอ เพราะ "มาถึงแล้ว ตอนนี้อยู่ที่นี่" · ทางการ: **왔습니다** (읽기 17-2: 러시아에서 왔습니다) · ✗ 와요 (= "กำลังมา/จะมา")
* ถามประเทศใช้ **어느 나라** (ไม่ใช่ 무슨 나라 — ดูส่วนที่ 3) · ถามละเอียดขึ้น: ประเทศ → **어디**에서 (เมืองไหน)
* "ฉันเป็นคนไทย" = 태국 사람이에요 (ข้อ 02) แต่ "ฉันมาจากไทย" = 태국**에서 왔어요**

| คำศัพท์ในบท 17 | (ระวังการสะกดตอนเขียนตามคำบอก) |
|:---|:---|
| ประเทศ | 몽골 *(มองโกเลีย)* · 베트남 *(เวียดนาม)* · 캐나다 *(แคนาดา)* · 태국 *(ไทย)* · 호주 *(ออสเตรเลีย)* · 중국 *(จีน)* · 미국 *(สหรัฐฯ)* · 러시아 *(รัสเซีย)* · 일본 *(ญี่ปุ่น)* · 사우디아라비아 *(ซาอุดีอาระเบีย)* |
| เมือง | 도쿄 *(โตเกียว)* · 워싱턴 *(วอชิงตัน)* · 울란바토르 *(อูลานบาตอร์)* · 하노이 *(ฮานอย)* · 베이징 *(ปักกิ่ง)* |

### 📖 ตัวอย่างและการใช้
1. 제 친구는 몽골에서 왔어요. *(เพื่อนของฉันมาจากมองโกเลีย — ชื่อบท 17)* · 베트남에서 왔어요. · 캐나다에서 왔어요. · 태국에서 왔어요. *(มาจากเวียดนาม · แคนาดา · ไทย — ตำรา 154쪽)*
2. 가: 알렉세이 씨는 어느 나라에서 왔어요? / 나: 러시아에서 왔어요. *({n:คุณอเล็กเซย์}{v:มา}{p:จาก}{n:ประเทศ}{q:ไหน} / {n:รัสเซีย})* — ฝึกต่อ: 제프리 / 미국 · 압둘라 / 사우디아라비아 · 마키 / 일본 · 장핑 / 중국 · 투이 / 베트남
3. 가: ○○ 씨는 어디에서 왔어요? / 나: 저는 중국 베이징에서 왔어요. *({n:คุณ}○○{v:มา}{p:จาก}{q:ที่ไหน} / {n:ฉัน}{v:มา}{p:จาก}{n:ปักกิ่ง ประเทศจีน})*
4. 대화 17-1: 마키 씨는 어디에서 왔어요? / 일본 도쿄에서 왔어요. · 고향에서 무엇을 했어요? / 회사에서 일했어요. *({n:คุณมากิ}{v:มา}{p:จาก}{q:ไหน} / {n:โตเกียว ญี่ปุ่น} · {p:ที่}{n:บ้านเกิด}{v:ทำ}{q:อะไร} / {v:ทำงาน}{p:ที่}{n:บริษัท})*
5. ฝึกต่อ 155쪽: 제프리 — 미국 워싱턴 · 간토야 — 몽골 울란바토르 · 투이 — 베트남 하노이 → 제프리 씨는 미국 워싱턴에서 왔어요. *(…{v:มา}{p:จาก}{n:วอชิงตัน สหรัฐฯ})*
6. ชุดคำถามสัมภาษณ์เพื่อน 155쪽: 어느 나라에서 왔어요? · 누구와 같이 왔어요? · 고향에서 뭘 했어요? · 고향에서 어디에 갔어요? *({v:มา}{p:จาก}{n:ประเทศ}{q:ไหน} · {v:มา}{p:กับ}{q:ใคร} · {p:ที่}{n:บ้านเกิด}{v:ทำ}{q:อะไร} · {p:ที่}{n:บ้านเกิด}{v:ไป}{q:ที่ไหน}{e:มา}บ้าง)*
7. 읽기 17-2 (อีเมลทางการ): 저는 이리나입니다. 러시아에서 왔습니다. *({n:ฉัน}{e:ชื่อ}{n:อีรินา} {v:มา}{p:จาก}{n:รัสเซีย})*
8. แนะนำตัวสั้น ๆ (รวมข้อ 02 · 24 · 23 — ใช้ตอบสัมภาษณ์ 말하기): 저는 투이예요. 베트남 하노이에서 왔어요. 고향 병원에서 일했어요. 지금 국민대학교에서 한국어를 공부해요. *({n:ฉัน}{e:ชื่อ}{n:ตุ้ย} {v:มา}{p:จาก}{n:ฮานอย เวียดนาม} {v:ทำงาน}{p:ที่}{n:โรงพยาบาลบ้านเกิด} {a:ตอนนี้}{v:เรียน}{n:ภาษาเกาหลี}{p:ที่}{n:ม.กุกมิน})*

#### 📽️ ฝึกจากสไลด์อาจารย์ (교과서 154쪽)
**명사 에서 왔어요** (명사 = 나라 · 고향 …) — ถามประเทศก่อน แล้วถามต่อเรื่องเมือง
- 가: 장핑 씨는 어느 나라에서 왔어요? / 나: 중국에서 왔어요. *({n:คุณจางผิง}{v:มา}{p:จาก}{n:ประเทศ}{q:ไหน} / {n:จีน})*
- 가: 중국 어디에서 왔어요? / 나: 중국 베이징에서 왔어요. *({v:มา}{p:จาก}{q:ที่ไหน}{p:ของ}{n:จีน} / {n:ปักกิ่ง})*

### ⚠️ จุดสับสน
**에서 왔어요 vs 에 왔어요** — ภาษาไทยใช้ "มา" ทั้ง "มาจาก" และ "มาถึง" จึงเลือก 에/에서 สลับกันง่าย (ทั้งสองประโยคถูกไวยากรณ์ แต่ความหมายคนละเรื่อง)

| | 에서 왔어요 | 에 왔어요 |
|:---|:---|:---|
| ความหมาย | มา**จาก** (ต้นทาง) | มา**ถึง** (ปลายทาง) |
| ตัวอย่าง | 몽골에서 왔어요 *({v:มา}{p:จาก}{n:มองโกเลีย})* | 한국에 왔어요 *({v:มา}{p:ถึง}{n:เกาหลี})* · 남이섬에 왔어요 *({v:มา}{p:ถึง}{n:เกาะนามิ} — 읽기 21)* |
| ถาม | 어디**에서** 왔어요? *(ถามที่มา)* | 어디**에** 왔어요? *(ถามว่ามาถึงที่ไหน — ไม่ใช่ถามที่มา)* |

**에서 มี 2 หน้าที่ — ดูที่กริยา:** 회사**에서 일했어요** *(ทำงานที่บริษัท — ข้อ 09)* · 몽골**에서 왔어요** *({v:มา}{p:จาก}{n:มองโกเลีย})* · 회사**에서 전화가 왔어요** *(มีโทรศัพท์มาจากบริษัท — ข้อ 29)*

- ✓ 태국에서 왔어요. / ✗ 태국 왔어요 (ตก 에서) / ✗ 태국에 왔어요 (= มาถึงไทย)
- ✓ 어느 나라에서 왔어요? / ✗ 무슨 나라 · ✗ 와요 → ✓ 왔어요
- ✓ 고향에서 무엇을 했어요? *(ที่บ้านเกิดทำอะไร — ที่ทำกิจกรรม)* ≠ 고향에서 왔어요 *({v:มา}{p:จาก}{n:บ้านเกิด})*

> [!TIP]
> 에서 = **จาก** (ต้นทาง) · 에 = **ถึง** (ปลายทาง) · ถามที่มา = **어디에서** · ถามประเทศ = **어느 나라에서** · ตอบเป็นอดีต **왔어요** เสมอ

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- **매일시험 17 (10/13) C8:** เขียนตามคำบอก "มาจากที่ไหน" = **어디에서 왔어요?** (ประโยคจาก 대화 17-1) — ได้เต็มคะแนน
- **복습시험② (14–20과 · เก็ง):** 듣기 [8~10] ฟังแล้วตอบ 어디에서 왔어요? · 읽기 17-2 ("러시아에서 왔습니다" ยกมาตอบช่อง 나) · 말하기 สัมภาษณ์เรื่องตัวเอง (ประเทศ ครอบครัว เมื่อวาน)
- **คู่ 에 / 에서 ที่เคยพลาด** (ยังไม่เคยพลาด 에서 왔어요 เอง): 학생식당**하고** 가요 ✗ → 학생식당**에** 가요 (복습시험① −4 · ปลายทางต้อง 에) · 백화점**에** 샀어요 ✗ → 백화점**에서** 샀어요 หรือ 백화점**에** 갔어요 (ข้อ 09)
