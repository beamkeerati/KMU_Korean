## 49. (으)로 — ทิศทาง (왼쪽으로 가세요 "ไปทางซ้าย")

> [!INTRO] ข้อนี้คืออะไร
> (으)로 ต่อท้าย**นาม**เพื่อบอก**ทิศทางของการเคลื่อนที่** เช่น "ไปทาง… ไปสู่… เลี้ยวไป…" ใช้คู่กับกริยาเคลื่อนที่ เช่น 가다 · 오다 · 올라가다 และใช้มากที่สุดตอน**บอกทาง**
>
> สอนในบท 30 (ตำราหน้า 298 준비 1 และหน้า 299 연습) ตำราเรียกรูปนี้ว่า (으)로¹ ต่อยอดจากข้อ 09 (에 = จุดหมาย) ข้อ 05 (왼쪽/오른쪽 · 위치 명사) ข้อ 20 (-(으)세요 ใช้สั่ง/บอกทาง) และข้อ 04 (ชั้น 층 เลขจีน)
>
> ไปใช้ต่อในข้อ 51 ((으)로² = วิธี/พาหนะ — รูปเดียวกัน คนละความหมาย) ข้อ 53 (6호선으로 갈아타세요) และข้อ 50 (-(으)니까 บอกเหตุผลของการบอกทาง)

### 📌 รูปแบบและเงื่อนไข

ให้ดู**พยางค์สุดท้ายของนาม** (ไม่ใช่ของกริยา) ว่ามีตัวสะกดหรือไม่ ถ้านามลงท้ายด้วย ㄹ ให้นับเหมือนสระ

| นามลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| ตัวสะกด (ยกเว้น ㄹ) | **-으로** | 오른쪽**으로** · 왼쪽**으로** · 3층**으로** |
| สระ | **-로** | 프랑스**로** · 사거리**로** · 전망대**로** |
| ลงท้าย **ㄹ** | **-로** (นับเป็นสระ ไม่ใส่ 으) | 교실**로** 들어오세요 · 서울**로** 가요 |

#### ตัวอย่างนามที่ตำราใช้กับ (으)로

ตารางนี้รวมนามที่ตำรา 30과 ใช้ทั้งหมด เรียงตามกฎข้างบน

| นาม + (으)로 | ความหมาย | กฎที่ใช้ |
|:---|:---|:---|
| 오른쪽**으로** | ไปทางขวา | ตัวสะกด |
| 왼쪽**으로** | ไปทางซ้าย | ตัวสะกด |
| 3층**으로** | ไปชั้น 3 | ตัวสะกด |
| 9층**으로** | ไปชั้น 9 | ตัวสะกด |
| 밖**으로** | ไปข้างนอก | ตัวสะกด |
| 안**으로** | ไปข้างใน | ตัวสะกด |
| 동대문시장**으로** | ไปตลาดตงแดมุน | ตัวสะกด |
| 프랑스**로** | ไปฝรั่งเศส | สระ |
| 사거리**로** | ไปทางสี่แยก | สระ |
| 전망대**로** | ขึ้นไปจุดชมวิว | สระ |
| 교실**로** 들어오세요 | เข้าห้องเรียนมา | ㄹ นับเป็นสระ |
| 서울**로** 가요 | ไปโซล | ㄹ นับเป็นสระ |

#### กริยาเคลื่อนที่ที่ใช้คู่กัน

(으)로 ใช้กับกริยาเคลื่อนที่เท่านั้น ตำราหน้า 298 มักใช้กับ 가다 และ 오다 รวมถึงกริยาที่บอกทิศ ซึ่งแบ่งเป็นคู่ "ไป" (ห่างจากผู้พูด) กับ "มา" (เข้าหาผู้พูด)

| ทิศ | "ไป" (ห่างจากผู้พูด) | "มา" (เข้าหาผู้พูด) |
|:---|:---|:---|
| ทั่วไป | 가다 | 오다 |
| ขึ้น | 올라가다 | 올라오다 |
| ลง | 내려가다 | 내려오다 |
| เข้า | 들어가다 | 들어오다 |
| ออก | 나가다 | 나오다 |

#### ชุดคำ "ทิศ/ตำแหน่ง" ที่มักตามด้วย (으)로

นามที่ใช้ในการบอกทางมาจากหมวดทิศและตำแหน่ง ซึ่งเรียนมาแล้วในข้อ 05 และข้อ 04

| คำ | ความหมาย |
|:---|:---|
| 왼쪽 | ซ้าย |
| 오른쪽 | ขวา |
| 밖 | ข้างนอก |
| 안 | ข้างใน |
| ~층 | ชั้น … |
| 지하 1층 | ชั้นใต้ดิน 1 |
| ~번 출구 | ทางออกหมายเลข … |
| 건물 안 | ข้างในตึก |

#### ตำรา 298쪽 และรูปประโยคบอกทาง

ส่วนนี้สรุปกฎจากกล่องไวยากรณ์ของตำรา พร้อมข้อควรระวังเรื่อง 똑바로 และรูปประโยคบอกทางมาตรฐานที่ควรจำ

- **ตำรา 298쪽:** ต่อหลังนามบอกทิศทางของการเคลื่อนที่ มักใช้กับกริยาเคลื่อนที่ในตารางข้างบน ตัวสะกด → -으로 · ลงท้ายสระหรือ **ㄹ** → -로
- **똑바로** *(ตรงไป)* เป็นกริยาวิเศษณ์ จึง**ไม่ต่อ (으)로**
  - ✓ 똑바로 가세요
  - ✗ 똑바로로 가세요
- **รูปประโยคบอกทาง:** [จุดอ้างอิง]**에서** [ทิศ]**(으)로** [กริยาเคลื่อนที่]**-(으)세요**
  - 사거리**에서** 오른쪽**으로** 가세요 *(ที่สี่แยก ไปทางขวา)*
  - 에서 = "ที่จุดนี้" (จุดเริ่ม/จุดอ้างอิง) ส่วน (으)로 = ทิศ

#### สูตรและวิธีทำ: (으)로 ทิศทาง (แบบกระดานครู)

(으)로 ต่อท้ายนามเพื่อบอกทิศที่เคลื่อนไป การเลือก 으로 หรือ 로 ดูแค่พยางค์สุดท้ายของนาม ไม่ใช่ของกริยาที่ตามมา

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | นามมีตัวสะกด (ที่ไม่ใช่ ㄹ) | ต่อ **으로** | ต้องมี 으 คั่นระหว่างตัวสะกดกับ ㄹ (✗ 오른쪽로) |
| **กฎ 2** | นามไม่มีตัวสะกด | ต่อ **로** | ไม่มีตัวสะกดก็ไม่ต้องใช้ 으 เชื่อม |
| **กฎ 3** | นามลงท้าย ㄹ | ต่อ **로** นับเหมือนไม่มีตัวสะกด | ข้อยกเว้นของ (으)로 (✗ 서울으로) |

ลำดับทำคือ ① ดูว่าสิ่งที่ตามหลังเป็นนาม (คำวิเศษณ์อย่าง 똑바로 ไม่ต่อ) ② ดูตัวสุดท้ายของนามว่ามีตัวสะกด ไม่มี หรือเป็น ㄹ ③ เลือก 으로 หรือ 로 แล้วตามด้วยกริยาเคลื่อนที่ ถ้าบอกทางให้ลงท้าย -(으)세요 ตารางนี้แสดงทุกขั้นกับคำที่ตำราใช้

| นาม + (으)로 | ① ดูตัวท้ายของนาม | ② เลือก | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 오른쪽 + (으)로 | ㄱ เป็นตัวสะกด | 으로 | **오른쪽으로** | ✗ 오른쪽로 ลืม 으 เหมือน ✗ 읽세요 |
| 3층 + (으)로 | ㅇ เป็นตัวสะกด | 으로 | **3층으로** | ชั้นอ่านเลขจีน (ข้อ 04) |
| 밖 + (으)로 | ㄲ เป็นตัวสะกด | 으로 | **밖으로** | 밖으로 나가세요 |
| 사거리 + (으)로 | ไม่มีตัวสะกด | 로 | **사거리로** | สระ ㅣ ไม่ต้องมี 으 |
| 전망대 + (으)로 | ไม่มีตัวสะกด | 로 | **전망대로** | 전망대로 올라가세요 |
| 서울 + (으)로 | ㄹ นับเหมือนไม่มีตัวสะกด | 로 | **서울로** | ✗ 서울으로 |
| 교실 + (으)로 | ㄹ นับเหมือนไม่มีตัวสะกด | 로 | **교실로** | 교실로 들어오세요 |
| 똑바로 | ไม่ใช่นาม (คำวิเศษณ์) | ไม่ต่อ | **똑바로 가세요** | ✗ 똑바로로 |

> [!TIP] วิธีจำสั้น ๆ
> ดูตัวท้ายของนาม มีตัวสะกดใช้ 으로 ไม่มีหรือเป็น ㄹ ใช้ 로 แล้วตามด้วยกริยาเคลื่อนที่ บอกทางลงท้าย -(으)세요

#### 연습 3: แผนที่สี่แยก

연습 3 ให้ดูแผนที่สี่แยกแล้วเติมตารางจุดหมายของ 2 คน โดยตอบตามแบบ 사거리에서 오른쪽으로 가세요

- เจฟฟรีย์ต้องไป 빵집 *(ร้านขนมปัง)* และ 약국 *(ร้านขายยา)*
- มากิต้องไป 백화점 *(ห้างสรรพสินค้า)* และ 병원 *(โรงพยาบาล)*
- 🖼️ แผนที่สี่แยก: ซ้ายมือมีร้านขนมปัง
- 🖼️ แผนที่สี่แยก: ขวาบนมีร้านขายยา ที่ทำการไปรษณีย์ และห้าง
- 🖼️ แผนที่สี่แยก: ล่างขวามีโรงพยาบาล
- 🖼️ แผนที่สี่แยก: ลูกศรบนบอกทางไปศาลากลาง (시청쪽)

#### ถาม-ตอบ

คำถาม "อยู่ที่ไหน" ตอบด้วยจุดอ้างอิง + ทิศ + กริยาเคลื่อนที่ที่ลงท้าย -(으)세요

| ที่มา | คำถาม | คำตอบ |
|:---|:---|:---|
| 준비 1 | 약국이 어디에 있어요? | 사거리에서 오른쪽으로 가세요. *(ร้านขายยาอยู่ไหน — ที่สี่แยกไปทางขวา)* |
| 연습 2 | 우체국이 어디에 있어요? | 오른쪽으로 가세요. *(ที่ทำการไปรษณีย์อยู่ไหน — ไปทางขวา)* |

### ⚠️ จุดสับสน

คำถามที่งงที่สุดคือเมื่อไรใช้ 에 เมื่อไรใช้ (으)로 และเมื่อไรใช้ 에서 ในประโยคบอกทาง รวมถึง (으)로 อีกความหมายหนึ่งที่รูปเหมือนกัน ตารางแรกสรุปคู่ ✓ ถูก / ✗ ผิด ที่เจอบ่อย

| กรณี | ✓ ถูก | ✗ ผิด |
|:---|:---|:---|
| หลังตัวสะกด | 오른쪽으로 · 3층으로 | 오른쪽로 · 3층로 |
| หลัง ㄹ | 교실로 · 서울로 | 교실으로 · 서울으로 |
| บอกทาง | 오른쪽으로 가세요 | 오른쪽에 가세요 · 오른쪽으로 갈 거예요 |
| จุดอ้างอิง | 사거리에서 오른쪽으로 가세요 | 사거리로 오른쪽에서 가세요 |
| ที่ตั้ง | 여기에 있어요 | 여기로 있어요 |
| 똑바로 | 똑바로 가세요 | 똑바로로 가세요 |
| ชั้น | 2층으로 | 두 층으로 |
| สะกด 쪽 | 오른쪽 · 왼쪽 | 오른족 · 왼쭉 |

#### 에 vs (으)로 (ทิศ) vs 에서

สามคำนี้ต่างกันที่สิ่งที่บอก คือ จุดหมาย ทิศทาง และจุดที่ทำหรือจุดเริ่ม

| | บอกอะไร | ตัวอย่าง |
|:---|:---|:---|
| **에** (ข้อ 09) | **จุดหมายปลายทาง** / ที่ตั้ง | 학교**에** 가요 *(ไปโรงเรียน)* · 학교**에** 있어요 *(อยู่ที่โรงเรียน)* |
| **(으)로** (ข้อ 49) | **ทิศทาง** ที่มุ่งไป | 학교**로** 가요 *(ไปทางโรงเรียน/มุ่งหน้าสู่โรงเรียน)* |
| **에서** (ข้อ 09) | ที่/จุดเริ่ม | 사거리**에서** 가세요 *(ที่สี่แยก/เริ่มจากสี่แยก)* |

- (으)로 ใช้กับ**กริยาเคลื่อนที่**เท่านั้น — ✗ 학교로 있어요 *(ที่ตั้งใช้ 에)*
- บอกทางคือ **ทิศ + (으)로**
  - ✓ 오른쪽**으로** 가세요
  - ✗ 오른쪽**에** 가세요 *(ผิดความหมาย: ไปที่ "ขวา" ไม่ใช่ทิศ)*
- สลับ 에서 กับ (으)로 ไม่ได้
  - ✓ 사거리**에서** 오른쪽**으로** 가세요
  - ✗ 사거리**로** 오른쪽**에서** 가세요

#### (으)로 ทิศ (ข้อ 49) vs (으)로 วิธี (ข้อ 51)

รูปเหมือนกัน ให้ดูที่**ประเภทของนาม**ที่อยู่ข้างหน้า

| | นามที่มาก่อน | ตัวอย่าง |
|:---|:---|:---|
| (으)로¹ ทิศทาง (ข้อ 49) | ทิศ · ชั้น · ทางออก | 오른쪽으로 *(ไปทางขวา)* · 3층으로 *(ไปชั้น 3)* |
| (으)로² วิธี (ข้อ 51) | พาหนะ · เครื่องมือ | 버스로 *(ด้วยรถเมล์)* · 칼로 *(ด้วยมีด)* |

ตำรา 31과 เขียนไว้ว่า "(으)로² … Related grammar N(으)로¹: Lesson 30"

#### กับดัก

ข้อผิดของข้อนี้ส่วนใหญ่เป็นเรื่องตัวสะกด ประเภทของประโยคท้าย และการเลือกกริยาไป/มา ไล่ดูทีละข้อ

- **ลืม 으 หลังตัวสะกด** *(ข้อผิดซ้ำ: 읽세요 · 받십니다 · 씻러 — ตกตัวเดียวกันคือลืม 으 ตามหลัง 받침)*
  - ✗ 오른쪽로 → ✓ **오른쪽으로**
  - ✗ 왼쪽로 → ✓ **왼쪽으로**
  - ✗ 3층로 → ✓ **3층으로**
  - ✗ 밖로 → ✓ **밖으로**
- **ㄹ-ท้าย ไม่ใส่ 으:** ✓ 교실**로** · 서울**로** / ✗ 교실으로 · 서울으로
- **คำสั่งบอกทางต้องใช้ -(으)세요:** ถามทาง "어떻게 가요?"
  - ✓ 오른쪽으로 **가세요**
  - ✗ 오른쪽으로 갈 거예요 *(ข้อ 28 ใช้ -(으)ㄹ 거예요 กับแผนของผู้พูด ตอนบอกทางผู้ฟังเป็นคนไป)*
  - รูปทางการ: 올라가십시오 · 가십시오
- **ไป vs มา:** กริยาที่ลงท้าย 가다 = "ไป" ในทิศนั้น (ห่างจากผู้พูด) ส่วนกริยาที่ลงท้าย 오다 = "มา" ในทิศนั้น (เข้าหาผู้พูด) ดูตารางใน 📌
  - 3번 출구로 **나가세요** *(ออกไปทางออก 3 — 연습 2)*
  - 교실로 **들어오세요** *(ครูอยู่ในห้อง เรียกเข้ามา — กล่อง 298쪽)*
  - 밖으로 **나오세요** *(ออกมาข้างนอก)*
- **ชั้น:** ชั้น = เลขจีน + 층 (ข้อ 04)
  - ✓ 2층으로 / ✗ 두 층으로
  - ใต้ดิน = 지하 1층 *(🖼️ ป้าย B1)*
- **เขียนสะกด:** 쪽 (ㅉ + ㅗ + ㄱ) — ✗ 오른족 · ✗ 왼쭉 → ✓ 오른쪽 · 왼쪽 *(ㅉ ตัวคู่ — ระวังเส้นบนของ ㅈ/ㅊ ซึ่งผู้เรียนเคยพลาด)*
- **ใช้กับกริยาเคลื่อนที่เท่านั้น:** ✗ 여기로 있어요 → ✓ 여기에 있어요 *(ที่ตั้งใช้ 에 ข้อ 05)*

> [!TIP] กฎสั้น ๆ
> **ทิศทาง = N(으)로 + กริยาเคลื่อนที่** · **ตัวสะกด→으로 สระ/ㄹ→로** · **ที่สี่แยก=사거리에서** · **บอกทางลงท้าย -(으)세요**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ข้อนี้ยังไม่มีข้อสอบจริงที่ครูตรวจแล้วเกี่ยวกับ (으)로 ทิศทาง เพราะ 30과 อยู่ใน **복습시험④ (11/18, 30–37과)** และ **기말** แต่การบอกทางเป็นสถานการณ์ที่ครูชอบออก จึงควรเตรียมไว้

- **นามสุ่มเสี่ยง:** การบอกทางเป็นสถานการณ์ที่ครูชอบออก (말하기: 길 묻기) — ตำราให้ทั้งบทสนทนา 30-1 (ธนาคาร/ห้าง/ร้านสะดวกซื้อ) และ 활동 รูปสี่แยก 4 ร้าน
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ:**
  - ลืม 으 หลังตัวสะกด (읽세요 · 받십니다 · 씻러)
  - 에 vs 에서 (백화점에 샀어요 → 갔어요/에서)
  - ตำแหน่งสลับจุดอ้างอิง (소파가 테이블 앞 → 뒤: ดูให้ถูกว่า "จากจุดไหน" — ข้อ 05)
- **คาดการณ์รูปแบบข้อสอบ** (จากรูปแบบ 복습시험①②; เป็นการคาด):
  - เติมคำช่วย: 사거리(　)오른쪽(　)가세요 → 에서 · 으로 (+ 교실(　)들어오세요 → 로)
  - ดูแผนที่/ลูกศร เขียนวิธีไป: ○○에 어떻게 가요? → …에서 오른쪽으로 가세요 (ตำรา 활동 สี่แยก: 라라미용실 · 우리PC방 · 서울병원 · 스타노래방)
  - ตอบคำถามด้วยไวยากรณ์ที่กำหนด: 우체국이 어디에 있어요? (오른쪽/가다) · PC방이 어디에 있어요? (2층/올라가다)
  - อ่าน 가/나 เว้นคำตอบ: 30-1 (카오루: 이 근처에 은행이 있습니까? / 사거리에서 왼쪽으로 가세요 · 4시에 문을 닫으니까 빨리 가세요)
