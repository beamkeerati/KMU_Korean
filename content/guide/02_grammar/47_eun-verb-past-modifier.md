## 47. -(으)ㄴ (กริยาขยายคำนาม · อดีต: 어제 본 영화)

> [!INTRO] ข้อนี้คืออะไร
> -(으)ㄴ ใช้ต่อท้ายรากของ**กริยา**เพื่อ**ขยายคำนามที่ตามหลัง** บอกว่าการกระทำนั้น**เกิดขึ้นหรือจบไปแล้ว** เช่น "หนังที่ดูเมื่อวาน" (어제 본 영화) หรือบอกสภาพที่เสร็จแล้วแต่ยังคงอยู่ เช่น "คนที่สวมหมวก" ภาษาไทยใช้คำว่า "ที่" นำหน้าประโยคย่อย แต่ภาษาเกาหลี**วางประโยคย่อยไว้หน้านาม** จึงต้องฝึกเรียงคำใหม่
>
> สอนในบท 29 (ตำราหน้า 286 준비 1 และหน้า 287 연습 2–3) ต่อยอดจากข้อ 44 (-는 ปัจจุบัน บท 27) ข้อ 36 (-(으)ㄴ ของคำคุณศัพท์ บท 23) ข้อ 23 (-았/었/였- อดีต) และข้อ 35 (ตาราง 받침)
>
> ไปใช้ต่อในข้อ 56 (-(으)ㄹ อนาคต บท 33 พร้อมตารางสรุป -(으)ㄴ/-는/-(으)ㄹ) ข้อ 59 (-는 것) และข้อ 61 (-(으)ㄴ/는데요)

### 📌 รูปแบบและเงื่อนไข

ให้ตัด 다 ออกจากรูปพจนานุกรม แล้วดูพยางค์สุดท้ายของรากว่ามีตัวสะกด (받침) หรือไม่ กฎนี้ใช้กับ**กริยา**เท่านั้น ส่วนรูป -(으)ㄴ ของคำคุณศัพท์แปลว่าปัจจุบัน (ดูข้อ 36)

| รากศัพท์ลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| ไม่มีตัวสะกด (รวม ㅡ · 하다) | **-ㄴ** | 보다 → **본** · 쓰다 → **쓴** · 하다 → **한** |
| มีตัวสะกด | **-은** | 먹다 → **먹은** · 받다 → **받은** · 읽다 → **읽은** |
| ลงท้าย **ㄹ** | **ตัด ㄹ ทิ้ง แล้วเติม -ㄴ** | 만들다 → **만든** (✗ 만들은) *(ที่ทำ — ตำรา 286쪽: 어제 만든 케이크)* |
| ปฏิเสธ | **-지 않은** / 안 + V-ㄴ | 안경을 쓰지 않은 사람 *(คนที่ไม่ได้ใส่แว่น)* · 모자를 쓰지 않은 사람 *(คนที่ไม่ได้สวมหมวก — ตำรา 291쪽)* |
| 있다 / 없다 | ใช้ **-는** (ไม่ใช่ -은) | 맛있는 음식 · 재미있는 영화 *(ข้อ 44 — ไม่ใช่ ✗ 맛있은)* |

#### ตารางผันที่ควรจำ (ตำรา 29과)

ตารางนี้รวมกริยาที่บท 29 ใช้ จัดตามกฎข้างบน ช่อง "แปล" คือความหมายเมื่อใช้ขยายนาม

| 기본형 | -(으)ㄴ | แปล | กฎที่ใช้ |
|:---|:---|:---|:---|
| 보다 | **본** | ที่ดู | ไม่มีตัวสะกด |
| 오다 | **온** | ที่มา | ไม่มีตัวสะกด |
| 사다 | **산** | ที่ซื้อ | ไม่มีตัวสะกด |
| 배우다 | **배운** | ที่เรียน | ไม่มีตัวสะกด |
| 다녀오다 | **다녀온** | ที่ไปมา | ไม่มีตัวสะกด |
| 쓰다 | **쓴** | ที่สวม (หมวก/แว่น) | ㅡ ไม่มีตัวสะกด |
| 하다 | **한** | ที่ทำ | 하다 ไม่มีตัวสะกด |
| 먹다 | **먹은** | ที่กิน | มีตัวสะกด |
| 받다 | **받은** | ที่ได้รับ | มีตัวสะกด |
| 읽다 | **읽은** | ที่อ่าน | มีตัวสะกด |
| 입다 | **입은** | ที่สวมใส่ | มีตัวสะกด |
| 찍다 | **찍은** | ที่ถ่าย | มีตัวสะกด |
| 신다 | **신은** | ที่สวม (รองเท้า) | มีตัวสะกด |
| 만들다 | **만든** | ที่ทำ (ตำรา 286쪽: 어제 만든 케이크) | ㄹ ตกก่อน ㄴ |

#### โครงสร้างประโยคและลำดับคำ

ตำราหน้า 286 อธิบายว่า -(으)ㄴ ต่อหลังกริยาเพื่อขยายนาม และแสดงว่าเหตุการณ์ "เกิดขึ้นในอดีตแล้ว" หรือ "จบแล้วแต่สภาพนั้นยังคงอยู่" ส่วนที่คนไทยมักพลาดคือลำดับคำที่กลับกับภาษาไทย

- **ตำรา 286쪽:** มีตัวสะกด → -은 · ไม่มี → -ㄴ · ㄹ-ราก → ตัด ㄹ แล้วใส่ ㄴ
- **โครงสร้าง:** [ประธานของประโยคย่อย + กรรม + กริยา-(으)ㄴ] + **นาม** + ส่วนที่เหลือของประโยคหลัก นามที่ถูกขยายเป็นประธานหรือกรรมของประโยคหลัก และ**ได้ 이/가/을/를 ของตัวเอง** เช่น 어제 본 영화**가** 재미있었어요 *(หนังที่ดูเมื่อวานสนุก)*
- **ลำดับคำกลับกับไทย:** ภาษาไทยเรียง นาม + ที่ + ประโยค (หนังที่ดูเมื่อวาน) ส่วนภาษาเกาหลีเรียง ประโยค + ㄴ + นาม (**어제 본 영화**)

#### กริยาสวมใส่ (입다 · 쓰다 · 신다)

กริยากลุ่มสวมใส่ใช้ -(으)ㄴ แล้วแปลว่า "ที่สวมอยู่" เพราะการสวมคือการกระทำที่จบแล้วแต่สภาพยังคงอยู่

- 입은 · 쓴 · 신은 = "ที่ **สวมอยู่**" (ตำราอธิบายว่า จบแล้วแต่สภาพยังคงอยู่)
- 바지를 입은 사람 *(คนที่ใส่กางเกง)*

#### สูตรและวิธีทำ: -(으)ㄴ กริยาขยายนามอดีต (แบบกระดานครู)

-(으)ㄴ ต่อท้ายรากของกริยาเพื่อขยายนามที่ตามมา และบอกว่าการกระทำนั้นจบไปแล้ว รูปนี้ผันด้วยกฎเดียวกับ -(으)ㄴ ของคำคุณศัพท์ แต่ความหมายต่างกัน สิ่งที่เปลี่ยนมีแค่ตัวสะกดของรากกับ 으

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | รากไม่มีตัวสะกด (รวม ㅡ · 하다) | ตัด 으 แล้วต่อ **ㄴ** เป็นตัวสะกดใหม่ | ไม่มีตัวสะกดก็ไม่ต้องใช้ 으 เชื่อม (본 · 쓴 · 한) |
| **กฎ 2** | รากมีตัวสะกด | เก็บ 으 ต่อ **은** | ต้องมี 은 (✗ 먹ㄴ · ✗ 읽ㄴ) |
| **กฎ 3** | รากลงท้าย ㄹ | ตัด 으 แล้ว **ตัด ㄹ ของราก** ก่อน ㄴ | ㄹ ไม่อยู่หน้า ㄴ (✗ 만들은) |
| **กฎ 4** | รากเป็น ㅂ 불규칙 | ㅂ หลุด ใส่ **우** แทน 으 แล้วต่อ ㄴ | ㅂ เปลี่ยนเมื่อมี (으) ตามหลัง (돕 → 도운) |

ลำดับทำคือ ① ดูตัวสะกดของรากว่าไม่มี มี หรือเป็น ㄹ แล้วตัดสินว่าเก็บหรือตัด 으 ② ปรับราก (ㄹ ตก · ㅂ → 우) ③ ต่อ ㄴ หรือ 은 แล้ววางนามที่ถูกขยายไว้ข้างหลัง ตารางนี้แสดงทุกขั้นกับคำที่ตำราใช้

| ราก + (으)ㄴ | ① ตัวสะกด / 으 | ② ปรับราก | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 보 + (으)ㄴ | ไม่มี ตัด 으 | ไม่ปรับ | **본** | 어제 본 영화 *(หนังที่ดูเมื่อวาน)* |
| 오 + (으)ㄴ | ไม่มี ตัด 으 | ไม่ปรับ | **온** | 다녀오다 → 다녀온 ใช้กฎเดียวกัน |
| 사 + (으)ㄴ | ไม่มี ตัด 으 | ไม่ปรับ | **산** | 사다 กับ 살다 ได้ 산 เหมือนกัน |
| 배우 + (으)ㄴ | ไม่มี ตัด 으 | ไม่ปรับ | **배운** | ที่เรียนมา |
| 쓰 + (으)ㄴ | ไม่มี ตัด 으 | ไม่ปรับ (ㅡ ไม่ตก) | **쓴** | ✗ 쓴은 · ✗ 썬 |
| 하 + (으)ㄴ | ไม่มี ตัด 으 | ไม่ปรับ | **한** | ✗ 하은 |
| 먹 + (으)ㄴ | มี เก็บ 으 | ไม่ปรับ | **먹은** | ✗ 먹ㄴ |
| 읽 + (으)ㄴ | มี เก็บ 으 | ไม่ปรับ | **읽은** | ✗ 읽ㄴ ลืม 으 เหมือน ✗ 읽세요 |
| 입 + (으)ㄴ | มี เก็บ 으 | ไม่ปรับ (ㅂ ปกติ) | **입은** | ㅂ ปกติ: 입다 · 잡다 · 좁다 |
| 만들 + (으)ㄴ | ㄹ ตัด 으 | ตัด ㄹ ของราก | **만든** | ✗ 만들은 |
| 살 + (으)ㄴ | ㄹ ตัด 으 | ตัด ㄹ ของราก | **산** | ที่เคยอยู่ *(ปัจจุบันใช้ 사는 ข้อ 44)* |
| 돕 + (으)ㄴ | ㅂ 불규칙 | ㅂ หลุด ใส่ 우 แทน 으 | **도운** | ✗ 돕은 (ข้อ 37) |
| 쓰지 않 + (으)ㄴ | มีตัวสะกด (않) เก็บ 으 | ไม่ปรับ | **쓰지 않은** | 모자를 쓰지 않은 사람 ✗ 쓰지 안은 |
| 맛있 + (으)ㄴ | 있다 ใช้ 는 | ไม่ใช้ 은 | **맛있는** | ✗ 맛있은 (ข้อ 44) |

> [!TIP] วิธีจำสั้น ๆ
> กริยา + ㄴ/은 แปลว่า "ที่ …แล้ว" ไม่มีตัวสะกดใช้ ㄴ มีตัวสะกดใช้ 은 ราก ㄹ ตัด ㄹ ก่อน ราก ㅂ ไม่ปกติใช้ 운 ส่วน 있다/없다 ใช้ 는 เสมอ

| 준비 1 | 작년 여름에 다녀온 산 이름이 뭐예요? | 작년 여름에 다녀온 산 이름은 한라산이에요. *(ชื่อภูเขาที่ไปมาเมื่อฤดูร้อนปีที่แล้วคืออะไร — คือฮัลลาซาน)* |
| 연습 2 | 어제 책을 읽은 사람은 누구예요? | 어제 책을 읽은 사람은 마키 씨예요. *(คนที่อ่านหนังสือเมื่อวานคือใคร — คือคุณมากิ)* |

### ⚠️ จุดสับสน

ความสับสนหลักคือรูป -(으)ㄴ ใช้ได้ทั้งกับกริยา (อดีต) และคำคุณศัพท์ (ปัจจุบัน) และกริยายังมีรูปขยายนามอีกสองกาลที่หน้าตาต่างกัน ตารางแรกสรุปคู่ ✓ ถูก / ✗ ผิด ที่เจอบ่อย ส่วนหัวข้อย่อยถัดไปช่วยแยกสามรูปนี้ออกจากกัน

| กรณี | ✓ ถูก | ✗ ผิด |
|:---|:---|:---|
| ㄹ-ราก | 만든 케이크 | 만들은 케이크 |
| มีตัวสะกด | 먹은 · 읽은 | 먹ㄴ 음식 · 읽ㄴ 책 |
| ㅡ ราก | 쓴 | 쓴은 · 썬 |
| 하다 | 화장을 한 사람 | 하은 |
| ใส่กาลซ้ำ | 어제 본 영화 | 어제 봤은 영화 |
| ปฏิเสธ | 모자를 쓰지 않은 사람 | 모자를 쓰지 안은 사람 |
| 있다/없다 | 맛있는 음식 | 맛있은 |

#### -(으)ㄴ vs -는 vs -(으)ㄹ (กริยาขยายนาม 3 กาล)

ใช้กริยาตัวเดียวกันเทียบสามกาล รูปที่เลือกขึ้นกับว่าเหตุการณ์จบแล้ว กำลังเกิด/ประจำ หรือยังไม่เกิด

| | อดีต/จบแล้ว | ปัจจุบัน/ประจำ | อนาคต/ยังไม่เกิด |
|:---|:---|:---|:---|
| รูป | **-(으)ㄴ** (ข้อ 47) | **-는** (ข้อ 44) | **-(으)ㄹ** (ข้อ 56 บท 33 — ยังไม่เรียน) |
| 보다 | **본** 영화 *(หนังที่ดูแล้ว)* | **보는** 영화 *(หนังที่กำลังดู/ดูอยู่เสมอ)* | **볼** 영화 *(หนังที่จะดู)* |
| 가다 | **간** 사람 *(คนที่ไปแล้ว)* | **가는** 사람 *(คนที่ไป/กำลังไป)* | **갈** 사람 *(คนที่จะไป)* |

ตัวอย่างที่ตำราใช้ทั้งสองแบบ ดูว่าเหตุการณ์เป็นประจำ (-는) หรือจบไปแล้ว (-ㄴ)

| คู่เทียบ | -는 (ประจำ) | -(으)ㄴ (จบแล้ว) |
|:---|:---|:---|
| คู่ที่ 1 | 외국 사람들이 많이 **구경하는** 축제 *(เทศกาลที่ชาวต่างชาติมาเที่ยวชมมาก)* | 지난 주말에 **다녀온** 바다 *(ทะเลที่ไปมาเมื่อสุดสัปดาห์ที่แล้ว)* |
| คู่ที่ 2 | 자주 **가는** 식당 *(ร้านอาหารที่ไปบ่อย)* | 어제 **간** 식당 *(ร้านอาหารที่ไปเมื่อวาน)* |

- **กริยา + ㄴ = อดีต แต่ คุณศัพท์ + ㄴ = ปัจจุบัน:** รูปเหมือนกัน (-ㄴ/-은) ต้องดูว่าราก**เป็นกริยาหรือคำคุณศัพท์**
  - 먹**은** 음식 *(อาหารที่กินแล้ว — กริยา)*
  - 매**운** 음식 *(อาหารที่เผ็ด — คำคุณศัพท์ ข้อ 36)*
- 있다/없다 ใช้ **-는** เสมอ เช่น 맛있는 · 재미있는 · 없는
- **ไม่ใส่ -았/었- ซ้ำในตัวขยาย:** ✗ 어제 봤은 영화 → ✓ **어제 본 영화**

#### กับดัก

ข้อผิดที่เจอบ่อยในข้อนี้เป็นเรื่องรูปสะกดและตำแหน่งของคำ ไล่ดูทีละข้อ

- **ㄹ-ราก:** ตัด ㄹ ก่อน ㄴ (ข้อ 35)
  - ✓ 만든 케이크 · ✗ 만들은 케이크
  - ✓ 논 *(เล่น)*
- **ลืม 은 หลังตัวสะกด** *(ข้อผิดซ้ำ: 읽세요 · 받십니다 · 씻러)*
  - ✗ 먹ㄴ 음식 → ✓ 먹은
  - ✗ 읽ㄴ 책 → ✓ 읽은
- **ㅡ ราก:** 쓰다 → ✓ **쓴** (ไม่ใช่ ✗ 쓴은 / ✗ 썬)
  - ประโยคจบ: 안경을 **썼어요** *(ใครสวมแว่น — -았/었-)*
  - ตัวขยาย: 안경을 **쓴** 사람 *(คนที่สวมแว่น)*
- **하다:** ✓ 화장을 **한** 사람 · 운동**한** 사람 — ✗ 하은
- **ตำแหน่ง:** นามอยู่หลังตัวขยายเสมอ
  - ✓ 어제 본 영화**가** … / ✗ 영화 어제 본가
  - ตัวขยายอาจมี กรรม + 을/를 ของมันเอง: ✓ 어제 **책을** 읽은 사람 / ✗ 어제 책이 읽은 사람 *(ผู้เรียนเคยเขียน 가 แทน 를 กับ 받다/듣다)*
- **ปฏิเสธ:** ✓ 모자를 쓰지 **않은** 사람 / ✓ 모자를 **안** 쓴 사람 — ✗ 모자를 쓰지 안은 사람 *(ตัวสะกด 않 + 은)*
- **กริยาไม่ปกติ (เสริม — ตารางข้อ 51/37/54):**
  - ㄷ-ราก: 듣다 → **들은** · 걷다 → **걸은** · 묻다 → **물은**
  - ㅂ-ราก: 돕다 → **도운** (ㅂ → 우 ก่อน -ㄴ ข้อ 37)
  - 르-ราก ไม่เปลี่ยนก่อน ㄴ: 부르다 → **부른** · 모르다 → **모른** *(ข้อ 54)*
- **다녀오다** = ไปแล้วกลับมา → 다녀온 산/바다 = ภูเขา/ทะเลที่ "ไปมาแล้ว" — ✗ 다녀간 (คนละคำ) ตำรา 29과 ใช้คำนี้ 3 ครั้ง
  - 작년 여름에 다녀온 산
  - 지난 주말에 다녀온 바다
  - 머드 축제에 다녀왔어요

> [!TIP] กฎสั้น ๆ
> **กริยา + (으)ㄴ + นาม = "นามที่ ...แล้ว"** · **ตัด ㄹ ของ ㄹ-ราก** · **คุณศัพท์ + ㄴ = ปัจจุบัน** · **있다/없다 ใช้ -는**
