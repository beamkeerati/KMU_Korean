## 32. -고 있다 (กำลัง...)

> [!INTRO] ข้อนี้คืออะไร
> -고 있다 บอกว่าการกระทำ **กำลังดำเนินอยู่** ณ ขณะพูด (หรือในช่วงนี้) ใช้กับ**กริยา**เท่านั้น วิธีสร้างคือต่อท้ายรากกริยาแล้วตามด้วย 있다
>
> สอนในบท 21 (교과서 190–191쪽) ต่อยอดจาก ข้อ 06 (-아/어요) · ข้อ 20 (계시다) · ข้อ 28 (อนาคต ↔ ตอนนี้)
>
> ต่อยอดจาก ข้อ 05 (있다) ด้วย
>
> ไปใช้ต่อใน ข้อ 34 (-고 อีกความหมาย "และ" ที่บท 22) · ข้อ 29 · ข้อ 31 · ข้อ 35

### 📌 รูปแบบและเงื่อนไข

-고 ขึ้นต้นด้วยพยัญชนะ จึงต่อท้ายรากกริยาได้ตรง ๆ โดยไม่ต้องดูตัวสะกด แล้วตามด้วย 있다 ที่เปลี่ยนไปตามระดับภาษา ตารางข้างล่างสรุปรูปที่ใช้ตามสถานการณ์

| รูป | วิธีต่อ |
|:---|:---|
| ปกติ | รากกริยา (ตัด 다) + **-고 있어요** |
| ผู้ใหญ่ | **-고 계세요** |
| ทางการ | **-고 있습니다** · **-고 계십니다** |
| อดีต *(เสริม)* | **-고 있었어요** |
| ถาม–ตอบ | **뭐 하고 있어요?** |

#### ตัวอย่างการต่อ

ตารางนี้เรียงตามรูปข้างบน หนึ่งตัวอย่างต่อหนึ่งแถว

| รูป | 한국어 | ไทย |
|:---|:---|:---|
| ปกติ | 공부하다 → 공부하**고 있어요** | กำลังเรียน |
| ปกติ | 읽다 → 읽**고 있어요** | กำลังอ่าน |
| ผู้ใหญ่ | 일을 하**고 계세요** | ท่านกำลังทำงาน |
| ทางการ | 공부하**고 있습니다** | กำลังเรียน (ทางการ) |
| ทางการ | 일을 하**고 계십니다** | ท่านกำลังทำงาน (ทางการ) |
| อดีต *(เสริม)* | 공부하**고 있었어요** | ตอนนั้น{e:กำลัง}{v:เรียน}{e:อยู่} |
| ถาม–ตอบ | 가: 지금 뭐 하고 있어요? — 나: 숙제하고 있어요. | {a:ตอนนี้}{v:ทำ}{q:อะไร}{e:อยู่} — {e:กำลัง}{v:ทำ}{n:การบ้าน} |

#### ข้อสังเกต

-고 ไม่ทำให้รากเปลี่ยนรูป และใช้กับ "ช่วงนี้" ได้ด้วย

- ไม่ดูตัวสะกดของราก และไม่ผันรากพิเศษ เพราะ -고 ขึ้นต้นด้วยพยัญชนะ
  - 듣다 → 듣**고 있어요** (ㄷ ไม่เปลี่ยน) *(กำลังฟัง)*
  - 살다 → 살**고 있어요** (ㄹ ไม่หลุด) *(กำลังอยู่อาศัย)*
- **ตำรา 190쪽:** ต่อหลังกริยาเพื่อบอกว่าการกระทำ "กำลังดำเนินอยู่"
- รูปยกย่องคือ **-고 계시다**
- ใช้กับ "ช่วงนี้" ได้ด้วย (워크북 21과 D): 요즘 뭐 해요? — 태권도를 배우고 있어요. *({a:ช่วงนี้}{v:ทำ}{q:อะไร} — {e:กำลัง}{v:เรียน}{n:เทควันโด})*

#### การออกเสียง

ตัว ㄱ ของ -고 ที่ตามหลังตัวสะกดออกเป็น ㄲ ควรระวังเป็นพิเศษตอน 낭독

| เขียน | อ่าน |
|:---|:---|
| 먹고 | [먹꼬] |
| 읽고 | [일꼬] |
| 듣고 | [듣꼬] |
| 찍고 | [찍꼬] |

#### สูตรและวิธีทำ: -고 있다 (แบบกระดานครู)

-고 있다 ใช้กับกริยาเท่านั้น และต่อ -고 ที่รากตรง ๆ โดยไม่ต้องคิดเรื่อง 받침 ส่วนที่ต้องเลือกคือคำท้าย (있다 หรือ 계시다) กับกาลและระดับภาษาที่คำท้ายนั้น

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | รากเป็นกริยา (ไม่ใช่คำคุณศัพท์) | ต่อ **-고** ที่รากตรง ๆ ไม่ตัด ไม่เปลี่ยนราก | -고 ขึ้นต้นด้วยพยัญชนะ จึงไม่มีการรวมเสียง ㄹ ㄷ และ 하 อยู่ครบ |
| **กฎ 2** | คนที่ทำเป็นผู้ใหญ่ | เปลี่ยน 있다 เป็น **계시다** (-고 계세요) | ยกย่องคนที่ทำ ✗ -고 있으세요 |
| **กฎ 3** | ระดับภาษาและกาล | ใส่ที่ **있다 / 계시다** ท้ายสุด (있어요 · 있습니다 · 있었어요) | รากกับ -고 ไม่เปลี่ยนตามกาล |

ลำดับทำคือ ① ดูว่ารากเป็นกริยาหรือไม่ ② ต่อ -고 ที่ราก ③ เลือก 있다 หรือ 계시다 แล้วใส่ระดับภาษาหรือกาล ตารางนี้แสดงทุกขั้นกับคำที่ตำราใช้

| ราก + คำต่อ | ① เป็นกริยาไหม | ② ต่อ -고 | ③ 있다 / 계시다 | ④ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|:---|
| 공부하 + 고 있다 | กริยา (N하다) | 공부하고 | 있어요 | **공부하고 있어요** | ไม่ตัด 하 |
| 읽 + 고 있다 | กริยา | 읽고 | 있어요 | **읽고 있어요** | ไม่ใส่ 으 |
| 듣 + 고 있다 | กริยา | 듣고 | 있어요 | **듣고 있어요** | ㄷ ไม่เปลี่ยน |
| 살 + 고 있다 | กริยา | 살고 | 있어요 | **살고 있어요** | ㄹ ไม่หลุด |
| 읽 + 고 있다 (คุณพ่อ) | กริยา | 읽고 | 계세요 (ผู้ใหญ่) | **읽고 계세요** | ✗ 읽고 있으세요 |
| 공부하 + 고 있다 (ทางการ) | กริยา | 공부하고 | 있습니다 | **공부하고 있습니다** | ไม่เปลี่ยนราก |
| 공부하 + 고 있다 (อดีต) | กริยา | 공부하고 | 있었어요 | **공부하고 있었어요** | ตอนนั้นกำลังเรียนอยู่ |
| 예쁘 + 고 있다 | ไม่ใช่ (คำคุณศัพท์) | หยุดที่ขั้น ① | ไม่ใช้ | ใช้ **예뻐요** แทน | ✗ 예쁘고 있어요 |

> [!TIP] วิธีจำสั้น ๆ
> เช็กว่าเป็นกริยาก่อน แล้วต่อ -고 ที่รากตรง ๆ ผู้ใหญ่เปลี่ยนเป็น 계세요 และกาลกับระดับภาษาไปอยู่ที่ 있다 ท้ายสุด

### 📖 ตัวอย่างและการใช้

ตัวอย่างในตอนนี้เริ่มจากประโยคสั้น ๆ ที่บอกว่าใครกำลังทำอะไร แล้วตามด้วยประโยคจากบทอ่านและแบบฝึกของบท 21

#### ประโยคตัวอย่าง

ประโยคเหล่านี้บอกการกระทำที่กำลังดำเนินอยู่ทั้งหมด

- 지금 공부하**고 있어요**. *(ตอนนี้กำลังเรียนอยู่)*
- 바트 씨가 전화하**고 있어요**. *(บัตกำลังโทรศัพท์)*
- 텔레비전을 보**고 있어요**. *(กำลังดูโทรทัศน์)*
- 음악을 듣**고 있어요**. *(กำลังฟังเพลง)*
- 장핑 씨가 노래를 부르**고 있어요**. *(จางผิงกำลังร้องเพลง)*
- 동생은 책을 읽**고 있어요**. *(น้องกำลังอ่านหนังสือ)*
- 어머니께서는 일을 하**고 계십니다**. *(คุณแม่กำลังทำงานอยู่)*
- 창문 밖에는 눈이 계속 오**고 있어요**. *({n:นอก}{n:หน้าต่างหิมะ}{v:ตก}{n:ต่อเนื่อง}{e:อยู่})*

#### จากบทอ่านและแบบฝึก 21과

ประโยคจากจดหมายในบทอ่านและจากแบบฝึกของเวิร์กบุ๊กมีดังนี้ ประโยคที่ติดป้าย 워크북 D มาจากแบบฝึก D

| 한국어 | ไทย |
|:---|:---|
| 투이: 뚜언 씨, 잘 지내고 있어요? | คุณตวน สบายดีไหม (ทักทายในจดหมาย) |
| 저는 지금 남이섬 카페에서 이 편지를 쓰고 있어요. | ตอนนี้ฉันกำลังเขียนจดหมายฉบับนี้ที่คาเฟ่เกาะนามิ |
| 친구들은 여기저기 사진을 찍고 있어요. | เพื่อน ๆ กำลังถ่ายรูปที่โน่นที่นี่ |
| 저만 여기에서 고향을 생각하고 있어요. | มีแค่ฉันที่นี่ที่กำลังคิดถึงบ้านเกิด |
| 가: 투이 씨는 사진을 찍고 있어요? — 나: 아니요, 운동을 하고 있어요. | คุณทุยกำลังถ่ายรูปอยู่หรือ — ไม่ กำลังออกกำลังกายอยู่ |
| 가: 어머니께서 청소를 하고 계세요? — 나: 아니요, 요리를 하고 계세요. *(워크북 D)* | คุณแม่กำลังทำความสะอาดอยู่หรือ — ไม่ กำลังทำอาหารอยู่ |
| 누구한테서 한국말을 배우고 있어요? *(워크북 D)* | กำลังเรียนภาษาเกาหลีจากใครอยู่ |
| 누구하고 같이 살고 있어요? *(워크북 D)* | อยู่ด้วยกันกับใคร |

### ⚠️ จุดสับสน

ภาษาไทยใช้ "กำลัง" ได้กับแทบทุกประโยค แต่ในเกาหลี -아/어요 ธรรมดาก็ครอบคลุม "กำลัง" อยู่แล้ว ตอนนี้จะเทียบ -고 있어요 กับรูปที่ใกล้เคียง แล้วดูข้อผิดที่เจอบ่อย

#### -고 있어요 vs -아/어요 vs 에 있어요

-고 있어요 ใช้เมื่ออยากเน้นว่า **กำลังดำเนินอยู่ ณ ขณะพูด** ส่วน 에 있어요 ไม่ใช่ "กำลัง" แต่แปลว่า "อยู่ที่…"

| | -아/어요 | -고 있어요 | 에 있어요 (ข้อ 05) |
|:---|:---|:---|:---|
| ความหมาย | ปัจจุบันทั่วไป (รวม "กำลัง") | เน้น "กำลังทำอยู่ตอนนี้" | "อยู่ที่…" |
| ตัวอย่าง 1 | 공부해요 *({v:เรียน} / {e:กำลัง}{v:เรียน}ก็ได้)* | 지금 책을 읽**고 있어요**. *(ตอนนี้กำลังอ่านหนังสือ)* | 학교에 있어요. *(อยู่ที่โรงเรียน)* |
| ตัวอย่าง 2 | 지금 뭐 해요? *({a:ตอนนี้}{v:ทำ}{q:อะไร}{e:อยู่})* | — | — |

#### ตัวอย่างผิด–ถูกและข้อควรระวัง

ข้อผิดของ -고 있다 มักเกิดจากการใช้กับคำคุณศัพท์ การยกย่องผิดรูป และการใช้ตอบคำถามอนาคต

| ✓ ถูก | ✗ ผิด | เหตุผล |
|:---|:---|:---|
| 아버지가 신문을 읽**고 계세요**. *(คุณพ่อกำลังอ่านหนังสือพิมพ์)* | 읽고 있으세요 | ยกย่อง = **고 계세요** |
| 예뻐요 | 예쁘**고 있어요** | คำคุณศัพท์ใช้ -고 있다 ไม่ได้ |
| 영화를 볼 거예요 *(จะดูหนัง)* | 영화를 보고 있어요 *(กำลังดูหนัง)* | ถามอนาคต `주말에 뭐 하실 거예요?` *(สุดสัปดาห์จะทำอะไร)* |

- ✓ 어제 저녁에 공부하**고 있었어요**. *({a:เมื่อวาน}{n:เย็น}{e:กำลัง}{v:เรียน}{e:อยู่})*
- สำนวน **알다 → 알고 있어요** *(เสริม ตำรา 21과 ยังไม่สอน)*: ✓ 그 사람을 알**고 있어요**. *({v:รู้จัก}{n:คนนั้น}{e:อยู่})*
- เลือกกาลจากเวลา: 지금 → **-고 있어요** · 내일/주말 → **-(으)ㄹ 거예요** (ข้อ 28)
- รากเดียวกัน คนละหน้าที่: ราก + **-고 있다/계시다** = กำลัง · ราก + **-고** + กริยา/คุณศัพท์อื่น = และ (ข้อ 34)

> [!TIP] กฎสั้น ๆ
> **-고 있다 = "กำลัง" (กริยาเท่านั้น) · ผู้ใหญ่ = -고 계세요 · อดีต = -고 있었어요**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ยังไม่มีข้อสอบจริงที่ครูตรวจแล้วเกี่ยวกับ -고 있다 แต่มีโจทย์ในชุดทบทวนของครู ข้อสอบรวม และชีตฟังที่ใช้ตัวนี้ รายการข้างล่างแยกตามแหล่งที่มา

- ข้อที่เสี่ยงผิด: ✗ 읽고 있으세요 · ✗ 예쁘고 있어요
- 21과 อยู่ในขอบเขต 중간시험 (10/22–23) แต่ไม่อยู่ใน 복습시험②
- **ชุดทบทวนของครู (중간시험 복습문제):**
  - 말하기 연습 Q18 `지금 뭐 하고 있어요?` *(ตอนนี้ทำอะไรอยู่)* → ตอบ `지금 ( )고 있어요`
  - Q14 ย่อย 8) `지금 무엇을 하고 있어요?` *(ตอนนี้กำลังทำอะไรอยู่)*
  - 읽기 Q25 ④ `투이 씨는 지금 사진을 찍고 있어요` ✗ (ในจดหมาย **เพื่อน ๆ** ถ่ายรูป ส่วนทุยกำลังเขียนจดหมาย)
- **ข้อสอบรวม 5~21과:**
  - Q29 `저도 ( )` → **배우고 있어요** (✗ 배우네요)
  - Q28 ตัวลวง ① `영화를 보고 있어요` ใช้ตอบคำถามอนาคตไม่ได้
  - เฉลยในไฟล์เป็นการแก้เอง ไม่ใช่เฉลยครู
- **ชีตฟัง 본문 듣기 21과 (ช่อง B):** เติม **숙제하고 있어요** จากบทสนทนา 21-1

### 🔗 เชื่อมโยง

← ต่อยอดจาก

- ข้อ 06 (-아/어요 ปัจจุบัน → -고 있어요 เน้น "กำลัง")
- ข้อ 28 (อนาคต ↔ ตอนนี้ เลือกกาลจากเวลา)
- ข้อ 20 (계시다 → -고 계세요)
- ข้อ 05 (있다 = อยู่)

→ ใช้ต่อใน

- ข้อ 34 (บท 22: ราก + -고 เหมือนกัน แต่ -고 = และ · -고 있다 = กำลัง)
- 22과 워크북 C-3 (`음식과 음료수를 준비하고 있어요` *(กำลังเตรียมอาหารและเครื่องดื่ม)*)
- ข้อ 29 (21과: `누구한테서 한국말을 배우고 있어요?`)
- ข้อ 31 (읽기 21 ใช้คู่กับ 만)

> [!SUMMARY] สรุป
> - ราก + **-고 있어요** = "กำลัง" ใช้กับ**กริยา**เท่านั้น ไม่ต้องดูตัวสะกดและไม่ผันรากพิเศษ (듣고 있어요 · 살고 있어요)
> - ผู้ใหญ่ = **-고 계세요** ทางการ = -고 있습니다 / -고 계십니다 อดีต = -고 있었어요
> - คำคุณศัพท์ใช้ไม่ได้ (✗ 예쁘고 있어요) และตอบคำถามอนาคตไม่ได้ (ต้อง -(으)ㄹ 거예요)
> - ราก + -고 + กริยาอื่น = "และ" (ข้อ 34) เป็นคนละหน้าที่กับ -고 있다
