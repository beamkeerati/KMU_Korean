## 50. -(으)니까 (…นะ / เพราะ…เลย — เหตุผลที่ผู้พูดยกเพื่อสั่ง · แนะนำ · ชวน)
ต่อท้ายรากของ**กริยา · คำคุณศัพท์ · N이다** บอก**เหตุผลหรือหลักฐานที่ผู้พูดยก**แล้วตามด้วย**คำสั่ง/คำแนะนำ/คำชวน**ที่ตั้งอยู่บนเหตุผลนั้น ("ฝนตกอยู่ เตรียมร่มไปนะ") — ต่างจาก -아/어서 ที่ใช้ได้แค่บอกเหตุผลตามธรรมชาติ
สอนในบท 30 (교과서 300쪽 준비 2 + 301쪽 연습) — ตำราอ้าง "Related grammar -아/어/여서¹: Lesson 29" · ต่อยอดจาก ข้อ 48 (-아/어서) · ข้อ 20 (-(으)세요) · ข้อ 33 (-(으)ㄹ까요?) · ข้อ 06 (หารากศัพท์) · ข้อ 35 (ㄹ ตกก่อน ㄴ)
ใช้ต่อใน บท 31 (안내 방송을 하니까 잘 들으세요 · 버스가 싸니까 버스로 가세요) · ข้อ 39 (-지 마세요 ตามหลัง -(으)니까) · ข้อ 55 (-(으)면)

### 📌 รูปแบบและเงื่อนไข
ตัด 다 ทิ้ง ดูพยางค์สุดท้ายของราก — เหมือนกฎ -(으)세요 (ข้อ 20) คือ**มีตัวสะกดใส่ 으**

| รากศัพท์ลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| ไม่มีตัวสะกด | **-니까** | 막히다 → **막히니까** · 오다 → **오니까** · 보다 → **보니까** · 기다리다 → **기다리니까** · 모르다 → **모르니까** *(เพราะรถติด · เพราะฝนตก · เพราะดู · เพราะรอ · เพราะไม่รู้)* |
| มีตัวสะกด (รวม 있다/없다) | **-으니까** | 없다 → **없으니까** · 있다 → **있으니까** · 닫다 → **닫으니까** · 좋다 → **좋으니까** *(เพราะไม่มี · เพราะมี · เพราะปิด · เพราะดี)* |
| ลงท้าย **ㄹ** | **ตัด ㄹ + -니까** | 멀다 → **머니까** · 만들다 → **만드니까** · 살다 → **사니까** · 알다 → **아니까** *(เพราะไกล · เพราะทำ · เพราะอยู่ · เพราะรู้ — ㄹ หลุดหน้า ㄴ ข้อ 35)* |
| **ㅂ 불규칙** (ข้อ 37) | ㅂ → **우** + 니까 | 덥다 → **더우니까** · 뜨겁다 → **뜨거우니까** · 시끄럽다 → **시끄러우니까** *(เพราะร้อน · เพราะร้อน (ของเหลว) · เพราะเสียงดัง)* |
| **ㄷ 불규칙** (ข้อ 51) | ㄷ → ㄹ + 으니까 | 듣다 → **들으니까** · 걷다 → **걸으니까** *(เพราะฟัง · เพราะเดิน)* |
| **นาม** (이다) | ตัวสะกด → **-이니까** · สระ → **-니까** | 생일**이니까** · 서류**니까** *(เพราะเป็นวันเกิด · เพราะเป็นเอกสาร)* |
| มีกาล | -았/었/였**으니까** · -(으)ㄹ **거니까** | 읽**었으니까** · 올 **거니까** *(เพราะอ่านแล้ว · เพราะจะมา)* |

- **ตำรา 300쪽:** ต่อหลังรากกริยา/คำคุณศัพท์ บอกว่าประโยคหน้าเป็นเหตุหรือหลักฐานของประโยคหลัง · รากมีตัวสะกด → -으니까 · สระ → -니까 · ต่อหลังนาม: ตัวสะกด → 이니까 · สระ → -니까 · **ใส่ตัวบอกกาลได้**
- **ประโยคหลังที่ใช้ได้:** -(으)세요 (สั่ง/แนะนำ) · -(으)ㄹ까요? / -아/어요 / -(으)ㅂ시다 (ชวน) · -지 마세요 (ห้าม ข้อ 39) · ประโยคบอกเล่าทั่วไป
- **ออกเสียง (ตำรา 300쪽):** 막히니까 [마키니까] · 없으니까 [업쓰니까] — ㄱ+ㅎ ควบเป็น [ㅋ] · ㅂ ท้าย + ㅅ → [ㅆ]
- **ร่วมกับ 거예요:** 여러 나라 학생들이 많이 **올 거니까** 꼭 오세요 *(ตำรา 31과 — -(으)ㄹ 거 + 이다 → 거니까 · "เพราะจะมาหลายประเทศ")*

### 📖 ตัวอย่างและการใช้
| | คำถาม/คำชวน | คำตอบ (เหตุผล → คำสั่ง) |
|:---|:---|:---|
| 준비 2 | 택시를 탈까요? | 출근 시간에는 길이 **막히니까** 지하철을 타세요. *(นั่งแท็กซี่ดีไหม — ช่วงเวลาไปทำงานรถติด นั่งรถไฟใต้ดินเถอะ)* |
| 연습 3 | 우리 등산을 할까요? | 비가 **오니까** 영화를 봐요. 어때요? — 좋아요. *(ไปเดินป่ากันไหม — ฝนตกอยู่ ดูหนังกันเถอะ เป็นไง — ดีเลย)* |

1. 다음 주에 시험을 **보니까** 같이 공부해요. *(สัปดาห์หน้ามีสอบ มาเรียนด้วยกันเถอะ)* — กล่องตำรา 300쪽
2. 제 생일**이니까** 꼭 오세요. *(เป็นวันเกิดฉัน มาให้ได้นะ)*
3. 이 책은 **읽었으니까** 다른 책을 빌려 주세요. *(เล่มนี้อ่านแล้ว ช่วยยืมเล่มอื่นให้หน่อย)*
4. 커피가 **뜨거우니까** 조심하세요. *(กาแฟร้อน ระวังด้วย)*
5. 중요한 서류**니까** 버리지 마세요. *(เป็นเอกสารสำคัญ อย่าทิ้งนะ)*
6. 연습 1 (6 ข้อ): 시간이 **없으니까** 택시를 타세요. · 점심에 약속이 **있으니까** 저녁에 만나요. · 친구가 **기다리니까** 빨리 가요. · 길을 **모르니까** 길을 물어보세요. · 우리 집이 **머니까** 기숙사에서 파티를 해요. · 교실이 **더우니까** 에어컨을 켜세요. *(ไม่มีเวลา นั่งแท็กซี่เถอะ · กลางวันมีนัด เจอกันเย็นนะ · เพื่อนรออยู่ รีบไปกัน · ไม่รู้ทาง ลองถามทางดู · บ้านฉันไกล ไปจัดปาร์ตี้ที่หอเถอะ · ห้องเรียนร้อน เปิดแอร์ซิ)*
7. 연습 2 (จับคู่เหตุ–คำสั่ง จากสองกล่อง): 비가 **오니까** 우산을 준비하세요. · 명동에 사람이 **많으니까** 동대문시장으로 가요. · 내일 손님이 **올 거니까** 방을 청소하세요. · 한국 노래를 **아니까** 한국 노래를 부르세요. · 다리가 **아프니까** 의자에 앉을까요? · 감기에 **걸렸으니까** 아이스크림을 먹지 마세요. *(ฝนตกเตรียมร่ม · เมียงดงคนเยอะ ไปตลาดตงแดมุนกัน · พรุ่งนี้แขกมา ทำความสะอาดห้อง · รู้เพลงเกาหลี ร้องเลย · ขาเจ็บ นั่งเก้าอี้ไหม · เป็นหวัด อย่ากินไอศกรีม — ตัวอย่างแรกเป็นของตำรา ที่เหลือจับคู่ตามความหมาย)*
8. 대화 30-1: 4시에 문을 **닫으니까** 빨리 가세요. *(ปิด 4 โมง รีบไปเถอะ)*
9. 읽기 30-2: 오후보다 저녁에 경치가 더 **좋으니까** 저녁에 가세요. *(เย็นวิวสวยกว่าช่วงบ่าย ไปตอนเย็นนะ — เปรียบเทียบ -보다 ข้อ 41)*
10. 대화 31-1: 안국동에서 내리세요. 안내 방송을 **하니까** 잘 들으세요. *(ลงที่อันกุกดง มีประกาศเสียงตามสาย ฟังดี ๆ นะ)* · 활동 31: 그런데 버스가 **싸니까** 버스로 가세요. *(แต่รถเมล์ถูก ไปรถเมล์เถอะ)* · 읽기 31-2: 아래 초대장을 같이 **보내니까** 보고 오세요. *(ส่งบัตรเชิญมาด้วย ดูแล้วมานะ)*

### ⚠️ จุดสับสน
#### -(으)니까 vs -아/어서 (ข้อ 48)
| | **-(으)니까** | **-아/어서** |
|:---|:---|:---|
| ประโยคหลัง = คำสั่ง · ชวน · ห้าม | ✓ | ✗ |
| ใส่ -았/었- ในประโยคหน้า | ✓ 읽었으니까 | ✗ |
| ใส่ -겠- / -(으)ㄹ 거 ในประโยคหน้า | ✓ 올 거니까 | ✗ |
| ตอบ 왜? | ไม่ใช่รูปมาตรฐาน | ✓ |
| ขอโทษ/ขอบคุณ | ✗ | ✓ 늦어서 죄송합니다 |
| น้ำเสียง | "ฉันบอกเหตุผลให้คุณทำตาม" | "เหตุเกิด ผลเลยเป็นอย่างนั้น" |

- ✓ 비가 **오니까** 우산을 가지고 **가세요** / ✗ 비가 와서 우산을 가지고 가세요 *(ตำรา 288쪽: ประโยคหลังของ -아/어서 ห้ามเป็นคำสั่ง/ชวน)*
- ✓ 시간이 **없으니까** 택시를 **타요** *(ชวน/แนะนำให้ทำ)* ↔ ✓ 시간이 **없어서** 택시를 **탔어요** *(เล่าเหตุผลที่ทำไปแล้ว)*
- กฎจำง่าย: ท้ายประโยคเป็น **-(으)세요 / -(으)ㅂ시다 / -(으)ㄹ까요? / 지 마세요** → **-(으)니까** · ท้ายเป็นเล่าเรื่อง/ถามเหตุผล/ขอโทษ/ขอบคุณ → **-아/어서**

#### กับดักที่เจอบ่อย
- **ลืม 으 หลังตัวสะกด:** ✗ 없니까 · ✗ 읽니까 · ✗ 앉니까 · ✗ 좋니까 → ✓ **없으니까 · 읽으니까 · 앉으니까 · 좋으니까** *(ข้อผิดซ้ำ: 읽세요 · 받십니다 · 씻러 — ลืม 으 หลัง 받침ทุกครั้ง)*
- **ㄹ-ราก:** ✗ 멀으니까 · ✗ 만들으니까 → ✓ **머니까 · 만드니까** *(ผู้เรียนเคยเขียน 만들으세요 · 만들습니다 ผิด — ㄹ หลุดก่อน ㄴ/ㅂ/ㅅ)*
- **ㅂ-ราก:** ✗ 덥으니까 · ✗ 뜨겁으니까 → ✓ **더우니까 · 뜨거우니까** (ข้อ 37)
- **ㄷ-ราก:** ✗ 듣으니까 → ✓ **들으니까** · ✗ 걷으니까 → ✓ **걸으니까** (ข้อ 51) · ✓ 닫으니까 *(닫다 ปกติ ไม่เปลี่ยน)*
- **르-ราก ไม่เปลี่ยนก่อน 니까:** ✓ **모르니까** (길을 모르니까 물어보세요) / ✗ 몰라니까 · ✗ 몰르니까 *(เทียบ -아/어서: 몰라서 — ข้อ 54)*
- **นาม:** ✗ 생일니까 → ✓ **생일이니까** · ✗ 서류이니까 → ✓ **서류니까** · ปฏิเสธ: ✓ 학생이 **아니니까** *(ไม่ใช่นักเรียน เพราะ…)*
- **-ㅂ니까 (ถาม ข้อ 21) ≠ -(으)니까 (เหตุผล):** 먹습니까? *(กินไหม — จบประโยค)* ≠ 먹으니까 *(เพราะกิน — ต่อประโยคต่อไป)* · ผู้เรียนเคยปน 니다/니까 เวลาแปลงประโยค — ดูเครื่องหมายท้ายประโยคก่อน
- **ตอบสั้นลงท้าย 요 (เสริม — ตำรายังไม่สอน):** 왜 서둘러요? — 시간이 없으니까요. *(ทำไมรีบ — ก็ไม่มีเวลานี่นา)* · เป็นน้ำเสียง "ก็เพราะ…ไง" ในภาษาพูด

> [!TIP]
> **-(으)니까 = เหตุผลที่ "คุณ" ควรทำตาม (สั่ง/ชวน/ห้าม) · -아/어서 = เหตุผลธรรมดา · ตัวสะกด→으니까 สระ→니까 · ㄹ ตก · ㅂ→우 · N이니까/N니까**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- ยังไม่มีข้อสอบจริงที่ครูตรวจแล้วเกี่ยวกับ -(으)니까 — 30과 อยู่ใน **복습시험④ (11/18, 30–37과)** และ **기말**
- **ตำราให้ฝึก:** 연습 1 (ผัน 6 ข้อ) · 연습 2 (จับคู่เหตุ–คำสั่ง) · 연습 3 (ชวนคุย: 뭘 할까요? / 저는 다른 것을 하고 싶어요 / 왜요?)
- **เฉลยภาคผนวก 읽기 30:** 나. 1 ○ 2 ✗ 3 ✗ — ข้อ 3 "N서울타워는 저녁보다 오후에 가는 것이 좋아요" ✗ เพราะบทอ่านบอก 오후보다 저녁에 경치가 더 좋으니까 저녁에 가세요 (ระวังสลับ 보다 ข้อ 41)
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ:** ลืม 으 หลังตัวสะกด · ㄹ-ราก (만들으세요) · ปน 니다/니까 · ตอบผิดคำถาม (언제 → กิจกรรม)
- **คาดการณ์รูปแบบข้อสอบ** (จากรูปแบบ 복습시험①②; เป็นการคาด)
  1. **ผันตาราง:** 없다 · 덥다 · 멀다 · 막히다 · 생일(이다) · 모르다 → 없으니까 · 더우니까 · 머니까 · 막히니까 · 생일이니까 · 모르니까
  2. **เลือก -아/어서 หรือ -(으)니까:** 비가 (와서/오니까) 우산을 가지고 가세요 → 오니까 · 늦어서/늦으니까 죄송합니다 → 늦어서
  3. **ตอบคำถามด้วยไวยากรณ์ที่กำหนด:** 택시를 탈까요? (길이 막히다 / 지하철) → 길이 막히니까 지하철을 타세요 · 같이 등산을 할까요? (비가 오다 / 영화를 보다)
  4. **อ่าน 가/나 เว้นคำตอบ:** 30-1 (카오루: 이 근처에 은행이 있습니까? — 4시에 문을 닫으니까 빨리 가세요) · 30-2 (N서울타워 · 오후보다 저녁에 경치가 더 좋으니까 저녁에 가세요)
