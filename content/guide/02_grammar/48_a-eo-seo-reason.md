## 48. -아/어/여서 (เหตุผล: "เพราะ… จึง…")
ต่อท้ายรากของ**กริยา · คำคุณศัพท์ · N이다** บอก**เหตุผลหรือสาเหตุตามข้อเท็จจริง**ของประโยคหลัง ("เพราะฝนตก จึงยกเลิกทริป") — ประโยคหน้า = เหตุ · ประโยคหลัง = ผล
สอนในบท 29 (교과서 288쪽 준비 2 + 289쪽 연습) — ตำราเรียก -아/어/여서¹ (ความหมาย "ลำดับการกระทำ" = -아/어/여서² บท 32 = ข้อ 53) · ต่อยอดจาก ข้อ 06 (กฎเลือก 아/어/해 ชุดเดียวกัน) · ข้อ 18 (คุณศัพท์) · ข้อ 02 (이다) · ข้อ 08 / 16 (ปฏิเสธ)
ใช้ต่อใน ข้อ 50 (-(으)니까 ↔ ข้อนี้) · ข้อ 53 (-아/어서 ลำดับ) · ข้อ 46 (…아/어서 …할 수 없어요) · ข้อ 54 (몰라서 · 빨라서)

### 📌 รูปแบบและเงื่อนไข
ตัด 다 ทิ้ง ดู**สระของพยางค์สุดท้าย**ของราก — กฎเดียวกับ -아/어요 (ข้อ 06) แค่เปลี่ยน 요 เป็น 서

| รากศัพท์ลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| สระ ㅏ / ㅗ | **-아서** | 오다 → **와서** · 좋다 → **좋아서** · 많다 → **많아서** · 비싸다 → **비싸서** *(มา · ดี · เยอะ · แพง)* |
| สระอื่น | **-어서** | 없다 → **없어서** · 늦다 → **늦어서** · 마시다 → **마셔서** · 먹다 → **먹어서** *(ไม่มี · สาย · ดื่ม · กิน)* |
| **하다** | **-해서** (-여서 → 해서) | 친절하다 → **친절해서** · 출근하다 → **출근해서** *(ใจดี · ไปทำงาน)* |
| ลงท้าย **ㅡ** | ตัด ㅡ ก่อน | 아프다 → **아파서** · 바쁘다 → **바빠서** *(เจ็บ · ยุ่ง)* |
| **ㅂ 불규칙** (ข้อ 37) | ㅂ → 워 | 춥다 → **추워서** · 어렵다 → **어려워서** *(หนาว · ยาก)* |
| **นาม** (이다) | ตัวสะกด → **-이어서** · สระ → **-여서** | 고등학생**이어서** · 친구**여서** · 친구 생일**이어서** *(เพราะเป็นนักเรียนมัธยม · เพราะเป็นเพื่อน · เพราะเป็นวันเกิดเพื่อน)* |

- **ตำรา 288쪽:** ต่อหลังรากกริยา/คำคุณศัพท์ บอกว่าเหตุการณ์/สภาพก่อนหน้าเป็นเหตุผลตามข้อเท็จจริงของประโยคหลัง · ต่อหลังนามได้ — ตัวสะกด → -이어서 · สระ → -여서
- **ข้อห้าม 3 ข้อ (ตำรา 288쪽):** **(1)** ไม่ใส่ -았/었/였- ในประโยคหน้า แม้เหตุผลเป็นอดีต — เวลาไปอยู่ท้ายประโยคหลัง · **(2)** ไม่ใส่ -겠- (ตั้งใจ/คาดเดา) ในประโยคหน้า · **(3)** ประโยคหลัง**ห้ามเป็นคำสั่ง/ชวน** (-(으)세요 · -(으)ㅂ시다 · -(으)ㄹ까요?) → ไปใช้ **-(으)니까** (ข้อ 50)
- ถาม **왜** (ทำไม) → ตอบ **เหตุผล + -아/어서 + ผล:** 왜 택시를 타요? — **늦어서** 택시를 타요. *(ทำไมนั่งแท็กซี่ — เพราะสายเลยนั่งแท็กซี่)*
- **그래서** *(เพราะฉะนั้น/เลยทำให้)* = 그렇게 해서 — คำเชื่อมเริ่มประโยคใหม่ที่ตำรา 28과 ใช้ก่อนสอน -아/어서: 저는 단풍이 아름다운 가을을 좋아해요. **그래서** 가을에 등산을 자주 해요. · 내일 시험이 있어요. **그래서** 갈 수 없어요. — เหตุ + 그래서 + ผล = เหตุ-아/어서 + ผล

### 📖 ตัวอย่างและการใช้
| | คำถาม | คำตอบ |
|:---|:---|:---|
| 준비 2 | 지훈 씨, 왜 가방을 안 샀어요? | 가방이 너무 **비싸서** 안 샀어요. *(จีฮุน ทำไมไม่ซื้อกระเป๋า — เพราะกระเป๋าแพงเกินไปเลยไม่ซื้อ)* |
| 연습 2 | 왜 택시를 타요? | **늦어서** 택시를 타요. *(ทำไมนั่งแท็กซี่ — เพราะสาย)* |

1. 비가 **와서** 여행을 취소했어요. *(เพราะฝนตกจึงยกเลิกการเดินทาง)* — กล่องตำรา 288쪽
2. 시간이 **없어서** 못 가겠어요. *(ไม่มีเวลา เลยไปไม่ได้ — 겠 อยู่ท้ายประโยคหลังได้)*
3. 그 사람은 **친절해서** 누구나 좋아해요. *(เขาใจดี ใคร ๆ ก็ชอบ)*
4. 저는 **고등학생이어서** 술을 마실 수 없어요. *(ฉันเป็นนักเรียนมัธยม จึงดื่มเหล้าไม่ได้ — ข้อ 46)*
5. 연습 1 (6 ข้อ): 날씨가 **추워서** 옷을 많이 입었어요. · 비가 많이 **와서** 우산을 가지고 가요. · 밤늦게 전화를 **해서** 죄송합니다. · 어제 술을 많이 **마셔서** 머리가 아파요. · 아침에 늦게 **일어나서** 택시를 탔어요. · 내일 시험이 **있어서** 도서관에서 공부를 할 거예요. *(อากาศหนาวเลยใส่เสื้อหลายชั้น · ฝนตกหนักเลยพกร่ม · ขอโทษที่โทรมาดึก · เมื่อวานดื่มเหล้าเยอะเลยปวดหัว · ตื่นสายเลยนั่งแท็กซี่ · พรุ่งนี้มีสอบเลยจะไปอ่านหนังสือที่ห้องสมุด)*
6. 연습 2 (ตารางจับคู่เหตุ–ผล; ตัวอย่างที่ตำราไม่ได้ให้คำตอบ ประโยคด้านล่างจับคู่ให้สมเหตุสมผล): 방이 **작아서** 이사를 해요. · 친구 생일**이어서** 케이크를 만들어요. · 숙제가 **많아서** 늦게까지 공부를 해요. · 비가 **와서** 빨래를 안 해요. · **무서워서** 공포 영화를 안 봐요. *(ห้องเล็กเลยย้ายบ้าน · เป็นวันเกิดเพื่อนเลยทำเค้ก · การบ้านเยอะเลยเรียนถึงดึก · ฝนตกเลยไม่ซักผ้า · กลัวเลยไม่ดูหนังผี)*
7. 대화 29-1: 날씨가 **추워서** 바다에 가지 않고 영화를 봤어요. *(อากาศหนาวเลยไม่ไปทะเลแต่ไปดูหนัง)* · 주말에 본 영화가 **재미있어서** 괜찮았어요. *(หนังที่ดูสนุกเลยไม่เป็นไร)*
8. 읽기 29-2: 알렉세이 씨는 수영을 하고 싶었지만 수영복이 **없어서** 수영을 할 수 없었어요. *(อเล็กเซย์อยากว่ายน้ำ แต่ไม่มีชุดว่ายน้ำเลยว่ายไม่ได้ — เหตุผลเป็นอดีตแต่ใช้ 없어서 ไม่ใช่ ✗ 없었어서)*
9. 연습 3 (คุยกับเพื่อน): 취미가 뭐예요? **왜** 그것을 해요? · 자주 가는 식당이 있어요? **왜** 거기에 가요? · 어디에서 쇼핑을 해요? **왜** 거기에서 쇼핑을 해요? · 날씨가 좋아요? 어디에 가요? **왜** 거기에 가요? · 좋아하는 배우/가수가 있어요? **왜** 좋아해요? *(งานอดิเรกคืออะไร ทำไมทำสิ่งนั้น · มีร้านอาหารที่ไปบ่อยไหม ทำไมไปที่นั่น · ซื้อของที่ไหน ทำไมซื้อที่นั่น · อากาศดีไหม ไปที่ไหน ทำไมไปที่นั่น · มีดารา/นักร้องที่ชอบไหม ทำไมชอบ)*

### ⚠️ จุดสับสน
#### -아/어서 (เหตุผล) vs -(으)니까 (ข้อ 50)
| | **-아/어서** | **-(으)니까** |
|:---|:---|:---|
| ประโยคหลังเป็นคำสั่ง/ชวน | ✗ | ✓ |
| ใส่ -았/었- ในประโยคหน้า | ✗ | ✓ (읽었으니까) |
| ใส่ -겠- ในประโยคหน้า | ✗ | ✓ |
| ใช้ตอบ 왜? | ✓ (รูปตอบมาตรฐาน) | ไม่ใช่รูปตอบ 왜 มาตรฐาน |
| น้ำเสียง | เหตุผลตามธรรมชาติ/ข้อเท็จจริง | ผู้พูดยกเหตุผลเพื่อให้ผู้ฟังทำตาม |

- ✓ 비가 와서 우산을 가지고 가요. *(ฝนตกเลยพกร่ม — บอกเล่า)* / ✗ 비가 와서 우산을 가지고 **가세요** → ✓ 비가 오니까 우산을 준비하세요. *(ฝนตก เตรียมร่มนะ — สั่ง)*
- ขอโทษ/ขอบคุณต้องใช้ -아/어서 (ผลเป็นความรู้สึก ไม่ใช่คำสั่ง): 늦어서 **죄송합니다** · 밤늦게 전화를 해서 **죄송합니다** · ✗ 늦으니까 죄송합니다

#### -아/어서 (เหตุผล ข้อ 48) vs -아/어서 (ลำดับ ข้อ 53) — รูปเดียวกัน
| | เหตุผล (ข้อ 48) | ลำดับ (ข้อ 53) |
|:---|:---|:---|
| ประโยคหน้า | คุณศัพท์ · 있다/없다 · 이다 · กริยา | กริยา (เคลื่อนที่ · ท่าทาง · สร้าง) |
| ประธาน | ต่างกันได้ | **ต้องเหมือนกัน** |
| ตามด้วยคำสั่ง/ชวน | ✗ | ✓ (내려서 갈아타세요) |
| ตัวอย่าง | 늦어서 택시를 탔어요 *(สายเลยนั่งแท็กซี่)* | 내려서 갈아탔어요 *(ลงแล้วเปลี่ยนสาย)* |

#### กับดักที่เจอบ่อย
- **ใส่กาลซ้ำ:** ✗ 비가 왔어서 → ✓ 비가 **와서** 취소했어요 · ✗ 늦었어서 → ✓ 늦어서 택시를 **탔어요** *(กาลอยู่ท้ายประโยคหลังตัวเดียว)*
- **เลือกสระผิด (ㅏ-ราก + 어):** ✗ 많어서 · ✗ 좋어서 → ✓ **많아서 · 좋아서** *(ครูไฮไลต์ 살어요 → 살아요 · 받었어요 → 받았어요 — ท่อง "ㅏ/ㅗ = 아")*
- **ㅡ-ตก:** ✗ 아프어서 · ✗ 바쁘어서 → ✓ **아파서 · 바빠서**
- **ㅂ-ราก:** ✗ 춥어서 · ✗ 무섭어서 → ✓ **추워서 · 무서워서**
- **N이어서:** ✗ 고등학생여서 → ✓ **고등학생이어서** *(เหมือนข้อผิดที่เคยเจอ ✗ 학생였어요 → ✓ 학생이었어요 — ตัวสะกด → 이)* · ✓ 친구여서 *(สระ → 여서)*
- **ผลที่ผิดคำถาม:** ถาม 왜 ต้องตอบเหตุผล: ✗ 왜 택시를 타요? — 택시를 타요. → ✓ **늦어서** 택시를 타요. *(ข้อผิดเดิม: ตอบไม่ตรงคำถาม)*
- **ลำดับประโยค:** เหตุมาก่อนผลเสมอ: ✓ 시험이 있어서 갈 수 없어요 / ✗ 갈 수 없어요 시험이 있어서 *(ไทยมักเอาผลขึ้นก่อน "ไปไม่ได้ เพราะสอบ")*
- **ประธานต่างกันได้:** ✓ **비가** 와서 **저는** 여행을 취소했어요 *(เหตุและผลคนละประธานได้)*
- **못 / 수 없다:** ✓ 시간이 없어서 못 가요 = ✓ 시간이 없어서 갈 수 없어요 (ข้อ 46)

> [!TIP]
> **เหตุ-아/어서 + ผล · ไม่ใส่ -았/-겠 ในเหตุ · ผลห้ามเป็นคำสั่ง/ชวน (ใช้ -(으)니까) · ㅏ/ㅗ=아서 อื่น=어서 하다=해서 · N=이어서/여서**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- ยังไม่มีข้อสอบจริงที่ครูตรวจแล้วเกี่ยวกับ -아/어서 (เหตุผล) — 29과 อยู่ใน **복습시험③ (11/6, 22–29과)** และ **기말**
- **ตำราให้ฝึกพูด:** 연습 2 ตาราง 6 คู่เหตุ–ผล + 연습 3 ถามเหตุผล 5 ข้อ — ครูมักยกรูป "ถาม–ตอบด้วยไวยากรณ์ที่กำหนด" มาออก
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ:** ㅏ-ราก + 어 (살어요 · 받었어요 → 아) · นามอดีต 학생였어요 (→ 이었) · ตอบไม่ตรงคำถาม (언제 → 가족을…) · ㅡ-ตก เขียนถูกอยู่แล้ว (바빴어요 · 컸어요)
- **เฉลยภาคผนวก 읽기 29:** 가. 3 수영복이 없어서 수영을 하지 않았습니다. (= ข้อความเหตุผลของข้อ 3 ใช้ -아/어서)
- **คาดการณ์รูปแบบข้อสอบ** (เป็นการคาด)
  1. **ต่อประโยคสองประโยค:** 날씨가 추워요. 옷을 많이 입었어요. → 날씨가 추워서 옷을 많이 입었어요. · 친구 생일이에요. 케이크를 만들어요. → 친구 생일이어서 케이크를 만들어요.
  2. **ตอบ 왜 ด้วยไวยากรณ์ที่กำหนด:** 왜 택시를 타요? (늦다) · 왜 가방을 안 샀어요? (비싸다) · 왜 수영을 하지 않았어요? (수영복이 없다)
  3. **ผันตาราง:** 춥다 · 아프다 · 바쁘다 · 일어나다 · 친절하다 · 학생 → 추워서 · 아파서 · 바빠서 · 일어나서 · 친절해서 · 학생이어서
  4. **อ่าน 가/나 เว้นคำตอบ:** 29-1 (바트: 날씨가 추워서 바다에 가지 않고 영화를 봤어요 / 주말에 본 영화가 재미있어서 괜찮았어요) และ 29-2 (수영복이 없어서 수영을 할 수 없었어요)
