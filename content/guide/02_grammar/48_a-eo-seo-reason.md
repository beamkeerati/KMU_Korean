## 48. -아/어/여서 (เหตุผล: "เพราะ… จึง…")

> [!INTRO] ข้อนี้คืออะไร
> -아/어/여서 ต่อท้ายรากของ**กริยา คำคุณศัพท์ และ N이다** เพื่อบอก**เหตุผลหรือสาเหตุตามข้อเท็จจริง**ของประโยคหลัง เช่น "เพราะฝนตก จึงยกเลิกทริป" ประโยคหน้าคือเหตุ ประโยคหลังคือผล
>
> สอนในบท 29 (ตำราหน้า 288 준비 2 และหน้า 289 연습) ตำราเรียกรูปนี้ว่า -아/어/여서¹ ส่วนความหมาย "ลำดับการกระทำ" คือ -아/어/여서² ในบท 32 (ข้อ 53) ต่อยอดจากข้อ 06 (กฎเลือก 아/어/해 ชุดเดียวกัน) ข้อ 18 (คำคุณศัพท์) ข้อ 02 (이다) และข้อ 08 / 16 (ปฏิเสธ)
>
> ไปใช้ต่อในข้อ 50 (-(으)니까 ↔ ข้อนี้) ข้อ 53 (-아/어서 ลำดับ) ข้อ 46 (…아/어서 …할 수 없어요) และข้อ 54 (몰라서 · 빨라서)

### 📌 รูปแบบและเงื่อนไข

ให้ตัด 다 ออก แล้วดู**สระของพยางค์สุดท้าย**ของราก กฎนี้เหมือนกับการผัน -아/어요 (ข้อ 06) ทุกประการ เพียงเปลี่ยน 요 เป็น 서

| รากศัพท์ลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| สระ ㅏ / ㅗ | **-아서** | 오다 → **와서** · 좋다 → **좋아서** · 비싸다 → **비싸서** |
| สระอื่น | **-어서** | 없다 → **없어서** · 늦다 → **늦어서** · 마시다 → **마셔서** |
| **하다** | **-해서** (-여서 → 해서) | 친절하다 → **친절해서** · 출근하다 → **출근해서** |
| ลงท้าย **ㅡ** | ตัด ㅡ ก่อน | 아프다 → **아파서** · 바쁘다 → **바빠서** |
| **ㅂ 불규칙** (ข้อ 37) | ㅂ → 워 | 춥다 → **추워서** · 어렵다 → **어려워서** |
| **นาม** (이다) | ตัวสะกด → **-이어서** · สระ → **-여서** | 고등학생**이어서** · 친구**여서** |

#### ตารางผันที่ควรจำ (ตำรา 29과)

ตารางนี้รวมคำที่ตำราใช้ทั้งหมดในข้อนี้ จัดตามกฎข้างบน ช่อง "ความหมาย" แปลเป็นรูป "เพราะ…"

| 기본형 | -아/어/여서 | ความหมาย | กฎที่ใช้ |
|:---|:---|:---|:---|
| 오다 | **와서** | เพราะมา | ㅏ/ㅗ → 아서 |
| 좋다 | **좋아서** | เพราะดี | ㅏ/ㅗ → 아서 |
| 많다 | **많아서** | เพราะเยอะ | ㅏ/ㅗ → 아서 |
| 비싸다 | **비싸서** | เพราะแพง | ㅏ/ㅗ → 아서 |
| 없다 | **없어서** | เพราะไม่มี | สระอื่น → 어서 |
| 늦다 | **늦어서** | เพราะสาย | สระอื่น → 어서 |
| 마시다 | **마셔서** | เพราะดื่ม | สระอื่น → 어서 |
| 먹다 | **먹어서** | เพราะกิน | สระอื่น → 어서 |
| 친절하다 | **친절해서** | เพราะใจดี | 하다 → 해서 |
| 출근하다 | **출근해서** | เพราะไปทำงาน | 하다 → 해서 |
| 아프다 | **아파서** | เพราะเจ็บ | ㅡ ตก |
| 바쁘다 | **바빠서** | เพราะยุ่ง | ㅡ ตก |
| 춥다 | **추워서** | เพราะหนาว | ㅂ ไม่ปกติ |
| 어렵다 | **어려워서** | เพราะยาก | ㅂ ไม่ปกติ |
| 고등학생 | **고등학생이어서** | เพราะเป็นนักเรียนมัธยม | นาม + ตัวสะกด |
| 친구 | **친구여서** | เพราะเป็นเพื่อน | นาม + สระ |
| 친구 생일 | **친구 생일이어서** | เพราะเป็นวันเกิดเพื่อน | นาม + ตัวสะกด |

#### ตำราหน้า 288 และข้อห้าม 3 ข้อ

ตำราอธิบายว่า -아/어/여서 เชื่อมเหตุการณ์หรือสภาพก่อนหน้าที่เป็นเหตุผลตามข้อเท็จจริงของประโยคหลัง ส่วนข้อห้ามสามข้อข้างล่างเป็นจุดที่ข้อสอบชอบจับ

- **ตำรา 288쪽:** ต่อหลังรากกริยา/คำคุณศัพท์ บอกว่าเหตุการณ์/สภาพก่อนหน้าเป็นเหตุผลตามข้อเท็จจริงของประโยคหลัง ต่อหลังนามได้ — ตัวสะกด → -이어서 · สระ → -여서
- **ข้อห้าม 3 ข้อ (ตำรา 288쪽):**
  - **(1)** ไม่ใส่ -았/었/였- ในประโยคหน้า แม้เหตุผลเป็นอดีต — กาลไปอยู่ท้ายประโยคหลัง
  - **(2)** ไม่ใส่ -겠- (ตั้งใจ/คาดเดา) ในประโยคหน้า
  - **(3)** ประโยคหลัง**ห้ามเป็นคำสั่ง/ชวน** (-(으)세요 · -(으)ㅂ시다 · -(으)ㄹ까요?) → ไปใช้ **-(으)니까** (ข้อ 50)

#### ถาม 왜 แล้วตอบด้วย -아/어서

คำถาม 왜 (ทำไม) เป็นสถานการณ์ที่ใช้ -아/어서 ตอบได้ตรงที่สุด

- ถาม **왜** (ทำไม) → ตอบ **เหตุผล + -아/어서 + ผล**
  - 왜 택시를 타요? — **늦어서** 택시를 타요. *(ทำไมนั่งแท็กซี่ — เพราะสายเลยนั่งแท็กซี่)*

#### 그래서 (เพราะฉะนั้น)

คำเชื่อม 그래서 ใช้เริ่มประโยคใหม่ ตำราบท 28 ใช้ก่อนที่จะสอน -아/어서

- **그래서** *(เพราะฉะนั้น/เลยทำให้)* = 그렇게 해서 — เหตุ + 그래서 + ผล เท่ากับ เหตุ-아/어서 + ผล
  - 저는 단풍이 아름다운 가을을 좋아해요. **그래서** 가을에 등산을 자주 해요. *(ฉันชอบฤดูใบไม้ร่วงที่ใบไม้เปลี่ยนสีสวย เพราะฉะนั้นฤดูใบไม้ร่วงจึงไปเดินป่าบ่อย)*
  - 내일 시험이 있어요. **그래서** 갈 수 없어요. *(พรุ่งนี้มีสอบ เพราะฉะนั้นไปไม่ได้)*

#### สูตรและวิธีทำ: -아/어/여서 เหตุผล (แบบกระดานครู)

-아/어/여서 เหตุผลผันด้วยกฎ 아/어 ชุดเดียวกับ -아/어요 เพียงเปลี่ยน 요 เป็น 서 และรากต้องเป็นรากเปล่า ๆ ที่ยังไม่มีตัวบอกกาลใด ๆ ติดอยู่

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | สระท้ายรากเป็น ㅏ ㅗ หรือเป็นสระอื่น | ㅏ ㅗ เลือก **아서** · สระอื่นเลือก **어서** | กฎเดียวกับ -아/어요 (✗ 좋어서 · ✗ 살어서) |
| **กฎ 2** | รากพิเศษ: 하다 · ㅡ · ㅂ 불규칙 | 하 → **해서** · ㅡ ตกก่อน แล้วดูสระหน้า ㅡ · ㅂ → **워서** (돕다 · 곱다 → **와서**) | พยางค์ต้องรวมกับ 아/어 ให้เสร็จก่อนต่อ 서 |
| **กฎ 3** | นาม + 이다 | นามมีตัวสะกดต่อ **이어서** · นามไม่มีตัวสะกดต่อ **여서** | 이다 ผันแบบเดียวกับรากอื่น (✗ 고등학생여서) |
| **กฎ 4** | ก่อน 서 | **ห้ามใส่** 았/었 และ 겠 ประโยคหลังห้ามเป็นคำสั่ง · ชวน | กาลไปอยู่ท้ายประโยคหลังเท่านั้น (✗ 비가 왔어서) |

ลำดับทำคือ ① ตัดตัวบอกกาลออกให้เหลือรากเปล่า ② เลือก 아 / 어 / 여 ตามสระท้ายราก แล้วรวมเสียง (ㅡ ตก · ㅂ → 워 · 하 → 해) ③ ต่อ 서 ตารางนี้แสดงทุกขั้นกับคำที่ตำราใช้

| ราก + 서 | ① เลือก 아/어/여 | ② รวมเสียง | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 좋 + 서 | ㅗ → 아 | 좋 + 아 → 좋아 | **좋아서** | ✗ 좋어서 |
| 오 + 서 | ㅗ → 아 | 오 + 아 → 와 | **와서** | ✗ 왔어서 ใส่กาลซ้ำ |
| 비싸 + 서 | ㅏ → 아 | 비싸 + 아 → 비싸 | **비싸서** | 아 รวมกับ ㅏ |
| 없 + 서 | ㅓ → 어 | 없 + 어 → 없어 | **없어서** | สระอื่นใช้ 어 |
| 마시 + 서 | ㅣ → 어 | 시 + 어 → 셔 | **마셔서** | ㅣ + ㅓ รวมเป็น ㅕ |
| 배우 + 서 | ㅜ → 어 | 우 + 어 → 워 | **배워서** | ㅜ + ㅓ รวมเป็น ㅝ |
| 친절하 + 서 | 하 → 여 | 하 + 여 → 해 | **친절해서** | ✗ 친절하서 |
| 아프 + 서 | ㅡ ตก ดู 아 → 아 | 프 → ㅍ + 아 → 파 | **아파서** | ✗ 아프어서 · เทียบ 바빠서 |
| 살 + 서 | ㅏ → 아 | 살 + 아 → 살아 | **살아서** | ✗ 살어서 · ㄹ อยู่ครบ |
| 춥 + 서 | ㅂ 불규칙 → 어 | ㅂ ตก + 우 + 어 → 워 | **추워서** | ✗ 춥어서 |
| 돕 + 서 | ㅂ ข้อยกเว้น → 아 | ㅂ → 오 + 아 → 와 | **도와서** | เหมือน 도와요 (ข้อ 37) |
| 입 + 서 | ㅣ → 어 | 입 + 어 → 입어 | **입어서** | ㅂ ปกติ ไม่เปลี่ยน |
| 고등학생 + 서 | นามมีตัวสะกด → 이 | 이 + 어 → 이어 | **고등학생이어서** | ✗ 고등학생여서 เหมือน ✗ 학생였어요 |
| 친구 + 서 | นามไม่มีตัวสะกด | 이 + 어 → 여 | **친구여서** | ตำรา 288쪽 |

> [!TIP] วิธีจำสั้น ๆ
> ตัดกาลออก เหลือรากเปล่า แล้วผันเหมือน -아/어요 ก่อน (ㅏ ㅗ = 아 · ที่เหลือ = 어 · 하 = 해) จากนั้นต่อ 서 เป็นขั้นสุดท้าย กาลทั้งหมดไปอยู่ท้ายประโยคหลัง

#### ผันคำเดียวครบทุกคำต่อ

ตารางนี้ผันคำเดียวกันกับคำต่อ 3 ตัวที่ใช้กฎ 아/어 ชุดเดียวกัน แล้วเทียบกับ -(으)니까 (ข้อ 50) ที่ใช้กฎ (으) ตามตัวสะกดแทน

| 기본형 | -아/어요 | -았/었어요 | -아/어서 | -(으)니까 |
|:---|:---|:---|:---|:---|
| 좋다 | **좋아**요 | **좋았**어요 | **좋아**서 | 좋**으**니까 |
| 아프다 | **아파**요 | **아팠**어요 | **아파**서 | 아프니까 |
| 춥다 | **추워**요 | **추웠**어요 | **추워**서 | **추우**니까 |
| 살다 | **살아**요 | **살았**어요 | **살아**서 | **사**니까 |
| 친절하다 | **친절해**요 | **친절했**어요 | **친절해**서 | 친절하니까 |

#### รูปผิด / รูปถูก

ตารางนี้รวมรูปผิดของ -아/어서 เหตุผล พร้อมขั้นที่ทำพลาด ข้อ 살어서 และ 고등학생여서 เป็นตระกูลเดียวกับที่ผู้เรียนเคยเขียนผิดจริง คือ 살어요 และ 학생였어요

| รูปผิด | รูปถูก | ขั้นที่พลาด |
|:---|:---|:---|
| ✗ 비가 왔어서 | ✓ 비가 **와서** | ① ตัดกาลออกก่อน (กฎ 4) |
| ✗ 늦었어서 | ✓ **늦어서** | ① ตัดกาลออกก่อน (กฎ 4) |
| ✗ 살어서 | ✓ **살아서** | ② ㅏ ต้องเลือก 아 (กฎ 1) |
| ✗ 고등학생여서 | ✓ **고등학생이어서** | ② นามมีตัวสะกดต้องมี 이 (กฎ 3) |
| ✗ 늦으니까 죄송합니다 | ✓ **늦어서** 죄송합니다 | ขอโทษ · ขอบคุณใช้ 서 ไม่ใช่ 니까 |

### 📖 ตัวอย่างและการใช้

ตัวอย่างเรียงตามลำดับในตำราบท 29 ตั้งแต่กล่อง 288쪽 แบบฝึก 연습 1–3 ไปจนถึงบทสนทนา 29-1 และบทอ่าน 29-2 สังเกตว่าประโยคหลังมักบอกผลหรือความรู้สึก ไม่ใช่คำสั่ง และกาลอยู่ที่ท้ายประโยคหลังตัวเดียว

#### จากตำรา 29과 (หน้า 288–289)

ช่อง ที่มา ที่เป็นขีด — คือประโยคประกอบที่ไม่ได้ระบุว่ามาจากหน้าไหนของตำรา

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 비가 **와서** 여행을 취소했어요. | เพราะฝนตกจึงยกเลิกการเดินทาง | กล่องตำรา 288쪽 |
| 시간이 **없어서** 못 가겠어요. | ไม่มีเวลา เลยไปไม่ได้ (겠 อยู่ท้ายประโยคหลังได้) | — |
| 그 사람은 **친절해서** 누구나 좋아해요. | เขาใจดี ใคร ๆ ก็ชอบ | — |
| 저는 **고등학생이어서** 술을 마실 수 없어요. | ฉันเป็นนักเรียนมัธยม จึงดื่มเหล้าไม่ได้ (ข้อ 46) | — |
| 날씨가 **추워서** 옷을 많이 입었어요. | อากาศหนาวเลยใส่เสื้อหลายชั้น | 연습 1 |
| 비가 많이 **와서** 우산을 가지고 가요. | ฝนตกหนักเลยพกร่ม | 연습 1 |
| 밤늦게 전화를 **해서** 죄송합니다. | ขอโทษที่โทรมาดึก | 연습 1 |
| 어제 술을 많이 **마셔서** 머리가 아파요. | เมื่อวานดื่มเหล้าเยอะเลยปวดหัว | 연습 1 |
| 아침에 늦게 **일어나서** 택시를 탔어요. | ตื่นสายเลยนั่งแท็กซี่ | 연습 1 |
| 내일 시험이 **있어서** 도서관에서 공부를 할 거예요. | พรุ่งนี้มีสอบเลยจะไปอ่านหนังสือที่ห้องสมุด | 연습 1 |
| 방이 **작아서** 이사를 해요. | ห้องเล็กเลยย้ายบ้าน | 연습 2 (จับคู่เอง) |
| 친구 생일**이어서** 케이크를 만들어요. | เป็นวันเกิดเพื่อนเลยทำเค้ก | 연습 2 (จับคู่เอง) |
| 숙제가 **많아서** 늦게까지 공부를 해요. | การบ้านเยอะเลยเรียนถึงดึก | 연습 2 (จับคู่เอง) |
| 비가 **와서** 빨래를 안 해요. | ฝนตกเลยไม่ซักผ้า | 연습 2 (จับคู่เอง) |
| **무서워서** 공포 영화를 안 봐요. | กลัวเลยไม่ดูหนังผี | 연습 2 (จับคู่เอง) |
| 날씨가 **추워서** 바다에 가지 않고 영화를 봤어요. | อากาศหนาวเลยไม่ไปทะเลแต่ไปดูหนัง | 대화 29-1 |
| 주말에 본 영화가 **재미있어서** 괜찮았어요. | หนังที่ดูสนุกเลยไม่เป็นไร | 대화 29-1 |
| 알렉세이 씨는 수영을 하고 싶었지만 수영복이 **없어서** 수영을 할 수 없었어요. | อเล็กเซย์อยากว่ายน้ำ แต่ไม่มีชุดว่ายน้ำเลยว่ายไม่ได้ (เหตุผลเป็นอดีตแต่ใช้ 없어서 ไม่ใช่ ✗ 없었어서) | 읽기 29-2 |
| 취미가 뭐예요? **왜** 그것을 해요? | งานอดิเรกคืออะไร ทำไมทำสิ่งนั้น | 연습 3 (คุยกับเพื่อน) |
| 자주 가는 식당이 있어요? **왜** 거기에 가요? | มีร้านอาหารที่ไปบ่อยไหม ทำไมไปที่นั่น | 연습 3 |
| 어디에서 쇼핑을 해요? **왜** 거기에서 쇼핑을 해요? | ซื้อของที่ไหน ทำไมซื้อที่นั่น | 연습 3 |
| 날씨가 좋아요? 어디에 가요? **왜** 거기에 가요? | อากาศดีไหม ไปที่ไหน ทำไมไปที่นั่น | 연습 3 |
| 좋아하는 배우/가수가 있어요? **왜** 좋아해요? | มีดารา/นักร้องที่ชอบไหม ทำไมชอบ | 연습 3 |

ตาราง 연습 2 ในตำราเป็นการจับคู่เหตุ–ผลที่ไม่ได้เฉลยคำตอบไว้ ประโยคทั้งห้าข้อด้านบนจับคู่ให้สมเหตุสมผลเอง

#### ถาม-ตอบ

คู่ถาม-ตอบสองคู่นี้เป็นรูปมาตรฐานของข้อนี้ คือถาม 왜 แล้วตอบด้วยเหตุผล + -아/어서

| ที่มา | คำถาม | คำตอบ |
|:---|:---|:---|
| 준비 2 | 지훈 씨, 왜 가방을 안 샀어요? | 가방이 너무 **비싸서** 안 샀어요. *(จีฮุน ทำไมไม่ซื้อกระเป๋า — เพราะกระเป๋าแพงเกินไปเลยไม่ซื้อ)* |
| 연습 2 | 왜 택시를 타요? | **늦어서** 택시를 타요. *(ทำไมนั่งแท็กซี่ — เพราะสาย)* |

### ⚠️ จุดสับสน

ความสับสนของข้อนี้มีสองคู่ คือ -아/어서 กับ -(으)니까 ที่แปลว่า "เพราะ" เหมือนกันแต่ใช้ต่างกัน และ -아/어서 สองความหมายที่หน้าตาเหมือนกัน

#### -아/어서 (เหตุผล) vs -(으)니까 (ข้อ 50)

ตารางนี้เทียบเงื่อนไขการใช้ วิธีแยกที่เร็วที่สุดคือดูว่าประโยคหลังเป็นคำสั่งหรือชวนหรือไม่

| | **-아/어서** | **-(으)니까** |
|:---|:---|:---|
| ประโยคหลังเป็นคำสั่ง/ชวน | ✗ | ✓ |
| ใส่ -았/었- ในประโยคหน้า | ✗ | ✓ (읽었으니까) |
| ใส่ -겠- ในประโยคหน้า | ✗ | ✓ |
| ใช้ตอบ 왜? | ✓ (รูปตอบมาตรฐาน) | ไม่ใช่รูปตอบ 왜 มาตรฐาน |
| น้ำเสียง | เหตุผลตามธรรมชาติ/ข้อเท็จจริง | ผู้พูดยกเหตุผลเพื่อให้ผู้ฟังทำตาม |

- **ประโยคหลังเป็นบอกเล่า ใช้ -아/어서:** ✓ 비가 **와서** 우산을 가지고 가요. *(ฝนตกเลยพกร่ม — บอกเล่า)*
- **ประโยคหลังเป็นคำสั่ง ต้องเปลี่ยนเป็น -(으)니까:**
  - ✗ 비가 와서 우산을 가지고 **가세요**
  - ✓ 비가 **오니까** 우산을 준비하세요. *(ฝนตก เตรียมร่มนะ — สั่ง)*
- **ขอโทษ/ขอบคุณต้องใช้ -아/어서** เพราะผลเป็นความรู้สึก ไม่ใช่คำสั่ง
  - ✓ 늦어서 **죄송합니다** *(ขอโทษที่มาสาย)*
  - ✓ 밤늦게 전화를 해서 **죄송합니다** *(ขอโทษที่โทรมาดึก)*
  - ✗ 늦으니까 죄송합니다

#### -아/어서 (เหตุผล ข้อ 48) vs -아/어서 (ลำดับ ข้อ 53) — รูปเดียวกัน

รูป -아/어서 เดียวกันมีสองความหมาย แยกได้จากชนิดของประโยคหน้า ประธาน และการตามด้วยคำสั่ง

| | เหตุผล (ข้อ 48) | ลำดับ (ข้อ 53) |
|:---|:---|:---|
| ประโยคหน้า | คุณศัพท์ · 있다/없다 · 이다 · กริยา | กริยา (เคลื่อนที่ · ท่าทาง · สร้าง) |
| ประธาน | ต่างกันได้ | **ต้องเหมือนกัน** |
| ตามด้วยคำสั่ง/ชวน | ✗ | ✓ (내려서 갈아타세요) |
| ตัวอย่าง | 늦어서 택시를 탔어요 *(สายเลยนั่งแท็กซี่)* | 내려서 갈아탔어요 *(ลงแล้วเปลี่ยนสาย)* |

#### กับดัก

ข้อผิดของข้อนี้ส่วนใหญ่เป็นเรื่องกาล สระ และลำดับประโยค ไล่ดูทีละข้อ

- **ใส่กาลซ้ำ:** กาลอยู่ท้ายประโยคหลังตัวเดียว
  - ✗ 비가 왔어서 → ✓ 비가 **와서** 취소했어요
  - ✗ 늦었어서 → ✓ 늦어서 택시를 **탔어요**
- **เลือกสระผิด (ㅏ-ราก + 어):** ✗ 많어서 · ✗ 좋어서 → ✓ **많아서 · 좋아서** *(ครูไฮไลต์ 살어요 → 살아요 · 받었어요 → 받았어요 — ท่อง "ㅏ/ㅗ = 아")*
- **ㅡ-ตก:** ✗ 아프어서 · ✗ 바쁘어서 → ✓ **아파서 · 바빠서**
- **ㅂ-ราก:** ✗ 춥어서 · ✗ 무섭어서 → ✓ **추워서 · 무서워서**
- **N이어서:**
  - ✗ 고등학생여서 → ✓ **고등학생이어서** *(เหมือนข้อผิดที่เคยเจอ ✗ 학생였어요 → ✓ 학생이었어요 — ตัวสะกด → 이)*
  - ✓ 친구여서 *(สระ → 여서)*
- **ผลที่ผิดคำถาม:** ถาม 왜 ต้องตอบเหตุผล
  - ✗ 왜 택시를 타요? — 택시를 타요.
  - ✓ **늦어서** 택시를 타요. *(ข้อผิดเดิม: ตอบไม่ตรงคำถาม)*
- **ลำดับประโยค:** เหตุมาก่อนผลเสมอ
  - ✓ 시험이 있어서 갈 수 없어요
  - ✗ 갈 수 없어요 시험이 있어서 *(ไทยมักเอาผลขึ้นก่อน "ไปไม่ได้ เพราะสอบ")*
- **ประธานต่างกันได้:** ✓ **비가** 와서 **저는** 여행을 취소했어요 *(เหตุและผลคนละประธานได้)*
- **못 / 수 없다:** ✓ 시간이 없어서 못 가요 = ✓ 시간이 없어서 갈 수 없어요 (ข้อ 46)

> [!TIP] กฎสั้น ๆ
> **เหตุ-아/어서 + ผล** · **ไม่ใส่ -았/-겠 ในเหตุ** · **ผลห้ามเป็นคำสั่ง/ชวน (ใช้ -(으)니까)**
>
> **ㅏ/ㅗ=아서 อื่น=어서 하다=해서** · **N=이어서/여서**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ข้อนี้ยังไม่มีข้อสอบจริงที่ครูตรวจแล้วเกี่ยวกับ -아/어서 (เหตุผล) เพราะ 29과 อยู่ใน **복습시험③ (11/6, 22–29과)** และ **기말** แต่ตำรามีแบบฝึกพูดและมีข้อผิดของกลุ่มเดียวกันให้เตรียมตัว

- **ตำราให้ฝึกพูด:** 연습 2 ตาราง 6 คู่เหตุ–ผล + 연습 3 ถามเหตุผล 5 ข้อ — ครูมักยกรูป "ถาม–ตอบด้วยไวยากรณ์ที่กำหนด" มาออก
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ:**
  - ㅏ-ราก + 어 (살어요 · 받었어요 → 아)
  - นามอดีต 학생였어요 (→ 이었)
  - ตอบไม่ตรงคำถาม (언제 → 가족을…)
  - ㅡ-ตก เขียนถูกอยู่แล้ว (바빴어요 · 컸어요)
- **เฉลยภาคผนวก 읽기 29:** 가. 3 수영복이 없어서 수영을 하지 않았습니다. (= ข้อความเหตุผลของข้อ 3 ใช้ -아/어서)
- **คาดการณ์รูปแบบข้อสอบ** (เป็นการคาด):
  - ต่อประโยคสองประโยค: 날씨가 추워요. 옷을 많이 입었어요. → 날씨가 추워서 옷을 많이 입었어요.
  - ต่อประโยคสองประโยค: 친구 생일이에요. 케이크를 만들어요. → 친구 생일이어서 케이크를 만들어요.
  - ตอบ 왜 ด้วยไวยากรณ์ที่กำหนด: 왜 택시를 타요? (늦다) · 왜 가방을 안 샀어요? (비싸다) · 왜 수영을 하지 않았어요? (수영복이 없다)
  - ผันตาราง: 춥다 → 추워서 · 아프다 → 아파서 · 바쁘다 → 바빠서
  - ผันตาราง: 일어나다 → 일어나서 · 친절하다 → 친절해서 · 학생 → 학생이어서
  - อ่าน 가/나 เว้นคำตอบ: 29-1 (바트: 날씨가 추워서 바다에 가지 않고 영화를 봤어요 / 주말에 본 영화가 재미있어서 괜찮았어요)
  - อ่าน 가/나 เว้นคำตอบ: 29-2 (수영복이 없어서 수영을 할 수 없었어요)
