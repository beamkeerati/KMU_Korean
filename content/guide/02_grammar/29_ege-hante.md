## 29. 에게/한테 · 에게서/한테서 · 께 (ถึง/แก่ · จาก · ท่าน)
คำช่วยบอก "ใครเป็นผู้รับ" และ "ใครเป็นผู้ให้/ต้นทาง" ของการกระทำ ใช้กับ **คนและสัตว์** (สิ่งของ/สถานที่ใช้ 에 / 에서) · ไม่เปลี่ยนรูปตามตัวสะกด
สอนในบท 20 (교과서 178–181쪽) · ต่อยอดจาก ข้อ 20 (께 · 드리다) · ข้อ 24 (에서 = "จาก") · ข้อ 09 (에 / 에서) · ข้อ 23 (줬어요 · 받았어요)
ใช้ต่อในบท 21: ข้อ 32 (누구한테서 …배우고 있어요?) · ข้อ 28 (ใบฟัง 20-2 ใช้ 한테서 คู่กับ 갈 거예요)

### 📌 รูปแบบและเงื่อนไข
#### 1) ผู้รับ — "ให้ ส่ง โทร สอน ถาม แก่ใคร"
| ผู้รับเป็น | ใช้ | ระดับ | ตัวอย่าง |
|:---|:---|:---|:---|
| คน · สัตว์ | **에게** | พูด + เขียน (ทั่วไป) | 친구**에게** 책을 줬어요 *(ให้หนังสือเพื่อน)* |
| คน · สัตว์ | **한테** | พูดสบาย ๆ (ใช้บ่อยสุด) | 친구**한테** 전화해요 *(โทรหาเพื่อน)* |
| ผู้ใหญ่ | **께** | ยกย่อง · กริยา 주다 → **드리다** | 할아버지**께** 양말을 드려요 *(ให้ถุงเท้าคุณปู่)* |
| สิ่งของ · สถานที่ · องค์กร | **에** | ไม่ใช่คน | 꽃**에** 물을 줘요 *({v:รดน้ำ}{n:ดอกไม้})* · 사무실**에** 전화해요 *({v:โทร}{p:ไป}{n:สำนักงาน})* |

#### 2) ต้นทาง — "จาก…"
| ต้นทางเป็น | ใช้ | ตัวอย่าง |
|:---|:---|:---|
| คน · สัตว์ | **에게서** (พูด+เขียน) · **한테서** (พูด) | 남자 친구**에게서** 꽃을 받았어요 *(ได้ดอกไม้จากแฟน)* |
| ผู้ใหญ่ | **께** | 선생님**께** 한국어를 배웠어요 *(เรียนภาษาเกาหลีจากครู)* |
| สิ่งของ · สถานที่ · องค์กร | **에서** | 회사**에서** 전화가 왔어요 *(มี{n:โทรศัพท์}{v:มา}{p:จาก}{n:บริษัท})* |

#### 3) ตารางเทียบสองทิศทาง — 📽️ สรุปบนกระดานของครู (교과서 180–181쪽)
ครูแบ่งกระดานซ้าย = ให้ (___에게 주다) · ขวา = ได้รับ (___에게서 받다) — เงื่อนไขของทั้งสองฝั่งเหมือนกันทุกแถว ต่างกันแค่ทิศทาง

| ผู้รับ / ต้นทางเป็น… | ให้แก่ (ผู้รับ) | จาก (ต้นทาง) |
|:---|:---|:---|
| คน · สัตว์ | 에게 / 한테 | **에게서 / 한테서** |
| ผู้ใหญ่ (ยกย่อง) | 께 | **께** (ไม่มีรูป 께서 สำหรับ "จาก") |
| สิ่งของ · สถานที่ · องค์กร | 에 | **에서** |

#### 4) กฎทอง: เลือกคำช่วยจาก**กริยาท้ายประโยค**
| กริยา (ของไหล**ออก**จากประธาน) | คำช่วย | กริยา (ของไหล**เข้า**หาประธาน) | คำช่วย |
|:---|:---|:---|:---|
| 주다 · 드리다 · 보내다 · 가르치다 · 전화하다 · 질문하다 · 선물하다 · 말하다 · (편지를) 쓰다 | 에게 / 한테 / 께 / 에 | 받다 · 빌리다 · 배우다 · 듣다 · 얻다 · (전화가) 오다 | 에게서 / 한테서 / 께 (ดู ⚠️) / 에서 |

### 📖 ตัวอย่างและการใช้
#### ถาม–ตอบจากตำรา (교과서 178–181쪽)
| ถาม | ตอบ |
|:---|:---|
| 누구에게 전화해요? *(โทรหาใคร)* | 친구**한테** 전화해요. *(โทรหาเพื่อน)* |
| 꽃을 누구한테서 받았어요? *(ได้ดอกไม้จากใคร)* | 남자 친구**에게서** 받았어요. *(จากแฟน)* |
| 누구한테서 그 이야기를 들었어요? *(ได้ยินเรื่องนั้นจากใคร)* | 바트 씨**한테서** 들었어요. *(จากคุณบัต)* |
| 할아버지께 뭘 선물할 거예요? *({e:จะ}{v:ให้}{q:อะไร}{n:คุณปู่})* | 할아버지**께** 양말을 **드릴 거예요**. *({e:จะ}{v:ให้}{n:ถุงเท้า})* |
| 생일에 뭘 받았어요? → 누구한테서 받았어요? *(ได้อะไรวันเกิด → จากใคร)* | 장갑을 받았어요. → 오빠**한테서** 받았어요. *(ได้ถุงมือ → จากพี่ชาย)* |

#### 📽️ สไลด์อาจารย์: 에게 / 한테 (교과서 178쪽)
สไลด์ 문법 1: **명사(사람, 동물) 에게 (= 한테) + 동사** และ **윗사람 께 + 동사** (주다 ✗ → **드리다**)

| ประโยคบนสไลด์ | แปล |
|:---|:---|
| 어머니가 아이**에게(한테)** 과자를 줘요. | แม่ให้ขนมเด็ก |
| 카오루 씨가 여자 친구**에게(한테)** 선물을 줘요. | คาโอรุให้ของขวัญแฟน |
| 동생이 고양이**에게(한테)** 밥을 줘요. | น้องให้อาหารแมว |
| 카오루 씨가 친구**에게(한테)** 전화해요. | คาโอรุโทรหาเพื่อน |
| 선생님이 학생**에게(한테)** 한국어를 가르쳐요. | ครูสอนภาษาเกาหลีนักเรียน |
| 제가 친구**에게(한테)** 이메일을 보내요. | ฉันส่งอีเมลหาเพื่อน |
| 동생이 친구**에게(한테)** 편지를 써요. | น้องเขียนจดหมายถึงเพื่อน |
| 카오루 씨가 아버지**께** 전화해요. | คาโอรุโทรหาคุณพ่อ |
| 학생이 선생님**께** 질문해요. | นักเรียนถามคำถามครู |
| 제가 할머니**께** 선물을 **드려요**. | ฉันให้ของขวัญคุณยาย |
| 학생이 선생님**께** 꽃을 **드려요**. | นักเรียนมอบดอกไม้ให้ครู |

#### 📽️ สไลด์อาจารย์: 에게서 / 한테서 (교과서 180쪽)
สไลด์: **명사 에게서 (= 한테서) + 동사** *(จาก…)* ใช้กับ 받다 · 배우다 · 듣다 · 빌리다

| ประโยคบนสไลด์ | แปล |
|:---|:---|
| 아이가 어머니**에게서(한테서)** 과자를 받아요. | เด็กได้รับขนมจากแม่ |
| 마키 씨가 장핑 씨**에게서(한테서)** 선물을 받아요. | คุณมากิรับของขวัญจากคุณจางผิง |
| 투이 씨가 남자 친구**에게서(한테서)** 꽃을 받아요. | คุณทุยรับดอกไม้จากแฟน |
| 학생이 선생님**에게서(한테서)** 한국어를 배워요. | นักเรียนเรียนภาษาเกาหลีจากครู |
| 제가 친구**에게서(한테서)** 이야기를 들었어요. | ฉันได้ยินเรื่องราวจากเพื่อน |
| 동생이 형**에게서(한테서)** 돈을 빌렸어요. | น้องยืมเงินจากพี่ชาย |

#### ผู้ให้เป็นผู้ใหญ่ · สถานที่/องค์กรเป็น "จาก"
- 부모님**께서** 전화를 하세요. *(พ่อแม่โทรมา — 께서 = ประธานผู้ใหญ่ แทน 이/가 ดูข้อ 20)*
- 회사**에서** 전화가 왔어요. *(มี{n:โทรศัพท์}{v:มา}{p:จาก}{n:บริษัท})* · 학교**에서** 이메일을 받았어요. *(ได้อีเมลจากโรงเรียน)*
- เทียบกับคน: 친구**한테서** 이메일을 받았어요. *(ได้อีเมลจากเพื่อน)*
- 저는 친구**한테** 선물을 **줬어요**. *(ฉันให้ของขวัญเพื่อน — ของไหลออกจากฉัน)* ↔ 저는 친구**한테서** 선물을 **받았어요**. *({n:ฉัน}{v:ได้}{n:ของขวัญ}{p:จาก}{n:เพื่อน} — ของไหลเข้าหาฉัน)*
- 아버지**한테서** 전화**가** 왔어요. *({n:พ่อ}{v:โทรมา} — ประธานคือ "โทรศัพท์" จึงเป็น 가 ไม่ใช่ 를)*

### ⚠️ จุดสับสน
#### 에게/한테 vs 에게서/한테서 vs 에서
คนไทยใช้ "จาก/ให้/ที่" ปนกัน แต่เกาหลีแยกตาม**ประเภทของต้นทาง/ผู้รับ** (คนหรือสถานที่) และตาม**ทิศทางของกริยา**

| | 에게/한테 | 에게서/한테서 | 에서 |
|:---|:---|:---|:---|
| ความหมาย | ให้**แก่**คน | **จาก**คน | **จาก**สถานที่ / ทำ**ที่**สถานที่ |
| ตัวอย่าง | 친구**에게** 편지를 보내요 | 친구**에게서** 편지를 받았어요 | 학교**에서** 왔어요 |
| แปล | ส่งจดหมายให้เพื่อน | ได้รับจดหมายจากเพื่อน | มาจากโรงเรียน |

#### ผิดทิศ / ผิดประเภท — แก้ให้ถูก
| ✗ ผิด | ✓ ถูก | เหตุผล |
|:---|:---|:---|
| 부모님**한테서** 한국 이야기를 했어요 | 부모님**께** (หรือ 한테/에게) 한국 이야기를 했어요 *({v:เล่า}{n:เรื่องเกาหลี}{p:ให้}{n:พ่อแม่}ฟัง)* | 했어요 = เล่าให้ → ของไหล**ออก** · ผู้ใหญ่ใช้ 께 |
| **라디오한테서** 들었어요 | 라디오**에서** 들었어요 *(ได้ยินจากวิทยุ)* | วิทยุไม่ใช่คน → 에서 |
| **사무실한테** 전화해요 | 사무실**에** 전화해요 *({v:โทร}{p:ไป}{n:สำนักงาน})* | สถานที่/องค์กร → 에 |
| 꽃**에게** 물을 줘요 | 꽃**에** 물을 줘요 *({v:รดน้ำ}{n:ดอกไม้})* | พืชไม่ใช่คน/สัตว์ |
| 선생님**한테** 꽃을 **드려요** | 선생님**께** 꽃을 드려요 | 드리다 คู่กับ 께 |
| 선생님**께** 꽃을 **줘요** | 선생님께 꽃을 **드려요** | 께 คู่กับ 드리다 (주다 ✗) |
| 제 고향 친구 부산 이야기를 들었어요 | 제 고향 친구**한테서** 부산 이야기를 들었어요 | 들었어요 = เข้าหาฉัน ต้องมีคำช่วย "จาก" |

- ✓ 친구**한테** 말해요 / 친구**에게** 편지를 써요 / 학생**에게** 한국어를 가르쳐요 *(บอกเพื่อน / เขียนจดหมายถึงเพื่อน / สอนนักเรียน)* — 전화하다 · 편지를 쓰다 · 말하다 · 주다 · 보내다 · 가르치다 ใช้ 에게/한테
- 받다 กับ 한테 (ไม่มี 서) ในภาษาพูดจริงอาจได้ยินบ้าง แต่ตำราและข้อสอบเน้น **한테서/에게서** — ในแบบฝึก "A / B : 받다" ของเวิร์กบุ๊ก เขียน 한테서/에게서 ตาม 보기 ได้แม้ต้นทางจะเป็นผู้ใหญ่ (할머니한테서 시계를 받았어요)

#### 께 ใช้ได้ทั้ง "ให้แก่" และ "จาก" — ดูที่กริยา
| ประโยค | กริยา | ความหมาย |
|:---|:---|:---|
| 할머니**께** 시계를 **드렸어요**. | 드리다 (ให้) | **ให้**นาฬิกาคุณยาย |
| 할머니**께** 시계를 **받았어요**. | 받다 (รับ) | ได้นาฬิกา**จาก**คุณยาย |
| 선생님**께** 한국어를 **배웠어요**. | 배우다 (เรียน) | เรียนภาษาเกาหลี**จาก**ครู |

**께 เป็น "จาก" ชัดเจนเมื่อใช้กับ 받다 · 배우다 · 듣다** ส่วนกับ **오다** ประโยค 아버지**께** 전화가 왔어요 **กำกวม** (อ่านได้ทั้ง "พ่อโทรมา" และ "มีสายเข้าถึงพ่อ" ต้องดูบริบท) → ในข้อสอบเขียน 아버지**한테서/에게서** 전화가 왔어요 จะไม่กำกวม หรือถ้าต้องการยกย่องพ่อ ให้ทำพ่อเป็นประธาน: 아버지**께서** 전화하**셨**어요

> [!WARNING]
> **께 ≠ 께서**
> - **께** = ผู้รับ หรือต้นทางที่เป็นผู้ใหญ่ (แทน 에게 / 에게서)
> - **께서** = **ประธาน**ที่เป็นผู้ใหญ่ (แทน 이/가) และกริยาต้องมี -시- เช่น 선생님**께서** 가르치**십**니다

#### เทียบกับ 에 และ 하고
| | หน้าที่ | ตัวอย่าง |
|:---|:---|:---|
| 에 (ข้อ 09–10) | สถานที่ปลายทาง/เวลา | 학교**에** 가요 |
| 에게/한테 | **คน**ปลายทาง | 친구**한테** 전화해요 |
| 하고 (ข้อ 11) | "กับ" (ทำด้วยกัน) | 친구**하고** 같이 가요 |

> [!TIP]
> **คน → 에게/한테 (ให้) · 에게서/한테서 (จาก) · สถานที่ → 에/에서 · ผู้ใหญ่ → 께**
> เช็กคู่ทุกครั้ง: 한테 + 드리다 ✗ · 께 + 주다 ✗ · 여자 친구**한테** 꽃을 **줄/선물할** 거예요 ✓ · 어머니**께** 돈을 **드렸어요** ✓
