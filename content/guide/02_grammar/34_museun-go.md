## 34. 무슨 · -고 (...อะไร · และ)

> [!INTRO] ข้อนี้คืออะไร
> ข้อนี้รวมสองเรื่องของบท 22 คือ **무슨 + N** ที่ใช้ถามชนิดของสิ่งนั้น ("N อะไร / N ชนิดไหน") และ **-고** ที่ใช้เชื่อมกริยาหรือคำคุณศัพท์เข้าด้วยกัน ("และ")
>
> สอนในบท 22 (교과서 206–209쪽) ต่อยอดจาก ข้อ 11 (하고: นาม + นาม) · ข้อ 10 (무슨 요일) · ข้อ 18 (คำคุณศัพท์)
>
> ต่อยอดจาก ข้อ 16 (-지 않다) ด้วย
>
> ไปใช้ต่อใน ข้อ 33 (무슨 영화를 볼까요?) · ข้อ 35 และบท 25 (-지만) / บท 32 (-고 "แล้ว") — ยังไม่เรียน

### 📌 รูปแบบและเงื่อนไข

ข้อนี้มีสองเรื่อง เรื่องแรกคือ 무슨 ที่วางหน้านามเพื่อถามชนิด เรื่องที่สองคือ -고 ที่ต่อท้ายรากเพื่อเชื่อมกริยาหรือคำคุณศัพท์เข้าด้วยกัน

#### 무슨 + N — "N อะไร / N ชนิดไหน"

ถามชนิดหรือประเภทของสิ่งต่าง ๆ วางหน้านามเสมอ และตอบด้วยสมาชิกของหมวดนั้น

| คำถาม | ตอบ | หมวดที่ตำรา 206쪽 ฝึก |
|:---|:---|:---|
| 무슨 음식을 좋아해요? *(ชอบอาหารอะไร)* | 삼계탕을 좋아해요. *(ชอบซัมกเยทัง)* | 음식: 삼계탕 · 갈비찜 · 비빔밥 |
| 무슨 영화를 볼까요? *({v:ดู}{n:หนัง}{q:อะไร}{e:ดี})* | 공포 영화를 봐요. *(ดูหนังสยองขวัญ)* | 영화: 액션 · 공포 · 코미디 |
| 무슨 색깔 옷을 샀어요? *(ซื้อเสื้อสีอะไร)* | 빨간색 옷을 샀어요. *(ซื้อเสื้อสีแดง)* | 색깔: 하얀색 · 빨간색 · 파란색 |
| 요즘 무슨 책을 읽어요? *(ช่วงนี้อ่านหนังสืออะไร)* | 소설책을 읽어요. *(อ่านนิยาย)* | ตัวอย่างในกรอบไวยากรณ์ |

หมวดอื่นที่ตำรา 206쪽 ฝึกด้วยแม่แบบเดียวกันมีอีกสองหมวด คือ 운동 กับ 음악

| หมวด | คำที่ฝึก | ไทย |
|:---|:---|:---|
| 운동 | 축구 · 농구 · 수영 | ฟุตบอล · บาสเกตบอล · ว่ายน้ำ |
| 음악 | 케이팝 · 클래식 · 힙합 | เคป๊อป · คลาสสิก · ฮิปฮอป |

#### V/A-고 — เชื่อมสองการกระทำ/สภาพ

-고 ต่อท้ายรากของกริยาหรือคำคุณศัพท์ ความหมายคือ "และ" ตารางแรกสรุปรูปที่ใช้ ตารางที่สองคือตัวอย่างของแต่ละรูป

| รูป | ความหมาย |
|:---|:---|
| คุณศัพท์ + -고 + คุณศัพท์ | "…และ…" (สภาพ + สภาพ) |
| กริยา + -고 + กริยา | "…และ…" (การกระทำ + การกระทำ) |
| N도 …-고 N도 … | ทั้ง…ทั้ง… |
| N**이고** N… *(워크북 22과 H)* | นาม + 이다 + -고 |

#### ตัวอย่างการต่อ -고

ตารางนี้เรียงตามรูปข้างบน หนึ่งประโยคต่อหนึ่งแถว

| รูป | 한국어 | ไทย |
|:---|:---|:---|
| คุณศัพท์ + คุณศัพท์ | 깨끗하**고** 밝아요 | {v:สะอาด}{e:และ}{v:สว่าง} |
| คุณศัพท์ + คุณศัพท์ | 물건이 많**고** 싸요 | {n:ของ}{v:เยอะ}{e:และ}{v:ถูก} |
| คุณศัพท์ + คุณศัพท์ | 맵지 않**고** 맛있어요 | {x:ไม่}{v:เผ็ด}{e:และ}{v:อร่อย} |
| กริยา + กริยา | 청소도 하**고** 요리도 합니다 | {p:ทั้ง}{v:ทำความสะอาด}{e:และ}{v:ทำ}{n:อาหาร} |
| กริยา + กริยา | 저는 숙제를 하**고** 동생은 피아노를 쳐요 | {n:ฉัน}{v:ทำ}{n:การบ้าน}{e:และ}{n:น้อง}{v:เล่น}{n:เปียโน} |
| N도 …-고 N도 … | 불고기**도** 맛있**고** 냉면**도** 맛있어요 | บุลโกกิก็อร่อย เนงมยอนก็อร่อย |
| N**이고** N… *(워크북 22과 H)* | 마키 씨는 일본 사람**이고** 장핑 씨는 중국 사람이에요 | {n:คุณมากิ}{e:เป็น}{n:คนญี่ปุ่น} {e:และ}{n:คุณจางผิง}{e:เป็น}{n:คนจีน} |

#### ข้อสังเกต

-고 ไม่ทำให้รากเปลี่ยนรูป และตำรากับเวิร์กบุ๊กวางกาลไว้ต่างกันเล็กน้อย

- ราก + **고** ไม่ดูตัวสะกด และไม่เปลี่ยนราก
  - 맵다 → 맵**고** (ㅂ ไม่เปลี่ยน เพราะ 고 ขึ้นต้นด้วยพยัญชนะ)
  - 멀다 → 멀**고** (ㄹ ไม่หลุด)
- **ตำรา 208쪽:** ต่อหลังกริยาหรือคำคุณศัพท์เพื่อเชื่อมการกระทำ สภาพ หรือข้อเท็จจริงตั้งแต่สองอย่างขึ้นไป
- **กาล:** ตัวอย่างในตำรา (-았/었-) ไปอยู่ที่กริยาตัวสุดท้าย — 깨끗하고 밝았어요 *(สะอาดและสว่าง — อดีต)*
- ไม่ได้ห้ามใส่กาลที่ตัวหน้า: 보기 ของเวิร์กบุ๊ก 22과 H ใช้ 세 달 전에 **왔고** 한 달 전에 왔어요 *({n:คุณมากิ}{v:มา}{p:เมื่อ}{m:สามเดือน}{n:ก่อน} {e:และ}{n:คุณจางผิง}{v:มา}{p:เมื่อ}{m:หนึ่งเดือน}{n:ก่อน})*

#### การออกเสียง

เสียงอ่านของราก + -고 เปลี่ยนไปเมื่อรากมีตัวสะกด ดูตัวอย่างที่ตำราให้ไว้ในตารางนี้

| เขียน | อ่าน |
|:---|:---|
| 많고 | [만코] |
| 넓고 | [널꼬] |
| 밝고 | [발꼬] |
| 깨끗하고 | [깨끄타고] |

### 📖 ตัวอย่างและการใช้

ตัวอย่างต่อไปนี้ใช้ -고 เชื่อมกริยาและคำคุณศัพท์ รวมทั้งบทสนทนาจากบท 22-1 ที่ใช้ทั้ง 무슨 และ -고 ในบทเดียวกัน

#### ประโยคตัวอย่าง

ประโยคเหล่านี้เชื่อมสองสภาพหรือสองการกระทำด้วย -고 ส่วนสองข้อสุดท้ายเป็นบทสนทนา

- 이 교실은 깨끗하**고** 밝아요. *({n:ห้องนี้}{v:สะอาด}{e:และ}{v:สว่าง})*
- 동대문 시장은 물건이 많**고** 싸요. *({n:ตลาดตงแดมุนของ}{v:เยอะ}{e:และ}{v:ถูก})*
- 불고기는 맵지 않**고** 맛있어요. *({n:บุลโกกิ}{x:ไม่}{v:เผ็ด}{e:และ}{v:อร่อย})*
- 비빔밥은 조금 맵**고** 맛있어요. *({n:บิบิมบับ}{v:เผ็ด}{a:นิดหน่อย}{e:และ}{v:อร่อย})*
- 서울은 사람이 많**고** 교통이 복잡해요. *({n:โซลคน}{v:เยอะ}{e:และ}{n:การจราจร}{v:แน่น})*
- 학교에서 한국어를 공부하**고** 친구도 만나요. *({p:ที่}{n:โรงเรียน}{v:เรียน}{n:เกาหลี}{e:และ}{v:พบ}{n:เพื่อน}{p:ด้วย})*
- 경복궁도 가깝**고** 한식집도 많아요. *({v:ใกล้}{n:พระราชวัง}{e:และ}มี{n:ร้านอาหารเกาหลี}{v:เยอะ})*
- 가: 그 식당은 무슨 음식이 맛있어요? — 나: 불고기도 맛있**고** 냉면도 맛있어요. *({n:ร้านนั้นอาหาร}{q:อะไร}{v:อร่อย} — {n:บุลโกกิ}{p:ก็}{v:อร่อย} {n:เนงมยอน}{p:ก็}{v:อร่อย} · 22-1)*
- 가: 무슨 음식을 좋아해요? — 나: 불고기**하고** 삼겹살을 좋아해요. *({v:ชอบ}{n:อาหาร}{q:อะไร} — {v:ชอบ}{n:บุลโกกิ}{p:กับ}{n:ซัมกยอบซัล} · นาม + นาม ใช้ 하고)*

### ⚠️ จุดสับสน

ข้อนี้มีคู่ที่คนไทยสับสนสองคู่ คือ 무슨 กับ 어떤 และ -고 กับ 하고/와/과 กับ 그리고 เพราะภาษาไทยใช้ "อะไร" และ "และ/กับ" คำเดียวครอบคลุมหลายหน้าที่

#### 무슨 vs 어떤 vs 뭐 / 어느

무슨 ถามชนิดของ N ส่วน 어떤 ถามลักษณะหรือสภาพของ N ว่า "แบบไหน" ส่วน 뭐 กับ 어느 ดูเพิ่มที่ส่วนที่ 3

| คำถาม | ถามอะไร | ตัวอย่าง |
|:---|:---|:---|
| **무슨 + N** | **ชนิด/ประเภท**ของ N | 무슨 음식을 좋아해요? *(ชอบอาหารอะไร)* |
| **무슨 + N** | **ชนิด/ประเภท**ของ N | 이 단어가 무슨 뜻이에요? *(คำนี้ความหมายว่าอะไร)* |
| **어떤 + N** | **ลักษณะ/สภาพ** ("แบบไหน") | 어떤 사람을 좋아해요? — 똑똑하고 착한 사람을 좋아해요. *({v:ชอบ}{n:คน}{q:แบบไหน} — {n:คน}{v:ฉลาด}{e:และ}{v:ใจดี})* |
| 뭐 · 어느 + N | ดู **ส่วนที่ 3** (뭐 vs 무슨 vs 어느) | 이게 뭐예요? *(นี่คืออะไร)* |
| 뭐 · 어느 + N | ดู **ส่วนที่ 3** (뭐 vs 무슨 vs 어느) | 어느 나라 사람이에요? *(เป็นคนประเทศไหน)* |

#### -고 (และ) vs 하고/와/과 vs 그리고

-고 เชื่อม**กริยา/คุณศัพท์** ส่วน 하고/와/과 เชื่อม**คำนาม** และ 그리고 เชื่อม**ประโยค** คนไทยใช้ "และ/กับ" คำเดียวจึงสับสน

| ตัวเชื่อม | เชื่อมอะไร | 한국어 | ไทย |
|:---|:---|:---|:---|
| -고 | กริยา/คุณศัพท์ในประโยคเดียว | 불고기를 먹**고** 커피를 마셔요 | กินบุลโกกิแล้วดื่มกาแฟ |
| 하고 / 와 / 과 (ข้อ 11 · 19) | คำนาม | 불고기**하고** 커피 | บุลโกกิกับกาแฟ |
| 그리고 | ประโยคกับประโยค | 불고기를 먹어요. **그리고** 커피를 마셔요 | กินบุลโกกิ แล้วก็ดื่มกาแฟ |

#### ข้อควรระวังเรื่องกาลและตัวเชื่อม

ข้อนี้รวมข้อสังเกตเรื่องกาลของ -고 และการเลือกระหว่าง -고 กับ 하고 รวมทั้ง -고 ที่ความหมายอื่น

- ✓ 어제 먹**고** 마셨어요. *(เมื่อวานกินแล้วก็ดื่ม — กาลอยู่ที่กริยาตัวท้าย ตามตัวอย่างในตำรา)*
- ตำราไม่มีตัวอย่างที่ใส่กาลที่ตัวหน้า แต่ 보기 ของเวิร์กบุ๊กใช้ 왔고 จึงอย่าถือว่า 먹었고 ผิดเสมอไป — ถ้าไม่แน่ใจ ให้ทำตามตำรา
- ✓ 불고기**하고** 냉면을 먹어요. *(กินบุลโกกิกับเนงมยอน)*
- ✗ 불고기고 냉면을 먹어요 — นามสองตัวที่เป็นกรรมต้องใช้ 하고
- -고 ในบทนี้ = "และ" ส่วน -고 "แล้ว" (ลำดับ) ตำราจะสอนบท 32 แต่ครูใช้ในโจทย์แล้ว: `시험이 끝나고 무엇을 할 거예요?` *({p:หลัง}{n:สอบ}{v:เสร็จ}{e:จะ}{v:ทำ}{q:อะไร})*
- ข้อ 26 ก็เทียบ 먹고 가요 *({v:กิน}{e:แล้ว}{v:ไป})* — อ่านเป็น "แล้ว" ได้
- ราก + 고 + 있다 = **กำลัง** (ข้อ 32)
- ราก + 고 + กริยาอื่น = เชื่อม (บทนี้)

> [!TIP] กฎสั้น ๆ
> **คำนาม+คำนาม → 하고/와/과 · กริยา/คุณศัพท์+กริยา/คุณศัพท์ → -고 · ถามชนิด → 무슨 + N · ถามแบบไหน → 어떤 + N**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ยังไม่มีข้อสอบจริงที่ครูตรวจแล้วเกี่ยวกับ 무슨 · -고 แต่มีโจทย์ในชีตฟังและเวิร์กบุ๊กของบท 22 รวมทั้งข้อผิดกลุ่มคำถามที่เคยเจอ

- 22과 อยู่ในขอบเขต 중간시험 (10/22–23) และ 복습시험③ (11/6, 22–29과)
- **ชีตฟัง 본문 듣기 22과 (ช่อง B):** เติม **무슨 음식** และ **맛있고** (불고기도 맛있고 냉면도 맛있어요) จากบทสนทนา 22-1
- **워크북 22과:**
  - B จัดหมวดคำ (음식 · 색깔 · 음악 · 운동 · 동물 — ฝึกใช้กับ 무슨)
  - G เลือกคุณศัพท์ 2 คำต่อด้วย -고 (운동장이 넓고 좋습니다) *(สนามกีฬากว้างและดี)*
  - H ใช้ N이고 และ 왔고 ใน 보기
  - เฉลยในไฟล์เป็นการแก้เอง ไม่ใช่เฉลยครู
- **ข้อผิดกลุ่มคำถามที่เคยเจอ:** สับสน `어때요` vs `어떻게` (บันทึกไว้ในข้อผิดด้านคำศัพท์) → 어떤 + N = N แบบไหน · 어때요? = เป็นอย่างไร
