## 13. 띄어쓰기 (กฎการเว้นวรรค) — เสียคะแนนง่ายที่สุดในข้อสอบ 쓰기
เขียนถูกไวยากรณ์แล้วแต่เว้นวรรคผิด = ยังโดนหักคะแนนอยู่ดี · ใช้ทุกบท · หลักเดียว: **คำช่วยและ 이다 "เกาะ" คำนาม จึงติดกัน — คำอิสระ (안 · 시 · 분 · 씨 · 같이 · 거예요) ต้องเว้นวรรค** · ใช้ร่วมกับข้อ 01–11 (คำช่วย) และข้อ 25 (เวลา)

### กฎที่ 1: คำชี้ (조사) ต้อง **ติด** คำนามเสมอ
คำชี้ไม่ใช่คำอิสระ มันเกาะคำนามข้างหน้าเสมอ ห้ามมีช่องว่างคั่นเด็ดขาด

| คำชี้ | ✅ ถูก | ❌ ผิด |
|:---|:---|:---|
| 이/가 | 지갑**이** 없어요 | 지갑 이 없어요 ✗ |
| 을/를 | 책**을** 읽어요 | 책 을 읽어요 ✗ |
| 은/는 | 저**는** 학생이에요 | 저 는 학생이에요 ✗ |
| 에 | 학교**에** 가요 / 한 개**에** | 학교 에 가요 ✗ |
| 에서 | 식당**에서** 먹어요 | 식당 에서 먹어요 ✗ |
| 하고 · 도 | 과일**하고** 고기 · 저**도** 가요 | 과일 하고 고기 ✗ · 저 도 가요 ✗ |
| 부터 · 까지 | 한 시**부터** 두 시**까지** | 한 시 부터 두 시 까지 ✗ |

### กฎที่ 2: 이다 (이에요/예요/입니다) ต้อง **ติด** คำนามเสมอ
"เป็น/คือ" ในภาษาเกาหลีไม่ใช่คำแยก มันเป็นส่วนท้ายของคำนาม

* ✅ 학생**이에요**. / 의사**예요**. / 선생님**입니다**.
* ✅ 몇 명**이에요**? / 사천 원**이에요**. / 한 개**에** 구백 원**이에요**.
* ❌ 학생 이에요 / 사천 원 이에요 · และนามที่ไม่มีตัวสะกดใช้ **예요** ไม่ใช่ 이에요: ✗ 카드 이에요 → ✓ 카드**예요** · ✗ 사과 이에요 → ✓ 사과**예요**
* ส่วน **아니에요 · 있어요 · 없어요** เป็นคำอิสระ: 이/가 ติดคำนาม แล้ว **เว้น** ก่อนคำเหล่านี้ → 학생**이 아니에요** · 지갑**이 없어요** · 책상 위**에 있어요** (✗ 학생이아니에요)

### กฎที่ 3: 안 ต้อง **เว้นวรรค** เสมอ (ตรงข้ามกับ 2 ข้อบน!)
안 เป็นคำวิเศษณ์ (부사) เป็นคำอิสระ จึงต้องแยกจากกริยา

* ✅ **안** 가요 / **안** 자요 / **안** 사요 / **안** 봐요
* ❌ 안가요 / 안자요
* กริยา `명사 + 하다` → แทรก 안 ตรงกลาง **เว้นวรรคทั้งหน้าและหลัง**: ✅ 공부 **안** 해요 / 운동 **안** 해요 / 전화 **안** 해요 · ❌ 안 공부해요 (ผิดตำแหน่ง) / 공부안해요 (ไม่เว้นวรรค)
* ตอนไม่ปฏิเสธ `명사 + 하다` เป็น **คำเดียว** เขียนติดกัน: ✅ 공부해요 / 청소했어요 · ❌ 청소 했어요 · จะแยกก็ต่อเมื่อมี 을/를 หรือ 안 มาแทรก: 공부**를** 해요

### กฎที่ 4: คำอิสระอื่น ๆ ก็เว้นวรรค
| ชนิดคำ | ✅ ถูก | ❌ ผิด |
|:---|:---|:---|
| ชื่อ + 씨 | 마키 **씨** | 마키씨 |
| นาม + คำบอกตำแหน่ง (위 · 아래 · 앞 · 뒤 · 옆 · 안 · 밖) | 책상 **위**에 있어요 | 책상위에 |
| ชั่วโมง · นาที · ครึ่ง | 두 **시** 이십 **분** · 세 **시 반** | 두시 이십분 |
| 오전 / 오후 มาก่อนเวลา | 오후 두 시 | 오후두시 |
| -(으)ㄹ **거예요** | 갈 **거예요** · 청소할 **거예요** | 갈거예요 · 청소할거예요 |
| คำวิเศษณ์ (같이 · 많이 · 열심히) | 친구하고 **같이** 가요 · **많이** 있어요 | 친구하고같이 · 많이있어요 |
| 이/그/저 · 제/우리 + นาม | 이 사람 · 제 사전 · 우리 반 | 이사람 · 제사전 |
| ตัวเลข + ลักษณนาม | 사과 **세 개** · 학생 **다섯 명** · 커피 **두 잔** · 책 **한 권** | 사과세개 |

* แต่คำชี้ที่ตามมายังติดเหมือนเดิม: 한 개**에** 칠백 원이에요 · วันที่เขียนฮันกึลตามตำรา: 일월 팔 일이에요 (เดือนติดเลข · เว้นก่อน 일)

> [!IMPORTANT]
> **สูตรเดียว:**
> - **조사 + 이다** → **ติด** (เพราะเกาะคำนาม)
> - **안 · 시 · 분 · 씨 · 같이 · 거예요** → **เว้น** (เพราะเป็นคำอิสระ)
>
> ตรวจงานตัวเอง: เห็น 안 / 시 / 분 / 거예요 → เช็กว่ามีช่องว่างข้างหน้าไหม · เห็นคำชี้ (이/가 · 에 · 하고 · 도 · 부터) → เช็กว่าติดคำหน้าไหม

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
* **เวลา:** 두시 이십분 ✗ → **두 시 이십 분** (워크북 18과 — เขียนติดกัน และบางครั้งตก 분: 사십오 이에요 ✗ → 사십오 분이에요)
* **거예요:** 갈거예요 · 청소할거예요 ✗ → **갈 거예요 · 청소할 거예요** (매일시험 19과 C10 และใบฝึก 20과 — ครูให้คะแนนแต่ผิดกฎ) · 가르칠 거요 ✗ → 가르칠 거예요 (ตก 예)
* **부터 / 까지:** 한시부터 두시까지 ✗ → **한 시부터 두 시까지** (매일시험 19과 A — 시 เว้น แต่ 부터 ติด) · 이십 일 부터 ✗ → 이십 일부터 (เคยเขียนแยก 부터 หรือลืม 까지 ในงาน 19과)
* **N하다 และ 이에요:** 기숙사를 청소 했어요 ✗ → 청소했어요 (매일시험 17과 ข้อ 7 — พร้อมปัญหา ㅊ ในคำเดียวกัน) · 가트 이에요 ✗ → 카드예요 (매일시험 7과 C9) · 사과 이에요 ✗ → 사과예요 (매일시험 13과 B15)
* **안:** 안 아르바이트 해요 ✗ → **아르바이트 안 해요** (복습시험 ① 듣기 9 — ครูแก้ให้) · 안 운동해요 ✗ → 운동을 안 해요 (매일시험 12과)
