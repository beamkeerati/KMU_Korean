## 41. N보다 (เปรียบเทียบ "…กว่า N") · 더 / 덜
ติดท้าย**คำนามที่เป็นตัวเปรียบเทียบ** — "A เป็น…กว่า **B**" = A이/가 **B보다** (더) … · ลำดับต่างจากไทย: ตัว B ที่เอามาเทียบ + 보다 ต้องอยู่**หน้า**คำคุณศัพท์/กริยา
สอนในบท 26 (교과서 262–263쪽 준비 1 · ⚠️ หน้า 대화 · 활동 · 읽기 ของบท 26 ยังไม่มีในคลัง) · ต่อยอดจาก ข้อ 18 (คำคุณศัพท์) · ข้อ 01 (이/가 · 은/는) · ข้อ 06 (ผัน) · ข้อ 37 (ㅂ 불규칙: 더워요)
ใช้ต่อใน ข้อ 43 (어제보다 시원해졌어요) · ข้อ 45 (N 중에서 제일 — เทียบ 3 สิ่งขึ้นไป) · ข้อ 40 (-지만 เทียบสองสิ่ง)

### 📌 รูปแบบและเงื่อนไข
ตำรา 262쪽: ติดหลังคำนามเพื่อ**เปรียบเทียบความต่าง** · **นามที่ติด 보다 คือสิ่งที่ถูกเอามาเทียบ (ตัวเทียบ)** · มักใช้คู่กับ **더** *(มากกว่า)*

| รูปแบบ | โครง | ตัวอย่าง |
|:---|:---|:---|
| มาตรฐาน | **A이/가 B보다 (더) + V/A** | 제주도**가** 서울**보다** 따뜻해요. *(เชจูอุ่นกว่าโซล)* |
| สลับลำดับ | **B보다 A가 (더) + V/A** | 형**보다** 내**가** 더 많이 먹어요. *(ฉันกินมากกว่าพี่ชาย)* |
| ละ 더 ได้ | A이/가 B보다 V/A | 말하기가 듣기**보다** 어려워요. *(การพูดยากกว่าการฟัง)* |
| มี 더 | A가 B보다 **더** V/A | 올해가 작년**보다 더** 추워요. *(ปีนี้หนาวกว่าปีที่แล้ว)* |
| น้อยกว่า *(เสริม)* | A가 B보다 **덜** + A | 김치찌개가 라면보다 **덜** 매워요. *(กิมจิจีเกเผ็ดน้อยกว่ามาม่า)* |

- **보다 ไม่ดูตัวสะกด** ติดนามตรง ๆ ไม่เว้นวรรค · ติดได้กับนามทุกชนิด รวมถึงกริยาที่ทำเป็นนามแล้ว (**듣기보다** · **말하기** · **쓰기** — ข้อ 59)
- **A (สิ่งเด่น)** รับ **이/가** (หรือ 은/는 ถ้าเทียบชัด) · **B (ตัวเทียบ)** ติด 보다 อย่างเดียว ✗ 서울이보다 · ✗ 서울을보다
- **วิธีอ่านเครื่องหมาย ＞ ＜ ในแบบฝึกตำรา (연습 1):** "A ＞ B / adj" = A เด่นกว่า → **A가 B보다 adj** · "A ＜ B / adj" = B เด่นกว่า → **B가 A보다 adj**

| โจทย์ตำรา (262쪽) | อ่านว่า | ประโยค (ข้อแรกคือตัวอย่างตำรา · ที่เหลือเฉลยเขียนเอง) |
|:---|:---|:---|
| 제주도 ＞ 서울 / 따뜻하다 | เชจูอุ่นกว่า | 제주도가 서울보다 **따뜻해요**. |
| 러시아 ＞ 일본 / 춥다 | รัสเซียหนาวกว่า | 러시아가 일본보다 **추워요**. |
| 사우디아라비아 ＞ 베트남 / 덥다 | ซาอุร้อนกว่า | 사우디아라비아가 베트남보다 **더워요**. |
| 부산 ＜ 경주 / 맑다 | คยองจูแจ่มใสกว่า | 경주가 부산보다 **맑아요**. |
| 지난주 ＜ 이번 주 / 시원하다 | สัปดาห์นี้เย็นกว่า | 이번 주가 지난주보다 **시원해요**. |
| 어제 ＜ 오늘 / 흐리다 | วันนี้มีเมฆมากกว่า | 오늘이 어제보다 **흐려요**. |

### 📖 ตัวอย่างและการใช้
#### จากตำรา 26과
1. 준비 1: 가: 제주도는 날씨가 어때요? 나: 제주도는 서울**보다** 따뜻해요. *(อากาศที่เชจูเป็นอย่างไร — อุ่นกว่าโซล)*
2. กล่องตำรา: 올해가 작년**보다** 더 추워요. · 말하기가 듣기**보다** 어려워요. · 형**보다** 내가 더 많이 먹어요. *(ปีนี้หนาวกว่าปีที่แล้ว · การพูดยากกว่าการฟัง · ฉันกินมากกว่าพี่ชาย)*
3. 연습 2 (263쪽) — ถามจากภาพ: 가: 누가 더 커요? 나: **압둘라 씨가 마키 씨보다 커요**. *(ใครตัวใหญ่/สูงกว่า — คุณอับดุลลาสูงกว่าคุณมากิ · ตัวอย่างตำรา)*
   ข้อ 2–5 (เฉลยเขียนเอง): 무엇이 더 많아요? → **커피가 주스보다 많아요**. *(🖼️ ถ้วยกาแฟหลายถ้วย vs ขวดน้ำส้ม 3 ขวด)* · 누구 집이 더 작아요? → **윤아 씨 집이 지훈 씨 집보다 작아요**. *(🖼️ บ้านหลังใหญ่ vs บ้านหลังเล็ก)* · 무엇이 더 비싸요? → **빵이 우유보다 비싸요**. *(🖼️ นม 700원 vs ขนมปัง 1,000원)* · 누구 머리가 더 짧아요? → **미나 머리가 유리 머리보다 짧아요**. *(🖼️ ผมยาว vs ผมสั้น)*
4. 연습 3 (263쪽) — ถามเพื่อน (เลือกคำตอบจากกรอบ): 언제 더 바빠요? (평일 ☑ · 주말) · 어디에 사람이 더 많아요? (동대문시장 · 명동) · 뭐가 더 매워요? (김치찌개 · 라면) · 뭐가 더 어려워요? (말하기 · 쓰기) · 누구하고 더 자주 전화해요? (부모님 · 남자/여자 친구) → ตัวอย่างตอบ: 평일이 주말**보다** 더 바빠요. *(วันธรรมดายุ่งกว่าสุดสัปดาห์)* · 부모님**보다** 친구하고 더 자주 전화해요. *(โทรหาเพื่อนบ่อยกว่าพ่อแม่ — เฉลยเขียนเอง)*
5. 27-1 (274쪽): 지난주**보다** 많이 덥네요. *(ร้อนมากกว่าสัปดาห์ก่อนนะเนี่ย)* · 준비 1 (27과): 어제**보다** 시원해졌어요. *(เย็นลงกว่าเมื่อวาน — -아/어지다 ข้อ 43)*
6. 듣기 28-2 (ภาคผนวก 372쪽): 가: 베트남도 많이 더워요? 나: 한국**보다** 더 더워요. *(เวียดนามก็ร้อนมากไหม — ร้อนกว่าเกาหลี)*
7. 활동 25과 (255쪽): 서울은 아침에 교통이 복잡하지만 ___ 씨 고향은 복잡하지 않아요 → 서울이 이리나 씨 고향보다 더 복잡해요. *(เทียบ ข้อ 40 → ข้อ 41: บอกซ้ำด้วย 보다 · เฉลยเขียนเอง)*
8. **บทอ่านบท 26** (หน้าไม่มีในคลัง): เฉลยท้ายเล่ม (372쪽) บอกว่าเรื่องเกี่ยวกับ "아침부터 눈이 왔어요 · 수업이 끝나고 반 학생들과 운동장에 나갔어요 · 눈길을 걷고 사진도 찍고 눈사람도 만들었어요 · 스키를 타러 갈 거예요" *(หิมะตกตั้งแต่เช้า · ออกสนามกับเพื่อนในห้อง · เดินบนทางหิมะ ถ่ายรูป ปั้นตุ๊กตาหิมะ · จะไปเล่นสกี)* — ตัวบทอ่านเองยังไม่มี จึงไม่ถอดความ

#### ถามเปรียบเทียบ → ตอบด้วย 보다
| คำถาม | ใช้ถามเมื่อ | คำตอบ |
|:---|:---|:---|
| 누가 더 + A? | เทียบคนสองคน | 압둘라 씨가 마키 씨보다 커요. |
| 무엇이 더 + A? · 뭐가 더 + A? | เทียบของสองอย่าง | 빵이 우유보다 비싸요. |
| 어디가 더 + A? · 어디에 + N이 더 많아요? | เทียบสถานที่ | 사우디아라비아가 한국보다 더워요. |
| 언제 더 + A? | เทียบเวลา | 평일이 주말보다 바빠요. |
| 누구하고 더 자주 + V? | เทียบกริยา/ความถี่ | 친구하고 더 자주 전화해요. |
| 어느 + N이 + A? *(เลือกจากสอง)* | ระบุตัวเลือก | 어느 음식이 매워요? → 떡볶이가 김밥보다 매워요. *(23과 연습 2)* |

### ⚠️ จุดสับสน
#### N보다 (กว่า) ≠ 보다 (ดู) — พ้องรูป
| | ตำแหน่ง | ตัวอย่าง |
|:---|:---|:---|
| **N보다** *(กว่า)* | ติดนาม ไม่ผัน | 서울**보다** 따뜻해요 *(อุ่นกว่าโซล)* |
| **보다** *(ดู — กริยา)* | ผันได้ (봐요 · 봤어요 · 보세요) | 영화를 **봐요** *(ดูหนัง)* |

- ถ้ามีคำนามติดอยู่ข้างหน้าและไม่มี 을/를 คั่น → "กว่า" · ถ้าเป็น 영화를 보다 → "ดู"

#### ใครเป็น "ตัวเทียบ" — ตัวที่ตามหลัง 보다 คือตัว "ด้อยกว่า"
| ข้อมูล | ✓ ถูก | ✗ สลับ |
|:---|:---|:---|
| เชจู **อุ่นกว่า** โซล | 제주도가 서울**보다** 따뜻해요 | ✗ 서울이 제주도보다 따뜻해요 |
| พี่ชายกินน้อยกว่าฉัน | 형**보다** 내가 더 많이 먹어요 | ✗ 내**보다** 형이 더 … |

- A ที่รับ **이/가** = ตัวที่ "…กว่า" · B ที่ติด **보다** = ตัวที่ถูกเอามาเทียบ (ด้อยกว่า)

#### กับดัก
- **ไม่ต้องใส่ 이/가/을/를 หลัง 보다:** ✗ 서울보다가 · ✗ 서울이보다 · ✗ 서울보다를
- **ไม่เว้นวรรค:** ✗ 서울 보다 → ✓ 서울보다
- **ใช้ 더 ก่อนกริยา/คำคุณศัพท์:** ✓ 더 커요 / ✗ 커요 더 · ✗ 더 보다 · ถ้าไม่ใช้ 더 ก็เข้าใจได้ (말하기가 듣기보다 어려워요)
- **많아요 vs 많이:** คำคุณศัพท์ 많다 → **많아요** (커피가 주스보다 **많아요**) · กริยาใช้ **많이** (형보다 내가 더 **많이** 먹어요) — ข้อ 18
- **ความถี่/วิธี:** วาง **더 자주 · 더 빨리 · 더 잘** ไว้ก่อนกริยา — 친구하고 **더 자주** 전화해요 *(โทรหาเพื่อนบ่อยกว่า)*
- **ไทยวางตรงกันข้าม:** "A สูงกว่า B" → เกาหลี **B보다 A가 크다** (หรือ A가 B보다 크다) — คุณศัพท์อยู่ท้ายสุดเสมอ
- **ปริมาณที่ชัดเจน (เสริม):** 훨씬 *(มาก ๆ)* · 조금 *(นิดหน่อย)* วางหน้า 더: 훨씬 더 추워요 *(หนาวกว่ามาก)*
- **อดีต/ปัจจุบัน:** ผันที่กริยา/คำคุณศัพท์ท้ายประโยค — 올해가 작년보다 더 **추웠어요** *(ปีนี้หนาวกว่า — ถ้าผ่านไปแล้ว)*

#### 보다 (2 สิ่ง) vs 중에서 제일 (3 สิ่งขึ้นไป)
| | จำนวนที่เทียบ | ตัวอย่าง |
|:---|:---|:---|
| **A가 B보다 더** (ข้อ 41) | **2** สิ่ง | 겨울이 가을보다 추워요. *(ฤดูหนาวหนาวกว่าฤดูใบไม้ร่วง)* |
| **N 중에서 A가 제일** (ข้อ 45) | **3** สิ่งขึ้นไป | 계절 중에서 겨울이 제일 추워요. *(ในบรรดาฤดู หนาวที่สุดคือฤดูหนาว)* |

> [!TIP]
> **A이/가 B보다 (더) + คำคุณศัพท์/กริยา** · B = ตัวเทียบ (ติด 보다) · ไม่ผัน ไม่ดูตัวสะกด · 2 สิ่ง = 보다 / 3 สิ่ง = 중에서 제일

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- **ยังไม่มีข้อสอบจริง** — 26과 อยู่ใน 복습시험③ (11/6 = 22–29과) · ⚠️ หน้า 대화 · 활동 · 읽기 26-2 ของบทนี้ยังไม่มีในคลัง (สแกนมี 3 หน้า) — เมื่อได้หน้าเหล่านั้นให้เติมลงข้อ 41 และ 42
- **คาดการณ์รูปแบบข้อสอบ:**
  - **เปรียบเทียบจากโจทย์ ＞ ＜:** 제주도 ＞ 서울 / 따뜻하다 → 제주도가 서울보다 따뜻해요 (เหมือน 연습 1)
  - **그림을 보고 대답하세요:** 🖼️ คน 2 คนสูงไม่เท่ากัน → 누가 더 커요? → ○○ 씨가 △△ 씨보다 커요
  - **ตอบคำถามด้วยไวยากรณ์ที่กำหนด:** 어느 음식이 더 매워요? (떡볶이 / 김밥) → 떡볶이가 김밥보다 매워요
  - **ต่อกับ -지만 (ข้อ 40):** 서울은 복잡하지만 제 고향은 복잡하지 않아요 → 서울이 제 고향보다 더 복잡해요
  - **말하기 (11/23):** ถามเปรียบเทียบง่าย ๆ — 평일하고 주말 중에서 언제 더 바빠요? · 한국 음식하고 고향 음식 중에서 뭐가 더 매워요? (คาดการณ์)
- **ข้อผิดที่เคยเจอและเกี่ยวกับข้อนี้ (§6b):** ★ **จุดอ้างอิงสลับ** (ข้อ 05: 소파가 테이블 앞 for 뒤) — ใน 보다 ก็เหมือนกัน: ตัวที่ติด 보다 คือตัวเทียบ · **ตอบไม่ตรงคำถาม** (누가 → ตอบคน · 뭐가 → ตอบของ · 언제 → ตอบเวลา) · **많이 vs 많아요** · ㅈ/ㅊ (**제주도** · **작년** ใช้ ㅈ)
