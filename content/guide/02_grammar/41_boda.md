## 41. N보다 (เปรียบเทียบ "…กว่า N") · 더 / 덜

> [!INTRO] ข้อนี้คืออะไร
> **N보다** ติดท้ายคำนามที่เป็นตัวเปรียบเทียบ แปลว่า "…กว่า N" โครงคือ "A เป็น…กว่า B" = **A이/가 B보다 (더) …** ลำดับต่างจากภาษาไทย เพราะตัว B ที่เอามาเทียบพร้อม 보다 ต้องอยู่**หน้า**คำคุณศัพท์หรือกริยาเสมอ
>
> สอนในบท 26 (ตำรา 262–263쪽 준비 1) แต่ต้องรู้ไว้ก่อนว่าหน้า 대화 · 활동 · 읽기 ของบท 26 ยังไม่มีในคลัง ข้อนี้ต่อยอดจากข้อ 18 (คำคุณศัพท์) ข้อ 01 (이/가 และ 은/는) ข้อ 06 (การผัน) และข้อ 37 (ㅂ 불규칙: 더워요) แล้วไปใช้ต่อในข้อ 43 (어제보다 시원해졌어요) ข้อ 45 (N 중에서 제일 ซึ่งเทียบ 3 สิ่งขึ้นไป) และข้อ 40 (-지만 ที่เทียบสองสิ่ง)

### 📌 รูปแบบและเงื่อนไข

ตำรา 262쪽 บอกว่า 보다 ติดหลังคำนามเพื่อ**เปรียบเทียบความต่าง** และ**นามที่ติด 보다 คือสิ่งที่ถูกเอามาเทียบ (ตัวเทียบ)** มักใช้คู่กับ **더** *(มากกว่า)*

| รูปแบบ | โครง | ตัวอย่าง |
|:---|:---|:---|
| มาตรฐาน | **A이/가 B보다 (더) + V/A** | 제주도**가** 서울**보다** 따뜻해요. *(เชจูอุ่นกว่าโซล)* |
| สลับลำดับ | **B보다 A가 (더) + V/A** | 형**보다** 내**가** 더 많이 먹어요. *(ฉันกินมากกว่าพี่ชาย)* |
| ละ 더 ได้ | A이/가 B보다 V/A | 말하기가 듣기**보다** 어려워요. *(การพูดยากกว่าการฟัง)* |
| มี 더 | A가 B보다 **더** V/A | 올해가 작년**보다 더** 추워요. *(ปีนี้หนาวกว่าปีที่แล้ว)* |
| น้อยกว่า *(เสริม)* | A가 B보다 **덜** + A | 김치찌개가 라면보다 **덜** 매워요. *(กิมจิจีเกเผ็ดน้อยกว่ามาม่า)* |

#### 보다 ติดอย่างไร

ข้อกำหนดของ 보다 มีน้อยมาก แต่ต้องแยกบทบาทของ A กับ B ให้ชัดว่าใครรับ 이/가 และใครติด 보다

- **보다 ไม่ดูตัวสะกด** ติดนามตรง ๆ ไม่เว้นวรรค
- ติดได้กับนามทุกชนิด รวมถึงกริยาที่ทำเป็นนามแล้ว เช่น **듣기보다** · **말하기** · **쓰기** (ข้อ 59)
- **A (สิ่งเด่น)** รับ **이/가** หรือ 은/는 ถ้าเทียบชัด
- **B (ตัวเทียบ)** ติด 보다 อย่างเดียว ✗ 서울이보다 ✗ 서울을보다

#### อ่านเครื่องหมาย ＞ ＜ ใน 연습 1

แบบฝึก 연습 1 (262쪽) ให้โจทย์เป็นเครื่องหมาย ＞ ＜ กับคำคุณศัพท์ วิธีอ่านคือ "A ＞ B / adj" แปลว่า A เด่นกว่า จึงเขียน **A가 B보다 adj** ส่วน "A ＜ B / adj" แปลว่า B เด่นกว่า จึงเขียน **B가 A보다 adj**

ข้อแรกคือตัวอย่างตำรา ที่เหลือเฉลยเขียนเอง

| โจทย์ตำรา | อ่านว่า | ประโยค |
|:---|:---|:---|
| 제주도 ＞ 서울 / 따뜻하다 | เชจูอุ่นกว่า | 제주도가 서울보다 **따뜻해요**. |
| 러시아 ＞ 일본 / 춥다 | รัสเซียหนาวกว่า | 러시아가 일본보다 **추워요**. |
| 사우디아라비아 ＞ 베트남 / 덥다 | ซาอุร้อนกว่า | 사우디아라비아가 베트남보다 **더워요**. |
| 부산 ＜ 경주 / 맑다 | คยองจูแจ่มใสกว่า | 경주가 부산보다 **맑아요**. |
| 지난주 ＜ 이번 주 / 시원하다 | สัปดาห์นี้เย็นกว่า | 이번 주가 지난주보다 **시원해요**. |
| 어제 ＜ 오늘 / 흐리다 | วันนี้มีเมฆมากกว่า | 오늘이 어제보다 **흐려요**. |

### 📖 ตัวอย่างและการใช้

ตัวอย่างมาจากตำราบท 26 เป็นหลัก เสริมด้วยประโยคจากบท 25, 27 และ 28 ที่กลับมาใช้ 보다 อีก สังเกตว่าคำถามแต่ละแบบ ไม่ว่าจะเป็น 누가, 무엇이, 어디가 หรือ 언제 ตอบด้วยโครงเดียวกันหมด

| 서울이 이리나 씨 고향**보다** 더 복잡해요. | โซลซับซ้อน/วุ่นวายกว่าบ้านเกิดคุณอีรีนา (เฉลยเขียนเอง) | 활동 25과 (255쪽) |

ประโยคสุดท้ายมาจากกิจกรรมที่ให้เทียบ "서울은 아침에 교통이 복잡하지만 ___ 씨 고향은 복잡하지 않아요" (ข้อ 40) แล้วบอกซ้ำด้วย 보다 (ข้อ 41)

#### 연습 3 (263쪽): ถามเพื่อน

แบบฝึกนี้ให้ถามเพื่อนแล้วเลือกคำตอบจากกรอบ ตารางข้างล่างคือโจทย์ 5 ข้อและตัวเลือก (☑ = ตัวอย่างที่ตำราติ๊กไว้)

| 질문 | ไทย | ตัวเลือก |
|:---|:---|:---|
| 언제 더 바빠요? | เมื่อไรยุ่งกว่า | 평일 ☑ · 주말 |
| 어디에 사람이 더 많아요? | ที่ไหนคนเยอะกว่า | 동대문시장 · 명동 |
| 뭐가 더 매워요? | อะไรเผ็ดกว่า | 김치찌개 · 라면 |
| 뭐가 더 어려워요? | อะไรยากกว่า | 말하기 · 쓰기 |
| 누구하고 더 자주 전화해요? | โทรหาใครบ่อยกว่า | 부모님 · 남자/여자 친구 |

#### จาก 대화 26-1 · 활동 · 읽기 26-2 (หน้า 266–269)

บทสนทนาและบทอ่านของบท 26 ใช้ 보다 ในประโยคจริงดังนี้ (ฉบับเต็มพร้อมคำแปลทุกบรรทัดอยู่ในเล่ม 1 บท 26) สังเกตว่าเมื่อรู้กันอยู่แล้วว่าเทียบกับอะไร คนเกาหลีจะละ N보다 แล้วพูดแค่ 더 추워요

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 러시아가 한국**보다** 더 추워요? | รัสเซียหนาวกว่าเกาหลีอีกเหรอ | 대화 26-1 |
| 러시아는 더 추워요. 보통 겨울 기온이 영하 40도예요. | รัสเซียหนาวกว่า (ละ 한국보다) ปกติหน้าหนาวติดลบ 40 องศา | 대화 26-1 |
| 한국**보다** 따뜻해요. | อุ่นกว่าเกาหลี | 대화 26-1 |
| 오늘 날씨가 어제**보다** 더 더워요. 오늘은 35도예요. | วันนี้อากาศร้อนกว่าเมื่อวาน วันนี้ 35 องศา | 활동 หน้า 267 |
| 저녁에는 오후**보다** 눈이 더 많이 왔어요. | ตอนเย็นหิมะตกมากกว่าตอนบ่าย | 읽기 26-2 |

เฉลยท้ายเล่ม (372쪽) สรุปบทอ่านว่าเป็นเรื่องวันหิมะตก: 아침부터 눈이 왔어요 *(หิมะตกตั้งแต่เช้า)* · 눈길을 걷고 사진도 찍고 눈사람도 만들었어요 *(เดินบนทางหิมะ ถ่ายรูป ปั้นตุ๊กตาหิมะ)* · 스키를 타러 갈 거예요 *(จะไปเล่นสกี)*

#### ถามเปรียบเทียบ → ตอบด้วย 보다

ตารางนี้จัดคำถามเปรียบเทียบตามสิ่งที่ถาม พร้อมคำตอบตัวอย่างที่ใช้โครง 보다 เหมือนกันทุกแถว

| คำถาม | ใช้ถามเมื่อ | คำตอบ |
|:---|:---|:---|
| 누가 더 + A? | เทียบคนสองคน | 압둘라 씨가 마키 씨보다 커요. |
| 무엇이 더 + A? · 뭐가 더 + A? | เทียบของสองอย่าง | 빵이 우유보다 비싸요. |
| 어디가 더 + A? · 어디에 + N이 더 많아요? | เทียบสถานที่ | 사우디아라비아가 한국보다 더워요. |
| 언제 더 + A? | เทียบเวลา | 평일이 주말보다 바빠요. |
| 누구하고 더 자주 + V? | เทียบกริยา/ความถี่ | 친구하고 더 자주 전화해요. |
| 어느 + N이 + A? *(เลือกจากสอง)* | ระบุตัวเลือก | 어느 음식이 매워요? → 떡볶이가 김밥보다 매워요. *(23과 연습 2)* |

### ⚠️ จุดสับสน

ข้อผิดของเรื่องนี้มี 3 กลุ่ม คือสับสนกับ 보다 ที่แปลว่า "ดู" สลับตัวเทียบ และวางตำแหน่งคำผิดตามลำดับของภาษาไทย

#### N보다 (กว่า) ≠ 보다 (ดู) พ้องรูป

ตารางนี้แยกสองคำที่หน้าตาเหมือนกันตรงที่ตำแหน่งในประโยคและการผัน

| รูป | ตำแหน่ง | ตัวอย่าง |
|:---|:---|:---|
| **N보다** *(กว่า)* | ติดนาม ไม่ผัน | 서울**보다** 따뜻해요 *(อุ่นกว่าโซล)* |
| **보다** *(ดู — กริยา)* | ผันได้ (봐요 · 봤어요 · 보세요) | 영화를 **봐요** *(ดูหนัง)* |

- ถ้ามีคำนามติดอยู่ข้างหน้าและไม่มี 을/를 คั่น → "กว่า"
- ถ้าเป็น 영화를 보다 → "ดู"

#### ใครเป็น "ตัวเทียบ"

ตัวที่ตามหลัง 보다 คือตัวที่ "ด้อยกว่า" หรือตัวที่ถูกเอามาเทียบ ผู้เรียนมักสลับสองตัวนี้

| ข้อมูล | ✓ ถูก | ✗ สลับ |
|:---|:---|:---|
| เชจู **อุ่นกว่า** โซล | 제주도가 서울**보다** 따뜻해요 | ✗ 서울이 제주도보다 따뜻해요 |
| พี่ชายกินน้อยกว่าฉัน | 형**보다** 내가 더 많이 먹어요 | ✗ 내**보다** 형이 더 … |

- A ที่รับ **이/가** = ตัวที่ "…กว่า"
- B ที่ติด **보다** = ตัวที่ถูกเอามาเทียบ (ด้อยกว่า)

#### กับดัก

กับดักเหล่านี้เป็นข้อผิดด้านรูปและด้านตำแหน่งคำ ข้อสุดท้ายเกี่ยวกับกาลของประโยค

- **ไม่ต้องใส่ 이/가/을/를 หลัง 보다:** ✗ 서울보다가 ✗ 서울이보다 ✗ 서울보다를
- **ไม่เว้นวรรค:** ✗ 서울 보다 → ✓ 서울보다
- **ใช้ 더 ก่อนกริยา/คำคุณศัพท์:** ✓ 더 커요 ✗ 커요 더 ✗ 더 보다 ถ้าไม่ใช้ 더 ก็เข้าใจได้ (말하기가 듣기보다 어려워요)
- **많아요 vs 많이:** คำคุณศัพท์ 많다 → **많아요** (커피가 주스보다 **많아요**) ส่วนกริยาใช้ **많이** (형보다 내가 더 **많이** 먹어요) — ข้อ 18
- **ความถี่/วิธี:** วาง **더 자주 · 더 빨리 · 더 잘** ไว้ก่อนกริยา เช่น 친구하고 **더 자주** 전화해요 *(โทรหาเพื่อนบ่อยกว่า)*
- **ไทยวางตรงกันข้าม:** "A สูงกว่า B" → เกาหลี **B보다 A가 크다** (หรือ A가 B보다 크다) คุณศัพท์อยู่ท้ายสุดเสมอ
- **ปริมาณที่ชัดเจน (เสริม):** 훨씬 *(มาก ๆ)* และ 조금 *(นิดหน่อย)* วางหน้า 더: 훨씬 더 추워요 *(หนาวกว่ามาก)*
- **อดีต/ปัจจุบัน:** ผันที่กริยา/คำคุณศัพท์ท้ายประโยค เช่น 올해가 작년보다 더 **추웠어요** *(ปีนี้หนาวกว่า — ถ้าผ่านไปแล้ว)*

#### 보다 (2 สิ่ง) vs 중에서 제일 (3 สิ่งขึ้นไป)

สองรูปนี้ต่างกันที่จำนวนสิ่งที่เทียบ ถ้าเทียบสองสิ่งใช้ 보다 แต่ถ้าเลือกที่สุดจากสามสิ่งขึ้นไปใช้ 중에서 제일

| รูป | จำนวนที่เทียบ | ตัวอย่าง |
|:---|:---|:---|
| **A가 B보다 더** (ข้อ 41) | **2** สิ่ง | 겨울이 가을보다 추워요. *(ฤดูหนาวหนาวกว่าฤดูใบไม้ร่วง)* |
| **N 중에서 A가 제일** (ข้อ 45) | **3** สิ่งขึ้นไป | 계절 중에서 겨울이 제일 추워요. *(ในบรรดาฤดู หนาวที่สุดคือฤดูหนาว)* |

> [!TIP] กฎสั้น ๆ
> - **A이/가 B보다 (더) + คำคุณศัพท์/กริยา** โดย B คือตัวเทียบที่ติด 보다
> - 보다 ไม่ผัน และไม่ดูตัวสะกด
> - 2 สิ่ง = 보다 และ 3 สิ่ง = 중에서 제일

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ข้อนี้ยังไม่มีข้อสอบจริง จึงมีเพียงการคาดการณ์รูปแบบ

- 26과 อยู่ใน 복습시험③ (11/6 = 22–29과)
- 대화 26-1 · 활동 · 읽기 26-2 ฉบับเต็ม (หน้า 266–269) อยู่ในเล่ม 1 บท 26 — ฝึกจากบทสนทนาและบทอ่านจริงประกอบข้อนี้
- คาดการณ์รูปแบบข้อสอบ (ไม่ใช่ข้อสอบจริง):
  - **เปรียบเทียบจากโจทย์ ＞ ＜:** 제주도 ＞ 서울 / 따뜻하다 → 제주도가 서울보다 따뜻해요 *(เหมือน 연습 1)*
  - **그림을 보고 대답하세요:** 🖼️ คน 2 คนสูงไม่เท่ากัน → 누가 더 커요? → ○○ 씨가 △△ 씨보다 커요 *(ใครสูงกว่า — ○○ สูงกว่า △△)*
  - **ตอบคำถามด้วยไวยากรณ์ที่กำหนด:** 어느 음식이 더 매워요? (떡볶이 / 김밥) → 떡볶이가 김밥보다 매워요 *(อาหารไหนเผ็ดกว่า — ต๊อกบกกีเผ็ดกว่ากิมบับ)*
  - **ต่อกับ -지만 (ข้อ 40):** 서울은 복잡하지만 제 고향은 복잡하지 않아요 → 서울이 제 고향보다 더 복잡해요 *(โซลวุ่นวายแต่บ้านเกิดไม่วุ่นวาย → โซลวุ่นวายกว่าบ้านเกิด)*
  - **말하기 (11/23):** ถามเปรียบเทียบง่าย ๆ (คาดการณ์)
    - 평일하고 주말 중에서 언제 더 바빠요? *(ระหว่างวันธรรมดากับสุดสัปดาห์ เมื่อไรยุ่งกว่า)*
    - 한국 음식하고 고향 음식 중에서 뭐가 더 매워요? *(ระหว่างอาหารเกาหลีกับอาหารบ้านเกิด อะไรเผ็ดกว่า)*
- ข้อผิดที่เคยเจอและเกี่ยวกับข้อนี้ (§6b):
  - ★ **จุดอ้างอิงสลับ** (ข้อ 05: 소파가 테이블 앞 for 뒤) ใน 보다 ก็เหมือนกัน ตัวที่ติด 보다 คือตัวเทียบ
  - **ตอบไม่ตรงคำถาม** (누가 → ตอบคน · 뭐가 → ตอบของ · 언제 → ตอบเวลา)
  - **많이 vs 많아요**
  - ㅈ/ㅊ (**제주도** และ **작년** ใช้ ㅈ)
