## 64. -아/어/여야 하다/되다 (ต้อง… · จะต้อง…จึงจะ…)
ต่อท้ายรากกริยา คำคุณศัพท์ 이다/아니다 และ 있다/없다 แล้วตามด้วย **하다** (หรือ **되다** ในภาษาพูด) เพื่อบอก**ข้อบังคับ ความจำเป็น หรือสิ่งที่ควรเป็น** — 숙제해야 **해요** *(ต้องทำการบ้าน)* · 학생증이 있어야 **해요** *(ต้องมีบัตรนักศึกษา)* — ตำรา 362쪽: obligation, necessity, and what should be
สอนในบท 37 (교과서 362–363쪽 · 준비 2) · ต่อยอดจาก ข้อ 06 (กฎ 아/어/해) · ข้อ 18 (คำคุณศัพท์) · ข้อ 02 (N이다) · ข้อ 48 (-아/어서 "เพราะ" นำหน้า) · ข้อ 55 (-(으)면)
ใช้ต่อใน ข้อ 62 (…아/어야 해요 → …ㄹ게요) · ข้อ 63 (บทเดียวกัน) · ข้อ 55 (…면 …아/어야 해요) และ 읽기 37-2 (마키 씨가 서울을 안내해야 해요)

### 📌 รูปแบบและเงื่อนไข
เลือก 아/어/해 จาก**สระของพยางค์สุดท้ายของราก** — กฎเหมือน -아/어요 (ข้อ 06) แล้วเติม **야 하다** (ภาษาพูด **야 되다**)

| รากศัพท์ | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| **ㅏ · ㅗ** | **-아야 하다** | 가다 → **가야 해요** · 오다 → **와야 해요** · 사다 → **사야 해요** · 앉다 → **앉아야 해요** · 받다 → **받아야 해요** · 갈아타다 → **갈아타야 해요** · 좋다 → **좋아야 해요** *(ต้องไป · ต้องมา · ต้องซื้อ · ต้องนั่ง · ต้องรับ · ต้องเปลี่ยนสาย · ต้องดี)* |
| สระอื่น | **-어야 하다** | 먹다 → **먹어야 해요** · 입다 → **입어야 해요** · 만들다 → **만들어야 해요** · 배우다 → **배워야 해요** · 기다리다 → **기다려야 해요** · 마시다 → **마셔야 해요** |
| **하다** | **해야 하다** | 공부하다 → **공부해야 해요** · 청소하다 → **청소해야 해요** · 준비하다 → **준비해야 해요** · 안내하다 → **안내해야 해요** |
| **있다 / 없다** | **-어야 하다** | 있다 → **있어야 해요** · 없다 → **없어야 해요** · 학생증이 **있어야** 해요 |
| **N이다** | 받침 → N**이어야** · สระ → N**여야** | 한국 음식**이어야 해요** · 의사**여야 해요** *(ต้องเป็นอาหารเกาหลี · ต้องเป็นหมอ)* |
| **N이/가 아니다** | **아니어야 하다** | 학생이 **아니어야 해요** |
| ㅡ-ราก | ㅡ หลุด | 쓰다 → **써야 해요** · 끄다 → **꺼야 해요** · 바쁘다 → **바빠야 해요** |
| 르 · ㄷ · ㅂ ไม่ปกติ | ตามกฎก่อน 아/어 (ข้อ 54 · 51 · 37) | 부르다 → **불러야 해요** · 듣다 → **들어야 해요** · 돕다 → **도와야 해요** · 춥다 → **추워야 해요** |
| ㄹ-ราก | ปกติ (ㄹ คงอยู่ + 아/어) | 살다 → **살아야 해요** · 열다 → **열어야 해요** · 놀다 → **놀아야 해요** |

- **ตำรา 362쪽:** "ใช้แสดงข้อบังคับ ความจำเป็น สิ่งที่ควรเป็น · ต่อหลังรากกริยา คำคุณศัพท์ 이다/아니다 และ 있다/없다 · ㅏ/ㅗ → -아야 하다 · อื่น → -어야 하다 · 하다 → 해야 하다 · N + 이다: สระ → N+여야 하다 · ตัวสะกด → N+이어야 하다 · 아니다 → 아니어야 · 있다/없다 → 있어야/없어야 · **ภาษาพูดใช้ -아/어/여야 되다**"
- **ภาษาพูด:** 해야 **돼요** = 해야 **해요** — มักได้ยิน 돼요 มากกว่าในชีวิตจริง (ตำราเขียนไว้ว่า "colloquial situation") แต่กล่องไวยากรณ์ของตำราใช้ **하다** เป็นรูปหลัก
- **ท่านผู้ใหญ่เป็นประธาน:** ใส่ -(으)시- ที่ 하다: 가셔야 **하세요** *(ท่านต้องไป — เสริม)* · ในตำราใช้ 시 ที่เหตุผล: 어머니가 **아프셔서** 고향에 가야 해요 *(เพราะคุณแม่ป่วย ต้องกลับบ้านเกิด)*
- **เว้นวรรค:** 해야 **해요** · 가야 **돼요** — 하다/되다 แยกคำจาก "-아/어야" (ข้อ 13) · ✗ 해야해요 · ✗ 갈거예요 (ติดกัน — ที่เคยพลาด)
- **เพียง "-아/어야" ไม่ใช่ประโยค** — ต้องต่อ 하다/되다 เสมอ · **ออกเสียง:** 해야 해요 [해야 해요] ไม่มีกฎพิเศษ · 있어야 [이써야] · 없어야 [업써야]

### 📖 ตัวอย่างและการใช้
#### จากกล่องไวยากรณ์และ 준비 (362쪽)
1. 가: 오늘 오후에 만날 수 있어요? — 나: 미안해요. 오늘은 **숙제해야 해요**. *(บ่ายนี้เจอกันได้ไหม — ขอโทษ วันนี้ต้องทำการบ้าน — ข้อ 46)*
2. 학교에 일찍 **와야 해요**. *(ต้องมาโรงเรียนเช้า — ㅗ + 아 → 와)*
3. 시험공부를 **해야 해요**. *(ต้องอ่านหนังสือสอบ)*
4. 한국 음식**이어야 해요**. *(ต้องเป็นอาหารเกาหลี — N이어야)*
5. 시간이 없으니까 빨리 점심을 **먹어야 해요**. *(เพราะไม่มีเวลา ต้องรีบกินข้าวเที่ยง — -(으)니까 ข้อ 50)*
6. 학생증이 **있어야 해요**. *(ต้องมีบัตรนักศึกษา — 있어야)*
7. 가수는 목소리가 **좋아야 해요**. *(นักร้องต้องมีเสียงดี — คำคุณศัพท์ 좋다 → 좋아야)*

#### 연습 1 (362쪽): ตอบด้วย -아/어야 해요
| ถาม | ตอบ | แปล |
|:---|:---|:---|
| 주말에 시간 있어요? (공부하다) | 미안해요. 다음 주에 시험이 있어서 **공부해야 해요**. | ว่างสุดสัปดาห์ไหม — ขอโทษ สัปดาห์หน้ามีสอบ ต้องอ่านหนังสือ — ตำราพิมพ์ไว้ |
| 명동에 어떻게 가요? (갈아타다) | 길음역에서 4호선으로 **갈아타야 해요**. | ไปเมียงดงยังไง — ต้องเปลี่ยนเป็นสาย 4 ที่สถานีกีรึม *(เติมตามกฎ)* |
| 방학 때 뭐 할 거예요? (고향에 가다) | 어머니가 아프셔서 **고향에 가야 해요**. | ช่วงปิดเทอมจะทำอะไร — คุณแม่ป่วยจึงต้องกลับบ้านเกิด *(เติมตามกฎ)* |
| 내일 이리나 씨 생일 파티에 올 수 있어요? (아르바이트를 하다) | 미안해요. **아르바이트를 해야 해요**. | พรุ่งนี้มางานวันเกิดอิรินาได้ไหม — ขอโทษ ต้องทำงานพิเศษ *(เติมตามกฎ)* |
| 휴대 전화가 고장 났어요. 어떻게 해야 해요? (서비스 센터에 가다) | **서비스 센터에 가야 해요**. | มือถือเสีย ต้องทำยังไง — ต้องไปศูนย์บริการ *(เติมตามกฎ)* |
| 아르바이트를 하고 싶어요. 어떻게 해야 해요? (친구에게 부탁하다) | **친구에게 부탁해야 해요**. | อยากทำงานพิเศษ ต้องทำยังไง — ต้องไหว้วานเพื่อน *(เติมตามกฎ)* |

#### 연습 2–3 (363쪽)
- **연습 2 (เหตุการณ์ → ต้องทำอะไร):** 고향에서 친구가 와요 → 방을 **청소해야 해요** *(ตำราพิมพ์ไว้ — เพื่อนจากบ้านเกิดจะมา ต้องทำความสะอาดห้อง)* · 친구 생일이에요 → 선물을 **사야 해요** *(เติมตามกฎ ต้องซื้อของขวัญ)* · 두 달 후에 결혼할 거예요 → *(ตอบเอง เช่น 준비를 시작해야 해요 — ต้องเริ่มเตรียม)* · 다음 주에 고향에 가요 → 비행기표를 **예약해야 해요** *(เติมตามกฎ ต้องจองตั๋วเครื่องบิน)*
- **연습 3 (กลุ่ม 3–4 คน):** 학생은 열심히 **공부해야 해요**. · 학생은 수업에 일찍 **와야 해요**. · 학생은 …… *(นักเรียนต้องขยันเรียน · ต้องมาเรียนเช้า · …)* — เปลี่ยนประธานเป็น 아버지/어머니 · 선생님 · 제 남자(여자) 친구 · 학생 แล้วต่อเอง

#### ในบทสนทนา · บทอ่าน · กิจกรรม (364–367쪽)
- 37-1: 마키: 미안하지만 내일 약속을 좀 바꿀 수 있어요? 고향에서 친구가 **와서** 공항에 **가야 해요**. *(ขอโทษนะ ขอเลื่อนนัดพรุ่งนี้หน่อยได้ไหม เพื่อนจากบ้านเกิดมา ฉันต้องไปสนามบิน — ข้อ 48 + 64)*
- 37-2 (366쪽): 그 친구는 토요일에 서울에 올 거예요. 한국말을 전혀 몰라서 마키 씨가 서울을 **안내해야 해요**. *(เพื่อนคนนั้นจะมาโซลวันเสาร์ ไม่รู้ภาษาเกาหลีเลย มากิจึงต้องพาเที่ยวโซล — ข้อ 48 · 58 전혀)*
- 활동 (365쪽): 마키: 그럼, 우리 파티 준비를 해요. 무엇을 **준비해야 해요**? — 바트: 저는 음식을 만들게요. 마키 씨는 과자하고 음료수를 준비해 주세요. — 마키: 알겠어요. 그리고 청소도 **해야 해요**. *(งั้นเรามาเตรียมปาร์ตี้ ต้องเตรียมอะไรบ้าง — ฉันทำอาหาร คุณมากิเตรียมขนมกับเครื่องดื่ม — ได้ แล้วก็ต้องทำความสะอาดด้วย)* — 바트: 맞아요. 그럼 제가 창문을 닦을게요.

### ⚠️ จุดสับสน
#### -아/어야 하다 vs -(으)ㄹ 거예요 vs -고 싶다 vs -아/어도 되다
| | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| **-아/어야 해요** | **ต้อง** (บังคับ/จำเป็น) | 고향에 가야 해요 *(ต้องกลับบ้านเกิด)* |
| -(으)ㄹ 거예요 (ข้อ 28) | **จะ** (แผน) | 고향에 갈 거예요 *(จะกลับบ้านเกิด)* |
| -고 싶다 (ข้อ 38) | **อยาก** | 고향에 가고 싶어요 *(อยากกลับบ้านเกิด)* |
| -아/어도 되다 *(เสริม — ปรากฏใน 352쪽)* | **ทำได้/อนุญาต** | 여기에 앉아도 돼요? *(นั่งตรงนี้ได้ไหม)* |
| -(으)면 안 되다 *(เสริม)* | **ห้าม** | 앉으면 안 돼요 *(นั่งไม่ได้)* |
| -지 않아도 되다 *(เสริม)* | **ไม่ต้อง** | 안 가도 돼요 *(ไม่ต้องไปก็ได้)* |

- **"ไม่ต้อง" ≠ -아/어야 하다 ปฏิเสธ:** △ 안 가야 해요 *(ต้อง "ไม่ไป" = ไม่ควรไป)* ≠ ✓ 안 가도 돼요 *(ไม่ต้องไป)* — ตำราบท 37 ยังไม่สอนรูปปฏิเสธ (เสริม)
- **ㅏ/ㅗ → 아:** ✓ 가야 · 와야 · 사야 · 앉아야 · 받아야 · 살아야 / ✗ 가아야 · 오아야 · 살어야 · 받어야 (เคยพลาด 살어요 · 받었어요 — ราก ㅏ ต้อง 아)
- **하다 → 해:** ✓ 공부해야 해요 / ✗ 공부하야 해요 · ✗ 공부하어야 해요 (รูปเต็มของตำรา: 하여야 → ย่อเป็น 해야)
- **있다 / 없다:** ✓ 있어야 · 없어야 / ✗ 있아야 (ㅣ → 어)
- **N이다:** ✓ 학생이어야 해요 *(ตัวสะกด → 이어야)* · ✓ 의사여야 해요 *(สระ → 여야)* / ✗ 학생여야 · ✗ 의사이어야 (พูดจริงมักย่อ 학생이어야 → [학쌩이어야])
- **ㅡ/르/ㄷ/ㅂ:** ✓ 써야 · 꺼야 · 불러야 · 들어야 · 도와야 / ✗ 쓰어야 · 부르어야 · 듣어야 · 돕아야
- **ผู้ใหญ่เป็นประธาน:** ✓ 어머니가 아프셔서 *(ตำราใช้)* · △ 어머니가 아파서 *(ไม่ยกย่องแม่ — ข้อ 20)*
- **ตอบให้ตรงคำถาม 어떻게 해야 해요?** → ตอบ**วิธี**: ✓ 서비스 센터에 가야 해요 · 친구에게 부탁해야 해요 / ✗ 내일 가야 해요 (ตอบเวลา — 언제 ไม่ใช่ 어떻게) *(เคยพลาด: 언제 → กิจกรรม สลับกัน)*
- **กรรมใช้ 을/를:** ✓ 방을 청소해야 해요 · 서울을 안내해야 해요 / ✗ 방이 청소해야 해요 (ข้อ 07 — เหมือนกับดัก 가 กับ 받다/듣다)
- **เหตุผล + -아/어야 해요:** ✓ 시험이 있어서 공부해야 해요 · ✓ 시간이 없으니까 빨리 먹어야 해요 *(ข้อ 48 · 50)* — -아/어서 ใช้กับ**ข้อเท็จจริง** แล้วจบด้วย "ต้อง" ได้ แต่ถ้าจบด้วยคำสั่ง/ชวนต้องใช้ -(으)니까 (ข้อ 50)

> [!TIP]
> **-아/어야 해요 = "ต้อง…"** — เลือก 아/어/해 จากสระราก (ㅏ/ㅗ → 아 · อื่น → 어 · 하다 → 해) · N → 이어야/여야 · 있다 → 있어야 · **ภาษาพูด 돼요 = 해요** · เว้นวรรค 해야 해요 · "ไม่ต้อง" = 안 -아/어도 돼요 ไม่ใช่ ✗ 안 -아/어야 해요

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- ยังไม่มีข้อสอบจริงเกี่ยวกับ -아/어야 하다 — 37과 อยู่ใน **복습시험④ (11/18 = 30–37과)** และ **기말 (11/20 쓰기·듣기·읽기 · 11/23 말하기)** · ตำรา 363쪽 ให้ผู้เรียนเปลี่ยนเหตุการณ์เป็น "ต้องทำอะไร" ซึ่งเหมาะกับ 쓰기 "ตอบด้วยไวยากรณ์ที่กำหนด" และ 말하기 (ถาม 어떻게 해야 해요?)
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ (CLAUDE.md §6b):** ★ **ㅏ-ราก + 어요:** 살어요 · 살었어요 · 받었어요 ✗ → 아 → ใช้กับ 살아야 해요 · 받아야 해요 · **ㅡ-drop** ทำถูกอยู่แล้ว (바빴어요 · 컸어요) → ใช้ต่อกับ 써야 · 꺼야 · ★ **ตอบคำถามไม่ตรง** (언제 → กิจกรรม) → 어떻게 해야 해요? ต้องตอบวิธี · **กรรมใช้ 가 แทน 를** (시계가 받았어요 · 이야기가 들었어요) · **เขียนติดกัน** 갈거예요 · 청소할거예요 → 해야 해요 ต้องเว้นวรรค · **สะกดตัวสุดท้าย** 가르칠 거요 ✗ · **tense หลุดเมื่อแปลงรูป** (숙제를 안 했어요 → 하지 않습니다) · ลืม 으 (읽세요) · ㅈ/ㅊ (몇 → 몆 · 책 → 젝) · ㅐ/ㅔ
- **คาดการณ์รูปแบบข้อสอบ** (เดาจากรูปแบบ 복습시험①②):
  1. **ผันตาราง/เติมคำ:** 가다 · 오다 · 먹다 · 하다 · 있다 · 좋다 · 학생이다 → ___야 해요 (เน้น ㅏ/ㅗ และ 하다 → 해)
  2. **ตอบด้วยไวยากรณ์ที่กำหนด:** 주말에 시간 있어요? (공부하다) → 미안해요. 시험이 있어서 공부해야 해요 · 휴대 전화가 고장 났어요. 어떻게 해야 해요? (서비스 센터에 가다)
  3. **เขียนประโยค (문장을 만드세요):** 학생 / 열심히 / 공부하다 → 학생은 열심히 공부해야 해요 · 고향에서 친구가 와요 → 방을 청소해야 해요
  4. **읽기 37-2 → บทสนทนา 가/나:** 마키: 내일 약속을 취소해야 해요. 고향에서 친구가 와서 공항에 가야 해요 ↔ ฟัง 37-1 แล้วตอบ "마키 씨는 내일 어디에 갑니까?" (ตำรา 364쪽: 공항)
