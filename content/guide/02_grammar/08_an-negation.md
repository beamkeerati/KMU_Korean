## 08. 안 (ปฏิเสธ "ไม่…" วางหน้ากริยา/คุณศัพท์)

> [!INTRO] ข้อนี้คืออะไร
> 안 คือคำปฏิเสธที่วางหน้ากริยาหรือคำคุณศัพท์ ใช้ในภาษาพูด แปลว่า "ไม่…"
>
> สอนในบท 12 (교과서 104쪽) ต่อยอดจากข้อ 06 (กริยา-아/어/여요 ที่ผันแล้ว) และข้อ 07 (กรรม 을/를)
>
> ไปใช้ต่อในข้อ 16 (-지 않다 = 안 แบบยาว) ข้อ 18 (คุณศัพท์) และข้อ 23 (안 갔어요 = 가지 않았어요)

### 📌 รูปแบบและเงื่อนไข

ให้ผันกริยาเป็น -아/어요 ก่อน แล้ววาง 안 ไว้ข้างหน้า ส่วนกริยา N + 하다 ต้องแทรก 안 ไว้ตรงกลาง ตารางนี้สรุปตำแหน่งของ 안 ในแต่ละชนิด

| ชนิด | โครงสร้าง | ตัวอย่าง |
|:---|:---|:---|
| กริยาทั่วไป | **안** + กริยา-아/어요 | 가요 → **안** 가요 *(ไม่ไป)* · 마셔요 → **안** 마셔요 *(ไม่ดื่ม)* · 읽어요 → **안** 읽어요 *(ไม่อ่าน)* |
| มีกรรม | กรรม을/를 + **안** + กริยา | 커피를 **안** 마셔요 *(ไม่ดื่มกาแฟ)* · 선생님을 **안** 만나요 *(ไม่พบครู)* |
| N + 하다 | N(을/를) **안** 해요 — **안 แทรกกลาง** | 공부 **안** 해요 *(ไม่เรียน)* · 운동 **안** 해요 *(ไม่ออกกำลังกาย)* · 일 **안** 해요 *(ไม่ทำงาน)* |
| คุณศัพท์ | **안** + คุณศัพท์ | 날씨가 **안** 좋아요 *({n:อากาศ}{x:ไม่}{v:ดี})* |

#### วาง 안 ที่ไหน

ตำราบอกว่าใช้ 안 หน้ากริยาหรือคุณศัพท์เพื่อบอกปฏิเสธ มักใช้ในภาษาพูด ให้ผันกริยาเป็น -아/어요 ก่อน (ข้อ 06) แล้ววาง **안** ไว้ข้างหน้าโดย**เว้นวรรค 1 ที** และ 안 อยู่ติดหน้ากริยา (หลัง 을/를)

- 안 가요 ✓ · 안가요 ✗
- 커피를 **안** 마셔요 *(ไม่ดื่มกาแฟ — 안 อยู่ติดหน้ากริยา หลัง 를)*

#### N + 하다 และกริยาคำเดียวที่ลงท้าย 하다

ตำราบอกว่ากริยา "N + 을/를 + 하다" ปฏิเสธเป็น **N을/를 안 해요** ไม่ใช่ **안 N을/를 해요** เพราะ N + 하다 แยกเป็นสองคำ จึงแทรก 안 ระหว่างนามกับ 해요 (ละ 를 ได้) ส่วนกริยาคำเดียวที่ลงท้าย 하다 ไม่แยก

- 공부(를) **안** 해요 ✓ · 안 공부해요 ✗
- **안** 좋아해요 ✓ · 좋아 안 해요 ✗ — 좋아하다 · 싫어하다 เป็นกริยาคำเดียว

#### ตอบคำถามปฏิเสธ

ตอบด้วย 아니요 แล้วตามด้วยประโยคเดิมที่ใส่ 안

- 시장에 가요? → 아니요, 시장에 **안** 가요. *(ไปตลาดไหม → ไม่ ไม่ไปตลาด)*

#### ที่ใช้ 안 ไม่ได้: 이다 และ 있다

이다 และ 있다 มีรูปปฏิเสธของตัวเอง จึงไม่ใช้ 안

- 학생**이 아니에요** *(ไม่ใช่นักเรียน — ข้อ 02)* · ✗ 학생이 안 이에요
- **없어요** *(ไม่มี/ไม่อยู่ — ข้อ 05)* · ✗ 안 있어요

#### 📽️ จากสไลด์อาจารย์ — 12과

สไลด์ของครูแบ่งเป็น 2 กฎ คือ 안 + กริยา และ นาม + 안 + 하다

- **1. 안 + 동사**: 마시다 → **안** 마셔요 *(ไม่ดื่ม)*
- **2. 명사 + 안 + 하다**: 공부(를) 하다 → 공부(를) **안** 해요 *(ไม่เรียน)*
- สรุป: 안 วางหน้ากริยา แต่ N + 하다 วางระหว่างนามกับ 해요 (ห้าม 안 공부해요)

### ⚠️ จุดสับสน

จุดสับสนมีสามเรื่อง คือ 안 กับ -지 않다 ที่ความหมายเท่ากันแต่ตำแหน่งต่างกัน การวาง 안 ผิดที่กับ N + 하다 และ 안 ที่แปลว่า "ไม่" กับ "ใน"

#### 안 vs -지 않다

ไทยแปลทั้งคู่ว่า "ไม่" จึงนึกว่าใช้แทนกันได้ทุกที่ ความหมายเท่ากันจริง แต่ตำแหน่งในประโยคต่างกัน โดยเฉพาะกับกริยา N + 하다 (-지 않다 เรียนบท 14 → ข้อ 16)

| | 안 + กริยา | กริยา + -지 않다 |
|:---|:---|:---|
| ความหมาย | ไม่ (เท่ากัน) | ไม่ (เท่ากัน) |
| ระดับ | ภาษาพูด (รูปสั้น) | ภาษาพูดเช่นกัน (ตำรา 126쪽) — รูปยาว ใช้เขียนได้ด้วย |
| 가다 | 안 가요 | 가지 않아요 |
| 공부하다 (N+하다) | 공부 **안** 해요 (แทรกกลาง) | 공부하지 않아요 (ไม่แยก) |
| 좋아하다 (กริยาคำเดียว) | 안 좋아해요 ✓ / 좋아 안 해요 ✗ | 좋아하지 않아요 ✓ |
| 이다 | 학생이 안 이에요 ✗ | 학생이지 않아요 ✗ |

- 저는 운동 **안** 해요. = 저는 운동하**지 않아요**. ✓ *(ฉันไม่ออกกำลังกาย)*
- 저는 커피를 **안** 좋아해요. ✓ *({n:ฉัน}{x:ไม่}{v:ชอบ}{n:กาแฟ})* / 커피를 좋아 안 해요 ✗
- **이다 ปฏิเสธด้วย 안 / 지 않다 ไม่ได้** → ใช้ **이/가 아니에요** เท่านั้น: 저는 학생**이 아니에요**. ✓ *(ฉันไม่ใช่นักเรียน)*

> [!TIP] กฎจำง่าย
> - **안** = ภาษาพูด และแทรกกลาง N + 하다 ได้
> - **-지 않다** = รูปยาว ต่อท้ายรากและห้ามแยก (ตำราหน้า 126 บอกว่าใช้ในภาษาพูดได้เหมือน 안 — ต่างกันที่รูป ไม่ใช่ระดับภาษา)
> - **이다** ไม่ใช้ทั้งสองแบบ → **아니에요**

#### ผิดที่เจอบ่อย

ตารางนี้รวมรูปที่ผิดบ่อยของ 안 พร้อมเหตุผล โดยข้อที่มี ★ เคยพลาดจริง

| ✗ ผิด | ✓ ถูก | เพราะ |
|:---|:---|:---|
| 안 운동해요 · 안 공부해요 | 운동 **안** 해요 · 공부 **안** 해요 | N + 하다 ต้องแทรก 안 ก่อน 해요 ★ เคยพลาด |
| 안 아르바이트 해요 | 아르바이트 **안** 해요 | เหมือนกัน — 아르바이트(를) 하다 ★ 복습시험① 듣기 [9] |
| 좋아 안 해요 | **안** 좋아해요 | 좋아하다 เป็นกริยาคำเดียว แยกไม่ได้ |
| 학생이 안 이에요 · 안 있어요 | 학생이 **아니에요** · **없어요** | 이다/있다 มีรูปปฏิเสธของตัวเอง |
| 안가요 | 안 가요 | เว้นวรรคหลัง 안 |

#### 안 (ไม่) ≠ 안 (ใน) — เขียนเหมือนกัน คนละคำ

안 สองตัวนี้ต่างกันที่ตำแหน่งในประโยค ตัวหนึ่งอยู่หน้ากริยา อีกตัวตามหลังนามพร้อม 에

| | ตำแหน่งในประโยค | ตัวอย่าง |
|:---|:---|:---|
| **안** *ไม่* | หน้ากริยา/คุณศัพท์ | 학교에 **안** 가요 *(ไม่ไปโรงเรียน)* |
| **안** *ใน* (위치 명사 ข้อ 05) | หลังนาม + 에 | 가방 **안에** 있어요 *(อยู่ในกระเป๋า)* |

  - 카오루 씨가 불고기를 좋아해요? → 좋아하지 않아요 / 안 좋아해요 *(คุณคาโอรุชอบบุลโกกิไหม → ไม่ชอบ)*
  - 투이 씨가 운동해요? → 운동하지 않아요 / 운동 안 해요 *(คุณทุยออกกำลังกายไหม → ไม่ออกกำลังกาย)*
- ★ ข้อผิดที่เคยเจอ: **안 + N하다** ต้องเป็น **N 안 해요**
  - 안 아르바이트 해요 *(복습시험① ฟัง 9)*
  - 안 운동해요 *(매일시험 12과 A2)*
- ฝึกเพิ่ม: ส่วนที่ 5 ชุด E โจทย์ที่ 2

### 🔗 เชื่อมโยง

← ต่อยอดจาก

- ข้อ 06 (กริยา-아/어/여요 ที่ผันแล้ว)
- ข้อ 07 (N을/를 + 안 + V)
- ข้อ 02 (이다 → 아니에요)
- ข้อ 05 (있다 → 없어요)

→ ใช้ต่อใน

- ข้อ 16 (-지 않다 = 안 แบบยาว: 비싸지 않아요 = 안 비싸요)
- ข้อ 18 (안 + คุณศัพท์)
- ข้อ 23 (안 갔어요 = 가지 않았어요)
- ข้อ 09 (บทเดียวกัน: 에 vs 에서)

> [!SUMMARY] สรุป
> - **안** วางหน้ากริยาหรือคุณศัพท์ที่ผันเป็น -아/어요 แล้ว เว้นวรรค 1 ที: 안 가요 · 커피를 안 마셔요
> - **N + 하다** แทรก 안 ตรงกลาง: 공부 안 해요 (✗ 안 공부해요) · กริยาคำเดียว: 안 좋아해요 (✗ 좋아 안 해요)
> - 이다 → 아니에요 · 있다 → 없어요 ห้ามใช้ 안 · 안 (ไม่) ≠ 안 (ใน)
> - -지 않다 คือ 안 แบบยาว (ข้อ 16) ความหมายเท่ากัน ต่างที่ตำแหน่งกับ N + 하다
