## 26. -(으)러 (ไป/มา เพื่อ…)

> [!INTRO] ข้อนี้คืออะไร
> -(으)러 ต่อท้ายรากกริยา แล้วตามด้วย**กริยาเคลื่อนที่** เช่น 가다 · 오다 · 다니다 เพื่อบอก**จุดประสงค์ของการไปหรือมา** เช่น 학교에 한국어를 배우러 가요 *(ไปโรงเรียนเพื่อเรียนภาษาเกาหลี)*
>
> สอนในบท 18 (ตำราหน้า 164) ต่อยอดจาก ข้อ 09 (N에 가요 "จุดหมาย" ↔ N에서 해요 "ที่ทำ") และ ข้อ 06 (ราก) แล้วไปใช้ต่อใน ข้อ 28 (…-(으)러 갈 거예요) และ ข้อ 33 (…-(으)러 갈까요?) ผู้เรียนมักพลาดตอนเขียนเอง คือลืม 으 หลังตัวสะกดและตอบไม่ครบกรรม

### 📌 รูปแบบและเงื่อนไข

-(으)러 ผันตามตัวสะกดของราก ถ้าไม่มีตัวสะกดใช้ -러 ถ้ามีตัวสะกดใช้ -으러 ส่วนรากที่ลงท้าย ㄹ ใช้ -러 ตารางแรกสรุปเงื่อนไข ตารางถัดไปให้ตัวอย่างทีละคำ

| ราก | รูป |
|:---|:---|
| **ไม่มีตัวสะกด** | **-러** |
| **มีตัวสะกด** | **-으러** |
| ตัวสะกด **ㄹ** (เสริม) | **-러** |

| ลักษณะราก | 기본형 | ผลลัพธ์ |
|:---|:---|:---|
| ไม่มีตัวสะกด | 사다 | **사러** |
| ไม่มีตัวสะกด | 보다 | **보러** |
| ไม่มีตัวสะกด | 하다 | **하러** |
| ไม่มีตัวสะกด | 배우다 | **배우러** |
| ไม่มีตัวสะกด | 마시다 | **마시러** |
| ไม่มีตัวสะกด | 만나다 | **만나러** |
| มีตัวสะกด | 먹다 | 먹**으러** |
| มีตัวสะกด | 읽다 | 읽**으러** |
| มีตัวสะกด | 찾다 | 찾**으러** |
| มีตัวสะกด | 씻다 | 씻**으러** |
| มีตัวสะกด | 입다 | 입**으러** |

กฎของราก ㄹ ตำราไม่ได้เขียนไว้ แต่สมุดงาน 18과 D ให้ผัน 만들다 → 만들러

#### โครงสร้างประโยค

โครงสร้างของประโยคที่มี -(으)러 คือ `[สถานที่]에 + [N을/를 + กริยา]-(으)러 + 가요/와요` ตัวหลังต้องเป็นกริยาเคลื่อนที่เสมอ

- สลับ [สถานที่에] กับ [กริยา-러] ได้
  - 서점에 책을 사러 가요 *(ไปร้านหนังสือเพื่อซื้อหนังสือ)*
  - 책을 사러 서점에 가요 *(ไปร้านหนังสือเพื่อซื้อหนังสือ — สลับลำดับ)*
- ตัวหลังต้องเป็น**กริยาเคลื่อนที่** ตามที่ตำราให้ไว้ ได้แก่
  - 가다 · 오다 · 다니다
  - 나가다 · 나오다
  - 들어가다 · 들어오다
- -(으)러 **ไม่ผันกาล** กาลอยู่ที่กริยาท้าย
  - 사러 **갔어요** *(ไปซื้อแล้ว)*
  - 사러 **갈 거예요** *(จะไปซื้อ)*
- กรรมของกริยาหน้า -러 ใช้ 을/를 ตามปกติ และ N하다 ก็ผันได้เช่นกัน
  - 쇼핑**하러** 가요 *(ไปช้อปปิ้ง)*
  - 쇼핑**을 하러** 가요 *(ไปช้อปปิ้ง — เขียนกรรมครบ)*
- ถามจุดประสงค์ใช้ **뭘 하러** 가요? *(ไปทำอะไร)* หรือ **왜** 가요? *(ไปทำไม)* แล้วตอบด้วย N을/를 V-(으)러 가요 (สมุดงาน 18과 F)
- พบใน**ประโยคเชิญ**
  - 저녁에 밥 먹**으러** 우리 집에 오세요. *({n:เย็นนี้}{v:มากิน}{n:ข้าว}{p:ที่}{n:บ้านเรา}นะ)*

### ⚠️ จุดสับสน

แปลเป็นไทยว่า "ไป…กิน" ได้ทั้งคู่ แต่ -(으)러 บอก **จุดประสงค์** ของการไป ส่วน -고 บอก **ลำดับ** (ทำแล้วค่อยไป) ตารางนี้เทียบทีละแถว

| | -(으)러 가요 | -고 가요 |
|:---|:---|:---|
| ความหมาย | ไป**เพื่อ**… | …**แล้ว**ไป |
| ตัวอย่าง | 먹**으러** 가요 *({v:ไป}{e:เพื่อ}{v:กิน})* | 먹**고** 가요 *({v:กิน}{e:แล้ว}{v:ไป})* |
| กริยาท้าย | ต้องเป็นกริยาเคลื่อนที่ | กริยาอะไรก็ได้ |

ประโยคคู่นี้ต่างกันตรงที่ -(으)러 ไปเพื่อกิน ส่วน -고 กินก่อนแล้วค่อยไป

| 한국어 | ไทย |
|:---|:---|
| ✓ 밥을 **먹고** 학교에 가요. | {v:กิน}{n:ข้าว}{e:แล้ว}{v:ไป}{n:โรงเรียน} |
| ≠ 밥을 **먹으러** 학교에 가요. | {v:ไป}{n:โรงเรียน}{e:เพื่อ}{v:กิน}{n:ข้าว} |

ข้อผิดที่เจอบ่อยสรุปเป็นคู่ ✓ / ✗ ได้ตามตารางนี้

| สถานการณ์ | ✓ ถูก | ✗ ผิด | เหตุผล |
|:---|:---|:---|:---|
| กริยาท้าย | 공부하러 도서관에 **가요** | 공부하러 도서관에 **있어요** · **해요** | 있다 · 하다 ไม่ใช่กริยาเคลื่อนที่ |
| ลืม **으** | 씻**으**러 · 찾**으**러 | 씻러 · 찾러 | รากมีตัวสะกดต้องมี **으** |
| ตอบไม่ครบกรรม | **과일을** 사러 · **사진을** 찍으러 | 사러 · 찍으러 | ต้องเขียน "N을/를 + V-러" ครบตาม <보기> |

#### กับดัก

- ✓ 도서관에 공부하러 가요. *(ไปห้องสมุดเพื่อเรียน)* = ✓ 공부하러 도서관에 가요. *(สลับลำดับได้)*
- **에 vs 에서** ต่างกันที่ทำกิจกรรมหรือจุดหมาย
  - ✓ 도서관**에서** 공부해요 *(เรียนที่ห้องสมุด — ที่ทำ)*
  - ✓ 도서관**에** 공부하러 가요 *({v:ไป}{n:ห้องสมุด}{e:เพื่อ}{v:เรียน} — จุดหมาย)*
- ✗ **씻러** → ✓ 씻**으**러 และ ✗ 찾러 → ✓ 찾**으**러 — รู้ในตารางแต่ลืมตอนเขียนเอง
- ตอบให้ครบ **กรรม** ตาม <보기>: ถ้า <보기> เขียน 영화를 보러 ต้องเขียน "N을/를 + V-러" ครบ
- ✓ 친구들과 **놀러** 가요 *(ไปเที่ยวเล่นกับเพื่อน)* และ ✓ 케이크를 **만들러** 가요 *(ไปทำเค้ก — ㄹ-ราก ใช้ -러)*
- ไม่สับสนกับ -(으)ㄹ 거예요 (ข้อ 28): ทั้งคู่มี ㄹ แต่ -(으)러 ต่อด้วยกริยาเคลื่อนที่ ส่วน -(으)ㄹ 거예요 ลงท้าย "거예요" เสมอ
  - ผสมกันได้ เช่น 전시회를 보**러** 갈 **거예요** *(จะไปดูนิทรรศการ)*

> [!TIP] กฎสั้น ๆ
> **-(으)러 = "เพื่อ"** (ต้องตามด้วย 가다/오다…) ส่วน **-고 = "แล้ว"** (ทำก่อน-หลัง)
>
> ไม่มีตัวสะกด → 러 · มีตัวสะกด → 으러 · ถามด้วย 뭘 하러 가요?

> [!SUMMARY] สรุป
> - -(으)러 = "ไป/มา เพื่อ…" ต่อรากกริยา ตามด้วยกริยาเคลื่อนที่เท่านั้น: ไม่มีตัวสะกด → **-러** มีตัวสะกด → **-으러** ราก ㄹ → -러
> - กาลอยู่ที่กริยาท้าย (사러 갔어요 · 사러 갈 거예요) และสลับ [สถานที่에] กับ [กริยา-러] ได้
> - ถามด้วย **뭘 하러 가요?** ตอบด้วย N을/를 V-(으)러 ให้เขียนกรรมครบ
> - อย่าสับสนกับ -고 ("แล้ว") และอย่าลืม **으** หลังตัวสะกด (씻러 ✗ → 씻으러 ✓)
