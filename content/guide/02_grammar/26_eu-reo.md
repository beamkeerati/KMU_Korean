## 26. -(으)러 (ไป/มา เพื่อ…)
ต่อท้ายรากกริยา แล้วตามด้วย **กริยาเคลื่อนที่** (가다 · 오다 · 다니다 · 나가다 · 나오다 · 들어가다 · 들어오다) บอก **จุดประสงค์ของการไป/มา** · **สอนในบท 18** (교과서 164쪽)
ต่อยอดจาก ข้อ 09 (N에 가요 "จุดหมาย" ↔ N에서 해요 "ที่ทำ") และ ข้อ 06 (ราก) · ใช้ต่อใน ข้อ 28 (…-(으)러 갈 거예요) · ข้อ 33 (…-(으)러 갈까요?)

### 📌 รูปแบบและเงื่อนไข
| ราก | รูป | ตัวอย่าง |
|:---|:---|:---|
| **ไม่มีตัวสะกด** | **-러** | 사다 → **사러** · 보다 → **보러** · 하다 → **하러** · 배우다 → **배우러** · 마시다 → **마시러** · 만나다 → **만나러** |
| **มีตัวสะกด** | **-으러** | 먹다 → 먹**으러** · 읽다 → 읽**으러** · 찾다 → 찾**으러** · 씻다 → 씻**으러** · 입다 → 입**으러** |
| ตัวสะกด **ㄹ** (เสริม) | **-러** | 만들다 → **만들러** · 놀다 → **놀러** (ตำราไม่ได้เขียนกฎนี้ แต่สมุดงาน 18과 D ให้ผัน 만들다 → 만들러) |

* โครงสร้าง `[สถานที่]에 + [N을/를 + กริยา]-(으)러 + 가요/와요` — สลับ [สถานที่에] กับ [กริยา-러] ได้: 서점에 책을 사러 가요 = 책을 사러 서점에 가요
* ตัวหลังต้องเป็น**กริยาเคลื่อนที่** (ตำรา: 가다 · 오다 · 다니다 · 나가다 · 나오다 · 들어가다 · 들어오다) · -(으)러 **ไม่ผันกาล** กาลอยู่ที่กริยาท้าย: 사러 **갔어요** · 사러 **갈 거예요**
* กรรมของกริยาหน้า -러 ใช้ 을/를 ตามปกติ · N하다 → 쇼핑**하러** 가요 = 쇼핑**을 하러** 가요
* ถามจุดประสงค์: **뭘 하러** 가요? *(ไปทำอะไร)* หรือ **왜** 가요? *(ไปทำไม)* → ตอบด้วย N을/를 V-(으)러 가요 (สมุดงาน 18과 F)
* พบใน **ประโยคเชิญ**: 저녁에 밥 먹**으러** 우리 집에 오세요. *({n:เย็นนี้}{v:มากิน}{n:ข้าว}{p:ที่}{n:บ้านเรา}นะ)*

### 📖 ตัวอย่างและการใช้
**ตำรา 교과서 164–167쪽**
1. 학교에 한국어를 배우**러** 가요. *({v:ไป}{n:โรงเรียน}{e:เพื่อ}{v:เรียน}{n:ภาษาเกาหลี})* · 커피숍에 친구를 만나**러** 가요 · 도서관에 책을 빌리**러** 가요 · 노래방에 노래를 부르**러** 가요 · 백화점에 옷을 사**러** 가요 · 은행에 돈을 찾**으러** 가요
2. 오후에 공부하**러** 도서관에 가요. *({p:ตอน}{n:บ่าย}{v:ไป}{n:ห้องสมุด}{e:เพื่อ}{v:เรียน})* · 옷을 사**러** 어디에 가세요? *({v:ไป}{q:ไหน}{e:เพื่อ}{v:ซื้อ}{n:เสื้อ}คะ)*

6. คู่ฝึก 166쪽: 은행 / 돈을 찾**으러** · 체육관 / 태권도를 배우**러** · 미용실 / 머리를 자르**러** · 학원 / 러시아어를 배우**러** · 도서관 / 책을 빌리**러** · 운동장 / 농구를 하**러** *({n:ธนาคาร}{v:ถอน}{n:เงิน} · {n:ยิม}{v:เรียน}{n:เทควันโด} · {n:ร้านทำผม}{v:ตัด}{n:ผม} · {n:สถาบัน}{v:เรียน}{n:รัสเซีย} · {n:ห้องสมุด}{v:ยืม}{n:หนังสือ} · {n:สนาม}{v:เล่น}{n:บาสเกตบอล})*
7. 읽기 18-2 (อดีต): 오후 2시에 윤아 씨를 만나**러** 명동에 갔습니다. · 우리는 5시에 바트 씨를 만나**러** 영화관에 갔습니다. *({n:บ่าย}{m:สอง}{v:ไป}{n:เมียงดง}{e:เพื่อ}{v:พบ}{n:คุณยุนอา} · {m:ห้าโมงเย็น}{v:ไป}{n:โรงหนัง}{e:เพื่อ}{v:พบ}{n:คุณบัต})*
8. กิจกรรมทาย 167쪽: 명동에 쇼핑하**러** 갔어요? / 아니요. · 그럼 친구를 만나**러** 갔어요? / 네, 맞아요. *({v:ไป}{n:เมียงดง}{e:เพื่อ}{v:ช้อปปิ้ง}หรือ / {x:ไม่ใช่} · {a:งั้น}{v:ไปพบ}{n:เพื่อน}หรือ / {a:ใช่}{v:ถูก}{e:แล้ว})*

**สถานที่ ↔ จุดประสงค์ที่คู่กัน** (รวบรวมจากตำรา · ใบฝึก · สมุดงาน — ใช้ตอบข้อที่ไม่มีภาพ เช่น 매일시험 18 ข้อ B)

### ⚠️ จุดสับสน
**-(으)러 가다 vs -고 가다** — แปลเป็นไทยว่า "ไป…กิน" ได้ทั้งคู่ แต่ -(으)러 บอก **จุดประสงค์** ของการไป ส่วน -고 บอก **ลำดับ** (ทำแล้วค่อยไป)

| | -(으)러 가요 | -고 가요 |
|:---|:---|:---|
| ความหมาย | ไป**เพื่อ**… | …**แล้ว**ไป |
| ตัวอย่าง | 먹**으러** 가요 *({v:ไป}{e:เพื่อ}{v:กิน})* | 먹**고** 가요 *({v:กิน}{e:แล้ว}{v:ไป})* |
| กริยาท้าย | ต้องเป็นกริยาเคลื่อนที่ | กริยาอะไรก็ได้ |

- ✓ 도서관에 공부하러 가요. = ✓ 공부하러 도서관에 가요. *(สลับลำดับได้)* · ✗ 공부하러 도서관에 **있어요** / **해요** → ✓ **가요** (있다 · 하다 ไม่ใช่กริยาเคลื่อนที่)
- ✓ 밥을 **먹고** 학교에 가요. *({v:กิน}{n:ข้าว}{e:แล้ว}{v:ไป}{n:โรงเรียน})* ≠ 밥을 **먹으러** 학교에 가요. *({v:ไป}{n:โรงเรียน}{e:เพื่อ}{v:กิน}{n:ข้าว})*
- **에 vs 에서:** ✓ 도서관**에서** 공부해요 *(เรียนที่ห้องสมุด — ที่ทำ)* ≠ ✓ 도서관**에** 공부하러 가요 *({v:ไป}{n:ห้องสมุด}{e:เพื่อ}{v:เรียน} — จุดหมาย)*
- ✗ **씻러** → ✓ 씻**으**러 · ✗ 찾러 → ✓ 찾**으**러 (รากมีตัวสะกด ต้องมี **으** — รู้ในตาราง แต่ลืมตอนเขียนเอง)
- ตอบให้ครบ **กรรม** ตาม <보기>: ✗ 사러 / 찍으러 → ✓ **과일을** 사러 · **사진을** 찍으러 (ถ้า <보기> เขียน 영화를 보러 ต้องเขียน "N을/를 + V-러" ครบ)
- ✓ 친구들과 **놀러** 가요 *(ไปเที่ยวเล่นกับเพื่อน)* · ✓ 케이크를 **만들러** 가요 *(ไปทำเค้ก — ㄹ-ราก ใช้ -러)*
- ไม่สับสนกับ -(으)ㄹ 거예요 (ข้อ 28): ทั้งคู่มี ㄹ แต่ -(으)러 ต่อด้วยกริยาเคลื่อนที่ ส่วน -(으)ㄹ 거예요 ลงท้าย "거예요" เสมอ — ผสมกันได้: 전시회를 보**러** 갈 **거예요**

> [!TIP]
> **-(으)러 = "เพื่อ" (ต้องตามด้วย 가다/오다…) · -고 = "แล้ว" (ทำก่อน-หลัง)** · ไม่มีตัวสะกด → 러 · มีตัวสะกด → 으러 · ถามด้วย 뭘 하러 가요?

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- **매일시험 18 (10/14) = 10/10:** B5–7 "…에 뭘 하러 가요?" ตอบด้วย -(으)러 (도서관 → 책을 빌리러 · 은행 → 돈을 찾으러 · 커피숍 → 커피를 마시러 — ไม่มีภาพ ต้องนึกกริยาคู่สถานที่เอง) · C10 เขียนตามคำบอก 체육관에 가요 (ย่อจาก 대화 18-1 "체육관에 운동하러 가요")
- **ใบฝึก 18과 ข้อ B (ดินสอ ถูกทั้ง 15 ช่องรวมทั้ง 씻으러)** แต่ **สมุดงาน 18과 สัปดาห์เดียวกัน:** **씻러** ✗ (E3 → 손을 씻으러) · **사러** ไม่มีกรรม (E4 → 과일을 사러 / 장을 보러) · **찍으러** ไม่มีกรรม (E5 → 사진을 찍으러) — ผันถูกในตาราง แต่พลาดตอนเขียนเอง
- **복습시험② (14–20과 · เก็ง):** 쓰기 ⑤ ดูภาพตอบ "…에 뭘 하러 가요?" · 읽기 18-2 ("윤아 씨를 만나러 명동에 갔습니다" ยกมาตอบช่อง 나) · ใบฝึกฟังบท 20 (ยังไม่ตรวจ) เติม 만나러 · 수영하러
