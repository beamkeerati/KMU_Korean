## 18. 형용사 (คำคุณศัพท์ + การผัน)
คำคุณศัพท์เกาหลีบอก **ลักษณะ/สภาพ** มี **รูปพื้นฐาน (-다)** และผันได้เหมือนกริยา คือเป็น **ภาคแสดง** ได้เอง **ไม่ต้องมี "เป็น"** (이다) — เหมือนภาษาไทยที่ไม่ใส่กริยา ("กระเป๋าเล็ก") · สอนในบท 14 · ต่อยอดจากข้อ 06 (กฎผัน -아/어/여요 ชุดเดียวกัน) และข้อ 01 (이/가) · ใช้ต่อในข้อ 16 (-지 않다), 17 (도), 20 (-(으)세요), 21 (-ㅂ니다), 23 (-았/었), 30 (-네요), 34 (-고)

### 📌 รูปแบบและเงื่อนไข
**สูตร:** `[คำนาม] + 이/가 + [รากคุณศัพท์]-아/어/여요` — 가방**이** 작아요. *(กระเป๋าเล็ก)* · 날씨**가** 좋아요. *(อากาศดี)* · ถามลักษณะ: **어때요?** *(เป็นอย่างไร)* — ตารางด้านล่างคือตาราง 4 กลุ่มของครู (สไลด์ 124쪽) รวมศัพท์จากใบฝึก 14과

| ราก (ตัด 다) | กฎ | ตัวอย่าง |
|:---|:---|:---|
| สระท้ายราก ㅏ · ㅗ | + **아요** | 작다 → 작**아요** · 좋다 → 좋**아요** · 많다 → 많**아요** · 짧다 → 짧**아요** · 싸다 → **싸요** *(ㅏ+아 ยุบ)* |
| สระอื่น ๆ | + **어요** | 적다 → 적**어요** · 길다 → 길**어요** · 재미있다 → 재미있**어요** · 맛있다 → 맛있**어요** · 재미없다 → 재미없**어요** |
| ลงท้าย 하다 | → **해요** | 친절하다 → 친절**해요** · 피곤하다 → 피곤**해요** · 조용하다 → 조용**해요** · 깨끗하다 → 깨끗**해요** |
| ราก **ㅡ** (ตัด ㅡ ทิ้ง) | ดูสระพยางค์หน้า: ㅏ/ㅗ → **아요** · อื่น/ไม่มี → **어요** | 크다 → **커요** · 바쁘다 → **바빠요** · 예쁘다 → **예뻐요** · 나쁘다 → **나빠요** · 아프다 → **아파요** |
| 어떻다 | ท่องเป็นรูปเดียว | **어때요?** · อดีต **어땠어요?** (ข้อ 23) |
| 어둡다 | ท่องเป็นคำ (ผันพิเศษ ยังไม่มีกฎในระดับนี้) | **어두워요** *({v:มืด})* · ส่วน -지 않다 ใช้รากเดิม: 어둡지 않아요 (ตัวอย่างใน 22과) |

* **วิธีคิดเมื่อมี ㅡ:** 바쁘다 → ㅡ ตก เหลือ 바ㅃ + **아** (พยางค์ 바 มี ㅏ) = **바빠요** · 예쁘다 → 예ㅃ + **어** (예 ไม่ใช่ ㅏ/ㅗ) = **예뻐요** · 크다 → ㅋ + **어** (ไม่มีพยางค์หน้า ใช้ 어) = **커요**
* ตำรา (124쪽): คำคุณศัพท์บอกลักษณะหรือสภาพของสิ่งของ มีรูปพื้นฐานและผันได้ — **ไม่มีกรรม** ประธานใช้ **이/가**
* ปฏิเสธ: 안 비싸요 / 비싸지 않아요 (ข้อ 08 · 16) · คุณศัพท์ N+하다 วาง 안 หน้าคำทั้งก้อน: **안 친절해요** (ไม่แยกกลางเหมือนกริยา)

### 📖 ตัวอย่างและการใช้
**คู่ตรงข้ามและคำที่ต้องจำ**

| คู่ / คำ | ตัวอย่าง | ความหมาย |
|:---|:---|:---|
| 길다 ↔ 짧다 | 머리가 길어요 / 짧아요 | ยาว ↔ สั้น |
| 싸다 ↔ 비싸다 | 과일이 싸요 / 비싸요 | ถูก ↔ แพง |
| 재미있다 ↔ 재미없다 | 책이 재미있어요 / 재미없어요 | สนุก ↔ ไม่สนุก |
| 많다 ↔ 적다 | 사람이 많아요 / 적어요 | มาก ↔ น้อย |
| 크다 ↔ 작다 | 키가 커요 / 가방이 작아요 | ใหญ่ (สูง) ↔ เล็ก (เตี้ย) |
| 넓다 ↔ 좁다 | 방이 넓어요 / 좁아요 | กว้าง ↔ แคบ |
| 좋다 ↔ 나쁘다 | 날씨가 좋아요 / 나빠요 | ดี ↔ แย่ |
| 예쁘다 · 멋있다 | 카오루 씨가 멋있어요 | สวย · เท่/หล่อ |
| 바쁘다 · 피곤하다 · 아프다 | 밍밍은 아주 바빠요 · 피곤해요 · 아파요 | ยุ่ง · เหนื่อย · ป่วย/เจ็บ |
| 친절하다 · 조용하다 · 깨끗하다 · 똑똑하다 · 중요하다 | 선생님이 친절해요 · 방이 깨끗해요 | ใจดี · เงียบ · สะอาด · ฉลาด · สำคัญ |

**ประโยคตัวอย่าง (ตำรา 124~127쪽)**
1. 가방이 작아요. *(กระเป๋าเล็ก)* · 자동차가 비싸요. *(รถแพง)* · 학생이 적어요. *({n:นักเรียน}{v:น้อย})*
2. 선생님이 친절해요. *(ครูใจดี)* · 제프리 씨가 친절해요. *(เจฟฟรีย์ใจดี)* · 카오루 씨가 멋있어요. *(คาโอรุเท่)*
3. 사과가 맛있어요. *(แอปเปิ้ลอร่อย)* · 키가 커요. *(ตัวสูง)* · 날씨가 나빠요. *(อากาศแย่)*
4. 가: 카오루 씨 집이 **어때요**? / 나: 작아요. *(บ้านคุณคาโอรุเป็นอย่างไร / เล็ก)* · 서울이 어때요? · 고향이 어때요? · 학교가 어때요?

📽️ **สไลด์อาจารย์ (교과서 124쪽):** `___이/가 형용사-아/어/여요` → 오늘 날씨**가 좋아요**. *(วันนี้อากาศดี)* · 한국 음식**이 맛있어요**. *(อาหารเกาหลีอร่อย)* · 선생님**이 친절해요**. *(ครูใจดี)* — ครูเขียน **어때요?** กำกับไว้เหนือสไลด์ · ใบฝึก 14과 ให้เขียนรูป -아/어요 ใต้ภาพคู่ตรงข้ามทั้งหมด (많아요 · 적어요 · 좋아요 · 나빠요 · 커요 · 작아요 · 싸요 · 비싸요 · 길어요 · 짧아요 · 예뻐요 · 멋있어요 · 맛있어요 · 맛없어요 · 재미있어요 · 재미없어요 · 바빠요 · 아파요 · 넓어요 · 좁아요 · 친절해요 · 피곤해요 · 조용해요 · 깨끗해요 · 똑똑해요 · 중요해요)

**เทียบกับกริยา**

| | กริยา | คำคุณศัพท์ |
|:---|:---|:---|
| ผัน -아/어요 | ✓ | ✓ |
| ปฏิเสธ | 안 가요 / 가지 않아요 | 안 비싸요 / 비싸지 않아요 |
| กรรม (을/를) | ✓ | ✗ ไม่มีกรรม |

### ⚠️ จุดสับสน: คำคุณศัพท์ไม่ใช้ 을/를 และกลุ่ม -있다
คำคุณศัพท์ในภาษาไทยดูเหมือนกริยา ("ชอบ/ดีกับ...") คนไทยจึงใส่กรรม 을/를 หรือ 이에요 ผิด ๆ โดยเฉพาะกลุ่ม 맛있다 / 재미있다 / 멋있다 ที่ลงท้ายด้วย 있다

| | กริยา | คำคุณศัพท์ |
|:---|:---|:---|
| ตัวหน้า | 을/를 (กรรม) | **이/가** (ประธาน) |
| ตัวอย่าง | 김치를 좋아해요 | 날씨가 좋아요 |
| ผิด | | ✗ 날씨를 좋아요 |
| -있다 ผัน | | 맛있어요 ✓ / ✗ 맛있이에요 |
| ถามลักษณะ | | 어때요? (ผิดปกติ ท่องเป็นคำ) |

* ✓ 한국 음식이 맛있어요. / ✗ 한국 음식을 맛있어요. *(อาหารเกาหลีอร่อย)*
* ✓ 이 영화가 재미있어요. / ✗ 재미있이에요 · ✗ 비싸이에요 → ✓ 비싸요 *(ห้ามใส่ 이에요 หลังคำคุณศัพท์)*
* ✗ 크어요 · 바쁘어요 · 예쁘어요 (ลืมตัด ㅡ) → ✓ 커요 · 바빠요 · 예뻐요
* ✓ 날씨가 어때요? — 좋아요. *({n:อากาศ}{q:เป็นอย่างไร} — {v:ดี})* · **어때요 vs 어떻게:** ถาม "เป็นอย่างไร" ตอบด้วยคำคุณศัพท์ใช้ **어때요** · 어떻게 = "อย่างไร/ยังไง" ใช้ในสำนวนอื่น เช่น 성함이 어떻게 되세요? (ข้อ 20)
* ✓ 사과가 좋아요 (ถูกใจ) / ✓ 사과를 좋아해요 (ชอบ) — **좋다 ≠ 좋아하다** → ข้อ 01
* **ยกย่อง -(으)시-** ใส่ได้เมื่อ **ประธานเป็นผู้ใหญ่**: ✓ 선생님이 멋있으세요 · 키가 크세요 · ส่วนอาหารหรือสิ่งของไม่ใส่ 시: ✓ 음식이 맛있어요 / ✗ 음식이 맛있으세요 (ข้อ 20)
* 키 (ส่วนสูง) ใช้ 크다 / 작다 ไม่ใช่ 높다: 키가 **커요** · ประธานของคำคุณศัพท์ใช้ **이/가** (ข้อมูลใหม่) · 은/는 ได้เมื่อเปรียบเทียบ
* 재미있다 · 재미없다 · 맛있다 · 맛없다 · 멋있다 เป็น **คำคุณศัพท์** (ไม่ใช่ "มี/ไม่มี") ผันแบบ 있어요 / 없어요

> [!TIP]
> คำคุณศัพท์ = **이/가 + คำคุณศัพท์** ไม่มี 을/를 · มี ㅡ ให้ตัดแล้วดูสระหน้า (바빠요 · 예뻐요 · 커요) · 어떻다 ใช้ได้แต่รูป **어때요**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
* **매일시험 14과 A** (10 ข้อจากภาพ ข้อละ 0.5 · รวมข้อสอบได้ 7.5/10): พลาด A1 **커요** (เว้นว่าง) · A5 **어두워요** (เว้นว่าง — ศัพท์ผันพิเศษ ท่องเป็นคำ) · A6 **피곤해요** (เขียน 피곤나요 ✗) · ที่เหลือ (작아요 · 비싸요 · 싸요 · 예뻐요 · 멋있어요 · 많아요 · 적어요) ถูกหมด
* **워크북 14과 A–B:** A เลือกคำจาก 보기 16 ข้อ · B ตอบ 어때요? 4 ข้อ — ครูทำเครื่องหมาย A8 · A12 · A13 · A15 · B3 · ส่วน A16 (คนนอนป่วย) ในสแกนเขียน 피곤하다 ซึ่งไม่อยู่ใน 보기 → ต้องเป็น **아프다**
* **อดีตและ 어때요:** ㅡ ตกในอดีตทำถูก (바빴어요 · 컸어요 — 17과) แต่ 어떻다 เคยเขียน **어떻었어요** ✗ → 어땠어요 (워크북 17과 — แม้พิมพ์ 어땠어요 ไว้ใกล้ ๆ) · เคยสับสน **어때요 กับ 어떻게**
* **복습시험 ②:** 쓰기 2 (เติมคำถามจาก 보기) คาดว่ามี 어때요 เช่น "날씨가 ( )? — 아주 좋아요" · 읽기 14-2 เป็นชุดสำรอง
