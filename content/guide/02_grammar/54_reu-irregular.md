## 54. 르 불규칙 (빠르다 → 빨라요 · 모르다 → 몰라요 · 다르다 → 달라요)
กริยา/คำคุณศัพท์ที่**รากลงท้ายด้วย 르** — เมื่อตามด้วย **아/어** ให้**ตัด ㅡ ของ 르 ทิ้ง แล้วเติม ㄹ** หน้าสระ (빠르 + 아요 → 빨라요) · ก่อนพยัญชนะหรือ 으 ไม่เปลี่ยน
สอนในบท 32 (교과서 318쪽 준비 2 + 319쪽 연습 2–3) · ต่อยอดจาก ข้อ 06 (ㅡ-ตกก่อน 아/어: 쓰다 → 써요) · ข้อ 37 (ㅂ 불규칙) · ข้อ 51 (ㄷ 불규칙) · ข้อ 18 (คุณศัพท์) · ข้อ 48 (-아/어서)
ใช้ต่อใน การใช้ -아/어서 เหตุผลที่พบบ่อย (몰라서 · 빨라서 · 달라서) · ข้อ 50 / 56 / 55 (ก่อน 으: 모르니까 · 다를 거예요) · งานพูด (노래를 부르다 · 길을 모르다)

### 📌 รูปแบบและเงื่อนไข
ดู**สระของพยางค์ที่อยู่หน้า 르** เพื่อเลือก 라 / 러 (กฎเดียวกับ 아/어 ข้อ 06): **ㅏ/ㅗ → ㄹ라** · อื่น → **ㄹ러**

| กริยา | + 아/어 (เพิ่ม ㄹ) | + พยัญชนะ (ไม่เปลี่ยน) | + 으 (ไม่เปลี่ยน) |
|:---|:---|:---|:---|
| **빠르다** *(เร็ว)* | **빨라**요 · **빨랐**어요 · **빨라**서 | 빠릅니다 · 빠르고 · 빠르네요 | **빠른** · 빠르니까 · 빠를 거예요 |
| **모르다** *(ไม่รู้)* | **몰라**요 · **몰랐**어요 · **몰라**서 | 모릅니다 · 모르고 · 모르는 | 모르세요 · **모르니까** · 모를 거예요 |
| **다르다** *(ต่าง)* | **달라**요 · **달랐**어요 · **달라**서 | 다릅니다 · 다르고 | **다른** · 다르니까 · 다를 거예요 |
| **부르다** *(ร้อง/เรียก)* | **불러**요 · **불렀**어요 · **불러**서 | 부릅니다 · 부르고 (싶어요) · 부르는 | 부르세요 · 부르니까 · 부를 거예요 |
| **자르다** *(ตัด)* | **잘라**요 · **잘랐**어요 · **잘라**서 | 자릅니다 · 자르고 | 자르세요 · 자르니까 · 자를 수 있어요 |

- **ตำรา 318쪽:** ถ้าพยางค์สุดท้ายของกริยา/คำคุณศัพท์เป็น 르 จะตัด ㅡ ก่อน 아/어 แล้วเติม ㄹ — ตัวอย่างในกล่อง: 날씨가 더워서 머리를 짧게 **잘랐어요** · 단어를 **몰라서** 친구에게 물어봤어요 · 한국 문화와 고향 문화가 **달라요** · 저도 마키 씨처럼 노래를 잘 **부르고** 싶어요
- **เลือก 라/러:** 빠 (ㅏ) → 빨라 · 모 (ㅗ) → 몰라 · 다 (ㅏ) → 달라 · 자 (ㅏ) → 잘라 · **부 (ㅜ → อื่น) → 불러**
- **เสริม (ไม่อยู่ในตำราช่วง 28–32과):** 고르다 → 골라요 *(เลือก)* · 누르다 → 눌러요 *(กด)* · 기르다 → 길러요 *(เลี้ยง)* · 서두르다 → 서둘러요 *(รีบ)* · 오르다 → 올라요 *(ขึ้น)*
- **ออกเสียง (ตำรา 318쪽):** 정류장 [정뉴장] *(ㄹ → ㄴ หลัง ㅇ)* · 빨라요 [빨라요] · 몰라요 [몰라요]

### 📖 ตัวอย่างและการใช้
| | คำถาม | คำตอบ |
|:---|:---|:---|
| 준비 2 | 버스를 탈까요? | 지하철을 타요. 지하철이 더 **빨라요**. *(นั่งรถเมล์ดีไหม — นั่งรถไฟใต้ดินเถอะ รถไฟใต้ดินเร็วกว่า)* |
| 연습 2 | 한국 영화를 이해할 수 있어요? | 아니요. 한국말이 **빨라서** 이해할 수 없어요. *(เข้าใจหนังเกาหลีได้ไหม — ไม่ได้ ภาษาเกาหลีพูดเร็วเลยไม่เข้าใจ)* |

1. 버스 정류장을 **몰라요**. *(ไม่รู้ป้ายรถเมล์)* · KTX가 제일 **빠릅니다 → 빨라요**. *(KTX เร็วที่สุด)* · 제 동생은 노래를 잘 **부릅니다 → 불러요**. *(น้องฉันร้องเพลงเก่ง)* · 제 고향 날씨와 한국 날씨가 **다릅니다 → 달라요**. *(อากาศบ้านเกิดต่างจากเกาหลี)* · 미용실에서 머리를 **자릅니다 → 잘라요**. *(ตัดผมที่ร้านทำผม)* — 연습 1: เปลี่ยน -ㅂ니다 เป็น -아/어요 (แบบ: 버스 정류장을 몰라요)
2. 날씨가 더워서 머리를 짧게 **잘랐어요**. *(อากาศร้อนเลยตัดผมสั้น)* — กล่องตำรา
3. 단어를 **몰라서** 친구에게 물어봤어요. *(ไม่รู้คำศัพท์เลยลองถามเพื่อน — ㄷ + 물어보다 ข้อ 51)*
4. 한국 문화와 고향 문화가 **달라요**. *(วัฒนธรรมเกาหลีกับบ้านเกิดต่างกัน — 와/과 + 다르다 ข้อ 19)*
5. 한국 한자하고 중국 한자하고 같아요? — 아니요, 조금 **달라요**. *(ตัวอักษรจีนเกาหลีกับจีนเหมือนกันไหม — ไม่ ต่างกันนิดหน่อย)*
6. 은행에서 돈을 잘 찾았어요? — 아니요, 비밀번호를 **몰라서** 돈을 찾을 수 없었어요. *(ถอนเงินได้ไหม — ไม่ได้ ไม่รู้รหัสเลยถอนไม่ได้ — ข้อ 46)*
7. 오늘 목소리가 이상하네요? — 어제 노래방에서 노래를 많이 **불러서** 목이 아파요. *(วันนี้เสียงแปลกจัง — เมื่อวานร้องเพลงที่ร้านคาราโอเกะเยอะเลยเจ็บคอ)*
8. 배가 고프네요. — 그럼, 이 케이크를 **잘라서** 같이 먹을까요? *(หิวจัง — งั้นตัดเค้กนี้แล้วกินด้วยกันไหม — -아/어서 ลำดับ ข้อ 53)*
9. 연습 3: 동물 중에서 어느 동물이 제일 **빠릅니까**? · 노래방에서 요즘 자주 **부르는** 노래가 있어요? · 우리 반 학생들 이름을 다 알아요? 누구의 이름을 **모릅니까**? · 1부터 20까지 숫자를 말해 봅시다. 누가 제일 **빠릅니까**? · 한국과 고향 날씨는 어떻게 **다릅니까**? *(สัตว์ตัวไหนเร็วที่สุด · ช่วงนี้มีเพลงที่ร้องบ่อยไหม · รู้จักชื่อเพื่อนครบไหม ไม่รู้ชื่อใคร · นับเลข 1–20 ใครเร็วที่สุด · อากาศเกาหลีกับบ้านเกิดต่างกันยังไง)*
10. 대화 32-1: 그런데 이태원역은 어떻게 가요? 길을 잘 **몰라요**. *(แต่ไปสถานีอีแทวอนยังไง ไม่ค่อยรู้ทาง)* — ใบฟัง 32: 길을 잘 **몰라서** 전화드렸습니다. *(เพราะไม่รู้ทาง จึงโทรมา — ภาคผนวก)*
11. ก่อน 으 (ไม่เปลี่ยน): 길을 **모르니까** 길을 물어보세요. *(ไม่รู้ทาง ลองถามทางดู — 30과 연습)* · 한국 노래를 **부르세요**. *(ร้องเพลงเกาหลีสิ — 30과 연습)* · 이 책은 읽었으니까 **다른** 책을 빌려 주세요. *(เล่มนี้อ่านแล้ว ยืมเล่มอื่น — 30과 กล่อง: 다른 = "อื่น")*

### ⚠️ จุดสับสน
#### 르 불규칙 vs ㅡ-ตกธรรมดา (ข้อ 06)
| | ㅡ-ตกธรรมดา (ข้อ 06) | 르 불규칙 (ข้อ 54) |
|:---|:---|:---|
| ตัวอย่าง | 쓰다 → **써**요 · 아프다 → **아파**요 · 바쁘다 → **바빠**요 · 크다 → **커**요 | 부르다 → **불러**요 · 모르다 → **몰라**요 · 빠르다 → **빨라**요 |
| เพิ่ม ㄹ? | ไม่เพิ่ม | **เพิ่ม ㄹ** ที่พยางค์หน้า |
| รากลงท้าย | ㅡ ล้วน (쓰 · 프 · 쁘 · 크) | **르** (ㄹ + ㅡ) |

#### 3 กริยาไม่ปกติที่ต้องแยกให้ออก
| ชนิด | เปลี่ยนเมื่อ | ตัวอย่าง |
|:---|:---|:---|
| ㅂ (ข้อ 37) | ก่อน**สระ**ทุกตัว (아/어/으): ㅂ → 우/워 | 춥다 → 추워요 · 더우니까 · 매운 |
| ㄷ (ข้อ 51) | ก่อน**สระ**ทุกตัว (아/어/으): ㄷ → ㄹ | 듣다 → 들어요 · 들으세요 |
| **르 (ข้อ 54)** | ก่อน **아/어 เท่านั้น** | 모르다 → **몰라**요 แต่ **모르**세요 · **모르**니까 |

#### กับดักที่เจอบ่อย
- **ก่อน 으 ห้ามเปลี่ยน:** ✓ 모르세요 · 모르니까 · 다른 · 빠른 · 부를 거예요 / ✗ 몰라세요 · ✗ 몰르세요 · ✗ 몰라니까 · ✗ 달른 *(ตำรา: "ก่อน 아/어" เท่านั้น)*
- **ก่อนพยัญชนะห้ามเปลี่ยน:** ✓ 모릅니다 · 빠르고 · 부르고 싶어요 / ✗ 몰랍니다 · ✗ 빨라고 *(ตำรา 318쪽: 저도 마키 씨처럼 노래를 잘 부르고 싶어요)*
- **เลือก 라/러 ผิด:** ✓ 불러요 *(부 = ㅜ → 러)* / ✗ 불라요 · ✓ 빨라요 *(빠 = ㅏ → 라)* / ✗ 빨러요
- **ลืมเติม ㄹ:** ✗ 빠라요 · ✗ 모라요 · ✗ 다라요 → ✓ 빨라요 · 몰라요 · 달라요 · **ใส่ ㄹ ซ้ำ:** ✗ 빨르아요
- **คำ look-alike:** 빨라요 *(เร็ว)* ≠ 빨아요 *(ซัก — 빨다 · 빨래 = ผ้าซัก)* · 달라요 *(ต่าง)* ≠ 달아요 *(หวาน — 달다 เสริม)* · 불러요 *(ร้อง/เรียก)* ≠ 불어요 *(เป่า — 불다)*
- **다르다 ≠ 틀리다:** 다르다 = **ต่าง** (한국 문화와 고향 문화가 달라요) · 틀리다 = **ผิด** (답이 틀렸어요) · ตรงข้าม: 같다 *(เหมือน — 같아요)* ↔ 다르다
- **모르다 ↔ 알다:** "รู้" = 알아요 · "ไม่รู้" = **몰라요** *(ไม่ใช้ ✗ 안 알아요 เป็นรูปมาตรฐาน)* · 알다 = ㄹ-ราก: 알아요 · 아니까 · 압니다 · 아는 *(ข้อ 35)* — ตำรา 연습 3: 이름을 다 **알아요**? ↔ 누구의 이름을 **모릅니까**?
- **빠르다 vs 빨리:** 빠르다 = คำคุณศัพท์ *(เร็ว)* · 빨리 = กริยาวิเศษณ์ *(เร็ว ๆ)* — ✓ 빨리 가세요 *(รีบไป — 30과)* / ✗ 빠르 가세요
- **노래를 부르다:** ตำราใช้ 노래를 **부르다** *(ร้องเพลง — ข้อ 14)* · ผันถูกต้อง: 노래를 부르고 · 노래를 불러요 · 노래를 부르세요
- **สะกด:** 빠르다 (ㅃ ตัวคู่) — ✗ 바르다 *(ถูกต้อง/ทา)* · 달라요 ✗ 다라요

> [!TIP]
> **르 불규칙: ก่อน 아/어 → ㅡ ตก + เติม ㄹ (빠르+아 = 빨라 · 부르+어 = 불러) · ก่อนพยัญชนะ/으 คงเดิม · ท่อง 5 คำ: 빠르다 · 모르다 · 다르다 · 부르다 · 자르다**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- ยังไม่มีข้อสอบจริงที่ครูตรวจแล้วเกี่ยวกับ 르 불규칙 — 32과 อยู่ใน **복습시험④ (11/18, 30–37과)** และ **기말** (เป็นไวยากรณ์ใหม่เอี่ยม ไม่เคยออกใน 복습시험①②)
- **เฉลยภาคผนวก 듣기 32:** ข้อ 나.1 ○ "간토야 씨는 길을 잘 **몰라요**" — เหตุผลที่โทรขอทาง ใช้ 몰라서 ในสคริปต์
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ:** ㅏ-ราก + 어 (살어요 · 받었어요 → ผันสระผิด) · ㅡ-ตกเขียนถูก (바빴어요 · 컸어요 — **ทำถูกอยู่แล้ว ใช้ตรรกะเดียวกัน**) · ㄹ-ราก (만들습니다 · 만들으세요) · ลืม 으 หลังตัวสะกด · 어떻다 → 어땠어요 (ผู้เรียนเขียน 어떻었어요 — ผันไม่ปกติเหมือนกัน ท่องรูป)
- **คาดการณ์รูปแบบข้อสอบ** (จากรูปแบบ 복습시험①②; เป็นการคาด)
  1. **ผันตาราง 4–5 รูป:** 빠르다 · 모르다 · 다르다 · 부르다 · 자르다 → -아/어요 · -았/었어요 · -ㅂ니다 · -아/어서 · -(으)세요
  2. **เติมคำตามเหตุผล:** 한국말이 (　)서 이해할 수 없어요 (빠르다 → 빨라) · 비밀번호를 (　)서 돈을 찾을 수 없었어요 (모르다 → 몰라)
  3. **ตอบคำถามด้วยไวยากรณ์ที่กำหนด:** 노래를 잘 불러요? · 한국과 고향 날씨는 어떻게 달라요? · 우리 반 학생들 이름을 다 알아요? (ตำรา 연습 3 ทั้งชุด)
  4. **แปลง 해요체 → 합니다체 (เหมือนส่วน "해요 → 합니다" ของ 복습시험②):** 빨라요 → 빠릅니다 · 몰라요 → 모릅니다 · 달라요 → 다릅니다 (ตำรา 연습 1 ทำทิศทางตรงข้าม — ผู้เรียนเคยพลาดการแปลงที่ตกกาลหรือสับ 니다/니까)
