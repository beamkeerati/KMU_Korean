## 45. N 중에서 (N을/를) 제일 (ในบรรดา N … ที่สุด)

> [!INTRO] ข้อนี้คืออะไร
> สำนวนนี้ใช้เลือก "ที่สุด" จาก**กลุ่มที่มีหลายสิ่ง** โครงคือ [กลุ่ม] 중에서 [ตัวที่เลือก]이/가 หรือ 을/를 제일 + กริยา/คำคุณศัพท์ เช่น "ในบรรดาฤดู ฉันชอบ**ฤดูใบไม้ผลิ**ที่สุด" = 계절 중에서 봄을 제일 좋아해요
>
> สอนในบท 28 (ตำรา 278–279쪽 준비 1 และ 대화 282쪽 และ 듣기 284쪽) ต่อยอดจากข้อ 41 (보다 เทียบ 2 สิ่ง) ข้อ 34 (무슨 + N) ข้อ 18 (คำคุณศัพท์ + 이/가) ข้อ 07 (을/를) และข้อ 38 (보고 싶다)
>
> ข้อนี้ไปใช้ต่อในข้อ 46 (บทเดียวกัน -(으)ㄹ 수 있다) ข้อ 59 (-는 것: 운동하는 것을 제일 좋아해요) ข้อ 44 (눈이 오는 날이 제일 좋아요) และ 말하기 기말 (11/23)

### 📌 รูปแบบและเงื่อนไข

ตำรา 278쪽 บอกว่าสำนวน "중에서 제일" ใช้บอกว่า**สิ่งหนึ่งดี/เด่นที่สุดในหมู่หลายสิ่ง** ประโยคหนึ่งประกอบด้วยสามส่วนตามตารางนี้

| ส่วน | หน้าที่ |
|:---|:---|
| **[กลุ่ม/หมวด] 중에서** | "ในบรรดา…" (กลุ่มที่มีหลายสิ่ง) |
| **[ตัวที่เลือก]** + 이/가 หรือ 을/를 | สิ่งที่ "ที่สุด" |
| **제일** + กริยา/คำคุณศัพท์ | "ที่สุด" (= **가장**) |

ตารางต่อไปนี้ยกคำที่ตำราใช้ในแต่ละส่วน ช่องว่างในคอลัมน์แรกหมายความว่ายังเป็นส่วนเดียวกับแถวบน

| ส่วน | ตัวอย่าง | ความหมาย |
|:---|:---|:---|
| กลุ่ม | 계절 중에서 | ในบรรดาฤดู |
| | 꽃 중에서 | ในบรรดาดอกไม้ |
| | 가족 중에서 | ในบรรดาครอบครัว |
| | 영화 중에서 | ในบรรดาหนัง |
| | 한국 음식 중에서 | ในบรรดาอาหารเกาหลี |
| | 시험 중에서 | ในบรรดาข้อสอบ |
| | 1년 중에서 | ใน 1 ปี |
| ตัวที่เลือก | 가을**을** | ฤดูใบไม้ร่วง (กรรม) |
| | 어머니**가** | แม่ (ประธาน) |
| | 공포 영화**를** | หนังสยองขวัญ (กรรม) |
| | 비빔밥**이** | บิบิมบับ (ประธาน) |
| 제일 + ภาคแสดง | 제일 좋아해요 | ชอบที่สุด |
| | 제일 보고 싶어요 | คิดถึงที่สุด |
| | 제일 맛있었어요 | อร่อยที่สุด |
| | 제일 추워요 | หนาวที่สุด |
| | 제일 어려워요 | ยากที่สุด |

#### ตัวที่เลือกใช้คำช่วยตัวไหน ดูที่ภาคแสดง

การเลือก 이/가 หรือ 을/를 หลังตัวที่เลือกขึ้นกับว่าภาคแสดงเป็นกริยาหรือคำคุณศัพท์ ตารางนี้สรุปตามตำรา

| ภาคแสดง | คำช่วย | ตัวอย่าง (ตำรา) |
|:---|:---|:---|
| กริยา (좋아하다 · 싫어하다 · 먹다) | **을/를** | 계절 중에서 봄**을** 제일 좋아해요. |
| คำคุณศัพท์ · 있다/없다 (맛있다 · 춥다 · 어렵다) | **이/가** | 한국 음식 중에서 비빔밥**이** 제일 맛있었어요. |
| คำคุณศัพท์ · 있다/없다 | **이/가** | 시험 중에서 말하기**가** 제일 어려워요. |
| -고 싶다 (ข้อ 38) | **이/가** (หรือ 을/를) | 가족 중에서 어머니**가** 제일 보고 싶어요. |
| ถามหา "ใคร" | 누가 | 가족 중에서 **누가** 제일 키가 커요? |
| ถามหา "อะไร" | 무슨 N을/를 | 꽃 중에서 **무슨 꽃을** 제일 좋아해요? |

#### ข้อควรรู้

ข้อต่อไปนี้เป็นกฎการวางคำและการเลือกคำที่ตำราใช้ทุกประโยค

- **제일 วางติดภาคแสดง** ตำราวางทุกประโยคเป็น …을/가 제일 + ภาคแสดง
- **가장** = ความหมายเดียวกับ 제일 (ตำรา 활동 24과 247쪽: 어떤 팀이 주문을 **가장** 잘 합니까? *(ทีมไหนสั่งอาหารเก่งที่สุด)*)
- **ไม่ดูตัวสะกด** ของ 중에서 / 제일 ส่วนคำช่วยหลังตัวเลือกเลือกตามตัวสะกดปกติ (봄**을** · 가을**을** · 겨울**이**)
- กลุ่มเป็น "เวลา/สถานที่" ก็ได้ เช่น 1년 중에서 · 나라 중에서 · 날씨 중에서

#### 대화 28-1 (282쪽)

บทสนทนาที่จีฮุนกับทุ้ยคุยกันเรื่องฤดูที่ชอบ จบด้วยการปฏิเสธคำชวนอย่างสุภาพ

> 투이: 지훈 씨는 계절 **중에서** 무슨 계절을 **제일** 좋아하세요? *(คุณจีฮุน ในบรรดาฤดูกาล ชอบฤดูไหนที่สุดคะ)*
>
> 지훈: 저는 단풍이 아름다운 가을을 좋아해요. 그래서 가을에 등산을 자주 해요. *(ชอบฤดูใบไม้ร่วงที่ใบไม้สวย เลยปีนเขาบ่อย)*
>
> 투이: 저도 등산을 좋아해요. *(ฉันก็ชอบปีนเขา)*
>
> 지훈: 그래요? 내일 같이 산에 갈까요? *(งั้นพรุ่งนี้ไปด้วยกันไหม)*
>
> 투이: 아, 미안해요. 내일 시험이 있어요. 그래서 갈 수 없어요. 다음에 가요. *(ขอโทษ พรุ่งนี้มีสอบ ไปไม่ได้ ไว้คราวหน้า)*

#### 표현 (282쪽): สร้างบทสนทนาแบบเดียวกัน

ตารางคำใบ้ในหน้า 282 ให้สร้างบทสนทนาแบบเดียวกัน แต่ละชุดมี 5 ช่อง คือ เหตุผลที่ชอบ ฤดู กิจกรรม สถานที่ และธุระที่ปฏิเสธ

- 단풍이 아름답다 / 가을 / 등산 / 산에 가다 / 시험이 있다 *(ใบไม้สวย / ใบไม้ร่วง / ปีนเขา / ไปภูเขา / มีสอบ)*
- 바다가 예쁘다 / 여름 / 수영 / 수영장에 가다 / 약속이 있다 *(ทะเลสวย / หน้าร้อน / ว่ายน้ำ / ไปสระ / มีนัด)*
- 눈이 오다 / 겨울 / 스키 / 스키장에 가다 / 바쁜 일이 있다 *(หิมะตก / หน้าหนาว / สกี / ไปลานสกี / มีธุระยุ่ง)*

### ⚠️ จุดสับสน

มีสามเรื่องที่ผู้เรียนมักพลาด คือแยก 보다 ออกจาก 중에서 제일 เลือกคำช่วยตัวเลือกให้ถูก และสะกด ㅈ/ㅊ กับ ㅔ/ㅐ ให้ถูก

#### N보다 (2 สิ่ง) vs N 중에서 제일 (3 สิ่งขึ้นไป)

สองสำนวนนี้ต่างกันที่จำนวนสิ่งที่เทียบ

| | ข้อ 41 보다 | ข้อ 45 중에서 제일 |
|:---|:---|:---|
| จำนวนที่เทียบ | **2** สิ่ง | **3** สิ่งขึ้นไป (กลุ่ม) |
| โครง | A가 B보다 (더) + … | [กลุ่ม] 중에서 A가 **제일** + … |
| ตัวอย่าง | 겨울이 가을보다 더 추워요. | 계절 중에서 겨울이 **제일** 추워요. |

- **ไม่ใช้ร่วมกัน:** ✗ 형보다 내가 제일 ✗ 제일 더 → เลือกอย่างใดอย่างหนึ่ง
- **ตัวเลือกจาก 2 อย่าง ใช้ 더 + 보다:** 봄과 가을 중에서 어느 계절을 더 좋아해요? *(ระหว่างฤดูใบไม้ผลิกับฤดูใบไม้ร่วง ชอบฤดูไหนมากกว่า)* — "중에서" ใช้กับสองสิ่งได้ แต่ใช้ 더 ไม่ใช่ 제일 (เสริม)

#### คำช่วยตัวเลือก: คำคุณศัพท์ = 이/가 · กริยา = 을/를

ข้อผิดหลักคือสลับ 이/가 กับ 을/를 ตามชนิดของภาคแสดง ตารางนี้เทียบรูปที่ถูกกับรูปที่ผิด

| ✗ ผิด | ✓ ถูก | สาเหตุ |
|:---|:---|:---|
| ✗ 겨울**을** 제일 추워요 | ✓ 겨울**이** 제일 추워요 | คำคุณศัพท์ไม่ใช้ 을/를 (ข้อ 18) |
| ✗ 봄**이** 제일 좋아해요 | ✓ 봄**을** 제일 좋아해요 | "ฉันชอบ" ต้องกรรม 을/를 — 좋아하다 เป็นกริยา |

- ✓ 어머니**가** 제일 보고 싶어요 *(싶다 คล้ายคำคุณศัพท์ จึงใช้ 이/가 ได้ — 28 연습 1)*
- ✓ 어머니**를** 제일 보고 싶어요 ก็พบได้

คำถามหาคนหรือของใช้คำต่างกันตามบทบาทในประโยค

| คำถาม | บทบาท | ตัวอย่าง |
|:---|:---|:---|
| **누가** | ใคร (ประธาน) | 가족 중에서 누가 제일 키가 커요? |
| **뭐가 / 무엇이** | อะไร (ประธาน) | 시험 중에서 무엇이 제일 어려워요? |
| **누구를 / 무슨 N을** | กรรม | 꽃 중에서 무슨 꽃을 제일 좋아해요? |

#### กับดักที่เจอบ่อย

ตาราง ✓/✗ ด้านล่างรวมข้อผิดเรื่องการสะกด ส่วนบุลเล็ตเป็นข้อผิดเรื่องตำแหน่งคำและการตอบให้ตรง

| ✗ ผิด | ✓ ถูก | สาเหตุ |
|:---|:---|:---|
| ✗ 층에서 | ✓ 중에서 | ㅈ ไม่ใช่ ㅊ (층 = ชั้น) |
| ✗ 체일 | ✓ 제일 | ㅈ ไม่ใช่ ㅊ |
| ✗ 재일 | ✓ 제일 | ㅔ ไม่ใช่ ㅐ |
| ✗ 게절 | ✓ 계절 | ㅖ |
| ✗ 제절 | ✓ 계절 | ㅖ |
| ✗ 가장 제일 | ✓ 제일 หรือ 가장 | ซ้อนคำ ใช้ตัวเดียว |
| ✗ 중에서에서 | ✓ 중에서 | ซ้อนคำ |
| ✗ 계절은 중에서 | ✓ 계절 중에서 | ไม่มีคำช่วยก่อน 중에서 |

- **ผู้เรียนเขียน ㅈ ให้หัวยื่นเกินจนเป็น ㅊ ซ้ำ ๆ** — เช็กทุกครั้ง (★ ㅈ/ㅊ)
- **ตำแหน่ง 제일:** ตำราวางไว้หน้าภาคแสดงเสมอ → ✓ 봄을 **제일** 좋아해요 ในข้อสอบให้ทำตามนี้ ✗ 제일 봄을 좋아해요 ก็ได้ในภาษาพูด แต่ไม่ใช่ตามตำรา
- **ซ้อนคำ:** ✗ 제일 더 → ใช้ตัวเดียว (ดูตารางข้างบน)
- **무슨 vs 어느 (ข้อ 34):** 꽃 중에서 **무슨** 꽃 *(ดอกอะไร — ชนิด)* ส่วนเลือกจากตัวเลือกที่เห็นตรงหน้า → **어느** (어느 음식이 매워요? — 23과)
- **ตอบให้ตรง:** 무슨 꽃을 제일 좋아해요? → **장미를** (ชื่อดอก) ไม่ใช่เหตุผล และ 누가 제일 …? → ชื่อคน
- **ประโยคเต็มคือคำตอบที่ปลอดภัย:** 저는 장미를 제일 좋아해요 (ข้อ 12 · ส่วนที่ 3)
- **-(으)ㄴ/는 + N เป็นตัวเลือก:** 날씨 중에서 **눈이 오는 날**이 제일 좋아요 *(ข้อ 44 — อนุประโยคขยายนาม "วันที่หิมะตก")*

> [!TIP] กฎสั้น ๆ
> - **[กลุ่ม] 중에서 + [ตัวเลือก] + 제일 + ภาคแสดง** โดย กริยา → 을/를 และ คุณศัพท์ → 이/가
> - 2 สิ่ง = 보다 (ข้อ 41) และ 3 สิ่ง = 중에서 제일
> - ระวัง **중/제 = ㅈ ไม่ใช่ ㅊ**

> [!SUMMARY] สรุป
> - **[กลุ่ม] 중에서 + [ตัวเลือก] + 제일 + ภาคแสดง** ใช้เลือก "ที่สุด" จากกลุ่ม 3 สิ่งขึ้นไป ส่วน 2 สิ่งใช้ A가 B보다 (ข้อ 41)
> - ภาคแสดงเป็นกริยา (좋아하다) → ตัวเลือกใช้ **을/를** ส่วนคำคุณศัพท์ (춥다 · 어렵다) → **이/가** และ -고 싶다 พบได้ทั้งสองแบบ
> - 제일 วางติดภาคแสดง และ 가장 ใช้แทนได้ แต่อย่าซ้อนกัน (✗ 가장 제일)
> - ระวังการสะกด 중에서 · 제일 (ㅈ ไม่ใช่ ㅊ และ ㅔ ไม่ใช่ ㅐ) และ 계절 (ㅖ) รวมทั้งต้องตอบให้ตรงคำถาม
