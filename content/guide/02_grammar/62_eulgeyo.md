## 62. -(으)ㄹ게요 (…นะ · จะ…เอง — สัญญา/อาสาต่อหน้าผู้ฟัง)
ลงท้ายประโยคเมื่อ**ผู้พูดบอกความตั้งใจ/สัญญา/อาสา**กับผู้ฟัง "ฉันจะ…นะ" — ประธานต้องเป็น**ผู้พูดเอง** (ตำรา 354쪽: willingness or promise to the listener — the subject should be the speaker) และใช้ขอ**อนุญาตง่าย ๆ**ได้ ("ขอ…หน่อยนะ")
สอนในบท 36 (교과서 354–355쪽 · 준비 2) · ต่อยอดจาก ข้อ 22 (-겠- ความตั้งใจ) · ข้อ 28 (-(으)ㄹ 거예요) · ข้อ 33 (-(으)ㄹ까요? — กฎ ㄹ/을 เดียวกัน)
ใช้ต่อใน ข้อ 63 (ผู้ฟังขอ -아/어 주세요 → ผู้พูดตอบ -(으)ㄹ게요) · ข้อ 55 (…면 …ㄹ게요) · ข้อ 64 · และ 활동 บท 36–37 (สัญญากับครู/แฟน/แม่)

### 📌 รูปแบบและเงื่อนไข
กฎเหมือน -(으)ㄹ 거예요 (ข้อ 28) และ -(으)ㄹ까요? (ข้อ 33) — ดู**พยางค์สุดท้ายของราก**

| รากศัพท์ลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| **สระ** | **-ㄹ게요** | 가다 → **갈게요** · 오다 → **올게요** · 사다 → **살게요** · 하다 → **할게요** · 전화하다 → **전화할게요** *(จะไป · จะมา · จะซื้อ · จะทำ · จะโทร)* |
| **ตัวสะกด** | **-을게요** | 읽다 → **읽을게요** · 먹다 → **먹을게요** · 앉다 → **앉을게요** · 닫다 → **닫을게요** · 닦다 → **닦을게요** *(จะอ่าน · จะกิน · จะนั่ง · จะปิด · จะเช็ด)* |
| ลงท้าย **ㄹ** | **-게요** (ㄹ ของรากอยู่แล้ว ไม่ซ้ำ ไม่ใส่ 을) | 만들다 → **만들게요** · 열다 → **열게요** · 놀다 → **놀게요** *(จะทำ · จะเปิด · จะเล่น)* |
| ㅂ · ㄷ ไม่ปกติ | ตามกฎก่อน 으 (ข้อ 37 · 51) | 돕다 → **도울게요** · 듣다 → **들을게요** *(จะช่วย · จะฟัง)* |
| 르 · ㅡ | ไม่เปลี่ยน (เปลี่ยนเฉพาะก่อน 아/어) | 부르다 → **부를게요** · 쓰다 → **쓸게요** · 끄다 → **끌게요** |
| พิเศษ: 기다리고 있다 | -고 있을게요 | 기다리고 있다 → **기다리고 있을게요** *(จะรออยู่นะ)* |

- **ตำรา 354쪽:** "ใช้เมื่อผู้พูดแสดงความตั้งใจของตนเองหรือสัญญากับผู้ฟัง ประธานต้องเป็นผู้พูด · ตัวสะกด → -을게요 · สระ → -ㄹ게요 · ㄹ → -게요 · ใช้ขออนุญาตง่าย ๆ ได้ด้วย"
- **ประธานต้องเป็น "ฉัน"** ละได้ หรือใส่ 제가/저는 เมื่อเน้น: **제가** 읽을게요 · **제가** 창문을 닦을게요 *(ฉันเองจะ…)*
- **ใช้กับกริยาเท่านั้น** ไม่ใช้กับคำคุณศัพท์/N이다 · **ไม่ใส่ -(으)시- ไม่ใส่ tense** (ประธานคือผู้พูด จึงไม่ยกย่องตัวเอง)
- **ออกเสียง:** 갈게요 [갈께요] · 읽을게요 [일글께요] · 앉을게요 [안즐께요] · **연락할게요 [열라칼께요]** *(ตำรา 364쪽)* — ㄱ หลัง ㄹ เป็น ㄲ **แต่สะกดด้วย ㄱ: 갈게요** (✗ 갈께요)
- **เสียงตก ↘ เมื่อสัญญา** · **เสียงขึ้น ↗ เมื่อขออนุญาต** (문 좀 열게요? ↗ = ขอเปิดประตูนะ)
- **ห้ามใส่ -(으)시- ให้ตัวเอง:** ✗ 가실게요 — ใช้ 갈게요 ได้แม้ผู้ฟังเป็นผู้ใหญ่ (ความสุภาพอยู่ที่ 요) หรือเปลี่ยนเป็น -겠습니다 (ข้อ 22) ในที่ทางการ

### 📖 ตัวอย่างและการใช้
#### จากกล่องไวยากรณ์และ 준비 (354쪽)
1. 가: 주말에 이 영화를 볼까요? — 나: 좋아요. 제가 표를 **살게요**. *(สุดสัปดาห์ดูหนังเรื่องนี้กันไหม — ได้ ฉันซื้อตั๋วเอง — 사다 + ㄹ게요)*
2. 먼저 **갈게요**. *(ขอไปก่อนนะ — เหมือน "ลาก่อน")*
3. 제가 **읽을게요**. *(ฉันจะอ่านเอง)*
4. 이번에는 제가 **만들게요**. *(ครั้งนี้ฉันจะทำเอง — ㄹ-ราก ไม่ซ้ำ ㄹ)*
5. 문 좀 **열게요**. · 여기 좀 **앉을게요**. *(ขอเปิดประตูหน่อยนะ · ขอนั่งตรงนี้หน่อยนะ — ใช้ขออนุญาตง่าย ๆ)*

#### 연습 1–2 (354–355쪽)
ตำราพิมพ์คำตอบไว้เพียง 전화할게요 (연습 1 ข้อ 1) และ 4시까지 갈게요 (연습 2 ข้อ 1) — ช่องว่างที่เหลือในตารางนี้เติมตามกฎ

| คำถาม/สถานการณ์ | คำตอบ | แปล |
|:---|:---|:---|
| 언제 전화할 거예요? | 이따가 다시 **전화할게요**. | จะโทรเมื่อไร — เดี๋ยวโทรใหม่นะ |
| 어디에서 기다릴 거예요? | 여기서 **기다리고 있을게요**. | จะรอที่ไหน — จะรออยู่ตรงนี้นะ *(เติมตามกฎ)* |
| 음악이 좀 시끄러워요. | 죄송합니다. 조용히 **할게요**. | เพลงดังไปหน่อย — ขอโทษ จะเงียบ ๆ นะ |
| 교실이 너무 더워요. (열다) | 제가 문을 **열게요**. | ห้องร้อนเกินไป — ฉันจะเปิดประตูเอง |
| 지훈 씨, 오늘도 지각했어요. (오다) | 내일은 학교에 일찍 **올게요**. | วันนี้ก็มาสายอีก — พรุ่งนี้จะมาเช้านะ |
| 좀 춥지 않아요? (닫다) | 그럼 창문을 **닫을게요**. | หนาวไหม — งั้นฉันปิดหน้าต่างนะ |
| 피자 좀 더 드세요. (먹다) | 그럼 더 **먹을게요**. | ทานพิซซ่าเพิ่มหน่อย — งั้นจะทานเพิ่มนะ |
| 몇 시까지 올 수 있어요? | 4시까지 **갈게요**. | มาถึงกี่โมงได้ — จะไปถึง 4 โมงนะ |
| 책을 누가 읽을까요? (제가 읽다) | 제가 **읽을게요**. | ใครจะอ่านหนังสือ — ฉันอ่านเอง |
| 지금 전화할 수 있어요? | 아니요. 이따가 **전화할게요**. | โทรคุยตอนนี้ได้ไหม — ไม่ได้ เดี๋ยวโทรไปนะ *(เติมตามกฎ)* |
| 교실이 어두워요. | 제가 불을 **켤게요**. | ห้องมืด — ฉันจะเปิดไฟเอง *(ตำราเว้นว่าง — ตัวอย่างตอบ: 켜다 → 켤게요)* |

- **โจทย์ 연습 2 ข้อ 5:** (식당에서) 오늘 지갑을 안 가지고 왔어요. → ตัวอย่างตอบ: 그럼 오늘은 제가 **살게요** *(งั้นวันนี้ฉันเลี้ยงเอง)*
- **ตัวอย่างจากบทสนทนา 36-1 (356쪽):** 마키: 그럼 우리 영화 보고 같이 식사해요. 저녁은 제가 **살게요**. *(งั้นเราดูหนังแล้วกินข้าวด้วยกัน มื้อเย็นฉันเลี้ยงเอง — 사다 vs 살다 เสียง 살게요 เหมือนกัน)*
- **활동 (357쪽) สัญญาตามบท:** 선생님–학생: 장핑: 죄송합니다. 어제 너무 바빴어요. 내일 꼭 **할게요**. · 책은 가지고 왔어요? — 아니요, 안 가지고 왔어요. 내일은 꼭 가지고 **올게요**. · 연필은 있어요? — 연필도 없어요. 내일은 꼭 준비**할게요**. *(ขอโทษค่ะ เมื่อวานยุ่งมาก พรุ่งนี้จะทำแน่ ๆ · พรุ่งนี้จะเอามาแน่ ๆ · พรุ่งนี้จะเตรียมแน่ ๆ)* · 꼭 = แน่ ๆ
- **37 활동:** 바트: 저는 음식을 **만들게요**. 마키 씨는 과자하고 음료수를 준비해 주세요. · 그럼 제가 창문을 **닦을게요**. *(ฉันจะทำอาหารเอง คุณมากิช่วยเตรียมขนมกับเครื่องดื่ม · งั้นฉันจะเช็ดหน้าต่างเอง)* · 37-1: 지금은 잘 모르겠어요. 나중에 다시 **연락할게요**. *(ตอนนี้ยังไม่แน่ใจ เดี๋ยวติดต่อกลับนะ)*
- **ตำรา 355쪽 연습 3 (สถานการณ์สัญญา):** 오늘 숙제를 안 하면…… · 시험에서 1등을 하면…… · 선생님/친구 생일에…… · 고향에 돌아가면…… *(ใช้ -(으)면 ข้อ 55 + -(으)ㄹ게요: 시험에서 1등을 하면 제가 저녁을 살게요)*

### ⚠️ จุดสับสน
#### -(으)ㄹ게요 vs -(으)ㄹ 거예요 vs -겠- vs -(으)ㄹ까요?
| | ความหมาย | ประธาน | ตัวอย่าง |
|:---|:---|:---|:---|
| **-(으)ㄹ게요** | **สัญญา/อาสา**ต่อหน้าผู้ฟัง (ตัดสินใจ ณ ตอนพูด ผูกกับผู้ฟัง) | **ผู้พูดเท่านั้น** | 제가 할게요 *(ฉันทำเอง)* |
| -(으)ㄹ 거예요 (ข้อ 28) | แผน/คาดเดา (ไม่ต้องเกี่ยวกับผู้ฟัง) | ทุกบุรุษ | 내일 할 거예요 *(พรุ่งนี้จะทำ — แผน)* |
| -겠- (ข้อ 22) | ตั้งใจ ณ ตอนนั้นแบบทางการ | ผู้พูด | 제가 하겠습니다 *(ดิฉันจะทำ — ทางการ)* |
| -(으)ㄹ까요? (ข้อ 33) | **ชวน/เสนอ** ถามความเห็น | 우리 / 제가 (เสนอ) | 제가 열까요? *(ให้ฉันเปิดไหม)* |

- **คำถาม 뭐 할 거예요? ต้องตอบด้วย -(으)ㄹ 거예요:** ✓ 내일은 공부할 거예요 / ✗ 내일은 공부할게요 (ฟังเหมือนสัญญากับผู้ถาม) · ✓ 이따가 다시 전화할게요 *(สัญญาว่าจะโทรกลับ)* ↔ 언제 전화할 거예요? *(ถามแผน)*
- **ไม่ใช้กับบุคคลที่ 2/3:** ✗ 친구가 갈게요 · ✗ 선생님이 오실게요 · ✓ 친구가 갈 거예요 (ข้อ 28) — ตำรา 354쪽 "ประธานต้องเป็นผู้พูด"
- **ไม่ใช้ถามผู้ฟังตรง ๆ:** ✗ 언제 갈게요? → ✓ 언제 갈 거예요? · ถามเสนอตัว: **제가 열까요?** (ข้อ 33) · ผู้ฟังตอบ **네, 열어 주세요** (ข้อ 63) · ผู้พูดตัดสินเอง **제가 열게요**
- **ตัวสะกด:** ✓ 읽을게요 / ✗ 읽게요 · ✓ 앉을게요 / ✗ 앉게요 · ✓ 먹을게요 / ✗ 먹게요 (ลืม 을 — กับดักเดียวกับ 읽세요 · 받십니다 · 씻러 · 먹까요)
- **ㄹ-ราก:** ✓ 만들게요 · 열게요 · 살게요(อยู่) / ✗ 만들을게요 · 열을게요 · ✓ 열게요 *(เปิด)* ≠ 열어요
- **สะกดผิด:** ✗ 갈께요 · ✗ 갈거예요 · ✗ 갈게예요 → ✓ **갈게요** (ㄱ ไม่ใช่ ㄲ · ไม่มี 예 · ไม่เกี่ยวกับ 거예요)
- **ㄷ/ㅂ ไม่ปกติ:** ✓ 들을게요 *(ฟัง)* / ✗ 듣을게요 · ✓ 도울게요 *(ช่วย)* / ✗ 돕을게요 (ข้อ 51 · 37)
- **ไม่ใส่ tense หรือ -(으)시-:** ✗ 갔을게요 · ✗ 가실게요 — ตำราไม่มีรูปเหล่านี้

> [!TIP]
> **-(으)ㄹ게요 = "ฉันจะ…นะ" (สัญญา/อาสา กับผู้ฟัง · ประธาน = ฉัน)** · ตัวสะกด → 을게요 · สระ → ㄹ게요 · ㄹ → 게요 · **ถามแผนผู้ฟัง = -(으)ㄹ 거예요? ไม่ใช่ -(으)ㄹ게요?**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- ยังไม่มีข้อสอบจริงเกี่ยวกับ -(으)ㄹ게요 — 36과 อยู่ใน **복습시험④ (11/18)** และ **기말** · ชื่อบท "저녁은 제가 살게요" และ 활동 (선생님–학생: 내일 꼭 할게요) น่าเป็นหัวข้อ 말하기/쓰기
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ (CLAUDE.md §6b):** ★ **ลืม 으/을 หลังตัวสะกด** — 받십니다 ✗ → 받으십니다 · 읽세요 ✗ → 읽으세요 · 씻러 ✗ → 씻으러 · 먹까요 ✗ → 먹을까요 (ข้อนี้คือ ✗ 읽게요 → 읽을게요) · ㄹ-ราก 만들으세요 ✗ → 만드세요 · **เขียนติดกัน** 갈거예요 · 청소할거예요 · **สะกด 거예요** (가르칠 거요 ✗ → 가르칠 거예요) → ใช้ 갈게요 ให้ถูก · **ตอบไม่ตรงคำถาม** (언제 → กิจกรรม) · **กาลของคำตอบไม่ตรงคำถาม** (어디에 가요? → 서점에 갈 거예요) · **tense หลุดเมื่อแปลงรูป** (숙제를 안 했어요 → 하지 않습니다)
- **คาดการณ์รูปแบบข้อสอบ** (เดาจากรูปแบบ 복습시험①②):
  1. **เติมรูป -(으)ㄹ게요:** 읽다 · 닫다 · 열다 · 만들다 · 돕다 · 듣다 → ___(เน้น ㄹ-ราก/ตัวสะกด/ㄷ/ㅂ)
  2. **ตอบด้วยไวยากรณ์ที่กำหนด:** 교실이 너무 더워요. (열다) → 제가 문을 열게요 · 지훈 씨, 오늘도 지각했어요. (오다) → 내일은 일찍 올게요 · เฉลยต้องมีประธาน 제가 ตามสถานการณ์
  3. **เลือก -(으)ㄹ게요 / -(으)ㄹ 거예요 / -(으)ㄹ까요?:** 가: 책을 누가 읽을까요? — 나: 제가 ( ) → 읽을게요 · 가: 언제 전화할 거예요? — 나: 이따가 ( )
  4. **쓰기 "รูปแบบบทสนทนา" 36 활동:** 선생님–학생 / 엄마–아이 / 남편–아내 → เขียนคำสัญญาด้วย -(으)ㄹ게요 + 꼭
