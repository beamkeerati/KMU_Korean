## 21. -(스)ㅂ니다 · -(스)ㅂ니까? (รูปทางการ)
ท้ายประโยคแบบ **ทางการ** — ประชุม ข่าว แนะนำตัว สัมภาษณ์ และภาษาเขียน (จดหมาย อีเมล ไดอารี่) · **สอนในบท 16** (교과서 144쪽) ส่วนรูปคำนาม **입니다/입니까?** เรียนมาตั้งแต่บท 5 เป็นชนิดเดียวกัน
ต่อยอดจาก ข้อ 06 (รากเดียวกับ -아/어요) · ข้อ 02 (입니다) · ข้อ 16 (-지 않다) · ข้อ 20 (-(으)시-) · ใช้ต่อใน ข้อ 22 (-겠습니다) · ข้อ 23 (갔습니다 · 먹었습니다 ในบทอ่าน 17–18)

### 📌 รูปแบบและเงื่อนไข
📽️ **สไลด์อาจารย์ (교과서 144쪽)** — ตัด 다 → ดูตัวสะกด → ต่อ ㅂ니다 / 습니다 (คำถามเปลี่ยนเป็น -ㅂ니까? / -습니까?) · ครูเขียนเพิ่มด้วยปากกาแดง: **드십니다** (= 드시다 + ㅂ니다) และ **않습니다**

| ลงท้ายราก | บอกเล่า | ถาม | ตัวอย่าง (ตำรา + สไลด์) |
|:---|:---|:---|:---|
| **สระ** | **-ㅂ니다** | **-ㅂ니까?** | 가다 → 갑니다 · 크다 → 큽니다 · 마시다 → 마십니다 · 하다 → 합니다 · 가르치다 → 가르칩니다 · 친절하다 → 친절합니다 |
| **พยัญชนะ** | **-습니다** | **-습니까?** | 먹다 → 먹습니다 · 읽다 → 읽습니다 · 작다 → 작습니다 · 많다 → 많습니다 · 좋다 → 좋습니다 · 있다 → 있습니다 |
| **N + 이다** | **입니다** | **입니까?** | 선생님입니다 · 의사입니다 · 몽골 사람입니다 · 학생입니까? |
| **N + 아니다** | **아닙니다** | **아닙니까?** | 학생이 아닙니다 · 의사가 아닙니다 |
| **-지 않다** (ข้อ 16) | **-지 않습니다** | **-지 않습니까?** | 가지 않습니다 · 바쁘지 않습니까? |
| **-(으)시-** (ข้อ 20) | **-(으)십니다** | **-(으)십니까?** | 가십니다 · 읽으십니다 · 계십니다 · 주무십니다 · 드십니다 |
| **N + 이다 + ยกย่อง** | **N(이)십니다** | **N(이)십니까?** | 선생님**이**십니다 · 아버지십니다 · 의사십니다 · 누구십니까? |
| **-았/었/였-** · **-겠-** | **-았/었/였습니다** · **-겠습니다** | **…습니까? · …겠습니까?** | 갔습니다 · 먹었습니다 · 공부했습니다 · 마시겠습니다 |

* ใช้ได้ทั้ง**กริยาและคำคุณศัพท์**: 날씨가 좋습니다 *(อากาศดี)* · 가방이 예쁩니다 *(กระเป๋าสวย)*
* **ㅡ ไม่หาย**ในรูปนี้ (ㅡ หายเฉพาะตอนต่อท้ายที่ขึ้นต้นด้วย 아/어 เช่น -아/어요 · -았/었-): 예뻐요 แต่ 예쁩니다 · 바빠요 แต่ 바쁩니다 · 커요 แต่ 큽니다
* อดีตและ -겠- ใช้ได้ (ตำรา 144쪽): -았/었/였- ลงท้ายตัวสะกด ㅆ จึงต่อ **-습니다**: 갔습니다 · 먹었습니다 · 마시겠습니다
* (เสริม) ราก ㄹ ตัด ㄹ ก่อน ㅂ: 살다 → 삽니다 · 만들다 → 만듭니다 · 알다 → 압니다 — **ไม่อยู่ในตำรา 5–22과** ใส่ไว้เพราะเจอบ่อย
* ตอบ -(스)ㅂ니까? ด้วย **-(스)ㅂ니다** (ตำรา 145쪽): 한국어를 배우**십니까**? → 네, 한국어를 배**웁니다** · 어디에서 일하**십니까**? → 회사에서 일**합니다** *(ตอบเรื่องตัวเองไม่ใส่ 시)*

| | -아/어요 | -(스)ㅂ니다 |
|:---|:---|:---|
| ระดับ | สุภาพทั่วไป ชีวิตประจำวัน | ทางการ ประกาศ พิธีการ ภาษาเขียน |
| บอกเล่า / ถาม | รูปเดียว (ใช้น้ำเสียงแยก) | -ㅂ니다 / -ㅂ니까? แยกชัด |
| คำนาม | 이에요 / 예요 | 입니다 |
| ยกย่อง | -(으)세요 | -(으)십니다 (ตาราง 2×2 อยู่ที่ข้อ 20) |

### 📖 ตัวอย่างและการใช้
**ตำรา 교과서 144–145쪽 + บทที่เจอ**
1. 집에 가요 → 집에 **갑니다**. · 책을 읽어요 → 책을 **읽습니다**. · 저는 몽골 사람이에요 → 저는 몽골 사람**입니다**. *(ไปบ้าน · อ่านหนังสือ · ฉันเป็นคนมองโกเลีย)*
2. 아버지는 책을 읽**으십니다**. · 김 선생님이 한국어를 가르치**십니다**. *(คุณพ่ออ่านหนังสือ · ครูคิมสอนภาษาเกาหลี)*
3. 가: 제프리 씨, 한국어를 배우**십니까**? / 나: 네, 한국어를 배**웁니다**. *({n:คุณเจฟฟรีย์} {v:เรียน}{n:ภาษาเกาหลี}หรือคะ / {a:ครับ} {v:เรียน})*
4. สัมภาษณ์ 145쪽: 안녕하**십니까**? · 고향이 어디**입니까**? · 어디에서 무엇을 하**십니까**? *({v:สวัสดี}ครับ · {n:บ้านเกิด}{e:อยู่}{q:ที่ไหน}ครับ · {v:ทำ}{q:อะไรที่ไหน}ครับ)*
5. 대화 16-1: 안녕하**십니까**? 이분은 왕쯔이 씨**입니다**. · 반갑**습니다**. 저는 왕쯔이**입니다**. *({v:สวัสดี}ครับ {N:ท่านนี้}{e:คือ}{n:คุณหวังจื่ออี} · {v:ยินดีที่ได้รู้จัก} {n:ฉัน}{n:หวังจื่ออี})*
6. 읽기 17-2 (อีเมลถึงอาจารย์): 러시아에서 **왔습니다**. · 고향에서 영어를 **공부했습니다**. · 한국말을 열심히 **공부하겠습니다**. · 감사**합니다**. *({v:มา}{p:จาก}{n:รัสเซีย} · {v:เรียน}{n:อังกฤษ}{p:ที่}{n:บ้านเกิด} · {e:จะ}{a:ตั้งใจ}{v:เรียน}{n:ภาษาเกาหลี} · {v:ขอบคุณ})*
7. 읽기 18-2 (ไดอารี่): 오늘은 토요일**입니다**. 저는 아침에 늦게 **일어났습니다**. 10시 20분**이었습니다**. *({a:วันนี้}{n:วันเสาร์} {v:ตื่น}{a:สาย}{p:ตอน}{n:เช้า} ตอนนั้น {m:10:20})*

**แปลงบทสนทนาเป็นทางการ (รูปแบบ 매일시험 16 ข้อ A)**
| -아/어요 | -(스)ㅂ니다 | | -아/어요 | -(스)ㅂ니다 |
|:---|:---|:---|:---|:---|
| 안녕하세요? | 안녕하**십니까**? | | 어때요? | 어떻**습니까**? |
| 뭘 하세요? | 뭘 하**십니까**? | | 재미있어요 | 재미있**습니다** |
| 일해요 | 일**합니다** | | 많아요? | 많**습니까**? |
| 있어요 | 있**습니다** | | 맛있어요 | 맛있**습니다** |

### ⚠️ จุดสับสน
**ㅂ니다 vs ㅂ니까** — คนไทยใช้รูปเดียวทั้งบอกเล่าและถาม (ใช้น้ำเสียง) แต่รูปทางการแยกที่ตอนจบ · **입니다 vs 이에요** เป็นคู่เดียวกันคนละระดับ: 학생입니다 (ทางการ) = 학생이에요 (สุภาพ)

| | บอกเล่า | คำถาม |
|:---|:---|:---|
| ทางการ | 갑니다 · 입니다 | 갑니까? · 입니까? |
| สุภาพทั่วไป | 가요 · 이에요 | 가요? · 이에요? |

- ✗ 갑니다? → ✓ 갑니까? · ✗ 학생입니다? → ✓ 학생입니까? (ดู**เครื่องหมายท้ายประโยคเป้าหมาย** — "." → ㅂ니다 · "?" → ㅂ니까)
- ✗ 마시다 → 맙니다 → ✓ 마**십**니다 (ห้ามตัดราก: 마시 + ㅂ니다) · ✗ 읽십니다 / 받십니다 → ✓ 읽**으십**니다 · 받**으십**니다
- ✗ 갔ㅂ니다 / 먹었ㅂ니다 → ✓ 갔**습**니다 · 먹었**습**니다 · ✗ 살습니다 → ✓ 삽니다 (เสริม)
- ✗ 안녀하습니까 → ✓ 안녕하**십**니까 (ต้องมี 시 ยกย่อง)
- ห้ามปนระดับในย่อหน้าเดียว (ยกเว้นเปิด/ปิดอย่าง 발표): ✓ 저는 학생입니다. 한국어를 공부합니다. / ✗ 저는 학생입니다. 한국어를 공부해요.
- ออกเสียง: ㅂ + ㄴ → [ㅁ]: 갑니다 [감니다] · 입니다 [임니다] · 안녕하십니까 [안녕하심니까] · 습니다 [슴니다] · หลังตัวสะกดอื่น ㅅ เข้มขึ้น: 먹습니다 [먹씀니다]

> [!TIP]
> ถาม = **ㅂ니까?** · ตอบ = **ㅂ니다** · สระ → ㅂ니다 · พยัญชนะ → 습니다 · อดีต/겠 → …**습**니다 · ผู้ใหญ่ → …(으)**십**니다

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- **매일시험 16 (10/12) = 10/10:** A แปลงบทสนทนา -아/어요 → -(스)ㅂ니다 6 ช่อง (하십니까 · 일합니다 · 어떻습니까 · 재미있습니다 · 많습니까 · 있습니다) · B เขียนตามคำบอก 반갑습니다 · 선생님이십니다 · 드시겠습니까? · 제 친구입니다 — ข้อ A1 เขียน **합니까** ครูให้เต็ม แต่ต้นฉบับ 하세요 มี 시 จึงควรเป็น **하십니까**
- **ใบฝึก 16과:** **받십니다** ✗ พลาด 2 ครั้ง (→ 받으십니다) · **마시다 → 맙니다** ✗ (ตัดราก → 마십니다) · ช่อง 운동하다 ลอกแถวบน (공부합니까) · **안녀하습니까** ✗ · สลับ 니다/니까 เพราะอ่านประโยคต้นฉบับแทนที่จะดูเครื่องหมายปลายทาง
- **매일시험 17 (10/13) C10:** เขียนตามคำบอก "ตั้งใจเรียน (ทางการ)" = **열심히 공부합니다** (หรือ 하겠습니다) ได้ครึ่งคะแนนเพราะเขียน 열심**이** — รูปทางการออกในข้อเขียนตามคำบอกด้วย
- **สมุดงาน 20과:** **빌렸십니다** ✗ → 빌리셨습니다 / 빌렸습니다 (ผสม 셨 กับ 십니다)
- **복습시험② (14–20과 · เก็ง):** 읽기 17-2 (อีเมล) และ 18-2 (ไดอารี่) เป็นภาษา -습니다 ต้องอ่านออกและเขียนตามได้ · 쓰기 ③ ตารางผัน 4 รูป (갑니다 · 가세요 · 갈 거예요 …)
