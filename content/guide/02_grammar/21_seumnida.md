## 21. -(스)ㅂ니다 · -(스)ㅂ니까? (รูปทางการ)

> [!INTRO] ข้อนี้คืออะไร
> -(스)ㅂ니다 และ -(스)ㅂ니까? คือคำลงท้ายประโยคแบบ**ทางการ** ใช้ในการประชุม ข่าว การแนะนำตัว การสัมภาษณ์ และภาษาเขียน เช่น จดหมาย อีเมล และไดอารี่ รูปบอกเล่าคือ -ㅂ니다/-습니다 ส่วนรูปคำถามคือ -ㅂ니까?/-습니까?
>
> สอนในบท 16 (ตำราหน้า 144) ส่วนรูปคำนาม 입니다/입니까? เรียนมาตั้งแต่บท 5 และเป็นชนิดเดียวกัน ความหมายเหมือนรูป -아/어요 ทุกอย่าง ต่างกันที่ระดับความเป็นทางการเท่านั้น
>
> ต่อยอดจาก ข้อ 06 (รากเดียวกับ -아/어요), ข้อ 02 (입니다), ข้อ 16 (-지 않다) และ ข้อ 20 (-(으)시-) แล้วไปใช้ต่อใน ข้อ 22 (-겠습니다) และ ข้อ 23 (갔습니다 และ 먹었습니다 ในบทอ่าน 17–18)

### 📌 รูปแบบและเงื่อนไข

รูปทางการสร้างจากราก โดยดูว่าพยางค์สุดท้ายมีตัวสะกดหรือไม่ แล้วต่อ ㅂ니다 หรือ 습니다 รูปคำถามเปลี่ยนเป็น -ㅂ니까? หรือ -습니까? ตารางแรกสรุปกฎ ตารางถัด ๆ ไปเป็นตัวอย่างและข้อควรรู้

#### 📽️ ขั้นตอนตามสไลด์อาจารย์ (교과서 144쪽)

ตัด 다 → ดูตัวสะกด → ต่อ ㅂ니다 / 습니다 (คำถามเปลี่ยนเป็น -ㅂ니까? / -습니까?) ครูเขียนเพิ่มด้วยปากกาแดงสองรูปคือ **드십니다** (= 드시다 + ㅂ니다) และ **않습니다**

| ลงท้ายราก | บอกเล่า | ถาม |
|:---|:---|:---|
| **สระ** | **-ㅂ니다** | **-ㅂ니까?** |
| **พยัญชนะ** | **-습니다** | **-습니까?** |
| **N + 이다** | **입니다** | **입니까?** |
| **N + 아니다** | **아닙니다** | **아닙니까?** |
| **-지 않다** (ข้อ 16) | **-지 않습니다** | **-지 않습니까?** |
| **-(으)시-** (ข้อ 20) | **-(으)십니다** | **-(으)십니까?** |
| **N + 이다 + ยกย่อง** | **N(이)십니다** | **N(이)십니까?** |
| **-았/었/였-** · **-겠-** | **-았/었/였습니다** · **-겠습니다** | **…습니까? · …겠습니까?** |

#### ตัวอย่างการผัน: กริยาและคำคุณศัพท์

ตัวอย่างต่อไปนี้มาจากตำราและสไลด์ ใช้ได้ทั้งกริยาและคำคุณศัพท์ สังเกตว่ารากที่ลงท้ายสระต่อ ㅂ니다 ตรง ๆ ส่วนรากที่มีตัวสะกดต้องเติม 습니다

|:---|:---|:---|:---|
| สระ | 가다 | 갑니다 | ไป |
| สระ | 크다 | 큽니다 | ใหญ่ |
| สระ | 마시다 | 마십니다 | ดื่ม |
| สระ | 하다 | 합니다 | ทำ |
| สระ | 가르치다 | 가르칩니다 | สอน |
| สระ | 친절하다 | 친절합니다 | ใจดี |
| พยัญชนะ | 먹다 | 먹습니다 | กิน |
| พยัญชนะ | 읽다 | 읽습니다 | อ่าน |
| พยัญชนะ | 작다 | 작습니다 | เล็ก |
| พยัญชนะ | 많다 | 많습니다 | เยอะ |
| พยัญชนะ | 좋다 | 좋습니다 | ดี |
| พยัญชนะ | 있다 | 있습니다 | มี/อยู่ |

#### ตัวอย่างรูปอื่นที่ใช้ร่วมกับรูปทางการ

รูปคำนาม รูปปฏิเสธ รูปยกย่อง อดีต และ -겠- ก็ต่อท้ายด้วยรูปทางการได้เหมือนกัน ตารางนี้ให้ตัวอย่างทีละรูป

| รูป | 한국어 | ความหมาย |
|:---|:---|:---|
| N + 이다 | 선생님입니다 | เป็นครู |
| N + 이다 | 의사입니다 | เป็นหมอ |
| N + 이다 | 몽골 사람입니다 | เป็นคนมองโกเลีย |
| N + 이다 (ถาม) | 학생입니까? | เป็นนักเรียนหรือ |
| N + 아니다 | 학생이 아닙니다 | ไม่ใช่นักเรียน |
| N + 아니다 | 의사가 아닙니다 | ไม่ใช่หมอ |
| -지 않다 | 가지 않습니다 | ไม่ไป |
| -지 않다 (ถาม) | 바쁘지 않습니까? | ไม่ยุ่งหรือ |
| -(으)시- | 가십니다 | ท่านไป |
| -(으)시- | 읽으십니다 | ท่านอ่าน |
| -(으)시- | 계십니다 | ท่านอยู่ |
| -(으)시- | 주무십니다 | ท่านนอน |
| -(으)시- | 드십니다 | ท่านรับประทาน |
| N + 이다 + ยกย่อง | 선생님**이**십니다 | ท่านเป็นอาจารย์ |
| N + 이다 + ยกย่อง | 아버지십니다 | ท่านเป็นคุณพ่อ |
| N + 이다 + ยกย่อง | 의사십니다 | ท่านเป็นหมอ |
| N + 이다 + ยกย่อง (ถาม) | 누구십니까? | ท่านคือใคร |
| -았/었/였- | 갔습니다 | ไปแล้ว |
| -았/었/였- | 먹었습니다 | กินแล้ว |
| -았/었/였- | 공부했습니다 | เรียนแล้ว |
| -겠- | 마시겠습니다 | จะดื่ม |

#### ข้อควรรู้เมื่อใช้รูปทางการ

ข้อควรรู้ต่อไปนี้คือเรื่องที่ตำราบอกไว้และเรื่องที่ผู้เรียนมักพลาด ตั้งแต่การใช้กับคำคุณศัพท์ไปจนถึงการตอบคำถามที่ลงท้าย -ㅂ니까?

ใช้ได้ทั้งกริยาและคำคุณศัพท์

| 한국어 | ไทย |
|:---|:---|
| 날씨가 좋습니다. | อากาศดี |
| 가방이 예쁩니다. | กระเป๋าสวย |

ในรูปนี้ **ㅡ ไม่หาย** เพราะ ㅡ หายเฉพาะตอนต่อท้ายที่ขึ้นต้นด้วย 아/어 เช่น -아/어요 และ -았/었-

| -아/어요 | -(스)ㅂ니다 | ความหมาย |
|:---|:---|:---|
| 예뻐요 | 예쁩니다 | สวย |
| 바빠요 | 바쁩니다 | ยุ่ง |
| 커요 | 큽니다 | ใหญ่ |

อดีตและ -겠- ใช้ได้ (ตำรา 144쪽) เพราะ -았/었/였- ลงท้ายด้วยตัวสะกด ㅆ จึงต่อ **-습니다** ได้แก่ 갔습니다 · 먹었습니다 · 마시겠습니다

(เสริม) ราก ㄹ ตัด ㄹ ก่อน ㅂ — **ไม่อยู่ในตำรา 5–22과** แต่ใส่ไว้เพราะเจอบ่อย

| 기본형 | -ㅂ니다 | ความหมาย |
|:---|:---|:---|
| 살다 | 삽니다 | อาศัยอยู่ |
| 만들다 | 만듭니다 | ทำ |
| 알다 | 압니다 | รู้ |

ตอบ -(스)ㅂ니까? ด้วย **-(스)ㅂ니다** (ตำรา 145쪽) และตอบเรื่องตัวเองไม่ใส่ 시

| คำถาม | คำตอบ | ไทย |
|:---|:---|:---|
| 한국어를 배우**십니까**? | 네, 한국어를 배**웁니다** | เรียนภาษาเกาหลีหรือครับ — ครับ เรียน |
| 어디에서 일하**십니까**? | 회사에서 일**합니다** | ทำงานที่ไหนครับ — ทำงานที่บริษัท |

#### เทียบกับ -아/어요

ความหมายเหมือนกัน ต่างกันที่ระดับภาษาและการแยกบอกเล่ากับคำถาม

| | -아/어요 | -(스)ㅂ니다 |
|:---|:---|:---|
| ระดับ | สุภาพทั่วไป ชีวิตประจำวัน | ทางการ ประกาศ พิธีการ ภาษาเขียน |
| บอกเล่า / ถาม | รูปเดียว (ใช้น้ำเสียงแยก) | -ㅂ니다 / -ㅂ니까? แยกชัด |
| คำนาม | 이에요 / 예요 | 입니다 |
| ยกย่อง | -(으)세요 | -(으)십니다 (ตาราง 2×2 อยู่ที่ข้อ 20) |

#### สูตรและวิธีทำ: -(스)ㅂ니다 · -(스)ㅂ니까? (แบบกระดานครู)

รูปทางการสร้างจากรากโดยดูแค่ตัวสะกดของพยางค์สุดท้าย ถ้าไม่มีตัวสะกดก็เอา ㅂ ไปวางใต้พยางค์นั้น ถ้ามีตัวสะกดก็ต่อพยางค์ 습 เพิ่มเข้าไป

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | ตัด 다 ออก แล้วดูตัวสะกดของพยางค์สุดท้ายของราก | ตัดสินใจเลือก ㅂ니다 หรือ 습니다 | ดูตัวสะกดอย่างเดียว ไม่ดูสระหรือชนิดคำ |
| **กฎ 2** | ผลของกฎ 1 | ไม่มีตัวสะกด วาง **ㅂ** ใต้พยางค์สุดท้ายแล้วต่อ **니다** และมีตัวสะกด ต่อ **습니다** | ราก ㅡ ยังอยู่ครบ ✗ 바빱니다 และตัวสะกด ㅆ ของ 았/었/겠 ก็นับว่ามี |
| **กฎ 3** | ราก ㄹ (เสริม · เรียนในบท 25) | นับเหมือนไม่มีตัวสะกด ใช้ ㅂ니다 แล้วตัด ㄹ ทิ้ง | ㄹ ไม่อยู่หน้า ㅂ ✗ 살습니다 |
| **กฎ 4** | เป็นประโยคคำถาม | เปลี่ยน **다** เป็น **까** และปิดด้วย ? | ✗ 먹습니다 ใช้ถามไม่ได้ |

ลำดับทำคือ ① ตัด 다 ② ดูตัวสะกด (ㄹ นับว่าไม่มี) แล้วเลือก ㅂ니다 หรือ 습니다 ③ ถ้าเป็นคำถามเปลี่ยน 다 เป็น 까 ตารางนี้แสดงทุกขั้นกับคำที่ตำราใช้

| ราก + คำต่อ | ① ตัด 다 | ② ดูตัวสะกด แล้วเลือก | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 가다 + (스)ㅂ니다 | 가 | ไม่มี → ㅂ니다 | **갑니다** | ㅂ ลงใต้ 가 |
| 마시다 + (스)ㅂ니다 | 마시 | ไม่มี → ㅂ니다 | **마십니다** | ✗ 맙니다 เพราะไม่ตัด 시 |
| 바쁘다 + (스)ㅂ니다 | 바쁘 | ไม่มี → ㅂ니다 | **바쁩니다** | ✗ 바빱니다 เพราะ ㅡ ไม่หายก่อน ㅂ |
| 먹다 + (스)ㅂ니다 | 먹 | มี (ㄱ) → 습니다 | **먹습니다** | ไม่ต้องมี 으 |
| 읽다 + (스)ㅂ니다 | 읽 | มี (ㄺ) → 습니다 | **읽습니다** | ตัวสะกดคู่ก็นับว่ามี |
| 살다 + (스)ㅂ니다 | 살 | ㄹ นับว่าไม่มี → ㅂ니다 แล้วตัด ㄹ | **삽니다** | ✗ 살습니다 (เสริม) |
| 만들다 + (스)ㅂ니다 | 만들 | ㄹ นับว่าไม่มี → ㅂ니다 แล้วตัด ㄹ | **만듭니다** | ✗ 만들습니다 (เสริม) |
| 드시다 + (스)ㅂ니다 | 드시 | ไม่มี → ㅂ니다 | **드십니다** | ครูเขียนด้วยปากกาแดง |
| 가지 않다 + (스)ㅂ니다 | 가지 않 | มี (ㄶ) → 습니다 | **가지 않습니다** | ครูเขียนด้วยปากกาแดง |
| 먹었다 + (스)ㅂ니다 | 먹었 | มี (ㅆ) → 습니다 | **먹었습니다** | ㅆ นับเป็นตัวสะกด |
| 가다 + (스)ㅂ니까? | 가 | ไม่มี → ㅂ니 + 까 | **갑니까?** | 다 → 까 |
| 먹다 + (스)ㅂ니까? | 먹 | มี → 습니 + 까 | **먹습니까?** | ✗ 먹습니다 เมื่อประโยคเป้าหมายเป็นคำถาม |
| 의사 + 이다 | 이 | ไม่แยกตัวสะกด ใช้ 입니다 เสมอ | **의사입니다** | ถาม 입니까? |
| 아니다 + (스)ㅂ니다 | 아니 | ไม่มี → ㅂ니다 | **아닙니다** | N이/가 아닙니다 |

> [!TIP] วิธีจำสั้น ๆ
> ตัด 다 ถามหาตัวสะกด ไม่มีใช้ ㅂ니다 มีใช้ 습니다 (ㄹ นับว่าไม่มีแล้วตัด ㄹ) แล้วดูเครื่องหมายท้ายประโยคเป้าหมาย ถ้าเป็น ? ต้องเปลี่ยน 다 เป็น 까

#### รูปผิด / รูปถูก (-(스)ㅂ니다)

ตารางนี้รวมรูปผิดที่ผู้เรียนเคยเขียนเมื่อเปลี่ยนเป็นรูปทางการ ดูคอลัมน์ขวาว่าผิดที่ขั้นไหนของสูตร

| รูปผิด | รูปถูก | ผิดที่ขั้นไหน |
|:---|:---|:---|
| ✗ 맙니다 | **마십니다** | ขั้น ① ตัด 시 ทิ้งไปด้วย |
| ✗ 바빱니다 | **바쁩니다** | ขั้น ② ตัด ㅡ ทั้งที่ ㅡ หายเฉพาะก่อน 아/어 |
| ✗ 먹습니다 | **먹습니까?** | ขั้น ③ ไม่เปลี่ยน 다 เป็น 까 ตามเครื่องหมาย ? |
| ✗ 살습니다 | **삽니다** | ขั้น ② ไม่นับ ㄹ ว่าไม่มีตัวสะกด |
| ✗ 만들습니다 | **만듭니다** | ขั้น ② ไม่นับ ㄹ ว่าไม่มีตัวสะกด |
| ✗ 숙제를 하지 않습니다 | **숙제를 안 했습니다** | เปลี่ยนแค่ท้ายประโยค ต้องคงอดีตไว้จากต้นฉบับ 안 했어요 |

### 📖 ตัวอย่างและการใช้

ตัวอย่างชุดแรกมาจากตำราหน้า 144–145 ชุดถัดมามาจากบทสนทนาและบทอ่านในบท 16–18 และสุดท้ายเป็นแบบฝึกแปลงบทสนทนาเป็นรูปทางการ ซึ่งออกใน 매일시험 16 ข้อ A

#### จากตำรา 16과 (หน้า 144–145)

ตัวอย่างพื้นฐานของบท 16 สังเกตลูกศรที่แปลงจากรูป -아/어요 เป็นรูปทางการ

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 집에 가요 → 집에 **갑니다**. | ไปบ้าน | ตำรา 144–145쪽 |
| 책을 읽어요 → 책을 **읽습니다**. | อ่านหนังสือ | ตำรา 144–145쪽 |
| 저는 몽골 사람이에요 → 저는 몽골 사람**입니다**. | ฉันเป็นคนมองโกเลีย | ตำรา 144–145쪽 |
| 아버지는 책을 읽**으십니다**. | คุณพ่ออ่านหนังสือ | ตำรา 144쪽 |
| 김 선생님이 한국어를 가르치**십니다**. | ครูคิมสอนภาษาเกาหลี | ตำรา 144쪽 |
| 가: 제프리 씨, 한국어를 배우**십니까**? / 나: 네, 한국어를 배**웁니다**. | {n:คุณเจฟฟรีย์} {v:เรียน}{n:ภาษาเกาหลี}หรือคะ / {a:ครับ} {v:เรียน} | ตำรา 145쪽 |
| 안녕하**십니까**? | {v:สวัสดี}ครับ | สัมภาษณ์ 145쪽 |
| 고향이 어디**입니까**? | {n:บ้านเกิด}{e:อยู่}{q:ที่ไหน}ครับ | สัมภาษณ์ 145쪽 |
| 어디에서 무엇을 하**십니까**? | {v:ทำ}{q:อะไรที่ไหน}ครับ | สัมภาษณ์ 145쪽 |

#### จากบทสนทนาและบทอ่าน (16 · 17 · 18과)

บทสนทนา 16-1 เป็นการแนะนำตัวอย่างทางการ ส่วนบทอ่าน 17-2 เป็นอีเมลถึงอาจารย์ และ 18-2 เป็นไดอารี่ ทั้งสองบทเขียนด้วยภาษา -습니다

#### แปลงบทสนทนาเป็นทางการ (รูปแบบ 매일시험 16 ข้อ A)

โจทย์ให้บทสนทนาแบบ -아/어요 แล้วให้เขียนใหม่เป็น -(스)ㅂ니다 ตารางนี้เป็นคู่ที่ใช้ฝึก

| -아/어요 | -(스)ㅂ니다 | ไทย |
|:---|:---|:---|
| 안녕하세요? | 안녕하**십니까**? | สวัสดี |
| 뭘 하세요? | 뭘 하**십니까**? | ทำอะไร |
| 일해요 | 일**합니다** | ทำงาน |
| 있어요 | 있**습니다** | มี/อยู่ |
| 어때요? | 어떻**습니까**? | เป็นอย่างไร |
| 재미있어요 | 재미있**습니다** | สนุก |
| 많아요? | 많**습니까**? | เยอะไหม |
| 맛있어요 | 맛있**습니다** | อร่อย |

### ⚠️ จุดสับสน

คนไทยใช้รูปเดียวทั้งบอกเล่าและถาม (แยกด้วยน้ำเสียง) แต่รูปทางการแยกที่ตอนจบ คือ **ㅂ니다** สำหรับบอกเล่า และ **ㅂ니까** สำหรับถาม ส่วน **입니다** กับ **이에요** เป็นคู่เดียวกันคนละระดับ เช่น 학생입니다 (ทางการ) = 학생이에요 (สุภาพ)

| | บอกเล่า | คำถาม |
|:---|:---|:---|
| ทางการ | 갑니다 · 입니다 | 갑니까? · 입니까? |
| สุภาพทั่วไป | 가요 · 이에요 | 가요? · 이에요? |

ข้อผิดที่เจอบ่อยสรุปเป็นคู่ ✓ / ✗ ได้ตามตารางนี้

| สถานการณ์ | ✓ ถูก | ✗ ผิด | เหตุผล |
|:---|:---|:---|:---|
| บอกเล่า/ถามสลับกัน | 갑니까? | 갑니다? | ถามต้องลงท้าย ㅂ니까 |
| คำนามถาม | 학생입니까? | 학생입니다? | ถามต้องลงท้าย ㅂ니까 |
| ตัดรากผิด | 마**십**니다 | 마시다 → 맙니다 | ห้ามตัดราก: 마시 + ㅂ니다 |
| ลืม **으** | 읽**으십**니다 · 받**으십**니다 | 읽십니다 · 받십니다 | รากมีตัวสะกดต้องมี **으** |
| อดีตและ 겠 | 갔**습**니다 · 먹었**습**니다 | 갔ㅂ니다 · 먹었ㅂ니다 | ลงท้ายตัวสะกด ㅆ ใช้ 습니다 |
| ราก ㄹ (เสริม) | 삽니다 | 살습니다 | ตัด ㄹ ก่อน ㅂ |
| ลืม 시 | 안녕하**십**니까 | 안녀하습니까 | ต้องมี 시 ยกย่อง |
| ปนระดับภาษา | 저는 학생입니다. 한국어를 공부합니다. | 저는 학생입니다. 한국어를 공부해요. | ห้ามปนระดับในย่อหน้าเดียว |

#### กับดัก

- ดู**เครื่องหมายท้ายประโยคเป้าหมาย** ว่า "." → ㅂ니다 และ "?" → ㅂ니까 (ไม่ใช่ดูประโยคต้นฉบับ)
- ห้ามตัดรากของ 마시다: 마시 + ㅂ니다 = 마**십**니다
- ราก ㄹ ใช้ ✓ 삽니다 (เสริม) ไม่ใช่ ✗ 살습니다
- ต้องมี 시 ยกย่อง เมื่อเป็นคำทักทายผู้ใหญ่: ✓ 안녕하**십**니까
- ห้ามปนระดับในย่อหน้าเดียว ยกเว้นเปิดหรือปิดอย่าง 발표

#### ออกเสียง

ㅂ ตามด้วย ㄴ จะออกเสียงเป็น [ㅁ] ส่วนหลังตัวสะกดอื่น ㅅ ของ 습 จะเข้มขึ้น

| เขียน | อ่าน | กฎ |
|:---|:---|:---|
| 갑니다 | [감니다] | ㅂ + ㄴ → [ㅁ] |
| 입니다 | [임니다] | ㅂ + ㄴ → [ㅁ] |
| 안녕하십니까 | [안녕하심니까] | ㅂ + ㄴ → [ㅁ] |
| 습니다 | [슴니다] | ㅂ + ㄴ → [ㅁ] |
| 먹습니다 | [먹씀니다] | หลังตัวสะกดอื่น ㅅ เข้มขึ้น |

> [!TIP] กฎสั้น ๆ
> ถาม = **ㅂ니까?** และตอบ = **ㅂ니다**
>
> สระ → ㅂ니다 · พยัญชนะ → 습니다 · อดีต/겠 → …**습**니다
>
> ผู้ใหญ่ → …(으)**십**니다

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

รูปทางการออกสอบแล้วใน 매일시험 16 (10/12) ซึ่งได้ 10/10 และเป็นรูปที่อยู่ในบทอ่านของ 복습시험② จึงต้องอ่านออกและเขียนตามได้ ข้อผิดของผู้เรียนส่วนใหญ่คือการลืม 으 การตัดราก และการสลับ 니다 กับ 니까

- **매일시험 16 (10/12) = 10/10**
  - A แปลงบทสนทนา -아/어요 → -(스)ㅂ니다 6 ช่อง: 하십니까 · 일합니다 · 어떻습니까
  - ช่องที่เหลือของ A: 재미있습니다 · 많습니까 · 있습니다
  - B เขียนตามคำบอก: 반갑습니다 · 선생님이십니다
  - B เขียนตามคำบอกต่อ: 드시겠습니까? · 제 친구입니다
  - ข้อ A1 เขียน **합니까** ครูให้เต็ม แต่ต้นฉบับ 하세요 มี 시 จึงควรเป็น **하십니까**
- **ใบฝึก 16과**
  - **받십니다** ✗ พลาด 2 ครั้ง (→ 받으십니다)
  - **마시다 → 맙니다** ✗ (ตัดราก → 마십니다)
  - ช่อง 운동하다 ลอกแถวบน (공부합니까)
  - **안녀하습니까** ✗
  - สลับ 니다/니까 เพราะอ่านประโยคต้นฉบับแทนที่จะดูเครื่องหมายปลายทาง
- **매일시험 17 (10/13) C10** เขียนตามคำบอก "ตั้งใจเรียน (ทางการ)" = **열심히 공부합니다** (หรือ 하겠습니다) ได้ครึ่งคะแนนเพราะเขียน 열심**이** — รูปทางการออกในข้อเขียนตามคำบอกด้วย
- **สมุดงาน 20과** **빌렸십니다** ✗ → 빌리셨습니다 / 빌렸습니다 (ผสม 셨 กับ 십니다)
- **복습시험② (14–20과 · เก็ง)** บทอ่านและตารางผัน
  - 읽기 17-2 (อีเมล) และ 18-2 (ไดอารี่) เป็นภาษา -습니다 ต้องอ่านออกและเขียนตามได้
  - 쓰기 ③ ตารางผัน 4 รูป (갑니다 · 가세요 · 갈 거예요 …)

> [!SUMMARY] สรุป
> - ถาม = **ㅂ니까?** ตอบ = **ㅂ니다** ตัด 다 แล้วดูตัวสะกด: สระ → ㅂ니다 พยัญชนะ → 습니다 นาม → 입니다/입니까?
> - อดีตและ -겠- ต่อ 습니다 (갔습니다 · 마시겠습니다) ผู้ใหญ่ใช้ -(으)십니다 และ ㅡ ไม่หาย (예쁩니다 · 큽니다)
> - ข้อผิดที่เคยเจอ: ลืม **으** (받십니다) ตัดราก (맙니다) ลืม 시 (안녀하습니까) และสลับ 니다/니까
> - ห้ามปนระดับภาษาในย่อหน้าเดียว (ยกเว้นเปิด/ปิดอย่าง 발표)
