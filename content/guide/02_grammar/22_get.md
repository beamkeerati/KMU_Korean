## 22. -겠- (ความตั้งใจ "จะ…")
ต่อหลังรากของ **กริยา** บอก **ความตั้งใจ/ความเต็มใจของผู้พูด** ("ฉันจะ…" · อาสา · สั่งอาหาร) หรือถามความตั้งใจของผู้ฟัง ("คุณจะ…?") · **สอนในบท 16** (교과서 146쪽) — ตำราเรียกว่า -겠-¹ ส่วน -겠-² "คาดเดา" อยู่ในบท 26
ต่อยอดจาก ข้อ 21 (มักปิดด้วย -겠습니다) · ข้อ 20 (시 + 겠) · ข้อ 16 (-지 않다) · เทียบ/ใช้ต่อใน ข้อ 28 (-(으)ㄹ 거예요)

### 📌 รูปแบบและเงื่อนไข
| ประเภท | รูป | ตัวอย่าง |
|:---|:---|:---|
| บอกเล่า (ฉัน) | รากกริยา + **-겠습니다 / -겠어요** | 내일 오**겠습니다**. *(พรุ่งนี้จะมา)* · 저는 커피로 하**겠어요**. *({n:ฉัน}{v:ขอ}{p:เป็น}{n:กาแฟ})* |
| ปฏิเสธ | **-지 않겠습니다** | 저는 그 일을 친구에게 말하**지 않겠습니다**. *(ฉันจะไม่บอกเรื่องนั้นกับเพื่อน)* |
| ถามผู้ฟัง | **-겠습니까? / -겠어요?** | 언제 오**겠습니까**? *(จะมาเมื่อไร)* · 누가 먼저 이야기하**겠습니까**? *(ใครจะพูดก่อน)* |
| ถามผู้ใหญ่ | **-(으)시겠습니까? / -(으)시겠어요?** | 무엇을 드시**겠습니까**? *({e:จะ}{V:รับ}{q:อะไร}ดีครับ)* · 뭘 드시**겠어요**? |

* **ไม่ดูตัวสะกด** — ลงท้ายสระหรือพยัญชนะก็ใช้ -겠- เหมือนกัน: 마시겠습니다 · 먹겠습니다 (ต่างจาก ㅂ니다/습니다 ที่ข้อ 21)
* ลำดับ **-(으)시- → -겠- → ท้ายประโยค**: 드시겠습니까 (✗ 먹겠으십니까)
* ใช้กับ **กริยา** เท่านั้น (คำคุณศัพท์ไม่มี "ความตั้งใจ" จึงไม่ใช้ในความหมายนี้)
* ประธานต้องเป็น **ผู้พูด** หรือถามตัว **ผู้ฟัง** — ถ้าประธานเป็นบุคคลที่ 3 ใช้ -겠- แบบตั้งใจ **ไม่ได้** (ตำรา 146쪽)
* พบบ่อยตอนสั่งอาหาร/ตัดสินใจทันที/อาสาทำ — ปิดประโยคด้วย -(스)ㅂ니다 → **-겠습니다** หรือ -아/어요 → **-겠어요** ก็ได้

| กริยา | -겠습니다 | -지 않겠습니다 | ถามผู้ใหญ่ -(으)시겠습니까? |
|:---|:---|:---|:---|
| 오다 · 가다 · 하다 | 오겠습니다 · 가겠습니다 · 하겠습니다 | 오지 않겠습니다 | 오시겠습니까? · 가시겠습니까? |
| 먹다 · 마시다 | 먹겠습니다 · 마시겠습니다 | 먹지 않겠습니다 | **드시겠습니까?** (คำพิเศษ ข้อ 20) |
| 읽다 · 받다 (มีตัวสะกด) | 읽겠습니다 · 받겠습니다 | 읽지 않겠습니다 | 읽**으**시겠습니까? |
| 알다 · 만들다 (ㄹ-ราก · เสริม) | 알겠습니다 · 만들겠습니다 | 알지 않겠습니다 | 아시겠습니까? · 만드시겠습니까? |

*ㄹ-ราก: ㄹ **ไม่หาย**หน้า -겠- (알겠습니다) ต่างจาก ㅂ니다 ที่ตัด ㄹ (압니다 — ข้อ 21)*

### 📖 ตัวอย่างและการใช้
**1) อาสา / ประกาศความตั้งใจ**
1. 가: 누가 먼저 이야기하겠습니까? / 나: 제가 먼저 하**겠습니다**. *({q:ใคร}{e:จะ}{v:พูด}{a:ก่อน} / {n:ฉัน}{e:ขอ}{v:พูด}{a:ก่อน})* — 교과서 146쪽
2. 가: 언제 오겠습니까? / 나: 내일 다시 오**겠습니다**. *(จะมาเมื่อไร / พรุ่งนี้จะมาใหม่)* — 147쪽
3. 저는 그 일을 친구에게 말하**지 않겠습니다**. *(ฉันจะไม่บอกเรื่องนั้นกับเพื่อน)* · 읽기 17-2: 한국말을 열심히 공부하**겠습니다**. *(จะตั้งใจเรียนภาษาเกาหลี)*
4. ใบฝึก 16과 D: 내일이 친구 생일입니다 → 모자를 사**겠습니다**. · 내일 시험입니다 → 공부를 하**겠습니다**. *(พรุ่งนี้วันเกิดเพื่อน → จะซื้อหมวก · พรุ่งนี้สอบ → จะอ่านหนังสือ — เฉลยเขียนเอง)*
5. กิจกรรม 147쪽: 친구 생일 파티에 무엇을 준비하겠습니까? / 저는 케이크를 준비하**겠습니다**. *(จะเตรียมอะไรสำหรับปาร์ตี้วันเกิดเพื่อน / ฉันจะเตรียมเค้ก)*

**2) สั่งอาหาร/เครื่องดื่ม และถามผู้ใหญ่ว่าจะรับอะไร**
6. 대화 16-1: 무엇을 드시**겠습니까**? / 저는 커피를 마시**겠습니다**. · 저는 주스를 마시**겠습니다**. *({e:จะ}{V:รับ}{q:อะไร}ดีครับ / {n:ฉัน}{e:จะ}{v:ดื่ม}{n:กาแฟ} · {n:น้ำผลไม้})*
7. 가: 제프리 씨는 뭘 드시겠어요? / 나: 저는 커피로 하**겠어요**. *({n:คุณเจฟฟรีย์}{e:จะ}{V:รับ}{q:อะไร} / {n:ฉัน}{v:ขอ}{p:เป็น}{n:กาแฟ})* — "N로 하겠어요" = ขอเลือก N
8. 가: 무엇을 먹겠습니까? / 나: 빵을 먹**겠습니다**. *(จะกินอะไร / จะกินขนมปัง)* — ฝึกต่อ: 김밥을 먹겠습니다 · 녹차를 마시겠습니다

**3) ขอร้องอย่างสุภาพ**
9. 대화 21-1: 그럼 바트 씨한테 이 책을 주시**겠어요**? / 네, 알**겠어요**. *({a:งั้น}{e:ช่วย}{v:ให้}{n:หนังสือเล่มนี้คุณบัต}{e:ได้}ไหมคะ / {v:ได้}ค่ะ)* — -(으)시겠어요? ถามขอร้องอย่างสุภาพ

### ⚠️ จุดสับสน
**-겠- vs -(으)ㄹ 거예요** — ทั้งคู่แปลเป็นไทยว่า "จะ" แต่ **-겠-** = ความตั้งใจ ณ ตอนพูด (ตัดสินใจ/อาสา/สั่ง) ส่วน **-(으)ㄹ 거예요** = แผน/การคาดการณ์ (ข้อ 28 — บท 19)

| | -겠- | -(으)ㄹ 거예요 |
|:---|:---|:---|
| ความหมาย | ตั้งใจ**ทันที** · สั่งอาหาร · อาสา | แผนล่วงหน้า · คาดการณ์ |
| ประธาน | **ผู้พูด** · ถามผู้ฟัง | ได้ทุกบุคคล |
| ตัวอย่าง | 제가 하겠습니다 · 드시겠습니까? | 내일 갈 거예요 · 친구가 올 거예요 |

- ✓ 저는 내일 가겠어요. *({a:พรุ่งนี้}{n:ฉัน}{e:จะ}{v:ไป}แน่ ๆ — ตัดสินใจ)* vs ✓ 저는 내일 갈 거예요. *(พรุ่งนี้ฉันจะไป — แผน)*
- ✗ 친구가 오겠습니다 (บุคคลที่ 3 — ตำรา 146쪽) → ✓ 친구가 올 거예요. *(เพื่อนจะมา)*
- -겠- **ไม่ใช่กาลอนาคตล้วน ๆ**: บอกนิสัย/ปัจจุบันใช้ -아/어요 (저는 커피를 마셔요 *ฉันดื่มกาแฟ*) · ตัดสินใจจะดื่มตอนนี้ใช้ -겠- (저는 커피를 마시겠습니다 *ฉันจะดื่มกาแฟ*)
- ✗ 먹겠으십니까 → ✓ 드시겠습니까 (**-(으)시- มาก่อน -겠-** · 먹다 → 드시다)
- -겠- ที่ไม่ได้แปลว่า "ตั้งใจ": **알겠습니다 / 알겠어요** = "รับทราบ/เข้าใจแล้ว" (สำนวน ไม่ใช่อนาคต — 21과) · **힘들겠네요** (บท 20) · **잘 모르겠어요** (บท 22) = ความหมาย "คาดเดา/นุ่มนวล" ที่ตำราสอนจริงในบท 26 — ตอนนี้จำเป็นสำนวนก่อน อย่าเพิ่งแต่งเอง
- ออกเสียง (ตำรา 146쪽): 오겠습니까 [오겐씀니까 / 오게씀니까] · 않겠습니다 [안켄씀니다 / 안케씀니다]

> [!TIP]
> เลือก **-겠-** เมื่อ "ฉันตัดสินใจตอนนี้ / สั่ง / อาสา / ถามว่าคุณจะรับอะไร" · เลือก **-(으)ㄹ 거예요** เมื่อ "แผน" หรือประธานเป็นคนอื่น

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- **매일시험 16 (10/12) = 10/10:** B9 เขียนตามคำบอก **드시겠습니까?** (ถามผู้ฟัง = 시 + 겠 + ㅂ니까) — ทำได้ดีอยู่แล้ว รูป -겠- เป็นจุดแข็งที่ครูไม่ได้หักเลย
- **ใบฝึก 16과:** C ดูภาพเติม -겠습니다 / -지 않겠습니다 (13 ข้อ บางข้อเดาจากภาพเล็ก) · D แต่งประโยคตามสถานการณ์ 10 ข้อ · G ช่อง 4 "먹겠습니다": เขียน **된장찌개를** ซ้ำ ⚠️ — ช่องว่างคือ**กริยา** ไม่ใช่คำนามที่พิมพ์อยู่หน้าช่องแล้ว
- **매일시험 17 (10/13) C10:** "ตั้งใจเรียน (ทางการ)" = 열심히 공부합니다 / 공부하겠습니다 — ได้ครึ่งคะแนนเพราะเขียน 열심**이** (ไม่ใช่ปัญหา 겠)
- **복습시험② (14–20과 · เก็ง):** 읽기 17-2 มี "한국말을 열심히 공부하겠습니다" ให้ยกมาตอบในช่อง 나 · ถ้าโจทย์ถามแผนสุดสัปดาห์หน้าต้องเปลี่ยนเป็น -(으)ㄹ 거예요 ไม่ใช่ -겠-
