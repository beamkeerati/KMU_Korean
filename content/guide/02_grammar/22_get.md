## 22. -겠- (ความตั้งใจ "จะ…")

> [!INTRO] ข้อนี้คืออะไร
> -겠- ต่อหลังรากของ**กริยา**เพื่อบอก**ความตั้งใจหรือความเต็มใจของผู้พูด** เช่น "ฉันจะ…" การอาสา และการสั่งอาหาร หรือใช้ถามความตั้งใจของผู้ฟังว่า "คุณจะ…?" มักปิดประโยคด้วย -겠습니다 หรือ -겠어요
>
> สอนในบท 16 (ตำราหน้า 146) ตำราเรียกว่า -겠-¹ ส่วน -겠-² ที่แปลว่า "คาดเดา" อยู่ในบท 26 ในข้อนี้เน้นเฉพาะความตั้งใจ ซึ่งต่างจาก -(으)ㄹ 거예요 ที่เป็นแผนล่วงหน้า (ข้อ 28)
>
> ต่อยอดจาก ข้อ 21 (มักปิดด้วย -겠습니다), ข้อ 20 (시 + 겠) และ ข้อ 16 (-지 않다) แล้วเทียบกับหรือไปใช้ต่อใน ข้อ 28 (-(으)ㄹ 거예요)

### 📌 รูปแบบและเงื่อนไข

-겠- ต่อกับรากโดยตรงโดยไม่ต้องดูตัวสะกด และถ้ามี -(으)시- ต้องวาง 시 ไว้ก่อน ตารางแรกสรุปรูปที่ใช้ตามประเภทของประโยค ตารางถัดไปเป็นตัวอย่าง

| ประเภท | รูป |
|:---|:---|
| บอกเล่า (ฉัน) | รากกริยา + **-겠습니다 / -겠어요** |
| ปฏิเสธ | **-지 않겠습니다** |
| ถามผู้ฟัง | **-겠습니까? / -겠어요?** |
| ถามผู้ใหญ่ | **-(으)시겠습니까? / -(으)시겠어요?** |

| ประเภท | 한국어 | ไทย |
|:---|:---|:---|
| บอกเล่า | 내일 오**겠습니다**. | พรุ่งนี้จะมา |
| บอกเล่า | 저는 커피로 하**겠어요**. | {n:ฉัน}{v:ขอ}{p:เป็น}{n:กาแฟ} |
| ปฏิเสธ | 저는 그 일을 친구에게 말하**지 않겠습니다**. | ฉันจะไม่บอกเรื่องนั้นกับเพื่อน |
| ถามผู้ฟัง | 언제 오**겠습니까**? | จะมาเมื่อไร |
| ถามผู้ฟัง | 누가 먼저 이야기하**겠습니까**? | ใครจะพูดก่อน |
| ถามผู้ใหญ่ | 무엇을 드시**겠습니까**? | {e:จะ}{V:รับ}{q:อะไร}ดีครับ |
| ถามผู้ใหญ่ | 뭘 드시**겠어요**? | {e:จะ}{V:รับ}{q:อะไร}ดีคะ |

#### ข้อควรรู้ของ -겠-

กฎต่อไปนี้ช่วยให้เลือกใช้ -겠- ได้ถูกที่ ทั้งเรื่องตัวสะกด ลำดับชิ้นส่วน ชนิดของคำ และประธานของประโยค

- **ไม่ดูตัวสะกด** — ลงท้ายสระหรือพยัญชนะก็ใช้ -겠- เหมือนกัน: 마시겠습니다 · 먹겠습니다 (ต่างจาก ㅂ니다/습니다 ที่ข้อ 21)
- ลำดับ **-(으)시- → -겠- → ท้ายประโยค**: 드시겠습니까 (✗ 먹겠으십니까)
- ใช้กับ **กริยา** เท่านั้น (คำคุณศัพท์ไม่มี "ความตั้งใจ" จึงไม่ใช้ในความหมายนี้)
- ประธานต้องเป็น **ผู้พูด** หรือถามตัว **ผู้ฟัง** — ถ้าประธานเป็นบุคคลที่ 3 ใช้ -겠- แบบตั้งใจ **ไม่ได้** (ตำรา 146쪽)
- พบบ่อยตอนสั่งอาหาร ตัดสินใจทันที และอาสาทำ — ปิดประโยคด้วย -(스)ㅂ니다 → **-겠습니다** หรือ -아/어요 → **-겠어요** ก็ได้

#### ตารางผันตามประเภทกริยา

ตารางนี้ดูทีละกลุ่มกริยา ตั้งแต่กริยาลงท้ายสระ กริยาที่มีตัวสะกด ไปจนถึงรากที่มี ㄹ

| กริยา | -겠습니다 | -지 않겠습니다 | ถามผู้ใหญ่ -(으)시겠습니까? |
|:---|:---|:---|:---|
| 오다 · 가다 · 하다 | 오겠습니다 · 가겠습니다 · 하겠습니다 | 오지 않겠습니다 | 오시겠습니까? · 가시겠습니까? |
| 먹다 · 마시다 | 먹겠습니다 · 마시겠습니다 | 먹지 않겠습니다 | **드시겠습니까?** (คำพิเศษ ข้อ 20) |
| 읽다 · 받다 (มีตัวสะกด) | 읽겠습니다 · 받겠습니다 | 읽지 않겠습니다 | 읽**으**시겠습니까? |
| 알다 · 만들다 (ㄹ-ราก · เสริม) | 알겠습니다 · 만들겠습니다 | 알지 않겠습니다 | 아시겠습니까? · 만드시겠습니까? |

ราก ㄹ นั้น ㄹ **ไม่หาย**หน้า -겠- (알겠습니다) ต่างจาก ㅂ니다 ที่ตัด ㄹ (압니다 — ข้อ 21)

### 📖 ตัวอย่างและการใช้

ตัวอย่างแบ่งตามสถานการณ์ที่ -겠- ใช้บ่อย 3 แบบ คืออาสาหรือประกาศความตั้งใจ สั่งอาหารและถามผู้ใหญ่ว่าจะรับอะไร และขอร้องอย่างสุภาพ

#### อาสา / ประกาศความตั้งใจ

สถานการณ์แรกคือบอกว่าตัวเองจะทำอะไร ตัวผู้พูดเป็นประธานเสมอ

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 가: 누가 먼저 이야기하겠습니까? / 나: 제가 먼저 하**겠습니다**. | {q:ใคร}{e:จะ}{v:พูด}{a:ก่อน} / {n:ฉัน}{e:ขอ}{v:พูด}{a:ก่อน} | ตำรา 146쪽 |
| 가: 언제 오겠습니까? / 나: 내일 다시 오**겠습니다**. | จะมาเมื่อไร / พรุ่งนี้จะมาใหม่ | ตำรา 147쪽 |
| 저는 그 일을 친구에게 말하**지 않겠습니다**. | ฉันจะไม่บอกเรื่องนั้นกับเพื่อน | — |
| 한국말을 열심히 공부하**겠습니다**. | จะตั้งใจเรียนภาษาเกาหลี | 읽기 17-2 |
| 내일이 친구 생일입니다 → 모자를 사**겠습니다**. | พรุ่งนี้วันเกิดเพื่อน → จะซื้อหมวก | ใบฝึก 16과 D (เฉลยเขียนเอง) |
| 내일 시험입니다 → 공부를 하**겠습니다**. | พรุ่งนี้สอบ → จะอ่านหนังสือ | ใบฝึก 16과 D (เฉลยเขียนเอง) |
| 친구 생일 파티에 무엇을 준비하겠습니까? / 저는 케이크를 준비하**겠습니다**. | จะเตรียมอะไรสำหรับปาร์ตี้วันเกิดเพื่อน / ฉันจะเตรียมเค้ก | กิจกรรม 147쪽 |

#### สั่งอาหาร/เครื่องดื่ม และถามผู้ใหญ่ว่าจะรับอะไร

สถานการณ์ที่สองคือร้านอาหารหรือร้านกาแฟ คนถามใช้ -(으)시겠습니까? ส่วนคนตอบใช้ -겠습니다 หรือ -겠어요

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 무엇을 드시**겠습니까**? / 저는 커피를 마시**겠습니다**. | {e:จะ}{V:รับ}{q:อะไร}ดีครับ / {n:ฉัน}{e:จะ}{v:ดื่ม}{n:กาแฟ} | 대화 16-1 |
| 저는 주스를 마시**겠습니다**. | {n:ฉัน}{e:จะ}{v:ดื่ม}{n:น้ำผลไม้} | 대화 16-1 |
| 가: 제프리 씨는 뭘 드시겠어요? / 나: 저는 커피로 하**겠어요**. | {n:คุณเจฟฟรีย์}{e:จะ}{V:รับ}{q:อะไร} / {n:ฉัน}{v:ขอ}{p:เป็น}{n:กาแฟ} | — |
| 가: 무엇을 먹겠습니까? / 나: 빵을 먹**겠습니다**. | จะกินอะไร / จะกินขนมปัง | — |
| 김밥을 먹겠습니다 | จะกินกิมบับ | ฝึกต่อ |
| 녹차를 마시겠습니다 | จะดื่มชาเขียว | ฝึกต่อ |

สำนวน "N로 하겠어요" แปลว่า ขอเลือก N เช่น 커피로 하겠어요 ในแถวที่สาม

#### ขอร้องอย่างสุภาพ

-(으)시겠어요? ยังใช้ถามขอร้องอย่างสุภาพ ได้ด้วย ไม่ได้ถามความตั้งใจอย่างเดียว

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 그럼 바트 씨한테 이 책을 주시**겠어요**? / 네, 알**겠어요**. | {a:งั้น}{e:ช่วย}{v:ให้}{n:หนังสือเล่มนี้คุณบัต}{e:ได้}ไหมคะ / {v:ได้}ค่ะ | 대화 21-1 |

### ⚠️ จุดสับสน

-겠- กับ -(으)ㄹ 거예요 แปลเป็นไทยว่า "จะ" ทั้งคู่ แต่ **-겠-** = ความตั้งใจ ณ ตอนพูด (ตัดสินใจ อาสา สั่ง) ส่วน **-(으)ㄹ 거예요** = แผนหรือการคาดการณ์ (ข้อ 28 — บท 19) ตารางนี้เทียบทีละแถว

| | -겠- | -(으)ㄹ 거예요 |
|:---|:---|:---|
| ความหมาย | ตั้งใจ**ทันที** · สั่งอาหาร · อาสา | แผนล่วงหน้า · คาดการณ์ |
| ประธาน | **ผู้พูด** · ถามผู้ฟัง | ได้ทุกบุคคล |
| ตัวอย่าง | 제가 하겠습니다 · 드시겠습니까? | 내일 갈 거예요 · 친구가 올 거예요 |

ประโยคคู่นี้ต่างกันตรงที่ตัดสินใจตอนพูดกับมีแผนมาก่อน

| 한국어 | ไทย | ความหมาย |
|:---|:---|:---|
| ✓ 저는 내일 가겠어요. | {a:พรุ่งนี้}{n:ฉัน}{e:จะ}{v:ไป}แน่ ๆ | ตัดสินใจตอนพูด |
| ✓ 저는 내일 갈 거예요. | พรุ่งนี้ฉันจะไป | แผน |

ข้อผิดที่เจอบ่อยสรุปเป็นคู่ ✓ / ✗ ได้ตามนี้

| สถานการณ์ | ✓ ถูก | ✗ ผิด | เหตุผล |
|:---|:---|:---|:---|
| ประธานบุคคลที่ 3 | 친구가 올 거예요. *(เพื่อนจะมา)* | 친구가 오겠습니다 | บุคคลที่ 3 ใช้ -겠- แบบตั้งใจไม่ได้ (ตำรา 146쪽) |
| ลำดับ 시 กับ 겠 | 드시겠습니까 | 먹겠으십니까 | **-(으)시- มาก่อน -겠-** และ 먹다 → 드시다 |

#### กับดัก

- -겠- **ไม่ใช่กาลอนาคตล้วน ๆ** บอกนิสัยหรือปัจจุบันใช้ -아/어요 ส่วนตัดสินใจจะทำตอนนี้ใช้ -겠-
  - 저는 커피를 마셔요 *(ฉันดื่มกาแฟ — นิสัย/ปัจจุบัน)*
  - 저는 커피를 마시겠습니다 *(ฉันจะดื่มกาแฟ — ตัดสินใจตอนนี้)*
- -겠- ที่ไม่ได้แปลว่า "ตั้งใจ" มีสามแบบที่ควรรู้
  - 알겠습니다 / 알겠어요 = "รับทราบ/เข้าใจแล้ว" (สำนวน ไม่ใช่อนาคต — 21과)
  - 힘들겠네요 (บท 20)
  - 잘 모르겠어요 (บท 22)
- สองสำนวนหลังมีความหมาย "คาดเดา/นุ่มนวล" ที่ตำราสอนจริงในบท 26 — ตอนนี้จำเป็นสำนวนก่อน อย่าเพิ่งแต่งเอง

#### ออกเสียง (ตำรา 146쪽)

เสียง -겠- ต่อด้วย ㅂ니다 หรือ ㅂ니까 เปลี่ยนเสียงและมีเสียงอ่านได้สองแบบ

| เขียน | อ่าน |
|:---|:---|
| 오겠습니까 | [오겐씀니까 / 오게씀니까] |
| 않겠습니다 | [안켄씀니다 / 안케씀니다] |

> [!TIP] กฎสั้น ๆ
> เลือก **-겠-** เมื่อ "ฉันตัดสินใจตอนนี้ สั่ง อาสา หรือถามว่าคุณจะรับอะไร" ส่วน **-(으)ㄹ 거예요** ใช้เมื่อเป็น "แผน" หรือประธานเป็นคนอื่น

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

รูป -겠- เป็นจุดแข็งของผู้เรียน ครูไม่ได้หักคะแนนข้อที่ใช้ -겠- ใน 매일시험 16 เลย ข้อที่พลาดมีเพียงช่องว่างในใบฝึกที่ต้องเติมกริยา และใน 복습시험② ควรระวังเลือก -겠- หรือ -(으)ㄹ 거예요 ให้ตรงกับโจทย์

- **매일시험 16 (10/12) = 10/10** B9 เขียนตามคำบอก **드시겠습니까?** (ถามผู้ฟัง = 시 + 겠 + ㅂ니까) ทำได้ดีอยู่แล้ว
- **ใบฝึก 16과**
  - C ดูภาพเติม -겠습니다 / -지 않겠습니다 (13 ข้อ บางข้อเดาจากภาพเล็ก)
  - D แต่งประโยคตามสถานการณ์ 10 ข้อ
  - G ช่อง 4 "먹겠습니다": เขียน **된장찌개를** ซ้ำ ⚠️ — ช่องว่างคือ**กริยา** ไม่ใช่คำนามที่พิมพ์อยู่หน้าช่องแล้ว
- **매일시험 17 (10/13) C10** "ตั้งใจเรียน (ทางการ)" = 열심히 공부합니다 / 공부하겠습니다 — ได้ครึ่งคะแนนเพราะเขียน 열심**이** (ไม่ใช่ปัญหา 겠)
- **복습시험② (14–20과 · เก็ง)**
  - 읽기 17-2 มี "한국말을 열심히 공부하겠습니다" ให้ยกมาตอบในช่อง 나
  - ถ้าโจทย์ถามแผนสุดสัปดาห์หน้าต้องเปลี่ยนเป็น -(으)ㄹ 거예요 ไม่ใช่ -겠-

### 🔗 เชื่อมโยง

ข้อนี้ใช้คู่กับรูปทางการและ -(으)시- และต้องเทียบกับ -(으)ㄹ 거예요 อยู่เสมอ

← ต่อยอดจาก

- ข้อ 21 -(스)ㅂ니다 (บท 16 — มักใช้คู่กัน)
- ข้อ 20 시 + 겠: 드시겠습니까
- ข้อ 16 -지 않다 → -지 않겠습니다

→ ใช้ต่อใน

- ข้อ 28 -(으)ㄹ 거예요 แผน ↔ -겠- ตัดสินใจตอนพูด
- ข้อ 23 บทอ่านบท 17: 왔습니다 + 공부하겠습니다
- ข้อ 30 -네요 ต่อ -겠-: 힘들겠네요 (บท 20)

> [!SUMMARY] สรุป
> - -겠- = ความตั้งใจของ**ผู้พูด** ณ ตอนพูด (ตัดสินใจ อาสา สั่ง) และถามความตั้งใจของผู้ฟัง ใช้กับกริยา ไม่ดูตัวสะกด
> - รูปที่ใช้: -겠습니다 · -겠어요 · -지 않겠습니다 และถามผู้ใหญ่ด้วย -(으)시겠습니까? (드시겠습니까)
> - ประธานบุคคลที่ 3 ใช้ไม่ได้ ให้ใช้ -(으)ㄹ 거예요 (ข้อ 28)
> - ลำดับชิ้นส่วน -(으)시- → -겠- → ท้ายประโยค และ 알겠습니다 เป็นสำนวน "รับทราบ"
