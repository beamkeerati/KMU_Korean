## 57. -거나 (…หรือ… — เลือกอย่างใดอย่างหนึ่ง)
เชื่อม**กริยา/คำคุณศัพท์สองตัวขึ้นไป**ในความหมาย "ทำ A **หรือ** ทำ B" — เลือกเพียงอย่างเดียว (ตำรา: connects two or more actions or states and denotes that one of them is chosen) · ต่อท้ายราก **ไม่ดูตัวสะกด**
สอนในบท 34 (교과서 336–337쪽 · 준비 1) · ต่อยอดจาก ข้อ 06 (ราก) · ข้อ 34 (-고 "และ" ← ใช้ตรงข้ามกับ -거나) · ข้อ 12 (รูปประโยค/ถาม–ตอบ)
ใช้ต่อใน ข้อ 58 (N(이)나 = "หรือ" ของคำนาม) · ข้อ 55 · ข้อ 38/63 (ให้คำแนะนำ -(으)세요) และงานพูด 말하기 "주말에 뭐 하세요?"

### 📌 รูปแบบและเงื่อนไข
รูปเดียวจบ — **ราก + -거나** (ไม่มี 으/을 ไม่มีสระกลมกลืน) และ **ไม่เปลี่ยนรากแม้เป็นคำผันไม่ปกติ** เพราะ 거 ขึ้นต้นด้วยพยัญชนะ

| รากศัพท์ลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| ทุกแบบ (สระ / ตัวสะกด) | **-거나** | 보다 → **보거나** · 먹다 → **먹거나** · 하다 → **하거나** · 쉬다 → **쉬거나** *(ดู… หรือ · กิน… หรือ · ทำ… หรือ · พัก… หรือ)* |
| ลงท้าย ㄹ | -거나 (ㄹ **คงอยู่**) | 놀다 → **놀거나** · 살다 → **살거나** · 만들다 → **만들거나** |
| ㅂ · ㄷ · 르 · ㅡ | ไม่เปลี่ยน (เปลี่ยนเฉพาะก่อนสระ) | 춥다 → **춥거나** · 듣다 → **듣거나** · 부르다 → **부르거나** · 바쁘다 → **바쁘거나** |
| คำคุณศัพท์ | -거나 | 흐리다 → **흐리거나** *(ครึ้ม… หรือ)* · 피곤하다 → **피곤하거나** |
| ผู้ใหญ่เป็นประธาน (เสริม) | ใส่ -(으)시- ก่อน 거나 | 읽다 → **읽으시거나** · 하다 → **하시거나** *(ท่านอ่าน… หรือ · ท่านทำ… หรือ — ข้อ 20 · ตำราไม่มีตัวอย่าง)* |

- **ตำรา 336쪽:** "เชื่อมการกระทำหรือสภาพสองอย่างขึ้นไป และบอกว่าเลือกหนึ่งในนั้น · ต่อท้ายรากของกริยาหรือคำคุณศัพท์"
- **กาล (tense) ใส่ที่ประโยคหลังสุดตัวเดียว:** ✓ 어제는 영화를 보거나 쇼핑을 했어요 / ✗ 어제는 봤거나 쇼핑을 했어요 · ประโยคหลักปิดด้วย -아/어요 · -았/었어요 · -(으)ㄹ 거예요 · -(으)세요
- **ประธานคนเดียวกัน:** ทั้งสองส่วนทำโดยคนเดียวกัน ไม่ต้องพูดประธานซ้ำ (ข้อ 15)
- **แต่ละกริยาครบองค์ประกอบของมันเอง:** 영화를 보거나 쇼핑을 해요 — กรรม (을/를) ไม่ถูกลด
- **ทั้งกริยากับคำคุณศัพท์ใช้ได้:** 내일은 **흐리거나** 비가 올 거예요 *(พรุ่งนี้ฟ้าครึ้มหรือฝนตก)* — คำคุณศัพท์ (흐리다) + กริยา (오다)

### 📖 ตัวอย่างและการใช้
#### จากกล่องไวยากรณ์และ 준비 (336쪽)
1. 이리나 씨, 주말에 뭐 하세요? — 영화를 **보거나** 쇼핑을 해요. *(คุณอิรินา สุดสัปดาห์ทำอะไร — ดูหนังหรือไม่ก็ช็อปปิง)*
2. 커피를 **마시거나** 녹차를 마셔요. *(ดื่มกาแฟหรือชาเขียว)*
3. 내일은 **흐리거나** 비가 올 거예요. *(พรุ่งนี้ฟ้าครึ้มหรือไม่ก็ฝนตก)*
4. 빵을 **먹거나** 밥을 먹어요. *(กินขนมปังหรือข้าว)*
5. 집에서 **쉬거나** 숙제를 해요. *(พักที่บ้านหรือทำการบ้าน — 보기 ของ 연습 1)*

#### แบบฝึก 연습 1–3 (336–337쪽)
| โจทย์ A – B | ประโยคผล |
|:---|:---|
| 집에서 쉬다 – 숙제하다 | 집에서 **쉬거나** 숙제를 해요. *(พักที่บ้านหรือทำการบ้าน)* |
| 쇼핑을 하다 – 집에서 쉬다 | 쇼핑을 **하거나** 집에서 쉬어요. *(ช็อปปิงหรือพักที่บ้าน)* |
| 음악을 듣다 – 게임을 하다 | 음악을 **듣거나** 게임을 해요. *(ฟังเพลงหรือเล่นเกม — ㄷ ไม่เปลี่ยน)* |
| 친구 집에서 놀다 – 여행을 하다 | 친구 집에서 **놀거나** 여행을 해요. *(เล่นที่บ้านเพื่อนหรือเที่ยว — ㄹ คงอยู่)* |
| 친구를 만나다 – 집안일을 하다 | 친구를 **만나거나** 집안일을 해요. *(พบเพื่อนหรือทำงานบ้าน)* |

- **연습 2 (337쪽):** 가: 오후에 뭐 하세요? — 나: 게임을 **하거나** 친구를 만나요. *(บ่ายทำอะไร — เล่นเกมหรือไม่ก็พบเพื่อน)* · รูป: 쇼핑을 하다 · 게임을 하다 · 책을 읽다 · 저녁을 만들다 · 공부하다 · 친구를 만나다 · 집안일을 하다 · 텔레비전을 보다 · 산책하다 *(ช็อปปิง · เล่นเกม · อ่านหนังสือ · ทำมื้อเย็น · เรียน · พบเพื่อน · ทำงานบ้าน · ดูทีวี · เดินเล่น)* — เลือกสองอย่างต่อด้วย -거나
- **연습 3 (337쪽) ให้คำแนะนำ:** 가: 너무 피곤해요. — 나: 커피를 **마시거나** 좀 쉬세요. *(เหนื่อยมาก — ดื่มกาแฟหรือพักหน่อยสิ)* · ประโยคหลัก = **-(으)세요** (ข้อ 20) · โจทย์ปัญหา: 부모님이 보고 싶어요 · 수업 시간에 졸려요 · 감기에 걸렸어요 · 여자(남자) 친구와 싸웠어요 · 요즘 스트레스가 많아요 *(คิดถึงพ่อแม่ · ง่วงในคาบ · เป็นหวัด · ทะเลาะกับแฟน · ช่วงนี้เครียดมาก)*
  - ตัวอย่างคำตอบ (เรียบเรียงตามรูปแบบตำรา): 부모님이 보고 싶어요 → 전화를 **하거나** 가족사진을 보세요 · 수업 시간에 졸려요 → 물을 **마시거나** 세수를 하세요 · 감기에 걸렸어요 → 약을 **먹거나** 병원에 가세요
- **대화 34-1 (340쪽):** 왕쯔이: 저는 집에서 **쉬거나** 가끔 친구를 만나요. *(ฉันพักอยู่บ้านหรือไม่ก็พบเพื่อนบ้างเป็นครั้งคราว — 가끔 ข้อ 58)* · แต่งบทสนทนา: 영화 / 액션 영화 / ✓ 집에서 쉬다 · ✓ 친구를 만나다 · 운동을 하다 · 독서를 하다 · 컴퓨터 게임을 하다 · 쇼핑을 하다 · 산책을 하다 *(✓ = ตัวอย่างที่ตำรา tick)*
- **활동 (341쪽):** ถามเพื่อนว่าวันหยุดทำอะไร — ตารางความถี่ 항상 · 자주 · 가끔 · 거의 안 · 전혀 안 *(ดู ข้อ 58)*

### ⚠️ จุดสับสน
#### -거나 vs -고 vs N(이)나 vs -(으)면
| | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| **-거나** (กริยา) | **หรือ** (เลือกอย่างเดียว) | 커피를 마시거나 녹차를 마셔요 *(ดื่มกาแฟหรือชา — อย่างใดอย่างหนึ่ง)* |
| **-고** (ข้อ 34) | **และ** (ทำทั้งคู่/ต่อเนื่อง) | 커피를 마시고 녹차를 마셔요 *(ดื่มกาแฟแล้วก็ดื่มชา — ทั้งคู่)* |
| **N(이)나** (ข้อ 58) | **หรือ** (คำนาม) | 커피나 녹차를 마셔요 |
| -(으)면 (ข้อ 55) | **ถ้า** (เงื่อนไข) | 시간이 있으면 쉬어요 |

- **คำนามใช้ (이)나 · กริยาใช้ -거나:** ✗ 커피거나 녹차 / ✗ 마시나 → ✓ 커피나 녹차 · ✓ 마시거나
- **ไม่ต้องแปรรูปตามตัวสะกด:** ✓ 먹거나 / ✗ 먹으거나 · ✓ 쉬거나 · ✓ 놀거나 / ✗ 노거나 (ㄹ ไม่หลุดเพราะ 거 ไม่ใช่ ㄴ/ㅂ/ㅅ)
- **ใส่กาลที่ท้ายเท่านั้น:** ✓ 보거나 쇼핑을 했어요 / ✗ 봤거나 쇼핑을 했어요
- **ปิดท้ายด้วยรูปที่ถูกกาล:** 어제 → -았/었어요 · 내일/แผน → -(으)ㄹ 거예요 (ข้อ 28) · ขอร้อง/แนะนำ → -(으)세요 (ข้อ 20) · อย่าใช้ -거나 ปิดประโยค (ปิดที่ -거나 ไม่ได้ ต้องมีประโยคต่อ)
- **รักษากรรม/คำช่วยของแต่ละกริยา:** ✓ 영화를 보거나 쇼핑을 해요 · ✓ 쇼핑하거나 쉬어요 / ✗ 영화를 보거나 쇼핑 해요 (ตก 을 หรือเว้นวรรคผิด) — ข้อ 07 · 13
- **อย่าสับสนกับ "ฉัน…ทุกอย่าง":** ฉันทำทั้งสองอย่าง = -고 / -하고 (ข้อ 11) · "หรือ" = -거나

> [!TIP]
> **-거나 = "หรือ" ระหว่างกริยา — ราก + 거나 ไม่ดูตัวสะกด ไม่ผันรากไม่ปกติ · กาลอยู่ท้ายประโยค**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- ยังไม่มีข้อสอบจริงที่ครูตรวจแล้วเกี่ยวกับ -거나 — 34과 อยู่ใน **복습시험④ (11/18)** และ **기말** · ตำราเปิดบทด้วย "주말에 뭐 하세요?" ซึ่งเป็นคำถามที่เข้ากับ 말하기 (สัมภาษณ์เรื่องชีวิตประจำวัน)
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ (CLAUDE.md §6b):** **ตอบไม่ตรงคำถาม** (언제 → กิจกรรม) — กับ 뭐 하세요? ต้องตอบเป็นกิจกรรม ไม่ใช่เวลา · เขียนติดกัน 갈거예요 · 안 + N하다 (안 아르바이트 해요) · ㅈ/ㅊ (몇 → 몆 · 책 → 젝 · 저 → 처) · ㅐ/ㅔ (네 개 → 네 게 · 책 → 젝)
- **คาดการณ์รูปแบบข้อสอบ** (เดาจากรูปแบบ 복습시험①②):
  1. **เติม -거나:** 집에서 쉬다 / 숙제를 하다 → ___ (เน้น ㄹ-ราก 놀거나 · ㄷ 듣거나)
  2. **ตอบคำถาม:** 주말에 뭐 하세요? · 오후에 뭐 하세요? → ใช้ -거나 สองกิจกรรม
  3. **ให้คำแนะนำ:** 너무 피곤해요 / 감기에 걸렸어요 → ___ -거나 ___ -(으)세요
  4. **읽기 34-2 → บทสนทนา:** "공포 영화나 코미디 영화를 좋아합니다" (นาม → ข้อ 58) กับ "집에서 쉬거나 가끔 친구를 만나요" (กริยา → ข้อ 57) — เป็นคู่ที่ครูชอบให้แยก
