## 44. -는 (กริยาขยายคำนาม ปัจจุบัน: 좋아하는 계절 · 자주 먹는 음식 — "ที่…")
ต่อท้ายรากของ **กริยา** (และ **있다 / 없다**) เพื่อให้ไปขยาย **คำนามที่ตามมา** บอกว่าการกระทำนั้น **เกิดอยู่/ทำเป็นประจำ** — ใช้แทน "ที่" ของภาษาไทย: "อาหารที่คนเกาหลี**กิน**บ่อย" = 한국 사람들이 자주 **먹는** 음식
สอนในบท 27 (교과서 272–273쪽 준비 2) · ต่อยอดจาก ข้อ 36 (-(으)ㄴ ของคำคุณศัพท์) · ข้อ 06 (กริยา) · ข้อ 07 (을/를) · ข้อ 35 (ตาราง ㄹ-ราก)
ใช้ต่อใน ข้อ 59 (-는 것 — ทำกริยาให้เป็นนาม) · ข้อ 47 (-(으)ㄴ กริยาอดีต) · ข้อ 56 (-(으)ㄹ อนาคต + ตารางสรุป) · ข้อ 45 (눈이 오는 날이 제일 좋아요) · ข้อ 51 (듣는 — ㄷ ไม่เปลี่ยนหน้า ㄴ)

### 📌 รูปแบบและเงื่อนไข
ตำรา 272쪽: ต่อหลัง**กริยา**หรือ **있다/없다** เพื่อขยายคำนามที่ตามมา — บอกว่าการกระทำนั้น**กำลังเกิดอยู่ในขณะนั้น หรือเกิดพร้อมกับกริยาหลักของประโยค**

| รากลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| กริยา (มี/ไม่มีตัวสะกด ก็เหมือนกัน) | ราก + **-는** | 먹다 → **먹는** · 읽다 → **읽는** · 입다 → **입는** · 가다 → **가는** · 마시다 → **마시는** · 듣다 → **듣는** |
| กริยา 하다 | ราก + -는 | 좋아하다 → **좋아하는** · 싫어하다 → **싫어하는** · 공부하다 → **공부하는** |
| **있다 / 없다** (รวม 맛있다 · 재미있다 · 재미없다) | -는 | **있는** 사람 · **맛있는** 음식 · **재미있는** 영화 · **없는** 물건 |
| ราก **ㄹ** (ㄹ หลุดหน้า ㄴ) | ㄹ ตก + -는 | 만들다 → **만드는** · 살다 → **사는** · 알다 → **아는** · 놀다 → **노는** · 팔다 → **파는** · 열다 → **여는** |
| ราก 르 *(ไม่ใช่ ㄹ ตก)* | -는 | 부르다 → **부르는** · 모르다 → **모르는** *(ตำราใช้ 부르는 노래 — 연습 2)* |
| ㄷ 불규칙 | ㄷ อยู่ (ตามหลังเป็นพยัญชนะ ㄴ) | 듣다 → **듣는** · 걷다 → **걷는** · 묻다 → **묻는** *(ข้อ 51)* |
| ปฏิเสธ | **안** + กริยา-는 · -지 **않는** *(เสริม)* | 안 먹는 음식 · 먹지 않는 음식 *(อาหารที่ไม่กิน)* |

- **ไม่ดูตัวสะกด** — เหมือน -고 · -겠- · -지만: ลงท้ายสระหรือพยัญชนะก็ **-는** ตัวเดียว
- **โครงประโยค:** `[ประธาน-이/가] + (เวลา) + (กรรม-을/를) + กริยา-는` + `นาม` → 한국 사람들**이** 여름에 자주 **먹는** 음식 *(อาหารที่คนเกาหลีกินบ่อยในหน้าร้อน)* · ภาษาไทยวางนามนำ + "ที่" แต่เกาหลีวางอนุประโยคขยาย**หน้า**นามเสมอ
- **ประธานในอนุประโยค** ใช้ **이/가** (한국 사람들**이** · 제**가**) · ถ้าประธานเป็นคนเดียวกับประโยคหลักก็ละได้
- **ออกเสียง (ตำรา 272쪽):** 먹는 [멍는] · 듣는 [든는] · 있는 [인는] · 읽는 [잉는] · 입는 [임는] — ตัวสะกดเสียงกลายเป็นนาสิกเมื่อตามด้วย ㄴ (ㄱ→ㅇ · ㄷ→ㄴ · ㅂ→ㅁ)

### 📖 ตัวอย่างและการใช้
#### จากตำรา 27과 (272–273쪽)
1. 준비 2: 가: 한국 사람들이 여름에 자주 **먹는** 음식이 뭐예요? 나: 여름에 냉면을 많이 먹어요. *(อาหารที่คนเกาหลีกินบ่อยในหน้าร้อนคืออะไร — กินเนงมยอนเยอะ)*
2. กล่องตำรา: 이 노래가 요즘 자주 **듣는** 노래예요. *(เพลงนี้คือเพลงที่ช่วงนี้ฟังบ่อย)* · 단어를 **외우는** 것이 힘들었어요. *(การท่องศัพท์เป็นเรื่องยาก — -는 것 ข้อ 59)* · 지금 교실에 **있는** 사람이 누구예요? *(คนที่อยู่ในห้องเรียนตอนนี้คือใคร)*
3. 연습 1 (272쪽) — จับคู่ "กริยา → คำนาม": 봄에 자주 **입는** 옷이에요. *(เป็นเสื้อผ้าที่ใส่บ่อยในฤดูใบไม้ผลิ — ตัวอย่างตำรา)* · 여름에 자주 **먹는** 과일 *(ผลไม้ที่กินบ่อยหน้าร้อน)* · 가을에 자주 **듣는** 음악 *(เพลงที่ฟังบ่อยหน้าใบไม้ร่วง)* · 겨울에 많이 **마시는** 차 *(ชาที่ดื่มมากหน้าหนาว)* · 요즘 **읽는** 책 *(หนังสือที่อ่านช่วงนี้ — ข้อ 2–5 เฉลยเขียนเอง จับคู่ตามความหมาย)*
4. 연습 2 (273쪽): 가: ___ 씨가 요즘 **배우는** 외국어가 뭐예요? 나: 제가 요즘 **배우는** 외국어는 한국어예요. *(ภาษาต่างประเทศที่คุณกำลังเรียนช่วงนี้คืออะไร — ภาษาเกาหลี)* · ตาราง: 요즘 **배우는** 외국어 → 한국어 · 자주 **마시는** 음료수 → 콜라 · 자주 **만드는** 음식 · 자주 **부르는** 노래 · 자주 **만나는** 친구 · 요즘 **좋아하는** 가수 *(ข้อ 3–6 ให้ตอบเอง)*
5. 연습 3 (273쪽): ___ 씨가 **좋아하는** / **싫어하는** 한국어 단어가 뭐예요? · ___ 씨가 **좋아하는** / **싫어하는** 채소가 있어요? · 동물은 뭐예요? · 무슨 색깔을 좋아해요? *(คำเกาหลีที่ชอบ/ไม่ชอบคืออะไร · มีผักที่ชอบ/เกลียดไหม · สัตว์ · สี)*
6. 대화 27-1 (274쪽): 장핑: 그런데 한국 사람들이 여름에 자주 **먹는** 음식이 뭐예요? 윤아: 한국 사람들은 여름에 팥빙수를 많이 먹어요. *(แล้วอาหารที่คนเกาหลีกินบ่อยในหน้าร้อนคืออะไร — พับบิงซู)*
7. 읽기 27-2 (276–277쪽): 축구를 **좋아하는** 제프리 씨는 너무 심심했습니다. *(คุณเจฟฟรีย์ที่ชอบฟุตบอลเบื่อมาก)* · SMS: 파전은 한국 사람들이 비 **오는** 날 **먹는** 음식이에요. *(ปาจอนคืออาหารที่คนเกาหลีกินในวันฝนตก)* · 다. 듣고 따라 해 봅시다 (ส่วนที่ขีดเส้นใต้ให้ฟังแล้วตามอ่าน): 축구를 **좋아하는** · **먹는** · 막걸리 · 같이 먹어요
8. 읽기 23-2 · 28과 (ที่ผ่านมา): 거기에는 **맛있는** 한식집이 많고 카페도 많아요. · 눈이 **오는** 날이 제일 좋아요. *(ที่นั่นมีร้านอาหารเกาหลีอร่อยเยอะและคาเฟ่ก็เยอะ · วันที่หิมะตกดีที่สุด — 28과 연습 1)*

#### คำถามที่ใช้ -는 บ่อย (พร้อมคำตอบตัวอย่าง)
| คำถาม | ตอบ |
|:---|:---|
| 요즘 자주 **듣는** 노래가 뭐예요? | 요즘 자주 듣는 노래는 BTS 노래예요. *(เพลงที่ฟังบ่อยตอนนี้คือเพลงของ BTS)* |
| 한국 사람들이 비 **오는** 날 **먹는** 음식이 뭐예요? | 파전이에요. *(ปาจอน)* |
| **좋아하는** 계절이 뭐예요? | 저는 봄을 좋아해요. *(ชอบฤดูใบไม้ผลิ — 28과 좋아하는 계절)* |
| 지금 교실에 **있는** 사람이 누구예요? | 선생님하고 학생들이에요. *(อาจารย์กับนักเรียน)* |
| 요즘 **배우는** 외국어가 뭐예요? | 한국어예요. |

### ⚠️ จุดสับสน
#### สามรูป ㄴ/는 — ขึ้นกับ "ชนิดคำ" และ "เวลา"
| ชนิดคำ | ปัจจุบัน | อดีต | อนาคต |
|:---|:---|:---|:---|
| **กริยา** | **-는** (먹는 음식 — ข้อ 44) | -(으)ㄴ (먹은 음식 — ข้อ 47) | -(으)ㄹ (먹을 음식 — ข้อ 56) |
| **คำคุณศัพท์** | **-(으)ㄴ** (매운 음식 — ข้อ 36) | — | — |
| **있다 / 없다 / -있다** | **-는** (맛있는) | — | — |

- ตารางสรุปครบทั้งสามอยู่ใน **ข้อ 56** (บท 33) · ตอนนี้จำ: **กริยา → -는 · คำคุณศัพท์ → -(으)ㄴ · 있다/없다 → -는**

#### กับดักที่เจอบ่อย
- **좋은 vs 좋아하는:** 좋다 (คำคุณศัพท์) → **좋은** 사람 *(คนดี)* · 좋아하다 (กริยา) → **좋아하는** 사람 *(คนที่ชอบ)* · ✗ 좋아한 / 좋아은 / 좋은 *(สำหรับ "ที่ชอบ")* — ตำราบท 28 ชื่อ "좋아하는 계절" · 싫다 → 싫은 / 싫어하다 → **싫어하는**
- **ㄹ-ราก:** ✗ 만들는 · 살는 · 알는 · 놀는 → ✓ **만드는 · 사는 · 아는 · 노는** (ㄹ + ㄴ → ㄹ ตก — ข้อ 40 เสริม) · ผู้เรียนเคยพลาด 만들습니다 / 만들으세요 — ตกที่ ㄹ-ราก เหมือนกัน
- **ใช้ -는 กับคำคุณศัพท์:** ✗ 예쁘는 · 매우는 · 작는 → ✓ **예쁜 · 매운 · 작은** (ข้อ 36) — ยกเว้นคำที่ลงท้าย 있다/없다 ซึ่ง **ต้อง** -는 (맛있는 · 재미있는)
- **ใช้ -는 กับอดีต:** ✗ 어제 먹는 음식 → ✓ 어제 **먹은** 음식 *(ข้อ 47 บท 29)* · -는 ใช้กับเรื่องที่เป็นประจำ/ขณะนั้น
- **ตัวสะกดไม่ใช่ปัญหา:** ✗ 먹으는 · 읽으는 → ✓ **먹는 · 읽는** (ไม่ต้องมี 으)
- **ใส่ที่:** ✗ "한국 사람들이 먹는 것 음식" ไม่ต้องใส่ "것" ระหว่างอนุประโยคกับนาม — วาง **นามต่อท้าย -는 ตรง ๆ**
- **ลำดับขยาย:** ✗ 음식 한국 사람들이 먹는 → ✓ 한국 사람들이 먹는 **음식** (อนุประโยคนำ นามท้าย)
- **เสียงนาสิก:** อ่านว่า [멍는] [든는] [잉는] — ✗ เขียนตามเสียง 멍는 · 든는
- **-는 (ขยายนาม) ≠ -는데 (ลงท้าย บท 36 — ข้อ 61)** · **-는 것 (ข้อ 59)** = ทำกริยาให้เป็นนาม: 단어를 외우**는 것**이 힘들었어요

> [!TIP]
> **กริยา → ราก + 는** (ㄹ-ราก ตัด ㄹ · ㄷ อยู่) · **있다/없다 → 는** · **คำคุณศัพท์ → (으)ㄴ (ข้อ 36)** · "ที่" ของไทย = วางอนุประโยคไว้**หน้า**นาม

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- **ยังไม่มีข้อสอบจริง** — 27과 อยู่ใน 복습시험③ (11/6) · **읽기 27-2** (ฝนตกต่อเนื่อง · SMS ปาจอน) เป็นผู้สมัครยกมาทำ 가/나 ใน ③
- **คาดการณ์รูปแบบข้อสอบ:**
  - **보기처럼 쓰세요:** 봄에 자주 입다 / 옷 → 봄에 자주 입는 옷이에요 (ตาราง 6 ข้อ ผสม ㄹ-ราก: 만들다 · 살다 · 알다)
  - **รวมสองประโยค:** 한국 사람들이 여름에 자주 먹어요. 팥빙수예요. → 한국 사람들이 여름에 자주 먹는 음식은 팥빙수예요.
  - **ตอบคำถามด้วยไวยากรณ์ที่กำหนด:** 요즘 배우는 외국어가 뭐예요? → 제가 요즘 배우는 외국어는 한국어예요
  - **เลือกรูปที่ถูก ㄴ / 는:** 매(운 / 는) 음식 · 좋아(한 / 하는) 계절 · 맛있(은 / 는) 영화 *(ตอบ: 운 · 하는 · 는)*
  - **그림을 보고 대답하세요:** 🖼️ ภาพ เด็กกำลังเตะบอล → 축구를 하는 아이 *(เมื่อโจทย์กำหนดให้ใช้ -는)*
- **ข้อผิดที่เคยเจอและเกี่ยวกับข้อนี้ (§6b):** **ㄹ-ราก** (만들습니다 · 만들으세요) · ★ **ลืม/ใส่ 으 ผิดที่** · **좋아 안 해요 → 안 좋아해요** (좋아하다 เป็นกริยาเดียว → 좋아하는) · **ตอบไม่ตรงคำถาม** · ㅈ/ㅊ
