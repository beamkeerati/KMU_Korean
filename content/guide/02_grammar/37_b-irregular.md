## 37. ㅂ 불규칙 (ㅂ ไม่ปกติ: 맵다 → 매워요 · 덥다 → 더워요)

> [!INTRO] ข้อนี้คืออะไร
> ㅂ 불규칙 คือกฎการสะกดของกริยาและคำคุณศัพท์ที่**รากลงท้ายด้วย ㅂ** พอมี**สระ**ตามมา ตัว ㅂ จะเปลี่ยนเป็น 우 (แล้วรวมกับ 어 เป็น 워) แต่ถ้ามี**พยัญชนะ**ตามมา ㅂ อยู่เหมือนเดิม เช่น 맵다 → 매워요 แต่ 맵고 · 맵습니다
>
> เรื่องนี้เป็นเรื่อง "รูป" ล้วน ๆ ความหมายไม่เปลี่ยนเลย 매워요 = 맵다 = เผ็ด สิ่งที่ข้อสอบตรวจคือเขียนรูปถูกหรือไม่ ใช้ทุกครั้งที่ผันคำกลุ่มนี้ ไม่ว่าจะเป็น -아/어요 · -았/었어요 · -(으)ㄴ · -(으)세요 · -(으)ㄹ까요?
>
> สอนในบท 23 (ตำราหน้า 234–235 준비 1) ต่อยอดจาก ข้อ 06 (ผัน -아/어요) · ข้อ 18 (คำคุณศัพท์) · ข้อ 35 (ตารางตัวสะกด) และไปใช้ต่อใน ข้อ 36 (매운 · 더운) · ข้อ 43 (더워졌어요) · ข้อ 50 (더우니까) · ข้อ 55 (더우면) · ข้อ 51 และ 54 (ไม่ปกติชนิดอื่น)

### 📌 รูปแบบและเงื่อนไข

ตำราหน้า 234 เขียนไว้ว่า "ถ้ารากลงท้ายด้วย ㅂ พอรวมกับสระ ㅂ เปลี่ยนเป็น 오 หรือ 우" ส่วนใหญ่เป็น 우 มีเพียง 돕다 กับ 곱다 ที่เป็น 오 เมื่อตามด้วย 아/어 (오 + 아 = 와) เงื่อนไขทั้งหมดจึงมีแค่คำถามเดียวคือ สิ่งที่ต่อท้ายรากขึ้นต้นด้วยสระหรือพยัญชนะ

| ตามหลังรากด้วย | การเปลี่ยน | ตัวอย่าง |
|:---|:---|:---|
| **สระ**: -아/어요 · -았/었- · -(으)ㄴ · -(으)세요 · -(으)ㄹ | ㅂ → **우** (+ 어 → **워**) | 덥다 → 더워요 · 더웠어요 · 더운 · 더우세요 · 더울 거예요 |
| **พยัญชนะ**: -고 · -지 · -ㅂ니다 · -네요 · -지만 · -겠- | ㅂ **อยู่เหมือนเดิม** | 덥고 · 덥지 않아요 · 덥습니다 · 덥네요 · 덥지만 · 덥겠어요 |
| **돕다 · 곱다** + 아/어 | ㅂ → **오** + 아 = **와** | 돕다 → 도와요 · 곱다 → 고와요 *(ช่วย · งาม)* |
| **돕다 · 곱다** + (으) | ㅂ → 우 | 도울까요? · 도우세요 · 고운 |
| **ปกติ** (ลงท้าย ㅂ แต่ไม่ใช่ ㅂ ไม่ปกติ): 입다 · 잡다 · 좁다 | ไม่เปลี่ยน | 입어요 · 입을 거예요 · 잡아요 · 좁아요 *(ใส่ · จับ · แคบ)* |

คำปกติที่ลงท้าย ㅂ นอกตำรา (เสริม): 씹다 · 접다 · 뽑다

#### ที่มาของรูป 워 และ 웠

- ㅂ → 우 แล้ว 우 + 어 → 워: 덥다 → 더우 + 어 → 더**워**요 · 쉽다 → 쉬우 + 어 → 쉬**워**요
- อดีตคือ 우 + 었 → 웠: 덥다 → 더우 + 었 → 더**웠**어요 · 추웠어요 · 어려웠어요 · 반가웠습니다 (읽기 27-2) — รูปอดีตของกลุ่มนี้ลงท้าย 웠 เสมอ
- คำคุณศัพท์ ㅂ ไม่ปกติ**เกือบทั้งหมดลงท้าย 워** แม้สระหน้าจะเป็น ㅏ: 가깝다 → 가까**워**요 · 아름답다 → 아름다**워**요 (ไม่ใช่ 와) การเลือก 아/어 ไม่ได้ดูสระเดิมของราก มีเพียง 돕다 · 곱다 ที่เป็น 와
- รูปทางการ -ㅂ니다 ขึ้นต้นด้วยพยัญชนะ ㅂ จึงอยู่: 덥**습**니다 · 맵**습**니다 · 어렵**습**니다 (ข้อ 21) ออกเสียง 뜨겁습니다 [뜨겁씀니다] · 작습니다 [작씀니다]

#### ตารางผันที่ควรจำ (ตำรา 23과 + 25 · 27 · 28과)

| 기본형 | -아/어요 | -았/었어요 | -(으)ㄴ + N | -ㅂ니다 |
|:---|:---|:---|:---|:---|
| 맵다 *(เผ็ด)* | **매워요** | 매웠어요 | **매운** 음식 | 맵습니다 |

| 춥다 *(หนาว)* | **추워요** | 추웠어요 | **추운** 겨울 | 춥습니다 |
| 쉽다 *(ง่าย)* | **쉬워요** | 쉬웠어요 | **쉬운** 시험 | 쉽습니다 |
| 어렵다 *(ยาก)* | **어려워요** | 어려웠어요 | **어려운** 한국어 | 어렵습니다 |
| 가깝다 *(ใกล้)* | **가까워요** | 가까웠어요 | **가까운** 집 | 가깝습니다 |
| 고맙다 *(ขอบคุณ)* | **고마워요** | 고마웠어요 | **고마운** 친구 | 고맙습니다 |
| 아름답다 *(สวยงาม)* | **아름다워요** | 아름다웠어요 | **아름다운** 경치 | 아름답습니다 |
| 귀엽다 *(น่ารัก)* | **귀여워요** | 귀여웠어요 | **귀여운** 아이 | 귀엽습니다 |
| 더럽다 *(สกปรก)* | **더러워요** | 더러웠어요 | **더러운** 운동화 | 더럽습니다 |
| 돕다 *(ช่วย)* | **도와요** | 도왔어요 | — (กริยา → ข้อ 44) | 돕습니다 |

| 기본형 | -아/어요 | 기본형 | -아/어요 |
|:---|:---|:---|:---|

| 반갑다 *(ยินดีที่ได้พบ)* | 반가워요 | 즐겁다 *(สนุกสนาน)* | 즐거워요 |

| 줍다 *(เก็บ)* | 주워요 | | |

#### ถาม 어때요? / อะไร…กว่า แล้วตอบด้วย ㅂ ไม่ปกติ

| คำถาม | คำตอบ |
|:---|:---|
| 한국어가 어때요? | **어려워요**. 그렇지만 재미있어요. *(ยาก แต่สนุก — ข้อ 40)* |
| 시험이 어땠어요? | **쉬웠어요**. / **어려웠어요**. *(ง่าย / ยาก — อดีต)* |
| 집이 학교에서 가까워요? | 네, **가까워요**. / 아니요, **가깝**지 않아요. |
| 고향 음식이 매워요? | 네, 아주 **매워요**. / 아니요, 안 **매워요**. |

### ⚠️ จุดสับสน

ข้อผิดของเรื่องนี้แทบทั้งหมดเกิดจากคำถามเดียวคือ "ㅂ อยู่หรือเปลี่ยน" ตารางนี้สรุปให้ดูตามสิ่งที่ตามมา

| ตามมาด้วย | ㅂ | ✓ ถูก | ✗ ผิด |
|:---|:---|:---|:---|
| สระ (아/어 · (으)ㄴ · (으)시 · (으)ㄹ) | → 우 | 더워요 · 더운 · 더우세요 · 더울 거예요 | 덥어요 · 덥은 · 덥으세요 |
| พยัญชนะ (ㄱ ㅈ ㅂ ㄴ …) | อยู่ | 덥고 · 덥지만 · 덥습니다 · 덥네요 | 더우고 · 더웁니다 · 더우네요 |

#### กับดัก

- **สองขั้นตอน:** ㅂ → 우 → ต่อ 어 = 워 · ✗ 더어요 · 더우어요 · 덥어요 · 매어요 → ✓ **더워요 · 매워요**
- **와 / 워:** ✗ 어려와요 · 가까와요 · 아름다와요 · 고마와요 → ✓ **어려워요 · 가까워요 · 아름다워요 · 고마워요** ใช้ 와 เฉพาะ 돕다 → 도와요 และ 곱다 → 고와요
- **ปกติ ≠ ไม่ปกติ:** ✗ 이워요 (입다) → ✓ 입어요 · ✗ 조와요 (좁다) → ✓ 좁아요 ท่อง 입다 · 잡다 · 좁다 เป็นข้อยกเว้น (ตำราหน้า 234)
- **ㅂ ไม่ใช่ทุกคำ:** 쉽다 · 어렵다 ไม่ปกติ แต่ 좁다 · 입다 · 잡다 ปกติ ดูจากรายการที่ตำราหรือครูให้ ไม่เดาจากตัวสะกด
- **อดีตต้องมี 었:** ✗ 더워어요 → ✓ 더웠어요 · ✗ 추웠었어요 (ซ้อน)
- **ปฏิเสธ:** 안 + A: **안** 매워요 · -지 않다: 맵**지** 않아요 (ㅂ อยู่ — ข้อ 16)
- **กับ -(으)ㄹ까요? / -(으)ㄹ 거예요:** **도울**까요? · **추울** 거예요 — เปลี่ยนเป็น 우 ก่อน แล้วค่อยใส่ ㄹ (ข้อ 33 · 28)
- **ㅐ/ㅔ ในคำเอง:** 매워요 ใช้ ㅐ (ใบฝึก 23과ผู้เรียนเขียน 메워요)
- **เทียบกับไม่ปกติชนิดอื่น:** ㅡ-drop (예뻐요 · ข้อ 06) · ㄹ-drop (삽니다 — ข้อ 40 เสริม) · ㄷ → ㄹ (들어요 — ข้อ 51) · 르 → ㄹ라 (빨라요 — ข้อ 54)

> [!TIP] กฎสั้น ๆ
> **สระตามมา → ㅂ เป็น 우 (워)** · **พยัญชนะตามมา → ㅂ อยู่** · ข้อยกเว้นที่ปกติ: **입다 · 잡다 · 좁다** · ข้อยกเว้นที่เป็น 와: **돕다 · 곱다**

  - 반대말: 덥다 ↔ 춥다 · 쉽다 ↔ 어렵다 · 가깝다 ↔ 멀다 · 맵다 ↔ 달다 · 무겁다 ↔ 가볍다
  - 해요체 → 합니다체: 매워요 → 맵습니다 · 더워요 → 덥습니다 · 어려워요 → 어렵습니다 (ㅂ กลับมา!)
  - ตอบ 어때요?: 시험이 어때요? (어렵다) → 어려워요 · 🖼️ เทอร์โมมิเตอร์ 48° → 아주 더워요
- **ข้อผิดเดิมที่เกี่ยวกับข้อนี้:** การเลือก 아/어 (살어요 · 받었어요) · ลืม 으 หลังตัวสะกด · ㅈ/ㅊ ในคำที่มี ㅊ (춥다 → 추워요 อย่าเขียน ㅊ เป็น ㅈ) · ㅐ/ㅔ (메워요) · **어때요 vs 어떻게** (ข้อ 18)

> [!SUMMARY] สรุป
> - ดูสิ่งที่ต่อท้ายราก: ขึ้นต้นด้วย**สระ** → ㅂ เป็น 우 (매워요 · 매운 · 매우세요 · 매울 거예요) ขึ้นต้นด้วย**พยัญชนะ** → ㅂ อยู่ (맵고 · 맵습니다 · 맵지 않아요 · 맵네요)
> - อดีตลงท้าย 웠 (매웠어요) · 와 ใช้เฉพาะ 돕다 · 곱다 · 입다 · 잡다 · 좁다 ผันปกติ
> - ความหมายไม่เปลี่ยน ข้อสอบตรวจแค่รูป: ตารางผัน · 반대말 · 해요 → 합니다 · ตอบ 어때요?
