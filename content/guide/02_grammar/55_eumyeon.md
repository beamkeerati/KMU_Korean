## 55. -(으)면 (ถ้า… / เมื่อ…)
ต่อท้ายรากของ**กริยาและคำคุณศัพท์**เพื่อบอก**เงื่อนไข** — "ถ้า A เกิดขึ้น ก็ B" ใช้ได้ทั้งกับเรื่องที่ยังไม่เกิด (แผน) และเรื่องที่เป็นนิสัย/ความจริง ("เมื่อไรที่ A ก็ B เสมอ") — ตำราเรียกว่า condition หรือ presupposition
สอนในบท 33 (교과서 324–325쪽 · 준비 1) · ต่อยอดจาก ข้อ 06 (หารากศัพท์) · ข้อ 28 (กฎ "มีตัวสะกดไหม" แบบเดียวกัน) · ข้อ 18 (คำคุณศัพท์) · ข้อ 33 (-(으)ㄹ까요? ใช้เป็นประโยคหลักได้)
ใช้ต่อใน ข้อ 56 (-(으)ㄹ 때 "ตอนที่…") · ข้อ 61 (-(으)ㄴ/는데요) · ข้อ 62 (-(으)ㄹ게요) · ข้อ 64 (-아/어야 하다) และบท 36 (연습 3 오늘 숙제를 안 하면……) · ขอบเขต 복습시험④ (11/18) และ 기말

### 📌 รูปแบบและเงื่อนไข
ตัด 다 ทิ้ง แล้วดู**พยางค์สุดท้ายของราก**ว่ามีตัวสะกด (받침) ไหม — ตำรา 324쪽: ตัวสะกด → **-으면** · สระ หรือ **ㄹ** → **-면**

| รากศัพท์ลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| มีตัวสะกด (รวม 있다 · 없다) | **-으면** | 먹다 → **먹으면** · 있다 → **있으면** · 없다 → **없으면** · 좋다 → **좋으면** *(ถ้ากิน · ถ้ามี · ถ้าไม่มี · ถ้าดี)* |
| สระ | **-면** | 오다 → **오면** · 되다 → **되면** · 가다 → **가면** · 부르다 → **부르면** *(ถ้ามา · ถ้าเป็น/ถึง · ถ้าไป · ถ้าอิ่ม)* |
| ลงท้ายด้วย **ㄹ** | **-면** (ㄹ ไม่หลุด ไม่ใส่ 으) | 살다 → **살면** · 만들다 → **만들면** · 놀다 → **놀면** *(ถ้าอยู่ · ถ้าทำ · ถ้าเล่น)* |
| ㅂ ไม่ปกติ (ข้อ 37) | ㅂ → **우** + 면 | 춥다 → **추우면** · 덥다 → **더우면** · 쉽다 → **쉬우면** · 돕다 → **도우면** |
| ㄷ ไม่ปกติ (ข้อ 51) | ㄷ → **ㄹ** + 으면 | 듣다 → **들으면** · 걷다 → **걸으면** *(ถ้าฟัง · ถ้าเดิน)* |
| 르 (ข้อ 54) | ไม่เปลี่ยน — 르 เปลี่ยนเฉพาะก่อน 아/어 | 모르다 → **모르면** · 다르다 → **다르면** · 빠르다 → **빠르면** |
| N이다 (เสริม ไม่อยู่ในกล่องตำรา) | N**이면** (หลังสระพูดว่า N**면** ได้) | 학생**이면** · 의사**면** *(ถ้าเป็นนักเรียน · ถ้าเป็นหมอ)* |

- **ตำรา 324쪽:** กล่องไวยากรณ์เขียนว่า "ต่อหลังรากของกริยาหรือคำคุณศัพท์ — แสดงความหมายเงื่อนไข (condition) หรือข้อสมมติ (presupposition)"
- **ประโยคหลัก (หลัง -(으)면) ได้ทุกแบบ:** -아/어요 (นิสัย/ความจริง) · -(으)ㄹ 거예요 (แผน ข้อ 28) · -(으)세요 (สั่ง/แนะนำ ข้อ 20) · -(으)ㄹ까요? (ชวน ข้อ 33) · -(으)ㅂ시다 (ชวนแบบทางการ — ตำรา 324쪽 ใช้ในตัวอย่าง 만납시다 แต่ยังไม่มีข้อไวยากรณ์ของตัวเอง)
- **กาล (tense) ใส่ที่ท้ายประโยคเท่านั้น** ไม่ใส่ที่ 면: ✓ 비가 오면 집에 있을 거예요 / ✗ 비가 올 거면… (ในตำรา 33과 ไม่มี) · รูป -았/었으면 "ถ้าได้…แล้ว/ถ้าหากเคย…" มีจริงแต่**ตำราไม่สอน** (เสริม)
- **ประธานของประโยคเงื่อนไข** ใช้ 이/가 (ข้อ 01): 시간**이** 있으면 · 비**가** 오면 · 기분**이** 나쁘면 · ส่วนประธานของประโยคหลักมักเป็น 저는 (หัวเรื่อง)
- **ออกเสียง (กฎมาตรฐาน — เสริม):** 있으면 [이쓰면] · 없으면 [업쓰면] · 먹으면 [머그면] · 좋으면 [조으면] — ตัวสะกดเลื่อนเป็นต้นพยางค์ถัดไป (หน้าเสียง 발음 ของ 33과 ยังไม่มีในคลัง)

### 📖 ตัวอย่างและการใช้
#### ตัวอย่างจากกล่องไวยากรณ์และ 준비 (324쪽)
1. 비가 **오면** 그 사람이 생각나요. *(ถ้าฝนตก จะนึกถึงคนคนนั้น — 생각나다 ใช้ 이/가 กับสิ่งที่นึกถึง)*
2. 오늘 시간이 **없으면** 다음에 만납시다. *(ถ้าวันนี้ไม่มีเวลา ไว้เจอกันคราวหน้า)*
3. 돼지고기를 **먹으면** 배가 아파요. *(ถ้ากินเนื้อหมู จะปวดท้อง)*
4. 배가 **부르면** 그만 드세요. *(ถ้าอิ่มแล้วก็หยุดทานเถอะ — 드세요 = 먹다 แบบยกย่อง ข้อ 20)*
5. 가: 기차표가 **없으면** 어떻게 해요? — 나: 기차표가 **없으면** 버스로 갈 거예요. *(ถ้าไม่มีตั๋วรถไฟทำยังไง — ถ้าไม่มีตั๋วรถไฟ จะไปด้วยรถบัส)*

#### แบบฝึก: เงื่อนไข → ผลลัพธ์ (연습 1–3, 324–325쪽)
| ประโยค (A -(으)면 B) | แปล |
|:---|:---|
| 방학이 **되면** 아르바이트를 할 거예요. | ถึงช่วงปิดเทอมจะทำงานพิเศษ |
| 고향에 **가면** 어머니께서 만든 음식을 먹을 거예요. | ถ้ากลับบ้านเกิดจะกินอาหารที่คุณแม่ทำ |
| 용돈을 **받으면** 운동화를 살 거예요. | ถ้าได้เงินค่าขนมจะซื้อรองเท้ากีฬา |
| 기분이 **나쁘면** 클래식 음악을 들어요. | ถ้าอารมณ์ไม่ดีจะฟังเพลงคลาสสิก |
| 날씨가 **좋으면** 등산을 해요. | ถ้าอากาศดีจะไปปีนเขา |
| 시간이 **있으면** 소설을 읽어요. | ถ้ามีเวลาจะอ่านนิยาย |
| 스트레스가 **많으면** 많이 먹어요. | ถ้าเครียดมากจะกินเยอะ |
| 비가 **오면** 따뜻한 커피를 마셔요. | ถ้าฝนตกจะดื่มกาแฟร้อน |
| 부모님이 **보고 싶으면** 가족사진을 봐요. | ถ้าคิดถึงพ่อแม่จะดูรูปครอบครัว |
| 100만 원이 **있으면** 노트북을 사고 싶어요. | ถ้ามีหนึ่งล้านวอนอยากซื้อโน้ตบุ๊ก |

- ตำราให้คู่คำ "A / B" เป็นรูปฐาน (방학이 되다 / 아르바이트를 하다) แล้วให้ผู้เรียนต่อเป็นประโยคเอง — ประโยคข้างบนเรียบเรียงตามรูปแบบ 보기 ของตำรา
- **연습 3 (325쪽):** คำถามตัวแกน "…(으)면 뭘 하고 싶어요?" คำตอบ "저는 …(으)면 …을/를 V-고 싶어요" (ข้อ 38) — โจทย์: 비행기가 있다 · 졸업하다 · 100만 원이 있다 · 남자(여자) 친구가 생기다 · 날씨가 맑다 · 영화배우가 되다
- **연습 3 ของบท 36 (355쪽):** ฝึกสัญญาด้วยประโยคเงื่อนไขค้างไว้ — 오늘 숙제를 안 하면…… · 시험에서 1등을 하면…… · 선생님/친구 생일에…… · 고향에 돌아가면…… (ต่อด้วย -(으)ㄹ게요 ข้อ 62: 숙제를 안 하면 벌을 받을게요)

#### ในบทสนทนา · บทอ่าน · กิจกรรม (328–331쪽)
- 윤아: 투이 씨, 방학을 **하면** 부산으로 여행을 갈까요? *(คุณทุย พอปิดเทอมแล้วไปเที่ยวปูซานกันไหม — 방학을 하다 = เริ่มปิดเทอม · 으로 ข้อ 49/51 · -(으)ㄹ까요? ข้อ 33)*
- 투이: 그렇지만 예약할 수 **없으면** 어떻게 해요? *(แต่ถ้าจองไม่ได้จะทำยังไง — -(으)ㄹ 수 없다 ข้อ 46)* — 윤아: 걱정하지 마세요. 버스로도 갈 수 있어요. *(อย่ากังวล ไปรถบัสก็ได้ — -지 마세요 ข้อ 39)*
- 제프리 (33-2): 오전에 출발하는 비행기표가 **없으면** 오후 2시 표로 주세요. *(ถ้าไม่มีตั๋วเครื่องบินออกเช้า ขอตั๋วบ่ายสองโมง — ข้อ 63)*
- 마키 씨의 일정표 (329쪽): 아침에 일찍 일어나**면** 한식을 먹을 거예요. 그렇지만 늦게 일어나**면** 샌드위치를 먹을 거예요. *(ถ้าตื่นเช้าจะกินอาหารเกาหลี แต่ถ้าตื่นสายจะกินแซนด์วิช)* · 저는 방학을 **하면** 남자 친구하고 같이 부산에 갈 거예요.
- ตารางตำรา: 갈 곳 — 날씨가 좋아요 / 비가 와요 → 바다에 가요 / 국제시장에 가요 · 할 일 — 바다에 가요 / 국제시장에 가요 → 수영을 해요 / 기념품을 사요 *(ต่อเป็นห่วงโซ่ได้: 날씨가 좋으면 바다에 가요. 바다에 가면 수영을 해요. — เรียบเรียงตามตาราง)*
- 36과 대화: 시간이 **있으면** 마키 씨하고 같이 영화를 보러 가고 싶어요. *(ถ้ามีเวลาอยากไปดูหนังกับคุณมากิ — -(으)러 ข้อ 26)*

#### ตอบคำถามที่มี -(으)면
| ถามด้วย | ตอบเป็น | ตัวอย่าง |
|:---|:---|:---|
| …(으)면 **뭘 해요?** | …(으)면 + กิจกรรมที่ทำเป็นนิสัย (-아/어요) | 가: 시간이 있으면 뭘 해요? — 나: 저는 시간이 있으면 소설을 읽어요. |
| …(으)면 **뭘 하고 싶어요?** | …(으)면 + N을/를 V-고 싶어요 | 가: 100만 원이 있으면 뭘 하고 싶어요? — 나: 100만 원이 있으면 노트북을 사고 싶어요. |
| …(으)면 **어떻게 해요?** | …(으)면 + วิธีแก้ (-(으)ㄹ 거예요) | 가: 기차표가 없으면 어떻게 해요? — 나: 버스로 갈 거예요. |

### ⚠️ จุดสับสน
#### -(으)면 vs -(으)ㄹ 때 vs -아/어서 vs -(으)니까
| | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| **-(으)면** | **ถ้า** (เงื่อนไข) / เมื่อไรก็ตามที่ | 시간이 있으면 소설을 읽어요 *(ถ้ามีเวลาจะอ่านนิยาย)* |
| -(으)ㄹ 때 (ข้อ 56) | **ตอนที่** (ช่วงเวลา ไม่ใช่เงื่อนไข) | 부산에 갈 때 무엇을 준비할 거예요? *(ตอนไปปูซานจะเตรียมอะไร)* |
| -아/어서 (ข้อ 48) | **เพราะ…** (เหตุผล เกิดขึ้นจริงแล้ว) | 시험이 있어서 공부해야 해요 *(เพราะมีสอบ ต้องอ่านหนังสือ)* |
| -(으)니까 (ข้อ 50) | **เพราะ…** (ใช้นำหน้าสั่ง/ชวนได้) | 가게가 많으니까 쇼핑을 해 보세요 *(เพราะร้านเยอะ ลองช็อปปิงดู)* |

- **-(으)면 = ยังไม่แน่ว่าจะเกิดไหม** · -아/어서 = เกิดขึ้นแล้ว/เป็นความจริง: ✓ 비가 오면 안 가요 *(ถ้าฝนตกจะไม่ไป)* ≠ 비가 와서 안 가요 *(ฝนตกเลยไม่ไป)*
- **ตัวสะกด:** ✓ 먹으면 / ✗ 먹면 · ✓ 있으면 / ✗ 있면 · ✓ 좋으면 / ✗ 좋면 — ลืม 으 หลังตัวสะกด (เคยเกิดซ้ำกับ -(으)세요 · -(으)러 · -(으)ㄹ까요?)
- **ㄹ-ราก:** ✓ 살면 / ✗ 살으면 · ✓ 만들면 / ✗ 만들으면 (เหมือน 만들 거예요 ใน ข้อ 28)
- **ㅂ ไม่ปกติ:** ✓ 추우면 / ✗ 춥으면 · ✓ 더우면 / ✗ 덥으면 (ข้อ 37)
- **되다 ใช้ 이/가:** ✓ 영화배우**가** 되면 · 방학**이** 되면 / ✗ 영화배우를 되면 — (กลับด้านกับกับดัก "ใช้ 가 กับ 받다/듣다" ที่เคยพลาด: 되다 รับ 이/가 ไม่ใช่ 을/를)
- **안 + N하다:** ✓ 숙제를 안 하면 / ✓ 숙제 안 하면 / ✗ 안 숙제하면 (ข้อ 08 — เคยพลาด 안 아르바이트 해요)
- **ประโยคหลักเป็นคำถาม:** ได้ — 방학을 하면 부산으로 여행을 갈까요? · แต่ถ้าถามด้วย -(으)ㄹ 거예요? ถามแผนของผู้ฟัง ไม่ใช่ชวน (ข้อ 33)
- **그러면 / 그럼** ต้นประโยค = "ถ้าอย่างนั้น" เป็นรูปหดของ 그렇(다)+(으)면: 그럼 다음에 같이 식사해요 *(งั้นไว้กินข้าวด้วยกันคราวหน้า — ตำรา 36과 353쪽)*

> [!TIP]
> **-(으)면 = "ถ้า"** (ตัวสะกด → 으면 · สระ/ㄹ → 면) · **-(으)ㄹ 때 = "ตอนที่"** · **-아/어서 = "เพราะ"** — ตัดสินจากความหมายก่อน แล้วค่อยเลือกรูป

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- ยังไม่มีข้อสอบจริงที่ครูตรวจแล้วเกี่ยวกับ -(으)면 — 33과 อยู่ในขอบเขต **복습시험④ (11/18 = 30–37과)** และ **기말시험 (11/20 쓰기·듣기·읽기 · 11/23 말하기 = 23–37과)** ส่วนบท 36 연습 3 (오늘 숙제를 안 하면…) น่าจะโผล่ใน 말하기
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ (CLAUDE.md §6b):** ลืม 으/을 หลังตัวสะกด — 받십니다 ✗ → 받으십니다 · 읽세요 ✗ → 읽으세요 · 씻러 ✗ → 씻으러 · 먹까요 ✗ → 먹을까요 (ข้อนี้คือ ✗ 먹면 → 먹으면) · ㄹ-ราก 만들으세요 ✗ → 만드세요 · ㅡ-ราก 바빱니다 ✗ → 바쁩니다 · **ใช้ 가 กับกริยาที่ต้องการ 을/를** (시계가 받았어요 · 이야기가 들었어요) · 안 + N하다 สลับตำแหน่ง (안 아르바이트 해요)
- **คาดการณ์รูปแบบข้อสอบ** (ตามรูปแบบ 복습시험①② — ยังเป็นการเดา ไม่ใช่ข้อสอบจริง):
  1. **ผันตาราง/เติมคำ:** 먹다 · 오다 · 살다 · 춥다 · 듣다 · 모르다 → ___(으)면 (เน้น ㄹ-ราก · ㅂ · ㄷ)
  2. **ตอบคำถามด้วยไวยากรณ์ที่กำหนด:** 시간이 있으면 뭘 해요? · 100만 원이 있으면 뭘 하고 싶어요? · 기차표가 없으면 어떻게 해요? *(ตอบเป็นประโยคเต็มที่มี -(으)면)*
  3. **ต่อสองประโยคเป็นหนึ่ง:** 비가 오다 / 집에서 쉬다 → 비가 오면 집에서 쉬어요 · 날씨가 좋다 / 등산을 하다
  4. **읽기 → บทสนทนา 가/나:** บท 33-2 (โทรจองตั๋วเครื่องบิน) มีประโยค "오전에 출발하는 비행기표가 없으면 오후 2시 표로 주세요" เหมาะแปลงเป็นบทสนทนาตามรูปแบบ 읽기 ของ 복습시험①②
