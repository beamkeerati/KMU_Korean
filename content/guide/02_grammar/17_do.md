## 17. 도 (...ก็ ...ด้วย ...เหมือนกัน)

> [!INTRO] ข้อนี้คืออะไร
> 도 คือคำช่วยที่ต่อท้ายคำนามหรือคำวิเศษณ์ เพื่อบอกว่า "สิ่งนี้ก็เหมือนกัน" คือเพิ่มจากสิ่งที่พูดไปแล้ว แปลว่า "...ก็ ...ด้วย ...เหมือนกัน" ลงท้ายสระหรือพยัญชนะก็ใช้รูป 도 เหมือนกัน
>
> เรื่องที่ต้องดูมีเรื่องเดียวคือ 도 "แทน" หรือ "ซ้อน" คำช่วยเดิม ถ้าคำนั้นมี 이/가 · 은/는 · 을/를 ให้ 도 แทนที่ แต่ถ้ามี 에 หรือ 에서 หรือ 에게 ให้ 도 มาต่อท้าย
>
> สอนในบท 14 ต่อยอดจากข้อ 01 และข้อ 07 (이/가 · 은/는 · 을/를 ที่ 도 มาแทน) และข้อ 11 (하고 รวมในประโยคเดียว) ไปใช้ต่อในข้อ 31 (만 = ตรงข้ามกับ 도)

### 📌 รูปแบบและเงื่อนไข

สูตรคือ `[คำนาม] + 도` ลงท้ายสระหรือพยัญชนะ **ใช้ 도 เหมือนกัน** ไม่ต้องเลือกรูป ตำรา (128쪽) ให้ใช้หลังคำนามหรือคำวิเศษณ์ และ **ห้ามใช้ร่วมกับ 이/가 และ 을/를** ตารางนี้แยกตามคำช่วยเดิมของคำนามนั้น

| เงื่อนไข | 도 ทำอะไร |
|:---|:---|
| คำนามที่เดิมมี **이/가 · 은/는 · 을/를** | **แทนที่** (ห้ามซ้อน) |
| คำที่มี **에 · 에서 · 에게/한테** | **ซ้อนท้าย** (คำเดิมยังอยู่) |
| ประโยคปฏิเสธ | 도 + 안 / -지 않다 |

#### ตัวอย่างของแต่ละกรณี

ตารางนี้ให้ตัวอย่างหนึ่งประโยคต่อหนึ่งแถว เรียงตามกรณีในตารางข้างบน

| กรณี | 한국어 | ไทย |
|:---|:---|:---|
| แทนที่ | 압둘라 씨는 학생이에요. 저**도** 학생이에요. | {n:อับดุลลา}{e:เป็น}{n:นักเรียน} {n:ฉัน}{p:ก็}{e:เป็น} |
| แทนที่ | 카오루 씨**가** 가요 → 간토야 씨**도** 가요 | คุณคาโอรุไป → คุณกันโตยะก็ไป |
| แทนที่ | 영어**를** 배워요 → 일본어**도** 배워요 | เรียนภาษาอังกฤษ → ภาษาญี่ปุ่นก็เรียน |
| ซ้อนท้าย | 학교**에도** 가요 | ไปโรงเรียนด้วย |
| ซ้อนท้าย | 집**에서도** 공부해요 | ที่บ้านก็เรียน |
| ซ้อนท้าย | 친구**에게도** 줘요 | ให้เพื่อนด้วย |
| ปฏิเสธ | 저**도** 안 가요 | ฉันก็ไม่ไป |

### 📖 ตัวอย่างและการใช้

ตัวอย่างต่อไปนี้อิงตำรา 128~129쪽 และบทเรียน 14과 ตามด้วยการเทียบ 도 กับ 은/는 และกับ 하고

#### ตัวอย่างจากตำรา 14과 (128~129쪽)

ทุกประโยคมี 도 เพิ่มสิ่งที่เหมือนกับประโยคก่อนหน้า

| 한국어 | ไทย |
|:---|:---|
| 교실에 몽골 사람이 있어요. 일본 사람**도** 있어요. | ในห้องมีคนมองโกเลีย คนญี่ปุ่นก็มี |
| 가게에 사과가 있어요. 배**도** 있어요. | ที่ร้านมีแอปเปิ้ล สาลี่ก็มี |
| 가 : 한국어를 배워요? / 나 : 네. 영어**도** 배워요. | เรียนเกาหลีเหรอ / ใช่ ภาษาอังกฤษด้วย |
| 시장에서 사과를 사요. 우유**도** 사요. 고기**도** 사요. | ซื้อแอปเปิ้ล นมด้วย เนื้อด้วย |
| 투이 씨는 커피를 마셔요. 녹차**도** 마셔요. | ดื่มกาแฟ ชาเขียวด้วย |
| 고향 친구**도** 한국말을 배워요? | เพื่อนบ้านเกิดก็เรียนภาษาเกาหลีเหรอ — บทสนทนา 14-1 |
| 집에서 책을 읽어요. 텔레비전**도** 봐요. | อ่านหนังสือที่บ้าน ดูทีวีด้วย — บทอ่าน 14-2 |
| 저**도** 한국 사람이 아니에요. | ฉันก็ไม่ใช่คนเกาหลี |

#### 도 กับ 은/는

คำ 은/는 คือหัวข้อหรือการเปรียบเทียบ ("ส่วน…") ต่างจาก **도** ที่เป็นการเพิ่ม ("…ด้วย") ดังนั้นเมื่อถามด้วย 도 แล้วตอบว่า **ไม่** ให้เปลี่ยนเป็น 은/는

| ถาม (ใช้ 도) | ตอบ (เปลี่ยนเป็น 은/는) | ไทย |
|:---|:---|:---|
| 소라 씨**도** 모자를 사요? | 아니요, 소라 씨**는** 옷을 사요. | {n:คุณโซรา}{p:ก็}{v:ซื้อ}{n:หมวก}เหรอ — {x:ไม่} {n:คุณโซรา}{v:ซื้อ}{n:เสื้อผ้า} |
| 주스**도** 많아요? | 아니요, 주스**는** 적어요. | น้ำผลไม้ก็เยอะเหรอ — ไม่ น้ำผลไม้น้อย (워크북 14과 ข้อ G) |

#### 도 กับ 하고 / 와/과

하고 และ 와/과 เชื่อมคำนามในประโยคเดียว ส่วน 도 เพิ่มสิ่งที่เหมือนกันในประโยคใหม่

| หัวข้อ | 하고 / 와/과 | 도 |
|:---|:---|:---|
| หน้าที่ | เชื่อมคำนามในประโยคเดียว | เพิ่มในประโยคใหม่ |
| ตัวอย่าง | 빵하고 우유를 먹어요 *(กินขนมปังกับนม)* | 빵을 먹어요. 우유도 먹어요. *(กินขนมปัง กินนมด้วย)* |

#### เมื่อประโยคแรกเป็นปฏิเสธ

ถ้าประโยคแรกปฏิเสธ ประโยคที่ตามมาก็ต้องปฏิเสธด้วย

- 저는 커피를 안 마셔요. 녹차**도** 안 마셔요. *({x:ไม่}{v:ดื่ม}{n:ชาเขียว}{p:เหมือนกัน})*

### ⚠️ จุดสับสน

ภาษาไทยใช้ "ก็/ด้วย" ที่เดียวจบ แต่ในภาษาเกาหลี 도 บางครั้ง **แทน** 조사 ตัวเดิม บางครั้ง **ซ้อน** ต่อท้าย 조사 ตัวเดิม จึงเลือกผิดบ่อย ตารางนี้เทียบสองแบบ

| หัวข้อ | 도 แทน | 도 ซ้อน |
|:---|:---|:---|
| ใช้กับ 조사 | 이/가, 은/는, 을/를 | 에, 에서, 에게 (ตัวเดิมยังอยู่) |
| รูป | 저도, 사과도 | 에도, 에서도, 에게도 |
| ตัวอย่าง | 저도 학생이에요 | 학교에도 가요 |

#### ✓ / ✗ ที่พบบ่อย

ข้อผิดที่เจอบ่อยที่สุดคือเอา 도 มาซ้อนกับ 이/가 · 은/는 · 을/를 ทั้งที่ 도 ต้องมาแทน

| ✗ ผิด | ✓ ถูก | ที่มา |
|:---|:---|:---|
| 간토야 씨**가도** 집에 가요 | 간토야 씨**도** 집에 가요 *(คุณกันโตยะก็กลับบ้าน)* | ตำรา 128쪽 |
| 제프리 씨**를도** 만났어요 | 제프리 씨**도** 만났어요 *(ได้พบคุณเจฟฟรีย์ด้วย)* | ตำรา 128쪽 |
| 저**는도** 학생이에요 | 저**도** 학생이에요 *(ฉันก็เป็นนักเรียน)* | — |
| 사과**를도** 먹어요 | 사과**도** 먹어요 *(กินแอปเปิ้ลด้วย)* | — |

#### กับดัก

กับดักทั้งสามข้อนี้ต่อยอดจากตาราง 도 แทนและ 도 ซ้อนด้านบน

- ซ้อนท้ายเมื่อมี 에 / 에서 / 에게 (คำเดิมยังอยู่ 도 มาต่อท้าย)
  - ✓ 학교**에도** 가요. *(ไปโรงเรียนด้วย)*
  - ✓ 집**에서도** 공부해요. *(ที่บ้านก็เรียน)*
  - ✓ 친구**에게도** 선물을 줘요. *(ให้ของขวัญเพื่อนด้วย)*
- 도 กับ 은/는 อยู่ด้วยกันไม่ได้
  - ✗ 저는도 가요 → ✓ 저도 가요 *(ฉันก็ไป)*
  - ปฏิเสธ "ก็ไม่": ✓ 저도 안 가요. *(ฉันก็ไม่ไป)*
- **ใช้ 도 เฉพาะเมื่อมีส่วนที่ "เหมือนกัน" กับประโยคก่อน** — ถ้าทั้งประธานและกริยาต่างกัน ให้ใช้ 은/는 เทียบกัน
  - ✓ 마키 씨**는** 책을 읽어요. 윤아 씨**는** 영화를 봐요. *(คุณมากิอ่านหนังสือ ส่วนคุณยุนอาดูหนัง)*

#### ใช้ 도 ใน 3 ขั้น

ลองทำตามสามขั้นนี้เมื่อต้องเติม 도 ในประโยคที่สอง

1. หาคำที่ "เหมือนกับประโยคก่อน"
2. ถ้าคำนั้นมี 이/가 · 은/는 · 을/를 → ลบคำชี้ทิ้ง แล้วใส่ **도** แทน
3. ถ้าคำนั้นมี 에 · 에서 · 에게 → เก็บไว้ แล้วต่อ **도** ท้ายคำชี้

> [!TIP] กฎสั้น ๆ
> - 이/가 · 은/는 · 을/를 → **ถูก 도 แทนที่**
> - 에/에서/에게 → **도 มาต่อท้าย**
> - ถามด้วย 도 แล้วตอบ "ไม่" → เปลี่ยนเป็น **은/는**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ข้อนี้ยังไม่มีบันทึกว่าเสียคะแนนเพราะ 도 โดยตรง แต่เคยออกในใบฝึกและมีการเก็งไว้ รายการต่อไปนี้เรียงตามแหล่งที่มา

- **워크북 14과 F** เติมประโยค 도 ต่อจากประโยคเดิม 5 ข้อ
  - 김밥도 *(กิมบับด้วย)*
  - 빨래도 *(ซักผ้าด้วย)*
  - 고양이도 *(แมวด้วย)*
  - 책도 *(หนังสือด้วย)*
  - 쇼핑도 *(ช็อปปิงด้วย)*
- **워크북 14과 G** ถามด้วย 도 แล้วตอบ ไม่ → 은/는
- **ครูทำเครื่องหมายใน 워크북 14과** F2 · G1 · G2 — ล้วนเป็นข้อที่ต้อง **เปลี่ยน 을/를 · 이/가 เป็น 도**
- **중간시험 복습문제 ข้อ 3** (ชีตที่ครูแจก): "한국말이 재미있어요. 한국 생활( ) 재미있어요." → **도** *(ภาษาเกาหลีสนุก ชีวิตในเกาหลีก็สนุก)*
- **복습시험 ②** เก็งว่า 쓰기 1 (เติมคำช่วย) มี 도
  - "저는 학생이에요. 제 친구( ) 학생이에요." *(ฉันเป็นนักเรียน เพื่อนของฉันก็เป็นนักเรียน)*
  - ตำรา 14과 ออกในรูปคำถาม "영어도 배워요?" *(เรียนภาษาอังกฤษด้วยไหม)*
- **매일시험 14과** ไม่มีข้อ 도
  - A คำคุณศัพท์จากภาพ
  - B -지 않아요
  - C เขียนตามคำบอก
  - ยังไม่มีบันทึกข้อผิดเรื่อง 도 จึงควรทบทวนข้อผิดมาตรฐาน: ✗ 씨가도 · 씨를도 · 는도

### 🔗 เชื่อมโยง

ข้อนี้ต่อจากคำช่วยหลักที่ 도 มาแทน และเป็นคู่เทียบของ 만 ในบทหลัง

← ต่อยอดจาก

- ข้อ 01 (이/가 · 은/는)
- ข้อ 07 (을/를)
- ข้อ 09 (에 · 에서)
- ข้อ 11 (하고 รวมในประโยคเดียว)

→ ใช้ต่อใน

- ข้อ 29 (에게도 · 한테도)
- ข้อ 31 (만 ↔ 도: 물도 마셔요 ↔ 물만 마셔요 — แทนที่ 을/를 เหมือนกัน)
- ข้อ 35 (ตารางตัวสะกด: 도 ไม่เปลี่ยนรูป)

> [!SUMMARY] สรุป
> - 도 = "…ก็ / …ด้วย" ต่อท้ายคำนามหรือคำวิเศษณ์ ใช้รูปเดียวกันไม่ว่าลงท้ายสระหรือพยัญชนะ
> - 이/가 · 은/는 · 을/를 → ถูก 도 แทนที่ (ห้ามซ้อน)
> - 에 · 에서 · 에게 → 도 ต่อท้าย (คำเดิมยังอยู่)
> - ถามด้วย 도 แล้วตอบ "ไม่" → เปลี่ยนเป็น 은/는
> - 도 เพิ่มในประโยคใหม่ ส่วน 하고 / 와/과 เชื่อมคำนามในประโยคเดียว
> - ใช้ 도 เฉพาะเมื่อมีส่วนที่ "เหมือนกัน" กับประโยคก่อน
