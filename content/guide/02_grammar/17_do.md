## 17. 도 (...ก็ ...ด้วย ...เหมือนกัน)
ต่อท้ายคำนามหรือคำวิเศษณ์เพื่อบอกว่า "สิ่งนี้ก็เหมือนกัน" (เพิ่มจากสิ่งที่พูดไปแล้ว) · สอนในบท 14 · ต่อยอดจากข้อ 01 และข้อ 07 (이/가 · 은/는 · 을/를 ที่ 도 มาแทน) และข้อ 11 (하고 รวมในประโยคเดียว) · ใช้ต่อในข้อ 31 (만 = ตรงข้ามกับ 도)

### 📌 รูปแบบและเงื่อนไข
**สูตร:** `[คำนาม] + 도` — ลงท้ายสระหรือพยัญชนะ **ใช้ 도 เหมือนกัน** ไม่ต้องเลือกรูป · ตำรา (128쪽): ใช้หลังคำนามหรือคำวิเศษณ์ **ห้ามใช้ร่วมกับ 이/가 และ 을/를**

| เงื่อนไข | 도 ทำอะไร | ตัวอย่าง |
|:---|:---|:---|
| คำนามที่เดิมมี **이/가 · 은/는 · 을/를** | **แทนที่** (ห้ามซ้อน) | 압둘라 씨는 학생이에요. 저**도** 학생이에요. *({n:อับดุลลา}{e:เป็น}{n:นักเรียน} {n:ฉัน}{p:ก็}{e:เป็น})* · 카오루 씨**가** 가요 → 간토야 씨**도** 가요 · 영어**를** 배워요 → 일본어**도** 배워요 |
| คำที่มี **에 · 에서 · 에게/한테** | **ซ้อนท้าย** (คำเดิมยังอยู่) | 학교**에도** 가요 · 집**에서도** 공부해요 · 친구**에게도** 줘요 |
| ประโยคปฏิเสธ | 도 + 안 / -지 않다 | 저**도** 안 가요. *(ฉันก็ไม่ไป)* |

### 📖 ตัวอย่างและการใช้
**ตัวอย่าง (อิงตำรา 128~129쪽 และบทเรียน 14과)**
1. 교실에 몽골 사람이 있어요. 일본 사람**도** 있어요. *(ในห้องมีคนมองโกเลีย คนญี่ปุ่นก็มี)*
2. 가게에 사과가 있어요. 배**도** 있어요. *(ที่ร้านมีแอปเปิ้ล สาลี่ก็มี)*
3. 가 : 한국어를 배워요? / 나 : 네. 영어**도** 배워요. *(เรียนเกาหลีเหรอ / ใช่ ภาษาอังกฤษด้วย)*
4. 시장에서 사과를 사요. 우유**도** 사요. 고기**도** 사요. *(ซื้อแอปเปิ้ล นมด้วย เนื้อด้วย)*
5. 투이 씨는 커피를 마셔요. 녹차**도** 마셔요. *(ดื่มกาแฟ ชาเขียวด้วย)*
6. 고향 친구**도** 한국말을 배워요? *(เพื่อนบ้านเกิดก็เรียนภาษาเกาหลีเหรอ — บทสนทนา 14-1)*
7. 집에서 책을 읽어요. 텔레비전**도** 봐요. *(อ่านหนังสือที่บ้าน ดูทีวีด้วย — บทอ่าน 14-2)* · 저**도** 한국 사람이 아니에요. *(ฉันก็ไม่ใช่คนเกาหลี)*

**เปรียบเทียบกับ 은/는 และ 하고**
* **은/는** = หัวข้อ/เปรียบเทียบ ("ส่วน…") ต่างจาก **도** = เพิ่ม ("…ด้วย") → ถามด้วย 도 แล้วตอบ **ไม่** ให้เปลี่ยนเป็น 은/는: 소라 씨**도** 모자를 사요? — 아니요, 소라 씨**는** 옷을 사요. *({n:คุณโซรา}{p:ก็}{v:ซื้อ}{n:หมวก}เหรอ — {x:ไม่} {n:คุณโซรา}{v:ซื้อ}{n:เสื้อผ้า})* · 주스**도** 많아요? — 아니요, 주스**는** 적어요. *(워크북 14과 ข้อ G)*
* **하고 / 와/과** เชื่อมคำนามในประโยคเดียว (빵하고 우유를 먹어요) / **도** เพิ่มในประโยคใหม่ (빵을 먹어요. 우유도 먹어요.)
* ถ้าประโยคแรกปฏิเสธ ประโยคที่ตามมาก็ปฏิเสธด้วย: 저는 커피를 안 마셔요. 녹차**도** 안 마셔요. *({x:ไม่}{v:ดื่ม}{n:ชาเขียว}{p:เหมือนกัน})*

### ⚠️ จุดสับสน: 도 "แทน" vs "ซ้อน"
ภาษาไทยใช้ "ก็/ด้วย" ที่เดียวจบ แต่ในภาษาเกาหลี 도 บางครั้ง **แทน** 조사 ตัวเดิม บางครั้ง **ซ้อน** ต่อท้าย 조사 ตัวเดิม จึงเลือกผิดบ่อย

| | 도 แทน | 도 ซ้อน |
|:---|:---|:---|
| ใช้กับ 조사 | 이/가, 은/는, 을/를 | 에, 에서, 에게 (ตัวเดิมยังอยู่) |
| รูป | 저도, 사과도 | 에도, 에서도, 에게도 |
| ตัวอย่าง | 저도 학생이에요 | 학교에도 가요 |

| ✗ ผิด | ✓ ถูก |
|:---|:---|
| 간토야 씨**가도** 집에 가요 | 간토야 씨**도** 집에 가요 *(ตำรา 128쪽)* |
| 제프리 씨**를도** 만났어요 | 제프리 씨**도** 만났어요 *(ตำรา 128쪽)* |
| 저**는도** 학생이에요 | 저**도** 학생이에요 |
| 사과**를도** 먹어요 | 사과**도** 먹어요 |

* ✓ 학교**에도** 가요. *(ไปโรงเรียนด้วย — 에 ยังอยู่ 도 มาต่อท้าย)* · ✓ 집**에서도** 공부해요. *(ที่บ้านก็เรียน)* · ✓ 친구**에게도** 선물을 줘요. *(ให้ของขวัญเพื่อนด้วย)*
* ✗ 저는도 가요 → ✓ 저도 가요 *(도 กับ 은/는 อยู่ด้วยกันไม่ได้)* · ปฏิเสธ "ก็ไม่": ✓ 저도 안 가요.
* **ใช้ 도 เฉพาะเมื่อมีส่วนที่ "เหมือนกัน" กับประโยคก่อน** — ถ้าทั้งประธานและกริยาต่างกัน ให้ใช้ 은/는 เทียบกัน: ✓ 마키 씨**는** 책을 읽어요. 윤아 씨**는** 영화를 봐요. *(คุณมากิอ่านหนังสือ ส่วนคุณยุนอาดูหนัง)*

**ใช้ 도 ใน 3 ขั้น:** ① หาคำที่ "เหมือนกับประโยคก่อน" ② ถ้าคำนั้นมี 이/가 · 은/는 · 을/를 → ลบคำชี้ทิ้ง แล้วใส่ **도** แทน ③ ถ้าคำนั้นมี 에 · 에서 · 에게 → เก็บไว้ แล้วต่อ **도** ท้ายคำชี้

> [!TIP]
> 이/가 · 은/는 · 을/를 → **ถูก 도 แทนที่** · 에/에서/에게 → **도 มาต่อท้าย** · ถามด้วย 도 แล้วตอบ "ไม่" → เปลี่ยนเป็น **은/는**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
* **워크북 14과 F–G:** F เติมประโยค 도 ต่อจากประโยคเดิม 5 ข้อ (김밥도 · 빨래도 · 고양이도 · 책도 · 쇼핑도) · G ถามด้วย 도 แล้วตอบ ไม่ → 은/는 (ครูทำเครื่องหมาย F2 · G1 · G2 — ล้วนเป็นข้อที่ต้อง **เปลี่ยน 을/를 · 이/가 เป็น 도**)
* **중간시험 복습문제 ข้อ 3** (ชีตที่ครูแจก): "한국말이 재미있어요. 한국 생활( ) 재미있어요." → **도**
* **복습시험 ②:** เก็งว่า 쓰기 1 (เติมคำช่วย) มี 도 — เช่น "저는 학생이에요. 제 친구( ) 학생이에요." · ตำรา 14과 ออกในรูปคำถาม "영어도 배워요?"
* **매일시험 14과** ไม่มีข้อ 도 (A คำคุณศัพท์จากภาพ · B -지 않아요 · C เขียนตามคำบอก) — ยังไม่มีบันทึกข้อผิดเรื่อง 도 จึงควรทบทวนข้อผิดมาตรฐาน: ✗ 씨가도 · 씨를도 · 는도
