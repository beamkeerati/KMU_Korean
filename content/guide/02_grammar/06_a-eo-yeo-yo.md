## 06. -아/어/여요 (รูปสุภาพไม่เป็นทางการ — ผันกริยา/คุณศัพท์)
ลงท้ายประโยคแบบสุภาพที่ใช้บ่อยที่สุดในชีวิตประจำวัน ใช้ได้ทั้ง **บอกเล่า · ถาม · สั่ง · ชวน** (ดูจากน้ำเสียงและบริบท) และเป็นฐานของรูปอื่นทั้งหมด · สอนในบท 11 (교과서 96쪽)
ต่อยอดจากข้อ 02 (이에요/예요 = หางสุภาพของ**นาม** · ข้อนี้คือหางสุภาพของ**กริยา**) และข้อ 05 (있어요/없어요) · ใช้ต่อในข้อ 08 (안 + V), 16 (-지 않다), 18 (คุณศัพท์), 23 (-았/었/였-), 20–21 (-(으)세요 · -ㅂ니다)

### 📌 รูปแบบและเงื่อนไข
วิธีผัน: **① ตัด 다 ได้ "ราก" → ② ดูสระของพยางค์สุดท้ายของราก → ③ เติม 아요/어요 → ④ ควบสระถ้าลงท้ายด้วยสระ**

| เงื่อนไข (พยางค์สุดท้ายของราก) | เติม | ตัวอย่าง |
|:---|:---|:---|
| สระ **ㅏ หรือ ㅗ** | **아요** | 가다 → 가 + 아요 = **가요** *(ไป)* · 앉다 → **앉아요** *(นั่ง)* · 오다 → **와요** *(มา)* · 보다 → **봐요** *(ดู)* |
| สระ **อื่นทั้งหมด** (ㅓ ㅜ ㅣ ㅐ ฯลฯ ที่ไม่ใช่ ㅏ/ㅗ) | **어요** | 먹다 → **먹어요** *(กิน)* · 읽다 → **읽어요** *(อ่าน)* · 씻다 → **씻어요** *(ล้าง)* · 마시다 → **마셔요** *(ดื่ม)* |
| ลงท้าย **하다** | **해요** (하 + 여요 → 하여요 → 해요) | 공부하다 → **공부해요** *(เรียน)* · 일하다 → **일해요** *(ทำงาน)* · 운동하다 → **운동해요** *(ออกกำลังกาย)* |
| ลงท้าย **ㅡ** | **ตัด ㅡ ก่อน** แล้วดูสระพยางค์หน้า: ㅏ/ㅗ → 아요 · อื่น หรือไม่มีพยางค์หน้า → 어요 | 쓰다 → ㅆ + 어요 = **써요** *(เขียน)* · 끄다 → **꺼요** *(ปิด)* · 아프다 → 아ㅍ + 아요 = **아파요** *({v:เจ็บ})* · 예쁘다 → **예뻐요** *(สวย)* |

**ควบสระ (กฎรวมสระ)** — เกิดเมื่อรากลงท้ายด้วยสระ (ไม่มีตัวสะกด) ส่วนรากที่มีตัวสะกด เติมต่อได้เลย: 앉아요 · 팔아요 · 받아요 · 먹어요 · 입어요

| ราก + 아/어 | ควบเป็น | ตัวอย่าง |
|:---|:---|:---|
| ㅏ + 아 | ㅏ | 가 + 아요 = **가요** · **자요** *(นอน)* · **사요** *(ซื้อ)* · **만나요** *(พบ)* |
| ㅗ + 아 | ㅘ | 오 + 아요 = **와요** · 보 + 아요 = **봐요** |
| ㅜ + 어 | ㅝ | 주 + 어요 = **줘요** *(ให้)* · 배우 + 어요 = **배워요** *(เรียน)* · 춤추 + 어요 = **춤춰요** *(เต้น)* |
| ㅣ + 어 | ㅕ | 마시 + 어요 = **마셔요** · 가르치 + 어요 = **가르쳐요** *(สอน)* · 기다리 + 어요 = **기다려요** *(รอ)* |
| ㅟ + 어 | ไม่ควบ | 쉬 + 어요 = **쉬어요** *(พัก — ✗ 숴요)* |

- **ใช้กับกริยาและคุณศัพท์** (ข้อ 18): 가요 · 좋아요 · 많아요 · 예뻐요 · ส่วน**นาม**ใช้ 이에요/예요 (ข้อ 02)
- **ถาม** ใช้รูปเดิมแล้วขึ้นเสียงท้าย ไม่ต้องเติม "ไหม": 먹어요. ↘ *(กิน)* · 먹어요? ↗ *(กินไหม)* · **ชวน**: 같이 가요 *(ไปด้วยกันเถอะ)*
- **สุภาพไม่เป็นทางการ** ใช้ในบทสนทนาทั่วไป · ทางการใช้ -ㅂ니다/습니다 (ข้อ 21)
- ลำดับประโยค: **ประธาน이/가(은/는) + กรรม을/를 + กริยา-아/어/여요** — 친구가 빵을 먹어요 *(เพื่อนกินขนมปัง — ข้อ 07)*

### 📖 ตัวอย่างและการใช้

**จากตำรา (บท 11)**
- 아이가 자요? → 네, 아이가 자요. *(เด็กนอนไหม → ใช่ เด็กนอน)* · 알렉세이 씨가 쉬어요? → 아니요, 노래해요. *(คุณอเล็กเซย์พักไหม → ไม่ ร้องเพลง)*
- 무엇을 해요? → 텔레비전을 봐요. · 왕쯔이 씨는 무엇을 해요? → 저는 지금 숙제를 해요. *(ทำอะไรอยู่ → ดูทีวี · คุณหวางจื่ออีทำอะไร → ตอนนี้ฉันทำการบ้าน)*
- บทอ่านวันเกิดคุณทุย: 마키 씨는 노래를 해요. 알렉세이 씨는 춤을 춰요. 제프리 씨는 케이크를 먹어요. 압둘라 씨는 주스를 마셔요. 카오루 씨는 사진을 찍어요. 파티가 재미있어요. *({n:คุณมากิ}{v:ร้องเพลง} · {n:อเล็กเซย์}{v:เต้น} · {n:เจฟฟรีย์}{v:กิน}{n:เค้ก} · {n:อับดุลลา}{v:ดื่ม}{n:น้ำผลไม้} · {n:คาโอรุ}{v:ถ่ายรูป} · {n:ปาร์ตี้}{v:สนุก})*
- คุณศัพท์ในกล่องไวยากรณ์ของตำรา: 좋+아요 = **좋아요** · 많+아요 = **많아요** · 예쁘+어요 = **예뻐요** *(ดี · มาก · สวย — ข้อ 18)*

📽️ **สไลด์อาจารย์ (สมุดจด "4 Rules" + กฎควบสระ)** — **1)** ㅏ/ㅗ + 아요 (가다 → 가아요 → 가요 · 앉다 → 앉아요) **2)** ถ้าไม่ใช่ ㅏ/ㅗ + 어요 (먹다 · 씻다 · 마시다 → 마시어요 = 마셔요) **3)** ___하다 → ___해요 **4)** ถ้ามี ㅡ ให้ตัด ㅡ ออกก่อน แล้วไปใช้กฎ 1) หรือ 2) (쓰다 → 써요 · 아프다 → 아파요) **5)** กฎควบสระ ㅗ + ㅏ = ㅘ · ㅣ + ㅓ = ㅕ

#### 📽️ ฝึกจากสไลด์อาจารย์ — ใบงาน 11과 형태 연습 (ผัน 24 คำ)
- **아요**: 가다 → **가요** · 자다 → **자요** · 사다 → **사요** · 만나다 → **만나요** · 팔다 → **팔아요** *(ขาย)* · 앉다 → **앉아요** · 받다 → **받아요** *(รับ)* · 오다 → **와요** · 보다 → **봐요**
- **어요**: 먹다 → **먹어요** · 읽다 → **읽어요** · 입다 → **입어요** *(สวมใส่)* · 쉬다 → **쉬어요** · 씻다 → **씻어요** · 주다 → **줘요** · 배우다 → **배워요** · 춤추다 → **춤춰요** · 마시다 → **마셔요** · 가르치다 → **가르쳐요** · 기다리다 → **기다려요**
- **해요 · ㅡ ตก**: 공부하다 → **공부해요** · 이야기하다 → **이야기해요** *({v:คุย}กัน)* · 일하다 → **일해요** · 운동하다 → **운동해요** · 노래하다 → **노래해요** *(ร้องเพลง)* · 쓰다 → **써요** · 끄다 → **꺼요**

### ⚠️ จุดสับสน

#### -아/어요 vs -(스)ㅂ니다 vs -세요
สามตัวนี้ดูเป็น "กริยาลงท้ายสุภาพ" เหมือนกัน แต่จริง ๆ อยู่คนละแกน: **-아/어요 กับ -ㅂ니다 = ระดับความเป็นทางการ** (เลือกอย่างใดอย่างหนึ่งต่อสถานการณ์) ส่วน **-세요 = ยกย่องประธาน** (แกนคนละอัน ซ้อนกับทั้งสองระดับได้)

| | สุภาพทั่วไป (아/어요) | ทางการ (ㅂ니다) |
|:---|:---|:---|
| ธรรมดา | 가요 | 갑니다 |
| ยกย่องประธาน (시) | 가세요 | 가십니다 |

* 저는 학교에 **가요**. ✓ *(ฉันไปโรงเรียน — สุภาพทั่วไป)* · 저는 학교에 **갑니다**. ✓ *(ทางการ)*
* 선생님이 학교에 **가세요**. ✓ *(คุณครูไปโรงเรียน — ยกย่อง + สุภาพทั่วไป)* · 선생님이 학교에 **가십니다**. ✓ *(ยกย่อง + ทางการ)*

**กับดัก:** พูด*กับ*อาจารย์ ใช้ 아/어요 ได้ (สุภาพพอแล้ว) แต่พูด*ถึง*อาจารย์ ต้องใส่ 시 ที่กริยาของอาจารย์ → 선생님이 **가세요** ✓ / 선생님이 가요 ✗

> [!TIP]
> **กฎจำง่าย:** 아/어요 กับ ㅂ니다 = เลือก 1 ใน 2 (ระดับ) · 시 = ถามว่า "ประธานควรยกย่องไหม" (แกนอีกอัน) — ดูข้อ 20 และข้อ 21

#### ผันผิดที่เจอบ่อย
| ✗ ผิด | ✓ ถูก | เพราะ |
|:---|:---|:---|
| 받어요 · 살어요 | **받아요** · **살아요** | พยางค์สุดท้าย 받/살 มีสระ ㅏ → 아요 (ตัวสะกด ㄷ/ㄹ ไม่นับ — ดูแต่สระ) |
| 춤어요 | 춤을 **춰요** | 춤을 추다 → 추 + 어요 = 춰요 (ㅜ + ㅓ = ㅝ) |
| 주세요 *(เมื่อหมายถึง "ให้")* | **줘요** | 주세요 = "ขอ…หน่อย" (บท 10) · 줘요 = "ให้" |
| 공부하어요 · 공부하요 | **공부해요** | ลงท้าย 하다 → 해요 |
| 마시요 · 마시어요 *(ขั้นกลางที่ยังไม่ควบ)* | **마셔요** | ㅣ + ㅓ = ㅕ |
| 쓰요 · 쓰어요 *(ยังไม่ตัด ㅡ)* | **써요** | ตัด ㅡ ก่อนเติม 어 |
| 숴요 | **쉬어요** | ㅟ ไม่ควบ |
| 반나요 | **만나요** | ขึ้นต้นด้วย ㅁ ไม่ใช่ ㅂ |
