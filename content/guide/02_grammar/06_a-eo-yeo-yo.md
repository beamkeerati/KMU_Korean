## 06. -아/어/여요 (รูปสุภาพไม่เป็นทางการ — ผันกริยา/คุณศัพท์)

> [!INTRO] ข้อนี้คืออะไร
> -아/어/여요 คือรูปลงท้ายแบบสุภาพที่ใช้บ่อยที่สุดในชีวิตประจำวัน ใช้ได้ทั้ง **บอกเล่า ถาม สั่ง และชวน** ดูจากน้ำเสียงและบริบท และยังเป็นฐานของรูปอื่นทั้งหมด
>
> สอนในบท 11 (교과서 96쪽) ต่อยอดจากข้อ 02 (이에요/예요 = หางสุภาพของ**นาม** ส่วนข้อนี้คือหางสุภาพของ**กริยา**) และข้อ 05 (있어요/없어요)
>
> ไปใช้ต่อในข้อ 08 (안 + V) ข้อ 16 (-지 않다) ข้อ 18 (คุณศัพท์) ข้อ 23 (-았/었/였-) และข้อ 20–21 (-(으)세요 · -ㅂ니다)

### 📌 รูปแบบและเงื่อนไข

การผันมี 4 ขั้น ตารางข้างล่างสรุปเงื่อนไขทีละกรณี ตามด้วยกฎควบสระและข้อควรรู้เรื่องการถามกับการชวน

1. ตัด 다 ได้ "ราก"
2. ดูสระของพยางค์สุดท้ายของราก
3. เติม 아요/어요
4. ควบสระถ้าลงท้ายด้วยสระ

| เงื่อนไข (พยางค์สุดท้ายของราก) | เติม | ตัวอย่าง |
|:---|:---|:---|
| สระ **ㅏ** | **아요** | 가다 → 가 + 아요 = **가요** *(ไป)* · 앉다 → **앉아요** *(นั่ง)* |
| สระ **ㅗ** | **아요** | 오다 → **와요** *(มา)* · 보다 → **봐요** *(ดู)* |
| สระ**อื่นทั้งหมด** (ㅓ ㅜ ㅣ ㅐ ฯลฯ ที่ไม่ใช่ ㅏ/ㅗ) | **어요** | 먹다 → **먹어요** *(กิน)* · 읽다 → **읽어요** *(อ่าน)* · 씻다 → **씻어요** *(ล้าง)* |
| ลงท้าย **하다** | **해요** (하 + 여요 → 하여요 → 해요) | 공부하다 → **공부해요** *(เรียน)* · 일하다 → **일해요** *(ทำงาน)* · 운동하다 → **운동해요** *(ออกกำลังกาย)* |
| **ㅡ** ตัดก่อน → พยางค์หน้า **ㅏ/ㅗ** | **아요** | 아프다 → 아ㅍ + 아요 = **아파요** *({v:เจ็บ})* |
| **ㅡ** ตัดก่อน → พยางค์หน้า**อื่น/ไม่มี** | **어요** | 쓰다 → ㅆ + 어요 = **써요** *(เขียน)* · 끄다 → **꺼요** *(ปิด)* · 예쁘다 → **예뻐요** *(สวย)* |

#### ควบสระ (กฎรวมสระ)

การควบสระเกิดเมื่อรากลงท้ายด้วยสระ (ไม่มีตัวสะกด) ส่วนรากที่มีตัวสะกดเติมต่อได้เลยโดยไม่ต้องควบ

| ราก + 아/어 | ควบเป็น | ตัวอย่าง |
|:---|:---|:---|
| ㅏ + 아 | ㅏ | 가 + 아요 = **가요** *(ไป)* · **자요** *(นอน)* |
| ㅏ + 아 | ㅏ | **사요** *(ซื้อ)* · **만나요** *(พบ)* |
| ㅗ + 아 | ㅘ | 오 + 아요 = **와요** · 보 + 아요 = **봐요** |
| ㅜ + 어 | ㅝ | 주 + 어요 = **줘요** *(ให้)* · 배우 + 어요 = **배워요** *(เรียน)* · 춤추 + 어요 = **춤춰요** *(เต้น)* |
| ㅣ + 어 | ㅕ | 마시 + 어요 = **마셔요** *(ดื่ม)* · 가르치 + 어요 = **가르쳐요** *(สอน)* · 기다리 + 어요 = **기다려요** *(รอ)* |
| ㅟ + 어 | ไม่ควบ | 쉬 + 어요 = **쉬어요** *(พัก — ✗ 숴요)* |

- รากที่มีตัวสะกด เติมต่อได้เลย (ไม่ต้องควบ): 앉아요, 팔아요, 받아요, 먹어요, 입어요

#### ข้อควรรู้เกี่ยวกับการใช้

รูป -아/어요 ใช้ได้กับกริยาและคุณศัพท์ ถามและชวนได้ด้วยรูปเดียวกัน และเป็นระดับสุภาพไม่เป็นทางการ

- **ใช้กับกริยาและคุณศัพท์** (ข้อ 18): 가요, 좋아요, 많아요, 예뻐요 — ส่วน**นาม**ใช้ 이에요/예요 (ข้อ 02)
- **ถาม** ใช้รูปเดิมแล้วขึ้นเสียงท้าย ไม่ต้องเติม "ไหม": 먹어요. ↘ *(กิน)* · 먹어요? ↗ *(กินไหม)*
- **ชวน**: 같이 가요 *(ไปด้วยกันเถอะ)*
- **สุภาพไม่เป็นทางการ** ใช้ในบทสนทนาทั่วไป ส่วนทางการใช้ -ㅂ니다/습니다 (ข้อ 21)
- ลำดับประโยค: **ประธาน이/가(은/는) + กรรม을/를 + กริยา-아/어/여요** — 친구가 빵을 먹어요 *(เพื่อนกินขนมปัง — ข้อ 07)*

#### สูตรและวิธีทำ: -아/어/여요 (แบบกระดานครู)

กฎการผันมี 4 ข้อ บวกข้อ 5 เรื่องควบสระ (เขียนเป็นข้อ ๆ แบบกระดานครู) ทุกข้อดูที่ **ราก** (กริยาหรือคุณศัพท์ที่ตัด 다 แล้ว) และดู**สระของพยางค์สุดท้าย**เท่านั้น ตัวสะกดไม่ใช้เลือก 아 หรือ 어

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | พยางค์สุดท้ายของรากมีสระ **ㅏ** หรือ **ㅗ** | ต่อ **아요** | สระ ㅏ ㅗ จับคู่กับ 아 |
| **กฎ 2** | สระอื่นทั้งหมด (ㅓ ㅜ ㅣ ㅟ …) | ต่อ **어요** | สระที่ไม่ใช่ ㅏ ㅗ จับคู่กับ 어 |
| **กฎ 3** | รากลงท้าย **하** (…하다) | ได้ **해요** | 하 + 여요 = 하여요 แล้วย่อเป็น 해요 (ตำรา 96쪽) |
| **กฎ 4** | รากลงท้ายด้วย **ㅡ** (쓰 · 아프 · 예쁘) | **ตัด ㅡ ก่อน** แล้วดูสระของพยางค์ที่อยู่หน้า ถ้าเป็น ㅏ/ㅗ ใช้ 아 ถ้าเป็นสระอื่นหรือไม่มีพยางค์หน้าใช้ 어 | ㅡ ไม่ใช่ทั้งสองกลุ่ม จึงต้องไปดูพยางค์หน้า |
| **กฎ 5** (ข้อเพิ่ม) | รากไม่มีตัวสะกด ทำให้สระชนกัน | **ควบสระ**เป็นพยางค์เดียว | ตัวสะกดไม่มี สระท้ายรากจึงชนกับ 아/어 โดยตรง |

ลำดับทำคือ ① ดูว่ารากลงท้ายด้วย ㅡ ไหม ถ้าใช่ตัด ㅡ ก่อน ② ดูสระที่เหลือ แล้วเลือก 아 (ㅏ ㅗ) หรือ 어 (สระอื่น) หรือ 여 (…하) ③ ต่อกัน แล้วควบสระถ้ารากไม่มีตัวสะกด ตารางนี้แสดงทุกขั้นกับคำที่ตำราและใบงานใช้

| ราก + คำต่อ | ① ตัด ㅡ? | ② ดูสระ → เลือก | ③ ควบสระ? | ④ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|:---|
| 받 + 아/어요 | ไม่มี ㅡ | ㅏ → 아 | ไม่ควบ (มีตัวสะกด) | **받아요** | ✗ 받어요 |
| 가 + 아/어요 | ไม่มี ㅡ | ㅏ → 아 | ควบ: 아 ยุบเข้า ㅏ | **가요** | ไม่เขียน 가아요 |
| 팔 + 아/어요 | ไม่มี ㅡ | ㅏ → 아 | ไม่ควบ (มี ㄹ) | **팔아요** | ㄹ ไม่หลุด ✗ 팔어요 |
| 보 + 아/어요 | ไม่มี ㅡ | ㅗ → 아 | ควบ ㅗ + ㅏ = ㅘ | **봐요** | ตำราเขียน 보아요 (봐요) |
| 오 + 아/어요 | ไม่มี ㅡ | ㅗ → 아 | ควบ ㅗ + ㅏ = ㅘ | **와요** | |
| 먹 + 아/어요 | ไม่มี ㅡ | ㅓ → 어 | ไม่ควบ (มีตัวสะกด) | **먹어요** | |
| 읽 + 아/어요 | ไม่มี ㅡ | ㅣ → 어 | ไม่ควบ (มีตัวสะกด) | **읽어요** | ✗ 읽아요 |
| 주 + 아/어요 | ไม่มี ㅡ | ㅜ → 어 | ควบ ㅜ + ㅓ = ㅝ | **줘요** | "ให้" |
| 마시 + 아/어요 | ไม่มี ㅡ | ㅣ → 어 | ควบ ㅣ + ㅓ = ㅕ | **마셔요** | |
| 쉬 + 아/어요 | ไม่มี ㅡ | ㅟ → 어 | ไม่ควบ | **쉬어요** | ✗ 숴요 |
| 공부하 + 아/어요 | ไม่มี ㅡ | …하 → 여 | 하 + 여 ย่อเป็น 해 | **공부해요** | กฎ 3 |
| 쓰 + 아/어요 | ตัด → ㅆ | ไม่มีพยางค์หน้า → 어 | ㅆ + ㅓ = 써 | **써요** | ✗ 쓰어요 |
| 아프 + 아/어요 | ตัด → 아ㅍ | พยางค์หน้า 아 (ㅏ) → 아 | ㅍ + ㅏ = 파 | **아파요** | ✗ 아프아요 |
| 예쁘 + 아/어요 | ตัด → 예ㅃ | พยางค์หน้า 예 (ไม่ใช่ ㅏ ㅗ) → 어 | ㅃ + ㅓ = 뻐 | **예뻐요** | ✗ 예쁘어요 |

> [!TIP] วิธีจำสั้น ๆ
> ตัด ㅡ ก่อน แล้วดูแค่สระ ㅏ ㅗ = 아 สระอื่น = 어 …하 = 해 ตัวสะกดไม่มีผลกับการเลือก (받 เป็น 받아요 เพราะสระ ㅏ ไม่ใช่เพราะ ㅂ) ตัวสะกดมีผลแค่ว่าต้องควบสระไหม และ ㄹ ในรากอย่าง 팔 ไม่หายเมื่อต่อ 아/어

#### รูปผิด / รูปถูก ของ -아/어/여요

สี่แถวแรกคือรูปที่ผู้เรียนเคยเขียนผิดจริงในใบฝึก ส่วนแถวสุดท้ายเป็นข้อเตือนจากตารางควบสระข้างบน ตารางนี้เทียบรูปผิดกับรูปถูกพร้อมกฎที่ใช้ตัดสิน

| ✗ รูปผิด | ✓ รูปถูก | ใช้กฎไหน |
|:---|:---|:---|
| 받어요 | **받아요** | กฎ 1: สระ ㅏ → 아 (ครูวงกลมในใบฝึกบท 11) |
| 살어요 | **살아요** | กฎ 1: สระ ㅏ → 아 และ ㄹ อยู่ครบ (ใบฝึกบท 19 ครูไฮไลต์) |
| 춤어요 | **춤춰요** หรือ **춰요** | 춤 เป็นคำนาม ราก 추 + 어 ควบเป็น 춰 (กฎ 2 + 5) |
| 주세요 (ตั้งใจ "ให้") | **줘요** | 주 + 어 = 줘 ส่วน 주세요 แปลว่า "ขอ" |
| 숴요 | **쉬어요** | ㅟ ไม่ควบกับ 어 (กฎ 2) |

#### 📽️ จากสไลด์อาจารย์ — สมุดจด "4 Rules" + กฎควบสระ

สมุดจดสรุปกฎการผันไว้ 4 ข้อ และเพิ่มกฎควบสระเป็นข้อที่ 5

1. ㅏ/ㅗ + 아요 (가다 → 가아요 → 가요 · 앉다 → 앉아요)
2. ถ้าไม่ใช่ ㅏ/ㅗ + 어요 (먹다 · 씻다 · 마시다 → 마시어요 = 마셔요)
3. ___하다 → ___해요
4. ถ้ามี ㅡ ให้ตัด ㅡ ออกก่อน แล้วไปใช้กฎ 1) หรือ 2) (쓰다 → 써요 · 아프다 → 아파요)
5. กฎควบสระ ㅗ + ㅏ = ㅘ · ㅣ + ㅓ = ㅕ

### ⚠️ จุดสับสน

มีสองเรื่องที่ควรแยกให้ออก คือ -아/어요 กับ -ㅂ니다 และ -세요 ซึ่งอยู่คนละแกน และรูปผันที่ผิดบ่อย

#### -아/어요 vs -(스)ㅂ니다 vs -세요

สามตัวนี้ดูเป็น "กริยาลงท้ายสุภาพ" เหมือนกัน แต่จริง ๆ อยู่คนละแกน **-아/어요 กับ -ㅂ니다 = ระดับความเป็นทางการ** (เลือกอย่างใดอย่างหนึ่งต่อสถานการณ์) ส่วน **-세요 = ยกย่องประธาน** (แกนคนละอัน ซ้อนกับทั้งสองระดับได้)

| | สุภาพทั่วไป (아/어요) | ทางการ (ㅂ니다) |
|:---|:---|:---|
| ธรรมดา | 가요 | 갑니다 |
| ยกย่องประธาน (시) | 가세요 | 가십니다 |

- 저는 학교에 **가요**. ✓ *(ฉันไปโรงเรียน — สุภาพทั่วไป)*
- 저는 학교에 **갑니다**. ✓ *(ฉันไปโรงเรียน — ทางการ)*
- 선생님이 학교에 **가세요**. ✓ *(คุณครูไปโรงเรียน — ยกย่อง + สุภาพทั่วไป)*
- 선생님이 학교에 **가십니다**. ✓ *(คุณครูไปโรงเรียน — ยกย่อง + ทางการ)*
- **กับดัก:** พูด*กับ*อาจารย์ ใช้ 아/어요 ได้ (สุภาพพอแล้ว) แต่พูด*ถึง*อาจารย์ ต้องใส่ 시 ที่กริยาของอาจารย์ → 선생님이 **가세요** ✓ / 선생님이 가요 ✗

> [!TIP] กฎจำง่าย
> - 아/어요 กับ ㅂ니다 = เลือก 1 ใน 2 (ระดับ)
> - 시 = ถามว่า "ประธานควรยกย่องไหม" (แกนอีกอัน) — ดูข้อ 20 และข้อ 21

#### ผันผิดที่เจอบ่อย

ตารางนี้รวมรูปผันที่ผิดบ่อย พร้อมเหตุผลว่าทำไมรูปที่ถูกจึงเป็นแบบนั้น

| ✗ ผิด | ✓ ถูก | เพราะ |
|:---|:---|:---|
| 받어요 · 살어요 | **받아요** · **살아요** | พยางค์สุดท้าย 받/살 มีสระ ㅏ → 아요 (ตัวสะกด ㄷ/ㄹ ไม่นับ — ดูแต่สระ) |
| 춤어요 | 춤을 **춰요** | 춤을 추다 → 추 + 어요 = 춰요 (ㅜ + ㅓ = ㅝ) |
| 주세요 *(เมื่อหมายถึง "ให้")* | **줘요** | 주세요 = "ขอ…หน่อย" (บท 10) · 줘요 = "ให้" |
| 공부하어요 · 공부하요 | **공부해요** | ลงท้าย 하다 → 해요 |
| 마시요 · 마시어요 *(ขั้นกลางที่ยังไม่ควบ)* | **마셔요** | ㅣ + ㅓ = ㅕ |
| 쓰요 · 쓰어요 *(ยังไม่ตัด ㅡ)* | **써요** | ตัด ㅡ ก่อนเติม 어 |
| 숴요 | **쉬어요** | ㅟ ไม่ควบ |
| 반나요 | **만나요** | ขึ้นต้นด้วย ㅁ ไม่ใช่ ㅂ |

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ข้อนี้ออกสอบตั้งแต่ 매일시험 11과 และ 12과 จนถึง 복습시험① ข้อผิดที่เจอซ้ำคือการเลือก 아/어 ผิดกับรากที่มีสระ ㅏ

- **매일시험 11과** A: ผันกริยาจากภาพ 15 ข้อ
  - 만나요 · 와요 · 써요
  - 춤을 춰요 · 입어요 · 쉬어요
  - 일해요 · 자요 · 봐요
  - 공부해요 · 줘요 · 마셔요
  - 씻어요 · 기다려요 · 사요
  - ⚠️ 춤어요 *(✗ — ต้อง 춤을 춰요)*
  - ⚠️ 줘요 → เขียน 주세요 *(ผิดความหมาย)*
- **매일시험 11과** B
  - 숙제를 해요 *(ทำการบ้าน)*
  - 친구를 만나요 ⚠️ *(พบเพื่อน — ✗ 반나요)*
  - 책을 읽어요 *(อ่านหนังสือ)*
- **매일시험 11과 연습지** ผัน 24 คำ (ตารางข้างบน)
- **매일시험 12과**
  - A: 안 + กริยาที่ผันแล้ว 15 ข้อ
  - ⚠️ 안 줘요 → เขียน 안 팔아요 ✗ *(ภาพ "ให้" กับ "ขาย" สลับกัน — ท่องเป็นคู่ 주다 → 줘요 · 팔다 → 팔아요 แล้วค่อยเติม 안 ข้อ 08)*
- **복습시험① (10/6)**
  - 읽기 [7~10]: 친구를 만나요 *(พบเพื่อน)* · 된장찌개를 먹어요 *(กินซุปเต้าเจี้ยว)* ✓
  - 듣기 [10]: 기숙사에서 (　) 아/어/여요 → 청소해요 *(ช่องว่างในสแกน ครูไม่ได้ระบุว่าได้คะแนน)*
- **중간시험 복습문제 13** (ชุดของครู) — ต้นฉบับเป็นรูป -아/어요 ทั้งบทความแล้วให้เปลี่ยนเป็น -ㅂ니다/습니다
- ★ ข้อผิดที่เคยเจอ: ㅏ-stem + 어요 — ท่องว่า "ราก ㅏ/ㅗ = 아요" ทุกบท
  - **살어요 / 살었어요** (sheet 19 ครูไฮไลต์)
  - **받었어요** (workbook 20과)
  - เขียนเองสลับสระ **막어요** ✗ → 먹어요
- ที่ทำได้ดีอยู่แล้ว: การตัด ㅡ (바빴어요 · 컸어요)
- ฝึกเพิ่ม: ส่วนที่ 5 ชุด D

### 🔗 เชื่อมโยง

← ต่อยอดจาก

- ข้อ 02 (이에요/예요 — หางสุภาพของนาม)
- ข้อ 05 (있어요/없어요 = ราก 있다/없다 + 어요)
- ข้อ 07 (กริยาต้องการกรรม 을/를)

→ ใช้ต่อใน

- ข้อ 08 (안 + V-아/어요)
- ข้อ 16 (-지 않아요 = 안)
- ข้อ 18 (คุณศัพท์ผันเหมือนกริยา: 커요 · 바빠요)
- ข้อ 23 (-았/었/였- ใช้รากและกฎควบสระเดียวกัน: 갔어요 · 했어요)
- ข้อ 20–21 (-(으)세요 · -ㅂ니다 — ระดับ/ยกย่อง)
- ข้อ 28 (-(으)ㄹ 거예요)
- ข้อ 32 (-고 있어요 ← 지금 숙제를 해요)

> [!SUMMARY] สรุป
> - ผัน 4 ขั้น: ตัด 다 → ดูสระท้ายราก → เติม 아요/어요 → ควบสระถ้ารากลงท้ายด้วยสระ
> - ㅏ/ㅗ → **아요** · สระอื่น → **어요** · 하다 → **해요**
> - ลงท้าย ㅡ ให้ตัด ㅡ ก่อนแล้วดูสระพยางค์หน้า
> - ถามและชวนใช้รูปเดิม ต่างกันที่น้ำเสียง · ระดับนี้คู่กับ -ㅂ니다 (ทางการ) ส่วน -세요 เป็นแกนยกย่อง
> - ข้อผิดที่เคยเจอ: 살어요 → 살아요 · 받었어요 → 받았어요 · 막어요 → 먹어요
