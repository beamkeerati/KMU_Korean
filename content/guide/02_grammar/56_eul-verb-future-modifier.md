## 56. -(으)ㄹ + นาม (กริยาขยายคำนาม — อนาคต/ยังไม่เกิด) · สรุป -(으)ㄴ / -는 / -(으)ㄹ

> [!INTRO] ข้อนี้คืออะไร
> -(으)ㄹ + นาม คือการเติมท้ายรากของ**กริยา** แล้ววางคำนามตามหลัง เพื่อขยายนามนั้นว่า "…ที่**จะ**ทำ" "…ที่**น่าจะ**ทำ" หรือ "…ที่ยังไม่เกิด" เช่น 먹을 간식 *(ขนมที่จะกิน)* · 갈 곳 *(ที่ที่จะไป)* · 할 일 *(งานที่ต้องทำ)* ตำราบอกว่าใช้กับเหตุการณ์ที่ "ยังไม่ถูกกำหนดแน่" คือ การเดา การสมมติ ความตั้งใจ หรือความเป็นไปได้
>
> ข้อนี้ยังเป็นที่รวมตารางสรุปคำขยายนามทั้งสามรูป คือ -(으)ㄴ -는 และ -(으)ㄹ ซึ่งต้องเลือกตามชนิดของคำและเวลา
>
> สอนในบท 33 (교과서 326–327쪽 · 준비 2) ต่อยอดจาก ข้อ 28 (กฎ ㄹ/을 แบบเดียวกับ -(으)ㄹ 거예요) และ ข้อ 33 (-(으)ㄹ까요?) รวมทั้ง ข้อ 44 (-는 บท 27) กับ ข้อ 47 (-(으)ㄴ บท 29) โดยตำรา 326쪽 เขียนอ้างว่า "Related grammar V는, V(으)ㄴ: Lesson 27 and 29"
>
> ไปใช้ต่อใน ข้อ 46 (-(으)ㄹ 수 있다 = ㄹ + 수) · ข้อ 55 (갈 때) · ข้อ 59 (먹을 것 ≠ 먹는 것) และข้อ 62 กับข้อ 64 รวมถึง 읽기 บท 34–37 (사진 찍는 것 · 살 것이 많이 있었어요)

### 📌 รูปแบบและเงื่อนไข

กฎตัวสะกดเหมือน -(으)ㄹ 거예요 (ข้อ 28) และ -(으)ㄹ까요? (ข้อ 33) ทุกอย่าง คือตัด 다 ออกแล้วดูพยางค์สุดท้ายของราก ตารางแรกบอกว่าต้องต่อ ㄹ หรือ 을 ส่วนตารางที่สองให้ตัวอย่างของรากแต่ละแบบ

| รากศัพท์ลงท้าย | ต่อ |
|:---|:---|
| สระ | **-ㄹ** |
| ตัวสะกด | **-을** |
| ลงท้าย **ㄹ** | **-ㄹ** (ㄹ ของรากอยู่แล้ว ไม่ซ้ำ ไม่ใส่ 을) |
| ยกย่อง -(으)시- | **-(으)실** |
| ㅂ · ㄷ · 르 | ตามกฎของแต่ละประเภท (ก่อน 을/ㄹ) |

#### ตัวอย่างตามชนิดของราก

ทุกแถวคือ ราก + -(으)ㄹ + คำนามที่ถูกขยาย สังเกตว่ารากที่ลงท้าย ㄹ ไม่ต้องใส่ 을 ซ้ำ และรากไม่ปกติต้องเปลี่ยนรูปก่อนแล้วจึงต่อ ㄹ/을 ครูวงกลมที่แถว ㄹ และ ㅂ บนสไลด์ 326쪽 เพื่อเน้นว่าสองแถวนี้ไม่เป็นไปตามกฎ "ตัวสะกดต่อ 을" (ㄹ ไม่ซ้ำ และ ㅂ → 울 เช่น 돕다 → 도울) ตัวอย่างของครูบนสไลด์รวมอยู่ในตารางนี้แล้ว

| รากลงท้าย | 기본형 → ขยายนาม | ไทย |
|:---|:---|:---|
| สระ | 가다 → **갈** 사람 | คนที่จะไป |
| สระ | 보다 → **볼** 영화 | หนังที่จะดู |
| สระ | 주다 → **줄** 선물 | ของขวัญที่จะให้ |
| สระ | 하다 → **할** 일 | งานที่ต้องทำ |
| สระ | 마시다 → **마실** 주스 | น้ำผลไม้ที่จะดื่ม |
| ตัวสะกด | 먹다 → **먹을** 것 | ของที่จะกิน |
| ตัวสะกด | 읽다 → **읽을** 책 | หนังสือที่จะอ่าน |
| ตัวสะกด | 입다 → **입을** 옷 | เสื้อที่จะใส่ |
| ตัวสะกด | 앉다 → **앉을** 자리 | ที่นั่งที่จะนั่ง |
| ตัวสะกด | 먹다 → **먹을** 사람 | คนที่จะกิน |
| ㄹ | 살다 → **살** 곳 | ที่ที่จะอยู่ |
| ㄹ | 만들다 → **만들** 음식 | อาหารที่จะทำ |
| ㄹ | 놀다 → **놀** 곳 | ที่ที่จะเที่ยว |
| ㄹ | 만들다 → **만들** 케이크 | เค้กที่จะทำ |
| ยกย่อง -(으)시- | 돌아오다 → **돌아오실** 표 | ตั๋วขากลับของท่าน |
| ㅂ | 돕다 → **도울** 사람 | คนที่จะช่วย |
| ㄷ | 듣다 → **들을** 음악 | เพลงที่จะฟัง |
| ㄷ | 듣다 → **들을** 사람 | คนที่จะฟัง |
| 르 | 부르다 → **부를** 노래 | เพลงที่จะร้อง |

#### ข้อความของตำราและข้อควรรู้

ตำราหน้า 326 อธิบายเงื่อนไขไว้สั้น ๆ และมีจุดหนึ่งที่ข้อความภาษาอังกฤษในกล่องไม่ตรงกับตัวอย่าง ข้อควรรู้ที่เหลือคือรูปประโยคและตัวสะกดของ 있다/없다

- **ตำรา 326쪽:** ต่อหลังรากกริยาเพื่อขยายนามที่ตามมา — เหตุการณ์ยังไม่แน่นอน แสดงการเดา การสมมติ ความตั้งใจ หรือความเป็นไปได้ · สระ/ㄹ → -ㄹ · ตัวสะกด → -을
- ⚠️ ข้อความอังกฤษในกล่องตำรา 326쪽 เขียนว่า "after a verb ending with 있다/없다" ซึ่งไม่ตรงกับตัวอย่างในกล่องเอง (먹을 · 살 · 할 เป็นกริยาทั่วไป) — ใช้ได้กับกริยาทุกตัว และใช้กับ 있다/없다 ได้ด้วย (있을 · 없을)
- **รูปคือ "ราก + ㄹ/을 + คำนาม"** คำนามที่ตามมาบ่อยอยู่ในตารางถัดไป
- **ประโยคเป็นคำขยายทั้งก้อน:** "[ประโยคย่อย ยกเว้นประธานหลัก] + -(으)ㄹ + N" ในประโยคย่อยยังมีกรรม สถานที่ หรือเวลาของมันเองได้
  - **기차에서** 먹을 음료수 *(เครื่องดื่มที่จะกิน**บนรถไฟ**)*
  - **친구에게** 줄 선물 *(ของขวัญที่จะให้**เพื่อน**)*
- **있다 / 없다** มีตัวสะกด (ㅆ · ㅄ) จึงใช้ 을: 있을 · 없을

#### คำนามที่ตามมาบ่อย

คำนามต่อไปนี้เป็นตัวที่ถูกขยายบ่อยที่สุดเมื่อใช้ -(으)ㄹ

| คำนาม | ความหมาย |
|:---|:---|
| **것** | สิ่งของ |
| **곳** | สถานที่ |
| **사람** | คน |
| **일** | เรื่อง/งาน |
| **때** | ตอน |
| **수** | ความเป็นไปได้ (ข้อ 46) |
| ชื่อสิ่งของ | 선물 *(ของขวัญ)* · 영화 *(หนัง)* · 간식 *(ขนม)* |

#### คำบอกเวลาอนาคตที่บอกให้ใช้ -(으)ㄹ

คำบอกเวลาเป็นตัวตัดสินรูปของคำขยายนาม ครูสรุปคำบอกเวลาอนาคตไว้ในตารางฝั่งซ้ายของสไลด์ 326쪽 ถ้าเห็นคำเหล่านี้ในประโยค ให้คิดถึง -(으)ㄹ ก่อน ลายมือครูบนสไลด์ดูเหมือนเขียน 어제 เทียบกับ 내일 และวงที่ 을 เพื่อชี้ว่าคำบอกเวลาเป็นตัวตัดสินรูป

| คำบอกเวลาอนาคต | ไทย |
|:---|:---|
| 내일 | พรุ่งนี้ |
| 다음 주 | สัปดาห์หน้า |
| 다음 달 | เดือนหน้า |
| 내년 | ปีหน้า |
| 이따가 | อีกสักครู่ |
| 나중에 | ภายหลัง |
| … 후 | หลังจาก … |

#### 🗂️ สรุปตาราง -(으)ㄴ / -는 / -(으)ㄹ ทั้งสามรูปขยายนาม (ข้อ 36 · 44 · 47 · 56)

ใช้ "ชนิดคำ" และ "เวลา" เลือกรูป ตารางนี้เป็นตารางหลักของชุดนี้ โดย ข้อ 36 = คำคุณศัพท์ · ข้อ 44 = กริยาปัจจุบัน · ข้อ 47 = กริยาอดีต · ข้อ 56 = กริยาอนาคต

| ชนิดของรากศัพท์ | อดีต (เสร็จแล้ว) | ปัจจุบัน | อนาคต / ยังไม่เกิด |
|:---|:---|:---|:---|
| **กริยา** | **-(으)ㄴ** (ข้อ 47) | **-는** (ข้อ 44) | **-(으)ㄹ** (ข้อ 56) |
| **คำคุณศัพท์** | ตำรา 23–37 ยังไม่สอน (-았/었던 = เสริม) | **-(으)ㄴ** (ข้อ 36) | ใช้ได้ (바쁠 때) แต่ไม่ใช่จุดของบทนี้ |
| **있다 / 없다** (รวม 맛있다 · 재미있다 · 재미없다) | — | **-는** (있는 · 없는) | **-을** (있을 · 없을) |
| **N이다** (เสริม) | — | N**인** (학생인 사람) | N**일** |

ตัวอย่างประกอบของแต่ละช่องในตารางหลักอยู่ในตารางนี้

| ช่อง | ตัวอย่าง | ไทย |
|:---|:---|:---|
| กริยา อดีต | 어제 **본** 영화 | หนังที่ดูเมื่อวาน |
| กริยา อดีต | 어제 **먹은** 음식 | อาหารที่กินเมื่อวาน |
| กริยา ปัจจุบัน | 지금 **보는** 영화 | หนังที่กำลังดูอยู่ |
| กริยา ปัจจุบัน | 좋아**하는** 계절 | ฤดูที่ชอบ |
| กริยา อนาคต | 내일 **볼** 영화 | หนังที่จะดูพรุ่งนี้ |
| กริยา อนาคต | 내일 **먹을** 간식 | ขนมที่จะกินพรุ่งนี้ |
| คำคุณศัพท์ ปัจจุบัน | **매운** 음식 | อาหารเผ็ด |
| คำคุณศัพท์ ปัจจุบัน | **좋은** 사람 | คนดี |
| คำคุณศัพท์ ปัจจุบัน | **바쁜** 날 | วันที่ยุ่ง |
| 있다/없다 ปัจจุบัน | **맛있는** 식당 | ร้านอาหารที่อร่อย |
| 있다/없다 ปัจจุบัน | **재미있는** 이야기 | เรื่องที่สนุก |
| N이다 ปัจจุบัน | 학생**인** 사람 | คนที่เป็นนักเรียน |

ตารางถัดไปเปรียบรูปตามตัวสะกดของราก โดยใช้ตัวอย่างชุดเดียวกันทุกช่อง

| รากลงท้าย | กริยา อดีต -(으)ㄴ | กริยา ปัจจุบัน -는 | คำคุณศัพท์ -(으)ㄴ | กริยา อนาคต -(으)ㄹ |
|:---|:---|:---|:---|:---|
| สระ (가다 · 바쁘다) | ㄴ → **간** | **가는** | ㄴ → **바쁜** | ㄹ → **갈** |
| ตัวสะกด (먹다 · 좋다) | 은 → **먹은** | **먹는** | 은 → **좋은** | 을 → **먹을** |
| **ㄹ** (만들다 · 길다) | ㄹ **หลุด** + ㄴ → **만든** | ㄹ **หลุด** + 는 → **만드는** | ㄹ **หลุด** + ㄴ → **긴** | ㄹ **คงอยู่** → **만들** |
| ㅂ ไม่ปกติ (돕다 · 맵다) | **도운** | **돕는** (ㅂ ไม่เปลี่ยน เพราะ 는 ขึ้นด้วยพยัญชนะ) | **매운** | **도울** |
| ㄷ ไม่ปกติ (듣다) | **들은** | **듣는** | — | **들을** |
| 르 (부르다) | **부른** | **부르는** | **다른** (다르다) | **부를** |
| 있다 / 없다 | ✗ (ไม่ใช้ 있은) | **있는 · 없는 · 맛있는** | (นับเป็น -는 แล้ว) | **있을 · 없을** |

#### สิ่งที่ต้องจำจากตารางสรุป

ตารางข้างบนย่อลงเหลือสามเรื่องที่ต้องจำ และอีกสองข้อสำหรับคำคุณศัพท์ที่ลงท้าย 있다/없다 กับที่ไม่ได้ลงท้ายอย่างนั้น

- **จดจำ 3 เรื่อง:**
  - ① กริยาแยก 3 เวลา: ㄴ/은 · 는 · ㄹ/을
  - ② คำคุณศัพท์มีรูปเดียว -(으)ㄴ (ปัจจุบัน)
  - ③ **-는 และ -(으)ㄴ ทำ ㄹ หลุด แต่ -(으)ㄹ ทำ ㄹ คงอยู่** (만드는 · 만든 · 만들)
- **คำคุณศัพท์ที่ลงท้าย 있다/없다 ใช้ -는:** ✓ 맛있는 · 재미있는 · 멋있는 · 재미없는 / ✗ 맛있은 · ✗ 재미있은
  - ตำรา 35 읽기 "재미있는 이야기" *(เรื่องที่สนุก)*
  - ตำรา 37 읽기 "맛있는 한국 식당" *(ร้านอาหารเกาหลีที่อร่อย)*
- **คำคุณศัพท์ไม่ลงท้าย 있다/없다 ใช้ -(으)ㄴ:** 좋은 · 괜찮은 · 많은 · 같은 (✗ 좋는 · 괜찮는 · 많는)
  - 별이 **많은** 하늘 *(ท้องฟ้าที่มีดาวมาก — 35과 활동)*

#### สูตรและวิธีทำ: -(으)ㄹ + นาม (แบบกระดานครู)

-(으)ㄹ ต่อกับรากของกริยาแล้ววางนามไว้ข้างหลัง (เช่น 먹을 것) ต้องตัดสินใจตามลำดับสองเรื่อง คือรากเป็น ㅂ หรือ ㄷ ไม่ปกติหรือไม่ แล้วจึงดูตัวสะกดเพื่อเลือกว่าจะต่อ ㄹ ต่อ 을 หรือไม่ต่ออะไรเลย

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | ราก ㅂ หรือ ㄷ ไม่ปกติ (돕 และ 듣) | เปลี่ยนก่อน ㅂ → **우** (도우) และ ㄷ → **ㄹ** (들) แล้วทำกฎ 2–4 ต่อ | เหมือนข้อ 37 และข้อ 51 |
| **กฎ 2** | รากที่ **ไม่มีตัวสะกด** (รวม 우 ที่ได้จาก ㅂ) | ต่อ **ㄹ** เป็นตัวสะกดของพยางค์สุดท้าย (가 → 갈, 도우 → 도울) | ㄹ ไม่ใช่พยางค์ใหม่ แต่ไปอยู่ใต้พยางค์เดิม |
| **กฎ 3** | รากที่ **มีตัวสะกด** (รวม 있 และ 없 และ 들 จาก ㄷ) | ต่อ **을** | 을 รองรับตัวสะกด |
| **กฎ 4** | ราก **ลงท้ายด้วย ㄹ เดิม** | **ไม่ต่ออะไร** ใช้ราก + คำนามได้เลย | ㄹ อยู่ครบแล้ว ถ้าใส่ซ้ำจะเป็น ✗ 살을 |

ลำดับทำคือ ① เปลี่ยนรากไม่ปกติ (ถ้ามี) ② ดูตัวสะกดของรากที่ได้ ③ ต่อ ㄹ หรือ 을 หรือไม่ต่อ แล้ววางคำนามตามหลัง ตารางนี้แสดงทุกขั้นกับคำที่ตำราใช้ ช่อง ③ ตัวหนาคือรูปขยายนาม

| ราก + (으)ㄹ | ① เปลี่ยนราก | ② ตัวสะกด | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 가 + (으)ㄹ | ไม่เปลี่ยน | ไม่มี → ต่อ ㄹ | **갈** 사람 | ✗ 가을 사람 (가을 = ฤดูใบไม้ร่วง) |
| 하 + (으)ㄹ | ไม่เปลี่ยน | ไม่มี → ต่อ ㄹ | **할** 일 | งานที่ต้องทำ |
| 보 + (으)ㄹ | ไม่เปลี่ยน | ไม่มี → ต่อ ㄹ | **볼** 영화 | หนังที่จะดู |
| 먹 + (으)ㄹ | ไม่เปลี่ยน | มี (ㄱ) → ต่อ 을 | **먹을** 것 | ✗ 먹ㄹ 것 |
| 읽 + (으)ㄹ | ไม่เปลี่ยน | มี (ㄺ) → ต่อ 을 | **읽을** 책 | ✗ 읽ㄹ 책 |
| 입 + (으)ㄹ | ไม่เปลี่ยน (ㅂ ปกติ) | มี (ㅂ) → ต่อ 을 | **입을** 옷 | ㅂ ปกติ จึงไม่เปลี่ยนเป็น 우 (✗ 이울 옷) |
| 있 + (으)ㄹ | ไม่เปลี่ยน | มี (ㅆ) → ต่อ 을 | **있을** 때 | ✗ 있ㄹ 때 |
| 없 + (으)ㄹ | ไม่เปลี่ยน | มี (ㅄ) → ต่อ 을 | **없을** 때 | ไม่ใช่ 없는 (없는 = ปัจจุบัน ข้อ 44) |
| 살 + (으)ㄹ | ไม่เปลี่ยน | ㄹ เดิม → ไม่ต่อ | **살** 곳 | ✗ 살을 곳 |
| 만들 + (으)ㄹ | ไม่เปลี่ยน | ㄹ เดิม → ไม่ต่อ | **만들** 음식 | ✗ 만들을 음식 (เหมือน ✗ 만들을까요) |
| 놀 + (으)ㄹ | ไม่เปลี่ยน | ㄹ เดิม → ไม่ต่อ | **놀** 곳 | ✗ 놀을 곳 |
| 돕 + (으)ㄹ | ㅂ → 우 (도우) | ไม่มี → ต่อ ㄹ | **도울** 사람 | ✗ 돕을 사람 |
| 듣 + (으)ㄹ | ㄷ → ㄹ (들) | มี → ต่อ 을 | **들을** 음악 | ✗ 듣을 음악 |
| 부르 + (으)ㄹ | ไม่เปลี่ยน (르 เปลี่ยนเฉพาะก่อน 아/어) | ไม่มี → ต่อ ㄹ | **부를** 노래 | ✗ 불를 노래 |

> [!TIP] วิธีจำสั้น ๆ
> ถามตัวสะกดของราก ไม่มีให้ต่อ ㄹ มีให้ต่อ 을 ถ้าเป็น ㄹ อยู่แล้วไม่ต้องต่ออะไร ส่วน ㅂ กับ ㄷ ให้เปลี่ยนก่อนแล้วจึงต่อ (도울 และ 들을)

### ⚠️ จุดสับสน

ข้อผิดของเรื่องนี้มี 3 กลุ่มใหญ่ คือเลือกรูปผิดเวลา สับสนกับ 것 ที่คล้ายกัน และใส่ ㄹ/을 ผิดตามตัวสะกด

#### -(으)ㄴ vs -는 vs -(으)ㄹ — เลือกด้วยเวลา

ใช้กริยาตัวเดียวกันเปลี่ยนเวลาเพื่อเห็นความต่างชัดที่สุด

| กริยา | อดีต | ปัจจุบัน | อนาคต |
|:---|:---|:---|:---|
| 보다 | 어제 **본** 영화 *(หนังที่ดูเมื่อวาน)* | 지금 **보는** 영화 *(หนังที่กำลังดูอยู่)* | 내일 **볼** 영화 *(หนังที่จะดูพรุ่งนี้)* |
| 먹다 | 어제 **먹은** 음식 | 자주 **먹는** 음식 *(อาหารที่กินบ่อย)* | 내일 **먹을** 음식 |
| 만들다 | 어제 **만든** 음식 | 지금 **만드는** 음식 | 내일 **만들** 음식 |
| 살다 | 서울에 **산** 사람 | 서울에 **사는** 사람 | 서울에 **살** 사람 |

#### 먹을 것 vs 먹는 것 vs 먹을 거예요

สามรูปนี้หน้าตาคล้ายกันและออกเสียงเกือบเหมือนกัน แต่ความหมายต่างกัน

| รูป | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| 먹**을 것** (ข้อ 56) | **สิ่งที่จะกิน** (ของกิน — 것 = สิ่งของ) | 집에 먹을 것이 없어요 *(ที่บ้านไม่มีของกิน)* |
| 먹**는 것** (ข้อ 59) | **การกิน** (ทำกริยาให้เป็นคำนาม) | 먹는 것을 좋아해요 *(ชอบการกิน)* |
| 먹**을 거예요** (ข้อ 28) | **จะกิน** (แผน) | 내일 먹을 거예요 *(พรุ่งนี้จะกิน)* |

- รูปเสียงเดียวกัน [먹을 꺼] แต่หน้าที่ต่างกัน: ㄹ 거예요 = 거 มาจาก 것 + 이에요 (ข้อ 28) ดังนั้น **먹을 것이에요** *(เป็นของกิน)* กับ **먹을 거예요** *(จะกิน)* ต่างกันที่ความหมาย — ดูบริบทและคำที่ตามมา

#### กับดัก

ตารางนี้รวมรูปที่ถูกและรูปที่ผิดที่พบบ่อย พร้อมเหตุผลสั้น ๆ ในคอลัมน์สุดท้าย

| ประเด็น | ✓ ถูก | ✗ ผิด | หมายเหตุ |
|:---|:---|:---|:---|
| ㄹ-ราก + -(으)ㄹ | 만들 사람 · 살 곳 | 만들을 사람 · 살을 곳 | ㄹ ของรากอยู่แล้ว ไม่ต้องเติมซ้ำ |
| ㄹ-ราก + -는/-ㄴ | 만드는 · 만든 | 만들는 · 만들은 | -는/-ㄴ ทำ ㄹ หลุด |
| ลืม 을 | 먹을 것 · 읽을 책 | 먹 것 · 읽 책 | กับดักตระกูลเดียวกับ 먹까요 · 읽세요 · 씻러 |
| ㄷ ไม่ปกติ ต้องมี 을 | 들을 사람 · 들을 거예요 | 들 사람 · 들 거예요 | ㄷ → ㄹ แล้วยังต้องต่อ 을 (ข้อสอบมักพลาด) |
| สระ + ㄹ | 갈 사람 · 볼 영화 | 가을 사람 · 보을 영화 | สระต้องต่อ ㄹ ไม่ใช่ 을 |
| เว้นวรรค | 먹을 것 · 갈 곳 · 할 일 | 먹을것 · 갈곳 · 할일 | ตัวขยาย + นามแยกคำกัน (ข้อ 13) เหมือน ✗ 갈거예요 ที่เคยเขียนติดกัน |
| นามที่ถูกขยายรับคำช่วย | 먹을 것**이** 없어요 · 줄 선물**을** 샀어요 | 먹을이 · 줄을 | คำช่วยต่อท้ายนาม ไม่ใช่ท้าย -(으)ㄹ |
| กรรมในวลีขยาย | 빵을 먹을 사람 | 빵이 먹을 사람 | กรรมของกริยาในวลีขยายใช้ 을/를 ไม่ใช่ 이/가 |
| ใช้ผิดเวลา | 어제 본 영화 | 어제 볼 영화 *(ดูเมื่อวาน)* | ตำราบอกว่า -(으)ㄹ = "ยังไม่แน่นอน" จึงไม่ใช้ขยายสิ่งที่เกิดแล้ว |

> [!TIP] กฎสั้น ๆ
> - **ㄴ/은 = เสร็จแล้ว · 는 = กำลัง/ประจำ · ㄹ/을 = จะ/ยังไม่เกิด**
> - **ㄹ-ราก: 는/ㄴ ทำ ㄹ หลุด (만드는 · 만든) · ㄹ คงอยู่ (만들)**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ข้อนี้ยังไม่เคยออกสอบจริง จึงสรุปกำหนดสอบ ข้อผิดเดิมของผู้เรียนที่เกี่ยวข้อง และรูปแบบข้อสอบที่คาดว่าจะเจอ

- ยังไม่มีข้อสอบจริงเกี่ยวกับ -(으)ㄹ + นาม — 33과 อยู่ใน **복습시험④ (11/18)** และ **기말**
- จากรูปแบบ 복습시험①② ข้อ 읽기 ยกบทอ่านของตำรามาทั้งบทแล้วปรับเป็นบทสนทนา 가/나 บทอ่าน 33–37 เต็มไปด้วยคำขยายแบบนี้ จึงต้อง**อ่านคำขยายให้ออกว่าเป็นเวลาไหน**
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ (CLAUDE.md §6b):**
  - ลืม 으/을 หลังตัวสะกด: 받십니다 · 읽세요 · 씻러 · 먹까요
  - ㄹ-ราก: 만들으세요 ✗ → 만드세요
  - เขียนติดกัน: 갈거예요 · 청소할거예요 ✗ → เว้นวรรค
  - ตอบไม่ตรงคำถาม (언제 → ต้องเป็นเวลา)
  - ใช้ 가 กับกริยาที่ต้องการ 을/를 (시계가 받았어요)
  - ㅈ/ㅊ: 몇 → 몆
- **คาดการณ์รูปแบบข้อสอบ** (เดาจากรูปแบบ 복습시험①②) มี 4 แบบ:
  - **ผันตาราง 3 รูป:** 먹다 · 보다 · 만들다 · 살다 · 좋다 · 맵다 → ___(อดีต) / ___(ปัจจุบัน) / ___(อนาคต) + นาม
  - **เลือกรูปตามคำบอกเวลา:** 어제 (본 · 보는 · 볼) 영화 · 내일 (먹은 · 먹는 · 먹을) 간식
  - **ต่อสองประโยคเป็นหนึ่ง:** 내일 먹다 / 간식이에요 → 내일 먹을 간식이에요 · 친구에게 주다 / 선물을 샀어요 → 친구에게 줄 선물을 샀어요
  - **ตอบคำถามด้วยไวยากรณ์ที่กำหนด:** 뭘 준비할 거예요? → 내일 먹을 간식을 준비할 거예요 · 부산에 갈 때 무엇을 준비할 거예요? → 기차에서 먹을 음료수와 간식을 준비할 거예요

### 🔗 เชื่อมโยง

ข้อนี้ใช้กฎ ㄹ/을 ร่วมกับข้อที่เรียนมาก่อน และเป็นฐานของหลายข้อในบท 33–37

← ต่อยอดจาก

- ข้อ 28 (-(으)ㄹ 거예요 กฎ ㄹ/을 เดียวกัน) · ข้อ 33 (-(으)ㄹ까요?)
- ข้อ 44 (-는 บท 27) · ข้อ 47 (-(으)ㄴ อดีต บท 29)
- ข้อ 36 (-(으)ㄴ คำคุณศัพท์ บท 23) · ข้อ 07 (을/를 ของนามที่ถูกขยาย)

→ ใช้ต่อใน

- ข้อ 46 (-(으)ㄹ 수 있다 = -ㄹ + 수) · ข้อ 55 (-(으)ㄹ 때 · -(으)면)
- ข้อ 59 (-는 것 ↔ -을 것) · ข้อ 64
- 읽기 บท 35–37 (살 것이 많이 · 여행할 곳 · 부탁할 것)

> [!SUMMARY] สรุป
> - -(으)ㄹ + นาม ขยายนามด้วยสิ่งที่ยังไม่เกิดหรือยังไม่แน่นอน: สระ/ㄹ → **-ㄹ** (갈 곳 · 만들 음식) · ตัวสะกด → **-을** (먹을 것)
> - เลือกรูปตามเวลา: **ㄴ/은 = เสร็จแล้ว · 는 = กำลัง/ประจำ · ㄹ/을 = จะ** และคำคุณศัพท์มีรูปเดียวคือ -(으)ㄴ
> - ㄹ-ราก: -는/-ㄴ ทำ ㄹ หลุด (만드는 · 만든) แต่ -(으)ㄹ ให้ ㄹ คงอยู่ (만들)
> - 먹을 것 *(ของกิน)* ≠ 먹는 것 *(การกิน)* ≠ 먹을 거예요 *(จะกิน)*
> - ที่ต้องระวัง: ลืม 을 หลังตัวสะกด · เขียนติดกัน (먹을것) · ใช้ -(으)ㄹ กับสิ่งที่เกิดแล้ว (✗ 어제 볼 영화)
