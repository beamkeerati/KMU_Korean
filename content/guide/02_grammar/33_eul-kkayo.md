## 33. -(으)ㄹ까요? (...กันไหม? / ...ดีไหม?)

> [!INTRO] ข้อนี้คืออะไร
> -(으)ㄹ까요? ใช้ชวนผู้ฟัง**ทำสิ่งหนึ่งด้วยกัน** หรือถามความเห็นผู้ฟังว่าเราควรทำอย่างไรดี ประธานคือ "เรา" และมักมี 같이 / 함께
>
> สอนในบท 22 (교과서 202–203쪽) ต่อยอดจาก ข้อ 28 (กฎ ㄹ/을 เดียวกัน) · ข้อ 26 (-(으)러) · ข้อ 06 (ตอบด้วย -아/어요)
>
> ไปใช้ต่อใน ข้อ 34 (무슨 영화를 볼까요?) · ข้อ 35 และบท 28 / 33 (ใช้กฎ ㄹ/을 เดียวกัน — ยังไม่เรียน)

### 📌 รูปแบบและเงื่อนไข

-(으)ㄹ까요? ใช้กฎเดียวกับ -(으)ㄹ 거예요 คือดูพยางค์สุดท้ายของรากว่ามีตัวสะกดไหม รากที่ไม่มีตัวสะกดหรือลงท้ายด้วย ㄹ เติม -ㄹ까요? ส่วนรากที่มีตัวสะกดเติม -을까요?

| รากศัพท์ลงท้าย | ต่อ |
|:---|:---|
| สระ หรือ **ㄹ** | **-ㄹ까요?** (ราก ㄹ มี ㄹ อยู่แล้ว — ไม่ซ้ำ ไม่ใส่ 을) |
| พยัญชนะ (มีตัวสะกด) | **-을까요?** |

#### ตัวอย่างการผัน

ตารางนี้เรียงตามกลุ่มของรากข้างบน หนึ่งคำต่อหนึ่งแถว

| 기본형 | ผัน | ไทย |
|:---|:---|:---|
| 보다 | **볼까요?** | {v:ดู}กันไหม |
| 마시다 | **마실까요?** | {v:ดื่ม}กันไหม |
| 만들다 | **만들까요?** | {v:ทำ}กันไหม |
| 먹다 | **먹을까요?** | {v:กิน}กันไหม |
| 찍다 | **찍을까요?** | {v:ถ่ายรูป}กันไหม |

#### ข้อสังเกต

ตำรา 202쪽 อธิบายว่า -(으)ㄹ까요? เป็นการเสนอหรือถามความเห็น และใช้ร่วมกับ -(으)러 ได้

- **ตำรา 202쪽:** ผู้พูด "เสนอ" ให้ผู้ฟังทำบางอย่างด้วยกัน หรือ "ถามความเห็น" ว่าทำร่วมกันดีไหม
- มักมี **같이 / 함께**
- ผสมกับ -(으)러 (ข้อ 26): 같이 밥 먹으러 갈까요? *(ไปกินข้าวด้วยกันไหม)*

#### ใช้คู่กับคำถาม — ความหมายเป็น "…ดี"

เมื่อใช้คู่กับคำถาม ความหมายจะเป็น "…ดี" คือถามว่าควรทำอะไร ที่ไหน หรือเมื่อไรดี

|:---|:---|

| 우리 몇 시에 만날까요? | {n:เรา}{v:นัด}กัน{q:กี่โมง}{e:ดี} |

### 📖 ตัวอย่างและการใช้

ตัวอย่างแบ่งเป็นสี่ส่วน คือ การตอบรับและตอบปฏิเสธ ประโยคตัวอย่างจากบทสนทนา กิจกรรมวางแผนเที่ยวท้ายบท 22 และเหตุผลที่ใช้ปฏิเสธ

#### ตอบรับและตอบปฏิเสธ

คำถามชวนมักได้คำตอบสองแบบ คือรับคำชวน หรือปฏิเสธพร้อมบอกเหตุผล

| | สูตร | ตัวอย่าง |
|:---|:---|:---|
| ตอบรับ | 네, 좋아요. / 네, **-아/어요** | 가: 오후에 같이 영화 보러 갈까요? — 나: 네, 좋아요. 같이 가요. *({n:บ่ายนี้}{v:ไปดู}{n:หนัง}{a:ด้วยกัน}ไหม — {v:ได้} {v:ไป}{a:ด้วยกัน}เลย)* |
| ตอบปฏิเสธ | 미안해요 + เหตุผล + 다음에 같이 해요 | 가: 같이 식당에 갈까요? — 나: 미안해요, 벌써 밥을 먹었어요. 다음에 같이 가요. *({v:ไป}{n:ร้านอาหาร}{a:ด้วยกัน}ไหม — {v:ขอโทษ} {v:กิน}{n:ข้าว}ไป{e:แล้ว} ไว้{n:คราวหน้า}{v:ไป}{a:ด้วยกัน})* |

#### ประโยคตัวอย่างจากบทสนทนา

ประโยคต่อไปนี้ชวนหรือถามความเห็นด้วย -(으)ㄹ까요? บางข้อมีคำตอบต่อท้าย

- 같이 밥 먹으러 **갈까요**? *(ไปกินข้าวด้วยกันไหม)*
- 영화를 **볼까요**? *(ดูหนังกันไหม)*
- 우리 어디에서 사진을 **찍을까요**? — 저기 나무 옆에서 찍어요. *({n:เรา}{e:จะ}{v:ถ่ายรูป}กัน{q:ที่ไหน}{e:ดี} — {v:ถ่าย}{p:ตรง}{n:ข้างต้นไม้}{a:นั่น}เลย)*
- 언제 파티를 **할까요**? *({v:จัด}{n:ปาร์ตี้}{q:เมื่อไหร่}{e:ดี})*
- 우리 몇 시에 **만날까요**? — 1시에 만나요. *({n:เรา}{v:นัด}กัน{q:กี่โมง}{e:ดี} — {v:นัด}{m:บ่ายโมง})*
- 가: 주말에 같이 영화를 볼까요? — 나: 미안해요. 약속이 있어요. — 가: 그럼 다음에 같이 봐요. *({n:สุดสัปดาห์}{v:ดู}{n:หนัง}{a:ด้วยกัน}ไหม — ขอโทษ มีนัด — {a:งั้น}{n:คราวหน้า}{v:ดู}{a:ด้วยกัน}นะ)*
- 그럼 같이 경복궁에 **갈까요**? — 미안해요. 저는 지난 주말에 갔어요. *({a:งั้น}{v:ไป}{n:พระราชวังคยองบก}{a:ด้วยกัน}ไหม — {v:ขอโทษ} {n:ฉัน}{v:ไป}{p:เมื่อ}{n:สุดสัปดาห์ที่แล้ว})*
- 그럼 토요일에는 어디에 **갈까요**? *({a:งั้น}{n:วันเสาร์}{v:ไป}{q:ไหน}{e:ดี})*
- 무슨 음식을 **먹을까요**? *({v:กิน}{n:อาหาร}{q:อะไร}{e:ดี})*

### ⚠️ จุดสับสน

-(으)ㄹ까요? ชวนให้ตอบรับหรือปฏิเสธ ต่างจากการถามแผนหรือการบอกเล่าธรรมดา ตอนนี้จะเทียบสามรูป แล้วดูข้อผิดที่เจอบ่อย

#### -(으)ㄹ까요? vs -아/어요 vs -(으)ㄹ 거예요?

สามรูปนี้ใช้ในสถานการณ์ต่างกัน -아/어요 บอกเล่าหรือชวนสั้น ๆ -(으)ㄹ까요? เสนอและถามความเห็น ส่วน -(으)ㄹ 거예요 บอกหรือถามแผน

| รูป | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| -아/어요 (ข้อ 06) | บอกเล่า / ถามธรรมดา / ชวนสั้น | 같이 가요 *(ไปด้วยกันเถอะ)* |
| **-(으)ㄹ까요?** | **เสนอ** ถามความเห็นร่วมกัน | 같이 갈까요? *(ไปด้วยกันไหม)* |
| -(으)ㄹ 거예요 (ข้อ 28) | บอกแผน | 갈 거예요 *(จะไป)* |
| -(으)ㄹ 거예요? | ถามแผนของผู้ฟัง | 갈 거예요? *(คุณจะไปไหม)* |

#### ตอบรับ ตอบปฏิเสธ และการผันที่ผิด

ตารางนี้เทียบคู่ ✓ / ✗ ที่เจอบ่อย ส่วนรายการใต้ตารางบอกวิธีตอบปฏิเสธและบทบาทของประธาน

| ✓ ถูก | ✗ ผิด | เหตุผล |
|:---|:---|:---|
| 네, 같이 가요. / 네, 좋아요. | 네, 갈까요 | ห้ามตอบด้วยรูปคำถามซ้ำ |
| 만들까요? | 만들을까요? | ราก ㄹ ไม่ใส่ 을 |
| 먹을까요 | 먹까요 | ลืม 을 หลังตัวสะกด |
| 찍을까요 | 찍까요 | ลืม 을 หลังตัวสะกด |

- ตอบปฏิเสธ: ✓ 미안해요. 시간이 없어요. *(ขอโทษ ไม่มีเวลา — บอกเหตุผล)* ไม่ตอบ "아니요" ตรง ๆ (ตำรา 202쪽)
- ประธานคือ "เรา" (ผู้พูด + ผู้ฟัง) ไม่ต้องพูดประธาน และมักมี **같이 / 함께**

#### เสริม: ประธานบุคคลที่ 3 (ตำรา 22과 ยังไม่สอน)

รูปเดียวกันใช้ "สงสัย / เดา" กับบุคคลที่ 3 ได้ในภาษาจริง

- 비가 **올까요**? *(ฝนจะตกไหมนะ)*
- 선생님이 **오실까요**? *(อาจารย์จะมาไหมนะ)*
- ในบทนี้จำแค่ความหมาย "เสนอ/ชวนกัน" ที่ประธานคือ 우리

> [!TIP] กฎสั้น ๆ
> **ㄹ까요? = "…กันไหม" (ชวน/ถามความเห็นร่วม) · ㄹ 거예요? = ถามแผนของอีกฝ่าย**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ยังไม่มีข้อสอบจริงที่ครูตรวจแล้วเกี่ยวกับ -(으)ㄹ까요? แต่มีโจทย์ในชีตฟังและเวิร์กบุ๊กของบท 22 รวมทั้งข้อผิดกลุ่มเดียวกันที่เคยเจอ

- 22과 อยู่ในขอบเขต 중간시험 (10/22–23) และ 복습시험③ (11/6, 22–29과)
- **ชีตฟัง 본문 듣기 22과 (ช่อง B):** เติม **먹으러 갈까요** (같이 밥 먹으러 갈까요?) จากบทสนทนา 22-1
- **워크북 22과 D–F:**
  - D ผันตาราง 보다 → 볼까요 · 마시다 → 마실까요 · 찍다 → 찍을까요 · 만들다 → 만들까요 (ㄹ-ราก)
  - E เลือกประโยคชวนตามสถานการณ์ (배가 고파요 → 같이 식당에 갈까요?) *(หิว → ไปร้านอาหารด้วยกันไหม)*
  - F ถามด้วย 어디/언제/몇 시/어디에서
  - เฉลยในไฟล์เป็นการแก้เอง ไม่ใช่เฉลยครู
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ:** ลืม 으/을 หลังตัวสะกด (ข้อนี้คือ ✗ 먹까요 → 먹을까요)
  - 받십니다 ✗ → 받으십니다
  - 읽세요 ✗ → 읽으세요
  - 씻러 ✗ → 씻으러

> [!SUMMARY] สรุป
> - -(으)ㄹ까요? = "…กันไหม / …ดี" ชวนหรือถามความเห็นร่วม ประธานคือ 우리 และมักมี 같이 / 함께
> - รากไม่มีตัวสะกดหรือลงท้าย ㄹ → **-ㄹ까요?** (볼까요 · 만들까요) รากมีตัวสะกด → **-을까요?** (먹을까요)
> - ตอบรับด้วย 네, 좋아요 / 네, 같이 가요 ตอบปฏิเสธด้วย 미안해요 + เหตุผล ห้ามตอบ 네, 갈까요
> - ข้อผิดที่เคยเจอคือลืม 으/을 หลังตัวสะกด (✗ 먹까요 · ✗ 찍까요 · ✗ 읽세요)
