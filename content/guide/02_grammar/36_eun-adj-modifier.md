## 36. -(으)ㄴ (คำคุณศัพท์ขยายคำนาม: 매운 음식 · 좋은 사람)
เติมท้ายรากของ **คำคุณศัพท์** เพื่อให้ไปขยาย **คำนามที่ตามหลัง** — "อาหาร**ที่เผ็ด**" = 매**운** 음식 · ลำดับกลับกับภาษาไทย: คำขยายอยู่ **หน้า** คำนาม
สอนในบท 23 (교과서 236–237쪽 준비 2) · ต่อยอดจาก ข้อ 18 (คำคุณศัพท์ + 이/가) · ข้อ 35 (ตาราง 받침 / ราก ㄹ) · ข้อ 37 (ㅂ 불규칙 — บทเดียวกัน)
ใช้ต่อใน ข้อ 44 (-는 สำหรับกริยา) · ข้อ 47 (-(으)ㄴ กริยาอดีต — หน้าตาเหมือนกัน) · ข้อ 56 (-(으)ㄹ + สรุปตาราง 3 รูป) · ข้อ 59 (-는 것)

### 📌 รูปแบบและเงื่อนไข
ตัด 다 ทิ้ง แล้วดู**พยางค์สุดท้ายของราก** — ตำรา 236쪽: "ต่อท้ายรากคำคุณศัพท์เพื่อขยายนามที่ตามมา บอกลักษณะหรือสภาพของนามนั้น"

| รากลงท้ายด้วย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| สระ (รวม 하다 · ㅡ) | **-ㄴ** | 예쁘다 → **예쁜** · 크다 → **큰** · 시원하다 → **시원한** · 깨끗하다 → **깨끗한** · 친절하다 → **친절한** *(สวย · ใหญ่ · เย็นสบาย · สะอาด · ใจดี)* |
| **ㄹ** (ㄹ หลุดหน้า ㄴ) | **-ㄴ** (ไม่มี ㄹ) | 길다 → **긴** · 달다 → **단** · 멀다 → **먼** *(ยาว · หวาน · ไกล)* |
| พยัญชนะ (มีตัวสะกด) | **-은** | 작다 → **작은** · 좋다 → **좋은** · 넓다 → **넓은** · 많다 → **많은** *(เล็ก · ดี · กว้าง · เยอะ)* |
| ลงท้าย **있다 / 없다** | **-는** (ไม่ใช่ -은) | 맛있다 → **맛있는** · 재미있다 → **재미있는** · 재미없다 → **재미없는** · 맛없다 → **맛없는** *(อร่อย · สนุก · ไม่สนุก · ไม่อร่อย)* |
| **ㅂ 불규칙** (ข้อ 37) | ㅂ → 우 + ㄴ | 맵다 → **매운** · 덥다 → **더운** · 춥다 → **추운** · 어렵다 → **어려운** · 아름답다 → **아름다운** · 가볍다 → **가벼운** · 뜨겁다 → **뜨거운** *(เผ็ด · ร้อน · หนาว · ยาก · สวยงาม · เบา · ร้อนจัด)* |
| 어떻다 *(เสริม)* | ㅎ หาย | 어떤 *(แบบไหน)* — 어떤 사람을 좋아해요? *(ชอบคนแบบไหน)* |

- **ตำรา 236쪽:** ลงท้ายสระหรือ ㄹ → -ㄴ · ลงท้ายพยัญชนะ → -은 · คำคุณศัพท์ที่ลงท้ายด้วย 있다/없다 (재미있다 · 재미없다) → **-는**
- **ㅡ ไม่ตัด** ในรูปนี้: ㅡ ตกเฉพาะตอนต่อ 아/어 (예뻐요) แต่ -ㄴ ไม่ใช่สระ → 예쁘다 → **예쁜** (✗ 예뻔)
- **-지 않다 + นาม** (ตำรา ชื่อบท 23): 맵지 **않은** 음식이에요 *(เป็นอาหารที่ไม่เผ็ด)* — 않다 มีตัวสะกด จึงเป็น -은 (ถ้าหน้ามันเป็นกริยาจะเป็น -지 않는 — เสริม ดูข้อ 44)
- **ลำดับ:** `[คำคุณศัพท์-(으)ㄴ] + [นาม] + 조사` — 매운 음식**을** 좋아해요 *(ชอบอาหารเผ็ด)* · อนุประโยคเล็ก ๆ ใส่ประธานของตัวเองได้: 창문**이** 큰 교실 *(ห้องที่หน้าต่างบานใหญ่)*
- **ออกเสียง (ตำรา 236–237쪽):** 작습니다 [작씀니다] · 넓습니다 [널씀니다] · 뜨겁습니다 [뜨겁씀니다] · 착하다 [차카다] · 똑똑하다 [똑또카다]

### 📖 ตัวอย่างและการใช้
#### จากตำรา 23과
1. 가: 투이 씨는 어떤 사람을 좋아해요? 나: **친절한** 사람을 좋아해요. *(คุณทุยชอบคนแบบไหน — ชอบคนใจดี)* — 준비 2
2. 이 가게에는 **예쁜** 옷이 많아요. *(ร้านนี้มีเสื้อผ้าสวย ๆ เยอะ)* — 236쪽 กล่อง
3. 저는 **매운** 음식을 좋아해요. *(ฉันชอบอาหารเผ็ด)*
4. **작은** 책상이 하나 필요해요. *(ต้องการโต๊ะเล็ก ๆ หนึ่งตัว)*
5. **재미있는** 영화를 보고 싶어요. *(อยากดูหนังสนุก ๆ — ข้อ 38)*
6. 연습 1 (236쪽): **시원한** 주스 · **예쁜** 옷 · **깨끗한** 교실 · **작은** 방 · **넓은** 운동장 · **뜨거운** 커피 · **재미있는** 영화 *(น้ำผลไม้เย็น ๆ · เสื้อสวย · ห้องเรียนสะอาด · ห้องเล็ก · สนามกว้าง · กาแฟร้อน · หนังสนุก)*
7. 연습 3 (237쪽): 가: 어떤 가방을 좋아해요? 나: **예쁘고 가벼운** 가방을 좋아해요. *(ชอบกระเป๋าแบบไหน — ชอบกระเป๋าสวยและเบา)* — -고 (ข้อ 34) ต่อคุณศัพท์สองตัวก่อนนาม
8. 연습 2 (237쪽): 가: 어떤 과일을 좋아해요? 나: **신** 과일을 좋아해요. *(ชอบผลไม้แบบไหน — ชอบผลไม้เปรี้ยว)* · 어떤 교실에서 공부해요? → **창문이 큰** 교실에서 공부해요. *(เรียนในห้องแบบไหน — ห้องที่หน้าต่างใหญ่ · เฉลยเขียนเอง)*
9. 대화 23-1 (238쪽): 마키: 순두부찌개가 뭐예요? **매운** 음식이에요? 장핑: 네, 조금 **매운** 음식이에요. *(ซุนดูบูจีเกคืออะไร เป็นอาหารเผ็ดไหม — ใช่ เป็นอาหารเผ็ดนิดหน่อย)* · 불고기는 맵지 **않은** 음식이에요. 달아요. *(บุลโกกิเป็นอาหารที่ไม่เผ็ด หวาน)*
10. 읽기 23-2 (240쪽): **시원한** 냉면 · 아주 **더운** 날씨에 **뜨거운** 삼계탕 · **매운** 떡볶이 · **맛있는** 한식집 · **예쁜** 카페 *(ก๋วยเตี๋ยวเย็น · ซัมเกทังร้อน ๆ ในวันที่ร้อนจัด · ต๊อกบกกีเผ็ด · ร้านอาหารเกาหลีอร่อย · คาเฟ่สวย)*
11. 28-1 (282쪽): 저는 단풍이 **아름다운** 가을을 좋아해요. *(ฉันชอบฤดูใบไม้ร่วงที่ใบไม้เปลี่ยนสีสวยงาม)*
12. 25 연습 2 (253쪽, ㄹ-ราก): 어제 **긴** 치마를 샀어요. · 저는 **단** 음식을 안 좋아해요. *(เมื่อวานซื้อกระโปรงยาว · ฉันไม่ชอบอาหารหวาน)*

#### ถามด้วย 어떤 → ตอบด้วย A-(으)ㄴ + N
| คำถาม | คำตอบ (ตำรา = 시다 ข้อ 1 · ที่เหลือเฉลยเขียนเอง) |
|:---|:---|
| 어떤 **과일**을 좋아해요? | **신** 과일을 좋아해요. |
| 어떤 **친구**를 좋아해요? | **착한** / **똑똑한** 친구를 좋아해요. *(ชอบเพื่อนที่ใจดี / ฉลาด)* |
| 어떤 **교실**에서 공부해요? | **넓은** 교실에서 공부해요. |
| 어떤 **음식**을 좋아해요? | **매운** 음식을 좋아해요. |
| 어떤 **영화**를 봤어요? | **무서운** / **재미있는** 영화를 봤어요. *(ดูหนังน่ากลัว / สนุก)* |

### ⚠️ จุดสับสน
#### คุณศัพท์เป็น "ภาคแสดง" vs "ขยายนาม"
| | ภาคแสดง (ข้อ 18) | ขยายนาม (ข้อ 36) |
|:---|:---|:---|
| รูป | N이/가 + A-아/어요 | A-(으)ㄴ + N |
| ตัวอย่าง | 음식이 **매워요** *(อาหารเผ็ด)* | **매운** 음식 *(อาหารที่เผ็ด)* |
| ตัวอย่าง 2 | 방이 **작아요** *(ห้องเล็ก)* | **작은** 방 *(ห้องที่เล็ก)* |

#### ㄴ ตัวเดียวกัน แต่ 3 ความหมาย (เตรียมไว้ก่อน)
| | ขยายนามด้วย | ตัวอย่าง | ข้อ |
|:---|:---|:---|:---|
| **คำคุณศัพท์** | -(으)ㄴ (สภาพปัจจุบัน) | 작**은** 방 · 매**운** 음식 | **36** |
| กริยา ปัจจุบัน/ประจำ | -**는** | 먹**는** 음식 | 44 |
| กริยา อดีต | -(으)ㄴ | 먹**은** 음식 *(บท 29 ยังไม่เรียน)* | 47 |

- **좋다 ≠ 좋아하다:** 좋다 เป็นคำคุณศัพท์ → **좋은** 사람 *(คนดี)* · 좋아하다 เป็น**กริยา** → 좋아**하는** 사람 *(คนที่ชอบ — ข้อ 44)* · ✗ 좋아한 사람 สำหรับ "คนที่ชอบ" ตอนนี้
- **있다/없다 → -는:** ✓ 맛있는 · 재미있는 / ✗ 맛있은 · 재미있은

#### กับดักที่เจอบ่อย
- **ㅂ:** ✗ 맵은 · 덥은 · 춥은 → ✓ 매운 · 더운 · 추운 (ข้อ 37)
- **ㄹ:** ✗ 길은 · 단은 → ✓ 긴 · 단 · ระวัง **달은** = "พระจันทร์ + 은" (달 = ดวงจันทร์) คนละคำกับ 단 ← 달다
- **ㅡ:** ✗ 예쁘은 · 크은 → ✓ 예쁜 · 큰
- **ลืม 으 หลังตัวสะกด:** ✗ 작 책상 · 많 사람 → ✓ 작은 책상 · 많은 사람 *(ผู้เรียนเคยลืม 으 ใน -(으)세요 → 읽세요 · 받십니다 — กฎ "มีตัวสะกด → ต้องมี 으" เดียวกัน)*
- **ลำดับ:** ภาษาไทย "อาหารเผ็ด" คำขยายตามหลัง · เกาหลี **매운 음식** คำขยายนำหน้า — ✗ 음식 매운
- **ไม่ใส่ 이에요 / 인:** ✗ 매운이에요 (ใช้ N ตามหลังเสมอ: 매운 **음식**이에요)

> [!TIP]
> ดูพยางค์สุดท้ายของราก: **สระ/ㄹ → ㄴ** · **พยัญชนะ → 은** · **있다/없다 → 는** · ㅂ → 우+ㄴ · ใช้กับ**คำคุณศัพท์**เท่านั้น (กริยา → ข้อ 44)
