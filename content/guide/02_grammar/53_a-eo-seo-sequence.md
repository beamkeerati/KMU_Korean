## 53. -아/어/여서 (ลำดับการกระทำ: "…แล้วก็…") ↔ -고

> [!INTRO] ข้อนี้คืออะไร
> -아/어/여서 ในความหมายนี้เชื่อมสองการกระทำที่**ต่อเนื่องกันตามลำดับเวลา** โดยการกระทำแรกเป็น**ก้าวแรกหรือวิธี**ที่นำไปสู่การกระทำหลัง เช่น "ลงรถไฟแล้วเปลี่ยนสาย" "ไปบ้านแล้วทำการบ้าน" "พบเพื่อนแล้วไปช็อปปิ้ง" และ**ประธานต้องเป็นคนเดียวกัน**
>
> สอนในบท 32 (ตำราหน้า 316 준비 1 และหน้า 317 연습 2–3) ตำราเรียกรูปนี้ว่า -아/어/여서² ส่วนความหมาย "เหตุผล" คือ -아/어/여서¹ ในบท 29 (ข้อ 48) ตำราพิมพ์ท้ายกล่องว่า "Lesson 9" ซึ่งน่าจะหมายถึงบท 29 ต่อยอดจากข้อ 06 (กฎ 아/어/해) ข้อ 48 (รูปเดียวกัน คนละความหมาย) ข้อ 34 (-고 "และ") และข้อ 20 (-(으)세요)
>
> ไปใช้ต่อในการบอกทางด้วยรถไฟใต้ดิน (32과 대화 · 활동) ข้อ 49 / 51 ((으)로 — 4호선으로 갈아타세요) และข้อ 60 (-아/어 보다 บท 35)

### 📌 รูปแบบและเงื่อนไข

ให้ตัด 다 ออก แล้วเลือก 아/어/여 ตามสระของพยางค์สุดท้ายของราก กฎเหมือนกับข้อ 48 ทุกประการ

| รากศัพท์ลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| ㅏ / ㅗ | **-아서** | 가다 → **가서** · 오다 → **와서** · 앉다 → **앉아서** |
| สระอื่น | **-어서** | 내리다 → **내려서** · 씻다 → **씻어서** · 입다 → **입어서** |
| **하다** | **-해서** | 출근하다 → **출근해서** · 선물하다 → **선물해서** · 구경하다 → **구경해서** |
| ㄷ 불규칙 (ข้อ 51) | ㄷ → ㄹ + 어서 | 걷다 → **걸어서** |

#### ตารางผันที่ควรจำ (ตำรา 32과)

ตารางนี้รวมกริยาที่ตำราบท 32 ใช้ จัดตามกฎข้างบน ช่อง "ความหมาย" แปลเป็นรูป "…แล้ว"

| 기본형 | -아/어/여서 | ความหมาย | กฎที่ใช้ |
|:---|:---|:---|:---|
| 가다 | **가서** | ไปแล้ว | ㅏ/ㅗ → 아서 |
| 오다 | **와서** | มาแล้ว | ㅏ/ㅗ → 아서 |
| 앉다 | **앉아서** | นั่งแล้ว | ㅏ/ㅗ → 아서 |
| 만나다 | **만나서** | พบแล้ว | ㅏ/ㅗ → 아서 |
| 일어나다 | **일어나서** | ตื่นแล้ว | ㅏ/ㅗ → 아서 |
| 돌아오다 | **돌아와서** | กลับมาแล้ว | ㅏ/ㅗ → 아서 |
| 타다 | **타서** | ขึ้นแล้ว | ㅏ/ㅗ → 아서 |
| 내리다 | **내려서** | ลงแล้ว | สระอื่น → 어서 |
| 씻다 | **씻어서** | ล้างแล้ว | สระอื่น → 어서 |
| 만들다 | **만들어서** | ทำแล้ว | สระอื่น → 어서 |
| 기다리다 | **기다려서** | รอแล้ว | สระอื่น → 어서 |
| 입다 | **입어서** | สวมแล้ว | สระอื่น → 어서 |
| 출근하다 | **출근해서** | ไปทำงานแล้ว | 하다 → 해서 |
| 선물하다 | **선물해서** | ให้ของขวัญแล้ว | 하다 → 해서 |
| 구경하다 | **구경해서** | เที่ยวชมแล้ว | 하다 → 해서 |
| 걷다 | **걸어서** | เดินแล้ว → "เดินไป" | ㄷ → ㄹ |

#### ตำราหน้า 316 และข้อควรจำ

ตำราบอกว่าประโยคหน้าเป็นวิธีหรือหนทางของการกระทำในประโยคหลัง ส่วนข้อควรจำข้างล่างเป็นสิ่งที่ทำให้รูปนี้ต่างจาก -아/어서 แบบเหตุผลและต่างจาก -고

- **ตำรา 316쪽:** ต่อหลังรากกริยาของประโยคหน้า เชื่อมกับประโยคหลัง**ตามลำดับเวลา** ใช้เมื่อประโยคหน้าเป็น**วิธีหรือหนทาง**ของการกระทำในประโยคหลัง
  - ㅏ/ㅗ → -아서 · อื่น → -어서 · 하다 → -여서 (→ 해서)
  - **ใส่ตัวบอกกาลไม่ได้**
  - **ประธานของสองประโยคต้องเหมือนกัน**
- **กาลอยู่ท้ายประโยคเท่านั้น:**
  - ✓ 내**려서** 갈아**탔어요** *(ลงแล้วเปลี่ยน — อดีตที่คำท้าย)*
  - ✗ 내렸어서 갈아탔어요
- **ผลของการกระทำแรก "ติดไปด้วย" ในการกระทำที่สอง** ต่างจาก -고 ที่การกระทำแรกแค่จบไป
  - 집에 **가서** 숙제를 해요 *(ไปบ้านแล้ว **ทำที่บ้าน**)*
  - 케이크를 **만들어서** 선물해요 *(ทำเค้กแล้ว **เอาเค้กนั้น**ไปให้)*
  - 의자에 **앉아서** 기다려요 *(นั่งแล้ว **รอในท่านั่ง**)*
- **ตามด้วยคำสั่ง/ชวนได้:** 서울역에서 **내려서** 1호선으로 **갈아타세요** *(ต่างจาก -아/어서 เหตุผล ข้อ 48 ที่ห้ามตามด้วยคำสั่ง)*

### 📖 ตัวอย่างและการใช้

ตัวอย่างเรียงตามลำดับในตำราบท 32 ตั้งแต่กล่องหน้า 316 แบบฝึก 연습 1–3 ไปจนถึงบทสนทนา 32-1 และใบฟัง 32-3 สังเกตว่าเกือบทุกประโยคเป็นการเดินทางหรือกิจวัตรที่ทำต่อเนื่องกัน และกาลอยู่ที่คำท้ายตัวเดียว

#### จากตำรา 32과 (หน้า 316–317)

ช่อง ที่มา ที่เป็นขีด — คือประโยคประกอบที่ไม่ได้ระบุว่ามาจากหน้าไหนของตำรา

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 친구를 **만나서** 쇼핑을 했어요. | พบเพื่อนแล้วไปช็อปปิ้ง | กล่องตำรา 316쪽 |
| 주말에 **출근해서** 일을 끝낼 거예요. | ไปทำงานวันหยุดแล้วทำงานให้เสร็จ | กล่องตำรา 316쪽 |

| 집에 **가서** 숙제를 해요 | ไปบ้านแล้วทำการบ้าน | 연습 1 |

| 의자에 **앉아서** 기다려요 | นั่งเก้าอี้แล้วรอ | 연습 1 |
| 동대문시장 — 동대문역에서 **내려서** 1번 출구로 **나가세요** | ตลาดตงแดมุน — ลงสถานีตงแดมุนแล้วออกทางออก 1 | 연습 2 |
| 인천공항 — 길음역에서 **내려서** 공항버스로 **갈아타세요** | สนามบินอินชอน — ลงสถานีคิรึมแล้วเปลี่ยนรถบัสสนามบิน | 연습 2 |
| 63빌딩 — 여의도역에서 **내려서** 200m쯤 **걸어서** 가세요 | ตึก 63 — ลงสถานียออีโดแล้วเดินราว 200 ม. | 연습 2 |
| 주차장 — 건물 안으로 **들어가서** 엘리베이터를 **타세요** | ที่จอดรถ — เข้าไปในตึกแล้วขึ้นลิฟต์ | 연습 2 |

| 저녁 6시에 **돌아와서** 숙제를 할 거예요 | กลับมา 6 โมงเย็นแล้วทำการบ้าน | 연습 3 |
| 길음역에서 지하철 4호선을 타세요. 그리고 삼각지역에서 **내려서** 6호선으로 **갈아타세요**. 이태원역 3번 출구에 차차가 있어요. | ขึ้นสาย 4 ที่สถานีคิรึม แล้วลงที่สถานีซัมกักจีแล้วเปลี่ยนเป็นสาย 6 ร้านชาช่าอยู่ทางออก 3 ของสถานีอีแทวอน | 대화 32-1 |
| 횡단보도를 **건너서** 100m쯤 똑바로 오세요. | ข้ามทางม้าลายแล้วเดินตรงมาราว 100 ม. | 읽기 31-2 |
| 학교에서 길음역까지 153번 버스를 **타고** 길음역에서 지하철 4호선으로 **갈아타세요**. | ขึ้นรถเมล์ 153 แล้วเปลี่ยนสาย 4 ("ขึ้น" ใช้ -고) | 읽기 31-2 |
| 저는 **걸어서** 가요. | ฉันเดินไป (ㄷ 불규칙 + -아/어서 = วิธีไป ข้อ 51) | ย้อนบท 31 (준비 1) |

#### 연습 3: คำถามประกอบแผนสุดสัปดาห์

연습 3 ให้ดูแผนสุดสัปดาห์ของบัตแล้วถาม-ตอบกันด้วยคำถามชุดนี้

- 몇 시에 일어날 거예요? *(กี่โมงจะตื่น)*
- 어디에 갈 거예요? *(จะไปที่ไหน)*
- 어디에 가서 뭐 먹을 거예요? *(ไปที่ไหนแล้วจะกินอะไร)*
- 몇 시에 집에 돌아올 거예요? *(จะกลับบ้านกี่โมง)*

#### ใบฟัง 32-3 (เติมคำ — เฉลยภาคผนวก)

ใบฟังนี้เป็นการบอกทางด้วยรถไฟใต้ดินเป็นขั้น ๆ ช่องเติมคือชื่อสถานี คำว่า 갈아타세요 และหมายเลขทางออก

- 명동역에서 지하철 4호선을 타세요 *(ขึ้นสาย 4 ที่สถานีมยองดง)*
- **서울역**에서 내리세요 *(ลงที่สถานีโซล)*
- 1호선으로 **갈아타세요** *(เปลี่ยนเป็นสาย 1)*
- **시청역**에서 내리세요 *(ลงที่สถานีศาลากลาง)*
- **3번 출구**로 나오세요 *(ออกทางออกที่ 3)*

#### กรอบคำท้าย 대화 32-1

ท้ายบทสนทนา 32-1 ตำรามีกรอบคำให้สร้างบทสนทนาเอง โดยใช้ -아/어서 ต่อเส้นทาง

- 선생님 결혼식 *(งานแต่งอาจารย์)*
- 삼성역 H호텔 *(สถานีซัมซอง โรงแรม H)*
- 서울역 1호선 *(สถานีโซล สาย 1)*
- 신도림역 2호선 *(สถานีซินโดริม สาย 2)*
- 1번 출구 *(ทางออกที่ 1)*

#### ถาม-ตอบ

คำถาม "ไป…ยังไง" ตอบด้วยการลงที่สถานีไหนแล้วเปลี่ยนสายอะไร ซึ่งเป็นรูปมาตรฐานของข้อนี้

| ที่มา | คำถาม | คำตอบ |
|:---|:---|:---|
| 준비 1 | 시청에 어떻게 가요? | 서울역에서 **내려서** 지하철 1호선으로 **갈아타세요**. *(ไปศาลากลางยังไง — ลงที่สถานีโซลแล้วเปลี่ยนเป็นสาย 1)* |
| 연습 2 | 국민대학교에 어떻게 가요? | 지하철 1호선 서울역에서 **내려서** 4호선으로 **갈아타세요**. *(ไปมหาวิทยาลัยคุกมินยังไง — ลงสถานีโซลสาย 1 แล้วเปลี่ยนเป็นสาย 4)* |

### ⚠️ จุดสับสน

ความสับสนของข้อนี้มีสองคู่ คือ -아/어서 แบบลำดับกับแบบเหตุผลที่รูปเหมือนกัน และ -아/어서 กับ -고 ที่แปลว่า "แล้ว/และ" เหมือนกัน

#### -아/어서 (ลำดับ ข้อ 53) vs -아/어서 (เหตุผล ข้อ 48) — รูปเดียวกัน

รูปเดียวกันมีสองความหมาย แยกได้จากชนิดของประโยคหน้า ประธาน และการตามด้วยคำสั่ง

| | **ลำดับ** (ข้อ 53) | **เหตุผล** (ข้อ 48) |
|:---|:---|:---|
| ความหมาย | A แล้วจึง B (A เป็นก้าวแรก/วิธี) | เพราะ A จึง B |
| ประโยคหน้า | **กริยา** (เคลื่อนที่ · ท่าทาง · ทำของ) | คุณศัพท์ · 있다/없다 · 이다 · กริยา |
| ประธาน | **ต้องเหมือนกัน** | ต่างกันได้ |
| ตามด้วย -(으)세요 / -(으)ㅂ시다 | ✓ | ✗ |
| ตัวอย่าง | 내려서 갈아탔어요 *(ลงแล้วเปลี่ยนสาย)* | 늦어서 택시를 탔어요 *(สายเลยนั่งแท็กซี่)* |

วิธีแยกสองความหมายนี้คือถามตัวเองด้วยคำถามสั้น ๆ

- ถามว่า "ประโยคหน้า**เกิดก่อนและเป็นทางผ่าน**ให้ประโยคหลังไหม?" → ลำดับ
- ถามว่า "ประโยคหน้า**เป็นสาเหตุ**ไหม?" → เหตุผล
- คำคุณศัพท์/있다/없다/이다 หน้า 서 = เหตุผลเสมอ

#### -아/어서 vs -고 (ข้อ 34 / บท 22 — "และ/แล้ว")

ทั้งสองรูปแปลว่า "แล้ว" ได้ แต่ -아/어서 ผูกสองการกระทำเข้าด้วยกัน ส่วน -고 เป็นแค่การเรียงต่อกัน

| | **-아/어서** | **-고** |
|:---|:---|:---|
| ความผูกพัน | ก้าวแรกผูกกับก้าวสอง | แค่เรียงลำดับ/ต่อกัน ไม่ผูก |
| ประธาน | ต้องเหมือนกัน | ต่างกันได้ |
| ใส่ -았/었- | ✗ | ✓ (먹었고) |
| ผลของ A คงอยู่ใน B | ✓ (앉아서 기다려요) | ไม่จำเป็น |
| ตัวอย่าง | **집에 가서** 숙제를 해요 *(ไปทำที่บ้าน)* | **숙제를 하고** 집에 가요 *(ทำการบ้านเสร็จแล้วค่อยกลับ)* |

ตำราเลือกใช้สองรูปนี้ตามกลุ่มคำที่ตายตัว ให้ท่องเป็นกลุ่มดังตารางนี้

| รูป | กลุ่มความหมาย | ตัวอย่างจากตำรา |
|:---|:---|:---|
| -고 | ขึ้นพาหนะแล้วไป | 버스를 **타고** 가세요 *(ขึ้นรถเมล์ไป)* |
| -고 | ขึ้นพาหนะแล้วไป | 케이블카를 **타고** 갔어요 *(ขึ้นกระเช้าไป)* |
| -고 | ถือแล้วไป | 수영복을 **가지고** 갈 거예요 *(ถือชุดว่ายน้ำไป)* |
| -고 | จับแล้วทำ | 손을 **잡고** 데이트를 해요 *(จับมือไปเดต)* |
| -아/어서 | ลงแล้วเปลี่ยน | 내려서 갈아타세요 *(ลงแล้วเปลี่ยนสาย)* |
| -아/어서 | ข้ามแล้วเดิน | 건너서 가세요 *(ข้ามแล้วไป)* |

- **그리고** *(แล้วก็)* ใช้เริ่มประโยคใหม่ ส่วน -고/-아서 เชื่อมภายในประโยคเดียว เช่น 길음역에서 4호선을 타세요. **그리고** 삼각지역에서 내려서 …

#### กับดัก

ข้อผิดของข้อนี้ส่วนใหญ่เป็นเรื่องกาลที่ใส่ผิดที่ การเลือก 아/어 และการควบสระ ไล่ดูทีละข้อ

- **ใส่กาลในประโยคหน้า:**
  - ✗ 내렸어서 갈아탔어요 → ✓ 내려서 갈아탔어요
  - ✗ 갔어서 숙제를 했어요
- **เลือก 아/어 ผิด (ㅏ-ราก + 어)** *(ครูไฮไลต์ 살어요 → 살아요 · 받었어요 → 받았어요 — ท่อง ㅏ/ㅗ = 아)*
  - ✗ 앉어서 → ✓ **앉아서**
  - ✗ 살어서 → ✓ **살아서**
  - ✗ 받어서 → ✓ **받아서**
- **ไม่ควบเสียงตามกฎ** *(ㅏ ชน ㅏ = ตัดหนึ่งตัว · ㅗ + ㅏ = ㅘ · ㅣ + ㅓ = ㅕ — ข้อ 06)*
  - ✗ 가아서 → ✓ **가서**
  - ✗ 오아서 → ✓ **와서**
  - ✗ 만나아서 → ✓ **만나서**
  - ✗ 내리어서 → ✓ **내려서**
- **ㄹ-ราก:** ✓ **만들어서** (ㄹ อยู่ครบ เพราะ 어 ไม่ใช่ ㄴ/ㅂ/ㅅ) / ✗ 만드어서 · ✗ 만들서
- **สะกดกริยา:** ✓ **갈아타다** *(เปลี่ยนสาย — 갈다 "เปลี่ยน" + 타다)* / ✗ 같아타다 *(같다 = เหมือน)* · ✓ 갈아타세요 · 갈아탔어요
- **ประธานต่างกัน = ใช้ -고 หรือ -(으)니까:**
  - ✗ 동생이 와서 제가 숙제를 했어요
  - ✓ 동생이 오니까 / 동생이 오고
- **내리다 + ที่:**
  - ✓ 서울역**에서** 내려요 *(ลงที่สถานีโซล — 에서 ข้อ 09)*
  - ✓ 4호선**으로** 갈아타세요 *((으)로 = "เปลี่ยนไปสู่สาย 4" ข้อ 49/51)*
  - ✗ 서울역에 내려요
- **돌아오다 / 돌아가다:**
  - 돌아오다 = กลับมา (หาผู้พูด)
  - 돌아가다 = กลับไป *(ตำรา 연습 3: 저녁 6시에 돌아와서 숙제를 해요)*
- **อย่าสับกับ -(으)니까:** 안내 방송을 하니까 잘 들으세요 *(มีประกาศ จึงฟังดี ๆ — เหตุผล ข้อ 50 ไม่ใช่ลำดับ)*

> [!TIP] กฎสั้น ๆ
> **-아/어서 (ลำดับ) = A แล้ว B** · **ประธานเดียวกัน** · **ไม่ใส่กาลหน้า** · **ตามคำสั่งได้**
>
> **ขึ้นรถ = 타고** · **ลงแล้วเปลี่ยน = 내려서 갈아타세요** · **-고 = เรียงต่อกันเฉย ๆ**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ข้อนี้ยังไม่มีข้อสอบจริงที่ครูตรวจแล้วเกี่ยวกับ -아/어서 (ลำดับ) เพราะ 32과 อยู่ใน **복습시험④ (11/18, 30–37과)** และ **기말** แต่มีเฉลยภาคผนวกของข้อ 듣기 และข้อผิดกลุ่มเดียวกันให้เตรียมตัว

- **เฉลยภาคผนวก 듣기 32:**
  - 나. 1 ○ (간토야 씨는 길을 잘 몰라요)
  - 나. 2 ✗ (ไม่ได้ขึ้นรถเมล์ — ใช้รถไฟใต้ดิน)
  - 나. 3 ✗ (ร้านอยู่ที่สถานีศาลากลาง ทางออก 3 ไม่ใช่สถานีโซล)
  - ดูข้อ 52 สำหรับ 20분쯤
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ:**
  - ㅏ-ราก + 어 (살어요 · 받었어요)
  - ลืม 으 หลังตัวสะกด (읽세요 · 씻러)
  - 에 vs 에서 (백화점에 샀어요)
  - ตอบผิดคำถาม (어떻게 ↔ 얼마나)
- **คาดการณ์รูปแบบข้อสอบ** (จากรูปแบบ 복습시험①②; เป็นการคาด):
  - รวมสองประโยคเป็นหนึ่ง: 집에 가요. 숙제를 해요. → 집에 가서 숙제를 해요.
  - รวมสองประโยคเป็นหนึ่ง: 서울역에서 내려요. 1호선으로 갈아타요. → 서울역에서 내려서 1호선으로 갈아타요.
  - ภาพไทม์ไลน์ + 합니다체 (เหมือน 복습시험② ข้อ 7): 9시에 일어납니다 → 커피를 마십니다 → 영화관에 갑니다 → 일어나서 커피를 마십니다. 영화관에 가서 영화를 봅니다.
  - เลือก -아/어서 (เหตุผล) หรือ -(으)니까 หรือ -고: ○ 비가 (와서/오니까) 우산을 가지고 가세요
  - เลือก -아/어서 (เหตุผล) หรือ -(으)니까 หรือ -고: ○ 버스에서 (내려서/내리고) 지하철로 갈아타요
  - บอกทางจากแผนที่รถไฟใต้ดิน (활동 32): …역에서 내려서 …호선으로 갈아타세요 + …번 출구로 나가세요
  - ฟัง 32-3 เติมคำ (서울역 · 갈아타세요 · 시청역 · 3번 출구)
