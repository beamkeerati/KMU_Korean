## 53. -아/어/여서 (ลำดับการกระทำ: "…แล้วก็…") ↔ -고
เชื่อมสองการกระทำที่**ต่อเนื่องกันตามลำดับเวลา** โดยการกระทำแรกเป็น**ก้าวแรก/วิธี**ที่นำไปสู่การกระทำหลัง ("ลงรถไฟแล้วเปลี่ยนสาย" · "ไปบ้านแล้วทำการบ้าน" · "พบเพื่อนแล้วไปช็อปปิ้ง") — **ประธานต้องเป็นคนเดียวกัน**
สอนในบท 32 (교과서 316쪽 준비 1 + 317쪽 연습 2–3) — ตำราเรียก -아/어/여서² (ความหมาย "เหตุผล" = -아/어/여서¹ บท 29 = ข้อ 48 — ตำราพิมพ์ท้ายกล่องว่า "Lesson 9" น่าจะหมายถึงบท 29) · ต่อยอดจาก ข้อ 06 (กฎ 아/어/해) · ข้อ 48 (รูปเดียวกัน คนละความหมาย) · ข้อ 34 (-고 "และ") · ข้อ 20 (-(으)세요)
ใช้ต่อใน การบอกทางด้วยรถไฟใต้ดิน (32과 대화 · 활동) · ข้อ 49 / 51 ((으)로 — 4호선으로 갈아타세요) · ข้อ 60 (-아/어 보다 บท 35)

### 📌 รูปแบบและเงื่อนไข
ตัด 다 ทิ้ง แล้วเลือก 아/어/여 ตามสระของพยางค์สุดท้ายของราก — กฎเดียวกับ ข้อ 48

| รากศัพท์ลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| ㅏ / ㅗ | **-아서** | 가다 → **가서** · 오다 → **와서** · 앉다 → **앉아서** · 만나다 → **만나서** · 일어나다 → **일어나서** · 돌아오다 → **돌아와서** · 타다 → **타서** *(ไปแล้ว · มาแล้ว · นั่งแล้ว · พบแล้ว · ตื่นแล้ว · กลับมาแล้ว · ขึ้นแล้ว)* |
| สระอื่น | **-어서** | 내리다 → **내려서** · 씻다 → **씻어서** · 만들다 → **만들어서** · 기다리다 → **기다려서** · 입다 → **입어서** *(ลงแล้ว · ล้างแล้ว · ทำแล้ว · รอแล้ว · สวมแล้ว)* |
| **하다** | **-해서** | 출근하다 → **출근해서** · 선물하다 → **선물해서** · 구경하다 → **구경해서** *(ไปทำงานแล้ว · ให้ของขวัญแล้ว · เที่ยวชมแล้ว)* |
| ㄷ 불규칙 (ข้อ 51) | ㄷ → ㄹ + 어서 | 걷다 → **걸어서** *(เดินแล้ว → "เดินไป")* |

- **ตำรา 316쪽:** ต่อหลังรากกริยาของประโยคหน้า เชื่อมกับประโยคหลัง**ตามลำดับเวลา** · ใช้เมื่อประโยคหน้าเป็น**วิธีหรือหนทาง**ของการกระทำในประโยคหลัง · ㅏ/ㅗ → -아서 · อื่น → -어서 · 하다 → -여서 (→ 해서) · **ใส่ตัวบอกกาลไม่ได้** · **ประธานของสองประโยคต้องเหมือนกัน**
- **กาลอยู่ท้ายประโยคเท่านั้น:** 내**려서** 갈아**탔어요** *(ลงแล้วเปลี่ยน — อดีตที่คำท้าย)* · ✗ 내렸어서 갈아탔어요
- **ผลของการกระทำแรก "ติดไปด้วย" ในการกระทำที่สอง:** 집에 **가서** 숙제를 해요 *(ไปบ้านแล้ว **ทำที่บ้าน**)* · 케이크를 **만들어서** 선물해요 *(ทำเค้กแล้ว **เอาเค้กนั้น**ไปให้)* · 의자에 **앉아서** 기다려요 *(นั่งแล้ว **รอในท่านั่ง**)* — ต่างจาก -고 ที่การกระทำแรกแค่จบไป
- **ตามด้วยคำสั่ง/ชวนได้:** 서울역에서 **내려서** 1호선으로 **갈아타세요** *(ต่างจาก -아/어서 เหตุผล ข้อ 48 ที่ห้ามตามด้วยคำสั่ง)*

### 📖 ตัวอย่างและการใช้
| | คำถาม | คำตอบ |
|:---|:---|:---|
| 준비 1 | 시청에 어떻게 가요? | 서울역에서 **내려서** 지하철 1호선으로 **갈아타세요**. *(ไปศาลากลางยังไง — ลงที่สถานีโซลแล้วเปลี่ยนเป็นสาย 1)* |
| 연습 2 | 국민대학교에 어떻게 가요? | 지하철 1호선 서울역에서 **내려서** 4호선으로 **갈아타세요**. *(ไปมหาวิทยาลัยคุกมินยังไง — ลงสถานีโซลสาย 1 แล้วเปลี่ยนเป็นสาย 4)* |

1. 친구를 **만나서** 쇼핑을 했어요. *(พบเพื่อนแล้วไปช็อปปิ้ง)* · 주말에 **출근해서** 일을 끝낼 거예요. *(ไปทำงานวันหยุดแล้วทำงานให้เสร็จ)* · 사과는 **씻어서** 드세요. *(ล้างแอปเปิลแล้วทานนะ)* — กล่องตำรา 316쪽
2. 연습 1 (แบบ: 버스에서 내려서 지하철로 갈아탔어요): 버스에서 **내려서** 지하철로 갈아탔어요 · 지하철 2호선에서 **내려서** 3호선으로 갈아타요 · 집에 **가서** 숙제를 해요 · 케이크를 **만들어서** 선물해요 · 의자에 **앉아서** 기다려요 *(ลงจากรถเมล์แล้วเปลี่ยนเป็นรถไฟใต้ดิน · ลงสาย 2 แล้วเปลี่ยนสาย 3 · ไปบ้านแล้วทำการบ้าน · ทำเค้กแล้วให้เป็นของขวัญ · นั่งเก้าอี้แล้วรอ)*
3. 연습 2 (ต่อ ตามกรอบคำ): 동대문시장 — 동대문역에서 **내려서** 1번 출구로 **나가세요** · 인천공항 — 길음역에서 **내려서** 공항버스로 **갈아타세요** · 63빌딩 — 여의도역에서 **내려서** 200m쯤 **걸어서** 가세요 · 주차장 — 건물 안으로 **들어가서** 엘리베이터를 **타세요** *(ตลาดตงแดมุน — ลงสถานีตงแดมุนแล้วออกทางออก 1 · สนามบินอินชอน — ลงสถานีคิรึมแล้วเปลี่ยนรถบัสสนามบิน · ตึก 63 — ลงสถานียออีโดแล้วเดินราว 200 ม. · ที่จอดรถ — เข้าไปในตึกแล้วขึ้นลิฟต์)*
4. 연습 3 (แผนสุดสัปดาห์ของบัต): 9시에 **일어나서** 커피를 마실 거예요. 그리고 영화관에 **가서** 무서운 영화를 볼 거예요. *(ตื่น 9 โมงแล้วดื่มกาแฟ แล้วไปโรงหนังดูหนังผี)* · 이태원에 **가서** 인도 요리를 먹을 거예요 · 저녁 6시에 **돌아와서** 숙제를 할 거예요 *(ไปอีแทวอนแล้วกินอาหารอินเดีย · กลับมา 6 โมงเย็นแล้วทำการบ้าน)* — คำถามประกอบ: 몇 시에 일어날 거예요? · 어디에 갈 거예요? · 어디에 가서 뭐 먹을 거예요? · 몇 시에 집에 돌아올 거예요?
5. 대화 32-1: 길음역에서 지하철 4호선을 타세요. 그리고 삼각지역에서 **내려서** 6호선으로 **갈아타세요**. 이태원역 3번 출구에 차차가 있어요. *(ขึ้นสาย 4 ที่สถานีคิรึม แล้วลงที่สถานีซัมกักจีแล้วเปลี่ยนเป็นสาย 6 ร้านชาช่าอยู่ทางออก 3 ของสถานีอีแทวอน)*
6. ใบฟัง 32-3 (เติมคำ — เฉลยภาคผนวก): 명동역에서 지하철 4호선을 타세요 ⇨ **서울역**에서 내리세요 ⇨ 1호선으로 **갈아타세요** ⇨ **시청역**에서 내리세요 ⇨ **3번 출구**로 나오세요 *(ขึ้นสาย 4 ที่มยองดง → ลงสถานีโซล → เปลี่ยนสาย 1 → ลงสถานีศาลากลาง → ออกทางออก 3)*
7. 읽기 31-2: 횡단보도를 **건너서** 100m쯤 똑바로 오세요. *(ข้ามทางม้าลายแล้วเดินตรงมาราว 100 ม.)* · 학교에서 길음역까지 153번 버스를 **타고** 길음역에서 지하철 4호선으로 **갈아타세요**. *(ขึ้นรถเมล์ 153 แล้วเปลี่ยนสาย 4 — "ขึ้น" ใช้ -고)*
8. ย้อนบท 31 (준비 1): 저는 **걸어서** 가요. *(ฉันเดินไป — ㄷ 불규칙 + -아/어서 = วิธีไป ข้อ 51)*
9. กรอบคำท้าย 대화 32-1: 선생님 결혼식 — 삼성역 H호텔 · 서울역 1호선 · 신도림역 2호선 · 1번 출구 *(งานแต่งอาจารย์ — สถานีซัมซอง โรงแรม H · ลงสาย 1 สถานีโซล ฯลฯ — ตำราให้สร้างบทสนทนาเอง)*

### ⚠️ จุดสับสน
#### -아/어서 (ลำดับ ข้อ 53) vs -아/어서 (เหตุผล ข้อ 48) — รูปเดียวกัน
| | **ลำดับ** (ข้อ 53) | **เหตุผล** (ข้อ 48) |
|:---|:---|:---|
| ความหมาย | A แล้วจึง B (A เป็นก้าวแรก/วิธี) | เพราะ A จึง B |
| ประโยคหน้า | **กริยา** (เคลื่อนที่ · ท่าทาง · ทำของ) | คุณศัพท์ · 있다/없다 · 이다 · กริยา |
| ประธาน | **ต้องเหมือนกัน** | ต่างกันได้ |
| ตามด้วย -(으)세요 / -(으)ㅂ시다 | ✓ | ✗ |
| ตัวอย่าง | 내려서 갈아탔어요 *(ลงแล้วเปลี่ยนสาย)* | 늦어서 택시를 탔어요 *(สายเลยนั่งแท็กซี่)* |

- วิธีแยก: ถามว่า "ประโยคหน้า**เกิดก่อนและเป็นทางผ่าน**ให้ประโยคหลังไหม?" → ลำดับ · "ประโยคหน้า**เป็นสาเหตุ**ไหม?" → เหตุผล · คำคุณศัพท์/있다/없다/이다 หน้า 서 = เหตุผลเสมอ

#### -아/어서 vs -고 (ข้อ 34 / บท 22 — "และ/แล้ว")
| | **-아/어서** | **-고** |
|:---|:---|:---|
| ความผูกพัน | ก้าวแรกผูกกับก้าวสอง | แค่เรียงลำดับ/ต่อกัน ไม่ผูก |
| ประธาน | ต้องเหมือนกัน | ต่างกันได้ |
| ใส่ -았/었- | ✗ | ✓ (먹었고) |
| ผลของ A คงอยู่ใน B | ✓ (앉아서 기다려요) | ไม่จำเป็น |
| ตัวอย่าง | **집에 가서** 숙제를 해요 *(ไปทำที่บ้าน)* | **숙제를 하고** 집에 가요 *(ทำการบ้านเสร็จแล้วค่อยกลับ)* |

- ตำราใช้ **-고** กับ "ขึ้นพาหนะแล้วไป/ถือแล้วไป": 버스를 **타고** 가세요 · 케이블카를 **타고** 갔어요 · 수영복을 **가지고** 갈 거예요 · 손을**잡고** 데이트를 해요 · ใช้ **-아/어서** กับ "ลงแล้วเปลี่ยน/ข้ามแล้วเดิน": 내려서 갈아타세요 · 건너서 가세요 — ท่องเป็นกลุ่มคำที่ตำราใช้
- **그리고** *(แล้วก็)* = เริ่มประโยคใหม่ · -고/-아서 = เชื่อมภายในประโยคเดียว: 길음역에서 4호선을 타세요. **그리고** 삼각지역에서 내려서 …

#### กับดักที่เจอบ่อย
- **ใส่กาลในประโยคหน้า:** ✗ 내렸어서 갈아탔어요 · ✗ 갔어서 숙제를 했어요 → ✓ 내려서 갈아탔어요
- **เลือก 아/어 ผิด (ㅏ-ราก + 어):** ✗ 앉어서 · ✗ 살어서 · ✗ 받어서 → ✓ **앉아서 · 살아서 · 받아서** *(ครูไฮไลต์ 살어요 → 살아요 · 받었어요 → 받았어요 — ท่อง ㅏ/ㅗ = 아)*
- **ไม่ควบเสียงตามกฎ:** ✗ 가아서 · ✗ 오아서 · ✗ 만나아서 · ✗ 내리어서 → ✓ **가서 · 와서 · 만나서 · 내려서** *(ㅏ ชน ㅏ = ตัดหนึ่งตัว · ㅗ + ㅏ = ㅘ · ㅣ + ㅓ = ㅕ — ข้อ 06)*
- **ㄹ-ราก:** ✓ **만들어서** (ㄹ อยู่ครบ เพราะ 어 ไม่ใช่ ㄴ/ㅂ/ㅅ) / ✗ 만드어서 · ✗ 만들서
- **สะกดกริยา:** ✓ **갈아타다** *(เปลี่ยนสาย — 갈다 "เปลี่ยน" + 타다)* / ✗ 같아타다 *(같다 = เหมือน)* · ✓ 갈아타세요 · 갈아탔어요
- **ประธานต่างกัน = ใช้ -고 หรือ -(으)니까:** ✗ 동생이 와서 제가 숙제를 했어요 → ✓ 동생이 오니까 / 동생이 오고
- **내리다 + ที่:** ✓ 서울역**에서** 내려요 *(ลงที่สถานีโซล — 에서 ข้อ 09)* · ✓ 4호선**으로** 갈아타세요 *((으)로 = "เปลี่ยนไปสู่สาย 4" ข้อ 49/51)* · ✗ 서울역에 내려요
- **돌아오다 / 돌아가다:** 돌아오다 = กลับมา (หาผู้พูด) · 돌아가다 = กลับไป *(ตำรา 연습 3: 저녁 6시에 돌아와서 숙제를 해요)*
- **อย่าสับกับ -(으)니까:** 안내 방송을 하니까 잘 들으세요 *(มีประกาศ จึงฟังดี ๆ — เหตุผล ข้อ 50 ไม่ใช่ลำดับ)*

> [!TIP]
> **-아/어서 (ลำดับ) = A แล้ว B · ประธานเดียวกัน · ไม่ใส่กาลหน้า · ตามคำสั่งได้ · ขึ้นรถ = 타고 / ลงแล้วเปลี่ยน = 내려서 갈아타세요 · -고 = เรียงต่อกันเฉย ๆ**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- ยังไม่มีข้อสอบจริงที่ครูตรวจแล้วเกี่ยวกับ -아/어서 (ลำดับ) — 32과 อยู่ใน **복습시험④ (11/18, 30–37과)** และ **기말**
- **เฉลยภาคผนวก 듣기 32:** 나. 1 ○ (간토야 씨는 길을 잘 몰라요) 2 ✗ (ไม่ได้ขึ้นรถเมล์ — ใช้รถไฟใต้ดิน) 3 ✗ (ร้านอยู่ที่สถานีศาลากลาง ทางออก 3 ไม่ใช่สถานีโซล) · ดู ข้อ 52 สำหรับ 20분쯤
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ:** ㅏ-ราก + 어 (살어요 · 받었어요) · ลืม 으 หลังตัวสะกด (읽세요 · 씻러) · 에 vs 에서 (백화점에 샀어요) · ตอบผิดคำถาม (어떻게 ↔ 얼마나)
- **คาดการณ์รูปแบบข้อสอบ** (จากรูปแบบ 복습시험①②; เป็นการคาด)
  1. **รวมสองประโยคเป็นหนึ่ง:** 집에 가요. 숙제를 해요. → 집에 가서 숙제를 해요. · 서울역에서 내려요. 1호선으로 갈아타요. → 서울역에서 내려서 1호선으로 갈아타요.
  2. **ภาพไทม์ไลน์ + 합니다체** (เหมือน 복습시험② ข้อ 7): 9시에 일어납니다 → 커피를 마십니다 → 영화관에 갑니다 → 일어나서 커피를 마십니다. 영화관에 가서 영화를 봅니다.
  3. **เลือก -아/어서 (เหตุผล) หรือ -(으)니까 หรือ -고:** ○ 비가 (와서/오니까) 우산을 가지고 가세요 · ○ 버스에서 (내려서/내리고) 지하철로 갈아타요
  4. **บอกทางจากแผนที่รถไฟใต้ดิน (활동 32):** …역에서 내려서 …호선으로 갈아타세요 + …번 출구로 나가세요 · ฟัง 32-3 เติมคำ (서울역 · 갈아타세요 · 시청역 · 3번 출구)
