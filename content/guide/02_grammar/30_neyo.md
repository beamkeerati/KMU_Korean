## 30. -네요 (...นะเนี่ย / ...จัง)
ลงท้ายประโยคเพื่ออุทานว่า **เพิ่งรู้ / เพิ่งเห็น / ประหลาดใจ** กับสิ่งที่เห็นหรือได้ยินตรงหน้า
สอนในบท 20 (교과서 182–183쪽) · ต่อยอดจาก ข้อ 06 (-아/어요) · ข้อ 23 (-았/었/였-) · ข้อ 22 (-겠-) · ข้อ 18 (คำคุณศัพท์)
ใช้ต่อใน บท 26 (-겠네요 คาดเดา — ยังไม่เรียน) · เทียบกับ ข้อ 28 และ ข้อ 32

### 📌 รูปแบบและเงื่อนไข
| ชนิดคำ | วิธีต่อ | ตัวอย่าง |
|:---|:---|:---|
| กริยา / คำคุณศัพท์ | ตัด 다 + **-네요** — **ไม่ดูตัวสะกด ไม่ต้องหา 아/어** | 오다 → 오**네요** · 크다 → 크**네요** · 예쁘다 → 예쁘**네요** · 많다 → 많**네요** *({v:มา}{e:นี่นา} · {v:ใหญ่}{e:จัง} · {v:สวย}{e:จัง} · {v:เยอะ}{e:จัง})* |
| อดีต | **-았/었/였네요** | 왔네요 · 많았네요 · 했네요 *({v:มา}{e:แล้วนี่} · {v:เยอะ}เลยนะ · {v:ทำ}{e:แล้วนี่})* |
| คาดเดา | **-겠네요** | 힘들겠네요 *(คงเหนื่อยแย่)* |
| 이다 *(เสริม ตำรายังไม่สอนตรง ๆ)* | N + **이네요** | 학생이네요 *({e:เป็น}{n:นักเรียน}{e:นี่เอง})* |

- **ตำรา 182쪽:** ใช้แสดงความรู้สึก "เพิ่งรู้ / เพิ่งเข้าใจ" ต่อ**สิ่งที่เห็น/ได้ยินตรงหน้า** · ต่อหลัง **-았/었/였-** หรือ **-겠-** ได้ · เป็นประโยค**บอกเล่า/อุทาน**
- น้ำเสียงอุทาน: มักขึ้นต้นด้วย **와** *({a:ว้าว})* และมี 아주 · 참 · 정말 ช่วยเน้น
- **ออกเสียง:** 많네요 [만네요] (ตำรา) · ㄱ/ㅂ + ㄴ → ㅇ/ㅁ: 먹네요 [멍네요] · 없네요 [엄네요]

### 📖 ตัวอย่างและการใช้
- 와, 예쁘**네요**! *({a:ว้าว} {v:สวย}{e:จัง})*
- 눈이 많이 오**네요**! *({n:หิมะ}{v:ตก}{a:เยอะ}{e:จัง})*
- 지하철이 복잡하**네요**. *({n:รถไฟใต้ดิน}{v:แน่น}{e:จัง})*
- 가족이 많**네요**. *({n:ครอบครัว}{v:ใหญ่}{e:จัง}นะ)*
- 키가 크**네요**. *({n:ตัว}{v:สูง}{e:จัง})*
- 가방이 비싸**네요**. *({n:กระเป๋า}{v:แพง}{e:จัง})*
- 오늘 아주 힘들겠**네요**. *(วันนี้คงเหนื่อยมากนะ)*
- 결혼식에 사람들이 많이 왔**네요**. *({n:คน}{v:มา}{n:งานแต่ง}{a:เยอะ}{e:จัง})*

#### 📽️ สไลด์อาจารย์ (교과서 182쪽)
สไลด์ 문법 3: **동사, 형용사 + -네요** · **과거 + -았/었/였네요** (ครูเขียน 했 ใต้ 했네요 เพื่อเน้นรูปอดีต) — บทสนทนา 3 คู่ ที่เห็นหรือได้ยินแล้วอุทานทันที:

| 가 (บอกข้อมูล) | 나 (อุทาน) |
|:---|:---|
| 어제 옷을 샀어요. *(เมื่อวานซื้อเสื้อ)* | 와, 예쁘**네요**. 얼마예요? *({a:ว้าว} {v:สวย}{e:จัง} ราคา{q:เท่าไหร่})* |
| 3만 원이에요. *(30,000 วอน)* | 와, 싸**네요**. *({a:ว้าว} {v:ถูก}{e:จัง})* |
| 어제 9시부터 5시까지 공부했어요. *(เมื่อวานเรียนตั้งแต่ 9 โมงถึง 5 โมง)* | 와, 공부를 열심히 **했네요**. *({a:ว้าว} {a:ขยัน}{v:เรียน}{e:จัง})* |

#### จากบทสนทนาในตำรา (20-1 หน้า 184 · กิจกรรม หน้า 185 · ใบฟัง 20-2 หน้า 186)
- (ดูรูปถ่ายงานวันเกิด) 와, 사람들이 많**네요**. *({a:ว้าว} {n:คน}{v:เยอะ}{e:จัง})*
- 와, 향수가 아주 좋**네요**. 감사합니다. *({a:ว้าว} {n:น้ำหอม}{v:ดี}{a:มาก}เลย {v:ขอบคุณ}ครับ)*
- 지훈 씨 참 친절하**네요**. *(คุณจีฮุนใจดีจริง ๆ)*

### ⚠️ จุดสับสน
#### -네요 vs -아/어요
-네요 ไม่ใช่การบอกเล่าธรรมดา แต่เป็นการ "อุทาน" ถึงสิ่งที่เพิ่งรู้ ณ ตอนนั้น จึงใช้กับสิ่งที่ผู้พูดรู้อยู่แล้วไม่ได้

| | -아/어요 | -네요 |
|:---|:---|:---|
| ความรู้สึก | บอกเล่าเฉย ๆ | เพิ่งรู้ / ประหลาดใจ |
| สิ่งที่พูดถึง | ข้อมูลที่รู้อยู่แล้ว | สิ่งที่เห็น/ได้ยิน/ลองตรงหน้า |
| ตัวอย่าง | 사람이 많아요. · 이 음식이 맛있어요. | 사람이 많**네요**! *({n:คน}{v:เยอะ}{e:จัง})* · 이 음식이 맛있**네요**! *(กินแล้วเพิ่งรู้ว่าอร่อย)* |

- ✓ 저는 학생이에요. *(แนะนำตัวเอง)* / ✗ 저는 학생이**네요**. — เรื่องของตัวเองที่รู้อยู่แล้วใช้ -네요 ไม่ได้ (แต่ ✓ 학생이**네요**. พูดกับคนที่เพิ่งรู้ว่าเขาเป็นนักเรียนได้)
- ✓ 비가 오**네요**. *({n:ฝน}{v:ตก}{e:นี่นา} — มองออกไปนอกหน้าต่างแล้วเห็น)*
- ✓ 벌써 왔**네요**. *({v:มา}{e:แล้วนี่} — ซ้อนอดีต 았/었 + 네요)*
- ✓ 한국어를 잘하**네요**! *({v:พูด}{n:เกาหลี}{a:เก่ง}{e:นะเนี่ย} — เพิ่งได้ยินเขาพูด)*

#### กับดัก
- ใช้เป็นประโยค**บอกเล่า/อุทาน** ห้ามทำเป็นคำถาม · เรื่องที่รู้อยู่แล้วใช้ -아/어요
- ไม่ต้องหา 아/어: ✓ 예쁘네요 / ✗ 예뻐네요 · ✓ 좋네요 / ✗ 좋아네요
- ㄹ-ราก *(เสริม ตำราไม่ได้สอน)*: ㄹ หลุดหน้า ㄴ → 멀다 → **머네요** · 살다 → **사네요** · 힘들다 → **힘드네요** (แต่ 힘들**겠**네요 ไม่หลุด เพราะ 겠 ขึ้นต้นด้วย ㄱ) — เหมือน ㅂ니다 ในข้อ 21 · ดูข้อ 35

#### -네요 vs -(으)ㄹ 거예요 vs -고 있어요
| ใช้เมื่อ | รูป | ตัวอย่าง |
|:---|:---|:---|
| เห็น/ได้ยินแล้วอุทานทันที | **-네요** | 가: 이 전자사전은 22만 원입니다. — 나: 비싸**네요**. *(...{v:แพง}{e:จัง})* |
| เดาสิ่งที่ยังไม่รู้ (ข้อ 28) | -(으)ㄹ 거예요 | 이 사전은 비쌀 거예요. *(พจนานุกรมเล่มนี้คงแพง — เดาโดยยังไม่เห็นราคา)* |
| บอกว่าตัวเองกำลังทำ (ข้อ 32) | -고 있어요 | 가: 아침에 테니스를 배워요. — 나: 저도 배우**고 있어요**. ✓ (✗ 배우네요) |

> [!TIP]
> **เห็น/ได้ยิน/ลองตรงหน้าแล้วเพิ่งรู้ → -네요 · บอกเรื่องที่รู้อยู่แล้ว → -아/어요**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- **ข้อสอบรวม 5~21과:** Q31 `이 전자사전은 22만 원입니다.` → ตอบ **비싸네요** (✗ 비쌀 거예요 · ✗ 비싸세요 เพราะยกย่องสิ่งของไม่ได้) · Q29 `저도 ( )` → 배우고 있어요 (✗ 배우네요) — เฉลยในไฟล์เป็นการแก้เอง ไม่ใช่เฉลยครู
- **ชีตฟัง 본문 듣기 20과 (ช่อง B):** เติม **많네요** (사람들이 많네요) · ใบฟัง 20-2 มี 친절하네요 อยู่ในบทพูดของ 이리나
- **복습시험② (14–20과) · 중간시험:** 20과 อยู่ในขอบเขตทั้งสอง — ยังไม่มีบันทึกว่าเคยผิดเรื่อง -네요 (ข้อที่ต้องระวังคือใช้ผิดสถานการณ์ ไม่ใช่ผันผิด)
