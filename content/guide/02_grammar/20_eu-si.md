## 20. -(으)시- · -(으)세요 (ยกย่องผู้ใหญ่ที่เป็นประธาน)

> [!INTRO] ข้อนี้คืออะไร
> -(으)시- คือส่วนแทรกท้ายรากศัพท์ที่**ยกย่อง "ประธาน"** ของประโยค ได้แก่ผู้ใหญ่ที่เราพูดถึง หรือผู้ใหญ่ที่เรากำลังคุยด้วย เช่น พ่อแม่ ปู่ย่า และครู ใช้ได้กับกริยา คำคุณศัพท์ และ N+이다 รูปที่เจอบ่อยที่สุดคือ -(으)세요 เช่น 아버지가 회사에 가세요 *(คุณพ่อไปบริษัท)*
>
> สอนในบท 15 (ตำราหน้า 138 และใบฝึก 15과) ส่วนรูปทางการ -(으)십니다 สอนในบท 16 และ **께서** ซึ่งเป็นประธานแบบยกย่องเจอครั้งแรกในบท 20 ในข้อนี้จะเจอกฎการผัน คำยกย่องพิเศษ ความต่างระหว่าง 계세요 กับ 있으세요 และคำเรียกครอบครัว
>
> ต่อยอดจาก ข้อ 06 (-아/어요), ข้อ 02 (N이에요) และ ข้อ 18 (คำคุณศัพท์) แล้วไปใช้ต่อใน ข้อ 21 (-(으)십니다), ข้อ 22 (-(으)시겠-), ข้อ 23 (-(으)셨-), ข้อ 29 (께 และ 께서) และ ข้อ 32 (-고 계시다)

### 📌 รูปแบบและเงื่อนไข

-(으)시- ไม่ใช่คำลงท้ายประโยค แต่เป็นชิ้นที่แทรกระหว่างรากกับคำลงท้าย ตอนนี้จะดูว่ามันประกอบกันอย่างไร ผันตามตัวสะกดอย่างไร และมีคำยกย่องพิเศษอะไรบ้างที่ต้องจำเป็นคำ

#### -(으)시- เป็นชิ้นแทรก

ใช้จบประโยคเองไม่ได้ ต้องแทรกหลังรากแล้วตามด้วยคำลงท้ายปกติ — **-세요 คือ 시 + 어요 ที่หดเสียงแล้ว**

```
가다  →  가 + 시 + 어요  →  가셔요  →  가세요
```

ตารางนี้ดูว่า 시 ไปรวมกับคำลงท้ายแต่ละแบบแล้วได้รูปอะไร

| ส่วนประกอบ | ได้รูป | 한국어 | ไทย |
|:---|:---|:---|:---|
| 시 + 어요 | **-세요** | 아버지가 회사에 가**세요**. | คุณพ่อไปบริษัท |
| 시 + ㅂ니다 | **-십니다** | 아버지가 회사에 가**십니다**. | คุณพ่อไปบริษัท (ทางการ — ข้อ 21) |
| 시 + 었어요 | **-셨어요** | 아버지가 회사에 가**셨어요**. | คุณพ่อไปบริษัทแล้ว (อดีต — ข้อ 23) |
| 시 + 겠습니까 | **-시겠습니까** | 무엇을 드시**겠습니까**? | {e:จะ}{V:รับ}{q:อะไร}ดีครับ (ข้อ 22) |

#### 📽️ กฎการผัน (สไลด์อาจารย์ 교과서 138쪽 + ใบฝึก 15과 B)

ขั้นตอนตามสไลด์คือ ตัด 다 → ดูตัวสะกดของพยางค์สุดท้าย → ใส่ 시 หรือ 으시 (คำนามใส่ 시 หรือ 이시) แล้วค่อยต่อ 어요 จะได้ **-세요** ตารางแรกเป็นกริยาและคำคุณศัพท์

| ตัวสะกด | ราก + (으)시다 | + 어요 |
|:---|:---|:---|
| ไม่มี → **-시다** | 가시다 | 가**세요** |
| ไม่มี → **-시다** | 오시다 | 오**세요** |
| ไม่มี → **-시다** | 크시다 | 크**세요** |
| ไม่มี → **-시다** | 친절하시다 | 친절하**세요** |
| มี → **-으시다** | 입으시다 | 입**으세요** |
| มี → **-으시다** | 읽으시다 | 읽**으세요** |
| มี → **-으시다** | 작으시다 | 작**으세요** |
| มี → **-으시다** | 많으시다 | 많**으세요** |

ส่วน N + 이다 ใช้ (N)시다 เมื่อ N ไม่มีตัวสะกด และ (N)**이**시다 เมื่อมีตัวสะกด

| N ลงท้าย | ราก + (이)시다 | + 어요 |
|:---|:---|:---|
| ไม่มีตัวสะกด | (N)시다: 할아버지시다 · 아버지시다 · 의사시다 | 아버지**세요** · 의사**세요** · 누구**세요** |
| มีตัวสะกด | (N)**이**시다: 선생님이시다 · 회사원이시다 | 선생님**이세요** · 회사원**이세요** |

#### เกร็ดการผันที่ต้องรู้

นอกจากกฎหลักข้างบน ยังมีเรื่องที่ต้องระวังตอนผัน ตั้งแต่ราก 하다 ไปจนถึงลำดับของชิ้นส่วนและการใช้เป็นคำขอร้อง

- 하다 ลงท้ายสระ จึงเป็น -하세요: 일하다 → 일하**세요** · 가르치다 → 가르치**세요**
- โครงสร้างคือ `[ผู้ใหญ่] + 이/가 + [ราก]-(으)세요`
- ใช้กับคำคุณศัพท์ได้ด้วย
  - 아버지가 키가 크**세요** *(คุณพ่อตัวสูง)*
  - 멋있**으세요** *(หล่อ)*
- ปฏิเสธได้สองแบบ (ข้อ 08 · 16)
  - 안 가세요 *(ไม่ไป)*
  - 가지 않으세요 *(ไม่ไป)*
- ลำดับชิ้นส่วน: **-(으)시- มาก่อน -겠- / -았/었-**
  - 드시**겠**습니까 *(จะรับ…ไหม — ข้อ 22)*
  - 가시+었 → 가**셨**어요 *(ท่านไปแล้ว — ข้อ 23)*
- -(으)세요 ที่ประธานคือ "คุณ" ใช้เป็น**คำขอร้อง/เชิญ**ได้ด้วย
  - 저녁에 밥 먹으러 우리 집에 오**세요**. *(เย็นนี้มากินข้าวที่บ้านเรานะ — 교과서 164쪽)*
  - 주**세요** *(ขอ…หน่อย — ข้อ 14)*
- (เสริม) ราก ㄹ ตัด ㄹ ก่อน 시: 살다 → 사세요 · 만들다 → 만드세요 — ตำรา 5–22과 ไม่มีตัวอย่าง (กฎเดียวกับ ㅂ니다 ข้อ 21)

#### คำยกย่องพิเศษ

คำกลุ่มนี้ต้องจำเป็นคำ ไม่ใช่เอาคำปกติมาใส่ 세요 ตำรา 138쪽 และสไลด์อาจารย์ให้ไว้ ครูเน้นว่าข้อที่มีดาว (★) ในใบฝึกจะออกสอบ

| ปกติ | ยกย่อง | ตัวอย่าง |
|:---|:---|:---|
| ★ 있다 (คน**อยู่**ที่…) | **계시다** · ไม่อยู่ = **안 계시다** | 부모님이 어디에 **계세요**? *(พ่อแม่อยู่ที่ไหน)* |
| ★ 먹다 · 마시다 | **드시다** (ตำราเพิ่ม **잡수시다** ของ 먹다) | 과일을 **드세요**. *(ทานผลไม้)* |
| ★ 자다 | **주무시다** | 할머니가 **주무세요**. *(คุณย่านอน)* |
| 말하다 | **말씀하시다** | 선생님이 **말씀하세요**. *(อาจารย์พูด)* |
| ★ 사람 | **분** (이분 = ท่านนี้) | 이분이 누구세요? *(ท่านนี้คือใคร)* |
| 이름 · 나이 · 말 | **성함 · 연세 · 말씀** | 성함이 어떻게 되세요? *(สำนวนเสริม ขอชื่อผู้ใหญ่)* |
| (เสริม) 생일 | **생신** | 할머니 생신 *(วันเกิดคุณย่า — อยู่ในสมุดงาน 20과 D3)* |
| (เสริม) 집 | **댁** | 선생님 댁 *(บ้านอาจารย์)* |

#### 계세요 vs 있으세요

ดูว่า 있다 หมายถึง "อยู่" หรือ "มี" **계시다 แทนได้แค่ความหมาย "อยู่" (คน + 에)** ส่วน "มี" ใช้ 있으시다 (ใบฝึก 15과 E: 이/가 있다 → 있으세요 · 없다 → 없으세요)

| ความหมาย | ธรรมดา | ยกย่อง | ตรงข้าม |
|:---|:---|:---|:---|
| **อยู่** (ที่ไหน — มี 에) | 있어요 | **계세요** | **안 계세요** |
| **มี** (เป็นเจ้าของ) | 있어요 | **있으세요** | **없으세요** |

| 한국어 | ไทย | ใช้ |
|:---|:---|:---|
| 할머니가 집에 **계세요**. | คุณยายอยู่ที่บ้าน | อยู่ → 계세요 |
| 할머니가 돈이 **있으세요**. | คุณยายมีเงิน | มี → 있으세요 |
| ✗ 할머니가 돈이 계세요 | (ผิด) "มี" ใช้ 계세요 ไม่ได้ | ต้องใช้ 있으세요 |
| 선생님이 사무실에 **안 계세요**. | {n:อาจารย์}{x:ไม่}{v:อยู่}{n:ห้องทำงาน} | อยู่ (ปฏิเสธ) → 안 계세요 |
| 선생님이 시간이 **없으세요**. | อาจารย์ไม่มีเวลา | มี (ปฏิเสธ) → 없으세요 |

> [!TIP] เลือกใน 1 วินาที
> ประโยคมี `에` (ที่…) → **계세요** · ไม่มี `에` (มี…) → **있으세요** · `안녕히 계세요` ก็คือ 계세요 "อยู่" (พูดกับคนที่อยู่ต่อ)

#### คำเรียกครอบครัว

คำศัพท์บท 15 ที่ 매일시험 15 ข้อ A ถามคำเหล่านี้ พ่อแม่และปู่ย่าเป็นผู้ใหญ่ จึงใช้ -(으)세요 ส่วนน้องไม่ต้องยกย่อง

| ไทย | เรียก | หมายเหตุ |
|:---|:---|:---|
| พ่อ · แม่ · พ่อแม่ | 아버지 · 어머니 · 부모님 | ผู้ใหญ่ → ใช้ -(으)세요 |
| ปู่-ย่า | 할아버지 · 할머니 | ผู้ใหญ่ → ใช้ -(으)세요 |
| ตา-ยาย (ฝั่งแม่ใส่ 외) | 외할아버지 · 외할머니 | ผู้ใหญ่ → ใช้ -(으)세요 |
| พี่ชาย | **형** (ผู้ชายเรียก) · **오빠** (ผู้หญิงเรียก) | ผู้พูดเป็นชายหรือหญิง เรียกต่างกัน |
| พี่สาว | **누나** (ผู้ชายเรียก) · **언니** (ผู้หญิงเรียก) | ผู้พูดเป็นชายหรือหญิง เรียกต่างกัน |
| น้องชาย · น้องสาว | 남동생 · 여동생 | ไม่ต้องยกย่อง |
| อายุ | ~살 (เลขแท้): 열네 살 *(14 ปี)* | 몇 살이에요? *(อายุเท่าไร — ข้อ 04)* |
| จำนวนคน | ~명: 언니가 한 명 있어요 *(มีพี่สาวหนึ่งคน)* | ไม่มี: 언니가 없어요 *(ไม่มีพี่สาว)* |

#### 📽️ ฝึกจากสไลด์อาจารย์ (บท 16) — ทางการ + ยกย่อง = -(으)십니다

ในบท 16 ครูให้เอา -(으)시- ไปรวมกับรูปทางการ -ㅂ니다 ตารางแรกเทียบสองแกนคือระดับความเป็นทางการกับผู้ที่ถูกพูดถึง ตารางถัดไปแสดงการผันของรูปใหม่

| | คุยทั่วไป (บท 11) | ทางการ (บท 16) |
|:---|:---|:---|
| พูดถึงคนทั่วไป | -아/어/여요 → 가요 | -(스)ㅂ니다 / -(스)ㅂ니까? → 갑니다 |
| พูดถึงผู้ใหญ่ | -(으)세요 (บท 15) → 가세요 | **-(으)십니다 / -(으)십니까?** → **가십니다** |

| ลักษณะราก | ราก | -(으)십니다 |
|:---|:---|:---|
| ไม่มีตัวสะกด → **-십니다** | 가다 | 가십니다 |
| ไม่มีตัวสะกด → **-십니다** | 가르치다 | 가르치십니다 |
| ไม่มีตัวสะกด → **-십니다** | 크다 | 크십니다 |
| ไม่มีตัวสะกด → **-십니다** | 친절하다 | 친절하십니다 |
| มีตัวสะกด → **-으십니다** | 씻다 | 씻으십니다 |
| มีตัวสะกด → **-으십니다** | 읽다 | 읽으십니다 |
| มีตัวสะกด → **-으십니다** | 작다 | 작으십니다 |
| มีตัวสะกด → **-으십니다** | 많다 | 많으십니다 |
| คำยกย่องพิเศษ + 십니다 | 자다 | **주무십니다** |
| คำยกย่องพิเศษ + 십니다 | 먹다 · 마시다 | **드십니다** |
| คำยกย่องพิเศษ + 십니다 | 있다 | **계십니다** |
| คำยกย่องพิเศษ + 십니다 | 없다 | **안 계십니다** |

|:---|:---|:---|
| 아버지는 책을 읽**으십니다**. | คุณพ่ออ่านหนังสือ | ตำรา 144쪽 |
| 김 선생님이 한국어를 가르치**십니다**. | ครูคิมสอนภาษาเกาหลี | ตำรา 144쪽 |

#### 께서 — ประธานผู้ใหญ่แบบยกย่อง

ในบท 15 ใช้ **이/가 + -(으)세요** แต่ตั้งแต่บท 20 ตำราใช้ **께서** แทน 이/가 (ไม่แยกตัวสะกด) และกริยาต้องมี -(으)시- ตามเสมอ ดูข้อ 29 ประกอบ

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 선생님**께서** 사무실에 전화를 하**십니다**. | อาจารย์โทรไปสำนักงาน | 교과서 178쪽 |
| 어머니**께서는** 일을 하고 **계십니다**. | คุณแม่กำลังทำงานอยู่ | 21과 190쪽 |
| 부모님**께서** 저한테 전화를 하**셨어요**. | พ่อแม่โทรหาฉัน | สมุดงาน 20과 G |

ต้องแยกให้ออกว่า **께서** = ผู้กระทำ (แทน 이/가) ส่วน **께** = ผู้รับ (แทน 에게/한테 และใช้กับกริยา 드리다)

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 할머니**께** 선물을 **드렸어요**. | {V:มอบ}{n:ของขวัญ}{p:ให้}{n:คุณย่า} | ตัวอย่างของ 께 |

### ⚠️ จุดสับสน

-(으)시- กับ -아/어요 อยู่คนละแกนกัน -아/어요 กับ -ㅂ니다 บอกระดับความเป็นทางการ ส่วน -(으)시- ยกย่อง**ประธาน** สองแกนนี้ซ้อนกันได้ตามตาราง 2×2 ข้างล่าง ข้อสำคัญคือ พูด**กับ**อาจารย์ใช้ -아/어요 ก็สุภาพพอ แต่พูด**ถึง**อาจารย์ (หรือถามอาจารย์ว่า "ท่าน…ไหม") ต้องใส่ 시

| | -아/어요 | -ㅂ니다 |
|:---|:---|:---|
| ไม่ยกย่อง | 가요 | 갑니다 |
| ยกย่อง (시) | 가세요 | 가십니다 |

ข้อผิดที่เจอบ่อยสรุปเป็นคู่ ✓ / ✗ ได้ตามตารางนี้

| สถานการณ์ | ✓ ถูก | ✗ ผิด | เหตุผล |
|:---|:---|:---|:---|
| ยกย่องตัวเอง | 제가 가요 | 제가 가세요 | ห้ามยกย่องตัวเอง |
| ยกย่องสิ่งของ | 할머니가 돈이 있으세요 | 책이 있으세요 · 가방이 예쁘세요 | ไม่ยกย่องสิ่งของ ผู้ถูกยกย่องคือ **คุณยาย** ไม่ใช่ "เงิน" |
| ประธานเป็นอาหาร | 요리가 맛있어요 | 요리가 맛이세요 · 요리가 맛있으세요 | ประธานเป็นอาหาร ไม่ใส่ 시 (15과 C10) |
| ลืม **으** หลังตัวสะกด | 읽으세요 · 받으세요 · 받으십니다 | 읽세요 · 받십니다 | ตัวสะกดแล้วลืม **으** |
| คำพิเศษของ 먹다 | **드세요** | 아버지가 과일을 먹으세요 | ข้อสอบ 15과 B7 ต้องเขียน 드세요 |
| คำพิเศษของ 자다 | **주무세요** | 자세요 | ต้องใช้คำเฉพาะ ไม่ใช่คำปกติ + 세요 |
| คำพิเศษของ 사람 | **분** | 사람 | ต้องใช้คำเฉพาะ ไม่ใช่คำปกติ |

#### กับดัก

- ✗ 친구가 가세요 — เพื่อนและน้องไม่ต้องยกย่อง (ยกย่องเฉพาะผู้ใหญ่ที่เป็นประธาน)
- ผู้ใหญ่ที่ใช้คำพิเศษ ต้องใช้คำเฉพาะ ไม่ใช่คำปกติ + 세요 เช่น 드세요 · 주무세요 · 분
- 재미있다 · 멋있다 ไม่เปลี่ยนเป็น 계시다 เพราะเป็นคำคุณศัพท์ที่ลงท้าย 있다 → 재미있**으**세요 · 멋있**으**세요

> [!TIP] กฎสั้น ๆ
> ยกย่องเฉพาะ**ผู้ใหญ่ที่เป็นประธาน** ไม่ใช่ตัวเอง เพื่อน น้อง หรือสิ่งของ และถ้ารากมีตัวสะกดต้องมี **으**
>
> คำพิเศษ: 먹다 → 드세요 · 자다 → 주무세요 · 있다 (อยู่) → 계세요

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

-(으)시- ออกสอบแล้วใน 매일시험 15 และครูเน้นว่าข้อที่มีดาวในใบฝึกจะออกสอบ ผู้เรียนทำได้ดีกับคำพิเศษ แต่พลาดเรื่องการลืม 으 และการผสมรูป

- **매일시험 15 (10/10) = 8.5/10**
  - B5–7 ใช้ -(으)세요 (가르치세요 · 읽으세요 · **드세요**)
  - C9 "고향에 **계세요**" (−0.5 ㅎ ใน 향 ลายมือ)
  - C10 "요리가 맛있어요" (เขียน 맛이세요 −0.5 — อาหารไม่ใส่ 시)
- **ใบฝึก 15과**
  - C10 ตอบ **사람** แทน **분** ⚠️
  - เขียน **읽세요** (ลืม 으)
  - ครูทำ ★ ที่ 자다 · 먹다 · 마시다 และที่ 있다 · 사람 พร้อมตาราง E ทั้งตาราง
  - ครูบอกว่า **จะออกสอบ** (และ 매일시험 15 ก็ออก 드세요 ข้อ B7 กับ 계세요 ข้อ C9 แล้ว)
- **ตระกูล "ลืม 으 / ผสมรูป"**
  - 받십니다 (พลาด 2 ครั้ง — ใบฝึก 16과 B และฉบับที่ทำซ้ำ)
  - 합니까 ที่ควรเป็น **하십니까** (매일시험 16 A1 ครูให้เต็มแต่ต้นฉบับมี 시)
  - 빌렸십니다 ✗ → **빌리셨습니다** (สมุดงาน 20과 — ผสม 셨 กับ 십니다)
- **ทำได้ดีอยู่แล้ว** คือ 드세요 · 주무세요 · 계세요 เก็บแต้มได้แน่
- **복습시험② (14–20과 · เก็ง)** ออกในรูปบทอ่านและตารางผัน
  - 읽기 15-2: 아버지가 할머니 옆에 계세요 *(คุณพ่ออยู่ข้างคุณย่า)*
  - 읽기 15-2: 어머니는 중국어를 가르치세요 *(คุณแม่สอนภาษาจีน)*
  - 쓰기 ③ ตารางผัน 4 รูป (갑니다 · 가세요 · 갈 거예요 ฯลฯ)

### 🔗 เชื่อมโยง

ข้อนี้ต่อจากการผัน -아/어요 และเป็นฐานของรูปทางการ อดีต และประธานแบบ 께서 ในข้อถัดไป

← ต่อยอดจาก

- ข้อ 06 รากเดียวกับ -아/어요
- ข้อ 18 คำคุณศัพท์ใส่ -(으)세요 ได้
- ข้อ 02 N이에요/예요 → N(이)세요
- ข้อ 05 N에 있어요 → N에 계세요
- ข้อ 04 몇 살 → ผู้ใหญ่ใช้ 연세

→ ใช้ต่อใน

- ข้อ 21 시 + ㅂ니다 = -(으)십니다 (บท 16)
- ข้อ 22 드시겠습니까
- ข้อ 23 가셨어요
- ข้อ 29 께 + 드리다 และ 께서 (บท 20)
- ข้อ 32 -고 있다 → -고 계시다 (บท 21)

> [!SUMMARY] สรุป
> - -(으)시- ยกย่อง**ประธานที่เป็นผู้ใหญ่**เท่านั้น: ไม่มีตัวสะกด → -세요 · มีตัวสะกด → -으세요 · N → N(이)세요
> - ลำดับชิ้นส่วนคือ ราก + 시 + (겠/었) + คำลงท้าย เช่น 드시겠습니까 · 가셨어요 · 가십니다
> - คำพิเศษที่ต้องจำ: 있다 (อยู่) → 계세요 · 있다 (มี) → 있으세요 · 사람 → 분
> - คำพิเศษของการกิน/นอน: 먹다 · 마시다 → 드세요 และ 자다 → 주무세요
> - ห้ามยกย่องตัวเอง เพื่อน น้อง หรือสิ่งของ และอย่าลืม **으** หลังตัวสะกด
> - ตั้งแต่บท 20 ประธานผู้ใหญ่ใช้ **께서** และกริยาต้องมี -(으)시- ตามเสมอ
