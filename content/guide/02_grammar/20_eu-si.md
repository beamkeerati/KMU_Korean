## 20. -(으)시- · -(으)세요 (ยกย่องผู้ใหญ่ที่เป็นประธาน)
**-(으)시-** คือส่วนแทรกท้ายรากศัพท์ที่ **ยกย่อง "ประธาน"** ของประโยค (ผู้ใหญ่ที่พูดถึง หรือผู้ใหญ่ที่เรากำลังคุยด้วย เช่น พ่อแม่ ปู่ย่า ครู) ใช้กับกริยา คำคุณศัพท์ และ N+이다 · **สอนในบท 15** (교과서 138쪽 + ใบฝึก 15과) · รูปทางการ -(으)십니다 สอนในบท 16 · **께서** เจอครั้งแรกในบท 20
ต่อยอดจาก ข้อ 06 (-아/어요) · ข้อ 02 (N이에요) · ข้อ 18 (คำคุณศัพท์) · ใช้ต่อใน ข้อ 21 (-(으)십니다) · ข้อ 22 (-(으)시겠-) · ข้อ 23 (-(으)셨-) · ข้อ 29 (께 · 께서) · ข้อ 32 (-고 계시다)

### 📌 รูปแบบและเงื่อนไข
#### 0) -(으)시- ไม่ใช่คำลงท้าย แต่เป็นชิ้นแทรก
ใช้จบประโยคเองไม่ได้ ต้องแทรกหลังรากแล้วตามด้วยคำลงท้ายปกติ — **-세요 คือ 시 + 어요 ที่หดเสียงแล้ว**

```
가다  →  가 + 시 + 어요  →  가셔요  →  가세요
```

| 시 + คำลงท้าย | ได้รูป | ตัวอย่าง |
|:---|:---|:---|
| 시 + 어요 | **-세요** | 아버지가 회사에 가**세요**. *(คุณพ่อไปบริษัท)* |
| 시 + ㅂ니다 | **-십니다** | 아버지가 회사에 가**십니다**. *(ทางการ — ข้อ 21)* |
| 시 + 었어요 | **-셨어요** | 아버지가 회사에 가**셨어요**. *(อดีต — ข้อ 23)* |
| 시 + 겠습니까 | **-시겠습니까** | 무엇을 드시**겠습니까**? *(ข้อ 22)* |

#### 1) กฎการผัน
📽️ **สไลด์อาจารย์ (교과서 138쪽) + ใบฝึก 15과 B** — ขั้นตอน: ตัด 다 → ดูตัวสะกดของพยางค์สุดท้าย → ใส่ 시 / 으시 (คำนามใส่ 시 / 이시) แล้วค่อยต่อ 어요 → **-세요**

| ลงท้าย | ไม่มีตัวสะกด → **-시다** → **-세요** | มีตัวสะกด → **-으시다** → **-으세요** |
|:---|:---|:---|
| กริยา · คำคุณศัพท์ | 가시다 · 오시다 · 크시다 · 친절하시다 → 가**세요** · 오**세요** · 크**세요** · 친절하**세요** | 입으시다 · 읽으시다 · 작으시다 · 많으시다 → 입**으세요** · 읽**으세요** · 작**으세요** · 많**으세요** |
| N + 이다 | (N)시다: 할아버지시다 · 아버지시다 · 의사시다 → 아버지**세요** · 의사**세요** · 누구**세요** | (N)**이**시다: 선생님이시다 · 회사원이시다 → 선생님**이세요** · 회사원**이세요** |

* 하다 ลงท้ายสระ จึงเป็น -하세요: 일하다 → 일하**세요** · 가르치다 → 가르치**세요**
* โครงสร้าง `[ผู้ใหญ่] + 이/가 + [ราก]-(으)세요` · ใช้กับคำคุณศัพท์ได้ (아버지가 키가 크**세요** · 멋있**으세요**) · ปฏิเสธ: 안 가세요 · 가지 않으세요 (ข้อ 08 · 16)
* ลำดับ: **-(으)시- มาก่อน -겠- / -았/었-** → 드시**겠**습니까 · 가시+었 → 가**셨**어요
* -(으)세요 ที่ประธานคือ "คุณ" ใช้เป็น **คำขอร้อง/เชิญ** ได้ด้วย: 저녁에 밥 먹으러 우리 집에 오**세요**. *(เย็นนี้มากินข้าวที่บ้านเรานะ — 교과서 164쪽)* · 주**세요** *(ขอ…หน่อย — ข้อ 14)*
* (เสริม) ราก ㄹ ตัด ㄹ ก่อน 시: 살다 → 사세요 · 만들다 → 만드세요 — ตำรา 5–22과 ไม่มีตัวอย่าง (กฎเดียวกับ ㅂ니다 ข้อ 21)

#### 2) คำยกย่องพิเศษ (ตำรา 138쪽 + สไลด์ · ครูเน้นว่าข้อที่มีดาวในใบฝึกออกสอบ)
| ปกติ | ยกย่อง | ตัวอย่าง |
|:---|:---|:---|
| ★ 있다 (คน**อยู่**ที่…) | **계시다** · ไม่อยู่ = **안 계시다** | 부모님이 어디에 **계세요**? *(พ่อแม่อยู่ที่ไหน)* |
| ★ 먹다 · 마시다 | **드시다** (ตำราเพิ่ม **잡수시다** ของ 먹다) | 과일을 **드세요**. *(ทานผลไม้)* |
| ★ 자다 | **주무시다** | 할머니가 **주무세요**. *(คุณย่านอน)* |
| 말하다 | **말씀하시다** | 선생님이 **말씀하세요**. *(อาจารย์พูด)* |
| ★ 사람 | **분** (이분 = ท่านนี้) | 이분이 누구세요? *(ท่านนี้คือใคร)* |
| 이름 · 나이 · 말 | **성함 · 연세 · 말씀** | 성함이 어떻게 되세요? *(สำนวนเสริม ขอชื่อผู้ใหญ่)* |
| (เสริม) 생일 · 집 | **생신 · 댁** | 할머니 생신 · 선생님 댁 (생신 อยู่ในสมุดงาน 20과 D3) |

#### 3) 계세요 vs 있으세요 — ดูว่า 있다 หมายถึง "อยู่" หรือ "มี"
**계시다 แทนได้แค่ความหมาย "อยู่" (คน + 에)** ส่วน "มี" ใช้ 있으시다 (ใบฝึก 15과 E: 이/가 있다 → 있으세요 · 없다 → 없으세요)

| ความหมาย | ธรรมดา | ยกย่อง | ตรงข้าม |
|:---|:---|:---|:---|
| **อยู่** (ที่ไหน — มี 에) | 있어요 | **계세요** | **안 계세요** |
| **มี** (เป็นเจ้าของ) | 있어요 | **있으세요** | **없으세요** |

* 할머니가 집에 **계세요**. *(คุณยายอยู่ที่บ้าน)* · 할머니가 돈이 **있으세요**. *(คุณยายมีเงิน)* · ✗ 할머니가 돈이 계세요
* 선생님이 사무실에 **안 계세요**. *({n:อาจารย์}{x:ไม่}{v:อยู่}{n:ห้องทำงาน})* · 선생님이 시간이 **없으세요**. *(อาจารย์ไม่มีเวลา)*

> [!TIP]
> **เลือกใน 1 วินาที:** ประโยคมี `에` (ที่…) → **계세요** · ไม่มี `에` (มี…) → **있으세요** · `안녕히 계세요` ก็คือ 계세요 "อยู่" (พูดกับคนที่อยู่ต่อ)

#### 4) คำเรียกครอบครัว (คำศัพท์บท 15 — 매일시험 15 ข้อ A ถามคำเหล่านี้)
| ไทย | เรียก | หมายเหตุ |
|:---|:---|:---|
| พ่อ · แม่ · พ่อแม่ | 아버지 · 어머니 · 부모님 | ผู้ใหญ่ → ใช้ -(으)세요 |
| ปู่-ย่า · ตา-ยาย (ฝั่งแม่ใส่ 외) | 할아버지 · 할머니 · 외할아버지 · 외할머니 | |
| พี่ชาย | **형** (ผู้ชายเรียก) · **오빠** (ผู้หญิงเรียก) | ผู้พูดเป็นชายหรือหญิง เรียกต่างกัน |
| พี่สาว | **누나** (ผู้ชายเรียก) · **언니** (ผู้หญิงเรียก) | |
| น้องชาย · น้องสาว | 남동생 · 여동생 | ไม่ต้องยกย่อง |
| อายุ · จำนวนคน | ~살 (เลขแท้): 열네 살 · ~명: 언니가 한 명 있어요 | 몇 살이에요? (ข้อ 04) · ไม่มี: 언니가 없어요 |

### 📖 ตัวอย่างและการใช้
**ตำรา 교과서 138–143쪽**
1. 가: 어머니가 회사에 가세요? / 나: 네, 어머니가 회사에 가**세요**. *(คุณแม่ไปบริษัทไหม / ไปค่ะ)*
2. 가: 어머니가 지금 뭘 하세요? / 나: 어머니가 버스를 타**세요**. *(คุณแม่ตอนนี้ทำอะไร / ขึ้นรถบัส)* — ฝึกต่อ: 과일을 사**세요** · 텔레비전을 보**세요** · 신문을 읽**으세요** *(ซื้อผลไม้ · ดูทีวี · อ่านหนังสือพิมพ์)*
3. 가: 아버지가 어디에서 일하세요? / 나: 아버지가 회사에서 일하**세요**. *(คุณพ่อทำงานที่ไหน / ที่บริษัท)*
4. 아버지가 키가 크**세요**? · 어머니가 재미있**으세요**? · 부모님이 지금 어디에 **계세요**? *({n:คุณพ่อตัว}{v:สูง}ไหม · {n:คุณแม่}{v:ตลก}ไหม · {n:พ่อแม่}{a:ตอนนี้}{v:อยู่}{q:ที่ไหน})*
5. 대화 15-1: 이분이 누구**세요**? / 아버지**세요**. · 아버지가 멋있**으세요**. *({N:ท่านนี้}{e:คือ}{q:ใคร} / {n:คุณพ่อ}ค่ะ · {n:คุณพ่อ}{v:หล่อ}จัง)*
6. 읽기 15-2: 아버지가 할머니 옆에 **계세요**. 아버지는 경찰관**이세요**. 어머니는 학교에서 중국어를 가르치**세요**. *(คุณพ่ออยู่ข้างคุณย่า คุณพ่อเป็นตำรวจ คุณแม่สอนภาษาจีนที่โรงเรียน)*
7. 요리 ไม่ใส่ 시: 할머니는 요리를 잘하**세요**. 할머니 **요리가** 정말 맛있어요. *(คุณย่าทำอาหารเก่ง · อาหารของคุณย่าอร่อยจริง ๆ)*

#### 📽️ ฝึกจากสไลด์อาจารย์ (บท 16) — ทางการ + ยกย่อง = -(으)십니다
| | คุยทั่วไป (บท 11) | ทางการ (บท 16) |
|:---|:---|:---|
| พูดถึงคนทั่วไป | -아/어/여요 → 가요 | -(스)ㅂ니다 / -(스)ㅂ니까? → 갑니다 |
| พูดถึงผู้ใหญ่ | -(으)세요 (บท 15) → 가세요 | **-(으)십니다 / -(으)십니까?** → **가십니다** |

| ไม่มีตัวสะกด → **-십니다** | มีตัวสะกด → **-으십니다** | คำยกย่องพิเศษ + 십니다 |
|:---|:---|:---|
| 가십니다 · 가르치십니다 · 크십니다 · 친절하십니다 | 씻으십니다 · 읽으십니다 · 작으십니다 · 많으십니다 | 자다 → **주무십니다** · 먹다·마시다 → **드십니다** · 있다 → **계십니다** · 없다 → **안 계십니다** |

*ตัวอย่างตำรา 144쪽:* 아버지는 책을 읽**으십니다**. · 김 선생님이 한국어를 가르치**십니다**. *(ครูคิมสอนภาษาเกาหลี)* — ครูเขียน **드십니다** ด้วยปากกาแดงบนสไลด์ (드시다 + ㅂ니다 → 드십니다)

#### 께서 — ประธานผู้ใหญ่แบบยกย่อง (เจอครั้งแรกในบท 20)
* บท 15 ใช้ **이/가 + -(으)세요** · ตั้งแต่บท 20 ตำราใช้ **께서** แทน 이/가 (ไม่แยกตัวสะกด) และกริยาต้องมี -(으)시- ตามเสมอ — ดูข้อ 29
* 선생님**께서** 사무실에 전화를 하**십니다**. *(อาจารย์โทรไปสำนักงาน — 교과서 178쪽)* · 어머니**께서는** 일을 하고 **계십니다**. *(คุณแม่กำลังทำงานอยู่ — 21과 190쪽)* · 부모님**께서** 저한테 전화를 하**셨어요**. *(พ่อแม่โทรหาฉัน — สมุดงาน 20과 G)*
* **께서** = ผู้กระทำ (แทน 이/가) · **께** = ผู้รับ (แทน 에게/한테 + กริยา 드리다): 할머니**께** 선물을 **드렸어요**. *({V:มอบ}{n:ของขวัญ}{p:ให้}{n:คุณย่า})*

### ⚠️ จุดสับสน
**-(으)시- กับ -아/어요 คนละแกนกัน** — -아/어요 กับ -ㅂ니다 = ระดับความเป็นทางการ ส่วน -(으)시- = ยกย่อง**ประธาน** ซ้อนกันได้ (가요 · 가세요 · 갑니다 · 가십니다) ดูตาราง 2×2 ข้างบน · พูด**กับ**อาจารย์ใช้ -아/어요 ก็สุภาพพอ แต่พูด**ถึง**อาจารย์ (หรือถามอาจารย์ว่า "ท่าน…ไหม") ต้องใส่ 시

- ✗ 제가 가세요 → ✓ 제가 가요 (ห้ามยกย่องตัวเอง) · ✗ 친구가 가세요 (เพื่อน/น้องไม่ต้องยกย่อง)
- ✗ 책이 있으세요 · 가방이 예쁘세요 (ไม่ยกย่องสิ่งของ) แต่ ✓ 할머니가 돈이 있으세요 (ผู้ถูกยกย่องคือ **คุณยาย** ไม่ใช่ "เงิน")
- ✗ 요리가 맛이세요 / 맛있으세요 → ✓ 요리가 맛있어요 (ประธานเป็นอาหาร ไม่ใส่ 시 — 15과 C10)
- ✗ 읽세요 → ✓ 읽으세요 · ✗ 받십니다 → ✓ 받으세요 / 받으십니다 (ตัวสะกดแล้วลืม **으**)
- ผู้ใหญ่ + คำพิเศษ ต้องใช้คำเฉพาะ ไม่ใช่คำปกติ + 세요: ✗ 아버지가 과일을 먹으세요 → ✓ **드세요** (ข้อสอบ 15과 B7 ต้องเขียน 드세요) · ✗ 자세요 → ✓ **주무세요** · ✗ 사람 → ✓ **분**
- 재미있다 · 멋있다 ไม่เปลี่ยนเป็น 계시다 (คือคำคุณศัพท์ที่ลงท้าย 있다) → 재미있**으**세요 · 멋있**으**세요

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- **매일시험 15 (10/10) = 8.5/10:** B5–7 ใช้ -(으)세요 (가르치세요 · 읽으세요 · **드세요**) · C9 "고향에 **계세요**" (−0.5 ㅎ ใน 향 ลายมือ) · C10 "요리가 맛있어요" (เขียน 맛이세요 −0.5 — อาหารไม่ใส่ 시)
- **ใบฝึก 15과:** C10 ตอบ **사람** แทน **분** ⚠️ · เขียน **읽세요** (ลืม 으) · ครูทำ ★ ที่ 자다 · 먹다 · 마시다 · 있다 · 사람 และตาราง E ทั้งตาราง พร้อมบอกว่า **จะออกสอบ** (และ 매일시험 15 ก็ออก 드세요 ข้อ B7 กับ 계세요 ข้อ C9 แล้ว)
- **ตระกูล "ลืม 으 / ผสมรูป":** 받십니다 (พลาด 2 ครั้ง — ใบฝึก 16과 B และฉบับที่ทำซ้ำ) · 합니까 ที่ควรเป็น **하십니까** (매일시험 16 A1 ครูให้เต็มแต่ต้นฉบับมี 시) · 빌렸십니다 ✗ → **빌리셨습니다** (สมุดงาน 20과 — ผสม 셨 กับ 십니다)
- **ทำได้ดีอยู่แล้ว:** 드세요 · 주무세요 · 계세요 — เก็บแต้มได้แน่
- **복습시험② (14–20과 · เก็ง):** 읽기 15-2 (아버지가 할머니 옆에 계세요 · 어머니는 중국어를 가르치세요) และ 쓰기 ③ ตารางผัน 4 รูป (갑니다 · 가세요 · 갈 거예요 ฯลฯ)
