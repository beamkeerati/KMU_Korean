## 16. -지 않다 (ไม่…)
ต่อท้ายรากของ **กริยาและคำคุณศัพท์** เพื่อบอกว่า "ไม่…" ความหมายเดียวกับ 안 · สอนในบท 14 (ครูทบทวน 안 ของบท 12 ไปพร้อมกัน) · ต่อยอดจากข้อ 08 (안) และข้อ 06 (-아/어요) · ใช้ต่อในข้อ 20 (-지 않으세요), ข้อ 21 (-지 않습니다), ข้อ 22 (-지 않겠습니다) และข้อ 23 (-지 않았어요)

### 📌 รูปแบบและเงื่อนไข
**สูตร:** `รากศัพท์ (ตัด 다) + -지 + 않아요` — ส่วนที่ผันคือ **않다** (않 + 아요 = 않아요) ส่วนรากไม่เปลี่ยนรูป และ **ไม่ต้องแยกกฎตามตัวสะกด**

| เงื่อนไข | ปกติ → ปฏิเสธ | ตัวอย่าง |
|:---|:---|:---|
| กริยาทั่วไป (มี/ไม่มีตัวสะกด ใช้ -지 เหมือนกัน) | 가요 → 가**지 않아요** | 마시다 → 마시**지 않아요** · 먹다 → 먹**지 않아요** *(ไม่ดื่ม · ไม่กิน)* |
| กริยา N+하다 (ติดกัน ไม่แยก) | 공부해요 → 공부하**지 않아요** | 운동하지 않아요 · 청소하지 않아요 *(ไม่ออกกำลังกาย · ไม่ทำความสะอาด)* |
| กริยา 하다 คำเดียว | 좋아해요 → 좋아하**지 않아요** | 김치를 좋아하지 않아요 *({x:ไม่}{v:ชอบ}{n:กิมจิ})* |
| คำคุณศัพท์ | 비싸요 → 비싸**지 않아요** | 좋지 않아요 · 재미있지 않아요 · 친절하지 않아요 *({x:ไม่}{v:ดี} · {x:ไม่}{v:สนุก} · {x:ไม่}{v:ใจดี})* |
| **ใช้ไม่ได้กับ** 이다 / 있다 | 이다 → **이/가 아니에요** · 있다 → **없어요** | 학생이 아니에요 · 돈이 없어요 |

* ตำรา (126쪽): ต่อท้ายรากของกริยา/คุณศัพท์ แสดงการปฏิเสธ **ใช้ในภาษาพูดทั่วไป — ระดับเดียวกับ 안** ตำราไม่ได้แบ่งว่า -지 않다 เป็นภาษาเขียนกว่า (ไกด์ฉบับเก่าเขียนว่า "เป็นแบบแผนกว่า" ซึ่งตำราไม่ได้บอก จึงปรับให้ตรงตำรา)
* ผันต่อได้ตามปกติ: -지 **않으**세요 (ยกย่อง) · -지 **않습**니다 (ทางการ) · -지 **않겠**습니다 (ตั้งใจจะไม่…) เช่น 오지 않겠습니다 = จะไม่มา · อดีต → 가지 **않았**어요
* ออกเสียง: 않아요 **[아나요]** · 많아요 [마나요] · 짧아요 [짤바요]

### 📖 ตัวอย่างและการใช้
**ประโยคจากตำรา (126~127쪽)**
1. 저는 커피를 마시**지 않아요**. *(ฉันไม่ดื่มกาแฟ)* · 김치를 먹**지 않아요**. *(ไม่กินกิมจิ)*
2. 토요일에 학교에 가**지 않아요**. *(วันเสาร์ไม่ไปโรงเรียน)* · 지금 공부를 하**지 않아요**. *(ตอนนี้ไม่ได้เรียน)*
3. 오늘 날씨가 좋**지 않아요**. *({a:วันนี้}{n:อากาศ}{x:ไม่}{v:ดี})*
4. 고향 친구는 한국말을 배우**지 않아요**. *(เพื่อนบ้านเกิดไม่ได้เรียนภาษาเกาหลี — บทสนทนา 14-1)* · 교실에서 베트남 말을 하**지 않아요**. *(บทอ่าน 14-2)*

**รูปแบบ "ไม่… แต่…"** — ตอบ 아니요 แล้วปฏิเสธ ตามด้วยสิ่งที่เป็นจริง
* 지금 집에 가요? — 아니요, 집에 가**지 않아요**. 도서관에 가요. *({a:ตอนนี้}{v:กลับ}{n:บ้าน}ไหม — {x:ไม่} {v:ไป}{n:ห้องสมุด})*
* 과일이 비싸요? — 아니요, 비싸**지 않아요**. 싸요. *({n:ผลไม้}{v:แพง}ไหม — {x:ไม่}{v:แพง} {v:ถูก})*
* 커피를 마셔요? — 아니요, 커피를 마시**지 않아요**. 물을 마셔요. *({v:ดื่ม}{n:กาแฟ}ไหม — {x:ไม่} {v:ดื่ม}{n:น้ำ})*

#### 📽️ สไลด์อาจารย์ (교과서 126쪽): 동사 · 형용사 + -지 않다 = 안 + 동사 · 형용사
| ถาม | ตอบ |
|:---|:---|
| 주말에 영화를 봐요? *(สุดสัปดาห์ดูหนังไหม)* | 영화를 보**지 않아요**. 책을 읽어요. *(ไม่ดูหนัง อ่านหนังสือ)* |
| 아침에 운동을 해요? *({p:ตอน}{n:เช้า}{v:ออกกำลังกาย}ไหม)* | 아침에 운동을 하**지 않아요**. 자요. *({x:ไม่}{v:ออกกำลังกาย} {v:นอน})* |
| 가방이 작아요? *(กระเป๋าเล็กไหม)* | 가방이 작**지 않아요**. 커요. *({x:ไม่}{v:เล็ก} {v:ใหญ่})* |
| 오늘 날씨가 어때요? *(วันนี้อากาศเป็นอย่างไร)* | 날씨가 나쁘**지 않아요**. 좋아요. *({x:ไม่}{v:เลว} {v:ดี})* |

สองรูปปฏิเสธเทียบกัน (ตารางของครู):

| ชนิด | ปกติ | 안 + … | -지 않다 |
|:---|:---|:---|:---|
| กริยาทั่วไป | 보다 · 먹다 | 안 봐요 · 안 먹어요 | 보지 않아요 · 먹지 않아요 |
| คำคุณศัพท์ | 크다 · 좋다 | 안 커요 · 안 좋아요 | 크지 않아요 · 좋지 않아요 |
| กริยา N+하다 | 운동하다 · 공부하다 | 운동을 **안** 해요 · 공부를 **안** 해요 | 운동하지 않아요 · 공부하지 않아요 |
| กริยา 하다 คำเดียว | 좋아하다 | **안** 좋아해요 | 좋아하지 않아요 |
| **คุณศัพท์** N+하다 | 친절하다 · 피곤하다 · 조용하다 | **안** 친절해요 · 안 피곤해요 · 안 조용해요 | 친절하지 않아요 · 피곤하지 않아요 · 조용하지 않아요 |

⚠️ ข้อสำคัญจากสไลด์: 하다 **กริยา** แทรก 안 หลังคำนาม (운동을 안 해요) แต่ 하다 **คำคุณศัพท์** วาง 안 ไว้หน้าคำทั้งก้อน (안 친절해요)

### ⚠️ จุดสับสน: 안 vs -지 않다 และการใช้กับอดีต
คนไทยมักคิดว่า 안 กับ -지 않다 ต่างกันที่ความหมาย แต่จริง ๆ **ความหมายเท่ากัน** ต่างกันแค่ตำแหน่งและความยาว ส่วนเรื่องอดีต คนมักสับสนว่า 았/었 ไปติดที่คำไหน

| | 안 | -지 않다 |
|:---|:---|:---|
| ตำแหน่ง | **หน้า**กริยา: 안 가요 | **หลัง**รากศัพท์: 가지 않아요 |
| ระดับภาษา | ภาษาพูดทั่วไป (ตำรา) | ภาษาพูดทั่วไป (ตำรา) |
| 하다-กริยา (N+하다) | **안 แทรกกลาง** 공부 안 해요 | **ไม่แยก** 공부하지 않아요 |
| 이다 | ✗ 학생이 안 이에요 | ✗ 학생이지 않아요 → **학생이 아니에요** ✓ |
| อดีต | 안 갔어요 (ผัน 았 ที่กริยา) | 가지 **않았**어요 (ผัน 았 ที่ **않**) |

* ✓ 어제 학교에 안 갔어요. = ✓ 어제 학교에 가지 않았어요. *({a:เมื่อวาน}{x:ไม่ได้}{v:ไป}{n:โรงเรียน})*
* ✓ 아침을 먹지 않았어요. *({x:ไม่ได้}{v:กิน}{n:ข้าวเช้า})* / ✗ 아침을 먹았지 않아요 (ห้ามใส่ 았 ก่อน 지)
* ✓ 한국 음식을 좋아하지 않아요. *({x:ไม่}{v:ชอบ}{n:อาหารเกาหลี})* / ✗ 좋아 안 해요
* ✓ 저는 의사가 아니에요. *(ฉันไม่ใช่หมอ)* / ✗ 의사지 않아요
* ✗ 공부 하지 않아요 (แยกคำ) → ✓ **공부하지 않아요** (ติดกัน)
* ปฏิเสธ 있다 (มี) ระดับนี้ใช้ **없다** ตรง ๆ: ✓ 돈이 없어요 / ✗ 안 있어요

> [!TIP]
> ลำดับในอดีตคือ **รากศัพท์ + 지 + 않 + 았 + 어요** — ส่วน **않** เป็นตัวรับ 았 เสมอ (가지 않았어요) ไม่ใช่ตัวกริยาหลัก · ข้อสอบที่สั่งให้ตอบด้วย -지 않아요 ต้องตอบรูปนี้ (ไม่ใช้ 안)

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
* **매일시험 14과 B** (ข้อ 11–13 · ข้อละ 1): "ตอบปฏิเสธด้วย -지 않아요" → 머리가 짧지 않아요 · 커피를 마시지 않아요 · 지금 공부하지 않아요 — **ถูกทั้ง 3 ข้อ** (รูป -지 않- เป็นจุดแข็ง)
* **워크북 14과:** C ตารางผัน (กริยา 9 + คุณศัพท์ 9) · D บทสนทนา 5 ข้อ · E ภาพ 6 ข้อ (E4–E5 ต้องแต่งคำถามของ 가 เอง: 키가 작아요? · 옆방이 조용해요?)
* **중간시험 복습문제 ข้อ 9** (ชีตที่ครูแจก): ตอบ 2 แบบคู่กัน — 마시지 않아요 / 안 마셔요 · 크지 않아요 / 안 커요 · 좋아하지 않아요 / 안 좋아해요 · 운동하지 않아요 / 운동 안 해요
* **복습시험 ②:** 읽기 14-2 (지훈 · 투이) เป็นชุดสำรอง มี -지 않아요 หลายที่ · ระวังประโยคแวดล้อมที่เคยพลาดใน 14과: 피곤나요 ✗ → 피곤해요 (매일시험 14과 A6)
