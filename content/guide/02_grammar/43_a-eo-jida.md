## 43. -아/어/여지다 (…ขึ้น / กลายเป็น… — การเปลี่ยนสภาพของคำคุณศัพท์)

> [!INTRO] ข้อนี้คืออะไร
> -아/어/여지다 ต่อท้ายรากของ**คำคุณศัพท์** เพื่อบอกว่าสภาพนั้น**ค่อย ๆ เปลี่ยนไป** เช่น 덥다 *(ร้อน)* → 더워**졌**어요 *(ร้อนขึ้นแล้ว)* รูปอดีต **-졌어요** คือรูปที่เจอบ่อยที่สุด
>
> สอนในบท 27 (ตำรา 270–271쪽 준비 1) ต่อยอดจากข้อ 18 (คำคุณศัพท์) ข้อ 06 (-아/어요 ตามสระ) ข้อ 37 (ㅂ 불규칙) และข้อ 41 (어제보다) แล้วไปใช้ต่อในข้อ 44 (บทเดียวกัน -는) ข้อ 38 (예뻐지고 싶어요) ข้อ 55 (-(으)면 + 더워지면) และข้อ 32 (-고 있다: 더워지고 있어요)

### 📌 รูปแบบและเงื่อนไข

ตำรา 270쪽 บอกว่าต่อหลังคำคุณศัพท์เพื่อบอกว่า**สภาพที่พูดถึงค่อย ๆ เปลี่ยน** ถ้าพยางค์สุดท้ายของรากมี **ㅏ หรือ ㅗ** ใช้ **-아지다** ถ้าเป็นสระอื่นใช้ **-어지다** และถ้าลงท้าย **하다** ใช้ **-여지다** ซึ่งย่อเป็น **해지다**

ตารางนี้แยกตามเสียงท้ายของราก ช่องว่างในสองคอลัมน์แรกหมายความว่ายังเป็นกรณีเดียวกับแถวบน

| รากลงท้าย | ต่อ | ตัวอย่าง (…ขึ้น / กลาย…) |
|:---|:---|:---|
| ㅏ · ㅗ | **-아지다** | 맑다 → **맑아졌어요** *(แจ่มใสขึ้น)* |
| | | 좋다 → **좋아졌어요** *(ดีขึ้น)* |
| | | 많다 → **많아졌어요** *(มากขึ้น)* |
| | | 높다 → **높아졌어요** *(สูงขึ้น)* |
| สระอื่น (ㅓ ㅜ ㅣ ㅐ…) | **-어지다** | 흐리다 → **흐려졌어요** *(มืดครึ้มขึ้น)* |
| | | 적다 → **적어졌어요** *(น้อยลง)* |
| | | 길다 → **길어졌어요** *(ยาวขึ้น)* |
| **하다** | **-해지다** | 따뜻하다 → **따뜻해졌어요** *(อุ่นขึ้น)* |
| | | 시원하다 → **시원해졌어요** *(เย็นขึ้น)* |
| | | 깨끗하다 → **깨끗해졌어요** *(สะอาดขึ้น)* |
| | | 쌀쌀하다 → **쌀쌀해졌어요** *(เย็นเฉียบขึ้น)* |
| ㅡ ลงท้าย (ㅡ ตก) | ㅏ/ㅓ ตามสระก่อนหน้า | 예쁘다 → **예뻐졌어요** *(สวยขึ้น)* |
| | | 나쁘다 → **나빠졌어요** *(แย่ลง)* |
| | | 바쁘다 → **바빠졌어요** *(ยุ่งขึ้น)* |
| | | 크다 → **커졌어요** *(ใหญ่ขึ้น)* |
| **ㅂ 불규칙** (ข้อ 37) | ㅂ → 우 + 어 → 워 | 춥다 → **추워졌어요** *(หนาวขึ้น)* |
| | | 덥다 → **더워졌어요** *(ร้อนขึ้น)* |
| | | 어렵다 → **어려워졌어요** *(ยากขึ้น)* |
| | | 쉽다 → **쉬워졌어요** *(ง่ายขึ้น)* |
| | | 어둡다 → **어두워졌어요** *(มืดลง)* |

#### ผันส่วน 지다 เหมือนกริยาปกติ

หลังจากต่อ -아/어지다 แล้ว ผันส่วน 지다 ได้ตามเวลาและแบบประโยคที่ต้องการ

| รูปผัน | ตัวอย่าง | ความหมาย |
|:---|:---|:---|
| -아/어지다 → **져요** | 더워**져요** | ร้อนขึ้น (ทั่วไป มักเป็นอนาคตใกล้) |
| → **졌어요** | 더워**졌어요** | **ร้อนขึ้นแล้ว** (เปลี่ยนไปแล้ว ใช้บ่อยสุด) |
| → **질 거예요** | 더워**질** 거예요 | จะร้อนขึ้น (ข้อ 28) |
| → **지고 있어요** | 더워**지고 있어요** | กำลังร้อนขึ้นเรื่อย ๆ (ข้อ 32) |
| → **졌습니다** | 쌀쌀해**졌습니다** | ทางการ/บทอ่าน (읽기 27-2) |

#### ข้อควรรู้เรื่องเสียงและขอบเขต

ข้อต่อไปนี้เป็นข้อจำกัดที่ตำราบอกไว้ในกล่อง 270쪽

- **ออกเสียง (ตำรา 270쪽):** 맑아졌어요 อ่านว่า [말가졌어요 / 말가져써요] เพราะ ㄹ + ㄱ ต่อเสียงไป และ ㅈ ออกเสียงนุ่ม
- **ตำราให้ใช้กับ "คำคุณศัพท์"** (ตามกล่อง 270쪽) ถ้าต่อกับกริยา 지다 จะมีความหมายอื่น (passive เช่น 만들어지다 — ตำราบทนี้ไม่สอน)

#### คำบอกเวลา/เปรียบเทียบที่มักไปด้วย

การ "เปลี่ยน" ต้องมีจุดเทียบเสมอ จึงมักพบ -아/어지다 คู่กับคำเหล่านี้ (ข้อ 41)

| 한국어 | ไทย |
|:---|:---|
| 어제보다 | กว่าเมื่อวาน |
| 지난주보다 | กว่าสัปดาห์ก่อน |
| 작년보다 | กว่าปีที่แล้ว |
| 장마가 끝나고 | หลังหมดหน้าฝน |
| 그래서 | เพราะฉะนั้น |
| 요즘 | ช่วงนี้ |

### ⚠️ จุดสับสน

จุดที่สับสนมีสองเรื่อง คือแยก "สภาพ" กับ "เปลี่ยนสภาพ" ให้ออก และเลือก 아/어/해 ให้ถูกกับรากแต่ละชนิด

#### สภาพ vs เปลี่ยนสภาพ

สี่รูปนี้ใช้กับคำเดียวกัน แต่บอกเวลาและสถานะต่างกัน

| รูป | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| 더**워요** | **ร้อน** (สภาพตอนนี้) | 오늘 날씨가 더워요. |
| 더워**졌어요** | **ร้อนขึ้นแล้ว** (เทียบกับก่อนหน้า) | 어제보다 더워졌어요. |
| 더워**질 거예요** | **จะร้อนขึ้น** | 내일은 더워질 거예요. *(เสริม — ข้อ 28)* |
| 더워**지고 있어요** | **กำลังร้อนขึ้นเรื่อย ๆ** | 요즘 날씨가 더워지고 있어요. *(เสริม — ข้อ 32)* |

#### กับดักที่เจอบ่อย

กับดักเหล่านี้เป็นข้อผิดที่เกิดจากการเลือก 아/어 การผันรากพิเศษ และการใช้กับชนิดคำที่ไม่ใช่คำคุณศัพท์

- **ใช้กับคำคุณศัพท์:** ตำรา (270쪽) สอนรูปนี้กับ**คำคุณศัพท์**เท่านั้น อย่านำไปต่อกับกริยาเพื่อแปลว่า "…ขึ้น" เช่น ✗ 많이 먹어졌어요 *(อยากบอกว่ากินมากขึ้น)* และเลือก 아/어 ตามสระของราก
- **하다 → 해:** ✗ 시원하졌어요 ✗ 시원했졌어요 → ✓ **시원해졌어요** (하 + 여지다 → 해지다)
- **เลือก 아/어 ตามสระของ "ราก":** ✓ 맑**아**졌어요 · 좋**아**졌어요 แต่ ✗ 맑**어**졌어요 · 좋**어**졌어요
  - ผู้เรียนเคยพลาดเหมือนกัน (살어요 · 받었어요 — ㅏ-ราก + 어 ✗) ท่อง "ㅏ ㅗ → 아"
- **ㅡ ตก:** ✗ 예쁘어졌어요 ✗ 나쁘아졌어요 ✗ 크어졌어요 → ✓ **예뻐졌어요** ✓ **나빠졌어요** ✓ **커졌어요** (ข้อ 06 · 18)
- **ㅂ ไม่ปกติ:** ✗ 덥어졌어요 ✗ 춥아졌어요 → ✓ **더워졌어요** ✓ **추워졌어요** (ข้อ 37)
- **ㅆ ซ้อน:** ✗ 더웠졌어요 → ✓ 더워**졌**어요 (ตัวอดีตอยู่ที่ **졌** ครั้งเดียว)
- **ประธาน + 이/가:** ✗ 날씨를 더워졌어요 → ✓ **날씨가** 더워졌어요 (คำคุณศัพท์ไม่ใช้ 을/를 — ข้อ 18)
- **อย่าขาดจุดเทียบ:** ตอบ 날씨가 어때요? ด้วย 졌어요 เมื่อมีการเปลี่ยน (어제보다 · 장마가 끝나고) ไม่ใช่เมื่อเป็นสภาพนิ่ง ๆ
- **ㅈ/ㅊ:** 졌 = ㅈ (ไม่มีขีดบน) · **지다** อย่าเขียนเป็น **치다** (ตี) ผู้เรียนมักเขียนหัว ㅈ ยื่นเกิน
- **เทียบกับ 되다 (เสริม):** **의사가 되었어요** *(กลายเป็นหมอ — N + 가 되다)* ไม่ใช่ 건강해졌어요 *(สุขภาพดีขึ้น — A + 지다)*

> [!TIP] กฎสั้น ๆ
> - **คำคุณศัพท์ + 아/어/해 + 지다 = "…ขึ้น/กลาย…"**
> - ㅏ ㅗ → 아지다 และอื่น → 어지다 และ 하다 → 해지다 ส่วน ㅡ ตก และ ㅂ → 워
> - อดีต = **졌어요** (ไม่ต้องใส่ 었 อีก)

  - **เหตุ + ผล:** 청소를 했어요. 그래서 방이 ___ . → 깨끗해졌어요 *(ทำความสะอาดแล้ว เลยห้อง… → สะอาดขึ้น)*
  - **เปลี่ยนเป็นทางการ (해요 → 합니다):** 따뜻해졌어요 → 따뜻해졌습니다 *(อุ่นขึ้น — บทอ่านใช้ -습니다)*
  - **ถาม-ตอบสั้น:** 오늘도 더워요? → 아니요, 어제보다 시원해졌어요 *(วันนี้ร้อนอีกไหม — ไม่ เย็นลงกว่าเมื่อวาน)*
- ข้อผิดที่เคยเจอและเกี่ยวกับข้อนี้ (§6b):
  - **살어요 / 살었어요 → 살아요 / 살았어요** (ㅏ-ราก + 어 ผิด)
  - **받었어요 → 받았어요**
  - ㅡ-drop
  - **어때요 vs 어떻게** (ใช้ถามก่อนตอบ 졌어요)
  - ㅈ/ㅊ

> [!SUMMARY] สรุป
> - **คำคุณศัพท์ + -아/어/해지다** = สภาพค่อย ๆ เปลี่ยน ("…ขึ้น/กลาย…") เลือก 아 เมื่อสระท้ายรากเป็น ㅏ ㅗ และ 어 เมื่อเป็นสระอื่น และ 하다 → 해지다
> - ㅡ ตก (예뻐졌어요 · 커졌어요) และ ㅂ → 워 (더워졌어요 · 추워졌어요) อดีตคือ **졌어요** ตัวเดียว ไม่ต้องมี 었
> - สภาพนิ่ง = 더워요 แต่ "ร้อนขึ้นแล้ว" = 더워졌어요 ซึ่งต้องมีจุดเทียบ เช่น 어제보다 หรือ 장마가 끝나고
> - ใช้กับคำคุณศัพท์เท่านั้น ประธานรับ 이/가 และข้อผิดที่เคยเจอคือเลือก 아/어 ผิด (살어요 · 받었어요)
