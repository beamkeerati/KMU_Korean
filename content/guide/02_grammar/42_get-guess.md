## 42. -겠- (คาดเดา: 맛있겠어요 · 재미있었겠어요 — "คงจะ… / ท่าทางจะ…")
ต่อท้ายรากของ **กริยาและคำคุณศัพท์** เพื่อ **เดา/สันนิษฐาน** สถานการณ์หรือสภาพ โดยมี**เบาะแส** (สิ่งที่เห็น ได้ยิน หรือเพิ่งได้รับรู้) — ถ้าเดาเรื่องในอดีตให้ใส่ **-았/었/였-** ก่อน → **-았겠 · -었겠 · -였겠**
สอนในบท 26 (교과서 264쪽 준비 2 · ⚠️ ตำราหน้า 연습 2–3 · 대화 · 활동 · 읽기 ของบท 26 ยังไม่มีในคลัง) · ต่อยอดจาก ข้อ 22 (-겠- ความตั้งใจ = ตำราเรียก -겠-¹) · ข้อ 30 (-네요) · ข้อ 28 (-(으)ㄹ 거예요 เดา)
ใช้ต่อใน ข้อ 62 (-(으)ㄹ게요 — ใช้ ㄹ + 게 คนละเรื่องกับ 겠) · ข้อ 61 · บทอ่าน/บทฟังบท 27–28 (맛있겠네요 · 정말 덥겠어요)

### 📌 รูปแบบและเงื่อนไข
ตำรา 264쪽: ต่อหลังรากกริยาหรือคำคุณศัพท์ ใช้เมื่อประธาน**เดาหรือสันนิษฐาน**บางสถานการณ์ · มักมี**เบาะแส**ของการเดาประกอบ · ถ้าเดาเหตุการณ์**อดีต**ใช้ -았/었/였- ร่วมด้วย กลายเป็น -았겠/었겠/였겠-

| สถานการณ์ | รูป | ตัวอย่าง |
|:---|:---|:---|
| เดา **ปัจจุบัน/อนาคตใกล้** จากสิ่งที่เห็น | ราก + **-겠어요** (ทางการ -겠습니다) | 곧 비가 오**겠어요**. · 맛있**겠어요**. *(เดี๋ยวฝนคงตก · ดูท่าจะอร่อย)* |
| เดา **เรื่องอดีต** | ราก + **-았/었/였겠어요** | 재미있**었겠어요**. · 힘들**었겠어요**. *(คงสนุกแน่ ๆ · คงลำบากน่าดู)* |
| ใช้กับ -네요 (ข้อ 30) | -겠**네요** | 아주 맛있**겠네요**. *(ดูอร่อยจังเลย — 27-2)* |
| ผู้ใหญ่ *(เสริม)* | -(으)시겠어요 · -(으)셨겠어요 | 피곤하**시겠어요**. *(ท่านคงเหนื่อย)* |
| คำถามเดา *(เสริม)* | -겠어요? | 배고프**겠어요**? *(คงหิวนะ)* |

- **ใช้ได้กับทั้งกริยาและคำคุณศัพท์** (ต่างจาก -겠- ความตั้งใจ ข้อ 22 ที่ใช้กับกริยา)
- **ไม่ดูตัวสะกด และไม่ผันก่อน 겠:** 겠 ขึ้นต้นด้วย ㄱ (พยัญชนะ) → **ㅂ อยู่ · ㅡ อยู่ · ㄹ อยู่**: 덥다 → **덥겠어요** · 춥겠어요 *(ไม่ใช่ 더우겠어요)* · 바쁘다 → **바쁘겠어요** *(ไม่ตัด ㅡ)* · 힘들다 → **힘들겠어요**
- **ลำดับ:** `ราก + (으)시 + 았/었 + 겠 + ท้ายประโยค` → 피곤하**셨겠**어요 · 재미있**었겠**어요 *(อดีต -았/었- มาก่อน 겠)*
- **เบาะแส** — ตำราให้ 3 คู่: 하늘이 흐려요 → 곧 비가 오겠어요 · 5시간 동안 청소를 했어요 → 피곤하겠어요 · 작년에 미국 여행을 했어요 → 재미있었겠어요

### 📖 ตัวอย่างและการใช้
#### จากตำรา 26과 (264쪽)
1. 준비 2: 가: 날씨가 많이 흐리네요. 나: 그래요. 곧 비가 **오겠어요**. *(อากาศมืดครึ้มมากเลยนะ — ใช่ เดี๋ยวฝนคงตก)*
2. กล่องตำรา: 가: 하늘이 흐려요. 나: 곧 비가 **오겠어요**. · 가: 5시간 동안 청소를 했어요. 나: **피곤하겠어요**. · 가: 작년에 미국 여행을 했어요. 나: **재미있었겠어요**. *(ท้องฟ้ามืด — คงฝนตกเร็ว ๆ นี้ · ทำความสะอาด 5 ชั่วโมง — คงเหนื่อย · ปีที่แล้วไปเที่ยวอเมริกา — คงสนุกมาก)*
3. 연습 1 (264쪽) — คำพูด (เบาะแส) → คำตอบ (เดา): ข้อ 1 คือตัวอย่างตำรา · ที่เหลือใช้สูตรเดียวกัน (เฉลยเขียนเอง)

| เบาะแส (가) | คำใบ้ที่ตำราให้ | คำเดา (나) |
|:---|:---|:---|
| 이 불고기 좀 드세요. | 맛있다 | **맛있겠어요.** *(ตัวอย่าง — ดูอร่อยจัง)* |
| 남자 친구한테서 편지를 받았어요. | 기분이 좋다 | **기분이 좋겠어요.** *(คงอารมณ์ดี)* |
| 지난 일요일에 기숙사 청소를 했어요. | 기숙사가 깨끗하다 | **기숙사가 깨끗하겠어요.** *(หอคงสะอาด)* |
| 주말부터 백화점에서 세일을 해요. | 주말에 사람이 많다 | **주말에 사람이 많겠어요.** *(สุดสัปดาห์คนคงเยอะ)* |
| 아침, 점심, 저녁 모두 안 먹었어요. | 배가 고프다 | **배가 고프겠어요.** *(คงหิวมาก)* |

4. 읽기 27-2 (276쪽, SMS ของจางผิง): **아주 맛있겠네요**. 저는 막걸리도 아주 좋아해요. *(ดูอร่อยจังเลย ฉันชอบมักกอลลีมากด้วย — -겠네요)*
5. 듣기 28-2 (ภาคผนวก 372쪽): 가: 한국보다 더 더워요. 보통 여름 기온이 30도예요. 나: 정말 **덥겠어요**. *(ร้อนกว่าเกาหลี ปกติหน้าร้อน 30 องศา — คงร้อนจริง ๆ)*
6. **บทอ่านบท 26** (หน้าไม่มีในคลัง): เฉลยท้ายเล่มระบุว่าเป็นเรื่องวันหิมะตก (아침부터 눈이 왔어요 · 눈길을 걷고 사진도 찍고 눈사람도 만들었어요) — ตัวบทยังไม่มี จึงไม่ถอดความ

#### ฝึกสูตร "เบาะแส → คำเดา" ด้วยตัวเอง
| เบาะแส | คำเดา |
|:---|:---|
| 어제 밤을 새웠어요. *(อดนอนเมื่อคืน)* | 피곤하겠어요. |
| 내일 시험이 있어요. *(พรุ่งนี้มีสอบ)* | 바쁘겠어요. · 힘들겠어요. |
| 지난주에 제주도에 갔어요. *(สัปดาห์ก่อนไปเชจู)* | 재미있었겠어요. |
| 오늘 최고 기온이 35도예요. *(วันนี้ร้อน 35 องศา)* | 덥겠어요. |

### ⚠️ จุดสับสน
#### -겠- ¹ (ตั้งใจ · ข้อ 22) vs -겠- ² (คาดเดา · ข้อ 42)
| | **-겠- ¹ ความตั้งใจ** (ข้อ 22) | **-겠- ² คาดเดา** (ข้อ 42) |
|:---|:---|:---|
| ประธาน | ฉัน (ถามคุณ) | คนอื่น · สิ่งของ · อากาศ (ฉันเดา) |
| ชนิดคำ | กริยา | กริยา **และคำคุณศัพท์** |
| อดีต | ไม่มี -았겠 | **มี -았/었겠** |
| เบาะแส | ไม่ต้องมี (ตัดสินใจตอนพูด) | **มักมี** (หน้าตา เสียง ข่าว) |
| ตัวอย่าง | 제가 하**겠습니다**. *(ฉันจะทำเอง)* | 맛있**겠어요**. *(ดูอร่อยจัง)* |

- **วิธีแยกเร็ว:** ประธานเป็น "ฉัน" + กริยา + ไม่มีเบาะแส → **ตั้งใจ** · คุณศัพท์ / อดีต / ประธานเป็นอย่างอื่น → **เดา**
- 알겠습니다 *(รับทราบ)* · 모르겠어요 *(ไม่รู้ — นุ่มนวล)* เป็นสำนวนที่จำเป็นคำ (ข้อ 22) ไม่ใช่เดาจริง

#### -아/어요 vs -겠어요 vs -았/었겠어요 — "รู้จริง" หรือ "เดา"
| | ผู้พูดอยู่ตรงไหน | ตัวอย่าง |
|:---|:---|:---|
| 맛있**어요** | ลองแล้ว — **รู้จริง** | 이 불고기 맛있**어요**. *(กินแล้ว อร่อย)* |
| 맛있**겠어요** | **ยังไม่ได้ลอง** เห็นหน้าตา/ได้กลิ่น | 이 불고기 맛있**겠어요**. *(ดูน่าอร่อย)* |
| 맛있**었겠어요** | **ไม่ได้อยู่ที่นั่น** เพื่อนเล่าว่าไปกินมา | 어제 그 식당에서 먹었어요 → 맛있**었겠어요**. *(คงอร่อยสินะ)* |

#### -겠- (เดา) vs -(으)ㄹ 거예요 (ข้อ 28)
- ทั้งคู่แปลได้ว่า "คงจะ…" ใกล้เคียงกัน: 곧 비가 **오겠어요** ≈ 비가 **올 거예요**
- **-겠-** ผูกกับ**เบาะแสตรงหน้า/ความรู้สึกทันที** (곧 · เห็นฟ้ามืด) · **-(으)ㄹ 거예요** ใช้ได้กับ**แผน**และ**คาดการณ์ทั่วไป** — ถ้าประธานคือ "ฉัน" แล้วพูดแผนธรรมดาให้ใช้ 갈 거예요 เพราะ 가겠어요 (ฉัน + กริยา) จะอ่านเป็น "ตั้งใจตัดสินใจเดี๋ยวนี้" (ข้อ 22)

#### กับดัก
- **เดาเรื่องตัวเองไม่ได้:** ✗ 저는 지금 배가 고프겠어요 → ✓ **배가 고파요** *(ฉันรู้ตัวเอง จึงไม่ต้องเดา)* · -겠- ใช้เดาสภาพของ**คนอื่น/สิ่งอื่น**: 배가 고프겠어요 *(คุณคงหิว)*
- **ลำดับอดีต:** ✗ 먹겠었어요 → ✓ **먹었겠어요** · ✗ 재미있겠었어요 → ✓ 재미있었겠어요
- **ไม่ผัน ㅂ/ㅡ ก่อน 겠:** ✗ 더우겠어요 · 바빠겠어요 → ✓ **덥겠어요 · 바쁘겠어요**
- **ใช้ -겠- ความตั้งใจกับคนอื่น ไม่ได้:** ✗ 친구가 오겠어요 (ตั้งใจ) → ✓ 친구가 올 거예요 (ข้อ 22)
- **-겠네요 vs -네요:** -네요 = เพิ่งรู้ (ข้อ 30: 덥**네요** = ร้อนนี่นา — ตอนนี้ร้อนจริง) · -겠네요 = เดาจากสิ่งที่เห็น (덥**겠네요** = คงร้อนแน่ ๆ — ยังไม่ได้สัมผัสเอง) · 비가 와요 / 오네요 / 오겠네요 ต่างกันที่ "รู้จริง / เพิ่งเห็น / เดา"
- **ใส่ 요 ท้าย:** ✗ 맛있겠다 ใช้พูดกับเพื่อนสนิท (반말) · พูดสุภาพ → 맛있겠어요 / 맛있겠네요 / ทางการ 맛있겠습니다

> [!TIP]
> **เห็นเบาะแส → เดา = ราก + 겠어요** (คุณศัพท์/กริยา · อดีต = **았/었겠어요**) · **ฉัน + กริยา + ตัดสินใจ = 겠 แบบตั้งใจ (ข้อ 22)** · เรื่องของฉันเองที่รู้แน่ → -아/어요

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- **ยังไม่มีข้อสอบจริง** — 26과 อยู่ใน 복습시험③ (11/6) · ⚠️ ข้อ 42 ยังขาดข้อมูลหน้า 연습 2–3 · 대화 · 활동 · 읽기 ของบท 26 (ตำราสแกนมาแค่ 3 หน้า)
- **คาดการณ์รูปแบบข้อสอบ:**
  - **เติมประโยคเดา (เบาะแส → คำเดา):** 어제 5시간 청소했어요 → ( ) — เหมือน 연습 1 · คำตอบ 피곤하겠어요
  - **ตอบคำถามด้วยไวยากรณ์ที่กำหนด:** 지난주에 제주도에 갔어요 → (-았/었겠어요) → 재미있었겠어요
  - **그림을 보고 대답하세요:** 🖼️ ภาพท้องฟ้ามืด/ไอศกรีม → 곧 비가 오겠어요 · 맛있겠어요
  - **แยก -겠- สองความหมาย:** ให้ตัดสินว่า "제가 하겠습니다" กับ "맛있겠어요" ต่างกันอย่างไร (เสี่ยงเป็นคำถามเลือกตอบ)
  - **읽기 (③):** ถ้ายกบท 27-2 มาทำ 가/나 → มี "아주 맛있겠네요" ในข้อความ SMS
- **ข้อผิดที่เคยเจอและเกี่ยวกับข้อนี้ (§6b):** ยังไม่มีข้อผิดของ -겠-² โดยตรง · ที่ควรระวัง: **ตอบไม่ตรงคำถาม** (언제 → กิจกรรม) · **เลือก -(으)ㄹ 거예요 / -겠- ตามประธานและเบาะแส** (ข้อ 28 · 22) · ㅡ-drop ผิดที่ (바쁘겠어요 ไม่ตัด ㅡ) · ㅈ/ㅊ/ㅍ (**피곤하다** ขึ้นต้นด้วย ㅍ)
