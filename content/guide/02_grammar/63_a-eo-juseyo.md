## 63. -아/어/여 주세요 (ช่วย…ให้หน่อย) · -아/어/여 주다 · 드리다

> [!INTRO] ข้อนี้คืออะไร
> -아/어/여 주세요 คือการต่อ **주세요** ท้ายรากกริยาเพื่อ**ขอให้ผู้ฟังทำสิ่งนั้นให้เรา** (ตำรา 360쪽: polite request or command) เช่น 사진 좀 찍어 **주세요** *(ช่วยถ่ายรูปให้หน่อย)* รูปฐานคือ **-아/어/여 주다** แปลว่า "ทำให้ (เพื่อคนอื่น)" ส่วน **드리다** คือ 주다 ที่ยกย่องผู้รับ
>
> สอนในบท 37 (교과서 360–361쪽 · 준비 1) ต่อยอดจาก ข้อ 06 (กฎ 아/어/해) ข้อ 20 (-(으)세요 ขอ/สั่ง · 드리다 · 께) ข้อ 29 (에게/한테 + 주다) และ ข้อ 10 (N 주세요 "ขอ…")
>
> ไปใช้ต่อใน ข้อ 62 (ผู้ฟังตอบ 제가 …ㄹ게요) · ข้อ 64 (-아/어야 하다 บทเดียวกัน) · ข้อ 39 (-지 마세요 = ขอไม่ให้ทำ) และบทสนทนาโทรศัพท์ 37-1

### 📌 รูปแบบและเงื่อนไข

เลือก 아/어/해 จาก**สระของพยางค์สุดท้ายของราก** แล้วตามด้วย **주세요** กฎเดียวกับ -아/어요 ทุกอย่าง (ข้อ 06) ตารางแรกสรุปกฎ ตารางที่สองให้ตัวอย่างของรากแต่ละแบบ

| สระพยางค์สุดท้ายของราก | ต่อ |
|:---|:---|
| **ㅏ · ㅗ** | **-아 주세요** |
| สระอื่น | **-어 주세요** |
| **하다** | **해 주세요** |
| ㅡ-ราก | ㅡ หลุด |
| 르 ไม่ปกติ (ข้อ 54) | ㅡ หลุด + ㄹ ซ้อน |
| ㄷ · ㅂ ไม่ปกติ (ข้อ 51 · 37) | ตามกฎก่อน 아/어 |

#### ตัวอย่างตามชนิดของราก

ทุกแถวคือรากกริยา + -아/어/여 + 주세요 ที่แปลว่า "ช่วย…ให้หน่อย" สังเกตรากไม่ปกติที่เปลี่ยนรูปก่อนต่อ 아/어

| รากลงท้าย | 기본형 → -아/어 주세요 | ไทย |
|:---|:---|:---|
| ㅏ · ㅗ | 앉다 → **앉아 주세요** | ช่วยนั่ง |
| ㅏ · ㅗ | 가다 → **가 주세요** | ช่วยไป |
| ㅏ · ㅗ | 오다 → **와 주세요** | ช่วยมา |
| ㅏ · ㅗ | 닫다 → **닫아 주세요** | ช่วยปิด |
| ㅏ · ㅗ | 사다 → **사 주세요** | ช่วยซื้อ |
| สระอื่น | 찍다 → **찍어 주세요** | ช่วยถ่าย |
| สระอื่น | 만들다 → **만들어 주세요** | ช่วยทำ |
| สระอื่น | 넣다 → **넣어 주세요** | ช่วยใส่ |
| สระอื่น | 가르치다 → **가르쳐 주세요** | ช่วยสอน/ช่วยบอก |
| สระอื่น | 기다리다 → **기다려 주세요** | ช่วยรอ |
| สระอื่น | 바꾸다 → **바꿔 주세요** | ช่วยเปลี่ยน/ช่วยแลก |
| 하다 | 설명하다 → **설명해 주세요** | ช่วยอธิบาย |
| 하다 | 전화하다 → **전화해 주세요** | ช่วยโทร |
| 하다 | 포장하다 → **포장해 주세요** | ช่วยห่อ |
| 하다 | 준비하다 → **준비해 주세요** | ช่วยเตรียม |
| ㅡ | 끄다 → **꺼 주세요** | ช่วยปิด |
| ㅡ | 쓰다 → **써 주세요** | ช่วยเขียน |
| 르 | 자르다 → **잘라 주세요** | ช่วยตัด |
| 르 | 부르다 → **불러 주세요** | ช่วยเรียก/ช่วยร้อง |
| ㄷ | 듣다 → **들어 주세요** | ช่วยฟัง |
| ㅂ | 돕다 → **도와 주세요** | ช่วยช่วยเหลือ |

#### ข้อความของตำราและข้อควรรู้

ตำราหน้า 360 สรุปเงื่อนไขไว้ชัดเจน ส่วนข้อควรรู้คือชนิดของคำที่ใช้ได้ คำว่า 좀 ผู้รับประโยชน์ และการเว้นวรรค

- **ตำรา 360쪽:** "ใช้ขอร้อง/สั่งอย่างสุภาพ ต่อหลังรากกริยา — ถ้าพยางค์สุดท้ายมี ㅏ หรือ ㅗ ใช้ -아 주세요 · สระอื่น -어 주세요 · 하다 → 하여 주세요 (→ 해 주세요)"
- **ใช้กับกริยาเท่านั้น** · **좀 (หน่อย)** วางหน้ากริยาช่วยให้สุภาพนุ่มนวล
  - 사진 **좀** 찍어 주세요 *(ช่วยถ่ายรูปให้หน่อย)*
  - 알렉세이 씨 **좀** 바꿔 주세요 *(ขอสายคุณอเล็กเซย์หน่อย)*
- **ผู้รับประโยชน์คือผู้พูด:** "ทำให้ฉัน/ให้พวกเรา" — ถ้าอยากบอกว่าทำให้ใคร ใช้ 에게/한테 (ข้อ 29): 친구**한테** 사 주세요 *(ช่วยซื้อให้เพื่อน)*
- **เว้นวรรค:** 해 **주세요** · 찍어 **주세요** — 주세요 แยกจากรากที่ผัน (ข้อ 13) · ตำราเว้นวรรคทุกประโยค

#### เสริม: -아/어/여 주다 และ 드리다 (ตำรา 37과 สอนแค่ -아/어/여 주세요)

รูปฐาน -아/어/여 주다 ผันได้หลายรูปตามผู้รับ ตารางนี้บอกรูปและผู้รับ ส่วนตัวอย่างอยู่ในตารางถัดไป

| ผู้รับ | รูป |
|:---|:---|
| เพื่อน/ทั่วไป | -아/어 **줘요 · 줬어요 · 줄게요** |
| ผู้ใหญ่ (ยกย่อง) | -아/어 **드려요 · 드릴게요** |
| ขอร้องสุภาพขึ้น | -아/어 **주시겠어요?** |
| ขอไม่ให้ทำ | -지 **마세요** (ข้อ 39) |

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 친구가 사진을 찍어 **줬어요** | เพื่อนถ่ายรูปให้ | เพื่อน/ทั่วไป |
| 제가 사 **줄게요** | ฉันซื้อให้เอง | เพื่อน/ทั่วไป |
| 제가 도와 **드릴게요** | ฉันจะช่วยท่านเอง — เสริม | ผู้ใหญ่ |
| 어머니에게 드릴 지갑 | กระเป๋าสตางค์ที่จะให้คุณแม่ — 33과: 드리다 = ให้ | ผู้ใหญ่ |
| 사진 좀 찍어 주시겠어요? | ช่วยถ่ายรูปให้หน่อยได้ไหมคะ — เสริม | ขอร้องสุภาพขึ้น |
| 걱정하지 **마세요** | อย่ากังวล — 33과 | ขอไม่ให้ทำ |

#### สูตรและวิธีทำ: -아/어/여 주세요 (แบบกระดานครู)

-아/어/여 주세요 คือรากกริยา + 아/어/여 + 주세요 ผันด้วยกฎเดียวกับ -아/어요 (ข้อ 06) ทุกข้อ ส่วน 주세요 ท้ายสุดไม่เปลี่ยนรูปเลย สิ่งที่ต้องตัดสินใจคือรากเป็น 하 หรือไม่ ต้องปรับรากไม่ปกติก่อนหรือไม่ ใช้ 아 หรือ 어 และสระรวมกันหรือไม่ กฎมีสี่ข้อและใช้ตามลำดับ

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | รากเป็น **하다** | ใช้ **해** เลย ไม่ต้องดูสระ | 하 + 여 ย่อเป็น 해 |
| **กฎ 2** | รากไม่ปกติ ㅡ · ㅂ · ㄷ · 르 | **ปรับรากก่อน** แล้วค่อยเลือก 아/어 | ㅡ ตก · ㅂ เป็น 우 · ㄷ เป็น ㄹ · 르 เปลี่ยนเป็น ㄹ ซ้อน |
| **กฎ 3** | ดูสระของพยางค์สุดท้ายของราก (หลังกฎ 2) | ㅏ · ㅗ ใช้ **아** สระอื่นทั้งหมดใช้ **어** | สระเสียงสว่างคู่กับ 아 สระอื่นคู่กับ 어 |
| **กฎ 4** | รากไม่มีตัวสะกด | สระของรากกับ 아/어 **รวมเป็นพยางค์เดียว** | ไม่มีตัวสะกดคั่น เสียงจึงหลอมกัน |

ลำดับทำคือ ① ปรับราก (하 เป็น 해 และ ㅡ ㅂ ㄷ 르) ② เลือก 아 หรือ 어 ③ รวมสระ ④ ต่อ 주세요 ท้ายสุด ตารางแรกแสดงทุกขั้นกับรากปกติและ 하다

| ราก + คำต่อ | ① ปรับราก | ② เลือก 아/어 | ③ รวมสระ | ④ ผล (+ 주세요) | หมายเหตุ |
|:---|:---|:---|:---|:---|:---|
| 앉 + 아/어 주세요 | ไม่ปรับ | ㅏ จึงใช้ 아 | ไม่รวม (มีตัวสะกด) | **앉아 주세요** | ✗ 앉어 주세요 |
| 가 + 아/어 주세요 | ไม่ปรับ | ㅏ จึงใช้ 아 | 가 + 아 เหลือ 가 | **가 주세요** | 아 ถูกกลืน |
| 오 + 아/어 주세요 | ไม่ปรับ | ㅗ จึงใช้ 아 | 오 + 아 เป็น 와 | **와 주세요** | |
| 찍 + 아/어 주세요 | ไม่ปรับ | ㅣ จึงใช้ 어 | ไม่รวม (มีตัวสะกด) | **찍어 주세요** | 사진 좀 찍어 주세요 |
| 서 + 아/어 주세요 | ไม่ปรับ | ㅓ จึงใช้ 어 | 서 + 어 เหลือ 서 | **서 주세요** | 어 ถูกกลืน |
| 바꾸 + 아/어 주세요 | ไม่ปรับ | ㅜ จึงใช้ 어 | 우 + 어 เป็น 워 | **바꿔 주세요** | 알렉세이 씨 좀 바꿔 주세요 |
| 가르치 + 아/어 주세요 | ไม่ปรับ | ㅣ จึงใช้ 어 | 치 + 어 เป็น 쳐 | **가르쳐 주세요** | ✗ 가르처 주세요 |
| 쉬 + 아/어 주세요 | ไม่ปรับ | ㅟ จึงใช้ 어 | ไม่รวม (ㅟ ไม่หลอมกับ 어) | **쉬어 주세요** | |
| 되 + 아/어 주세요 | ไม่ปรับ | ㅚ จึงใช้ 어 | 되 + 어 เป็น 돼 | **돼 주세요** | 친구가 돼 주세요 |
| 하 + 아/어 주세요 | **하 เป็น 해** | ไม่ต้องเลือก (여) | 하 + 여 เป็น 해 | **해 주세요** | 전화하 เป็น 전화해 주세요 |

ตารางที่สองเป็นรากที่ลงท้าย ㅡ รากที่ลงท้าย ㄹ และราก 불규칙 ทุกแถวต้องปรับรากในข้อ ① ก่อนเลือก 아/어

| ราก + คำต่อ | ① ปรับราก | ② เลือก 아/어 | ③ รวมสระ | ④ ผล (+ 주세요) | หมายเหตุ |
|:---|:---|:---|:---|:---|:---|
| 쓰 + 아/어 주세요 | ㅡ ตก เหลือ ㅆ | ไม่มีสระหน้า ㅡ จึงใช้ 어 | ㅆ + 어 เป็น 써 | **써 주세요** | ㅡ ตกก่อน 아/어 |
| 만들 + 아/어 주세요 | ไม่ปรับ (ㄹ อยู่ครบ) | ㅡ จึงใช้ 어 | ไม่รวม (มีตัวสะกด) | **만들어 주세요** | ㄹ ไม่ตัดก่อนสระ |
| 입 + 아/어 주세요 | ไม่ปรับ (ㅂ ปกติ) | ㅣ จึงใช้ 어 | ไม่รวม (มีตัวสะกด) | **입어 주세요** | ㅂ ปกติไม่เปลี่ยน |
| 돕 + 아/어 주세요 | ㅂ เป็น 우 (도우) | 돕다 ใช้ 아 (ข้อยกเว้น) | 우 + 아 เป็น 와 | **도와 주세요** | ㅂ อื่นใช้ 워 เช่น 덥 เป็น 더워 |
| 닫 + 아/어 주세요 | ไม่ปรับ (ㄷ ปกติ) | ㅏ จึงใช้ 아 | ไม่รวม (มีตัวสะกด) | **닫아 주세요** | ต่างจาก 듣 |
| 듣 + 아/어 주세요 | ㄷ เป็น ㄹ (들) | ㅡ จึงใช้ 어 | ไม่รวม (มีตัวสะกด) | **들어 주세요** | ✗ 듣어 주세요 |
| 자르 + 아/어 주세요 | 르 เป็น ㄹ ซ้อน (잘 + ㄹ) | ㅏ จึงใช้ 아 | ㄹ + 아 เป็น 라 | **잘라 주세요** | |
| 부르 + 아/어 주세요 | 르 เป็น ㄹ ซ้อน (불 + ㄹ) | ㅜ จึงใช้ 어 | ㄹ + 어 เป็น 러 | **불러 주세요** | |

> [!TIP] วิธีจำสั้น ๆ
> ก่อนเลือก 아/어 ให้ปรับ 하 ㅡ ㅂ ㄷ 르 ก่อนเสมอ แล้วดูสระ ㅏ ㅗ ใช้ 아 สระอื่นใช้ 어 ถ้ารากไม่มีตัวสะกดให้รวมสระ ส่วน 주세요 ต่อท้ายสุดโดยไม่เปลี่ยนรูป

#### ผู้รับเป็นผู้ใหญ่: 주다 เป็น 드리다

เมื่อผู้พูดทำสิ่งนั้นให้ผู้ใหญ่ ให้เปลี่ยน 주다 เป็น 드리다 ส่วนรูป -아/어/여 ข้างหน้าไม่เปลี่ยนเลย ส่วนตอนขอให้ผู้ฟังทำให้เรา 주세요 มี 시 อยู่ในตัวแล้ว จึงห้ามเติม 시 ซ้ำ ตารางนี้ต่อจากผลของสองตารางบน

| ผลจากตารางบน | ① ผู้รับหรือผู้ฟัง | ② เลือกคำท้าย | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 해 | เพื่อน | 주다 + 어요 เป็น 줘요 | **해 줘요** | |
| 해 | ผู้ใหญ่ | 드리다 + 어요 เป็น 드려요 | **해 드려요** | ✗ 해 줘요 กับผู้ใหญ่ |
| 해 | เพื่อน (รับปาก) | 주다 + ㄹ게요 เป็น 줄게요 | **해 줄게요** | |
| 해 | ผู้ใหญ่ (รับปาก) | 드리다 + ㄹ게요 เป็น 드릴게요 | **해 드릴게요** | ข้อ 62 |
| 도와 | ผู้ใหญ่ (รับปาก) | 드리다 + ㄹ게요 เป็น 드릴게요 | **도와 드릴게요** | 제가 도와 드릴게요 |
| 해 | ขอให้ผู้ฟังทำให้เรา | 주 + 세요 เป็น 주세요 | **해 주세요** | ✗ 해 주시세요 ซ้อน 시 เหมือน 드시세요 ที่ต้องเป็น 드세요 |

### 📖 ตัวอย่างและการใช้

ตัวอย่างเรียงตามตำราบท 37 จากกล่องไวยากรณ์ 준비 ไปถึงแบบฝึก 연습 1–3 บทสนทนาโทรศัพท์ 37-1 และกิจกรรม สังเกตว่าตำราใช้ 주세요 ขอร้องทั้งกับคนและกับร้านค้า

| 가: 사진 좀 **찍어 주세요**. — 나: 알겠어요. | ช่วยถ่ายรูปให้หน่อยค่ะ — ได้ครับ | 360쪽 |
| 잠깐 여기에 **앉아 주세요**. | ช่วยนั่งตรงนี้สักครู่ | 360쪽 |
| 전화번호를 **가르쳐 주세요**. | ช่วยบอกเบอร์โทรศัพท์หน่อย — 가르치다 → 가르쳐 | 360쪽 |
| 이따가 **전화해 주세요**. | ช่วยโทรมาทีหลังนะ | 360쪽 |

#### 연습 1 (360쪽): สถานการณ์ → ขอร้อง

โจทย์ให้สถานการณ์พร้อมกริยาในวงเล็บ แล้วให้เติมคำขอร้อง ตำราพิมพ์ตัวอย่างข้อ 1 (설명해 주세요) ไว้ ส่วนข้ออื่นเติมตามกฎ

| สถานการณ์ | คำขอ | แปล |
|:---|:---|:---|
| 잘 모르겠어요. 다시 … (설명하다) | 다시 **설명해 주세요**. | ไม่เข้าใจเลย ช่วยอธิบายใหม่ |
| 너무 추워요. 에어컨을 … (끄다) | 에어컨을 **꺼 주세요**. | หนาวมาก ช่วยปิดแอร์ |
| 시끄러워요. 조용히 … (하다) | 조용히 **해 주세요**. | เสียงดัง ช่วยเงียบหน่อย |
| 고향 음식을 먹고 싶어요. … (만들다) | **만들어 주세요**. | อยากกินอาหารบ้านเกิด ช่วยทำให้หน่อย |
| 바람이 많이 불어요. 창문을 … (닫다) | 창문을 **닫아 주세요**. | ลมแรง ช่วยปิดหน้าต่าง |
| 오늘은 밤에 시간이 있어요. … (밤에 전화하다) | 밤에 **전화해 주세요**. | คืนนี้ว่าง ช่วยโทรมาตอนกลางคืน |
| 앞머리가 너무 길어요. … (앞머리를 더 자르다) | 앞머리를 더 **잘라 주세요**. | ผมหน้าม้ายาวไป ช่วยตัดเพิ่ม — 르 ไม่ปกติ |

#### 연습 2–3 (361쪽): ภาพ → ขอร้อง

ตำราให้ภาพห้องเรียนและสถานที่ต่าง ๆ แล้วให้เติมคำขอร้องในกรอบคำพูด ซึ่งตรงกับรูปแบบ "그림을 보고 대답하세요"

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 글씨가 너무 작아요. 칠판에 (**크게 써 주세요**) | ตัวเล็กไป ช่วยเขียนบนกระดานให้ใหญ่ — ㅡ หลุด: 쓰다 → 써 | 연습 2 ห้องเรียน |
| 모르겠어요. 다시 **설명해 주세요** | ไม่เข้าใจ ช่วยอธิบายใหม่ — ตำราพิมพ์ไว้ | 연습 2 ห้องเรียน |
| 배가 고파요. 하지만 돈이 없어요. (**돈 좀 빌려 주세요**) | หิวแต่ไม่มีเงิน ช่วยให้ยืมเงินหน่อย — ตัวอย่างตอบ | 연습 2 ห้องเรียน |
| 이 단어를 모르겠어요. (**설명해 주세요 / 가르쳐 주세요**) | ไม่รู้คำนี้ ช่วยอธิบาย/สอนหน่อย | 연습 2 ห้องเรียน |
| 남대문으로 **가 주세요** | ช่วยไปที่นัมแดมุนหน่อย — 으로 ทิศทาง ข้อ 49 (ตำราพิมพ์ไว้) | 연습 3 · 택시 (แท็กซี่) |
| 봉지에 **넣어 주세요** | ช่วยใส่ถุงให้หน่อย | 연습 3 ร้านผลไม้ |
| **포장해 주세요** | ช่วยห่อกลับบ้านให้ | 연습 3 ร้านฟาสต์ฟู้ด |
| 돈을 **바꿔 주세요** | ช่วยแลกเงินให้ | 연습 3 ธนาคาร |

#### บทสนทนา โทรศัพท์ 37-1 (364쪽) และ 활동 (365쪽)

บทสนทนา 37-1 ใช้ 바꿔 주세요 ขอโอนสายและ -(으)ㄹ 수 있다 ขอเลื่อนนัด ส่วนกิจกรรมใช้ 주세요 แบ่งงานกันเตรียมปาร์ตี้

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 마키: 여보세요. 저는 마키인데요. 알렉세이 씨 좀 **바꿔 주세요**. | ฮัลโหล ฉันมากิ ช่วยโอนสายคุณอเล็กเซย์ให้หน่อย — ข้อ 61 | 37-1 (364쪽) |
| 하숙집 아주머니: 네, 잠깐만 **기다리세요**. | ได้ค่ะ รอสักครู่นะคะ — -(으)세요 ข้อ 20 | 37-1 (364쪽) |
| 마키: 미안하지만 내일 약속을 좀 **바꿀 수 있어요**? | ขอโทษนะ ขอเลื่อนนัดพรุ่งนี้หน่อยได้ไหม — -(으)ㄹ 수 있다 ข้อ 46 · 바꾸다 = เปลี่ยน | 37-1 (364쪽) |
| 바트: 저는 음식을 만들게요. 마키 씨는 과자하고 음료수를 **준비해 주세요**. | ฉันจะทำอาหารเอง คุณมากิช่วยเตรียมขนมกับเครื่องดื่มนะ — ผู้ฟังขอ ↔ ผู้พูดอาสา ข้อ 62 | 활동 (365쪽) |
| 마키 씨는 청소를 **해 주세요**. | คุณมากิช่วยทำความสะอาดนะ | 활동 (365쪽) |
| 이것 좀 **해 주세요**. | ช่วยทำสิ่งนี้หน่อย — ตัวอย่างบนวงกลมกิจกรรม 365쪽 | 활동 (365쪽) |

### ⚠️ จุดสับสน

-아/어 주세요 สับสนกับ -(으)세요 และ N 주세요 ที่หน้าตาคล้ายกัน และพลาดบ่อยที่การเลือก 아/어/해 ตารางแรกเทียบความหมายของสี่รูป ตารางที่สองรวมรูปที่ถูกกับรูปที่ผิด

#### -아/어 주세요 vs -(으)세요 vs N 주세요 vs -(으)ㄹ게요

สี่รูปนี้ล้วนเกี่ยวกับการขอหรือการเสนอ แต่ต่างกันที่ว่าประโยชน์ตกที่ใครและขอสิ่งของหรือการกระทำ

| รูป | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| **-아/어 주세요** | **ขอให้ผู้ฟังทำให้เรา** (ประโยชน์ตกที่ผู้พูด) | 창문을 닫아 주세요 *(ช่วยปิดหน้าต่างให้หน่อย)* |
| -(으)세요 (ข้อ 20) | เชิญ/สั่ง/แนะนำ (ประโยชน์ตกที่ผู้ฟัง หรือเป็นคำสั่งทั่วไป) | 창문을 닫으세요 *(ปิดหน้าต่างนะ)* · 기다리세요 *(โปรดรอ)* · 앉으세요 *(เชิญนั่ง)* |
| **N 주세요** (ข้อ 10) | **ขอ N** (ส่งสิ่งของมา) | 오후 2시 표로 주세요 *(ขอตั๋วรอบบ่ายสอง)* · 물 좀 주세요 *(ขอน้ำหน่อย)* |
| -(으)ㄹ게요 (ข้อ 62) | **ฉันจะทำเอง** (ผู้พูดอาสา) | 제가 닫을게요 *(ฉันปิดเอง)* |

- **ความต่างของ 앉으세요 กับ 앉아 주세요:** 앉으세요 = "เชิญนั่ง" (ผู้ให้บริการเชิญลูกค้า) · 앉아 주세요 = "ช่วยนั่งให้หน่อย" (ขอให้คนอื่นทำอะไรสักอย่างให้เรา) — ตำรา 364쪽 เจ้าของหอ: 기다리세요 · มากิ: 바꿔 주세요

#### กับดัก

ตารางนี้รวมรูปที่ถูกและรูปที่ผิดที่พบบ่อย พร้อมเหตุผลสั้น ๆ ส่วนข้อที่ไม่ใช่คู่ ✓/✗ อยู่ในรายการด้านล่าง

| ประเด็น | ✓ ถูก | ✗ ผิด | หมายเหตุ |
|:---|:---|:---|:---|
| ㅏ/ㅗ → 아 | 앉아 주세요 · 닫아 주세요 · 와 주세요 · 가 주세요 | 앉어 주세요 · 닫어 주세요 · 오어 주세요 | เหมือน ✗ 살어요 · 받었어요 ที่เคยพลาด |
| 하다 → 해 | 설명해 주세요 · 전화해 주세요 | 설명하 주세요 · 설명하어 주세요 | 하다 ต้องย่อเป็น 해 |
| ㅡ / 르 / ㄷ | 꺼 주세요 · 잘라 주세요 · 들어 주세요 | 끄어 주세요 · 자르어 주세요 · 듣어 주세요 | ผันตามกฎก่อนต่อ 아/어 |
| ㅣ-ราก | 가르쳐 · 기다려 · 마셔 | 가르치어 | ต้องย่อเป็น 가르쳐 — 가르치 + 어 → 가르쳐 |
| ขอไม่ให้ทำ | 하지 마세요 (ข้อ 39) · 하지 말아 주세요 (เสริม) | 안 해 주세요 | ขอไม่ให้ทำห้ามใช้ 안 |
| 바꾸다 | 바꿔 | 바꾸어 · 바구어 | พลาดตรงสะกด 바꿔 (ㅜ + 어 → ㅝ) |
| กรรมที่ผู้ฟังจะ "ได้รับ" | 친구한테 전화해 주세요 *(ช่วยโทรถึงเพื่อนให้)* | 친구를 전화해 주세요 | ใช้ 에게/한테 (ข้อ 29) |
| ผู้พูดอาสาให้ผู้ใหญ่ | 도와 **드릴게요** | 도와 줄게요 | ข้อ 62 + 20 |

- **바꾸다 สามความหมายใน 37:**
  - 돈을 **바꾸다** *(แลกเงิน)*
  - 약속을 **바꾸다** *(เลื่อน/เปลี่ยนนัด)*
  - 전화를 **바꾸다** *(โอนสาย — 알렉세이 씨 좀 바꿔 주세요 = ขอสาย…)*
- **ผู้ใหญ่ผู้ฟัง:** ✓ 해 주세요 (สุภาพพอ) · ยกระดับ → 해 주시겠어요? / 해 주십시오 (เสริม)

> [!TIP] กฎสั้น ๆ
> **-아/어 주세요 = "ช่วย…ให้หน่อย" — เลือก 아/어/해 จากสระรากเหมือน -아/어요 · ใส่ 좀 ให้นุ่ม · ห้ามเขียนติด · ขอไม่ให้ทำ = -지 마세요**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ข้อนี้ยังไม่มีข้อสอบจริง รายการข้างล่างจึงรวมกำหนดสอบ ข้อผิดเดิมของผู้เรียนที่เกี่ยวข้อง และรูปแบบข้อสอบที่คาดว่าจะเจอ

- ยังไม่มีข้อสอบจริงเกี่ยวกับ -아/어 주세요 — 37과 อยู่ใน **복습시험④ (11/18)** และ **기말**
- ตำรา 361쪽 มีภาพให้ "เติมคำขอร้องในกรอบคำพูด" ซึ่งตรงกับรูปแบบ **"그림을 보고 대답하세요" (쓰기 ข้อ 5 ของ 복습시험①)** อย่างมาก
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ (CLAUDE.md §6b):**
  - ★ **ㅏ-ราก + 어요:** 살어요 · 살었어요 · 받었어요 ✗ → 아
  - **ㅡ-drop** ผู้เรียนทำถูกอยู่แล้ว (바빴어요 · 컸어요) → ใช้ตรรกะเดียวกันกับ 꺼 · 써
  - **เขียนติดกัน** 갈거예요 · 청소할거예요 (และ 해주세요 ก็ควรเว้นวรรค)
  - **ตอบไม่ตรงคำถาม**
  - **ใช้ 가 กับกริยาที่ต้องการ 을/를** (시계가 받았어요 · 이야기가 들었어요)
  - **ใช้ -(으)세요 ผิดตอน** (드시세요 ✗ → 드세요: double honorific) → ขอร้องด้วย 해 주세요 ไม่ต้องใส่ 시 ซ้ำ
  - 드리다/주다 สลับ (한테 + 드리다 ✗ → 께 + 드리다)
- **คาดการณ์รูปแบบข้อสอบ** (เดาจากรูปแบบ 복습시험①②) มี 4 แบบ:
  - **ผันตาราง:** 앉다 · 가르치다 · 끄다 · 자르다 · 바꾸다 · 하다 → ___ 주세요
  - **ดูภาพแล้วขอร้อง:** 글씨가 너무 작아요 → 칠판에 크게 써 주세요 · 택시 → 남대문으로 가 주세요 · 은행 → 돈을 바꿔 주세요
  - **เลือก -(으)세요 / -아/어 주세요 / -(으)ㄹ게요:** 가: 창문을 열까요? — 나: 네, 열어 ( ) · 가: 제가 ( ) → 열게요
  - **읽기/듣기 37-1 (โทรศัพท์):** เติม "알렉세이 씨 좀 ___" · ตอบ "마키 씨는 왜 알렉세이 씨에게 전화를 했습니까?" (ตำรา 364쪽 확인 — เพราะอยากเลื่อนนัด เนื่องจากต้องไปรับเพื่อนที่สนามบิน)

-아/어 주세요 ใช้กฎ 아/어/해 เดียวกับ -아/어요 และคู่กับ -(으)ㄹ게요 ที่ผู้ฟังใช้ตอบรับ

- ข้อ 51 · 54 · 37 (ㄷ · 르 · ㅂ ก่อน 아/어)

→ ใช้ต่อใน

- ข้อ 62 (-(으)ㄹ게요 — ตอบรับคำขอ) · ข้อ 64 (บทเดียวกัน)
- ข้อ 61 (저는 마키인데요 + 바꿔 주세요) · ข้อ 39 (-지 마세요 ↔ ขอไม่ให้ทำ)
- ข้อ 60 (-아/어 보다 ที่สะกดคล้ายกัน: 가 봐요 ≠ 가 주세요)

> [!SUMMARY] สรุป
> - -아/어 주세요 = "ช่วย…ให้หน่อย" ขอให้ผู้ฟังทำให้เรา: เลือก 아/어/해 จากสระของรากเหมือน -아/어요 (앉아 · 찍어 · 설명해 · 꺼)
> - ใส่ 좀 ให้นุ่มนวล (사진 좀 찍어 주세요) และเว้นวรรคระหว่างรากกับ 주세요 · ขอไม่ให้ทำใช้ -지 마세요
> - แยกให้ออก: -아/어 주세요 *(ช่วยทำให้)* ≠ -(으)세요 *(เชิญ/แนะนำ)* ≠ N 주세요 *(ขอสิ่งของ)* ≠ -(으)ㄹ게요 *(ฉันจะทำเอง)*
> - ที่ต้องระวัง: ㅏ + 어 ✗ (앉어 주세요) · ขอไม่ให้ทำใช้ 안 ✗ · ผู้ใหญ่ใช้ 드릴게요 ไม่ใช่ 줄게요
