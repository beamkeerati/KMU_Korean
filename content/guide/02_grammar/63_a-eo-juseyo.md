## 63. -아/어/여 주세요 (ช่วย…ให้หน่อย) · -아/어/여 주다 · 드리다
ต่อท้ายรากกริยา + **주세요** เพื่อ**ขอให้ผู้ฟังทำสิ่งนั้นให้เรา** (ตำรา 360쪽: polite request or command) — 사진 좀 찍어 **주세요** *(ช่วยถ่ายรูปให้หน่อย)* · รูปฐาน **-아/어/여 주다** = "ทำให้ (เพื่อคนอื่น)" ส่วน **드리다** คือ 주다 ที่ยกย่องผู้รับ
สอนในบท 37 (교과서 360–361쪽 · 준비 1) · ต่อยอดจาก ข้อ 06 (กฎ 아/어/해) · ข้อ 20 (-(으)세요 ขอ/สั่ง · 드리다 · 께) · ข้อ 29 (에게/한테 + 주다) · ข้อ 10 (N 주세요 "ขอ…")
ใช้ต่อใน ข้อ 62 (ผู้ฟังตอบ 제가 …ㄹ게요) · ข้อ 64 (-아/어야 하다 บทเดียวกัน) · ข้อ 39 (-지 마세요 = ขอไม่ให้ทำ) และบทสนทนาโทรศัพท์ 37-1

### 📌 รูปแบบและเงื่อนไข
เลือก 아/어/해 จาก**สระของพยางค์สุดท้ายของราก** แล้วตามด้วย **주세요** — กฎเดียวกับ -아/어요 ทุกอย่าง (ข้อ 06)

| สระพยางค์สุดท้ายของราก | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| **ㅏ · ㅗ** | **-아 주세요** | 앉다 → **앉아 주세요** · 가다 → **가 주세요** · 오다 → **와 주세요** · 닫다 → **닫아 주세요** · 사다 → **사 주세요** *(ช่วยนั่ง · ช่วยไป · ช่วยมา · ช่วยปิด · ช่วยซื้อ)* |
| สระอื่น | **-어 주세요** | 찍다 → **찍어 주세요** · 만들다 → **만들어 주세요** · 넣다 → **넣어 주세요** · 가르치다 → **가르쳐 주세요** · 기다리다 → **기다려 주세요** · 바꾸다 → **바꿔 주세요** |
| **하다** | **해 주세요** | 설명하다 → **설명해 주세요** · 전화하다 → **전화해 주세요** · 포장하다 → **포장해 주세요** · 준비하다 → **준비해 주세요** |
| ㅡ-ราก | ㅡ หลุด | 끄다 → **꺼 주세요** · 쓰다 → **써 주세요** |
| 르 ไม่ปกติ (ข้อ 54) | ㅡ หลุด + ㄹ ซ้อน | 자르다 → **잘라 주세요** · 부르다 → **불러 주세요** |
| ㄷ · ㅂ ไม่ปกติ (ข้อ 51 · 37) | ตามกฎก่อน 아/어 | 듣다 → **들어 주세요** · 돕다 → **도와 주세요** |

- **ตำรา 360쪽:** "ใช้ขอร้อง/สั่งอย่างสุภาพ ต่อหลังรากกริยา — ถ้าพยางค์สุดท้ายมี ㅏ หรือ ㅗ ใช้ -아 주세요 · สระอื่น -어 주세요 · 하다 → 하여 주세요 (→ 해 주세요)"
- **ใช้กับกริยาเท่านั้น** · **좀 (หน่อย)** วางหน้ากริยาช่วยให้สุภาพนุ่มนวล: 사진 **좀** 찍어 주세요 · 알렉세이 씨 **좀** 바꿔 주세요
- **ผู้รับประโยชน์คือผู้พูด:** "ทำให้ฉัน/ให้พวกเรา" — ถ้าอยากบอกว่าทำให้ใคร ใช้ 에게/한테 (ข้อ 29): 친구**한테** 사 주세요
- **เว้นวรรค:** 해 **주세요** · 찍어 **주세요** — 주세요 แยกจากรากที่ผัน (ข้อ 13) · ตำราเว้นวรรคทุกประโยค

#### 📌 เสริม -아/어/여 주다 และ 드리다 (ตำรา 37과 สอนแค่ -아/어/여 주세요)
| ผู้รับ | รูป | ตัวอย่าง |
|:---|:---|:---|
| เพื่อน/ทั่วไป | -아/어 **줘요 · 줬어요 · 줄게요** | 친구가 사진을 찍어 **줬어요** *(เพื่อนถ่ายรูปให้)* · 제가 사 **줄게요** *(ฉันซื้อให้เอง)* |
| ผู้ใหญ่ (ยกย่อง) | -아/어 **드려요 · 드릴게요** | 제가 도와 **드릴게요** *(ฉันจะช่วยท่านเอง — เสริม)* · 어머니에게 드릴 지갑 (33과: 드리다 = ให้) |
| ขอร้องสุภาพขึ้น | -아/어 **주시겠어요?** | 사진 좀 찍어 주시겠어요? *(เสริม)* |
| ขอไม่ให้ทำ | -지 **마세요** (ข้อ 39) | 걱정하지 마세요 *(อย่ากังวล — 33과)* |

### 📖 ตัวอย่างและการใช้
#### จากกล่องไวยากรณ์และ 준비 (360쪽)
1. 가: 사진 좀 **찍어 주세요**. — 나: 알겠어요. *(ช่วยถ่ายรูปให้หน่อยค่ะ — ได้ครับ)*
2. 잠깐 여기에 **앉아 주세요**. *(ช่วยนั่งตรงนี้สักครู่)*
3. 전화번호를 **가르쳐 주세요**. *(ช่วยบอกเบอร์โทรศัพท์หน่อย — 가르치다 → 가르쳐)*
4. 이따가 **전화해 주세요**. *(ช่วยโทรมาทีหลังนะ)*

#### 연습 1 (360쪽): สถานการณ์ → ขอร้อง
| สถานการณ์ | คำขอ | แปล |
|:---|:---|:---|
| 잘 모르겠어요. 다시 … (설명하다) | 다시 **설명해 주세요**. | ไม่เข้าใจเลย ช่วยอธิบายใหม่ |
| 너무 추워요. 에어컨을 … (끄다) | 에어컨을 **꺼 주세요**. | หนาวมาก ช่วยปิดแอร์ |
| 시끄러워요. 조용히 … (하다) | 조용히 **해 주세요**. | เสียงดัง ช่วยเงียบหน่อย |
| 고향 음식을 먹고 싶어요. … (만들다) | **만들어 주세요**. | อยากกินอาหารบ้านเกิด ช่วยทำให้หน่อย |
| 바람이 많이 불어요. 창문을 … (닫다) | 창문을 **닫아 주세요**. | ลมแรง ช่วยปิดหน้าต่าง |
| 오늘은 밤에 시간이 있어요. … (밤에 전화하다) | 밤에 **전화해 주세요**. | คืนนี้ว่าง ช่วยโทรมาตอนกลางคืน |
| 앞머리가 너무 길어요. … (앞머리를 더 자르다) | 앞머리를 더 **잘라 주세요**. | ผมหน้าม้ายาวไป ช่วยตัดเพิ่ม — 르 ไม่ปกติ |

- ตำราพิมพ์ตัวอย่างข้อ 1 (설명해 주세요) ไว้ ส่วนข้ออื่นเติมตามกฎ

#### 연습 2–3 (361쪽): ภาพ → ขอร้อง
- **ห้องเรียน 연습 2:** 글씨가 너무 작아요. 칠판에 (**크게 써 주세요**) *(ตัวเล็กไป ช่วยเขียนบนกระดานให้ใหญ่ — ㅡ หลุด: 쓰다 → 써)* · 모르겠어요. 다시 **설명해 주세요** *(ตำราพิมพ์ไว้)* · 배가 고파요. 하지만 돈이 없어요. (**돈 좀 빌려 주세요**) *(หิวแต่ไม่มีเงิน ช่วยให้ยืมเงินหน่อย — ตัวอย่างตอบ)* · 이 단어를 모르겠어요. (**설명해 주세요 / 가르쳐 주세요**) *(ไม่รู้คำนี้ ช่วยอธิบาย/สอนหน่อย)*
- **연습 3 (สถานที่ → ประโยคขอ):** 택시 — 남대문으로 **가 주세요** *(ตำราพิมพ์ไว้ — ช่วยไปที่นัมแดมุนหน่อย — 으로 ทิศทาง ข้อ 49)* · ร้านผลไม้ — 봉지에 **넣어 주세요** *(ช่วยใส่ถุงให้หน่อย)* · ร้านฟาสต์ฟู้ด — **포장해 주세요** *(ช่วยห่อกลับบ้านให้)* · ธนาคาร — 돈을 **바꿔 주세요** *(ช่วยแลกเงินให้)*

#### บทสนทนา โทรศัพท์ 37-1 (364쪽)
- 마키: 여보세요. 저는 마키인데요. 알렉세이 씨 좀 **바꿔 주세요**. *(ฮัลโหล ฉันมากิ ช่วยโอนสายคุณอเล็กเซย์ให้หน่อย — ข้อ 61)* — 하숙집 아주머니: 네, 잠깐만 **기다리세요**. *(ได้ค่ะ รอสักครู่นะคะ — -(으)세요 ข้อ 20)*
- 마키: 미안하지만 내일 약속을 좀 **바꿀 수 있어요**? *(ขอโทษนะ ขอเลื่อนนัดพรุ่งนี้หน่อยได้ไหม — -(으)ㄹ 수 있다 ข้อ 46 · 바꾸다 = เปลี่ยน)*
- 활동 (365쪽): 바트: 저는 음식을 만들게요. 마키 씨는 과자하고 음료수를 **준비해 주세요**. *(ฉันจะทำอาหารเอง คุณมากิช่วยเตรียมขนมกับเครื่องดื่มนะ — ผู้ฟังขอ ↔ ผู้พูดอาสา ข้อ 62)* · 마키 씨는 청소를 **해 주세요**. *(คุณมากิช่วยทำความสะอาดนะ)* · 이것 좀 **해 주세요**. *(ช่วยทำสิ่งนี้หน่อย — ตัวอย่างบนวงกลมกิจกรรม 365쪽)*

### ⚠️ จุดสับสน
#### -아/어 주세요 vs -(으)세요 vs N 주세요 vs -(으)ㄹ게요
| | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| **-아/어 주세요** | **ขอให้ผู้ฟังทำให้เรา** (ประโยชน์ตกที่ผู้พูด) | 창문을 닫아 주세요 *(ช่วยปิดหน้าต่างให้หน่อย)* |
| -(으)세요 (ข้อ 20) | เชิญ/สั่ง/แนะนำ (ประโยชน์ตกที่ผู้ฟัง หรือเป็นคำสั่งทั่วไป) | 창문을 닫으세요 *(ปิดหน้าต่างนะ)* · 기다리세요 *(โปรดรอ)* · 앉으세요 *(เชิญนั่ง)* |
| **N 주세요** (ข้อ 10) | **ขอ N** (ส่งสิ่งของมา) | 오후 2시 표로 주세요 *(ขอตั๋วรอบบ่ายสอง)* · 물 좀 주세요 *(ขอน้ำหน่อย)* |
| -(으)ㄹ게요 (ข้อ 62) | **ฉันจะทำเอง** (ผู้พูดอาสา) | 제가 닫을게요 *(ฉันปิดเอง)* |

- **ความต่างของ 앉으세요 กับ 앉아 주세요:** 앉으세요 = "เชิญนั่ง" (ผู้ให้บริการเชิญลูกค้า) · 앉아 주세요 = "ช่วยนั่งให้หน่อย" (ขอให้คนอื่นทำอะไรสักอย่างให้เรา) — ตำรา 364쪽 เจ้าของหอ: 기다리세요 · มากิ: 바꿔 주세요
- **ㅏ/ㅗ → 아:** ✓ 앉아 주세요 · 닫아 주세요 · 와 주세요 · 가 주세요 / ✗ 앉어 주세요 · 닫어 주세요 · 오어 주세요 (เหมือน ✗ 살어요 · 받었어요 ที่เคยพลาด)
- **하다 → 해:** ✓ 설명해 주세요 · 전화해 주세요 / ✗ 설명하 주세요 · 설명하어 주세요
- **ㅡ/르/ㄷ:** ✓ 꺼 주세요 · 잘라 주세요 · 들어 주세요 / ✗ 끄어 주세요 · 자르어 주세요 · 듣어 주세요
- **ㅣ-ราก:** ✓ 가르쳐 · 기다려 · 마셔 / ✗ 가르치어 (ต้องย่อเป็น 가르쳐) — 가르치 + 어 → 가르쳐
- **ขอไม่ให้ทำ ห้ามใช้ 안:** ✗ 안 해 주세요 → ✓ 하지 마세요 (ข้อ 39) หรือ 하지 말아 주세요 (เสริม)
- **바꾸다 สามความหมายใน 37:** 돈을 **바꾸다** *(แลกเงิน)* · 약속을 **바꾸다** *(เลื่อน/เปลี่ยนนัด)* · 전화를 **바꾸다** *(โอนสาย — 알렉세이 씨 좀 바꿔 주세요 = ขอสาย…)* — พลาดตรงสะกด 바꿔 (ㅜ + 어 → ㅝ) ✗ 바꾸어 · ✗ 바구어
- **กรรมที่ผู้ฟังจะ "ได้รับ" ใช้ 에게/한테:** ✓ 친구한테 전화해 주세요 *(ช่วยโทรถึงเพื่อนให้)* ≠ ✗ 친구를 전화해 주세요 (ข้อ 29)
- **ผู้ใหญ่ผู้ฟัง:** ✓ 해 주세요 (สุภาพพอ) · ยกระดับ → 해 주시겠어요? / 해 주십시오 (เสริม) · **ผู้พูดอาสาให้ผู้ใหญ่:** ✓ 도와 **드릴게요** / ✗ 도와 줄게요 (ข้อ 62 + 20)

> [!TIP]
> **-아/어 주세요 = "ช่วย…ให้หน่อย" — เลือก 아/어/해 จากสระรากเหมือน -아/어요 · ใส่ 좀 ให้นุ่ม · ห้ามเขียนติด · ขอไม่ให้ทำ = -지 마세요**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- ยังไม่มีข้อสอบจริงเกี่ยวกับ -아/어 주세요 — 37과 อยู่ใน **복습시험④ (11/18)** และ **기말** · ตำรา 361쪽 มีภาพให้ "เติมคำขอร้องในกรอบคำพูด" ซึ่งตรงกับรูปแบบ **"그림을 보고 대답하세요" (쓰기 ข้อ 5 ของ 복습시험①)** อย่างมาก
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ (CLAUDE.md §6b):** ★ **ㅏ-ราก + 어요:** 살어요 · 살었어요 · 받었어요 ✗ → 아 · **ㅡ-drop** ผู้เรียนทำถูกอยู่แล้ว (바빴어요 · 컸어요) → ใช้ตรรกะเดียวกันกับ 꺼 · 써 · **เขียนติดกัน** 갈거예요 · 청소할거예요 (และ 해주세요 ก็ควรเว้นวรรค) · **ตอบไม่ตรงคำถาม** · **ใช้ 가 กับกริยาที่ต้องการ 을/를** (시계가 받았어요 · 이야기가 들었어요) · **ใช้ -(으)세요 ผิดตอน** (드시세요 ✗ → 드세요: double honorific) → ขอร้องด้วย 해 주세요 ไม่ต้องใส่ 시 ซ้ำ · 드리다/주다 สลับ (한테 + 드리다 ✗ → 께 + 드리다)
- **คาดการณ์รูปแบบข้อสอบ** (เดาจากรูปแบบ 복습시험①②):
  1. **ผันตาราง:** 앉다 · 가르치다 · 끄다 · 자르다 · 바꾸다 · 하다 → ___ 주세요
  2. **ดูภาพแล้วขอร้อง:** 글씨가 너무 작아요 → 칠판에 크게 써 주세요 · 택시 → 남대문으로 가 주세요 · 은행 → 돈을 바꿔 주세요
  3. **เลือก -(으)세요 / -아/어 주세요 / -(으)ㄹ게요:** 가: 창문을 열까요? — 나: 네, 열어 ( ) · 가: 제가 ( ) → 열게요
  4. **읽기/듣기 37-1 (โทรศัพท์):** เติม "알렉세이 씨 좀 ___" · ตอบ "마키 씨는 왜 알렉세이 씨에게 전화를 했습니까?" (ตำรา 364쪽 확인 — เพราะอยากเลื่อนนัด เนื่องจากต้องไปรับเพื่อนที่สนามบิน)
