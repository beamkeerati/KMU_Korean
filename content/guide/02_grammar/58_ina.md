## 58. N(이)나 (N หรือ N) · คำวิเศษณ์บอกความถี่ (자주 · 가끔 · 거의 · 전혀)
คำช่วยที่ต่อท้าย**คำนาม**เพื่อบอกว่า "เลือกอย่างใดอย่างหนึ่ง" — **หรือ** ของคำนาม (ตำรา 338쪽: connects two or more things and denotes that one of them is chosen) · รวมคำวิเศษณ์บอกความถี่ที่ตำราสอนคู่กันใน 준비 2 ของบท 34
สอนในบท 34 (교과서 338–339쪽 · 준비 2) · ต่อยอดจาก ข้อ 01 (ตัวสะกด → 이 · สระ → ไม่มี) · ข้อ 11 (하고 "และ") · ข้อ 19 (와/과) · ข้อ 17 (도) · ข้อ 57 (-거나 "หรือ" ของกริยา)
ใช้ต่อใน ข้อ 59 (ในบท 35 읽기: 친구나 부모님께 편지도 자주 씁니다) · บท 36 (목요일이나 금요일 저녁에는) · ข้อ 52 (쯤 ใช้บอกความถี่ 일주일에 한 번쯤)

### 📌 รูปแบบและเงื่อนไข
| คำนามลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| **สระ** | **-나** | 사과 → 사과**나** 배 · 커피 → 커피**나** 녹차 · 코미디 영화 → 코미디 영화**나** 액션 영화 *(แอปเปิลหรือลูกแพร์ · กาแฟหรือชาเขียว · หนังตลกหรือหนังแอ็กชัน)* |
| **ตัวสะกด** | **-이나** | 빵 → 빵**이나** 밥 · 집 → 집**이나** 도서관 · 빨간색 → 빨간색**이나** 노란색 *(ขนมปังหรือข้าว · บ้านหรือห้องสมุด · สีแดงหรือสีเหลือง)* |
| ตัวสะกด ㄹ | **-이나** (ㄹ ถือเป็นตัวสะกด) | 금요일 → 금요일**이나** 토요일 *(วันศุกร์หรือวันเสาร์)* |

- **ตำรา 338쪽:** "ต่อคำนาม (หรือคำวิเศษณ์) — ถ้าลงท้ายด้วยสระใช้ 나 ถ้าลงท้ายด้วยตัวสะกดใช้ 이나" — กฎตัวสะกดเดียวกับ 은/는 · 이/가 · 을/를 (ข้อ 35)
- **ต่อกับคำนามทุกตัวที่ "เลือกได้":** เวลา · สถานที่ · ของกิน · สี · วัน — 목요일이나 금요일 *(วันพฤหัสหรือวันศุกร์)* · 이태원이나 대학로 *(อิแทวอนหรือแทฮักโน)*
- **คำช่วยอื่น (을/를 · 에 · 에서 · 이/가) ตามหลังคำนามตัวสุดท้าย:** 사과나 배**를** · 집이나 도서관**에서** · 동대문시장이나 명동**에서** · 빨간색이나 노란색**이** — ตำราใช้ตำแหน่งนี้ทุกประโยค
- **อ่านออกเสียง:** 빵이나 [빵이나] — ตัวสะกดเชื่อมกับ 이 (ไม่มีกฎพิเศษ) · 책이나 [채기나]

### 📖 ตัวอย่างและการใช้
#### ตัวอย่างจากกล่องและ 준비 (338쪽)
1. 가: 무슨 영화를 자주 보세요? — 나: 코미디 영화**나** 액션 영화를 자주 봐요. *(ดูหนังอะไรบ่อย — ดูหนังตลกหรือหนังแอ็กชันบ่อย ๆ)*
2. 사과**나** 배를 주세요. *(ขอแอปเปิลหรือลูกแพร์)*
3. 빨간색**이나** 노란색이 잘 어울려요. *(สีแดงหรือสีเหลืองเข้ากันดี)*
4. 저는 아침에 빵**이나** 밥을 먹어요. *(ตอนเช้าฉันกินขนมปังหรือข้าว — 연습 1)*
5. 저는 집**이나** 도서관에서 숙제를 해요. *(ฉันทำการบ้านที่บ้านหรือห้องสมุด)*
6. 동대문시장**이나** 명동에서 옷을 사요. *(ซื้อเสื้อผ้าที่ตลาดตงแดมุนหรือเมียงดง)*
7. 이태원**이나** 대학로에 고향 음식을 먹으러 가요. *(ไปกินอาหารบ้านเกิดที่อิแทวอนหรือแทฮักโน — -(으)러 ข้อ 26)*
8. 여자 친구 생일에 향수**나** 화장품을 선물하고 싶어요. *(วันเกิดแฟนอยากให้น้ำหอมหรือเครื่องสำอาง — -고 싶다 ข้อ 38)*

#### 연습 2–4 และบทอื่น (338–343쪽)
คำตอบของ 연습 2 ที่ตำราเว้นว่างเติมตามคู่คำใน ( ) ของตำรา — ตำราให้ 보기 (비빔밥 / 김치찌개 · 금요일 / 토요일) เท่านั้น
- 점심에 뭘 자주 드세요? — 비빔밥**이나** 김치찌개를 자주 먹어요. *(กลางวันกินอะไรบ่อย — กินบิบิมบับหรือกิมจิจีเก)*
- 언제 운동을 하세요? — 금요일**이나** 토요일에 해요. *(ออกกำลังเมื่อไร — วันศุกร์หรือวันเสาร์)*
- 내일 어디에서 만날까요? — 도서관**이나** 카페에서 만나요. *(พรุ่งนี้เจอกันที่ไหน — ห้องสมุดหรือคาเฟ่ · เติมตามกฎ ตำราเว้นว่าง)* · 무슨 차를 마시고 싶어요? — 녹차**나** 커피를 마시고 싶어요. *(อยากดื่มชาอะไร — ชาเขียวหรือกาแฟ)*
- 34 읽기: 공포 영화**나** 코미디 영화를 좋아합니다. *(ชอบหนังสยองขวัญหรือหนังตลก)*
- 35 읽기: 친구**나** 부모님께 편지도 자주 씁니다. *(เขียนจดหมายถึงเพื่อนหรือพ่อแม่บ่อย ๆ — 께 ข้อ 29)* · 유명한 소설가**나** 영화감독도 되고 싶습니다. *(อยากเป็นนักเขียนนวนิยายหรือผู้กำกับภาพยนตร์ที่มีชื่อ)*
- 36 대화: 목요일**이나** 금요일 저녁에는 시간이 괜찮아요. *(คืนวันพฤหัสหรือศุกร์ว่างอยู่ — ข้อ 61)*

### 📌 เสริม คำวิเศษณ์บอกความถี่ (빈도 부사) — 준비 2 บท 34
ตำรา 338쪽 สอนคู่กับ (이)나: 빈도 부사 = **자주 · 가끔 · 거의 · 전혀** (+ 항상 ใน 활동/읽기) วางหน้ากริยา

| คำ | ความหมาย | ใช้กับ | ตัวอย่างจากตำรา |
|:---|:---|:---|:---|
| **항상** | เสมอ | ประโยคบอกเล่า | 장범준이 나오는 영화는 **항상** 봅니다. *(หนังที่มีจางบอมจุนเล่น ดูทุกเรื่อง — 34 읽기)* · 방학이 되면 **항상** 친구들과 여행을 떠납니다. *(35 읽기)* |
| **자주** | บ่อย | ประโยคบอกเล่า | 떡볶이를 **자주** 먹어요. *(กินต๊อกบกกีบ่อย)* · 무슨 영화를 **자주** 보세요? |
| **가끔** | เป็นครั้งคราว | ประโยคบอกเล่า | **가끔** 고향 생각이 나요. *(เป็นครั้งคราวคิดถึงบ้านเกิด)* · 저는 집에서 쉬거나 **가끔** 친구를 만나요. |
| **거의 안** | แทบไม่… | + ปฏิเสธ (안) | **거의 안** 가요. *(แทบไม่ไป — 연습 4)* |
| **전혀 안** | ไม่…เลย | + ปฏิเสธ (안/없다/못) | **전혀 안** 먹어요 · **전혀** 볼 수 없어요. *(ไม่กินเลย · ดูไม่ได้เลย)* |

- **ภาพรวมระดับความถี่ (연습 3):** 자주 → 가끔 → 거의 안 → 전혀 안 *(บ่อย → บางครั้ง → แทบไม่ → ไม่เลย)* · **ถาม–ตอบในตำรา:** 가: 고기를 자주 드세요? — 나: 아니요, **가끔** 먹어요. **일주일에 한 번쯤** 먹어요. *(ทานเนื้อบ่อยไหม — ไม่ค่ะ ทานเป็นครั้งคราว สัปดาห์ละครั้งประมาณ — ข้อ 52 쯤)*
- **연습 3 โจทย์ความถี่:** 운동 — 1주일에 네 번 *(อาทิตย์ละ 4 ครั้ง)* · 영화 — 1년에 한 번 *(ปีละครั้ง)* · 쇼핑 — 토요일**마다** *(ทุกวันเสาร์)* · แล้วเติมเอง: 고향 음식 · 등산 · 부모님/친구에게 전화 · 여행
- **연습 4:** 가: 압둘라 씨는 놀이공원에 자주 가세요? — 나: 네, **자주** 가요. / 아니요, **거의 안** 가요. *(คุณอับดุลลาห์ไปสวนสนุกบ่อยไหม — ไปบ่อย / ไม่ไป แทบไม่ไปเลย)*
- **마다 = ทุก…:** 토요일**마다** · 주말**마다** *(ทุกวันเสาร์ · ทุกสุดสัปดาห์ — 35 읽기)* · 날**마다** *(ทุกวัน — 35 읽기)* — ต่อท้ายนามเวลา ติดกัน (ข้อ 13)
- **거의 กับประโยคบอกเล่า = "เกือบ":** 숙제를 **거의** 다 했어요. *(ทำการบ้านเกือบหมดแล้ว)* ≠ **거의 안** 해요 *(แทบไม่ทำ)* — ตำรา 338쪽
- **전혀 มักตามด้วยปฏิเสธ:** 요즘 바빠서 텔레비전을 **전혀** 볼 수 없어요. *(ช่วงนี้ยุ่ง ดูทีวีไม่ได้เลย — -(으)ㄹ 수 없다 ข้อ 46)*

### ⚠️ จุดสับสน
#### (이)나 vs 하고/와/과 vs -거나 vs 도
| | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| N**(이)나** N | **หรือ** (เลือกหนึ่ง) | 빵**이나** 밥을 먹어요 *(กินขนมปังหรือข้าว)* |
| N**하고/와/과** N (ข้อ 11 · 19) | **และ** (ทั้งคู่) | 빵**하고** 밥을 먹어요 *(กินทั้งขนมปังและข้าว)* |
| V**-거나** V (ข้อ 57) | **หรือ** (กริยา) | 빵을 먹거나 밥을 먹어요 |
| N**도** (ข้อ 17) | **ก็…ด้วย** | 빵도 먹어요 |

- **คำนาม = (이)나 · กริยา = -거나:** ✗ 커피거나 녹차 · ✗ 마시나 → ✓ 커피나 녹차 · ✓ 마시거나
- **ตัวสะกด:** ✓ 사과나 *(สระ → 나)* / ✗ 사과이나 · ✓ 빵이나 *(ตัวสะกด → 이나)* / ✗ 빵나 · ✓ 책이나 / ✗ 책나
- **คำช่วยแสดงบทบาท (을/를) ไปต่อหลังคำนามสุดท้ายเท่านั้น:** ✓ 사과나 배를 / ✗ 사과를 배나 — ตำราไม่แสดงรูป ✗ จึงเป็นข้อสังเกตจากตัวอย่างทุกประโยค
- **이/가 ก็ต่อหลังคำนามตัวสุดท้ายเช่นกัน:** ✓ 빨간색이나 노란색**이** 잘 어울려요 / ✗ 빨간색이가 노란색이나
- **빈도 부사 + ปฏิเสธ:** ✓ 거의 안 가요 · ✓ 전혀 안 먹어요 / ✗ 전혀 먹어요 (ไม่มีปฏิเสธ) · ✓ 운동을 **거의** 안 해요 (ตำแหน่ง 안: ก่อนกริยา — ข้อ 08) · ✗ 안 거의 가요
- **좋아하다 + ปฏิเสธ:** ✓ 거의 안 좋아해요 · ✓ 좋아하지 않아요 (ข้อ 16) / ✗ 좋아 안 해요 (좋아하다 เป็นกริยาตัวเดียว — 안 ต้องอยู่หน้า · เคยพลาดมาแล้ว)
- **เว้นวรรค:** ✓ 일주일에 한 번 · 토요일마다 *(ติดกัน)* · ✓ 금요일이나 토요일 *(ติดกัน — คำช่วย)*

> [!TIP]
> **คำนามหรือกริยา?** คำนาม → N(이)나 · กริยา → -거나 · **สระ → 나 · ตัวสะกด → 이나** · 거의/전혀 ต้องมีปฏิเสธ (안/없다/못)

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- ยังไม่มีข้อสอบจริงเกี่ยวกับ (이)나 และ 빈도 부사 — 34과 อยู่ใน **복습시험④ (11/18)** และ **기말** · 쓰기 ของ 복습시험② มีหมวด "เติมคำช่วย" (조사) อยู่แล้ว (사과과 → 사과와) จึงมีโอกาสที่ (이)나 จะเป็นหนึ่งในตัวเลือก
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ (CLAUDE.md §6b):** เลือก 와/과 ผิดตามตัวสะกด **사과과 ✗ → 사과와** (복습시험② — หลังสระใช้ 와 ไม่ใช่ 과) → ใช้วิธีเดียวกันตรวจ (이)나: สระ → 나 · ตัวสะกด → 이나 · **ใช้ 하고 แทน 에** (학생식당하고 가요 ✗) → เลือกคำช่วยจากความหมาย · ㄱ ตกหลังคำนาม (한구 ✗ → 한국)
- **คาดการณ์รูปแบบข้อสอบ** (เดาจากรูปแบบ 복습시험①②):
  1. **เติมคำช่วย:** 빵 ( ) 밥 · 사과 ( ) 배 · 금요일 ( ) 토요일 → (이)나 / 나 ตามตัวสะกด (6 ข้อ × 4 แต้มแบบหมวด 1–2 ของ 복습시험①)
  2. **ตอบคำถามด้วยไวยากรณ์ที่กำหนด:** 무슨 영화를 자주 보세요? → ___(이)나 ___를 자주 봐요 · 점심에 뭘 자주 드세요?
  3. **เติมคำวิเศษณ์ + ปฏิเสธ:** 고기를 ( ) 안 먹어요 (ตัวเลือก 자주/가끔/거의/전혀) · ผิดมักเป็นการวาง 전혀 กับประโยคบอกเล่า
  4. **읽기 34-2:** "공포 영화나 코미디 영화를 좋아합니다 / 장범준이 나오는 영화는 항상 봅니다" — เหมาะแปลงเป็นบทสนทนา 가/나 และตอบ "투이 씨는 어떤 영화를 자주 봐요?"
