## 28. -(으)ㄹ 거예요 (จะ... / คงจะ...)
บอก**แผนในอนาคต** (ประธานเป็น ฉัน/คุณ) หรือ**การคาดเดา** (ประธานเป็นบุคคลที่ 3 หรือเป็นคำคุณศัพท์) — รูปสุภาพ เติมท้ายรากศัพท์ (어간) แล้วตามด้วย 거예요
สอนในบท 19 (교과서 172–173쪽) · ต่อยอดจาก ข้อ 06 (หารากศัพท์) · ข้อ 23 (เลือกกาลจากเวลา) · ข้อ 26 (-(으)러)
ใช้ต่อใน ข้อ 32 · ข้อ 33 · ข้อ 35 (ตาราง 받침) และงานพูด 발표 방학 계획 (10/20)

### 📌 รูปแบบและเงื่อนไข
ตัด 다 ทิ้งก่อน แล้วดู**พยางค์สุดท้ายของราก**ว่ามีตัวสะกด (받침) ไหม

| รากศัพท์ลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| ไม่มีตัวสะกด (รวม ㅡ · 하다) | **-ㄹ 거예요** | 가다 → **갈 거예요** · 보다 → **볼 거예요** · 쓰다 → **쓸 거예요** · 하다 → **할 거예요** *(จะไป · จะดู · จะเขียน · จะทำ)* |
| มีตัวสะกด (รวม 있다) | **-을 거예요** | 읽다 → **읽을 거예요** · 먹다 → **먹을 거예요** · 있다 → **있을 거예요** *(จะอ่าน · จะกิน · จะอยู่)* |
| ลงท้ายด้วย **ㄹ** | เติมแค่ **거예요** — ㄹ ของรากเป็น ㄹ ของรูปนี้อยู่แล้ว (ไม่ซ้ำ ㄹ · ไม่ใส่ 을) | 만들다 → **만들 거예요** · 살다 → **살 거예요** · 놀다 → **놀 거예요** *(จะทำ · จะอยู่ · จะเล่น)* |
| คำนาม | N + **일 거예요** (ไม่ดูตัวสะกด) | 선생님**일 거예요** · 학생**일 거예요** *(คงเป็นอาจารย์ · คงเป็นนักเรียน)* |
| ยกย่อง -(으)시- | **-(으)실 거예요** | 하다 → **하실 거예요** · 오다 → **오실 거예요** *(ท่านจะทำ · ท่านจะมา)* |

- **ความหมายตามประธาน (ตำรา 172쪽):** ประธาน ฉัน/คุณ → "ตั้งใจ / วางแผนว่าจะ…" · ประธานบุคคลที่ 3 หรือคำคุณศัพท์ → "คงจะ…" (ผู้พูดเดา) เช่น 날씨가 좋**을 거예요** *(อากาศคงจะดี)*
- ใช้ได้กับกริยา · คำคุณศัพท์ · N일 — รูปไม่เปลี่ยนตามบุรุษ · ปฏิเสธใส่ 안 หน้ากริยา (ข้อ 08): 안 갈 거예요 *(จะไม่ไป)*
- **ที่มาของการสะกด:** 거예요 = 것 *({n:สิ่ง}ที่/{n:เรื่อง}ที่)* + 이에요 → ต้องมี **예** และเว้นวรรคจากราก: **갈 거예요** (✗ 거요 · ✗ 거에요 · ✗ 갈거예요)
- **ออกเสียง:** 할 거예요 [할 꺼예요] · 읽을 거예요 [일글 꺼예요] · 먹을 거예요 [머글 꺼예요] — ㄱ หลัง ㄹ ออกเสียงเป็น ㄲ

### 📖 ตัวอย่างและการใช้
#### เลือกกาลจากคำบอกเวลา
| คำบอกเวลา | กาล | ตัวอย่าง |
|:---|:---|:---|
| 어제 · 지난주에 · 작년에 | -았/었/였어요 (ข้อ 23) | 어제 학교에 **갔어요** *(เมื่อวานไปโรงเรียน)* |
| 지금 · 매일 | -아/어요 (ข้อ 06) | 지금 학교에 **가요** *(ตอนนี้ไปโรงเรียน)* |
| 내일 · 모레 · 다음 주에 · 방학에 · 이번 주말에 | **-(으)ㄹ 거예요** | 내일 학교에 **갈 거예요** *(พรุ่งนี้จะไปโรงเรียน)* |

ปัจจุบันแทนอนาคตได้ (내일 학교에 가요) แต่ **갈 거예요** ชัดเจนว่าเป็น**แผน** · เปลี่ยนเฉพาะท้ายราก — ฝึกผัน 3 กาล (연습지 19과 A):

| 동사 | -아/어요 | -았/었어요 | -(으)ㄹ 거예요 |
|:---|:---|:---|:---|
| 오다 *(มา)* | 와요 | 왔어요 | **올 거예요** |
| 읽다 *(อ่าน)* | 읽어요 | 읽었어요 | **읽을 거예요** |
| 만들다 *(ทำ)* | 만들어요 | 만들었어요 | **만들 거예요** |
| 살다 *({v:อยู่อาศัย})* | 살아요 | 살았어요 | **살 거예요** |

#### ตอบให้ตรงกับคำถาม
เลือกชนิดคำตอบตามคำถาม (ข้อ 12 · ส่วนที่ 3) — ครูวาดวง **언제** เป็นคำถามเวลารวม ครอบคลุม 며칠 · 몇 시 · 무슨 요일 · 몇 월: ทุกแบบต้องตอบเป็น**เวลา**

| ถามด้วย | ตอบเป็น | ตัวอย่าง |
|:---|:---|:---|
| 뭐 · 무엇을 | **กิจกรรม** (+ 을/를) | 가: 오늘 오후에 뭐 할 거예요? — 나: 친구를 **만날 거예요**. *({n:บ่ายนี้}{e:จะ}{v:ทำ}{q:อะไร} — {e:จะ}{v:พบ}{n:เพื่อน})* |
| **언제** · 몇 시에 | **เวลา** (วัน/เดือน/ช่วง + 에) | 가: 언제 고향에 갈 거예요? — 나: **방학에** 고향에 갈 거예요. *({e:จะ}{v:กลับ}{n:บ้านเกิด}{q:เมื่อไหร่} — {p:ช่วง}{n:ปิดเทอม})* · 가: 몇 시에 갈 거예요? — 나: 오후 두 시에 갈 거예요. |
| 어디에 · 어디에서 | **สถานที่** (에 = ไป · 에서 = ทำที่) | 가: 친구와 같이 어디에 갈 거예요? — 나: 서울타워에 갈 거예요. *({e:จะ}{v:ไป}{q:ไหน}{p:กับ}{n:เพื่อน} — {n:หอคอยโซล})* |
| 누구하고 | **คน** + 하고 | 가: 누구하고 갈 거예요? — 나: 친구하고 같이 갈 거예요. *({e:จะ}{v:ไป}{p:กับ}{q:ใคร} — {v:ไป}{p:กับ}{n:เพื่อน})* |

#### 📽️ สไลด์อาจารย์ (교과서 172쪽)
สไลด์ 문법 2 มีบทสนทนา 3 คู่ และตารางตามตัวสะกด (○ → 을 · ✗ → ㄹ · ㄹ → ㄹ — รวมอยู่ใน 📌 แล้ว):

- 가: 내일 뭐 **할 거예요**? — 나: 쇼핑**할 거예요**. *({a:พรุ่งนี้}{e:จะ}{v:ทำ}{q:อะไร} — {e:จะ}{v:ไป}{n:ช็อปปิง})*
- 가: 주말에 뭐 **할 거예요**? — 나: 도서관에서 책을 **읽을 거예요**. *({n:สุดสัปดาห์}{e:จะ}{v:ทำ}{q:อะไร} — {e:จะ}{v:อ่าน}{n:หนังสือ}{p:ที่}{n:ห้องสมุด})*
- 가: 언제 대학교에 **갈 거예요**? — 나: 내년에 대학교에 **갈 거예요**. *({e:จะ}{v:ไป}{n:มหาวิทยาลัย}{q:เมื่อไหร่} — {n:ปีหน้า})*

#### ตัวอย่างประโยค
1. 내일 영화를 **볼 거예요**. *(พรุ่งนี้จะดูหนัง)*
2. 집에서 책을 **읽을 거예요**. *(จะอ่านหนังสือที่บ้าน)*
3. 오늘 저녁에 한국 음식을 **만들 거예요**. *({n:เย็น}{a:นี้}{e:จะ}{v:ทำ}{n:อาหารเกาหลี})*
4. 이번 주말에 뭐 **할 거예요**? — 전시회를 **보러** 덕수궁 미술관에 **갈 거예요**. *(สุดสัปดาห์นี้จะทำอะไร — จะไปหอศิลป์ท็อกซูกุงเพื่อดูนิทรรศการ · -(으)러 ข้อ 26 ใช้ร่วมกันได้)*
5. 내일은 날씨가 **좋을 거예요**. *(พรุ่งนี้อากาศคงจะดี)*
6. 저분은 아마 우리 학교 선생님**일 거예요**. *(ท่านนั้นคงเป็นอาจารย์ของโรงเรียนเรา)*
7. 불고기를 **먹을 거예요**. 그리고 학교를 **구경할 거예요**. *({e:จะ}{v:กิน}{n:บุลโกกิ} {a:แล้วก็}{e:จะ}{v:เที่ยวชม}{n:โรงเรียน})*

### ⚠️ จุดสับสน
#### -(으)ㄹ 거예요 vs -겠- vs -(으)ㄹ까요?
"จะ" ในภาษาไทยมีคำเดียว แต่เกาหลีแยกหลายรูป หน้าที่ต่างกัน (ดูข้อ 22 สำหรับ -겠- · ข้อ 33 สำหรับ -(으)ㄹ까요?)

| | -(으)ㄹ 거예요 | -겠- (ข้อ 22) | -(으)ㄹ까요? (ข้อ 33) |
|:---|:---|:---|:---|
| ความหมาย | แผน / คาดการณ์ | ตั้งใจ**ทันที** / สูตรสุภาพ | ชวน / ถามความเห็น |
| ประธาน | ทุกบุรุษ | บุรุษที่ 1 (ถามผู้ฟังได้) | 우리 (เรา) |
| ตัวอย่าง | 내일 갈 거예요 | 제가 하겠습니다 | 같이 갈까요? |

- ✓ 저는 내일 **갈 거예요**. *(ฉันพรุ่งนี้จะไป — แผน)* · ✓ 친구가 **갈 거예요**. *(เพื่อนจะไป / คงไป)*
- ✓ 내일 **갈 거예요?** *(คุณพรุ่งนี้จะไปไหม — ถามแผน)* ≠ 같이 **갈까요?** *(ไปด้วยกันไหม — ชวน)*
- ✓ 학생**일 거예요**. *(คงเป็นนักเรียน)* · ✓ 선생님이 **오실 거예요**. *(อาจารย์คงจะมา / จะมา)*

#### กับดักที่เจอบ่อย
- **ㄹ-ราก:** ✓ 살 거예요 / ✗ 살을 거예요 · ✓ 놀 거예요 / ✗ 놀을 거예요 · ✓ 만들 거예요 / ✗ 만들을 거예요
- **สะกด:** ✗ 갈 거에요 · ✗ 갈 거요 · ✗ 갈거예요 → ✓ **갈 거예요** (มี 예 และเว้นวรรค)
- **일 거예요** ใช้ต่อท้าย**คำนาม**เท่านั้น: ✓ 학생일 거예요 / ✗ 가일 거예요
- **คำเวลา:** 내일 · 모레 · 오늘 · 지금 · 매일 ไม่ใส่ 에 (ข้อ 10) แต่ 방학에 · 주말에 · 저녁에 ใส่ 에
- **ตอบไม่ตรงคำถาม:** 언제 → เวลา ไม่ใช่กิจกรรม · 어디에서 → สถานที่ ไม่ใช่คน (ดู 📖 ตาราง "ตอบให้ตรงกับคำถาม")

> [!TIP]
> **แผนของตัวเอง/คาดเดา = ㄹ 거예요 · ตั้งใจแน่วแน่ตอนนี้ = 겠 · ชวนกัน = ㄹ까요?**
