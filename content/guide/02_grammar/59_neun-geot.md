## 59. -는 것 (การ…/ที่…ทำ — ทำกริยาให้เป็นคำนาม)
เปลี่ยน**กริยา**ให้เป็นคำนาม "การ…" ด้วย **รากกริยา + -는 + 것** แล้วใช้เป็นประธาน/กรรม/ภาคแสดงได้ — 운동하는 것 *(การออกกำลังกาย)* · 영화 보는 것 *(การดูหนัง)* — ตำราบอกว่าใช้กับกริยา และกับคำคุณศัพท์ที่ลงท้าย 있다/없다
สอนในบท 35 (교과서 344–345쪽 · 준비 1) · ต่อยอดจาก ข้อ 44 (-는 ขยายนาม บท 27) · ข้อ 56 (-(으)ㄹ 것 "ของที่จะ…") · ข้อ 07 (을/를) · ข้อ 01 (이/가 ↔ 은/는)
ใช้ต่อใน ข้อ 41 (-는 것보다 -는 것을 좋아해요) · ข้อ 60 · 읽기 บท 35 (사진 찍는 것을 좋아해서) และ 말하기 หัวข้อ 취미 *(งานอดิเรก)*

### 📌 รูปแบบและเงื่อนไข
| รากศัพท์ลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| กริยา (สระหรือตัวสะกด) | **-는 것** (ไม่ดูตัวสะกด) | 보다 → **보는 것** · 먹다 → **먹는 것** · 하다 → **하는 것** · 운동하다 → **운동하는 것** *(การดู · การกิน · การทำ · การออกกำลังกาย)* |
| ลงท้าย **ㄹ** | **ㄹ หลุด** + 는 것 | 살다 → **사는 것** · 만들다 → **만드는 것** · 놀다 → **노는 것** · 팔다 → **파는 것** *(การอยู่ · การทำ · การเล่น · การขาย)* |
| 있다 / 없다 (รวม 맛있다 · 재미있다) | **-는 것** | 있다 → **있는 것** · 없다 → **없는 것** · 시간이 **없는 것** *(การมี · การไม่มี · การไม่มีเวลา)* |
| ㅂ · ㄷ · 르 (กริยา) | ไม่เปลี่ยน — 는 ขึ้นต้นด้วย ㄴ | 걷다 → **걷는 것** · 듣다 → **듣는 것** · 돕다 → **돕는 것** · 부르다 → **부르는 것** |
| ยกย่อง -(으)시- | **-(으)시는 것** | 하다 → **하시는 것** *(เสริม)* |

- **ตำรา 344쪽:** "ต่อหลังรากของกริยา หรือ 있다/없다 เพื่อทำเป็นรูปนาม — ถ้ารากลงท้าย ㄹ ให้ตัด ㄹ" (**ㄹ-stem: ㄹ หลุด** เหมือน -는 ข้อ 44)
- **ตำแหน่งในประโยค:** [ส่วนกริยา + 는 것] + **คำช่วย** (이/가 · 은/는 · 을/를 · 도 · 보다) + ภาคแสดง — 영화 보는 것**을** 좋아해요 · 걷는 것**은** 건강에 좋아요
- **"것" เขียนเว้นวรรคเสมอ** (นามพึ่งพา — ข้อ 13): 보는 **것** · ✗ 보는것
- **ภาคแสดงที่พบบ่อยกับ -는 것:** 좋아하다 · 싫어하다 · 좋다 · 어렵다 · 쉽다 · 재미있다 · 즐겁다 · 건강에 좋다 · 문제이다 · 취미이다 · 어때요?
- **คำคุณศัพท์ทั่วไปทำเป็นนามไม่ได้ด้วย -는 것** — ใช้ -(으)ㄴ 것 *(สิ่งที่…)* เช่น 매운 것 · 큰 것 (เสริม ข้อ 36 + 56)

### 📖 ตัวอย่างและการใช้
#### จากกล่องไวยากรณ์และ 준비 (344쪽)
1. 영화 **보는 것**을 좋아해요. *(ชอบการดูหนัง)*
2. 시간이 **없는 것**이 문제입니다. *(การที่ไม่มีเวลาคือปัญหา — 이 + 입니다 ข้อ 02)*
3. **걷는 것**은 건강에 좋아요. *(การเดินดีต่อสุขภาพ — ㄷ ไม่เปลี่ยน)*
4. 외국에서 **사는 것**은 쉽지 않습니다. *(การอยู่ต่างประเทศไม่ใช่เรื่องง่าย — 살다 → 사는 · -지 않다 ข้อ 16)*

#### 연습 1 (344쪽) ผันเป็น -는 것
| โจทย์ | ประโยค | แปล |
|:---|:---|:---|
| 운동하다 | **운동하는 것**을 싫어해요. | ไม่ชอบการออกกำลังกาย |
| 음악을 듣다 | **음악을 듣는 것**을 좋아해요. | ชอบการฟังเพลง |
| 영화를 보다 | **영화를 보는 것**이 제 취미예요. | การดูหนังคืองานอดิเรกของฉัน |
| 노래를 부르다 | **노래를 부르는 것**을 좋아하세요? | ชอบการร้องเพลงไหม |
| 단어를 설명하다 | **단어를 설명하는 것**이 어려워요. | การอธิบายคำศัพท์ยาก |
| 기숙사에 살다 | **기숙사에 사는 것**이 어때요? | การอยู่หอพักเป็นยังไงบ้าง — ㄹ หลุด |

#### 연습 2–3 และบทสนทนา (345–351쪽)
- 가: 제프리 씨, 취미가 뭐예요? — 나: 저는 **운동하는 것**을 좋아해요. *(คุณเจฟฟรีย์ งานอดิเรกคืออะไร — ฉันชอบการออกกำลังกาย)* · รูป: 영화 보다 · 음악 듣다 · 음식 만들다 · 춤추다 · 콘서트에 가다 · 여행하다 · 게임하다 · 사진 찍다 · 산책하다 *(ดูหนัง · ฟังเพลง · ทำอาหาร · เต้น · ไปคอนเสิร์ต · เที่ยว · เล่นเกม · ถ่ายรูป · เดินเล่น)*
- 가: **혼자 영화 보는 것**을 좋아하세요? — 나: 네, 아주 좋아해요. / 아니요, 싫어해요. *(ชอบดูหนังคนเดียวไหม — ชอบมาก / ไม่ค่ะ ไม่ชอบ)* · โจทย์ถามเพื่อน: 혼자 영화를 보다 · 그림을 그리다 · 혼자 식사하다 · 외국어 공부를 하다 · 편지를 쓰다 · 앞자리에 앉다 *(ดูหนังคนเดียว · วาดรูป · กินข้าวคนเดียว · เรียนภาษาต่างประเทศ · เขียนจดหมาย · นั่งแถวหน้า)*
- 35-1 (348쪽): 윤아: 간토야 씨, **운동하는 것**을 좋아하세요? — 간토야: 아니요, **하는 것**보다 **보는 것**을 좋아해요. *(คุณคันโตยะ ชอบการออกกำลังกายไหม — ไม่ค่ะ ชอบดูมากกว่าเล่นเอง — 보다 ข้อ 41)*
- 간토야: 저는 **춤추는 것**을 좋아하지 않아요. 하지만 윤아 씨가 **하는 것**을 보러 가고 싶어요. *(ฉันไม่ชอบการเต้น แต่อยากไปดูคุณยุนอาเต้น — -지 않다 ข้อ 16 · -(으)러 ข้อ 26)*
- 연습 3 ของ 35 (347쪽): 가: 명동에서는 무엇을 **하는 것**이 좋아요? *(ที่เมียงดงทำอะไรดี)* · 가: 음식은 뭘 **먹는 것**이 좋아요? — 나: 명동은 칼국수가 유명해요. 칼국수를 먹어 보세요. *(อาหารกินอะไรดี — เมียงดงขึ้นชื่อเรื่องคัลกุกซู ลองกินดูสิ — ข้อ 60)*
- 35-2 읽기 (350쪽): 사진 **찍는 것**을 좋아해서 주말마다 밖으로 사진을 찍으러 나갑니다. *(ชอบการถ่ายรูปจึงออกไปถ่ายรูปข้างนอกทุกสุดสัปดาห์)* · 또 여행**하는 것**도 좋아합니다. *(และชอบการเที่ยวด้วย)* · 글을 **쓰는 것**도 좋아합니다. *(ชอบการเขียนด้วย — ㅡ ไม่หลุด: 쓰는)* · 여러 사람을 **만나는 것**도 즐겁고 *(การพบผู้คนมากมายก็สนุก)*

### ⚠️ จุดสับสน
#### -는 것 vs -(으)ㄹ 것 vs -(으)ㄴ 것 vs -(으)ㄹ 거예요
| | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| 먹**는 것** (ข้อ 59) | **การกิน** (นามจากกริยา ปัจจุบัน/ทั่วไป) | 먹는 것을 좋아해요 *(ชอบการกิน)* |
| 먹**을 것** (ข้อ 56) | **ของที่จะกิน** | 먹을 것이 없어요 *(ไม่มีของกิน)* |
| 먹**은 것** (ข้อ 47) | **ของที่กินไปแล้ว** | 어제 먹은 것이 맛있었어요 *(ที่กินเมื่อวานอร่อย)* |
| 먹**을 거예요** (ข้อ 28) | **จะกิน** (แผน) | 내일 먹을 거예요 |

- **좋아하다 รับ 을/를 · 좋다 รับ 이/가:** ✓ 운동하는 것**을** 좋아해요 · ✓ 운동하는 것**이** 좋아요 / ✗ 운동하는 것이 좋아해요 · ✗ 운동하는 것을 좋아요 (ข้อ 07 — เหมือนกับดักที่เคย "ใช้ 가 กับกริยาที่ต้องการ 을/를")
- **싫어하다 รับ 을/를 · 싫다 รับ 이/가:** ✓ 운동하는 것을 싫어해요 · ✓ 운동하는 것이 싫어요
- **นามเดี่ยว ๆ ไม่ต้อง -는 것:** ✓ 운동을 좋아해요 · ✓ 영화를 좋아해요 — เมื่อมี**กรรมของกริยา** (영화를 보다) จึงต้องทำเป็น 영화 보는 것 · ✗ 영화를 보를 좋아해요
- **ㄹ-ราก:** ✓ 사는 것 · 만드는 것 · 노는 것 / ✗ 살는 것 · 만들는 것 (ㄹ หลุด) — ต่างจาก -(으)ㄹ 것 ที่ ㄹ คงอยู่ (살 것 · 만들 것)
- **ตำแหน่ง ปฏิเสธ:** ✓ 운동하는 것을 좋아하지 않아요 · ✓ 운동하는 것을 안 좋아해요 / ✗ 운동하는 것을 좋아 안 해요 (좋아하다 เป็นกริยาเดี่ยว 안 ต้องอยู่หน้า — เคยพลาด) · ข้อ 08 · 16
- **ประธานของ -는 것:** ละได้เมื่อเป็นผู้พูด: 사진 찍는 것을 좋아해요 *(ฉันชอบถ่ายรูป)* · ใส่ประธานเมื่อต่างคน: **윤아 씨가** 하는 것
- **-는 것보다 -는 것을** = "ชอบ B มากกว่า A": **하는 것보다 보는 것을** 좋아해요 (ตำรา 348쪽) — รูปเทียบของ ข้อ 41 (N보다)

> [!TIP]
> **-는 것 = "การ…" · 좋아하다/싫어하다 + 을/를 · 좋다/싫다/어렵다 + 이/가 · ㄹ-ราก: ㄹ หลุด (사는 것) · 것 เว้นวรรค**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- ยังไม่มีข้อสอบจริงเกี่ยวกับ -는 것 — 35과 อยู่ใน **복습시험④ (11/18)** และ **기말** · "취미가 뭐예요?" เป็นคำถามพื้นฐานของ 말하기 (เรื่อง 취미/주말 อยู่ในบทพูด 자기 소개 อยู่แล้ว)
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ (CLAUDE.md §6b):** ★ **좋아 안 해요** แทน 안 좋아해요 (복습문제 쓰기 9-3) → ใช้ 좋아하지 않아요 · **คำช่วยผิดตามกริยา** — 시계가 받았어요 · 이야기가 들었어요 (ใช้ 가 กับกริยาที่ต้องการ 을/를) → กับ 좋아하다 ต้อง 을/를 · ตอบไม่ตรงคำถาม · ลืม 으 (읽세요) · ㅈ/ㅊ (책 → 젝 · 몇 → 몆 · 저 → 처)
- **คาดการณ์รูปแบบข้อสอบ** (เดาจากรูปแบบ 복습시험①②):
  1. **เปลี่ยนเป็น -는 것:** 운동하다 → 운동하는 것을 좋아해요 · 기숙사에 살다 → ___이 어때요? (เน้น ㄹ-ราก)
  2. **เลือกคำช่วย:** 운동하는 것( )좋아해요 / 운동하는 것( )좋아요 → 을 / 이
  3. **ตอบ:** 취미가 뭐예요? → 저는 ___-는 것을 좋아해요 · 운동하는 것을 좋아하세요? → 아니요, 하는 것보다 보는 것을 좋아해요
  4. **읽기 35-2 → บทสนทนา:** "사진 찍는 것을 좋아해서 주말마다 사진을 찍으러 나갑니다" → 친구: 취미가 뭐예요? / 바트: 사진 찍는 것을 좋아해요 (ตามแบบ "읽은 내용을 대화로 만들어 봅시다" 351쪽)
