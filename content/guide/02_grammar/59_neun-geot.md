## 59. -는 것 (การ…/ที่…ทำ — ทำกริยาให้เป็นคำนาม)

> [!INTRO] ข้อนี้คืออะไร
> -는 것 คือการเปลี่ยน**กริยา**ให้เป็นคำนามที่แปลว่า "การ…" ด้วยสูตร **รากกริยา + -는 + 것** แล้วนำไปใช้เป็นประธาน กรรม หรือภาคแสดงได้ เช่น 운동하는 것 *(การออกกำลังกาย)* · 영화 보는 것 *(การดูหนัง)* ตำราบอกว่าใช้กับกริยา และกับคำคุณศัพท์ที่ลงท้าย 있다/없다
>
> สอนในบท 35 (교과서 344–345쪽 · 준비 1) ต่อยอดจาก ข้อ 44 (-는 ขยายนาม บท 27) · ข้อ 56 (-(으)ㄹ 것 "ของที่จะ…") · ข้อ 07 (을/를) และ ข้อ 01 (이/가 ↔ 은/는)
>
> ไปใช้ต่อใน ข้อ 41 (-는 것보다 -는 것을 좋아해요) · ข้อ 60 · 읽기 บท 35 (사진 찍는 것을 좋아해서) และ 말하기 หัวข้อ 취미 *(งานอดิเรก)*

### 📌 รูปแบบและเงื่อนไข

รูปนี้ไม่ดูตัวสะกดของราก ต่อ **-는 것** หลังรากกริยาเสมอ มีเงื่อนไขพิเศษเพียงข้อเดียวคือรากที่ลงท้าย ㄹ ซึ่งตัว ㄹ จะหลุดเหมือน -는 ในข้อ 44 ตารางแรกสรุปกฎ ส่วนตารางที่สองให้ตัวอย่างของแต่ละแบบ

| รากศัพท์ลงท้าย | ต่อ |
|:---|:---|
| กริยา (สระหรือตัวสะกด) | **-는 것** (ไม่ดูตัวสะกด) |
| ลงท้าย **ㄹ** | **ㄹ หลุด** + 는 것 |
| 있다 / 없다 (รวม 맛있다 · 재미있다) | **-는 것** |
| ㅂ · ㄷ · 르 (กริยา) | ไม่เปลี่ยน — 는 ขึ้นต้นด้วย ㄴ |
| ยกย่อง -(으)시- | **-(으)시는 것** |

#### ตัวอย่างตามชนิดของราก

ทุกแถวคือรากกริยา + -는 것 ที่แปลว่า "การ…" สังเกตรากที่ลงท้าย ㄹ ซึ่ง ㄹ หายไปก่อนต่อ 는

| รากลงท้าย | 기본형 → -는 것 | ไทย |
|:---|:---|:---|
| กริยา | 보다 → **보는 것** | การดู |
| กริยา | 먹다 → **먹는 것** | การกิน |
| กริยา | 하다 → **하는 것** | การทำ |
| กริยา | 운동하다 → **운동하는 것** | การออกกำลังกาย |
| ㄹ | 살다 → **사는 것** | การอยู่ |
| ㄹ | 만들다 → **만드는 것** | การทำ |
| ㄹ | 놀다 → **노는 것** | การเล่น |
| ㄹ | 팔다 → **파는 것** | การขาย |
| 있다 / 없다 | 있다 → **있는 것** | การมี |
| 있다 / 없다 | 없다 → **없는 것** | การไม่มี |
| 있다 / 없다 | 시간이 **없는 것** | การไม่มีเวลา |
| ㄷ | 걷다 → **걷는 것** | การเดิน |
| ㄷ | 듣다 → **듣는 것** | การฟัง |
| ㅂ | 돕다 → **돕는 것** | การช่วย |
| 르 | 부르다 → **부르는 것** | การร้อง |
| ยกย่อง -(으)시- (เสริม) | 하다 → **하시는 것** | การที่ท่านทำ |

#### ข้อความของตำราและข้อควรรู้

ตำราหน้า 344 อธิบายกฎไว้สั้น ๆ ส่วนข้อควรรู้คือตำแหน่งของ 는 것 ในประโยค การเขียน 것 และคำคุณศัพท์ที่ใช้รูปนี้ไม่ได้

- **ตำรา 344쪽:** "ต่อหลังรากของกริยา หรือ 있다/없다 เพื่อทำเป็นรูปนาม — ถ้ารากลงท้าย ㄹ ให้ตัด ㄹ" (**ㄹ-stem: ㄹ หลุด** เหมือน -는 ข้อ 44)
- **ตำแหน่งในประโยค:** [ส่วนกริยา + 는 것] + **คำช่วย** (이/가 · 은/는 · 을/를 · 도 · 보다) + ภาคแสดง
  - 영화 보는 것**을** 좋아해요 *(ชอบการดูหนัง)*
  - 걷는 것**은** 건강에 좋아요 *(การเดินดีต่อสุขภาพ)*
- **"것" เขียนเว้นวรรคเสมอ** (นามพึ่งพา — ข้อ 13): 보는 **것** · ✗ 보는것
- **คำคุณศัพท์ทั่วไปทำเป็นนามไม่ได้ด้วย -는 것** — ใช้ -(으)ㄴ 것 *(สิ่งที่…)* เช่น 매운 것 *(ของที่เผ็ด)* · 큰 것 *(ของที่ใหญ่)* (เสริม ข้อ 36 + 56)

#### ภาคแสดงที่พบบ่อยกับ -는 것

ภาคแสดงในตารางนี้พบบ่อยที่สุดหลัง [กริยา + 는 것] โดย 좋아하다 กับ 싫어하다 รับ 을/를 ส่วนที่เหลือส่วนใหญ่รับ 이/가

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|
| 좋아하다 | ชอบ | 싫어하다 | ไม่ชอบ |
| 좋다 | ดี | 어렵다 | ยาก |
| 쉽다 | ง่าย | 재미있다 | สนุก |
| 즐겁다 | สนุกสนาน | 건강에 좋다 | ดีต่อสุขภาพ |
| 문제이다 | เป็นปัญหา | 취미이다 | เป็นงานอดิเรก |
| 어때요? | เป็นอย่างไร | | |

#### สูตรและวิธีทำ: -는 것 (แบบกระดานครู)

-는 것 ต่อท้ายรากกริยาโดยไม่ดูตัวสะกด สิ่งเดียวที่ต้องเช็กคือรากลงท้าย ㄹ หรือไม่ ซึ่งใช้กฎ ㄹ หลุดแบบเดียวกับที่ครูเขียนบนกระดานวันที่ 10/28 กฎมีสามข้อ

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | รากกริยา หรือ 있다/없다 (ลงท้ายสระหรือตัวสะกดก็ได้) | ต่อ **-는 것** ตรง ๆ | 는 ไม่มี (으) จึงไม่ต้องเลือกตามตัวสะกด |
| **กฎ 2** | รากลงท้าย **ㄹ** | **ตัด ㄹ ของราก** ก่อนต่อ 는 | 는 ขึ้นต้นด้วย ㄴ และ ㄹ ไม่อยู่หน้า ㄴ |
| **กฎ 3** | รากไม่ปกติ ㅂ · ㄷ · 르 (กริยา) | **ไม่เปลี่ยนรูป** | 는 ขึ้นต้นด้วยพยัญชนะ รากไม่ปกติเปลี่ยนเฉพาะก่อนสระ |

ลำดับทำคือ ① ดูว่ารากลงท้าย ㄹ หรือไม่ ② ถ้าใช่ให้ตัด ㄹ ทิ้ง ③ ต่อ 는 แล้วเว้นวรรคเขียน 것 ตารางนี้แสดงทุกขั้นกับกริยาที่ตำราใช้

| ราก + คำต่อ | ① ลงท้าย ㄹ หรือไม่? | ② ตัด ㄹ ของราก | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 보 + -는 것 | ไม่ใช่ (ลงท้ายสระ) | ไม่ตัด | **보는 것** | 영화 보는 것 |
| 먹 + -는 것 | ไม่ใช่ (ตัวสะกด ㄱ) | ไม่ตัด | **먹는 것** | ไม่ใช่ 먹은 것 ซึ่งแปลว่า "ที่กินไปแล้ว" |
| 하 + -는 것 | ไม่ใช่ (ลงท้ายสระ) | ไม่ตัด | **하는 것** | 운동하는 것 |
| 살 + -는 것 | ใช่ | ตัด ㄹ | **사는 것** | ✗ 살는 것 |
| 만들 + -는 것 | ใช่ | ตัด ㄹ | **만드는 것** | ✗ 만들는 것 |
| 있 + -는 것 | ไม่ใช่ (ตัวสะกด ㅆ) | ไม่ตัด | **있는 것** | 없는 것 ต่อแบบเดียวกัน |
| 걷 + -는 것 | ไม่ใช่ (ตัวสะกด ㄷ) | ไม่ตัด | **걷는 것** | ㄷ ไม่เปลี่ยนเป็น ㄹ เพราะ 는 ไม่ใช่สระ |
| 돕 + -는 것 | ไม่ใช่ (ตัวสะกด ㅂ) | ไม่ตัด | **돕는 것** | ㅂ ไม่เปลี่ยนเป็น 우 |

> [!TIP] วิธีจำสั้น ๆ
> เห็นรากลงท้าย ㄹ ให้ตัด ㄹ ก่อนต่อ 는 เช่น 살다 เป็น 사는 것 รากอื่นต่อ 는 ได้เลยไม่ว่าจะมีตัวสะกดหรือไม่ และต้องเว้นวรรคก่อน 것 เสมอ

### 📖 ตัวอย่างและการใช้

ตัวอย่างเรียงตามตำราบท 35 เริ่มจากกล่องไวยากรณ์ 준비 ไปถึงแบบฝึก 연습 บทสนทนา 35-1 และบทอ่าน 35-2 สังเกตว่าตำราใช้ -는 것 กับเรื่องงานอดิเรกเป็นหลัก

#### จากกล่องไวยากรณ์และ 준비 (344쪽)

สี่ประโยคนี้แสดง 는 것 ทำหน้าที่ทั้งเป็นกรรมและเป็นประธาน

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 영화 **보는 것**을 좋아해요. | ชอบการดูหนัง | 344쪽 |
| 시간이 **없는 것**이 문제입니다. | การที่ไม่มีเวลาคือปัญหา — 이 + 입니다 ข้อ 02 | 344쪽 |
| **걷는 것**은 건강에 좋아요. | การเดินดีต่อสุขภาพ — ㄷ ไม่เปลี่ยน | 344쪽 |
| 외국에서 **사는 것**은 쉽지 않습니다. | การอยู่ต่างประเทศไม่ใช่เรื่องง่าย — 살다 → 사는 · -지 않다 ข้อ 16 | 344쪽 |

#### 연습 1 (344쪽): ผันเป็น -는 것

โจทย์ให้กริยาหนึ่งตัว แล้วให้แต่งประโยคที่ใช้ -는 것 เป็นกรรม ประธาน หรือภาคแสดง

| โจทย์ | ประโยค | แปล |
|:---|:---|:---|
| 운동하다 | **운동하는 것**을 싫어해요. | ไม่ชอบการออกกำลังกาย |
| 음악을 듣다 | **음악을 듣는 것**을 좋아해요. | ชอบการฟังเพลง |
| 영화를 보다 | **영화를 보는 것**이 제 취미예요. | การดูหนังคืองานอดิเรกของฉัน |
| 노래를 부르다 | **노래를 부르는 것**을 좋아하세요? | ชอบการร้องเพลงไหม |
| 단어를 설명하다 | **단어를 설명하는 것**이 어려워요. | การอธิบายคำศัพท์ยาก |
| 기숙사에 살다 | **기숙사에 사는 것**이 어때요? | การอยู่หอพักเป็นยังไงบ้าง — ㄹ หลุด |

#### 연습 2–3 และบทสนทนา (345–351쪽)

ส่วนนี้รวมแบบฝึกถามงานอดิเรก บทสนทนา 35-1 และบทอ่าน 35-2 ซึ่งใช้ -는 것 ทั้งถามและตอบ

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 가: 제프리 씨, 취미가 뭐예요? — 나: 저는 **운동하는 것**을 좋아해요. | คุณเจฟฟรีย์ งานอดิเรกคืออะไร — ฉันชอบการออกกำลังกาย | 연습 2–3 |
| 가: **혼자 영화 보는 것**을 좋아하세요? — 나: 네, 아주 좋아해요. / 아니요, 싫어해요. | ชอบดูหนังคนเดียวไหม — ชอบมาก / ไม่ค่ะ ไม่ชอบ | 연습 2–3 |
| 윤아: 간토야 씨, **운동하는 것**을 좋아하세요? — 간토야: 아니요, **하는 것**보다 **보는 것**을 좋아해요. | คุณคันโตยะ ชอบการออกกำลังกายไหม — ไม่ค่ะ ชอบดูมากกว่าเล่นเอง — 보다 ข้อ 41 | 35-1 (348쪽) |
| 간토야: 저는 **춤추는 것**을 좋아하지 않아요. 하지만 윤아 씨가 **하는 것**을 보러 가고 싶어요. | ฉันไม่ชอบการเต้น แต่อยากไปดูคุณยุนอาเต้น — -지 않다 ข้อ 16 · -(으)러 ข้อ 26 | 35-1 (348쪽) |
| 가: 명동에서는 무엇을 **하는 것**이 좋아요? | ที่เมียงดงทำอะไรดี | 연습 3 ของ 35 (347쪽) |
| 가: 음식은 뭘 **먹는 것**이 좋아요? — 나: 명동은 칼국수가 유명해요. 칼국수를 먹어 보세요. | อาหารกินอะไรดี — เมียงดงขึ้นชื่อเรื่องคัลกุกซู ลองกินดูสิ — ข้อ 60 | 연습 3 ของ 35 (347쪽) |
| 사진 **찍는 것**을 좋아해서 주말마다 밖으로 사진을 찍으러 나갑니다. | ชอบการถ่ายรูปจึงออกไปถ่ายรูปข้างนอกทุกสุดสัปดาห์ | 35-2 읽기 (350쪽) |
| 또 여행**하는 것**도 좋아합니다. | และชอบการเที่ยวด้วย | 35-2 읽기 (350쪽) |

#### โครงประโยคตอบ 취미가 뭐예요? (연습 1–3)

ครูเขียนโครงถาม–ตอบเรื่องงานอดิเรกบนกระดานเพื่อใช้ทำแบบฝึก 연습 1 ถึง 3 ของบท 35 คำตอบมีสองรูป ในกรอบคือกริยาที่ทำเป็น -는 것

- 가: 취미가 뭐예요? *(งานอดิเรกคืออะไร)*
- 나 ①: 저는 [V-는 것]을 좋아해요. *(ฉันชอบการ…)*
- 나 ②: 제 취미는 [V-는 것]이에요. *(งานอดิเรกของฉันคือการ…)*

รูป ① ใช้ 좋아하다 ซึ่งรับกรรมด้วย 을/를 และ 것 มีตัวสะกด จึงได้ 것**을** ส่วนรูป ② ใช้ 이에요 ต่อท้าย 것 ตารางนี้เรียบเรียงจากกิจกรรมใน 연습 2 ของตำรา

| กิจกรรม | ① 저는 …을 좋아해요 | ② 제 취미는 …이에요 | ไทย |
|:---|:---|:---|:---|
| 영화 보다 | 저는 영화 보는 것을 좋아해요. | 제 취미는 영화 보는 것이에요. | ดูหนัง |
| 음악 듣다 | 저는 음악 듣는 것을 좋아해요. | 제 취미는 음악 듣는 것이에요. | ฟังเพลง |
| 음식 만들다 | 저는 음식 만드는 것을 좋아해요. | 제 취미는 음식 만드는 것이에요. | ทำอาหาร |
| 사진 찍다 | 저는 사진 찍는 것을 좋아해요. | 제 취미는 사진 찍는 것이에요. | ถ่ายรูป |

### ⚠️ จุดสับสน

-는 것 สับสนกับ 것 ที่หน้าตาคล้ายกันอีกสามรูป และมักพลาดที่คำช่วยหลัง 는 것 ตารางแรกเทียบความหมายของสี่รูป หัวข้อถัดมาอธิบายว่า 것 ต่อ 이 หรือ 을 ตามภาคแสดง และตารางสุดท้ายรวมรูปที่ถูกกับรูปที่ผิดที่พบบ่อย

#### -는 것 vs -(으)ㄹ 것 vs -(으)ㄴ 것 vs -(으)ㄹ 거예요

สี่รูปนี้ใช้รากกริยาตัวเดียวกันแต่ให้ความหมายต่างกัน ดูที่คำอธิบายในคอลัมน์ที่สอง

| รูป | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| 먹**는 것** (ข้อ 59) | **การกิน** (นามจากกริยา ปัจจุบัน/ทั่วไป) | 먹는 것을 좋아해요 *(ชอบการกิน)* |
| 먹**을 것** (ข้อ 56) | **ของที่จะกิน** | 먹을 것이 없어요 *(ไม่มีของกิน)* |
| 먹**은 것** (ข้อ 47) | **ของที่กินไปแล้ว** | 어제 먹은 것이 맛있었어요 *(ที่กินเมื่อวานอร่อย)* |
| 먹**을 거예요** (ข้อ 28) | **จะกิน** (แผน) | 내일 먹을 거예요 *(พรุ่งนี้จะกิน)* |

#### 것이 กับ 것을 ต่างกันอย่างไร

คำช่วยที่ต่อท้าย 것 ไม่ได้ขึ้นกับ -는 것 เอง แต่ขึ้นกับ**ภาคแสดงของประโยค** ถ้าภาคแสดงเป็นคำคุณศัพท์ใช้ 것**이** ถ้าภาคแสดงเป็นกริยาที่มีกรรมใช้ 것**을**

| ภาคแสดง | คำช่วย | ตัวอย่างภาคแสดง |
|:---|:---|:---|
| คำคุณศัพท์ | 것**이** | 좋다 · 재미있다 · 어렵다 · 힘들다 |
| กริยาที่มีกรรม | 것**을** | 좋아하다 · 싫어하다 · 보다 |

- 책을 읽는 것**이** 좋아요. *(การอ่านหนังสือดี)*
- 단어를 설명하는 것**이** 어려워요. *(การอธิบายคำศัพท์ยาก)*
- 영화 보는 것**을** 좋아해요. *(ชอบการดูหนัง)*
- 운동하는 것**을** 싫어해요. *(ไม่ชอบการออกกำลังกาย)*
- 윤아 씨가 하는 것**을** 보러 가고 싶어요. *(อยากไปดูสิ่งที่คุณยุนอาทำ)*

กรรมที่อยู่ข้างในวลี -는 것 ยังใช้ 을/를 ของมันเองตามปกติ เพราะเป็นกรรมของกริยาตัวนั้น และรากที่ลงท้ายด้วย ㄹ ทำ ㄹ หลุดก่อน 는

- ✓ 책**을** 읽는 것이 좋아요 / ✗ 책**이** 읽는 것이 좋아요 *(ข้อผิดที่เคยเจอ: ใช้ 이/가 แทน 을/를 ในวลี -는)*
- ✓ 음식을 **만드는** 것 / ✗ 만들는 것 *(ㄹ หลุด)*
- ✓ 친구들과 **노는** 것 / ✗ 놀는 것 *(ㄹ หลุด)*

ในภาษาพูดคนเกาหลีมักย่อ 것이 เป็น **게** และย่อ 것을 เป็น **걸** (เสริม ไม่อยู่ในตำรา) ความหมายเหมือนเดิมทุกอย่าง

| รูปเขียน | รูปพูด | ตัวอย่าง |
|:---|:---|:---|
| 것이 | 게 | 책을 읽는 게 좋아요. *(การอ่านหนังสือดี)* |
| 것을 | 걸 | 영화 보는 걸 좋아해요. *(ชอบการดูหนัง)* |

#### กับดัก

ตารางนี้รวมรูปที่ถูกและรูปที่ผิดที่พบบ่อย พร้อมเหตุผลสั้น ๆ ส่วนข้อที่ไม่มีคู่เปรียบเทียบอยู่ในรายการด้านล่าง

| ประเด็น | ✓ ถูก | ✗ ผิด | หมายเหตุ |
|:---|:---|:---|:---|
| 좋아하다 + 을/를 | 운동하는 것**을** 좋아해요 | 운동하는 것이 좋아해요 | 좋아하다 รับ 을/를 (ข้อ 07 — เหมือนกับดักที่เคย "ใช้ 가 กับกริยาที่ต้องการ 을/를") |
| 좋다 + 이/가 | 운동하는 것**이** 좋아요 | 운동하는 것을 좋아요 | 좋다 รับ 이/가 |
| 싫어하다 · 싫다 | 운동하는 것을 싫어해요 · 운동하는 것이 싫어요 | — | 싫어하다 รับ 을/를 · 싫다 รับ 이/가 |
| นามเดี่ยว ๆ | 운동을 좋아해요 · 영화를 좋아해요 | 영화를 보를 좋아해요 | นามเดี่ยว ๆ ไม่ต้อง -는 것 — เมื่อมี**กรรมของกริยา** (영화를 보다) จึงต้องทำเป็น 영화 보는 것 |
| ㄹ-ราก | 사는 것 · 만드는 것 · 노는 것 | 살는 것 · 만들는 것 | ㄹ หลุด — ต่างจาก -(으)ㄹ 것 ที่ ㄹ คงอยู่ (살 것 · 만들 것) |
| ตำแหน่งปฏิเสธ | 운동하는 것을 좋아하지 않아요 · 운동하는 것을 안 좋아해요 | 운동하는 것을 좋아 안 해요 | 좋아하다 เป็นกริยาเดี่ยว 안 ต้องอยู่หน้า — เคยพลาด · ข้อ 08 · 16 |

- **ประธานของ -는 것:** ละได้เมื่อเป็นผู้พูด และใส่ประธานเมื่อต่างคน
  - 사진 찍는 것을 좋아해요 *(ฉันชอบถ่ายรูป — ละประธานได้)*
  - **윤아 씨가** 하는 것 *(สิ่งที่คุณยุนอาทำ — ใส่ประธานเมื่อต่างคน)*
- **-는 것보다 -는 것을** = "ชอบ B มากกว่า A": **하는 것보다 보는 것을** 좋아해요 (ตำรา 348쪽) — รูปเทียบของ ข้อ 41 (N보다)

> [!TIP] กฎสั้น ๆ
> - **-는 것 = "การ…"** · ㄹ-ราก: ㄹ หลุด (사는 것) · 것 เว้นวรรค
> - **좋아하다/싫어하다 + 을/를** · **좋다/싫다/어렵다 + 이/가**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

-는 것 ออกจริงแล้วใน 매일시험 35과 ส่วน A (ถูกครบ 4 ข้อ ได้ 10/10 ทั้งใบ) และอยู่ในชุดทบทวนปลายภาค รายการแยกตามแหล่งที่มา

- **매일시험 35과 (16 พ.ย. · ส่วน A ได้ 4/4):** ดูภาพงานอดิเรก แล้วเติมช่องว่างที่ท้ายช่องพิมพ์ 이에요 · 을 · 이
  - 영화 보는 것 ✓ *(การดูหนัง)*
  - 사진 찍는 것 ✓ *(การถ่ายรูป)*
  - 음식 만드는 것 ✓ *(การทำอาหาร — ราก ㄹ หลุดก่อน ㄴ)*
  - 음악 듣는 것 ✓ *(การฟังเพลง — ㄷ ไม่เปลี่ยนก่อน -는)*
- **연습지 35 (13 พ.ย.) หน้า 1 ข้อ 1:** ตาราง -는 것 12 กริยา ผู้เรียนเว้นว่างทั้งหมด
  - กับดักในตาราง: 돕는 것 ✗ 도우는 · 듣는 것 ✗ 들는 · 부르는 것 ✗ 불르는
  - กับดักในตาราง: 사는 것 ✗ 살는 · 만드는 것 ✗ 만들는 · 노는 것 ✗ 놀는

- **워크북 35과:** ส่วน C กับ D เป็น -는 것 สแกนเป็นหน้าเปล่า ไม่มีบันทึกการตรวจ

> [!SUMMARY] สรุป
> - -는 것 = "การ…" ทำกริยาให้เป็นนาม: **รากกริยา + 는 것** ไม่ดูตัวสะกด (보는 것 · 먹는 것) และรากที่ลงท้าย ㄹ ทำ ㄹ หลุด (사는 것 · 만드는 것)
> - เลือกคำช่วยตามภาคแสดง: **좋아하다/싫어하다 + 을/를 · 좋다/싫다/어렵다 + 이/가**
> - แยกให้ออก: 먹는 것 *(การกิน)* ≠ 먹을 것 *(ของที่จะกิน)* ≠ 먹은 것 *(ของที่กินแล้ว)* ≠ 먹을 거예요 *(จะกิน)*
> - ที่ต้องระวัง: 좋아 안 해요 (→ 안 좋아해요) · 것 ต้องเว้นวรรค · ㄹ ไม่หลุดผิดที่ (살는 것 ✗)
