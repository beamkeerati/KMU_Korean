## 35. ตารางรวม "มีตัวสะกด / ไม่มี" — ทุก 조사 และคำลงท้ายในบท 5–22
ทุกครั้งที่ต้องเลือกรูป ให้ถามข้อเดียว: **พยางค์สุดท้ายมี 받침 (ตัวสะกด) ไหม?** แล้วเปิดตารางนี้ — ช่อง "หลัง ㄹ" แยกไว้เพราะ ㄹ ทำตัวไม่เหมือนตัวสะกดอื่นในคำลงท้ายของ**กริยา** (ส่วนนามที่ลงท้าย ㄹ เป็นตัวสะกดปกติ)
รวมรูปที่ตำรา 5–22과 สอน — รูปที่ตำราไม่ได้สอนตรง ๆ แต่เจอบ่อยทำเครื่องหมาย *(เสริม)* · 이랑/랑 และ (으)로 ยังไม่เรียน จึงไม่อยู่ในตาราง
ต้นทางของแต่ละแถวอยู่ที่ ข้อ 01 · 02 · 07 · 19 · 20 · 21 · 23 · 26 · 28 · 33 (เลขท้ายแถว)

คอลัมน์ ㄹ: แถว**คำนาม** = ตัวสะกดปกติ ไม่มีข้อยกเว้น · แถว**กริยา** = ข้อยกเว้นของ ㄹ-ราก (สรุป 4 กฎใน 📖) · -았/었-/-겠- ลงท้าย ㅆ จึงตามด้วย **습니다** เสมอ ไม่ว่ารากจะลงท้ายอะไร

### 📖 ตัวอย่างและการใช้
#### ราก ㄹ — 4 กฎ
| กฎ | ใช้กับ | ตัวอย่าง |
|:---|:---|:---|
| 1) ㄹ ทำหน้าที่เป็น "สระ" — ไม่เติม 으 ไม่ซ้ำ ㄹ | -(으)ㄹ 거예요 · -(으)ㄹ까요? (ตำรา) · -(으)러 *(เสริม)* | 살 거예요 · 살까요? · 놀러 갈까요? · ✗ 살을 거예요 · ✗ 만들을까요 |
| 2) ㄹ หลุดหน้า ㅂ · ㄴ · ㅅ *(เสริม ตำราไม่ได้สอน)* | -ㅂ니다 · -네요 · -(으)세요 · -(으)십니다 | 삽니다 · 사네요 · 사세요 · 사십니다 · 만듭니다 · 만드세요 |
| 3) ㄹ อยู่เหมือนเดิมหน้าสระและพยัญชนะอื่น | -아/어요 · -았/었- · -고 · -겠- | 살아요 · 살았어요 · 살고 있어요 · 힘들겠네요 |
| 4) นามลงท้าย ㄹ = ตัวสะกดปกติ | 조사 ทุกตัว | 물은 · 물이 · 물을 · 물과 · 물이에요 |

|:---|:---|:---|:---|:---|
| 가다 *(ไป)* | 갔어요 | 갑니다 | 가세요 | 갈 거예요 |
| 먹다 *(กิน)* | 먹었어요 | 먹습니다 | 먹으세요 · 드세요 | 먹을 거예요 |
| 읽다 *(อ่าน)* | 읽었어요 | 읽습니다 | 읽으세요 | 읽을 거예요 |
| 공부하다 *(เรียน)* | 공부했어요 | 공부합니다 | 공부하세요 | 공부할 거예요 |
| 바쁘다 *(ยุ่ง)* | 바빴어요 | 바쁩니다 | 바쁘세요 | 바쁠 거예요 |
| 만들다 *(ทำ)* | 만들었어요 | 만듭니다 *(เสริม)* | 만드세요 *(เสริม)* | 만들 거예요 |

#### ตัวสะกดไม่เกี่ยวกับ 아/어 — ดู**สระ**ของราก (ข้อ 06 · 23)
| สระท้ายราก | -아/어요 · -았/었어요 | ตัวอย่าง |
|:---|:---|:---|
| ㅏ · ㅗ (แม้มีตัวสะกด ㄹ ㅂ ㅁ…) | **아요 · 았어요** | 살다 → 살**아**요 · 받다 → 받**아**요 · 좋다 → 좋**아**요 ✗ 살어요 · 받어요 |
| สระอื่น (ㅓ ㅜ ㅣ ㅡ…) | **어요 · 었어요** | 먹다 → 먹**어**요 · 읽다 → 읽**어**요 · 만들다 → 만들**어**요 |
| ㅡ ท้ายราก (ไม่มีตัวสะกด) | ตัด ㅡ แล้วดูสระก่อนหน้า | 쓰다 → 써요 · 바쁘다 → 바빠요 · 크다 → 커요 |

### ⚠️ จุดสับสน
#### 과 ดูเหมือน "สระ" แต่ใช้หลังตัวสะกด
คนไทยจำ 와/과 สลับบ่อย เพราะรูป 과 มีสระ (ㅘ) อยู่ในตัว เลยรู้สึกว่าต้องตามหลังสระ — ความจริงคือ **ตัวสะกด → 과** เท่านั้น

| | หลังสระ (받침 ✗) | หลังตัวสะกด (받침 ○) |
|:---|:---|:---|
| 와/과 | 친구**와** | 선생님**과** |
| 이/가 | 친구**가** | 선생님**이** |

* 선생님**과** 먹어요. ✓ *(กินกับครู)* / 선생님**와** ✗
* 친구**와** 가요. ✓ *(ไปกับเพื่อน)* / 친구**과** ✗
* 책**과** 연필 ✓ *(หนังสือกับดินสอ)* / 책**와** ✗
* ㅇ ท้ายพยางค์ก็เป็นตัวสะกด: 책상**과** · 방**이** · 공**을** *(โต๊ะกับ · ห้อง · ลูกบอล)*

#### ตัวสะกดอยู่ "ตัวแรก" หรือ "ตัวหลัง" ของคู่?
ความไม่สม่ำเสมอที่ต้องท่องแยก:

| คู่ | ตัวที่ใช้หลังตัวสะกด | อยู่ตำแหน่ง |
|:---|:---|:---:|
| 이/가 | **이** | ตัวแรก |
| 은/는 | **은** | ตัวแรก |
| 을/를 | **을** | ตัวแรก |
| 와/과 | **과** | ตัวหลัง |

#### กับดักตัวสะกดในคำลงท้ายกริยา
- ลืม 으 หลังตัวสะกด: ✗ 읽세요 → ✓ 읽으세요 · ✗ 받십니다 → ✓ 받으십니다 · ✗ 씻러 → ✓ 씻으러 · ✗ 먹까요 → ✓ 먹을까요
- เติม 으/을 ทั้งที่ไม่ต้องเติม: ✗ 가을 거예요 → ✓ 갈 거예요 · ✗ 살을 거예요 → ✓ 살 거예요 · ✗ 만들을까요 → ✓ 만들까요
- เติม ㅂ ทับ 았/었: ✗ 갔ㅂ니다 → ✓ 갔습니다 · ตัดรากเกิน: ✗ 맙니다 → ✓ 마십니다 *(마시다)*
- รูปหดของ 가 หลังสระ: 저+가 = **제가** · 나+가 = **내가** · 누구+가 = **누가** *(ห้าม ✗ 저가 · 누구가 — ข้อ 01)*

> [!TIP]
> **กฎจำง่าย:** 이/은/을 = ตัวแรกของคู่ใช้หลังตัวสะกด แต่ **과 = ข้อยกเว้นเดียว** อยู่ตัวหลังของคู่ — ท่อง "ตัวสะกด → 이·은·을·과"

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ
- ★ **ตก 으 หลังตัวสะกด:** 받십니다 ✗ (2 ครั้ง: ใบฝึก 16과 และใบที่ทำซ้ำ) · 읽세요 ✗ (연습지 15과) · 씻러 ✗ → 씻으러 (워크북 18과) — เกิดตอนเขียนเอง ไม่ใช่ตอนเติมตาราง
- ★ **ผัน ㅏ เป็น 어:** 살어요 · 살었어요 ✗ → 살아요 · 살았어요 (연습지 19과 A ครูไฮไลต์) · 받었어요 ✗ → 받았어요 (워크북 20과) — ตัวสะกดของรากไม่เกี่ยว ดูสระ
- **รูปทางการ/นามอดีต:** 빌렸십니다 ✗ → 빌렸습니다 (워크북 20과 · 었 + 습니다) · 마시다 → 맙니다 ✗ → 마십니다 (ตัดรากเกิน) · 학생였어요 · 공원였어요 ✗ → 학생이었어요 · 공원이었어요 (มีตัวสะกด → 이었) ส่วน 의사였어요 ทำถูก
- **ทำถูกอยู่แล้ว:** เลือก ㅂ니다/습니다 ตามตัวสะกด · 살 거예요 · 만들 거예요 (연습지 19과 A)
- **ชุดเก็ง 복습시험② (10/20):** คาดว่า 쓰기 3 เป็นตารางผัน 4 รูป (ตารางใน 📖) — เป็นการเดา ไม่ใช่ข้อสอบจริง
