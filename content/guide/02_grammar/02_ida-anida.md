## 02. 이다 / 아니다 — 입니다 · 이에요/예요 · 이/가 아니에요 (เป็น/คือ · ไม่ใช่)

> [!INTRO] ข้อนี้คืออะไร
> "เป็น/คือ" ในภาษาเกาหลีเป็น**หางที่ติดท้ายคำนาม** ไม่ใช่กริยาแยกออกมา และอยู่ท้ายประโยคเสมอ
>
> มี 3 รูปที่ต้องรู้ คือรูปทางการ **입니다/입니까?** (บท 5) รูปสุภาพทั่วไป **이에요/예요** (บท 7) และรูปปฏิเสธ **이/가 아니에요** (บท 7)
>
> ต่อยอดจากข้อ 01 (은/는 — "A은/는 B입니다") และข้อ 35 (ตัวสะกด) และไปใช้ต่อในข้อ 21 (입니다 = รูป -ㅂ니다 ของ 이다 · 아닙니다) ข้อ 20 ((이)세요) และข้อ 23 (이었어요/였어요)

### 📌 รูปแบบและเงื่อนไข

ประโยค "A คือ B" ลงท้ายด้วยหางของ 이다 ซึ่งเปลี่ยนรูปตามระดับความสุภาพและตัวสะกดของคำนามข้างหน้า ตารางนี้สรุปทั้งห้ารูป ส่วนข้างล่างเป็นกฎย่อยเรื่องการถาม-ตอบ ตัวสะกด และการเว้นวรรค

| รูป | ระดับ | เงื่อนไข | ตัวอย่าง |
|:---|:---|:---|:---|
| N**입니다** / N**입니까?** | ทางการ *(บท 5 · 교과서 42쪽)* | ไม่ดูตัวสะกด ต่อท้ายได้เลย | 학생**입니다** *(เป็นนักเรียน)* · 중국 사람**입니까?** *(เป็นคนจีนไหม)* |
| N**이에요** | สุภาพทั่วไป *(บท 7 · 58쪽)* | คำนาม **มี**ตัวสะกด | 책**이에요** *(เป็นหนังสือ)* · 사전**이에요** *(เป็นพจนานุกรม)* |
| N**예요** | สุภาพทั่วไป | คำนาม **ไม่มี**ตัวสะกด | 의사**예요** *(เป็นหมอ)* · 카메라**예요** *(เป็นกล้อง)* |
| N**이 아니에요** | ปฏิเสธ *(บท 7 · 60쪽)* | คำนาม **มี**ตัวสะกด | 사전**이 아니에요** *(ไม่ใช่พจนานุกรม)* |
| N**가 아니에요** | ปฏิเสธ | คำนาม **ไม่มี**ตัวสะกด | 카메라**가 아니에요** *(ไม่ใช่กล้อง)* |

#### ความหมายเท่ากัน และวิธีถาม-ตอบ

입니다 กับ 이에요/예요 มีความหมายเท่ากัน ต่างกันแค่ระดับความสุภาพ ตำราบอกว่า 입니다 ใช้ในสถานการณ์ทางการ ส่วน 이에요/예요 ใช้ในสถานการณ์ไม่เป็นทางการ การถามและการตอบมีกฎดังนี้

- **ถามแบบทางการ:** เปลี่ยน 입니다 → **입니까?** (✗ 입니다?)
- **ถามแบบสุภาพทั่วไป:** ใช้รูปเดิมแล้วขึ้นเสียงท้าย: 연필이에요? ↗ *(เป็นดินสอหรือ)*
- **ตอบรับ:** 네 + ประโยคเต็ม: 네, 중국 사람입니다. *(ใช่ เป็นคนจีน)*
- **ตอบปฏิเสธ:** 아니요 + ข้อมูลจริง
  - 아니요, 저는 학생입니다. *(ไม่ใช่ ฉันเป็นนักเรียน)*
  - 아니요, 지우개예요. *(ไม่ใช่ เป็นยางลบ)*
- ข้อควรรู้: บท 5 ยังไม่มี 아닙니다 (เรียนในบท 16)

#### เลือก 이에요 หรือ 예요 ตามตัวสะกด

ให้ดูตัวสะกดที่พยางค์สุดท้ายของคำนาม ถ้าไม่มีตัวสะกดใช้ **예요** ถ้ามีตัวสะกดใช้ **이에요**

| ไม่มีตัวสะกด → **예요** | มีตัวสะกด → **이에요** |
|:---|:---|
| 전화 *(โทรศัพท์)* | 책 *(หนังสือ)* |
| 기자 *(นักข่าว)* | 사전 *(พจนานุกรม)* |
| 여자 *(ผู้หญิง)* | 연필 *(ดินสอ)* |
| 카드 *(บัตร)* | 지갑 *(กระเป๋าสตางค์)* |
| 운동선수 *(นักกีฬา)* | |

ข้อที่พลาดบ่อยคือการใส่ 이에요 หลังคำที่ไม่มีตัวสะกด เช่น ✗ 전화이에요 ต้องเป็น 전화예요

#### การเว้นวรรค

입니다 ติดคำนามทันที ไม่เว้นวรรค แต่ 이/가 ที่ตามด้วย 아니에요 ติดนามแล้ว ต้อง**เว้นวรรคก่อน 아니에요** *(ตำรา 60쪽)*

| ✓ ถูก | ✗ ผิด |
|:---|:---|
| 학생입니다 *(เป็นนักเรียน)* | 사람 입니까 |
| 나무가 아니에요 *(ไม่ใช่ต้นไม้)* | 나무가아니에요 |

#### ต่อท้ายหน่วยนับและคำถาม

คำถามเรื่องชั้น ห้อง เบอร์ และราคา ก็ลงท้ายด้วย 이에요/예요 ตามตัวสะกดเช่นกัน *(ข้อ 04 · ส่วนที่ 3)*

| 한국어 | ไทย |
|:---|:---|
| 몇 층**이에요**? | ชั้นไหน (층 มีตัวสะกด) |
| 몇 호**예요**? | ห้องอะไร (호 ไม่มีตัวสะกด) |
| 몇 번**이에요**? | เบอร์อะไร |
| 얼마**예요**? → 천 원**이에요** | เท่าไร → 1,000 วอน |
| 뭐**예요**? | อะไร |
| 누구**예요**? | ใคร |

#### เสียงจริง ≠ ตัวเขียน

เสียงที่ออกจริงต่างจากตัวเขียน ให้เขียนตามรูปคำเสมอ ไม่เขียนตามเสียง

| เขียน | อ่านออกเสียง |
|:---|:---|
| 입니다 | [임니다] |
| 입니까 | [임니까] |
| 책이에요 | [채기에요] |
| 지갑이에요 | [지가비에요] |
| 회사원입니다 | [회사워님니다] |

### 📖 ตัวอย่างและการใช้

ตัวอย่างแบ่งตามบทที่สอน บท 5 ใช้รูปทางการ ถามด้วย 입니까? ตอบด้วย 입니다 ส่วนบท 7 ใช้รูปสุภาพทั่วไป ถามด้วยรูปเดิมแล้วขึ้นเสียง

#### บท 5 — ทางการ (ถามด้วย 입니까? · ตอบด้วย 입니다)

| คำถาม | คำตอบ |
|:---|:---|
| 중국 사람**입니까?** *(เป็นคนจีนไหม)* | 네, 중국 사람**입니다**. *(ใช่ เป็นคนจีน)* |
| 윤아 씨는 선생님**입니까?** *(คุณยุนอาเป็นครูหรือ)* | 아니요, 저는 학생**입니다**. *(ไม่ใช่ ฉันเป็นนักเรียน)* |
| 어느 나라 사람**입니까?** *({e:เป็น}{n:คนประเทศ}{q:ไหน})* | 한국 사람**입니다**. *(เป็นคนเกาหลี)* |
| 이름이 무엇**입니까?** *(ชื่ออะไร)* | 김윤아**입니다**. *(ชื่อคิมยุนอา)* |

#### บท 7 — สุภาพทั่วไป (ถามด้วยรูปเดิม ขึ้นเสียง)

| 한국어 | ไทย |
|:---|:---|
| 연필**이에요**? → 아니요, 지우개**예요**. | เป็นดินสอหรือ → ไม่ใช่ เป็นยางลบ |
| 이게 뭐**예요**? → 지갑**이에요**. | นี่คืออะไร → กระเป๋าสตางค์ |
| 카메라**예요**? → 아니요, 카메라**가 아니에요**. 휴대폰**이에요**. | เป็นกล้องหรือ → ไม่ใช่กล้อง เป็นมือถือ |
| 투이 씨 사전**이에요**? → 아니요, **제** 사전**이 아니에요**. 친구 사전**이에요**. | ของคุณทุยหรือ → ไม่ใช่ของฉัน ของเพื่อน — **제 = 저의** "ของฉัน" วางหน้านาม |
| 이것은 국민대학교 학생증**이에요**. | นี่คือบัตรนักศึกษามหาวิทยาลัยคุกมิน — บทอ่านบท 7 |
| 그리고 이것은 여자 친구 사진**이에요**. | และนี่คือรูปแฟน — บทอ่านบท 7 |
| 제 여자 친구는 러시아 사람**이 아니에요**. | แฟนฉันไม่ใช่คนรัสเซีย — บทอ่านบท 7 |
| 미국 사람**이에요**. | เป็นคนอเมริกัน — บทอ่านบท 7 |

### ⚠️ จุดสับสน

มีสามเรื่องที่ควรแยกให้ออก คือ 입니까 กับ 입니다 และ 아니요 กับ 아니에요, 이에요/예요 กับ 있어요 และการเลือก 입니다/있습니다 ในข้อสอบเลือกคำ

#### 입니까 ≠ 입니다 · 아니요 ≠ 아니에요

입니까 ใช้ถาม ส่วน 입니다 ใช้บอก และ 아니요 เป็นคำตอบว่า "ไม่" ส่วน 아니에요 เป็นกริยา "ไม่ใช่" ที่ต้องมี 이/가 อยู่ข้างหน้า

| | ใช้เมื่อ | ตัวอย่าง |
|:---|:---|:---|
| **입니까?** | ถาม (ทางการ) — ต้องลงท้าย 까 | 중국 사람입니까? ✓ · 중국 사람입니다? ✗ |
| **입니다** | บอกเล่า (ทางการ) | 네, 중국 사람입니다. *(ใช่ เป็นคนจีน)* |
| **아니요** | "ไม่" — คำตอบ ขึ้นต้นประโยค | 아니요, 지갑이 아니에요. *(ไม่ใช่ ไม่ใช่กระเป๋าสตางค์)* |
| **아니에요** | "ไม่ใช่" — กริยา ท้ายประโยค มี 이/가 อยู่หน้า | 지갑**이** 아니에요. ✓ · 지갑이 아니요 ✗ |

#### 이에요/예요 vs 있어요 (และ 아니에요 vs 없어요)

คนเรียนมักเอา 이에요/예요 ไปใช้แทน "มี/อยู่" เพราะภาษาไทยใช้คำว่า "เป็น / มี / อยู่" ต่างกัน แต่เกาหลีแบ่งชัดว่า 이다 = **เป็น/คือ** (เอาคำนามมาเทียบกัน) ส่วน 있다 = **มี/อยู่** (บอกการมีอยู่)

| | เป็น/คือ | มี/อยู่ |
|:---|:---|:---|
| ยืนยัน | 이에요/예요 | 있어요 |
| ปฏิเสธ | 이/가 아니에요 (ไม่ใช่) | 이/가 없어요 (ไม่มี/ไม่อยู่) |

- 저는 학생**이에요**. ✓ *(ฉันเป็นนักเรียน)*
- 교실에 학생**이 있어요**. ✓ *(ในห้องเรียนมีนักเรียนอยู่)*
- 여기가 도서관**이에요**. ✓ *(ที่นี่คือห้องสมุด)*
- 저는 학생**이 아니에요**. ✓ *(ฉันไม่ใช่นักเรียน)*
- 교실에 학생**이 없어요**. ✓ *(ในห้องเรียนไม่มีนักเรียน)*

> [!TIP] กฎจำง่าย
> - "A คือ B" → 이에요/예요 (A = B)
> - "A มี/อยู่ ที่…" → 있어요
> - ปฏิเสธ: ไม่ใช่ → 아니에요 · ไม่มี → 없어요

#### โครงสร้างประโยค 이에요/예요 vs 있어요 — ต้องมี 이/가 ไหม?

สองตัวนี้ไม่ใช่แค่ "ความหมายต่างกัน" แต่เป็น**คนละชนิดคำ** จึงต่อกับคำนามคนละแบบ ตารางนี้เทียบทีละประเด็น

| | 이에요/예요 (이다) | 있어요 (있다) |
|:---|:---|:---|
| คืออะไร | **หาง** ที่ติดท้ายคำนาม (= "คือ/เป็น") | **กริยา** เดี่ยว ๆ (= "มี/อยู่") |
| คำนามข้างหน้า | ติดกัน **ไม่มี 조사 ไม่เว้นวรรค** → 학생**이에요** | ต้องมี **이/가** + **เว้นวรรค** → 학생**이 있어요** |
| ตัว 이 ที่เห็น | เป็น**ส่วนหนึ่งของคำ** 이에요 (ไม่ใช่ 조사) | เป็น **조사 ประธาน** 이/가 |
| ขึ้นกับตัวสะกด | 책**이에요** / 의사**예요** | 책**이** 있어요 / 의사**가** 있어요 (ดูข้อ 01) |
| ปฏิเสธ | 이/가 **아니에요** (ตรงนี้กลับ "ต้องมี" 이/가) | **없어요** (안 있어요 ✗) |
| รูปทางการ | 입니다 / 입니까? | 있습니다 / 있습니까? |
| รูปยกย่อง | (이)세요 | 계세요 (คนอยู่) / 있으세요 (มีของ) → ข้อ 20 |

#### ตอบตรง ๆ ว่า "ต้องมี 이/가 ไหม"

คำตอบขึ้นกับท้ายประโยค 이에요/예요 ห้ามมี 이/가 ข้างหน้า ส่วน 아니에요 ต้องมี 이/가 เสมอ และ 있어요/없어요 ต้องมี 이/가 ที่คำนามข้างหน้าโดยห้ามเป็น 을/를

1. **이에요/예요 → คำนามข้างหน้า "ห้ามมี" 이/가**
   - 저는 학생**이에요**. ✓ *(ฉันเป็นนักเรียน)* · 학생**이 이에요** ✗ · 학생**을 이에요** ✗
   - ส่วน*ประธาน*ของประโยค (คำแรก) ใช้ 은/는 ตามปกติ ใช้ 이/가 เมื่อตอบคำถาม "ใคร/อันไหน"
   - 그것**이** 마키 씨 지갑입니까? *(นั่นเป็นกระเป๋าสตางค์ของคุณมากิหรือ — ชื่อบท 6)*
   - **제가** 학생이에요. *(ฉันเองเป็นนักเรียน — ตอบ 누가?)*
2. **아니에요 → "ต้องมี" 이/가 เสมอ** — ข้อยกเว้นที่ทำให้งง
   - 저는 학생**이 아니에요**. ✓ *(ฉันไม่ใช่นักเรียน)* · 학생 아니에요 ✗ (ในข้อสอบ)
   - 이/가 ตรงนี้ **ไม่ใช่ประธาน** แต่เป็น "ตัวต่อ" ที่ 아니다 บังคับใช้ ประโยคจึงมี 이/가 ซ้ำได้
   - 이것**이** 제 사전**이** 아니에요. *(นี่ไม่ใช่พจนานุกรมของฉัน)*
3. **있어요/없어요 → "ต้องมี" 이/가 ที่คำนามหน้ามัน และห้ามเป็น 을/를**
   - 교실에 학생**이** 있어요. ✓ *(ในห้องเรียนมีนักเรียน)* · 학생**을** 있어요 ✗ ← กับดักใหญ่ เพราะไทยพูด "มี + กรรม"
   - "ฉันมีน้อง": 저**는** 동생**이** 있어요. *(คนที่มี = 은/는 · สิ่งที่มี = 이/가)*

#### โครงสร้างสำเร็จรูป 3 แบบ

ประโยคส่วนใหญ่ที่ใช้ 이다 และ 있다 ลงตัวอยู่ในสามโครงนี้ ท่องโครงแล้วแทนคำได้เลย

| แบบ | โครงสร้าง | ตัวอย่าง |
|:---|:---|:---|
| ① A คือ B | A**은/는** B**이에요/예요** | 저는 태국 사람**이에요**. *(ฉันเป็นคนไทย)* |
| ① A ไม่ใช่ B | A**은/는** B**이/가 아니에요** | 저는 중국 사람**이 아니에요**. *(ฉันไม่ใช่คนจีน)* |
| ② B อยู่ที่ P | B**이/가** P**에** 있어요/없어요 | 책**이** 책상 위**에** 있어요. *(หนังสืออยู่บนโต๊ะ)* |
| ② (สลับได้) | P**에** B**이/가** 있어요/없어요 | 책상 위**에** 책**이** 있어요. *(บนโต๊ะมีหนังสือ)* |
| ③ A มี B | A**은/는** B**이/가** 있어요/없어요 | 저**는** 형**이** 있어요. *(ฉันมีพี่ชาย)* |

#### ประโยคคู่ที่ดูเหมือนกันแต่คนละเรื่อง

ประโยคชุดนี้หน้าตาเกือบเหมือนกัน แต่ความหมายต่างกันเพราะท้ายประโยคเป็น 이에요 หรือ 있어요

| ประโยค | ความหมาย |
|:---|:---|
| 학생**이에요**. | (เขา) **เป็น**นักเรียน |
| 학생**이 있어요**. | **มี**นักเรียน / นักเรียน**อยู่** |
| 학생**이 아니에요**. | **ไม่ใช่**นักเรียน |
| 학생**이 없어요**. | **ไม่มี**นักเรียน |
| 여기**가** 도서관**이에요**. | ที่นี่**คือ**ห้องสมุด |
| 여기**에** 도서관**이 있어요**. | ที่นี่**มี**ห้องสมุด |

> [!TIP] ตัดสินใจเร็ว
> - แปลไทยแล้วเจอ "คือ/เป็น" → 이에요 ติดคำนามเลย
> - "มี/อยู่" → 이/가 + เว้นวรรค + 있어요
> - "ไม่ใช่" → 이/가 아니에요 · "ไม่มี" → 이/가 없어요
> - จำง่าย ๆ: **"ติด" = 이에요 · "แยก" = 있어요**

#### ประโยคเดียวกัน 3 แบบ — รูปทางการ 입니다 / 있습니다 (จากชุดทบทวนกลางภาค ข้อ 1)

ข้อสอบให้เลือก (입니다, 있습니다) ในประโยคเดียว ให้ดูว่าสิ่งที่อยู่ข้างหน้า "ติดได้" หรือ "ต้องมีคำช่วย"

| ประโยค | แปล | ใช้ได้ไหม |
|:---|:---|:---|
| 고향이 LA**입니다** | บ้านเกิด**คือ** LA | ✓ คำตอบของข้อนี้ — 입니다 ติดคำนามตรง ๆ |
| 고향이 LA**에** 있습니다 | บ้านเกิด**อยู่ที่** LA | ✓ แต่ต้องมี 에 — โจทย์ไม่ได้ให้ 에 จึงเลือกไม่ได้ |
| 고향이 LA 있습니다 | (บ้านเกิดมี… LA?) | ✗ LA ไม่มีคำช่วย ไม่เป็นประโยค |
| 아버지, 어머니, 남동생**이 있습니다** | **มี**พ่อ แม่ น้องชาย | ✓ 이 นำหน้า + เว้นวรรค = มี |
| 아버지, 어머니, 남동생**입니다** | (พวกเขา) **เป็น**พ่อ แม่ น้องชาย | ✓ ถูกไวยากรณ์ แต่ไม่ใช่ความหมายของเรื่อง |
| 남동생이 입니다 | — | ✗ 입니다 ไม่รับ 이/가 ข้างหน้า |

> [!TIP] ดูตัวบอกก่อนช่องว่าง
> - **เห็น 이/가 นำหน้าช่องว่าง → ต้องเป็น 있습니다/없습니다** (입니다 ติดคำนามเสมอ ไม่มี 이/가 คั่น)
> - **เห็น 에 นำหน้า → 있습니다** (입니다 ไม่ใช้กับ 에)

#### กรณีคำนามหลายคำต่อด้วย 와/과 (บท 15 · ข้อ 19)

ให้ดู**คำสุดท้าย**ที่ติด 이에요/예요 คำเดียว คำข้างหน้าไม่เกี่ยว และช่องว่างไม่ต้องใส่ 이/가

| โจทย์ (워크북 15과) | เฉลย | เหตุผล |
|:---|:---|:---|
| 지훈 씨 방 친구는 ___ (이에요/예요). | 인성과 수현**이에요** | 수현 ลงท้าย ㄴ → 이에요 |
| 지훈 씨 취미는 ___ (이에요/예요). | 요리와 축구**예요** | 축구 ลงท้ายสระ → 예요 |
| เทียบ: 지훈 씨 방에 ___ 있어요. | 인성과 수현**이** 있어요 | 있어요 = กริยา → ต้องมี 이 + เว้นวรรค |

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ข้อนี้ออกสอบตั้งแต่ 매일시험 5과 จนถึงชุดทบทวนกลางภาคของครู โดยข้อที่ครูให้แยกคือ 입니다 กับ 있습니다 ส่วนข้อผิดจริงที่เจอเป็นเรื่องรูป 입니까 และตัวสะกด

- **매일시험 5과** — B: …는 …입니다 ×4
- **매일시험 6과** — B–C
  - 누가 한국 사람입니까? → 선생님이 한국 사람입니다 *(ใครเป็นคนเกาหลี → คุณครูเป็นคนเกาหลี)*
  - 교실입니다 *(เป็นห้องเรียน)*
  - 그것이 시계입니다 *(นั่นคือนาฬิกา)*
- **매일시험 7과**
  - B: 이게 책상이에요? *(นี่โต๊ะหรือ)* · 이것이 뭐예요? *(นี่คืออะไร)* · 의자가 아니에요 *(ไม่ใช่เก้าอี้)*
  - C: 제 사전이에요 *(เป็นพจนานุกรมของฉัน)* · 그게 카드예요 *(นั่นคือบัตร)* · 이것이 돈이에요 *(นี่คือเงิน)*
- **매일시험 8과 연습지** D: 이에요 vs 있어요 เลือก 5 ข้อ
- **복습시험① (10/6)** — ได้เต็มทุกข้อต่อไปนี้
  - 쓰기 A5–A6: 저는 한국 사람이 아니에요 *(ฉันไม่ใช่คนเกาหลี)*
  - 쓰기 B3: 이 사람이 누구예요? → 제 동생이에요 *(คนนี้คือใคร → น้องของฉัน)*
  - 쓰기 E2: 아니요, 선생님이 아니에요. 간호사예요 *(ไม่ใช่ ไม่ใช่ครู เป็นพยาบาล)*
- **중간시험 복습문제 1** (ชุดของครู) — เลือก **입니다 / 있습니다** 11 ช่องในบทความเดียว = ตัวที่ต้องแยกให้ออก
  - 고향이 LA입니다 *(บ้านเกิดคือ LA)*
  - 남동생이 있습니다 *(มีน้องชาย)*
  - 학교 안에 기숙사가 있습니다 *(ในโรงเรียนมีหอพัก)*
  - … *(ช่องที่เหลือในบทความเดียวกัน)*
- ★ ข้อผิดที่เคยเจอ
  - ฟังเขียน "어느 나라 사람**입니다**" ทั้งที่เป็นคำถาม → ต้อง **입니까**
  - 워크북 7과 ครูแก้ 4 ข้อ: 전화**이에요** ✗ → 전화**예요** และ 기자 · 여자 · 운동선수 ต้อง 예요
  - สะกดผิด 카드 → 가트 · 돈 → 둔 (매일시험 7과 C)
- ข้อผิดที่เกี่ยวกับ 이다 ในอดีต: 학생**였**어요 ✗ → 학생**이었**어요 (รู้ 의사였어요 แต่พลาดคำที่มีตัวสะกด — ข้อ 23)
- ฝึกเพิ่ม: ส่วนที่ 5 ชุด B

> [!SUMMARY] สรุป
> - 이다 = "เป็น/คือ" เป็น**หาง**ติดท้ายคำนาม เขียนติดไม่เว้นวรรค: **입니다** (ทางการ) · **이에요/예요** (สุภาพทั่วไป) · **이/가 아니에요** (ปฏิเสธ)
> - เลือก 이에요 หลังตัวสะกด และ 예요 หลังสระ · ถามแบบทางการต้อง 입니까? ไม่ใช่ 입니다?
> - ปฏิเสธต้องมี 이/가 และเว้นวรรคก่อน 아니에요 · "ติด" = 이에요 · "แยก" = 있어요
> - ข้อผิดที่เคยเจอ: 전화이에요 → 전화예요 · 학생였어요 → 학생이었어요 · ใช้ 입니다 แทน 입니까
