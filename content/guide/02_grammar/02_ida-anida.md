## 02. 이다 / 아니다 — 입니다 · 이에요/예요 · 이/가 아니에요 (เป็น/คือ · ไม่ใช่)
"เป็น/คือ" ในภาษาเกาหลีเป็น **หางที่ติดท้ายคำนาม** (ไม่ใช่กริยาแยก) และอยู่ท้ายประโยคเสมอ มี 3 รูปที่ต้องรู้: ทางการ **입니다/입니까?** (บท 5) · สุภาพทั่วไป **이에요/예요** (บท 7) · ปฏิเสธ **이/가 아니에요** (บท 7)
ต่อยอดจากข้อ 01 (은/는 — "A은/는 B입니다") และข้อ 35 (ตัวสะกด) · ใช้ต่อในข้อ 21 (입니다 = รูป -ㅂ니다 ของ 이다 · 아닙니다), ข้อ 20 ((이)세요), ข้อ 23 (이었어요/였어요)

### 📌 รูปแบบและเงื่อนไข

| รูป | ระดับ | เงื่อนไข | ตัวอย่าง |
|:---|:---|:---|:---|
| N**입니다** / N**입니까?** | ทางการ *(บท 5 · 교과서 42쪽)* | ไม่ดูตัวสะกด ต่อท้ายได้เลย | 학생**입니다** *(เป็นนักเรียน)* · 중국 사람**입니까?** *(เป็นคนจีนไหม)* |
| N**이에요** | สุภาพทั่วไป *(บท 7 · 58쪽)* | คำนาม **มี**ตัวสะกด | 책**이에요** *(เป็นหนังสือ)* · 사전**이에요** *(เป็นพจนานุกรม)* |
| N**예요** | สุภาพทั่วไป | คำนาม **ไม่มี**ตัวสะกด | 의사**예요** *(เป็นหมอ)* · 카메라**예요** *(เป็นกล้อง)* |
| N**이 아니에요** | ปฏิเสธ *(บท 7 · 60쪽)* | คำนาม **มี**ตัวสะกด | 사전**이 아니에요** *(ไม่ใช่พจนานุกรม)* |
| N**가 아니에요** | ปฏิเสธ | คำนาม **ไม่มี**ตัวสะกด | 카메라**가 아니에요** *(ไม่ใช่กล้อง)* |

- **ความหมายเท่ากัน** — 입니다 = 이에요/예요 ต่างแค่ระดับความสุภาพ (ตำรา: 입니다 ใช้ในสถานการณ์ทางการ · 이에요/예요 ใช้ในสถานการณ์ไม่เป็นทางการ)
- **ถาม** — ทางการเปลี่ยน 입니다 → **입니까?** (✗ 입니다?) · สุภาพทั่วไปใช้รูปเดิมแล้วขึ้นเสียงท้าย: 연필이에요? ↗ *(เป็นดินสอหรือ)*
- **ติดคำนาม ไม่เว้นวรรค**: 학생입니다 ✓ · 사람 입니까 ✗ · แต่ 이/가 ที่ตามด้วย 아니에요 ติดนามแล้ว **เว้นวรรคก่อน 아니에요**: 나무가 아니에요 ✓ · 나무가아니에요 ✗ *(ตำรา 60쪽)*
- **ตอบ** — 네 + ประโยคเต็ม (네, 중국 사람입니다) · 아니요 + ข้อมูลจริง (아니요, 저는 학생입니다 / 아니요, 지우개예요) *(บท 5 ยังไม่มี 아닙니다 — เรียนบท 16)*
- **ตัวสะกดดูที่พยางค์สุดท้าย**: 전화 · 기자 · 여자 · 카드 · 운동선수 ไม่มีตัวสะกด → **예요** (✗ 전화이에요) · 책 · 사전 · 연필 · 지갑 มีตัวสะกด → **이에요**
- **ต่อท้ายหน่วยนับ/คำถาม**: 몇 층**이에요**? (층 มีตัวสะกด) · 몇 호**예요**? (호 ไม่มี) · 몇 번**이에요**? · 얼마**예요**? → 천 원**이에요** · 뭐**예요**? · 누구**예요**? *(ข้อ 04 · ส่วนที่ 3)*
- **เสียงจริง** — 입니다 [임니다] · 입니까 [임니까] · 책이에요 [채기에요] · 지갑이에요 [지가비에요] · 회사원입니다 [회사워님니다] เขียนตามรูปคำ ไม่เขียนตามเสียง

### 📖 ตัวอย่างและการใช้

**บท 5 — ทางการ (ถามด้วย 입니까? · ตอบด้วย 입니다)**

| คำถาม | คำตอบ |
|:---|:---|
| 중국 사람**입니까?** *(เป็นคนจีนไหม)* | 네, 중국 사람**입니다**. *(ใช่ เป็นคนจีน)* |
| 윤아 씨는 선생님**입니까?** *(คุณยุนอาเป็นครูหรือ)* | 아니요, 저는 학생**입니다**. *(ไม่ใช่ ฉันเป็นนักเรียน)* |
| 어느 나라 사람**입니까?** *({e:เป็น}{n:คนประเทศ}{q:ไหน})* | 한국 사람**입니다**. *(เป็นคนเกาหลี)* |
| 이름이 무엇**입니까?** *(ชื่ออะไร)* | 김윤아**입니다**. *(ชื่อคิมยุนอา)* |

**บท 7 — สุภาพทั่วไป (ถามด้วยรูปเดิม ขึ้นเสียง)**
- 연필**이에요**? → 아니요, 지우개**예요**. *(เป็นดินสอหรือ → ไม่ใช่ เป็นยางลบ)*
- 이게 뭐**예요**? → 지갑**이에요**. *(นี่คืออะไร → กระเป๋าสตางค์)*
- 카메라**예요**? → 아니요, 카메라**가 아니에요**. 휴대폰**이에요**. *(เป็นกล้องหรือ → ไม่ใช่กล้อง เป็นมือถือ)*
- 투이 씨 사전**이에요**? → 아니요, **제** 사전**이 아니에요**. 친구 사전**이에요**. *(ของคุณทุยหรือ → ไม่ใช่ของฉัน ของเพื่อน — **제 = 저의** "ของฉัน" วางหน้านาม)*
- 이것은 국민대학교 학생증**이에요**. 그리고 이것은 여자 친구 사진**이에요**. 제 여자 친구는 러시아 사람**이 아니에요**. 미국 사람**이에요**. *(บทอ่านบท 7: นี่คือบัตรนักศึกษา และนี่คือรูปแฟน แฟนฉันไม่ใช่คนรัสเซีย เป็นคนอเมริกัน)*

### ⚠️ จุดสับสน

#### 입니까 ≠ 입니다 · 아니요 ≠ 아니에요
| | ใช้เมื่อ | ตัวอย่าง |
|:---|:---|:---|
| **입니까?** | ถาม (ทางการ) — ต้องลงท้าย 까 | 중국 사람입니까? ✓ · 중국 사람입니다? ✗ |
| **입니다** | บอกเล่า (ทางการ) | 네, 중국 사람입니다. |
| **아니요** | "ไม่" — คำตอบ ขึ้นต้นประโยค | 아니요, 지갑이 아니에요. |
| **아니에요** | "ไม่ใช่" — กริยา ท้ายประโยค มี 이/가 อยู่หน้า | 지갑**이** 아니에요. ✓ · 지갑이 아니요 ✗ |

#### 이에요/예요 vs 있어요 (และ 아니에요 vs 없어요)
ไทยใช้คำว่า "เป็น / มี / อยู่" ต่างกัน แต่คนเรียนมักเอา 이에요/예요 ไปใช้แทน "มี/อยู่" — 이다 = **เป็น/คือ** (เอาคำนามมาเทียบกัน) · 있다 = **มี/อยู่** (บอกการมีอยู่)

| | เป็น/คือ | มี/อยู่ |
|:---|:---|:---|
| ยืนยัน | 이에요/예요 | 있어요 |
| ปฏิเสธ | 이/가 아니에요 (ไม่ใช่) | 이/가 없어요 (ไม่มี/ไม่อยู่) |

* 저는 학생**이에요**. ✓ *(ฉันเป็นนักเรียน)*
* 교실에 학생**이 있어요**. ✓ *(ในห้องเรียนมีนักเรียนอยู่)*
* 여기가 도서관**이에요**. ✓ *(ที่นี่คือห้องสมุด)*
* 저는 학생**이 아니에요**. ✓ *(ฉันไม่ใช่นักเรียน)* / 교실에 학생**이 없어요**. ✓ *(ในห้องเรียนไม่มีนักเรียน)*

> [!TIP]
> **กฎจำง่าย:** "A คือ B" → 이에요/예요 (A = B) · "A มี/อยู่ ที่…" → 있어요 · ปฏิเสธ: ไม่ใช่ → 아니에요 · ไม่มี → 없어요

#### โครงสร้างประโยค 이에요/예요 vs 있어요 — ต้องมี 이/가 ไหม?
สองตัวนี้ไม่ใช่แค่ "ความหมายต่างกัน" แต่เป็น**คนละชนิดคำ** จึงต่อกับคำนามคนละแบบ

| | 이에요/예요 (이다) | 있어요 (있다) |
|:---|:---|:---|
| คืออะไร | **หาง** ที่ติดท้ายคำนาม (= "คือ/เป็น") | **กริยา** เดี่ยว ๆ (= "มี/อยู่") |
| คำนามข้างหน้า | ติดกัน **ไม่มี 조사 ไม่เว้นวรรค** → 학생**이에요** | ต้องมี **이/가** + **เว้นวรรค** → 학생**이 있어요** |
| ตัว 이 ที่เห็น | เป็น**ส่วนหนึ่งของคำ** 이에요 (ไม่ใช่ 조사) | เป็น **조사 ประธาน** 이/가 |
| ขึ้นกับตัวสะกด | 책**이에요** / 의사**예요** | 책**이** 있어요 / 의사**가** 있어요 (ดูข้อ 01) |
| ปฏิเสธ | 이/가 **아니에요** (ตรงนี้กลับ "ต้องมี" 이/가) | **없어요** (안 있어요 ✗) |
| รูปทางการ | 입니다 / 입니까? | 있습니다 / 있습니까? |
| รูปยกย่อง | (이)세요 | 계세요 (คนอยู่) / 있으세요 (มีของ) → ข้อ 20 |

**ตอบตรง ๆ ว่า "ต้องมี 이/가 ไหม"**

1. **이에요/예요 → คำนามข้างหน้า "ห้ามมี" 이/가**
   - 저는 학생**이에요**. ✓ · 학생**이 이에요** ✗ · 학생**을 이에요** ✗
   - ส่วน*ประธาน*ของประโยค (คำแรก) ใช้ 은/는 ตามปกติ; ใช้ 이/가 เมื่อตอบคำถาม "ใคร/อันไหน"
     → 그것**이** 마키 씨 지갑입니까? (ชื่อบท 6) · **제가** 학생이에요. (ตอบ 누가?)
2. **아니에요 → "ต้องมี" 이/가 เสมอ** — ข้อยกเว้นที่ทำให้งง
   - 저는 학생**이 아니에요**. ✓ · 학생 아니에요 ✗ (ในข้อสอบ)
   - 이/가 ตรงนี้ **ไม่ใช่ประธาน** แต่เป็น "ตัวต่อ" ที่ 아니다 บังคับใช้ ประโยคจึงมี 이/가 ซ้ำได้: 이것**이** 제 사전**이** 아니에요.
3. **있어요/없어요 → "ต้องมี" 이/가 ที่คำนามหน้ามัน และห้ามเป็น 을/를**
   - 교실에 학생**이** 있어요. ✓ · 학생**을** 있어요 ✗ ← กับดักใหญ่ เพราะไทยพูด "มี + กรรม"
   - "ฉันมีน้อง": 저**는** 동생**이** 있어요. (คนที่มี = 은/는 · สิ่งที่มี = 이/가)

**โครงสร้างสำเร็จรูป 3 แบบ**

| แบบ | โครงสร้าง | ตัวอย่าง |
|:---|:---|:---|
| ① A คือ B | A**은/는** B**이에요/예요** | 저는 태국 사람**이에요**. |
| ① A ไม่ใช่ B | A**은/는** B**이/가 아니에요** | 저는 중국 사람**이 아니에요**. |
| ② B อยู่ที่ P | B**이/가** P**에** 있어요/없어요 | 책**이** 책상 위**에** 있어요. |
| ② (สลับได้) | P**에** B**이/가** 있어요/없어요 | 책상 위**에** 책**이** 있어요. |
| ③ A มี B | A**은/는** B**이/가** 있어요/없어요 | 저**는** 형**이** 있어요. |

**ประโยคคู่ที่ดูเหมือนกันแต่คนละเรื่อง**

| ประโยค | ความหมาย |
|:---|:---|
| 학생**이에요**. | (เขา) **เป็น**นักเรียน |
| 학생**이 있어요**. | **มี**นักเรียน / นักเรียน**อยู่** |
| 학생**이 아니에요**. | **ไม่ใช่**นักเรียน |
| 학생**이 없어요**. | **ไม่มี**นักเรียน |
| 여기**가** 도서관**이에요**. | ที่นี่**คือ**ห้องสมุด |
| 여기**에** 도서관**이 있어요**. | ที่นี่**มี**ห้องสมุด |

> [!TIP]
> **ตัดสินใจเร็ว:** แปลไทยแล้วเจอ "คือ/เป็น" → 이에요 ติดคำนามเลย · "มี/อยู่" → 이/가 + เว้นวรรค + 있어요 · "ไม่ใช่" → 이/가 아니에요 · "ไม่มี" → 이/가 없어요
> จำง่าย ๆ: **"ติด" = 이에요 · "แยก" = 있어요**

#### ประโยคเดียวกัน 3 แบบ — รูปทางการ 입니다 / 있습니다 (จากชุดทบทวนกลางภาค ข้อ 1)

ข้อสอบให้เลือก (입니다, 있습니다) ในประโยคเดียว ดูว่าสิ่งที่อยู่ข้างหน้า "ติดได้" หรือ "ต้องมีคำช่วย"

| ประโยค | แปล | ใช้ได้ไหม |
|:---|:---|:---|
| 고향이 LA**입니다** | บ้านเกิด**คือ** LA | ✓ คำตอบของข้อนี้ — 입니다 ติดคำนามตรง ๆ |
| 고향이 LA**에** 있습니다 | บ้านเกิด**อยู่ที่** LA | ✓ แต่ต้องมี 에 — โจทย์ไม่ได้ให้ 에 จึงเลือกไม่ได้ |
| 고향이 LA 있습니다 | (บ้านเกิดมี… LA?) | ✗ LA ไม่มีคำช่วย ไม่เป็นประโยค |
| 아버지, 어머니, 남동생**이 있습니다** | **มี**พ่อ แม่ น้องชาย | ✓ 이 นำหน้า + เว้นวรรค = มี |
| 아버지, 어머니, 남동생**입니다** | (พวกเขา) **เป็น**พ่อ แม่ น้องชาย | ✓ ถูกไวยากรณ์ แต่ไม่ใช่ความหมายของเรื่อง |
| 남동생이 입니다 | — | ✗ 입니다 ไม่รับ 이/가 ข้างหน้า |

> [!TIP]
> **เห็น 이/가 นำหน้าช่องว่าง → ต้องเป็น 있습니다/없습니다** (입니다 ติดคำนามเสมอ ไม่มี 이/가 คั่น) · **เห็น 에 นำหน้า → 있습니다** (입니다 ไม่ใช้กับ 에)

**กรณีคำนามหลายคำต่อด้วย 와/과 (บท 15 · ข้อ 19)** — ดู**คำสุดท้าย**ที่ติด 이에요/예요 คำเดียว คำข้างหน้าไม่เกี่ยว และช่องว่างไม่ต้องใส่ 이/가

| โจทย์ (워크북 15과) | เฉลย | เหตุผล |
|:---|:---|:---|
| 지훈 씨 방 친구는 ___ (이에요/예요). | 인성과 수현**이에요** | 수현 ลงท้าย ㄴ → 이에요 |
| 지훈 씨 취미는 ___ (이에요/예요). | 요리와 축구**예요** | 축구 ลงท้ายสระ → 예요 |
| เทียบ: 지훈 씨 방에 ___ 있어요. | 인성과 수현**이** 있어요 | 있어요 = กริยา → ต้องมี 이 + เว้นวรรค |
