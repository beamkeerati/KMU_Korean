## 31. 만 (...เท่านั้น / เพียง...)

> [!INTRO] ข้อนี้คืออะไร
> 만 เป็นคำช่วยที่เน้น**คนหรือสิ่งเดียว** แล้วตัดอย่างอื่นออก แปลว่า "แค่ / เฉพาะ / แต่" ไม่เปลี่ยนรูปตามตัวสะกด
>
> สอนในบท 21 (교과서 188–189쪽) ต่อยอดจาก ข้อ 17 (도: แทน/ซ้อนคำช่วยแบบเดียวกัน)
>
> ต่อยอดจาก ข้อ 01 และ ข้อ 07 (은/는 · 이/가 · 을/를 ที่ถูกแทน) ด้วย
>
> ไปใช้ต่อใน ข้อ 32 (읽기 21 มีทั้ง 만 และ -고 있다) และ ข้อ 35 (ตาราง 받침)

### 📌 รูปแบบและเงื่อนไข

만 ต่อท้ายคำนามได้ตรง ๆ โดยแทน 이/가 · 은/는 · 을/를 หรือจะซ้อนหลังคำช่วยอื่นอย่าง 에 / 에서 / 에게 / 하고 ก็ได้ ตารางแรกบอกตำแหน่งที่ 만 ไปต่อ ตารางที่สองคือตัวอย่างของแต่ละตำแหน่ง

| ตำแหน่ง | วิธีใช้ |
|:---|:---|
| ต่อท้ายนามตรง ๆ | N + **만** (แทน 이/가 · 은/는 · 을/를) |
| ต่อท้ายจำนวน | จำนวน + **만** |
| ซ้อนหลังคำช่วยอื่น | N + 에 / 에서 / 에게 / 하고 + **만** |
| ต่อท้ายช่วงเวลา | 부터~까지 + **만** |

#### ตัวอย่างตามตำแหน่ง

ตารางนี้เรียงตามตำแหน่งข้างบน หนึ่งประโยคต่อหนึ่งแถว

| ตำแหน่ง | 한국어 | ไทย |
|:---|:---|:---|
| ต่อท้ายนามตรง ๆ | 저**만** 한국에 있어요 | มี{p:แค่}{n:ฉัน}ที่{v:อยู่}{n:เกาหลี} |
| ต่อท้ายนามตรง ๆ | 우유**만** 마셔요 | {v:ดื่ม}{p:แต่}{n:นม} |
| ต่อท้ายจำนวน | 커피 한 잔**만** 마셔요 | {v:ดื่ม}{n:กาแฟ}{p:แค่}{m:แก้วเดียว} |
| ต่อท้ายจำนวน | 하루에 한 번**만** 먹어요 | {v:กิน}{n:วัน}{p:ละ}{m:ครั้งเดียว} |
| ซ้อนหลังคำช่วยอื่น | 월요일**에만** 배워요 | เรียนเฉพาะวันจันทร์ |
| ซ้อนหลังคำช่วยอื่น | 집**에서만** 공부해요 | เรียนเฉพาะที่บ้าน |
| ซ้อนหลังคำช่วยอื่น | 친구**에게만** 말해요 | บอกแค่เพื่อน |
| ซ้อนหลังคำช่วยอื่น | 친구**하고만** 가요 | ไปกับเพื่อนเท่านั้น |
| ต่อท้ายช่วงเวลา | 월요일부터 금요일까지**만** 학교에 가요 | ไปโรงเรียนเฉพาะจันทร์ถึงศุกร์ |

#### ข้อสังเกต

ตำรา 188쪽 อธิบายหน้าที่ของ 만 ไว้ และมีข้อสังเกตเรื่องรูปกับรูปตอบที่ใช้บ่อย

- **ตำรา 188쪽:** 만 = เน้นคำที่อยู่ข้างหน้าเพียงคำเดียวและตัดสิ่งอื่นทั้งหมดออก
- ต่อท้ายนามหรือหลังคำช่วยอื่นได้
- ไม่เปลี่ยนตามตัวสะกด: 저만 · 선생님만 · 물만 (ข้อ 35)
- ติดคำหน้าไม่เว้นวรรค (ข้อ 13)
- รูปตอบที่ใช้บ่อย: ถามรวม ๆ (모두 · -도?) แล้วตอบ **아니요, N만 …**
- หรือเล่า 2 ประโยค **안 V. N만 V.** *(ไม่ทำ… แต่ทำเฉพาะ N)*

### 📖 ตัวอย่างและการใช้

ตัวอย่างแบ่งเป็นสองแบบ คือถาม–ตอบที่ตอบว่า "ไม่ใช่ทั้งหมด มีแค่…" และประโยคเดี่ยวที่ใช้ 만

#### ถาม–ตอบ: "ไม่ใช่ทั้งหมด — มีแค่…"

คำถามรวม ๆ เช่น 모두 หรือ -도? ถามว่าทุกคนหรือทุกอย่างใช่ไหม คำตอบด้วย 만 จะเลือกเหลือแค่สิ่งเดียว

| ถาม | ตอบ |
|:---|:---|
| 가족이 모두 한국에 있어요? *(ครอบครัวอยู่เกาหลีทั้งหมดไหม)* | 아니요, **저만** 한국에 있어요. *({x:ไม่} {v:มี}{p:แค่}{n:ฉัน})* |
| 가족들이 모두 고향에 있어요? *(ครอบครัวอยู่บ้านเกิดทั้งหมดไหม)* | 아니요, **부모님만** 고향에 계세요. *({x:ไม่} มี{p:แค่}{n:พ่อแม่}ที่{v:อยู่}{n:บ้านเกิด})* |
| 학교에서 영어도 배워요? *(ที่โรงเรียนเรียนอังกฤษด้วยไหม)* | 아니요, **한국어만** 배워요. *(ไม่ เรียนแค่ภาษาเกาหลี)* |
| 아침에 밥을 먹어요? *({p:ตอน}{n:เช้า}{v:กิน}{n:ข้าว}ไหม)* | 아니요, **우유만** 마셔요. *({x:ไม่} {v:ดื่ม}{p:แต่}{n:นม})* |

#### ประโยคตัวอย่าง

ประโยคเดี่ยวต่อไปนี้ใช้ 만 กับนาม จำนวน และคำช่วย

- 저는 고기를 안 먹어요. 야채**만** 먹어요. *({n:ฉัน}{x:ไม่}{v:กิน}{n:เนื้อ} {v:กิน}{p:แต่}{n:ผัก} — 보기 ของเวิร์กบุ๊ก 21과)*
- 선생님**만** 한국 사람이에요. *({p:เฉพาะ}{n:ครู}ที่{e:เป็น}{n:คนเกาหลี})*
- 고향에는 어머니**만** 계십니다. *(ที่บ้านเกิดมีเฉพาะแม่)*
- 저는 아침에 커피 한 잔**만** 마셔요. *({p:ตอน}{n:เช้า}{v:ดื่ม}{n:กาแฟ}{p:แค่}{m:แก้วเดียว})*
- 월요일에**만** 태권도를 배워요. *(เรียนเทควันโดเฉพาะวันจันทร์)*
- 이리나 씨**만** 커피를 마셔요. *(มี{p:แค่}{n:อีรีนา}ที่{v:ดื่ม}{n:กาแฟ})*

### ⚠️ จุดสับสน

만 กับ 도 หน้าตาการใช้คล้ายกันมากแต่ความหมายตรงข้ามกัน ตอนนี้จะเทียบตำแหน่งที่ทั้งสองคำไปต่อ แล้วเทียบความหมายกับ 은/는

#### 만 "แทน" vs "ซ้อน" และ 만 vs 도

เหมือน 도 (ข้อ 17) คือ 만 **แทน** 이/가/은/는/을/를 แต่ **ซ้อน** หลัง 에/에서/에게 และ 만 กับ 도 มีความหมาย**ตรงข้าม**กัน

| | แทน 이/가 · 은/는 · 을/를 | ซ้อนหลัง 에/에서/에게 |
|:---|:---|:---|
| 만 | 저**만**, 물**만** | 집에서**만**, 친구에게**만**, 월요일에**만** |
| 도 | 저**도**, 물**도** | 집에서**도**, 친구에게**도**, 월요일에**도** |

ตารางต่อไปนี้เทียบความหมายของ 은/는 · 도 · 만 โดยใช้ตัวอย่างชุดเดียวกัน

| | 은/는 (ข้อ 01) | 도 (ข้อ 17) | 만 |
|:---|:---|:---|:---|
| ความหมาย | หัวเรื่อง / เปรียบเทียบ | "ก็ / ด้วย" (เพิ่ม) | "เท่านั้น" (ตัดออก) |
| ตัวอย่าง 1 | 저**는** 한국에 있어요 *(ฉันอยู่เกาหลี)* | 저**도** 있어요 *(ฉันก็อยู่)* | 저**만** 있어요 *({v:มี}{p:แค่}{n:ฉัน})* |
| ตัวอย่าง 2 | — | 저**도** 가요 *(ฉันก็ไปด้วย)* | 저**만** 가요 *({v:ไป}{p:แค่}{n:ฉัน}คนเดียว)* |

#### ตัวอย่างถูก–ผิดและเกณฑ์เลือก 만 หรือ 도

ดูคู่ ✓ / ✗ ต่อไปนี้ แล้วใช้ประโยคก่อนหน้าเป็นเกณฑ์ว่าจะเลือก 만 หรือ 도

- ✓ 커피**만** 마셔요. *(ดื่มแค่กาแฟ)*
- ✓ 커피**만** 안 마셔요. *({p:เฉพาะ}{n:กาแฟ}ที่{x:ไม่}{v:ดื่ม} — อย่างอื่นดื่ม)* ความหมายต่างจากประโยคบน

| ✓ ถูก | ✗ ผิด | เหตุผล |
|:---|:---|:---|
| 저**만** | 저는만 · 저가만 | 만 แทน 은/는/이/가/을/를 ไม่ซ้อน |

| เกณฑ์ | 한국어 | ไทย | เลือก |
|:---|:---|:---|:---|
| เพิ่มจากของเดิม | 한국 음식을 잘 먹어요. 중국 음식**도** 잘 먹어요. | กินอาหารเกาหลีเก่ง อาหารจีนก็กินเก่ง | เพิ่ม → 도 |
| ตัดของอื่นออก | 아침에 밥을 안 먹어요. 우유**만** 마셔요. | ตอนเช้าไม่กินข้าว ดื่มแค่นม | ตัดออก → 만 |

> [!TIP] กฎสั้น ๆ
> **만 = "แค่" (ตัดคนอื่นออก) · 도 = "ก็" (เพิ่มคนอื่นเข้า) · ทั้งคู่แทน 이/가/을/를 และซ้อนหลัง 에/에서/에게**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ยังไม่มีข้อสอบจริงที่ครูตรวจแล้วเกี่ยวกับ 만 ข้อที่เสี่ยงผิดคือการซ้อนคำช่วย (✗ 저는만 / 저가만) ส่วนโจทย์ที่ใช้ตัวนี้อยู่ในชุดทบทวนของครู ข้อสอบรวม และชีตฟัง

- 21과 อยู่ในขอบเขต 중간시험 (10/22–23) แต่ไม่อยู่ใน 복습시험②
- **ชุดทบทวนของครู (중간시험 복습문제):**
  - Q3 ย่อย 4) `아침에 밥을 안 먹어요. 우유( ) 마셔요.` *(เช้าไม่กินข้าว ดื่มแค่นม)* → เติม **만**
  - 읽기 Q24–25 จดหมายบทที่ 21 มี `저만 여기에서 고향을 생각하고 있어요` *(มีแค่ฉันที่นี่ที่กำลังคิดถึงบ้านเกิด)*
- **ข้อสอบรวม 5~21과:**
  - Q23 `한국 음식을 잘 먹어요. 중국 음식 ( ) 잘 먹어요` *(กินอาหารเกาหลีเก่ง อาหารจีนก็กินเก่ง)* → **도** (เพิ่ม ไม่ใช่ตัดออก)
  - Q37 `티셔츠 하나만 샀습니다` (ซื้อแค่ตัวเดียว)
  - เฉลยในไฟล์เป็นการแก้เอง ไม่ใช่เฉลยครู
- **ชีตฟัง 본문 듣기 21과 (ช่อง B):** เติม **저만** จากบทสนทนา `그래서 저만 있어요` *(เลยมีแค่ฉัน)*

> [!SUMMARY] สรุป
> - 만 = "แค่ / เฉพาะ" (ตัดคนอื่นออก) ต่อท้ายนามหรือจำนวนได้ตรง ๆ และไม่เปลี่ยนตามตัวสะกด (저만 · 선생님만 · 물만)
> - แทน 이/가 · 은/는 · 을/를 แต่ซ้อนหลัง 에 / 에서 / 에게 / 하고 (집에서만 · 친구에게만)
> - 만 = ตัดออก ส่วน 도 = เพิ่มเข้า ดูประโยคก่อนหน้าเป็นเกณฑ์เลือก
> - ✗ 저는만 / 저가만 → ✓ 저만 รูปตอบที่ใช้บ่อยคือ **아니요, N만 …** หรือ **안 V. N만 V.**
