### 📚 คำศัพท์ 5과 (ชีตคำศัพท์ของศูนย์ · 어느 나라 사람입니까?)

| 단어 | ไทย | English |
|---|---|---|
| 중국 | จีน | China |
| 사람 | คน | person |
| 일본 | ญี่ปุ่น | Japan |
| 몽골 | มองโกเลีย | Mongolia |
| 베트남 | เวียดนาม | Vietnam |
| 러시아 | รัสเซีย | Russia |
| 호주 | ออสเตรเลีย | Australia |
| 어느 나라 | ประเทศไหน | which country |
| 한국 | เกาหลี | Korea |
| 미국 | อเมริกา | America (USA) |
| 캐나다 | แคนาดา | Canada |
| 사우디아라비아 | ซาอุดีอาระเบีย | Saudi Arabia |
| 태국 | ไทย (ประเทศไทย) | Thailand |
| 씨 | คุณ (ต่อท้ายชื่อ) | Mr./Ms. |
| 선생님 | ครู | teacher |
| 저 | ฉัน/ผม (สุภาพ) | I (humble) |
| 학생 | นักเรียน นักศึกษา | student |
| 요리사 | พ่อครัว แม่ครัว เชฟ | chef, cook |
| 회사원 | พนักงานบริษัท | office worker |
| 변호사 | ทนายความ | lawyer |
| 경찰관 | ตำรวจ | police officer |
| 의사 | แพทย์ หมอ | doctor |
| 간호사 | พยาบาล | nurse |
| 가수 | นักร้อง | singer |
| 운동선수 | นักกีฬา | athlete |
| 이름 | ชื่อ | name |
| 직업 | อาชีพ | job, occupation |
| 친구 | เพื่อน | friend |
| 안녕하세요? | สวัสดีครับ/ค่ะ | Hello |

**∞ 읽기 ∞ (ศัพท์จากบทอ่าน)**

| 단어 | ไทย | English |
|---|---|---|
| 병원 | โรงพยาบาล | hospital |
| 호텔 | โรงแรม | hotel |
| 이메일 | อีเมล | email |
| 전화번호 | หมายเลขโทรศัพท์ | phone number |
| 만나서 반갑습니다 | ยินดีที่ได้รู้จัก | Nice to meet you |

*โน้ตที่คุณเขียนไว้ท้ายหน้า:* 회사 = company (บริษัท); 원 / 사 / 관 / 수 = person (คำต่อท้ายบอกคน เช่น 회사원, 변호사, 경찰관, 운동선수)
