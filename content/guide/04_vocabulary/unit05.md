### 📚 คำศัพท์ 5과 (ชีตคำศัพท์ของศูนย์ · 어느 나라 사람입니까?)

| 단어 | ไทย | English |
|---|---|---|
| 중국 | จีน | China |
| 사람 | คน | person |
| 일본 | ญี่ปุ่น | Japan |
| 몽골 | มองโกเลีย | Mongolia |
| 베트남 | เวียดนาม | Vietnam |
| 러시아 | รัสเซีย | Russia |
| 호주 | ออสเตรเลีย | Australia |

| 사우디아라비아 | ซาอุดีอาระเบีย | Saudi Arabia |

**∞ 읽기 ∞ (ศัพท์จากบทอ่าน)**

| 단어 | ไทย | English |
|---|---|---|
| 병원 | โรงพยาบาล | hospital |
| 호텔 | โรงแรม | hotel |
| 이메일 | อีเมล | email |
| 전화번호 | หมายเลขโทรศัพท์ | phone number |
| 만나서 반갑습니다 | ยินดีที่ได้รู้จัก | Nice to meet you |

*โน้ตที่คุณเขียนไว้ท้ายหน้า:* 회사 = company (บริษัท); 원 / 사 / 관 / 수 = person (คำต่อท้ายบอกคน เช่น 회사원, 변호사, 경찰관, 운동선수)

#### ศัพท์เพิ่มเติมจากตำราและเวิร์กบุ๊ก (ไม่อยู่ในชีตของศูนย์)

คำต่อไปนี้ใช้ในบทนี้ของตำราหรือเวิร์กบุ๊ก แต่ไม่มีในชีตคำศัพท์ของศูนย์ เรียงจากคำที่พบบ่อยที่สุด

| 단어 | ไทย | English |
|---|---|---|
| 아니요 | ไม่ ไม่ใช่ (ใช้เป็นคำตอบเท่านั้น) | no (as an answer) |
| 네 | ครับ ค่ะ ใช่ | yes |
| 안녕하세요 | สวัสดี | hello |
| 이다 | เป็น คือ (입니다 / 이에요) | to be |
| 아니다 | ไม่ใช่ (กริยา N이/가 아니에요) | to not be |
| 어느 | ไหน (어느 나라 = ประเทศไหน) | which |
| 소개 | การแนะนำ | introduction |
| 명함 | นามบัตร | business card |
| 국민대학교 | มหาวิทยาลัยคุกมิน | Kookmin University |
| 법원 | ศาล | court |
| 법률 회사 | บริษัทกฎหมาย | law firm |
| 또는 | หรือ | or |
| 내용 | เนื้อหา | content |
| 부분 | ส่วน | part |
| 확인하다 | ตรวจสอบ ยืนยัน | to check, to confirm |
| 얘기(를) 하다 | คุยกัน (= 이야기하다) | to talk |
| 자모 | พยัญชนะและสระฮันกึล | Korean letters |
| 받침 | ตัวสะกด | final consonant |
| 발음 | การออกเสียง | pronunciation |
| 연음 | การเชื่อมเสียง | liaison |
| 얘기 | เรื่องที่คุย (= 이야기) | talk, story |
