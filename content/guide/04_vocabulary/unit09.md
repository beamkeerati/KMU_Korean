### 📚 คำศัพท์ 9과 (ชีตคำศัพท์ของศูนย์ · 도서관은 학생회관 옆에 있어요)

| 앞 | ข้างหน้า | front |
| 뒤 | ข้างหลัง | back, behind |
| 위 | ข้างบน | above, on top |
| 아래 | ข้างล่าง | below, under |
| 옆 | ข้าง ๆ | beside, next to |
| 안 | ข้างใน | inside |
| 밖 | ข้างนอก | outside |
| 칠판 | กระดานดำ | blackboard, whiteboard |

| 나무 | ต้นไม้ ไม้ | tree, wood |
| 도서관 | ห้องสมุด | library |
| 우체국 | ที่ทำการไปรษณีย์ | post office |

**∞ 읽기 ∞ (ศัพท์จากบทอ่าน)**

| 단어 | ไทย | English |
|---|---|---|
| 매일 | ทุกวัน | every day |
| 위층 | ชั้นบน | upper floor |
| 학생 식당 | โรงอาหารนักศึกษา | student cafeteria |
| 음식 | อาหาร | food |
| 맛있다 | อร่อย | to be delicious |

*โน้ตที่คุณเขียนไว้ท้ายหน้า:* 아래 = 밑 (ข้างล่าง ใช้แทนกันได้); 극장 (โรงภาพยนตร์ = movie theater)
