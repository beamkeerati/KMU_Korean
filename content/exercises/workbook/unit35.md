## 35과 · 워크북 (운동하는 것을 좋아하세요? - ชอบการออกกำลังกายไหมคะ)
*หน้าหนังสือ 162–165 (สแกน wb-1 ถึง wb-4) · ไม่มีรอยดินสอของผู้เรียนเลย (มีเฉพาะตัวอย่างที่พิมพ์ไว้ในหนังสือ) · 7 แบบฝึกหัด (A–G)*

### A. 어휘 1: 관계 있는 것을 연결하세요.
*คำสั่ง: โยงสิ่งที่เกี่ยวข้องกัน — ภาพทางซ้ายกับคำทางขวา (ในหนังสือให้ลากเส้นโยง ในไฟล์นี้ให้เขียนคำลงในวงเล็บแทน)*

> **คำทางขวาที่พิมพ์ไว้ (เรียงตามหนังสือ):** ⓐ 태권도 (เทควันโด) · ⓑ 찜질방 (ชิมจิลบัง ซาวน่าเกาหลี) · ⓒ 삼계탕 (ซัมกเยทัง ไก่ตุ๋นเกาหลี) · ⓓ 한복 (ฮันบก ชุดประจำชาติเกาหลี)

1. 🖼️ หม้อหินสีดำใบใหญ่ ในหม้อมีไก่ทั้งตัวแช่อยู่ในน้ำซุป — (　　　　)
2. 🖼️ ผู้ชายสวมชุดเทควันโดสีขาว คาดเข็มขัดดำ กำลังเตะขาขึ้นสูง — (　　　　)
3. 🖼️ ผู้หญิงผูกผมเป็นมวย สวมชุดฮันบก เสื้อตัวสั้นสีเข้มผูกริบบิ้น กระโปรงบานยาวสีเทาเข้ม (ภาพเต็มตัว) — (　　　　)
4. 🖼️ ภาพสองคนนั่งขัดสมาธิบนพื้นหน้าห้องทรงโดมคล้ายอิกลู คนหนึ่งสวมผ้าขนหนูม้วนเป็นหมวกทรงหัวแกะ ทั้งสองดื่มเครื่องดื่มและมีชามอาหารว่างวางอยู่ตรงหน้า — (　　　　)

### B. 어휘 2: <보기>에서 알맞은 단어를 골라 문장을 완성하세요.
*คำสั่ง: เลือกคำที่เหมาะสมจาก <보기> มาเติมให้ประโยคสมบูรณ์ (ใส่เฉพาะส่วนหน้า ส่วนที่ต่อท้ายพิมพ์ไว้ในประโยคแล้ว)*

> **<보기>:** 떠나다 (ออกเดินทาง จากไป) · 설명하다 (อธิบาย) · 고민 (ความกังวล เรื่องหนักใจ) · 상 (รางวัล)

1. 날씨가 좋으니까 가까운 곳으로 여행을 (　　　　)(으)ㄹ까요? *(อากาศดี … ไปเที่ยวที่ใกล้ ๆ กันดีไหม)*
2. 간토야 씨는 시험 점수가 좋아요. 그래서 선생님께서 간토야 씨에게 (　　　　)을/를 줬어요. *(คุณคันโตยะได้คะแนนสอบดี ครูเลยมอบ … ให้คุณคันโตยะ)*
3. 이 문법을 모르겠어요? 다시 (　　　　)(으)ㄹ까요? *(ไม่เข้าใจไวยากรณ์นี้เหรอ ให้ … อีกครั้งดีไหม)*
4. 요즘 밤에 잠을 못 자서 (　　　　)예요/이에요. *(ช่วงนี้กลางคืนนอนไม่หลับ นี่เป็น … ของฉัน)*

---

### C. -는 것 1: <보기>에서 알맞은 동사를 골라 문장을 완성하세요.
*คำสั่ง: เลือกกริยาจาก <보기> แล้วเติมเป็นรูป V-는 것 (การ…) ให้ประโยคสมบูรณ์ (ข้อ 1 เป็นตัวอย่าง)*

> **<보기>:** 하다 (ทำ) · 보다 (ดู) · 만들다 (ทำ สร้าง) · 읽다 (อ่าน) · 입다 (สวมใส่) · 모르다 (ไม่รู้ ไม่เข้าใจ)

1. 날마다 운동을 하는 것은 어렵습니다. *(ตัวอย่าง — การออกกำลังกายทุกวันเป็นเรื่องยาก)*
2. 아이들이 혼자 옷을 (　　　　)은 쉽지 않아요. *(การที่เด็ก ๆ … เสื้อผ้าด้วยตัวเองไม่ใช่เรื่องง่าย)*
3. 매일 저녁 음식을 (　　　　)이 재미있어요. *(การ … อาหารทุกเย็นเป็นเรื่องสนุก)*
4. 영화관에서 영화를 (　　　　)이 집에서 (　　　　)보다 더 재미있었어요. *(การ … หนังที่โรงภาพยนตร์สนุกกว่าการ … ที่บ้าน)*
5. 한국 소설을 (　　　　)은 아직 어려워요. *(การ … นิยายเกาหลียังยากอยู่)*
6. 한국어 문법 중에서 아직 (　　　　)이 많이 있어요. *(ในไวยากรณ์ภาษาเกาหลี ยังมีสิ่งที่ … อยู่มาก)*

---

### D. -는 것 2: <보기>와 같이 문장을 완성하세요.
*คำสั่ง: เติมประโยคตามตัวอย่าง โดยเทียบสองกิจกรรมด้วยรูป V-는 것보다 … V-는 것을 더 …*

> **<보기>:** 저는 노래를 부르는 것보다 춤추는 것을 더 좋아해요. *(ฉันชอบการเต้นมากกว่าการร้องเพลง)*

1. 저는 게임을 (　　　　)보다 (　　　　)을/를 더 좋아해요. *(เมื่อเทียบกับการ … เกม ฉันชอบการ … มากกว่า)*
2. 제 동생은 음악을 (　　　　)보다 (　　　　)을/를 더 좋아해요. *(เมื่อเทียบกับการ … ดนตรี น้องของฉันชอบการ … มากกว่า)*
3. 청소를 (　　　　)보다 (　　　　)이/가 더 힘들어요. *(เมื่อเทียบกับการ … ทำความสะอาด การ … ลำบากกว่า)*
4. 비타민을 (　　　　)보다 (　　　　)이/가 건강에 더 좋아요. *(เมื่อเทียบกับการ … วิตามิน การ … ดีต่อสุขภาพมากกว่า)*
5. 명동에서 (　　　　)보다 (　　　　)이/가 더 재미있어요. *(เมื่อเทียบกับการ … ที่เมียงดง การ … สนุกกว่า)*

### E. -아/어/여 보다 1: <보기>와 같이 문장을 완성하세요.
*คำสั่ง: เติมประโยคตามตัวอย่าง โดยใช้กริยาในวงเล็บเติมหน้า "봤어요" (บอกประสบการณ์ "เคย…")*

> **<보기>:** 놀이공원에 가 봤어요? *(เคยไปสวนสนุกไหม — ในหนังสือขีดเส้นใต้ 가)*

1. 전에 이 음료수를 (　　　　) 봤어요. (마시다) *(เมื่อก่อนเคยดื่มเครื่องดื่มนี้มาแล้ว)*
2. 한국에서 혼자 (　　　　) 봤어요? (여행하다) *(เคยเที่ยวเกาหลีคนเดียวไหม)*
3. 노래방에서 한국 노래를 (　　　　) 봤어요? (부르다) *(เคยร้องเพลงเกาหลีที่ร้านคาราโอเกะไหม)*
4. 이 음악을 (　　　　) 봤어요? (듣다) *(เคยฟังเพลงนี้ไหม)*
5. 스키를 (　　　　) 봤어요. (안 타다) *(ไม่เคยเล่นสกีมาก่อน)*

### F. -아/어/여 보다 2: 다음 대화를 완성하세요.

2. 가: 도서관이 오늘 문을 열어요? *(วันนี้ห้องสมุดเปิดไหม)*

3. 가: 떡볶이를 만들어 봤어요? *(เคยทำต๊อกบกกีไหม)*

*คำสั่ง: เติมบทสนทนาในกรอบให้สมบูรณ์ (ช่องว่างเลือกเติมเองได้ เช่น กีฬาหรือกิจกรรมที่ชอบ — ในไฟล์นี้ใส่เลข 1)–9) กำกับช่องว่างเพื่อให้ตรงกับเฉลย)*

## 35과 · 워크북 (เฉลย)
*เฉลยจากหน้า 194 ของหนังสือ (ส่วน 정답 ของเวิร์กบุ๊ก) · ผู้เรียนยังไม่ได้เขียนคำตอบ จึงไม่มีข้อที่ดินสอต่างจากเฉลย · เฉลยพิมพ์เขียนรูปเต็ม เช่น 떠날까요 — ในช่องว่างของโจทย์เติมเฉพาะส่วนหน้าก็ได้ เพราะ (으)ㄹ까요 พิมพ์ไว้แล้ว*

**A.** 1) ⓒ 삼계탕 2) ⓐ 태권도 3) ⓓ 한복 4) ⓑ 찜질방

**B.** 1) 떠날까요 2) 상 3) 설명할까요 4) 고민

**C.** 2) 입는 것 3) 만드는 것 *(ก้าน 만들- ตัว ㄹ หลุดก่อน -는: 만들다 → 만드는 것)* 4) 보는 것 / 보는 것 *(ทั้งสองช่องเป็น 보는 것)* 5) 읽는 것 6) 모르는 것

**D.** *(ตัวอย่างตอบ — เลือกกิจกรรมอื่นได้)* 1) 저는 게임을 하는 것보다 운동을 하는 것을 더 좋아해요 2) 제 동생은 음악을 듣는 것보다 노래를 부르는 것을 더 좋아해요 3) 청소를 하는 것보다 요리하는 것이 더 힘들어요 4) 비타민을 먹는 것보다 운동하는 것이 건강에 더 좋아요 5) 명동에서 쇼핑하는 것보다 친구와 같이 얘기하는 것이 더 재미있어요

**E.** 1) 마셔 2) 여행해 3) 불러 *(르 불규칙: 부르다 → 불러)* 4) 들어 *(ㄷ 불규칙: 듣다 → 들어)* 5) 안 타

**F.** *(ตัวอย่างตอบ)* 1) 찾아 2) 가 보세요 3) 안 만들어 봤어요 4) 안 가 봤어요 5) 식당 아르바이트를 해 봤어요

**G.** *(ตัวอย่างตอบ)* 1) 장핑 2) 테니스 치 3) 테니스를 쳐요 *(치다 + 어요 → 쳐요)* 4) 테니스 치 5) 학교 테니스장 6) 테니스를 쳐 보셨어요 7) 테니스를 쳐 보지 않았어요 8) 테니스를 쳐 보세요 9) 좋아요
