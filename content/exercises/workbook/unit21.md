### A. 어휘: <보기>에서 알맞은 단어를 골라 문장을 완성하세요.
*คำสั่ง: เลือกคำศัพท์จาก <보기> มาเติมให้ประโยคสมบูรณ์ (ข้อ 2, 3, 5 ต้องผันเป็นรูปที่ระบุท้ายช่องว่าง)*

> **<보기>:** 여러 가지 (หลายอย่าง) · 그리다 (วาด) · 열다 (เปิด) · 계속 (ต่อเนื่อง) · 넣다 (ใส่)

1. 편의점에 (　　　　) 물건이 많아요. *(ที่ร้านสะดวกซื้อมีของหลายอย่างมาก)*
2. 저는 보통 주말에 그림을 (　　　　)아/어/여요. *(ปกติวันหยุดสุดสัปดาห์ฉันวาดรูป)*
3. 밖에 친구가 왔어요. 그래서 문을 (　　　　)았/었/였어요. *(เพื่อนมาอยู่ข้างนอก ฉันจึงเปิดประตู)*
4. 오늘부터 방학이에요. 저는 내일 고향에 가요. 8월까지 고향에 (　　　　) 있을 거예요. *(ตั้งแต่วันนี้เป็นปิดเทอม พรุ่งนี้ฉันกลับบ้านเกิด จะอยู่บ้านเกิดต่อเนื่องถึงเดือนสิงหาคม)*
5. 지갑을 가방에 (　　　　)았/었/였어요. *(ใส่กระเป๋าสตางค์ลงในกระเป๋า)*

### B. 만 1: <보기>와 같이 문장을 완성하세요.
*คำสั่ง: เติมคำในวงเล็บ + 만 (เฉพาะ/แค่) ให้ประโยคสมบูรณ์ตามตัวอย่าง*

> **<보기>:** 저는 고기를 안 먹어요. 야채만 먹어요. (야채) *(ฉันไม่กินเนื้อ กินแต่ผัก)*

1. 제니 씨는 치마를 입지 않아요. (　　　　) 입어요. (바지) *(คุณเจนนี่ไม่ใส่กระโปรง ใส่แต่กางเกง)*
2. 저는 아침에 밥을 먹지 않아요. (　　　　) 마셔요. (커피) *(ตอนเช้าฉันไม่กินข้าว ดื่มแต่กาแฟ)*
3. 교실에 학생들이 없어요. (　　　　) 계세요. (선생님) *(ในห้องเรียนไม่มีนักเรียน มีแต่ครู)*
4. 주말에는 학교에 가지 않아요. (　　　　) 학교에 가요. (월요일부터 금요일까지) *(สุดสัปดาห์ไม่ไปโรงเรียน ไปแต่ตั้งแต่วันจันทร์ถึงวันศุกร์)*
5. 제 동생은 집에서는 공부를 하지 않아요. (　　　　) 공부해요. (학교에서) *(น้องฉันไม่เรียนที่บ้าน เรียนแต่ที่โรงเรียน)*
