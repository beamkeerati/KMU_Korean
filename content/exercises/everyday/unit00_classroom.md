## 교실 용어 · 교실 한국어 (คำศัพท์และสำนวนในห้องเรียน)

### A. 그림을 보고 단어를 쓰세요.
*คำสั่ง: ดูภาพแล้วเขียนคำศัพท์และสำนวนในห้องเรียนให้ถูกต้อง*

1. 🖼️ ผู้หญิงชี้นิ้วที่ดวงตาทั้งสองข้าง → (　　　　) *(กรุณาดู)*
2. 🖼️ ผู้หญิงเอามือป้องหูตั้งใจฟัง → (　　　　) *(กรุณาฟัง)*
3. 🖼️ ผู้ชายกำลังใช้ปากกาเขียนหนังสือ → (　　　　) *(กรุณาเขียน)*
4. 🖼️ ผู้ชายกำลังก้มหน้าอ่านหนังสือ → (　　　　) *(กรุณาอ่าน)*
5. 🖼️ คุณครูกำลังพูดอธิบายให้นักเรียนฟัง → (　　　　) *(กรุณาพูด)*
6. 🖼️ ครูพูด "합니다..." แล้วนักเรียนพูดตาม "합니다..." → (　　　　) *(กรุณาพูดตาม)*
7. 🖼️ นักเรียนหญิงยกมือถามคำถาม มีบอลลูนข้อความ "질문?" → (　　　　) *(กรุณาถาม / ถามคำถาม)*
8. 🖼️ ครูถาม "누구입니까?" นักเรียนยกมือตอบ "그 사람은..." → (　　　　) *(กรุณาตอบ / ตอบคำถาม)*
9. 🖼️ สมุดโน้ตจดคำศัพท์มากมายที่กำลังท่องจำ → (　　　　) *(กรุณาท่องจำ)*
10. 🖼️ ผู้ชายนั่งดื่มกาแฟพักผ่อนสบายๆ บนเก้าอี้ → (　　　　) *(กรุณาพักผ่อน)*
11. 🖼️ ผู้ชายกำลังหย่อนตัวนั่งลงบนเก้าอี้ → (　　　　) *(กรุณานั่งลง)*
12. 🖼️ ผู้ชายเอามือเท้าคาง ทำหน้าสงสัย/ไม่เข้าใจ มีเครื่องหมาย ? → (　　　　) *(ไม่รู้ / ไม่เข้าใจ)*
13. 🖼️ ผู้ชายมีหลอดไฟปิ๊งขึ้นข้างศีรษะ ยิ้มชี้นิ้วเข้าใจ → (　　　　) *(รู้ / เข้าใจ)*
14. 🖼️ ผู้ชายใส่แว่นชูป้ายสัญลักษณ์วงกลม ⭕ → (　　　　) *(ถูกต้อง)*
15. 🖼️ ผู้ชายใส่แว่นทำหน้าผิดหวังชูป้ายสัญลักษณ์กากบาท ❌ → (　　　　) *(ผิด / ไม่ถูกต้อง)*
16. 🖼️ แอปเปิ้ลสองผลมีเครื่องหมายเท่ากับ (=) คั่นกลาง → (　　　　) *(เหมือนกัน)*
17. 🖼️ แอปเปิ้ลกับกล้วยมีเครื่องหมายไม่เท่ากับ (≠) คั่นกลาง → (　　　　) *(ต่างกัน)*
18. 🖼️ กล่องนมมีแสงประกายรอบกล่อง → (　　　　) *(มี)*
19. 🖼️ มีเส้นประกายแต่ว่างเปล่า ไม่มีสิ่งของใดอยู่ → (　　　　) *(ไม่มี)*
