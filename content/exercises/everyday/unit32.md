### A. 32과 -고² 문장 연습 — ต่อสองประโยคด้วย -고 (문장을 쓰세요)
*คำสั่ง: เชื่อมสองกริยาที่คั่นด้วย / ให้เป็นประโยคเดียวด้วย -고 (ทำอย่างแรกแล้วทำอย่างที่สอง) แล้วเขียนลงบรรทัดใต้ข้อ · -고 ไม่ผันกาลเอง ใส่กาลที่กริยาท้ายประโยคเท่านั้น · ใบฝึกให้กริยารูปพจนานุกรม · ผู้เรียนยังไม่ได้เขียน*

1. 손을 씻다 / 밥을 먹다 *(ล้างมือ / กินข้าว)*

2. 밥을 먹다 / 수업을 듣다 *(กินข้าว / เรียน)*

3. 수업을 듣다 / 친구를 만나다 *(เรียน / เจอเพื่อน)*

4. 친구를 만나다 / 아르바이트를 하러 가다 *(เจอเพื่อน / ไปทำงานพิเศษ)*

5. 아르바이트를 하다 / 저녁을 먹다 *(ทำงานพิเศษ / กินข้าวเย็น)*

6. 숙제를 하다 / 텔레비전을 보다 *(ทำการบ้าน / ดูทีวี)*

7. 텔레비전을 보다 / 샤워를 하다 *(ดูทีวี / อาบน้ำ)*

8. 샤워를 하다 / 잠을 자다 *(อาบน้ำ / นอน)*

### B. 32과 _아/어/여서² — กรอบตัวอย่างกริยาที่ใช้กับ -고 (ไม่มีช่องเติม)
*หน้าตัวอย่าง ไม่มีช่องให้เขียน · กริยากลุ่ม "สวมใส่ · ถือ · ขึ้นพาหนะ" (입다 · 신다 · 쓰다 · 들다 · 타다) ต่อด้วย -고 ไม่ใช้ -아/어서 เพราะสภาพที่สวม ถือ หรือนั่งอยู่ยังคงอยู่ตอนไปต่อ*

| ประโยคในกรอบ | กริยา | แปลไทย |
|:---|:---|:---|
| (옷을) 입고 학교에 가요 | 입다 | ใส่เสื้อผ้าแล้วไปโรงเรียน |
| (신발을/양말을) 신고 밖에 나가요 | 신다 | ใส่รองเท้า/ถุงเท้าแล้วออกไปข้างนอก |
| (안경을/모자를) 쓰고 밖에 나가요 | 쓰다 | ใส่แว่น/สวมหมวกแล้วออกไปข้างนอก |

| (버스를/지하철을) 타고 명동에 가요 | 타다 | นั่งรถเมล์/รถไฟใต้ดินไปมยองดง |

### C. 32과 _아/어/여서² 문장 연습 — ต่อสองประโยคด้วย -아/어/여서 (문장을 쓰세요)
*คำสั่ง: เชื่อมสองส่วนที่คั่นด้วย / ให้เป็นประโยคเดียว ท่อนแรกใช้ -아/어/여서 (ทำอย่างแรกแล้วเอาผลไปใช้ต่อ) ท่อนหลังคงรูปตามที่พิมพ์ไว้ (กาลและท้ายประโยคไม่เปลี่ยน) · ข้อ 6 มีดาว คือข้อยาก · ผู้เรียนยังไม่ได้เขียน*

1. 불고기를 만들다 / 친구와 같이 먹었어요 *(ทำพูลโกกีแล้วกินกับเพื่อน)*

2. 도서관에 가다 / 책을 빌렸어요 *(ไปห้องสมุดแล้วยืมหนังสือ)*

3. 꽃을 사다 / 여자 친구에게 줄 거예요 *(ซื้อดอกไม้แล้วจะให้แฟนสาว)*

4. 시험 사진을 찍다 / 선생님에게 보내세요 *(ถ่ายรูปข้อสอบแล้วส่งให้ครู)*

5. 열심히 공부하다 / 2급에 갈 거예요 *(ตั้งใจเรียนแล้วจะขึ้นระดับ 2 ต่อไป)*

6. \*지난 주말에 산 옷을 입다 / 회사에 갈 거예요 *(ใส่เสื้อผ้าที่ซื้อเมื่อสุดสัปดาห์ที่แล้วไปบริษัท)*

### D. 32과 -고² _아/어/여서² 비교 문장 연습 — ดูภาพแล้วเลือก -고 หรือ -아/어/여서 (문장을 쓰세요)
*คำสั่ง: ดูภาพก่อน → หลัง แล้วต่อกริยาในกรอบด้วย -고 หรือ -아/어/여서 ให้ถูกกับความสัมพันธ์ของสองการกระทำ แล้วเขียนประโยคใต้ข้อ · ผู้เรียนเขียนตัวเชื่อมเหนือกริยาไว้แล้ว (ตัวหนังสือดินสอ) แต่ยังไม่ได้เขียนประโยค*

1. 🖼️ ผู้หญิงยืดแขนบนที่นอน → ผู้หญิงล้างหน้า (กรอบ: 일어나다 / 씻다 · ดินสอ: 서)

2. 🖼️ ผู้หญิงล้างหน้า → ผู้หญิงนั่งกินอาหารเช้าที่โต๊ะ (กรอบ: 씻다 / 아침을 먹다 · ดินสอ: 고)

3. 🖼️ ผู้หญิงปั่นจักรยานพร้อมของที่ซื้อ → ผู้หญิงหั่นเนื้อทำอาหารที่เคาน์เตอร์ (กรอบ: 시장에서 고기를 사다 / 요리하다 · ดินสอ: 서)

4. 🖼️ ผู้หญิงหั่นเนื้อทำอาหาร → ผู้หญิงนั่งกินอาหารที่ทำเสร็จ (กรอบ: 요리하다 / 먹다 · ดินสอ: 해서)

5. 🖼️ คนนั่งยองล้างตัวข้างถังน้ำ → คนคาดผ้าที่หัวนั่งอ่านหนังสือที่โต๊ะ (กรอบ: 씻다 / 공부하다 · ดินสอ: 고)

6. 🖼️ ผู้หญิงนั่งคุยโทรศัพท์ → ผู้หญิงถือเครื่องดูดฝุ่นทำความสะอาด (กรอบ: 친구하고 전화하다 / 청소하다 · ดินสอ: 고)

7. 🖼️ ผู้หญิงสองคนเดินเข้ามาหากัน → ผู้หญิงสองคนยืนคุยกัน (กรอบ: 친구를 만나다 / 이야기하다 · ดินสอ: 서)
