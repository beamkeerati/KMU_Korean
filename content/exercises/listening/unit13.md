## 13과 · 본문 듣기 (ฟังบทสนทนาหลัก บทที่ 13 · 시장에서 과일하고 고기를 사요)
*ชีตฟังของศูนย์ · คำตอบในภาพเป็นดินสอของคุณเอง · เฉลย = ประโยคจากบทสนทนาในตำรา*

### A. 맞아요: O, 틀려요: X (ถูก O / ผิด X)
1. 알렉세이 씨는 매일 시장에 가요. (　　) *({n:อเล็กเซย์}{v:ไป}{n:ตลาด}{a:ทุกวัน})*
2. 알렉세이 씨는 과일을 안 사요. (　　) *({n:อเล็กเซย์}{x:ไม่}{v:ซื้อ}{n:ผลไม้})*
3. 시장에는 과일하고 고기가 있어요. (　　) *(ที่ตลาดมีผลไม้และเนื้อ)*

### B. 듣고 쓰세요 (ฟังแล้วเขียนเติม)
> 간토야: 알렉세이 씨, 1)(　　　　　　) 시장에 가요? *({n:คุณอเล็กเซย์} {v:ไป}{n:ตลาด}{q:เมื่อไหร่})*
>
> 알렉세이: 2)(　　　　　　　　) 가요. *(ไปวันเสาร์ครับ)*
>
> 간토야: 시장에서 무엇을 사요? *(ซื้ออะไรที่ตลาด)*
>
> 알렉세이: 과일 3)(　　　　) 고기를 4)(　　　　　　). *(ซื้อผลไม้กับเนื้อครับ)*
