เว็บฝึกสอบ 복습시험 ② และ 중간시험 · ใช้ได้บน iPad, มือถือ และ PC

ลำดับการทำข้อสอบ

  • หน้าแรก แบ่งตามการสอบ 3 ชุด กดการ์ดชุดที่ต้องการ → เข้าสู่หน้าปกข้อสอบ ซึ่งบอกจำนวนข้อ คะแนน เวลา และกติกา
  • ▶ เริ่มสอบจริง = จำลองห้องสอบ: จับเวลาตามข้อสอบจริง (ดูที่แถบลอยมุมล่างขวา) ซ่อนคำแปลและคำใบ้ ชุดฟังจะเล่นเสียงเองตอนละ 2 รอบแล้วให้เวลาตอบ ชุดพูดครูจะถามทีละข้อ หมดเวลาแล้วระบบส่งคำตอบให้อัตโนมัติ
  • ✎ ฝึกทำ = ไม่จับเวลา เปิดคำแปลได้ กดฟังซ้ำได้ไม่จำกัด เปิดสคริปต์ได้ กด ▶ ถาม ทีละข้อได้
  • ทำเสร็จกด ส่งคำตอบ → เห็นผลสอบ คะแนนรวม คะแนนรายตอน ข้อที่เสียคะแนน และเฉลยทุกข้อ แต่ละข้อเปลี่ยนสีทั้งข้อ: เขียว = ถูก · ส้ม = ครึ่งคะแนน · แดง = ผิด · เทา = รอตรวจ
  • ⚙ ตั้งค่า › รูปแบบหน้า: แบ่งซ้าย-ขวา = คำสั่ง บทอ่าน และเสียงอยู่ซ้าย (ค้างไว้ขณะเลื่อน) ส่วนข้อและช่องตอบอยู่ขวา · ใช้ได้บนจอกว้าง (iPad แนวนอน / PC)
  • ออกกลางคันได้ด้วยปุ่ม พักไว้ก่อน คำตอบและเวลาที่เหลือจะถูกเก็บไว้ กลับมาที่หน้าปกแล้วกด ทำต่อ ได้

การตรวจ

  • ข้อเลือกตอบและเติมคำ ตรวจทันที ถ้าสะกดผิดเล็กน้อยได้ครึ่งคะแนนและบอกตัวที่ผิด
  • 🤖 AI ตรวจอัตโนมัติ (เฉพาะลิงก์ claude.ai): หลังส่งคำตอบ Claude จะตรวจทุกข้อที่พิมพ์ตอบซึ่งไม่ตรงเฉลยตรง ๆ — ข้อเขียนประโยค ข้อเติมคำ และข้อพูด — โดยอ่านบทอ่าน/สคริปต์ โจทย์ และคำตอบตัวอย่าง แล้วให้ ถูก / ครึ่ง / ผิด พร้อมเหตุผลภาษาไทยและประโยคที่แก้แล้ว คะแนนรวมอัปเดตเอง ใช้โควตา Claude ของคุณ ครั้งแรกจะถามขออนุญาต
  • ไม่เห็นด้วยกับ AI หรือเปิดจากไฟล์ในเครื่อง (ไม่มี AI) ให้กด ถูก / ครึ่ง / ผิด ตรวจเองได้ทุกข้อที่พิมพ์ตอบ
  • คำตอบ คะแนน และประวัติเก็บไว้ในเบราว์เซอร์ และซิงก์ข้ามเครื่องผ่านบัญชี claude.ai (ดูสถานะ ☁️ บนแถบด้านบน) ไฟล์ index.html ในเครื่องเก็บแยก ไม่ซิงก์
