## 🔮 เก็งข้อสอบ 매일 시험 23과 — 불고기는 맵지 않은 음식이에요
*คาดว่าสอบวันอังคารที่ 27 ต.ค. 2026 (ยังไม่ยืนยัน · 낭독시험 ⑤ บท 23 คือวันพุธที่ 28) · เก็งจาก 연습지 23과 (3 หน้า ที่แจกวันนี้) + ข้อสอบจริง 22과 (8.5/10) + หนังสือเรียน 23과 (หน้า 236–241) + เวิร์กบุ๊ก 23과 + กระดานครู*

> [!IMPORTANT]
> **คำใบ้จากครู: ข้อสอบรอบนี้เน้น "การผันรูป" (conjugation) — ㅂ 불규칙 และ -(으)ㄴ + คำนาม**
> ทุกชุดจำลองด้านล่างจึงสร้างรอบสองเรื่องนี้ · **นี่คือการเดา ไม่ใช่ข้อสอบจริง** · สถิติ: ใบฝึกที่แจกก่อนสอบมักกลายเป็นส่วน B (ตรงเป๊ะใน 8, 11, 12, 15, 16, 17, 18, 19과) → B ของ 23과 ≈ ตารางในใบฝึกวันนี้

| 뜨겁다 | 뜨거워요 | 뜨거웠어요 | 뜨거운 커피 | ร้อน (ของ) |

- 가까워요 (ㅏ ในราก แต่ยังใช้ 워 — ทุกคำใช้ **워** ยกเว้น 돕다 · 곱다 (고와요))

#### 2.3 -(으)ㄴ + N — คำคุณศัพท์ขยายคำนาม (ข้อ 36)

| ราก | ผล | ตัวอย่าง |
|:---|:---|:---|
| มีตัวสะกด | **-은** | 작은 가방 · 적은 돈 · 많은 사람 · 넓은 교실 · 좁은 방 |
| ไม่มีตัวสะกด | **-ㄴ** (รวมในตัวอักษร) | 큰 교실 · 싼 옷 · 바쁜 생활 · 깨끗한 방 · 예쁜 카페 · 시원한 냉면 · 친절한 사람 |
| ตัวสะกด **ㅂ** (ㅂ 불규칙) | ㅂ ตก + **-운** | 쉬운 문제 · 어려운 시험 · 고마운 사람 · 아름다운 경치 · 매운 음식 · 더운 날씨 |
| **있다 / 없다** (재미있다 · 맛있다 · 멋있다 · 맛없다) | **-는** | 멋있는 사람 · 재미있는 영화 · 맛없는 음식 · 재미없는 책 |
| ในรูปปฏิเสธ -지 않다 | -지 **않은** | 맵지 않은 음식 (ตามชื่อบท) |

- เว้นวรรค: **-(으)ㄴ + เว้นวรรค + คำนาม** (매운 음식 · ไม่ติดกัน)
- ใช้ **어떤** ถามลักษณะ → ตอบ **-(으)ㄴ N**: 어떤 사람을 좋아해요? → 친절한 사람을 좋아해요 · **무슨** ถามชนิด → 무슨 영화 → 코미디 영화
- ต่อหลายคำ: **형①-고 형②-(으)ㄴ N** → 예쁘고 가벼운 가방 · 똑똑하고 착한 친구 (ตัวแรกไม่ใส่ -ㄴ)
- 5 รส: 시다 (เปรี้ยว–레몬) · 맵다 (เผ็ด–김치) · 달다 (หวาน–설탕) · 짜다 (เค็ม–소금) · 쓰다 (ขม–약) → 단 음식 (ㄹ หลุด — บท 25)

#### 2.4 จุดที่คุณเคยพลาดเอง — เช็กก่อนส่ง
- ★ **ㅐ/ㅔ:** วันนี้ในใบฝึกเขียน **메워요** → ต้องเป็น **매워요** (맵다 ㅐ) · ที่เคยเสีย: 네 게 · 젝
- ★ **좋다 vs 좋아하다:** 좋아 하고 ✗ (22과) · คุณศัพท์ใช้ **좋고 / 좋은** · กริยา 좋아하다 ใช้เมื่อมีกรรม (불고기를 좋아해요) · ปฏิเสธ = 안 좋아해요 (ไม่ใช่ 좋아 안 해요)
- ★ **ทิ้ง 하:** 산책고 ✗ → 산책**하고** · 친절하고 · 깨끗하고 · 똑똑하고 (N하다 / 형용사 하다 ต้องเก็บ 하)
- ★ **-는 หลัง 있다/없다:** 멋있는 ✓ · 멋있은 ✗ · 재미있는 · 맛없는
- ★ **큰 (ไม่ใช่ 컨 · 크은):** ㅡ ตกเฉพาะก่อน 아/어 (커요) — -ㄴ ต่อรากที่ไม่มีตัวสะกดตรง ๆ → 큰
- ★ **돕다 → 도와요 (와 ไม่ใช่ 워)** · **입다 · 좁다 · 잡다 ปกติ:** 좁아요 (ไม่ใช่ 좁워요)
- ★ **ㅈ/ㅊ:** 착하다 · 짜다 · 짬뽕 · 친절하다 · 시끄럽다 — ㅈ 2 ขีด ㅊ 3 ขีด
- **ห้ามปนทางการ/ไม่ทางการ:** คำถามเป็น 해요체 → ตอบ 해요체 (22과 ตอบ 달립니다 ทั้งที่คำถามเป็น -요)
- **ลืมเว้นวรรคระหว่าง -(으)ㄴ กับคำนาม:** 매운음식 ✗ → 매운 음식
- ตอบให้ตรงคำถาม: 누가 → ชื่อคน (○○ 씨) · 어떤 → ลักษณะ · 무슨 → ชนิด

### 6. เช็กลิสต์ก่อนเข้าห้องสอบ
- [ ] ㅂ 불규칙: ตัด ㅂ + ใส่ **워** (ยกเว้น 돕다 → **도와요**) · ก่อน -(으)ㄴ → **-운** (매운 · 더운 · 쉬운)
- [ ] ก่อน -지 않다 / -고 / -ㅂ니다 ㅂ **ไม่เปลี่ยน** (맵지 않아요 · 맵고)
- [ ] 입다 · 좁다 · 잡다 = **ปกติ** (입어요 · 좁아요 · 잡아요)
- [ ] -(으)ㄴ: มีตัวสะกด → -은 · ไม่มี → -ㄴ (큰 · 싼 · 바쁜 · 깨끗한) · 있다/없다 → **-는**
- [ ] เว้นวรรคก่อนคำนาม: 매운 음식 · และเก็บ 하 : 친절하고 · 깨끗한
- [ ] 매워요 (ㅐ) ไม่ใช่ 메워요 · 큰 ไม่ใช่ 컨 · 좋고 ไม่ใช่ 좋아 하고
- [ ] ตอบตามคำถาม: 누가 → ชื่อ + 씨예요 · 어떤 → -(으)ㄴ N
- [ ] ท่อง ★★★: 불고기는 맵지 않은 음식이에요. 달아요. · 순두부찌개가 뭐예요? 매운 음식이에요? · 거기에는 맛있는 한식집이 많고 카페도 많아요. · 이 식당 음식이 맛있어요. 그래서 자주 와요.
