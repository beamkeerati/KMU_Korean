# 🔮 매일 시험 เก็งข้อสอบ — 35과

## 🔮 เก็งข้อสอบ 매일 시험 35과 — 운동하는 것을 좋아하세요?
*คาดว่าสอบจันทร์ที่ 16 พ.ย. 2026 · เก็งจากใบฝึก 35과 (แจก 13 พ.ย.) + ตำรา หน้า 344–350 + เวิร์กบุ๊ก หน้า 162–165 + ผลจริง 34과 (8.5) · ยังไม่มีคำใบ้จากครูที่บันทึกไว้ · 35과 อยู่ใน 복습시험 ④ (18 พ.ย.) และ 기말 (20 พ.ย.)*

### 1. รูปแบบที่คาด

- ตั้งแต่ 22과 ข้อสอบ = A 4 ข้อ + B 3–4 ข้อ + C คำบอก 3 ข้อ รวม 10 คะแนน · ลำดับ A/B ไม่คงที่ · 31–32과 เคยเป็นตารางผัน 8 ช่อง
- 34과 จริง (8.5): A ภาพคู่ → บทสนทนา (이)나 / -거나 4 ข้อ · B ปฏิทิน เลือก 자주 · 거의 안 · 전혀 안 3 ข้อ · C คำบอกตัดสั้นจาก 대화 34-1 (주말 잘 보내셨어요 · 집에서 쉬어요) → ส่วน B เปลี่ยนรูปทุกครั้ง แต่คำที่ออกอยู่ในบทเสมอ
- ข้อสอบยกจากใบฝึกที่แจกวันก่อน เวิร์กบุ๊ก และตำรา 연습 เกือบตรงตัว (34과 ข้อ 3–4 = ใบฝึกหน้า 2 ข้อ 2 · 1)
- ใบฝึก 35과 มี 3 หน้า: ตาราง -는 것 12 ช่อง (ผู้เรียนเว้นว่าง) · ตาราง -아/어 보다 12 กริยา × 2 รูป (เติมแล้ว ถูกหมด) · 활동 취미 ไอคอน 6 อัน + คำถาม 6 ข้อ
- คาดมากที่สุด: A ไอคอนงานอดิเรก → -는 것 · B -아/어 봤어요 / 보세요 (รวม 듣다 · 부르다 · 돕다) · C คำบอกจาก 대화 35-1 · สำรอง = ตารางผันแบบ 31–32과
- คะแนนที่หลุดรอบนี้เป็นตัวสะกดและคำช่วย (차 → 자 · 책 → 젝 · 주말에) ไม่ใช่ไวยากรณ์ → §2 ท่องตัวสะกดก่อน

#### 2.3 กฎของบท

- V-는 것 = "การ…": รากกริยา + 는 + 것 ไม่ดูตัวสะกด: 보는 것 · 먹는 것 · 하는 것 · 있는 것 · 없는 것
- ★ รากลงท้าย ㄹ ตัว ㄹ หลุด: 만드는 것 · 사는 것 · 노는 것 (✗ 만들는)
- ★ ㅂ · ㄷ · 르 ไม่เปลี่ยนก่อน -는 เพราะ 는 ขึ้นต้นด้วย ㄴ: 돕는 것 · 듣는 것 · 부르는 것
- 것 เป็นคำนามอาศัย เว้นวรรค แล้วตามด้วย 을/를 · 이/가 · 은/는: 운동하는 것을 좋아해요 · 걷는 것은 건강에 좋아요 · 취미는 영화 보는 것이에요
- ★ กรรมในวลี -는 것 ยังใช้ 을/를: 영화를 보는 것 (✗ 영화가 보는 것 · เคยพลาด 책이 읽는)
- A-는 것보다 B-는 것을 좋아해요 = ชอบ B มากกว่า A (ตัวที่อยู่หน้า 보다 คือตัวที่ชอบน้อยกว่า)
- V-아/어 보다 = "เคย…" (봤어요) และ "ลอง…ดู" (보세요): ㅏ/ㅗ → -아 (가 봤어요) · อื่น ๆ → -어 (먹어 · 입어 · 읽어 · 배워) · 하다 → 해 (여행해 봤어요)
- ★ 불규칙 ก่อน -어 보다: 듣다 → 들어 · 걷다 → 걸어 · 부르다 → 불러 · 돕다 → 도와 (✗ 듣어 · 부르어) · ㄹ-stem ต่อตรง ๆ: 만들어 · 놀아 · 살아 · ㅂ ปกติไม่เปลี่ยน: 입어 (✗ 이워)
- ★ ㅡ-drop: 쓰다 → 써 봤어요 · อย่าทิ้ง 어 ตอนเขียนเอง: 먹어 봤어요 (✗ 먹 봤어요)
- 봤어요 = เคย ≠ 갔어요 = ไปแล้ว · ปฏิเสธ 안 가 봤어요 (✗ 가 안 봤어요) · 한번 가 보세요 = ลองไปสักครั้งนะ
- 에 vs 에서: 제주도에 가 봤어요 (จุดหมาย) · 한강에서 유람선을 타 봤어요 (ที่ทำกิจกรรม)
- N이/가 되고 싶다 = อยากเป็น…: 사진작가가 되고 싶어요 (✗ 사진작가를 되고)
- ★ ตัวสะกดที่เคยเสียคะแนน: ㅊ ต้องมีขีดบน (책 · 차 · 취미 · 춤 · 친구) · ㅐ/ㅔ (세계 · 배우다 · 게임) · สระ ㅡ แทนสระอื่น (✗ 아르바으트 · ✗ 음료스) · ㅆ ใน 봤/갔 ต้องเขียนสองตัว
- ★ คำบอก: เขียนเท่าที่ได้ยิน ห้ามเติม 에 · 을 · 에서 จากความเคยชิน (34과: ✗ 주말에 잘 보내셨어요)

# 정답 (เฉลยข้อสอบจำลอง)

## ชุดที่ 1
**ส่วน A**  
1) 자전거 타는 것을 좋아해요. *(ขี่จักรยาน · 타다 → 타는 · ✗ 자전거가 타는)* 또는 자전거 타는 것이 제 취미예요.  
2) 그림 그리는 것을 좋아해요. *(วาดรูป · 그리다 → 그리는)*  
3) 책 읽는 것을 좋아해요. *(อ่านหนังสือ · ★ 책 = ㅊ + ㅐ ✗ 젝 · ✗ 책이 읽는 · 읽는 [잉는])*  
4) 춤추는 것을 좋아해요. *(เต้น · ★ ㅊ สองตัว)*  

**ส่วน B**  
5) 들어 *(듣다 → 들어 · ㄷ 불규칙 ✗ 듣어)*  
6) 안 불러 봤어요 *(ไม่เคยร้อง · 르 불규칙 → 불러 · 안 อยู่หน้า ✗ 불러 안 봤어요)*  
7) 타 *(타 보세요 · ㅏ + 아 ยุบเป็น 타)*  

**ส่วน C**  
8) 운동하는 것을 좋아하세요 *(대화 35-1 บรรทัดแรก · ★ 운동 · 것을 · 좋아하세요 ㅈ)*

10) 배워 보세요 *(배우다 → 배워 · ★ ㅐ)*

1) 듣는 것 *(ㄷ ไม่เปลี่ยนก่อน 는)*
