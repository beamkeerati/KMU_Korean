### 1. คำถาม 19 ข้อ

ตารางนี้ให้คำถามพร้อมหน้าตำรา และช่องขวาบอกไวยากรณ์ที่ครูอยากได้ยินในคำตอบ · เลข ❶ ❷ คือคำถามย่อยที่พิมพ์ไว้ในตาราง

**1. 무슨 음식(음악, 운동, 색깔, 영화)을/를 좋아해요?**  
*ชอบ…อะไร · 226p · 무슨 + N*  
→ (음식) **저는 팟타이를 좋아해요.**  
🇹🇭 ผมชอบผัดไทย  
→ (음악) **저는 K-pop을 좋아해요.** ✏️  
🇹🇭 ผมชอบเค-ป๊อป  
→ (운동) **저는 축구를 좋아해요.** ✏️  
🇹🇭 ผมชอบฟุตบอล  
→ (색깔) **저는 파란색을 좋아해요.** ✏️  
🇹🇭 ผมชอบสีฟ้า/น้ำเงิน  
→ (영화) **저는 액션 영화를 좋아해요.** ✏️  
🇹🇭 ผมชอบหนังแอ็กชัน

**2. 학생 식당(교실, 기숙사)이/가 어때요?**  
*…เป็นอย่างไร · 228p · V/A + -고 (ข้อ 22)*  
→ (학생 식당) **학생 식당은 맛있고 싸요.**  
🇹🇭 โรงอาหารนักศึกษาอร่อยและถูก  
→ (교실) **교실은 넓고 깨끗해요.**  
🇹🇭 ห้องเรียนกว้างและสะอาด  
→ (기숙사) **기숙사는 조용하고 깨끗해요.**  
🇹🇭 หอพักเงียบและสะอาด

**3. 주말에 뭐 하고 싶어요?**  
*สุดสัปดาห์อยากทำอะไร · 242p · V + -고 싶다 (ข้อ 38)*  
→ **주말에 친구하고 명동에 가고 싶어요. 거기에서 쇼핑하고 싶어요.**  
🇹🇭 สุดสัปดาห์อยากไปเมียงดงกับเพื่อน อยากช้อปปิ้งที่นั่น

**4. 245p 그림**  
*ดูภาพป้ายห้ามในตำราแล้วบอกข้อห้าม · V + -지 마세요 (ข้อ 39)*  
![🖼️ ป้ายห้าม 6 ป้าย](img:tb24-245-panel)  
→ 🖼️ จานอาหาร: **여기에서 먹지 마세요.**  
🇹🇭 ห้ามกินที่นี่  
→ 🖼️ คนกำลังคุย: **이야기하지 마세요.**  
🇹🇭 ห้ามคุยกัน  
→ 🖼️ ฝ่ามือ: **만지지 마세요.**  
🇹🇭 ห้ามจับ  
→ 🖼️ บุหรี่: **담배를 피우지 마세요.**  
🇹🇭 ห้ามสูบบุหรี่  
→ 🖼️ กล้อง: **사진을 찍지 마세요.**  
🇹🇭 ห้ามถ่ายรูป  
→ 🖼️ ป้ายเลือน (ตำราให้ตอบ): **지각하지 마세요.**  
🇹🇭 ห้ามมาสาย

**5. 기숙사가 어때요? / 집이 어때요?**  
*หอพัก/บ้านเป็นอย่างไร · 251p · V/A + -지만 (ข้อ 40)*

🇹🇭 หอพักแคบแต่สะอาด  
→ (집) **집은 작지만 편해요.** ✏️  
🇹🇭 บ้านเล็กแต่สบาย

**6. ❶ 평일하고 주말 중에서 언제 더 바빠요? ❷ 동대문 시장하고 명동 중에서 어디가 더 사람이 많아요?**

→ ❷ **동대문 시장보다 명동이 사람이 더 많아요.** ✏️  
🇹🇭 เมียงดงคนเยอะกว่าตลาดทงแดมุน

**7. ❶ 고향 친구가 왔어요. ❷ 기숙사에 살아요.**  
*ครูพูดประโยคนี้ คุณเดาตอบ · 265p · -겠- (เดา, ข้อ 42)*  
→ ❶ **기분이 좋겠어요.**  
🇹🇭 คงอารมณ์ดีมาก  
→ ❷ **학교에서 가깝겠어요. 편하겠어요.**  
🇹🇭 คงใกล้โรงเรียน คงสะดวกสบาย  
→ ถ้าครูหมายถึงตัวคุณ: **네, 기숙사에 살아요. 학교에서 가까워요.**  
🇹🇭 ใช่ ผมอยู่หอพัก ใกล้โรงเรียน

**8. 271p 연습3 그림 / 지금 저녁 8시입니다. 학교가 어때요?**  
*ภาพโรงเรียนตอนบ่ายเทียบกับตอนค่ำ · A + -아/어/해졌어요 (ข้อ 43)*  
![🖼️ 오후 vs 밤](img:tb27-271-3scene)  
→ 🖼️ ท้องฟ้า: **하늘이 어두워졌어요.**  
🇹🇭 ท้องฟ้ามืดลง  
→ 🖼️ ไม่มีเสียง: **학교가 조용해졌어요.**  
🇹🇭 โรงเรียนเงียบลง  
→ 🖼️ อากาศ: **날씨가 추워졌어요.**  
🇹🇭 อากาศหนาวขึ้น  
→ 🖼️ ผู้คน: **사람이 적어졌어요.**  
🇹🇭 คนน้อยลง  
→ 🖼️ ถังขยะ (ตอนบ่ายขยะล้น ตอนค่ำว่าง): **쓰레기통이 깨끗해졌어요.**  
🇹🇭 ถังขยะสะอาดขึ้น  
→ 🖼️ หน้าต่างอาคารมีไฟ: **학교 건물이 밝아졌어요.**  
🇹🇭 อาคารเรียนสว่างขึ้น

**9. 계절(동물, 색깔, 과일, 운동) 중에서 무슨 ○○을/를 제일 좋아해요?**  
*279p · N + 중에서 + 제일 (ข้อ 45)*  
→ (계절) **계절 중에서 가을을 제일 좋아해요.**  
🇹🇭 ในบรรดาฤดู ชอบฤดูใบไม้ร่วงที่สุด  
→ (동물) **동물 중에서 고양이를 제일 좋아해요.** ✏️  
🇹🇭 ในบรรดาสัตว์ ชอบแมวที่สุด  
→ (색깔) **색깔 중에서 파란색을 제일 좋아해요.** ✏️  
🇹🇭 ในบรรดาสี ชอบสีฟ้า/น้ำเงินที่สุด  
→ (과일) **과일 중에서 수박을 제일 좋아해요.** ✏️  
🇹🇭 ในบรรดาผลไม้ ชอบแตงโมที่สุด  
→ (운동) **운동 중에서 축구를 제일 좋아해요.** ✏️  
🇹🇭 ในบรรดากีฬา ชอบฟุตบอลที่สุด

**10. 무슨 운동(요리, 악기)을/를 할 수 있어요?**  
*281p · V + -(으)ㄹ 수 있다/없다 (ข้อ 46)*

🇹🇭 ผมว่ายน้ำได้

🇹🇭 ผมทำผัดไทยได้  
→ (악기) **저는 기타를 칠 수 있어요. 피아노는 칠 수 없어요.** ✏️  
🇹🇭 ผมเล่นกีตาร์ได้ แต่เล่นเปียโนไม่ได้

**11. ❶ 왜 공포 영화를 안 봐요? ❷ 왜 택시를 탔어요?**  
*289p · V/A + -아/어/해서 (เหตุผล, ข้อ 48)*  
→ ❶ **공포 영화는 무서워서 안 봐요.**  
🇹🇭 หนังสยองขวัญน่ากลัว เลยไม่ดู  
→ ❷ **비가 와서 택시를 탔어요.**  
🇹🇭 ฝนตก เลยนั่งแท็กซี่  
→ ❷ (อีกแบบ) **늦어서 택시를 탔어요.**  
🇹🇭 สาย เลยนั่งแท็กซี่

**12. ❶ 우리 등산을 할까요? ❷ 우리 영화를 볼까요?**

🇹🇭 ได้เลย ฝนตก ดูหนังกันเถอะ

**13. 기숙사에서 학교까지 (학교에서 명동까지) 어떻게 가요?**

### 2. 길 묻기 (지하철)

งานนี้ครูถามว่า **가: ( )에 어떻게 가요?** และ **가: 얼마나 걸려요?** แล้วให้ดูแผนผังตอบเป็นเส้นทาง · ตอบเรียงตามลำดับ: ขึ้นสายอะไร → เปลี่ยนสายที่ไหน → ลงสถานีไหน → ออกทางออกไหน → ใช้เวลาเท่าไร

**เส้นทาง 1 · 길음역 → 충무로역 → 경복궁역 3번 출구 → 국민호텔 (15분 + 10분)**

![🖼️ เส้นทาง 1](img:rv02-15-route1)

> 가: 국민호텔에 어떻게 가요? *(ไปโรงแรมกุกมินยังไง)*
>
> 나: 길음역에서 지하철 4호선을 타세요. *(ขึ้นรถไฟใต้ดินสาย 4 ที่สถานีกิรึม)*
>
> 나: 충무로역에서 3호선으로 갈아타세요. *(เปลี่ยนเป็นสาย 3 ที่สถานีชุงมูโร)*
>
> 나: 경복궁역에서 내려서 3번 출구로 나가세요. *(ลงที่สถานีคยองบกกุง แล้วออกทางออกที่ 3)*
>
> 나: 3번 출구로 나가면 국민호텔이 있어요. *(ถ้าออกทางออกที่ 3 จะเจอโรงแรมกุกมิน)*
>
> 가: 얼마나 걸려요? *(ใช้เวลาเท่าไร)*
>

### 3. 햄버거 가게

ภาพเรียงเป็นลำดับ: สั่ง (불고기버거 세트 หรือ 치킨버거 세트) → กินที่ร้าน (매장 식사) หรือห่อกลับ (포장) → ใบเสร็จ (영수증) ลงถังขยะ → น้ำแข็ง (얼음) ใส่แก้ว · ตอบตามภาพ แล้วใช้ **-(으)ㄹ게요** ตอนสั่งและ **-아/어 주세요** ตอนขอ

![🖼️ ร้านเบอร์เกอร์](img:rv02-15-burger)

**แบบ A · กินที่ร้าน (불고기버거 · ใบเสร็จทิ้ง · ใส่น้ำแข็ง)**

> 가: 어서 오세요. 뭘 드시겠습니까? *(ยินดีต้อนรับ รับอะไรดีคะ)*
>
> 나: 불고기버거 세트 하나 주세요. *(ขอเซ็ตพุลโกกิเบอร์เกอร์หนึ่งที่ครับ)*
>
> 가: 여기에서 드시겠어요? 포장하시겠어요? *(ทานที่นี่หรือห่อกลับคะ)*
>
> 나: 여기에서 먹을게요. *(ทานที่นี่ครับ)*
>
> 가: 영수증 드릴까요? *(รับใบเสร็จไหมคะ)*
>
> 나: 아니요, 영수증은 버려 주세요. *(ไม่ครับ ช่วยทิ้งใบเสร็จให้หน่อย)*
>
> 가: 콜라에 얼음을 넣을까요? *(ใส่น้ำแข็งในโคล่าไหมคะ)*
>
> 나: 네, 얼음을 넣어 주세요. *(ครับ ช่วยใส่น้ำแข็งให้หน่อย)*

**แบบ B · ห่อกลับ (치킨버거 · รับใบเสร็จ · ไม่ใส่น้ำแข็ง)**

> 가: 어서 오세요. 뭘 드시겠습니까? *(รับอะไรดีคะ)*
>
> 나: 치킨버거 세트를 주문할게요. *(ขอสั่งเซ็ตไก่ทอดเบอร์เกอร์ครับ)*
>
> 가: 여기에서 드시겠어요? 포장하시겠어요? *(ทานที่นี่หรือห่อกลับคะ)*
>
> 나: 포장해 주세요. *(ห่อกลับให้หน่อยครับ)*
>
> 가: 영수증 드릴까요? *(รับใบเสร็จไหมคะ)*
>
> 나: 네, 영수증 주세요. *(ครับ ขอใบเสร็จด้วย)*
>
> 가: 콜라에 얼음을 넣을까요? *(ใส่น้ำแข็งในโคล่าไหมคะ)*
>
> 나: 아니요, 얼음은 넣지 마세요. *(ไม่ครับ อย่าใส่น้ำแข็ง)*

| ตอบตามภาพ | ประโยคที่ใช้ได้ |
|:---|:---|
| สั่ง | 불고기버거 세트 주세요. · 치킨버거 세트를 주문할게요. |
| กินที่ร้าน | 여기에서 먹을게요. |
| ห่อกลับ | 포장해 주세요. |
| ใบเสร็จ (ภาพ = ลงถัง) | 영수증은 버려 주세요. · ถ้าอยากได้: 영수증 주세요. |
| น้ำแข็ง (ภาพ = ใส่แก้ว) | 얼음을 넣어 주세요. · ถ้าไม่เอา: 얼음은 넣지 마세요. |

### 4. 좋아하는 계절 소개

กรอบนี้ถามเจ็ดข้อเป็น 합니다체 ที่ครูหรือเพื่อนถาม และเว้นช่อง ( ) ไว้ให้ใส่ฤดูของคุณ · คำตอบต้องเป็น 합니다체 ด้วย (-ㅂ니다/습니다 · -입니다) · ตัวอย่างนี้ใช้ฤดู 가을

**คำถามที่พิมพ์ไว้**

1. OO 씨가 좋아하는 계절은 무슨 계절입니까? *(ฤดูที่คุณ OO ชอบคือฤดูอะไร)*
2. 왜 ( )을 좋아합니까? *(ทำไมชอบ…)*
3. ( )은 몇 월부터 몇 월까지입니까? *(… คือตั้งแต่เดือนไหนถึงเดือนไหน)*
4. ( )에는 날씨가 어떻습니까? *(ช่วง… อากาศเป็นอย่างไร)*
5. ( )에 무엇을 자주 합니까? *(ช่วง… ทำอะไรบ่อย ๆ)*
6. ( )에 무슨 음식을 자주 먹습니까? *(ช่วง… กินอาหารอะไรบ่อย ๆ)*
7. ( )에 어디에 자주 갑니까? *(ช่วง… ไปที่ไหนบ่อย ๆ)*

**บทพูดเต็ม (ตอบทีละข้อตามลำดับ)**

**1. 제가 좋아하는 계절은 가을입니다.**  
🇹🇭 ฤดูที่ผมชอบคือฤดูใบไม้ร่วง  
**2. 하늘이 맑고 날씨가 시원해서 가을을 좋아합니다.**  
🇹🇭 ผมชอบฤดูใบไม้ร่วงเพราะท้องฟ้าแจ่มใสและอากาศเย็นสบาย  
**3. 가을은 구월부터 십일월까지입니다.**  
🇹🇭 ฤดูใบไม้ร่วงตั้งแต่เดือนกันยายนถึงเดือนพฤศจิกายน  
**4. 가을에는 날씨가 시원합니다. 그리고 비가 많이 오지 않습니다.**  
🇹🇭 ช่วงใบไม้ร่วงอากาศเย็นสบาย และฝนไม่ตกมาก  
**5. 가을에는 친구하고 등산을 자주 합니다.**  
🇹🇭 ช่วงใบไม้ร่วงผมปีนเขากับเพื่อนบ่อย ๆ  
**6. 가을에는 불고기를 자주 먹습니다.**  
🇹🇭 ช่วงใบไม้ร่วงผมกินพุลโกกิบ่อย ๆ  
**7. 가을에는 공원에 자주 갑니다. 거기에서 사진을 찍습니다.**  
🇹🇭 ช่วงใบไม้ร่วงผมไปสวนสาธารณะบ่อย ๆ และถ่ายรูปที่นั่น  
**8. 저는 한국의 가을이 정말 좋습니다.**  
🇹🇭 ผมชอบฤดูใบไม้ร่วงของเกาหลีมากจริง ๆ

ถ้าเลือกฤดูอื่น ใช้ตารางนี้แทนข้อ 2–7 (เดือนเกาหลีไม่ตรงกับไทย)

| ฤดู | เดือน | อากาศ | ทำบ่อย ๆ | กินบ่อย ๆ | ไปบ่อย ๆ |
|:---|:---|:---|:---|:---|:---|
| 봄 | 삼월~오월 | 따뜻합니다 | 사진을 찍습니다 | 비빔밥을 먹습니다 | 공원에 갑니다 |
| 여름 | 유월~팔월 | 덥고 비가 많이 옵니다 | 수영을 합니다 | 팥빙수를 먹습니다 | 바다에 갑니다 |
| 겨울 | 십이월~이월 | 춥고 눈이 옵니다 | 영화를 봅니다 | 김치찌개를 먹습니다 | 명동에 갑니다 |

### 5. 취미 소개

กรอบนี้ถามหกข้อเป็น 해요체 ทุกข้อ ครูจะเลือกหน่วยเวลาใน (하루/일주일/한 달/일 년) ข้อ 3 · ตัวอย่างใช้งานอดิเรก 운동 ตามที่คุณเคยตอบ 취미가 뭐예요?

**คำถามที่พิมพ์ไว้**

1. 취미가 뭐예요? *(งานอดิเรกคืออะไร)*
2. 그것을 왜 좋아해요? *(ทำไมถึงชอบสิ่งนั้น)*
3. (하루/일주일/한 달/일 년)에 몇 번쯤 해요? *(…ทำกี่ครั้งโดยประมาณ)*
4. 보통 어디에서 -아/어요? *(ปกติทำที่ไหน)*
5. 보통 누구하고 -아/어요? *(ปกติทำกับใคร)*
6. 그 취미를 하면 어떻게 달라져요? *(ถ้าทำงานอดิเรกนั้นแล้วจะเปลี่ยนไปอย่างไร)*

**บทพูดเต็ม (ตอบทีละข้อตามลำดับ)**

**1. 제 취미는 운동이에요.**  
🇹🇭 งานอดิเรกของผมคือออกกำลังกาย  
**2. 운동은 재미있고 건강에 좋아서 좋아해요.**  
🇹🇭 ผมชอบเพราะสนุกและดีต่อสุขภาพ  
**3. 일주일에 세 번쯤 해요.**  
🇹🇭 ทำสัปดาห์ละราว 3 ครั้ง  
**4. 보통 학교 운동장에서 운동해요.**  
🇹🇭 ปกติออกกำลังกายที่สนามของโรงเรียน  
**5. 보통 친구하고 같이 해요.**  
🇹🇭 ปกติทำกับเพื่อน  
**6. 운동을 하면 기분이 좋아져요.**  
🇹🇭 ถ้าออกกำลังกายแล้ว อารมณ์ดีขึ้น  
**7. 그리고 건강해져요.**  
🇹🇭 แล้วก็แข็งแรงขึ้นด้วย  
**8. 계속 열심히 운동할 거예요.**  
🇹🇭 ผมจะขยันออกกำลังกายต่อไปเรื่อย ๆ

หน่วยเวลาข้อ 3 ที่ครูอาจเลือก:

| หน่วย | ตอบ |
|:---|:---|
| 하루 | 하루에 한 번 해요. |
| 일주일 | 일주일에 세 번쯤 해요. |
| 한 달 | 한 달에 열 번쯤 해요. |
| 일 년 | 일 년에 두 번쯤 해요. |

ถ้างานอดิเรกเป็นกริยา ใช้ -는 것 (ข้อ 59): 제 취미는 사진을 찍는 거예요. *(งานอดิเรกคือการถ่ายรูป)*

### 6. 한국인의 식사 예절

หน้า 16 ของใบทบทวน (หน้าที่เพิ่งได้ครบ 19 พ.ย.) เป็นมารยาทบนโต๊ะอาหารของคนเกาหลี ครูพูดบรรทัด 가 แล้วคุณตอบบรรทัด 나 · คำตอบสองคู่แรกและคู่สุดท้ายเป็นสำนวนตายตัว ต้องพูดได้ทันทีโดยไม่ต้องคิด ส่วนสองคู่กลางเติมเรื่องของตัวเอง

> 가: 많이 드세요. *(ทานเยอะ ๆ นะ — เจ้าภาพ/ผู้ใหญ่พูดก่อนเริ่มกิน)*
>
> 나: **잘 먹겠습니다.** *(จะทานให้อร่อยนะครับ — พูดก่อนเริ่มกิน)*
>
> 가: 무슨 음식을 자주 먹어요? *(ทานอาหารอะไรบ่อย)*
>
> 나: **김치찌개를 자주 먹어요.** ✏️ *(ทานกิมจิจิเกบ่อย)*
>
> 가: 얼마나 자주 먹어요? *(ทานบ่อยแค่ไหน)*
>
> 나: **일주일에 세 번 먹어요.** ✏️ *(ทานสัปดาห์ละสามครั้ง)*
>
> 가: 다 먹었어요? *(ทานหมดแล้วเหรอ)*
>
> 나: **잘 먹었습니다.** *(ขอบคุณสำหรับอาหารครับ — พูดหลังกินเสร็จ)*

ช่องว่างสองช่องในใบของครูคือ ( )을/를 자주 먹어요 และ ( )에 ( )번 먹어요 · ช่องแรกใส่ชื่ออาหาร เลือก 을/를 ตามตัวสะกดท้าย ช่องหลังใส่ช่วงเวลา + จำนวนครั้ง

| ช่อง | ตัวอย่าง | ไทย |
|:---|:---|:---|
| ( )을/를 | **비빔밥을** · **김치찌개를** · **라면을** · **불고기를** | ตัวสะกดท้าย → 을 · สระท้าย → 를 |
| ( )에 ( )번 | **하루에 한 번** · **일주일에 두 번** · **한 달에 세 번** | วันละครั้ง · สัปดาห์ละสองครั้ง · เดือนละสามครั้ง |

- จำนวนครั้งใช้ตัวเลขเกาหลีแท้: **한 번 · 두 번 · 세 번 · 네 번** (✗ 일 번 · 이 번)
- **드세요** = กิน แบบยกย่อง (먹다 → 드시다) ห้ามตอบกลับด้วย 드세요 ให้ใช้ 먹겠습니다 / 먹었습니다 กับตัวเอง
- **잘 먹겠습니다** (ก่อนกิน · -겠-) กับ **잘 먹었습니다** (หลังกิน · -었-) สลับกันไม่ได้

### 7. จุดที่ต้องระวัง

1. **걸려요** ไม่ใช่ ✗ 거려요 — 십 분쯤 **걸려요** (ข้อ 13 · เส้นทางรถไฟ)
2. **-아/어서 ไม่ใส่กาล** ✗ 왔어서 → 와서 · ถ้าประโยคหลังเป็นชวน/สั่ง (ข้อ 12 ...봐요) ต้องใช้ **-(으)니까** ไม่ใช่ -아/어서
3. **보다 = คำหน้าแพ้** — 주말보다 평일이 더 바빠요 (평일 ชนะ) · ห้ามใส่ 이 ที่คำหน้า 보다
4. **คำขยายนาม:** 작은/예쁜 ✗ 작는/예쁘는 · แต่ 재미있는 ถูก (있다/없다 ใช้ -는) · 어제 **만난** · 내일 **볼**
5. **กรรมใช้ 을/를 แม้อยู่ในวลีขยาย** ✗ 책이 읽는 → 책을 읽는 · 시계나 가방**을** (ไม่ใช่ ✗ 가방이) ข้อ 15
6. **ㄷ불규칙:** 듣다 → 들어야 해요 ข้อ 18 · อนาคตต้องมี 을 → 들을 거예요 · 걸을 거예요
