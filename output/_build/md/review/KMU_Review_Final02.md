## 불규칙 정리 (สรุปกริยา/คุณศัพท์ไม่ปกติ 5 กลุ่ม · ใบ 「국민한국어1 불규칙 정리」 หน้า 1–7)

### ❶ '으' 탈락 · เฉลยตาราง

| | -(스)ㅂ니다 | -고 | -(으)면 | -아/어/여요 | -았/었/였어요 |
|---|---|---|---|---|---|
| **쓰다** | 씁니다 | 쓰고 | 쓰면 | 써요 | 썼어요 |
| **크다** | 큽니다 | 크고 | 크면 | 커요 | 컸어요 |
| **예쁘다** | 예쁩니다 | 예쁘고 | 예쁘면 | 예뻐요 | 예뻤어요 |
| **바쁘다** | 바쁩니다 | 바쁘고 | 바쁘면 | 바빠요 | 바빴어요 |
| **고프다** | 고픕니다 | 고프고 | 고프면 | 고파요 | 고팠어요 |
| **나쁘다** | 나쁩니다 | 나쁘고 | 나쁘면 | 나빠요 | 나빴어요 |

- **쓰다** — ㅡ ตก + 어: 써요 · 썼어요 (พยางค์เดียว ไม่มีสระหน้า ใช้ 어) · ก่อน ㅂ/ㄱ/ㅁ ไม่ตัด ㅡ
- **크다** — ㅡ ตก + 어: 커요 · 컸어요 (ㅋ + 어 = 커)
- **예쁘다** — สระก่อนหน้าคือ ㅖ (ไม่ใช่ ㅏ/ㅗ) ใช้ 어: 예뻐요 · 예뻤어요 (ผิดบ่อย ✗ 여뻐요)
- **바쁘다** — สระก่อนหน้า ㅏ ใช้ 아: 바빠요 · 바빴어요
- **고프다** — สระก่อนหน้า ㅗ ใช้ 아: 고파요 · 고팠어요
- **나쁘다** — สระก่อนหน้า ㅏ ใช้ 아: 나빠요 · 나빴어요

**❶ ประโยค.**
- **1)** 꺼 주세요 *(ㅡ ตก + 어 = 꺼 (พยางค์เดียวใช้ 어) แล้วต่อ 주세요 (✗ 끄어 주세요))*
- **2)** 바빠서 *(바쁘다 ตัด ㅡ ใช้ 아 (สระหน้าคือ ㅏ) → 바빠 + 서 (✗ 바쁘어서))*
- **3)** 커요 *(크 → ㅋ + 어 = 커요 (✗ 크어요))*
- **4)** 고프니까 *(ต่อ -(으)니까 ไม่ใช่ 아/어 จึงไม่ตัด ㅡ · รากลงท้ายสระ ใช้ 니까 → 고프니까)*
- **5)** 고프지 않아요 *(-지 않아요 ต่อที่รากตรง ๆ ไม่ตัด ㅡ (ตัดเฉพาะก่อน 아/어))*
- **6)** 예쁘고 *(-고 ต่อที่รากตรง ๆ → 예쁘고 (ไม่ตัด ㅡ · ✗ 여쁘고))*

### ❷ 'ㅂ' 불규칙 · เฉลยตาราง

| | -(스)ㅂ니다 | -고 | -아/어/여요 | -(으)면 | -(으)ㄴ/는 (현재) |
|---|---|---|---|---|---|
| **쉽다** | 쉽습니다 | 쉽고 | 쉬워요 | 쉬우면 | 쉬운 |
| **어렵다** | 어렵습니다 | 어렵고 | 어려워요 | 어려우면 | 어려운 |
| **맵다** | 맵습니다 | 맵고 | 매워요 | 매우면 | 매운 |
| **덥다** | 덥습니다 | 덥고 | 더워요 | 더우면 | 더운 |
| **춥다** | 춥습니다 | 춥고 | 추워요 | 추우면 | 추운 |
| **무겁다** | 무겁습니다 | 무겁고 | 무거워요 | 무거우면 | 무거운 |
| **돕다** | 돕습니다 | 돕고 | 도와요 | 도우면 | 돕는 |

- **쉽다** — ก่อนสระ ㅂ → 우 + 어 = 워 · ก่อนพยัญชนะ ㅂ คงเดิม · คุณศัพท์ ใช้ -(으)ㄴ → 쉬운
- **어렵다** — ㅂ → 우: 어려워요 · 어려우면 · 어려운 (✗ 어려와요)
- **맵다** — ㅂ → 우: 매워요 · 매우면 · 매운 (ผิดบ่อย ✗ 메워요)
- **덥다** — ㅂ → 우: 더워요 · 더우면 · 더운
- **춥다** — ㅂ → 우: 추워요 · 추우면 · 추운
- **무겁다** — ㅂ → 우: 무거워요 · 무거우면 · 무거운
- **돕다** — พิเศษ: ㅂ → 오 + 아 = 와 (도와요) แต่ก่อนสระ 으 ใช้ 우 (도우면) · เป็นกริยา ใช้ -는 → 돕는

*※ 규칙 (ปกติ — ㅂ ไม่เปลี่ยน)*

| | -(스)ㅂ니다 | -고 | -아/어/여요 | -(으)면 | -(으)ㄴ/는 (현재) |
|---|---|---|---|---|---|
| **입다** | 입습니다 | 입고 | 입어요 | 입으면 | 입는 |
| **잡다** | 잡습니다 | 잡고 | 잡아요 | 잡으면 | 잡는 |
| **좁다** | 좁습니다 | 좁고 | 좁아요 | 좁으면 | 좁은 |

- **입다** — ㅂ ปกติ ไม่เปลี่ยน: 입어요 · 입으면 (✗ 이워요) · กริยา → 입는
- **잡다** — ㅂ ปกติ: 잡아요 · 잡으면 (✗ 자바요) · กริยา → 잡는
- **좁다** — ㅂ ปกติ: 좁아요 · 좁으면 (✗ 조와요) · คุณศัพท์ → 좁은

**❷ ประโยค.**
- **1)** 가벼워요 *(ㅂ ไม่ปกติ: 가볍 → 가벼우 + 어요 = 가벼워요 (✗ 가벼와요))*
- **2)** 추우니까 *(ㅂ → 우 + 니까 (สระ 으 ของ -(으)니까) = 추우니까 (✗ 춥으니까))*
- **3)** 좁아서 *(좁다 เป็น ㅂ ปกติ (ข้อยกเว้น) ไม่เปลี่ยนเป็น 우 → 좁아서 (✗ 조워서))*
- **4)** 맵지만 *(ก่อนพยัญชนะ (지) ㅂ ไม่เปลี่ยน → 맵지만 (✗ 매우지만))*
- **5)** 쉽고 *(ก่อนพยัญชนะ ㄱ ㅂ ไม่เปลี่ยน → 쉽고)*
- **6)** 입으니까 *(입다 เป็น ㅂ ปกติ ใส่ 으 ตามธรรมดา → 입으니까 (✗ 이우니까))*

### ❸ 'ㄹ' 탈락 · เฉลยตาราง

| | -아/어/여요 | -(으)러 | -(스)ㅂ니다 | -(으)세요 | -(으)니까 | -(으)ㄴ/는 (현재) |
|---|---|---|---|---|---|---|
| **살다** | 살아요 | 살러 | 삽니다 | 사세요 | 사니까 | 사는 |
| **만들다** | 만들어요 | 만들러 | 만듭니다 | 만드세요 | 만드니까 | 만드는 |
| **열다** | 열어요 | 열러 | 엽니다 | 여세요 | 여니까 | 여는 |
| **놀다** | 놀아요 | 놀러 | 놉니다 | 노세요 | 노니까 | 노는 |
| **멀다** | 멀어요 | X | 멉니다 | X | 머니까 | 먼 |
| **달다** | 달아요 | X | 답니다 | X | 다니까 | 단 |

- **살다** — ㄹ ตกก่อน ㅂ/ㅅ/ㄴ: 삽니다 · 사세요 · 사니까 · 사는 · ก่อนสระ/러 ไม่ตก: 살아요 · 살러
- **만들다** — ㄹ ตก: 만듭니다 · 만드세요 · 만드니까 · 만드는 (✗ 만들는) · 만들어요 ไม่ตก
- **열다** — ㄹ ตก: 엽니다 · 여세요 · 여니까 · 여는 · 열어요 · 열러 ไม่ตก
- **놀다** — ㄹ ตก: 놉니다 · 노세요 · 노니까 · 노는 · 놀아요 · 놀러 ไม่ตก
- **멀다** — คุณศัพท์ ใช้ -러/-(으)세요 ไม่ได้ (X) · ㄹ ตก: 멉니다 · 머니까 · 먼 (คุณศัพท์ใช้ -(으)ㄴ)
- **달다** — คุณศัพท์ (หวาน) ใช้ -러/-(으)세요 ไม่ได้ (X) · ㄹ ตก: 답니다 · 다니까 · 단 (ไม่ใช่ 달은 = ดวงจันทร์ + 은)

**❸ ประโยค.**
- **1)** 부니까 *(ㄹ ตกหน้า ㄴ: 불 + 니까 = 부니까 (✗ 불으니까 · ✗ 불니까))*
- **2)** 사는 *(ㄹ ตกหน้า ㄴ ของ 는: 살 + 는 = 사는 (✗ 살는))*
- **3)** 팝니다 *(ㄹ ตกหน้า ㅂ: 팔 + ㅂ니다 = 팝니다 (✗ 팔습니다))*
- **4)** 드세요 *(ㄹ ตกหน้า ㅅ: 들 + 세요 = 드세요 (✗ 들으세요 ซึ่งเป็น 듣다 = ฟัง))*
- **5)** 단 *(คุณศัพท์ + -(으)ㄴ · ㄹ ตกหน้า ㄴ: 달 + ㄴ = 단 (ไม่ใช่ ✗ 달은 = ดวงจันทร์))*
- **6)** 힘들지만 *(ก่อน 지 (พยัญชนะ ㅈ) ㄹ ไม่ตก → 힘들지만)*
- **7)** 깁니다 *(ㄹ ตกหน้า ㅂ: 길 + ㅂ니다 = 깁니다)*
- **8)** 놀까요? *(-(으)ㄹ까요? ต่อรากลงท้าย ㄹ ได้ตรง ๆ ไม่เติม ㄹ ซ้ำ → 놀까요? (ไม่ใช่ ✗ 놀을까요))*

### ❹ 'ㄷ' 불규칙 · เฉลยตาราง

| | -(스)ㅂ니다 | -고 | -아/어/여요 | -았/었/였어요 | -(으)세요 |
|---|---|---|---|---|---|
| **듣다** | 듣습니다 | 듣고 | 들어요 | 들었어요 | 들으세요 |
| **묻다** | 묻습니다 | 묻고 | 물어요 | 물었어요 | 물으세요 |
| **걷다** | 걷습니다 | 걷고 | 걸어요 | 걸었어요 | 걸으세요 |

- **듣다** — ก่อนสระ ㄷ → ㄹ: 들어요 · 들었어요 · 들으세요 · ก่อนพยัญชนะ คงเดิม: 듣고 · 듣습니다
- **묻다** — ถาม: ㄷ → ㄹ ก่อนสระ: 물어요 · 물었어요 · 물으세요 · ก่อนพยัญชนะ 묻고 · 묻습니다
- **걷다** — ㄷ → ㄹ ก่อนสระ: 걸어요 · 걸었어요 · 걸으세요 · ก่อนพยัญชนะ 걷고 · 걷습니다

*※ 규칙 (ปกติ — ㄷ ไม่เปลี่ยน)*

| | -(스)ㅂ니다 | -고 | -아/어/여요 | -았/었/였어요 | -(으)세요 |
|---|---|---|---|---|---|
| **닫다** | 닫습니다 | 닫고 | 닫아요 | 닫았어요 | 닫으세요 |
| **받다** | 받습니다 | 받고 | 받아요 | 받았어요 | 받으세요 |

- **닫다** — ㄷ ปกติ ไม่เปลี่ยน: 닫아요 (✗ 달아요) · 닫으세요 (✗ 달으세요)
- **받다** — ㄷ ปกติ ไม่เปลี่ยน: 받아요 (✗ 발아요) · 받으세요

**❹ ประโยค.**
- **1)** 물어 볼게요 (물어볼게요) *(묻다 → ㄷ เป็น ㄹ ก่อน 어 = 물어 + 보다 + -(으)ㄹ게요 → 물어 볼게요 (✗ 묻어 볼게요))*
- **2)** 들으세요 *(듣 + (으)세요 → ก่อนสระ 으 ㄷ เป็น ㄹ แล้วยังต้องมี 으 = 들으세요 (✗ 들세요))*
- **3)** 닫아요 *(닫다 เป็น ㄷ ปกติ (กับดัก) ไม่เปลี่ยนเป็น ㄹ → 닫아요 (✗ 달아요))*

### ❺ '르' 불규칙 · เฉลยตาราง

| | -(스)ㅂ니다 | -(으)면 | -아/어/여요 | -았/었/였어요 |
|---|---|---|---|---|
| **자르다** | 자릅니다 | 자르면 | 잘라요 | 잘랐어요 |
| **부르다** | 부릅니다 | 부르면 | 불러요 | 불렀어요 |
| **모르다** | 모릅니다 | 모르면 | 몰라요 | 몰랐어요 |
| **다르다** | 다릅니다 | 다르면 | 달라요 | 달랐어요 |
| **빠르다** | 빠릅니다 | 빠르면 | 빨라요 | 빨랐어요 |

- **자르다** — ก่อน 아/어: ㅡ ตก + ㄹ เพิ่ม → 잘 + 라요 (สระ ㅏ ใช้ 아) · ก่อนพยัญชนะ/ 으면 คงเดิม: 자릅니다 · 자르면
- **부르다** — 부르 → 불 + 러요 (สระ ㅜ ใช้ 어) · 부릅니다 · 부르면 คงเดิม (✗ 불라요)
- **모르다** — 모르 → 몰 + 라요 (สระ ㅗ ใช้ 아) · 모릅니다 · 모르면 คงเดิม
- **다르다** — 다르 → 달 + 라요 (สระ ㅏ ใช้ 아) · 다릅니다 · 다르면 คงเดิม
- **빠르다** — 빠르 → 빨 + 라요 (สระ ㅏ ใช้ 아) · 빠릅니다 · 빠르면 คงเดิม (ผิดบ่อย ✗ 바르다)

**❺ ประโยค.**
- **1)** 빨라요 *(르 ไม่ปกติ: 빠르 → 빨 + 라요 = 빨라요 (✗ 빠르어요 · ✗ 빨러요))*
- **2)** 달라요 *(르 ไม่ปกติ: 다르 → 달 + 라요 = 달라요 (ตัวอย่างในกรอบกฎของใบ))*
- **3)** 불러서 *(르 ไม่ปกติ: 부르 → 불 + 러서 = 불러서 (สระ ㅜ ใช้ 어 · ✗ 불라서))*
- **4)** 자르니까 *(ต่อ -(으)니까 ไม่ใช่ 아/어 จึงไม่เป็น 르 ไม่ปกติ → 자르니까 (✗ 잘르니까))*
