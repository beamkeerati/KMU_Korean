⚠ 아니요 ≠ 아니에요 · 아니요, 지갑이 아니에요 ✓
아니요 = ไม่ (คำตอบ) · 아니에요 = ไม่ใช่ (กริยา)
제 · 이게 · 뭐
คำย่อที่ใช้พูด
제 = 저의 · 제 사전 · 제 지갑
ของฉัน (저 + 의 → 제) วางหน้านาม
이게 · 그게 · 저게 = 이것이 · 그것이 · 저것이
รูปย่อของ นี่ · นั่น · โน่น (ใช้เป็นประธาน)
뭐 = 무엇 · 이게 뭐예요? → 지갑이에요
อะไร (ภาษาพูด) · 뭐 ไม่มีตัวสะกด จึงตามด้วย 예요
⚠ 무엇이에요 ✓ · 뭐예요 ✓ · 무엇예요 ✗ · 뭐이에요 ✗
무엇 มีตัวสะกด → 이에요 · 뭐 ไม่มี → 예요
