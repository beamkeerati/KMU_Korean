문법
ไวยากรณ์
-(스)ㅂ니다 / -(스)ㅂ니까?
ท้ายประโยคแบบทางการ
받침 ✗ → -ㅂ니다 · ○ → -습니다: 갑니다 · 마십니다 · 읽습니다
ไม่มีตัวสะกด + ㅂ니다 · มีตัวสะกด + 습니다
N입니다/입니까? · N이/가 아닙니다 · V-지 않습니다
เป็น · ไม่ใช่ · ไม่ (รากศัพท์ + 지 않습니다): 학생입니다
한국어를 배우십니까? → 네, 한국어를 배웁니다
ถามด้วย ㅂ니까 ตอบด้วย ㅂ니다 (ตอบไม่ใส่ 시 กับตัวเอง)
ㄹ 받침 어간: ㄹ 탈락 + ㅂ니다: 살다→삽니다 · 만들다→만듭니다
ตัด ㄹ ก่อนเติม ㅂ (เสริมจากไกด์ ไม่อยู่ในตำรา)
⚠ 마시다→맙니다 ✗ · 입니다? ✗ → 입니까?
ห้ามตัดรากศัพท์ · คำถามต้องจบ ㅂ니까 (ดูเครื่องหมาย ?)
-(으)십니다 / -(으)십니까?
ทางการ + ยกย่อง (시 + ㅂ니다)
받침 ✗ → -십니다: 가십니다 · 가르치십니다 · 친절하십니다
รากศัพท์ไม่มีตัวสะกด + 십니다
받침 ○ → -으십니다: 읽으십니다 · 받으십니다 · 씻으십니다
รากศัพท์มีตัวสะกด + 으십니다 · ห้ามลืม 으
자다→주무십니다 · 먹다→드십니다 · 있다→계십니다 · 없다→안 계십니다
คำยกย่องพิเศษ ต่อ 십니다 ได้เลย
N이다 → N(이)십니다: 선생님이십니다
คำนามมีตัวสะกด + 이십니다 (매일시험 B8)
⚠ 받십니다 ✗ → 받으십니다 · 합니까 → 하십니까
ลืม 으 (ผิด 2 ครั้ง) · ต้นฉบับมี 시 ต้องคงไว้
-겠-
ตั้งใจจะ… (ความตั้งใจของผู้พูด)
어간 + -겠습니다 (받침 ○/✗ 같음): 마시겠습니다 · 먹겠습니다
ต่อท้ายรากศัพท์ ไม่เปลี่ยนตามตัวสะกด
부정 -지 않겠습니다: 오지 않겠습니다 · 보지 않겠습니다
จะไม่… (รากศัพท์ + 지 않겠습니다)
언제 오겠습니까? → 내일 다시 오겠습니다
จะมาเมื่อไร → พรุ่งนี้จะมาอีก (ถามความตั้งใจผู้ฟัง)
⚠ 주어 = 나 (3인칭 ✗) · 시 + 겠: 드시겠습니까?
ใช้กับตัวเอง/ถามผู้ฟัง · ใส่ 시 ก่อน 겠 · ใช้กับกริยา
