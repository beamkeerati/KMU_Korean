안 + 동사·형용사 (안 가요 · 안 마셔요 · 안 좋아요)
วาง 안 ไว้หน้ากริยา/คุณศัพท์ (ภาษาพูด)
N하다 → N + 안 해요 (공부 안 해요 · 운동 안 해요)
กริยา 하다 แทรก 안 ระหว่างคำนามกับ 해요
N을/를 + 안 + V (커피를 안 마셔요 · 선생님을 안 만나요)
안 อยู่ติดหน้ากริยา หลังคำที่มี 을/를
시장에 가요? → 아니요, 시장에 안 가요
ตอบ: 아니요 แล้วพูดประโยคเดิมใส่ 안 หน้ากริยา
⚠ 안 아르바이트 해요 ✗ · 안 운동해요 ✗ → N 안 해요
안 ต้องอยู่หน้า 해요 · 좋아하다 คำเดียว → 안 좋아해요
N에서 + 동사
ที่… (สถานที่ทำกิจกรรม)
장소 + 에서 + 동사 → 집에서 쉬어요 · 학교에서 선생님을 만나요
สถานที่ที่ทำกิจกรรม ติด 에서 แล้วตามด้วยกริยา
N은/는 + 장소에서 + N을/를 + V → 저는 교실에서 공부를 해요
ลำดับ: ประธาน · ที่ · กรรม · กริยา
어디에서 옷을 사요? → 백화점에서 옷을 사요
ถามสถานที่ทำกิจกรรม ตอบ ที่ + 에서 + กรรม + กริยา
⚠ 백화점에 샀어요 ✗ → 백화점에서 샀어요
กริยากิจกรรม (ซื้อ ทำ เรียน อ่าน) ต้องใช้ 에서
에 vs 에서
ไปที่ · อยู่ที่ ↔ ทำที่
가다 · 오다 · 있다 · 없다 → 에 (학교에 가요 · 집에 있어요)
กริยาไป มา อยู่ มี → ใช้ 에 (ที่หมาย/ที่ตั้ง)
그 밖의 동작 동사 → 에서 (공원에서 운동해요)
กริยาทำกิจกรรมอื่น ๆ → ใช้ 에서 (ทำที่…)
같은 장소도 동사가 정함 → 집에 가요 ↔ 집에서 쉬어요
สถานที่เดียวกัน ให้ดูที่กริยา ไม่ใช่ที่สถานที่
⚠ 학생식당하고 가요 ✗ → 학생식당에 가요
