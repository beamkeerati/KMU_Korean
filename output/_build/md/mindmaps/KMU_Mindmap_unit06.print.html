문법
ไวยากรณ์
N이 / N가
ตัวบอกประธาน (ใคร/อะไร ทำ-เป็น)
받침 ○ → N이 · 책이 · 직업이 · 선생님이
พยางค์ท้ายมีตัวสะกด → 이
받침 ✗ → N가 · 의자가 · 아이가 · 마키 씨가
ไม่มีตัวสะกด → 가 (씨 → 가)
누구+가 → 누가 · 저+가 → 제가 · 나+가 → 내가
รูปหดที่ต้องจำ ไม่ใช่ 누구가 · 저가
누가 의사입니까? → 왕쯔이 씨가 의사입니다
ถามว่าใคร ตอบด้วย 이/가 (ไม่ตอบด้วย 은/는)
⚠ 처음 말하면 이/가 → 이어 말하면 은/는
พูดถึงครั้งแรกใช้ 이/가 พูดต่อไปใช้ 은/는
이것 · 그것 · 저것
นี่ · นั่น · โน่น
이것 = 내 가까이 · 그것 = 상대 가까이 · 저것 = 둘 다 멀리
นี่ ใกล้ผู้พูด · นั่น ใกล้ผู้ฟัง · โน่น ไกลทั้งคู่
이것이 · 그것이 · 저것이 + 무엇입니까? → N입니다
ถามสิ่งของ ตอบ N입니다 (저것이 → 시계입니다)
이/그/저 + N · 이 사람 · 그 책 · 저 의자
ขยายนาม นี้/นั้น/โน้น (หน้านามไม่ใช้ 이것)
⚠ 소리 ≠ 철자 · [그거시] → 그것이 · [교시림니다] → 교실입니다
เสียงเชื่อมไม่ใช่ตัวเขียน เขียนตามรูปคำ
무엇 · 누구
อะไร · ใคร
이름이 무엇입니까? → 김윤아입니다 · 직업이 무엇입니까? → 학생입니다
ถามชื่อ ตอบชื่อ · ถามอาชีพ ตอบอาชีพ
누구 + N · 누구 지갑입니까? → 마키 씨 지갑입니다
ใคร + นาม = ของใคร ตอบ ชื่อ + 씨 + ของ
N + N = ของ N · 마키 씨 지갑 · 압둘라 씨 책
วางสองนามติดกัน ไม่ต้องมีคำว่า ของ
⚠ 대답 먼저 읽기 · 선생님이 → 누가 · 왕쯔이입니다 → 이름
อ่านคำตอบก่อนเลือกคำถาม: คน → 누가 · ชื่อ → 이름
