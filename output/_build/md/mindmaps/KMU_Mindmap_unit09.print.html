ไวยากรณ์
N 위치 명사 + 에 있어요/없어요
อยู่ที่… (บอกตำแหน่ง)
N + 위치 명사 + 에 → 책상 위에 · 의자 아래에
เว้นวรรคหลังคำนาม แล้วติด 에 กับคำบอกตำแหน่ง
N이/가 + 장소에 + 있어요 → 연필이 책 옆에 있어요
ของ + 이/가 + ที่ + 에 있어요 (ดินสออยู่ข้างหนังสือ)
순서 바꿔도 같음 → 책상 위에 볼펜이 있어요
สลับลำดับได้ ความหมายเท่ากัน (บนโต๊ะมีปากกา)
N이/가 + 장소에 + 없어요 → 지훈 씨가 식당에 없어요
ไม่มี/ไม่อยู่ ใช้ 없어요 (คุณจีฮุนไม่อยู่ที่ร้าน)
⚠ 앞 ≠ 옆 · 위 ≠ 위층 · 아래 = 밑
หน้า ≠ ข้าง · บน ≠ ชั้นบน · ล่าง = ใต้ (ใช้แทนกันได้)
N에 가요 / 와요
ไป / มา ที่… (จุดหมาย)
장소 + 에 + 가요/와요 → 학교에 가요 · 우체국에 가요
ที่หมายต้องตามด้วย 에 แล้วจึง 가요 (ไป) / 와요 (มา)
주어 + 은/는 + 장소에 가요 → 바트 씨는 은행에 가요
ประธานใช้ 은/는 ได้ (คุณบาตไปธนาคาร)
어디에 가요? → 우체국에 가요 (장소 + 에)
ถามว่าไปไหน ตอบเป็นสถานที่ + 에 가요
⚠ 학생식당하고 가요 ✗ → 학생식당에 가요
ที่หมายของ 가다 ใช้ 에 ไม่ใช่ 하고 (เสีย 4 คะแนน)
어디에 있어요? vs 뭐가 있어요?
ถามที่อยู่ ↔ ถามว่ามีอะไร
연필이 어디에 있어요? → 책 옆에 있어요
ถามที่อยู่ → ตอบเป็นตำแหน่ง (ดินสออยู่ข้างหนังสือ)
책상 위에 뭐가 있어요? → 필통이 있어요
ถามว่ามีอะไร → ตอบชื่อสิ่งของ (กล่องดินสอ)
도서관은 어디에 있어요? (이미 나온 말 → 은/는)
ของที่พูดถึงแล้วใช้ 은/는 · ของใหม่ใช้ 이/가 (연필이)
층 + 에 + N이/가 있어요 → 1층에 빵집이 있어요
ชั้น/ที่ + 에 + ของ + 이/가 (ชั้น 1 มีร้านขนมปัง)
⚠ 무엇이 있어요? → 나무가 있어요 (위치 ✗)
ถามว่า "มีอะไร" ต้องตอบเป็นสิ่งของ ไม่ใช่ตำแหน่ง
