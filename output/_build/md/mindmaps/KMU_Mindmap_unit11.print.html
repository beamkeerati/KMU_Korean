문법
ไวยากรณ์
V-아/어/여요
สุภาพไม่เป็นทางการ (ปัจจุบัน)
어간 끝 모음 ㅏ/ㅗ → -아요 (가요 · 와요 · 봐요 · 앉아요)
ตัด 다 ดูสระท้าย ㅏ/ㅗ ใช้ 아요 (ㅗ+ㅏ ควบเป็น ㅘ)
그 외 모음 → -어요 (먹어요 · 마셔요 · 줘요 · 배워요 · 있어요)
สระอื่นทั้งหมดใช้ 어요 (ㅣ+ㅓ=ㅕ · ㅜ+ㅓ=ㅝ)
하다 → 해요 (공부해요 · 일해요 · 운동해요)
กริยาลงท้าย 하다 เปลี่ยนเป็น 해요 ทันที
어간 ㅡ → ㅡ 빼고 아/어 (써요 · 꺼요 · 아파요)
ตัด ㅡ ก่อน แล้วดูสระหน้า (พยางค์เดียวใช้ 어요)
⚠ 받어요 ✗ → 받아요 · 춤어요 ✗ → 춰요 · 주세요 ✗ → 줘요
ㅏ ต้อง 아요 · 춤을 추다 = 춤을 춰요 · ให้ = 줘요
N을/를
ชี้กรรม (สิ่งที่ถูกกระทำ)
받침 ○ → 을 · 받침 ✗ → 를
มีตัวสะกด → 을: 책을 · 밥을 · ไม่มี → 를: 영화를 · 커피를
N이/가 + N을/를 + V → 친구가 빵을 먹어요
ประธาน + 이/가 + กรรม + 을/를 + กริยา
N하다의 N + 을/를 → 숙제를 해요 · 운동을 해요
คำนามหน้า 하다 ก็ติด 을/를 (숙제를 · 운동을 · 청소를)
⚠ 학생을 공부해요 ✗ → 숙제를 해요 · 반나요 ✗ → 만나요
กรรมต้องเข้ากับกริยา · 만나요 ขึ้นต้น ㅁ ไม่ใช่ ㅂ
묻고 답하기
ถาม-ตอบ ด้วยรูป -아/어요
무엇을 해요? → 텔레비전을 봐요
ถามว่าทำอะไร ตอบด้วย กรรม + 을/를 + กริยา
누가 노래를 해요? → 마키 씨가 노래를 해요
ถามว่าใครทำ ตอบด้วยชื่อ + 이/가
알렉세이 씨가 쉬어요? → 아니요, 노래해요
