# 📝 매일 시험 · 연습지 —  classroom

## 교실 용어 · 교실 한국어 (คำศัพท์และสำนวนในห้องเรียน)

### A. 그림을 보고 단어를 쓰세요.
*คำสั่ง: ดูภาพแล้วเขียนคำศัพท์และสำนวนในห้องเรียนให้ถูกต้อง*

1. ![](img:ev00-s-1) 🖼️ ผู้หญิงชี้นิ้วที่ดวงตาทั้งสองข้าง → <span class="wl"></span>*(กรุณาดู)*
2. ![](img:ev00-s-2) 🖼️ ผู้หญิงเอามือป้องหูตั้งใจฟัง → <span class="wl"></span>*(กรุณาฟัง)*
3. ![](img:ev00-s-3) 🖼️ ผู้ชายกำลังใช้ปากกาเขียนหนังสือ → <span class="wl"></span>*(กรุณาเขียน)*
4. ![](img:ev00-s-4) 🖼️ ผู้ชายกำลังก้มหน้าอ่านหนังสือ → <span class="wl"></span>*(กรุณาอ่าน)*
5. ![](img:ev00-s-5) 🖼️ คุณครูกำลังพูดอธิบายให้นักเรียนฟัง → <span class="wl"></span>*(กรุณาพูด)*
6. ![](img:ev00-s-6) 🖼️ ครูพูด "합니다..." แล้วนักเรียนพูดตาม "합니다..." → <span class="wl"></span>*(กรุณาพูดตาม)*
7. ![](img:ev00-s-7) 🖼️ นักเรียนหญิงยกมือถามคำถาม มีบอลลูนข้อความ "질문?" → <span class="wl"></span>*(กรุณาถาม / ถามคำถาม)*
8. ![](img:ev00-s-8) 🖼️ ครูถาม "누구입니까?" นักเรียนยกมือตอบ "그 사람은..." → <span class="wl"></span>*(กรุณาตอบ / ตอบคำถาม)*
9. ![](img:ev00-s-9) 🖼️ สมุดโน้ตจดคำศัพท์มากมายที่กำลังท่องจำ → <span class="wl"></span>*(กรุณาท่องจำ)*
10. ![](img:ev00-s-10) 🖼️ ผู้ชายนั่งดื่มกาแฟพักผ่อนสบายๆ บนเก้าอี้ → <span class="wl"></span>*(กรุณาพักผ่อน)*
11. ![](img:ev00-s-11) 🖼️ ผู้ชายกำลังหย่อนตัวนั่งลงบนเก้าอี้ → <span class="wl"></span>*(กรุณานั่งลง)*
12. ![](img:ev00-s-12) 🖼️ ผู้ชายเอามือเท้าคาง ทำหน้าสงสัย/ไม่เข้าใจ มีเครื่องหมาย ? → <span class="wl"></span>*(ไม่รู้ / ไม่เข้าใจ)*
13. ![](img:ev00-s-13) 🖼️ ผู้ชายมีหลอดไฟปิ๊งขึ้นข้างศีรษะ ยิ้มชี้นิ้วเข้าใจ → <span class="wl"></span>*(รู้ / เข้าใจ)*
14. ![](img:ev00-s-14) 🖼️ ผู้ชายใส่แว่นชูป้ายสัญลักษณ์วงกลม ⭕ → <span class="wl"></span>*(ถูกต้อง)*
15. ![](img:ev00-s-15) 🖼️ ผู้ชายใส่แว่นทำหน้าผิดหวังชูป้ายสัญลักษณ์กากบาท ❌ → <span class="wl"></span>*(ผิด / ไม่ถูกต้อง)*
16. ![](img:ev00-s-16) 🖼️ แอปเปิ้ลสองผลมีเครื่องหมายเท่ากับ (=) คั่นกลาง → <span class="wl"></span>*(เหมือนกัน)*
17. ![](img:ev00-s-17) 🖼️ แอปเปิ้ลกับกล้วยมีเครื่องหมายไม่เท่ากับ (≠) คั่นกลาง → <span class="wl"></span>*(ต่างกัน)*
18. ![](img:ev00-s-18) 🖼️ กล่องนมมีแสงประกายรอบกล่อง → <span class="wl"></span>*(มี)*
19. ![](img:ev00-s-19) 🖼️ มีเส้นประกายแต่ว่างเปล่า ไม่มีสิ่งของใดอยู่ → <span class="wl"></span>*(ไม่มี)*
