# 📝 매일 시험 · 연습지 — 26

## 26과 · 연습지 (ใบฝึกหัด บทที่ 26 · 보다 · -겠-)
*ใบฝึกที่ครูแจกราว 30 ต.ค. 2026 (สแกนเข้ามา 30 ต.ค.) · 3 ส่วน: 보다 문장 연습 1 (6 คำใบ้ ไม่มีดินสอ) · 보다 문장 연습 2 (6 คำใบ้ ผู้เรียนเขียนดินสอไว้ ครูยังไม่ตรวจ) · -겠 확장 연습 (การ์ดสถานการณ์ 10 ใบ ไม่มีช่องเขียน) · ⚠️ = ตรวจเอง*

### A. 26과_보다_문장 연습 1 — 보다를 사용해서 문장을 쓰세요.
*คำสั่ง: แต่งประโยคเปรียบเทียบด้วย A이/가 B보다 더 … · เครื่องหมาย > แปลว่าฝั่งซ้ายมากกว่า < แปลว่าฝั่งขวามากกว่า (ใบจริงมีแค่กล่องคำใบ้ ไม่มีช่องเขียน)*

1. 오늘 > 어제 / 날씨가 좋다 *(วันนี้ > เมื่อวาน / อากาศดี)*
   <span class="wl2"></span>
2. 비행기 > 배 / 빠릅니다 *(เครื่องบิน > เรือ / เร็ว)*
   <span class="wl2"></span>
3. 월요일 > 토요일 / 바쁘다 *(วันจันทร์ > วันเสาร์ / ยุ่ง)*
   <span class="wl2"></span>
4. 쓰기 > 말하기 / 어렵다 *(การเขียน > การพูด / ยาก)*
   <span class="wl2"></span>
5. 한국노래 < 고향노래 / 자주 듣다 *(เพลงเกาหลี < เพลงบ้านเกิด / ฟังบ่อย)*
   <span class="wl2"></span>
6. 야채 < 고기 / 많이 먹다 *(ผัก < เนื้อสัตว์ / กินเยอะ)*
   <span class="wl2"></span>

### B. 26과_보다_문장 연습 2 — 보다를 사용해서 문장을 쓰세요.
*คำสั่ง: ดูตัวเลขในวงเล็บแล้วแต่งประโยคเปรียบเทียบ — ฝ่ายที่ "ชนะ" ตามคำคุณศัพท์ท้ายกล่องรับ 이/가 ฝ่ายที่แพ้รับ 보다*

1. 남산(262m) / 한라산(1,950m) / 낮다 *(ภูเขานัมซัน 262 ม. / ภูเขาฮัลลา 1,950 ม. / เตี้ย ต่ำ)*
   <span class="wl2"></span>
2. 왕쯔이(90점) / 압둘라(70점) / 시험을 잘 봤다 *(หวางจื่ออี 90 คะแนน / อับดุลลาห์ 70 คะแนน / สอบได้ดี)*
   <span class="wl2"></span>
3. 컴퓨터(200만 원) / 휴대전화(100만 원) / 비싸다 *(คอมพิวเตอร์ 2 ล้านวอน / มือถือ 1 ล้านวอน / แพง)*
   <span class="wl2"></span>
4. 고양이(IQ 50) / 개(IQ 30) / 똑똑하다 *(แมว IQ 50 / หมา IQ 30 / ฉลาด)*
   <span class="wl2"></span>
5. 장핑(175cm) / 카오루(170cm) / 키가 커요 *(จางผิง 175 ซม. / คาโอรุ 170 ซม. / ตัวสูง)*
   <span class="wl2"></span>
6. 투이(1잔) / 알렉세이(3잔) / 커피를 많이 마시다 *(ทุย 1 แก้ว / อเล็กเซย์ 3 แก้ว / ดื่มกาแฟเยอะ)*
   <span class="wl2"></span>

### C. 26과_-겠_확장 연습 — 친구의 말을 듣고 -겠-으로 대답을 쓰세요.
*คำสั่ง: การ์ดแต่ละใบคือสิ่งที่เพื่อนเล่า ให้ตอบโดยเดาความรู้สึกหรือสภาพของเพื่อนด้วย -겠어요 (เรื่องที่จบไปแล้วใช้ -았/었겠어요 ได้) · ใบจริงเป็นการ์ดพูดคุย ไม่มีช่องเขียน*

1. "어제 이사했어요." *(เมื่อวานย้ายบ้าน)*
   <span class="wl2"></span>
2. "이번 시험에서 1등을 했어요." *(สอบครั้งนี้ได้ที่ 1)*
   <span class="wl2"></span>
3. "아침, 점심, 저녁을 모두 안 먹었어요." *(ไม่ได้กินทั้งข้าวเช้า กลางวัน และเย็นเลย)*
   <span class="wl2"></span>
4. "어제 3시부터 10시까지 노래방에서 노래를 했어요." *(เมื่อวานร้องคาราโอเกะตั้งแต่บ่าย 3 ถึง 4 ทุ่ม)*
   <span class="wl2"></span>
5. "숙제가 너무 많아요." *(การบ้านเยอะเกินไป)*
   <span class="wl2"></span>
6. "다음 달에 결혼해요." *(เดือนหน้าจะแต่งงาน)*
   <span class="wl2"></span>
7. "남자 친구와 헤어졌어요." *(เลิกกับแฟนแล้ว)*
   <span class="wl2"></span>
8. "지금 영하 12도예요." *(ตอนนี้ติดลบ 12 องศา)*
   <span class="wl2"></span>
9. "내일 시험을 봐요." *(พรุ่งนี้มีสอบ)*
   <span class="wl2"></span>
10. "오늘 생일이에요." *(วันนี้เป็นวันเกิด)*
   <span class="wl2"></span>

## 26과 · 연습지

**A.** *(ตัวอย่างตอบ — ใบนี้ไม่มีดินสอ)*
- **1)** 오늘이 어제보다 날씨가 더 좋아요 *(วันนี้อากาศดีกว่าเมื่อวาน · ประธานสองชั้น 오늘이 … 날씨가)*
- **2)** 비행기가 배보다 더 빠릅니다 *(เครื่องบินเร็วกว่าเรือ · 해요체 = 빨라요 เพราะ 빠르다 เป็น 르 불규칙)*
- **3)** 월요일이 토요일보다 더 바빠요 *(วันจันทร์ยุ่งกว่าวันเสาร์ · ㅡ หลุดก่อน 아요)*
- **4)** 쓰기가 말하기보다 더 어려워요 *(การเขียนยากกว่าการพูด · ㅂ 불규칙)*
- **5)** 한국 노래보다 고향 노래를 더 자주 들어요 *(ฟังเพลงบ้านเกิดบ่อยกว่าเพลงเกาหลี · กริยา 듣다 มีกรรม จึงใช้ 를 · 듣다 → 들어요 เป็น ㄷ 불규칙 ซึ่งจะเรียนเต็ม ๆ ในบท 31 · < = ฝั่งขวาชนะ)*
- **6)** 야채보다 고기를 더 많이 먹어요 *(กินเนื้อเยอะกว่าผัก · 고기를 เป็นกรรมของ 먹다)*

**B.**
- **1)** 남산이 한라산보다 낮아요 ✓ *(นัมซันเตี้ยกว่าฮัลลาซัน · ผู้เรียนเขียนตรง)*
- **2)** 왕쯔이 씨가 압둘라 씨보다 시험을 잘 봤어요 ⚠️ *(หวางจื่ออีได้ 90 คะแนน จึงสอบได้ดีกว่า · ผู้เรียนเขียน 압둘라 씨가 왕쯔이보다 시험을 잘 봤어요 = สลับฝ่ายชนะกับฝ่ายแพ้ · ถ้าจะเริ่มด้วยอับดุลลาห์ต้องใช้คำตรงข้าม: 압둘라 씨가 왕쯔이 씨보다 시험을 못 봤어요)*
- **3)** 컴퓨터가 휴대전화보다 비싸요 ✓ *(คอมพิวเตอร์แพงกว่ามือถือ · ใส่ 더 ก็ได้: 더 비싸요)*

- **5)** 장핑 씨가 카오루 씨보다 키가 커요 ✓ *(จางผิงสูงกว่าคาโอรุ · ประธานสองชั้น 장핑 씨가 … 키가)*
- **6)** 알렉세이 씨가 투이 씨보다 커피를 많이 마셔요 ✓ *(อเล็กเซย์ดื่มกาแฟเยอะกว่าทุย · ผู้เรียนเขียน 투이보다 ไม่มี 씨 — ใช้ได้ แต่ใส่ 씨 ให้เหมือนฝั่งแรกจะสุภาพกว่า)*

- **1)** 힘들었겠어요 / 피곤하겠어요 *(คงเหนื่อยแย่ · เรื่องจบแล้วใช้ 었겠 ได้)*
