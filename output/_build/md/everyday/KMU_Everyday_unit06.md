### A. 그림을 보고 단어를 쓰세요.
*คำสั่ง: ดูภาพแล้วเขียนคำศัพท์*

> **보기 (ตัวอย่าง):** 🖼️ รูปหนังสือ → 책 *(หนังสือ)*

1. 🖼️ รูปแผนที่โลก → <span class="wl"></span>*(แผนที่)*
2. 🖼️ รูปกระเป๋าเป้สะพายหลัง → <span class="wl"></span>*(กระเป๋า)*
3. 🖼️ รูปนาฬิกาตั้งโต๊ะ → <span class="wl"></span>*(นาฬิกา)*
4. 🖼️ รูปโต๊ะเรียน / โต๊ะทำงาน → <span class="wl"></span>*(โต๊ะเรียน)*

### B. (　　　　　　　　)에 들어갈 단어를 <보기>에서 골라 쓰세요.
*คำสั่ง: เลือกคำศัพท์จากกรอบตัวอย่างมาเติมลงในช่องว่าง*

> **보기 (ตัวอย่าง):** 누가 *(ใคร)* / 무엇 *(อะไร)* / 이름 *(ชื่อ)* / 직업 *(อาชีพ)*
> 가: 이것이 ( 무엇 )입니까? *(สิ่งนี้คืออะไรครับ/ค่ะ?)*
> 나: 의자입니다. *(คือเก้าอี้ครับ/ค่ะ)*

5. 가: (　　　　　　　　) 한국 사람입니까? *(ใครเป็นคนเกาหลีครับ/ค่ะ?)*
   나: 선생님이 한국 사람입니다. *(คุณครูเป็นคนเกาหลีครับ/ค่ะ)*

6. 가: (　　　　　　　　)(이/가) 무엇입니까? *(ชื่ออะไรครับ/ค่ะ?)*
   나: 왕쯔이입니다. *(คือหวังจื่อครับ/ค่ะ)*

7. 가: (　　　　　　　　)(이/가) 무엇입니까? *(ทำงานอะไร / อาชีพอะไรครับ/ค่ะ?)*
   나: 경찰관입니다. *(เป็นตำรวจครับ/ค่ะ)*
