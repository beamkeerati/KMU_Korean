### D. 문맥에 알맞은 것을 고르세요 (이다 vs 있다).
*คำสั่ง: เลือกคำตอบที่ถูกต้องระหว่าง 이에요/예요 (เป็น/คือ) กับ 있어요 (มี/อยู่)*

> **참고 (หลักไวยากรณ์):**  
> 명사 + 이다/아니다 → 저는 학생**이에요**. *(ฉันเป็นนักเรียน)*  
> 명사 + 에 있다/없다 → 교실**에** 학생이 **있어요**. *(มีนักเรียนอยู่ในห้องเรียน)*

1. 저는 유진( 이에요 / 있어요 ). 학생( 이에요 / 있어요 ). *(ฉันคือยูจิน เป็นนักเรียน)*
2. 롯데월드가 서울에 ( 이에요 / 있어요 ). *(ล็อตเต้เวิลด์อยู่ที่โซล)*
3. 학교에 식당이 ( 이에요 / 있어요 ). *(ที่โรงเรียนมีโรงอาหาร)*
4. 여기가 도서관( 이에요 / 있어요 ). *(ที่นี่คือห้องสมุด)*
5. 지훈 씨는 회사에 ( 이에요 / 있어요 ). *(คุณจีฮุนอยู่ที่บริษัท)*
