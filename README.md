# KMU Korean 1 — โฟลเดอร์นี้มีอะไร

**จะอ่าน พิมพ์ หรือฝึก → เปิด `output/START_HERE.html`** (สารบัญพร้อมลิงก์ทุกไฟล์)

| โฟลเดอร์ | คืออะไร | แก้ได้ไหม |
|:---|:---|:---|
| `output/` | ไฟล์สำเร็จรูปทั้งหมด (PDF · เว็บฝึกสอบ) แบ่งเป็น 1_Guides · 2_Practice_Web · 3_Exam_Prep · 4_Daily_Tests · 5_Homework · 6_Speaking | ไม่ต้องแก้ — สร้างใหม่ทุกครั้ง |
| `content/` | ต้นฉบับเนื้อหาทั้งหมด (Markdown/JSON) ที่ใช้สร้าง output | แก้ที่นี่ · `content/speaking/myself.md` คือบทพูดของคุณเอง |
| `source/` | ไฟล์สแกนจากครูและตำรา (ต้นฉบับจริง) | ห้ามแก้ — แค่เพิ่มไฟล์ใหม่ |
| `extracted/` | รูปหน้าที่แตกจาก source และไฟล์เสียงชั่วคราว | ไม่ต้องสนใจ — สร้างใหม่ได้ |
| `scripts/` | โปรแกรมสร้าง PDF / เว็บ | — |
| `CLAUDE.md` | บันทึกงานสำหรับ Claude (ภาษาอังกฤษ) | — |

ไฟล์ใหม่จากครู (แบบทดสอบ ชีต ข้อสอบ) วางไว้ใน `source/` ตามประเภท แล้วบอก Claude
