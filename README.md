# KMU Korean — โฟลเดอร์นี้มีอะไร

**แยกเป็นระดับ:** ของแต่ละระดับอยู่ใน `levels/<เลขระดับ>/` · 1급 (จบแล้ว 25 พ.ย. 2026) = `levels/1/` · 2급 เริ่ม 14 ธ.ค. 2026 → `levels/2/`

**จะอ่าน พิมพ์ หรือฝึก 1급 → เปิด `levels/1/output/START_HERE.html`** (สารบัญพร้อมลิงก์ทุกไฟล์)

| โฟลเดอร์ | คืออะไร | แก้ได้ไหม |
|:---|:---|:---|
| `inbox/` | **วางไฟล์ใหม่จากครูไว้ตรงนี้** (สแกน ชีต ข้อสอบ ใบคะแนน) แล้วบอก Claude ให้จัดเข้าที่ | วางได้เลย |
| `levels/1/output/` | ไฟล์สำเร็จรูปของ 1급 (PDF · เว็บฝึกสอบ) แบ่งเป็น 1_Guides · 2_Practice_Web · 3_Exam_Prep · 4_Daily_Tests · 5_Homework · 6_Speaking | ไม่ต้องแก้ — สร้างใหม่ทุกครั้ง |
| `levels/1/content/` | ต้นฉบับเนื้อหา 1급 (Markdown/JSON) ที่ใช้สร้าง output | แก้ที่นี่ · `content/speaking/myself.md` คือบทพูดของคุณเอง |
| `levels/1/source/` | ไฟล์สแกนจากครูและตำรา 1급 (ต้นฉบับจริง) · ใบเกรดและใบประกาศอยู่ใน `source/results/` | ห้ามแก้ — แค่เพิ่มไฟล์ใหม่ |
| `levels/1/extracted/` | รูปหน้าที่แตกจาก source และไฟล์เสียงชั่วคราว | ไม่ต้องสนใจ — สร้างใหม่ได้ |
| `levels/1/docs/` | บันทึกยาวของ 1급 (ตารางสอบ สถานะเนื้อหา คะแนนรายวัน) | — |
| `scripts/` | โปรแกรมสร้าง PDF / เว็บ (ใช้ร่วมกันทุกระดับ) | — |
| `specs/` | ข้อกำหนดรูปแบบหนังสือ สี เว็บ และคำสั่งงานสำหรับ agent (ใช้ร่วมกันทุกระดับ) | — |
| `docs/` | บันทึกที่ใช้ทุกระดับ: ข้อผิดพลาดที่คุณทำบ่อย · กฎการทำ PDF · ประวัติการทำงาน | — |
| `tools/` | โปรแกรมขยายรูป (ไม่อยู่ใน git) | — |
| `CLAUDE.md` | บันทึกงานสำหรับ Claude (ภาษาอังกฤษ) | — |
