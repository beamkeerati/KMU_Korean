## 문법 | ไวยากรณ์ @right
### 한자어 수 | เลขจีน-เกาหลี 일 이 삼
- 1~10: 일 이 삼 사 오 육 칠 팔 구 십 · 0 = 공 · 영 | เลข 1–10 · เลข 0 อ่านว่า 공 (เบอร์โทร) หรือ 영
- 11~19 = 십 + 숫자 · 십일 · 십구 · 20~ = 숫자 + 십 · 이십칠 | สิบกว่า = 십 + หน่วย · ยี่สิบขึ้นไป = เลข + 십
- 100 = 백 · 1,000 = 천 · 10,000 = 만 · 153 = 백오십삼 | ร้อย พัน หมื่น ไม่ใส่ 일 นำหน้า
- ⚠️ 이(2) ≠ 일(1) · 사(4) ≠ 삼(3) · 이백사 ≠ 이백삼 | เสียงใกล้กัน เคยฟังผิด: ห้อง 204→203 · ชั้น 2→1
### 층 · 호 · 번 | ชั้น · ห้อง · หมายเลข
- 5층 = 오 층 · 402호 = 사백이 호 · 7211번 = 칠이일일 번 | เลขจีน + หน่วย (층 ชั้น · 호 ห้อง · 번 หมายเลข)
- 전화번호 = 한 자리씩 읽기 · 010 = 공일공 · 2396 = 이삼구육 | เบอร์โทรอ่านทีละหลัก เลข 0 ใช้ 공
- 몇 층이에요? → 이 층이에요 · 몇 호예요? → 이백삼 호예요 | ถามชั้น/ห้อง → ตอบ เลขจีน + 층/호
- 층 · 번 (받침 ○) → 이에요 · 호 (받침 ✗) → 예요 | หน่วยมีตัวสะกด → 이에요 · ไม่มี → 예요
- ⚠️ 몇 호예요 ✓ · 몇 호ㅇ예요 ✗ · 몇 → 몆 ✗ (ㅊ) | เขียน 몇 ลงท้าย ㅊ (ไม่ใช่ ㅈ) · 호 + 예요 ติดกัน
### N에 있어요 / 없어요 | อยู่ที่… · มี / ไม่มี
- N(장소)에 N이/가 있어요 · 가방에 책이 있어요 | ที่ (สถานที่) + ของ + 이/가 + 있어요
- N이/가 N에 있어요 · 간토야 씨가 사무실에 있어요 | สลับลำดับได้ บอกว่าคน/ของอยู่ที่ไหน
- 부정은 없어요 · 교실에 의자가 없어요 | ปฏิเสธใช้ 없어요 ไม่ใช้ 안 있어요
- 어디에 있어요? · 몇 층에 있어요? → 2층에 있어요 | ถามที่อยู่ ตอบ ที่ + 에 있어요
- ⚠️ 학생이에요 ≠ 학생이 있어요 · 학생을 있어요 ✗ | เป็น = ติดนาม · มี/อยู่ = 이/가 + เว้นวรรค ห้าม 을/를
