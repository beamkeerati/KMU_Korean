## 64. -아/어/여야 하다/되다 (ต้อง… · จะต้อง…จึงจะ…)

> [!INTRO] ข้อนี้คืออะไร
> -아/어/여야 하다/되다 ใช้ต่อท้ายรากกริยา คำคุณศัพท์ 이다/아니다 และ 있다/없다 แล้วตามด้วย **하다** (หรือ **되다** ในภาษาพูด) เพื่อบอก**ข้อบังคับ ความจำเป็น หรือสิ่งที่ควรเป็น** เช่น 숙제해야 **해요** *(ต้องทำการบ้าน)* หรือ 학생증이 있어야 **해요** *(ต้องมีบัตรนักศึกษา)* ตำรา 362쪽 สรุปว่า obligation, necessity, and what should be
>
> สอนในบท 37 (교과서 362–363쪽 · 준비 2) ต่อยอดจาก ข้อ 06 (กฎ 아/어/해) ข้อ 18 (คำคุณศัพท์) ข้อ 02 (N이다) ข้อ 48 (-아/어서 "เพราะ" นำหน้า) และ ข้อ 55 (-(으)면)
>
> ไปใช้ต่อใน ข้อ 62 (…아/어야 해요 → …ㄹ게요) · ข้อ 63 (บทเดียวกัน) · ข้อ 55 (…면 …아/어야 해요) และ 읽기 37-2 (마키 씨가 서울을 안내해야 해요)

### 📌 รูปแบบและเงื่อนไข

เลือก 아/어/해 จาก**สระของพยางค์สุดท้ายของราก** กฎเหมือน -아/어요 (ข้อ 06) แล้วเติม **야 하다** (ภาษาพูด **야 되다**) ตารางแรกสรุปกฎ ตารางที่สองให้ตัวอย่างของรากแต่ละแบบ

| รากศัพท์ | ต่อ |
|:---|:---|
| **ㅏ · ㅗ** | **-아야 하다** |
| สระอื่น | **-어야 하다** |
| **하다** | **해야 하다** |
| **있다 / 없다** | **-어야 하다** |
| **N이다** | ตัวสะกด (받침) → N**이어야** · สระ → N**여야** |
| **N이/가 아니다** | **아니어야 하다** |
| ㅡ-ราก | ㅡ หลุด |
| 르 · ㄷ · ㅂ ไม่ปกติ | ตามกฎก่อน 아/어 (ข้อ 54 · 51 · 37) |
| ㄹ-ราก | ปกติ (ㄹ คงอยู่ + 아/어) |

#### ตัวอย่างตามชนิดของราก

ทุกแถวคือรากหรือคำนาม + -아/어/여야 + 하다 ในรูป 해요 สังเกตว่า N이다 มีสองรูปตามตัวสะกด และรากไม่ปกติเปลี่ยนรูปก่อนต่อ 아/어

| ชนิดของราก | ตัวอย่าง | ไทย |
|:---|:---|:---|
| ㅏ · ㅗ | 가다 → **가야 해요** | ต้องไป |

#### ข้อความของตำราและข้อควรรู้

ตำราหน้า 362 อธิบายกฎครบทุกชนิดของคำ ส่วนข้อควรรู้คือภาษาพูด 되다 ท่านผู้ใหญ่เป็นประธาน การเว้นวรรค และเสียงอ่าน

- **ตำรา 362쪽:** "ใช้แสดงข้อบังคับ ความจำเป็น สิ่งที่ควรเป็น · ต่อหลังรากกริยา คำคุณศัพท์ 이다/아니다 และ 있다/없다" และสรุปรูปไว้ดังนี้
  - ㅏ/ㅗ → -아야 하다 · อื่น → -어야 하다 · 하다 → 해야 하다
  - N + 이다: สระ → N+여야 하다 · ตัวสะกด → N+이어야 하다
  - 아니다 → 아니어야 · 있다/없다 → 있어야/없어야
  - **ภาษาพูดใช้ -아/어/여야 되다**
- **ภาษาพูด:** 해야 **돼요** = 해야 **해요** — มักได้ยิน 돼요 มากกว่าในชีวิตจริง (ตำราเขียนไว้ว่า "colloquial situation") แต่กล่องไวยากรณ์ของตำราใช้ **하다** เป็นรูปหลัก
- **ท่านผู้ใหญ่เป็นประธาน:** ใส่ -(으)시- ที่ 하다
  - 가셔야 **하세요** *(ท่านต้องไป — เสริม)*
  - ในตำราใช้ 시 ที่เหตุผล: 어머니가 **아프셔서** 고향에 가야 해요 *(เพราะคุณแม่ป่วย ต้องกลับบ้านเกิด)*
- **เว้นวรรค:** 해야 **해요** · 가야 **돼요** — 하다/되다 แยกคำจาก "-아/어야" (ข้อ 13) · ✗ 해야해요 · ✗ 갈거예요 (ติดกัน — ที่เคยพลาด)
- **เพียง "-아/어야" ไม่ใช่ประโยค** — ต้องต่อ 하다/되다 เสมอ

#### เสียงอ่านที่ควรรู้

ตัวอย่างต่อไปนี้ไม่มีกฎเสียงพิเศษ ยกเว้นคำที่มี 있다/없다 ซึ่ง ㅆ กับ ㅄ ออกเสียงต่อไปยังพยางค์ถัดไป

| 한국어 | เสียงอ่าน | หมายเหตุ |
|:---|:---|:---|
| 해야 해요 | [해야 해요] | ไม่มีกฎพิเศษ |
| 있어야 | [이써야] | |
| 없어야 | [업써야] | |

#### สูตรและวิธีทำ: -아/어/여야 하다/되다 (แบบกระดานครู)

-아/어/여야 คือรากหรือคำนาม + 아/어/여 + 야 ตามด้วย 하다 ผันด้วยกฎเดียวกับ -아/어요 (ข้อ 06) ทุกข้อ ส่วน 하다 ท้ายสุดเป็นตัวที่ผันกาลได้ สิ่งที่ต้องตัดสินใจคือเป็นคำนามหรือไม่ รากเป็น 하 หรือไม่ ต้องปรับรากไม่ปกติก่อนหรือไม่ และใช้ 아 หรือ 어 กฎมีสี่ข้อและใช้ตามลำดับ

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | คำนาม + 이다 หรือ 아니다 | นามมีตัวสะกด ใช้ **N이어야** · นามไม่มีตัวสะกด ใช้ **N여야** · 아니다 ใช้ **아니어야** | 이 ลงท้ายด้วย ㅣ จึงใช้ 어 และ 이 + 어 ย่อเป็น 여 หลังสระ |
| **กฎ 2** | รากเป็น **하다** | ใช้ **해** เลย ไม่ต้องดูสระ | 하 + 여 ย่อเป็น 해 |
| **กฎ 3** | รากไม่ปกติ ㅡ · ㅂ · ㄷ · 르 | **ปรับรากก่อน** แล้วค่อยเลือก 아/어 | ㅡ ตก · ㅂ เป็น 우 · ㄷ เป็น ㄹ · 르 เปลี่ยนเป็น ㄹ ซ้อน |
| **กฎ 4** | ดูสระของพยางค์สุดท้ายของราก (หลังกฎ 3) | ㅏ · ㅗ ใช้ **아** สระอื่นใช้ **어** และถ้าไม่มีตัวสะกดให้**รวมสระ** | สระเสียงสว่างคู่กับ 아 สระอื่นคู่กับ 어 |

ลำดับทำคือ ① ปรับราก (นาม + 이 · 하 เป็น 해 · ㅡ ㅂ ㄷ 르) ② เลือก 아 หรือ 어 ③ รวมสระ ④ ต่อ 야 ติดกับรูปที่ได้ แล้วเว้นวรรคเขียน 해요 ตารางแรกแสดงทุกขั้นกับรากปกติ 있다 และคำนาม

| ราก + คำต่อ | ① ปรับราก | ② เลือก 아/어 | ③ รวมสระ | ④ ผล (+ 야 해요) | หมายเหตุ |
|:---|:---|:---|:---|:---|:---|
| 가 + 아/어야 하다 | ไม่ปรับ | ㅏ จึงใช้ 아 | 가 + 아 เหลือ 가 | **가야 해요** | 아 ถูกกลืน |
| 오 + 아/어야 하다 | ไม่ปรับ | ㅗ จึงใช้ 아 | 오 + 아 เป็น 와 | **와야 해요** | |
| 앉 + 아/어야 하다 | ไม่ปรับ | ㅏ จึงใช้ 아 | ไม่รวม (มีตัวสะกด) | **앉아야 해요** | ✗ 앉어야 해요 |
| 먹 + 아/어야 하다 | ไม่ปรับ | ㅓ จึงใช้ 어 | ไม่รวม (มีตัวสะกด) | **먹어야 해요** | |
| 서 + 아/어야 하다 | ไม่ปรับ | ㅓ จึงใช้ 어 | 서 + 어 เหลือ 서 | **서야 해요** | 어 ถูกกลืน |
| 배우 + 아/어야 하다 | ไม่ปรับ | ㅜ จึงใช้ 어 | 우 + 어 เป็น 워 | **배워야 해요** | |
| 기다리 + 아/어야 하다 | ไม่ปรับ | ㅣ จึงใช้ 어 | 리 + 어 เป็น 려 | **기다려야 해요** | |
| 쉬 + 아/어야 하다 | ไม่ปรับ | ㅟ จึงใช้ 어 | ไม่รวม (ㅟ ไม่หลอมกับ 어) | **쉬어야 해요** | |
| 되 + 아/어야 하다 | ไม่ปรับ | ㅚ จึงใช้ 어 | 되 + 어 เป็น 돼 | **돼야 해요** | ภาษาพูด 돼야 돼요 |
| 하 + 아/어야 하다 | **하 เป็น 해** | ไม่ต้องเลือก (여) | 하 + 여 เป็น 해 | **공부해야 해요** | 해야 กับ 해요 เป็นคนละคำ |
| 있 + 아/어야 하다 | ไม่ปรับ | ㅣ จึงใช้ 어 | ไม่รวม (มีตัวสะกด) | **있어야 해요** | 학생증이 있어야 해요 |
| 학생 + 이다 + 아/어야 하다 | นามมีตัวสะกด ใส่ 이 | 이 ลงท้าย ㅣ จึงใช้ 어 | ไม่รวม | 학생**이어야 해요** | |
| 의사 + 이다 + 아/어야 하다 | นามไม่มีตัวสะกด 이 ย่อ | 이 ลงท้าย ㅣ จึงใช้ 어 | 이 + 어 เป็น 여 | 의사**여야 해요** | ตำราให้ใช้ N여야 หลังสระ |
| 학생 + 이/가 아니다 + 아/어야 하다 | 아니 | ㅣ จึงใช้ 어 | ไม่รวม | 학생이 **아니어야 해요** | |

ตารางที่สองเป็นรากที่ลงท้าย ㅡ รากที่ลงท้าย ㄹ และราก 불규칙 ทั้งกริยาและคำคุณศัพท์ ทุกแถวต้องปรับรากในข้อ ① ก่อนเลือก 아/어

| ราก + คำต่อ | ① ปรับราก | ② เลือก 아/어 | ③ รวมสระ | ④ ผล (+ 야 해요) | หมายเหตุ |
|:---|:---|:---|:---|:---|:---|
| 쓰 + 아/어야 하다 | ㅡ ตก เหลือ ㅆ | ไม่มีสระหน้า ㅡ จึงใช้ 어 | ㅆ + 어 เป็น 써 | **써야 해요** | ㅡ ตกก่อน 아/어 |
| 바쁘 + 아/어야 하다 | ㅡ ตก เหลือ ㅃ | ㅏ จึงใช้ 아 | ㅃ + 아 เป็น 빠 | **바빠야 해요** | ✗ 바쁘야 해요 |
| 살 + 아/어야 하다 | ไม่ปรับ (ㄹ อยู่ครบ) | ㅏ จึงใช้ 아 | ไม่รวม (มีตัวสะกด) | **살아야 해요** | ✗ 살어야 해요 |
| 입 + 아/어야 하다 | ไม่ปรับ (ㅂ ปกติ) | ㅣ จึงใช้ 어 | ไม่รวม (มีตัวสะกด) | **입어야 해요** | ㅂ ปกติไม่เปลี่ยน |
| 돕 + 아/어야 하다 | ㅂ เป็น 우 (도우) | 돕다 ใช้ 아 (ข้อยกเว้น) | 우 + 아 เป็น 와 | **도와야 해요** | ✗ 돕아야 해요 |
| 춥 + 아/어야 하다 | ㅂ เป็น 우 (추우) | ㅜ จึงใช้ 어 | 우 + 어 เป็น 워 | **추워야 해요** | ㅂ อื่นส่วนใหญ่ใช้ 워 |
| 닫 + 아/어야 하다 | ไม่ปรับ (ㄷ ปกติ) | ㅏ จึงใช้ 아 | ไม่รวม (มีตัวสะกด) | **닫아야 해요** | ต่างจาก 듣 |
| 듣 + 아/어야 하다 | ㄷ เป็น ㄹ (들) | ㅡ จึงใช้ 어 | ไม่รวม (มีตัวสะกด) | **들어야 해요** | ✗ 듣어야 해요 |
| 다르 + 아/어야 하다 | 르 เป็น ㄹ ซ้อน (달 + ㄹ) | ㅏ จึงใช้ 아 | ㄹ + 아 เป็น 라 | **달라야 해요** | |
| 부르 + 아/어야 하다 | 르 เป็น ㄹ ซ้อน (불 + ㄹ) | ㅜ จึงใช้ 어 | ㄹ + 어 เป็น 러 | **불러야 해요** | |

> [!TIP] วิธีจำสั้น ๆ
> ก่อนเลือก 아/어 ให้ปรับ 하 ㅡ ㅂ ㄷ 르 ก่อนเสมอ ส่วนคำนามให้ใช้ 이어야 เมื่อมีตัวสะกด และ 여야 เมื่อไม่มี แล้วดูสระ ㅏ ㅗ ใช้ 아 สระอื่นใช้ 어 ถ้ารากไม่มีตัวสะกดให้รวมสระ จากนั้นต่อ 야 และตามด้วย 하다 ซึ่งเป็นตัวที่ผันกาล

#### ใส่กาลที่ 하다 ตัวท้าย

กาลและภาษาพูดอยู่ที่ **하다/되다** ตัวท้ายเท่านั้น ส่วน -아/어/여야 ข้างหน้าไม่เปลี่ยนเลย ตารางนี้ต่อจากผลของสองตารางบน แถวละหนึ่งรูป

| รูปจากตารางบน | ① เลือกรูปของ 하다/되다 | ② ผล | หมายเหตุ |
|:---|:---|:---|:---|
| 가야 | ปัจจุบัน: 하다 เป็น 해요 | **가야 해요** | ต้องไป |
| 가야 | อดีต: 하다 เป็น 했어요 | **가야 했어요** | ✗ 갔어야 해요 แปลว่า "ควรจะไปแล้ว" คนละความหมาย |

### ⚠️ จุดสับสน

-아/어야 하다 สับสนกับรูปที่บอกแผน ความอยาก และการอนุญาต และพลาดบ่อยที่การเลือก 아/어/해 ตารางแรกเทียบความหมายของหกรูป ตารางที่สองรวมรูปที่ถูกกับรูปที่ผิด

#### -아/어야 하다 vs -(으)ㄹ 거예요 vs -고 싶다 vs -아/어도 되다

หกรูปนี้ล้วนต่อกับกริยาแต่บอกเรื่องต่างกัน คือต้อง จะ อยาก ทำได้ ห้าม และไม่ต้อง

| รูป | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| **-아/어야 해요** | **ต้อง** (บังคับ/จำเป็น) | 고향에 가야 해요 *(ต้องกลับบ้านเกิด)* |
| -(으)ㄹ 거예요 (ข้อ 28) | **จะ** (แผน) | 고향에 갈 거예요 *(จะกลับบ้านเกิด)* |
| -고 싶다 (ข้อ 38) | **อยาก** | 고향에 가고 싶어요 *(อยากกลับบ้านเกิด)* |
| -아/어도 되다 *(เสริม — ปรากฏใน 352쪽)* | **ทำได้/อนุญาต** | 여기에 앉아도 돼요? *(นั่งตรงนี้ได้ไหม)* |
| -(으)면 안 되다 *(เสริม)* | **ห้าม** | 앉으면 안 돼요 *(นั่งไม่ได้)* |
| -지 않아도 되다 *(เสริม)* | **ไม่ต้อง** | 안 가도 돼요 *(ไม่ต้องไปก็ได้)* |

- **"ไม่ต้อง" ≠ -아/어야 하다 ปฏิเสธ:** ตำราบท 37 ยังไม่สอนรูปปฏิเสธ (เสริม)
  - △ 안 가야 해요 *(ต้อง "ไม่ไป" = ไม่ควรไป)*
  - ≠ ✓ 안 가도 돼요 *(ไม่ต้องไป)*

#### กับดัก

ตารางนี้รวมรูปที่ถูกและรูปที่ผิดที่พบบ่อย พร้อมเหตุผลสั้น ๆ ส่วนข้อที่ไม่ใช่คู่ ✓/✗ อยู่ในรายการด้านล่าง

| ประเด็น | ✓ ถูก | ✗ ผิด | หมายเหตุ |
|:---|:---|:---|:---|
| ㅏ/ㅗ → 아 | 가야 · 와야 · 사야 · 앉아야 · 받아야 · 살아야 | 가아야 · 오아야 · 살어야 · 받어야 | เคยพลาด 살어요 · 받었어요 — ราก ㅏ ต้อง 아 |
| 하다 → 해 | 공부해야 해요 | 공부하야 해요 · 공부하어야 해요 | รูปเต็มของตำรา: 하여야 → ย่อเป็น 해야 |
| 있다 / 없다 | 있어야 · 없어야 | 있아야 | ㅣ → 어 |
| N이다 | 학생이어야 해요 *(ตัวสะกด → 이어야)* · 의사여야 해요 *(สระ → 여야)* | 학생여야 · 의사이어야 | พูดจริงมักย่อ 학생이어야 → [학쌩이어야] |
| ㅡ / 르 / ㄷ / ㅂ | 써야 · 꺼야 · 불러야 · 들어야 · 도와야 | 쓰어야 · 부르어야 · 듣어야 · 돕아야 | ผันตามกฎก่อนต่อ 아/어 |
| กรรมใช้ 을/를 | 방을 청소해야 해요 · 서울을 안내해야 해요 | 방이 청소해야 해요 | ข้อ 07 — เหมือนกับดัก 가 กับ 받다/듣다 |

- **ผู้ใหญ่เป็นประธาน:** ✓ 어머니가 아프셔서 *(ตำราใช้)* · △ 어머니가 아파서 *(ไม่ยกย่องแม่ — ข้อ 20)*
- **ตอบให้ตรงคำถาม 어떻게 해야 해요?** → ตอบ**วิธี** *(เคยพลาด: 언제 → กิจกรรม สลับกัน)*
  - ✓ 서비스 센터에 가야 해요
  - ✓ 친구에게 부탁해야 해요
  - ✗ 내일 가야 해요 (ตอบเวลา — 언제 ไม่ใช่ 어떻게)
- **เหตุผล + -아/어야 해요:** -아/어서 ใช้กับ**ข้อเท็จจริง** แล้วจบด้วย "ต้อง" ได้ แต่ถ้าจบด้วยคำสั่ง/ชวนต้องใช้ -(으)니까 (ข้อ 50)
  - ✓ 시험이 있어서 공부해야 해요 *(ข้อ 48)*
  - ✓ 시간이 없으니까 빨리 먹어야 해요 *(ข้อ 50)*

> [!TIP] กฎสั้น ๆ
> - **-아/어야 해요 = "ต้อง…"** — เลือก 아/어/해 จากสระราก (ㅏ/ㅗ → 아 · อื่น → 어 · 하다 → 해)
> - N → 이어야/여야 · 있다 → 있어야 · **ภาษาพูด 돼요 = 해요** · เว้นวรรค 해야 해요
> - "ไม่ต้อง" = 안 -아/어도 돼요 ไม่ใช่ ✗ 안 -아/어야 해요

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

-아/어야 하다 ยังไม่เคยออกใน 매일시험 (ยังไม่ยืนยันว่า 매일시험 37과 จะมี) มีแต่ในใบฝึก 37과 ซึ่งผู้เรียนพลาด 1 ช่องจาก 14 และในชุดทบทวนปลายภาคกับ 복습시험④ รายการแยกตามแหล่งที่มา

- **연습지 37 (17 พ.ย.) หน้า 4:** ตาราง 12 กริยา/คำคุณศัพท์ + นาม 2 คำ ถูก 13/14
  - 봐야 · 알아야 · 받아야 · 켜야 · 줘야 · 읽어야 · 기다려야 · 말해야 ✓ *(ㅏ/ㅗ → -아 · อื่น ๆ → -어 · 하다 → 해)*
  - 빨라야 ✓ *(르 불규칙 · ㅃ คู่)* · 걸어야 ✓ *(ㄷ → ㄹ)* · 도와야 ✓ *(ㅂ → 와)* · 커야 ✓ *(ㅡ หลุด)*
  - 학교여야 해요 ✓ *(นามจบสระใช้ 여야)*
  - 교실이야 해요 ✗ → **교실이어야 해요** *(ตรวจเอง — ทิ้ง 어 กลายเป็น 교실이야 ภาษากันเอง)*
- **워크북 37과:** ส่วน D E F เป็น -아/어/여야 하다 (E ข้อ 1 = 숙제가 많아서 … · F = ซื้อของขวัญที่ร้าน) สแกนเป็นหน้าเปล่า ไม่มีบันทึกการตรวจ
- **ชุดทบทวนปลายภาค (เฉลยเป็นของ AI ไม่ใช่ของครู):** ข้อ 6-14 *(아니요, 갈 수 없어요. … -아/어/여야 해요)* → 숙제를 해야 해요 ✓ *(ตัวอย่างตอบ — เหตุผลที่ไปไม่ได้)*
- **대화 37-1 ในตำรา:** 고향에서 친구가 와서 공항에 가야 해요 *(เพื่อนมาจากบ้านเกิดเลยต้องไปสนามบิน)* — ประโยคที่ใช้ -아/어야 해요 ในบทสนทนาโทรศัพท์ของบทนี้

- ข้อ 38 (อยาก ↔ ต้อง)

> [!SUMMARY] สรุป
> - -아/어야 해요 = "ต้อง…": เลือก 아/어/해 จากสระราก (ㅏ/ㅗ → 아 · อื่น → 어 · 하다 → 해) แล้วต่อ 하다 (ภาษาพูด 되다)
> - N이다: ตัวสะกด → **N이어야** · สระ → **N여야** · 있다/없다 → **있어야/없어야** · คำคุณศัพท์ใช้ได้ (좋아야)
> - "ไม่ต้อง" ใช้ 안 -아/어도 돼요 ไม่ใช่ 안 -아/어야 해요 · เหตุผลนำหน้าด้วย -아/어서 หรือ -(으)니까
> - ที่ต้องระวัง: ㅏ + 어 ✗ (살어야) · ติดกัน ✗ (해야해요) · ตอบเวลาแทนวิธีเมื่อถูกถาม 어떻게 해야 해요?
