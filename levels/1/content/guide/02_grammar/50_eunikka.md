## 50. -(으)니까 (…นะ / เพราะ…เลย — เหตุผลที่ผู้พูดยกเพื่อสั่ง · แนะนำ · ชวน)

> [!INTRO] ข้อนี้คืออะไร
> -(으)니까 ต่อท้ายรากของ**กริยา คำคุณศัพท์ และ N이다** เพื่อบอก**เหตุผลหรือหลักฐานที่ผู้พูดยกขึ้นมา** แล้วตามด้วย**คำสั่ง คำแนะนำ หรือคำชวน**ที่ตั้งอยู่บนเหตุผลนั้น เช่น "ฝนตกอยู่ เตรียมร่มไปนะ" ต่างจาก -아/어서 ที่ใช้ได้แค่บอกเหตุผลตามธรรมชาติ
>
> สอนในบท 30 (ตำราหน้า 300 준비 2 และหน้า 301 연습) ตำราอ้างว่า "Related grammar -아/어/여서¹: Lesson 29" ต่อยอดจากข้อ 48 (-아/어서) ข้อ 20 (-(으)세요) ข้อ 33 (-(으)ㄹ까요?) ข้อ 06 (หารากศัพท์) และข้อ 35 (ㄹ ตกก่อน ㄴ)
>
> ไปใช้ต่อในบท 31 (안내 방송을 하니까 잘 들으세요 · 버스가 싸니까 버스로 가세요) ข้อ 39 (-지 마세요 ตามหลัง -(으)니까) และข้อ 55 (-(으)면)

### 📌 รูปแบบและเงื่อนไข

ให้ตัด 다 ออก แล้วดูพยางค์สุดท้ายของราก กฎเดียวกับ -(으)세요 (ข้อ 20) คือ**มีตัวสะกดให้ใส่ 으**

| รากศัพท์ลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| ไม่มีตัวสะกด | **-니까** | 막히다 → **막히니까** · 오다 → **오니까** · 보다 → **보니까** |
| มีตัวสะกด (รวม 있다/없다) | **-으니까** | 없다 → **없으니까** · 닫다 → **닫으니까** · 좋다 → **좋으니까** |
| ลงท้าย **ㄹ** | **ตัด ㄹ + -니까** | 멀다 → **머니까** · 만들다 → **만드니까** · 살다 → **사니까** |
| **ㅂ 불규칙** (ข้อ 37) | ㅂ → **우** + 니까 | 덥다 → **더우니까** · 뜨겁다 → **뜨거우니까** · 시끄럽다 → **시끄러우니까** |
| **ㄷ 불규칙** (ข้อ 51) | ㄷ → ㄹ + 으니까 | 듣다 → **들으니까** · 걷다 → **걸으니까** |
| **นาม** (이다) | ตัวสะกด → **-이니까** · สระ → **-니까** | 생일**이니까** · 서류**니까** |
| มีกาล | -았/었/였**으니까** · -(으)ㄹ **거니까** | 읽**었으니까** · 올 **거니까** |

#### ตารางผันที่ควรจำ (ตำรา 30과 + 31과)

ตารางนี้รวมคำที่ตำราใช้ในข้อนี้ทั้งหมด จัดตามกฎข้างบน ช่อง "ความหมาย" แปลเป็นรูป "เพราะ…"

| 기본형 | -(으)니까 | ความหมาย | กฎที่ใช้ |
|:---|:---|:---|:---|
| 막히다 | **막히니까** | เพราะรถติด | ไม่มีตัวสะกด |
| 오다 | **오니까** | เพราะฝนตก | ไม่มีตัวสะกด |
| 보다 | **보니까** | เพราะดู | ไม่มีตัวสะกด |
| 기다리다 | **기다리니까** | เพราะรอ | ไม่มีตัวสะกด |
| 모르다 | **모르니까** | เพราะไม่รู้ | ไม่มีตัวสะกด |
| 없다 | **없으니까** | เพราะไม่มี | มีตัวสะกด |
| 있다 | **있으니까** | เพราะมี | มีตัวสะกด |
| 닫다 | **닫으니까** | เพราะปิด | มีตัวสะกด |
| 좋다 | **좋으니까** | เพราะดี | มีตัวสะกด |
| 멀다 | **머니까** | เพราะไกล | ㄹ หลุดหน้า ㄴ (ข้อ 35) |
| 만들다 | **만드니까** | เพราะทำ | ㄹ หลุดหน้า ㄴ |
| 살다 | **사니까** | เพราะอยู่ | ㄹ หลุดหน้า ㄴ |
| 알다 | **아니까** | เพราะรู้ | ㄹ หลุดหน้า ㄴ |
| 덥다 | **더우니까** | เพราะร้อน | ㅂ → 우 |
| 뜨겁다 | **뜨거우니까** | เพราะร้อน (ของเหลว) | ㅂ → 우 |
| 시끄럽다 | **시끄러우니까** | เพราะเสียงดัง | ㅂ → 우 |
| 듣다 | **들으니까** | เพราะฟัง | ㄷ → ㄹ |
| 걷다 | **걸으니까** | เพราะเดิน | ㄷ → ㄹ |
| 생일 + 이다 | **생일이니까** | เพราะเป็นวันเกิด | นาม + ตัวสะกด |
| 서류 + 이다 | **서류니까** | เพราะเป็นเอกสาร | นาม + สระ |
| 읽다 + 았/었 | 읽**었으니까** | เพราะอ่านแล้ว | ใส่กาล |
| 오다 + (으)ㄹ 거 | 올 **거니까** | เพราะจะมา | ใส่กาล |

#### ตำราหน้า 300 และข้อควรจำ

ตำราบอกว่าประโยคหน้าเป็นเหตุหรือหลักฐานของประโยคหลัง และต่างจาก -아/어서 ตรงที่ใส่ตัวบอกกาลได้ ส่วนประโยคหลังใช้ได้หลายแบบ

- **ตำรา 300쪽:** ต่อหลังรากกริยา/คำคุณศัพท์ บอกว่าประโยคหน้าเป็นเหตุหรือหลักฐานของประโยคหลัง
  - รากมีตัวสะกด → -으니까 · สระ → -니까
  - ต่อหลังนาม: ตัวสะกด → 이니까 · สระ → -니까
  - **ใส่ตัวบอกกาลได้**
- **ประโยคหลังที่ใช้ได้:**
  - -(으)세요 (สั่ง/แนะนำ)
  - -(으)ㄹ까요? / -아/어요 / -(으)ㅂ시다 (ชวน)
  - -지 마세요 (ห้าม ข้อ 39)
  - ประโยคบอกเล่าทั่วไป
- **ร่วมกับ 거예요:** -(으)ㄹ 거 + 이다 → 거니까
  - 여러 나라 학생들이 많이 **올 거니까** 꼭 오세요 *(ตำรา 31과 — "เพราะจะมาหลายประเทศ")*

#### ออกเสียง (ตำรา 300쪽)

คำที่ลงท้ายด้วย -(으)니까 มีกฎออกเสียงควบที่ตำราหน้า 300 ยกมาเป็นตัวอย่างสองคำ

| เขียน | อ่านว่า | กฎ |
|:---|:---|:---|
| 막히니까 | [마키니까] | ㄱ + ㅎ ควบเป็น [ㅋ] |
| 없으니까 | [업쓰니까] | ㅂ ท้าย + ㅅ → [ㅆ] |

#### สูตรและวิธีทำ: -(으)니까 (แบบกระดานครู)

-(으)니까 ต่อท้ายรากของกริยา คำคุณศัพท์ หรือนาม + 이다 และเป็นคำต่อที่ขึ้นต้นด้วย (으) กับ ㄴ ดังนั้นต้องทำสองอย่างตามลำดับ คือตัดสินว่าจะเก็บ 으 ไหม แล้วดูว่า ㄴ ทำให้ราก ㄹ หรือ ㅂ เปลี่ยนไหม

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | รากไม่มีตัวสะกด | ตัด 으 ต่อ **니까** | ไม่มีตัวสะกดก็ไม่ต้องใช้ 으 เชื่อม |
| **กฎ 2** | รากมีตัวสะกด (รวมรากที่ลงท้าย ㅆ เพราะมี 았/었/겠) | เก็บ 으 ต่อ **으니까** | ต้องมี 으 (✗ 없니까 · ✗ 읽니까) |
| **กฎ 3** | รากลงท้าย ㄹ | ตัด 으 แล้ว **ตัด ㄹ ของราก** ต่อ 니까 | 니까 ขึ้นต้นด้วย ㄴ ซึ่งทำให้ ㄹ หลุด (사니까 · 만드니까 · 머니까) |
| **กฎ 4** | รากเป็น ㅂ 불규칙 | ㅂ หลุด ใส่ **우** แทน 으 แล้วต่อ 니까 | ㅂ เปลี่ยนเมื่อมี (으) ตามหลัง (더우니까) |

ลำดับทำคือ ① ดูตัวสะกดของรากแล้วตัดสินว่าเก็บหรือตัด 으 ② ถ้าตัด 으 แล้วรากลงท้าย ㄹ ให้ตัด ㄹ ถ้าเป็น ㅂ 불규칙 ให้ใช้ 우 ③ ต่อ 니까 หรือ 으니까 ตารางนี้แสดงทุกขั้นกับคำที่ตำราใช้ ส่วนนามให้ต่อ 이니까 เมื่อมีตัวสะกดและ 니까 เมื่อไม่มี

| ราก + (으)니까 | ① ตัวสะกด / 으 | ② ตัด ㄹ / ปรับ ㅂ | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 막히 + (으)니까 | ไม่มี ตัด 으 | ไม่ปรับ | **막히니까** | อ่าน [마키니까] |
| 오 + (으)니까 | ไม่มี ตัด 으 | ไม่ปรับ | **오니까** | 비가 오니까 *(เพราะฝนตก)* |
| 없 + (으)니까 | มี เก็บ 으 | ไม่ปรับ | **없으니까** | ✗ 없니까 · อ่าน [업쓰니까] |
| 읽 + (으)니까 | มี เก็บ 으 | ไม่ปรับ | **읽으니까** | ✗ 읽니까 ลืม 으 เหมือน ✗ 읽세요 |
| 좋 + (으)니까 | มี เก็บ 으 | ไม่ปรับ | **좋으니까** | ✗ 좋니까 |
| 읽 + 었 + (으)니까 | ลงท้าย ㅆ จึงมีตัวสะกด เก็บ 으 | ไม่ปรับ | **읽었으니까** | ใส่กาลได้ ต่างจาก -아/어서 |
| 오 + ㄹ 거 + (이)니까 | 거 เป็นนาม ไม่มีตัวสะกด ตัด 이 | ไม่ปรับ | **올 거니까** | ตำรา 31과 *(เพราะจะมา)* |
| 만들 + (으)니까 | ㄹ ตัด 으 | ตัด ㄹ ของราก | **만드니까** | ✗ 만들으니까 เหมือน ✗ 만들으세요 |
| 살 + (으)니까 | ㄹ ตัด 으 | ตัด ㄹ ของราก | **사니까** | ㄹ หลุดแบบเดียวกับ 만드니까 |
| 멀 + (으)니까 | ㄹ ตัด 으 | ตัด ㄹ ของราก | **머니까** | ✗ 멀으니까 |
| 덥 + (으)니까 | ㅂ 불규칙 | ㅂ หลุด ใส่ 우 แทน 으 | **더우니까** | ✗ 덥으니까 |
| 가깝 + (으)니까 | ㅂ 불규칙 | ㅂ หลุด ใส่ 우 แทน 으 | **가까우니까** | ㅂ 불규칙 (23과 · ข้อ 37) |
| 생일 + (이)니까 | นามมีตัวสะกด เก็บ 이 | ไม่ปรับ (ㄹ ของนามไม่ตก) | **생일이니까** | ✗ 생일니까 ตำรา 300쪽 |
| 서류 + (이)니까 | นามไม่มีตัวสะกด ตัด 이 | ไม่ปรับ | **서류니까** | ✗ 서류이니까 |

> [!TIP] วิธีจำสั้น ๆ
> ดูตัวสะกดก่อน ไม่มีใช้ 니까 มีใช้ 으니까 (กาล 았/었/겠 นับว่ามีตัวสะกด) แล้วถามต่อว่ารากเป็น ㄹ ไหม ถ้าใช่ ㄹ หลุดเพราะ ㄴ ถ้าเป็น ㅂ 불규칙 ใช้ 우 แทน 으

#### ผันคำเดียวครบทุกคำต่อ

ตารางนี้ผันกริยา ㄹ คำเดียวกับคำต่อ 5 ตัว (4 ตัวหลังเรียนมาแล้ว) จะเห็นว่า 니까 เข้ากลุ่มเดียวกับ ㄴ ㅂ ㅅ ㄹ ที่ทำให้ ㄹ หลุด ส่วน -(으)러 ที่ขึ้นต้นด้วย ㄹ ไม่ใช่ ㄴ ㅂ ㅅ จึงเก็บ ㄹ ไว้ (ข้อ 40)

| กริยา | -(으)니까 | -(으)세요 | -(스)ㅂ니다 | -(으)ㄹ 거예요 | -(으)러 가요 |
|:---|:---|:---|:---|:---|:---|
| 만들다 | **만드**니까 | **만드**세요 | **만듭**니다 | **만들** 거예요 | 만들러 가요 |
| 살다 | **사**니까 | **사**세요 | **삽**니다 | **살** 거예요 | 살러 가요 |
| 놀다 | **노**니까 | **노**세요 | **놉**니다 | **놀** 거예요 | 놀러 가요 |

### 📖 ตัวอย่างและการใช้

ตัวอย่างเรียงตามลำดับในตำราบท 30 และต่อด้วยบท 31 ซึ่งยังใช้ -(으)니까 อยู่ สังเกตว่าประโยคหลังเป็นคำสั่ง คำแนะนำ หรือคำชวนแทบทุกประโยค ตรงข้ามกับ -아/어서

| 감기에 **걸렸으니까** 아이스크림을 먹지 마세요. | เป็นหวัด อย่ากินไอศกรีม | 연습 2 (จับคู่เอง) |
| 4시에 문을 **닫으니까** 빨리 가세요. | ปิด 4 โมง รีบไปเถอะ | 대화 30-1 |
| 오후보다 저녁에 경치가 더 **좋으니까** 저녁에 가세요. | เย็นวิวสวยกว่าช่วงบ่าย ไปตอนเย็นนะ (เปรียบเทียบ -보다 ข้อ 41) | 읽기 30-2 |
| 안국동에서 내리세요. 안내 방송을 **하니까** 잘 들으세요. | ลงที่อันกุกดง มีประกาศเสียงตามสาย ฟังดี ๆ นะ | 대화 31-1 |
| 그런데 버스가 **싸니까** 버스로 가세요. | แต่รถเมล์ถูก ไปรถเมล์เถอะ | 활동 31 |
| 아래 초대장을 같이 **보내니까** 보고 오세요. | ส่งบัตรเชิญมาด้วย ดูแล้วมานะ | 읽기 31-2 |

연습 2 ให้จับคู่เหตุกับคำสั่งจากสองกล่อง ตัวอย่างแรก (비가 오니까 우산을 준비하세요) เป็นของตำรา ส่วนที่เหลือจับคู่ตามความหมาย

#### ถาม-ตอบ

คำถามที่เป็นคำชวนหรือขอความเห็น ตอบด้วยเหตุผล -(으)니까 ตามด้วยคำสั่งหรือคำแนะนำ

| ที่มา | คำถาม/คำชวน | คำตอบ (เหตุผล → คำสั่ง) |
|:---|:---|:---|
| 준비 2 | 택시를 탈까요? | 출근 시간에는 길이 **막히니까** 지하철을 타세요. *(นั่งแท็กซี่ดีไหม — ช่วงเวลาไปทำงานรถติด นั่งรถไฟใต้ดินเถอะ)* |
| 연습 3 | 우리 등산을 할까요? | 비가 **오니까** 영화를 봐요. 어때요? — 좋아요. *(ไปเดินป่ากันไหม — ฝนตกอยู่ ดูหนังกันเถอะ เป็นไง — ดีเลย)* |

### ⚠️ จุดสับสน

ความสับสนหลักคือ -(으)니까 กับ -아/어서 ที่แปลว่า "เพราะ" เหมือนกันแต่ใช้ในประโยคต่างชนิดกัน ถัดมาเป็นข้อผิดเรื่องตัวสะกด ㄹ ㅂ ㄷ 르 และนาม

#### -(으)니까 vs -아/어서 (ข้อ 48)

ตารางนี้เทียบเงื่อนไขการใช้ วิธีแยกที่เร็วที่สุดคือดูว่าประโยคหลังเป็นคำสั่ง ชวน หรือห้ามหรือไม่

| | **-(으)니까** | **-아/어서** |
|:---|:---|:---|
| ประโยคหลัง = คำสั่ง · ชวน · ห้าม | ✓ | ✗ |
| ใส่ -았/었- ในประโยคหน้า | ✓ 읽었으니까 | ✗ |
| ใส่ -겠- / -(으)ㄹ 거 ในประโยคหน้า | ✓ 올 거니까 | ✗ |
| ตอบ 왜? | ไม่ใช่รูปมาตรฐาน | ✓ |
| ขอโทษ/ขอบคุณ | ✗ | ✓ 늦어서 죄송합니다 |
| น้ำเสียง | "ฉันบอกเหตุผลให้คุณทำตาม" | "เหตุเกิด ผลเลยเป็นอย่างนั้น" |

- ประโยคหลังเป็นคำสั่ง ต้องใช้ -(으)니까 (ตำรา 288쪽: ประโยคหลังของ -아/어서 ห้ามเป็นคำสั่ง/ชวน)
  - ✓ 비가 **오니까** 우산을 가지고 **가세요**
  - ✗ 비가 와서 우산을 가지고 가세요
- เทียบรูปเดียวกันในสองสถานการณ์
  - ✓ 시간이 **없으니까** 택시를 **타요** *(ชวน/แนะนำให้ทำ)*
  - ✓ 시간이 **없어서** 택시를 **탔어요** *(เล่าเหตุผลที่ทำไปแล้ว)*
- กฎจำง่าย: ดูท้ายประโยค
  - ท้ายประโยคเป็น -(으)세요 / -(으)ㅂ시다 / -(으)ㄹ까요? / 지 마세요 → **-(으)니까**
  - ท้ายเป็นเล่าเรื่อง/ถามเหตุผล/ขอโทษ/ขอบคุณ → **-아/어서**

#### กับดัก

ข้อผิดที่เจอบ่อยเกือบทั้งหมดเป็นเรื่องรูปสะกดเมื่อรากเป็น ㄹ ㅂ ㄷ 르 หรือนาม ไล่ดูทีละข้อ

- **ลืม 으 หลังตัวสะกด** *(ข้อผิดซ้ำ: 읽세요 · 받십니다 · 씻러 — ลืม 으 หลัง 받침 ทุกครั้ง)*
  - ✗ 없니까 → ✓ **없으니까**
  - ✗ 읽니까 → ✓ **읽으니까**
  - ✗ 앉니까 → ✓ **앉으니까**
  - ✗ 좋니까 → ✓ **좋으니까**
- **ㄹ-ราก:** ㄹ หลุดก่อน ㄴ/ㅂ/ㅅ *(ผู้เรียนเคยเขียน 만들으세요 · 만들습니다 ผิด)*
  - ✗ 멀으니까 → ✓ **머니까**
  - ✗ 만들으니까 → ✓ **만드니까**
- **ㅂ-ราก:** (ข้อ 37)
  - ✗ 덥으니까 → ✓ **더우니까**
  - ✗ 뜨겁으니까 → ✓ **뜨거우니까**
- **ㄷ-ราก:** (ข้อ 51)
  - ✗ 듣으니까 → ✓ **들으니까**
  - ✗ 걷으니까 → ✓ **걸으니까**
  - ✓ 닫으니까 *(닫다 ปกติ ไม่เปลี่ยน)*
- **르-ราก ไม่เปลี่ยนก่อน 니까:** ✓ **모르니까** (길을 모르니까 물어보세요) / ✗ 몰라니까 · ✗ 몰르니까 *(เทียบ -아/어서: 몰라서 — ข้อ 54)*
- **นาม:**
  - ✗ 생일니까 → ✓ **생일이니까**
  - ✗ 서류이니까 → ✓ **서류니까**
  - ปฏิเสธ: ✓ 학생이 **아니니까** *(ไม่ใช่นักเรียน เพราะ…)*
- **-ㅂ니까 (ถาม ข้อ 21) ≠ -(으)니까 (เหตุผล):**
  - 먹습니까? *(กินไหม — จบประโยค)*
  - 먹으니까 *(เพราะกิน — ต่อประโยคต่อไป)*
  - ผู้เรียนเคยปน 니다/니까 เวลาแปลงประโยค — ดูเครื่องหมายท้ายประโยคก่อน
- **ตอบสั้นลงท้าย 요 (เสริม — ตำรายังไม่สอน):** 왜 서둘러요? — 시간이 없으니까요. *(ทำไมรีบ — ก็ไม่มีเวลานี่นา)* เป็นน้ำเสียง "ก็เพราะ…ไง" ในภาษาพูด

> [!TIP] กฎสั้น ๆ
> **-(으)니까 = เหตุผลที่ "คุณ" ควรทำตาม (สั่ง/ชวน/ห้าม)** · **-아/어서 = เหตุผลธรรมดา**
>
> **ตัวสะกด→으니까 สระ→니까** · **ㄹ ตก ㅂ→우** · **N이니까/N니까**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ข้อนี้ออกจริงแค่ช่อง 니까 ของตาราง 르 ใน 매일시험 32과 ส่วน 매일시험 30과 (9 พ.ย.) ไม่มี -(으)니까 เลย ที่เหลือเป็นใบฝึกกับชุดทบทวน และ 복습시험④ (18 พ.ย.) ผลยังไม่ออก ดู KMU_Predict_miniexam04.pdf

- **매일시험 32과 (11 พ.ย.):** ช่อง 니까 ของตาราง 르 → 부르니까 ✓ · 바르니까 ✗ → **빠르니까** (ผันถูกแต่เป็นคำผิด)
- **연습지 30 (5 พ.ย. · ตารางผัน 16 ช่อง ถูกครบ):**
  - 가니까 · 공부하니까 · 먹으니까 · 읽으니까 · 크니까 · 빠르니까 · 좋으니까 · 재미있으니까 ✓
  - 추우니까 · 어려우니까 · 머니까 · 기니까 · 만드니까 · 주말이니까 · 방학이니까 · 친구니까 ✓
- **연습지 31 หน้า 3:** กรอบตัวอย่าง 버스가 싸니까 버스로 가세요 · 지하철이 빠르니까 지하철로 가세요 (ยังไม่เขียน)
- **워크북 30과:** E ตาราง · F เติมเหตุผล · G ถามอยากทำอะไร · H แผนที่ถามหา 미용실 · ยังไม่มีบันทึกของผู้เรียน
- **ชุดทบทวนปลายภาค (เฉลยเป็นของ AI):**
  - ข้อ 3-7 아기가 자요 / 조용히 하세요 → 아기가 자니까 조용히 하세요
  - ข้อ 4-6 길이 (막혀서, 막히니까) 지하철을 타세요 → **막히니까**
  - ข้อ 4-8 제주도는 너무 (멀어서, 머니까) 남이섬에 가요 → **머니까**
  - 말하기 23 พ.ย. ข้อ 12 우리 등산을 할까요? · 우리 영화를 볼까요?
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ:** 멀서 ✗ → 멀어서 (매일시험 29 · -아/어서 ไม่ตัด ㄹ แต่ -(으)니까 ตัด) · ปน 니다/니까 · ตอบผิดคำถาม (언제 → กิจกรรม)
