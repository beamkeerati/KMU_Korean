## 44. -는 (กริยาขยายคำนาม ปัจจุบัน: 좋아하는 계절 · 자주 먹는 음식 — "ที่…")

> [!INTRO] ข้อนี้คืออะไร
> -는 ต่อท้ายรากของ**กริยา** (และ **있다 / 없다**) เพื่อให้ไปขยาย**คำนามที่ตามมา** บอกว่าการกระทำนั้น**เกิดอยู่หรือทำเป็นประจำ** ใช้แทนคำว่า "ที่" ของภาษาไทย เช่น "อาหารที่คนเกาหลี**กิน**บ่อย" = 한국 사람들이 자주 **먹는** 음식
>
> สอนในบท 27 (ตำรา 272–273쪽 준비 2) ต่อยอดจากข้อ 36 (-(으)ㄴ ของคำคุณศัพท์) ข้อ 06 (กริยา) ข้อ 07 (을/를) และข้อ 35 (ตาราง ㄹ-ราก) แล้วไปใช้ต่อในข้อ 59 (-는 것 ที่ทำกริยาให้เป็นนาม) ข้อ 47 (-(으)ㄴ กริยาอดีต) ข้อ 56 (-(으)ㄹ อนาคต และตารางสรุป) ข้อ 45 (눈이 오는 날이 제일 좋아요) และข้อ 51 (듣는 ที่ ㄷ ไม่เปลี่ยนหน้า ㄴ)

### 📌 รูปแบบและเงื่อนไข

ตำรา 272쪽 บอกว่า -는 ต่อหลัง**กริยา**หรือ **있다/없다** เพื่อขยายคำนามที่ตามมา บอกว่าการกระทำนั้น**กำลังเกิดอยู่ในขณะนั้น หรือเกิดพร้อมกับกริยาหลักของประโยค**

ตารางนี้แยกตามชนิดของราก ช่องว่างในสองคอลัมน์แรกหมายความว่ายังเป็นกรณีเดียวกับแถวบน

#### โครงประโยค

อนุประโยคขยายคำนามเกาหลีวางอยู่**หน้า**คำนามเสมอ ต่างจากภาษาไทยที่วางนามนำแล้วตามด้วย "ที่"

- โครง: [ประธาน-이/가] + (เวลา) + (กรรม-을/를) + กริยา-는 + นาม
- ตัวอย่าง: 한국 사람들**이** 여름에 자주 **먹는** 음식 *(อาหารที่คนเกาหลีกินบ่อยในหน้าร้อน)*
- ประธานในอนุประโยคใช้ **이/가** (한국 사람들**이** · 제**가**) และถ้าประธานเป็นคนเดียวกับประโยคหลักก็ละได้
- ไม่ดูตัวสะกด เหมือน -고 · -겠- · -지만 ลงท้ายสระหรือพยัญชนะก็ **-는** ตัวเดียว

#### การออกเสียง (ตำรา 272쪽)

ตัวสะกดเสียงกลายเป็นนาสิกเมื่อตามด้วย ㄴ (ㄱ→ㅇ · ㄷ→ㄴ · ㅂ→ㅁ) จึงอ่านต่างจากที่เขียน

| คำ | อ่านว่า |
|:---|:---|
| 먹는 | [멍는] |
| 듣는 | [든는] |
| 있는 | [인는] |
| 읽는 | [잉는] |
| 입는 | [임는] |

#### สูตรและวิธีทำ: -는 กริยาขยายนาม (แบบกระดานครู)

-는 ต่อท้ายรากของกริยาหรือ 있다/없다 โดยตรง สิ่งที่ต้องดูมีสองอย่างคือรากเป็นคำชนิดไหน และรากลงท้าย ㄹ หรือไม่ เพราะ 는 ขึ้นต้นด้วย ㄴ ซึ่งทำให้ ㄹ หลุด

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | รากเป็นกริยา หรือเป็น 있다/없다 (รวม 맛있다 · 재미없다) | ราก + **는** ไม่ว่ามีตัวสะกดหรือไม่ | 는 ขึ้นต้นด้วยพยัญชนะ จึงไม่ต้องมี 으 (✗ 먹으는) |
| **กฎ 2** | รากลงท้าย ㄹ | **ตัด ㄹ** ของรากทิ้ง แล้วต่อ 는 | ㄹ ไม่อยู่หน้า ㄴ (ข้อ 40) |
| **กฎ 3** | รากเป็น ㅂ 불규칙 | **ไม่เปลี่ยน** ㅂ แล้วต่อ 는 | ㅂ → 우 เกิดหน้าสระเท่านั้น แต่ 는 ขึ้นต้นด้วยพยัญชนะ |

ลำดับทำคือ ① ดูชนิดคำ ถ้าเป็นคำคุณศัพท์ไม่ใช่ข้อนี้ให้ไปใช้ -(으)ㄴ (ข้อ 36) ② ถ้ารากลงท้าย ㄹ ตัด ㄹ ทิ้ง ③ ต่อ 는 แล้ววางคำนามที่ถูกขยายไว้ข้างหลัง ตารางนี้แสดงทุกขั้นกับคำที่ตำราใช้

| ราก + 는 | ① ชนิดคำ | ② ราก ㄹ? | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 먹 + 는 | กริยา → 는 | ไม่ใช่ | **먹는** | ✗ 먹으는 · อ่าน [멍는] |
| 읽 + 는 | กริยา → 는 | ไม่ใช่ | **읽는** | ✗ 읽으는 · อ่าน [잉는] |
| 마시 + 는 | กริยา → 는 | ไม่ใช่ | **마시는** | ไม่มีตัวสะกดก็ใช้ 는 เหมือนกัน |
| 좋아하 + 는 | กริยา 하다 → 는 | ไม่ใช่ | **좋아하는** | 좋아하다 เป็นกริยา ≠ 좋다 ที่เป็นคำคุณศัพท์ (좋은) |
| 맛있 + 는 | 있다 → 는 | ไม่ใช่ | **맛있는** | ✗ 맛있은 |
| 재미없 + 는 | 없다 → 는 | ไม่ใช่ | **재미없는** | ✗ 재미없은 |
| 만들 + 는 | กริยา → 는 | ใช่ ตัด ㄹ (ตามหลังคือ ㄴ) | **만드는** | ✗ 만들는 |
| 살 + 는 | กริยา → 는 | ใช่ ตัด ㄹ | **사는** | ✗ 살는 |
| 알 + 는 | กริยา → 는 | ใช่ ตัด ㄹ | **아는** | ✗ 알는 |
| 놀 + 는 | กริยา → 는 | ใช่ ตัด ㄹ | **노는** | ✗ 놀는 |
| 돕 + 는 | กริยา ㅂ 불규칙 → 는 | ไม่ใช่ | **돕는** | ㅂ อยู่ ✗ 도우는 |
| 듣 + 는 | กริยา → 는 | ไม่ใช่ | **듣는** | อ่าน [든는] แต่เขียน ㄷ ✗ 든는 |
| 맵 (คำคุณศัพท์) | ไม่ใช่กริยา ✗ 는 | ไม่ใช่ | **매운** | ใช้ -(으)ㄴ ข้อ 36 ✗ 맵는 |

> [!TIP] วิธีจำสั้น ๆ
> กริยาและ 있다/없다 ต่อ 는 ตรง ๆ ไม่ต้องมี 으 ราก ㄹ ตัด ㄹ ก่อน (사는 · 만드는 · 아는) ราก ㅂ ไม่ต้องเปลี่ยน (돕는) ถ้าเป็นคำคุณศัพท์ให้ใช้ -(으)ㄴ แทน

#### รูปผิด / รูปถูก

ตารางนี้รวมรูปผิดของ -는 พร้อมขั้นที่ทำพลาด แถวแรกคือคำที่ผู้เรียนเขียนผิดจริงในข้อสอบ 23과 ส่วนแถวอื่นเป็นรูปผิดที่ตำรากับคู่มือเตือนไว้

| รูปผิด | รูปถูก | ขั้นที่พลาด |
|:---|:---|:---|
| ✗ 영화은 | ✓ **재미있는** 영화 | ① 재미있다 ต้องเปลี่ยนเป็น 는 วางหน้านาม ไม่ใช่เติม 은 หลังนาม *(ข้อสอบ 23과)* |
| ✗ 만들는 | ✓ **만드는** | ② ราก ㄹ ต้องตัดก่อน 는 |
| ✗ 살는 | ✓ **사는** | ② ราก ㄹ ต้องตัดก่อน 는 |
| ✗ 먹으는 | ✓ **먹는** | ③ 는 ไม่ใช้ 으 เชื่อม |
| ✗ 맵는 | ✓ **매운** | ① คำคุณศัพท์ไม่ใช้ 는 |

#### คำถามที่ใช้ -는 บ่อย

ตารางนี้รวมคำถามที่ใช้ -는 พร้อมคำตอบตัวอย่าง ซึ่งเป็นรูปที่น่าเจอทั้งในข้อเขียนและ 말하기

| คำถาม | ตอบ |
|:---|:---|
| 요즘 자주 **듣는** 노래가 뭐예요? | 요즘 자주 듣는 노래는 BTS 노래예요. *(เพลงที่ฟังบ่อยตอนนี้คือเพลงของ BTS)* |
| 한국 사람들이 비 **오는** 날 **먹는** 음식이 뭐예요? | 파전이에요. *(ปาจอน)* |
| **좋아하는** 계절이 뭐예요? | 저는 봄을 좋아해요. *(ชอบฤดูใบไม้ผลิ — 28과 좋아하는 계절)* |
| 지금 교실에 **있는** 사람이 누구예요? | 선생님하고 학생들이에요. *(อาจารย์กับนักเรียน)* |
| 요즘 **배우는** 외국어가 뭐예요? | 한국어예요. *(ภาษาเกาหลี)* |

### ⚠️ จุดสับสน

ข้อผิดหลักของเรื่องนี้คือเลือกรูปขยายนามผิดตามชนิดคำและเวลา และผันรากพิเศษอย่าง ㄹ-ราก ผิด

#### สามรูป ㄴ/는 ขึ้นกับ "ชนิดคำ" และ "เวลา"

ตารางนี้สรุปว่ากริยาและคำคุณศัพท์ขยายนามด้วยรูปไหน ในแต่ละเวลา

| ชนิดคำ | ปัจจุบัน | อดีต | อนาคต |
|:---|:---|:---|:---|
| **กริยา** | **-는** (먹는 음식 — ข้อ 44) | -(으)ㄴ (먹은 음식 — ข้อ 47) | -(으)ㄹ (먹을 음식 — ข้อ 56) |
| **คำคุณศัพท์** | **-(으)ㄴ** (매운 음식 — ข้อ 36) | — | — |
| **있다 / 없다 / -있다** | **-는** (맛있는) | — | — |

- ตารางสรุปครบทั้งสามอยู่ใน **ข้อ 56** (บท 33)
- ตอนนี้ให้จำว่า **กริยา → -는** และ **คำคุณศัพท์ → -(으)ㄴ** และ **있다/없다 → -는**

#### ตาราง ✓/✗ ของ -는

ข้อผิดต่อไปนี้ส่วนใหญ่เป็นข้อผิดที่ผู้เรียนเคยทำหรือน่าจะทำ

| ✗ ผิด | ✓ ถูก | สาเหตุ |
|:---|:---|:---|
| ✗ 만들는 | ✓ **만드는** | ㄹ + ㄴ → ㄹ ตก (ข้อ 40 เสริม) |
| ✗ 살는 | ✓ **사는** | ㄹ ตก |
| ✗ 알는 | ✓ **아는** | ㄹ ตก |
| ✗ 놀는 | ✓ **노는** | ㄹ ตก |
| ✗ 예쁘는 | ✓ **예쁜** | คำคุณศัพท์ใช้ -(으)ㄴ (ข้อ 36) |
| ✗ 매우는 | ✓ **매운** | คำคุณศัพท์ใช้ -(으)ㄴ |
| ✗ 작는 | ✓ **작은** | คำคุณศัพท์ใช้ -(으)ㄴ |
| ✗ 어제 먹는 음식 | ✓ 어제 **먹은** 음식 | อดีตใช้ -(으)ㄴ (ข้อ 47 บท 29) |
| ✗ 먹으는 | ✓ **먹는** | ตัวสะกดไม่ใช่ปัญหา ไม่ต้องมี 으 |
| ✗ 읽으는 | ✓ **읽는** | ไม่ต้องมี 으 |
| ✗ 한국 사람들이 먹는 것 음식 | ✓ 한국 사람들이 **먹는 음식** | ไม่ต้องใส่ "것" ระหว่างอนุประโยคกับนาม |
| ✗ 음식 한국 사람들이 먹는 | ✓ 한국 사람들이 먹는 **음식** | อนุประโยคนำ นามท้าย |
| ✗ 멍는 | ✓ **먹는** | อ่านว่า [멍는] แต่อย่าเขียนตามเสียง |
| ✗ 든는 | ✓ **듣는** | อ่านว่า [든는] แต่อย่าเขียนตามเสียง |

#### กับดักที่ตารางไม่ครอบคลุม

ข้อเหล่านี้ต้องอธิบายด้วยคำพูดมากกว่าจะอยู่ในตารางได้

- **좋은 vs 좋아하는:** ต่างกันที่ชนิดคำ
  - 좋다 (คำคุณศัพท์) → **좋은** 사람 *(คนดี)*
  - 좋아하다 (กริยา) → **좋아하는** 사람 *(คนที่ชอบ)*
  - ✗ 좋아한 / 좋아은 / 좋은 สำหรับ "ที่ชอบ" ตำราบท 28 ชื่อ "좋아하는 계절"
  - 싫다 → 싫은 และ 싫어하다 → **싫어하는**
- **ㄹ-ราก:** ผู้เรียนเคยพลาด 만들습니다 / 만들으세요 ซึ่งตกที่ ㄹ-ราก เหมือนกัน
- **-는 กับคำคุณศัพท์:** ยกเว้นคำที่ลงท้าย 있다/없다 ซึ่ง **ต้อง** ใช้ -는 (맛있는 · 재미있는)
- **-는 กับอดีต:** -는 ใช้กับเรื่องที่เป็นประจำหรือเกิดขึ้นในขณะนั้น
- **-는 (ขยายนาม) ≠ -는데 (ลงท้าย บท 36 — ข้อ 61)**
- **-는 것 (ข้อ 59)** = ทำกริยาให้เป็นนาม: 단어를 외우**는 것**이 힘들었어요 *(การท่องศัพท์เป็นเรื่องยาก)*

> [!TIP] กฎสั้น ๆ
> - **กริยา → ราก + 는** (ㄹ-ราก ตัด ㄹ และ ㄷ อยู่)
> - **있다/없다 → 는** และ **คำคุณศัพท์ → (으)ㄴ** (ข้อ 36)
> - "ที่" ของไทย = วางอนุประโยคไว้**หน้า**นาม

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

-는 (กริยา + นาม) ออกสอบจริงแล้วทั้งใน 매일시험 27과 และ 복습시험③ ข้อผิดที่เกิดซ้ำคือใส่ 이/가 ให้กรรมในวลีขยาย และเอา -는 ไปใส่กับคุณศัพท์

- **매일시험 27과 (3 พ.ย. · ได้ 7.5/10):** ส่วน A ภาพ "ใครคือใคร" (보기 운동하는 사람이 윤아 씨입니다) ได้ครึ่งทั้ง 4 ข้อ
  - 책이 읽는 ✗ → **책을 읽는**
  - 주스가 마시는 ✗ → **주스를 마시는**
  - 음식이 먹는 ✗ → **음식을 먹는**
  - 한국어가 공부하는 ✗ → **한국어를 공부하는**
  - ส่วน C ข้อ 9: 자주 입는 옷이에요 ✓
- **연습지 27과 (2 พ.ย.):** ตาราง -는 ถูก 22 ใน 24 ช่อง
  - ข้อ 17 팔는 ✗ → **파는** (ㄹ หลุดก่อน ㄴ)
  - ข้อ 24 정소하는 ✗ → **청소하는**
  - ข้อ 13 듣는 ✓ (ㄷ ไม่เปลี่ยนก่อน ㄴ)
- **워크북 27과 C–E (รูปถ่าย 2 พ.ย.):** ตาราง -는 ถูกครบ (사는 · 만드는 · 여는)
  - E2 음식를 ✗ → **음식을**
  - E ตอบกว้างกว่าภาพ (음식을 먹는 แทน 빵을 먹는)
- **복습시험③ (6 พ.ย.):** 쓰기 ตอน 4
  - ข้อ 1–3: 지금 **부르는** ✓ · 어제 **읽은** ✓ · 자주 **먹는** ✓
  - ข้อ 4–5: 작는 ✗ → **작은** · 예쁘는 ✗ → **예쁜** (เสีย 6 คะแนน)
- **ชุดทบทวนปลายภาค:** ข้อ 5-2 ถึง 5-4 และ 5-8 ถึง 5-10 (제가 자주 듣는 음악 · 아는 친구)
  - ตัดคำนามที่ซ้ำออก (✗ 음식을 좋아하는 음식)
  - final02 ★ กรรมใช้ 을/를 แม้อยู่ในวลีขยาย
- **ข้อผิดกลุ่มเดียวกันที่เคยเจอ:**
  - 다르는 · 빠르는 ✗ → **다른 · 빠른** (워크북 32과)
  - 좋아 안 해요 ✗ → **안 좋아해요** (좋아하다 เป็นกริยาเดียว → 좋아하는)
  - ★ ลืม/ใส่ 으 ผิดที่ · ㄹ-ราก: 만들습니다 ✗ → 만듭니다
