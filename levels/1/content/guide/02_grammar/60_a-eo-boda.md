## 60. -아/어/여 보다 (ลอง… · เคย…)

> [!INTRO] ข้อนี้คืออะไร
> -아/어/여 보다 คือการต่อ **보다** ท้ายรากกริยา (ตำราเรียกว่า trial of an action or past experience) มีสองความหมาย ความหมายแรกคือ**ลองทำ** เช่น 먹어 **보세요** *(ลองกินดูสิ)* หรือ 가 **보고 싶어요** *(อยากลองไป)* ความหมายที่สองคือ**เคยทำ (ประสบการณ์)** เช่น 가 **봤어요?** *(เคยไปไหม)* หรือ 안 가 **봤어요** *(ไม่เคยไป)*
>
> สอนในบท 35 (교과서 346–347쪽 · 준비 2) ต่อยอดจาก ข้อ 06 (-아/어요 — กฎ ㅏ/ㅗ → 아 · อื่น → 어 · 하다 → 해) ข้อ 23 (-았/었어요) ข้อ 08 (안) และ ข้อ 20 (-(으)세요)
>
> ไปใช้ต่อใน ข้อ 38 (-고 싶다: 가 보고 싶어요) · ข้อ 55 (…가 보면) · ข้อ 63 (-아/어/여 주세요 ที่ดูคล้ายกัน) และ 활동 บท 35 (몽골에 가 보고 싶어요)

### 📌 รูปแบบและเงื่อนไข

เลือก 아/어/여 จาก**สระของพยางค์สุดท้ายของราก** เหมือนการผัน -아/어요 (ข้อ 06) แล้วตามด้วย **보다** ซึ่งผันตามปกติ เช่น 봐요 · 봤어요 · 보세요 · 보고 싶어요 ตารางแรกสรุปกฎ โดยครูแยกคอลัมน์ "เคย" (…봤어요) กับ "แนะนำให้ลอง" (…보세요) ไว้ให้บนสไลด์ 346쪽 ตารางที่สองให้ตัวอย่างของรากแต่ละแบบ

| สระพยางค์สุดท้ายของราก | ต่อ | เคย (ประสบการณ์) | แนะนำให้ลอง |
|:---|:---|:---|:---|
| **ㅏ · ㅗ** | **-아 보다** | -아 봤어요 | -아 보세요 |
| สระอื่น | **-어 보다** | -어 봤어요 | -어 보세요 |
| **하다** | **해 보다** (하여 → 해) | 해 봤어요 | 해 보세요 |
| ㅡ-ราก | ㅡ หลุด | — | — |
| ㄷ · ㅂ · 르 ไม่ปกติ | ตามกฎเดิมก่อน 아/어 (ข้อ 51 · 37 · 54) | — | — |

#### ตัวอย่างตามชนิดของราก

ทุกแถวคือราก + -아/어/여 + 보다 ในรูป 봐요 สังเกตว่ารากไม่ปกติเปลี่ยนรูปก่อนแล้วจึงต่อ 아/어

| รากลงท้าย | 기본형 → -아/어 봐요 | ไทย |
|:---|:---|:---|
| ㅏ · ㅗ | 가다 → **가 봐요** | ลองไป |
| ㅏ · ㅗ | 오다 → **와 봐요** | ลองมา |
| ㅏ · ㅗ | 타다 → **타 봐요** | ลองขี่ |
| ㅏ · ㅗ | 앉다 → **앉아 봐요** | ลองนั่ง |
| ㅏ · ㅗ | 살다 → **살아 봐요** | ลองอยู่ |
| สระอื่น | 먹다 → **먹어 봐요** | ลองกิน |
| สระอื่น | 입다 → **입어 봐요** | ลองใส่ |
| สระอื่น | 읽다 → **읽어 봐요** | ลองอ่าน |
| สระอื่น | 만들다 → **만들어 봐요** | ลองทำ |
| สระอื่น | 배우다 → **배워 봐요** | ลองเรียน |
| สระอื่น | 마시다 → **마셔 봐요** | ลองดื่ม |
| 하다 | 하다 → **해 봐요** | ลองทำ |
| 하다 | 여행하다 → **여행해 봐요** | ลองเที่ยว |
| 하다 | 공부하다 → **공부해 봐요** | ลองเรียน |
| ㅡ | 쓰다 → **써 봐요** | ลองเขียน/ลองใช้ |
| ㅡ | 끄다 → **꺼 봐요** | ลองปิด |
| ㄷ | 듣다 → **들어 봐요** | ลองฟัง |
| ㅂ | 돕다 → **도와 봐요** | ลองช่วย |
| 르 | 부르다 → **불러 봐요** | ลองร้อง |
| 르 | 자르다 → **잘라 봐요** | ลองตัด |

#### ข้อความของตำราและข้อควรรู้

ตำราหน้า 346 อธิบายกฎไว้สั้น ๆ ส่วนข้อควรรู้คือชนิดของคำที่ใช้ได้ วิธีถามประสบการณ์ และการเว้นวรรค

- **ตำรา 346쪽:** "ต่อหลังรากกริยาแสดงการทดลองทำหรือประสบการณ์ในอดีต — ㅏ/ㅗ → -아 보다 · อื่น ๆ → -어 보다 · 하다 → 하여 보다 (→ 해 보다)"
- **ใช้กับกริยาเท่านั้น** — ลองทำ/เคยทำต้องเป็นการกระทำ ไม่ใช้กับคำคุณศัพท์
- **ถามประสบการณ์:** …-아/어 봤어요? → ตอบ **네, -아/어 봤어요** *(เคย)* / **아니요, 안 -아/어 봤어요** *(ไม่เคย — 안 อยู่หน้ากลุ่มทั้งหมด: 안 가 봤어요)*
- **เว้นวรรค:** 가 **봤어요** · 먹어 **보세요** · 해 **봤어요** — 보다 เป็นกริยาช่วยแยกคำจากราก (ข้อ 13) · 한번 = "ลองสักครั้ง" (ตำราเขียน 한번 ติดกัน)

#### รูปที่พบบ่อย (เปลี่ยนเฉพาะ 보다)

รากกริยาและ 아/어 คงเดิม ส่วน 보다 ผันได้หลายรูป ตารางนี้ใช้ 가 เป็นตัวอย่างรากเดียวกันทุกแถว

| รูป | ความหมาย |
|:---|:---|
| 가 **봐요** | บอกเล่า/ลอง |
| 가 **봤어요** | เคย |
| 가 **보세요** | ลองไปสิ — ขอร้อง/แนะนำ (ข้อ 20) |
| 가 **보셨어요?** | ถามผู้ใหญ่ว่าเคยไหม |
| 가 **보고 싶어요** | อยากลองไป (ข้อ 38) |
| 가 **볼까요?** | ลองไปกันไหม (ข้อ 33) |
| 가 **볼 거예요** | จะลองไป (ข้อ 28) |
| 가 **보면** | ถ้าลองไป (ข้อ 55) |

#### สูตรและวิธีทำ: -아/어/여 보다 (แบบกระดานครู)

-아/어/여 보다 คือรากกริยา + 아/어/여 + 보다 ผันด้วยกฎเดียวกับ -아/어요 (ข้อ 06) ทุกข้อ ส่วนที่ต้องตัดสินใจมีสี่อย่าง คือรากเป็น 하 หรือไม่ ต้องปรับรากไม่ปกติก่อนหรือไม่ ใช้ 아 หรือ 어 และสระรวมกันหรือไม่ กฎมีสี่ข้อและใช้ตามลำดับ

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | รากเป็น **하다** | ใช้ **해** เลย ไม่ต้องดูสระ | 하 + 여 ย่อเป็น 해 |
| **กฎ 2** | รากไม่ปกติ ㅡ · ㅂ · ㄷ · 르 | **ปรับรากก่อน** แล้วค่อยเลือก 아/어 | ㅡ ตก · ㅂ เป็น 우 · ㄷ เป็น ㄹ · 르 เปลี่ยนเป็น ㄹ ซ้อน |
| **กฎ 3** | ดูสระของพยางค์สุดท้ายของราก (หลังกฎ 2) | ㅏ · ㅗ ใช้ **아** สระอื่นทั้งหมดใช้ **어** | สระเสียงสว่างคู่กับ 아 สระอื่นคู่กับ 어 |
| **กฎ 4** | รากไม่มีตัวสะกด | สระของรากกับ 아/어 **รวมเป็นพยางค์เดียว** | ไม่มีตัวสะกดคั่น เสียงจึงหลอมกัน |

ลำดับทำคือ ① ปรับราก (하 เป็น 해 และ ㅡ ㅂ ㄷ 르) ② เลือก 아 หรือ 어 ③ รวมสระ ④ ต่อ 보다 ท้ายสุด ตารางแรกแสดงทุกขั้นกับรากปกติและ 하다

| ราก + คำต่อ | ① ปรับราก | ② เลือก 아/어 | ③ รวมสระ | ④ ผล (+ 보다) | หมายเหตุ |
|:---|:---|:---|:---|:---|:---|
| 앉 + 아/어 보다 | ไม่ปรับ | ㅏ จึงใช้ 아 | ไม่รวม (มีตัวสะกด) | **앉아 봐요** | ✗ 앉어 봐요 |
| 가 + 아/어 보다 | ไม่ปรับ | ㅏ จึงใช้ 아 | 가 + 아 เหลือ 가 | **가 봐요** | 아 ถูกกลืน ✗ 가아 봐요 |
| 오 + 아/어 보다 | ไม่ปรับ | ㅗ จึงใช้ 아 | 오 + 아 เป็น 와 | **와 봐요** | |
| 보 + 아/어 보다 | ไม่ปรับ | ㅗ จึงใช้ 아 | 보 + 아 เป็น 봐 | **봐 봐요** | 봐 ตัวหน้าคือรากที่ผันแล้ว 봐요 ตัวหลังคือ 보다 |
| 먹 + 아/어 보다 | ไม่ปรับ | ㅓ จึงใช้ 어 | ไม่รวม (มีตัวสะกด) | **먹어 봐요** | |
| 서 + 아/어 보다 | ไม่ปรับ | ㅓ จึงใช้ 어 | 서 + 어 เหลือ 서 | **서 봐요** | 어 ถูกกลืน |
| 배우 + 아/어 보다 | ไม่ปรับ | ㅜ จึงใช้ 어 | 우 + 어 เป็น 워 | **배워 봐요** | |
| 마시 + 아/어 보다 | ไม่ปรับ | ㅣ จึงใช้ 어 | 시 + 어 เป็น 셔 | **마셔 봐요** | ✗ 마시어 봐요 |
| 쉬 + 아/어 보다 | ไม่ปรับ | ㅟ จึงใช้ 어 | ไม่รวม (ㅟ ไม่หลอมกับ 어) | **쉬어 봐요** | |
| 되 + 아/어 보다 | ไม่ปรับ | ㅚ จึงใช้ 어 | 되 + 어 เป็น 돼 | **돼 봐요** | ใช้น้อย แสดงเพื่อให้เห็นการรวมสระ |
| 하 + 아/어 보다 | **하 เป็น 해** | ไม่ต้องเลือก (여) | 하 + 여 เป็น 해 | **해 봐요** | 공부하 เป็น 공부해 봐요 |

ตารางที่สองเป็นรากที่ลงท้าย ㅡ รากที่ลงท้าย ㄹ และราก 불규칙 ทุกแถวต้องปรับรากในข้อ ① ก่อนเลือก 아/어

| ราก + คำต่อ | ① ปรับราก | ② เลือก 아/어 | ③ รวมสระ | ④ ผล (+ 보다) | หมายเหตุ |
|:---|:---|:---|:---|:---|:---|
| 쓰 + 아/어 보다 | ㅡ ตก เหลือ ㅆ | ไม่มีสระหน้า ㅡ จึงใช้ 어 | ㅆ + 어 เป็น 써 | **써 봐요** | ㅡ ตกก่อน 아/어 |
| 살 + 아/어 보다 | ไม่ปรับ (ㄹ อยู่ครบ) | ㅏ จึงใช้ 아 | ไม่รวม (มีตัวสะกด) | **살아 봐요** | ✗ 살어 봐요 |
| 입 + 아/어 보다 | ไม่ปรับ (ㅂ ปกติ) | ㅣ จึงใช้ 어 | ไม่รวม (มีตัวสะกด) | **입어 봐요** | ㅂ ปกติไม่เปลี่ยน |
| 돕 + 아/어 보다 | ㅂ เป็น 우 (도우) | 돕다 ใช้ 아 (ข้อยกเว้น) | 우 + 아 เป็น 와 | **도와 봐요** | ㅂ อื่นใช้ 워 เช่น 덥 เป็น 더워 |
| 닫 + 아/어 보다 | ไม่ปรับ (ㄷ ปกติ) | ㅏ จึงใช้ 아 | ไม่รวม (มีตัวสะกด) | **닫아 봐요** | ต่างจาก 듣 |
| 듣 + 아/어 보다 | ㄷ เป็น ㄹ (들) | ㅡ จึงใช้ 어 | ไม่รวม (มีตัวสะกด) | **들어 봐요** | ✗ 듣어 봐요 |
| 자르 + 아/어 보다 | 르 เป็น ㄹ ซ้อน (잘 + ㄹ) | ㅏ จึงใช้ 아 | ㄹ + 아 เป็น 라 | **잘라 봐요** | |
| 부르 + 아/어 보다 | 르 เป็น ㄹ ซ้อน (불 + ㄹ) | ㅜ จึงใช้ 어 | ㄹ + 어 เป็น 러 | **불러 봐요** | |

> [!TIP] วิธีจำสั้น ๆ
> ก่อนเลือก 아/어 ให้ปรับ 하 ㅡ ㅂ ㄷ 르 ก่อนเสมอ แล้วดูสระ ㅏ ㅗ ใช้ 아 สระอื่นใช้ 어 ถ้ารากไม่มีตัวสะกดให้รวมสระ และต่อ 보다 เป็นคำสุดท้ายของรูป

#### ลอง กับ เคย: ใส่กาลที่ 보다 ตัวท้าย

ความหมาย "เคย" ได้จากการใส่อดีตที่ **보다** ตัวท้ายเท่านั้น รูป -아/어 ข้างหน้าไม่เปลี่ยนเลย ตารางนี้ผันรากหนึ่งตัวต่อหนึ่งแถว จากผลของสองตารางบนไปสู่ 봐요 และ 봤어요

| ราก | ① ผล -아/어 | ② ลอง: + 봐요 | ③ เคย: + 봤어요 | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 가 | 가 | **가 봐요** | **가 봤어요** | ปฏิเสธว่าไม่เคย 안 가 봤어요 |
| 먹 | 먹어 | **먹어 봐요** | **먹어 봤어요** | ✗ 먹었어 봐요 ใส่ 었 ผิดตำแหน่ง |
| 하 | 해 | **해 봐요** | **해 봤어요** | 보 + 았 เป็น 봤 |
| 듣 | 들어 | **들어 봐요** | **들어 봤어요** | ถามผู้ใหญ่ 들어 보셨어요 |
| 부르 | 불러 | **불러 봐요** | **불러 봤어요** | |

### 📖 ตัวอย่างและการใช้

ตัวอย่างเรียงตามตำราบท 35 จากกล่องไวยากรณ์ 준비 ไปถึงแบบฝึก 연습 1–3 และกิจกรรม 활동 สังเกตว่าตำราใช้ 봤어요 ถามประสบการณ์ และใช้ 보세요 ชวนให้ลองทำ

#### จากกล่องไวยากรณ์และ 준비 (346쪽)

สี่ประโยคนี้ครอบคลุมทั้งคำถามประสบการณ์ การชวนให้ลอง และรากที่ผันไม่ปกติ

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 제프리 씨, 제주도에 **가 봤어요**? — 아니요, **안 가 봤어요**. | คุณเจฟฟรีย์ เคยไปเกาะเชจูไหม — ไม่ค่ะ ไม่เคยไป | 346쪽 |
| 우리 집에 한번 **와 보세요**. | ลองมาบ้านเราสักครั้งสิ — ㅗ + 아 → 와 | 346쪽 |
| 한국 노래를 **해 봤어요**? | เคยร้องเพลงเกาหลีไหม — 노래를 하다 = ร้อง/ทำเพลง | 346쪽 |
| 이 음악을 **들어 보셨어요**? | เคยฟังเพลงนี้ไหมคะ — ㄷ → ㄹ + 시 + 었 | 346쪽 |

#### 연습 1 (346쪽): 〜해 봤어요?

โจทย์ให้กริยาในรูปพจนานุกรมพร้อมกรรม แล้วให้ถามว่า "เคย…ไหม" สังเกตแถวที่เป็น 르 และ ㄷ ไม่ปกติ

| โจทย์ | ประโยคคำถาม | แปล |
|:---|:---|:---|
| 제주도에 가다 | 제주도에 **가 봤어요**? | เคยไปเกาะเชจูไหม |
| 고속버스를 타다 | 고속버스를 **타 봤어요**? | เคยขึ้นรถบัสด่วนไหม |
| 한국 노래를 부르다 | 한국 노래를 **불러 봤어요**? | เคยร้องเพลงเกาหลีไหม — 르 ไม่ปกติ |
| 한복을 입다 | 한복을 **입어 봤어요**? | เคยใส่ชุดฮันบกไหม |
| 혼자 여행을 하다 | 혼자 여행을 **해 봤어요**? | เคยเที่ยวคนเดียวไหม |
| 삼계탕을 먹다 | 삼계탕을 **먹어 봤어요**? | เคยกินซัมกเยทังไหม |
| 이 음악을 듣다 | 이 음악을 **들어 봤어요**? | เคยฟังเพลงนี้ไหม — ㄷ ไม่ปกติ |

#### 연습 2–3 และ 활동 (347–349쪽): ถาม–แนะนำให้ลอง

ส่วนนี้ถามประสบการณ์ก่อน แล้วแนะนำให้ลองด้วย -아/어 보세요 ตามด้วยกิจกรรมที่บอกว่าอยากลองทำอะไร

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 가: 한강에서 유람선을 **타 봤어요**? — 나: 아니요, **안 타 봤어요**. — 가: 그럼 한번 **타 보세요**. 아주 재미있어요. | เคยขึ้นเรือสำราญที่แม่น้ำฮันไหม — ไม่เคย — งั้นลองขึ้นดูสักครั้ง สนุกมาก | 연습 2–3 |
| 가: 바트 씨, 명동에 **가 봤어요**? — 나: 네, **가 봤어요**. — 가: 그래요? 저도 명동에 가고 싶어요. 명동에서는 무엇을 하는 것이 좋아요? — 나: 가게가 많으니까 쇼핑을 **해 보세요**. 아주 재미있을 거예요. | เคยไปเมียงดงไหม — เคย — อยากไปเหมือนกัน ที่นั่นทำอะไรดี — ร้านเยอะ ลองช็อปปิงดูสิ สนุกแน่ | 연습 2–3 |
| … 칼국수를 **먹어 보세요**. | ลองกินคัลกุกซูดูสิ | 연습 2–3 |
| 저는 몽골에 **가 보고 싶어요**. | ฉันอยากลองไปมองโกเลีย — -고 싶다 ข้อ 38 | 활동 (349쪽) |
| 몽골에서 말을 **타 보고 싶어요**. | อยากลองขี่ม้าที่มองโกเลีย | 활동 (349쪽) |
| 그리고 몽골의 전통 집 게르에서 **자 보고 싶어요**. | และอยากลองนอนในเกอร์ บ้านดั้งเดิมของมองโกเลีย | 활동 (349쪽) |
| 몽골에 가면 어디에서 말을 탈 수 있어요? | ถ้าไปมองโกเลียจะขี่ม้าได้ที่ไหน — ข้อ 55 · 46 | 활동 (349쪽) |

โจทย์ต่อของ 연습 2–3 ตำราให้คู่คำมา ตารางนี้เรียบเรียงตามรูปแบบของตำรา

| โจทย์ (คู่คำ) | ประโยคเรียบเรียง | ไทย |
|:---|:---|:---|
| 태권도를 배우다 / 재미있다 | 태권도를 **배워 보세요**. 재미있어요. | ลองเรียนเทควันโดดูสิ สนุกนะ |
| 한복을 입다 / 예쁘다 | **입어 보세요**. 예뻐요. | ลองใส่ดูสิ สวยนะ |
| 한국 신문을 읽다 / 어렵지 않다 | **읽어 보세요**. 어렵지 않아요. | ลองอ่านดูสิ ไม่ยากนะ |
| 찜질방에 가다 / 기분이 좋다 | **가 보세요**. 기분이 좋아요. | ลองไปดูสิ รู้สึกดีนะ |
| 떡볶이를 만들다 / 아주 간단하다 | **만들어 보세요**. 아주 간단해요. | ลองทำดูสิ ง่ายมากเลย |
| 시골 여행하다 / 경치가 좋다 | **여행해 보세요**. 경치가 좋아요. | ลองไปเที่ยวต่างจังหวัดดูสิ วิวสวยนะ |

#### ตัวอย่างบอกประสบการณ์ แนะนำให้ลอง และบทสนทนา 3 ชุด (ตำรา 346쪽)

ตำรา 346쪽 ใช้รูปเดียวกันสองแบบ แบบแรกเติม 봤어요 เพื่อบอก**ประสบการณ์ที่เคยทำ** แบบที่สองเติม 보세요 เพื่อ**แนะนำให้ลอง** ประโยคและบทสนทนาข้างล่างเป็นสิ่งที่ครูเขียนบนสไลด์ ส่วนกฎเลือก 아/어/여 ที่ใช้ร่วมกันทั้งสองแบบอยู่ในตารางแรกของหัวข้อรูปแบบข้างบนแล้ว

ตัวอย่างบนสไลด์แรกเป็นประโยค 봤어요 ทั้งสี่ประโยค ครูวาง 안 ไว้หน้ากริยาหลัก (먹다) เมื่อต้องการบอกว่า "ไม่เคย"

| 한국어 | ไทย |
|:---|:---|
| 제주도에 가 봤어요. | เคยไปเกาะเชจู |
| 삼계탕을 안 먹어 봤어요. | ไม่เคยกินซัมกเยทัง |
| 혼자 여행해 봤어요. | เคยเที่ยวคนเดียว |
| 한국 노래를 들어 봤어요. | เคยฟังเพลงเกาหลี |

สไลด์ที่สองเป็นประโยค 보세요 ที่ตามด้วยประโยคบอกเหตุผลว่าทำไมควรลอง ซึ่งใช้ -아/어요 ธรรมดา

| 한국어 | ไทย |
|:---|:---|
| 제주도에 가 보세요. 경치가 아름다워요. | ลองไปเกาะเชจูสิ วิวสวยนะ |
| 삼계탕을 먹어 보세요. 정말 맛있어요. | ลองกินซัมกเยทังสิ อร่อยจริง ๆ |
| 혼자 여행해 보세요. 재미있어요. | ลองเที่ยวคนเดียวสิ สนุกนะ |
| 이 노래를 들어 보세요. 노래가 정말 좋아요. | ลองฟังเพลงนี้สิ เพลงดีจริง ๆ |

สไลด์สุดท้ายสรุปเป็นบทสนทนา 3 ประโยคต่อชุด คือถามประสบการณ์ ตอบว่าไม่เคย แล้วแนะนำให้ลอง ครูให้สามชุดดังนี้

- 가: 김치를 먹어 봤어요? *(เคยกินกิมจิไหม)*
- 나: 아니요, 김치를 안 먹어 봤어요. *(ไม่ค่ะ ไม่เคยกินกิมจิ)*
- 가: 그럼 김치를 먹어 보세요. 정말 맛있어요. *(งั้นลองกินกิมจิสิ อร่อยจริง ๆ)*

ชุดที่สองใช้ N서울타워 *(หอคอยเอ็นโซล)* และคำว่า 야경 *(วิวกลางคืน)*

- 가: N서울타워에 가 봤어요? *(เคยไปหอคอยเอ็นโซลไหม)*
- 나: 아니요, 안 가 봤어요. *(ไม่ค่ะ ไม่เคยไป)*
- 가: 그럼 N서울타워에 가 보세요. 야경이 아름다워요. *(งั้นลองไปสิ วิวกลางคืนสวย)*

ชุดที่สามใช้ 이 노래 *(เพลงนี้)* กับกริยา 듣다 ซึ่งเป็น ㄷ ไม่ปกติ จึงเปลี่ยนเป็น 들어 (ข้อ 51)

- 가: 이 노래를 들어 봤어요? *(เคยฟังเพลงนี้ไหม)*
- 나: 아니요, 안 들어 봤어요. *(ไม่ค่ะ ไม่เคยฟัง)*
- 가: 그럼 이 노래를 들어 보세요. 정말 좋아요. *(งั้นลองฟังเพลงนี้สิ ดีจริง ๆ)*

### ⚠️ จุดสับสน

-아/어 보다 สับสนกับตัวที่ลงท้ายด้วย 아/어 เหมือนกัน และพลาดบ่อยที่การเลือก 아/어 ตารางแรกเทียบความหมายของสี่รูป ตารางที่สองรวมรูปที่ถูกกับรูปที่ผิด

#### -아/어 보다 vs -았/었어요 vs -아/어 주다 vs -고 있다

สี่รูปนี้ใช้กริยาเดียวกันแต่ให้ความหมายต่างกัน ดูที่คอลัมน์ความหมาย

| รูป | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| **-아/어 보다** | **ลอง / เคย** (ประสบการณ์) | 삼계탕을 먹어 봤어요 *(เคยกินซัมกเยทัง)* |
| -았/었어요 (ข้อ 23) | ทำแล้ว (เหตุการณ์ในอดีต ไม่เน้นประสบการณ์) | 삼계탕을 먹었어요 *(กินซัมกเยทังแล้ว)* |
| -아/어 주다 (ข้อ 63) | **ทำให้** (เพื่อผู้อื่น) | 삼계탕을 만들어 주세요 *(ช่วยทำซัมกเยทังให้หน่อย)* |
| -고 있다 (ข้อ 32) | กำลังทำ | 삼계탕을 먹고 있어요 *(กำลังกิน)* |

#### กับดัก

ตารางนี้รวมรูปที่ถูกและรูปที่ผิดที่พบบ่อย พร้อมเหตุผลสั้น ๆ ส่วนข้อที่ไม่ใช่คู่ ✓/✗ อยู่ในรายการด้านล่าง

| ประเด็น | ✓ ถูก | ✗ ผิด | หมายเหตุ |
|:---|:---|:---|:---|
| ㅏ/ㅗ → 아 | 가 봐요 · 와 봐요 · 앉아 봐요 · 살아 봐요 | 살어 봐요 · 받어 봐요 · 앉어 봐요 | เคยพลาด 살어요 · 받었어요 — ราก 살 · 받 มี ㅏ จึงใช้ 아 |
| 하다 → 해 | 해 봤어요 · 여행해 봤어요 | 하 봤어요 · 하어 봤어요 | รูปเต็ม 하여 보다 เป็นภาษาเขียน/ทางการ — ตำราให้ย่อเป็น 해 보다 |
| ㅡ-ราก | 써 봤어요 (쓰다) · 꺼 봤어요 (끄다) | 쓰어 봤어요 | ㅡ หลุดก่อน 어 |
| ㄷ / 르 | 들어 봤어요 · 불러 봤어요 | 듣어 봤어요 · 부르어 봤어요 | ㄷ → ㄹ และ 르 → ㄹ라 ก่อน 아/어 (ข้อ 51 · 54) |
| เว้นวรรค | 가 봤어요 | 가봤어요 | ตำราเว้นวรรค — เหมือน ✗ 갈거예요 ที่เคยเขียนติดกัน |
| ตำแหน่ง 안 | 안 가 봤어요 *(ตำรา 346쪽)* · 아직 안 가 봤어요 *(ยังไม่เคยไป — เสริม)* | 가 안 봤어요 | △ ไวยากรณ์ได้แต่ความหมายเพี้ยน — ตำราใช้ 안 วางหน้ากลุ่ม |

- **เคย (ถามประสบการณ์) ใช้ -아/어 봤어요** ในอดีต:
  - ✓ 제주도에 가 봤어요? *(เคยไปไหม)*
  - 제주도에 갔어요? *(ไปเชจูแล้วหรือยัง/ไปมาหรือเปล่า — ไม่ชัดว่าถามประสบการณ์)*
  - ✗ 제주도에 가 봐요? (ปัจจุบัน = "ลองไป")
- **ลอง (ขอร้อง/แนะนำ) ใช้ -아/어 보세요:** ✓ 한번 가 보세요 *(ลองไปสักครั้ง)* · ใช้ 한번 บ่อย
- **-(으)ㄴ 적이 있다** *(เคยมีประสบการณ์)* ปรากฏในคำถามอุ่นเครื่องของ 읽기 บท 37 ("약속을 바꾼 적이 있어요?" *(เคยเปลี่ยนนัดไหม)*) แต่**ตำรายังไม่สอนเป็นข้อไวยากรณ์** — ในบท 35 ใช้ -아/어 봤어요 แทน (เสริม)

> [!TIP] กฎสั้น ๆ
> - **-아/어 보다 = "ลอง/เคย"** — เลือก 아/어/해 จากสระของราก
> - เปลี่ยนเฉพาะ 보다: **봐요 · 봤어요 (เคย) · 보세요 (ลองสิ) · 보고 싶어요 (อยากลอง)**
