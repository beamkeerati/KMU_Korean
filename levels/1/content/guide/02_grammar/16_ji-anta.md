## 16. -지 않다 (ไม่…)

> [!INTRO] ข้อนี้คืออะไร
> -지 않다 คือรูปปฏิเสธที่ต่อท้ายรากของ **กริยาและคำคุณศัพท์** เพื่อบอกว่า "ไม่…" ความหมายเดียวกับ 안 ต่างกันแค่ตำแหน่ง คือ 안 อยู่หน้ากริยา ส่วน -지 않다 อยู่หลังราก
>
> ส่วนที่ผันตามกาลและระดับภาษาคือ **않다** ส่วนรากไม่เปลี่ยนรูป จึงไม่ต้องแยกกฎตามตัวสะกด ใช้ได้กับกริยาทุกชนิดและคำคุณศัพท์ แต่ใช้กับ 이다 และ 있다 ไม่ได้
>
> สอนในบท 14 (ครูทบทวน 안 ของบท 12 ไปพร้อมกัน) ต่อยอดจากข้อ 08 (안) และข้อ 06 (-아/어요) ไปใช้ต่อในข้อ 20 (-지 않으세요) ข้อ 21 (-지 않습니다) ข้อ 22 (-지 않겠습니다) และข้อ 23 (-지 않았어요)

### 📌 รูปแบบและเงื่อนไข

สูตรของข้อนี้คือ `รากศัพท์ (ตัด 다) + -지 + 않아요` ส่วนที่ผันคือ **않다** (않 + 아요 = 않아요) ส่วนรากไม่เปลี่ยนรูป และไม่ต้องแยกกฎตามตัวสะกด ตารางนี้ดูว่าคำแต่ละชนิดต่อกับ -지 않다 อย่างไร

| เงื่อนไข | ปกติ → ปฏิเสธ |
|:---|:---|
| กริยาทั่วไป (มี/ไม่มีตัวสะกด ใช้ -지 เหมือนกัน) | 가요 → 가**지 않아요** |
| กริยา N+하다 (ติดกัน ไม่แยก) | 공부해요 → 공부하**지 않아요** |
| กริยา 하다 คำเดียว | 좋아해요 → 좋아하**지 않아요** |
| คำคุณศัพท์ | 비싸요 → 비싸**지 않아요** |
| **ใช้ไม่ได้กับ** 이다 / 있다 | 이다 → **이/가 아니에요** · 있다 → **없어요** |

#### ตัวอย่างตามชนิดของคำ

ตารางนี้ให้ตัวอย่างหนึ่งประโยคต่อหนึ่งแถว เรียงตามชนิดของคำในตารางข้างบน

| ชนิด | 한국어 | ไทย |
|:---|:---|:---|
| กริยาทั่วไป | 마시다 → 마시**지 않아요** | ไม่ดื่ม |
| กริยาทั่วไป | 먹다 → 먹**지 않아요** | ไม่กิน |
| กริยา N+하다 | 운동하지 않아요 | ไม่ออกกำลังกาย |
| กริยา N+하다 | 청소하지 않아요 | ไม่ทำความสะอาด |
| กริยา 하다 คำเดียว | 김치를 좋아하지 않아요 | {x:ไม่}{v:ชอบ}{n:กิมจิ} |
| คำคุณศัพท์ | 좋지 않아요 | {x:ไม่}{v:ดี} |
| คำคุณศัพท์ | 재미있지 않아요 | {x:ไม่}{v:สนุก} |
| คำคุณศัพท์ | 친절하지 않아요 | {x:ไม่}{v:ใจดี} |
| 이다 (ใช้ -지 않다 ไม่ได้) | 학생이 아니에요 | ไม่ใช่นักเรียน |
| 있다 (ใช้ -지 않다 ไม่ได้) | 돈이 없어요 | ไม่มีเงิน |

#### ระดับภาษาของ -지 않다

ตำราและไกด์ฉบับเก่าเขียนเรื่องระดับภาษาต่างกัน ข้อนี้ยึดตามตำรา

- ตำรา (126쪽): ต่อท้ายรากของกริยา/คุณศัพท์ แสดงการปฏิเสธ **ใช้ในภาษาพูดทั่วไป — ระดับเดียวกับ 안**
- ตำราไม่ได้แบ่งว่า -지 않다 เป็นภาษาเขียนกว่า (ไกด์ฉบับเก่าเขียนว่า "เป็นแบบแผนกว่า" ซึ่งตำราไม่ได้บอก จึงปรับให้ตรงตำรา)

#### ผันต่อได้ตามปกติ

เพราะส่วนที่ผันคือ 않다 จึงต่อกับยกย่อง ทางการ ตั้งใจ และอดีตได้เหมือนกริยาทั่วไป

| รูปผัน | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| -지 **않으**세요 | ยกย่อง | — |
| -지 **않습**니다 | ทางการ | — |
| -지 **않겠**습니다 | ตั้งใจจะไม่… | 오지 않겠습니다 *(จะไม่มา)* |
| -지 **않았**어요 | อดีต | 가지 **않았**어요 *(ไม่ได้ไป)* |

#### การออกเสียง

คำที่มี 않 หรือ 많 ตามด้วยสระ จะออกเสียงต่อกัน ดังนี้

| เขียน | อ่านว่า | ความหมาย |
|:---|:---|:---|
| 않아요 | **[아나요]** | ไม่ |
| 많아요 | [마나요] | มาก |
| 짧아요 | [짤바요] | สั้น |

#### สูตรและวิธีทำ: -지 않다 (แบบกระดานครู)

-지 않다 ต่อท้ายรากโดยตรง ไม่ต้องดูตัวสะกด และส่วนเดียวที่ผันต่อคือ 않다 จึงมีกฎให้ตัดสินใจแค่สามข้อตามลำดับนี้

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | เป็นกริยาหรือคำคุณศัพท์ (ไม่ใช่ 이다 และ 있다) | ตัด **다** ออก แล้วต่อ **-지** ทันที | -지 ไม่เปลี่ยนตามตัวสะกด จึงใช้กับรากทุกแบบเหมือนกัน |
| **กฎ 2** | รากลงท้ายด้วย 하다 เช่น 공부하다 | เก็บ **하** ไว้ติดราก แล้วต่อ -지 ที่ท้าย 하 | ต่อ -지 ที่ท้ายราก จึงไม่ต้องแยกคำ ต่างจาก 안 ที่ต้องเลือกตำแหน่ง |
| **กฎ 3** | ปิดท้ายประโยค | ผันที่ **않다**: 않 + 아요 → **않아요** | 않 มีตัวสะกด ㄶ จึงไม่ควบสระกับ 아 |

ลำดับทำคือ ① ดูชนิดคำ ถ้าเป็น 이다 หรือ 있다 ให้ใช้ 아니에요 หรือ 없어요 แทน ② ตัด 다 แล้วต่อ -지 ③ ต่อ 않 กับคำลงท้าย ตารางนี้แสดงทุกขั้นกับคำที่ตำราใช้

| ราก + คำต่อ | ① ชนิดคำ | ② ตัด 다 + -지 | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 가다 + -지 않다 | กริยา | 가 + 지 | **가지 않아요** | ไม่มีตัวสะกด ก็ต่อ -지 เหมือนกัน |
| 먹다 + -지 않다 | กริยา | 먹 + 지 | **먹지 않아요** | มีตัวสะกด ไม่ต้องใส่ 으 |
| 마시다 + -지 않다 | กริยา | 마시 + 지 | **마시지 않아요** | ไม่ตัด 시 |
| 공부하다 + -지 않다 | กริยา N+하다 | 공부하 + 지 | **공부하지 않아요** | เทียบ 안: 공부 안 해요 |
| 좋아하다 + -지 않다 | กริยา 하다 คำเดียว | 좋아하 + 지 | **좋아하지 않아요** | ✗ 좋아 안 해요 เพราะ 좋아하다 แยกไม่ได้ |
| 비싸다 + -지 않다 | คำคุณศัพท์ | 비싸 + 지 | **비싸지 않아요** | คำคุณศัพท์ผันเหมือนกริยา |
| 좋다 + -지 않다 | คำคุณศัพท์ | 좋 + 지 | **좋지 않아요** | ไม่ต้องใส่ 으 |
| 친절하다 + -지 않다 | คำคุณศัพท์ ...하다 | 친절하 + 지 | **친절하지 않아요** | เทียบ 안: 안 친절해요 |
| 크다 + -지 않다 | คำคุณศัพท์ | 크 + 지 | **크지 않아요** | ㅡ ไม่หาย เพราะ -지 ไม่ใช่ 아/어 |
| 이다 + -지 않다 | ใช้ไม่ได้ (이다) | ไม่ทำ | **이/가 아니에요** | ใช้รูปปฏิเสธของ 이다 แทน |
| 있다 + -지 않다 | ใช้ไม่ได้ (있다) | ไม่ทำ | **없어요** | ใช้คำตรงข้ามแทน |

> [!TIP] วิธีจำสั้น ๆ
> ตัด 다 แล้วต่อ -지 ได้เลยโดยไม่ต้องดูตัวสะกด จากนั้นปิดด้วย 않아요 ถ้ารากเป็น 하다 ให้เก็บ 하 ไว้ติดราก ส่วน 이다 กับ 있다 ไม่ผ่านสูตรนี้

### 📖 ตัวอย่างและการใช้

ตัวอย่างต่อไปนี้เริ่มจากประโยคในตำรา แล้วดูรูปแบบ "ไม่… แต่…" และปิดด้วยสไลด์ของอาจารย์ที่เทียบ -지 않다 กับ 안

#### จากตำรา 14과 (126~127쪽)

ประโยคจากตำรา เรียงตามลำดับในหน้า

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 저는 커피를 마시**지 않아요**. | ฉันไม่ดื่มกาแฟ | 126~127쪽 |
| 김치를 먹**지 않아요**. | ไม่กินกิมจิ | 126~127쪽 |
| 토요일에 학교에 가**지 않아요**. | วันเสาร์ไม่ไปโรงเรียน | 126~127쪽 |
| 지금 공부를 하**지 않아요**. | ตอนนี้ไม่ได้เรียน | 126~127쪽 |
| 오늘 날씨가 좋**지 않아요**. | {a:วันนี้}{n:อากาศ}{x:ไม่}{v:ดี} | 126~127쪽 |
| 고향 친구는 한국말을 배우**지 않아요**. | เพื่อนบ้านเกิดไม่ได้เรียนภาษาเกาหลี | บทสนทนา 14-1 |
| 교실에서 베트남 말을 하**지 않아요**. | ไม่พูดภาษาเวียดนามในห้องเรียน | บทอ่าน 14-2 |

#### รูปแบบ "ไม่… แต่…"

เมื่อถูกถามแบบใช่/ไม่ใช่ ให้ตอบ 아니요 แล้วปฏิเสธ ตามด้วยสิ่งที่เป็นจริง

| ถาม | ตอบ | ไทย |
|:---|:---|:---|
| 지금 집에 가요? | 아니요, 집에 가**지 않아요**. 도서관에 가요. | {a:ตอนนี้}{v:กลับ}{n:บ้าน}ไหม — {x:ไม่} {v:ไป}{n:ห้องสมุด} |
| 과일이 비싸요? | 아니요, 비싸**지 않아요**. 싸요. | {n:ผลไม้}{v:แพง}ไหม — {x:ไม่}{v:แพง} {v:ถูก} |
| 커피를 마셔요? | 아니요, 커피를 마시**지 않아요**. 물을 마셔요. | {v:ดื่ม}{n:กาแฟ}ไหม — {x:ไม่} {v:ดื่ม}{n:น้ำ} |

#### 📽️ สไลด์อาจารย์ (교과서 126쪽): 동사 · 형용사 + -지 않다 = 안 + 동사 · 형용사

ครูให้ถาม–ตอบสี่คู่ แล้วเทียบสองรูปปฏิเสธให้เห็นว่าความหมายเท่ากัน

| ถาม | ตอบ |
|:---|:---|
| 주말에 영화를 봐요? *(สุดสัปดาห์ดูหนังไหม)* | 영화를 보**지 않아요**. 책을 읽어요. *(ไม่ดูหนัง อ่านหนังสือ)* |
| 아침에 운동을 해요? *({p:ตอน}{n:เช้า}{v:ออกกำลังกาย}ไหม)* | 아침에 운동을 하**지 않아요**. 자요. *({x:ไม่}{v:ออกกำลังกาย} {v:นอน})* |
| 가방이 작아요? *(กระเป๋าเล็กไหม)* | 가방이 작**지 않아요**. 커요. *({x:ไม่}{v:เล็ก} {v:ใหญ่})* |
| 오늘 날씨가 어때요? *(วันนี้อากาศเป็นอย่างไร)* | 날씨가 나쁘**지 않아요**. 좋아요. *({x:ไม่}{v:เลว} {v:ดี})* |

สองรูปปฏิเสธเทียบกัน (ตารางของครู)

| ชนิด | ปกติ | 안 + … | -지 않다 |
|:---|:---|:---|:---|
| กริยาทั่วไป | 보다 · 먹다 | 안 봐요 · 안 먹어요 | 보지 않아요 · 먹지 않아요 |
| คำคุณศัพท์ | 크다 · 좋다 | 안 커요 · 안 좋아요 | 크지 않아요 · 좋지 않아요 |
| กริยา N+하다 | 운동하다 · 공부하다 | 운동을 **안** 해요 · 공부를 **안** 해요 | 운동하지 않아요 · 공부하지 않아요 |
| กริยา 하다 คำเดียว | 좋아하다 | **안** 좋아해요 | 좋아하지 않아요 |
| **คุณศัพท์** N+하다 | 친절하다 · 피곤하다 · 조용하다 | **안** 친절해요 · 안 피곤해요 · 안 조용해요 | 친절하지 않아요 · 피곤하지 않아요 · 조용하지 않아요 |

⚠️ ข้อสำคัญจากสไลด์: 하다 **กริยา** แทรก 안 หลังคำนาม (운동을 안 해요 *(ไม่ออกกำลังกาย)*) แต่ 하다 **คำคุณศัพท์** วาง 안 ไว้หน้าคำทั้งก้อน (안 친절해요 *(ไม่ใจดี)*)

### ⚠️ จุดสับสน

คนไทยมักคิดว่า 안 กับ -지 않다 ต่างกันที่ความหมาย แต่จริง ๆ **ความหมายเท่ากัน** ต่างกันแค่ตำแหน่งและความยาว ส่วนเรื่องอดีต คนมักสับสนว่า 았/었 ไปติดที่คำไหน ตารางนี้เทียบสองรูปในห้าด้านสำคัญ

| หัวข้อ | 안 | -지 않다 |
|:---|:---|:---|
| ตำแหน่ง | **หน้า**กริยา: 안 가요 | **หลัง**รากศัพท์: 가지 않아요 |
| ระดับภาษา | ภาษาพูดทั่วไป (ตำรา) | ภาษาพูดทั่วไป (ตำรา) |
| 하다-กริยา (N+하다) | **안 แทรกกลาง** 공부 안 해요 | **ไม่แยก** 공부하지 않아요 |
| 이다 | ✗ 학생이 안 이에요 | ✗ 학생이지 않아요 → **학생이 아니에요** ✓ |
| อดีต | 안 갔어요 (ผัน 았 ที่กริยา) | 가지 **않았**어요 (ผัน 았 ที่ **않**) |

#### อดีต: สองรูปได้ผลเท่ากัน

ในอดีต 안 ผัน 았 ที่กริยา ส่วน -지 않다 ผัน 았 ที่ 않 ทั้งสองแบบถูกและความหมายเท่ากัน

- ✓ 어제 학교에 안 갔어요. = ✓ 어제 학교에 가지 않았어요. *({a:เมื่อวาน}{x:ไม่ได้}{v:ไป}{n:โรงเรียน})*

#### ✓ / ✗ ที่พบบ่อย

ตารางนี้เทียบรูปที่ถูกกับรูปที่ผิดซึ่งเกิดขึ้นบ่อยที่สุดกับ -지 않다

| ✓ ถูก | ✗ ผิด | เหตุผล |
|:---|:---|:---|
| 아침을 먹지 않았어요 *({x:ไม่ได้}{v:กิน}{n:ข้าวเช้า})* | 아침을 먹았지 않아요 | ห้ามใส่ 았 ก่อน 지 |
| 한국 음식을 좋아하지 않아요 *({x:ไม่}{v:ชอบ}{n:อาหารเกาหลี})* | 좋아 안 해요 | 좋아하다 เป็นกริยาคำเดียว ไม่แยกแบบ N+하다 |
| 저는 의사가 아니에요 *(ฉันไม่ใช่หมอ)* | 의사지 않아요 | 이다 ใช้ -지 않다 ไม่ได้ |
| **공부하지 않아요** *(ไม่เรียน)* | 공부 하지 않아요 | แยกคำผิด ต้องเขียนติดกัน |
| 돈이 없어요 *(ไม่มีเงิน)* | 안 있어요 | ปฏิเสธ 있다 ระดับนี้ใช้ **없다** ตรง ๆ |

> [!TIP] ลำดับในอดีต
> ลำดับในอดีตคือ **รากศัพท์ + 지 + 않 + 았 + 어요** ส่วน **않** เป็นตัวรับ 았 เสมอ (가지 않았어요) ไม่ใช่ตัวกริยาหลัก
>
> ข้อสอบที่สั่งให้ตอบด้วย -지 않아요 ต้องตอบรูปนี้ (ไม่ใช้ 안)

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

รูป -지 않- เป็นจุดแข็งของผู้เรียน เพราะถูกทั้งสามข้อใน 매일시험 14과 B รายการต่อไปนี้เรียงตามแหล่งที่มา

- **매일시험 14과 B** (ข้อ 11–13 · ข้อละ 1): "ตอบปฏิเสธด้วย -지 않아요" **ถูกทั้ง 3 ข้อ** (รูป -지 않- เป็นจุดแข็ง)
  - 머리가 짧지 않아요 *(ผมไม่สั้น)*
  - 커피를 마시지 않아요 *(ไม่ดื่มกาแฟ)*
  - 지금 공부하지 않아요 *(ตอนนี้ไม่ได้เรียน)*
- **워크북 14과**
  - C ตารางผัน (กริยา 9 + คุณศัพท์ 9)
  - D บทสนทนา 5 ข้อ
  - E ภาพ 6 ข้อ (E4–E5 ต้องแต่งคำถามของ 가 เอง)
    - 키가 작아요? *(ตัวเตี้ยไหม)*
    - 옆방이 조용해요? *(ห้องข้าง ๆ เงียบไหม)*
- **중간시험 복습문제 ข้อ 9** (ชีตที่ครูแจก): ตอบ 2 แบบคู่กัน
  - 마시지 않아요 / 안 마셔요 *(ไม่ดื่ม)*
  - 크지 않아요 / 안 커요 *(ไม่ใหญ่)*
  - 좋아하지 않아요 / 안 좋아해요 *(ไม่ชอบ)*
  - 운동하지 않아요 / 운동 안 해요 *(ไม่ออกกำลังกาย)*
- **복습시험 ②** 읽기 14-2 (지훈 · 투이) เป็นชุดสำรอง มี -지 않아요 หลายที่
- **ประโยคแวดล้อมที่เคยพลาดใน 14과:** 피곤나요 ✗ → 피곤해요 *(เหนื่อย)* (매일시험 14과 A6)

### 🔗 เชื่อมโยง

ข้อนี้ต่อจากการปฏิเสธด้วย 안 และเป็นฐานของรูปปฏิเสธในระดับภาษาและกาลอื่น ๆ

← ต่อยอดจาก

- ข้อ 08 (안 + กริยา · N 안 해요)
- ข้อ 06 (ผัน 않다 → 않아요)
- ข้อ 18 (คำคุณศัพท์ — เรียนในบทเดียวกัน ปฏิเสธด้วยกฎเดียวกัน)
- ข้อ 02 (이다 ไม่ใช้ -지 않다 → 이/가 아니에요)

→ ใช้ต่อใน

- ข้อ 20 (-지 않으세요)
- ข้อ 21 (-지 않습니다)
- ข้อ 22 (-지 않겠습니다)
- ข้อ 23 (-지 않았어요)

> [!SUMMARY] สรุป
> - สูตร: รากศัพท์ (ตัด 다) + -지 않아요 ใช้ได้กับกริยาและคำคุณศัพท์ ความหมายเดียวกับ 안 แต่ใช้กับ 이다 / 있다 ไม่ได้ (→ 이/가 아니에요 · 없어요)
> - กริยา N+하다 เขียนติดกัน (공부하지 않아요) ส่วน 안 แทรกกลาง (공부 안 해요)
> - อดีต: รากศัพท์ + 지 + 않 + 았 + 어요 (가지 않았어요) ห้ามใส่ 았 ก่อน 지
> - ที่เคยออกสอบ: 매일시험 14과 B ถูกทั้ง 3 ข้อ และใบทบทวนให้ตอบ 2 แบบคู่กัน (-지 않아요 / 안)
