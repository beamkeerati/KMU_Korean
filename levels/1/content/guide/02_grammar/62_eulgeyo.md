## 62. -(으)ㄹ게요 (…นะ · จะ…เอง — สัญญา/อาสาต่อหน้าผู้ฟัง)

> [!INTRO] ข้อนี้คืออะไร
> -(으)ㄹ게요 ใช้ลงท้ายประโยคเมื่อ**ผู้พูดบอกความตั้งใจ สัญญา หรืออาสา**กับผู้ฟัง แปลว่า "ฉันจะ…นะ" โดยประธานต้องเป็น**ผู้พูดเอง** (ตำรา 354쪽: willingness or promise to the listener — the subject should be the speaker) และใช้ขอ**อนุญาตง่าย ๆ** ได้ ("ขอ…หน่อยนะ")
>
> สอนในบท 36 (교과서 354–355쪽 · 준비 2) ต่อยอดจาก ข้อ 22 (-겠- ความตั้งใจ) ข้อ 28 (-(으)ㄹ 거예요) และ ข้อ 33 (-(으)ㄹ까요? — กฎ ㄹ/을 เดียวกัน)
>
> ไปใช้ต่อใน ข้อ 63 (ผู้ฟังขอ -아/어 주세요 → ผู้พูดตอบ -(으)ㄹ게요) · ข้อ 55 (…면 …ㄹ게요) · ข้อ 64 และ 활동 บท 36–37 (สัญญากับครู/แฟน/แม่)

### 📌 รูปแบบและเงื่อนไข

กฎเหมือน -(으)ㄹ 거예요 (ข้อ 28) และ -(으)ㄹ까요? (ข้อ 33) คือดู**พยางค์สุดท้ายของราก** ตารางแรกสรุปกฎ ตารางที่สองให้ตัวอย่างของรากแต่ละแบบ

| รากศัพท์ลงท้าย | ต่อ |
|:---|:---|
| **สระ** | **-ㄹ게요** |
| **ตัวสะกด** | **-을게요** |
| ลงท้าย **ㄹ** | **-게요** (ㄹ ของรากอยู่แล้ว ไม่ซ้ำ ไม่ใส่ 을) |
| ㅂ · ㄷ ไม่ปกติ | ตามกฎก่อน 으 (ข้อ 37 · 51) |
| 르 · ㅡ | ไม่เปลี่ยน (เปลี่ยนเฉพาะก่อน 아/어) |
| พิเศษ: 기다리고 있다 | -고 있을게요 |

#### ตัวอย่างตามชนิดของราก

ทุกแถวคือรากกริยา + -(으)ㄹ게요 ที่แปลว่า "จะ…นะ" สังเกตรากที่ลงท้าย ㄹ ซึ่งไม่ต้องเติม 을 ซ้ำ

| รากลงท้าย | 기본형 → -(으)ㄹ게요 | ไทย |
|:---|:---|:---|
| สระ | 가다 → **갈게요** | จะไป |
| สระ | 오다 → **올게요** | จะมา |
| สระ | 사다 → **살게요** | จะซื้อ |
| สระ | 하다 → **할게요** | จะทำ |
| สระ | 전화하다 → **전화할게요** | จะโทร |
| ตัวสะกด | 읽다 → **읽을게요** | จะอ่าน |
| ตัวสะกด | 먹다 → **먹을게요** | จะกิน |
| ตัวสะกด | 앉다 → **앉을게요** | จะนั่ง |
| ตัวสะกด | 닫다 → **닫을게요** | จะปิด |
| ตัวสะกด | 닦다 → **닦을게요** | จะเช็ด |
| ㄹ | 만들다 → **만들게요** | จะทำ |
| ㄹ | 열다 → **열게요** | จะเปิด |
| ㄹ | 놀다 → **놀게요** | จะเล่น |
| ㅂ | 돕다 → **도울게요** | จะช่วย |
| ㄷ | 듣다 → **들을게요** | จะฟัง |
| 르 | 부르다 → **부를게요** | จะร้อง |
| ㅡ | 쓰다 → **쓸게요** | จะเขียน/จะใช้ |
| ㅡ | 끄다 → **끌게요** | จะปิด |
| พิเศษ | 기다리고 있다 → **기다리고 있을게요** | จะรออยู่นะ |

#### ข้อความของตำราและข้อควรรู้

ตำราหน้า 354 สรุปเงื่อนไขไว้ชัดเจน ส่วนข้อควรรู้คือประธาน ชนิดของคำที่ใช้ได้ น้ำเสียง และการไม่ใส่ -(으)시-

- **ตำรา 354쪽:** "ใช้เมื่อผู้พูดแสดงความตั้งใจของตนเองหรือสัญญากับผู้ฟัง ประธานต้องเป็นผู้พูด" และสรุปรูปไว้ดังนี้
  - ตัวสะกด → -을게요
  - สระ → -ㄹ게요
  - ㄹ → -게요
  - ใช้ขออนุญาตง่าย ๆ ได้ด้วย
- **ประธานต้องเป็น "ฉัน"** ละได้ หรือใส่ 제가/저는 เมื่อเน้น
  - **제가** 읽을게요 *(ฉันเองจะอ่าน)*
  - **제가** 창문을 닦을게요 *(ฉันเองจะเช็ดหน้าต่าง)*
- **ใช้กับกริยาเท่านั้น** ไม่ใช้กับคำคุณศัพท์/N이다 · **ไม่ใส่ -(으)시- ไม่ใส่ tense** (ประธานคือผู้พูด จึงไม่ยกย่องตัวเอง)
- **เสียงตก ↘ เมื่อสัญญา** · **เสียงขึ้น ↗ เมื่อขออนุญาต** (문 좀 열게요? ↗ = ขอเปิดประตูนะ)
- **ห้ามใส่ -(으)시- ให้ตัวเอง:** ✗ 가실게요 — ใช้ 갈게요 ได้แม้ผู้ฟังเป็นผู้ใหญ่ (ความสุภาพอยู่ที่ 요) หรือเปลี่ยนเป็น -겠습니다 (ข้อ 22) ในที่ทางการ

#### เสียงอ่านที่ควรรู้

ㄱ หลัง ㄹ ออกเสียงเป็น ㄲ **แต่สะกดด้วย ㄱ เสมอ** คือ 갈게요 (✗ 갈께요) ตารางนี้แสดงเสียงอ่านของคำที่ตำราและตัวอย่างใช้

| 한국어 | เสียงอ่าน | ที่มา |
|:---|:---|:---|
| 갈게요 | [갈께요] | กฎ ㄱ → ㄲ |
| 읽을게요 | [일글께요] | กฎ ㄱ → ㄲ |
| 앉을게요 | [안즐께요] | กฎ ㄱ → ㄲ |
| **연락할게요** | [열라칼께요] | ตำรา 364쪽 |

#### สูตรและวิธีทำ: -(으)ㄹ게요 (แบบกระดานครู)

-(으)ㄹ게요 เลือกจากตัวสะกดของรากเหมือน -(으)ㄹ 거예요 และ -(으)ㄹ까요? ทุกอย่าง รากที่ลงท้าย ㄹ ใช้กฎ ㄹ หลุดที่ครูเขียนบนกระดานวันที่ 10/28 ส่วนรากที่ลงท้าย ㅂ หรือ ㄷ ไม่ปกติต้องปรับรากหลังเลือกคำต่อ กฎมีสี่ข้อและใช้ตามลำดับ

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | ดูพยางค์สุดท้ายของราก | ไม่มีตัวสะกด ใช้ **ㄹ게요** · มีตัวสะกด ใช้ **을게요** | ㄹ ต้องมีสระรองรับ จึงเติม 으 เฉพาะรากที่มีตัวสะกด |
| **กฎ 2** | ราก **ㄹ** | นับเหมือนไม่มีตัวสะกด **ตัด 으** แล้ว**ตัด ㄹ ของราก** ให้ ㄹ ของคำต่อมาแทน | ㄹ สองตัวติดกันเหลือตัวเดียว หน้าตาจึงไม่เปลี่ยน |
| **กฎ 3** | รากไม่ปกติ ㅂ · ㄷ | ใช้ **을게요** ตามตัวสะกด แล้วปรับราก ㅂ **เป็น 우** (으 รวมเข้า) · ㄷ **เป็น ㄹ** (으 อยู่) | ปรับเฉพาะตอนมีสระ 으 ตามหลัง เหมือนข้อ 37 และ 51 |
| **กฎ 4** | ประธาน | ต้องเป็น**ผู้พูด**เท่านั้น ไม่ใส่ -(으)시- ไม่ใส่กาล | ผู้พูดไม่ยกย่องตัวเอง ✗ 가실게요 |

ลำดับทำคือ ① ดูตัวสะกดแล้วเลือก ㄹ게요 หรือ 을게요 ② ตัด 으 และ ㄹ ของรากถ้ารากเป็น ㄹ ③ ปรับ ㅂ ㄷ ④ ต่อกันและเช็กว่าประธานคือผู้พูด ตารางนี้แสดงทุกขั้นกับรากที่ตำราใช้และราก 불규칙

| ราก + คำต่อ | ① ตัวสะกด → เลือก | ② ตัด 으 / ㄹ ของราก | ③ ปรับ ㅂ · ㄷ | ④ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|:---|
| 가 + (으)ㄹ게요 | ไม่มีตัวสะกด → ㄹ게요 | ไม่มี 으 ให้ตัด | ไม่ปรับ | **갈게요** | อ่าน [갈께요] แต่เขียน ㄱ ✗ 갈께요 |
| 하 + (으)ㄹ게요 | ไม่มีตัวสะกด → ㄹ게요 | ไม่มี 으 ให้ตัด | ไม่ปรับ | **할게요** | 전화하 เป็น 전화할게요 |
| 읽 + (으)ㄹ게요 | มีตัวสะกด ㄱ → 을게요 | ไม่ตัด 으 | ไม่ปรับ | **읽을게요** | อ่าน [일글께요] |
| 입 + (으)ㄹ게요 | มีตัวสะกด ㅂ → 을게요 | ไม่ตัด 으 | ไม่ปรับ (ㅂ ปกติ) | **입을게요** | ต่างจาก 돕 |
| 닫 + (으)ㄹ게요 | มีตัวสะกด ㄷ → 을게요 | ไม่ตัด 으 | ไม่ปรับ (ㄷ ปกติ) | **닫을게요** | ต่างจาก 듣 |
| 만들 + (으)ㄹ게요 | ราก ㄹ นับเหมือนไม่มี → ㄹ게요 | ตัด 으 แล้วตัด ㄹ ของราก | ไม่ปรับ | **만들게요** | ✗ 만들을게요 |
| 살 + (으)ㄹ게요 | ราก ㄹ นับเหมือนไม่มี → ㄹ게요 | ตัด 으 แล้วตัด ㄹ ของราก | ไม่ปรับ | **살게요** | 사다 (ซื้อ) ต่อ ㄹ게요 ก็เป็น 살게요 เหมือนกัน |
| 돕 + (으)ㄹ게요 | มีตัวสะกด ㅂ → 을게요 | 으 รวมเข้ากับ 우 | ㅂ เป็น 우 | **도울게요** | ✗ 돕을게요 |
| 듣 + (으)ㄹ게요 | มีตัวสะกด ㄷ → 을게요 | ไม่ตัด 으 | ㄷ เป็น ㄹ | **들을게요** | ✗ 듣을게요 |
| 부르 + (으)ㄹ게요 | ไม่มีตัวสะกด → ㄹ게요 | ไม่มี 으 ให้ตัด | ไม่ปรับ (르 เปลี่ยนเฉพาะก่อน 아/어) | **부를게요** | ✗ 불를게요 |
| 쓰 + (으)ㄹ게요 | ไม่มีตัวสะกด → ㄹ게요 | ไม่มี 으 ให้ตัด | ไม่ปรับ (ㅡ ตกเฉพาะก่อน 아/어) | **쓸게요** | ㄹ เป็นตัวสะกดของ 쓰 |

> [!TIP] วิธีจำสั้น ๆ
> ดูตัวสะกดก่อน ไม่มีใช้ ㄹ게요 มีใช้ 을게요 ถ้ารากเป็น ㄹ ให้เหลือ ㄹ ตัวเดียว (만들게요 ไม่ใช่ 만들을게요) ถ้าเป็น ㅂ หรือ ㄷ ไม่ปกติให้ปรับราก (도울게요 · 들을게요) และประโยคนี้พูดเรื่องตัวเองเท่านั้น

### 📖 ตัวอย่างและการใช้

ตัวอย่างเรียงตามตำราบท 36 จากกล่องไวยากรณ์ 준비 ไปถึงแบบฝึก 연습 1–2 แล้วต่อด้วยบทสนทนา 36-1 กิจกรรมใน 357쪽 และ 37과 สังเกตว่าทุกประโยคมีผู้พูดเป็นผู้ตัดสินใจเอง

#### จากกล่องไวยากรณ์และ 준비 (354쪽)

ห้าประโยคนี้แสดงการอาสา การบอกลา การสัญญา และการขออนุญาตง่าย ๆ

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 가: 주말에 이 영화를 볼까요? — 나: 좋아요. 제가 표를 **살게요**. | สุดสัปดาห์ดูหนังเรื่องนี้กันไหม — ได้ ฉันซื้อตั๋วเอง — 사다 + ㄹ게요 | 354쪽 |
| 먼저 **갈게요**. | ขอไปก่อนนะ — เหมือน "ลาก่อน" | 354쪽 |
| 제가 **읽을게요**. | ฉันจะอ่านเอง | 354쪽 |
| 이번에는 제가 **만들게요**. | ครั้งนี้ฉันจะทำเอง — ㄹ-ราก ไม่ซ้ำ ㄹ | 354쪽 |
| 문 좀 **열게요**. | ขอเปิดประตูหน่อยนะ — ใช้ขออนุญาตง่าย ๆ | 354쪽 |
| 여기 좀 **앉을게요**. | ขอนั่งตรงนี้หน่อยนะ — ใช้ขออนุญาตง่าย ๆ | 354쪽 |

#### 연습 1–2 (354–355쪽)

ตำราพิมพ์คำตอบไว้เพียง 전화할게요 (연습 1 ข้อ 1) และ 4시까지 갈게요 (연습 2 ข้อ 1) ช่องว่างที่เหลือในตารางนี้เติมตามกฎ

| คำถาม/สถานการณ์ | คำตอบ | แปล |
|:---|:---|:---|
| 언제 전화할 거예요? | 이따가 다시 **전화할게요**. | จะโทรเมื่อไร — เดี๋ยวโทรใหม่นะ |
| 어디에서 기다릴 거예요? | 여기서 **기다리고 있을게요**. | จะรอที่ไหน — จะรออยู่ตรงนี้นะ *(เติมตามกฎ)* |
| 음악이 좀 시끄러워요. | 죄송합니다. 조용히 **할게요**. | เพลงดังไปหน่อย — ขอโทษ จะเงียบ ๆ นะ |
| 교실이 너무 더워요. (열다) | 제가 문을 **열게요**. | ห้องร้อนเกินไป — ฉันจะเปิดประตูเอง |
| 지훈 씨, 오늘도 지각했어요. (오다) | 내일은 학교에 일찍 **올게요**. | วันนี้ก็มาสายอีก — พรุ่งนี้จะมาเช้านะ |
| 좀 춥지 않아요? (닫다) | 그럼 창문을 **닫을게요**. | หนาวไหม — งั้นฉันปิดหน้าต่างนะ |
| 피자 좀 더 드세요. (먹다) | 그럼 더 **먹을게요**. | ทานพิซซ่าเพิ่มหน่อย — งั้นจะทานเพิ่มนะ |
| 몇 시까지 올 수 있어요? | 4시까지 **갈게요**. | มาถึงกี่โมงได้ — จะไปถึง 4 โมงนะ |
| 책을 누가 읽을까요? (제가 읽다) | 제가 **읽을게요**. | ใครจะอ่านหนังสือ — ฉันอ่านเอง |
| 지금 전화할 수 있어요? | 아니요. 이따가 **전화할게요**. | โทรคุยตอนนี้ได้ไหม — ไม่ได้ เดี๋ยวโทรไปนะ *(เติมตามกฎ)* |
| 교실이 어두워요. | 제가 불을 **켤게요**. | ห้องมืด — ฉันจะเปิดไฟเอง *(ตำราเว้นว่าง — ตัวอย่างตอบ: 켜다 → 켤게요)* |

#### ตัวอย่างจากโจทย์ บทสนทนา และกิจกรรม (355–357쪽 · 37과)

ส่วนนี้รวมโจทย์ 연습 2 ข้อ 5 บทสนทนา 36-1 กิจกรรม 357쪽 และกิจกรรมกับบทสนทนาของ 37과

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| (식당에서) 오늘 지갑을 안 가지고 왔어요. → 그럼 오늘은 제가 **살게요**. | (ที่ร้านอาหาร) วันนี้ไม่ได้เอากระเป๋าสตางค์มา — งั้นวันนี้ฉันเลี้ยงเอง (ตัวอย่างตอบ) | โจทย์ 연습 2 ข้อ 5 |
| 마키: 그럼 우리 영화 보고 같이 식사해요. 저녁은 제가 **살게요**. | งั้นเราดูหนังแล้วกินข้าวด้วยกัน มื้อเย็นฉันเลี้ยงเอง — 사다 vs 살다 เสียง 살게요 เหมือนกัน | 36-1 (356쪽) |
| 장핑: 죄송합니다. 어제 너무 바빴어요. 내일 꼭 **할게요**. | ขอโทษค่ะ เมื่อวานยุ่งมาก พรุ่งนี้จะทำแน่ ๆ | 활동 (357쪽) 선생님–학생 |
| 책은 가지고 왔어요? — 아니요, 안 가지고 왔어요. 내일은 꼭 가지고 **올게요**. | เอาหนังสือมาไหม — ไม่ได้เอามา พรุ่งนี้จะเอามาแน่ ๆ | 활동 (357쪽) |

| 그럼 제가 창문을 **닦을게요**. | งั้นฉันจะเช็ดหน้าต่างเอง | 37 활동 |

- 꼭 = แน่ ๆ (ในกิจกรรม 357쪽)

### ⚠️ จุดสับสน

-(으)ㄹ게요 ถูกใช้ผิดกับประธานที่ไม่ใช่ผู้พูดบ่อยที่สุด และสับสนกับ -(으)ㄹ 거예요 ที่บอกแผนทั่วไป ตารางแรกเทียบความหมายของสี่รูป ตารางที่สองรวมรูปที่ถูกกับรูปที่ผิด

#### -(으)ㄹ게요 vs -(으)ㄹ 거예요 vs -겠- vs -(으)ㄹ까요?

สี่รูปนี้ล้วนพูดถึงอนาคต แต่ต่างกันที่ว่าเป็นสัญญา แผน ความตั้งใจทางการ หรือการชวน

| รูป | ความหมาย | ประธาน | ตัวอย่าง |
|:---|:---|:---|:---|
| **-(으)ㄹ게요** | **สัญญา/อาสา**ต่อหน้าผู้ฟัง (ตัดสินใจ ณ ตอนพูด ผูกกับผู้ฟัง) | **ผู้พูดเท่านั้น** | 제가 할게요 *(ฉันทำเอง)* |
| -(으)ㄹ 거예요 (ข้อ 28) | แผน/คาดเดา (ไม่ต้องเกี่ยวกับผู้ฟัง) | ทุกบุรุษ | 내일 할 거예요 *(พรุ่งนี้จะทำ — แผน)* |
| -겠- (ข้อ 22) | ตั้งใจ ณ ตอนนั้นแบบทางการ | ผู้พูด | 제가 하겠습니다 *(ดิฉันจะทำ — ทางการ)* |
| -(으)ㄹ까요? (ข้อ 33) | **ชวน/เสนอ** ถามความเห็น | 우리 / 제가 (เสนอ) | 제가 열까요? *(ให้ฉันเปิดไหม)* |

#### กับดัก

ตารางนี้รวมรูปที่ถูกและรูปที่ผิดที่พบบ่อย พร้อมเหตุผลสั้น ๆ ส่วนข้อที่ไม่ใช่คู่ ✓/✗ อยู่ในรายการด้านล่าง

| ประเด็น | ✓ ถูก | ✗ ผิด | หมายเหตุ |
|:---|:---|:---|:---|
| บุคคลที่ 2/3 | 친구가 갈 거예요 | 친구가 갈게요 · 선생님이 오실게요 | ตำรา 354쪽 "ประธานต้องเป็นผู้พูด" — ใช้ -(으)ㄹ 거예요 (ข้อ 28) |
| ถามผู้ฟังตรง ๆ | 언제 갈 거예요? | 언제 갈게요? | ใช้ -(으)ㄹ 거예요? ถามแผน |
| ตัวสะกด | 읽을게요 · 앉을게요 · 먹을게요 | 읽게요 · 앉게요 · 먹게요 | ลืม 을 — กับดักเดียวกับ 읽세요 · 받십니다 · 씻러 · 먹까요 |
| ㄹ-ราก | 만들게요 · 열게요 · 살게요 (อยู่) | 만들을게요 · 열을게요 | ✓ 열게요 *(เปิด)* ≠ 열어요 |
| สะกดผิด | 갈게요 | 갈께요 · 갈거예요 · 갈게예요 | ㄱ ไม่ใช่ ㄲ · ไม่มี 예 · ไม่เกี่ยวกับ 거예요 |
| ㄷ / ㅂ ไม่ปกติ | 들을게요 *(ฟัง)* · 도울게요 *(ช่วย)* | 듣을게요 · 돕을게요 | ข้อ 51 · 37 |
| tense / -(으)시- | — | 갔을게요 · 가실게요 | ตำราไม่มีรูปเหล่านี้ |

- **คำถาม 뭐 할 거예요? ต้องตอบด้วย -(으)ㄹ 거예요:**
  - ✓ 내일은 공부할 거예요
  - ✗ 내일은 공부할게요 (ฟังเหมือนสัญญากับผู้ถาม)
  - ✓ 이따가 다시 전화할게요 *(สัญญาว่าจะโทรกลับ)* ↔ 언제 전화할 거예요? *(ถามแผน)*
- **ถามเสนอตัวแล้วตอบรับ:** **제가 열까요?** (ข้อ 33) · ผู้ฟังตอบ **네, 열어 주세요** (ข้อ 63) · ผู้พูดตัดสินเอง **제가 열게요**

> [!TIP] กฎสั้น ๆ
> - **-(으)ㄹ게요 = "ฉันจะ…นะ"** (สัญญา/อาสา กับผู้ฟัง · ประธาน = ฉัน)
> - ตัวสะกด → 을게요 · สระ → ㄹ게요 · ㄹ → 게요
> - **ถามแผนผู้ฟัง = -(으)ㄹ 거예요? ไม่ใช่ -(으)ㄹ게요?**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

-(으)ㄹ게요 ออกจริงแล้วใน 매일시험 36과 ส่วน B (ถูกครบ 4 ข้อ) และมีในใบฝึกกับชุดทบทวนปลายภาค รายการแยกตามแหล่งที่มา

- **매일시험 36과 (17 พ.ย. · ส่วน B ได้ 4/4):** เติมบทสนทนา ข้อละ 1 คะแนน
  - 전화할게요 ✓ *(เดี๋ยวจะโทรให้ — มาจากเวิร์กบุ๊ก F ข้อแรก)*
  - 내일 일찍 올게요 ✓ *(พรุ่งนี้จะมาเช้า — ตรง [보기] ของเวิร์กบุ๊ก F)*
  - 안 피울게요 ✓ *(จะไม่สูบ — มาจากใบฝึกหน้า 4 ข้อแรก)*
  - 열게요 ✓ *(จะเปิดเอง — ราก ㄹ มี ㄹ ตัวเดียว · มาจากเวิร์กบุ๊ก F ข้อสี่)*
- **연습지 36 (16 พ.ย.):** ถูกทุกช่อง
  - หน้า 3 ตาราง 12 ช่อง ตัวสะกด: 입을게요 · 읽을게요 · 앉을게요 · 받을게요 · 닫을게요 ✓ *(ต้องมี 을)*
  - หน้า 3 ไม่ปกติ: 걸을게요 ✓ *(ㄷ → ㄹ ยังมี 을)* · 도울게요 ✓ *(ㅂ → 우)* · 고를게요 ✓ *(르 ไม่เปลี่ยนก่อน ㄹ)*
  - หน้า 3 ราก ㄹ และสระ: 살게요 · 열게요 ✓ *(ㄹ ตัวเดียว)* · 켤게요 · 끌게요 ✓
  - หน้า 4 เลือก -(으)ㄹ게요 หรือ -(으)ㄹ 거예요 8 ข้อ ✓ *(รับปาก → 안 피울게요 · 가지고 올게요 · 마실게요 · 할게요 · 안 할게요 · 살게요)*
  - หน้า 4 ตอบคำถามแผนใช้ -(으)ㄹ 거예요 ✓ *(뭐 먹을 거예요? → 먹을 거예요 · 어디에 갈 거예요? → 갈 거예요)*
- **워크북 36과:** ส่วน E F G สแกนเป็นหน้าเปล่า ไม่มีบันทึกการตรวจ
- **ชุดทบทวนปลายภาค (เฉลยเป็นของ AI ไม่ใช่ของครู):** ข้อ 6-10 *(네, … -(으)ㄹ게요)* · ข้อ 4-3 *(쇼핑하러 명동에 갈 거예요 หรือ 갈게요)* · ข้อ 4-4 *(이따가 전화할 거예요 หรือ 전화할게요)* และข้อ 2-2 พิมพ์ 일찍 올게요 ไว้ในประโยค

> [!SUMMARY] สรุป
> - -(으)ㄹ게요 = "ฉันจะ…นะ" สัญญา/อาสา/ขออนุญาตง่าย ๆ ต่อหน้าผู้ฟัง ประธานต้องเป็นผู้พูดเท่านั้น
> - ตัวสะกด → **-을게요** (읽을게요) · สระ → **-ㄹ게요** (갈게요) · ㄹ → **-게요** (만들게요) และสะกดด้วย ㄱ ไม่ใช่ ㄲ (✗ 갈께요)
> - ถามแผนของผู้ฟังใช้ -(으)ㄹ 거예요? ไม่ใช่ -(으)ㄹ게요? และไม่ใส่ -(으)시- หรือ tense (✗ 가실게요 · ✗ 갔을게요)
> - ที่ต้องระวัง: ลืม 을 (✗ 읽게요) · ใช้กับบุคคลที่ 3 ✗ · เขียนติดกัน (갈거예요)
