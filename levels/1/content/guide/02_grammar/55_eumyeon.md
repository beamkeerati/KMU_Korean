## 55. -(으)면 (ถ้า… / เมื่อ…)

> [!INTRO] ข้อนี้คืออะไร
> -(으)면 ต่อท้ายรากของ**กริยาและคำคุณศัพท์**เพื่อบอก**เงื่อนไข** คือ "ถ้า A เกิดขึ้น ก็ B" ใช้ได้ทั้งกับเรื่องที่ยังไม่เกิด (แผน) และเรื่องที่เป็นนิสัยหรือความจริง ("เมื่อไรที่ A ก็ B เสมอ") ตำราเรียกว่า condition หรือ presupposition
>
> สอนในบท 33 (ตำราหน้า 324–325 준비 1) ต่อยอดจากข้อ 06 (หารากศัพท์) ข้อ 28 (กฎ "มีตัวสะกดไหม" แบบเดียวกัน) ข้อ 18 (คำคุณศัพท์) และข้อ 33 (-(으)ㄹ까요? ใช้เป็นประโยคหลักได้)
>
> ไปใช้ต่อในข้อ 56 (-(으)ㄹ 때 "ตอนที่…") ข้อ 61 (-(으)ㄴ/는데요) ข้อ 62 (-(으)ㄹ게요) ข้อ 64 (-아/어야 하다) และบท 36 (연습 3 오늘 숙제를 안 하면……) อยู่ในขอบเขต 복습시험④ (11/18) และ 기말

### 📌 รูปแบบและเงื่อนไข

ให้ตัด 다 ออก แล้วดู**พยางค์สุดท้ายของราก**ว่ามีตัวสะกด (받침) หรือไม่ ตำรา 324쪽 บอกว่า ตัวสะกด → **-으면** และ สระ หรือ **ㄹ** → **-면**

| รากศัพท์ลงท้าย | ต่อ | ตัวอย่าง |
|:---|:---|:---|
| มีตัวสะกด (รวม 있다 · 없다) | **-으면** | 먹다 → **먹으면** · 있다 → **있으면** · 좋다 → **좋으면** |
| สระ | **-면** | 오다 → **오면** · 되다 → **되면** · 가다 → **가면** |
| ลงท้ายด้วย **ㄹ** | **-면** (ㄹ ไม่หลุด ไม่ใส่ 으) | 살다 → **살면** · 만들다 → **만들면** · 놀다 → **놀면** |
| ㅂ ไม่ปกติ (ข้อ 37) | ㅂ → **우** + 면 | 춥다 → **추우면** · 덥다 → **더우면** · 쉽다 → **쉬우면** |
| ㄷ ไม่ปกติ (ข้อ 51) | ㄷ → **ㄹ** + 으면 | 듣다 → **들으면** · 걷다 → **걸으면** |
| 르 (ข้อ 54) | ไม่เปลี่ยน — 르 เปลี่ยนเฉพาะก่อน 아/어 | 모르다 → **모르면** · 다르다 → **다르면** · 빠르다 → **빠르면** |
| N이다 (เสริม ไม่อยู่ในกล่องตำรา) | N**이면** (หลังสระพูดว่า N**면** ได้) | 학생**이면** · 의사**면** |

#### ตารางผันที่ควรจำ (ตำรา 33과)

ตารางนี้รวมคำที่ใช้ในข้อนี้ทั้งหมด จัดตามกฎข้างบน ช่อง "ความหมาย" แปลเป็นรูป "ถ้า…"

| 기본형 | -(으)면 | ความหมาย | กฎที่ใช้ |
|:---|:---|:---|:---|
| 먹다 | **먹으면** | ถ้ากิน | มีตัวสะกด |
| 있다 | **있으면** | ถ้ามี | มีตัวสะกด |
| 없다 | **없으면** | ถ้าไม่มี | มีตัวสะกด |
| 좋다 | **좋으면** | ถ้าดี | มีตัวสะกด |
| 오다 | **오면** | ถ้ามา | สระ |
| 되다 | **되면** | ถ้าเป็น/ถึง | สระ |
| 가다 | **가면** | ถ้าไป | สระ |
| 부르다 | **부르면** | ถ้าอิ่ม | สระ |
| 살다 | **살면** | ถ้าอยู่ | ㄹ ไม่หลุด |
| 만들다 | **만들면** | ถ้าทำ | ㄹ ไม่หลุด |
| 놀다 | **놀면** | ถ้าเล่น | ㄹ ไม่หลุด |
| 춥다 | **추우면** | ถ้าหนาว | ㅂ → 우 |
| 덥다 | **더우면** | ถ้าร้อน | ㅂ → 우 |
| 쉽다 | **쉬우면** | ถ้าง่าย | ㅂ → 우 |
| 돕다 | **도우면** | ถ้าช่วย | ㅂ → 우 |
| 듣다 | **들으면** | ถ้าฟัง | ㄷ → ㄹ |
| 걷다 | **걸으면** | ถ้าเดิน | ㄷ → ㄹ |
| 모르다 | **모르면** | ถ้าไม่รู้ | 르 ไม่เปลี่ยน |
| 다르다 | **다르면** | ถ้าต่าง | 르 ไม่เปลี่ยน |
| 빠르다 | **빠르면** | ถ้าเร็ว | 르 ไม่เปลี่ยน |
| 학생 + 이다 | 학생**이면** | ถ้าเป็นนักเรียน | N이다 (เสริม) |
| 의사 + 이다 | 의사**면** | ถ้าเป็นหมอ | N이다 (เสริม) |

#### ตำรา 324쪽 และข้อควรจำ

ส่วนนี้สรุปสิ่งที่ตำราบอกไว้ในกล่องไวยากรณ์ และข้อสังเกตเรื่องประโยคหลัก กาล และประธานของประโยคเงื่อนไข

- **ตำรา 324쪽:** กล่องไวยากรณ์เขียนว่า "ต่อหลังรากของกริยาหรือคำคุณศัพท์ — แสดงความหมายเงื่อนไข (condition) หรือข้อสมมติ (presupposition)"
- **ประโยคหลัก (หลัง -(으)면) ได้ทุกแบบ:**
  - -아/어요 (นิสัย/ความจริง)
  - -(으)ㄹ 거예요 (แผน ข้อ 28)
  - -(으)세요 (สั่ง/แนะนำ ข้อ 20)
  - -(으)ㄹ까요? (ชวน ข้อ 33)
  - -(으)ㅂ시다 (ชวนแบบทางการ — ตำรา 324쪽 ใช้ในตัวอย่าง 만납시다 แต่ยังไม่มีข้อไวยากรณ์ของตัวเอง)
- **กาล (tense) ใส่ที่ท้ายประโยคเท่านั้น** ไม่ใส่ที่ 면
  - ✓ 비가 오면 집에 있을 거예요 *(ถ้าฝนตกจะอยู่บ้าน)*
  - ✗ 비가 올 거면… *(ในตำรา 33과 ไม่มี)*
  - รูป -았/었으면 "ถ้าได้…แล้ว/ถ้าหากเคย…" มีจริงแต่**ตำราไม่สอน** (เสริม)
- **ประธานของประโยคเงื่อนไข** ใช้ 이/가 (ข้อ 01)
  - 시간**이** 있으면 *(ถ้ามีเวลา)*
  - 비**가** 오면 *(ถ้าฝนตก)*
  - 기분**이** 나쁘면 *(ถ้าอารมณ์ไม่ดี)*
  - ส่วนประธานของประโยคหลักมักเป็น 저는 (หัวเรื่อง)

#### สูตรและวิธีทำ: -(으)면 (แบบกระดานครู)

-(으)면 ต่อกับรากของกริยาหรือคำคุณศัพท์ ต้องตัดสินใจตามลำดับสองเรื่อง คือรากเป็น ㅂ หรือ ㄷ ไม่ปกติหรือไม่ แล้วจึงดูตัวสะกดเพื่อเลือกระหว่าง 면 กับ 으면

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | ราก ㅂ ไม่ปกติ (춥 และ 덥) | เปลี่ยน **ㅂ เป็น 우** แล้วต่อ **면** | ㅂ กับ 으 หลอมเป็น 우 จึงไม่ใส่ 으 ซ้ำ |
| **กฎ 2** | ราก ㄷ ไม่ปกติ (듣 และ 걷) | เปลี่ยน **ㄷ เป็น ㄹ** แล้วต่อ **으면** | ตัวต่อ (으) ขึ้นต้นด้วยสระ จึงเข้ากฎ ㄷ → ㄹ และยังใส่ 으 เพราะไม่ใช่ราก ㄹ จริง |
| **กฎ 3** | รากอื่นที่ **มีตัวสะกด** (รวม 있 และ 없) | ต่อ **으면** | 으 รองรับตัวสะกด |
| **กฎ 4** | รากอื่นที่ **ไม่มีตัวสะกด** หรือลงท้ายด้วย **ㄹ เดิม** | ต่อ **면** | ㄹ เดิมนับเหมือนไม่มีตัวสะกด และไม่หลุดเพราะ ㅁ ไม่ใช่ ㄴ ㅂ ㅅ ㄹ |

ลำดับทำคือ ① เปลี่ยนรากไม่ปกติ (ㅂ → 우 และ ㄷ → ㄹ) ② ดูตัวสะกดของรากที่ได้ โดยให้ ㄹ เดิมนับว่าไม่มี แต่ ㄹ ที่มาจาก ㄷ นับว่ามี ③ ต่อ 면 หรือ 으면 ตารางนี้แสดงทุกขั้นกับคำที่ตำรารวมทั้ง 르

| ราก + (으)면 | ① เปลี่ยนราก | ② ตัวสะกด | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 가 + (으)면 | ไม่เปลี่ยน | ไม่มี | **가면** | ถ้าไป |
| 되 + (으)면 | ไม่เปลี่ยน | ไม่มี | **되면** | 방학이 되면 |
| 먹 + (으)면 | ไม่เปลี่ยน | มี (ㄱ) | **먹으면** | ✗ 먹면 (ลืม 으 เหมือน ✗ 읽세요) |
| 좋 + (으)면 | ไม่เปลี่ยน | มี (ㅎ) | **좋으면** | ✗ 좋면 |
| 있 + (으)면 | ไม่เปลี่ยน | มี (ㅆ) | **있으면** | ✗ 있면 |
| 없 + (으)면 | ไม่เปลี่ยน | มี (ㅄ) | **없으면** | ✗ 없면 |
| 살 + (으)면 | ไม่เปลี่ยน | ㄹ เดิม ไม่นับ | **살면** | ✗ 살으면 และ ✗ 사면 (사면 = ถ้าซื้อ) |
| 만들 + (으)면 | ไม่เปลี่ยน | ㄹ เดิม ไม่นับ | **만들면** | ✗ 만들으면 (เหมือน ✗ 만들으세요) |
| 놀 + (으)면 | ไม่เปลี่ยน | ㄹ เดิม ไม่นับ | **놀면** | ✗ 노면 |
| 춥 + (으)면 | ㅂ → 우 (추우) | ลงท้ายสระ ไม่มี | **추우면** | ✗ 춥으면 |
| 덥 + (으)면 | ㅂ → 우 (더우) | ลงท้ายสระ ไม่มี | **더우면** | ✗ 덥으면 |
| 듣 + (으)면 | ㄷ → ㄹ (들) | ㄹ จาก ㄷ นับว่ามี | **들으면** | ✗ 들면 |
| 걷 + (으)면 | ㄷ → ㄹ (걸) | ㄹ จาก ㄷ นับว่ามี | **걸으면** | ✗ 걸면 |
| 모르 + (으)면 | ไม่เปลี่ยน (르 เปลี่ยนเฉพาะก่อน 아/어) | ไม่มี | **모르면** | ✗ 몰라면 |

> [!TIP] วิธีจำสั้น ๆ
> เห็น ㄹ ให้ถามก่อนว่า ㄹ ตัวนี้เป็นของรากเดิมหรือมาจาก ㄷ ถ้าเป็นของเดิม (살 และ 만들) ใช้ 면 ถ้ามาจาก ㄷ (들 และ 걸) ใช้ 으면 ส่วน ㅂ เปลี่ยนเป็น 우 ก่อนเสมอ (추우면)

### 📖 ตัวอย่างและการใช้

ตัวอย่างเรียงตามลำดับในตำราบท 33 ต่อด้วยบท 36 สังเกตว่าประโยคเงื่อนไขอยู่หน้า ประโยคผลอยู่หลัง และประธานของประโยคเงื่อนไขใช้ 이/가

#### ตัวอย่างจากกล่องไวยากรณ์และ 준비 (324쪽)

ห้าตัวอย่างนี้มาจากกล่องไวยากรณ์และ 준비 1 ของหน้า 324

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 비가 **오면** 그 사람이 생각나요. | ถ้าฝนตก จะนึกถึงคนคนนั้น (생각나다 ใช้ 이/가 กับสิ่งที่นึกถึง) | กล่อง/준비 324쪽 |
| 오늘 시간이 **없으면** 다음에 만납시다. | ถ้าวันนี้ไม่มีเวลา ไว้เจอกันคราวหน้า | กล่อง/준비 324쪽 |
| 돼지고기를 **먹으면** 배가 아파요. | ถ้ากินเนื้อหมู จะปวดท้อง | กล่อง/준비 324쪽 |
| 배가 **부르면** 그만 드세요. | ถ้าอิ่มแล้วก็หยุดทานเถอะ (드세요 = 먹다 แบบยกย่อง ข้อ 20) | กล่อง/준비 324쪽 |
| 가: 기차표가 **없으면** 어떻게 해요? — 나: 기차표가 **없으면** 버스로 갈 거예요. | ถ้าไม่มีตั๋วรถไฟทำยังไง — ถ้าไม่มีตั๋วรถไฟ จะไปด้วยรถบัส | กล่อง/준비 324쪽 |

#### แบบฝึก: เงื่อนไข → ผลลัพธ์ (연습 1–3, 324–325쪽)

ตำราให้คู่คำ "A / B" เป็นรูปฐาน (방학이 되다 / 아르바이트를 하다) แล้วให้ผู้เรียนต่อเป็นประโยคเอง ประโยคข้างล่างเรียบเรียงตามรูปแบบ 보기 ของตำรา

| ประโยค (A -(으)면 B) | แปล |
|:---|:---|
| 방학이 **되면** 아르바이트를 할 거예요. | ถึงช่วงปิดเทอมจะทำงานพิเศษ |
| 고향에 **가면** 어머니께서 만든 음식을 먹을 거예요. | ถ้ากลับบ้านเกิดจะกินอาหารที่คุณแม่ทำ |
| 용돈을 **받으면** 운동화를 살 거예요. | ถ้าได้เงินค่าขนมจะซื้อรองเท้ากีฬา |
| 기분이 **나쁘면** 클래식 음악을 들어요. | ถ้าอารมณ์ไม่ดีจะฟังเพลงคลาสสิก |
| 날씨가 **좋으면** 등산을 해요. | ถ้าอากาศดีจะไปปีนเขา |
| 시간이 **있으면** 소설을 읽어요. | ถ้ามีเวลาจะอ่านนิยาย |
| 스트레스가 **많으면** 많이 먹어요. | ถ้าเครียดมากจะกินเยอะ |
| 비가 **오면** 따뜻한 커피를 마셔요. | ถ้าฝนตกจะดื่มกาแฟร้อน |
| 부모님이 **보고 싶으면** 가족사진을 봐요. | ถ้าคิดถึงพ่อแม่จะดูรูปครอบครัว |
| 100만 원이 **있으면** 노트북을 사고 싶어요. | ถ้ามีหนึ่งล้านวอนอยากซื้อโน้ตบุ๊ก |

- **연습 3 (325쪽):** คำถามตัวแกน "…(으)면 뭘 하고 싶어요?" คำตอบ "저는 …(으)면 …을/를 V-고 싶어요" (ข้อ 38) โจทย์ที่ให้มีดังนี้
  - 비행기가 있다 *(มีเครื่องบิน)*
  - 졸업하다 *(เรียนจบ)*
  - 100만 원이 있다 *(มีเงินหนึ่งล้านวอน)*
  - 남자(여자) 친구가 생기다 *(มีแฟน)*
  - 날씨가 맑다 *(อากาศแจ่มใส)*
  - 영화배우가 되다 *(ได้เป็นดาราหนัง)*
- **연습 3 ของบท 36 (355쪽):** ฝึกสัญญาด้วยประโยคเงื่อนไขที่ค้างไว้ ให้ต่อด้วย -(으)ㄹ게요 (ข้อ 62)
  - 오늘 숙제를 안 하면…… *(ถ้าวันนี้ไม่ทำการบ้าน…)*
  - 시험에서 1등을 하면…… *(ถ้าสอบได้ที่ 1…)*
  - 선생님/친구 생일에…… *(ในวันเกิดอาจารย์/เพื่อน…)*
  - 고향에 돌아가면…… *(ถ้ากลับบ้านเกิด…)*
  - ตัวอย่างที่ต่อแล้ว: 숙제를 안 하면 벌을 받을게요 *(ถ้าไม่ทำการบ้านจะยอมรับโทษ)*

#### ในบทสนทนา · บทอ่าน · กิจกรรม (328–331쪽)

ประโยค -(으)면 ในบทสนทนา บทอ่าน และกิจกรรมของบท 33 และ 36 มีดังนี้ แต่ละแถวบอกที่มาและข้อไวยากรณ์ที่ใช้ร่วมกัน

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 윤아: 투이 씨, 방학을 **하면** 부산으로 여행을 갈까요? | คุณทุย พอปิดเทอมแล้วไปเที่ยวปูซานกันไหม (방학을 하다 = เริ่มปิดเทอม · 으로 ข้อ 49/51 · -(으)ㄹ까요? ข้อ 33) | บทสนทนา |
| 투이: 그렇지만 예약할 수 **없으면** 어떻게 해요? | แต่ถ้าจองไม่ได้จะทำยังไง (-(으)ㄹ 수 없다 ข้อ 46) | บทสนทนา |
| 윤아: 걱정하지 마세요. 버스로도 갈 수 있어요. | อย่ากังวล ไปรถบัสก็ได้ (-지 마세요 ข้อ 39) | บทสนทนา |
| 제프리: 오전에 출발하는 비행기표가 **없으면** 오후 2시 표로 주세요. | ถ้าไม่มีตั๋วเครื่องบินออกเช้า ขอตั๋วบ่ายสองโมง (ข้อ 63) | 33-2 |
| 아침에 일찍 일어나**면** 한식을 먹을 거예요. 그렇지만 늦게 일어나**면** 샌드위치를 먹을 거예요. | ถ้าตื่นเช้าจะกินอาหารเกาหลี แต่ถ้าตื่นสายจะกินแซนด์วิช | 마키 씨의 일정표 (329쪽) |
| 저는 방학을 **하면** 남자 친구하고 같이 부산에 갈 거예요. | ถ้าปิดเทอมฉันจะไปปูซานกับแฟน | 마키 씨의 일정표 (329쪽) |
| 시간이 **있으면** 마키 씨하고 같이 영화를 보러 가고 싶어요. | ถ้ามีเวลาอยากไปดูหนังกับคุณมากิ (-(으)러 ข้อ 26) | 36과 대화 |

ตำรายังมีตารางให้ต่อประโยคเป็นห่วงโซ่เงื่อนไข ซึ่งประโยคตัวอย่างด้านล่างเรียบเรียงตามตาราง

| | เงื่อนไข | ผลที่ตามมา |
|:---|:---|:---|
| 갈 곳 | 날씨가 좋아요 / 비가 와요 | 바다에 가요 / 국제시장에 가요 |
| 할 일 | 바다에 가요 / 국제시장에 가요 | 수영을 해요 / 기념품을 사요 |

- 날씨가 좋으면 바다에 가요. *(ถ้าอากาศดีไปทะเล)*
- 바다에 가면 수영을 해요. *(ถ้าไปทะเลจะว่ายน้ำ)*

#### ตอบคำถามที่มี -(으)면

คำถามที่มี -(으)면 มีสามแบบหลัก ตอบด้วยประโยคเงื่อนไขซ้ำแล้วตามด้วยผลตามชนิดของคำถาม

| ถามด้วย | ตอบเป็น | ตัวอย่าง |
|:---|:---|:---|
| …(으)면 **뭘 해요?** | …(으)면 + กิจกรรมที่ทำเป็นนิสัย (-아/어요) | 가: 시간이 있으면 뭘 해요? — 나: 저는 시간이 있으면 소설을 읽어요. *(ถ้ามีเวลาทำอะไร — ถ้ามีเวลาฉันอ่านนิยาย)* |
| …(으)면 **뭘 하고 싶어요?** | …(으)면 + N을/를 V-고 싶어요 | 가: 100만 원이 있으면 뭘 하고 싶어요? — 나: 100만 원이 있으면 노트북을 사고 싶어요. *(ถ้ามีหนึ่งล้านวอนอยากทำอะไร — อยากซื้อโน้ตบุ๊ก)* |
| …(으)면 **어떻게 해요?** | …(으)면 + วิธีแก้ (-(으)ㄹ 거예요) | 가: 기차표가 없으면 어떻게 해요? — 나: 버스로 갈 거예요. *(ถ้าไม่มีตั๋วรถไฟทำยังไง — จะไปรถบัส)* |

### ⚠️ จุดสับสน

ความสับสนหลักคือ -(으)면 ที่แปลว่า "ถ้า" ต้องแยกจาก -(으)ㄹ 때 ที่แปลว่า "ตอนที่" และจาก -아/어서 กับ -(으)니까 ที่แปลว่า "เพราะ" ส่วนข้อผิดอื่นเป็นเรื่องรูปสะกด ตารางแรกสรุปคู่ ✓ ถูก / ✗ ผิด ที่เจอบ่อย

| กรณี | ✓ ถูก | ✗ ผิด |
|:---|:---|:---|
| ตัวสะกด | 먹으면 · 좋으면 | 먹면 · 좋면 |
| ㄹ-ราก | 살면 · 만들면 | 살으면 · 만들으면 |
| ㅂ ไม่ปกติ | 추우면 · 더우면 | 춥으면 · 덥으면 |
| 되다 | 영화배우가 되면 | 영화배우를 되면 |
| 안 + N하다 | 숙제를 안 하면 | 안 숙제하면 |
| กาล | 비가 오면 집에 있을 거예요 | 비가 올 거면… |

#### -(으)면 vs -(으)ㄹ 때 vs -아/어서 vs -(으)니까

ตารางนี้เทียบความหมายของสี่รูปที่ผู้เรียนมักสับสนว่าจะเลือกใช้รูปไหน

| | ความหมาย | ตัวอย่าง |
|:---|:---|:---|
| **-(으)면** | **ถ้า** (เงื่อนไข) / เมื่อไรก็ตามที่ | 시간이 있으면 소설을 읽어요 *(ถ้ามีเวลาจะอ่านนิยาย)* |
| -(으)ㄹ 때 (ข้อ 56) | **ตอนที่** (ช่วงเวลา ไม่ใช่เงื่อนไข) | 부산에 갈 때 무엇을 준비할 거예요? *(ตอนไปปูซานจะเตรียมอะไร)* |
| -아/어서 (ข้อ 48) | **เพราะ…** (เหตุผล เกิดขึ้นจริงแล้ว) | 시험이 있어서 공부해야 해요 *(เพราะมีสอบ ต้องอ่านหนังสือ)* |
| -(으)니까 (ข้อ 50) | **เพราะ…** (ใช้นำหน้าสั่ง/ชวนได้) | 가게가 많으니까 쇼핑을 해 보세요 *(เพราะร้านเยอะ ลองช็อปปิงดู)* |

- **-(으)면 = ยังไม่แน่ว่าจะเกิดไหม** ส่วน -아/어서 = เกิดขึ้นแล้ว/เป็นความจริง
  - ✓ 비가 오면 안 가요 *(ถ้าฝนตกจะไม่ไป)*
  - ≠ 비가 와서 안 가요 *(ฝนตกเลยไม่ไป)*

#### กับดัก

ข้อผิดของข้อนี้ส่วนใหญ่เป็นเรื่องตัวสะกด ㄹ ㅂ และการเลือก 이/가 ไล่ดูทีละข้อ

- **ตัวสะกด:** ลืม 으 หลังตัวสะกด (เคยเกิดซ้ำกับ -(으)세요 · -(으)러 · -(으)ㄹ까요?)
  - ✓ 먹으면 / ✗ 먹면
  - ✓ 있으면 / ✗ 있면
  - ✓ 좋으면 / ✗ 좋면
- **ㄹ-ราก:** เหมือน 만들 거예요 ใน ข้อ 28
  - ✓ 살면 / ✗ 살으면
  - ✓ 만들면 / ✗ 만들으면
- **ㅂ ไม่ปกติ:** (ข้อ 37)
  - ✓ 추우면 / ✗ 춥으면
  - ✓ 더우면 / ✗ 덥으면
- **되다 ใช้ 이/가:** ✓ 영화배우**가** 되면 · 방학**이** 되면 / ✗ 영화배우를 되면 — กลับด้านกับกับดัก "ใช้ 가 กับ 받다/듣다" ที่เคยพลาด เพราะ 되다 รับ 이/가 ไม่ใช่ 을/를
- **안 + N하다:** ✓ 숙제를 안 하면 / ✓ 숙제 안 하면 / ✗ 안 숙제하면 (ข้อ 08 — เคยพลาด 안 아르바이트 해요)
- **ประโยคหลักเป็นคำถาม:** ได้ เช่น 방학을 하면 부산으로 여행을 갈까요? แต่ถ้าถามด้วย -(으)ㄹ 거예요? จะเป็นการถามแผนของผู้ฟัง ไม่ใช่ชวน (ข้อ 33)
- **그러면 / 그럼** ต้นประโยค = "ถ้าอย่างนั้น" เป็นรูปหดของ 그렇(다)+(으)면
  - 그럼 다음에 같이 식사해요 *(งั้นไว้กินข้าวด้วยกันคราวหน้า — ตำรา 36과 353쪽)*

> [!TIP] กฎสั้น ๆ
> **-(으)면 = "ถ้า"** (ตัวสะกด → 으면 · สระ/ㄹ → 면) · **-(으)ㄹ 때 = "ตอนที่"** · **-아/어서 = "เพราะ"** — ตัดสินจากความหมายก่อน แล้วค่อยเลือกรูป

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

-(으)면 ออกจริงแล้วใน 매일시험 33과 ส่วน A และมีทั้งในใบฝึก เวิร์กบุ๊ก และชุดทบทวนปลายภาค รายการข้างล่างแยกตามแหล่งที่มา พร้อมข้อที่ผู้เรียนเคยพลาด

- **매일시험 33과 (12 พ.ย. · ส่วน A ได้ 3.5/4):**
  - 날씨가 좋으면 등산을 해요 ✓ *(ถ้าอากาศดีก็ปีนเขา)*
  - 김치가 매우면 먹지 마세요 ✓ *(ถ้ากิมจิเผ็ดก็อย่ากิน — ㅂ 불규칙 เวิร์กบุ๊กเคยผิด)*
  - 방학이 되면 아르바이트 할 거예요 *(รูป 되면 ✓ แต่เขียน 아르바으트 ✗ → **아르바이트**)*
  - 돈이 있으면 컴퓨터를 사고 싶어요 ✓ *(ถ้ามีเงินอยากซื้อคอมพิวเตอร์)*
- **연습지 33 (11 พ.ย.) หน้า 1 ตารางจากภาพ 23 ช่อง ถูกครบ:**
  - 걸으면 · 도우면 · 가까우면 ✓ *(ㄷ และ ㅂ 불규칙)*
  - 열면 · 놀면 · 길면 ✓ *(ราก ㄹ ไม่เติม 으)*
  - 입으면 · 좁으면 ✓ *(ㅂ ปกติ ไม่เปลี่ยน)* · 학생이면 · 의사면 ✓
- **워크북 33과 (ตรวจ 11 พ.ย.):**
  - C ประโยค 3/4: 맵으면 ✗ → **매우면**
  - D: ข้อ 2–5 ตัดอนุประโยค -(으)면 ที่ [보기] ใช้ซ้ำ และตอบเป็นผลแทนที่จะตอบ 어떻게 해요?
- **ชุดทบทวนปลายภาค (เฉลยเป็นของ AI ไม่ใช่ของครู):**
  - ข้อ 3-1 *(비가 와요 / 파전을 많이 먹어요)* → 오면 ✓
  - ข้อ 6-12 *(… -(으)면 병원에 가세요)* → 아프면 ✓ *(ㅡ ไม่ตกเพราะ 면 ไม่ขึ้นต้นด้วย 아/어)*
  - ข้อ 6-2 ใช้ 있으면 เป็นคำถาม แล้วตอบด้วย -고 싶어요
- **복습시험④ (18 พ.ย.):** สอบแล้ว ผลยังไม่ออก ดูชุดเก็งใน KMU_Predict_miniexam04.pdf
