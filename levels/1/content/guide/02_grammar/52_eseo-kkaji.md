## 52. N에서 N까지 · 얼마나 걸려요? · 쯤 (จาก…ถึง… · ใช้เวลานานเท่าไร · ประมาณ)

> [!INTRO] ข้อนี้คืออะไร
> **N에서 N까지** บอก**จุดเริ่มและจุดสิ้นสุดของการเดินทางหรือระยะทาง** จากนั้นถามระยะเวลาด้วย **얼마나 걸려요?** และตอบด้วย **ตัวเลขเวลา + 쯤 + 걸려요** เช่น "ใช้เวลาประมาณ 30 นาที"
>
> สอนในบท 31 (ตำราหน้า 309 준비 2 หน้า 310 연습 2–3 และหน้า 311 대화) ต่อยอดจากข้อ 09 (에서 = ที่/จาก) ข้อ 27 (부터~까지 สำหรับ**เวลา**) ข้อ 25 (시 · 분 · 시간) ข้อ 04 (เลข 2 ระบบ) และข้อ 51 (พาหนะ + (으)로)
>
> ไปใช้ต่อในข้อ 53 (…에서 내려서 …) ข้อ 50 (31과 대화: 안내 방송을 하니까…) และงานพูดบอกทาง/เดินทาง (말하기)

### 📌 รูปแบบและเงื่อนไข

ข้อนี้ประกอบด้วยสามส่วนที่ใช้ด้วยกันในประโยคเดียว คือ จุดเริ่ม–จุดสิ้นสุด คำถามระยะเวลา และคำตอบที่มี 쯤

| ส่วน | รูป | ตัวอย่าง |
|:---|:---|:---|
| จุดเริ่ม → จุดสิ้นสุด (สถานที่) | **N에서 N까지** | 학교**에서** 길음역**까지** *(จากโรงเรียนถึงสถานีคิรึม)* · 서울**에서** 부산**까지** *(จากโซลถึงปูซาน)* |
| จุดเริ่ม → จุดสิ้นสุด (เวลา) | N**부터** N**까지** (ข้อ 27) | 9시**부터** 12시**까지** *(ตั้งแต่ 9 โมงถึงเที่ยง)* |
| ถามระยะเวลา | **얼마나 걸려요?** | 학교에서 길음역까지 **얼마나 걸려요**? *(จากโรงเรียนถึงสถานีคิรึมใช้เวลาเท่าไร)* |
| ตอบ | [พาหนะ(으)로] + [เวลา] + **쯤 걸려요** | 버스로 20분**쯤 걸려요**. *(ไปรถเมล์ใช้เวลาประมาณ 20 นาที)* |

#### ตำรา 309쪽

ตำราหน้า 309 อธิบายว่า 에서 ~까지 ใช้กับการเคลื่อนที่ ตัวอย่างในกล่องของตำราอยู่ในส่วน 📖 ข้างล่าง

- **ตำรา 309쪽:** 에서 ~까지 ต่อหลังนามเพื่อบอก **จุดเริ่มต้นและจุดสิ้นสุดของการเคลื่อนที่**
  - ตัวอย่างในกล่อง: 학교에서 집까지 멀지 않아요
  - ตัวอย่างในกล่อง: 서울에서 부산까지 기차로 2시간쯤 걸려요

#### เวลา 부터 ~ 까지 เทียบกับสถานที่ 에서 ~ 까지 (ตำรา 309쪽)

ตำรา 309쪽 วางสองสูตรเทียบกันเป็นสองคอลัมน์ ฝั่งซ้ายคือคำนามเวลาใช้ 부터 ~ 까지 ฝั่งขวาคือคำนามสถานที่ใช้ 에서 ~ 까지 ตัวหลังสุดคือ 까지 เหมือนกันทั้งคู่ ครูเขียนตัวอย่างไว้บนสไลด์ตามตารางนี้

| คำนามเวลา (부터 ~ 까지) | ไทย | คำนามสถานที่ (에서 ~ 까지) | ไทย |
|:---|:---|:---|:---|
| 1시부터 2시까지 | ตั้งแต่ 1 โมงถึง 2 โมง | 기숙사에서 교실까지 | จากหอพักถึงห้องเรียน |
| 오늘부터 내일까지 | ตั้งแต่วันนี้ถึงพรุ่งนี้ | 서울에서 부산까지 | จากโซลถึงปูซาน |
| 토요일부터 일요일까지 | ตั้งแต่วันเสาร์ถึงวันอาทิตย์ | 국민대에서 명동역까지 | จากมหาวิทยาลัยคุกมินถึงสถานีมยองดง |

#### ตัวเลขเวลา (ระยะเวลา)

การบอกระยะเวลาใช้เลขสองระบบต่างกัน ถ้าลืมให้ย้อนไปดูข้อ 04 และข้อ 25

- นาที = **เลขจีน + 분**
- ชั่วโมง = **เลขแท้ + 시간**
- เรียง **ชั่วโมงก่อน นาทีหลัง**
- **ไม่ใส่ 에**

| ระยะเวลา | อ่านเป็นคำ |
|:---|:---|
| 5분 | 오 분 |
| 30분 | 삼십 분 |
| 1시간 | 한 시간 |
| 2시간 30분 | 두 시간 삼십 분 *(= 두 시간 반)* |
| 13시간 30분 | 열세 시간 삼십 분 |

#### 쯤 (ประมาณ)

쯤 ต่อติดท้ายตัวเลขหรือปริมาณเพื่อบอกว่า "ประมาณ" โดยไม่เว้นวรรค

- **쯤** *(ประมาณ)* ต่อ**ติด**ท้ายตัวเลข/ปริมาณ ไม่เว้นวรรค
  - 30분쯤 · 2시간쯤 · 100m쯤 · 4m쯤
  - ตำรา 30과 อ่าน: 1초에 4m쯤 올라가는 엘리베이터 *(ลิฟต์ที่ขึ้นประมาณ 4 เมตรต่อวินาที)*

#### 얼마나 걸려요? และคำถามที่เกี่ยวข้อง

얼마나 แปลว่า "เท่าไร" ในแง่ปริมาณหรือระยะ ใช้คู่กับ 걸리다 ที่แปลว่า "ใช้เวลา" และผันตามกาลได้

- **얼마나** *(เท่าไร — ปริมาณ/ระยะ)* + **걸리다** *(ใช้เวลา)*
  - ปัจจุบัน: 걸려요
  - อดีต: 걸렸어요
  - อนาคต: 걸릴 거예요 *(ตำรา 31-2: 명동역에서 걸어서 5분쯤 걸릴 거예요)*
- **ถามเวลาแบบนับ (เสริม — ตำราใช้ 얼마나):** 몇 시간 걸려요? · 몇 분 걸려요?
- **ราคา:** ใช้ **얼마예요?** (ข้อ 04) — ✗ 얼마나 걸려요 = ถามเวลา ไม่ใช่ราคา

ตัวอย่างเรียงตามลำดับในตำราบท 31 ตั้งแต่กล่องหน้า 309 แบบฝึก 연습 1–3 กิจกรรม 활동 ไปจนถึงบทสนทนาและบทอ่าน สังเกตว่าทุกประโยคที่ตอบ 얼마나 걸려요? มีเลขเวลาและ 쯤 เสมอ

#### ถาม-ตอบ

คำถาม 어떻게 가요? ถามวิธีไป ส่วน 얼마나 걸려요? ถามระยะเวลา สองคำถามนี้มักมาคู่กัน ตำรา 307쪽 ใช้สูตร "สถานที่ 1 + 에서 / สถานที่ 2 + 까지" แล้วให้ดูสามบทสนทนาเรียงกัน คือถามวิธีไป ถามระยะทางด้วย 멀어요? แล้วถามระยะเวลา ใต้บทสนทนาที่สามครูเขียน 버스로 ด้วยมือพร้อมเครื่องหมายซ้ำ ซึ่งหมายถึงตอบเป็น 버스로 10분쯤 걸려요 ก็ได้

| ที่มา | คำถาม | คำตอบ |
|:---|:---|:---|
| 준비 2 | 학교에서 길음역까지 얼마나 걸려요? | 버스로 20분쯤 걸려요. *(จากโรงเรียนถึงสถานีคิรึมใช้เวลาเท่าไร — ไปรถเมล์ราว 20 นาที)* |

### ⚠️ จุดสับสน

คำถามที่สับสนกันง่ายในข้อนี้คือ 에서~까지 กับ 부터~까지 ที่ใช้ต่างกันตามสถานที่หรือเวลา และคำถามสี่คำที่ถามเรื่องใกล้กันแต่ต้องตอบต่างกัน ตารางแรกสรุปคู่ ✓ ถูก / ✗ ผิด ที่เจอบ่อย

| กรณี | ✓ ถูก | ✗ ผิด |
|:---|:---|:---|
| สถานที่ | 학교에서 집까지 | 학교부터 집까지 |
| เวลา | 9시부터 12시까지 | 9시에서 12시까지 |
| ระยะเวลา | 두 시간쯤 걸려요 | 두 시간에 걸려요 |
| เลขแท้ | 두 시간 · 열세 시간 | 이 시간 · 열셋 시간 |
| นาที | 삼십 분 | 서른 분 |
| 쯤 | 30분쯤 | 30분 쯤 |
| ตอบ 얼마나 | 버스로 20분쯤 걸려요 | 버스로 가요 · 900원이에요 |
| จุดเริ่ม | 학교에서 집까지 가요 | 학교 집까지 가요 · 학교에 집까지 |

#### 에서~까지 vs 부터~까지 และ 4 คำถามที่ใกล้กัน

ตารางนี้เทียบคำถามและรูปตอบ โดยดูว่าต้องการรู้สถานที่ เวลา ระยะเวลา ราคา หรือเวลาบนนาฬิกา

| | ถามอะไร | ตอบ/คำใช้ |
|:---|:---|:---|
| **에서 ~까지** (ข้อ 52) | จุดเริ่ม–จบของ**สถานที่** | 학교**에서** 집**까지** |
| **부터 ~까지** (ข้อ 27) | จุดเริ่ม–จบของ**เวลา** | 9시**부터** 12시**까지** |
| **얼마나 걸려요?** | **ระยะเวลา**ที่ใช้ | 20분쯤 걸려요 · 두 시간 걸려요 |
| **얼마예요?** (ข้อ 04) | **ราคา** | 천 원이에요 |
| **몇 시예요?** (ข้อ 25) | **กี่โมง** (ตำแหน่งบนนาฬิกา) | 세 시예요 |

- สถานที่ใช้ 에서 เวลาใช้ 부터 ส่วน 까지 ใช้ได้กับทั้งสอง
  - ✓ 학교**에서** 집까지 / ✗ 학교**부터** 집까지
  - ✓ 9시**부터** 12시까지 / ✗ 9시**에서** 12시까지
- ตอบ **얼마나 걸려요?** ด้วย**เวลา** ไม่ใช่ราคา พาหนะอย่างเดียว หรือสถานที่ *(ข้อผิดเดิม: ตอบไม่ตรงคำถาม เช่น 언제 → 가족을…)*
  - ✓ 버스로 20분쯤 걸려요
  - ✗ 버스로 가요 *(นั่นตอบ 어떻게 가요? ข้อ 51)*
  - ✗ 900원이에요 *(ราคา)*

#### กับดัก

ข้อผิดของข้อนี้เกี่ยวกับการสับ 시 กับ 시간 การเลือกเลขสองระบบ และการเว้นวรรค ไล่ดูทีละข้อ

- **시 vs 시간 (ข้อ 25):** 2시**에** *(ตอนสองโมง)* ≠ 2시간 *(สองชั่วโมง)* ระยะเวลาไม่ใส่ 에
  - ✓ 두 시간쯤 걸려요
  - ✗ 두 시간에 걸려요
- **เลขแท้ก่อน 시간:** เหมือน 열넷 명 → 열네 명
  - ✓ 두 시간 · 세 시간 · 열세 시간
  - ✗ 이 시간 · 삼 시간 · 십삼 시간
  - ✗ 열셋 시간
  - รูปย่อของเลขแท้: 하나→한 · 둘→두 · 셋→세
  - รูปย่อของเลขแท้: 넷→네 · 열셋→열세
- **นาที = เลขจีนเสมอ + 분:** ✓ 삼십 분 / ✗ 서른 분
  - ผู้เรียนเคยลืม 분 (사십오 이에요) และเขียนติด (두시 이십분)
  - เว้นวรรคเมื่อสะกดเป็นตัวอักษร: 두 시간 삼십 분
- **쯤 ติดตัวเลข:** ✓ 30분쯤 / ✗ 30분 쯤 · ถ้าเวลาเป๊ะ (ตามตาราง) ไม่ใส่ 쯤: 정확히 30분
- **걸리다 ≠ 걷다:** 걸려요 *(ใช้เวลา — 30분쯤 걸려요)* ≠ 걸어요 *(เดิน — ㄷ 불규칙 ข้อ 51)* ประโยค 걸어서 5분 걸려요 *(เดินใช้เวลา 5 นาที)* ใช้ทั้งสองคำในประโยคเดียวได้
- **얼마나 ที่คนไทยสับกับ 얼마:** ตำราใช้ 얼마나 걸려요 เสมอ
  - 얼마 = เท่าไร (ราคา/จำนวน)
  - 얼마나 = เท่าไร/นานแค่ไหน (ระดับ/ระยะ)
- **멀다 (ㄹ-ราก):** ㄹ หลุดก่อน ㅂ/ㄴ (ข้อ 35)
  - 멀지 않아요 *(ไม่ไกล)*
  - 멉니까? *(ไกลไหม)*
  - 머니까 *(เพราะไกล)*
- **ลืม 에서:** จุดเริ่มต้องใช้ 에서 (ข้อ 09: 에 = จุดหมาย)
  - ✓ 학교**에서** 집**까지** 가요
  - ✗ 학교 집까지 가요
  - ✗ 학교에 집까지

> [!TIP] กฎสั้น ๆ
> **สถานที่: N에서 N까지** · **เวลา: N부터 N까지** · **ถามเวลาที่ใช้: 얼마나 걸려요?** · **ตอบ: พาหนะ(으)로 + เลขจีน 분 / เลขแท้ 시간 + 쯤 걸려요**
