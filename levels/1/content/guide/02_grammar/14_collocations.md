## 14. Collocations และคำที่สับสนบ่อย

> [!INTRO] ข้อนี้คืออะไร
> ข้อนี้รวมจุดที่แปลจากภาษาไทยตรง ๆ แล้วผิด 5 เรื่อง ได้แก่ คู่คำนาม–กริยาที่ตายตัว, 아니요 กับ 아니에요, 뭐 กับ 무엇, 주다 / 받다 / 주세요 และการผันกริยาที่สระควบกัน
>
> ทั้งห้าเรื่องไม่ได้สอนในบทใดบทหนึ่งโดยเฉพาะ แต่ใช้ได้ทุกบท ต่อยอดจากข้อ 06 (ผัน -아/어/여요) และข้อ 07 (을/를) และไปใช้ต่อในข้อ 18, 26, 29 และ 34
>
> วิธีใช้หัวข้อนี้คือ ดูรูปที่ถูกในหัวข้อ 📌 ดูตัวอย่างในหัวข้อ 📖 แล้วเทียบกับข้อผิดจริงในหัวข้อ ⚠️ และ 🧪

### 📌 รูปแบบและเงื่อนไข

ตารางในหัวข้อนี้เก็บเฉพาะรูปที่ถูกของทั้งห้าเรื่อง ส่วนรูปที่ผิดที่เคยพลาดรวมไว้ในหัวข้อ ⚠️ จุดสับสน

#### คำนาม–กริยาที่บังคับคู่

ภาษาเกาหลีมีคู่คำที่ตายตัว ถ้าแปลจากไทยตรง ๆ ("เล่น / ทำ / กิน / ใส่") แล้วใช้ 하다 หรือ 먹다 จะผิดทันที จึงต้องจำเป็นคู่ ๆ และห้ามใช้ 하다 ครอบจักรวาล

| ความหมาย | ✅ ต้องใช้ | รูปผัน |
|:---|:---|:---|
| เต้นรำ | 춤**을 추다** | 춤을 **춰요** |
| ถ่ายรูป | 사진**을 찍다** | 사진을 **찍어요** |
| ถอนเงิน | 돈**을 찾다** | 돈을 **찾아요** |
| สูบบุหรี่ | 담배**를 피우다** | 담배를 **피워요** |
| ขึ้น (รถ/เครื่องบิน) | 버스**를 타다** | 버스를 **타요** |
| ดื่ม (กาแฟ/น้ำ) | 커피**를 마시다** | 커피를 **마셔요** |
| ใส่ (เสื้อผ้า) | 옷**을 입다** | 옷을 **입어요** |
| ใช้/เล่นคอมพิวเตอร์ | 컴퓨터**를 하다** | 컴퓨터를 **해요** |

> [!NOTE] ข้อสอบจริง
> ข้อ `컴퓨터를 해요` ออกจริงใน workbook 12과 (`윤아 씨가 컴퓨터를 해요?` — คุณยุนอาใช้คอมพิวเตอร์ไหม)
>
> "ใช้คอมพิวเตอร์" ใช้ 하다 ได้ แต่ "เต้นรำ" ใช้ไม่ได้ ต้องจำเป็นคู่ ๆ ไป

#### กลุ่มที่ใช้ 하다 ได้ (N을/를 하다 — ตำรา 11–13과)

คำนามกลุ่มนี้ตัด 을/를 แล้วต่อ 하다 ได้เลย (공부를 해요 = 공부해요) และปฏิเสธใช้ 공부 안 해요 (ข้อ 08)

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|
| 공부 | การเรียน | 운동 | ออกกำลังกาย |
| 이야기 | การคุย / เรื่องเล่า | 노래 | เพลง |
| 청소 | ทำความสะอาด | 쇼핑 | ช็อปปิง |
| 일 | งาน | 전화 | โทรศัพท์ |
| 요리 | ทำอาหาร | 샤워 | อาบน้ำ |
| 숙제 | การบ้าน | 빨래 | ซักผ้า |
| 아르바이트 | งานพาร์ทไทม์ | 산책 | เดินเล่น |
| 파티 | ปาร์ตี้ | 결혼 | แต่งงาน |

#### 아니요 vs 아니에요 — คนละชนิดคำ

สองคำนี้หน้าตาคล้ายกันจึงสับสนบ่อยมาก แต่เป็นคนละชนิดคำและอยู่คนละตำแหน่งในประโยค

| หัวข้อ | 아니요 | 아니에요 |
|:---|:---|:---|
| ชนิดคำ | คำอุทาน (ตอบรับ-ปฏิเสธ) | **คำกริยา** |
| แปล | "ไม่" (= No) | "ไม่ใช่..." |
| ตำแหน่ง | ขึ้นต้นประโยค ตามด้วยจุลภาค | ท้ายประโยค ต่อจาก คำนาม + **이/가** |

#### 뭐 vs 무엇 — เลือกตามตัวสะกด

ทั้งคู่แปลว่า "อะไร" (뭐 คือรูปย่อของ 무엇) แต่กริยาที่ตามมาต่างกัน

| คำ | ตัวสะกด | ใช้คู่กับ | ตัวอย่าง |
|:---|:---|:---|:---|
| **뭐** | ✗ ไม่มี | **예요** | 이름이 **뭐예요**? *(ชื่ออะไร)* |
| **무엇** | ✓ มี (ㅅ) | **이에요** | 이름이 **무엇이에요**? *(ชื่ออะไร)* |
| **무엇** | ✓ มี (ㅅ) | **입니까** | 직업이 **무엇입니까**? *(อาชีพอะไร)* |

> [!NOTE] หลักเดียวกับ 이에요/예요
> หลักเดียวกับ 이에요/예요 (ข้อ 02) เป๊ะ ๆ — ดูตัวสะกดของคำที่อยู่ข้างหน้าเท่านั้น

#### 주다 / 받다 / 주세요 — ใครให้ ใครรับ

คำสามคำนี้เกี่ยวกับการให้และการรับ ให้ดูว่าประธานเป็นคนยื่นให้หรือเป็นคนรับ

| คำ | รูปผัน | ความหมาย | มุมมอง |
|:---|:---|:---|:---|
| 주다 | **줘요** | ให้ | **ประธานเป็นคนยื่นให้** |
| 받다 | **받아요** | ได้รับ | **ประธานเป็นคนรับ** |
| 주세요 | — | "ขอ... / กรุณาให้..." | รูปขอร้อง ใช้ตอนสั่งอาหาร/ซื้อของ |

#### การผันกริยาที่สระควบกัน (เสริมข้อ 06)

กริยากลุ่มนี้ผันตามกฎของข้อ 06 แต่สระของรากกับ 아/어 ควบหรือยุบกัน จึงเขียนผิดง่าย

| กริยา | ผัน | กฎ |
|:---|:---|:---|
| 쓰다 (เขียน) | **써요** | สระ ㅡ ลดรูป |
| 추다 (เต้น) | **춰요** | ㅜ + ㅓ → ㅝ |
| 주다 (ให้) | **줘요** | ㅜ + ㅓ → ㅝ |
| 기다리다 (รอ) | **기다려요** | ㅣ + ㅓ → ㅕ |
| 마시다 (ดื่ม) | **마셔요** | ㅣ + ㅓ → ㅕ |
| 만나다 (พบ) | **만나요** | ㅏ + ㅏ → ㅏ (ยุบเป็นตัวเดียว) |
| 받다 · 살다 | **받아요 · 살아요** | สระ ㅏ → 아요 แม้มีตัวสะกด |

### 📖 ตัวอย่างและการใช้

ตัวอย่างต่อไปนี้เอารูปที่ถูกจากหัวข้อ 📌 ไปใช้ในประโยคจริง เรียงตามเรื่อง

#### ตัวอย่าง: 아니요 กับ 아니에요

ประโยคตอบแบบปฏิเสธขึ้นต้นด้วย 아니요 แล้วตามด้วยประโยคที่จบด้วย 아니에요

- ✅ **아니요**, 지갑**이 아니에요**. *({x:ไม่}ครับ {x:ไม่ใช่}{n:กระเป๋าสตางค์})*
- ✅ **아니요**, 선생님**이 아니에요**. 간호사예요. *(복습시험 ① 쓰기 E2 — ไม่ ไม่ใช่ครู เป็นพยาบาล)*

#### ตัวอย่าง: 뭐 กับ 무엇

เวลาพูดเร็ว เกาหลีย่อ 무엇 เป็น 뭐 ได้ และใช้ 무슨 เมื่อมีคำนามตามหลัง

- พูดเร็วย่อได้: 무엇**을** → **뭘** และ 무엇**이** → **뭐가** *(ตำรา 13과)*
  - 학교에서 **뭘** 해요? *(ทำอะไรที่โรงเรียน)*
  - **뭐가** 있어요? *(มีอะไร)*
- **무슨** ต้องมีนามตามหลัง ดูข้อ 34 ส่วนรายละเอียดทั้งหมดอยู่ในส่วนที่ 3
  - 무슨 요일 *(วันอะไร)*
  - 무슨 음식 *(อาหารอะไร)*

#### ตัวอย่าง: 주다 / 받다 / 주세요

ประธานของ 주다 เป็นคนยื่นให้ ประธานของ 받다 เป็นคนรับ ส่วน 주세요 เป็นรูปขอร้อง

- 친구가 선물을 **줘요**. *(เพื่อนให้ของขวัญ)*
- 저는 선물을 **받아요**. *(ฉันได้รับของขวัญ)*
- 빵 세 개 **주세요**. *(ขอขนมปัง 3 ชิ้นครับ)* ← ออกสอบใน 10과 แน่นอน
  - 매일시험 10과 C10: "주스 한 병 주세요" *(ขอน้ำผลไม้หนึ่งขวด)*

### ⚠️ จุดสับสน

ทั้งห้าเรื่องมีจุดที่ผู้เรียนพลาดซ้ำ ตารางนี้รวมรูปที่ผิดไว้ที่เดียวและเทียบกับรูปที่ถูก

| ✗ ผิด | ✓ ถูก | เหตุผล |
|:---|:---|:---|
| 춤을 하다 | 춤**을 추다** | เต้นรำใช้ 하다 ไม่ได้ ต้องใช้ 추다 |
| 춤어요 | 춤을 **춰요** | ผัน 추다 เป็น 춰요 (ㅜ + ㅓ → ㅝ) |
| 사진을 하다 | 사진**을 찍다** | ถ่ายรูปใช้ 찍다 |
| 돈을 하다 | 돈**을 찾다** | ถอนเงินใช้ 찾다 |
| 담배를 하다 | 담배**를 피우다** | สูบบุหรี่ใช้ 피우다 |
| 버스를 하다 | 버스**를 타다** | ขึ้นรถใช้ 타다 |
| 커피를 먹어요 | 커피를 **마셔요** | ดื่มกาแฟใช้ 마시다 ไม่ใช่ 먹다 |
| 컴퓨터를 일하다 | 컴퓨터를 **해요** | ใช้คอมพิวเตอร์ใช้ 하다 ได้ |
| 주세요 (เมื่อต้องบรรยาย) | **줘요** | บรรยายภาพที่เห็นคนยื่นของใช้ 줘요 |
| 반나요 | **만나요** | สะกดผิด |
| 받어요 | **받아요** | สระ ㅏ → 아요 แม้มีตัวสะกด |
| 살어요 | **살아요** | สระ ㅏ → 아요 แม้มีตัวสะกด |
| 아니에요, 지갑이 아니요 | **아니요**, 지갑**이 아니에요** | สลับที่กัน |

#### กับดัก

ข้อควรระวังต่อไปนี้เป็นรายละเอียดที่ควรจำเพิ่มเติมจากตารางด้านบน

- **줘요 ≠ 주세요:** บรรยายภาพที่เห็นคนยื่นของ → 줘요 (매일시험 11과 A11 เคยเขียน 주세요 ✗) ส่วนขอของ → 주세요
- **ผัน 추다 เป็น 춰요 (ㅜ + ㅓ → ㅝ):** ห้ามเขียนเป็น 춤어요 เพราะเป็นการเอา 어요 ไปต่อกับคำนาม 춤
- **아니요 ขึ้นต้นประโยค ส่วน 아니에요 อยู่ท้ายประโยค:** ห้ามสลับที่กัน
- **하다 ใช้กับ "ใช้คอมพิวเตอร์" ได้ แต่ใช้กับ "เต้นรำ" ไม่ได้:** ต้องจำเป็นคู่ ๆ ไป

> [!TIP] กฎสั้น ๆ
> - จำคำนาม–กริยาเป็นคู่ ๆ อย่าแปลตรงจากไทย
> - 뭐 + 예요 · 무엇 + 이에요/입니까 — ดูตัวสะกดของคำหน้า
> - 줘요 = ให้ (ประธานยื่น) · 받아요 = ได้รับ · 주세요 = ขอ

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

จุดทั้งห้าเรื่องเคยออกสอบและเคยพลาดในแบบทดสอบประจำวันและ 복습시험 ① รายการต่อไปนี้เรียงตามแหล่งที่มา

- **คู่คำ**
  - 춤어요 ✗ → 춤을 춰요 *(เต้นรำ)* (매일시험 11과 A)
  - 학생을 공부해요 ✗ → 숙제를 해요 *(ทำการบ้าน)* (11과 B16)
  - 안 팔아요 ✗ → 안 줘요 *(ไม่ให้)* (12과 A1 — ภาพคือการให้ ไม่ใช่การขาย)
- **복습시험 ① (10/6)**
  - 쓰기 B4 "저것이 (무엇)입니까?" *(นั่นคืออะไร)*
  - B3 "이 사람이 (누구)예요?" *(คนนี้คือใคร)* — เลือกคำถามให้เข้ากับ 입니까 / 이에요
  - 쓰기 E2–E3 "아니요, 선생님이 **아니에요**" *(ไม่ ไม่ใช่ครู)*
  - "한국어를 **안** 가르쳐요" *(ไม่สอนภาษาเกาหลี)*

#### สะกดซ้ำที่เสียคะแนนหรือครูแก้

ตารางนี้รวมคำที่ผู้เรียนสะกดผิดซ้ำ พร้อมที่มาของข้อผิดแต่ละคำ

| เขียนผิด | ถูก | ที่มา |
|:---|:---|:---|
| 생할 | **생활** | 매일시험 17과 C9 (−0.5) · ร่างบทแนะนำตัว |
| 열심이 | **열심히** | 매일시험 17과 C10 (−0.5) — คำวิเศษณ์ลงท้าย 히 |
| 메일 | **매일** | งานเขียน — ㅐ ไม่ใช่ ㅔ |
| 네 게 · 젝 | **네 개 · 책** | 복습시험 ① (−4) · 매일시험 17과 (−0.5) |
| 십월 | **시월** | 복습시험 ① (−4) |
| 칻시 | **같이** | 매일시험 13과 C16 — อ่าน [가치] แต่เขียน 같이 |
| 막어요 · 고등생 · 여동새 · 안녀하습니까 | **먹어요 · 고등학생 · 여동생 · 안녕하십니까** | ร่างบทแนะนำตัว (แก้แล้ว) |
| 사라요 · 거요 | **살아요 · 거예요** | 매일시험 14과 C14 · ใบฝึก 20과 |
| 조문합니다 | **주문합니다** | งานบทสั่งเครื่องดื่ม (น่าจะหมายถึงสั่ง) |

- **ลายมือ ㅈ / ㅊ** เสียคะแนนมาแล้ว 5 ครั้ง
  - 저 → 처
  - 책 → 젝
  - 청
  - 몇 → 몆
  - ㅊ ต้องมีขีดบน ส่วน ㅈ ห้ามมี

### 🔗 เชื่อมโยง

ข้อนี้ต่อจากเรื่องการผันและกรรมของกริยา และเป็นฐานของเรื่องคำคุณศัพท์ การไปทำสิ่งต่าง ๆ และการให้กับผู้ใหญ่

← ต่อยอดจาก

- ข้อ 06 (ผัน -아/어/여요)
- ข้อ 07 (을/를 + กริยาคู่ใจ)
- ข้อ 02 (이에요/예요 → 뭐예요 / 무엇이에요)

→ ใช้ต่อใน

- ข้อ 18 (คำคุณศัพท์ใช้ 이/가 ไม่ใช้ 을/를)
- ข้อ 26 (사진을 찍으러 · 돈을 찾으러 — คำนามคู่กริยาเดิม)
- ข้อ 29 (주다 → 드리다 · 받다 → 에게서)
- ข้อ 34 (무슨)
- ส่วนที่ 3 (뭐 vs 무엇 vs 무슨)

> [!SUMMARY] สรุป
> - คำนาม–กริยาที่ตายตัวต้องจำเป็นคู่ เช่น 춤을 추다 · 사진을 찍다 · 돈을 찾다 ห้ามใช้ 하다 ครอบจักรวาล
> - 아니요 (ขึ้นต้นประโยค) กับ 아니에요 (ท้ายประโยค) เป็นคนละชนิดคำ
> - 뭐 + 예요 และ 무엇 + 이에요/입니까 ให้ดูตัวสะกดของคำหน้า
> - 줘요 = ให้ · 받아요 = ได้รับ · 주세요 = ขอ
> - ผันควบสระ: 춰요 · 줘요 · 마셔요 และ 받아요 · 살아요
