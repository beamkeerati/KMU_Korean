## 18. 형용사 (คำคุณศัพท์ + การผัน)

> [!INTRO] ข้อนี้คืออะไร
> 형용사 คือคำคุณศัพท์ของภาษาเกาหลี ใช้บอก**ลักษณะหรือสภาพ** มีรูปพื้นฐานลงท้าย -다 และผันได้เหมือนกริยา ข้อสำคัญคือมันเป็นภาคแสดงได้เอง **ไม่ต้องมี "เป็น"** (이다) เหมือนภาษาไทยที่พูดว่า "กระเป๋าเล็ก"
>
> โครงประโยคคือ ประธาน + 이/가 + คำคุณศัพท์ที่ผันแล้ว เช่น 가방이 작아요 และไม่มีกรรม จึงไม่ใช้ 을/를 ส่วนการถามลักษณะใช้ 어때요?
>
> สอนในบท 14 ต่อยอดจากข้อ 06 (กฎผัน -아/어/여요 ชุดเดียวกัน) และข้อ 01 (이/가) ไปใช้ต่อในข้อ 16 (-지 않다) ข้อ 17 (도) ข้อ 20 (-(으)세요) ข้อ 21 (-ㅂ니다) ข้อ 23 (-았/었) ข้อ 30 (-네요) และข้อ 34 (-고)

### 📌 รูปแบบและเงื่อนไข

สูตรของข้อนี้คือ `[คำนาม] + 이/가 + [รากคุณศัพท์]-아/어/여요` ตัวอย่างและคำถามต่อไปนี้ใช้สูตรนั้นโดยตรง

- 가방**이** 작아요. *(กระเป๋าเล็ก)*
- 날씨**가** 좋아요. *(อากาศดี)*
- ถามลักษณะ: **어때요?** *(เป็นอย่างไร)*

#### 📽️ ตาราง 4 กลุ่มของครู (สไลด์ 124쪽)

ตารางนี้คือกฎผันของคำคุณศัพท์ตามตาราง 4 กลุ่มของครู รวมศัพท์จากใบฝึก 14과 และคำที่ผันพิเศษอีกสองคำ

| ราก (ตัด 다) | กฎ |
|:---|:---|
| สระท้ายราก ㅏ · ㅗ | + **아요** |
| สระอื่น ๆ | + **어요** |
| ลงท้าย 하다 | → **해요** |
| ราก **ㅡ** (ตัด ㅡ ทิ้ง) | ดูสระพยางค์หน้า: ㅏ/ㅗ → **아요** · อื่น/ไม่มี → **어요** |
| 어떻다 | ท่องเป็นรูปเดียว |
| 어둡다 | ท่องเป็นคำ (ผันพิเศษ ยังไม่มีกฎในระดับนี้) |

#### ตัวอย่างการผันตามกลุ่ม

ตารางนี้ให้ตัวอย่างหนึ่งคำต่อหนึ่งแถว เรียงตามกลุ่มในตารางข้างบน

| กลุ่ม | 기본형 | -아/어요 | ความหมาย / หมายเหตุ |
|:---|:---|:---|:---|
| ㅏ · ㅗ | 작다 | 작**아요** | เล็ก |
| ㅏ · ㅗ | 좋다 | 좋**아요** | ดี |
| ㅏ · ㅗ | 많다 | 많**아요** | มาก |
| ㅏ · ㅗ | 짧다 | 짧**아요** | สั้น |
| ㅏ · ㅗ | 싸다 | **싸요** | ถูก (ㅏ+아 ยุบ) |
| อื่น ๆ | 적다 | 적**어요** | น้อย |
| อื่น ๆ | 길다 | 길**어요** | ยาว |
| อื่น ๆ | 재미있다 | 재미있**어요** | สนุก |
| อื่น ๆ | 맛있다 | 맛있**어요** | อร่อย |
| อื่น ๆ | 재미없다 | 재미없**어요** | ไม่สนุก |
| 하다 | 친절하다 | 친절**해요** | ใจดี |
| 하다 | 피곤하다 | 피곤**해요** | เหนื่อย |
| 하다 | 조용하다 | 조용**해요** | เงียบ |
| 하다 | 깨끗하다 | 깨끗**해요** | สะอาด |
| ㅡ | 크다 | **커요** | ใหญ่ |
| ㅡ | 바쁘다 | **바빠요** | ยุ่ง |
| ㅡ | 예쁘다 | **예뻐요** | สวย |
| ㅡ | 나쁘다 | **나빠요** | แย่ |
| ㅡ | 아프다 | **아파요** | ป่วย/เจ็บ |
| 어떻다 | 어떻다 | **어때요?** | เป็นอย่างไร — อดีต **어땠어요?** (ข้อ 23) |
| 어둡다 | 어둡다 | **어두워요** | {v:มืด} — ส่วน -지 않다 ใช้รากเดิม: 어둡지 않아요 (ตัวอย่างใน 22과) |

#### วิธีคิดเมื่อมี ㅡ

ราก ㅡ ให้ตัด ㅡ ทิ้งก่อน แล้วดูสระของพยางค์ที่อยู่ข้างหน้าเพื่อเลือก 아 หรือ 어

| คำ | พยางค์หน้า | ผล |
|:---|:---|:---|
| 바쁘다 | 바 มี ㅏ → ใช้ **아** | ㅡ ตก เหลือ 바ㅃ + **아** = **바빠요** |
| 예쁘다 | 예 ไม่ใช่ ㅏ/ㅗ → ใช้ **어** | 예ㅃ + **어** = **예뻐요** |
| 크다 | ไม่มีพยางค์หน้า → ใช้ **어** | ㅋ + **어** = **커요** |

#### ข้อควรรู้จากตำรา

ตำรากับครูให้ข้อสังเกตเกี่ยวกับกรรมและการปฏิเสธไว้สองข้อ

- ตำรา (124쪽): คำคุณศัพท์บอกลักษณะหรือสภาพของสิ่งของ มีรูปพื้นฐานและผันได้ — **ไม่มีกรรม** ประธานใช้ **이/가**
- ปฏิเสธด้วย 안 หรือ -지 않다 (ข้อ 08 และข้อ 16)
  - 안 비싸요 / 비싸지 않아요 *(ไม่แพง)*
  - คุณศัพท์ N+하다 วาง 안 หน้าคำทั้งก้อน: **안 친절해요** *(ไม่ใจดี — ไม่แยกกลางเหมือนกริยา)*

### 📖 ตัวอย่างและการใช้

ตัวอย่างต่อไปนี้เริ่มจากคู่ตรงข้ามที่ต้องจำ แล้วดูประโยคจากตำรา 124~127쪽 สไลด์ของอาจารย์ และปิดด้วยการเทียบคำคุณศัพท์กับกริยา

#### คู่ตรงข้ามและคำที่ต้องจำ

คำคุณศัพท์ส่วนใหญ่จำเป็นคู่ตรงข้าม ตารางนี้ให้ประโยคตัวอย่างของแต่ละคู่

| คู่ / คำ | ตัวอย่าง | ความหมาย |
|:---|:---|:---|
| 길다 ↔ 짧다 | 머리가 길어요 / 짧아요 | ยาว ↔ สั้น |
| 싸다 ↔ 비싸다 | 과일이 싸요 / 비싸요 | ถูก ↔ แพง |
| 재미있다 ↔ 재미없다 | 책이 재미있어요 / 재미없어요 | สนุก ↔ ไม่สนุก |
| 많다 ↔ 적다 | 사람이 많아요 / 적어요 | มาก ↔ น้อย |
| 크다 ↔ 작다 | 키가 커요 / 가방이 작아요 | ใหญ่ (สูง) ↔ เล็ก (เตี้ย) |
| 넓다 ↔ 좁다 | 방이 넓어요 / 좁아요 | กว้าง ↔ แคบ |
| 좋다 ↔ 나쁘다 | 날씨가 좋아요 / 나빠요 | ดี ↔ แย่ |
| 예쁘다 · 멋있다 | 카오루 씨가 멋있어요 | สวย · เท่/หล่อ |
| 바쁘다 · 피곤하다 · 아프다 | 밍밍은 아주 바빠요 · 피곤해요 · 아파요 | ยุ่ง · เหนื่อย · ป่วย/เจ็บ |
| 친절하다 · 조용하다 · 깨끗하다 · 똑똑하다 · 중요하다 | 선생님이 친절해요 · 방이 깨끗해요 | ใจดี · เงียบ · สะอาด · ฉลาด · สำคัญ |

#### ประโยคตัวอย่าง (ตำรา 124~127쪽)

ประโยคจากตำราทุกประโยคใช้โครง "ประธาน + 이/가 + คำคุณศัพท์" และถามลักษณะด้วย 어때요

| 한국어 | ไทย |
|:---|:---|
| 가방이 작아요. | กระเป๋าเล็ก |
| 자동차가 비싸요. | รถแพง |
| 학생이 적어요. | {n:นักเรียน}{v:น้อย} |
| 선생님이 친절해요. | ครูใจดี |
| 제프리 씨가 친절해요. | เจฟฟรีย์ใจดี |
| 카오루 씨가 멋있어요. | คาโอรุเท่ |
| 사과가 맛있어요. | แอปเปิ้ลอร่อย |
| 키가 커요. | ตัวสูง |
| 날씨가 나빠요. | อากาศแย่ |
| 가: 카오루 씨 집이 **어때요**? / 나: 작아요. | บ้านคุณคาโอรุเป็นอย่างไร / เล็ก |
| 서울이 어때요? | โซลเป็นอย่างไร |
| 고향이 어때요? | บ้านเกิดเป็นอย่างไร |
| 학교가 어때요? | โรงเรียนเป็นอย่างไร |

#### 📽️ จากสไลด์อาจารย์ (교과서 124쪽)

ครูเขียนโครง `___이/가 형용사-아/어/여요` ไว้บนสไลด์ พร้อมตัวอย่างสามประโยคนี้

| 한국어 | ไทย |
|:---|:---|
| 오늘 날씨**가 좋아요**. | วันนี้อากาศดี |
| 한국 음식**이 맛있어요**. | อาหารเกาหลีอร่อย |
| 선생님**이 친절해요**. | ครูใจดี |

- ครูเขียน **어때요?** กำกับไว้เหนือสไลด์
- ใบฝึก 14과 ให้เขียนรูป -아/어요 ใต้ภาพคู่ตรงข้ามทั้งหมด 26 คำ ดังตารางนี้

| ① | ② | ③ | ④ |
|:---|:---|:---|:---|
| 많아요 | 적어요 | 좋아요 | 나빠요 |
| 커요 | 작아요 | 싸요 | 비싸요 |
| 길어요 | 짧아요 | 예뻐요 | 멋있어요 |
| 맛있어요 | 맛없어요 | 재미있어요 | 재미없어요 |
| 바빠요 | 아파요 | 넓어요 | 좁아요 |
| 친절해요 | 피곤해요 | 조용해요 | 깨끗해요 |
| 똑똑해요 | 중요해요 | | |

#### เทียบกับกริยา

คำคุณศัพท์ผันและปฏิเสธได้เหมือนกริยา แต่ต่างกันที่ไม่มีกรรม

| หัวข้อ | กริยา | คำคุณศัพท์ |
|:---|:---|:---|
| ผัน -아/어요 | ✓ | ✓ |
| ปฏิเสธ | 안 가요 / 가지 않아요 | 안 비싸요 / 비싸지 않아요 |
| กรรม (을/를) | ✓ | ✗ ไม่มีกรรม |

### ⚠️ จุดสับสน

คำคุณศัพท์ในภาษาไทยดูเหมือนกริยา ("ชอบ/ดีกับ...") คนไทยจึงใส่กรรม 을/를 หรือ 이에요 ผิด ๆ โดยเฉพาะกลุ่ม 맛있다 / 재미있다 / 멋있다 ที่ลงท้ายด้วย 있다 ตารางนี้เทียบกริยากับคำคุณศัพท์ในห้าด้าน

| หัวข้อ | กริยา | คำคุณศัพท์ |
|:---|:---|:---|
| ตัวหน้า | 을/를 (กรรม) | **이/가** (ประธาน) |
| ตัวอย่าง | 김치를 좋아해요 | 날씨가 좋아요 |
| ผิด | | ✗ 날씨를 좋아요 |
| -있다 ผัน | | 맛있어요 ✓ / ✗ 맛있이에요 |
| ถามลักษณะ | | 어때요? (ผิดปกติ ท่องเป็นคำ) |

#### ✓ / ✗ ที่พบบ่อย

ตารางนี้รวมรูปผิดที่พบบ่อยของคำคุณศัพท์ ได้แก่ ใส่กรรม ใส่ 이에요 ลืมตัด ㅡ และใส่ 시 ผิดที่

| ✓ ถูก | ✗ ผิด | เหตุผล |
|:---|:---|:---|
| 한국 음식이 맛있어요 *(อาหารเกาหลีอร่อย)* | 한국 음식을 맛있어요 | คำคุณศัพท์ไม่มีกรรม ใช้ 이/가 |
| 이 영화가 재미있어요 *(ภาพยนตร์เรื่องนี้สนุก)* | 재미있이에요 | ห้ามใส่ 이에요 หลังคำคุณศัพท์ |
| 비싸요 *(แพง)* | 비싸이에요 | ห้ามใส่ 이에요 หลังคำคุณศัพท์ |
| 커요 *(ใหญ่)* | 크어요 | ลืมตัด ㅡ |
| 바빠요 *(ยุ่ง)* | 바쁘어요 | ลืมตัด ㅡ |
| 예뻐요 *(สวย)* | 예쁘어요 | ลืมตัด ㅡ |
| 음식이 맛있어요 *(อาหารอร่อย)* | 음식이 맛있으세요 | อาหารหรือสิ่งของไม่ใส่ 시 (ข้อ 20) |

#### กับดัก

กับดักเหล่านี้เป็นข้อควรระวังเพิ่มเติมนอกตารางด้านบน

- ✓ 날씨가 어때요? — 좋아요. *({n:อากาศ}{q:เป็นอย่างไร} — {v:ดี})*
- **어때요 vs 어떻게:** ถาม "เป็นอย่างไร" ตอบด้วยคำคุณศัพท์ใช้ **어때요** ส่วน 어떻게 = "อย่างไร/ยังไง" ใช้ในสำนวนอื่น
  - 성함이 어떻게 되세요? *(ท่านชื่ออะไรคะ — ข้อ 20)*
- **좋다 ≠ 좋아하다** → ข้อ 01
  - ✓ 사과가 좋아요 *(ถูกใจแอปเปิ้ล)*
  - ✓ 사과를 좋아해요 *(ชอบแอปเปิ้ล)*
- **ยกย่อง -(으)시-** ใส่ได้เมื่อ **ประธานเป็นผู้ใหญ่** (ข้อ 20)
  - ✓ 선생님이 멋있으세요 *(คุณครูเท่/หล่อ)*
  - ✓ 키가 크세요 *(ตัวสูง)*
  - ส่วนอาหารหรือสิ่งของไม่ใส่ 시: ✓ 음식이 맛있어요 / ✗ 음식이 맛있으세요
- 키 (ส่วนสูง) ใช้ 크다 / 작다 ไม่ใช่ 높다: 키가 **커요** *(ตัวสูง)*
- ประธานของคำคุณศัพท์ใช้ **이/가** (ข้อมูลใหม่) ส่วน 은/는 ได้เมื่อเปรียบเทียบ
- กลุ่ม -있다 / -없다 (재미있다 · 재미없다 · 맛있다 และ 맛없다 · 멋있다) เป็น **คำคุณศัพท์** (ไม่ใช่ "มี/ไม่มี") ผันแบบ 있어요 / 없어요

> [!TIP] กฎสั้น ๆ
> - คำคุณศัพท์ = **이/가 + คำคุณศัพท์** ไม่มี 을/를
> - มี ㅡ ให้ตัดแล้วดูสระหน้า (바빠요 · 예뻐요 · 커요)
> - 어떻다 ใช้ได้แต่รูป **어때요**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

คำคุณศัพท์เป็นหัวใจของ 매일시험 14과 ส่วน A และ B และยังเกี่ยวกับการผันอดีตในบทหลัง รายการต่อไปนี้เรียงตามแหล่งที่มา

- **매일시험 14과 A** (10 ข้อจากภาพ ข้อละ 0.5 · รวมข้อสอบได้ 7.5/10)
  - พลาด A1 **커요** (เว้นว่าง)
  - พลาด A5 **어두워요** (เว้นว่าง — ศัพท์ผันพิเศษ ท่องเป็นคำ)
  - พลาด A6 **피곤해요** (เขียน 피곤나요 ✗)
  - ที่เหลือถูกหมด: 작아요 · 비싸요 · 싸요 · 예뻐요
  - ที่เหลือถูกหมด: 멋있어요 · 많아요 · 적어요
- **워크북 14과 A–B**
  - A เลือกคำจาก 보기 16 ข้อ
  - B ตอบ 어때요? 4 ข้อ
  - ครูทำเครื่องหมาย A8 · A12 · A13 และ A15 กับ B3
  - A16 (คนนอนป่วย) ในสแกนเขียน 피곤하다 ซึ่งไม่อยู่ใน 보기 → ต้องเป็น **아프다**
- **อดีตและ 어때요**
  - ㅡ ตกในอดีตทำถูก: 바빴어요 · 컸어요 (17과)
  - 어떻다 เคยเขียน **어떻었어요** ✗ → 어땠어요 (워크북 17과 — แม้พิมพ์ 어땠어요 ไว้ใกล้ ๆ)
  - เคยสับสน **어때요 กับ 어떻게**
- **복습시험 ②**
  - 쓰기 2 (เติมคำถามจาก 보기) คาดว่ามี 어때요 เช่น "날씨가 ( )? — 아주 좋아요" *(อากาศเป็นอย่างไร — ดีมาก)*
  - 읽기 14-2 เป็นชุดสำรอง

### 🔗 เชื่อมโยง

ข้อนี้ต่อจากกฎผันของกริยาและ 이/가 และเป็นฐานของการปฏิเสธ การยกย่อง และกาลในข้อถัดไป

← ต่อยอดจาก

- ข้อ 06 (กฎผัน -아/어/여요 และ ㅡ ตก)
- ข้อ 01 (이/가 = ประธาน)
- ข้อ 07 (กรรม 을/를 — คำคุณศัพท์ไม่มี)

→ ใช้ต่อใน

- ข้อ 16 (-지 않다: 비싸지 않아요)
- ข้อ 17 (도)
- ข้อ 20 (키가 크세요 — ใส่ 시 เมื่อประธานเป็นผู้ใหญ่)
- ข้อ 21 (좋습니다 · 예쁩니다)
- ข้อ 23 (바빴어요 · 컸어요 · 어땠어요)
- ข้อ 30 (친절하네요 · 많네요)
- ข้อ 34 (싸고 맛있어요)

> [!SUMMARY] สรุป
> - คำคุณศัพท์ = **이/가 + คำคุณศัพท์** ไม่มีกรรม (ไม่ใช้ 을/를) และไม่ต้องใส่ "เป็น" (이다)
> - ผัน -아/어/여요 ตามกฎเดียวกับกริยา: ㅏ · ㅗ → 아요 · อื่น → 어요 · 하다 → 해요
> - มี ㅡ ให้ตัดแล้วดูสระพยางค์หน้า (바빠요 · 예뻐요 · 커요) ส่วน 어떻다 ใช้ได้แต่รูป 어때요
> - ปฏิเสธด้วย 안 หรือ -지 않다 โดยคุณศัพท์ N+하다 วาง 안 หน้าคำทั้งก้อน (안 친절해요)
> - ที่เคยพลาด: 피곤나요 (→ 피곤해요) · 어떻었어요 (→ 어땠어요) · A16 ต้องเลือก 아프다 ไม่ใช่ 피곤하다
