## 24. N에서 왔어요 (มาจาก…)

> [!INTRO] ข้อนี้คืออะไร
> N에서 왔어요 ใช้บอก**ต้นทาง**ของคนที่มา เช่น ประเทศ เมือง หรือบ้านเกิด โครงสร้างคือ **สถานที่ + 에서 + 왔어요** เช่น 몽골에서 왔어요 *(มาจากมองโกเลีย)* ใช้ตอนแนะนำตัวและตอบคำถามว่า "มาจากที่ไหน"
>
> สอนในบท 17 (ตำราหน้า 154 และ 대화 17-1) ต่อยอดจาก ข้อ 09 (에서 = "ที่" ทำกิจกรรม แต่ในข้อนี้แปลว่า "จาก") และ ข้อ 23 (왔어요 = 오다 อดีต) แล้วไปใช้ต่อใน ข้อ 29 (에게서/한테서 "จาก" + คน ส่วนสถานที่ยังใช้ 에서)

### 📌 รูปแบบและเงื่อนไข

โครงสร้างหลักคือ N에서 왔어요 แปลว่า "มาจาก N" ตารางแรกสรุปรูปประโยคที่ใช้บ่อย 5 แบบ ตารางถัดไปเป็นตัวอย่างของแต่ละแบบ

| โครงสร้าง | ความหมาย |
|:---|:---|
| N**에서 왔어요** | มาจาก N |
| ประเทศ + เมือง + 에서 | ระบุเมืองด้วย |
| **어느 나라**에서 왔어요? | มาจากประเทศไหน |
| **어디**에서 왔어요? | มาจากที่ไหน |
| 고향이 어디예요? | บ้านเกิดอยู่ที่ไหน (ไม่ใช้กริยา) |

| โครงสร้าง | 한국어 | ไทย |
|:---|:---|:---|
| N에서 왔어요 | 몽골**에서 왔어요**. | {v:มา}{p:จาก}{n:มองโกเลีย} |
| ประเทศ + เมือง | 일본 도쿄**에서** 왔어요 | มาจากโตเกียว ญี่ปุ่น |
| ประเทศ + เมือง | 중국 베이징**에서** 왔어요 | มาจากปักกิ่ง จีน |
| ประเทศ + เมือง | 베트남 하노이**에서** 왔어요 | มาจากฮานอย เวียดนาม |
| 어느 나라 | 알렉세이 씨는 어느 나라에서 왔어요? / 러시아에서 왔어요. | {n:คุณอเล็กเซย์}{v:มา}{p:จาก}{n:ประเทศ}{q:ไหน} / {n:รัสเซีย} |
| 어디 | 마키 씨는 어디에서 왔어요? / 일본 도쿄에서 왔어요. | {n:คุณมากิ}{v:มา}{p:จาก}{q:ไหน} / {n:โตเกียว ญี่ปุ่น} |
| 고향 (ข้อ 02) | 고향이 어디예요? / 몽골이에요. | บ้านเกิดอยู่ที่ไหน / มองโกเลีย |

ตรงตำแหน่งของ 몽골 แทนด้วยประเทศอื่นได้ ตัวอย่างเช่น

- 베트남 · 캐나다 · 태국
- 호주 · 중국 · 미국

#### ข้อควรรู้เมื่อใช้ N에서 왔어요

ต้องใช้กริยาในรูปอดีตเสมอ และถามประเทศกับถามเมืองใช้คำถามต่างกัน

- ใช้ **왔어요** (อดีต) เสมอ เพราะ "มาถึงแล้ว ตอนนี้อยู่ที่นี่"
- รูปทางการคือ **왔습니다** เช่น 읽기 17-2: 러시아에서 왔습니다 *(มาจากรัสเซีย)*
- ✗ 와요 (= "กำลังมา/จะมา")
- ถามประเทศใช้ **어느 나라** (ไม่ใช่ 무슨 나라 — ดูส่วนที่ 3)
- ถามละเอียดขึ้น: ประเทศ → **어디**에서 (เมืองไหน)
- "ฉันเป็นคนไทย" = 태국 사람이에요 (ข้อ 02) แต่ "ฉันมาจากไทย" = 태국**에서 왔어요**

สไลด์ให้รูป 명사 에서 왔어요 (명사 = 나라 · 고향 …) โดยถามประเทศก่อน แล้วถามต่อเรื่องเมือง

| 한국어 | ไทย |
|:---|:---|

| 가: 중국 어디에서 왔어요? / 나: 중국 베이징에서 왔어요. | {v:มา}{p:จาก}{q:ที่ไหน}{p:ของ}{n:จีน} / {n:ปักกิ่ง} |

### ⚠️ จุดสับสน

ภาษาไทยใช้ "มา" ทั้ง "มาจาก" และ "มาถึง" จึงเลือก 에 กับ 에서 สลับกันได้ง่าย ทั้งสองประโยคถูกไวยากรณ์ แต่ความหมายคนละเรื่อง ตารางนี้เทียบทีละแถว

| | 에서 왔어요 | 에 왔어요 |
|:---|:---|:---|
| ความหมาย | มา**จาก** (ต้นทาง) | มา**ถึง** (ปลายทาง) |
| ตัวอย่าง | 몽골에서 왔어요 *({v:มา}{p:จาก}{n:มองโกเลีย})* | 한국에 왔어요 *({v:มา}{p:ถึง}{n:เกาหลี})* |
| ถาม | 어디**에서** 왔어요? *(ถามที่มา)* | 어디**에** 왔어요? *(ถามว่ามาถึงที่ไหน — ไม่ใช่ถามที่มา)* |

ตัวอย่างของ 에 อีกประโยคหนึ่งมาจากบทอ่าน 21 คือ 남이섬에 왔어요 *({v:มา}{p:ถึง}{n:เกาะนามิ})*

#### 에서 มี 2 หน้าที่ — ดูที่กริยา

ดูที่กริยาเพื่อรู้ว่า 에서 หมายถึง "ที่" (ที่ทำกิจกรรม) หรือ "จาก" (ต้นทาง)

| 한국어 | ไทย | หน้าที่ของ 에서 |
|:---|:---|:---|
| 회사**에서 일했어요** | ทำงานที่บริษัท (ข้อ 09) | ที่ทำกิจกรรม |
| 몽골**에서 왔어요** | {v:มา}{p:จาก}{n:มองโกเลีย} | ต้นทาง |
| 회사**에서 전화가 왔어요** | มีโทรศัพท์มาจากบริษัท (ข้อ 29) | ต้นทาง |
| 고향**에서 무엇을 했어요**? | ที่บ้านเกิดทำอะไร | ที่ทำกิจกรรม |
| 고향**에서 왔어요** | {v:มา}{p:จาก}{n:บ้านเกิด} | ต้นทาง |

ข้อผิดที่เจอบ่อยสรุปเป็นคู่ ✓ / ✗ ได้ตามตารางนี้

| สถานการณ์ | ✓ ถูก | ✗ ผิด | เหตุผล |
|:---|:---|:---|:---|
| ตก 에서 | 태국에서 왔어요. | 태국 왔어요 | ตก 에서 |
| ใช้ 에 แทน 에서 | 태국에서 왔어요. | 태국에 왔어요 | = มาถึงไทย |
| ถามประเทศ | 어느 나라에서 왔어요? | 무슨 나라 | ถามประเทศใช้ 어느 |
| กาลของกริยา | 왔어요 | 와요 | ต้องเป็นอดีต |

#### กับดัก

- ✗ 태국에 왔어요 ไม่ใช่ "มาจากไทย" แต่แปลว่า "มาถึงไทย"
- ถาม 어디에 왔어요? หมายถึงถามว่ามาถึงที่ไหน ไม่ใช่ถามที่มา
- 고향에서 무엇을 했어요? (ที่ทำกิจกรรม) ≠ 고향에서 왔어요 (ต้นทาง) — 에서 เหมือนกันแต่หน้าที่ต่างกัน

> [!TIP] กฎสั้น ๆ
> 에서 = **จาก** (ต้นทาง) · 에 = **ถึง** (ปลายทาง) · ตอบเป็นอดีต **왔어요** เสมอ
>
> ถามที่มา = **어디에서** · ถามประเทศ = **어느 나라에서**

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

ข้อนี้ออกในรูปเขียนตามคำบอกและเป็นประโยคที่คาดว่าจะออกใน 복습시험② ส่วนข้อผิดที่เจอเกี่ยวข้องกับคู่ 에 กับ 에서 มากกว่าตัวข้อนี้เอง

- **매일시험 17 (10/13) C8** เขียนตามคำบอก "มาจากที่ไหน" = **어디에서 왔어요?** (ประโยคจาก 대화 17-1) — ได้เต็มคะแนน
- **복습시험② (14–20과 · เก็ง)**
  - 듣기 [8~10] ฟังแล้วตอบ 어디에서 왔어요?
  - 읽기 17-2 ("러시아에서 왔습니다" ยกมาตอบช่อง 나)
  - 말하기 สัมภาษณ์เรื่องตัวเอง (ประเทศ ครอบครัว เมื่อวาน)
- **คู่ 에 / 에서 ที่เคยพลาด** (ยังไม่เคยพลาด 에서 왔어요 เอง)
  - 학생식당**하고** 가요 ✗ → 학생식당**에** 가요 *(ไปโรงอาหาร)* (복습시험① −4 — ปลายทางต้อง 에)
  - 백화점**에** 샀어요 ✗ → 백화점**에서** 샀어요 *(ซื้อที่ห้างสรรพสินค้า)* หรือ 백화점**에** 갔어요 *(ไปห้าง)* (ข้อ 09)

> [!SUMMARY] สรุป
> - 에서 왔어요 = "มาจาก" บอกต้นทาง ต้องใช้ **왔어요** (อดีต) เสมอ ไม่ใช่ 와요
> - ถามประเทศ = **어느 나라**에서 ถามที่มา = **어디**에서 และระบุเมืองได้ เช่น 일본 도쿄에서 왔어요
> - 에서 = จาก (ต้นทาง) แต่ 에 = ถึง (ปลายทาง) จึง 한국에 왔어요 แปลว่า "มาถึงเกาหลี"
> - 에서 อีกหน้าที่คือ "ที่" ทำกิจกรรม (회사에서 일했어요) ดูจากกริยาตามหลัง
