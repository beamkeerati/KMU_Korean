## 36. -(으)ㄴ (คำคุณศัพท์ขยายคำนาม: 매운 음식 · 좋은 사람)

> [!INTRO] ข้อนี้คืออะไร
> -(으)ㄴ เติมท้ายรากของ **คำคุณศัพท์** เพื่อให้ไปขยาย **คำนามที่ตามหลัง** เช่น "อาหาร**ที่เผ็ด**" = 매**운** 음식 ลำดับกลับกับภาษาไทย คือคำขยายอยู่ **หน้า** คำนาม
>
> สอนในบท 23 (교과서 236–237쪽 준비 2) ต่อยอดจาก ข้อ 18 (คำคุณศัพท์ + 이/가) · ข้อ 35 (ตาราง 받침 / ราก ㄹ) · ข้อ 37 (ㅂ 불규칙 — บทเดียวกัน)
>
> ไปใช้ต่อใน ข้อ 44 (-는 สำหรับกริยา) · ข้อ 47 (-(으)ㄴ กริยาอดีต — หน้าตาเหมือนกัน) · ข้อ 56 (-(으)ㄹ + สรุปตาราง 3 รูป) · ข้อ 59 (-는 것)

### 📌 รูปแบบและเงื่อนไข

ตัด 다 ทิ้ง แล้วดู**พยางค์สุดท้ายของราก** ตำรา 236쪽 อธิบายว่า "ต่อท้ายรากคำคุณศัพท์เพื่อขยายนามที่ตามมา บอกลักษณะหรือสภาพของนามนั้น"

| รากลงท้ายด้วย | ต่อ |
|:---|:---|
| สระ (รวม 하다 · ㅡ) | **-ㄴ** |
| **ㄹ** (ㄹ หลุดหน้า ㄴ) | **-ㄴ** (ไม่มี ㄹ) |
| พยัญชนะ (มีตัวสะกด) | **-은** |
| ลงท้าย **있다 / 없다** | **-는** (ไม่ใช่ -은) |
| **ㅂ 불규칙** (ข้อ 37) | ㅂ → 우 + ㄴ |
| 어떻다 *(เสริม)* | ㅎ หาย |

#### ข้อสังเกต

ตำรา 236쪽 สรุปกฎไว้สามข้อ และมีข้อสังเกตเพิ่มเรื่อง ㅡ ที่ไม่ตัด รูป -지 않다 + นาม และลำดับคำ

- **ตำรา 236쪽:** ลงท้ายสระหรือ ㄹ → -ㄴ
- ลงท้ายพยัญชนะ → -은
- คำคุณศัพท์ที่ลงท้ายด้วย 있다/없다 (재미있다 · 재미없다) → **-는**
- **ㅡ ไม่ตัด** ในรูปนี้: ㅡ ตกเฉพาะตอนต่อ 아/어 (예뻐요) แต่ -ㄴ ไม่ใช่สระ
- ดังนั้น 예쁘다 → **예쁜** (✗ 예뻔)
- **-지 않다 + นาม** (ตำรา ชื่อบท 23): 맵지 **않은** 음식이에요 *(เป็นอาหารที่ไม่เผ็ด)*
- 않다 มีตัวสะกด จึงเป็น -은 (ถ้าหน้ามันเป็นกริยาจะเป็น -지 않는 — เสริม ดูข้อ 44)
- **ลำดับ:** `[คำคุณศัพท์-(으)ㄴ] + [นาม] + 조사`
  - 매운 음식**을** 좋아해요 *(ชอบอาหารเผ็ด)*
  - อนุประโยคเล็ก ๆ ใส่ประธานของตัวเองได้: 창문**이** 큰 교실 *(ห้องที่หน้าต่างบานใหญ่)*

#### สูตรและวิธีทำ: -(으)ㄴ ขยายนาม (แบบกระดานครู)

-(으)ㄴ ต่อท้ายรากคำคุณศัพท์เพื่อให้ขยายนามที่ตามมา และต้องตัดสินใจตามลำดับสี่ข้อ ข้อแรกคือเป็น 있다/없다 หรือไม่ ข้อสองคือ ㅂ ไม่ปกติหรือไม่ ข้อสามคือรากลงท้าย ㄹ หรือไม่ และข้อสุดท้ายคือดู 받침 ของพยางค์สุดท้าย

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | รากลงท้าย **있다 / 없다** (맛있다 · 재미없다) | ต่อ **-는** แล้วจบ | 있/없 ทำตัวเหมือนกริยา จึงใช้ -는 ไม่ใช่ -은 |
| **กฎ 2** | ㅂ 불규칙 (맵다 · 덥다 · 어렵다) | เปลี่ยน **ㅂ → 우** ก่อน แล้วถือว่ารากลงท้ายด้วยสระ | ㅂ ไม่อยู่หน้าสระ (บท 23 ข้อ 37) |
| **กฎ 3** | รากลงท้าย **ㄹ** | **ตัด ㄹ ของราก** แล้วต่อ **-ㄴ** | ตัด 으 ก่อน แล้ว ㄹ หลุดหน้า ㄴ (กระดานครู 10/28 กฎ 2) |
| **กฎ 4** | ที่เหลือ ดู 받침 ท้ายราก | ไม่มี 받침 ต่อ **-ㄴ** แต่มี 받침 ต่อ **-은** | มี 받침 ต้องเก็บ 으 ไว้เป็นตัวพา ㄴ ไม่มี 받침 ตัด 으 ทิ้ง |

ลำดับทำคือ ① ตัด 다 แล้วดูว่าลงท้าย 있다 หรือ 없다 ไหม ถ้าใช่ต่อ -는 ② ถ้าเป็น ㅂ ไม่ปกติให้เปลี่ยน ㅂ เป็น 우 ③ ดูตัวสะกดท้ายราก ㄹ ตัด ㄹ แล้วต่อ -ㄴ ไม่มี 받침 ต่อ -ㄴ มี 받침 ต่อ -은 ตารางนี้แสดงทุกขั้นกับคำที่ตำราใช้

| 기본형 | ① 있다 / 없다? | ② ㅂ → 우? | ③ ดู 받침 → ต่อ | ④ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|:---|
| 예쁘다 | ไม่ใช่ | ไม่ใช่ | ไม่มี → -ㄴ | **예쁜** | ㅡ ไม่หลุด ✗ 예뻔 |
| 시원하다 | ไม่ใช่ | ไม่ใช่ | ไม่มี → -ㄴ | **시원한** | 하다 ไม่มี 받침 |
| 길다 | ไม่ใช่ | ไม่ใช่ | ㄹ → ตัด ㄹ + -ㄴ | **긴** | ตำรา 236쪽 ระบุ ㄹ |
| 달다 | ไม่ใช่ | ไม่ใช่ | ㄹ → ตัด ㄹ + -ㄴ | **단** | ㄹ หลุดหน้า ㄴ |
| 멀다 | ไม่ใช่ | ไม่ใช่ | ㄹ → ตัด ㄹ + -ㄴ | **먼** | ㄹ หลุดหน้า ㄴ |
| 작다 | ไม่ใช่ | ไม่ใช่ | ㄱ → -은 | **작은** | ✗ 작ㄴ (ตก 으) |
| 좋다 | ไม่ใช่ | ไม่ใช่ | ㅎ → -은 | **좋은** | ✗ 좋ㄴ (ตก 으) |
| 맛있다 | ใช่ | ข้ามไป | ข้ามไป → -는 | **맛있는** | ✗ 맛있은 |
| 재미있다 | ใช่ | ข้ามไป | ข้ามไป → -는 | **재미있는** | ✗ 영화은 |
| 재미없다 | ใช่ | ข้ามไป | ข้ามไป → -는 | **재미없는** | ✗ 재미없은 |
| 맵다 | ไม่ใช่ | ใช่ → 매우 | สระ → -ㄴ | **매운** | ✗ 맵은 |
| 덥다 | ไม่ใช่ | ใช่ → 더우 | สระ → -ㄴ | **더운** | ✗ 덥은 |
| 어렵다 | ไม่ใช่ | ใช่ → 어려우 | สระ → -ㄴ | **어려운** | ✗ 어렵은 |
| 뜨겁다 | ไม่ใช่ | ใช่ → 뜨거우 | สระ → -ㄴ | **뜨거운** | 뜨거운 커피 |

> [!TIP] วิธีจำสั้น ๆ
> ถามตามลำดับ เจอ 있다/없다 ต่อ -는 เจอ ㅂ ไม่ปกติ เปลี่ยนเป็น 우 ก่อน เจอ ㄹ ตัด ㄹ แล้วต่อ -ㄴ ที่เหลือไม่มี 받침 ใช้ -ㄴ มี 받침 ใช้ -은 และคำขยายต้องวางหน้านามเสมอ

#### รูปผิด / รูปถูก ของ -(으)ㄴ

ตารางนี้เทียบรูปที่เคยเจอในใบฝึกและรูปที่เสี่ยงผิดกับรูปถูก พร้อมบอกว่าผิดกฎข้อไหน

| ✗ รูปผิด | ✓ รูปถูก | ผิดกฎข้อ |
|:---|:---|:---|
| 영화은 | **재미있는** 영화 | กฎ 1 (เอา 은 ไปต่อท้ายนาม ทั้งที่ต้องเปลี่ยนรากคำคุณศัพท์เป็น -는 · ใบฝึก 23과) |
| 맛있은 음식 | 맛있**는** 음식 | กฎ 1 (있다 ใช้ -는) |
| 덥은 날씨 | **더운** 날씨 | กฎ 2 (ㅂ → 우 ก่อน) |
| 작ㄴ 책상 | 작**은** 책상 | กฎ 4 (มี 받침 ต้องเก็บ 으 ตระกูลเดียวกับ 읽세요 · 씻러) |

#### ถามด้วย 어떤 → ตอบด้วย A-(으)ㄴ + N

คำถาม 어떤 + N ถามว่า N เป็นแบบไหน คำตอบจึงเป็นคำคุณศัพท์ที่ผัน -(으)ㄴ ขยาย N นั้น

| คำถาม | คำตอบ (ตำรา = 시다 ข้อ 1 · ที่เหลือเฉลยเขียนเอง) |
|:---|:---|
| 어떤 **과일**을 좋아해요? | **신** 과일을 좋아해요. |
| 어떤 **친구**를 좋아해요? | **착한** / **똑똑한** 친구를 좋아해요. *(ชอบเพื่อนที่ใจดี / ฉลาด)* |
| 어떤 **교실**에서 공부해요? | **넓은** 교실에서 공부해요. |
| 어떤 **음식**을 좋아해요? | **매운** 음식을 좋아해요. |
| 어떤 **영화**를 봤어요? | **무서운** / **재미있는** 영화를 봤어요. *(ดูหนังน่ากลัว / สนุก)* |

### ⚠️ จุดสับสน

ข้อผิดของ -(으)ㄴ มาจากสามเรื่อง คือแยกคุณศัพท์ที่เป็นภาคแสดงกับที่ขยายนาม แยก ㄴ ตัวเดียวกันที่มีสามความหมาย และผันผิดตามกลุ่มของราก ตอนนี้ดูทีละเรื่อง

#### คุณศัพท์เป็น "ภาคแสดง" vs "ขยายนาม"

คำคุณศัพท์ตัวเดียวกันวางได้สองตำแหน่ง ตำแหน่งท้ายประโยคเป็นภาคแสดง ส่วนตำแหน่งหน้านามเป็นตัวขยาย

| | ภาคแสดง (ข้อ 18) | ขยายนาม (ข้อ 36) |
|:---|:---|:---|
| รูป | N이/가 + A-아/어요 | A-(으)ㄴ + N |
| ตัวอย่าง | 음식이 **매워요** *(อาหารเผ็ด)* | **매운** 음식 *(อาหารที่เผ็ด)* |
| ตัวอย่าง 2 | 방이 **작아요** *(ห้องเล็ก)* | **작은** 방 *(ห้องที่เล็ก)* |

#### ㄴ ตัวเดียวกัน แต่ 3 ความหมาย (เตรียมไว้ก่อน)

ตารางนี้เตรียมไว้ให้เห็นภาพรวมก่อนเรียนบทหลัง ๆ ว่ารูปที่ขยายนามมีสามรูปตามชนิดคำและกาล

| | ขยายนามด้วย | ตัวอย่าง | ข้อ |
|:---|:---|:---|:---|
| **คำคุณศัพท์** | -(으)ㄴ (สภาพปัจจุบัน) | 작**은** 방 · 매**운** 음식 | **36** |
| กริยา ปัจจุบัน/ประจำ | -**는** | 먹**는** 음식 | 44 |
| กริยา อดีต | -(으)ㄴ | 먹**은** 음식 *(บท 29 ยังไม่เรียน)* | 47 |

คำที่หน้าตาคล้ายกันและใช้รูปคนละแบบ ต้องแยกให้ออก

- **좋다 ≠ 좋아하다:** 좋다 เป็นคำคุณศัพท์ → **좋은** 사람 *(คนดี)*
- 좋아하다 เป็น**กริยา** → 좋아**하는** 사람 *(คนที่ชอบ — ข้อ 44)* ✗ 좋아한 사람 สำหรับ "คนที่ชอบ" ตอนนี้

#### กับดักที่เจอบ่อย

ข้อผิดหลักคือผันตามกลุ่มของรากผิด ตารางนี้เทียบคู่ ✓ / ✗ พร้อมเหตุผล ส่วนรายการใต้ตารางเป็นข้อควรระวังเพิ่มเติม

| ✓ ถูก | ✗ ผิด | เหตุผล |
|:---|:---|:---|
| 매운 · 더운 · 추운 | 맵은 · 덥은 · 춥은 | ㅂ → 우 (ข้อ 37) |
| 긴 · 단 | 길은 · 단은 | ราก ㄹ หลุดหน้า ㄴ |
| 예쁜 · 큰 | 예쁘은 · 크은 | ㅡ ไม่ตัด ใช้ -ㄴ ต่อได้เลย |
| 작은 책상 · 많은 사람 | 작 책상 · 많 사람 | ลืม 으 หลังตัวสะกด |
| 맛있는 · 재미있는 | 맛있은 · 재미있은 | 있다/없다 → -는 |
| 매운 **음식**이에요 | 매운이에요 | ไม่ใส่ 이에요 / 인 ต่อท้ายคำขยายตรง ๆ ใช้ N ตามหลังเสมอ |

- ระวัง **달은** = "พระจันทร์ + 은" (달 = ดวงจันทร์) คนละคำกับ 단 ← 달다
- ผู้เรียนเคยลืม 으 ใน -(으)세요 → 읽세요 · 받십니다 — กฎ "มีตัวสะกด → ต้องมี 으" เดียวกัน
- **ลำดับ:** ภาษาไทย "อาหารเผ็ด" คำขยายตามหลัง แต่เกาหลี **매운 음식** คำขยายนำหน้า — ✗ 음식 매운

> [!TIP] กฎสั้น ๆ
> ดูพยางค์สุดท้ายของราก: **สระ/ㄹ → ㄴ** · **พยัญชนะ → 은** · **있다/없다 → 는**
>
> ㅂ → 우+ㄴ และใช้กับ**คำคุณศัพท์**เท่านั้น (กริยา → ข้อ 44)

### 🧪 ออกสอบแล้ว · ข้อผิดที่เคยเจอ

คุณศัพท์ + -(으)ㄴ ออกสอบจริงหลายครั้ง และเป็นข้อที่เสียคะแนนมากที่สุดใน 복습시험③ (เสีย 6 คะแนน)

- **매일시험 23과 (27 ต.ค. · ได้ 4.5/10):**
  - B5 큰 가방 ✓ · B6 매운 떡볶이 ✓
  - B7 เว้นว่าง → **어려운** 질문
  - B8 영화은 ✗ → **재미있는** 코미디 영화 (-있다 ใช้ -는)
  - C10 친절안 사람은 ✗ → **친절한 사람을** (ครึ่ง)
- **연습지 23과 (26 ต.ค.):** ตาราง 4 กลุ่ม 16 ช่อง ถูกทั้งหมด (작은 · 큰 · 어려운 · 재미있는) ครูยังไม่ตรวจ
- **워크북 23과 G–H:** 작은 가방 · 더러운 방 · 멋있는 · 슬픈 ✓ (ผู้เรียนตอบตรงเฉลยพิมพ์)
- **복습시험③ (6 พ.ย.):**
  - 쓰기 ตอน 3 ข้อ 2: 어떤 친구 → 재미있고 친절한 ✓
  - ตอน 4 ข้อ 1–3: 부르는 · 읽은 · 먹는 ✓
  - ตอน 4 ข้อ 4: 작는 ✗ → **작은** (เสีย 3)
  - ตอน 4 ข้อ 5: 예쁘는 ✗ → **예쁜** (เสีย 3)
- **ชุดทบทวนปลายภาค:**
  - ข้อ 5-1 다른 나라 · ข้อ 5-3 재미있는 영화 · ข้อ 5-5 어려운 문법
  - ❷ ตารางคอลัมน์ -(으)ㄴ/는: 쉬운 · 매운 · 좁은 (กับ 돕는 · 입는)
  - ❸ ข้อ 5: 달다 → **단** (ไม่ใช่ ✗ 달은)
- **หลัง ③:** 다르는 · 빠르는 ✗ → **다른 · 빠른** (워크북 32과 ครั้งที่ 2)
  - คุณศัพท์ใช้ -(으)ㄴ เสมอ ไม่ต้องดูคำบอกเวลา · ㅡ-drop ใช้กับ -아/어 เท่านั้น (예쁜 · 큰 ไม่ตัด ㅡ)

> [!SUMMARY] สรุป
> - -(으)ㄴ ใช้กับ**คำคุณศัพท์**เท่านั้น ขยายคำนามที่ตามหลัง โดยคำขยายอยู่หน้านาม เช่น 매운 음식 · 좋은 사람
> - ราก: สระ/ㄹ → **ㄴ** (예쁜 · 긴) · พยัญชนะ → **은** (작은) · 있다/없다 → **는** (맛있는)
> - ราก ㅂ 불규칙 → ㅂ เป็น 우 แล้วต่อ ㄴ (매운 · 더운 · 추운)
> - ㅡ ไม่ตัด (예쁜 · 큰) และราก ㄹ ไม่ต้องมี ㄹ (긴 · 단) ต่างจากการผัน -아/어
> - ข้อผิดที่เคยเจอคือลืม 으 หลังตัวสะกด และ ㅈ/ㅊ (저 → 처) ส่วน 낭독시험 ⑤ (10/28) = 23과
