## 28. -(으)ㄹ 거예요 (จะ... / คงจะ...)

> [!INTRO] ข้อนี้คืออะไร
> -(으)ㄹ 거예요 เป็นรูปสุภาพที่บอก**แผนในอนาคต** เมื่อประธานเป็น ฉัน/คุณ และบอก**การคาดเดา** เมื่อประธานเป็นบุคคลที่ 3 หรือเป็นคำคุณศัพท์ วิธีสร้างคือเติมท้ายรากศัพท์ (어간) แล้วตามด้วย 거예요
>
> ใช้ทุกครั้งที่พูดถึงสิ่งที่ยังไม่เกิด เช่น แผนวันหยุด แผนปิดเทอม หรือเดาว่าพรุ่งนี้อากาศจะเป็นอย่างไร รูปนี้ไม่เปลี่ยนตามบุรุษ
>
> สอนในบท 19 (교과서 172–173쪽) ต่อยอดจาก ข้อ 06 (หารากศัพท์) · ข้อ 23 (เลือกกาลจากเวลา) · ข้อ 26 (-(으)러)
>
> ไปใช้ต่อใน ข้อ 32 · ข้อ 33 · ข้อ 35 (ตาราง 받침) และงานพูด 발표 방학 계획 (10/20)

### 📌 รูปแบบและเงื่อนไข

ขั้นแรกให้ตัด 다 ทิ้ง แล้วดู**พยางค์สุดท้ายของราก**ว่ามีตัวสะกด (받침) ไหม ถ้าไม่มีให้เติม ㄹ ถ้ามีให้เติม 을 ส่วนรากที่ลงท้ายด้วย ㄹ อยู่แล้วเติมแค่ 거예요

| รากศัพท์ลงท้าย | ต่อ |
|:---|:---|
| ไม่มีตัวสะกด (รวม ㅡ · 하다) | **-ㄹ 거예요** |
| มีตัวสะกด (รวม 있다) | **-을 거예요** |
| ลงท้ายด้วย **ㄹ** | เติมแค่ **거예요** — ㄹ ของรากเป็น ㄹ ของรูปนี้อยู่แล้ว (ไม่ซ้ำ ㄹ · ไม่ใส่ 을) |
| คำนาม | N + **일 거예요** (ไม่ดูตัวสะกด) |
| ยกย่อง -(으)시- | **-(으)실 거예요** |

#### ตัวอย่างการผัน

ตารางนี้เรียงตามกลุ่มของรากข้างบน หนึ่งคำต่อหนึ่งแถว ส่วนคำนามไม่ต้องผัน แค่ต่อ 일 거예요 ท้ายคำ

| กลุ่ม | 기본형 → ผัน | ไทย |
|:---|:---|:---|
| ไม่มี 받침 | 가다 → **갈 거예요** | จะไป |
| ไม่มี 받침 | 보다 → **볼 거예요** | จะดู |
| ไม่มี 받침 (ㅡ) | 쓰다 → **쓸 거예요** | จะเขียน |
| ไม่มี 받침 (하다) | 하다 → **할 거예요** | จะทำ |
| มี 받침 | 읽다 → **읽을 거예요** | จะอ่าน |
| มี 받침 | 먹다 → **먹을 거예요** | จะกิน |
| มี 받침 (있다) | 있다 → **있을 거예요** | จะอยู่ |
| ราก ㄹ | 만들다 → **만들 거예요** | จะทำ |
| ราก ㄹ | 살다 → **살 거예요** | จะอยู่ |
| ราก ㄹ | 놀다 → **놀 거예요** | จะเล่น |
| คำนาม | 선생님**일 거예요** | คงเป็นอาจารย์ |
| คำนาม | 학생**일 거예요** | คงเป็นนักเรียน |
| ยกย่อง | 하다 → **하실 거예요** | ท่านจะทำ |
| ยกย่อง | 오다 → **오실 거예요** | ท่านจะมา |

#### ความหมายและข้อสังเกต

รูปเดียวกันมีสองความหมายตามประธานของประโยค และมีข้อสังเกตเรื่องการใช้กับชนิดคำ การปฏิเสธ และการสะกดที่ต้องจำ

- **ความหมายตามประธาน (ตำรา 172쪽):** ประธาน ฉัน/คุณ → "ตั้งใจ / วางแผนว่าจะ…"
- ประธานบุคคลที่ 3 หรือคำคุณศัพท์ → "คงจะ…" (ผู้พูดเดา) เช่น 날씨가 좋**을 거예요** *(อากาศคงจะดี)*
- ใช้ได้กับกริยา คำคุณศัพท์ และ N일 รูปไม่เปลี่ยนตามบุรุษ
- ปฏิเสธใส่ 안 หน้ากริยา (ข้อ 08): 안 갈 거예요 *(จะไม่ไป)*
- **ที่มาของการสะกด:** 거예요 = 것 *({n:สิ่ง}ที่/{n:เรื่อง}ที่)* + 이에요
- จึงต้องมี **예** และเว้นวรรคจากราก: **갈 거예요** (✗ 거요 · ✗ 거에요 · ✗ 갈거예요)

#### การออกเสียง

ตัว ㄱ ของ 거 ที่ตามหลัง ㄹ ออกเสียงเป็น ㄲ

| เขียน | อ่าน |
|:---|:---|
| 할 거예요 | [할 꺼예요] |
| 읽을 거예요 | [일글 꺼예요] |
| 먹을 거예요 | [머글 꺼예요] |

#### สูตรและวิธีทำ: -(으)ㄹ 거예요 (แบบกระดานครู)

-(으)ㄹ 거예요 ต่อท้ายรากกริยา สิ่งเดียวที่ต้องตัดสินใจคือตัวคั่นระหว่างรากกับ 거예요 ว่าจะเป็น ㄹ เป็น 을 หรือไม่ต้องเติมอะไร ซึ่งดูจากตัวสะกด (받침) ของพยางค์สุดท้ายของราก

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | พยางค์สุดท้ายของรากไม่มี 받침 (รวม ㅡ และ 하다) | ต่อ **ㄹ** ติดราก | ไม่มี 받침 ให้ตัด 으 ของ (으)ㄹ ทิ้ง เหลือ ㄹ ตัวเดียวเป็น 받침 |
| **กฎ 2** | พยางค์สุดท้ายมี 받침 (รวม 있다 และ 받침คู่อย่าง 읽) | ต่อ **을** | มี 받침 แล้วต้องเก็บ 으 ไว้เป็นตัวพา ㄹ |
| **กฎ 3** | พยางค์สุดท้ายคือ 받침 **ㄹ** | **ไม่เติมอะไร** ต่อ 거예요 ได้เลย | ตัด 으 ก่อน แล้ว ㄹ ของรากหลุด ให้ ㄹ ของคำต่อมาแทน หน้าตาเหมือนเดิม (กฎ ㄹ 탈락 บท 25 ข้อ 40) |
| **กฎ 4** | ทุกกรณี | เว้นวรรคหนึ่งครั้ง แล้วเขียน **거예요** ให้ครบ | 거예요 = 것 + 이에요 เป็นอีกคำหนึ่ง จึงต้องมี 예 |

ลำดับทำคือ ① ตัด 다 เหลือราก ② ดูพยางค์สุดท้ายของรากว่าไม่มี 받침 มี 받침 หรือเป็น ㄹ ③ ต่อตัวคั่นตามกฎ 1 ถึง 3 แล้วเว้นวรรคเขียน 거예요 ตามกฎ 4 ตารางนี้แสดงทุกขั้นกับคำที่ตำราใช้

| 기본형 | ① ราก (ตัด 다) | ② 받침 ท้ายราก → ตัวคั่น | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 가다 | 가 | ไม่มี → ㄹ | **갈 거예요** | ✗ 갈거예요 (ไม่เว้นวรรค) |
| 보다 | 보 | ไม่มี → ㄹ | **볼 거예요** | อ่าน [볼 꺼예요] |
| 쓰다 | 쓰 | ไม่มี (ㅡ ไม่ใช่ 받침) → ㄹ | **쓸 거예요** | ㅡ ไม่หลุดตรงนี้ |
| 하다 | 하 | ไม่มี → ㄹ | **할 거예요** | อ่าน [할 꺼예요] |
| 가르치다 | 가르치 | ไม่มี → ㄹ | **가르칠 거예요** | ✗ 가르칠 거요 (ตก 예) |
| 먹다 | 먹 | ㄱ → 을 | **먹을 거예요** | อ่าน [머글 꺼예요] |
| 읽다 | 읽 | ㄺ (ไม่ใช่ ㄹ เดี่ยว) → 을 | **읽을 거예요** | อ่าน [일글 꺼예요] |
| 있다 | 있 | ㅆ → 을 | **있을 거예요** | จะอยู่ หรือคงมี |
| 만들다 | 만들 | ㄹ → ไม่เติม | **만들 거예요** | ✗ 만들을 거예요 |
| 살다 | 살 | ㄹ → ไม่เติม | **살 거예요** | ✗ 살을 거예요 |
| 놀다 | 놀 | ㄹ → ไม่เติม | **놀 거예요** | ✗ 놀을 거예요 |
| 하다 + (으)시 | 하시 | ไม่มี → ㄹ | **하실 거예요** | ใส่ 시 (ยกย่อง) ก่อนแล้วจึงต่อ ㄹ |
| 학생 (นาม) | 학생 | ไม่ดู 받침 | **학생일 거예요** | N + 일 거예요 แปลว่าคงเป็น |

> [!TIP] วิธีจำสั้น ๆ
> ดู 받침 ตัวสุดท้ายของรากก่อนเสมอ ไม่มีก็ต่อ ㄹ มีก็ต่อ 을 ถ้าเป็น ㄹ ไม่ต้องเติมอะไร แล้วเว้นวรรคและเขียน 거예요 ให้ครบ (갈 거예요 ไม่ใช่ 갈거요)

#### รูปผิด / รูปถูก ของ -(으)ㄹ 거예요

ตารางนี้เทียบรูปที่เคยเจอในใบฝึกกับรูปที่เสี่ยงผิดตามกฎ พร้อมบอกว่าผิดกฎข้อไหน

| ✗ รูปผิด | ✓ รูปถูก | ผิดกฎข้อ |
|:---|:---|:---|
| 가르칠 거요 | 가르칠 **거예요** | กฎ 4 (ตก 예 · ใบฝึก 20과) |
| 갈거예요 | 갈 **거예요** | กฎ 4 (ไม่เว้นวรรค · ครูรับแต่ไม่ถูก) |
| 갈 거에요 | 갈 **거예요** | กฎ 4 (ต้องเป็น 예 ไม่ใช่ 에) |
| 만들을 거예요 | 만들 **거예요** | กฎ 3 (ราก ㄹ ไม่เติม 을) |

### 📖 ตัวอย่างและการใช้

ตัวอย่างในตอนนี้แบ่งเป็นสี่กลุ่ม คือ การเลือกกาลจากคำบอกเวลา การตอบให้ตรงกับคำถาม บทสนทนาจากสไลด์ของครู และประโยคตัวอย่างเพิ่มเติม

#### เลือกกาลจากคำบอกเวลา

คำบอกเวลาในประโยคบอกว่าต้องใช้กาลไหน คำที่ชี้ไปอนาคตคือสัญญาณให้ใช้ -(으)ㄹ 거예요

| คำบอกเวลา | กาล | ตัวอย่าง |
|:---|:---|:---|
| 어제 · 지난주에 · 작년에 | -았/었/였어요 (ข้อ 23) | 어제 학교에 **갔어요** *(เมื่อวานไปโรงเรียน)* |
| 지금 · 매일 | -아/어요 (ข้อ 06) | 지금 학교에 **가요** *(ตอนนี้ไปโรงเรียน)* |
| 내일 · 모레 · 다음 주에 | **-(으)ㄹ 거예요** | 내일 학교에 **갈 거예요** *(พรุ่งนี้จะไปโรงเรียน)* |
| 방학에 · 이번 주말에 | **-(으)ㄹ 거예요** | ใช้เหมือนแถวบน |

ใช้ปัจจุบันแทนอนาคตได้ (내일 학교에 가요 *(พรุ่งนี้ไปโรงเรียน)*) แต่ **갈 거예요** ชัดเจนว่าเป็น**แผน** การเปลี่ยนกาลเปลี่ยนเฉพาะท้ายราก ตารางต่อไปนี้คือแบบฝึกผัน 3 กาล (연습지 19과 A)

| 동사 | -아/어요 | -았/었어요 | -(으)ㄹ 거예요 |
|:---|:---|:---|:---|
| 오다 *(มา)* | 와요 | 왔어요 | **올 거예요** |
| 읽다 *(อ่าน)* | 읽어요 | 읽었어요 | **읽을 거예요** |
| 만들다 *(ทำ)* | 만들어요 | 만들었어요 | **만들 거예요** |
| 살다 *({v:อยู่อาศัย})* | 살아요 | 살았어요 | **살 거예요** |

#### ตอบให้ตรงกับคำถาม

เลือกชนิดของคำตอบตามคำถาม (ข้อ 12 และ ส่วนที่ 3) ครูวงกลมคำว่า **언제** ไว้เป็นคำถามเวลารวม ครอบคลุม 며칠 · 몇 시 · 무슨 요일 · 몇 월 ทุกแบบต้องตอบเป็น**เวลา**

| ถามด้วย | ตอบเป็น |
|:---|:---|
| 뭐 · 무엇을 | **กิจกรรม** (+ 을/를) |
| **언제** · 몇 시에 | **เวลา** (วัน/เดือน/ช่วง + 에) |
| 어디에 · 어디에서 | **สถานที่** (에 = ไป · 에서 = ทำที่) |
| 누구하고 | **คน** + 하고 |

ตัวอย่างถาม–ตอบของแต่ละแบบมีดังนี้ สังเกตว่าคำตอบเปลี่ยนชนิดตามคำถามเสมอ

| ถามด้วย | ถาม | ตอบ |
|:---|:---|:---|
| 뭐 | 가: 오늘 오후에 뭐 할 거예요? *({n:บ่ายนี้}{e:จะ}{v:ทำ}{q:อะไร})* | 나: 친구를 **만날 거예요**. *({e:จะ}{v:พบ}{n:เพื่อน})* |
| 언제 | 가: 언제 고향에 갈 거예요? *({e:จะ}{v:กลับ}{n:บ้านเกิด}{q:เมื่อไหร่})* | 나: **방학에** 고향에 갈 거예요. *({p:ช่วง}{n:ปิดเทอม})* |
| 몇 시에 | 가: 몇 시에 갈 거예요? *(จะไปกี่โมง)* | 나: 오후 두 시에 갈 거예요. *(จะไปบ่ายสองโมง)* |
| 어디에 | 가: 친구와 같이 어디에 갈 거예요? *({e:จะ}{v:ไป}{q:ไหน}{p:กับ}{n:เพื่อน})* | 나: 서울타워에 갈 거예요. *({e:จะ}{v:ไป}{n:หอคอยโซล})* |
| 누구하고 | 가: 누구하고 갈 거예요? *({e:จะ}{v:ไป}{p:กับ}{q:ใคร})* | 나: 친구하고 같이 갈 거예요. *({v:ไป}{p:กับ}{n:เพื่อน})* |

#### 📽️ จากสไลด์อาจารย์ (교과서 172쪽)

สไลด์ 문법 2 ของครูมีบทสนทนา 3 คู่ และตารางตามตัวสะกด (○ → 을 · ✗ → ㄹ · ㄹ → ㄹ) ซึ่งรวมอยู่ในตอน 📌 ข้างบนแล้ว

| ถาม | ตอบ |
|:---|:---|
| 가: 내일 뭐 **할 거예요**? *({a:พรุ่งนี้}{e:จะ}{v:ทำ}{q:อะไร})* | 나: 쇼핑**할 거예요**. *({e:จะ}{v:ไป}{n:ช็อปปิง})* |
| 가: 주말에 뭐 **할 거예요**? *({n:สุดสัปดาห์}{e:จะ}{v:ทำ}{q:อะไร})* | 나: 도서관에서 책을 **읽을 거예요**. *({e:จะ}{v:อ่าน}{n:หนังสือ}{p:ที่}{n:ห้องสมุด})* |
| 가: 언제 대학교에 **갈 거예요**? *({e:จะ}{v:ไป}{n:มหาวิทยาลัย}{q:เมื่อไหร่})* | 나: 내년에 대학교에 **갈 거예요**. *({n:ปีหน้า}{e:จะ}{v:ไป}{n:มหาวิทยาลัย})* |

#### ตัวอย่างประโยคเพิ่มเติม

ประโยคต่อไปนี้ใช้ -(으)ㄹ 거예요 ทั้งแบบแผนและแบบคาดเดา ข้อ 4 ใช้ร่วมกับ -(으)러 ได้

1. 내일 영화를 **볼 거예요**. *(พรุ่งนี้จะดูหนัง)*
2. 집에서 책을 **읽을 거예요**. *(จะอ่านหนังสือที่บ้าน)*
3. 오늘 저녁에 한국 음식을 **만들 거예요**. *({n:เย็น}{a:นี้}{e:จะ}{v:ทำ}{n:อาหารเกาหลี})*
4. 이번 주말에 뭐 **할 거예요**? — 전시회를 **보러** 덕수궁 미술관에 **갈 거예요**. *(สุดสัปดาห์นี้จะทำอะไร — จะไปหอศิลป์ท็อกซูกุงเพื่อดูนิทรรศการ — -(으)러 ข้อ 26 ใช้ร่วมกันได้)*
5. 내일은 날씨가 **좋을 거예요**. *(พรุ่งนี้อากาศคงจะดี)*
6. 저분은 아마 우리 학교 선생님**일 거예요**. *(ท่านนั้นคงเป็นอาจารย์ของโรงเรียนเรา)*
7. 불고기를 **먹을 거예요**. 그리고 학교를 **구경할 거예요**. *({e:จะ}{v:กิน}{n:บุลโกกิ} {a:แล้วก็}{e:จะ}{v:เที่ยวชม}{n:โรงเรียน})*

### ⚠️ จุดสับสน

คำว่า "จะ" ในภาษาไทยมีคำเดียว แต่ภาษาเกาหลีแยกเป็นหลายรูปตามหน้าที่ ตอนนี้จะเทียบ -(으)ㄹ 거예요 กับรูปที่ใกล้เคียง แล้วดูกับดักที่ผู้เรียนมักพลาด

#### -(으)ㄹ 거예요 vs -겠- vs -(으)ㄹ까요?

สามรูปนี้แปลเป็นไทยว่า "จะ" ได้เหมือนกัน แต่หน้าที่ต่างกัน (ดูข้อ 22 สำหรับ -겠- และข้อ 33 สำหรับ -(으)ㄹ까요?)

| | -(으)ㄹ 거예요 | -겠- (ข้อ 22) | -(으)ㄹ까요? (ข้อ 33) |
|:---|:---|:---|:---|
| ความหมาย | แผน / คาดการณ์ | ตั้งใจ**ทันที** / สูตรสุภาพ | ชวน / ถามความเห็น |
| ประธาน | ทุกบุรุษ | บุรุษที่ 1 (ถามผู้ฟังได้) | 우리 (เรา) |
| ตัวอย่าง | 내일 갈 거예요 | 제가 하겠습니다 | 같이 갈까요? |
| ไทย | พรุ่งนี้จะไป | ฉันจะทำ | ไปด้วยกันไหม |

ตัวอย่างที่ใช้ได้และคู่เทียบที่ต้องแยกให้ออก:

| ประโยค | ไทย | หมายเหตุ |
|:---|:---|:---|
| ✓ 저는 내일 **갈 거예요**. | ฉันพรุ่งนี้จะไป | แผน |
| ✓ 친구가 **갈 거예요**. | เพื่อนจะไป / คงไป | — |
| ✓ 내일 **갈 거예요?** | คุณพรุ่งนี้จะไปไหม | ถามแผน |
| ≠ 같이 **갈까요?** | ไปด้วยกันไหม | ชวน |
| ✓ 학생**일 거예요**. | คงเป็นนักเรียน | — |
| ✓ 선생님이 **오실 거예요**. | อาจารย์คงจะมา / จะมา | — |

#### กับดักที่เจอบ่อย

ข้อผิดของข้อนี้มี 5 กลุ่ม คือ รากที่ลงท้าย ㄹ การสะกด 거예요 การใช้ 일 거예요 คำบอกเวลา และการตอบไม่ตรงคำถาม ตารางข้างล่างเทียบ ✓ / ✗ ของสามกลุ่มแรก ส่วนอีกสองกลุ่มอยู่ในรายการต่อจากตาราง

| ✓ ถูก | ✗ ผิด | เหตุผล |
|:---|:---|:---|
| 살 거예요 | 살을 거예요 | ราก ㄹ ไม่ใส่ 을 |
| 놀 거예요 | 놀을 거예요 | ราก ㄹ ไม่ใส่ 을 |
| 만들 거예요 | 만들을 거예요 | ราก ㄹ ไม่ใส่ 을 |
| **갈 거예요** | 갈 거에요 · 갈 거요 · 갈거예요 | ต้องมี 예 และเว้นวรรค |
| 학생일 거예요 | 가일 거예요 | 일 거예요 ใช้ต่อท้าย**คำนาม**เท่านั้น |

- **คำเวลา:** บางคำไม่ใส่ 에 บางคำต้องใส่
  - ไม่ใส่ 에 (ข้อ 10): 내일 · 모레 · 오늘
  - ไม่ใส่ 에 เช่นกัน: 지금 · 매일
  - ต้องใส่ 에: 방학에 · 주말에 · 저녁에
- **ตอบไม่ตรงคำถาม:** 언제 → เวลา ไม่ใช่กิจกรรม · 어디에서 → สถานที่ ไม่ใช่คน (ดู 📖 ตาราง "ตอบให้ตรงกับคำถาม")

> [!TIP] กฎสั้น ๆ
> **แผนของตัวเอง/คาดเดา = ㄹ 거예요 · ตั้งใจแน่วแน่ตอนนี้ = 겠 · ชวนกัน = ㄹ까요?**
