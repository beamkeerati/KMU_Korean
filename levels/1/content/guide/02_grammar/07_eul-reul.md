## 07. 을/를 (คำชี้กรรม)

> [!INTRO] ข้อนี้คืออะไร
> 을/를 ติดหลังคำนามที่เป็น **กรรม** (สิ่งที่ถูกกระทำ) ก่อนกริยา เพื่อบอกว่านามนั้นเป็นสิ่งที่ได้รับผลของการกระทำจากผู้ทำ
>
> สอนในบท 11 (교과서 98쪽) ต่อยอดจากข้อ 01 (이/가 — ประธาน) และข้อ 06 (กริยา-아/어/여요)
>
> ไปใช้ต่อในข้อ 08 (N을/를 안 V) ข้อ 09 (N에서 + กรรม + กริยา) ข้อ 12 (โครงสร้างประโยค) ข้อ 14 (คู่กรรม-กริยาที่ต้องจำ) และข้อ 17 (도) กับข้อ 31 (만) ที่แทนที่ 을/를 ได้

### 📌 รูปแบบและเงื่อนไข

เลือก 을 หรือ 를 ตามตัวสะกดของคำนาม ตำราบอกว่าติดหลังนามเพื่อบอกว่านามนั้นเป็นสิ่งที่ได้รับผลของการกระทำจากผู้ทำ ส่วนข้างล่างเป็นโครงสร้างประโยคและกฎย่อย

| คำนามลงท้าย | ใช้ | ตัวอย่าง |
|:---|:---|:---|
| **มีตัวสะกด** (받침 ○) | **을** | 책**을** 읽어요 *(อ่านหนังสือ)* · 밥**을** 먹어요 *(กินข้าว)* · 신문**을** 봐요 *(ดูหนังสือพิมพ์)* |
| **ไม่มีตัวสะกด** (받침 ✗) | **를** | 친구**를** 만나요 *(พบเพื่อน)* · 커피**를** 마셔요 *(ดื่มกาแฟ)* · 영화**를** 봐요 *(ดูหนัง)* |

#### โครงสร้างประโยคเต็ม

ลำดับประโยคเกาหลีคือ ประธาน + กรรม + กริยา โดยกริยาอยู่ท้ายสุดและกรรมอยู่หน้ากริยา โครงสร้างเต็มคือ **ประธาน이/가(은/는) + กรรม을/를 + กริยา-아/어/여요**

- 친구**가** 신문**을** 봐요 *(เพื่อนดูหนังสือพิมพ์)*
- 마키 씨**는** 사과**를** 먹어요 *(คุณมากิกินแอปเปิล)*
- ภาษาไทยพูด "กิน**ข้าว**" แต่เกาหลีวางกรรมก่อน: "**ข้าว**을 กิน" (밥을 먹어요)

#### คำนามหน้า 하다

คำนามที่ตามด้วย 하다 ก็ติด 을/를 ได้ และภาษาพูดละ 를 ได้

- 숙제**를** 해요 *(ทำการบ้าน)*
- 청소**를** 해요 *(ทำความสะอาด)*
- 운동**을** 해요 *(ออกกำลังกาย)*
- 공부**를** 해요 *(เรียน)* — ภาษาพูดละ 를 ได้ (공부(를) 해요 · 공부 안 해요 — ข้อ 08)

#### ถามหากรรมและถามหาผู้ทำ

ถามหากรรมด้วย 무엇을 / 누구를 และถามหาผู้ทำด้วย 누가 (ดู ส่วนที่ 3)

- **ถามหากรรม** = 무엇을 / 누구를 + กริยา
  - 무엇**을** 해요? → 텔레비전을 봐요. *(ทำอะไร → ดูทีวี)*
  - 누구**를** 만나요? → 친구를 만나요. *(พบใคร → พบเพื่อน)*
- **ถามหาผู้ทำ** = 누가 + กรรม**를** + กริยา
  - 누가 노래**를** 해요? → 마키 씨가 노래**를** 해요. *(ใครร้องเพลง → คุณมากิร้องเพลง)*

#### เสียงจริง ≠ ตัวเขียน

ตัวสะกดของคำหน้าไปเชื่อมกับเสียง 을/를 แต่ให้เขียนตามรูปคำเสมอ

| เขียน | อ่านออกเสียง |
|:---|:---|
| 물을 | [무를] |
| 이메일을 | [이메이를] |
| 책을 | [채글] |

#### สูตรและวิธีทำ: N + 을/를 (แบบกระดานครู)

ติด 을/를 หลังคำนามที่เป็นกรรมของกริยา โดยเลือกรูปจากตัวสะกดของพยางค์สุดท้าย แต่ต้องถามก่อนว่ากริยานั้นมีกรรมจริงหรือไม่ กฎมีสี่ข้อ ทำตามลำดับ

| กฎ | เงื่อนไข | ทำอะไร | ทำไม |
|:---|:---|:---|:---|
| **กฎ 1** | กริยาลงมือทำกับสิ่งหนึ่ง (อ่านอะไร กินอะไร พบใคร) | ใส่ **을/를** ให้นามที่ถูกกระทำ | 을/를 ชี้ผู้ถูกกระทำ ส่วนผู้ทำใช้ 이/가 |
| **กฎ 2** | นามมีตัวสะกด (ㄹ และ ㅇ ก็นับ) | ใช้ **을** | รูปที่ขึ้นต้นด้วยเสียงสระ ต่อหลังตัวสะกดได้ลื่น |
| **กฎ 3** | นามไม่มีตัวสะกด | ใช้ **를** | รูปที่ขึ้นต้นด้วยพยัญชนะ ต่อหลังสระได้ลื่น |
| **กฎ 4** | N + 하다 (숙제 운동 청소) | ถือ N เป็นกรรม ใส่ 을/를 ตามกฎ 2–3 แล้วตามด้วย 해요 | N กับ 하다 เป็นสองคำ (ภาษาพูดละ 를 ได้ — ข้อ 08) |

ลำดับทำคือ ① ถามว่ากริยามีกรรมไหม ถ้าเป็น 있다 · 이다 · คุณศัพท์ หรือไป/มา ไม่ใส่ 을/를 ② ดูตัวสะกดของกรรม เลือก 을 หรือ 를 ③ ติดนามทันทีไม่เว้นวรรค แล้ววางไว้หน้ากริยา ตารางนี้แสดงทุกขั้นกับคำที่ตำรา 11과 ใช้

| นาม + กริยา | ① มีกรรมไหม | ② ตัวสะกด → เลือก | ③ ผล | หมายเหตุ |
|:---|:---|:---|:---|:---|
| 책 + 읽어요 | มี (อ่านอะไร) | มี (ㄱ) → 을 | **책을 읽어요** | |
| 물 + 마셔요 | มี (ดื่มอะไร) | มี (ㄹ) → 을 | **물을 마셔요** | ㄹ นับเป็นตัวสะกด |
| 가방 + 사요 | มี (ซื้ออะไร) | มี (ㅇ) → 을 | **가방을 사요** | ㅇ นับเป็นตัวสะกด |
| 친구 + 만나요 | มี (พบใคร) | ไม่มี → 를 | **친구를 만나요** | |
| 숙제 + 해요 | มี (N + 하다) | ไม่มี → 를 | **숙제를 해요** | ภาษาพูดละ 를 ได้ |
| 운동 + 해요 | มี (N + 하다) | มี (ㅇ) → 을 | **운동을 해요** | |
| 꽃 + 예뻐요 | ไม่มี (คุณศัพท์) | ไม่ต้องเลือก | **꽃이 예뻐요** | ใช้ 이/가 (ข้อ 01) |
| 학교 + 가요 | ไม่มี (ไป → 에) | ไม่ต้องเลือก | **학교에 가요** | ใช้ 에 (ข้อ 05) |

> [!TIP] วิธีจำสั้น ๆ
> ผู้ทำใช้ 이/가 ผู้ถูกกระทำใช้ 을/를 แล้วดูตัวสะกดของผู้ถูกกระทำ มี = 을 ไม่มี = 를 ถ้ากริยาไม่มีผู้ถูกกระทำ (있다 · 이다 · คุณศัพท์) หรือเป็นไป/มา ไม่ใช้ 을/를

#### รูปผิด / รูปถูก ของ 을/를

รูปต่อไปนี้ผู้เรียนเคยเขียนผิดในแบบทดสอบและโจทย์ฝึก ปัญหาไม่ใช่การเลือก 을 หรือ 를 แต่เป็นกรรมที่ไม่เข้ากับกริยา การใช้ 가 หรือ 에 แทน และการลืมใส่

| ✗ รูปผิด | ✓ รูปถูก | ทำไม |
|:---|:---|:---|
| 학생을 공부해요 | **숙제를 해요** | กรรมต้องเข้ากับกริยา (매일시험 11과 B) |
| 경치에 구경할 거예요 | **경치를 구경할 거예요** | 구경하다 รับกรรมด้วย 를 ไม่ใช่ 에 (ชุดทบทวนของครู 쓰기 14) |
| 시계가 받았어요 | **시계를 받았어요** | 시계 เป็นสิ่งที่ถูกรับ ใช้ 를 ไม่ใช่ 가 (mock บท 20) |
| 양말 드릴 거예요 | **양말을 드릴 거예요** | ลืม 을 หน้ากริยา (mock บท 20) |

### 📖 ตัวอย่างและการใช้

ตัวอย่างเริ่มจากสไลด์ของครู แล้วต่อด้วยคู่ "กรรม + กริยา" และประโยคจากตำรา 11과

#### 📽️ จากสไลด์อาจารย์ — 교과서 11과 문법 1 명사 + 을/를

ครูเขียนโครงสร้าง **___이/가 ___을/를 ___아/어/여요** (ในสมุดจดคุณเขียนสีน้ำเงิน) แล้วฝึกถาม-ตอบด้วย 무엇을 해요?

- 가: 친구가 무엇을 해요? 나: 빵을 먹어요. *(เพื่อนทำอะไร → กินขนมปัง)*
- 가: 선생님이 무엇을 해요? 나: 텔레비전을 봐요. *(ครูทำอะไร → ดูทีวี)*
- 가: 왕쯔이 씨가 무엇을 해요? 나: 친구를 만나요. *(คุณหวางจื่ออีทำอะไร → พบเพื่อน)*
- สรุปของครู: กรรมของกริยาติด **을** (ลงท้ายพยัญชนะ) หรือ **를** (ลงท้ายสระ) ก่อนกริยา · ประโยคเต็ม = ประธาน + 이/가 + กรรม + 을/를 + กริยา

#### จากตำรา 11과 — คู่ "กรรม + กริยา" (연습 3–4, 교과서 98–99쪽 · บทอ่าน 11과)

คู่ต่อไปนี้มาจากแบบฝึกหัดและบทอ่าน ควรท่องเป็นคู่ ไม่ท่องแยกคำ

| 한국어 | ไทย |
|:---|:---|
| 영화**를** 봐요 | ดูหนัง |
| 책**을** 읽어요 | อ่านหนังสือ |
| 신문**을** 읽어요 | อ่านหนังสือพิมพ์ |
| 물**을** 마셔요 | ดื่มน้ำ |
| 커피**를** 마셔요 | ดื่มกาแฟ |
| 빵**을** 먹어요 | กินขนมปัง |
| 케이크**를** 먹어요 | กินเค้ก |
| 옷**을** 입어요 | สวมเสื้อผ้า |
| 손**을** 씻어요 | ล้างมือ |
| 친구**를** 만나요 | พบเพื่อน |
| 이메일**을** 써요 | เขียนอีเมล |
| 청소**를** 해요 | ทำความสะอาด |
| 운동**을** 해요 | ออกกำลังกาย |
| 춤**을** 춰요 | เต้นรำ |
| 사진**을** 찍어요 | ถ่ายรูป |

#### ประโยคและบทสนทนาจากตำรา 11과

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 친구**가** 신문**을** 봐요. | เพื่อนดูหนังสือพิมพ์ | ตำรา 98쪽 |
| 동생**이** 사과**를** 먹어요. | น้องกินแอปเปิล | ตำรา 98쪽 |
| 학생**이** 책**을** 읽어요. | นักเรียนอ่านหนังสือ | ตำรา 98쪽 |
| 마키 씨가 이메일**을** 써요? → 아니요, 책**을** 읽어요. | คุณมากิเขียนอีเมลไหม → ไม่ อ่านหนังสือ | บท 11 |
| 친구들이 투이 씨 생일**을** 축하해요. | {n:เพื่อน ๆ} {v:อวยพร}{n:วันเกิด}{n:คุณทุย} | บทอ่าน |
| 매일 한국 음식**을** 먹어요? → 네, 매일 한국 음식을 먹어요. | กินอาหารเกาหลีทุกวันไหม → ใช่ กินทุกวัน | กิจกรรมบท 11 |

#### ท่องเป็นคู่ (ข้อ 14)

กริยาบางตัวต้องจับคู่กับกรรมเฉพาะ ต้องท่องไว้เป็นคู่ ไม่เปลี่ยนไปใช้กริยาอื่น

- 춤**을** 추다 *(เต้นรำ)*
- 사진**을** 찍다 *(ถ่ายรูป)*
- 돈**을** 찾다 *(ถอนเงิน)*
- 노래**를** 하다 *(ร้องเพลง)*

### ⚠️ จุดสับสน

ข้อผิดของ 을/를 ส่วนใหญ่ไม่ใช่การเลือก 을 หรือ 를 แต่เป็นการเลือกกรรมที่ไม่เข้ากับกริยา หรือใช้ 을/를 กับกริยาที่ไม่ต้องการกรรม

| ✗ ผิด | ✓ ถูก | เพราะ |
|:---|:---|:---|
| 학생을 공부해요 | 숙제를 해요 *(ทำการบ้าน)* · 한국어를 공부해요 *(เรียนภาษาเกาหลี)* | กรรมต้องเข้ากับกริยา — 공부하다 ต้องตามด้วยสิ่งที่เรียน ไม่ใช่คน |
| 학교를 가요 · 집을 와요 | 학교**에** 가요 *(ไปโรงเรียน)* · 집**에** 와요 *(มาบ้าน)* | ไป/มา ใช้ 에 (ไทย "ไป+โรงเรียน" หน้าตาเหมือนกริยา+กรรม แต่เกาหลีเป็น "จุดหมาย" — ข้อ 09) |
| 학생을 있어요 | 학생**이** 있어요 *(มีนักเรียน)* | 있다 · 이다 · 아니다 ไม่ใช้ 을/를 (ข้อ 02) |
| 사과를 좋아요 | 사과**가** 좋아요 *(ถูกใจแอปเปิล)* · 사과**를** 좋아해요 *(ชอบแอปเปิล)* | 좋다 = คุณศัพท์ → 가 · 좋아하다 = กริยา → 를 (ข้อ 01) |
| 친구를 빵이 먹어요 | 친구**가** 빵**을** 먹어요 *(เพื่อนกินขนมปัง)* | ผู้ทำ = 이/가 · ผู้ถูกกระทำ = 을/를 อย่าสลับ |
| 반나요 | **만**나요 *(พบ)* | ขึ้นต้นด้วย ㅁ ไม่ใช่ ㅂ |

#### 을/를 ที่ไม่ใช้ และที่ถูกแทนที่

บางประโยคไม่มีกรรมจึงไม่มี 을/를 และในภายหลังจะเรียนว่า 은/는 · 도 · 만 วางแทน 을/를 ได้

- ตัวที่ผู้ทำ**ไม่ได้ลงมือกระทำต่อสิ่งใด** (มี, เป็น, ไม่ใช่, คุณศัพท์) ไม่มี 을/를
  - 꽃**이** 예뻐요 *(ดอกไม้สวย)*
  - 책**이** 있어요 *(มีหนังสือ)*
  - 사전**이** 아니에요 *(ไม่ใช่พจนานุกรม)*
- 은/는 · 도 · 만 วางแทน 을/를 ได้ (ภายหลัง)
  - 커피**는** 안 마셔요 *({n:กาแฟ}{p:น่ะ}{x:ไม่}{v:ดื่ม})*
  - 책**도** 읽어요 *(อ่านหนังสือด้วย — ข้อ 17)*
  - 물**만** 마셔요 *(ดื่มแต่น้ำ — ข้อ 31)*

> [!TIP] กฎสั้น ๆ
> - ผู้ทำ = **이/가** · ผู้ถูกกระทำ = **을/를** อย่าสลับกัน
> - 있다 · 이다 · 아니다 และคำคุณศัพท์ ไม่ใช้ 을/를
> - ไป/มา ใช้ **에** ไม่ใช่ 을/를: 학교**에** 가요

  - 쓰기 A3: 선생님이 책(**을**) 읽어요 ✓ *(คุณครูอ่านหนังสือ)*
  - 읽기 [7~10]: 친구를 만나요 *(พบเพื่อน)* · 된장찌개를 먹어요 *(กินซุปเต้าเจี้ยว)* ✓
  - 듣기 [8]: 친구 집에서 생일 파티**를** 해요 *(ปาร์ตี้วันเกิดที่บ้านเพื่อน — ครูเติม 생일 ให้)*
- **중간시험 복습문제** (ชุดของครู)
  - โจทย์ที่ 3: 동생이 책(**을**) 읽어요 *(น้องอ่านหนังสือ)*
  - โจทย์ที่ 12: 보다 / 텔레비전 / 저녁 8시 → 저는 저녁 8시에 텔레비전**을** 봐요 *(ฉันดูทีวีตอน 2 ทุ่ม)*
  - โจทย์ที่ 15 (อ่าน 5–11과) ข้อย่อย 13: 카오루 씨가 노래를 해요 = ✗ *(คุณคาโอรุร้องเพลง — ผิด)*
  - เหตุผล: บทอ่านคือ 마키 씨가 노래를 해요 *(คุณมากิร้องเพลง)* และ 카오루 씨는 사진을 찍어요 *(คุณคาโอรุถ่ายรูป)*
- ข้อผิดที่เคยเจอ: ที่ผ่านมาพลาดเรื่อง "กรรมไม่เข้ากับกริยา" (학생을 공부해요) และการสะกด (반나요) — ยังไม่มีบันทึกว่าเลือก 을 ↔ 를 ผิดตามตัวสะกด
- ฝึกเพิ่ม: ส่วนที่ 5 ชุด C โจทย์ที่ 3–4 และ 6

> [!SUMMARY] สรุป
> - 을/를 ติดหลังกรรม: **을** หลังตัวสะกด · **를** หลังสระ · โครงสร้าง ประธาน이/가 + กรรม을/를 + กริยา (กริยาอยู่ท้ายสุด)
> - คำนามหน้า 하다 ก็ติด 을/를 (ภาษาพูดละได้) · ถามกรรมด้วย 무엇을/누구를 · ถามผู้ทำด้วย 누가
> - กรรมต้องเข้ากับกริยา: 숙제를 해요 (ไม่ใช่ 학생을 공부해요) · ไป/มาใช้ 에 · 있다/이다/คุณศัพท์ไม่มี 을/를
> - ท่องเป็นคู่: 춤을 추다, 사진을 찍다, 돈을 찾다, 노래를 하다
