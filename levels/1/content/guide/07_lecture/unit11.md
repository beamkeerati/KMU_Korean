### 📽️ สไลด์อาจารย์ 11과

#### 📽️ [topic:07] 명사 + 을/를 (교과서 11과 문법 1)
![](img:lc11-teacher) 🖼️ *ภาพครูยืนหน้าจอ (ภาพหน้า 4 ของไฟล์) สไลด์ 문법 1 หัวข้อ 명사 + 을/를 อาจารย์เขียนบนสไลด์ ___이/가 ___을/를 ___아/어/여요*

- 가: 친구가 무엇을 해요? *(เพื่อนทำอะไร)*
- 나: 빵을 먹어요. *(กินขนมปัง)*
- 가: 선생님이 무엇을 해요? *(ครูทำอะไร)*
- 나: 텔레비전을 봐요. *(ดูทีวี)*
- 가: 왕쯔이 씨가 무엇을 해요? *(คุณหวางทำอะไร)*
- 나: 친구를 만나요. *(พบเพื่อน)*

**📝 ที่คุณจดไว้:** โครงสร้างประโยค "____ 이/가 ____ 을/를 ____ 아/어/여요" (ลายมือน้ำเงิน)

**💡 สรุป:** กรรมของกริยาติด 을 (ลงท้ายด้วยพยัญชนะ) หรือ 를 (ลงท้ายด้วยสระ) ก่อนกริยา ประโยคเต็ม = ประธาน + 이/가 + กรรม + 을/를 + กริยา

#### 📽️ [topic:06] สมุดจด: 4 กฎ + กฎควบสระ ของ -아/어/여요
![](img:lc11-rules) 🖼️ *หน้าสมุดลายมือ (ภาพหน้า 4 ของไฟล์) มีหัวข้อ "4 Rules" และตัวอย่างพร้อมขีดฆ่า 다 และไฮไลต์เหลือง/ฟ้า/เขียว*

- **1)** ㅏ/ㅗ + **아요**
  - 가다 → 가 + 아요 → 가아요 → **가요** *(ไป)*
  - 앉다 → 앉 + 아요 → **앉아요** *(นั่ง)*
- **2)** ถ้าไม่ใช่ ㅏ/ㅗ + **어요**
  - 먹다 → 먹 + 어요 = **먹어요** *(กิน)*
  - 씻다 → 씻 + 어요 = **씻어요** *(ล้าง/อาบ)*
  - 마시다 → 마시 + 어요 = 마시어요 = **마셔요** *(ดื่ม)*
- **3)** ___ + 하다 → ___ **해요** : 공부하다 → **공부해요** *(เรียน)*
- **4)** ถ้ามี **ㅡ** ให้ตัด ㅡ ออกก่อน แล้วไปใช้ข้อ 1) หรือ 2)
  - 쓰다 → ㅆ + 어요 → **써요** *(เขียน)*
  - 아프다 → 아ㅍ + 아요 → **아파요** *(เจ็บ/ป่วย)*
- **5)** กฎรวมสระ : ㅗ + ㅏ = ㅘ · ㅣ + ㅓ = ㅕ

**📝 ที่คุณจดไว้:** ข้อ 2 "ถ้าไม่ใช่ ㅏ/ㅗ" · ข้อ 4 "ถ้ามี ㅡ ... ให้ตัดออกก่อนแล้วไปใช้ข้อ 1.), 2.)" · ข้อ 5 "กฎการรวมสระ" (ลายมือไทยปนเกาหลี)

**💡 สรุป:** ดูสระตัวสุดท้ายของคำกริยาก่อนตัด 다 — ㅏ/ㅗ ใส่ 아요 สระอื่นใส่ 어요 และ 하다 เป็น 해요 ถ้ามี ㅡ ตัดทิ้งก่อนแล้วใช้กฎเดิม
