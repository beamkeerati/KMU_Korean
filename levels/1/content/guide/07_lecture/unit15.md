### 📽️ สไลด์อาจารย์ 15과

#### 📽️ [topic:20] 윗사람 + 이/가 + -(으)시- (교과서 138쪽)
![](img:lc15-p13-a) 🖼️ *สไลด์ 문법 3 (ภาพหน้า 13 ของไฟล์) ตารางแบ่งครึ่ง ซ้าย 동사/형용사 ขวา 명사 (อาจารย์วงกลม 명사) ช่องสีเขียวเป็นคำตอบ มีลายมือน้ำเงินของคุณในบางช่อง*

| 동사, 형용사 | 받침(✗) + 시다 | 받침(○) + **으시다** |
|---|---|---|
| ตัวอย่าง | 가다-가시다 · 오다-오시다 · 크다-크시다 · 친절하다-친절하시다 | 입다-입으시다 · 읽다-읽으시다 · 작다-작으시다 · 많다-많으시다 |

| 명사 | 받침(✗) + 시다 | 받침(○) + **이시다** |
|---|---|---|
| ตัวอย่าง | 할아버지 · 아버지 · 의사 (ช่องว่าง) | 선생님 · 회사원 (ช่องว่าง) |

- คำตอบที่คุณเติม: 가시다 · 오시다 · 크시다 · 친절하시다 · 입으시다 · 읽으시다 · 작으시다 · 많으시다
- ช่องของ 명사 ยังว่าง — ตอบได้ว่า 할아버지(이)시다 ... → 할아버지시다 · 아버지시다 · 의사시다 · 선생님이시다 · 회사원이시다

**📝 ที่คุณจดไว้:** ขีดฆ่า 다 ที่ท้ายกริยาทุกตัว และเขียนวงกลมสีแดงล้อมคำ 받침 (O)

**💡 สรุป:** เมื่อพูดถึงผู้ใหญ่ ใส่ -(으)시- หลังก้านคำ ตัว 다 ถูกตัดออก ก้านไม่มีตัวสะกดใส่ 시 ก้านมีตัวสะกดใส่ 으시 ส่วนคำนามคือ 시다 / 이시다

#### 📽️ [topic:20] ศัพท์ยกย่อง (높임말) (교과서 138쪽)
![](img:lc15-p13-b) 🖼️ *สไลด์ -(으)시- (ภาพหน้า 13 ของไฟล์) ตารางคำสุภาพ ลูกศร สีแดงคือคำยกย่อง ลายมือน้ำเงินของคุณมีเครื่องหมายหัวใจ/ดอกไม้เล็ก ๆ ท้ายแถว*

| ปกติ | ยกย่อง | | ปกติ | ยกย่อง |
|---|---|---|---|---|
| 자다 | **주무시다** | | 이름 | **성함** |
| 먹다 | **드시다 / 잡수시다** | | 말 | **말씀** |
| 마시다 | **드시다** | | 나이 | **연세** |
| 말하다 | **말씀하시다** | | 사람 | **분** |
| 있다 | **계시다** | | | |
| 없다 | **안 계시다** | | | |

**📝 ที่คุณจดไว้:** "Name" ข้างคำ 이름 · 분 เขียนไทยกำกับ "(คนที่?)" (?) · ติดเครื่องหมายหัวใจเล็ก ๆ ที่ 주무시다 · 드시다 · 계시다 · 분

**💡 สรุป:** ผู้ใหญ่ใช้คำเฉพาะแทนคำปกติ: 자다 → 주무시다, 먹다/마시다 → 드시다, 있다 → 계시다 (ไม่อยู่ = 안 계시다) และคำนาม 이름 → 성함, 말 → 말씀, 나이 → 연세, 사람 → 분
