# ส่วนที่ 5 · แบบทดสอบตัวเอง (พร้อมเฉลย)

ส่วนนี้เป็นแบบทดสอบตัวเองรวม 20 ชุด (ชุด A ถึง T) ครอบคลุมไวยากรณ์ตั้งแต่บท 5 ถึงบท 37 ทุกชุดมีโจทย์ข้อละบรรทัด พร้อมคำแปลหรือคำใบ้ภาษาไทย และมีเฉลยอยู่ในกล่องคำตอบใต้ชุดนั้น

วิธีทำที่ได้ผลที่สุดคือใช้กระดาษปิดกล่องคำตอบไว้ก่อน เขียนคำตอบลงกระดาษให้ครบทุกข้อ แล้วจึงเปิดกล่องคำตอบมาตรวจ ข้อไหนผิดให้กลับไปอ่านข้อไวยากรณ์ที่ชุดนั้นอ้างถึง และทำชุดเดิมซ้ำอีกครั้งในวันถัดไป

## 📝 ชุดแบบฝึกหัด A–F

> [!INTRO] หกชุดแรกทดสอบอะไร
> ชุด A ถึง F ทบทวนพื้นฐานของบท 5–13 ได้แก่ คำช่วย 은/는 กับ 이/가, รูป 이에요/예요, คำช่วย 에 กับ 에서 และ 을/를, การผันกริยาเป็น -아/어/여요, การแปลประโยคสั้น ๆ และการอ่านตัวเลข เรื่องเหล่านี้เป็นพื้นฐานที่ข้อสอบทุกครั้งใช้ซ้ำ จึงควรทำให้ถูกทุกข้อก่อนไปชุดถัดไป ท้ายชุด F มีเคล็ดลับสอบ 5 ข้อไว้ไล่ทบทวนอีกรอบ

### 🔸 A. เติม 은/는 หรือ 이/가

ชุดนี้ฝึกเลือกคำช่วยบอกหัวเรื่อง (은/는) หรือคำช่วยบอกประธาน (이/가) ให้ตัดสินก่อนว่าคำนามนั้นเป็นหัวเรื่องหรือเป็นประธานของประโยค แล้วค่อยเลือกรูปตามตัวสะกด เติมลงในวงเล็บทีละข้อ

1. 저( ) 학생입니다.
2. 직업( ) 무엇입니까?
3. 마키 씨( ) 일본 사람입니다.
4. 누( ) 의사입니까?
5. 이것( ) 책입니다.

<details>
<summary>คำตอบ</summary>

1. 저**는** 학생입니다.
2. 직업**이** 무엇입니까?
3. 마키 씨**는** 일본 사람입니다.
4. 누**가** 의사입니까?
5. 이것**은** 책입니다.

</details>

### 🔸 B. เติม 이에요/예요 หรือ 이/가 아니에요

ชุดนี้ฝึกรูป "เป็น" (이에요/예요) และรูป "ไม่ใช่" (이/가 아니에요) ให้ดูตัวสะกดของคำนามหน้าวงเล็บ และอ่านประโยคที่อยู่ติดกันเป็นเบาะแสว่าต้องใช้รูปบอกเล่า รูปถาม หรือรูปปฏิเสธ

1. 이것은 사전( ).
2. 이것은 카메라( ).
3. 아니요, 볼펜( ). 연필이에요.
4. 학생( )? — 네, 학생이에요.
5. 중국 사람( ). 태국 사람이에요.

<details>
<summary>คำตอบ</summary>

1. 사전**이에요**.
2. 카메라**예요**.
3. 볼펜**이 아니에요**.
4. 학생**이에요**?
5. 중국 사람**이 아니에요**.

</details>

### 🔸 C. เติม 에, 에서, 을/를

ชุดนี้ฝึกเลือก 에 (จุดหมายหรือที่ตั้ง), 에서 (สถานที่ทำกิจกรรม) และ 을/를 (กรรม) ให้ดูกริยาท้ายประโยคก่อนว่าเป็นกริยาไปมาอยู่หรือกริยาที่ทำกิจกรรม แล้วค่อยเลือกคำช่วยให้เข้าคู่กัน

1. 도서관( ) 가요.
2. 학교( ) 공부해요.
3. 영화( ) 봐요.
4. 책( ) 읽어요.
5. 교실( ) 학생이 있어요.
6. 커피숍( ) 커피( ) 마셔요.

<details>
<summary>คำตอบ</summary>

1. 도서관**에** 가요.
2. 학교**에서** 공부해요.
3. 영화**를** 봐요.
4. 책**을** 읽어요.
5. 교실**에** 학생이 있어요.
6. 커피숍**에서** 커피**를** 마셔요.

</details>

### 🔸 D. ผันกริยา -아/어/여요

ชุดนี้ฝึกผันกริยาและคำคุณศัพท์ 10 คำเป็นรูปสุภาพ -아/어/여요 ดูสระของพยางค์สุดท้ายของราก ㅏ หรือ ㅗ ใช้ 아요 สระอื่นใช้ 어요 คำที่ลงท้าย 하다 เป็น 해요 และรากที่ลงท้าย ㅡ ต้องตัด ㅡ ก่อน (ดูข้อ 06 ในส่วนที่ 1)

1. 먹다 →
2. 가다 →
3. 마시다 →
4. 공부하다 →
5. 쓰다 →
6. 보다 →
7. 크다 →
8. 읽다 →
9. 예쁘다 →
10. 만나다 →

<details>
<summary>คำตอบ</summary>

1. 먹어요
2. 가요
3. 마셔요
4. 공부해요
5. 써요
6. 봐요
7. 커요
8. 읽어요
9. 예뻐요
10. 만나요

</details>

### 🔸 E. แปลเป็นภาษาเกาหลี

ชุดนี้ฝึกแปลประโยคสั้น ๆ จากภาษาไทยเป็นภาษาเกาหลี ประโยคทั้ง 5 ข้อมาจากบท 9–13 เขียนคำตอบเต็มประโยคลงกระดาษก่อนเปิดเฉลย แล้วเทียบทีละคำช่วย

1. ขนมปังชิ้นละเท่าไร?
2. ฉันไม่ดื่มกาแฟ
3. วันเสาร์ซื้อผลไม้กับเนื้อที่ตลาด
4. ห้องสมุดอยู่ข้างตึกนักศึกษา
5. ฉันทำงานพาร์ทไทม์ที่ร้านกาแฟ

<details>
<summary>คำตอบ</summary>

1. 빵 한 개에 얼마예요?
2. 저는 커피를 안 마셔요.
3. 토요일에 시장에서 과일하고 고기를 사요.
4. 도서관은 학생회관 옆에 있어요.
5. 커피숍에서 아르바이트를 해요.

</details>

### 🔸 F. อ่านเลข

ชุดนี้ฝึกอ่านตัวเลขเป็นภาษาเกาหลี ต้องเลือกระบบเลขให้ถูก คือเลขจีนสำหรับเบอร์โทร ราคา ชั้น ห้อง และวันที่ ส่วนเลขแท้ใช้นับจำนวนของ (ดูข้อ 04 ในส่วนที่ 1)

1. 전화번호: 010-3847-2951
2. 사과 3개 — 한 개에 1,500원 → 모두?
3. 8층 203호
4. 6월 15일 토요일

<details>
<summary>คำตอบ</summary>

1. 공일공-삼팔사칠-이구오일
2. 사과 세 개, 한 개에 천오백 원 → 모두 사천오백 원이에요.
3. 팔 층 이백삼 호
4. 유월 십오일 토요일

</details>

> [!TIP] เคล็ดลับสอบ
> 1. ⭐ **ผันกริยา -아/어요** ออกสอบแน่นอน — ฝึกจนคล่อง!
> 2. ⭐ **에 vs 에서** ระวังสับสน — 있다/가다 ใช้ **에** / action verb ใช้ **에서**
> 3. ⭐ **은/는 vs 이/가** — topic vs subject
> 4. ⭐ **ตัวเลข 한자어 vs 고유어** — จำว่าใช้กับอะไร
> 5. ⭐ **안 + 하다 verbs** — 공부를 안 해요 (ไม่ใช่ 안 공부해요)

## 🔸 ชุด G · 은/는 vs 이/가 (ทบทวนส่วนที่ 2)

> [!INTRO] ชุด G ทดสอบอะไร
> ชุดนี้ทบทวนการเลือกระหว่าง 은/는 กับ 이/가 ซึ่งเป็นเรื่องที่ผู้เรียนสับสนบ่อย เนื้อหาเต็มอยู่ในส่วนที่ 2 ของหนังสือเล่มนี้ ทั้ง 8 ข้อต้องตัดสินก่อนว่าคำนามนั้นเป็นหัวเรื่อง เป็นประธานใหม่ หรือเป็นคำตอบของคำถาม แล้วค่อยเลือกรูปตามตัวสะกด ในเฉลยแต่ละข้อมีเหตุผลสั้น ๆ กำกับ ให้อ่านเหตุผลด้วยแม้จะตอบถูกแล้ว

1. 저( ) 학생이에요.
2. 누( ) 선생님이에요?
3. 가방에 지갑( ) 있어요.
4. 이것( ) 볼펜( ) 아니에요.
5. 사과( ) 있어요. 배( ) 없어요. *(เปรียบเทียบ)*
6. 오늘( ) 투이 씨 생일이에요.
7. 가: 뭐( ) 맛있어요? 나: 김밥( ) 맛있어요.
8. 제 이름( ) 바트예요.

<details>
<summary>คำตอบ</summary>

1. 저**는** — แนะนำตัว
2. 누**가** — คำถาม "ใคร"
3. 지갑**이** — 있다
4. 이것**은** 볼펜**이** 아니에요 — หัวข้อ + 아니에요
5. 사과**는** / 배**는** — เปรียบเทียบ
6. 오늘**은** — หัวข้อ (จากบทอ่าน Unit 11)
7. 뭐**가** / 김밥**이** — คำถาม-คำตอบ "อะไร"
8. 이름**은** — ประโยคบอกข้อมูลตัวเอง (ถ้าถาม 이름이 뭐예요? ใช้ 이 ในคำถาม แต่ตอนบอก "ชื่อของฉันน่ะคือ..." ใช้ 은)

</details>

## 📝 ชุด H–M · บท 14–22

> [!INTRO] ชุด H ถึง M ทดสอบอะไร
> หกชุดนี้ทบทวนไวยากรณ์ของบท 14–22 เรียงตามลำดับที่เรียน ได้แก่ การปฏิเสธและ 도, การพูดแบบทางการและการยกย่อง, อดีต, อนาคตและจุดประสงค์, การให้-รับ กับ 만 และ -고 있다, และการชวนด้วย -(으)ㄹ까요? หลายข้อต้องดูตัวสะกดของรากก่อนเลือกรูป จึงควรอ่านคำใบ้ในวงเล็บให้ครบก่อนตอบ

### 🔸 H. -지 않다 & 도 (14과)

ชุดนี้ฝึก -지 않다 (ปฏิเสธโดยต่อท้ายราก) และ 도 (…ก็ หรือ …ด้วย) ข้อที่ใช้ 도 ให้ดูว่า 도 แทนที่ 은/는 หรือ 이/가 หรือ 을/를 หรือต่อท้าย 에 (ดูข้อ 16 และ 17 ในส่วนที่ 1)

1. 저는 커피를 마시(　　　　) 않아요. *(ไม่ดื่มกาแฟ)*
2. 이 가방은 비싸(　　　　) 않아요. *(กระเป๋านี้ไม่แพง)*
3. 저는 학생이에요. 마이클 씨(　　　　) 학생이에요. *(…{p:ก็}{e:เป็น}{n:นักเรียน}{p:เหมือนกัน})*
4. 김치(　　　　) 먹어요. *(กินกิมจิด้วย)*
5. 오늘은 날씨가 좋(　　　　) 않아요. *({a:วันนี้}{n:อากาศ}{x:ไม่}{v:ดี})*
6. 사과를 먹어요. 배(　　　　) 먹어요. *(กินแอปเปิ้ล กินสาลี่ด้วย)*
7. 도서관에(　　　　) 가요. *(ไปห้องสมุดด้วย — ใช้ 도 แทน 에)*
8. 선생님이 친절하(　　　　) 않아요. *(อาจารย์ไม่ใจดี)*

<details>
<summary>คำตอบ</summary>

1. 마시**지** 않아요 — กริยา + -지 않다 = ไม่...
2. 비싸**지** 않아요 — ใช้กับคุณศัพท์ได้เช่นกัน
3. 마이클 씨**도** — 도 แทน 은/는 (ไม่ใช้ 도 ซ้อนกับ 은/는)
4. 김치**도** — 도 แทน 을/를
5. 좋**지** 않아요
6. 배**도** 먹어요
7. 도서관에**도** 가요 — 도 วางต่อท้าย 에 ได้ (에도)
8. 친절하**지** 않아요

</details>

### 🔸 I. -(스)ㅂ니다 & -(으)시- (15–16과)

ชุดนี้ฝึกท้ายประโยคแบบทางการ -(스)ㅂ니다 และการยกย่องด้วย -(으)시- ให้ดูตัวสะกดของรากเพื่อเลือก ㅂ니다 หรือ 습니다 และดูว่าประธานเป็นผู้ใหญ่หรือไม่ (ดูข้อ 20 และ 21 ในส่วนที่ 1)

1. 저는 한국어를 배우(　　　　). *(ทางการ: {v:เรียน}{n:ภาษาเกาหลี})*
2. 책을 읽(　　　　). *(ทางการ: {v:อ่าน}{n:หนังสือ})*
3. 학교에 (　　　　)? *(ทางการ ถาม: {v:ไป}{n:โรงเรียน}ไหมคะ — 가다)*
4. 아버지는 신문을 읽(　　　　). *(คุณพ่ออ่านหนังสือพิมพ์ — สุภาพ -아/어요)*
5. 선생님이 한국어를 가르치(　　　　). *(อาจารย์สอนภาษาเกาหลี — ทางการ + เคารพ)*
6. 할머니는 집에 (　　　　). *(คุณย่าอยู่บ้าน — 있다 รูปเคารพ)*
7. 김 선생님이 태국 사람(　　　　)? *({n:อาจารย์}{n:คิม}{e:เป็น}{n:คนไทย}หรือคะ — ทางการ + เคารพ)*
8. 어머니는 요리를 하(　　　　). *(คุณแม่ทำอาหาร — เคารพ -아/어요)*

<details>
<summary>คำตอบ</summary>

1. 배웁니다 — สระ → -ㅂ니다
2. 읽습니다 — ตัวสะกด → -습니다
3. 갑니까 — -ㅂ니까?
4. 읽으세요 — ตัวสะกด → -으세요
5. 가르치십니다 — สระ → -십니다
6. 계세요 — 있다 → 계시다 (เคารพ)
7. 태국 사람이십니까 — 이다 + -시- → 이십니까
8. 세요 — 하**세요** (-(으)시- + -아/어요)

</details>

### 🔸 J. -았/었/였- (17과)

ชุดนี้ฝึกรูปอดีต ดูสระของพยางค์สุดท้ายของราก ㅏ หรือ ㅗ ใช้ 았 สระอื่นใช้ 었 และ 하다 เป็น 했 ข้อที่บอกที่มาต้องใช้ 에서 (ดูข้อ 23 และ 24 ในส่วนที่ 1)

1. 어제 영화를 (　　　　). *(เมื่อวานดูหนัง — 보다)*
2. 지난 주말에 친구를 (　　　　). *(สุดสัปดาห์ที่แล้วพบเพื่อน — 만나다)*
3. 아침에 밥을 (　　　　). *({n:เช้านี้}{v:กิน}{n:ข้าว} — 먹다)*
4. 숙제를 (　　　　)? *({v:ทำ}{n:การบ้าน}{e:แล้ว}หรือยัง — 하다)*
5. 편지를 (　　　　). *(เขียนจดหมาย — 쓰다)*
6. 영화가 재미(　　　　). *(หนังสนุก — 재미있다)*
7. 저는 몽골(　　　　) 왔어요. *({n:ฉัน}{v:มา}{p:จาก}{n:มองโกเลีย})*
8. 작년에는 한국에 (　　　　). *(ปีที่แล้วอยู่เกาหลี — 있다)*

<details>
<summary>คำตอบ</summary>

1. 봤어요 — 보 + 았 → 봤
2. 만났어요
3. 먹었어요
4. 했어요 — 하다 → 했어요
5. 썼어요 — ㅡ หลุด: 쓰 + 었 → 썼
6. 있었어요 — 재미있었어요
7. 에서 — 몽골**에서** 왔어요 (มาจาก...)
8. 있었어요

</details>

### 🔸 K. -(으)ㄹ 거예요 & -(으)러 (18–19과)

ชุดนี้ฝึกบอกแผนในอนาคตด้วย -(으)ㄹ 거예요 บอกจุดประสงค์ว่า "ไปเพื่อ…" ด้วย -(으)러 และบอกช่วงเวลาด้วย 부터/까지 ให้ดูตัวสะกดของรากทุกข้อ (ดูข้อ 26 ถึง 28 ในส่วนที่ 1)

ชุดนี้ฝึกคำช่วยบอกทิศทางและพาหนะ (으)로 เหตุผลที่ตามด้วยคำสั่ง -(으)니까 ระยะจาก…ถึง… และกริยา ㄷ กับ 르 ไม่ปกติ ข้อที่ต้องผันให้ดูว่าสิ่งที่ตามหลังรากเป็นสระหรือพยัญชนะ (ดูข้อ 49 ถึง 54 ในส่วนที่ 1)

1. 저 사거리에서 왼쪽(　　　　) 가세요. *(ที่สี่แยกโน้นไปทางซ้าย)*
2. 지하철(　　　　) 가요. *(ไปรถไฟใต้ดิน)*
3. 출근 시간에는 길이 막히(　　　　) 지하철을 타세요. *(ชั่วโมงเร่งด่วนรถติด ไปรถไฟใต้ดินเถอะ)*
4. 4시에 문을 닫(　　　　) 빨리 가세요. *(4 โมงปิดประตู รีบไปนะ)*
5. 학교(　　　　) 집(　　　　) 얼마나 걸려요? *(จากโรงเรียนถึงบ้านใช้เวลานานเท่าไร)*
6. 안내 방송을 하니까 잘 (　　　　). *(มีประกาศ ฟังให้ดีนะ — 듣다, -(으)세요)*
7. 저는 학교에 (　　　　) 가요. *(ฉันเดินไปโรงเรียน — 걷다 + -아/어서)*
8. 어제 한국 노래를 (　　　　). *(เมื่อวานฟังเพลงเกาหลี — 듣다, อดีต)*
9. 이 버스가 (　　　　). *(รถบัสคันนี้เร็ว — 빠르다, -아/어요)*
10. 길을 잘 (　　　　) 전화드렸습니다. *(ไม่ค่อยรู้ทางเลยโทรมา — 모르다 + -아/어서)*

<details>
<summary>คำตอบ</summary>

1. 왼쪽**으로** — มีตัวสะกด → 으로 (ทิศทาง)
2. 지하철**로** — ลงท้าย ㄹ ใช้ 로 (지하철으로 ✗) · พาหนะ
3. 막히**니까** — ก้านจบสระ → -니까
4. 닫**으니까** — มีตัวสะกด → -으니까 (닫다 = ปกติ)
5. 학교**에서** 집**까지** — จาก…ถึง (ที่/ระยะทาง)
6. **들으세요** — 듣다: ㄷ → ㄹ ก่อนสระ (듣으세요 ✗)
7. **걸어서** — 걷다 → 걸어서 (걷어서 ✗)
8. **들었어요** — ㄷ → ㄹ ก่อน -었-
9. **빨라요** — 르 불규칙: ㅡ ตก + ㄹ ไปเพิ่มที่พยางค์หน้า (빠라요 ✗)
10. **몰라서** — 모르다 → 몰라 + 서

</details>

### 🔸 S. -(으)면 & -거나 & (이)나 & -는 것 & -아/어 보다 (33–35과)

ชุดนี้ฝึกเงื่อนไข "ถ้า" ด้วย -(으)면 ตัวเลือก "หรือ" ทั้งแบบกริยา (-거나) และแบบนาม ((이)나) การทำกริยาให้เป็นนามด้วย -는 것 และการลองหรือเคยด้วย -아/어 보다 (ดูข้อ 55 และข้อ 57 ถึง 60 ในส่วนที่ 1)

1. 기차표가 없(　　　　) 버스로 갈 거예요. *(ถ้าไม่มีตั๋วรถไฟจะไปรถบัส)*
2. 방학을 하(　　　　) 부산으로 여행을 갈까요? *(ปิดเทอมแล้วไปเที่ยวปูซานไหม)*
3. 집에서 쉬(　　　　) 친구를 만나요. *(พักที่บ้านหรือพบเพื่อน)*
4. 내일은 흐리(　　　　) 비가 올 거예요. *(พรุ่งนี้ฟ้าครึ้มหรือฝนตก)*
5. 빵(　　　　) 밥을 먹어요. *(กินขนมปังหรือข้าว)*
6. 코미디 영화(　　　　) 액션 영화를 자주 봐요. *(ดูหนังตลกหรือหนังแอ็กชันบ่อย ๆ)*
7. 저는 운동하(　　　　) 것을 좋아해요. *(ฉันชอบการออกกำลังกาย)*
8. 저는 요리를 (　　　　) 것을 좋아해요. *(ฉันชอบการทำอาหาร — 만들다)*
9. 이 노래를 (　　　　)? *(เคยฟังเพลงนี้ไหม — 듣다 + -아/어 봤어요)*
10. 가: 한강에서 유람선을 타 봤어요? 나: 아니요, 안 타 봤어요. 가: 그럼 한번 타 (　　　　). *(งั้นลองนั่งดูสักครั้งนะ)*

<details>
<summary>คำตอบ</summary>

1. 없**으면** — มีตัวสะกด → -으면 (없면 ✗)
2. 하**면** — ไม่มีตัวสะกด → -면
3. 쉬**거나** — -거나 ต่อก้านตรง ๆ (쉬으거나 ✗)
4. 흐리**거나** — ใช้กับคุณศัพท์ได้ · กาลอยู่ท้ายประโยค
5. 빵**이나** — มีตัวสะกด → 이나 (빵나 ✗)
6. 영화**나** — ไม่มีตัวสะกด → 나
7. 하**는** 것 — ก้านกริยา + 는 것
8. **만드는** — ก้าน ㄹ ตก ㄹ (만들는 ✗)
9. **들어 봤어요** — 듣다: ㄷ → ㄹ ก่อนต่อ -어 보다 (듣어 ✗)
10. **보세요** — ลองดู: 타 보세요

</details>

### 🔸 T. -(으)ㄴ/는데요 & -(으)ㄹ게요 & -아/어 주세요 & -아/어야 하다 (36–37과)

ชุดนี้ฝึกบอกสถานการณ์หรือปฏิเสธอ้อม ๆ ด้วย -(으)ㄴ/는데요 สัญญาหรืออาสาด้วย -(으)ㄹ게요 ขอร้องด้วย -아/어 주세요 และบอกความจำเป็นด้วย -아/어야 하다 (ดูข้อ 61 ถึง 64 ในส่วนที่ 1)

1. 내일은 시험이 있(　　　　). *(พรุ่งนี้มีสอบน่ะ — ปฏิเสธนุ่ม ๆ)*
2. 숙제가 많(　　　　). *(การบ้านเยอะน่ะ)*
3. 여보세요. 저는 마키(　　　　). *(ฮัลโหล นี่มากิค่ะ)*
4. 저녁은 제가 사(　　　　). *(มื้อเย็นฉันเลี้ยงเอง)*
5. 언제 전화할 거예요? — 이따가 다시 전화(　　　　). *(เมื่อไรจะโทร — เดี๋ยวโทรใหม่นะ)*
6. 여기 좀 앉(　　　　). *(ขอนั่งตรงนี้นะ)*
7. 남대문으로 가 (　　　　). *(ไปนัมแดมุนด้วยครับ — ในแท็กซี่)*
8. 불 좀 (　　　　) 주세요. *(ช่วยปิดไฟหน่อย — 끄다)*
9. 다음 주에 시험이 있어서 공부(　　　　). *(สัปดาห์หน้ามีสอบเลยต้องอ่านหนังสือ)*
10. 고향에서 친구가 와서 공항에 (　　　　) 해요. *(เพื่อนมาจากบ้านเกิดเลยต้องไปสนามบิน — 가다)*

<details>
<summary>คำตอบ</summary>

1. 있**는데요** — 있다/없다 ใช้ -는데요 (있은데요 ✗)
2. 많**은데요** — คุณศัพท์มีตัวสะกด → -은데요
3. 마키**인데요** — นาม + 인데요
4. **ㄹ게요** — 사 + ㄹ게요 = 살게요 (ผู้พูดสัญญาเอง)
5. **할게요** — ถามด้วย 거예요 ตอบด้วย -(으)ㄹ게요 ได้
6. **을게요** — 앉다 → 앉을게요 (มีตัวสะกด)
7. **주세요** — ก้าน 가 + 아 → 가 주세요
8. **꺼** — 끄다: ㅡ ตก → 꺼 주세요 (끄어 ✗)
9. **해야 해요** — 하다 → 해야 해요 (하야 해요 ✗)
10. **가야** — 가다 + 아야 → 가야 해요 (ก้านจบ ㅏ)

</details>
