## 14과 · 친구가 친절해요 (เพื่อนใจดี)

> [!INTRO] บทนี้ว่าด้วยอะไร
> บทที่ 14 ว่าด้วยเรื่อง **การบรรยายลักษณะของคน สิ่งของ และอากาศ** สถานการณ์ในบทคือ 이리나 ถาม 투이 ว่าอยู่หอพักกับใคร และเพื่อนคนนั้นเป็นอย่างไร ส่วนบทอ่านให้ 지훈 กับ 투이 แนะนำตัวเองและเล่าชีวิตในช่วงปิดเทอม
>
> ไวยากรณ์ใหม่มี 3 เรื่อง:
>
> 1. **A-아/어/여요** (ข้อ 18) — คำคุณศัพท์เป็นภาคแสดงของประโยคได้เอง ไม่ต้องมี 이다 และผันเหมือนกริยาในบท 11 (วิธีผันดูข้อ 06)
> 2. **-지 않다** (ข้อ 16) — การปฏิเสธแบบยาว ความหมายเท่ากับ 안 ที่เรียนในบท 12 ใช้ได้กับทั้งกริยาและคำคุณศัพท์
> 3. **N도** (ข้อ 17) — "…ก็" หรือ "…ด้วย" ต่อท้ายคำนามเพื่อเพิ่มข้อมูล โดยใช้แทนที่ 이/가 · 은/는 · 을/를
>
> จบบทแล้วจะบรรยายลักษณะด้วยคำคุณศัพท์ได้ ปฏิเสธได้ทั้ง 2 แบบ (안 และ -지 않다) และเพิ่มข้อมูลด้วย 도 ได้
>
> จุดที่คนไทยงงบ่อย: ภาษาไทยไม่ต้องมีคำกริยาช่วยหน้าคำคุณศัพท์ (กระเป๋าเล็ก) ภาษาเกาหลีก็เช่นกัน แต่ต้องผันให้ถูก (✗ 피곤나요) แยก 좋다 (คุณศัพท์ "ดี") ออกจาก 좋아하다 (กริยา "ชอบ") และจำไว้ว่า 도 ไม่ซ้อนกับ 이/가 หรือ 을/를

### 🗣️ คำศัพท์ที่ต้องรู้ก่อน

คำศัพท์ของบทนี้มี 4 กลุ่ม: คำคุณศัพท์คู่ตรงข้าม คำบรรยายคนและสิ่งของ คำนามที่ใช้คู่กับคำคุณศัพท์ และคำในบทสนทนากับบทอ่าน ตารางนี้คัดเฉพาะคำสำคัญ รายการเต็มของศูนย์อยู่ท้ายบท

#### คู่ตรงข้าม

แต่ละแถวคือคู่ของคำที่มีความหมายตรงข้ามกัน

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|
| 크다 | ใหญ่ | 작다 | เล็ก |
| 많다 | มาก | 적다 | น้อย |
| 싸다 | ถูก | 비싸다 | แพง |
| 길다 | ยาว | 짧다 | สั้น |
| 좋다 | ดี | 나쁘다 | แย่ |
| 재미있다 | สนุก | 재미없다 | ไม่สนุก |

#### บรรยายคน · ของ

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|
| 예쁘다 | สวย | 멋있다 | เท่ / หล่อ |
| 친절하다 | ใจดี | 피곤하다 | เหนื่อย |
| 바쁘다 | ยุ่ง | 어둡다 | มืด |
| 어떻다 → 어때요? | เป็นอย่างไร | | |

### 📝 ไวยากรณ์: A-아/어/여요 — คำคุณศัพท์ผันแบบกริยา (ไวยากรณ์ข้อ 18 · วิธีผัน → ข้อ 06)

ตอนนี้ว่าด้วยคำคุณศัพท์ที่เป็นภาคแสดงของประโยคได้เอง ไม่ต้องมี 이다 เหมือนภาษาไทยที่พูดว่า "กระเป๋าเล็ก" ได้เลย แต่ภาษาเกาหลีต้องผันคำคุณศัพท์เป็นรูป -아/어/여요 ด้วยกฎเดียวกับกริยาใน 11과 โครงประโยคคือ **ประธาน 이/가 + คำคุณศัพท์-아/어/여요**

#### รูปแบบ

| สระท้ายราก | ต่อท้าย | ตัวอย่าง |
|:---|:---|:---|
| ㅏ · ㅗ | -아요 | 많다 → 많아요 |
| สระอื่น | -어요 | 적다 → 적어요 |
| ...하다 | 해요 | 친절하다 → 친절해요 |
| ㅡ | ตก ㅡ แล้วดูสระพยางค์หน้า | 바쁘다 → 바빠요 |

#### ตัวอย่างประโยค

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 가방이 작아요. | กระเป๋าเล็ก | ประธาน 이/가 + คุณศัพท์ |
| 오늘 날씨가 좋아요. | วันนี้อากาศดี | ประธาน 이/가 + คุณศัพท์ |
| 한국 음식이 맛있어요. | อาหารเกาหลีอร่อย | ประธาน 이/가 + คุณศัพท์ |
| 선생님이 친절해요. | ครูใจดี | ประธาน 이/가 + คุณศัพท์ |
| 날씨가 어때요? | อากาศเป็นอย่างไร | ถามลักษณะ (어떻다 → 어때요) |

#### ตัวอย่างในกรอบตำรา (หน้า 124)

ตำราเปิดข้อ 준비 1 ด้วยบทสนทนาสั้น ๆ แล้วสรุปไว้ในกรอบว่า 형용사 (คำคุณศัพท์) บอกลักษณะหรือสภาพของสิ่งต่าง ๆ มีรูปพื้นฐานและผันรูปได้ พร้อมประโยคตัวอย่าง 4 ประโยค ประโยคแรกในกรอบใช้รูปทางการ -ㅂ니다

- 날씨가 어때요? *(อากาศเป็นอย่างไร)*
- 좋아요. *(ดี)*

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 가방이 큽니다. | กระเป๋าใหญ่ | รูปทางการ -ㅂ니다 |
| 꽃이 예뻐요. | ดอกไม้สวย | ㅡ ตก: 예쁘 + 어요 |
| 제프리 씨가 친절해요. | คุณเจฟฟรีย์ใจดี | ...하다 → 해요 |
| 사과가 맛있어요. | แอปเปิลอร่อย | สระอื่น + 어요 |

#### 연습 1 (หน้า 124) — พูดตามตัวอย่าง "N이/가 + คำคุณศัพท์"

ตำราให้คู่ "คำนาม / คำคุณศัพท์" 6 ข้อ ตามตัวอย่าง "가방이 작아요." ตำราไม่พิมพ์เฉลย คำตอบด้านล่างทำตามกฎของข้อนี้ (ตัวอย่างตอบ)

| ข้อ | คำใบ้ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 가방 / 작다 | 가방이 작아요. | กระเป๋าเล็ก (ตัวอย่างตำรา) |
| 2 | 자동차 / 비싸다 | 자동차가 비싸요. | รถยนต์แพง |
| 3 | 학생 / 적다 | 학생이 적어요. | นักเรียนน้อย |
| 4 | 선생님 / 친절하다 | 선생님이 친절해요. | ครูใจดี |
| 5 | 카오루 씨 / 멋있다 | 카오루 씨가 멋있어요. | คุณคาโอรุเท่ |
| 6 | 날씨 / 나쁘다 | 날씨가 나빠요. | อากาศแย่ |

#### 연습 2 (หน้า 125) — ดูภาพแล้วถามว่าเป็นอย่างไร

ตำราให้คำใบ้ 12 คำ (길다, 짧다, 싸다, 비싸다, 재미있다, 재미없다, 많다, 적다, 예쁘다, 멋있다, 크다, 작다) แล้วดูภาพ 6 ข้อถาม-ตอบตามตัวอย่าง "카오루 씨 집이 어때요? → 작아요." ข้อ 1 คือตัวอย่างที่ตำราติ๊ก ✓ ไว้ที่คำว่า 작다 ตำราไม่พิมพ์เฉลย คำตอบด้านล่างผู้เขียนคู่มืออ่านจากภาพและคำใบ้ (ตัวอย่างตอบ)

| ข้อ | คำถาม | ตัวอย่างตอบ | ความหมาย · ภาพ |
|:---|:---|:---|:---|
| 1 | 카오루 씨 집이 어때요? | 작아요. | บ้านเล็ก (ตัวอย่างตำรา) — ![](img:tb14-125-1) 🖼️ บ้านหลังใหญ่ของยุนอาเทียบกับบ้านหลังเล็กของคาโอรุ |
| 2 | 미나 씨 머리가 어때요? | 길어요. | ผมยาว — ![](img:tb14-125-2) 🖼️ มินะผมยาว โซระผมสั้น |
| 3 | B반 학생이 어때요? | 많아요. | นักเรียนเยอะ — ![](img:tb14-125-3) 🖼️ ห้อง A นักเรียนน้อยกว่าห้อง B |
| 4 | 미나 씨 가방이 어때요? | 비싸요. | กระเป๋าแพง — ![](img:tb14-125-4) 🖼️ กระเป๋ามินะป้าย 30만원 ของโซระป้าย 만원 |

#### 연습 3 (หน้า 125) — ถามเพื่อนด้วยกรอบคำถาม 7 ข้อ

ข้อนี้ให้ถาม-ตอบกับเพื่อนตามตัวอย่าง "○○ 씨가 어때요? → ○○ 씨가 재미있어요." โดยเลือกคำถามจากกรอบ 7 ข้อที่ตำราพิมพ์ไว้ คำตอบเป็นความเห็นจริงของผู้ตอบ ตำราไม่พิมพ์เฉลย ตารางนี้ให้ตัวอย่างตอบที่ใช้คำใบ้ของข้อ 연습 2 (ตัวอย่างตอบ)

| คำถามในกรอบ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|
| ○○ 씨가 어때요? | ○○ 씨가 재미있어요. | คุณ ○○ เป็นอย่างไร — สนุก (ตัวอย่างตำรา) |
| ○○ 씨 옷이 어때요? | ○○ 씨 옷이 예뻐요. | เสื้อผ้าคุณ ○○ เป็นอย่างไร — สวย |
| ○○ 씨 시계가 어때요? | ○○ 씨 시계가 비싸요. | นาฬิกาคุณ ○○ เป็นอย่างไร — แพง |
| 교실이 어때요? | 교실이 커요. | ห้องเรียนเป็นอย่างไร — ใหญ่ |
| 학교가 어때요? | 학교가 좋아요. | โรงเรียนเป็นอย่างไร — ดี |
| 서울이 어때요? | 서울이 멋있어요. | โซลเป็นอย่างไร — เท่ |
| 고향이 어때요? | 고향이 좋아요. | บ้านเกิดเป็นอย่างไร — ดี |

#### 📽️ จากสไลด์อาจารย์ (교과서 124쪽)

สไลด์มีตาราง 4 ช่องที่แบ่งตามวิธีผัน คือ กลุ่ม ㅏ/ㅗ + 아요, กลุ่มสระอื่น + 어요, กลุ่ม 하다 → 해요 และกลุ่ม ㅡ ตก (ㅡ ตกแล้วต่อ 아요 หรือ 어요)

| 한국어 | ไทย | กลุ่ม |
|:---|:---|:---|
| 많다 → 많아요 | มาก | ㅏㅗ + 아요 |
| 작다 → 작아요 | เล็ก | ㅏㅗ + 아요 |
| 싸다 → 싸요 | ถูก | ㅏㅗ + 아요 |
| 좋다 → 좋아요 | ดี | ㅏㅗ + 아요 |
| 적다 → 적어요 | น้อย | อื่น + 어요 |
| 길다 → 길어요 | ยาว | อื่น + 어요 |
| 재미있다 → 재미있어요 | สนุก | อื่น + 어요 |
| 재미없다 → 재미없어요 | ไม่สนุก | อื่น + 어요 |
| 친절하다 → 친절해요 | ใจดี | 하다 → 해요 |
| 피곤하다 → 피곤해요 | เหนื่อย | 하다 → 해요 |

| 예쁘다 → 예뻐요 | สวย | ㅡ ตก: ㅡ + 어요 |

#### ⚠️ ระวัง

- 날씨를 좋아요 ✗ → 날씨가 좋아요 — 좋다 เป็นคำคุณศัพท์ ใช้ 이/가 ส่วน 좋아하다 เป็นกริยา "ชอบ" ใช้ 을/를
- 비싸이에요 ✗ → **비싸요**
- 피곤나요 ✗ → **피곤해요**
- 크다 → **커요** (ㅡ ตก)
- 어둡다 → **어두워요** (ผันพิเศษ ท่องทั้งคำ)

→ เจาะลึก: ไวยากรณ์ข้อ 18 · วิธีผัน ข้อ 06 (เล่ม 2)

### 📝 ไวยากรณ์: -지 않다 — ปฏิเสธแบบยาว (ไวยากรณ์ข้อ 16)

ตอนนี้ว่าด้วย -지 않다 ซึ่งมีความหมายเท่ากับ 안 ที่เรียนในบท 12 ต่างกันแค่ตำแหน่ง คือ 안 อยู่หน้ากริยา ส่วน -지 않다 ต่อท้ายราก ใช้ได้กับทั้งกริยาและคำคุณศัพท์ และไม่เปลี่ยนตามตัวสะกด

#### รูปแบบ

| ชนิดของคำ | รูปปฏิเสธ | ตัวอย่าง |
|:---|:---|:---|
| กริยา · คุณศัพท์ | ราก + -지 않아요 | 가지 않아요 |
| ...하다 | ...하지 않아요 (เขียนติดกัน) | 공부하지 않아요 |

#### แสดงวิธีทำ: -지 않다 (ย่อ · ตารางเต็มในไวยากรณ์ข้อ 16)

กฎ 1 ตัด 다 ออกแล้วต่อ -지 ทันทีโดยไม่ต้องดู받침 กฎ 2 ปิดด้วย 않아요 และรากที่เป็น ...하다 ให้เก็บ 하 ไว้ติดราก

| ราก + คำต่อ | ① ตัด 다 | ② ต่อ -지 | ③ ผล |
|:---|:---|:---|:---|
| 가다 + -지 않다 | 가 | 가 + 지 | **가지 않아요** |
| 마시다 + -지 않다 | 마시 | 마시 + 지 | **마시지 않아요** |
| 좋다 + -지 않다 | 좋 | 좋 + 지 | **좋지 않아요** |
| 비싸다 + -지 않다 | 비싸 | 비싸 + 지 | **비싸지 않아요** |
| 공부하다 + -지 않다 | 공부하 | 공부하 + 지 | **공부하지 않아요** |

#### ตัวอย่าง

| 한국어 | ไทย |
|:---|:---|
| 가지 않아요. | ไม่ไป |
| 마시지 않아요. | ไม่ดื่ม |
| 좋지 않아요. | {x:ไม่}{v:ดี} |
| 비싸지 않아요. | ไม่แพง |
| 공부하지 않아요. | ไม่เรียน |

#### เทียบ 안 กับ -지 않다

| 안 (สั้น) | -지 않다 (ยาว) |
|:---|:---|
| 안 가요 | 가지 않아요 |
| 공부 안 해요 | 공부하지 않아요 |

#### ถาม-ตอบ

คำตอบแบบปฏิเสธมักบอกต่อว่าจริง ๆ แล้วเป็นอย่างไรหรือทำอะไร

| คำถาม | คำตอบ | ความหมาย |
|:---|:---|:---|
| 과일이 비싸요? | 아니요, 비싸지 않아요. 싸요. | ผลไม้แพงไหม — ไม่แพง ถูก |
| 지금 집에 가요? | 아니요, 집에 가지 않아요. 도서관에 가요. | ตอนนี้กลับบ้านไหม — ไม่กลับ ไปห้องสมุด |

#### ตัวอย่างในกรอบตำรา (หน้า 126)

ตำราเปิดข้อ 준비 2 ด้วยบทสนทนาสั้น ๆ แล้วสรุปไว้ในกรอบว่า -지 않다 ต่อท้ายรากของกริยาหรือคำคุณศัพท์ ใช้ในภาษาพูด และให้ย้อนไปดูรูป 안 ของบท 12 กรอบมีประโยคตัวอย่าง 4 ประโยคกับบทสนทนาอีก 1 คู่

- 김치를 먹어요? *(กินกิมจิไหม)*
- 아니요, 김치를 먹지 않아요. *(ไม่ ไม่กินกิมจิ)*

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 토요일에 학교에 가지 않아요. | วันเสาร์ไม่ไปโรงเรียน | กริยา |
| 저는 커피를 마시지 않아요. | ฉันไม่ดื่มกาแฟ | กริยา |
| 지금 공부를 하지 않아요. | ตอนนี้ไม่เรียน | N하다: 공부를 하지 |
| 오늘 날씨가 좋지 않아요. | วันนี้อากาศไม่ดี | คุณศัพท์ |

- 가: 투이 씨, 지금 집에 가요? *(คุณทุย ตอนนี้กลับบ้านไหม)*
- 나: 아니요, 집에 가지 않아요. 도서관에 가요. *(ไม่ ไม่กลับบ้าน ไปห้องสมุด)*

#### 연습 1 (หน้า 126) — ทำเป็นประโยคปฏิเสธด้วย -지 않아요

ตำราให้ทำประโยคปฏิเสธจากวลี 6 ข้อ ตามตัวอย่าง "커피를 마시지 않아요." ตำราไม่พิมพ์เฉลย คำตอบด้านล่างทำตามกฎของข้อนี้ (ตัวอย่างตอบ)

| ข้อ | วลีในตำรา | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 커피를 마시다 | 커피를 마시지 않아요. | ไม่ดื่มกาแฟ (ตัวอย่างตำรา) |
| 2 | 텔레비전을 보다 | 텔레비전을 보지 않아요. | ไม่ดูทีวี |
| 3 | 농구를 하다 | 농구를 하지 않아요. | ไม่เล่นบาสเกตบอล |
| 4 | 지금 집에 가다 | 지금 집에 가지 않아요. | ตอนนี้ไม่กลับบ้าน |
| 5 | 오늘 친구를 만나다 | 오늘 친구를 만나지 않아요. | วันนี้ไม่พบเพื่อน |
| 6 | 김치를 좋아하다 | 김치를 좋아하지 않아요. | ไม่ชอบกิมจิ |

#### 연습 2 (หน้า 127) — ปฏิเสธคำคุณศัพท์แล้วบอกคำตรงข้าม

ตำราให้ถาม-ตอบ 6 ข้อ ตามตัวอย่าง "과일이 비싸요? → 아니요, 비싸지 않아요. 싸요." คำใบ้คือ "คำนาม / คำคุณศัพท์" คำตอบปฏิเสธด้วย -지 않아요 แล้วบอกคำตรงข้าม ตำราไม่พิมพ์เฉลย แถว 2–6 เป็นตัวอย่างตอบที่ทำตามแบบเดียวกัน

| คำใบ้ในตำรา | คำถาม | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1. 과일 / 비싸다 | 과일이 비싸요? | 아니요, 비싸지 않아요. 싸요. | ผลไม้แพงไหม — ไม่แพง ถูก (ตัวอย่างตำรา) |
| 2. 꽃 / 싸다 | 꽃이 싸요? | 아니요, 싸지 않아요. 비싸요. | ดอกไม้ถูกไหม — ไม่ถูก แพง |
| 3. 사람 / 적다 | 사람이 적어요? | 아니요, 적지 않아요. 많아요. | คนน้อยไหม — ไม่น้อย เยอะ |
| 4. 머리 / 짧다 | 머리가 짧아요? | 아니요, 짧지 않아요. 길어요. | ผมสั้นไหม — ไม่สั้น ยาว |
| 5. 책 / 재미없다 | 책이 재미없어요? | 아니요, 재미없지 않아요. 재미있어요. | หนังสือไม่สนุกไหม — ไม่ใช่ สนุก |
| 6. 키 / 크다 | 키가 커요? | 아니요, 크지 않아요. 작아요. | ตัวสูงไหม — ไม่สูง เตี้ย |

#### 연습 3 (หน้า 127) — ปฏิเสธกริยาแล้วบอกสิ่งที่ทำจริง

ตำราให้ถาม-ตอบ 6 ข้อ ตามตัวอย่าง "커피를 마셔요? → 아니요, 커피를 마시지 않아요. 물을 마셔요." คำใบ้คือ "สิ่งที่ถาม / สิ่งที่ทำจริง" ตำราไม่พิมพ์เฉลย แถว 2–6 เป็นตัวอย่างตอบที่ทำตามแบบเดียวกัน

| คำใบ้ในตำรา | คำถาม | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1. 커피를 마시다 / 물 | 커피를 마셔요? | 아니요, 커피를 마시지 않아요. 물을 마셔요. | ไม่ดื่มกาแฟ ดื่มน้ำ (ตัวอย่างตำรา) |
| 2. 라면을 먹다 / 김밥 | 라면을 먹어요? | 아니요, 라면을 먹지 않아요. 김밥을 먹어요. | ไม่กินรามยอน กินคิมบับ |
| 3. 책을 읽다 / 신문 | 책을 읽어요? | 아니요, 책을 읽지 않아요. 신문을 읽어요. | ไม่อ่านหนังสือ อ่านหนังสือพิมพ์ |
| 4. 영화를 보다 / 텔레비전 | 영화를 봐요? | 아니요, 영화를 보지 않아요. 텔레비전을 봐요. | ไม่ดูหนัง ดูทีวี |
| 5. 시장에 가다 / 편의점 | 시장에 가요? | 아니요, 시장에 가지 않아요. 편의점에 가요. | ไม่ไปตลาด ไปร้านสะดวกซื้อ |
| 6. 과일을 사다 / 과자 | 과일을 사요? | 아니요, 과일을 사지 않아요. 과자를 사요. | ไม่ซื้อผลไม้ ซื้อขนม |

#### 📽️ จากสไลด์อาจารย์ (교과서 126쪽)

สไลด์ให้ปฏิเสธด้วย -지 않아요 แล้วบอกสิ่งที่ตรงข้ามต่อ

- 영화를 보지 않아요. 책을 읽어요. *(ไม่ดูหนัง อ่านหนังสือ)*
- 아침에 운동을 하지 않아요. 자요. *({p:ตอน}{n:เช้า}{x:ไม่}{v:ออกกำลังกาย} {v:นอน})*
- 가방이 작지 않아요. 커요. *(กระเป๋าไม่เล็ก ใหญ่)*
- 날씨가 나쁘지 않아요. 좋아요. *(อากาศไม่เลว ดี)*

สไลด์ยังทบทวนรูป 안 ของ 12과 เพื่อเทียบกับ -지 않다

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 보다 → 안 봐요 | ไม่ดู | 안 + ราก + 아/어요 |
| 먹다 → 안 먹어요 | ไม่กิน | 안 + ราก + 아/어요 |
| 크다 → 안 커요 | ไม่ใหญ่ | 안 + ราก + 아/어요 |
| 좋다 → 안 좋아요 | ไม่ดี | 안 + ราก + 아/어요 |
| 운동을 안 해요 | ไม่ออกกำลังกาย | ...하다 กริยา: แทรก 안 ตรงกลาง |
| 공부를 안 해요 | ไม่เรียน | ...하다 กริยา: แทรก 안 ตรงกลาง |
| 안 좋아해요 | ไม่ชอบ | ข้อยกเว้น: 좋아하다 เป็นกริยาคำเดียว |
| 안 친절해요 | ไม่ใจดี | ...하다 คุณศัพท์: 안 วางหน้าทั้งคำ |
| 안 피곤해요 | ไม่เหนื่อย | ...하다 คุณศัพท์: 안 วางหน้าทั้งคำ |
| 안 조용해요 | ไม่เงียบ | ...하다 คุณศัพท์: 안 วางหน้าทั้งคำ |

#### ⚠️ ระวัง

- 이다 → 아니에요 (✗ 학생이지 않아요)
- 있다 → 없어요 (✗ 있지 않아요)
- 하다 เขียนติดกัน 공부하지 (✗ 공부 하지)
- ออกเสียง 않아요 [아나요]

→ เจาะลึก: ไวยากรณ์ข้อ 16 (เล่ม 2)

### 📝 ไวยากรณ์: N도 — …ก็ · …ด้วย (ไวยากรณ์ข้อ 17)

ตอนนี้ว่าด้วย 도 ซึ่งแปลว่า "…ก็" หรือ "…ด้วย" ต่อท้ายคำนามเพื่อบอกว่ามีอีกสิ่งหนึ่งที่เป็นเช่นเดียวกัน จุดสำคัญคือ 도 **แทนที่** 이/가 · 은/는 · 을/를 ไม่ใช่ต่อซ้อนท้ายคำช่วยเดิม และไม่เปลี่ยนตามตัวสะกด

#### รูปแบบ

| คำช่วยเดิม | เมื่อเติม 도 | ตัวอย่าง |
|:---|:---|:---|
| 이/가 · 은/는 | 도 แทนที่ | 저도 |
| 을/를 | 도 แทนที่ | 사과도 |

#### ตัวอย่าง

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 압둘라 씨는 학생이에요. 저도 학생이에요. | คุณอับดุลลาห์เป็นนักเรียน ฉันก็เป็นนักเรียน | 도 อยู่ที่ประธาน |
| 아침에 빵을 먹어요. 사과도 먹어요. | {p:ตอน}{n:เช้า}{v:กิน}{n:ขนมปัง} {v:กิน}{n:แอปเปิล}{p:ด้วย} | 도 อยู่ที่กรรม |
| 한국어를 배워요? → 네, 영어도 배워요. | เรียนภาษาเกาหลีไหม — ใช่ เรียนภาษาอังกฤษด้วย | 도 อยู่ที่กรรม |

#### ตัวอย่างในบทเรียน

| 한국어 | ไทย | สังเกต |
|:---|:---|:---|
| 고향 친구도 한국말을 배워요? | เพื่อนบ้านเกิดก็เรียนภาษาเกาหลีด้วยเหรอ | 도 อยู่ที่ประธาน |
| 텔레비전도 봐요. | ดูทีวีด้วย | 도 อยู่ที่กรรม |
| 커피도 마셔요. | ดื่มกาแฟด้วย | 도 อยู่ที่กรรม |

#### 연습 1 (หน้า 128) — พูดว่า "มี … และมี … ด้วย"

ตำราเปิดข้อ 준비 3 ด้วยบทสนทนาสั้น ๆ ที่ใช้ 도 ในคำถามที่สอง

- 교실에 미국 사람이 있어요? *(ในห้องเรียนมีคนอเมริกันไหม)*
- 네, 있어요. *(มี)*
- 중국 사람도 있어요? *(มีคนจีนด้วยไหม)*
- 네, 중국 사람도 있어요. *(ใช่ มีคนจีนด้วย)*

จากนั้นให้ฝึกพูด 2 ประโยคต่อกันจากคำใบ้ "สถานที่ / ของแรก / ของที่สอง" 6 ข้อ ตามตัวอย่าง "교실에 몽골 사람이 있어요. 일본 사람도 있어요." ประโยคแรกใช้ 이/가 ประโยคที่สองใช้ 도 แทน 이/가 ตำราไม่พิมพ์เฉลย แถว 2–6 เป็นตัวอย่างตอบที่ทำตามแบบเดียวกัน

| ข้อ | คำใบ้ | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1 | 교실 / 몽골 사람 / 일본 사람 | 교실에 몽골 사람이 있어요. 일본 사람도 있어요. | ในห้องเรียนมีคนมองโกเลีย มีคนญี่ปุ่นด้วย (ตัวอย่างตำรา) |
| 2 | 학교 / 베트남 사람 / 사우디아라비아 사람 | 학교에 베트남 사람이 있어요. 사우디아라비아 사람도 있어요. | ในโรงเรียนมีคนเวียดนาม มีคนซาอุดีอาระเบียด้วย |
| 3 | 기숙사 / 한국 사람 / 중국 사람 | 기숙사에 한국 사람이 있어요. 중국 사람도 있어요. | ในหอพักมีคนเกาหลี มีคนจีนด้วย |
| 4 | 가게 / 사과 / 배 | 가게에 사과가 있어요. 배도 있어요. | ในร้านมีแอปเปิล มีลูกแพร์ด้วย |
| 5 | 책상 / 연필 / 공책 | 책상에 연필이 있어요. 공책도 있어요. | บนโต๊ะมีดินสอ มีสมุดด้วย |
| 6 | 냉장고 / 물 / 우유 | 냉장고에 물이 있어요. 우유도 있어요. | ในตู้เย็นมีน้ำ มีนมด้วย |

#### 연습 2 (หน้า 129) — ถาม-ตอบแล้วถามต่อด้วย 도

ตัวอย่างของตำราเป็นบทสนทนา 2 คู่ คู่แรกถามกรรมตัวแรก คู่ที่สองถามกรรมตัวที่สองด้วย 도 คำใบ้ของแต่ละข้อคือ "กรรมที่ 1 / กรรมที่ 2 / กริยา" ตำราไม่พิมพ์เฉลย แถว 2–6 เป็นตัวอย่างตอบที่ทำตามแบบเดียวกัน

- 가: 한국어를 배워요? *(เรียนภาษาเกาหลีไหม)*
- 나: 네, 한국어를 배워요. *(เรียนค่ะ)*
- 가: 영어도 배워요? *(เรียนภาษาอังกฤษด้วยไหม)*
- 나: 네, 영어도 배워요. *(เรียนด้วยค่ะ)*

| คำใบ้ในตำรา | ถามครั้งที่ 1 → ตอบ | ถามครั้งที่ 2 (ใช้ 도) → ตอบ | ความหมาย |
|:---|:---|:---|:---|
| 1. 한국어 / 영어 / 배우다 | 한국어를 배워요? → 네, 한국어를 배워요. | 영어도 배워요? → 네, 영어도 배워요. | เรียนภาษาเกาหลี เรียนภาษาอังกฤษด้วย (ตัวอย่างตำรา) |
| 2. 커피 / 녹차 / 마시다 | 커피를 마셔요? → 네, 커피를 마셔요. | 녹차도 마셔요? → 네, 녹차도 마셔요. | ดื่มกาแฟ ดื่มชาเขียวด้วย |
| 3. 티셔츠 / 바지 / 사다 | 티셔츠를 사요? → 네, 티셔츠를 사요. | 바지도 사요? → 네, 바지도 사요. | ซื้อเสื้อยืด ซื้อกางเกงด้วย |
| 4. 책 / 신문 / 읽다 | 책을 읽어요? → 네, 책을 읽어요. | 신문도 읽어요? → 네, 신문도 읽어요. | อ่านหนังสือ อ่านหนังสือพิมพ์ด้วย |
| 5. 과자 / 빵 / 팔다 | 과자를 팔아요? → 네, 과자를 팔아요. | 빵도 팔아요? → 네, 빵도 팔아요. | ขายขนม ขายขนมปังด้วย |

### 💬 대화 14-1 — อยู่หอพักกับใคร

이리나 ถาม 투이 ว่าอยู่หอพักกับใคร 투이 ตอบว่าอยู่กับเพื่อนจากบ้านเกิด 이리나 จึงถามต่อว่าเพื่อนก็เรียนภาษาเกาหลีด้วยหรือเปล่า ซึ่ง 투이 ตอบว่าไม่ และบอกว่าเพื่อนใจดี บทสนทนานี้ใช้ครบทั้ง 도 -지 않다 และคำคุณศัพท์ -아/어/여요

> 이리나: 투이 씨, 기숙사에서 누구와 같이 살아요? *(คุณทุย อยู่หอพักกับใคร)*
>
> 투이: 고향 친구하고 같이 살아요. *(อยู่กับเพื่อนจากบ้านเกิด)*
>
> 이리나: 고향 친구도 한국말을 배워요? *(เพื่อนจากบ้านเกิดก็เรียนภาษาเกาหลีด้วยเหรอ)*
>
> 투이: 아니요, 고향 친구는 한국말을 배우지 않아요. *(ไม่ ไม่ได้เรียนภาษาเกาหลี)*
>
> 이리나: 그 친구가 친절해요? *(เพื่อนคนนั้นใจดีไหม)*
>
> 투이: 친절해요. *(ใจดี)*

#### สังเกตจากบทสนทนา

- 누구와 같이 살아요? — 이리나 ใช้ 와 "กับ" ซึ่งบท 15 จะอธิบายเต็ม ส่วน 투이 ตอบด้วย 하고 จากบท 13
- 고향 친구도 한국말을 배워요? — 도 แทนที่ 이/가 ที่ประธาน
- 고향 친구는 한국말을 배우지 않아요 — ใช้ 은/는 เพื่อเทียบว่า "ส่วนเพื่อนฉัน" (ต่างจาก 도 ในคำถามก่อนหน้า) และใช้ -지 않다 หลังกริยา 배우다
- 친절해요 — คำคุณศัพท์ ผัน -여요 → 해요 โดยไม่ต้องมี 이다

#### 확인해 봅시다 (หน้า 130)

ตำราถามเช็กความเข้าใจ 2 ข้อหลังบทสนทนา ตอบด้วยประโยคจากบทสนทนาได้เลย ตำราไม่พิมพ์เฉลย ข้อที่สองถามถึงทั้งสองคน คำตอบด้านล่างสรุปจากบทสนทนา (ตัวอย่างตอบ)

| คำถาม | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|
| 투이 씨가 기숙사에서 누구와 같이 살아요? | 고향 친구하고 같이 살아요. | ทุยอยู่หอกับใคร — กับเพื่อนบ้านเกิด |
| 투이 씨와 친구는 무엇을 해요? | 투이 씨는 한국말을 배워요. 고향 친구는 한국말을 배우지 않아요. | ทุยกับเพื่อนทำอะไร — ทุยเรียนภาษาเกาหลี เพื่อนไม่ได้เรียน |

#### ฝึกสลับ (หน้า 130)

ตำราให้เปลี่ยนคำในบทสนทนา 14-1 ตามตารางที่มี 5 ช่องต่อแถว ตารางนี้จัดเป็น 4 คอลัมน์โดยรวมช่องกรรมกับกริยาไว้ด้วยกัน คอลัมน์ที่ 1 ใส่แทน 고향 친구 คอลัมน์ที่ 2 ใส่แทน 한국말을 배워요 คอลัมน์ที่ 3 ใส่แทน 친구 ในประโยค 그 친구 และคอลัมน์ที่ 4 ใส่แทน 친절해요 แถวแรกคือบทสนทนาเดิม

### 📖 읽기 14-2 — จีฮุนกับทุย

บทอ่านให้ 지훈 กับ 투이 แนะนำตัวเอง คนแรกเล่าชีวิตช่วงปิดเทอมที่ไม่ต้องไปโรงเรียน อีกคนเล่าชีวิตนักเรียนต่างชาติในเกาหลี สองข้อความนี้ใช้ -지 않다 และ 도 ในบริบทจริง

ก่อนอ่าน ตำราถามให้คิดเรื่องชีวิตที่เกาหลีของตัวเอง (หน้า 132):

- 여러분이 요즘 한국에서 하는 일과 하지 않는 일이 뭐예요? *(ช่วงนี้ที่เกาหลีคุณทำอะไรและไม่ทำอะไร)*

#### 이지훈 เล่าเรื่องตัวเอง

> 저는 이지훈이에요. *({n:ฉัน}{e:ชื่อ}{n:อีจีฮุน})* 대학생이에요. *(เป็นนักศึกษา)* 지금 방학이에요. *(ตอนนี้ปิดเทอม)*
>
> 수업이 없어요. *({x:ไม่มี}{n:เรียน})* 학교에 가지 않아요. *(ไม่ไปโรงเรียน)*
>
> 저는 서점에서 아르바이트를 해요. *(ทำงานพิเศษที่ร้านหนังสือ)* 그래서 밤에 좀 피곤해요. *(เลย{p:ตอน}{n:กลางคืน}{v:เหนื่อย}{a:หน่อย})*
>
> 밤에 친구를 만나지 않아요. *(กลางคืนไม่พบเพื่อน)* 집에서 책을 읽어요. *(อ่านหนังสือที่บ้าน)* 텔레비전도 봐요. *(ดูทีวีด้วย)*

#### 투이 เล่าเรื่องตัวเอง

> 저는 투이예요. *({n:ฉัน}{e:ชื่อ}{n:ทุย})* 한국 사람이 아니에요. *(ไม่ใช่คนเกาหลี)* 베트남 사람이에요. *(เป็นคนเวียดนาม)*
>
> 지금 한국에서 한국어를 공부해요. *(ตอนนี้เรียนภาษาเกาหลีที่เกาหลี)* 여러 나라 친구들과 같이 공부해요. *(เรียนด้วยกันกับเพื่อนหลายประเทศ)*
>
> 교실에서 베트남 말을 하지 않아요. *(ในห้องเรียนไม่พูดภาษาเวียดนาม)* 커피숍에서 친구들과 같이 커피도 마셔요. *({p:ที่}{n:ร้านกาแฟ}{p:ก็}{v:ดื่ม}{n:กาแฟ}{p:กับ}{n:เพื่อน}{p:ด้วย})* 학교생활이 재미있어요. *(ชีวิตโรงเรียนสนุก)*

#### 가 — 하는 일 / 하지 않는 일 (เฉลยจากภาคผนวก)

ข้อ 가 ให้อ่านบทอ่านแล้วแยกสิ่งที่ 이지훈 กับ 투이 ทำ (하는 일) และไม่ทำ (하지 않는 일) ลงตาราง 2 ช่อง เฉลยของตำราเป็นประโยคเต็มตามบทอ่าน ส่วนลายมือในตำราเขียนรูปสั้น เช่น 아르바이트 해요 หรือ 학교에 안 가요 ซึ่งความหมายเดียวกัน แต่ฝั่ง 투이 ที่ทำมี 3 ประโยคในเฉลย (ลายมือเขียนไว้ 2)

- 이지훈 씨와 투이 씨가 하는 것과 하지 않는 것을 나눠서 쓰세요. *(แยกเขียนสิ่งที่คุณจีฮุนกับคุณทุยทำและไม่ทำ)*

ตารางในตำรามีหัวคอลัมน์ 무엇을 해요? *(ทำอะไร)* กับ 무엇을 하지 않아요? *(ไม่ทำอะไร)* เฉลยแยกตามคนดังนี้

- 지훈 — 하는 일 (สิ่งที่ทำ):
  - 서점에서 아르바이트를 해요. *(ทำงานพิเศษที่ร้านหนังสือ)*
  - 집에서 책을 읽어요. *(อ่านหนังสือที่บ้าน)*
  - 텔레비전도 봐요. *(ดูทีวีด้วย)*
- 지훈 — 하지 않는 일 (สิ่งที่ไม่ทำ):
  - 학교에 가지 않아요. *(ไม่ไปโรงเรียน)*
  - 밤에 친구를 만나지 않아요. *(กลางคืนไม่พบเพื่อน)*
- 투이 — 하는 일 (สิ่งที่ทำ):
  - 한국에서 한국어를 공부해요. *(เรียนภาษาเกาหลีที่เกาหลี)*
  - 여러 나라 친구들과 같이 공부해요. *(เรียนด้วยกันกับเพื่อนหลายประเทศ)*
  - 커피숍에서 친구들과 같이 커피도 마셔요. *(ดื่มกาแฟด้วยกันกับเพื่อนที่ร้านกาแฟ)*
- 투이 — 하지 않는 일 (สิ่งที่ไม่ทำ):
  - 교실에서 베트남 말을 하지 않아요. *(ในห้องเรียนไม่พูดภาษาเวียดนาม)*

> 지훈: **서점에서 아르바이트를 해요.** *(ทำงานพิเศษที่ร้านหนังสือ)*
>
> 투이: 방학에 **학교에 가요**? *(ช่วงปิดเทอมไปโรงเรียนไหม)*
>
> 지훈: 아니요. 학교에 가지 않아요. *(ไม่ ไม่ไปโรงเรียน)*

#### คำถามชวนคุย (หน้า 133)

ท้ายหน้าตำรามีคำถามให้คุยกับเพื่อนเรื่องสิ่งที่นักเรียนทำและไม่ทำ

- 학생이 하는 일과 하지 않는 일을 이야기해 봅시다. *(ลองคุยกันว่านักเรียนทำอะไรและไม่ทำอะไร)*
- ตัวอย่างตอบ: 학생은 한국어를 공부해요. 교실에서 커피를 마시지 않아요. *(นักเรียนเรียนภาษาเกาหลี ไม่ดื่มกาแฟในห้องเรียน)*

#### 활동 (หน้า 131)

กิจกรรมหน้า 131 ให้เขียนถึงเพื่อน ก่อนเขียนให้สัมภาษณ์เพื่อนตามตารางคำถาม ตัวอย่างในตำราเป็นข้อความด้านล่าง

- 여러분 친구에 대해서 써 봅시다. 먼저 친구를 인터뷰하세요. *(เขียนเกี่ยวกับเพื่อนของคุณ ก่อนอื่นให้สัมภาษณ์เพื่อน)*

ตารางสัมภาษณ์ของตำรามีคอลัมน์ "친구 이름: 밍밍" ที่กรอกตัวอย่างไว้แล้ว กับคอลัมน์ "친구 이름:" ว่างให้กรอกชื่อเพื่อนของตัวเอง และแถวสุดท้ายเว้นว่างให้เติมคำถามเอง

| 질문 | 밍밍 | ความหมาย |
|:---|:---|:---|
| 어디에서 살아요? | 기숙사 | อยู่ที่ไหน — หอพัก |
| 누구와 같이 살아요? | 고향 친구 | อยู่กับใคร — เพื่อนบ้านเกิด |
| 무엇을 잘해요? | 한국어 | เก่งอะไร — ภาษาเกาหลี |
| 무엇을 좋아해요? | 운동, 요리 | ชอบอะไร — ออกกำลังกาย ทำอาหาร |
| 무엇을 좋아하지 않아요? | 김치 | ไม่ชอบอะไร — กิมจิ |
| 아르바이트를 해요? | ○ | ทำงานพิเศษไหม — ทำ |

ข้อความตัวอย่างที่เขียนจากตารางนี้

> 제 친구 이름은 밍밍이에요. *({n:เพื่อนชื่อหมิงหมิง})*
>
> 밍밍은 기숙사에서 살아요. 고향 친구와 같이 살아요. *({v:อยู่}{n:หอ}{p:กับ}{n:เพื่อนบ้านเกิด})*
>
> 제 친구 밍밍은 한국어를 잘해요. *({a:เก่ง}{n:ภาษาเกาหลี})*
>
> 밍밍은 요리와 운동을 좋아해요. *({v:ชอบ}{n:ทำอาหาร}{p:กับ}{n:ออกกำลังกาย})*
>
> 김치를 좋아하지 않아요. *({x:ไม่}{v:ชอบ}{n:กิมจิ})*
>
> 밍밍은 아르바이트를 해요. *({v:ทำ}{n:งานพิเศษ})*
>
> 아주 바빠요. *({v:ยุ่ง}{a:มาก})*

ท้ายหน้ามีกรอบเส้นบรรทัด 7 บรรทัดที่ขึ้นต้นด้วย "제 친구 이름은" ให้เขียนถึงเพื่อนของตัวเองในแบบเดียวกัน (เว้นไว้ให้เขียนเอง)

### 🔊 발음

บทนี้เจอทั้งการเชื่อมเสียง (연음) และการกลืนตัวสะกด เช่น ㅎ ใน 않아요 กับ ㄼ ใน 짧아요 สัญลักษณ์ 📖 ในตารางหมายถึงเสียงอ่านที่ตำราพิมพ์ไว้เอง (ระบุหน้า) ส่วนแถวที่ไม่มีเครื่องหมายคือเสียงตามกฎมาตรฐาน

| เขียน | อ่าน | กฎ |
|:---|:---|:---|
| 않아요 | [아나요] | 📖 หน้า 126 · ㅎ ไม่ออกเสียง + 연음 |
| 많아요 | [마나요] | 📖 หน้า 127 · ㅎ ไม่ออกเสียง + 연음 |
| 짧아요 | [짤바요] | 📖 หน้า 127 · ㄼ + สระ → ออกเสียง ㄹ แล้วย้าย ㅂ ไปพยางค์ถัดไป |
| 한국어 | [한구거] | 📖 หน้า 129 · 연음 |
| 읽어요 | [일거요] | 📖 หน้า 129 · 연음 |
| 같이 | [가치] | 📖 หน้า 130 · ㅌ + ㅣ → [ㅊ] |
| 한국말 | [한궁말] | 📖 หน้า 130 · ㄱ + ㅁ → [ㅇ] + ㅁ |
| 수업이 없어요 | [수어비 업써요] | 연음 · ㅄ + 어 → [업써] (ตำราขีดเส้นใต้ 14-3) |
| 집에서 책을 읽어요 | [지베서 채글 일거요] | 연음 (ตำราขีดเส้นใต้ 14-3) |
| 한국에서 한국어를 공부해요 | [한구게서 한구거를 공부해요] | 연음 (ตำราขีดเส้นใต้ 14-3) |

ข้อควรระวังตอนเขียนตามคำบอก: ฟังได้ [사라요] ต้องเขียน 살아요 เพราะตัวสะกดถูกกลืนในเสียง ตัวอย่างอื่นคือ 많아요 [마나요] กับ 읽어요 [일거요]

### 🧪 ออกสอบอย่างไร

บทนี้ออกสอบในแบบทดสอบประจำวัน 매일시험 14 (7 ต.ค.) ซึ่งได้ 7.5 จาก 10 และยังมีในชุดทบทวนกลางภาค ส่วนนี้สรุปโครงข้อสอบ ข้อที่เสียคะแนน และข้อสอบอื่นที่ใช้เนื้อหาบทนี้

#### 매일시험 14 (7 ต.ค.) = 7.5 / 10

เสียไป 2.5 คะแนน คะแนนเต็ม 10 = A 10 × 0.5 + B 3 × 1 + C 2 × 1 ส่วน A ให้ดูภาพแล้วเขียนคำคุณศัพท์ รูปที่ถูกทั้ง 10 ข้อคือ

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|
| 커요 | ใหญ่ | 작아요 | เล็ก |
| 비싸요 | แพง | 싸요 | ถูก |
| 어두워요 | มืด | 피곤해요 | เหนื่อย |
| 예뻐요 | สวย | 멋있어요 | เท่ / หล่อ |
| 많아요 | มาก | 적어요 | น้อย |

- ส่วน B ตอบด้วย -지 않아요 ถูกทั้งหมด (3 ข้อ):
  - 머리가 짧지 않아요. *(ผมไม่สั้น)*
  - 커피를 마시지 않아요. *(ไม่ดื่มกาแฟ)*
  - 지금 공부하지 않아요. *(ตอนนี้ไม่ได้เรียน)*
- ส่วน C เขียนตามคำบอก (2 ข้อ):
  - 누구하고 같이 살아요? *(อยู่กับใคร)*
  - 한국어를 배워요. *(เรียนภาษาเกาหลี)*

#### ข้อที่เสียคะแนนใน 매일시험 14

- A1 커요 *(ใหญ่)* และ A5 어두워요 *(มืด)* เว้นว่าง
- A6 เขียน 피곤나요 ✗ → 피곤해요 (A1 · A5 · A6 รวม −1.5)
- C14 เขียน 사라요 ✗ → **살아요** (−1)

#### ข้อสอบอื่นที่ใช้บทนี้

- ชุดทบทวนกลางภาค (ครูแจก):
  - ชุด 1 ข้อ 6 ออกคู่ตรงข้าม
  - ชุด 1 ข้อ 9 ออก -지 않아요 / 안
  - ชุด 2 ข้อ 17–19 = บทอ่าน 14-2
  - ข้อ 19 เติม 수업이 **없어요** *(ไม่มีเรียน)*
  - ข้อ 18 투이 씨는 한국에서 일해요 *(ทุยทำงานที่เกาหลี)* = X
- 복습시험② (10/19) *(เก็ง)*: 쓰기 1 ออก 도 · 읽기 อาจยกบทอ่านนี้ (เป็นชุดสำรอง)

> [!WARNING] ที่น่าจะพลาด (คาดจากข้อผิดเดิม)
> - 살아요 [사라요]: ราก 살 ลงท้าย ㅏ → ใช้ 아요 และต้องเขียน ㄹ — ✗ 사라요 · ✗ 살어요 (พลาดซ้ำในใบฝึก 19 · ครูไฮไลต์)
> - 피곤나요 ✗ → 피곤해요 และ 어때요 กับ 어떻게 เคยสับสน (어때요 = ถามลักษณะ ใช้จบประโยคได้เลย)
> - "ไม่ใช่คน…" ใช้ 이/가 아니에요 ไม่ใช่ -지 않다 (한국 사람이 아니에요)
> - อย่าซ้อน 도 กับคำช่วยเดิม: ✗ 친구가도 · ✗ 친구를도

### 🔗 เชื่อมโยง

← ต่อยอดจาก

- 11과 -아/어요 — คำคุณศัพท์ผันเหมือนกริยา
- 12과 안 + V / N 안 하다 → -지 않아요 — สั้น → ยาว ความหมายเท่ากัน
- 11 · 13과 을/를 · 하고 → 도 — 사과를 → 사과도 ต่างจาก 하고 ที่รวมในประโยคเดียว

→ ใช้ต่อใน

- 15과 N와/과 — บทสนทนา 14 ใช้ 누구와 ไปแล้ว
- 15과 키가 크세요 — คำคุณศัพท์ใส่ 시 ได้
- 16–17과 예쁩니다 · 가지 않습니다 · 바빴어요
- 20과 -네요 — 친절하네요
- 21과 N만 ↔ N도
- 22과 -고 — 값이 싸고 맛있어요

> [!SUMMARY] สรุปท้ายบท
> - คำคุณศัพท์เป็นภาคแสดงเองโดยไม่ต้องมี 이다 และผันเหมือนกริยา: ㅏ/ㅗ → 아요, สระอื่น → 어요, ...하다 → 해요, ㅡ ตก (크다 → 커요 · 나쁘다 → 나빠요)
> - ประธานของคำคุณศัพท์ใช้ 이/가 (✗ 날씨를 좋아요) เพราะ 좋다 เป็นคุณศัพท์ ส่วน 좋아하다 เป็นกริยา "ชอบ" ใช้ 을/를
> - -지 않다 คือ 안 แบบยาว (ราก + 지 않아요) ใช้ได้ทั้งกริยาและคุณศัพท์ ส่วน 이다 → 아니에요 และ 있다 → 없어요
> - N도 แทนที่ 이/가 · 은/는 · 을/를 ห้ามซ้อน (✗ 가도 · ✗ 를도) และ 도 ≠ 은/는
> - ข้อสอบ: เขียนรูปคำคุณศัพท์จากภาพ · ตอบด้วย -지 않아요 · เขียนตามคำบอก (누구하고 같이 살아요? · 한국어를 배워요)
> - ข้อผิดที่เคยเจอ: 피곤나요 · 사라요 · 살어요 · 어두워요 กับ 커요 ที่เว้นว่าง
