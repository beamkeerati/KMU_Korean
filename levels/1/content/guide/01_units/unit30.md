## 30과 · 사거리에서 왼쪽으로 가세요 (ที่สี่แยกให้เลี้ยวซ้าย)

> [!INTRO] บทนี้ว่าด้วยอะไร
> บทที่ 30 ว่าด้วย **การถามทางและบอกทาง** สถานการณ์ในบทคือคนต่างชาติถามคนที่เดินผ่านไปมาว่าแถวนี้มีธนาคารไหม ได้คำตอบว่าที่สี่แยกให้เลี้ยวซ้าย แล้วบทอ่านเป็นโพสต์ของอีรีนาที่เล่าเรื่องไปเที่ยวหอคอย N서울타워
>
> ไวยากรณ์ใหม่มี 2 เรื่อง:
>
> 1. **N-(으)로** (ไวยากรณ์ข้อ 49) — ต่อท้ายคำนามเพื่อบอก**ทิศทางที่ไป** เช่น 왼쪽으로 가세요 *(ไปทางซ้าย)* ต่างจาก 에 ที่บอก "จุดหมาย"
> 2. **V/A-(으)니까** (ไวยากรณ์ข้อ 50) — บอก**เหตุผล** เหมือน -아/어서 ในบท 29 แต่ประโยคหลังเป็นคำสั่งหรือชวนได้ เช่น 비가 오니까 우산을 준비하세요 *(ฝนตก เตรียมร่มด้วย)*
>
> จบบทแล้วจะถามทางและบอกทางด้วยทิศ + (으)로 ได้ ให้เหตุผลพร้อมแนะนำหรือชวนด้วย -(으)니까 ได้ และอ่านเรื่องเที่ยวหอคอย N서울타워 ในบทอ่าน 30-2 ได้
>
> จุดที่คนไทยงงบ่อย: (으)로 แปลว่า "ไปทาง…" ไม่ใช่ "ไปที่…" (우체국에 가요 ↔ 우체국으로 가요) และเลือกไม่ถูกว่าเมื่อไรใช้ -아/어서 เมื่อไรใช้ -(으)니까 คำตอบสั้น ๆ คือถ้าประโยคหลังเป็นคำสั่งหรือชวนต้องใช้ -(으)니까

### 📝 ไวยากรณ์: N-(으)로 — บอกทิศทางที่ไป (ไวยากรณ์ข้อ 49)

ตอนนี้ว่าด้วย (으)로 ที่ต่อท้ายคำนามเพื่อบอก "ไปทาง…" หรือ "ไปที่ทิศ…" เช่น 오른쪽으로 가세요 *(ไปทางขวา)* ตำราอธิบายในกล่องว่า (으)로 บอก**ทิศทางของการเคลื่อนที่** และใช้บ่อยกับกริยาเคลื่อนที่ 7 คำในตารางด้านล่าง ตัวเลือก 으로 หรือ 로 ดูที่ตัวท้ายของคำนาม

#### รูปแบบ

| นามลงท้ายด้วย | ต่อท้าย | ตัวอย่าง |
|:---|:---|:---|
| พยัญชนะ | **-으로** | 오른쪽으로 · 3층으로 · 밖으로 |
| พยัญชนะ | **-으로** | 안으로 · 시청으로 |
| สระหรือ ㄹ | **-로** | 교실로 · 서울로 · 거기로 |

#### แสดงวิธีทำ: (으)로 ทิศทาง (ย่อ · ตารางเต็มในไวยากรณ์ข้อ 49)

กฎ 1 นามมีตัวสะกดต่อ 으로 กฎ 2 นามไม่มีตัวสะกดต่อ 로 กฎ 3 นามลงท้าย ㄹ ต่อ 로 เหมือนไม่มีตัวสะกด ดูตัวท้ายของนามเท่านั้น ไม่ดูกริยาที่ตามมา

| นาม + (으)로 | ① ดูตัวท้ายของนาม | ② เลือก | ③ ผล |
|:---|:---|:---|:---|
| 오른쪽 + (으)로 | ㄱ เป็นตัวสะกด | 으로 | **오른쪽으로** |
| 3층 + (으)로 | ㅇ เป็นตัวสะกด | 으로 | **3층으로** |
| 사거리 + (으)로 | ไม่มีตัวสะกด | 로 | **사거리로** |
| 서울 + (으)로 | ㄹ นับเหมือนไม่มีตัวสะกด | 로 | **서울로** |
| 교실 + (으)로 | ㄹ นับเหมือนไม่มีตัวสะกด | 로 | **교실로** |

#### กริยาเคลื่อนที่ที่ใช้คู่กับ (으)로

| 한국어 | ไทย | 한국어 | ไทย |
|:---|:---|:---|:---|
| 가다 | ไป | 오다 | มา |
| 내려가다 | ลงไป | 올라가다 | ขึ้นไป |
| 들어가다 | เข้าไป | 들어오다 | เข้ามา |
| 나오다 | ออกมา | | |

#### ตัวอย่างจากตำรา

ตัวอย่างในตำรามาจากบทสนทนาสั้น ๆ ประโยคสุดท้ายใช้ -(으)니까 ด้วย (끝났으니까) ซึ่งจะเรียนในข้อถัดไป

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 약국이 어디에 있어요? → 사거리에서 오른쪽으로 가세요. | ร้านขายยาอยู่ที่ไหน → ที่สี่แยกให้ไปทางขวา | ตัวอย่างบทสนทนา |
| 저는 프랑스로 여행을 가고 싶어요. | ฉันอยากไปเที่ยวฝรั่งเศส | ตัวอย่างบทสนทนา |
| 3층으로 올라가십시오. | เชิญขึ้นไปชั้น 3 | ตัวอย่างบทสนทนา |
| 쉬는 시간이 끝났으니까 교실로 들어오세요. | หมดเวลาพักแล้ว เข้าห้องเรียนด้วย | ตัวอย่างบทสนทนา |

#### 연습 1 — ดูไอคอนแล้วบอกทิศ

แบบฝึกนี้ให้ดูไอคอนแล้วบอกทิศทางด้วย (으)로 + กริยาเคลื่อนที่ แล้วลงท้ายด้วย -(으)세요 ตำราพิมพ์ 보기 ไว้ในกรอบ (왼쪽으로 가세요.) แล้วให้ทำ 5 ข้อ ข้อ 1 ตรงกับ 보기 ตารางข้างล่างแสดงโจทย์ที่พิมพ์ในตำราแล้วตามด้วยประโยคที่ได้ ตำราไม่พิมพ์เฉลยข้อ 2–5 ประโยคที่ได้คือตัวอย่างตอบ

| ข้อ | โจทย์ → ประโยคที่ได้ | ไทย |
|:---|:---|:---|
| 보기 | 왼쪽으로 가세요. | ไปทางซ้าย |
| 1 | 왼쪽 / 가다 → 왼쪽으로 가세요. | ไปทางซ้าย |
| 2 | 밖 / 나오다 → 밖으로 나오세요. | ออกไปข้างนอก |
| 3 | 안 / 들어가다 → 안으로 들어가세요. | เข้าไปข้างใน |
| 4 | 9층 / 올라가다 → 9층으로 올라가세요. | ขึ้นไปชั้น 9 |
| 5 | 1층 / 내려가다 → 1층으로 내려가세요. | ลงไปชั้น 1 |

#### 연습 2 — ถามที่ตั้งแล้วตอบด้วยทิศ

แบบฝึกนี้ให้ถามว่าสถานที่อยู่ที่ไหนแล้วตอบด้วยทิศ + (으)로 + กริยา มี 보기 หนึ่งข้อ (우체국이 어디에 있어요? → 오른쪽으로 가세요) ตารางข้างล่างคือโจทย์ 5 ข้อกับตัวอย่างตอบตามกฎ

| โจทย์ (สถานที่ / ทิศ / กริยา) | ตัวอย่างตอบ | ความหมาย |
|:---|:---|:---|
| 1 (보기) 우체국 / 오른쪽 / 가다 | 우체국이 어디에 있어요? → 오른쪽으로 가세요. | ไปรษณีย์อยู่ที่ไหน → ไปทางขวา |
| 2. PC방 / 2층 / 올라가다 | PC방이 어디에 있어요? → 2층으로 올라가세요. | ร้านเน็ตอยู่ที่ไหน → ขึ้นไปชั้น 2 |
| 3. 병원 / 3번 출구 / 나가다 | 3번 출구로 나가세요. | ออกทางออก 3 |
| 4. 교실 / 건물 안 / 들어가다 | 건물 안으로 들어가세요. | เข้าไปในอาคาร |
| 5. 주차장 / 지하 1층 / 내려가다 | 지하 1층으로 내려가세요. | ลงไปชั้นใต้ดิน 1 |

#### 연습 3 — บอกทางจากแผนที่

แบบฝึกนี้ให้ดูแผนที่สี่แยกแล้วบอกทางไปสถานที่ต่าง ๆ จากจุดที่ตัวละครอยู่ ตำราพิมพ์โจทย์ไว้ว่า

- 오늘 오후에 제프리 씨와 마키 씨는 어디에 가고 싶어요? 그림을 보고 다음과 같이 그곳에 가는 방법을 설명해 주세요. *(บ่ายนี้เจฟฟรีย์กับมากิอยากไปที่ไหน ดูรูปแล้วอธิบายวิธีไปที่นั่นตามตัวอย่างต่อไปนี้)*

ตัวอย่างบทสนทนาที่ให้มาคือ

- 제프리: 우체국에 가고 싶어요. 그런데 우체국에 어떻게 가요? *(อยากไปไปรษณีย์ แต่ไปยังไง)*
- 지훈: 사거리에서 오른쪽으로 가세요. *(ที่สี่แยกไปทางขวา)*

![](img:tb30-299-map) 🖼️ *แผนที่สี่แยก (ภาพเล็ก) — 제프리 อยู่ด้านล่าง ส่วน 마키 อยู่ด้านซ้าย มีร้านขนม ร้านขายยา ไปรษณีย์ ห้าง และโรงพยาบาล ลูกศรชี้ขึ้นเขียนว่า 시청쪽*

ตำราเว้นช่อง 가는 방법 (วิธีไป) ให้เติม และพิมพ์เฉลยไว้เฉพาะแถวแรก (우체국) เป็นตัวอย่าง แถวที่เหลือตำราไม่มีเฉลย คอลัมน์ ตัวอย่างตอบ เขียนเพิ่มจากแผนที่ (ภาพเล็ก อ่านรายละเอียดไม่ชัด ตรวจกับครูถ้าไม่แน่ใจ) โดย 제프리 ยืนที่ปลายถนนด้านล่างมองไปทาง 시청쪽 ส่วน 마키 ยืนที่ปลายถนนด้านซ้าย

| ตัวละคร | สถานที่ | วิธีไป (ตัวอย่างตอบ) |
|:---|:---|:---|
| 제프리 | 우체국 | 사거리에서 오른쪽으로 가세요. *(ที่สี่แยกไปทางขวา เป็นเฉลยที่ตำราพิมพ์ไว้)* |
| 제프리 | 빵집 | 사거리에서 왼쪽으로 가세요. *(ที่สี่แยกไปทางซ้าย)* |
| 제프리 | 약국 | 사거리에서 오른쪽으로 가세요. 우체국 옆에 약국이 있어요. *(ที่สี่แยกไปทางขวา ร้านขายยาอยู่ข้างไปรษณีย์)* |
| 마키 | 백화점 | 사거리에서 왼쪽으로 가세요. *(ที่สี่แยกไปทางซ้าย)* |
| 마키 | 병원 | 사거리에서 오른쪽으로 가세요. *(ที่สี่แยกไปทางขวา)* |

#### ⚠️ ระวัง

- **에 = จุดหมาย** (우체국에 가요) ↔ **(으)로 = ทิศทาง/ช่องทาง** (우체국으로 가요) — ตำราสอนให้ตอบ "어떻게 가요?" ด้วยทิศ + (으)로
- ★ ㄹ ท้ายใช้ **로** ไม่ใช่ 으로: 서울로 ✓ · 서울으로 ✗
- (으)로 ที่บท 31 เป็นอีกความหมาย "ด้วยวิธี/พาหนะ" (ไวยากรณ์ข้อ 51) รูปเหมือนกัน

→ เจาะลึก: ไวยากรณ์ข้อ 49 (เล่ม 2)

### 📝 ไวยากรณ์: V/A-(으)니까 — เหตุผลที่ตามด้วยคำสั่ง/ชวนได้ (ไวยากรณ์ข้อ 50)

ตอนนี้ว่าด้วยตัวเชื่อมที่แปลว่า "เพราะ… (เลย…)" เหมือน -아/어서 ในบท 29 แต่ต่างกันตรงที่ประโยคหลังเป็นคำสั่งหรือชวนได้ และใส่กาล -았/었- ได้ ตำราอธิบายในกล่องว่า -(으)니까 บอกว่าประโยคหน้าเป็น**เหตุผลหรือข้ออ้าง**ของประโยคหลัง (เทียบ -아/어서 ไวยากรณ์ข้อ 48 บท 29)

#### รูปแบบ

| รากลงท้าย | ต่อท้าย | ตัวอย่าง |
|:---|:---|:---|
| มีตัวสะกด | **-으니까** | 없다 → 없으니까 · 읽다 → 읽었으니까 |
| ไม่มีตัวสะกด | **-니까** | 막히다 → 막히니까 · 오다 → 오니까 |
| ตัวสะกด ㄹ (ตัด ㄹ) | **-니까** | 멀다 → **머니까** |
| ㅂ 불규칙 (ไวยากรณ์ข้อ 37) | ㅂ → 우 + -니까 | 덥다 → **더우니까** · 춥다 → 추우니까 |
| ㅂ 불규칙 (ไวยากรณ์ข้อ 37) | ㅂ → 우 + -니까 | 뜨겁다 → 뜨거우니까 |
| นามลงท้ายพยัญชนะ | **N이니까** | 제 생일이니까 |
| นามลงท้ายสระ | **N니까** | 중요한 서류니까 |

#### แสดงวิธีทำ: -(으)니까 (ย่อ · ตารางเต็มในไวยากรณ์ข้อ 50)

กฎ 1 รากไม่มีตัวสะกดตัด 으 ต่อ 니까 กฎ 2 รากมีตัวสะกดเก็บ 으 เป็น 으니까 กฎ 3 รากลงท้าย ㄹ ตัด ㄹ ของรากเพราะ 니까 ขึ้นต้นด้วย ㄴ กฎ 4 ราก ㅂ 불규칙 ใช้ 우 แทน 으

| ราก + (으)니까 | ① ตัวสะกด / 으 | ② ตัด ㄹ / ปรับ ㅂ | ③ ผล |
|:---|:---|:---|:---|
| 막히 + (으)니까 | ไม่มี ตัด 으 | ไม่ปรับ | **막히니까** |
| 없 + (으)니까 | มี เก็บ 으 | ไม่ปรับ | **없으니까** |
| 읽 + 었 + (으)니까 | ลงท้าย ㅆ เก็บ 으 | ไม่ปรับ | **읽었으니까** |
| 만들 + (으)니까 | ㄹ ตัด 으 | ตัด ㄹ ของราก | **만드니까** |
| 덥 + (으)니까 | ㅂ 불규칙 | ㅂ หลุด ใส่ 우 | **더우니까** |
| 생일 + (이)니까 | นามมีตัวสะกด เก็บ 이 | ไม่ปรับ | **생일이니까** |

#### ตัวอย่างจากตำรา

ตัวอย่างในตำราทุกประโยคมีเหตุผลอยู่หน้า และตามด้วยคำสั่งหรือชวนอยู่หลัง (-(으)세요 · -아/어요 แบบชวน) สังเกตว่า 읽었으니까 ใส่ -었- ได้

| 한국어 | ไทย | ที่มา |
|:---|:---|:---|
| 택시를 탈까요? → 출근 시간에는 길이 막히니까 지하철을 타세요. | นั่งแท็กซี่ดีไหม → ชั่วโมงเร่งด่วนรถติด ไปรถไฟใต้ดินเถอะ | ตัวอย่างบทสนทนา |
| 다음 주에 시험을 보니까 같이 공부해요. | สัปดาห์หน้ามีสอบ เรียนด้วยกันเถอะ | ตัวอย่างบทสนทนา |
| 제 생일이니까 꼭 오세요. | วันเกิดฉัน มาให้ได้นะ | ตัวอย่างบทสนทนา |
| 이 책은 읽었으니까 다른 책을 빌려 주세요. | เล่มนี้อ่านแล้ว ช่วยยืมเล่มอื่นให้หน่อย | ตัวอย่างบทสนทนา |
| 커피가 뜨거우니까 조심하세요. | กาแฟร้อน ระวังนะ | ตัวอย่างบทสนทนา |
| 중요한 서류니까 버리지 마세요. | เอกสารสำคัญ อย่าทิ้ง | ตัวอย่างบทสนทนา |

#### 연습 1 — เชื่อมเหตุผลกับข้อเสนอ

แบบฝึกนี้ให้ผันรากที่ตำราให้มาเป็น -(으)니까 แล้วต่อด้วยข้อเสนอ มี 보기 คือ 시간이 없으니까 택시를 타세요 *(ไม่มีเวลา ไปแท็กซี่เถอะ)* ซึ่งตรงกับข้อ 1 ของตำรา รวมเป็นโจทย์ 6 ข้อ คำตอบด้านล่างเป็นตัวอย่างผันตามกฎ (ตำราให้แค่ราก)

- 시간이 없다 / 택시를 타다 → 시간이 없으니까 택시를 타세요. *(ไม่มีเวลา ไปแท็กซี่เถอะ)*
- 점심에 약속이 있다 / 저녁에 만나다 → 점심에 약속이 있으니까 저녁에 만나요. *(มีนัดตอนเที่ยง เลยเจอกันตอนเย็น)*
- 친구가 기다리다 / 빨리 가다 → 친구가 기다리니까 빨리 가세요. *(เพื่อนรออยู่ รีบไปนะ)*
- 길을 모르다 / 길을 물어보다 → 길을 모르니까 길을 물어보세요. *(ไม่รู้ทาง ลองถามทางดู)*
- 우리 집이 멀다 / 기숙사에서 파티를 하다 → 우리 집이 머니까 기숙사에서 파티를 해요. *(บ้านฉันไกล เลยจัดปาร์ตี้ที่หอพัก)*
- 교실이 덥다 / 에어컨을 켜다 → 교실이 더우니까 에어컨을 켜세요. *(ห้องเรียนร้อน เปิดแอร์เถอะ)*

#### 연습 2 — จับคู่เหตุผลกับข้อเสนอ

แบบฝึกนี้ให้จับคู่เหตุผลกับข้อเสนอที่เข้ากัน แล้วรวมเป็นประโยคเดียวด้วย -(으)니까 มี 보기 คือ 비가 오니까 우산을 준비하세요 *(ฝนตก เตรียมร่มด้วย)* คู่ด้านล่างเป็นตัวอย่างจับคู่ตามความหมาย

- 내일 손님이 올 거예요 → 방을 청소하세요 *(พรุ่งนี้มีแขก → ทำความสะอาดห้อง)*
- 다리가 아파요 → 의자에 앉을까요? *(ขาเจ็บ → นั่งเก้าอี้ไหม)*
- 한국 노래를 알아요 → 한국 노래를 부르세요 *(รู้จักเพลงเกาหลี → ร้องเพลงเกาหลีสิ)*
- 감기에 걸렸어요 → 아이스크림을 먹지 마세요 *(เป็นหวัด → อย่ากินไอศกรีม)*
- 명동에 사람이 많아요 → 동대문시장으로 가요 *(เมียงดงคนเยอะ → ไปตลาดทงแดมุน)*

#### 연습 3 — คุยแผนของวันนี้

แบบฝึกนี้ให้ชวนเพื่อนทำอะไรสักอย่าง แล้วอีกฝ่ายเสนอสิ่งอื่นพร้อมเหตุผลด้วย -(으)니까 ตำราให้ตัวอย่างบทสนทนาและตัวเลือกสำหรับเปลี่ยนคำ

- 가: ___ 씨, 우리 등산을 할까요? *(…ไปปีนเขากันไหม)*
- 나: 비가 오니까 영화를 봐요. 어때요? *(ฝนตกเลยดูหนังกันเถอะ เป็นไง)*
- 가: 좋아요. *(ดีเลย)*

ตัวเลือกสำหรับเปลี่ยนคำ แบ่งเป็น 3 ช่อง ข้อความข้างล่างคัดตามที่พิมพ์ในตำรา (ท้ายแต่ละช่องตำรามีบรรทัดว่าง 2 บรรทัดให้เติมคำของตัวเอง):

- 뭘 할까요? *(ทำอะไรดี)*
  - 등산을 해요 *(ปีนเขา)* · 영화를 봐요 *(ดูหนัง)* · 도서관에 가요 *(ไปห้องสมุด)*
  - 게임을 해요 *(เล่นเกม)* · 따뜻한 차를 마셔요 *(ดื่มชาร้อน)* · 산책을 해요 *(เดินเล่น)*
- 저는 다른 것을 하고 싶어요 *(ฉันอยากทำอย่างอื่น)*
  - 집에서 TV를 봐요 *(ดูทีวีที่บ้าน)* · 영화를 봐요 *(ดูหนัง)* · 단어를 외워요 *(ท่องศัพท์)*
  - 놀이공원에 가요 *(ไปสวนสนุก)* · 쇼핑을 해요 *(ช้อปปิ้ง)* · 노래방에 가요 *(ไปคาราโอเกะ)*
- 왜요? *(ทำไม)*
  - 내일 시험이에요 *(พรุ่งนี้สอบ)* · 비가 와요 *(ฝนตก)* · 기분이 나쁘다 *(อารมณ์ไม่ดี)*
  - 눈이 와요 *(หิมะตก)* · 날씨가 좋아요 *(อากาศดี)* · 날씨가 더워요 *(อากาศร้อน)*

ตัวอย่างตอบอีกชุดที่เขียนเพิ่มตามโครงเดียวกัน (เลือก 뭘 할까요? = 산책을 해요, 다른 것 = 집에서 TV를 봐요, 왜요? = 눈이 와요):

- 가: 마키 씨, 우리 산책을 할까요? *(มากิ เราไปเดินเล่นกันไหม)*
- 나: 눈이 오니까 집에서 TV를 봐요. 어때요? *(หิมะตกเลยดูทีวีที่บ้านกันเถอะ เป็นไง)*
- 가: 좋아요. *(ดีเลย)*

#### -(으)니까 กับ -아/어서 ต่างกันอย่างไร

ตำราโยงกลับไปไวยากรณ์ข้อ 48 (บท 29) เพราะทั้งสองตัวแปลว่า "เพราะ" เหมือนกัน แต่ใช้แทนกันไม่ได้เสมอ ตารางนี้สรุปความต่างที่ต้องจำ

| จุดเทียบ | -아/어서 | -(으)니까 |
|:---|:---|:---|
| ประโยคหลังเป็นคำสั่ง/ชวน | ใช้ไม่ได้ | ใช้ได้ (우산을 준비하세요 · 같이 공부해요) |
| ใส่ -았/었- | ใส่ไม่ได้ | ใส่ได้ (읽었으니까) |
| ใช้เมื่อ | บอกข้อเท็จจริงที่เป็นเหตุผลโดยตรง (비가 와서 안 갔어요) | ต้องการบอก "เพราะเหตุผลนี้ ขอให้…" |

#### ⚠️ ระวัง

- ★ ราก ㄹ: 멀다 → **머니까** (멀으니까 ✗)
- 만들다 → 만드니까 (ตระกูลเดียวกับ 만들습니다 ✗ ที่เคยพลาด)
- ลืม **으** หลังตัวสะกด: 없으니까 ✓ · 없니까 ✗
- 읽으니까 ต้องมี 으 (ตระกูลเดียวกับ 읽세요 ✗ · 씻러 ✗)
- ㅂ: 덥다 → **더우니까** (덥으니까 ✗)

→ เจาะลึก: ไวยากรณ์ข้อ 50 (เล่ม 2)

### 💬 대화 30-1 — ถามทางไปธนาคาร

카오루 ถามคนที่เดินผ่านมาว่าแถวนี้มีธนาคารไหม ได้คำตอบว่าให้ไปทางซ้ายที่สี่แยกแล้วธนาคารอยู่ข้างไปรษณีย์ บทสนทนานี้มี (으)로 (왼쪽으로) และ -(으)니까 (문을 닫으니까 빨리 가세요) ในที่เดียว

> 카오루: 실례합니다. 이 근처에 은행이 있습니까? *(ขอโทษครับ แถวนี้มีธนาคารไหมครับ)*
>
> 지나가는 사람: 네. 저 사거리에서 왼쪽으로 가세요. 우체국 옆에 은행이 있어요. *(มีครับ ที่สี่แยกโน้นให้ไปทางซ้าย ธนาคารอยู่ข้างไปรษณีย์)*
>
> 카오루: 여기에서 은행까지 멉니까? *(จากที่นี่ไปธนาคารไกลไหมครับ)*
>
> 지나가는 사람: 아니요, 멀지 않아요. 그렇지만 4시에 문을 닫으니까 빨리 가세요. *(ไม่ไกลครับ แต่ 4 โมงปิด รีบไปนะครับ)*
>
> 카오루: 그래요? 감사합니다. *(อย่างนั้นเหรอ ขอบคุณครับ)*

#### สังเกตจากบทสนทนา

- ⚠️ **N에서 N까지** (여기에서 은행까지) จะเรียนต่อในบท 31 (ไวยากรณ์ข้อ 52)
- ⚠️ **우체국 옆에 은행이** — ผู้ถูกบอกตำแหน่งคือ 은행 จุดอ้างอิงคือ 우체국 (ไวยากรณ์ข้อ 05)
- 저 사거리에서 왼쪽으로 가세요 — บอกทางด้วยทิศ + (으)로 + -(으)세요
- 4시에 문을 닫으니까 빨리 가세요 — เหตุผล + -(으)니까 ตามด้วยคำสั่ง

#### คำถามเช็กความเข้าใจ

ตำราให้ตอบ 2 ข้อหลังบทสนทนา (확인해 봅시다) แต่ไม่พิมพ์เฉลย ข้างล่างคือตัวอย่างตอบ

- 카오루 씨는 어디에 가고 싶어요? → 은행 *(คาโอรุอยากไปไหน — ธนาคาร)*
- 거기에 어떻게 가요? → 저 사거리에서 왼쪽으로 가요. *(ไปยังไง — ที่สี่แยกโน้นไปทางซ้าย)*

#### 라 — เติมบทสนทนา (ตัวอย่างตอบ)

ตำราให้ทำบทอ่านเป็นบทสนทนา (읽은 내용을 대화로 만들어 봅시다) โดยพิมพ์กรอบบทสนทนาระหว่าง 압둘라 กับ 이리나 บางบรรทัดพิมพ์ไว้ให้แล้ว บางบรรทัดเว้นช่อง ＿＿＿ ไว้ให้เติมเอง บรรทัดที่มีช่องแสดงกรอบที่พิมพ์ แล้วตามด้วยคำตอบหลังลูกศร (→) ซึ่งเป็นตัวอย่างตอบ

- 압둘라: 이리나 씨, 주말 잘 보냈어요? *(อีรีนา สุดสัปดาห์เป็นไงบ้าง)*
- 이리나: 네, 아주 재미있었어요. *(ค่ะ สนุกมาก)*
- 압둘라: 뭐 했어요? *(ทำอะไรมา)*
- 이리나: ＿＿＿. → N서울타워에 갔어요. *(ไป N Seoul Tower)*
- 압둘라: 누구하고 ＿＿＿? → 누구하고 같이 갔어요? *(ไปกับใคร)*
- 이리나: ＿＿＿. → 친구들하고 같이 갔어요. *(ไปกับเพื่อน ๆ)*
- 압둘라: N서울타워에서 뭐 했어요? *(ทำอะไรที่ N Seoul Tower)*
- 이리나: ＿＿＿. → 전망대에서 서울 야경을 보고 식당에서 스파게티를 먹었어요. *(ชมวิวกลางคืนของโซลที่จุดชมวิวและกินสปาเกตตีที่ร้านอาหาร)*

> - ★ จุดอ้างอิงกลับด้าน: 우체국 **옆에** 은행이 있어요 = ธนาคารอยู่ข้างไปรษณีย์ (B5 ถูกครบ ไม่ได้เสีย)
> - -서 แทน -(으)니까 เมื่อประโยคหลังเป็นคำสั่ง ✗ · หลัง -(으)니까: 가세요 · 드세요 (드시세요 ✗)
> - ★ ㅈ/ㅊ และ ㅐ/ㅔ ในคำของบท: 출구 · 출근 · 주차장 · 경찰서 · 전망대 · 신호 · 건너다

### 🔗 เชื่อมโยง

← ต่อยอดจาก

- 9과 คำบอกตำแหน่ง 옆 · 앞 + 에 가다 (ไวยากรณ์ข้อ 05 → 우체국 옆에 은행)
- 12과 에/에서 (ไวยากรณ์ข้อ 09 → 에 จุดหมาย ↔ (으)로 ทิศทาง)
- 15과 -(으)시- / -(으)세요 (ไวยากรณ์ข้อ 20 → 가세요 / 올라가세요)
- 18과 -(으)러 가요 (ไวยากรณ์ข้อ 26)
- 22과 -(으)ㄹ까요? (ไวยากรณ์ข้อ 33 → 택시를 탈까요?)
- 29과 -아/어서 (ไวยากรณ์ข้อ 48 ↔ ข้อ 50)
- 23과 ㅂ 불규칙 (ไวยากรณ์ข้อ 37 → 더우니까)

→ ใช้ต่อใน

- 31과 (으)로 อีกความหมาย "พาหนะ/วิธี" (ไวยากรณ์ข้อ 51)
- 31과 N에서 N까지 (ไวยากรณ์ข้อ 52 — มีแล้วในบทสนทนา 30-1)
- 32과 갈아타세요 / 내리세요 (ไวยากรณ์ข้อ 53)
- 33과 -(으)면 เงื่อนไข (ไวยากรณ์ข้อ 55)
- 37과 -아/어 주세요 (ไวยากรณ์ข้อ 63 — ขอให้ทำ ต่อจากการสั่งในบทนี้)

> [!SUMMARY] สรุปท้ายบท
> - N-(으)로 บอกทิศทางที่ไป: ลงท้ายพยัญชนะ -으로 (오른쪽으로) ลงท้ายสระหรือ ㄹ -로 (교실로 · 서울로) ใช้คู่กับกริยาเคลื่อนที่ เช่น 가다 และ 올라가다
> - 에 บอกจุดหมาย (우체국에 가요) ส่วน (으)로 บอกทิศทางหรือช่องทาง (우체국으로 가요) และตอบ "어떻게 가요?" ด้วยทิศ + (으)로
> - -(으)니까: มีตัวสะกด -으니까 · ไม่มีตัวสะกดหรือ ㄹ -니까 (머니까) · ㅂ 불규칙 → 우 (더우니까) · นาม N이니까 / N니까
> - -(으)니까 ต่อด้วยคำสั่ง/ชวนได้และใส่ -았/었- ได้ ส่วน -아/어서 ทำไม่ได้ทั้งสองอย่าง
> - ข้อผิดที่ต้องระวัง: ลืม 으 (읽세요 · 없니까) เติม 으 ให้ ㄹ (멀으니까 · 서울으로) และ ㅂ ไม่เปลี่ยน (덥으니까) รวมทั้งจุดอ้างอิงตำแหน่งกลับด้านกับ ㅈ/ㅊ ใน 주차장
