# ส่วนที่ 6 · ตารางสรุปไวยากรณ์ 64 หัวข้อ (ฉบับย่อ)

ส่วนนี้เป็นตารางสรุปไวยากรณ์ทั้ง 64 ข้อในฉบับย่อ ไว้กวาดตาทบทวนรอบสุดท้ายก่อนเข้าห้องสอบ เนื้อหาเต็มของแต่ละข้ออยู่ในส่วนที่ 1 ข้อเดียวกัน และตารางที่เรียงตามบทอยู่ในส่วนที่ 0 ส่วนนี้เรียงตามเลขข้อ แบ่งเป็น 7 กลุ่ม

ในแต่ละข้อจะมีบรรทัด "ใช้เมื่อ…" บอกว่าเรื่องนี้ใช้ตอนไหน ตามด้วยตารางรูปและตัวอย่าง และปิดท้ายด้วยเครื่องหมาย ⚠️ ที่รวมกับดักซึ่งผู้เรียนมักพลาด ถ้าข้อไหนยังไม่แน่ใจ ให้เปิดดูข้อเดียวกันในส่วนที่ 1

## ข้อ 01–09 · ประโยคพื้นฐาน · ตัวเลข · ผันกริยา · สถานที่ (5–12과)

> [!INTRO] กลุ่มนี้ครอบคลุมอะไร
> ข้อ 01 ถึง 09 เป็นพื้นฐานของบท 5–12 ได้แก่ คำช่วยหัวเรื่องและประธาน, 이다, คำชี้ 이/그/저, เลข 2 ระบบ, คำบอกตำแหน่ง, การผันเป็น -아/어/여요, คำช่วยกรรม, การปฏิเสธด้วย 안 และการแยก 에 กับ 에서 สิ่งที่ต้องดูทุกครั้งคือเงื่อนไขตัวสะกดและรูปผิดที่มีเครื่องหมาย ✗ กำกับในแต่ละข้อ

### 01. 은/는 vs 이/가 `[Unit 5·6]` — ชี้หัวเรื่อง vs ชี้ประธาน

ใช้เมื่อต้องเลือกคำช่วยหลังคำนามว่าจะชี้เป็นหัวเรื่อง (은/는) หรือชี้เป็นประธาน (이/가) แล้วเลือกรูปตามตัวสะกด

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| มีตัวสะกด → **은 / 이** (ดูพยางค์สุดท้าย) | 선생님**은** *(ครู)* · 책**이** *(หนังสือ)* |
| ไม่มีตัวสะกด → **는 / 가** (씨 → 는/가 เสมอ) | 저**는** *(ฉัน)* · 의자**가** *(เก้าอี้)* |
| **은/는** = หัวเรื่อง "ส่วน…น่ะ" ใช้ตอนแนะนำตัว เปรียบเทียบ และพูดต่อ | 저**는** 장핑입니다. *({n:ฉัน}{e:ชื่อ}{n:จางผิง})* |
| **이/가** = ตอบ 누가/뭐가 บอกของใหม่ และใช้กับ 있다/없다 และ 아니에요 | 누가 의사입니까? → 왕쯔이 씨**가** 의사입니다. *(ใครเป็นหมอ → คุณหวางจื่ออี)* |
| รูปหด: 저 → **제가** · 나 → **내가** · 누구 → **누가** | **제가** 선생님입니다. *({n:ฉัน}{p:เอง}{e:เป็น}{n:ครู})* |

⚠️ ตอบ 누가/뭐가 ต้องใช้ 이/가: 마키 씨**는** ✗ → 마키 씨**가** ✓ (และ 저가 ✗ → 제가)

### 02. 이다/아니다 `[Unit 5·7]` — "เป็น/คือ" และ "ไม่ใช่"

ใช้เมื่อจะบอกว่า A เป็น B หรือไม่ใช่ B โดยเลือกรูปทางการ (입니다) หรือรูปสุภาพ (이에요/예요) และรูปปฏิเสธตามตัวสะกด

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ทางการ บอกเล่า: N**입니다** (ไม่ดูตัวสะกด) | 저는 학생**입니다**. *(ฉันเป็นนักเรียน)* |
| ทางการ ถาม: N**입니까?** (ไม่ดูตัวสะกด) | 중국 사람**입니까?** *(เป็นคนจีนไหม)* |
| สุภาพ: 받침 ○ → N**이에요** | 책**이에요** *(เป็นหนังสือ)* |
| สุภาพ: 받침 ✗ → N**예요** | 의사**예요** *(เป็นหมอ)* · 전화**예요** *(เป็นโทรศัพท์)* |
| ปฏิเสธ: 받침 ○ → N**이 아니에요** (เว้นวรรคก่อน 아니에요) | 사전**이 아니에요** *(ไม่ใช่พจนานุกรม)* |
| ปฏิเสธ: 받침 ✗ → N**가 아니에요** (เว้นวรรคก่อน 아니에요) | 카메라**가 아니에요** *(ไม่ใช่กล้อง)* |
| "ติด" = 이에요 และ "แยก" = 이/가 + 있어요 | 학생**이에요** *(เป็นนักเรียน)* ≠ 학생**이 있어요** *(มีนักเรียน)* |

⚠️ หน้า 아니에요 ต้องมี 이/가 เสมอ (✗ 학생 아니에요) แต่หน้า 이에요/예요 ห้ามมี (✗ 학생이 이에요)

### 03. 이/그/저 `[Unit 6]` — นี่ · นั่น · โน่น

ใช้เมื่อจะชี้บอกสิ่งของหรือคนว่าอยู่ใกล้ผู้พูด ใกล้ผู้ฟัง หรือไกลทั้งคู่ และเมื่อจะบอกว่าสิ่งนั้นเป็นของใคร

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| **이** ใกล้ผู้พูด, **그** ใกล้ผู้ฟัง, **저** ไกลทั้งคู่ | 이것 *(สิ่งนี้)* · 그것 *(สิ่งนั้น)* · 저것 *(สิ่งโน้น)* |
| 이/그/저 + **นาม** (ต้องมีนามตามหลัง) | 이 사람 *(คนนี้)* · 그 책 *(หนังสือเล่มนั้น)* · 저 의자 *(เก้าอี้ตัวโน้น)* |
| 이것/그것/저것 ต่อ 조사 ได้ | 이것이 무엇입니까? *(นี่คืออะไร)* |
| พูดย่อ 이게 · 그게 · 저게 | 이게 뭐예요? *(นี่คืออะไร)* |
| ของใคร: นาม + นาม (ไม่มีคำว่า "ของ") | 누구 지갑입니까? → 마키 씨 지갑입니다. *(กระเป๋าสตางค์ของใคร → ของคุณมากิ)* |

⚠️ 이것 + นามไม่ได้ (✗ 이것 책 → 이 책) · เสียงอ่าน [이거시] แต่ต้องเขียน 이것이

### 04. ตัวเลข 2 ระบบ + ลักษณนาม `[Unit 8·10]` — เลขจีน vs เลขแท้

ใช้เมื่อต้องเลือกว่าจะอ่านตัวเลขด้วยเลขจีน (ชั้น ห้อง เบอร์ ราคา) หรือเลขแท้ (นับของ คน สัตว์ อายุ) และเลือกลักษณนามให้ถูก

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| **เลขจีน** (일 이 삼…) ใช้กับชั้น ห้อง และเบอร์ (0 = 공) | 5층 = 오 층 *({m:ชั้น} {m:5})* · 203호 = 이백삼 호 *({m:ห้อง} {m:203})* · 010 = 공일공 *(เลข 010)* |
| **เลขจีน** ใช้กับราคา วันที่ และนาที | 천 원 *({m:1,000 วอน})* |
| **เลขแท้** (하나 둘 셋…) + ลักษณนาม ใช้นับของ คน สัตว์ และอายุ | 사과 한 개 *(แอปเปิล 1 ผล)* · 학생 열두 명 *(นักเรียน 12 คน)* · 스물두 살 *(22 ปี)* |
| **한 · 두 · 세** หน้าลักษณนาม | 한 개 *(1 ชิ้น)* · 두 명 *(2 คน)* · 세 권 *(3 เล่ม)* |
| **네 · 스무** หน้าลักษณนาม (เลข 11–14 ใช้รูปย่อ 열한, 열두, 열세, 열네) | 네 병 *(4 ขวด)* · 스무 잔 *(20 แก้ว)* |
| ลักษณนาม: 개 명 마리 권 병 잔 장 (자루) และราคาต่อหน่วย = จำนวน + ลักษณนาม + **에** | 빵 한 개**에** 칠백 원이에요. *(ขนมปังชิ้นละ 700 วอน)* |

⚠️ ห้ามปนเลข 2 ชุด: จำนวนใช้เลขแท้ ราคาใช้เลขจีน — 세 개에 삼천 원 (✗ 삼 개 · ✗ 셋천 원)

### 05. 위치 명사 + 에 있어요/없어요 `[Unit 8·9]` — อยู่ที่ไหน · มีอะไร

ใช้เมื่อจะบอกว่าของหรือคนอยู่ตรงไหนด้วยคำบอกตำแหน่ง 7 คำ คือ 위 บน, 아래(밑) ล่าง, 앞 หน้า, 뒤 หลัง, 옆 ข้าง, 안 ใน และ 밖 นอก หรือถามว่าตรงนั้นมีอะไรอยู่

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| นามอ้างอิง + 위치 명사 + **에** | 책상 위**에** *(บนโต๊ะ)* · 가방 안**에** *(ในกระเป๋า)* |
| ของ**이/가** + ที่**에** + 있어요/없어요 | 연필이 책 옆에 있어요. *(ดินสออยู่ข้างหนังสือ)* |
| สลับที่ได้: ที่**에** + ของ**이/가** + 있어요 | 책 옆에 연필이 있어요. *(ข้างหนังสือมีดินสออยู่)* |
| ถาม 어디에 (อยู่ที่ไหน) → ตอบตำแหน่ง · ถาม 뭐가 (มีอะไร) → ตอบสิ่งของ | 책상 위에 뭐가 있어요? → 필통이 있어요. *(บนโต๊ะมีอะไร → กล่องดินสอ)* |

⚠️ นามอ้างอิงมาก่อน 위치 명사 (책상 위 ✓ · 위 책상 ✗) · 안 (ใน) ≠ 안 (ไม่)

### 06. -아/어/여요 `[Unit 11]` — ผันกริยา/คุณศัพท์แบบสุภาพ

ใช้เมื่อจะพูดประโยคบอกเล่า ถาม หรือชวนแบบสุภาพในชีวิตประจำวัน โดยผันกริยาหรือคำคุณศัพท์ตามสระของพยางค์สุดท้ายของราก

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ตัด 다 แล้วสระท้ายราก **ㅏ/ㅗ** → **아요** | 가다 → **가요** *(ไป)* · 앉다 → **앉아요** *(นั่ง)* · 보다 → **봐요** *(ดู)* |
| สระท้ายรากเป็นสระอื่น → **어요** | 먹다 → **먹어요** *(กิน)* · 마시다 → **마셔요** *(ดื่ม)* |
| ลงท้าย **하다** → **해요** | 공부하다 → **공부해요** *(เรียน)* · 일하다 → **일해요** *(ทำงาน)* |
| ลงท้าย **ㅡ** → ตัด ㅡ แล้วดูสระพยางค์หน้า | 쓰다 → **써요** *(เขียน)* · 아프다 → **아파요** *({v:เจ็บ})* · 예쁘다 → **예뻐요** *(สวย)* |
| ควบสระ: ㅗ+ㅏ=ㅘ · ㅜ+ㅓ=ㅝ · ㅣ+ㅓ=ㅕ (쉬다 → 쉬어요 ไม่ควบ) | 오다 → **와요** *(มา)* · 주다 → **줘요** *(ให้)* · 가르치다 → **가르쳐요** *(สอน)* |

⚠️ ดู*สระ*ของพยางค์สุดท้ายของราก (ตัวสะกดไม่นับ): 받다 → 받**아**요 (✗ 받어요) · 살다 → 살**아**요 (✗ 살어요)

### 07. 을/를 `[Unit 11]` — ชี้กรรม

ใช้เมื่อจะบอกว่าคำนามใดเป็นกรรมของกริยา คือสิ่งที่ถูกอ่าน กิน พบ หรือดื่ม โดยเลือก 을 หรือ 를 ตามตัวสะกด

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| 받침 ○ → **을** | 책**을** 읽어요 *(อ่านหนังสือ)* · 밥**을** 먹어요 *(กินข้าว)* |
| 받침 ✗ → **를** | 친구**를** 만나요 *(พบเพื่อน)* · 커피**를** 마셔요 *(ดื่มกาแฟ)* |
| ประธาน이/가 + กรรม**을/를** + กริยา-아/어/여요 (กริยาอยู่ท้ายสุด) | 친구가 신문**을** 봐요. *(เพื่อนดูหนังสือพิมพ์)* |
| คำนามหน้า 하다 ก็ติด 을/를 (ภาษาพูดละได้) | 숙제**를** 해요 *(ทำการบ้าน)* · 운동**을** 해요 *(ออกกำลังกาย)* |

⚠️ กรรมต้องเข้ากับกริยา และ ไป/มา/มี/เป็น ไม่ใช้ 을/를: ✗ 학생을 공부해요 · ✗ 학교를 가요 (→ 학교**에** 가요)

### 08. 안 `[Unit 12]` — ปฏิเสธ "ไม่…" วางหน้ากริยา/คุณศัพท์

ใช้เมื่อจะปฏิเสธในภาษาพูดว่า "ไม่…" โดยวาง 안 ไว้หน้ากริยาหรือคำคุณศัพท์ ส่วนกริยาแบบ N + 하다 ให้ 안 แทรกกลาง

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| **안** + กริยา/คุณศัพท์ (ภาษาพูด เว้นวรรคหลัง 안) | 안 가요 *({x:ไม่}{v:ไป})* · 안 마셔요 *({x:ไม่}{v:ดื่ม})* · 날씨가 안 좋아요 *({n:อากาศ}{x:ไม่}{v:ดี})* |
| กรรม을/를 + **안** + กริยา (안 อยู่ติดกริยา) | 커피를 **안** 마셔요. *(ไม่ดื่มกาแฟ)* |
| N + 하다 → N **안** 해요 (안 แทรกกลาง) | 공부 **안** 해요 *(ไม่เรียน)* · 운동 **안** 해요 *(ไม่ออกกำลังกาย)* |

⚠️ ระวัง

- ✗ 안 공부해요 → ✓ 공부 안 해요
- ✗ 안 아르바이트 해요 → ✓ 아르바이트 안 해요 (★ เสียคะแนนมาแล้ว)
- 이다 → 아니에요 และ 있다 → 없어요 ไม่ใช้ 안

### 09. 에 vs 에서 `[Unit 9·12]` — ไปที่/อยู่ที่ vs ทำที่

ใช้เมื่อต้องเลือกว่าสถานที่นั้นเป็นจุดหมายหรือที่ตั้ง (에) หรือเป็นที่ที่ทำกิจกรรม (에서)

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| **에** + 있다/없다/가다/오다 → ที่ตั้ง / จุดหมาย | 학교**에** 가요 *(ไปโรงเรียน)* · 집**에** 있어요 *(อยู่บ้าน)* |
| **에서** + กริยาการกระทำ (กิน ซื้อ เรียน ทำงาน พบ) → ทำที่… | 학교**에서** 공부해요 *(เรียนที่โรงเรียน)* · 식당**에서** 밥을 먹어요 *(กินข้าวที่โรงอาหาร)* |
| ถามจุดหมาย: 어디**에** 가요? | 도서관에 가요 *(ไปห้องสมุด)* |
| ถามที่ตั้ง: 어디**에** 있어요? | 학생회관 옆에 있어요 *(อยู่ข้างตึกนักศึกษา)* |
| ถามที่ทำกิจกรรม: 어디**에서** …? | 백화점에서 옷을 사요 *(ซื้อเสื้อที่ห้าง)* |

⚠️ ✗ 백화점에 샀어요 → 백화점**에서** 샀어요 · ✗ 학생식당하고 가요 → 학생식당**에** 가요 (★ เสีย 4 คะแนน)

### 10. 시간 + 에 `[Unit 13]` — ตอน… / ในวัน… (คำบอกเวลา + 에)

ใช้เมื่อจะบอกว่าทำอะไรตอนไหนหรือวันไหน โดยคำบอกเวลาบางคำต้องตามด้วย 에 และบางคำห้ามใส่ 에

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ช่วงของวัน, วัน, วันที่, 작년, 내년, 이번 주, 방학 และ 생일 + **에** (ไม่เปลี่ยนตามตัวสะกด) | 토요일**에** 친구를 만나요 *(วันเสาร์พบเพื่อน)* · 내년**에** 가요 *({n:ปีหน้า}{v:ไป})* |
| 어제, 오늘, 내일, 그저께, 모레, 지금, 매일, 올해 และ 언제 → **ไม่ใส่ 에** | 오늘 영화관에 가요 *(วันนี้ไปโรงหนัง)* |
| ถาม **언제** (ไม่มี 에) → ตอบ เวลา + 에 | 언제 가요? — 아침**에** 가요 *({v:ไป}เมื่อไร — {p:ตอน}{n:เช้า})* |
| 6월 = **유월** · 10월 = **시월** · 6일 = **육 일** | 유월 육 일 *({m:6} {m:มิ.ย.})* · 시월 십 일 *({m:10} {m:ต.ค.})* |

⚠️ ลืม 에 หลัง 아침 / 오전 / 일요일 หรือใส่เกินหลัง 오늘 / 내일 / 지금 — และ 10월 อ่าน 시월 (✗ 십월 เสีย 4 คะแนนใน 복습시험 ①)

### 11. 하고 `[Unit 13]` — และ / กับ (เชื่อมคำนาม)

ใช้เมื่อจะเชื่อมคำนามกับคำนามว่า "และ" หรือบอกว่าทำสิ่งใดร่วมกับใคร (กับ)

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| N + **하고** + N = "และ" (ไม่เปลี่ยนตามตัวสะกด) | 사과**하고** 배가 있어요 *(มีแอปเปิ้ลกับสาลี่)* |
| คำช่วยของประโยคใส่ **ท้ายสุดตัวเดียว** | 병원하고 도서관**에** 가요 *(ไปโรงพยาบาลกับห้องสมุด)* |
| N하고 **같이** + กริยา = "กับ" (ผู้ร่วมทำ) | 친구하고 같이 인사동에 가요 *(ไปอินซาดงกับเพื่อน)* |

⚠️ เชื่อมได้แค่คำนาม — "ไปที่…" ใช้ 에 (✗ 학생식당하고 가요 → 학생식당에 가요) และเชื่อมประโยคใช้ 그리고

### 12. โครงสร้างประโยค `[Unit 13]` — เวลา – ประธาน – สถานที่ – กรรม – กริยา

ใช้เมื่อจะเรียงองค์ประกอบของประโยคให้ถูกลำดับ คือ เวลา ประธาน สถานที่ กรรม และกริยาที่อยู่ท้ายสุดเสมอ

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ลำดับ: N**에** → N**이/가** หรือ **은/는** → N**에서** → N**을/를** → V-아/어요 (ตัดช่องที่ไม่ต้องการได้ แต่ไม่สลับที่) | 저녁**에** 집**에서** 컴퓨터**를** 해요 *({p:ตอน}{n:เย็น}{v:ใช้}{n:คอม}{p:ที่}{n:บ้าน})* |
| ย้ายประธานไปหน้าสุดก็ได้ | 저는 주말에 도서관에서 책을 읽어요 *(ฉันอ่านหนังสือที่ห้องสมุดวันสุดสัปดาห์)* |
| 있다 / 가다 → N**에** และกริยากิจกรรม → N**에서** + N**을/를** (안 ติดหน้ากริยา) | 책상 위에 컴퓨터가 있어요 *(มีคอมพิวเตอร์อยู่บนโต๊ะ)* · 주말에 학교에 **안** 가요 *(วันสุดสัปดาห์ไม่ไปโรงเรียน)* |

⚠️ กริยาต้องอยู่ท้ายสุด และคำช่วยต้องเข้าคู่กับกริยา (✗ 학교에서 가요 · ✗ 안 공부해요 → 공부 안 해요)

### 13. 띄어쓰기 `[ทุกบท]` — เว้นวรรคตรงไหน ติดตรงไหน

ใช้เมื่อเขียนประโยคแล้วไม่แน่ใจว่าตรงไหนต้องเขียนติดกันและตรงไหนต้องเว้นวรรค

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| 조사 → **ติด** คำนามเสมอ | 학교**에서** *(ที่โรงเรียน)* · 저**도** *(ฉันก็)* |
| 이다 → **ติด** คำนามเสมอ | 학생**이에요** *(เป็นนักเรียน)* · 사과**예요** *(เป็นแอปเปิล)* |
| **안** → **เว้น** | **안** 가요 *(ไม่ไป)* |
| **시 · 분 · 반** → **เว้น** | 두 **시** 이십 **분** *(สองโมงยี่สิบนาที)* |
| **씨 · 같이 · 거예요** → **เว้น** | 마키 **씨** *(คุณมากิ)* · 갈 **거예요** *(จะไป)* |
| 아니에요 / 있어요 / 없어요 → เว้นหลัง 이/가 | 학생**이 아니에요** *(ไม่ใช่นักเรียน)* · 지갑**이 없어요** *(ไม่มีกระเป๋าสตางค์)* |
| ตัวเลข + ลักษณนาม → เว้น | 사과 **세 개** *(แอปเปิล 3 ผล)* |
| 부터 / 까지 → ติดคำหน้า | 한 시**부터** 두 시**까지** *(ตั้งแต่ 1 โมงถึง 2 โมง)* |

⚠️ 두시 이십분 ✗ → 두 시 이십 분 · 갈거예요 ✗ → 갈 거예요 · 청소 했어요 ✗ → 청소했어요 (N+하다 เป็นคำเดียว)

### 14. Collocations · คำที่สับสน `[ทุกบท]` — คู่คำที่ต้องจำ

ใช้เมื่อกริยาที่แปลเป็นไทยตรง ๆ แล้วใช้ 하다 ไม่ได้ จึงต้องจำคู่คำที่เกาหลีใช้ตายตัว และเมื่อต้องแยกคำที่หน้าตาใกล้กัน

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| คู่คำตายตัว (ใช้ 하다 แทนไม่ได้) | 춤**을 추다** *(เต้นรำ)* · 사진**을 찍다** *(ถ่ายรูป)* · 돈**을 찾다** *(ถอนเงิน)* |
| คู่คำตายตัวอื่น ๆ (ใช้ 하다 แทนไม่ได้) | 담배**를 피우다** *(สูบบุหรี่)* · 버스**를 타다** *(ขึ้นรถเมล์)* |
| 아니요 = "ไม่" (ต้นประโยค) และ 아니에요 = "ไม่ใช่" (ท้ายประโยค) | **아니요**, 지갑**이 아니에요** *(ไม่ ไม่ใช่กระเป๋าสตางค์)* |
| 뭐 + 예요 และ 무엇 + 이에요 / 입니까 | 이름이 **뭐예요**? *(ชื่ออะไร)* · 직업이 **무엇입니까**? *(อาชีพอะไรครับ)* |
| 줘요 = ให้ · 받아요 = ได้รับ · 주세요 = ขอ | 선물을 **줘요** *(ให้ของขวัญ)* · 선물을 **받아요** *(ได้รับของขวัญ)* · 빵 세 개 **주세요** *(ขอขนมปัง 3 ชิ้น)* |

⚠️ แปลไทยตรง ๆ แล้วใช้ 하다 ผิด (✗ 춤을 해요 · ✗ 사진을 해요) และ 줘요 (บรรยาย) ≠ 주세요 (ขอ)

### 15. 주어 생략 `[ทุกบท]` — ละประธาน + 이/가 หลายตัว

ใช้เมื่อประธานรู้กันอยู่แล้วจึงละได้ และเมื่อต้องตอบคำถามที่ถามหาประธาน หรือเจอ 이/가 หลายตัวในประโยคเดียว

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รู้เรื่องกันอยู่แล้ว → ตัดประธานพร้อมคำชี้ทิ้งทั้งก้อน | 가: 연필이 어디에 있어요? 나: 책 옆에 있어요 *(ดินสออยู่ไหน — {v:อยู่}{p:ข้าง}{n:หนังสือ})* |
| 읽기 → 대화 ใน 복습시험: ตอบ = ประโยคในข้อความ ตัดประธาน | 가: 주말에 무엇을 해요? 나: 친구를 만나요 *(สุดสัปดาห์ทำอะไร — {v:พบ}{n:เพื่อน})* |
| ตอบคำถามที่ถามหาประธาน (누가 / 뭐가) → ต้องมีประธาน + 이/가 | 누가 의사입니까? — 왕쯔이 씨**가** 의사입니다 *(ใครเป็นหมอ — คุณหวางจื่ออีเป็นหมอ)* |
| 이/가 หลายตัวได้ (ผู้กระทำ · มี/ไม่มี · ไม่ใช่) | 저**는** 돈**이** 없어요 *(ฉันน่ะ ไม่มีเงิน)* |

⚠️ คำนาม 1 ตัวมีได้หน้าที่เดียว — ✗ 책이을 읽어요 · 영화가를 봐요 (ซ้อน 이/가 กับ 을/를 ไม่ได้)

### 16. -지 않다 `[Unit 14]` — ไม่… (= 안 แต่ต่อท้ายราก)

ใช้เมื่อจะปฏิเสธว่า "ไม่…" โดยต่อ -지 않다 ท้ายราก ความหมายเหมือน 안 และใช้ได้กับทั้งกริยาและคำคุณศัพท์

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ราก (ตัด 다) + **-지 않아요** (ไม่แยกตามตัวสะกด) | 마시**지 않아요** *(ไม่ดื่ม)* · 먹**지 않아요** *(ไม่กิน)* |
| 하다 กริยา / คุณศัพท์ → เขียนติดกัน | 공부하**지 않아요** *(ไม่เรียน)* · 친절하**지 않아요** *(ไม่ใจดี)* |
| คำคุณศัพท์ | 비싸**지 않아요** *({x:ไม่}{v:แพง})* · 좋**지 않아요** *({x:ไม่}{v:ดี})* |
| อดีต = 않 + 았 | 가지 **않았**어요 *({x:ไม่ได้}{v:ไป})* |

⚠️ ใช้กับ 이다 / 있다 ไม่ได้ → 이/가 아니에요 · 없어요 (✗ 학생이지 않아요)

### 17. 도 `[Unit 14]` — …ก็ / …ด้วย

ใช้เมื่อจะบอกว่า "…ก็เหมือนกัน" หรือ "…ด้วย" โดยเอา 도 ไปแทนที่คำช่วยเดิม

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| N + **도** (ไม่เปลี่ยนตามตัวสะกด) | 저**도** 학생이에요 *(ฉันก็เป็นนักเรียน)* |
| **แทนที่** 이/가 · 은/는 · 을/를 | 빵을 먹어요. 사과**도** 먹어요 *(กินขนมปัง กินแอปเปิ้ลด้วย)* |
| **ซ้อนท้าย** 에 · 에서 · 에게 | 학교**에도** 가요 *(ไปโรงเรียนด้วย)* · 집**에서도** 공부해요 *(เรียนที่บ้านด้วย)* |
| ประโยคปฏิเสธ → 도 + 안 | 저**도** 안 가요 *(ฉันก็ไม่ไป)* |

⚠️ ✗ 씨가도 · 씨를도 · 저는도 (도 ต้องแทนที่) และถามด้วย 도 แล้วตอบ "ไม่" → เปลี่ยนเป็น 은/는

### 18. 형용사 `[Unit 14]` — คำคุณศัพท์ ผันเหมือนกริยา

ใช้เมื่อจะบอกลักษณะหรือสภาพของสิ่งต่าง ๆ ด้วยคำคุณศัพท์ ซึ่งผันเป็นรูปสุภาพได้เหมือนกริยาแต่ไม่มีกรรม

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| N**이/가** + A-아/어요 (ไม่มีกรรม ไม่มี 이에요) | 날씨**가** 좋아요 *(อากาศดี)* |
| ราก ㅏ หรือ ㅗ → 아요, อื่น → 어요, 하다 → 해요 | 작아요 *(เล็ก)* · 길어요 *(ยาว)* · 친절해요 *(ใจดี)* |
| ราก ㅡ → ตัด ㅡ แล้วดูสระพยางค์หน้า | 크다→**커요** *(ใหญ่)* · 예쁘다→**예뻐요** *(สวย)* |
| ราก ㅡ ที่สระพยางค์หน้าเป็น ㅏ → 아 | 바쁘다→**바빠요** *(ยุ่ง)* · 나쁘다→**나빠요** *(แย่)* |
| 어떻다 → ท่องรูปเดียว | **어때요?** *(เป็นอย่างไร)* · **어땠어요?** *({q:เป็นอย่างไร}{e:มา})* |

⚠️ ✗ 날씨를 좋아요 (คุณศัพท์ไม่มีกรรม 을/를) · ✗ 비싸이에요 · ✗ 어떻어요 → 어때요

### 19. 와/과 `[Unit 15]` — "และ / กับ" เชื่อมคำนามกับคำนาม (สุภาพ · แบบเขียน)

ใช้เมื่อจะเชื่อมคำนามกับคำนามว่า "และ" หรือ "กับ" ในแบบสุภาพและภาษาเขียน โดยเลือก 와 หรือ 과 ตามตัวสะกดของคำนามตัวหน้า

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| พยางค์ท้ายของคำนามตัวหน้า **ไม่มีตัวสะกด** → **와** | 우유**와** 빵 *(นมกับขนมปัง)* · 압둘라**와** 왕쯔이 *(อับดุลลากับหวางจื่ออี)* |
| พยางค์ท้ายของคำนามตัวหน้า **มีตัวสะกด** (รวม ㅇ ㅁ ㄴ ㄹ) → **과** | 책상**과** 의자 *(โต๊ะกับเก้าอี้)* · 선생님**과** 학생 *(ครูกับนักเรียน)* |
| เชื่อมได้หลายคำ แต่ไม่ใส่หลังคำสุดท้าย และคำช่วยประโยคอยู่ท้าย N2 | 언니**와** 오빠가 있어요 *(มีพี่สาวกับพี่ชาย)* |

⚠️ ✗ 선생님와 → ✓ 선생님과 (ㅁ คือตัวสะกด) · เชื่อมได้แค่ **คำนาม** (เชื่อมประโยคใช้ -고) · ✗ 빵과 우유와 있어요

### 20. -(으)시- · -(으)세요 `[Unit 15]` — ยกย่องผู้ใหญ่ที่เป็นประธาน

ใช้เมื่อประธานของประโยคเป็นผู้ใหญ่ที่ต้องให้เกียรติ จึงใส่ -(으)시- เข้าไปที่กริยา เช่น -(으)세요

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากไม่มีตัวสะกด → **-세요** · มีตัวสะกด → **-으세요** · 하다 → **-하세요** | 가**세요** *(ไป)* · 읽**으세요** *(อ่าน)* · 일하**세요** *(ทำงาน)* |
| N+이다: ไม่มีตัวสะกด → N**세요** · มีตัวสะกด → N**이세요** | 아버지**세요** *(เป็นคุณพ่อ)* · 선생님**이세요** *(เป็นอาจารย์)* |
| คำพิเศษ: 있다 (คนอยู่) → **계시다** (ไม่อยู่ **안 계세요**) | 부모님이 **계세요** *(คุณพ่อคุณแม่อยู่)* |
| คำพิเศษ: 먹다 และ 마시다 → **드시다** | 과일을 **드세요** *(ทานผลไม้)* |
| คำพิเศษ: 자다 → **주무시다** | 할머니가 **주무세요** *(คุณยายนอน)* |
| คำพิเศษ: 말하다 → **말씀하시다** | — |
| คำนามเคารพ: 이름 → **성함**, 나이 → **연세**, 말 → **말씀**, 사람 → **분** | — |
| "มี" (เป็นเจ้าของ) ใช้ **있으세요 / 없으세요** ไม่ใช่ 계세요 | 할머니가 돈이 **있으세요** *(คุณยายมีเงิน)* |
| รูปทางการ → **-(으)십니다** | 가**십니다** *(ท่านไป)* |

⚠️ ใส่เฉพาะผู้ใหญ่ที่เป็นประธาน ✗ 제가 가세요 · ✗ 요리가 맛있으세요 (ของไม่ใส่ 시) · ลืม 으: ✗ 읽세요 → ✓ 읽으세요

### 21. -(스)ㅂ니다 · -(스)ㅂ니까? `[Unit 16]` — ท้ายประโยคแบบทางการ (ประชุม ข่าว แนะนำตัว ภาษาเขียน)

ใช้เมื่อต้องพูดหรือเขียนแบบทางการ เช่น ในการประชุม ข่าว การแนะนำตัว และภาษาเขียน โดยเลือก ㅂ니다 หรือ 습니다 ตามตัวสะกดของราก

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากไม่มีตัวสะกด → **-ㅂ니다 / -ㅂ니까?** | 갑니다 *(ไป)* · 마십니다 *(ดื่ม)* |
| รากมีตัวสะกด → **-습니다 / -습니까?** | 먹습니다 *(กิน)* · 읽습니까? *(อ่านไหม)* |
| N+이다 → **입니다 / 입니까?** · 아니다 → **아닙니다** · -지 않다 → **-지 않습니다** | 학생입니다 *(เป็นนักเรียน)* · 학생이 아닙니다 *(ไม่ใช่นักเรียน)* · 가지 않습니다 *(ไม่ไป)* |
| ผู้ใหญ่ → **-(으)십니다 / -(으)십니까?** (N+이다 → **N(이)십니다**) | 읽으십니다 *(ท่านอ่าน)* · 선생님이십니다 *(เป็นอาจารย์)* |
| อดีต → **-았/었/였습니다** และ 겠 → **-겠습니다** | 갔습니다 *(ไปแล้ว)* · 마시겠습니다 *(จะดื่ม)* |
| ถามด้วย ㅂ니까 ตอบด้วย ㅂ니다 (ตอบเรื่องตัวเองไม่ใส่ 시) | 배우십니까? — 네, 배웁니다 *(เรียนไหมครับ — {a:ครับ} {v:เรียน})* |

⚠️ ✗ 마시다 → 맙니다 (ห้ามตัดราก → ✓ 마십니다) · ✗ 갑니다? (คำถามต้องจบ ㅂ니까) · ราก ㄹ ตัด ㄹ: 살다 → 삽니다 (เสริม ไม่อยู่ในตำรา)

### 22. -겠- `[Unit 16]` — ความตั้งใจของผู้พูด "จะ…" (อาสา · สั่งอาหาร · ถามความตั้งใจผู้ฟัง)

ใช้เมื่อผู้พูดจะบอกความตั้งใจของตัวเองว่า "จะ…" เช่น อาสาทำ สั่งอาหาร หรือถามความตั้งใจของผู้ฟัง

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากกริยา + **-겠습니다 / -겠어요** (ไม่ดูตัวสะกด) | 제가 하겠습니다 *({n:ฉัน}{e:จะ}{v:ทำ}{p:เอง})* · 저는 커피를 마시겠습니다 *(ฉันจะดื่มกาแฟ)* |
| ปฏิเสธ **-지 않겠습니다** | 오지 않겠습니다 *(จะไม่มา)* |
| ถามผู้ฟัง **-겠습니까?** | 언제 오겠습니까? *(จะมาเมื่อไร)* |
| ถามผู้ใหญ่ **-(으)시겠습니까?** (ลำดับ 시 → 겠) | 무엇을 드시겠습니까? *({e:จะ}{v:รับ}{q:อะไร}ดีครับ)* |
| ประธานคือ "ฉัน" หรือถามตัว "คุณ" เท่านั้น และใช้กับกริยา | ✗ 친구가 오겠습니다 → ✓ 친구가 올 거예요 *(เพื่อนจะมา)* |

⚠️ ✗ 먹겠으십니까 → ✓ 드시겠습니까 · -겠- = ตัดสินใจตอนพูด ต่างจาก -(으)ㄹ 거예요 (แผน) · 알겠습니다 = "รับทราบ" ไม่ใช่อนาคต

### 23. -았/었/였- · N이었어요/였어요 `[Unit 17]` — อดีตกาล "…แล้ว / เคย…"

ใช้เมื่อจะบอกเรื่องที่เกิดขึ้นแล้วในอดีต โดยดูสระของพยางค์สุดท้ายของรากเพื่อเลือก 았 หรือ 었 และใช้ 이었어요 หรือ 였어요 กับคำนาม

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ดู**สระ**ท้ายราก: ㅏ/ㅗ → **-았어요** | 많았어요 *(มีมาก ในอดีต)* · 살았어요 *(เคยอยู่)* |
| ดู**สระ**ท้ายราก: สระอื่น → **-었어요** | 먹었어요 *(กินแล้ว)* · 읽었어요 *(อ่านแล้ว)* |
| 하다 → **했어요** | 공부했어요 *(เรียนแล้ว)* |
| ไม่มีตัวสะกด → ควบสระ | 갔 *(ไป)* · 왔 *(มา)* · 봤 *(ดู)* · 마셨 *(ดื่ม)* |
| ราก ㅡ ตัดแล้วดูพยางค์ก่อนหน้า | 바빴어요 *(ยุ่ง)* · 컸어요 *(ใหญ่)* · 썼어요 *(เขียน)* |
| 어떻다 → 어땠어요 | 어땠어요 *(เป็นอย่างไร)* |
| N+이다: มีตัวสะกด → **N이었어요** · ไม่มี → **N였어요** · ปฏิเสธ **N이/가 아니었어요** | 학생이었어요 *(เคยเป็นนักเรียน)* · 의사였어요 *(เคยเป็นหมอ)* · 학생이 아니었어요 *(ไม่เคยเป็นนักเรียน)* |

⚠️ ระวัง

- ✗ 살었어요, 받었어요 → ✓ 살았어요, 받았어요 (ดูสระ ไม่ใช่ตัวสะกด)
- ✗ 학생였어요 → ✓ 학생이었어요
- ✗ 어떻었어요 → ✓ 어땠어요
- 어제 ไม่มี 에 แต่ 작년에 และ 지난주에 มี 에

### 24. N에서 왔어요 `[Unit 17]` — มาจาก… (ประเทศ · เมือง · บ้านเกิด)

ใช้เมื่อจะบอกว่ามาจากประเทศ เมือง หรือบ้านเกิดที่ไหน และเมื่อต้องถามที่มาของคน

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| สถานที่ + **에서 왔어요** (อดีต **왔어요** เสมอ และทางการ **왔습니다**) | 몽골**에서 왔어요** *({v:มา}{p:จาก}{n:มองโกเลีย})* · 일본 도쿄**에서** 왔어요 *(มาจากโตเกียว ญี่ปุ่น)* |
| ถามประเทศ **어느 나라에서** และถามที่มา **어디에서** | 어느 나라에서 왔어요? — 러시아에서 왔어요 *(มาจากประเทศไหน — มาจากรัสเซีย)* |
| ถามบ้านเกิดแบบไม่ใช้กริยา **고향이 어디예요?** | 고향이 어디예요? — 베트남이에요 *(บ้านเกิดอยู่ที่ไหน — เวียดนาม)* |

⚠️ ระวัง

- 에서 왔어요 = มา**จาก** · 에 왔어요 = มา**ถึง** (한국에 왔어요)
- ✗ 와요 → ✓ 왔어요 · ✗ 무슨 나라 → ✓ 어느 나라

### 25. N시 N분 · 오전/오후 · 반 · 전 `[Unit 18]` — บอกเวลา กี่โมง กี่นาที

ใช้เมื่อจะบอกหรือถามเวลาว่ากี่โมงกี่นาที โดยชั่วโมงใช้เลขแท้และนาทีใช้เลขจีน

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ชั่วโมง = **เลขแท้ + 시** (한, 두, 세, 네, 다섯 … 열한, 열두) และนาที = **เลขจีน + 분** | 세 시 이십오 분 *(3 โมง 25 นาที)* |
| 30 นาที = **반** | 두 시 **반** *(2:30)* |
| **오전 / 오후** วาง**หน้า**เวลา | 오후 두 시 반 *(บ่าย 2 โมงครึ่ง)* |
| …분 **전** = อีก…นาทีจะถึงชั่วโมงถัดไป | 세 시 십 분 **전** *(= 2:50)* |
| ถาม **몇 시예요?** และเขียนตัวอักษรต้องเว้นวรรค | 두 시 이십 분 *(สองโมงยี่สิบนาที)* |
| "เมื่อ…โมง" ใส่ **에** (지금 ไม่ใส่ 에) | 일곱 시**에** 일어나요 *(ตื่นเจ็ดโมง)* |

⚠️ ระวัง

- ✗ 일 시, 열 분 → ✓ 한 시, 십 분
- อย่าลืม **분** (✗ 사십오 이에요)
- ✗ 두시 이십분 → ✓ 두 시 이십 분
- 시 = โมง ≠ 시간 = ชั่วโมง (몇 시간)

### 26. -(으)러 `[Unit 18]` — ไป/มา เพื่อ… (ตามด้วยกริยาเคลื่อนที่)

ใช้เมื่อจะบอกว่าไปหรือมาที่ใดเพื่อทำอะไร โดยต่อ -(으)러 ท้ายรากแล้วตามด้วยกริยาเคลื่อนที่ เช่น 가다 หรือ 오다

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากไม่มีตัวสะกด → **-러** | 사러 *(เพื่อซื้อ)* · 하러 *(เพื่อทำ)* |
| รากมีตัวสะกด → **-으러** | 먹**으**러 *(เพื่อกิน)* · 씻**으**러 *(เพื่อล้าง)* |
| (เสริม) ตัวสะกด ㄹ → -러 | 만들러 *(เพื่อทำ)* |
| โครงสร้าง N**에** + (N을/를) V-(으)러 **가요/와요** และคำถาม 뭘 하러 가요? | 서점에 책을 사러 가요 *({v:ไป}{n:ร้านหนังสือ}{e:เพื่อ}{v:ซื้อ}{n:หนังสือ})* |
| ตัวหลังต้องเป็นกริยาเคลื่อนที่ (가다, 오다, 다니다 …) และกาลอยู่ที่กริยาท้าย | 도서관에 책을 빌리러 **갔어요** *({v:ไป}{n:ห้องสมุด}{e:เพื่อ}{v:ยืม}{n:หนังสือ})* |

⚠️ ✗ 씻러 → ✓ 씻으러 · ตอบให้มีกรรมตาม <보기> (✗ 사러 → ✓ 과일을 사러) · -(으)러 가요 = ไป**เพื่อ**กิน ≠ -고 가요 = กิน**แล้ว**ไป

### 27. N부터 N까지 `[Unit 19]` — ตั้งแต่ … ถึง … (เวลา · วันที่ · วัน · เดือน)

ใช้เมื่อจะบอกช่วงเวลาตั้งแต่จุดเริ่มถึงจุดสิ้นสุด ไม่ว่าจะเป็นเวลา วันที่ วัน หรือเดือน

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| N1**부터** N2**까지** ติดคำหน้า ไม่เว้นวรรค ไม่ใส่ 에 | 아홉 시부터 한 시까지 *(9 โมงถึงบ่ายโมง)* · 월요일부터 금요일까지 *(ตั้งแต่วันจันทร์ถึงวันศุกร์)* |
| ถามเวลา **몇 시부터 몇 시까지** · ถามวันที่ **며칠부터 며칠까지** · ถามทั่วไป **언제부터 언제까지** | 오전 9시부터 오후 1시까지 *(ตั้งแต่ 9 โมงเช้าถึงบ่าย 1 โมง)* · 7월 5일부터 8월 20일까지 *(ตั้งแต่ 5 กรกฎาคมถึง 20 สิงหาคม)* |
| ท้ายประโยคไม่มีกริยา → N**까지예요** | 전시회는 7월 5일부터 8월 20일까지**예요** *(นิทรรศการตั้งแต่ 5 กรกฎาคมถึง 20 สิงหาคม)* |
| นับเดือน = **한 달** (เลขแท้ + 달) | 한 달 전에 왔어요 *(มาเมื่อหนึ่งเดือนก่อน)* |

⚠️ ระวัง

- ✗ 이십 일 부터 (แยกคำ) และ ✗ 9시에부터
- ✗ ลืม 까지 และ ✗ 몇 시 แทน 며칠
- ✗ 한 월 → ✓ 한 달
- ✗ 한시부터 두시까지 → ✓ 한 시부터 두 시까지

## ข้อ 28–35 · อนาคต · ให้-รับ · -네요 · 만 · -고 있다 · ชวน · ตาราง 받침 (19–22과)

> [!INTRO] กลุ่มนี้ครอบคลุมอะไร
> ข้อ 28 ถึง 35 ครอบคลุมบท 19–22 ได้แก่ -(으)ㄹ 거예요, คำช่วยบอกผู้รับ 에게/한테, -네요, 만, -고 있다, -(으)ㄹ까요? และ 무슨 กับ -고 ส่วนข้อ 35 เป็นตารางสรุปตัวสะกดของทุกรูปที่ผ่านมา ถ้าจำเงื่อนไขตัวสะกดไม่ได้ ให้เริ่มจากข้อ 35 แล้วย้อนไปดูข้อที่เกี่ยวข้อง

### 28. -(으)ㄹ 거예요 `[Unit 19]` — จะ... (แผน/อนาคต) · คงจะ... (คาดเดา)

ใช้เมื่อจะบอกแผนในอนาคตว่า "จะ…" หรือเดาเรื่องที่คิดว่าน่าจะเป็นอย่างนั้นว่า "คงจะ…" โดยดูตัวสะกดของรากเพื่อเลือกรูป

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากไม่มีตัวสะกด → **-ㄹ 거예요** | 가다 → **갈 거예요** *(จะไป)* · 하다 → **할 거예요** *(จะทำ)* |
| รากมีตัวสะกด → **-을 거예요** | 읽다 → **읽을 거예요** *(จะอ่าน)* · 먹다 → **먹을 거예요** *(จะกิน)* |
| รากลงท้าย ㄹ → เติมแค่ **거예요** (ไม่ซ้ำ ㄹ และไม่ใส่ 을) | 만들다 → **만들 거예요** *(จะทำ)* · 살다 → **살 거예요** *(จะอยู่)* |
| คำนาม → N**일 거예요** (คาดเดา) | 선생님**일 거예요** *(คงเป็นอาจารย์)* |

⚠️ ระวัง

- ตอบ 언제 ด้วย**เวลา** (언제 고향에 갈 거예요? — 방학에 갈 거예요) ไม่ใช่กิจกรรม — เสียคะแนนใน 매일시험 19과
- สะกด 거예요 ต้องมี 예 และเว้นวรรค (✗ 거요 · ✗ 갈거예요)

### 29. 에게/한테 · 에게서/한테서 · 께 `[Unit 20]` — ให้แก่คน · รับจากคน · ผู้ใหญ่

ใช้เมื่อจะบอกว่าให้หรือทำอะไรแก่ใคร (ผู้รับ) หรือรับอะไรมาจากใคร (ต้นทาง) โดยเลือกคำช่วยตามว่าเป็นคน สัตว์ ผู้ใหญ่ หรือสิ่งของ

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ผู้รับเป็นคน/สัตว์ (주다 보내다 전화하다 가르치다) → **에게** (พูด+เขียน) / **한테** (พูด) | 친구**한테** 전화해요 *(โทรหาเพื่อน)* |
| ต้นทางเป็นคน (받다 빌리다 배우다 듣다) → **에게서 / 한테서** | 남자 친구**에게서** 꽃을 받았어요 *(ได้ดอกไม้จากแฟน)* |
| ผู้ใหญ่ → **께** (กริยา 주다 → **드리다**) | 할머니**께** 선물을 **드려요** *(ให้ของขวัญคุณยาย)* |
| สิ่งของ/สถานที่ → **에** (ให้) | 꽃**에** 물을 줘요 *({v:รดน้ำ}{n:ดอกไม้})* |
| สิ่งของ/สถานที่ → **에서** (จาก) | 회사**에서** 전화가 왔어요 *(มี{n:สาย}{v:มา}{p:จาก}{n:บริษัท})* |

⚠️ ระวัง

- ดูทิศทางของกริยา: ให้ออก = 한테 แต่ได้รับ/เรียน/ฟัง = 한테서 (✗ 부모님한테서 이야기를 했어요)
- สถานที่ห้ามใช้ 한테 (✗ 사무실한테 · ✗ 라디오한테서)
- 드리다 คู่กับ 께 เท่านั้น

### 30. -네요 `[Unit 20]` — ...นะเนี่ย / ...จัง (เพิ่งเห็น เพิ่งรู้)

ใช้เมื่อเพิ่งเห็นหรือเพิ่งรู้เรื่องตรงหน้าแล้วอุทานหรือบอกความรู้สึก เช่น "…จัง" หรือ "…นะเนี่ย"

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากกริยา/คุณศัพท์ (ตัด 다) + **-네요** — ไม่ดูตัวสะกด | 예쁘다 → **예쁘네요** *({v:สวย}{e:จัง})* · 많다 → **많네요** [만네요] *({v:เยอะ}{e:จัง})* |
| อดีต → **-았/었/였네요** | 왔네요 *({v:มา}{e:แล้ว}{e:นี่})* · 했네요 *({v:ทำ}{e:แล้ว}{e:นี่})* |
| คาดเดา → **-겠네요** | 힘들겠네요 *(คงเหนื่อยแย่)* |

⚠️ ใช้กับสิ่งที่เพิ่งเห็น/ได้ยินตรงหน้า เป็นประโยคบอกเล่า/อุทาน — ไม่ใช้ถาม และไม่ใช้กับเรื่องของตัวเองที่รู้อยู่แล้ว (✗ 저는 학생이네요)

### 31. 만 `[Unit 21]` — ...เท่านั้น / แค่...

ใช้เมื่อจะบอกว่า "แค่…" หรือ "…เท่านั้น" โดยเอา 만 ไปแทนที่คำช่วยเดิม หรือต่อท้ายคำช่วยบอกที่

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| N + **만** (แทน 이/가, 은/는 และ 을/를 — ไม่ดูตัวสะกด) | 저**만** 한국에 있어요 *({v:มี}{p:แค่}{n:ฉัน}ที่{v:อยู่}{n:เกาหลี})* · 우유**만** 마셔요 *({v:ดื่ม}{p:แต่}{n:นม})* |
| ซ้อนหลัง 에, 에서, 에게 และ 하고 | 월요일**에만** *(เฉพาะวันจันทร์)* · 집**에서만** *(เฉพาะที่บ้าน)* · 친구**에게만** *(แค่เพื่อน)* |
| ต่อท้ายจำนวน | 커피 한 잔**만** 마셔요 *({v:ดื่ม}{n:กาแฟ}{p:แค่}{m:แก้วเดียว})* |

⚠️ ✗ 저는만 / 저가만 → ✓ 저**만** (แทนคำช่วยเดิม ไม่ซ้อน) · 만 = "แค่" (ตัดออก) ≠ 도 = "ก็" (เพิ่ม)

### 32. -고 있다 `[Unit 21]` — กำลัง... (กริยาเท่านั้น)

ใช้เมื่อจะบอกว่ากำลังทำอะไรอยู่ในขณะนี้ ใช้ได้กับกริยาเท่านั้น ไม่ใช้กับคำคุณศัพท์

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากกริยา + **-고 있어요** (ไม่ดูตัวสะกด ไม่ผันราก) | 공부하**고 있어요** *(กำลังเรียน)* · 듣**고 있어요** *(กำลังฟัง)* |
| ผู้ใหญ่ → **-고 계세요** · ทางการ → **-고 있습니다 / -고 계십니다** | 일을 하**고 계세요** *(ท่าน{e:กำลัง}{v:ทำงาน})* |
| ถาม–ตอบ | 뭐 하고 있어요? — 숙제하고 있어요. *(กำลังทำอะไรอยู่ — {e:กำลัง}{v:ทำ}{n:การบ้าน})* |

⚠️ ใช้กับคำคุณศัพท์ไม่ได้ (✗ 예쁘고 있어요 → 예뻐요) · ผู้ใหญ่ ✗ -고 있으세요 → ✓ -고 계세요

### 33. -(으)ㄹ까요? `[Unit 22]` — ...กันไหม? (ชวน) · ...ดีไหม? (ถามความเห็น)

ใช้เมื่อจะชวนผู้ฟังทำอะไรด้วยกัน ("…กันไหม?") หรือถามความเห็นของผู้ฟัง ("…ดีไหม?")

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากไม่มีตัวสะกด หรือลงท้าย ㄹ → **-ㄹ까요?** | 보다 → **볼까요?** *({v:ดู}กันไหม)* · 만들다 → **만들까요?** *({v:ทำ}กันไหม)* |
| รากมีตัวสะกด → **-을까요?** | 먹다 → **먹을까요?** *({v:กิน}กันไหม)* · 찍다 → **찍을까요?** *({v:ถ่ายรูป}กันไหม)* |
| ตอบรับ | 네, 좋아요. 같이 가요. *({v:ได้} {v:ไป}{a:ด้วยกัน})* |
| ตอบปฏิเสธ | 미안해요. 약속이 있어요. *({v:ขอโทษ} {v:มี}{n:นัด})* |

⚠️ ตอบรับด้วย -아/어요 ไม่ตอบซ้ำรูปคำถาม (✗ 네, 갈까요) · ปฏิเสธไม่ตอบ 아니요 ตรง ๆ แต่ขอโทษ + บอกเหตุผล · ราก ㄹ ไม่ใส่ 을 (✗ 만들을까요)

### 34. 무슨 · -고 `[Unit 22]` — ...อะไร · และ

ใช้เมื่อจะถามชนิดของสิ่งต่าง ๆ ด้วย 무슨 และเมื่อจะเชื่อมกริยาหรือคำคุณศัพท์สองอย่างว่า "และ" ด้วย -고

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| **무슨 + N** (วางหน้านามเสมอ ถามชนิด) | 무슨 음식을 좋아해요? — 삼계탕을 좋아해요. *(ชอบอาหารอะไร — {n:ซัมกเยทัง})* |
| รากกริยา/คุณศัพท์ + **-고** (และ ไม่ดูตัวสะกด) | 깨끗하**고** 밝아요 *({v:สะอาด}{e:และ}{v:สว่าง})* · 맵지 않**고** 맛있어요 *({x:ไม่}{v:เผ็ด}{e:และ}{v:อร่อย})* |
| นาม + นาม ใช้ **하고/와/과** (ไม่ใช่ -고) | 불고기**하고** 냉면 *(บุลโกกิกับเนงมยอน)* |

⚠️ 무슨 = ถามชนิด / 어떤 = ถามลักษณะ ("แบบไหน") · ✗ 불고기고 냉면 — นามเชื่อมนามต้องใช้ 하고

### 35. ตาราง 받침 `[Unit 5–22]` — ตัวสะกดไหม? → เลือกรูป

ใช้เมื่อไม่แน่ใจว่าหลังดูตัวสะกดของคำนามหรือรากกริยาแล้วต้องเลือกรูปไหน ตารางนี้รวมทุกคู่รูปที่เปลี่ยนตามตัวสะกดไว้ในที่เดียว

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| **นาม** มีตัวสะกด → 은 · 이 · 을 | 선생님**은** *(ครู)* · 책**이** *(หนังสือ)* · 책**을** *(หนังสือ)* |
| **นาม** มีตัวสะกด → 과 · 이에요 · 이었어요 | 선생님**과** *(กับครู)* · 책**이에요** *(เป็นหนังสือ)* · 학생**이었**어요 *(เคยเป็นนักเรียน)* |
| **นาม** ไม่มีตัวสะกด → 는 · 가 · 를 | 나**는** *(ฉัน)* · 친구**가** *(เพื่อน)* · 커피**를** *(กาแฟ)* |
| **นาม** ไม่มีตัวสะกด → 와 · 예요 · 였어요 | 친구**와** *(กับเพื่อน)* · 의사**예요** *(เป็นหมอ)* · 의사**였**어요 *(เคยเป็นหมอ)* |
| **กริยา** ไม่มีตัวสะกด → ㅂ니다 · 세요 · 러 | 가 → 갑니다 *(ไป ทางการ)* · 가세요 *(ท่านไป)* · 보러 *(เพื่อดู)* |
| **กริยา** ไม่มีตัวสะกด → ㄹ 거예요 · ㄹ까요 | 가 → 갈 거예요 *(จะไป)* |
| **กริยา** มีตัวสะกด → 습니다 · 으세요 · 으러 | 먹 → 먹습니다 *(กิน ทางการ)* · 먹으세요 *(ท่านทาน)* · 먹으러 *(เพื่อกิน)* |
| **กริยา** มีตัวสะกด → 을 거예요 · 을까요 | 먹 → 먹을 거예요 *(จะกิน)* |
| รากลงท้าย **ㄹ**: นับเป็น "สระ" ไม่เติม 으/을 *(เสริม)* | 살 거예요 *(จะอยู่)* · 살까요? *(อยู่ดีไหม)* · 놀러 *(เพื่อเที่ยวเล่น)* |
| ㄹ หลุดหน้า ㅂ · ㅅ · ㄴ *(เสริม)* | 삽니다 *(อยู่ ทางการ)* · 사세요 *(ท่านอยู่)* · 사네요 *(อยู่นี่นา)* |

⚠️ ระวัง

- 과 ดูเหมือนสระแต่ใช้หลัง**ตัวสะกด** (선생님과 / 친구와)
- ลืม 으 หลังตัวสะกดเป็นข้อผิดซ้ำ (✗ 읽세요 · ✗ 받십니다 · ✗ 씻러)

> [!INTRO] กลุ่มนี้ครอบคลุมอะไร
> ข้อ 36 ถึง 45 ครอบคลุมบท 23–28 ได้แก่ คำคุณศัพท์ขยายนาม -(으)ㄴ, ㅂ 불규칙, ความอยาก -고 싶다, การห้าม -지 마세요, -지만 กับ ㄹ ตก, การเปรียบเทียบด้วย 보다, การเดาด้วย -겠-, การเปลี่ยนสภาพด้วย -아/어지다, กริยาขยายนาม -는 และ 중에서 제일 สิ่งที่ต้องระวังคือการผันแบบไม่ปกติ (ㅂ และ ㄹ) กับการเลือกคำช่วย 이/가 หรือ 을/를

### 36. -(으)ㄴ (คำคุณศัพท์ขยายนาม) `[Unit 23]` — ที่… + นาม (매운 음식 · 좋은 사람)

ใช้เมื่อจะใช้คำคุณศัพท์ขยายคำนามว่า "…ที่…" โดยเอาคำคุณศัพท์ไว้หน้านาม และเลือก -ㄴ หรือ -은 ตามตัวสะกดของราก

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากลงท้ายสระหรือ ㄹ → **-ㄴ** (ㄹ หลุด) | 예쁘다 → **예쁜** *(สวย)* · 길다 → **긴** *(ยาว)* · 달다 → **단** *(หวาน)* |
| รากมีตัวสะกด → **-은** | 작다 → **작은** *(เล็ก)* · 좋다 → **좋은** *(ดี)* |
| ลงท้าย **있다/없다** → **-는** | 맛있다 → **맛있는** *(อร่อย)* · 재미있다 → **재미있는** *(สนุก)* |
| ㅂ 불규칙 → ㅂ เป็น 우 + ㄴ (ข้อ 37) | 맵다 → **매운** *(เผ็ด)* · 덥다 → **더운** *(ร้อน)* · 어렵다 → **어려운** *(ยาก)* |
| ลำดับ: คำขยายอยู่**หน้า**นาม และถามด้วย 어떤 | 어떤 가방을 좋아해요? — **예쁘고 가벼운** 가방을 좋아해요. *(ชอบกระเป๋าแบบไหน — สวยและเบา)* |

⚠️ ระวัง

- ใช้กับ**คำคุณศัพท์**เท่านั้น (กริยา → -는 ข้อ 44)
- ㅡ ไม่ตัด: 예쁜 · 큰 (✗ 예쁘은)
- ✗ 맵은 → 매운 และ ✗ 맛있은 → 맛있는
- 좋다 → 좋은 แต่ 좋아하다 → 좋아하는

### 37. ㅂ 불규칙 `[Unit 23]` — ㅂ → 우 (워) เมื่อมีสระตามมา

ใช้เมื่อคำคุณศัพท์หรือกริยาที่ลงท้ายด้วย ㅂ ต้องเปลี่ยน ㅂ เป็น 우 (รวมกับ 어 เป็น 워) พอมีสระตามมา แต่ ㅂ อยู่เหมือนเดิมเมื่อมีพยัญชนะตามมา

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| **สระ**ตามมา คือ 아/어, (으)ㄴ, (으)세요 และ (으)ㄹ → ㅂ → **우** (+ 어 → **워**) | 덥다 → **더워요** *(ร้อน)* · 맵다 → **매워요** *(เผ็ด)* |
| ตัวอย่างรูปอื่นของ 덥다 ที่มีสระตามมา | **더운** *(ที่ร้อน)* · **더우세요** *(ท่านร้อน)* · **더울** 거예요 *(คงร้อน)* |
| **พยัญชนะ**ตามมา (-고, -지, -ㅂ니다, -네요, -지만) → ㅂ **อยู่** | **덥**습니다 *(ร้อน ทางการ)* · **덥**지만 *(ร้อนแต่)* · **덥**네요 *(ร้อนจัง)* |
| ตัวอย่างรูปปฏิเสธที่ ㅂ อยู่ | **맵**지 않아요 *(ไม่เผ็ด)* |
| ยกเว้น 돕다 · 곱다 + 아/어 → **와** | 돕다 → **도와요** *(ช่วย)* · 곱다 → **고와요** *(งาม)* · **도울**까요? *(ให้ช่วยไหม)* |
| ปกติ (ไม่ใช่ ㅂ ไม่ปกติ): 입다 · 잡다 · 좁다 | **입어요** *(ใส่)* · **잡아요** *(จับ)* · **좁아요** *(แคบ)* |

⚠️ ระวัง

- เกือบทั้งหมดลงท้าย **워** แม้สระหน้าเป็น ㅏ: 가까워요 และ 아름다워요 (✗ 가까와요)
- ✗ 더어요, 덥어요 → ✓ 더워요
- ✗ 이워요 → 입어요
- อดีต 더웠어요 และ 추웠어요

### 38. -고 싶다 · -고 싶어 하다 `[Unit 24]` — อยาก… (ฉัน/คุณ · บุคคลที่ 3)

ใช้เมื่อจะบอกว่าอยากทำอะไร โดยใช้ -고 싶어요 เมื่อประธานคือฉันหรือถามผู้ฟัง และใช้ -고 싶어 해요 เมื่อประธานเป็นบุคคลที่ 3

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ราก + **-고 싶어요** (ไม่ดูตัวสะกด ใช้กับกริยา) — ประธาน**ฉัน**/ถาม**คุณ** | 저는 불고기를 **먹고 싶어요**. *(ฉันอยากกินบุลโกกิ)* · 뭘 **하고 싶어요**? *(อยากทำอะไร)* |
| **บุคคลที่ 3** → **-고 싶어 해요** (ทางการ -고 싶어 합니다) | 제 동생은 뉴욕에 **가고 싶어 해요**. *(น้องของฉันอยากไปนิวยอร์ก)* · 마키 씨는 불고기를 먹고 **싶어 합니다**. *(คุณมากิอยากกินบุลโกกิ)* |
| อดีต -고 싶었어요 และปฏิเสธ -고 싶지 않아요 | 먹고 싶**었**지만 … *(อยากกินแต่…)* · 가고 싶**지 않**아요 *(ไม่อยากไป)* |
| รูปย่อในภาษาพูด: **전** = 저는 · **절** = 저를 · **뭘** = 무엇을 | **전** 냉면을 먹고 싶어요. *(ฉันอยากกินเนงมยอน)* |

⚠️ ระวัง

- ✗ 마키 씨는 … 먹고 싶어요 (บุคคลที่ 3 ต้อง 싶어 **해요** — เว้นวรรค)
- ✗ 먹 싶어요 (ขาด -고)
- "อยากได้ของ" ต้องมีกริยา: 선물을 **받고** 싶어요
- ใช้กับคำคุณศัพท์ไม่ได้ (✗ 예쁘고 싶어요 → 예뻐지고 싶어요)
- 전 (ㅈ) อย่าเขียนเป็น 천

### 39. -지 마세요 `[Unit 24]` — อย่า… (คู่ตรงข้ามของ -(으)세요 "ขอให้…")

ใช้เมื่อจะห้ามหรือขอร้องไม่ให้ทำว่า "อย่า…" โดยต่อ -지 마세요 ท้ายราก ส่วนการขอให้ทำใช้ -(으)세요

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ห้าม: ราก + **-지 마세요** (ไม่ดูตัวสะกด และใช้กับกริยาเท่านั้น) | 먹다 → **먹지 마세요** *(อย่ากิน)* · 말하다 → **말하지 마세요** *(อย่าพูด)* |
| ห้าม (ตัวอย่างเพิ่ม) | 넣다 → **넣지 마세요** *(อย่าใส่)* · 늦다 → **늦지 마세요** *(อย่ามาสาย)* |
| ขอให้ทำ: ไม่มีตัวสะกด หรือ ㄹ → **-세요** | 보세요 *(ดูสิ)* · 쓰세요 *(เขียนสิ)* · 숙제하세요 *(ทำการบ้านนะ)* |
| ขอให้ทำ: มีตัวสะกด → **-으세요** | **읽으세요** *(อ่านสิ)* · **닫으세요** *(ปิดสิ)* |
| คำพิเศษของการยกย่อง | 먹다 → **드세요** *(ทานเถอะ)* |
| ราก ㄹ + (으)세요 → ㄹ หลุด | 열다 → **여세요** *(เปิดสิ)* · 만들다 → **만드세요** *(ทำสิ)* · 놀다 → **노세요** *(เที่ยวเล่นสิ)* |
| ตัวอย่างตำรา | 비빔밥 하나 주세요. 고기는 **넣지 마세요**. *(ขอบิบิมบับหนึ่งที่ ไม่ใส่เนื้อ)* |
| ตัวอย่างตำรา (ต่อ) | 영화가 3시에 시작하니까 빨리 오세요. **늦지 마세요**. *(หนังเริ่ม 3 โมง รีบมานะ อย่ามาสาย)* |

⚠️ ระวัง

- ✗ 안 가세요 (≠ ห้าม · = ท่านไม่ไป) → 가지 마세요
- ✗ 먹으지 마세요 และ ✗ 가지마세요 (เว้นวรรค 마세요)
- ★ ✗ 읽세요 → 읽**으**세요 (ลืม 으 หลังตัวสะกด)
- ✗ 열으세요 → 여세요
- 고기**는** ใช้ 은/는 เพราะเทียบ

### 40. -지만 · ㄹ 탈락 `[Unit 25]` — …แต่… · ราก ㄹ หลุดหน้า ㄴ ㅂ ㅅ ㄹ

ใช้เมื่อจะเชื่อมสองเรื่องที่ขัดกันว่า "…แต่…" ด้วย -지만 และเมื่อรากที่ลงท้ายด้วย ㄹ ต้องทิ้ง ㄹ ก่อน ㄴ ㅂ ㅅ ㄹ

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ราก + **-지만** (กริยา/คำคุณศัพท์ ไม่ดูตัวสะกด ㅂ และ ㄹ อยู่) | 김치는 **맵지만** 맛있어요. *(กิมจิเผ็ดแต่อร่อย)* |
| ต่อหลัง -았/었- และ -겠- ได้ | 이 옷이 비**쌌지만** 예뻐서 샀어요. *(เสื้อแพงแต่สวย)* |
| คำนาม: N**이지만** / N**지만** · อดีต N**이었지만** / N**였지만** (สไลด์ครู 문법 1) | 저는 **학생이지만** 언니는 학생이 아니에요. *(ฉันเป็นนักเรียนแต่พี่สาวไม่ใช่)* |
| สองประธานเทียบด้วย 은/는 | 한국 음식**은** 맵지만 일본 음식**은** 안 매워요. *(อาหารเกาหลีเผ็ดแต่อาหารญี่ปุ่นไม่เผ็ด)* · 음식은 맛있지만 좀 불친절해요. *(อาหารอร่อยแต่บริการไม่ค่อยดี)* |
| สำนวนคงรูป | **실례지만** *(ขอโทษนะ)* · **죄송하지만** 여기 화장실이 어디에 있어요? *(ขอโทษนะคะ ห้องน้ำที่นี่อยู่ไหน)* |
| **ㄹ 탈락 ขั้นตอน (กระดานครู):** ① ตัด 으 ② ตัด ㄹ ของรากหน้า ㄴ ㅂ ㅅ ㄹ ③ ต่อ | 만들 + (으)세요 → 만들 + 세요 → **만드세요** *(ทำสิ)* |
| **ㄹ 탈락:** ราก ㄹ + ㅂ → ㄹ ตก | 삽니다 *(อยู่ ทางการ)* · 만듭니다 *(ทำ ทางการ)* · 압니다 *(รู้ ทางการ)* |
| **ㄹ 탈락:** ราก ㄹ + ㅅ → ㄹ ตก | 여세요 *(เปิดสิ)* · 만드세요 *(ทำสิ)* |
| **ㄹ 탈락:** ราก ㄹ + ㄴ → ㄹ ตก | 긴 *(ยาว)* · 단 *(หวาน)* |
| **ㄹ 탈락:** ราก ㄹ + ㄹ → ㄹ ตก | 놀 거예요 *(จะเที่ยวเล่น)* · 만들까요? *(ทำกันไหม)* |
| หน้า 아/어, -고 และ -지 → ㄹ **อยู่** | 달아요 *(หวาน)* · 놀고 *(เที่ยวเล่นและ)* |

⚠️ ระวัง

- ✗ 맵으지만 → 맵지만 (ไม่ดูตัวสะกด)
- -지만 = ขัดกัน / -고 = ไปทางเดียวกัน (음식도 맛있**고** 아주머니도 친절한…)
- ✗ 살습니다, 만들으세요, 놀을 거예요 → ✓ 삽니다, 만드세요, 놀 거예요

### 41. N보다 · 더 / 덜 `[Unit 26]` — …กว่า N (เปรียบเทียบ 2 สิ่ง)

ใช้เมื่อจะเปรียบเทียบสองสิ่งว่าสิ่งหนึ่ง…กว่าอีกสิ่งหนึ่ง โดยเอา 보다 ต่อท้ายสิ่งที่ถูกเทียบ

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| **A이/가 B보다 (더) + V/A** — B (ตัวเทียบ) ติด 보다 ไม่เว้นวรรค | 제주도**가** 서울**보다** 따뜻해요. *(เชจูอุ่นกว่าโซล)* |
| สลับ: **B보다 A가 더 …** | 형**보다** 내가 더 많이 먹어요. *(ฉันกินมากกว่าพี่)* |
| ใช้ละ 더 ได้ และนามอาจเป็นกริยาที่ทำเป็นนาม | 말하기가 듣기**보다** 어려워요. *(การพูดยากกว่าการฟัง)* |
| ใส่ **더** เพื่อเน้น | 올해가 작년**보다 더** 추워요. *(ปีนี้หนาวกว่าปีที่แล้ว)* |
| ถาม: 누가 / 무엇이 / 어디가 + **더** … (ตัวอย่างตำรา) | 누가 더 커요? — 압둘라 씨가 마키 씨보다 커요. *(ใครตัวใหญ่กว่า — คุณอับดุลลาตัวใหญ่กว่าคุณมากิ)* |

⚠️ ระวัง

- ตัวหลัง 보다 = ตัวที่ "ด้อยกว่า" (✗ 서울이 제주도보다 따뜻해요 ถ้าเชจูอุ่นกว่า)
- ✗ 서울보다가
- N보다 (กว่า) ≠ 보다 (ดู)
- ใช้ 보다 กับ **2** สิ่ง ส่วน 3 สิ่งขึ้นไป = 중에서 제일 (ข้อ 45)
- 많아요 (คำคุณศัพท์) vs 많이 (กริยา)

### 42. -겠- (คาดเดา) `[Unit 26]` — ดูท่าจะ… · คงจะ… (มีเบาะแส)

ใช้เมื่อจะเดาเรื่องจากเบาะแสที่เห็นหรือได้ยินว่า "ดูท่าจะ…" หรือ "คงจะ…" ซึ่งใช้ได้กับทั้งกริยา คำคุณศัพท์ และเรื่องในอดีต

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ราก + **-겠어요** (กริยา **และ**คำคุณศัพท์ ไม่ดูตัวสะกด) | 곧 비가 오**겠어요**. *(เดี๋ยวฝนคงตก)* · 맛있**겠어요**. *(ดูอร่อย)* |
| ㅂ ㅡ ไม่เปลี่ยน | 덥**겠어요**. *(คงร้อน)* |
| เดาเรื่อง**อดีต** → ราก + **-았/었/였겠어요** | 작년에 미국 여행을 했어요. → 재미있**었겠**어요. *(ปีที่แล้วไปเที่ยวอเมริกา → คงสนุก)* |
| เบาะแส (가) → คำเดา (나) | 5시간 동안 청소를 했어요. → 피곤하**겠**어요. *(ทำความสะอาด 5 ชั่วโมง → คงเหนื่อย)* |
| ต่อ -네요 | 아주 맛있**겠네요**. *(ดูอร่อยจังเลย)* · 정말 덥**겠어요**. *(คงร้อนมาก)* |

⚠️ ระวัง

- -겠-¹ (ตั้งใจ · ฉัน + กริยา — ข้อ 22) ≠ -겠-² (เดา · คนอื่น/คุณศัพท์/อดีต)
- ✗ 먹겠었어요 → 먹**었겠**어요
- ✗ 더우겠어요 → 덥겠어요
- เรื่องตัวเองที่รู้แน่ใช้ -아/어요 (✗ 저는 배가 고프겠어요)
- 맛있어요 (กินแล้ว) ≠ 맛있겠어요 (ยังไม่ลอง)

### 43. -아/어/여지다 `[Unit 27]` — …ขึ้น / กลายเป็น… (คำคุณศัพท์เปลี่ยนสภาพ)

ใช้เมื่อจะบอกว่าสภาพของสิ่งหนึ่งเปลี่ยนไปเป็น "…ขึ้น" หรือ "กลายเป็น…" โดยต่อ -아/어/여지다 ท้ายรากของคำคุณศัพท์

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| สระ ㅏ ㅗ → **-아지다** · สระอื่น → **-어지다** · 하다 → **-해지다** | 맑다 → **맑아졌어요** *(แจ่มใสขึ้น)* · 흐리다 → **흐려졌어요** *(มืดครึ้มขึ้น)* · 따뜻하다 → **따뜻해졌어요** *(อุ่นขึ้น)* |
| ㅡ ตก | 예쁘다 → **예뻐졌어요** *(สวยขึ้น)* · 나쁘다 → **나빠졌어요** *(แย่ลง)* |
| ㅂ 불규칙 (ข้อ 37) | 춥다 → **추워졌어요** *(หนาวขึ้น)* · 덥다 → **더워졌어요** *(ร้อนขึ้น)* |
| รูปผัน: 져요, **졌어요** (…แล้ว), 질 거예요 และ 지고 있어요 | 어제보다 **시원해졌어요**. *(เย็นลงกว่าเมื่อวาน)* · 작년보다 한국어 실력이 **좋아졌어요**. *(ภาษาเกาหลีดีขึ้นกว่าปีก่อน)* |

⚠️ ระวัง

- ตำราให้ใช้กับ**คำคุณศัพท์**เท่านั้น
- ✗ 시원하졌어요 → 시원해졌어요 และ ✗ 맑어졌어요 → 맑아졌어요 (ดูสระของราก)
- ✗ 예쁘어졌어요 → 예뻐졌어요
- ✗ 날씨를 더워졌어요 → 날씨가
- สภาพนิ่ง 더워요 ≠ เปลี่ยนแล้ว 더워졌어요

### 44. -는 (กริยาขยายนาม) `[Unit 27]` — ที่… + นาม (좋아하는 계절 · 자주 먹는 음식)

ใช้เมื่อจะใช้กริยาขยายคำนามว่า "…ที่…" ในปัจจุบันหรือเป็นประจำ โดยต่อ -는 ท้ายรากแล้วตามด้วยนาม

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| กริยา → ราก + **-는** (ไม่ดูตัวสะกด) | 먹다 → **먹는** *(ที่กิน)* · 읽다 → **읽는** *(ที่อ่าน)* · 좋아하다 → **좋아하는** *(ที่ชอบ)* |
| **있다 · 없다** → ราก + **-는** | 맛있다 → **맛있는** *(ที่อร่อย)* |
| ราก ㄹ → ㄹ ตก + -는 | 만들다 → **만드는** *(ที่ทำ)* · 살다 → **사는** *(ที่อยู่)* · 알다 → **아는** *(ที่รู้)* |
| ㄷ 불규칙 (ไม่เปลี่ยนก่อนพยัญชนะ) | 듣다 → **듣는** *(ที่ฟัง)* |
| โครง: [ประธาน이/가 + กริยา-는] + นาม | 한국 사람들이 여름에 자주 **먹는** 음식이 뭐예요? *(อาหารที่คนเกาหลีกินบ่อยหน้าร้อนคืออะไร)* |
| ตัวอย่างตำรา | 이 노래가 요즘 자주 **듣는** 노래예요. *(เพลงนี้เป็นเพลงที่ฟังบ่อยช่วงนี้)* · 지금 교실에 **있는** 사람이 누구예요? *(คนที่อยู่ในห้องเรียนตอนนี้คือใคร)* |
| ตัวอย่างตำรา (ต่อ) | 비 **오는** 날 **먹는** 음식 *(อาหารที่กินในวันฝนตก)* |

⚠️ ระวัง

- กริยา = **-는** / คำคุณศัพท์ = -(으)ㄴ (매운 · 작은 ข้อ 36) / อดีต = -(으)ㄴ (ข้อ 47)
- 좋은 (ดี) ≠ 좋아하는 (ที่ชอบ)
- ✗ 만들는 → 만드는 และ ✗ 먹으는 → 먹는
- ออกเสียง 먹는 [멍는] และ 듣는 [든는]
- ✗ 예쁘는

### 45. N 중에서 (N을/를) 제일 `[Unit 28]` — ในบรรดา N …ที่สุด

ใช้เมื่อจะเลือกสิ่งที่…ที่สุดจากกลุ่มที่มีตั้งแต่ 3 สิ่งขึ้นไป โดยบอกกลุ่มด้วย 중에서 แล้วตามด้วย 제일

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| **[กลุ่ม] 중에서 + [ตัวที่เลือก] + 제일 + ภาคแสดง** | 저는 영화 **중에서** 공포 영화를 **제일** 좋아해요. *(ในบรรดาหนังชอบหนังสยองขวัญที่สุด)* |
| กริยา → **을/를** | 계절 중에서 봄**을** 제일 좋아해요. *(ในบรรดาฤดู ชอบฤดูใบไม้ผลิที่สุด)* |
| คำคุณศัพท์/있다 → **이/가** | 한국 음식 중에서 비빔밥**이** 제일 맛있었어요. *(ในบรรดาอาหารเกาหลี บิบิมบับอร่อยที่สุด)* |
| -고 싶다 → 이/가 ได้ | 가족 중에서 어머니**가** 제일 보고 싶어요. *(ในบรรดาครอบครัว คิดถึงคุณแม่ที่สุด)* |
| ถามด้วย 누가 และ 무슨 N | 꽃 중에서 **무슨 꽃을** 제일 좋아해요? — 장미를 제일 좋아해요. *(ในบรรดาดอกไม้ ชอบดอกไม้อะไรที่สุด — ชอบกุหลาบที่สุด)* |
| 제일 = 가장 และวางติดภาคแสดง | 시험 중에서 말하기가 제일 어려워요. *(ในบรรดาข้อสอบ การพูดยากที่สุด)* · 1년 중에서 장마 때 비가 제일 자주 와요. *(ในหนึ่งปี ช่วงฤดูฝนฝนตกบ่อยที่สุด)* |

⚠️ ระวัง

- 2 สิ่ง = A가 B**보다** 더 (ข้อ 41) ส่วน 3 สิ่งขึ้นไป = **중에서 제일**
- ✗ 겨울을 제일 추워요 → 겨울**이** (คำคุณศัพท์ไม่ใช้ 을/를)
- ✗ 가장 제일
- ★ ㅈ/ㅊ: **중에서** ≠ 층에서
- **제일** (ㅔ ไม่ใช่ ㅐ · ㅈ ไม่ใช่ ㅊ) และ 계절 (ㅖ)

> ข้อ 46 ถึง 55 ครอบคลุมบท 28–33 ได้แก่ ความสามารถ -(으)ㄹ 수 있다, กริยาอดีตขยายนาม, เหตุผลด้วย -아/어서 และ -(으)니까, (으)로, ㄷ กับ 르 불규칙, ระยะเวลา, ลำดับการกระทำ และเงื่อนไข -(으)면 สองรูปที่ต้องแยกให้ออกคือ -아/어서 ที่มีทั้งความหมายเหตุผลและลำดับ กับ (으)로 ที่มีทั้งความหมายทิศทางและวิธี

### 46. -(으)ㄹ 수 있다/없다 `[Unit 28]` — ทำได้ · ทำไม่ได้

ใช้เมื่อจะบอกว่าทำสิ่งใดได้หรือทำไม่ได้ โดยต่อ -(으)ㄹ 수 있다 หรือ -(으)ㄹ 수 없다 ท้ายราก

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากไม่มีตัวสะกด → **-ㄹ 수 있어요** | 타다 → **탈 수 있어요** *(ขี่ได้)* |
| รากมีตัวสะกด → **-을 수 있어요** | 먹다 → **먹을 수 있어요** *(กินได้)* |
| รากลงท้าย **ㄹ** → ไม่ซ้ำ ㄹ ไม่ใส่ 을 | 만들다 → **만들 수 있어요** *(ทำได้)* · 살다 → **살 수 있어요** *(อยู่ได้)* |
| ปฏิเสธ → **수 없어요** และกาลอดีตเปลี่ยนที่ 있다/없다 | 갈 수 **없어요** *(ไปไม่ได้)* · 할 수 **없었어요** *(ทำไม่ได้ (ตอนนั้น))* |
| ตอบ: 네, …-ㄹ 수 있어요 / 아니요, …-ㄹ 수 없어요 (+ 그렇지만 …은/는) | 스케이트를 탈 수 없어요. 그렇지만 스키는 탈 수 있어요. *(เล่นสเก็ตไม่ได้ แต่เล่นสกีได้)* |

⚠️ ระวัง

- **수** เป็นคำนาม เว้นวรรค 3 คำ (✗ 갈수있어요)
- ✗ 만들을 수 → ✓ 만들 수
- ✗ 먹 수 → ✓ 먹을 수
- 안 = ไม่ทำ แต่ 수 없다 = ทำไม่ได้ (✗ 안 할 수 있어요)

### 47. -(으)ㄴ (กริยา อดีต) `[Unit 29]` — "นามที่…แล้ว" (어제 본 영화)

ใช้เมื่อจะใช้กริยาในอดีตขยายคำนามว่า "…ที่…แล้ว" เช่น หนังที่ดูเมื่อวาน โดยต่อ -(으)ㄴ ท้ายรากแล้วตามด้วยนาม

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากไม่มีตัวสะกด → **-ㄴ** | 보다 → **본** *(ที่ดู)* · 오다 → **온** *(ที่มา)* |
| รากมีตัวสะกด → **-은** | 먹다 → **먹은** *(ที่กิน)* · 입다 → **입은** *(ที่สวม)* |
| รากลงท้าย **ㄹ** → ตัด ㄹ แล้วเติม ㄴ | 만들다 → **만든** *(어제 만든 케이크 = เค้กที่ทำเมื่อวาน)* |
| โครงสร้าง: [ประโยคย่อย + -(으)ㄴ] + **นาม** (นามได้ 이/가/을/를 ของตัวเอง) | 어제 본 영화**가** 재미있었어요. *(หนังที่ดูเมื่อวานสนุก)* |
| ปฏิเสธ -지 않은 | 안경을 쓰지 않은 사람 *(คนที่ไม่ใส่แว่น)* |
| 있다/없다 ใช้ -는 | 맛있는 음식 *(อาหารอร่อย)* |

⚠️ ระวัง

- -(으)ㄴ = อดีต · -는 = ปัจจุบัน/ประจำ · -(으)ㄹ = อนาคต (บท 33)
- ไม่ใส่ -았- ซ้ำ (✗ 봤은)
- ✗ 만들은 → ✓ 만든
- ลำดับกลับกับไทย (นามตามหลังตัวขยาย)

### 48. -아/어/여서 (เหตุผล) `[Unit 29]` — เพราะ… จึง…

ใช้เมื่อจะบอกเหตุผลว่า "เพราะ… จึง…" โดยเหตุอยู่ในประโยคหน้าและผลอยู่ในประโยคหลัง

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ㅏ/ㅗ → **-아서** · อื่น → **-어서** · 하다 → **-해서** | 비가 **와서** *(เพราะฝนตก)* · 시간이 **없어서** *(เพราะไม่มีเวลา)* · 친절**해서** *(เพราะใจดี)* |
| ㅡ-ตก และ ㅂ → 워 | **아파서** *(เพราะเจ็บ)* · **추워서** *(เพราะหนาว)* |
| นาม: ตัวสะกด → **-이어서** · สระ → **-여서** | 고등학생**이어서** *(เพราะเป็นนักเรียนมัธยม)* · 친구**여서** *(เพราะเป็นเพื่อน)* |
| ตอบ 왜? ด้วย เหตุ-아/어서 + ผล | 왜 택시를 타요? — **늦어서** 택시를 타요. *(ทำไมนั่งแท็กซี่ — เพราะสายเลยนั่งแท็กซี่)* |
| ห้ามใส่ -았/었- และ -겠- ในประโยคหน้า และห้ามตามด้วยคำสั่งหรือชวน | ✓ 비가 와서 취소했어요 *(เพราะฝนตกเลยยกเลิก)* · ✗ 비가 왔어서 |

⚠️ ระวัง

- คำสั่ง/ชวนต้องใช้ -(으)니까 (ข้อ 50)
- ✗ 많어서 → ✓ 많아서
- ✗ 고등학생여서 → ✓ 이어서
- เหตุมาก่อนผลเสมอ
- ขอโทษ/ขอบคุณใช้ -아/어서 (늦어서 죄송합니다)

### 49. (으)로 (ทิศทาง) `[Unit 30]` — ไปทาง… (왼쪽으로 가세요)

ใช้เมื่อจะบอกทิศทางที่ไปว่า "ไปทาง…" เช่น ตอนบอกทาง โดยเลือก (으)로 ตามตัวสะกดของคำนาม

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| นามลงท้ายตัวสะกด (ยกเว้น ㄹ) → **-으로** | 오른쪽**으로** *(ไปทางขวา)* · 3층**으로** *(ขึ้นชั้น 3)* · 밖**으로** *(ออกไปข้างนอก)* |
| นามลงท้ายสระ หรือ **ㄹ** → **-로** | 프랑스**로** *(ไปฝรั่งเศส)* · 교실**로** *(เข้าห้องเรียน)* · 서울**로** *(ไปโซล)* |
| ใช้กับ 가다, 오다, 올라가다, 내려가다, 들어가다 และ 나가다 | 사거리**에서** 오른쪽**으로** 가세요. *(ที่สี่แยกไปทางขวา)* |
| 똑바로 = ตรงไป (ไม่ใส่ (으)로) | 똑바로 가세요. *(ตรงไปเลย)* |

⚠️ ระวัง

- ✗ 오른쪽로 → ✓ 오른쪽으로 (ลืม 으 หลังตัวสะกด)
- ✗ 교실으로 → ✓ 교실로
- 에 = จุดหมาย/ที่ตั้ง แต่ (으)로 = ทิศ (✗ 학교로 있어요)
- บอกทางลงท้าย -(으)세요 ไม่ใช่ 거예요

### 50. -(으)니까 `[Unit 30]` — …นะ เพราะ… (เหตุผลเพื่อสั่ง/ชวน)

ใช้เมื่อจะบอกเหตุผลเพื่อนำไปสู่การสั่งหรือชวน เช่น "รถติดนะ นั่งรถไฟใต้ดินเถอะ" ซึ่งต่างจาก -아/어서 ที่ตามด้วยคำสั่งไม่ได้

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากไม่มีตัวสะกด → **-니까** · มีตัวสะกด → **-으니까** | 막히**니까** *(เพราะรถติด)* · 없**으니까** *(เพราะไม่มี)* · 있**으니까** *(เพราะมี)* |
| ㄹ ตกก่อน ㄴ · ㅂ → 우 · ㄷ → ㄹ | 멀다 → **머니까** *(เพราะไกล)* · 덥다 → **더우니까** *(เพราะร้อน)* · 듣다 → **들으니까** *(เพราะฟัง)* |
| นาม: ตัวสะกด → **이니까** · สระ → **니까** · ใส่กาลได้ | 생일**이니까** *(เพราะเป็นวันเกิด)* · 읽**었으니까** *(เพราะอ่านแล้ว)* · 올 **거니까** *(เพราะจะมา)* |
| ตามด้วย -(으)세요, -아/어요 (ชวน) และ -지 마세요 | 길이 막히니까 **지하철을 타세요**. *(รถติด นั่งรถไฟใต้ดินเถอะ)* |

⚠️ ระวัง

- -(으)니까 ใช้กับคำสั่ง/ชวน แต่ -아/어서 ห้าม
- ✗ 없니까 → ✓ 없으니까
- ✗ 멀으니까 → ✓ 머니까
- 모르니까 (르 ไม่เปลี่ยนก่อน 으)
- -습니까? (ถาม) ≠ -으니까 (เหตุผล)

### 51. (으)로 (วิธี/พาหนะ) · ㄷ 불규칙 `[Unit 31]` — 버스로 가요 · 듣다 → 들어요

ใช้เมื่อจะบอกว่าไปด้วยพาหนะหรือทำด้วยเครื่องมืออะไรด้วย (으)로 และเมื่อกริยา ㄷ ไม่ปกติต้องเปลี่ยน ㄷ เป็น ㄹ เมื่อมีสระตามมา

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| พาหนะ/เครื่องมือ + **(으)로** (ตัวสะกด → 으로 · สระ/ㄹ → 로) และตอบ 어떻게 가요? | 버스**로** 가요 = 버스**를 타고** 가요 *(ไปรถเมล์)* |
| เครื่องมือ + **(으)로** | 칼**로** *(ด้วยมีด)* · 젓가락**으로** *(ด้วยตะเกียบ)* |
| เดินไป = **걸어서** (ไม่ใช้ (으)로) | 저는 걸어서 가요. *(ฉันเดินไป)* |
| **ㄷ 불규칙** ก่อน**สระ** ㄷ → ㄹ: 듣다 | 들**어요** *(ฟัง)* · 들**으세요** *(ฟังสิ)* |
| **ㄷ 불규칙** ก่อน**สระ** ㄷ → ㄹ: 걷다 และ 묻다 | 걸**어서** *(เดิน)* · 물**어보세요** *(ลองถามดูสิ)* |
| ก่อนพยัญชนะไม่เปลี่ยน | 듣고 *(ฟังและ)* · 걷습니다 *(เดิน ทางการ)* |
| ปกติ (ไม่เปลี่ยน): 닫다 · 받다 | **닫**아요 *(ปิด)* · **받**아요 *(รับ)* |

⚠️ ระวัง

- (으)로¹ ทิศ (오른쪽으로) vs (으)로² วิธี (버스로) — ดูที่นามหน้า
- ✗ 듣어요 → ✓ 들어요
- ✗ 달아요 → ✓ 닫아요
- ✗ 걸세요 → ✓ 걸으세요
- 걷다 (เดิน) ≠ 걸리다 (ใช้เวลา)

### 52. N에서 N까지 · 얼마나 걸려요? · 쯤 `[Unit 31]` — จาก…ถึง… · ใช้เวลาเท่าไร

ใช้เมื่อจะบอกระยะจากที่หนึ่งถึงอีกที่หนึ่ง ถามว่าใช้เวลาเดินทางนานเท่าไร และบอกเวลาโดยประมาณด้วย 쯤

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| สถานที่: N**에서** N**까지** | 학교**에서** 길음역**까지** *(จากโรงเรียนถึงสถานีคิรึม)* |
| เวลา: N**부터** N**까지** (ข้อ 27) | 9시**부터** 12시**까지** *(ตั้งแต่ 9 ถึง 12)* |
| ถาม **얼마나 걸려요?** และตอบ พาหนะ(으)로 + เวลา + **쯤 걸려요** | 버스로 **20분쯤 걸려요**. *(ไปรถเมล์ประมาณ 20 นาที)* |
| นาที = เลขจีน + 분 และชั่วโมง = เลขแท้ + 시간 (ชั่วโมงก่อน นาทีหลัง ไม่ใส่ 에) | 두 시간 삼십 분 *(2 ชม. 30 น.)* · 열세 시간 삼십 분 *(13 ชม. 30 น.)* |
| 쯤 ติดท้ายตัวเลข ไม่เว้นวรรค | 30분쯤 *(ราว 30 นาที)* · 100m쯤 *(ราว 100 ม.)* |

⚠️ ระวัง

- สถานที่ = 에서~까지 แต่เวลา = 부터~까지
- 얼마나 걸려요 (ระยะเวลา) ≠ 얼마예요 (ราคา) ≠ 어떻게 가요 (วิธี)
- ✗ 이 시간 → ✓ 두 시간
- ✗ 열셋 시간 → ✓ 열세 시간
- 걸려요 (ใช้เวลา) ≠ 걸어요 (เดิน)

### 53. -아/어/여서 (ลำดับ) `[Unit 32]` — A แล้ว B (내려서 갈아타세요)

ใช้เมื่อจะเล่าการกระทำสองอย่างต่อเนื่องกันว่า "ทำ A แล้วจึงทำ B" โดยผลของ A ติดไปถึง B และประธานเป็นคนเดียวกัน

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ㅏ/ㅗ → **-아서** | 가**서** *(ไปแล้ว)* · 와**서** *(มาแล้ว)* |
| สระอื่น → **-어서** | 내려**서** *(ลงแล้ว)* · 만들어**서** *(ทำแล้ว)* |
| 하다 → **-해서** | 출근해**서** *(ไปทำงานแล้ว)* |
| **ประธานเดียวกัน** ไม่ใส่กาลในประโยคหน้า และตามด้วยคำสั่งได้ | 서울역에서 **내려서** 1호선으로 **갈아타세요**. *(ลงสถานีโซลแล้วเปลี่ยนเป็นสาย 1)* |
| ผลของ A ติดไปใน B | 집에 가서 숙제를 해요 *(ไปบ้านแล้วทำการบ้าน)* · 의자에 앉아서 기다려요 *(นั่งแล้วรอ)* |
| เทียบ -고: เรียงต่อกันเฉย ๆ ใส่กาลได้ ประธานต่างได้ | 숙제를 **하고** 집에 가요 *(ทำการบ้านเสร็จแล้วกลับบ้าน)* · 버스를 **타고** 가세요 *(ขึ้นรถเมล์ไป)* |

⚠️ ระวัง

- รูปเดียวกับ -아/어서 เหตุผล (ข้อ 48): ลำดับ = กริยา+ประธานเดียวกัน+ตามคำสั่งได้ · เหตุผล = ตามคำสั่งไม่ได้
- ✗ 내렸어서 → ✓ 내려서
- ✗ 앉어서 → ✓ 앉아서
- ✗ 가아서 → ✓ 가서
- 갈아타다 (ไม่ใช่ 같아타다)

### 54. 르 불규칙 `[Unit 32]` — 빠르다 → 빨라요 · 모르다 → 몰라요

ใช้เมื่อกริยาหรือคำคุณศัพท์ที่ลงท้ายด้วย 르 ต้องตัด ㅡ ของ 르 แล้วเติม ㄹ ไปที่พยางค์หน้า เมื่อตามด้วย 아/어

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ก่อน **아/어**: ตัด ㅡ ของ 르 + เติม ㄹ · พยางค์หน้า ㅏ/ㅗ → **ㄹ라** | 빠르다 → **빨라**요 *(เร็ว)* · 모르다 → **몰라**요 *(ไม่รู้)* |
| พยางค์หน้า ㅏ/ㅗ → **ㄹ라** (ตัวอย่างเพิ่ม) | 다르다 → **달라**요 *(ต่าง)* · 자르다 → **잘라**요 *(ตัด)* |
| พยางค์หน้าอื่น → **ㄹ러** | 부르다 → **불러**요 *(ร้อง)* |
| ผันก่อน -았/었 | **빨랐**어요 *(เร็ว)* · **달랐**어요 *(ต่าง)* |
| ผันก่อน -아/어서 | **몰라**서 *(เพราะไม่รู้)* · **불러**서 *(เพราะร้อง)* |
| ก่อนพยัญชนะ **ไม่เปลี่ยน** | 모릅니다 *(ไม่รู้ ทางการ)* · 빠르고 *(เร็วและ)* · 부르고 싶어요 *(อยากร้อง)* |
| ก่อน 으 **ไม่เปลี่ยน** | **빠른** *(ที่เร็ว)* · 모르세요 *(ท่านไม่รู้)* · 모르니까 *(เพราะไม่รู้)* |
| ก่อน -(으)ㄹ **ไม่เปลี่ยน** | 다를 거예요 *(คงต่าง)* |

⚠️ ระวัง

- ต่างจาก ㅡ-ตกธรรมดา (쓰다 → 써요 ไม่เพิ่ม ㄹ)
- ✗ 몰라세요 / ✗ 몰라니까 (ก่อน 으 ห้ามเปลี่ยน)
- ✗ 빠라요 → ✓ 빨라요
- 빨라요 (เร็ว) ≠ 빨아요 (ซัก)
- 다르다 (ต่าง) ≠ 틀리다 (ผิด)

### 55. -(으)면 `[Unit 33]` — ถ้า… / เมื่อ…

ใช้เมื่อจะบอกเงื่อนไขว่า "ถ้า…" หรือ "เมื่อ…" แล้วตามด้วยผลที่จะเกิด โดยดูตัวสะกดของรากเพื่อเลือก -으면 หรือ -면

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากมีตัวสะกด → **-으면** | 먹다 → **먹으면** *(ถ้ากิน)* · 있다 → **있으면** *(ถ้ามี)* · 없다 → **없으면** *(ถ้าไม่มี)* |
| รากสระ → **-면** | 오다 → **오면** *(ถ้ามา)* · 되다 → **되면** *(ถ้าเป็น หรือถึงเวลา)* |
| รากลงท้าย ㄹ → **-면** | 살다 → **살면** *(ถ้าอยู่)* · 만들다 → **만들면** *(ถ้าทำ)* |
| ㅂ → 우 · ㄷ → ㄹ · 르 ไม่เปลี่ยน | 춥다 → **추우면** *(ถ้าหนาว)* · 듣다 → **들으면** *(ถ้าฟัง)* · 모르다 → **모르면** *(ถ้าไม่รู้)* |
| ประโยคหลักได้ทุกแบบ (-아/어요 · -(으)ㄹ 거예요 · -(으)세요) | 시간이 있으면 소설을 읽어요. *(ถ้ามีเวลาจะอ่านนิยาย)* · 기차표가 없으면 버스로 갈 거예요. *(ถ้าไม่มีตั๋วรถไฟจะไปรถบัส)* |

⚠️ ระวัง

- ลืม 으 หลังตัวสะกด (✗ 먹면 → 먹으면)
- ㄹ-ราก ไม่ใส่ 으 (✗ 살으면)
- 되다 รับ 이/가 (영화배우**가** 되면)
- "ถ้า" ≠ "ตอนที่" -(으)ㄹ 때 (ข้อ 56) ≠ "เพราะ" -아/어서 (ข้อ 48)

## ข้อ 56–64 · -(으)ㄹ N · หรือ · -는 것 · ลอง · -는데요 · -(으)ㄹ게요 · ขอให้ทำ · ต้อง (33–37과)

> [!INTRO] กลุ่มนี้ครอบคลุมอะไร
> ข้อ 56 ถึง 64 ครอบคลุมบท 33–37 ได้แก่ กริยาอนาคตขยายนาม -(으)ㄹ, ตัวเลือก -거나 กับ (이)나, การทำกริยาให้เป็นนามด้วย -는 것, การลองหรือเคยด้วย -아/어 보다, -(으)ㄴ/는데요, -(으)ㄹ게요, -아/어 주세요 และ -아/어야 하다 สิ่งที่ต้องระวังคือคู่ที่หน้าตาใกล้กัน เช่น 먹을 것 กับ 먹는 것 และ -(으)ㄹ게요 กับ -(으)ㄹ 거예요

### 56. -(으)ㄹ + นาม `[Unit 33]` — …ที่จะ… (กริยาขยายนาม อนาคต) · สรุป -(으)ㄴ/-는/-(으)ㄹ

ใช้เมื่อจะใช้กริยาที่ยังไม่เกิดขึ้นขยายคำนามว่า "…ที่จะ…" และเมื่ออยากเทียบให้ออกว่า -(으)ㄴ, -는 และ -(으)ㄹ ต่างกันที่เวลาอดีต ปัจจุบัน และอนาคต

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากสระ → **-ㄹ** + นาม | 갈 사람 *(คนที่จะไป)* · 볼 영화 *(หนังที่จะดู)* |
| รากลงท้าย ㄹ → **-ㄹ** (ไม่เติมซ้ำ) + นาม | 살 곳 *(ที่ที่จะอยู่)* · 만들 음식 *(อาหารที่จะทำ)* |
| รากมีตัวสะกด → **-을** + นาม | 먹을 간식 *(ขนมที่จะกิน)* |
| นามที่ตามมาบ่อย: 것, 곳, 사람, 일, 때 และ 수 | 먹을 것이 없어요 *(ไม่มีของกิน)* · 할 일이 많아요 *(งานเยอะ)* · 같이 갈 사람 *(คนไปด้วย)* |
| **สรุป 3 รูป (กริยา):** อดีต **-(으)ㄴ** · ปัจจุบัน **-는** · อนาคต **-(으)ㄹ** | 본 영화 *(หนังที่ดูแล้ว)* · 보는 영화 *(หนังที่กำลังดู)* · 볼 영화 *(หนังที่จะดู)* |
| **คำคุณศัพท์:** **-(으)ㄴ** | 매운 음식 *(อาหารเผ็ด)* · 좋은 사람 *(คนดี)* |
| คำคุณศัพท์ที่มี 있다/없다 → **-는** | 맛있는 식당 *(ร้านอร่อย)* · 재미있는 이야기 *(เรื่องสนุก)* |
| **ㄹ-ราก:** -(으)ㄴ ทำ ㄹ **หลุด** | 만든 *(ที่ทำแล้ว)* · 산 *(ที่อยู่แล้ว)* |
| **ㄹ-ราก:** -는 ทำ ㄹ **หลุด** | 만드는 *(ที่กำลังทำ)* · 사는 *(ที่อยู่)* |
| **ㄹ-ราก:** -(으)ㄹ ㄹ **คงอยู่** | 만들 음식 *(อาหารที่จะทำ)* · 살 곳 *(ที่ที่จะอยู่)* |

⚠️ ระวัง

- 먹**을** 것 (ของที่จะกิน) ≠ 먹**는** 것 (การกิน ข้อ 59) ≠ 먹을 거예요 (จะกิน ข้อ 28)
- ✗ 갈거예요 · ✗ 먹을것 (ต้องเว้นวรรค)
- ✗ 맛있은 · ✗ 좋는 (있다/없다 ใช้ -는 · คำคุณศัพท์อื่นใช้ -(으)ㄴ)

### 57. -거나 `[Unit 34]` — …หรือ… (กริยา/คำคุณศัพท์ เลือกอย่างเดียว)

ใช้เมื่อจะเชื่อมกริยาหรือคำคุณศัพท์ว่า "…หรือ…" ซึ่งให้เลือกทำอย่างใดอย่างหนึ่ง โดยต่อ -거나 ท้ายรากได้ทุกราก

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| **ราก + -거나** (ทุกราก ไม่ดูตัวสะกด) | 보다 → **보거나** *(ดู… หรือ)* · 먹다 → **먹거나** *(กิน… หรือ)* · 쉬다 → **쉬거나** *(พัก… หรือ)* |
| ㄹ และ ㅂ ไม่เปลี่ยน | 놀다 → **놀거나** *(เที่ยวเล่น… หรือ)* · 춥다 → **춥거나** *(หนาว… หรือ)* |
| ㄷ และ 르 ไม่เปลี่ยน | 듣다 → **듣거나** *(ฟัง… หรือ)* · 부르다 → **부르거나** *(ร้อง… หรือ)* |
| กาลใส่ที่ท้ายประโยคเท่านั้น | 영화를 보거나 쇼핑을 해요. *(ดูหนังหรือช็อปปิง)* · 집에서 쉬거나 숙제를 했어요. *(พักที่บ้านหรือทำการบ้าน)* |
| ปิดท้ายด้วยคำแนะนำ -(으)세요 ได้ | 너무 피곤해요. — 커피를 마시거나 좀 쉬세요. *(เหนื่อยมาก — ดื่มกาแฟหรือพักหน่อย)* |

⚠️ ระวัง

- กริยา = -거나 · คำนาม = N(이)나 (ข้อ 58) · "และ" = -고 (ข้อ 34)
- ✗ 봤거나 쇼핑을 했어요 (ไม่ใส่กาลที่ 거나)
- ✗ 먹으거나 (ไม่มี 으)

### 58. N(이)나 · 빈도 부사 `[Unit 34]` — N หรือ N · บ่อย/ครั้งคราว/แทบไม่

ใช้เมื่อจะเลือกระหว่างคำนามสองคำว่า "N หรือ N" ด้วย (이)나 และเมื่อจะบอกความถี่ว่าทำบ่อยแค่ไหนด้วยคำวิเศษณ์บอกความถี่

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| N ลงท้ายสระ → **-나** (หรือ) | 사과**나** 배 *(แอปเปิลหรือแพร์)* |
| N มีตัวสะกด → **-이나** (หรือ) | 빵**이나** 밥 *(ขนมปังหรือข้าว)* · 금요일**이나** 토요일 *(ศุกร์หรือเสาร์)* |
| คำช่วยอื่นต่อหลังคำนามตัวสุดท้าย | 코미디 영화나 액션 영화**를** 자주 봐요 *(ดูหนังตลกหรือหนังแอ็กชันบ่อย ๆ)* · 집이나 도서관**에서** 숙제를 해요 *(ทำการบ้านที่บ้านหรือห้องสมุด)* |
| **빈도 부사 (คำวิเศษณ์บอกความถี่):** 항상 > **자주** > **가끔** > **거의 안** > **전혀 안** | 떡볶이를 자주 먹어요 *(กินต็อกบกกีบ่อย)* · 가끔 고향 생각이 나요 *(บางครั้งคิดถึงบ้านเกิด)* |
| ความถี่ต่ำ: **거의 안** และ **전혀 안** | 거의 안 가요 *(แทบไม่ไป)* · 전혀 안 먹어요 *(ไม่กินเลย)* |
| ความถี่ = N에 + จำนวนครั้ง และ ทุก… = N마다 | 일주일에 한 번쯤 *(สัปดาห์ละครั้ง)* · 토요일마다 *(ทุกวันเสาร์)* · 날마다 *(ทุกวัน)* |

⚠️ ระวัง

- N(이)나 = "หรือ" ≠ N하고 = "และ" (ข้อ 11)
- ✗ 빵나 · ✗ 사과이나 (สระ → 나 · ตัวสะกด → 이나)
- 전혀/거의 ต้องคู่กับปฏิเสธ (✗ 전혀 먹어요) แต่ 거의 + บอกเล่า = "เกือบ" (숙제를 거의 다 했어요)

### 59. -는 것 `[Unit 35]` — การ… (ทำกริยาให้เป็นนาม)

ใช้เมื่อจะเปลี่ยนกริยาให้เป็นนามว่า "การ…" เพื่อให้เป็นประธาน กรรม หรือภาคแสดงของประโยค

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| **กริยา + -는 것** (ไม่ดูตัวสะกด) | 보다 → **보는 것** *(การดู)* · 먹다 → **먹는 것** *(การกิน)* |
| 있다/없다 ก็ -는 것 | 있다 → **있는 것** *(การมี)* · 없다 → **없는 것** *(การไม่มี)* |
| ㄹ-ราก: ㄹ **หลุด** + 는 것 | 살다 → **사는 것** *(การอยู่)* · 만들다 → **만드는 것** *(การทำ)* · 놀다 → **노는 것** *(การเที่ยวเล่น)* |
| ใช้เป็นประธาน/กรรม/ภาคแสดง | 영화 보는 것을 좋아해요. *(ชอบการดูหนัง)* · 걷는 것은 건강에 좋아요. *(การเดินดีต่อสุขภาพ)* |
| ชอบ B มากกว่า A | 하는 것보다 보는 것을 좋아해요. *(ชอบดูมากกว่าเล่นเอง — ข้อ 41)* |

⚠️ ระวัง

- 좋아하다/싫어하다 + **을/를** แต่ 좋다/싫다/어렵다 + **이/가** (✗ 운동하는 것이 좋아해요)
- ✗ 좋아 안 해요 → 안 좋아해요/좋아하지 않아요
- 먹**는** 것 (การกิน) ≠ 먹**을** 것 (ของกิน ข้อ 56)
- ✗ 살는 것
- 것 ต้องเว้นวรรค

### 60. -아/어/여 보다 `[Unit 35]` — ลอง… · เคย…

ใช้เมื่อจะบอกว่าลองทำสิ่งใดดู หรือเคยทำสิ่งใดมาแล้ว โดยต่อ -아/어/여 보다 ท้ายราก

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ราก ㅏ → **-아 보다** | 가다 → **가 봐요** *(ลองไปดู)* · 타다 → **타 봐요** *(ลองขี่ดู)* · 앉다 → **앉아 봐요** *(ลองนั่งดู)* |
| ราก ㅗ → **-아 보다** | 오다 → **와 봐요** *(ลองมาดู)* |
| สระอื่น → **-어 보다** | 먹다 → **먹어 봐요** *(ลองกินดู)* · 입다 → **입어 봐요** *(ลองใส่ดู)* · 듣다 → **들어 봐요** *(ลองฟังดู)* |
| 하다 → **해 보다** | 하다 → **해 봐요** *(ลองทำดู)* |
| **เคย** = 봤어요 และไม่เคย = 안 … 봤어요 | 제주도에 가 봤어요? — 아니요, 안 가 봤어요. *(เคยไปเชจูไหม — ไม่เคย)* |
| **ลอง** = 보세요 และอยากลอง = 보고 싶어요 | 한번 타 보세요. *(ลองขี่ดูสิ)* · 몽골에서 말을 타 보고 싶어요. *(อยากลองขี่ม้าที่มองโกเลีย)* |

⚠️ ระวัง

- เลือก 아/어 จากสระราก (✗ 살어 봐요 → 살아 봐요)
- ✗ 하 봤어요 → 해 봤어요
- ✗ 가봤어요 (เว้นวรรค 가 봤어요)
- "เคย" ต้อง 봤어요 (อดีต) ≠ 가 줘요/가 주세요 (ข้อ 63)

### 61. -(으)ㄴ/는데요 `[Unit 36]` — …น่ะ (บอกสถานการณ์ · ปฏิเสธอ้อม ๆ)

ใช้เมื่อจะบอกสถานการณ์หรือเหตุผลคร่าว ๆ แล้วทิ้งท้ายไว้ว่า "…น่ะ" เช่น เวลาปฏิเสธคำชวนอย่างอ้อม ๆ

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| กริยา → **-는데요** | 가는데요 *(ไปน่ะ)* · 먹는데요 *(กินน่ะ)* |
| **있다/없다** → **-는데요** | 있는데요 *(มีน่ะ)* · 없는데요 *(ไม่มีน่ะ)* · 재미있는데요 *(สนุกน่ะ)* |
| คำคุณศัพท์ มีตัวสะกด → **-은데요** | 좋은데요 *(ดีน่ะ)* · 많은데요 *(เยอะน่ะ)* |
| คำคุณศัพท์ ไม่มีตัวสะกด → **-ㄴ데요** | 바쁜데요 *(ยุ่งน่ะ)* · 고픈데요 *(หิวน่ะ)* |
| ㅂ ไม่ปกติ (ㅂ → 우 + ㄴ) และราก ㄹ (ㄹ หลุด) | 추운데요 *(หนาวน่ะ)* · 긴데요 *(ยาวน่ะ)* |
| N → **인데요** · N이/가 **아닌데요** · อดีต **-았/었는데요** | 제 자리인데요 *(ที่นั่งของฉันน่ะ)* · 저는 마키인데요 *(ฉันมากิน่ะ)* · 벌써 먹었는데요 *(กินไปแล้วน่ะ)* |
| ใช้ปฏิเสธคำชวน (เหตุผล + -는데요) | 같이 식사할까요? — 배가 안 고픈데요. *(ไปกินข้าวกันไหม — ไม่หิวน่ะ)* / 내일은 다른 약속이 있는데요. *(พรุ่งนี้มีนัดอื่นน่ะ)* |

⚠️ ระวัง

- ✗ 바쁘는데요 และ ✗ 있은데요
- ✗ 먹은데요 (อดีต = 먹었는데요)
- N: ✗ 학생는데요 → 학생인데요
- ไม่ใช่เหตุผลตรง ๆ (-아/어서 ข้อ 48)
- ตอบคำชวนไม่ซ้ำรูป (✗ 네, 갈까요)

### 62. -(으)ㄹ게요 `[Unit 36]` — …นะ / จะ…เอง (สัญญา · อาสา ประธาน = ฉัน)

ใช้เมื่อผู้พูดจะสัญญา อาสา หรือขออนุญาตทำบางอย่างว่า "…นะ" หรือ "จะ…เอง" ซึ่งประธานต้องเป็นฉันเท่านั้น

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| รากสระ → **-ㄹ게요** | 가다 → **갈게요** *(จะไปนะ)* · 사다 → **살게요** *(จะซื้อนะ)* |
| ตัวสะกด → **-을게요** | 읽다 → **읽을게요** *(จะอ่านนะ)* · 닫다 → **닫을게요** *(จะปิดนะ)* |
| ลงท้าย ㄹ → **-게요** (ไม่ซ้ำ ㄹ) | 만들다 → **만들게요** *(จะทำนะ)* · 열다 → **열게요** *(จะเปิดนะ)* · 놀다 → **놀게요** *(จะเที่ยวเล่นนะ)* |
| ㅂ และ ㄷ ไม่ปกติ (ก่อน 으) | 돕다 → **도울게요** *(จะช่วยนะ)* · 듣다 → **들을게요** *(จะฟังนะ)* |
| สัญญา / อาสา / ขออนุญาต | 저녁은 제가 살게요. *(มื้อเย็นฉันเลี้ยง)* · 내일은 꼭 올게요. *(พรุ่งนี้จะมาแน่)* · 문 좀 열게요. *(ขอเปิดประตูนะ)* |

⚠️ ระวัง

- ประธานต้องเป็น "ฉัน" (✗ 친구가 갈게요)
- ถามแผน = -(으)ㄹ 거예요? (✗ 언제 갈게요?)
- ตอบ "뭐 할 거예요?" ด้วย 할 거예요 ไม่ใช่ 할게요
- สะกด ✗ 갈께요
- ✗ 읽게요 → 읽을게요 และ ✗ 만들을게요

### 63. -아/어/여 주세요 `[Unit 37]` — ช่วย…ให้หน่อย (ขอร้อง)

ใช้เมื่อจะขอให้คนอื่นช่วยทำบางอย่างให้ว่า "ช่วย…ให้หน่อย" โดยต่อ -아/어/여 주세요 ท้ายราก

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ราก ㅏ · ㅗ → **-아 주세요** | 앉다 → **앉아 주세요** *(ช่วยนั่งหน่อย)* · 가다 → **가 주세요** *(ช่วยไปให้หน่อย)* · 닫다 → **닫아 주세요** *(ช่วยปิดให้หน่อย)* |
| สระอื่น → **-어 주세요** · 하다 → **해 주세요** | 찍다 → **찍어 주세요** *(ช่วยถ่ายให้หน่อย)* · 바꾸다 → **바꿔 주세요** *(ช่วยเปลี่ยนให้หน่อย)* · 설명하다 → **설명해 주세요** *(ช่วยอธิบายให้หน่อย)* |
| ㅡ · 르 · ㄷ ไม่ปกติ | 끄다 → **꺼 주세요** *(ช่วยปิดไฟให้หน่อย)* · 자르다 → **잘라 주세요** *(ช่วยตัดให้หน่อย)* · 듣다 → **들어 주세요** *(ช่วยฟังให้หน่อย)* |
| เติม 좀 ให้สุภาพ และผู้ใหญ่ → 드리다 (เสริม) | 사진 좀 찍어 주세요. *(ช่วยถ่ายรูปหน่อย)* · 알렉세이 씨 좀 바꿔 주세요. *(ขอสายคุณอเล็กเซย์หน่อย)* |

⚠️ ระวัง

- ✗ 앉어 주세요 (ㅏ → 아)
- ✗ 해주세요 (เว้นวรรค)
- -(으)세요 = เชิญ/สั่ง ≠ -아/어 주세요 = ขอให้ทำให้เรา
- ตอบรับคำขอด้วย 제가 …ㄹ게요 (ข้อ 62)
- ขอไม่ให้ทำ = -지 마세요 (ข้อ 39)

### 64. -아/어/여야 하다/되다 `[Unit 37]` — ต้อง…

ใช้เมื่อจะบอกว่าต้องทำสิ่งใดสิ่งหนึ่ง โดยต่อ -아/어/여야 하다 ท้ายราก และในภาษาพูดใช้ -아/어야 되다 ได้ด้วย

| รูป / เงื่อนไข | ตัวอย่าง |
|:---|:---|
| ราก ㅏ · ㅗ ไม่มีตัวสะกด → **-아야 하다** | 가다 → **가야 해요** *(ต้องไป)* · 오다 → **와야 해요** *(ต้องมา)* · 사다 → **사야 해요** *(ต้องซื้อ)* |
| ราก ㅏ มีตัวสะกด → **-아야 하다** | 받다 → **받아야 해요** *(ต้องรับ)* |
| สระอื่น → **-어야 하다** · 하다 → **해야 하다** | 먹다 → **먹어야 해요** *(ต้องกิน)* · 공부하다 → **공부해야 해요** *(ต้องเรียน)* · 있다 → **있어야 해요** *(ต้องมี)* |
| N + 이다: ตัวสะกด → **N이어야** · สระ → **N여야** | 한국 음식이어야 해요 *(ต้องเป็นอาหารเกาหลี)* · 가수는 목소리가 좋아야 해요 *(นักร้องต้องเสียงดี)* |
| ภาษาพูด **-아/어야 돼요** และเหตุผล + ต้อง | 다음 주에 시험이 있어서 공부해야 해요. *(สัปดาห์หน้ามีสอบ ต้องอ่านหนังสือ)* · 고향에서 친구가 와서 공항에 가야 해요. *(เพื่อนมาจากบ้านเกิด ต้องไปสนามบิน)* |

⚠️ ระวัง

- ✗ 살어야 → 살아야 (ราก ㅏ)
- ✗ 하야 해요 → 해야 해요
- ✗ 해야해요 (เว้นวรรค)
- "ไม่ต้อง" = 안 가도 돼요 (ไม่ใช่ ✗ 안 가야 해요)
- 어떻게 해야 해요? ตอบ**วิธี**
- กรรมใช้ 을/를 (방을 청소해야 해요)
