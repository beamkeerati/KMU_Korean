## 18과 · 본문 듣기 (ฟังบทสนทนาหลัก บทที่ 18 · 서점에 책을 사러 가요)
*ชีตฟังของศูนย์ · คำตอบในภาพเป็นดินสอของคุณเอง · เฉลย = ประโยคจากบทสนทนาในตำรา*

### A. 다음을 듣고, 내용과 같은 것을 고르세요 (ฟังแล้วเลือกข้อที่ตรงกับเนื้อหา)
1. 여자는 책을 샀습니다. (　　) *(ผู้หญิงซื้อหนังสือแล้ว)*
2. 여자는 서점에 갑니다. (　　) *(ผู้หญิงไปร้านหนังสือ)*
3. 남자는 매일 운동을 합니다. (　　) *(ผู้ชายออกกำลังกายทุกวัน)*
4. 남자는 아침에 운동을 합니다. (　　) *(ผู้ชายออกกำลังกายตอนเช้า)*

### B. 듣고 쓰세요 (ฟังแล้วเขียนเติม)
> 알렉세이: 투이 씨, 어디에 가요? *(คุณทุย ไปไหนครับ)*
>
> 투이: 서점에 1)(　　　　　　　　) 가요. *({v:ไป}{n:ร้านหนังสือ}{e:เพื่อ}{v:ซื้อ}{n:หนังสือ}ค่ะ)*
>
> 알렉세이 씨는요? *({a:แล้ว}{n:คุณอเล็กเซย์}ล่ะคะ)*
>
> 알렉세이: 저는 체육관에 2)(　　　　　　) 가요. *({n:ผม}{v:ไป}{n:ยิม}{e:เพื่อ}{v:ออกกำลังกาย}ครับ)*
>
> 투이: 그래요? *({a:อย่างนั้น}หรือคะ)*
>
> 알렉세이 씨는 3)(　　　　) 운동을 하세요? *({n:คุณอเล็กเซย์}{v:ออกกำลังกาย}{q:เมื่อไหร่}คะ)*
>
> 알렉세이: 4)(　　　　　　)과 금요일 5)(　　　　　　　　)에 해요. *({n:วันพุธ}{p:กับ}{n:วันศุกร์} {p:ตอน}{m:บ่าย 4 โมง}ครับ)*
