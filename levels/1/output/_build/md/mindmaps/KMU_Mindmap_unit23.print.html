บุลโกกิเป็นอาหารที่ไม่เผ็ด — ㅂ 불규칙 และคำคุณศัพท์ขยายคำนาม
문법
ไวยากรณ์
ㅂ 불규칙
ราก ㅂ เปลี่ยนก่อนสระ
ㅂ + 아/어 → 워요: 맵다→매워요 · 덥다→더워요
ㅂ หายแล้วเติม 우 + 어 = 워 (ส่วนใหญ่)
ㅂ + 으 → 운: 맵다→매운 · 가깝다→가까운
ก่อน -(으)ㄴ/-(으)ㄹ เป็น 우 เช่นกัน
돕다→도와요 · 곱다→고와요
ข้อยกเว้น 2 คำ: ก่อน 아/어 เป็น 와
입다 · 잡다 · 좁다 = ปกติ
입어요 · 잡아요 · 좁아요 ㅂ ไม่เปลี่ยน
맵습니다 · 맵지 않아요
ก่อนพยัญชนะ (ㅂ니다 · ㅈ) ㅂ คงเดิม
⚠ 맵어요 ✗ → 매워요 · 추와요 ✗ → 추워요
อย่าเขียนรากเดิม · 와 ใช้เฉพาะ 돕다 · 곱다
A-(으)ㄴ N
คำคุณศัพท์ขยายคำนาม
สระ → -ㄴ: 시원한 주스 · 예쁜 옷
ไม่มีตัวสะกด ใช้ -ㄴ
ㄹ → ㄴ: 길다→긴 · 달다→단
ㄹ หลุดแล้วเติม ㄴ
ตัวสะกด → -은: 작은 방 · 넓은 운동장
มีตัวสะกด ใช้ -은
-있다/-없다 → -는: 재미있는 영화 · 맛있는 한식집
กลุ่ม 있다 ใช้ -는
ㅂ: 매운 음식 · 뜨거운 커피 · 가벼운 가방
ㅂ→우+ㄴ
A-지 않은 N: 맵지 않은 음식
ปฏิเสธขยายนาม (ชื่อบท)
⚠ 좋ㄴ ✗ → 좋은 · 맛있은 ✗ → 맛있는
ตัด 으 ไม่ได้ · -있다 ต้อง -는
어떤 + N
ถามลักษณะของสิ่งนั้น
어떤 과일을 좋아해요? → 신 과일을 좋아해요
ถามแบบไหน → ตอบด้วย A-(으)ㄴ N
예쁘고 가벼운 가방
หลายคำ: ตัวแรก -고 ตัวสุดท้าย -(으)ㄴ
⚠ 어떤 (ลักษณะ) vs 무슨 (ชนิด)
무슨 음식 = ชนิดอาหาร · 어떤 사람 = ลักษณะคน
