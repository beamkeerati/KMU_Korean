N시에

N시에 + V: 일곱 시에 일어나요 · 오후 4시에 해요
เวลาเจาะจง + 에 (ตื่นเจ็ดโมง · บ่ายสี่โมงทำ…)

ถามว่าทำกี่โมง → ตอบเวลา + 에

지금 ไม่ใช้ 에 · ถามเวลาที่ทำใช้ 에
V-(으)러 가요/와요
ไป/มา เพื่อ…
받침 ✗·ㄹ → -러: 사다→사러 · 하다→하러 · 만들다→만들러
ไม่มีตัวสะกด หรือ ㄹ ใช้ 러
받침 ○ → -으러: 먹다→먹으러 · 읽다→읽으러 · 씻다→씻으러
มีตัวสะกดใช้ 으러
N에 V-러 가요: 서점에 책을 사러 가요
ตามด้วย 가다/오다/다니다 · กาลอยู่ที่ท้าย (사러 갔어요)
은행에 뭘 하러 가요? → 돈을 찾으러 가요
ไปธนาคารเพื่อทำอะไร → ไปถอนเงิน
⚠ 사러 ✗ → 과일을 사러 · 씻러 ✗ → 씻으러

대화 18-1 · 어디에 가요?
ถามว่าไปไหน ไปทำอะไร กี่โมง
투이 씨, 어디에 가요? → 서점에 책을 사러 가요
คุณตุ้ย ไปไหน → ไปร้านหนังสือเพื่อซื้อหนังสือ
알렉세이 씨는요? → 저는 체육관에 운동하러 가요
แล้วคุณอเล็กเซย์ → ไปยิมเพื่อออกกำลังกาย
언제 운동을 하세요? → 수요일과 금요일 오후 4시에 해요
ออกกำลังกายเมื่อไหร่ → พุธกับศุกร์ บ่ายสี่โมง
