14과 · 친구가 친절해요
บอกลักษณะ · ปฏิเสธแบบยาว · พูดว่า …ก็…ด้วย 도
문법
ไวยากรณ์
형용사 + -아/어요
คำคุณศัพท์ (เป็นภาคแสดงเอง)
어간 끝 ㅏ·ㅗ → -아요: 많아요 · 좋아요 · 작아요 · 싸요
รากศัพท์ลงท้ายสระ ㅏ หรือ ㅗ ใช้ 아요
그 외 → -어요 · 하다 → 해요: 길어요 · 재미있어요 · 친절해요
สระอื่นใช้ 어요 · ลงท้าย 하다 เป็น 해요
ㅡ 어간: ㅡ 빼고 앞 모음 보기: 크다→커요 · 바쁘다→바빠요 · 예쁘다→예뻐요
ตัด ㅡ ออก ดูสระพยางค์หน้า (ㅏ/ㅗ → 아 · อื่น → 어)
N이/가 + 형용사: 날씨가 어때요? → 좋아요
ประธานใช้ 이/가 · ถามลักษณะ 어때요? (ไม่ใช่ 어떻게)
⚠ 날씨를 좋아요 ✗ · 비싸이에요 ✗
คุณศัพท์ไม่มีกรรม 을/를 · ไม่ใส่ 이에요 (좋다 ≠ 좋아하다)
-지 않다
ไม่… (ปฏิเสธแบบยาว = 안)
어간 + -지 않아요: 가지 않아요 · 좋지 않아요 · 마시지 않아요
ต่อท้ายรากศัพท์กริยา/คุณศัพท์ ไม่เปลี่ยนตามตัวสะกด
안 = -지 않다: 안 가요 = 가지 않아요 · 공부 안 해요 = 공부하지 않아요
ความหมายเท่ากัน · 하다 เขียนติดกัน 공부하지
과일이 비싸요? → 아니요, 비싸지 않아요. 싸요
ผลไม้แพงไหม → ไม่แพง ถูก (ปฏิเสธแล้วบอกสิ่งตรงข้าม)
⚠ 이다 → 아니에요 · 있다 → 없어요 (지 않다 ✗)
ไม่ใช่ · ไม่มี ใช้คำเฉพาะ: 학생이지 않아요 ✗ · 있지 않아요 ✗
N도
…ก็ · …ด้วย
N + 도 (받침 ○/✗ 같음): 저도 학생이에요 · 사과도 먹어요
เพิ่มสิ่งที่เหมือนกัน ไม่เปลี่ยนตามตัวสะกด
이/가 · 은/는 · 을/를 자리에 도 (겹침 ✗)
도 แทนที่ ห้ามซ้อน: ✗ 씨가도 · ✗ 씨를도 → ✓ 씨도
영어도 배워요? → 네, 영어도 배워요
เรียนอังกฤษด้วยไหม → ใช่ เรียนอังกฤษด้วย
⚠ 도 ≠ 은/는 · 부정 뒤엔 부정
เหมือนกันใช้ 도 · ต่างใช้ 은/는 · 저도 안 가요 (ก็ไม่ไป)

기숙사 대화 (14-1)
บทสนทนา: อยู่หอกับใคร
기숙사에서 누구와 같이 살아요? → 고향 친구하고 같이 살아요
อยู่หอกับใคร → อยู่กับเพื่อนบ้านเกิด
고향 친구도 한국말을 배워요? → 아니요, 고향 친구는 한국말을 배우지 않아요
เพื่อนก็เรียนไหม → ไม่ ไม่ได้เรียน
그 친구가 친절해요? → 친절해요
เพื่อนคนนั้นใจดีไหม → ใจดี
