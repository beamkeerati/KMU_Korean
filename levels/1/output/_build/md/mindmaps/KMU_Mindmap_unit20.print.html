ผู้รับเป็นคน/สัตว์ · 한테 = พูด · 에게 = พูดและเขียน
윗사람 + 께 + 드리다: 할머니께 선물을 드려요

사물·장소 + 에: 꽃에 물을 줘요 · 사무실에 전화해요

N에게서/한테서
จาก… (ต้นทาง: คน · สัตว์)
한테서 + 받다·빌리다·배우다·듣다: 친구한테서 들었어요
ต้นทางเป็นคน · 한테서 = พูด · 에게서 = พูดและเขียน
사물·장소 → 에서: 회사에서 전화가 왔어요 · 라디오에서 들었어요
ไม่ใช่คนใช้ 에서 (한테서 ✗)
누구한테서 받았어요? → 오빠한테서 받았어요
ถามต้นทาง → ตอบด้วย 한테서
⚠ 동사가 방향 결정: 주다 → 한테 · 받다 → 한테서
ดูกริยา: ไหลออกจากฉัน = 한테 · ไหลเข้าหาฉัน = 한테서
⚠ 부모님께 한국 이야기를 했어요 ✓ · 한테서 ✗
เล่าให้ฟัง = ออก ใช้ 께/한테 · ได้ยินมา = เข้า ใช้ 한테서
