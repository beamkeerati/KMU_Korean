문법
ไวยากรณ์
V/A-았/었/였어요
อดีต "…แล้ว/เคย…" ใช้กับกริยาและคุณศัพท์
어간 ㅏ·ㅗ → -았어요: 가다→갔어요 · 보다→봤어요 · 살다→살았어요
ราก ㅏ/ㅗ ใช้ 았 (มีตัวสะกดอย่าง 살다 ก็ใช้ 았)
그 외 모음 → -었어요: 먹다→먹었어요 · 읽다→읽었어요 · 마시다→마셨어요
สระอื่นใช้ 었 · ไม่มีตัวสะกดจะหดรวม (마시+었=마셨)
하다 → 했어요 · ㅡ 탈락: 썼어요 · 바빴어요 · 컸어요
하다 เป็น 했 · ตัด ㅡ แล้วดูสระพยางค์ก่อนหน้า
숙제를 했어요? → 네, 했어요 / 아니요, 안 했어요
ถามว่าทำแล้วไหม · ปฏิเสธใช้ 안 + อดีต
⚠ 살었어요 ✗ → 살았어요 · 어떻었어요 ✗ → 어땠어요
ดูสระของราก ไม่ใช่ตัวสะกด · 어떻다 เป็น 어땠어요
N이었어요/였어요
เคยเป็น… (นามในอดีต)
받침 ○ → 이었어요: 학생이었어요 · 선생님이었어요
นามมีตัวสะกด + 이었어요
받침 ✗ → 였어요: 의사였어요 · 변호사였어요
นามไม่มีตัวสะกด + 였어요 (ย่อจาก 이었)
부정: N이/가 아니었어요 → 학생이 아니었어요
ปฏิเสธอดีต "ไม่ได้เป็น…"
⚠ 학생였어요 ✗ → 학생이었어요 · 공원였어요 ✗
มีตัวสะกดต้องมี 이 (이었) · คุณเขียนผิดบ่อย
N에서 왔어요
มาจาก… (ประเทศ · เมือง · บ้านเกิด)
N에서 왔어요: 몽골에서 · 베트남에서 · 캐나다에서
ต้นทาง + 에서 + 왔어요 (ต้องเป็นอดีต)
어느 나라에서 왔어요? → 러시아에서 왔어요
ถามประเทศใช้ 어느 나라 (무슨 ✗)
회사에서 일했어요 · 백화점에서 샀어요
에서 = "ที่" ทำกิจกรรม (왔어요 = จาก) · 백화점에 샀어요 ✗
⚠ 한국에서 왔어요 (จาก) ≠ 한국에 왔어요 (ถึง)
에서 = ต้นทาง · 에 = ปลายทาง · 와요 ✗

대화 17-1 · 어디에서 왔어요?
ถามที่มาและชีวิตที่บ้านเกิด
마키 씨는 어디에서 왔어요? → 일본 도쿄에서 왔어요
คุณมากิมาจากไหน → มาจากโตเกียว ญี่ปุ่น
고향에서 무엇을 했어요? → 회사에서 일했어요
ที่บ้านเกิดทำอะไร → ทำงานที่บริษัท
회사 생활이 어땠어요? → 아주 바빴어요
ชีวิตที่บริษัทเป็นอย่างไร → ยุ่งมาก
