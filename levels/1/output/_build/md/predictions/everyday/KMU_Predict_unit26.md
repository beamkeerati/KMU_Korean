#### 2.2 보다 — สูตรสั้น (เต็มในไวยากรณ์ข้อ 41)

ตารางนี้สรุปว่าใครรับ 이/가 ใครรับ 보다 และกริยาแบบไหนต้องเปลี่ยนคำช่วย

| เรื่อง | สูตร | ตัวอย่าง |
|:---|:---|:---|
| โครง | A이/가 B보다 (더) + คำคุณศัพท์/กริยา | 제주도가 서울보다 (더) 따뜻해요 |
| ผู้ชนะ | ตัวที่ "มากกว่า" รับ 이/가 · ตัวเทียบรับ 보다 ติดนามไม่เว้นวรรค | 왕쯔이 씨가 압둘라 씨보다 시험을 잘 봤어요 |
| เครื่องหมายบนบัตร | > = ฝั่งซ้ายชนะ · < = ฝั่งขวาชนะ | 야채 < 고기 → 고기가 야채보다 · 한국노래 < 고향노래 → 고향 노래를 더 자주 들어요 |
| 더 | เน้นความต่าง ตัดทิ้งได้ | 말하기가 듣기보다 어려워요 |
| ประธานสองชั้น | ผู้ชนะ가 + สิ่งที่เทียบ가 + คำคุณศัพท์ | 국민식당이 학생 식당보다 분위기가 더 좋아요 · 축구가 농구보다 선수가 더 많아요 |
| กริยามีกรรม | กรรมรับ 을/를 ไม่ใช่ 이/가 | 야채보다 고기를 더 많이 먹어요 · 김밥보다 떡볶이를 더 좋아해요 |
| ตอบให้ตรงคำถาม | 누구 가족이 → ชื่อ + 가족이 · 어느 식당이 → ชื่อร้าน + 이/가 | 바트 가족이 윤아 가족보다 더 많아요 |
| สลับตำแหน่ง | B보다 A가 ก็ได้ | 형보다 내가 더 많이 먹어요 |

#### 2.4 จุดที่คุณเคยพลาดเอง — เช็กก่อนส่ง

- **ตัวชนะ/ตัวแพ้ของ 보다:** ดูตัวเลขหรือเครื่องหมายก่อน แล้วผู้ชนะ + 이/가 (ใบฝึก B2)
- **คำช่วยในวลี 보다:** 학생 식당보다 (ไม่ใส่ 이 ก่อน 보다 และ 보다 ติดตัวเทียบ) (เวิร์กบุ๊ก D2 D3)
- **เลือกความรู้สึกให้เข้ากัน:** 노래방 → 시끄럽겠어요 ไม่ใช่ 행복하겠어요 (F3)
- **อย่าเว้นว่าง:** F4 คุณเว้นว่าง · เขียนคำที่ใกล้ที่สุดไว้ก่อน
- **ศัพท์:** 앉다 = นั่ง · 시끄럽다 = เสียงดัง · 슬프다 = เศร้า
- **สระ:** 매워요 / 세일 / 배 ใช้ ㅐ ㅔ ให้ถูก (บทก่อนคุณเขียน 메워요 และ 테국)
- **ㅈ/ㅊ:** 제주도 · 이번 주 · 작년 · 차 ไม่เหมือน 자
- **ตอบให้ตรงคำถาม:** 누구 가족이 → ชื่อคน + 가족이 ไม่ตอบเป็นชื่อคนเดี่ยว ๆ
